# 重点企业空间分布地图/列表视图切换设计

> 日期：2026-07-23  
> 模块：ENT-KEYENT / 重点企业分析  
> 页面：`/enterprise-center/key-enterprise-analysis`  
> 适用区域：类型与区域分析 → 重点企业空间分布

## 1. 目标

让“重点企业空间分布”与“企业分布情况”采用一致的地图/列表双视图心智模型。用户可在不丢失当前区域浏览状态和右侧区域洞察的前提下，切换空间对象的可视化或结构化查看方式。

默认进入地图视图。

## 2. 范围

本次只调整“重点企业空间分布”主工作区：

- 在区域标题区增加“地图视图 / 列表视图”切换。
- 地图视图保留现有地图、面包屑、返回上一级、下钻和企业点位选择。
- 列表视图展示与当前地图层级相同的空间对象。
- 列表提供分页、固定首尾列和中间字段横向滚动。
- 列表操作支持“在地图中查看”；企业“查看画像”统一使用页面内宽幅画像抽屉。
- 右侧“区域洞察”在两种视图下保持可见，并继续使用同一当前区域、企业类型和企业集合状态。

不调整顶部筛选条件、右侧区域洞察结构、企业清单 Drawer、领域分布分析，也不新增“进入企业查询”动作。

## 3. 交互设计

### 3.1 视图切换

- 使用现有 Arco 小尺寸按钮样式，文案为“地图视图”和“列表视图”。
- 当前视图按钮使用主色选中态，另一按钮使用次级态。
- 初始状态固定为 `map`，不跨会话持久化。
- 切换视图不改变顶部筛选、地图面包屑、当前区域、已选类型或右侧洞察。

### 3.2 层级等价

列表与地图读取同一个当前层级数据：

| 当前层级 | 地图对象 | 列表对象 |
| --- | --- | --- |
| 国家 | 省级聚合点 | 省级区域行 |
| 省 | 城市聚合点 | 城市区域行 |
| 市 | 区县聚合点 | 区县区域行 |
| 区县 | 企业点位 | 企业行 |

区域行至少展示地域名称与重点企业数量，并提供“在地图中查看”动作。企业行展示企业名称、所在区域、产业和企业类型，并提供“在地图中查看”“查看画像”两个动作。

列表中的区域“在地图中查看”与地图点击区域完全等价：进入下一级、更新当前区域和右侧洞察，并切换到地图视图，但不反写顶部区域筛选。区县企业行的“在地图中查看”切换到地图视图并选中对应企业点位，不产生新的行政层级；“查看画像”打开当前页面内统一的宽幅企业详情抽屉。

### 3.3 表格与画像抽屉

- 列表使用 Arco `Table`，每页展示 10 条；分页只改变当前列表页，不改变地图层级、顶部筛选或右侧洞察。
- 首列固定在左侧，承载地域名称或企业名称；操作列固定在右侧。
- 产业、区域、企业类型等中间字段放入可横向滚动区域。横向滚动只发生在表格内部，页面不得产生水平溢出。
- 操作列宽度必须同时容纳两个企业动作，且固定后不遮挡中间内容。
- 企业“查看画像”复用现有 `ElementProfile` 企业详情能力，使用 `clamp(1040px, 80vw, 1520px)` 的右侧宽幅 Drawer；关闭抽屉后保留列表页码、横向滚动位置、行政层级和右侧洞察。

### 3.4 返回与空状态

- “返回上一级”在地图和列表视图中共用，行为不变。
- 当前层级无对象时，主工作区保持稳定高度并显示局部空状态。
- 列表加载或错误时只影响主工作区，不清空顶部筛选或右侧既有上下文。

## 4. 页面结构

页面继续采用 `17/24 + 7/24` 的地图/列表分析工作台：

```text
┌──────────────────────────────────────┬──────────────────┐
│ 重点企业空间分布  [地图视图][列表视图] │ 区域洞察         │
│ 面包屑                    返回上一级 │ 当前区域         │
│                                      │ 类型结构         │
│ 地图 或 同层级列表                    │ 同级区域分布     │
└──────────────────────────────────────┴──────────────────┘
```

切换仅替换左侧主内容，不将列表扩展为全宽页面，不隐藏右侧洞察。

## 5. 状态与数据边界

- 新增局部状态 `distributionView: "map" | "list"`，默认 `"map"`。
- 继续由现有 `mapPath` 决定当前地图/列表层级。
- 新增列表局部分页状态；层级或顶部范围改变时回到第一页，单纯切换地图/列表时保留当前页。
- 继续由现有区域数据和企业记录派生列表，不引入新的样例数据或指标口径。
- 企业数量沿用 `M_ENT_REGIONAL_COUNT`，不新增验收指标。
- 该能力属于 E-21 三级地理透视的产品交互解释，不新增 Bid 叶子。

## 6. 可访问性与视觉

- 切换控件使用真实 `Button`，具备可见文字、选中态、键盘焦点和指针点击路径。
- 列表使用 Arco `Table`，不制作页面私有表格控件。
- 分页使用 Arco Table 分页能力；固定列和横向滚动使用 Arco `fixed` 与 `scroll.x` 配置。
- 画像详情使用页面现有 Arco `Drawer` 与 `ElementProfile`，不跳转到另一页面，也不新增画像组件。
- 工作区高度保持现有最低 `520px`，切换时不引发布局跳变。
- 颜色、字号、间距和控件尺寸沿用 GKX 与当前“企业分布情况”实现。

## 7. 验证

自动化验证覆盖：

1. 默认渲染地图视图。
2. 点击“列表视图”后出现当前层级列表且地图隐藏。
3. 点击区域行进入下一层并更新面包屑和区域洞察。
4. 点击“返回上一级”恢复上一层，且当前仍为列表视图。
5. 再切回地图时保留同一浏览层级。
6. 右侧区域洞察在两种视图下持续存在。
7. 列表每页 10 条，首列和操作列固定，中间内容在表内横滑且页面无横向溢出。
8. 地域“在地图中查看”进入目标层并显示地图；企业“在地图中查看”选中对应点位。
9. 企业“查看画像”打开宽幅企业详情抽屉，关闭后列表上下文不变。

浏览器验证覆盖真实指针切换、列表下钻、返回和地图恢复，并在 `1920 / 1680 / 1440` 三档检查工作区比例与稳定高度。

## 8. 非目标

- 不将企业清单 Drawer 合并进列表视图。
- 不新增导出、批量选择或自定义排序规则。
- 不改变地图缩放、热力、全屏或底图能力。
- 不修改领域分布分析。
- 不据此宣称 PDR、Gate、发布或部署完成。
