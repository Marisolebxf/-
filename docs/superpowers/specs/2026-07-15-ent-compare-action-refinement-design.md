# 对比篮空态、搜索与分析分发修订设计

## 目标

修订 `ENT-COMPARE` 产品定义四件套，使对比篮只承担企业对象暂存、管理与明确分发，不承担企业推荐，也不用合并动作隐藏目标分析类型。

## 已确认产品结论

1. 空对比篮不展示固定重点企业或明星企业推荐；只保留“去企业查询”主操作和目标能力说明。
2. 篮内搜索只按企业名称，不提供统一社会信用代码搜索。统一社会信用代码仍可作为企业识别字段和去重键，不因搜索能力收缩而删除。
3. 批量工具栏保留两个分组入口：
   - `企业评估 ▾`：`技术力评估`、`商业力评估`、`综合竞争力评估`。
   - `风险洞察 ▾`：`供应链关系分析`、`发展痛难点分析`。
4. 用户选择具体分析类型后，对比篮只传递已选企业、来源和 `analysis_type`；对象数量、权限、字段与模型条件仍由目标模块校验。

## 交互与状态

- 未选企业时，两个分组入口均不可执行，并提示“请先选择企业”。
- 已选企业时，点击分组入口展开对应分析菜单；不弹出额外模态框。
- 具体分析类型因权限不可用时，菜单项保留且显示不可用原因，不静默隐藏；具体对象数量和字段条件进入目标模块后再校验。
- 选择菜单项后直接进入对应目标模块，不在对比篮设置指标、权重或生成结果。

## 四件套修订范围

- IA：删除空态推荐职责，将批量分发区改为两个分组、五个明确分析落点。
- TRACE：移除 Q037 与空态推荐映射，修订允许搜索字段、分析类型及验收条件。Q037 仅从对比篮包移除，不删除全局决策清单中的原记录。
- USM：将空态故事收缩为去企业查询，将评估 / 风险分发改为先选具体分析类型再跳转。
- Wireframe：删除推荐企业卡片，搜索框改为仅企业名称，工具栏改为两个分组下拉入口并写明五个菜单项。

## 验证标准

- 四件套不再出现对比篮推荐企业或 Q037 模块开放项。
- 四件套不再声称可按统一社会信用代码搜索。
- 企业评估的 3 种、风险洞察的 2 种分析名称在 IA、TRACE、USM、Wireframe 中完全一致。
- 对比篮仍不生成分析结果，不配置指标或权重。
