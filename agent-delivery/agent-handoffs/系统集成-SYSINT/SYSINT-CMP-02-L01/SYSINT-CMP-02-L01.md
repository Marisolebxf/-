## 4. 核心结论（供决策）

1. **五分类**：①完全能对应 38 + ②大概率一致 55 = 93；③④⑤为 0。域外发现：久新研究问题域 45 张表在 3 份需求文档 0 命中，属⑤类自有设计，不接。
2. **四轮裁决**（R1 需规度淘汰 → R2 依赖指标支撑度 → R3 权威引用 → R4 加权求和兜底）：**本地 65 / 久新 26 / 相当 2**。R1 淘汰久新 48 条（久新只有原料表或无数据，未做设计）；R2 久新胜 18 条（结果已算好落表）；R3 本地 21 / 久新 4。
3. **决策建议**：以本地 565 指标设计为主干、久新 130 表作为数据供给层接入。久新版胜出 26 条按「口径守本地 8 件套、数值消费久新结果表 + 对账」处置。
