# UX-UE 通用交互组件规范

适用范围：科技信息展示系统、科技专题服务系统  
当前存放：`gkx-orchestration/agent-delivery/agent-handoffs/产品整体定义`
版本：v0.1  
来源：Figma《交互组组件库》页面 / frame 抽取，结合通用交互场景补齐  

## 1. 编写原则

本规范用于沉淀两个系统可复用的交互组件与行为规则，优先服务数据展示、趋势研判、专题分析、资源匹配、图谱探索、报告导出等高频工作流。

本规范面向 UX、UE、UI 和前端协作中的交互一致性，不替代前端代码规范、架构规范、组件实现方案、接口规范或测试规范。其他智能体在编写代码时，可以把本文作为交互行为、状态覆盖、键盘可达性和 Arco 组件选型的参考，但不得仅凭本文改变技术架构、数据流、权限模型或既有代码约定。

本文初稿以 Figma 页面 / frame 为主要输入源，迁入本仓后以本文、Figma 后续变更和团队确认记录为准。Figma 当前可抽取到的主 frame 包含“科技信息展示系统 / Dashboard 1680x944”和“通用组件 / 地图相关 / 遮罩 / 右侧详情 Drawer”。其中 Dashboard frame 包含左侧导航、顶部页签、筛选区、内容画布、排行表、趋势图、指标体系、对比图、人才流动图、资源表格与行内操作等组件；地图 frame 包含地图工具栏、热力开关、基础图例和热力强度分级图例；抽屉样例包含页面遮罩、右侧非模态详情 Drawer、header、可滚动 body 和固定 footer 操作区。图谱、导出、权限态在当前可见 frame 中未完整出现，本规范按同一交互语言补齐为通用规则，并在组件分类中标注来源等级。

前端和 UI 组件库以 Arco Design React 为基础。交互规范应优先复用 Arco 已定义的组件结构、状态语义、键盘行为和无障碍能力，再结合科技信息展示与专题服务业务场景做扩展。若 Figma 定义与 Arco 默认交互存在差异，以 Figma 的交互定义为准，并通过 Arco 组件扩展、组合或二次封装实现；实现过程中不得破坏基础可访问性、焦点管理和弹层行为。具体颜色、字号、圆角、阴影等视觉 token 归属 UI 视觉规范或 Arco 主题规范，不在本文展开。

### 1.1 来源等级

| 等级 | 含义 | 使用方式 |
| --- | --- | --- |
| A | Figma frame 中可见并可抽取结构 | 可作为当前实现与设计走查的直接依据 |
| B | 由可见组件模式推导出的同类规则 | 可用于同类页面，但需结合业务验证 |
| C | 为通用系统能力补齐的规范项 | 可作为新需求设计基线，落地前需与具体业务确认 |

### 1.2 通用组件与业务组件边界

| 类型 | 定义 | 示例 | 规范归属 |
| --- | --- | --- | --- |
| 通用交互组件 | 不依赖具体业务含义，可跨页面复用的控件、容器与状态规则 | 导航、页签、筛选器、卡片、表格、图表容器、抽屉、弹窗、导出按钮、权限占位 | 本文定义结构、状态、键盘、无障碍、异常态 |
| 业务组件 | 由通用组件组合而成，承载特定业务语义、指标口径或业务动作 | 全球热点技术捕捉、技术与产业热点动态跟踪、科创资源整合与推送、人才流动监控 | 本文只定义拆解方法与复用边界，不固化业务指标 |

业务组件必须拆成两层描述：先说明它用了哪些通用组件，再说明业务字段、默认筛选、联动关系、权限约束和导出规则。

### 1.3 Arco 交互基准

| 规范项 | Arco 基础 | 补充规则 |
| --- | --- | --- |
| 组件优先级 | 优先使用 Arco 原生组件，如 `Menu`、`Tabs`、`Select`、`Cascader`、`DatePicker`、`Table`、`Drawer`、`Modal`、`Button`、`Tag`、`Tooltip`、`Dropdown`、`Spin`、`Skeleton`、`Empty`、`Result`、`Message`、`Notification` | 顶部与左侧导航按 Figma 定制化组件实现，但需保留 Arco 同类组件的状态、键盘和无障碍语义；其他组件只有当 Arco 原生能力无法表达复杂可视分析行为时，才封装业务组件 |
| 状态语义 | 沿用 Arco 的 `disabled`、`loading`、`error`、`success`、`warning`、`checked`、`selected`、`active` 等状态 | 业务态不得另起一套视觉语言；应映射到 Arco 状态后再扩展 |
| 弹层体系 | 下拉用 `Dropdown` / `Select` 弹层，轻量确认用 `Popconfirm`，复杂配置用 `Modal`，详情承载用 `Drawer` | 不把复杂表单塞进 tooltip；不把详情页伪装成弹窗 |
| 表单校验 | 使用 Arco 表单项校验、错误提示和帮助文本模式 | 校验文案说明修复动作，不只写“错误” |
| 反馈体系 | 短反馈用 `Message`，持续或后台任务用 `Notification`，页面级结果用 `Result` | 导出、推送、权限申请等异步任务需要明确完成位置 |
| 空态与加载 | 使用 `Empty`、`Spin`、`Skeleton` 作为基础 | 数据密集卡片优先 skeleton；整页阻塞只用于首次加载 |
| 主题边界 | 具体视觉 token 以 UI 视觉规范和 Arco 主题为准 | 本文只约束交互语义、状态可辨识性和组件复用边界 |
| 无障碍 | 保留 Arco 组件自带的键盘与 ARIA 行为 | 自定义图表、地图、图谱必须补等价键盘路径和文本替代 |

## 2. 全局交互语言

### 2.1 页面骨架

页面采用“左侧主导航 + 顶部用户区 + 顶部页签 + 内容画布”的工作台结构。

| 区域 | Figma 表现 | 通用规则 | 来源 |
| --- | --- | --- | --- |
| 左侧导航 | 定制化侧栏，菜单纵向排列，当前项有明确选中态 | 用于系统级模块切换；当前项必须高亮；可展开项显示箭头；长导航需支持滚动或折叠；实现可不直接使用 Arco `Menu`，但需保留菜单语义 | A |
| 顶部用户区 | 右上角胶囊用户身份入口 | 用于角色、组织、退出、个人设置；不承载业务筛选 | A |
| 顶部页签 | 定制化横向页签组，当前页签有明确选中态 | 用于同一模块内视角切换；切换不应丢失全局筛选，除非业务明确要求重置；实现可不直接使用 Arco `Tabs`，但需保留页签语义 | A |
| 内容画布 | 主工作区容器，承载筛选区和多个数据卡片 | 用于组织分析内容；画布内部遵循从筛选到结论、从总览到明细的阅读顺序 | A |

### 2.2 交互密度与视觉边界

| 项 | 规则 |
| --- | --- |
| 视觉规范边界 | 本文不规定主色、背景色、字号、圆角、阴影、图标风格、图表配色等视觉 token |
| 栅格系统边界 | 本文不定义完整栅格系统、断点、间距 token 或布局尺寸规范；仅定义与交互行为相关的布局关系和响应策略 |
| 交互状态可辨识 | 选中、禁用、错误、警告、成功、加载等状态必须可被清楚识别，并沿用 Arco 语义状态 |
| 非颜色依赖 | 状态和数据含义不能只依赖颜色表达，必须配合文本、图例、形状、位置或可访问名称 |
| 信息密度 | 管理驾驶舱和分析工作台允许高信息密度，但必须保留标题、筛选、数据、操作之间的明确边界 |
| 冲突处理 | 当 Figma 定义与 Arco 默认交互冲突时，以 Figma 为准，通过 Arco 扩展、组合或二次封装实现，同时保留焦点、键盘、弹层和无障碍能力 |

### 3.1 Arco 组件映射

| 交互组件 | Arco 基础组件 | 组合 / 扩展建议 |
| --- | --- | --- |
| 左侧导航 | 定制导航组件 + `Menu` 语义 | 按 Figma 定制化实现侧栏结构、图标、选中态和展开态；不要求直接使用 Arco `Menu`，但交互语义需对齐菜单组件 |
| 一级 Tab / 顶部页签 | 定制页签组件 + `Tabs` 语义 | 按 Figma 定制化实现顶部页签；选中项使用主色文字 + 底部指示条，不要求直接使用 Arco `Tabs`，但交互语义需对齐页签组件 |
| 面包屑导航 | `Breadcrumb` | 展示当前位置和层级回溯路径；不替代主导航、页签或筛选器 |
| 筛选器 | `Select`、`Cascader`、`DatePicker`、`TreeSelect`、`Input.Search` | 复杂筛选组合成 FilterBar；保留 Arco 弹层、清除、搜索、多选行为 |
| 二级圆角 Tab | `Radio.Group`、`Segmented` 或自定义 Tab 组 | 卡片、面板或局部区域内的二级视角切换；选中项使用圆角浅底 + 主色文字 |
| 按钮组 | `Radio.Group`、`Segmented` | 紧凑单选按钮组，用于模式、粒度、排序等互斥切换；选中项使用白底浮层 + 主色文字 |
| 标签 | `Tag` | 状态标签用 `Tag`；只表达状态，不承担主要点击入口 |
| 数据卡片 | `Card` | 只作为单个分析单元容器；避免卡片套卡片 |
| 指标卡 | `Statistic`、`Card` | 指标值、变化率、趋势箭头组合，状态语义沿用 Arco |
| 表格 | `Table` | 排序、筛选、固定列、空态、加载态、分页优先使用 Arco 内建能力 |
| 行内操作 | `Button`、`Link`、`Popconfirm`、`Dropdown` | 主次动作按 Arco 按钮语义区分；危险动作必须确认 |
| 图表容器 | `Card`、`Spin`、`Empty`、`Tooltip` | 图形由 ECharts / 地图库 / 图谱库承载，外围状态和操作用 Arco |
| 地图容器 | `Card`、`Drawer`、`Tooltip`、`Checkbox`、`Switch` | 图层控制可用 Checkbox / Switch；详情用 Drawer |
| 图谱容器 | `Card`、`Drawer`、`Input.Search`、`Tag` | 节点搜索、关系筛选、详情抽屉使用 Arco 组件组合 |
| 详情抽屉 | `Drawer`、`Descriptions`、`Tabs`、`Timeline` | 对象详情、证据链、关联对象、操作记录分区展示 |
| 遮罩 | `Drawer`、`Modal` 内建 mask | 需要阻断背景操作时启用；非模态抽屉可不阻断背景但仍需管理层级 |
| 弹窗配置 | `Modal`、`Form`、`Steps` | 推送设置、关注条件、导出配置等使用 Modal + Form |
| 导出 | `Button`、`Dropdown`、`Progress`、`Notification` | 多格式导出用 Dropdown；后台导出用 Notification / Progress |
| 权限态 | `Result`、`Tooltip`、`Button`、`Alert` | 仅保留通用占位能力；具体权限态规则引用权限专项文档 |

### 3.2 组件实现约定表

本表用于约束通用组件的实现语义，帮助 frontend-agent、qa-agent 和后续组件库建设对齐。它不是 TypeScript `Props` 接口定义，也不替代前端组件库 API 文档；具体属性命名可按代码库约定落地，但必须保留对应交互能力、状态语义和事件语义。

| 组件 | Arco 基础 | 适用场景 | 必备配置 | 状态字段 | 事件语义 | 异常入口 | 禁用策略 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 左侧导航 | 定制导航组件 + `Menu` 语义 | 系统级模块切换、二级菜单展开 | 当前项、展开项、禁用项、图标、路径映射 | `selectedKey`、`openKeys`、`disabled`、`loading` | `onMenuSelect`、`onOpenChange` | 目标内容区显示加载 / 错误，不让整条导航闪烁 | 无权限或未开放项保留可见时使用禁用或锁态，具体权限按专项文档 |
| 一级 Tab / 顶部页签 | 定制页签组件 + `Tabs` 语义 | 模块内平级视角切换、结果分组 | 当前页签、禁用页签、保留筛选上下文、底部指示条 | `activeKey`、`disabled`、`loading` | `onTabChange` | 页签内容区展示加载、空态、错误态 | 不支持当前上下文的页签禁用并说明原因 |
| 二级圆角 Tab | `Radio.Group`、`Segmented` 或自定义 Tab 组 | 卡片、面板、抽屉内的局部视角切换 | 当前项、禁用项、与上级 Tab 的作用域绑定 | `activeKey`、`disabled`、`loading` | `onSubTabChange` | 所在局部容器展示加载、空态、错误态 | 不支持当前局部上下文的项禁用并说明原因 |
| 按钮组 | `Radio.Group`、`Segmented` | 模式、粒度、排序、展示口径等互斥切换 | 当前项、选项列表、紧凑尺寸、防重复触发 | `value`、`disabled`、`loading` | `onSegmentChange` | 所影响的数据区展示加载、空态、错误态 | 不可用选项禁用；不静默改选到其他项 |
| 面包屑导航 | `Breadcrumb` | 页面、对象、地图下钻、图谱节点等层级回溯 | 当前项只读、上级可点击、过长折叠 | `currentKey`、`disabled` | `onBreadcrumbClick` | 不单独承载异常；返回失败时使用页面反馈 | 返回会丢失未保存内容时阻断并确认 |
| 筛选器 | `Select`、`Cascader`、`TreeSelect`、`DatePicker`、`Input.Search` | 时间、区域、领域、对象类型等条件筛选 | 默认值、清除、搜索、多选 / 级联、远程加载 | `value`、`loading`、`disabled`、`error`、`empty` | `onFilterChange`、`onSearch`、`onClear` | 下拉面板或筛选区内展示加载、空态、错误和重试 | 无权限或上下文不支持时禁用；不静默清空已有合法条件 |
| 操作按钮 | `Button`、`Link`、`Popconfirm`、`Dropdown` | 查询、重置、关注、推送、查看详情、危险操作 | 主次层级、loading、防重复提交、危险确认 | `loading`、`disabled`、`active`、`danger` | `onAction`、`onConfirm`、`onCancel` | 操作失败用 Message / Notification / 局部错误承载 | 无权入口可可见但禁用 / 锁态 / 申请引导，按权限专项文档 |
| 表格 | `Table` | 资源列表、热点排行、对象明细、操作列表 | 列定义、排序、筛选、分页、行操作、可选行选择 | `loading`、`empty`、`error`、`selectedRowKeys`、`sorter`、`pagination` | `onRowOpen`、`onSortChange`、`onPageChange`、`onSelectionChange` | 表头保留，行区域展示 skeleton / Empty / Error + retry | 行或操作无权时禁用对应操作；敏感字段处理按权限专项文档 |
| 图表容器 | `Card`、`Spin`、`Empty`、`Tooltip` + 图表内核 | 折线、柱状、排行、桑基等可视分析 | 标题、图例、指标切换、tooltip、数据下载入口 | `loading`、`empty`、`error`、`selectedDatum`、`activeLegend` | `onChartPointClick`、`onLegendToggle`、`onMetricChange` | 图形区展示加载、空态、错误，不移动标题和操作区 | 无权数据不直接渲染；展示规则按权限专项文档 |
| 地图容器 | `Card`、`Button`、`Switch`、`Tooltip` + 地图内核 | 空间分布、点位、热力、区域选择 | 工具栏、热力开关、基础图例、热力强度图例、框选 | `loading`、`empty`、`error`、`heatmapEnabled`、`selectedRegion`、`selectedPoint` | `onMapZoom`、`onMapReset`、`onHeatmapToggle`、`onRegionSelect`、`onBoxSelect` | 区分底图加载、业务图层加载、热力无数据、底图失败 | 无权对象类型或热力层按专项文档处理，保持图例和布局稳定 |
| 详情抽屉 | `Drawer`、`Descriptions`、`Tabs`、`Table`、`Timeline` | 对象详情、证据摘要、关联对象、配置结果 | header、可滚动 body、固定 footer、关闭、业务可调宽度 | `open`、`loading`、`error`、`readonly`、`width` | `onDrawerOpen`、`onDrawerClose`、`onPrimaryAction` | 抽屉先打开，body 区域展示 skeleton / error，保留关闭入口 | 未保存内容关闭需确认；无权区块处理按权限专项文档 |
| 弹窗配置 | `Modal`、`Form`、`Steps` | 推送设置、关注条件、导出配置、确认操作 | 标题、表单校验、确认 / 取消、关闭确认 | `open`、`loading`、`validating`、`disabled`、`dirty` | `onSubmit`、`onCancel`、`onValidate` | 表单项内展示校验错误；提交失败保留用户输入 | 不可配置时禁用入口并说明原因；权限细节引用专项文档 |
| 遮罩 | `Drawer`、`Modal` 内建 mask | 模态阻断、背景降噪、弹层层级管理 | 是否阻断背景、是否允许点击关闭、层级顺序 | `open`、`modal`、`maskClosable` | `onMaskClick`、`onEscClose` | 不单独承载异常 | 存在未保存内容或强制流程时不允许点击遮罩直接关闭 |
| 导出入口 | `Button`、`Dropdown`、`Progress`、`Notification` | 卡片、表格、报告、配置导出 | 格式选择、当前筛选上下文、异步任务反馈 | `loading`、`disabled`、`progress`、`error` | `onExportStart`、`onExportSuccess`、`onExportError` | 导出失败显示原因和重试；数据过大提示异步生成 | 无导出能力时禁用或引导申请，具体规则按权限专项文档 |

### 3.3 Arco API 映射表

本表用于把通用交互组件映射到可落地的 Arco API 或定制组件语义。顶部与左侧导航为 Figma 定制化组件，不要求直接使用 Arco `Menu` / `Tabs`，但实现时必须保留 Arco 同类组件的状态、事件、键盘与无障碍语义。具体代码实现可按项目组件封装调整，但不得丢失表中的状态、事件和禁用语义。

| 通用组件 | 建议 Arco 组件 / 组合 | 必须保留的能力 | 关键事件 | 实现约束 |
| --- | --- | --- | --- | --- |
| 左侧导航 | 定制导航组件 + `Menu` 语义 | 当前项、展开项、禁用项、图标、路径映射 | `onMenuSelect`、`onOpenChange` | 按 Figma 定制侧栏实现，不验收是否直接使用 Arco `Menu`；必须保留菜单语义、键盘路径和当前项可辨识性 |
| 一级 Tab / 顶部页签 | 定制页签组件 + `Tabs` 语义 | 当前页签、禁用页签、切换事件、底部指示条 | `onTabChange` | 按 Figma 定制顶部页签实现，不验收是否直接使用 Arco `Tabs`；必须保留页签语义、键盘路径和选中态 |
| 二级圆角 Tab | `Radio.Group`、`Segmented` 或自定义 Tab 组 | 当前项、禁用项、单选切换、局部刷新 | `onSubTabChange` | 用于卡片、面板、抽屉内局部视角；只刷新所在容器 |
| 按钮组 | `Radio.Group type="button"`、`Segmented` | 当前值、选项列表、禁用项、单选切换 | `onSegmentChange` | 用于模式、粒度、排序等互斥选择；同组只能有一个选中项 |
| 标签 | `Tag` | 状态、类型、颜色、可关闭状态 | `onClose` | 只表达状态或类型；不可替代按钮、页签或筛选项 |
| 筛选器 | `Select`、`Cascader`、`TreeSelect`、`DatePicker`、`Input.Search` | 值、清除、多选、远程搜索、加载、空态、错误态 | `onFilterChange`、`onSearch`、`onClear` | 筛选条件必须显性可见；不可静默清空已有合法条件 |
| 操作按钮 | `Button`、`Link`、`Popconfirm`、`Dropdown` | 主次层级、loading、防重复提交、危险确认 | `onAction`、`onConfirm`、`onCancel` | 主次动作清晰；危险动作必须二次确认；异步操作防重复提交 |
| 数据卡片 | `Card` | 标题、右上操作、加载态、空态、错误态 | `extra` 区操作事件 | 卡片只承载单个分析单元；内部切换使用二级圆角 Tab 或按钮组 |
| 图表容器 | `Card`、`Spin`、`Empty`、`Tooltip` + 图表内核 | 标题、图例、指标切换、tooltip、加载、空态、错误态 | `onLegendToggle`、`onMetricChange`、图表点击事件 | Arco 负责外围状态和操作；图表库负责渲染内核 |
| 地图容器 | `Card`、`Button`、`Switch`、`Tooltip` + 地图内核 | 工具栏、热力开关、基础图例、热力强度图例、选中对象 | `onMapZoom`、`onMapReset`、`onHeatmapToggle`、`onRegionSelect` | 工具栏、开关、图例用通用控件；地图内核负责缩放、点位、热力 |
| 图谱容器 | `Card`、`Input.Search`、`Tag`、`Drawer` + 图谱内核 | 节点搜索、类型筛选、节点选中、关系展开、详情抽屉 | `onNodeSelect`、`onEdgeSelect`、`onSearch`、`onFilterChange` | 大图谱需限制展开数量；必须提供重置视图和搜索定位 |
| 表格 | `Table`、`Pagination`、`Dropdown`、`Popconfirm` | 列定义、排序、筛选、分页、行选择、行内操作 | `onTableChange`、`onRowOpen`、`onSelectionChange` | 排序、筛选、分页优先用 Arco 内建能力；行内危险操作需确认 |
| 详情抽屉 | `Drawer`、`Descriptions`、`Tabs`、`Table`、`Timeline` | 打开关闭、宽度、滚动 body、固定 footer、加载和错误态 | `onDrawerOpen`、`onDrawerClose`、`onPrimaryAction` | 默认保留上下文；复杂内容用可滚动 body + 固定 footer |
| 弹窗配置 | `Modal`、`Form`、`Steps` | 打开关闭、表单校验、提交 loading、取消确认 | `onSubmit`、`onCancel`、`onValidate` | 用于配置、确认、审批等阻断流程；提交失败保留用户输入 |
| 遮罩 | `Drawer` / `Modal` 内建 mask | 是否阻断背景、是否允许点击关闭、Esc 关闭 | `onMaskClick`、`onEscClose` | 只表达层级和阻断；存在未保存内容时不得直接关闭 |
| 导出入口 | `Button`、`Dropdown`、`Progress`、`Notification` | 格式选择、导出 loading、进度、成功反馈、失败重试 | `onExportStart`、`onExportSuccess`、`onExportError` | 导出必须携带筛选上下文；失败需说明原因并支持重试 |
| 权限态 | `Result`、`Tooltip`、`Alert`、`Button` | 无权限占位、禁用说明、申请入口、只读或脱敏提示 | 申请权限、返回或关闭事件 | 仅保留通用占位能力；具体权限规则引用权限专项文档 |

### 3.4 通用组件验收用例

本表用于设计走查、前端自测和 QA 验收。验收重点是交互语义、状态覆盖、上下文保留和可访问性，不把“是否直接使用某个 Arco 原生组件”作为唯一标准。

| 组件 | 验收标准 |
| --- | --- |
| 左侧导航 | 符合 Figma 定制视觉；当前模块高亮明确；展开 / 收起不清空页面筛选；禁用项不可点击并说明原因；保留菜单语义、键盘操作和无障碍状态 |
| 一级 Tab / 顶部页签 | 符合 Figma 定制视觉；当前项有主色文字和底部指示条；切换不清空全局筛选；再次点击当前项不重复查询；保留页签语义、键盘操作和无障碍状态 |
| 二级圆角 Tab | 同组只有一个选中项；选中项为圆角浅底 + 主色文字；只刷新所在容器；方向键可在组内移动 |
| 按钮组 | 同组只有一个选中项；禁用项保留位置；切换后只刷新受控区域；不承载页面跳转 |
| 标签 | 只表达状态、类型或属性；颜色含义必须有文字辅助；长文本不破坏布局；不作为主要操作入口 |
| 筛选器 | 支持默认值、清除、多选、远程搜索、加载、空态、错误态；筛选条件显性可见；筛选变化后图表、表格、地图、图谱上下文一致 |
| 操作按钮 | 主次动作层级清楚；异步操作有 loading 并防重复提交；危险动作必须二次确认；失败后保留当前上下文 |
| 数据卡片 | 标题、主内容、右上操作边界清楚；加载和空态不移动标题和操作区；内部切换不影响其他卡片 |
| 图表容器 | loading、空态、错误态不破坏标题和图例位置；tooltip 可读；图例切换至少保留一个系列；图表点击结果可解释 |
| 地图容器 | 工具栏可操作；热力开关只影响热力层；基础图例始终保留；图例固定在容器右下角；全屏状态仍保留图例 |
| 图谱容器 | 节点点击后选中态明确；搜索可定位并高亮；关系展开有数量控制；提供重置视图和防迷失机制 |
| 表格 | 表头保留；排序、筛选、分页状态可见；加载显示 skeleton 或 loading；空态说明原因；行内操作后保留分页和滚动位置 |
| 详情抽屉 | 打开后不丢失原页面上下文；header、body、footer 结构稳定；body 可滚动，footer 固定；关闭后焦点回到触发入口 |
| 弹窗配置 | 表单错误能定位到字段；提交时有 loading；提交失败保留输入；取消或关闭时若有未保存内容需确认 |
| 遮罩 | 模态场景阻断背景；非模态抽屉不强制遮罩；点击遮罩关闭必须遵守未保存内容规则；`Esc` 行为明确 |
| 导出入口 | 单格式直接导出，多格式使用下拉；生成中有进度或通知；成功说明文件去向；失败说明原因并支持重试 |
| 权限态 | 无权限、只读、脱敏、禁用状态可区分；布局稳定；不可操作入口有说明；不暴露未授权敏感数据 |

验收补充规则：

| 主题 | 验收规则 |
| --- | --- |
| 状态覆盖 | 每个可交互组件至少覆盖默认、悬停、聚焦、按下、选中、禁用、加载 |
| 键盘路径 | 鼠标可完成的核心任务必须有键盘等价路径 |
| 焦点恢复 | 抽屉、弹窗、下拉关闭后，焦点回到触发元素 |
| 异常恢复 | 错误态必须提供重试、返回、调整筛选或替代查看路径 |
| 上下文保留 | 页签、筛选、表格分页、地图视野、图表选中态不能被静默重置 |
| 权限边界 | 可见、可点、可导出、可复制需要分别处理，不用一个“无权限”状态混过去 |

### 3.5 Arco 外围 + 可视化内核边界

图表、地图、图谱不属于纯 Arco 组件。它们应按“Arco 外围组件 + 专业可视化内核”的方式实现：Arco 负责容器、状态、工具栏、弹层、反馈和通用交互；ECharts、GIS / 地图库、图谱库负责具体图形渲染、空间渲染和关系布局。

| 类型 | Arco 外围负责 | 可视化内核负责 |
| --- | --- | --- |
| 图表 | 卡片容器、标题、图例区域、指标切换、loading、空态、错误态、导出入口、tooltip 容器 | 折线、柱状、排行、桑基等图形绘制；坐标轴；数据点 hover / click；图形缩放或 brush |
| 地图 | 地图容器、工具栏、热力开关、基础图例、热力强度图例、loading、空态、错误态、详情抽屉入口 | 底图渲染、点位渲染、区域边界、热力层、缩放、平移、框选、聚合点计算 |
| 图谱 | 图谱容器、搜索框、筛选器、图例、详情抽屉、loading、空态、错误态、重置入口 | 节点渲染、边渲染、布局算法、节点拖拽、关系展开、路径高亮、邻居计算 |

边界规则：

| 规则 | 说明 |
| --- | --- |
| Arco 不直接承载复杂图形 | 不用 Arco 组件硬画折线、地图点位、图谱关系；这些交给专业可视化内核 |
| 可视化内核不承载通用状态 | loading、空态、错误态、无权限、导出反馈等由 Arco 外围统一表达 |
| 工具栏归外围管理 | 放大、缩小、复位、全屏、框选、导出等工具入口由 Arco Button / Tooltip 等承载 |
| 图例归外围与内核协同 | 图例视觉与位置由外围统一；点击图例后的高亮、隐藏、过滤由内核执行 |
| Tooltip 可由内核触发，外围约束样式 | tooltip 内容来自数据点、地图对象或图谱节点；样式、层级和可读性需符合统一规范 |
| 详情由外围承载 | 点击图表点、地图对象、图谱节点后，详情展示优先进入 Drawer，不在 canvas / svg 内堆复杂信息 |
| 筛选上下文归页面管理 | 全局筛选由页面或业务状态管理；内核只接收已计算好的数据和可视参数 |
| 视觉状态必须可解释 | 用户需要能看出当前选中对象、筛选条件、图例状态、热力开关状态和影响范围 |

事件联动规则：

| 触发来源 | 事件语义 | 外围响应 | 内核响应 |
| --- | --- | --- | --- |
| 指标切换 | `onMetricChange` | 更新当前卡片 loading / empty / error 状态 | 重绘图形数据 |
| 图例点击 | `onLegendToggle` | 更新图例选中状态；至少保留一个系列或对象类型 | 高亮、隐藏或过滤对应图形元素 |
| 图表点点击 | `onChartPointClick` | 打开详情抽屉或联动表格；保留当前筛选上下文 | 标记当前数据点选中 |
| 地图热力开关 | `onHeatmapToggle` | 更新开关状态和热力强度图例显隐 | 显示或隐藏热力覆盖层 |
| 地图区域点击 | `onRegionSelect` | 更新选中区域、联动统计卡片或列表 | 高亮区域边界 |
| 地图框选 | `onBoxSelect` | 生成临时空间选择上下文，显示清除入口 | 绘制框选范围并返回命中对象 |
| 图谱节点点击 | `onNodeSelect` | 打开详情抽屉或关联列表 | 高亮节点和相邻关系 |
| 图谱展开邻居 | `onExpandNeighbors` | 更新展开状态、展示加载或数量限制提示 | 计算并渲染一跳或多跳邻居 |
| 重置视图 | `onViewReset` | 清除临时选择、恢复默认说明 | 重置缩放、平移、布局或选中态 |
| 导出 | `onExportStart` | 记录筛选上下文、显示生成中和结果反馈 | 提供当前图形快照或数据范围 |

状态归属规则：

| 状态 | 归属 | 规则 |
| --- | --- | --- |
| 首次加载 | Arco 外围 | 容器显示 skeleton 或 loading，不让页面整体闪烁 |
| 数据刷新 | Arco 外围 + 内核 | 外围显示局部 loading，内核保留旧视图或轻量刷新，避免画布突兀清空 |
| 空态 | Arco 外围 | 保留标题、工具栏和图例位置，说明当前筛选下暂无数据 |
| 错误态 | Arco 外围 | 显示错误原因和重试入口；不在图形内部只画错误文案 |
| 选中态 | 可视化内核 | 图形元素负责高亮；外围负责同步标题、详情、列表或抽屉 |
| 禁用 / 无权限 | Arco 外围 | 禁用工具入口、图例项或数据区域，并说明原因；内核不渲染未授权敏感数据 |
| 全屏态 | Arco 外围 | 管理容器全屏、退出入口、图例和工具栏保留；内核响应尺寸变化重新渲染 |

实现要求：

| 要求 | 说明 |
| --- | --- |
| 外围和内核之间只传结构化状态 | 不直接让内核读取页面 DOM 或全局变量 |
| 所有内核事件都要有业务语义命名 | 使用 `onChartPointClick`、`onRegionSelect`、`onNodeSelect`，避免只暴露 `onClick` |
| 内核重绘不能丢失页面上下文 | 页签、筛选、表格分页、抽屉打开状态不应因图形刷新被静默重置 |
| 可视化结果必须有替代路径 | 复杂图表、地图、图谱需要提供表格、列表、摘要或下载作为辅助查看路径 |
| 键盘和无障碍由外围兜底 | 图形内部难以完整键盘操作时，必须提供等价的列表、筛选或详情入口 |

## 4. 导航规则

### 4.1 左侧主导航

左侧导航用于系统级信息架构，不用于页面内临时筛选。该组件按 Figma 定制化实现，不要求直接使用 Arco `Menu`，但必须保留菜单的选中、展开、禁用、键盘和无障碍语义。导航项由图标、文本、可选展开箭头组成。

| 状态 | 呈现规则 | 交互规则 |
| --- | --- | --- |
| 默认 | 使用 Figma 定制导航默认态，并保持可点击语义 | 点击进入模块；鼠标悬停显示可交互反馈 |
| 当前 | 使用 Figma 定制导航选中态，必须与默认态清楚区分 | 表示当前模块；再次点击可刷新或保持当前页，不重复跳转 |
| 展开 | 右侧箭头向上或旋转 | 展开二级菜单；只影响该组，不重置页面筛选 |
| 收起 | 右侧箭头向下 | 隐藏二级菜单；保留当前子项路径 |
| 禁用 | 使用 Figma 定制禁用态，不响应点击 | 用于无权限或未开放模块，需提供 tooltip 说明 |
| 加载 | 保留导航骨架，目标区域显示加载态 | 不建议整条导航闪烁 |

键盘规则：`Tab` 进入导航，方向键在同级项间移动，`Enter` / `Space` 激活，`ArrowRight` 展开，`ArrowLeft` 收起，`Esc` 退出当前展开层。

无障碍规则：导航容器使用语义化导航区域；当前项需要暴露 `current` 状态；可展开项需要暴露展开 / 收起状态。

### 4.2 一级 Tab / 顶部页签

一级 Tab / 顶部页签用于同一模块内的平级视角切换，如“综合发展规划 / 重点领域规划 / 研究领域分析”。顶部页签按 Figma 定制化实现，不要求直接使用 Arco `Tabs`，但必须保留页签的选中、禁用、键盘和无障碍语义。Figma `TAB和按钮组` 中对应 `01 / 一级tab`：页签横向排列，默认项为次强调文字，当前项为主色文字并带底部主色指示条。

| 状态 | 呈现规则 | 交互规则 |
| --- | --- | --- |
| 默认 | 14px 常规文字，使用次强调文字色 | 点击切换同一模块内内容区 |
| 当前 | 14px 中字重主色文字，底部显示 3px 左右的主色指示条 | 当前页签内容显示在同一画布内；再次点击不重复触发查询 |
| 悬停 | 显示可点击反馈 | 不改变当前内容 |
| 聚焦 | 显示清晰焦点环 | 键盘用户可见 |
| 禁用 | 降低透明度 | 不可点击，说明原因 |
| 加载 | 当前页签保持高亮，画布区域加载 | 避免页签自身变成 loading 控件 |

使用边界：

| 场景 | 规则 |
| --- | --- |
| 模块内一级视角 | 使用一级 Tab / 顶部页签 |
| 卡片、抽屉、面板内局部视角 | 使用二级圆角 Tab，不升级为顶部页签 |
| 模式、粒度、排序等互斥选项 | 使用按钮组，不使用顶部页签 |
| 状态展示 | 使用标签，不使用页签或按钮组 |

切换规则：页签切换默认保留全局筛选条件；若某页签不支持某筛选项，应禁用该筛选项并说明，而不是静默清空。一级 Tab 与二级圆角 Tab 同屏出现时，一级 Tab 控制模块级内容，二级圆角 Tab 只控制所在容器；下级切换不得重置上级 Tab。

### 4.3 面包屑导航

面包屑导航用于展示用户当前所在页面、对象或下钻层级的位置，并提供向上级层级回溯的路径。它是位置与层级回溯组件，不是主导航、页签或筛选器。

| 场景 | 规则 |
| --- | --- |
| 列表进入详情页 | 显示模块 / 列表 / 对象详情，返回列表时保留筛选、排序、分页和滚动位置 |
| 地图区域下钻 | 显示模块 / 区域 / 城市或园区等层级，返回时保留地图视野和已选筛选 |
| 图谱节点详情 | 显示模块 / 图谱 / 节点详情或关联对象，返回时保留图谱选中节点和展开状态 |
| 专题分析结果 | 显示专题 / 分析类型 / 结果或证据链，返回时保留分析上下文 |
| 抽屉临时详情 | 一般不展示完整面包屑；可使用返回列表、返回对象或关闭抽屉表达回退 |

| 项 | 规则 |
| --- | --- |
| 层级含义 | 只展示当前信息层级路径，不展示完整浏览历史 |
| 最后一级 | 表示当前位置，只读不可点击 |
| 上级节点 | 可点击返回对应层级；返回时尽量保留上下文 |
| 层级数量 | 建议不超过 3-4 级；过长时中间层可折叠或使用下拉承载 |
| 未保存内容 | 返回会丢失编辑、配置或筛选草稿时，必须二次确认 |
| Arco 基础 | 使用 Arco `Breadcrumb`；可点击项使用链接语义，当前项不使用链接 |

键盘规则：可点击面包屑项可 `Tab` 聚焦，`Enter` 激活返回；分隔符不可聚焦。

无障碍规则：面包屑区域需表达导航语义；当前项需要能被辅助技术识别为当前位置；分隔符不应被误读为可操作内容。

## 5. 筛选组件规则

Figma 中筛选区包含“时间维度、规划区域、技术领域、产业门类、人才流动”等横向排列的选择器。筛选组件属于全局上下文，影响画布内所有卡片。

筛选器实现和交互以 Arco `Select`、`Cascader`、`TreeSelect`、`DatePicker`、`Input.Search` 为基础。除非业务需要地图框选、图谱节点筛选等特殊交互，不应创建页面私有下拉框、私有搜索框或私有级联控件。

### 5.1 筛选器结构

| 元素 | 规则 |
| --- | --- |
| 标签 | 位于控件上方，简短明确，不使用业务说明长句 |
| 输入区 | 216px 宽、28px 高为当前设计参考；跨系统可按栅格扩展 |
| 展开箭头 | 右侧固定位置；点击输入框任意区域均可展开 |
| 已选值 | 单选直接展示值；多选展示前 1-2 项 + 数量 |
| 清除 | 有默认值的筛选不强制展示清除；临时筛选应提供清除能力 |

### 5.2 筛选行为

| 场景 | 规则 |
| --- | --- |
| 单选 | 选中后立即收起并刷新关联内容 |
| 多选 | 勾选后保持面板打开，点击“确定”后刷新；少量选项可即时刷新 |
| 搜索 | 支持拼音、关键词或编码搜索时，输入后 300ms 左右防抖 |
| 级联 | 上级变化后，下级选项刷新；已不合法的下级值需清空并提示 |
| 默认值 | 使用业务推荐默认值，如近 12 个月、当前区域、全部领域 |
| 重置 | 重置回业务默认值，而不是空值 |
| 联动 | 筛选变化后，图表、表格、地图、图谱必须使用同一上下文 |

Arco 补充规则：多选筛选优先使用 Arco 多选模式和 tag 展示；级联筛选优先使用 `Cascader` 或 `TreeSelect`；远程搜索必须展示加载态和空态；校验或异常信息使用表单项帮助文本、`Alert` 或局部错误提示承载，不用浏览器原生弹窗。

### 5.3 筛选状态矩阵

| 状态 | 触发 | 展示 | 可操作 |
| --- | --- | --- | --- |
| 默认 | 有可选项 | 正常边框、当前值 | 可展开 |
| 悬停 | 鼠标经过 | 边框或背景轻微强调 | 可展开 |
| 聚焦 | 键盘或点击聚焦 | 显示焦点环 | 可键盘选择 |
| 已选择 | 存在非默认条件 | 展示选中值，可选显示数量 | 可清除或修改 |
| 加载 | 选项请求中 | 控件禁用，显示加载标识 | 不可提交 |
| 空选项 | 请求成功但无选项 | 面板显示“暂无可选项” | 可关闭 |
| 错误 | 选项请求失败 | 面板显示错误与重试 | 可重试 |
| 禁用 | 权限或上下文不支持 | 低对比，tooltip 说明 | 不可展开 |

键盘规则：`Enter` / `Space` 展开，`ArrowUp` / `ArrowDown` 移动选项，`Enter` 选择，`Esc` 关闭，`Backspace` 可删除多选最后一项。

## 6. 内容画布与卡片规则

### 6.1 内容画布

内容画布承载筛选器、卡片网格和分析结果。画布是页面内主要工作区，不应再嵌套同级“大卡片”制造多层边框。

| 项 | 规则 |
| --- | --- |
| 宽高 | 桌面端以可视区自适应；Figma 参考为 1440x836 |
| 滚动 | 画布可纵向滚动；左导航和顶部结构保持稳定 |
| 布局 | 按业务优先级排列，高价值结论靠前，明细和资源靠后 |
| 刷新 | 全局筛选变更时，画布内卡片可以局部刷新，不阻塞整个页面 |
| 空白 | 不用大面积装饰图填补；用可操作的空态说明下一步 |

### 6.2 数据卡片

数据卡片是承载标题、操作、指标、图表、表格的基本容器。

| 元素 | 规则 |
| --- | --- |
| 标题 | 左上角，说明数据对象或分析目的 |
| 右上操作 | “查看全部 / 导出 / 设置 / 更多”等低频操作放右上角 |
| 主内容 | 优先展示图形或数据，不堆叠说明性文字 |
| 内部切换 | 使用二级圆角 Tab 或按钮组，切换局部视角或指标维度 |
| 状态 | 每张卡片独立处理加载、空态、错误、无权限 |

卡片交互规则：点击卡片标题不触发跳转；点击图形元素可高亮、联动或打开详情；右上“查看全部”进入更完整的列表或抽屉。

## 7. 二级圆角 Tab、按钮组、标签与行内操作

Figma `TAB和按钮组` 中对应 `02 / 二级tab` 和 `03 / 按钮组`。二级圆角 Tab 用于局部内容切换，按钮组用于紧凑的互斥选项切换；二者都可以表现为单选，但信息层级不同，不能混用。趋势、类型、增长状态等只读信息仍使用标签。

| 类型 | 使用场景 | 规则 |
| --- | --- | --- |
| 二级圆角 Tab | 卡片、面板、抽屉内的局部视角，如“概览 / 详情 / 趋势 / 对比” | 单选；选中项使用圆角浅底 + 主色文字；默认项使用透明底 + 次强调文字；只刷新所在容器 |
| 指标切换按钮组 | 热度指数、文献数量、专利数量、项目数量 | 单选；外层使用浅灰底，选中项使用白底浮层 + 主色文字；切换后只刷新所在卡片 |
| 时间粒度按钮组 | 季度、月度、年度 | 单选；影响当前图表时间轴；需与全局时间范围兼容 |
| 模式 / 排序按钮组 | 列表 / 图表、升序 / 降序、综合 / 最新等互斥模式 | 单选；不承载跳转；当前选项变化后更新受控区域 |
| 状态标签 | 高速增长、趋势、类型点 | 只表达状态，不承担主要点击入口 |
| 行内主操作 | 推送设置等 | 使用 Arco 主按钮语义，突出推荐动作 |
| 行内次操作 | 关注条件、资源评估等 | 使用 Arco 次级或文本按钮语义，避免表格过重 |

状态：默认、悬停、聚焦、按下、选中、禁用、加载。二级圆角 Tab 和按钮组选中态必须唯一；不可用项保留位置并禁用，不自动改选到其他项。行内按钮如果触发异步操作，需局部 loading，不应让整行消失。

键盘规则：二级圆角 Tab 与按钮组进入焦点后，方向键在同组项目间移动，`Enter` / `Space` 选择当前项；`Tab` 离开当前组。当前项需要通过语义状态暴露给辅助技术，不能只依赖颜色。

## 8. 图表规则

### 8.1 通用图表容器

图表容器包括标题、指标切换、图例、时间粒度、图形区、坐标轴、tooltip、必要时的下载入口。

| 场景 | 规则 |
| --- | --- |
| 折线图 | 用于趋势变化；支持多系列图例开关；hover 显示同一横轴时间点全部系列 |
| 柱状 / 条形图 | 用于对比；当前区域与平均值等对比对象需通过图例、标签或样式差异区分 |
| 桑基 / 流向图 | 用于流动关系；hover 高亮路径，点击节点筛选关联明细 |
| 排行条 | 用于 TOP 列表；数值、排名、变化趋势必须同时可读 |
| 小型指标图 | 可弱化坐标轴，但必须保留数值来源或 tooltip |

### 8.2 图表交互

| 交互 | 规则 |
| --- | --- |
| Hover | 高亮当前点、线、柱、路径；显示 tooltip |
| Click | 选中数据点并联动详情、表格或地图 |
| Legend click | 显示 / 隐藏系列；至少保留一个系列 |
| Brush / 框选 | 仅在复杂分析图表中启用；启用后提供清除选择 |
| Zoom | 时间序列和地图可支持缩放；普通卡片图表不默认启用 |
| Drill down | 下钻后保留面包屑或返回入口 |

### 8.3 图表状态

| 状态 | 展示规则 |
| --- | --- |
| 加载 | 图表区域显示 skeleton 或轻量 loading，不移动卡片标题 |
| 空态 | 保留坐标系或容器，说明当前筛选下暂无数据 |
| 错误 | 显示错误原因和重试；不展示过期图形冒充有效数据 |
| 部分数据缺失 | tooltip 和图例标注缺失，不用 0 替代未知值 |
| 权限不足 | 图表区域展示权限占位，说明申请路径或联系管理员 |

键盘规则：图表容器可聚焦；方向键在数据点间移动；`Enter` 打开详情；`Esc` 取消选中。复杂图表需提供等价表格或数据下载入口。

## 9. 地图规则

地图规则来源于 Figma `通用组件 / 地图相关` frame。新版 frame 明确包含地图工具栏、热力开关、基础图例和热力强度分级图例；不再包含“图层设置 / 显示模式切换 / 关联展示”展开面板。地图组件属于“专业可视化内核 + Arco 外围控件”的组合：地图渲染可由 GIS / 地图库承担，工具栏、开关、图例、说明、抽屉、加载、空态、权限态优先复用 Arco。

| 组件 | 规则 |
| --- | --- |
| 地图画布 | 支持缩放、平移、区域选择、点位聚合；画布操作不得影响全局筛选，除非用户明确提交框选或区域选择 |
| 地图工具栏 | Figma 出现放大、缩小、复位、全屏、框选区域五类工具；工具栏应贴近地图左上角或固定在地图容器内 |
| 工具栏简化态 | 当业务不需要框选时，可只保留放大、缩小、复位、全屏四类工具 |
| 热力开关 | 使用独立开关控制热力覆盖层；开启后展示热力强度分级图例，关闭后隐藏热力强度分级但保留基础图例 |
| 基础图例 | 展示地图对象类型，对应 Figma 中的“热点、舆情、政策、产业、科研动态” |
| 热力强度图例 | 仅在热力开关开启时展示，必须标明低值和高值含义 |
| 区域选择 | 点击区域高亮并联动右侧详情、表格或抽屉；区域选择应可取消或复位 |
| 点位聚合 | 缩小时聚合，放大后拆分；聚合点 tooltip 显示数量、主类型和可继续下钻提示 |
| 图例 | 必须说明系列、大小、形状、热力强度等编码含义；图例开关需可键盘操作 |
| 复位 | 复位回默认中心点、缩放级别、选中对象和框选状态；不重置全局筛选 |

### 9.1 地图工具栏

| 工具 | Arco / 图标基础 | 交互规则 |
| --- | --- | --- |
| 放大 | `Button` + 放大图标 | 点击后地图放大一级；达到最大级别后禁用 |
| 缩小 | `Button` + 缩小图标 | 点击后地图缩小一级；达到最小级别后禁用 |
| 复位 | `Button` + 复位图标 | 回到默认视野并清除地图内临时选择；不清空全局筛选 |
| 全屏 | `Button` + 全屏图标 | 地图容器进入全屏或大屏查看；再次点击退出 |
| 框选区域 | `Button` + 框选图标 | 进入框选模式；完成框选后显示选中区域统计，并提供清除框选 |

工具按钮必须有 tooltip 或可访问名称，说明具体动作。工具栏不承载业务筛选项；筛选项仍应放在页面筛选区。热力开关属于地图表现控制，不替代业务筛选。

### 9.2 热力开关与图例

| 模块 | 规则 |
| --- | --- |
| 热力开关开启 | 在地图上叠加热力覆盖层，同时展示基础图例和热力强度分级图例 |
| 热力开关关闭 | 隐藏热力覆盖层和热力强度分级图例，保留基础图例和点位 / 区域对象 |
| 基础图例 | 以对象类型为主，当前 Figma 包含“热点、舆情、政策、产业、科研动态”；图例文本必须与业务数据类型一致 |
| 热力强度分级 | 用于说明热力强弱区间，只表达密度或强度趋势，不用于精确读取单点数值 |
| 图例位置 | 图例位置应固定在容器右下角，跟随地图容器显示，不应遮挡核心地图对象；全屏时图例需要保留 |

热力开关只改变地图表达方式，不改变底层筛选条件。若当前筛选下无热力数据，应保留开关和基础图例，并在地图区域提示当前筛选暂无热力数据，而不是自动关闭开关。

### 9.3 地图联动

| 触发 | 联动结果 |
| --- | --- |
| 点击区域 | 高亮区域，刷新关联指标、对象列表或打开详情抽屉 |
| 点击点位 | 选中点位，显示 tooltip 或打开对象详情 |
| 点击聚合点 | 优先放大到聚合范围；如已到最大级别，则打开聚合对象列表 |
| 框选区域 | 生成临时空间选择上下文，联动统计面板和列表；需提供清除框选 |
| 切换热力开关 | 只刷新热力覆盖层和热力强度图例，不重置时间、区域、领域等全局筛选 |
| 点击图例项 | 可高亮或过滤对应对象类型；若支持隐藏图例项，至少保留一个对象类型可见 |

地图联动结果必须可解释：用户应能看到当前选中对象、框选范围、热力开关状态、可见对象类型和影响的数据范围。

### 9.4 地图状态

| 状态 | 展示规则 |
| --- | --- |
| 底图加载中 | 地图容器显示加载，不阻塞页面其他卡片 |
| 业务图层加载中 | 底图可见，业务图层区域显示加载或骨架 |
| 热力无数据 | 保留地图视野、基础图例和热力开关，提示当前筛选暂无热力数据 |
| 当前区域无数据 | 保留区域边界，提示可调整筛选或关闭热力覆盖层查看基础对象 |
| 底图失败 | 显示错误和重试；仍应尽量保留表格或列表替代信息 |
| 图层失败 | 底图继续可用，失败图层显示错误和重试 |
| 框选无结果 | 保留框选范围，提示范围内暂无对象，并提供清除框选 |
| 权限不足 | 无权限对象类型或热力层不可见 / 脱敏；对应开关或图例项说明不可用原因 |

### 9.5 地图键盘与无障碍

| 操作 | 规则 |
| --- | --- |
| 工具栏访问 | `Tab` 进入工具栏，方向键可在工具按钮间移动，`Enter` / `Space` 激活 |
| 热力开关访问 | `Tab` 聚焦热力开关，`Space` 切换开关状态 |
| 图例访问 | 图例项如支持交互，应可通过键盘聚焦并触发；非交互图例只作为说明信息 |
| 地图对象访问 | 关键区域、点位、聚合点应提供可聚焦列表或等价表格 |
| 框选替代 | 框选必须提供非拖拽替代路径，如区域列表、多选筛选或行政区选择 |
| 图例说明 | 对象类型和热力强度必须有文本说明，不能只依赖视觉编码 |

## 10. 图谱规则

图谱用于展示技术、机构、人才、成果、政策、资源之间的关系。

| 交互 | 规则 |
| --- | --- |
| 节点 hover | 显示名称、类型、关键指标 |
| 节点点击 | 选中节点，打开详情抽屉或侧栏 |
| 边 hover | 显示关系类型、强度、证据数量 |
| 展开邻居 | 支持一跳展开；多跳展开需限制数量并提供收起 |
| 搜索定位 | 搜索结果定位到节点并高亮上下文 |
| 过滤 | 按节点类型、关系类型、强度、时间过滤 |
| 布局切换 | 力导向、层级、时间线等布局切换不丢失选中对象 |

图谱必须提供防迷失机制：当前选中节点、路径面包屑、重置视图、收起全部、搜索定位。大图谱不应一次性渲染全部节点。

## 11. 表格规则

Figma 中表格包含表头、斑马纹行、类型点、资源名称、核心内容、匹配领域、可信度、时效性和行内操作。

表格以 Arco `Table` 为基础。排序、筛选、分页、固定列、加载、空态、行选择等能力优先使用 Arco 内建机制；业务只补充列定义、单元格渲染、权限控制和行内操作。

### 11.1 表格结构

| 元素 | 规则 |
| --- | --- |
| 表头 | 用浅底区分，文字加重；支持排序的列显示排序状态 |
| 行 | 可使用浅斑马纹提升扫描效率 |
| 类型标识 | 使用点、标签或图标表达类型；必须有文本辅助 |
| 数值列 | 右对齐或居中，保持可比较 |
| 文本列 | 长文本单行截断，hover 或详情展示完整内容 |
| 操作列 | 固定在右侧；主次动作区分明显 |

### 11.2 表格交互

| 场景 | 规则 |
| --- | --- |
| 行点击 | 如支持打开详情，整行 hover 应显示可点击反馈 |
| 复选 | 批量操作才显示复选框；选中后出现批量操作栏 |
| 排序 | 单列排序为默认；多列排序需明确优先级 |
| 筛选 | 列筛选与全局筛选需合并展示，避免隐藏条件 |
| 分页 | 大列表使用分页；分析型列表可使用虚拟滚动 |
| 行内操作 | 点击后保持当前表格上下文，成功后局部反馈 |

Arco 补充规则：表格加载使用 `loading` 或外层 `Spin`；无数据使用 `Empty`；分页使用 Arco `Pagination`；批量选择使用 `rowSelection` 对应的交互模型；危险行内操作必须使用 `Popconfirm` 或二次确认 `Modal`。

### 11.3 表格状态

| 状态 | 展示规则 |
| --- | --- |
| 加载 | 表头保留，行区域 skeleton |
| 空态 | 保留表头，说明无数据原因和可调整的筛选条件 |
| 错误 | 表格区域显示重试，不清空筛选 |
| 禁用行 | 行降低透明度，操作按钮禁用并说明原因 |
| 部分无权限 | 敏感字段脱敏，操作列展示申请权限或不可用原因 |

键盘规则：`Tab` 进入表格操作，方向键可在单元格或行间移动，`Enter` 打开行详情，`Space` 勾选行，`Esc` 关闭行内浮层。

## 12. 详情抽屉规则

详情抽屉用于在不离开当前分析上下文的情况下查看对象详情、证据、配置和操作结果。规则来源于 Figma `右侧详情 Drawer / 非模态 / 30vw（576px@1920）` 和 `遮罩` 样例。

详情承载优先使用 Arco `Drawer`。当内容是短确认或简单表单时使用 `Modal`；当内容包含对象画像、证据链、关联图谱、操作记录或长列表时使用 `Drawer`，避免打断当前分析上下文。Figma 当前样例为右侧非模态抽屉，适合在地图、图表、表格等分析对象旁展示详情。

| 区域 | 规则 |
| --- | --- |
| 遮罩 | 用于需要阻断背景操作或突出弹层层级的场景；非模态抽屉可不阻断背景，但必须保证抽屉层级和焦点路径清晰 |
| 抽屉标题 | 显示对象名称和类型；可包含副标题、提示图标和关闭入口 |
| 标签区 | 用 Tag 展示对象类型、状态、来源、风险等级等短标签 |
| 摘要区 | 展示关键指标、状态、更新时间或当前关注原因 |
| 内容区 | 使用分块、页签或描述列表组织，如概览、证据、关联、操作记录；长内容区域可滚动 |
| 底部操作 | 固定在抽屉底部，放置关闭、关注、订阅、展开证据区等操作 |
| 返回上下文 | 关闭抽屉后，原表格行、图表点、地图区域保持选中或高亮 |

### 12.1 宽度规则

右侧抽屉应可根据业务需求调整宽度。Figma 样例给出基础规则：`30vw / min 480 / max 640`，在 1920px 宽屏下约为 576px。该规则作为默认建议，不应固化为唯一宽度。

| 类型 | 建议宽度 | 适用场景 |
| --- | --- | --- |
| 轻量详情 | 360-480px | 简短说明、单对象摘要、少量字段 |
| 标准详情 | 30vw，建议 min 480 / max 640 | Figma 当前右侧详情样例；对象详情、证据摘要、标签和固定操作区 |
| 复杂画像 | 640-800px 或按内容扩展 | 多页签、证据链、关联对象、长表格 |
| 宽屏分析抽屉 | 40vw-50vw，需业务确认 | 图谱关系、复杂证据、对比分析 |
| 全屏详情 | 独立页面或全屏弹层 | 信息量超过抽屉承载能力，或需要完整工作流 |

宽度选择以业务任务为准：既要保证详情信息完整可读，也要保留用户对原分析上下文的空间感。抽屉宽度变化不应导致底层地图、图表或表格状态丢失。

### 12.2 模态、非模态与遮罩

| 类型 | 规则 |
| --- | --- |
| 非模态右侧抽屉 | 默认用于对象详情查看；用户可保留背景上下文，必要时允许继续查看底层地图、图表或表格 |
| 模态抽屉 | 用于必须先处理的配置、确认、审批、权限申请；应启用遮罩并限制背景交互 |
| 遮罩 | 遮罩只表达层级和交互阻断，不承载业务信息；关闭遮罩时需遵循业务确认规则 |
| 点击遮罩关闭 | 仅适用于无未保存内容的轻量查看；存在表单编辑、配置变更或未提交操作时，不允许直接丢失内容 |
| 层级 | 抽屉、Modal、Dropdown、Tooltip 同时出现时，需要明确层级；抽屉内弹层必须高于抽屉内容但不破坏焦点路径 |

### 12.3 结构与滚动

| 区域 | 规则 |
| --- | --- |
| Header | 固定在顶部，包含标题、副标题或说明、关闭按钮 |
| Body | 可滚动；按信息块组织，避免把长内容堆在单一段落内 |
| Footer | 固定在底部，承载关闭和主操作；滚动 body 时 footer 不消失 |
| 内容分块 | 证据摘要、当前关注原因、对象属性、关联信息等应分块展示 |
| 标签 | 标签只表达对象属性或状态，不替代标题和详情字段 |

键盘规则：打开抽屉后焦点进入标题或首个可操作项；`Esc` 关闭；焦点被限制在抽屉内；关闭后焦点回到触发元素。

Arco 补充规则：抽屉内分组优先使用 `Tabs`、`Descriptions`、`Timeline`、`Table`、`Alert`；底部操作使用 Arco `Button`，主次按钮顺序保持一致；关闭前如存在未保存表单变更，使用 `Modal.confirm` 或同等确认机制。

## 13. 导出规则

导出是分析工作台的重要闭环，分为卡片导出、表格导出、报告导出和配置导出。

| 类型 | 规则 |
| --- | --- |
| 卡片导出 | 导出当前卡片图表或图片，必须包含筛选上下文和时间 |
| 表格导出 | 导出当前筛选、排序、列配置下的数据 |
| 报告导出 | 生成可汇报文档，包含结论、图表、数据来源、生成时间 |
| 配置导出 | 导出关注条件、推送设置、图谱筛选等配置 |

导出状态：准备中、生成中、成功、失败、无权限、数据过大。导出失败必须说明原因并支持重试；数据过大时提供缩小范围或异步生成。

权限规则：用户只能导出其可见数据；敏感字段按权限脱敏；导出文件需记录操作者、时间、筛选条件和数据版本。

Arco 补充规则：单一导出使用 `Button`；多格式导出使用 `Dropdown`；导出配置使用 `Modal` + `Form`；生成中使用 `Button loading`、`Progress` 或 `Notification` 表达进度；成功后用 `Message` 提示即时结果，用 `Notification` 承载后台任务完成入口。

## 14. 权限态规则

权限交互已有专项文档，本文不单独定义页面权限、模块权限、字段脱敏、操作权限、导出权限和数据授权范围等细则。

权限相关 UX 规则以同目录下的专项文档为准：

- `UX-权限交互规范-企业维度.md`
- `全系统角色权限体系设计.md`
- `权限点清单-菜单与按钮.md`

本文只保留最小通用边界：当通用组件进入无权限、只读、禁用、脱敏或不可导出状态时，组件仍需保持布局稳定、状态可辨识。在演示原型或转化引导场景下，无权入口可保持可见，但应呈现禁用、锁态、只读或申请引导；未授权的敏感数据本身仍不得直接暴露。具体文案、申请路径、脱敏方式和按钮可见性不在本文展开。

## 15. 状态矩阵

### 15.1 通用控件状态

| 状态 | 适用组件 | 视觉表现 | 交互表现 | 文案规则 |
| --- | --- | --- | --- | --- |
| 默认 | 全部 | 使用 Arco 默认态 | 可操作 | 无需额外说明 |
| 悬停 | 可点击组件 | 显示可交互反馈 | 指针反馈 | 不弹无必要提示 |
| 聚焦 | 键盘可达组件 | 清晰焦点环 | 可用键盘操作 | 不遮挡内容 |
| 按下 | 按钮、按钮组、标签、导航 | 短暂压低或加深 | 触发动作或选择 | 无需文案 |
| 选中 | 导航、一级 Tab、二级圆角 Tab、按钮组、筛选、图例 | 一级 Tab 使用底部指示条；二级圆角 Tab 使用圆角浅底；按钮组使用白底浮层；其余使用 Arco 选中态或明确当前指示 | 表示当前状态；同组单选组件只能有一个选中项 | 文案保持原义 |
| 加载 | 异步组件 | loading 或 skeleton | 阻止重复提交 | 使用“加载中 / 生成中”等动词 |
| 成功 | 表单、导出、设置 | 成功提示 | 可继续操作 | 说明结果和去向 |
| 错误 | 异步组件 | 错误占位或错误提示 | 支持重试 | 说明原因和解决动作 |
| 空态 | 数据组件 | 空状态占位 | 提供调整筛选或创建入口 | 说明为什么为空 |
| 禁用 | 操作组件 | 降低对比度 | 不响应点击 | tooltip 或旁注说明原因 |
| 只读 | 表单、配置、详情 | 正常显示但无编辑入口 | 可复制按权限控制 | 标注只读来源 |
| 无权限 | 任意组件 | 占位或脱敏 | 引导申请权限 | 避免暴露敏感信息 |

### 15.2 数据组件状态

| 组件 | 加载态 | 空态 | 错误态 | 禁用 / 无权限 |
| --- | --- | --- | --- | --- |
| 图表 | 保留标题和图例位置，图形区 skeleton | 保留坐标或容器，说明筛选无结果 | 显示重试，不展示旧图 | 权限占位或脱敏 |
| 表格 | 表头保留，行 skeleton | 表头保留，提示调整筛选 | 行区域错误 + 重试 | 字段脱敏、操作禁用 |
| 地图 | 底图和图层分开加载 | 显示无点位或无区域数据 | 底图错误 / 图层错误分开提示 | 图层不可见或点位脱敏 |
| 图谱 | 中心区域 loading | 搜索或筛选无节点 | 关系加载失败可重试 | 节点脱敏或禁止展开 |
| 抽屉 | 抽屉先打开，body 区域 skeleton，header/footer 保持稳定 | 显示对象无详情 | 显示详情加载失败，保留关闭入口 | 敏感区块隐藏或脱敏 |
| 遮罩 | 不单独加载；随 Drawer / Modal 出现 | 不适用 | 遮罩不承载错误态 | 按权限或业务阻断规则决定是否允许关闭 |
| 导出 | 按钮 loading，防重复点击 | 无可导出数据 | 失败原因 + 重试 | 禁用并说明权限 |

## 16. 键盘操作总则

| 按键 | 通用行为 |
| --- | --- |
| `Tab` | 在可交互元素间正向移动 |
| `Shift + Tab` | 反向移动 |
| `Enter` | 激活当前按钮、链接、行、节点 |
| `Space` | 激活按钮、勾选复选框、选择 Tab / 按钮组项目 |
| `ArrowUp / ArrowDown` | 在菜单、下拉、表格行、图表数据点中移动 |
| `ArrowLeft / ArrowRight` | 在一级 Tab、二级圆角 Tab、按钮组、图例、图谱邻居、时间轴中移动 |

所有鼠标可完成的核心任务必须有键盘等价路径，尤其是筛选、切换页签、查看详情、导出、关闭浮层。

## 17. 无障碍规则

| 主题 | 规则 |
| --- | --- |
| 语义 | 导航、按钮、表格、页签、弹窗、抽屉使用正确语义 |
| 焦点 | 焦点环清晰，不被容器裁剪；浮层打开后焦点管理正确 |
| 对比度 | 正文、按钮、状态文字满足 WCAG AA 基线 |
| 文本替代 | 图标按钮必须有可访问名称；颜色状态必须有文字或形状辅助 |
| 动态更新 | 加载、错误、导出完成等异步结果需可被辅助技术感知 |
| 图表替代 | 复杂图表提供数据表、下载或摘要说明 |
| 键盘陷阱 | 抽屉、弹窗内可以关闭并回到触发点，不产生无法退出的焦点陷阱 |

Arco 补充规则：使用 Arco 组件时不得移除默认焦点、键盘和语义能力；如果因视觉还原覆盖了默认样式，必须补回等价的焦点环、禁用态、错误态和可访问名称。

| 权限明确 | 不可见、不可点、不可导出都有清晰原因 |
| 导出可信 | 导出包含筛选条件、时间、数据范围和权限处理 |
| 异常可恢复 | 错误态提供重试或替代路径 |
| 空态可行动 | 空态告诉用户如何调整筛选或下一步操作 |
| 抽屉宽度合理 | 右侧抽屉宽度可按业务需求调整，默认可参考 30vw / min 480 / max 640 |
| 遮罩策略明确 | 能区分模态遮罩、非模态抽屉和背景可交互场景 |
| 无障碍达标 | 语义、焦点、对比度、替代文本、动态提示满足基线 |
| Arco 一致性 | 优先使用 Arco 原生组件、状态语义和弹层体系，不出现页面私有控件风格 |
