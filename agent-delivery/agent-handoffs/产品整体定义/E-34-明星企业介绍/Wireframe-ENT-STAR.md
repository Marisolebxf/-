### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 共享上下文 | 确认当前专题、产业和数据时间 | `topic_service`、`future_industry_code/name`、`data_batch` | 切换产业刷新整页，不保留旧企业局部状态 |
| 明星企业首屏 | 理解展示对象及其代表性 | `enterprise_code/name/logo/summary`、`selection_reason`、`standard_name/version`、`data_time` | 当前产业固定一家具代表性企业；不提供手动选择或换一换 |
| 查看入选标准 | 理解共用标准 | 适用产业、候选范围、标准名称/版本、已确认维度、更新时间 | 不展示权重、内部阈值、排名或敏感证据 |
| 资质荣誉 | 识别企业公开资质 | 系统通用枚举 | 复用企业查询/档案；多标签展示，不推导评分 |
| 产品功能全景 | 理解核心产品与产业影响 | 产品名称、能力、场景、案例、影响摘要；内容字段非统计指标 | 默认展示 CMS 已发布内容；按产品卡切换关联媒体 |
| 媒体内容 | 直观理解产品和技术 | `media_type/title/cover/url/publish_status/source` | 支持视频、3D、案例、操作演示；只消费已发布资源 |
| 技术优势 | 理解公开技术基础 | `patent_count`、`rd_investment_ratio`：`metric_id: null`，Q048 / DEMO；核心技术、原理、成果为内容字段 | 量化指标与数据批次一致；不转化为评分排名 |
| 团队实力 | 理解核心成员与人才结构 | 核心成员、履历摘要、团队成果；`scientist_talent_ratio`：`metric_id: null`，Q048 / DEMO | 团队内容读取 CMS 已发布版本；非公开字段不展示 |
| 产业生态图谱 | 理解合作网络 | 企业节点、关系类型、关系说明、来源时间；Q040 / DEMO | 默认聚焦当前企业，只读浏览；点击节点显示关系摘要 |
| 发展历程 | 理解成长脉络 | 事件时间、标题、摘要、公开来源；内容字段 | CMS 正式内容优先；演示可用开放官网事实摘要并标 DEMO/来源 |
| 公开口碑 | 查看公开评价主题 | 主题词、来源范围、时间；内容字段 | 仅展示已发布摘要，不展示未经授权原始评价或生成满意度评分 |

### 2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 切换当前未来产业 | 刷新固定明星企业、标准版本和四区内容，回到首屏 | 不保留旧企业内容，不跨产业混排 |
| 点击查看入选标准 | 打开只读浮层/抽屉 | 不暴露权重、阈值、企业排名或敏感证据 |
| 点击产品卡 | 更新关联场景、案例和媒体 | 不触发企业查询或添加对比篮 |
| 点击视频/3D/案例 | 打开媒体查看层；失败显示资源状态 | 不自动播放失效资源，不读取 CMS 草稿 |
| 点击生态节点或关系 | 展示合作主体、关系类型、公开说明和来源时间 | 不自动生成供应链风险、中心性排名或推荐结论 |
| 点击企业名称 | 进入统一企业画像并携带来源 `E-34` | 不在本页复制画像全部能力 |

### 2.4 入选标准只读浮层

| 内容 | 展示规则 |
| --- | --- |
| 适用产业 | 当前未来产业名称与编码 |
| 候选范围 | 展示范围摘要；未确认时写“候选范围待配置” |
| 标准信息 | 标准名称、版本、已确认维度、更新时间 |
| 企业入选理由 | 展示本企业匹配共用标准的公开亮点与证据摘要 |
| 禁止项 | 不展示权重、内部阈值、排名、敏感原始证据，不允许页面内修改 |

### 2.5 媒体双模式规则

| 模式 | 视频 / 3D / 案例 / 操作演示表现 |
| --- | --- |
| 内部评审模式 | 使用占位图，展示媒体类型、字段、来源、CMS 发布状态、接口依赖和 DEMO 标识，便于评审数据闭环。 |
| 非评审演示模式 | 模拟真实封面、播放、3D 旋转或案例浏览效果；明确标注演示内容，不宣称来自 CMS 正式发布。 |
| 正式发布态 | 只加载 CMS 已发布资源；草稿、失效和无授权资源不得对外展示。 |

### 2.6 发展历程演示规则

- 正式态以 CMS 已发布事件为准。
- 演示态可选用开放企业官网的公开事实，例如华为官网企业信息中的发展历程，进行摘要改写和来源标注。
- 不复制官网长文或受限媒体，不把开放网页事实写成 CMS 已审核内容。

### 2.7 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 展示固定企业首屏与已发布四区内容 | 浏览区块或查看标准 |
| 加载 | 首屏和各内容区使用稳定骨架，避免布局跳变 | 等待 |
| 明星企业未配置 | 显示“本产业明星企业待配置”及返回入口 | 返回概况或切换产业 |
| 标准待配置 | 首屏保留企业与内容，标准位置显示待配置 | 浏览公开内容 |
| CMS 未发布/部分缺失 | 缺失区块显示业务空态；已有区块正常展示 | 浏览其他区块 |
| 媒体失败 | 显示封面、资源不可用说明与重试 | 重试或关闭媒体层 |
| 图谱关系不足 | 显示已确认关系或“生态关系待完善” | 查看企业画像 |
| 接口错误 | 局部错误隔离并提供重试 | 重试失败区块 |
| 无权限 | 隐藏非公开字段，展示公开范围说明 | 查看公开内容 |

## 3. 内部评审模式

- 标出固定明星企业表、标准版本和入选理由的字段来源及 Q048。
- 专利数、研发投入占比、人才比例没有正式 `metric_id` 时显示 DEMO/Q048。
- CMS 媒体和团队内容显示字段、发布状态与 Q041；草稿不可冒充正式内容。
- 生态图谱显示 Q040、关系来源和数据时间，不生成风险结论。
- 系统通用资质荣誉枚举在本页只读复用，不允许页面私有扩展。

## 4. 响应式与视觉约束

- **屏幕层级**：medium；PC 门户工作台，不建设手机端。
- **布局**：内容纵向叙事，产品全景优先；技术与团队可双栏，生态图谱保持可读固定高度。
- **设计系统**：遵循 `Design.md` 和 Arco 公共组件；媒体容器使用统一宽高比与加载/错误状态。
- **裁剪规则**：窄中屏时技术与团队改为单栏；图谱和时间轴保持局部交互，不整页横向滚动。
