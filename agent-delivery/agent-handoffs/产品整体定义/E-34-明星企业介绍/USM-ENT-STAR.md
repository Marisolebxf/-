## 模块：E-34 明星企业介绍

明星企业介绍面向门户浏览场景，在当前未来产业下展示一家具代表性的固定明星企业，解释其入选理由，并通过产品功能全景、技术优势、团队实力和产业生态四个区块呈现其产业带动作用。页面不承担自由选企、换一换、跨产业混排、企业评分排名、风险诊断或招引培育结论。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 访客（未登录用户） | E-31 已确认门户公开信息角色；原始需求为企业重点介绍 | 快速理解当前产业代表企业的产品、技术、团队和生态影响。 |
| 科研人员 | E-31 已确认产品角色；原始需求包含技术优势与团队实力 | 查看公开技术成果、专利及人才团队信息，理解企业技术基础。 |
| 政府科技管理与决策部门 | E-31 已确认产品角色；原始需求强调企业对产业的带头作用 | 理解代表企业的入选依据、产业贡献和合作生态。 |

## 用户故事

### US-E34-01 理解代表企业及其入选理由

作为政府科技管理与决策部门用户，我想看到当前未来产业固定展示的明星企业、入选理由和适用标准版本，以便理解该企业为何能作为产业代表被介绍。

### US-E34-02 查看产品功能全景

作为访客，我想浏览明星企业的核心产品、应用场景、行业案例和公开媒体内容，以便直观理解其主要产品及产业影响。

### US-E34-03 理解技术优势与团队实力

作为科研人员，我想查看企业的专利、研发投入、核心技术、科研成果、核心团队和人才结构等公开信息，以便判断其可展示的技术与团队基础。

### US-E34-04 浏览产业生态与企业故事

作为访客，我想浏览企业上下游合作网络、发展历程和公开口碑摘要，以便理解企业在产业生态中的位置及成长脉络。

## 系统通用资质荣誉枚举

本模块不建立页面私有资质枚举，统一消费企业查询/企业档案的系统通用枚举：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

原始数据中的“高企”统一展示为“国高企”。同一企业允许多标签命中；标签用于事实展示，不直接推导明星企业评分或排名。

## 场景 walkthrough

### 主路径

1. 用户从企业总览切换到“明星企业介绍”，页面保持科技专题服务、当前未来产业和数据批次上下文。
2. 系统按当前产业及有效标准版本读取固定明星企业表，首屏展示企业名称、公开基础档案、资质荣誉、入选理由、标准版本和数据时间。
3. 用户点击“查看入选标准”，只读查看适用产业、候选范围、标准名称/版本、已确认维度和更新时间；不展示权重、内部阈值、排名或敏感原始证据。
4. 用户向下浏览产品功能全景、技术优势、团队实力和产业生态四个区块。
5. 产品、视频、3D 模型、案例、团队介绍、发展历程和口碑等内容只读取 CMS 已发布版本；基础指标由数据侧提供。
6. 用户点击生态节点查看合作关系摘要，或点击企业名称进入统一企业画像；页面不生成风险或推荐结论。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 当前产业未配置明星企业 | 展示“本产业明星企业待配置”，不随机推荐或跨产业补位 | 返回企业整体概况或切换产业 |
| 入选标准未定稿 | 保留明星企业展示并标记“入选标准待配置”；不伪造版本、阈值或排名 | 查看已公开企业内容 |
| CMS 内容未发布或部分缺失 | 只展示已发布内容；缺失区块使用业务空态，不显示编辑入口 | 浏览其他已发布区块 |
| 媒体资源不可用 | 保持区块高度并显示封面、资源不可用说明和重试，不自动播放失效资源 | 重试或继续浏览 |
| 产业生态关系不足 | 展示已确认关系摘要或“生态关系待完善”，不生成虚假节点 | 查看企业画像或其他区块 |
| 加载或接口失败 | 使用稳定骨架；局部失败隔离并提供重试 | 重试失败区块 |
| 无权限查看非公开字段 | 隐藏非公开字段并说明公开展示边界，不泄露 CMS 草稿 | 查看公开内容 |

## 模块边界与依赖

- 固定明星企业表、推荐标准版本与基础指标依赖数据/算法侧；选取规则及正式指标由 Q048 闭合。
- 视频、团队、详细介绍、案例、媒体、发展历程和口碑内容依赖 E-37 CMS 已发布版本，遵循 Q041。
- 产业生态关系先按 Q040 使用图数据库 demo 接口占位，正式关系不得由前端推断。
- 企业基础档案和资质荣誉复用企业查询/统一企业画像的数据定义。
- 页面不提供 CMS 编辑、内容发布、复杂筛选、导出、评分、风险、招引或培育操作。
