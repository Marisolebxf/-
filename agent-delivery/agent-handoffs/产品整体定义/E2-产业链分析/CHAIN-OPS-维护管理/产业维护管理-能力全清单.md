## 0. 结论

产业「维护管理」覆盖三类写侧，**共 16 项一级能力**（门户内容下再拆二级内容类型 / block_key，不另计一级；2026-08-17 增 C7）：

| 分组 | 项数 | 说明 |
| --- | --- | --- |
| A. 内容运营（CMS） | 5 | 招标门户内容 · 产业全景相关叶子 |
| B. 图谱运营 | 4 | 全要素图谱 · 产业链相关叶子 |
| C. 分析配置（APP OPS） | 7 | 诊断 / 区域 / 深圳分析配置 + 产业集群映射 |

系统级账户 / 全局工单中枢仍归「系统管理中心」。不增加八项分析 Bid 叶子计数。

## D. 边界

| 能力 | 归属 | 本菜单处理 |
| --- | --- | --- |
| 门户总览 / 专题八项分析读侧 | CHAIN-PORTAL / CHAIN-TOPIC-* | 只消费已发布 + ADS |
| 企业维护字段 | ENT-OPS | **禁止硬套**；仅复用壳与工作流形态 |
| 账户 / 全局工单 | 系统管理中心 | 链出，不重建 |
| CMS 正文写入诊断特征 / DWD | 禁止 | SPEC-CMS §3 / §6 |
