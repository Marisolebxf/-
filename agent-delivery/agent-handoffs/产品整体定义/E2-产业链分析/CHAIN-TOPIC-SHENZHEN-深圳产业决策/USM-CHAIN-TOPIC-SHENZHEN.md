### US-CHAIN-SZ-01｜配置并提交深圳产业情况对比

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` / `REQ-CHAIN-SZ-01` |
| 角色 | `ROLE-SZ-GOV` |
| Frames | `F-SZ-02` |
| 依赖 | `US-SYS-JOBS-01/02` |

作为政府科技主管部门决策人员，我想配置深圳与国内外标杆区域的产业对比，以便建立深圳产业坐标系。

**主路径**：确认产业 → 固定深圳 → 用四级地域 Cascader（全球/全国/区域/深圳，与产业总览同源）选 1～5 标杆（列表自带就绪态，未就绪不可选；**控件可编辑白底，不整控件置灰**）→ 只读确认四维 → 生成分析（至少 1 个就绪标杆）。

| 异常 | 行为 |
| --- | --- |
| 标杆均不可用 | 不创建任务、不伪造默认标杆 |
| 试图更换主体 | 主体锁定深圳 |

验收：`AC-US-CHAIN-SZ-01-01` 固化主体/标杆/四维/版本；`AC-US-CHAIN-SZ-01-02` 无有效标杆不建任务；`AC-US-CHAIN-SZ-01-03` 标杆可选国际节点（全球 G20 等），控件为共享四级 Cascader 而非国内城市扁平多选。

| 属性 | 内容 |
| --- | --- |

**主路径**：显式打开成功结果 → **对比结果**（主体/标杆 + 企业/专利/政策/人才表）→ **对标研判**（副标「独特优势 · 差距与劣势」；三栏：独特优势｜差距｜劣势；差距≠劣势；不单开「优势与劣势」）→ **产业化潜力与发展阶段综合判断**（三评估 + 所处阶段/阶段特征；不另挂顶部摘要 KPI）。

| 异常 | 行为 |
| --- | --- |
| 标杆数据后续失效 | 旧快照不变，局限可见 |

| 验收 | 说明 |
| --- | --- |
| `AC-US-CHAIN-SZ-02-01` | 结论绑定同一快照 |
| `AC-US-CHAIN-SZ-02-02` | 失效不静默改写 |
| `AC-US-CHAIN-SZ-02-03` | 结果页可见：**对标研判**（副标「独特优势 · 差距与劣势」）三栏标签「独特优势 / 差距 / 劣势」+「市场前景 / 技术成熟度 / 链条完整性 / 所处阶段 / 阶段特征」；「优势」业务态并入独特优势（评审旁注可追溯），禁止再拆重复「优势与劣势」块 |
