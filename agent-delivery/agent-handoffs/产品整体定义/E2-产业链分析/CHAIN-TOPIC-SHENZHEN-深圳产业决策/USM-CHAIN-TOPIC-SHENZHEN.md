## 4. 用户故事

### US-CHAIN-SZ-01｜配置并提交深圳产业情况对比

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` / `REQ-CHAIN-SZ-01` |
| 角色 | `ROLE-SZ-GOV` |
| Frames | `F-SZ-02` |
| 依赖 | `US-SYS-JOBS-01/02` |

作为政府科技主管部门决策人员，我想配置深圳与标杆区域的产业对比，以便建立深圳产业坐标系。

**主路径**：确认产业 → 固定深圳 → 选 1～5 标杆 → 只读确认四维与就绪 → 生成分析。

| 异常 | 行为 |
| --- | --- |
| 标杆均不可用 | 不创建任务、不伪造默认标杆 |
| 试图更换主体 | 主体锁定深圳 |

验收：`AC-US-CHAIN-SZ-01-01` 固化主体/标杆/四维/版本；`AC-US-CHAIN-SZ-01-02` 无有效标杆不建任务。

### US-CHAIN-SZ-03｜选择有效对比结果并提交深圳产业发展分析
