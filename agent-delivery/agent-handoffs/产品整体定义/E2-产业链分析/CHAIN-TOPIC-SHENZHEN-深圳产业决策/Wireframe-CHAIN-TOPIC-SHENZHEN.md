```text
┌─ 深圳产业决策 / 情况对比 ─────────────────────────────────────────┐
│ 主体：深圳（固定，只读置灰） | 产业：1（只读置灰）                 │
│ 标杆区域：1~5（可编辑白底；选项自带就绪/未就绪，未就绪项禁用）     │
│ 四维模型（只读）                                   [生成分析]        │
│ （无「就绪检测」按钮；门禁=选项禁用+提交校验；可编辑控件禁止整控件置灰） │
├─ 结果（Bid .6.1 / .6.2 原文词须可见）──────────────────────────────┤
│ 对比结果（整块）：主体/标杆标签 + 企业/专利/政策/人才表（无「四维对比」副标题）│
│ 对标研判（副标：独特优势 · 差距与劣势）                             │
│   [独特优势] | [差距] | [劣势]  ← 三栏；差距≠劣势；去掉重复「优势与劣势」块 │
│ .6.2 产业化潜力与发展阶段综合判断                                   │
│   三评估卡：市场前景 / 技术成熟度 / 链条完整性（含释义，不另挂顶 KPI）│
│   所处阶段 + 阶段特征                                               │
│ [生成报告] / [带入发展分析]                                         │
└────────────────────────────────────────────────────────────────────┘
```

| 字段 | 规则 | gap |
| --- | --- | --- |
| 主体 | 固定深圳 | — |
| `industry_id` | 恰好 1 | — |
| benchmarks | 1～5；控件=产业总览同款四级可搜索 Cascader（全球含 G20 / 全国省市区县 / 区域城市群 / 深圳各区）；不可用保留原因；禁止仅国内城市扁平多选 | — |
| 企业/专利/政策/人才 | 只读确认 | `GAP-CHAIN-SZ-METRICS` |
| 对标研判 | 主标题「对标研判」+ 副标「独特优势 · 差距与劣势」；三栏 **独特优势｜差距｜劣势** | `GAP-CHAIN-SZ-METRICS` |
| 独特优势 / 差距 | `.6.1`：相对标杆；**禁止**与「劣势」合并标签 | `GAP-CHAIN-SZ-METRICS` |
| 劣势 | `.6.2` 自身短板；紧随差距右侧；**劣势 ≠ 差距** | `GAP-CHAIN-SZ-METRICS` |
| 优势 | 业务态并入「独特优势」（不单开「优势与劣势」块）；评审旁注可追溯 | `GAP-CHAIN-SZ-METRICS` |
| 市场前景 / 技术成熟度 / 链条完整性 | `.6.2`：三评估须独立字段/卡片标签（不可仅埋散文） | `GAP-CHAIN-SZ-METRICS` |
| 所处阶段 / 阶段特征 | `.6.2`：阶段名 +「阶段特征」列表标题可见 | `GAP-CHAIN-SZ-METRICS` |

禁止：静默删不利标杆；无结构化合同时冒充可喂给发展分析；用私有城市列表替代共享四级地域控件；把「差距」与「劣势」合成同一栏；再拆一块重复的「优势与劣势」。

## 5. F-SZ-03 发展分析

```text
┌─ 深圳产业决策 / 发展分析 ─────────────────────────────────────────┐
│ 产业：1 | 来源：有效深圳对比结构化结果（显式选择）                  │
│ 目标：政策 / 技术 / 人才                            [生成分析]      │
├─ 结果 ─────────────────────────────────────────────────────────────┤
│ 来源依据（只读快照）：独特优势 | 差距 | 劣势 + [展开完整对比结果→抽屉] │
│ 三类建议（每条挂「针对：短板/优势」）                               │
│ 路径A/B（≥2；列：适用条件 / 局限性 / 针对） | 报告                  │
│ （不挂「重点行动/优先布局/周期/证据快照」类摘要 KPI 卡）             │
└────────────────────────────────────────────────────────────────────┘
```

| 字段 | 规则 | gap |
| --- | --- | --- |
| `source_result_id` | 同产业、有效、有权、结构兼容 | — |
| 目标三维 | 用户显式确认 | — |
| 来源依据 | 结果页顶部展示对比快照「独特优势 / 差距 / 劣势」摘要；**抽屉只读展开**完整对比（不离开发展结果 URL）；只读 | `GAP-CHAIN-SZ-METRICS` |
| 建议与路径 | 绑定来源快照；路径≥2；条目标注「针对」短板/优势 | `GAP-CHAIN-SZ-METRICS` |
| 摘要 KPI | **禁止**在发展结果页挂无业务口径的数字摘要卡（如重点行动数/周期等） | — |
| 全球案例 | 本轮不宣称交付 | `GAP-CHAIN-SZ-CASE-LIBRARY` |

禁止：PDF 作输入；自动继承最近对比；项目/预算/排期/责任分派 UI；结果页改写来源快照；无来源依据仅抛建议；发展结果页装饰性 KPI 条；「展开完整对比」整页跳转导致无法返回发展结果。

挂点：`CHAIN-SZ-F03-DEV-TITLE`、`CHAIN-SZ-F03-DEV-EVIDENCE`、`CHAIN-SZ-F03-SOURCE-RESULT`、`CHAIN-SZ-F03-CASE-GAP`。
