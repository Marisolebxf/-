## 模块：产业链总览

> **v1.5 全景范围收口**：用户先选择 **产业层级 L0**，五个 Tab 共用 `industry_id`。全景 Tab **仅承接门户 Bid 产业链全景**：结构图（上下游/细分产业/工艺环节依赖）+ 点击细分产业看**简介与企业列表**。默认展示 L1 子链并支持结构下钻。不提供产业链演进、核心技术、科研与服务机构、市场规模（归专题全景）。

本模块面向已经确定一个 L0 产业的用户，提供“先看 L1 子链全景，再按需要看概况、资讯、历程和深圳现状”的连续认知路径。它是单产业门户总览，不是产业查询页，也不运行趋势诊断、区域评价或深圳决策任务。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府产业管理与决策人员 | Bid 明确产业链分析为政府制定产业政策提供依据，并要求产业全景满足政府对格局、结构和趋势的掌握 | 看清产业结构与空间分布，理解深圳本地现状，选定后续分析对象 |
| 投资机构产业研究人员 | Bid 的产业全景可视化与内容管理明确服务投资机构 | 沿资讯与发展阶段理解重大变化，以原始证据支撑研究判断 |
| 企业战略与产业合作人员 | Bid 明确支持企业布局上下游合作，并要求产业全景服务企业 | 定位链位环节与关联企业，寻找上下游协作位置 |

## 用户故事（As / Want / So that）

### US-CHAIN-OV-01 确定并切换当前 L0 产业

作为政府产业管理与决策人员，我想通过顶部可检索下拉框快速确定一个 **L0 产业**（与企业查询所属产业同口径），以便下方所有内容始终围绕同一产业展开。

### US-CHAIN-OV-02 看清 L1 子链结构

作为政府产业管理与决策人员，我想先看到当前 L0 产业下的 **L1 子链**（如半导体设备、晶圆制造）及其上下游依赖，以便建立产业结构认知，而不是一上来淹没在工艺叶子节点中。

### US-CHAIN-OV-03 查看细分产业简介与企业列表

作为企业战略与产业合作人员，我想点击一个细分产业（L1 子链）查看**简介与企业列表**，并在需要时 **逐级下钻** 更细子链结构，以便定位合作主体而不丢失图谱上下文。

### US-CHAIN-OV-04 （废止）查看同链动态演进

> **已废止**：门户全景不承接动态演进（`DEC-CHAIN-PORTAL-OVERVIEW-PANORAMA-SCOPE-20260806`）。能力归专题 `CHAIN-TOPIC-PANORAMA` / IC-30。

### US-CHAIN-OV-05 沿事件线追踪产业资讯

作为投资机构产业研究人员，我想按事件时间浏览经整合确认的产业资讯并打开原始报道，以便验证信息而不是只阅读二次摘要。

### US-CHAIN-OV-06 查看整链概况

作为政府产业管理与决策人员，我想查看当前整条产业链的基本介绍以及企业、机构规模，以便形成不受局部节点选择影响的整体判断。

### US-CHAIN-OV-07 查看产业空间布局

作为政府产业管理与决策人员，我想在全球、全国、区域和深圳范围间检索地域，并在地图与同层列表间切换，以便从宏观到区县理解主体空间分布。

### US-CHAIN-OV-08 理解产业发展阶段

作为投资机构产业研究人员，我想按发展阶段查看关键里程碑、产业影响和证据，以便理解产业演进逻辑而不是浏览一组无结构新闻。

### US-CHAIN-OV-09 查看深圳产业现状

作为政府产业管理与决策人员，我想查看当前产业链在深圳的关键指标、各区布局及特色优势、集群效应和竞争地位，以便判断本地产业基本面。

### US-CHAIN-OV-10 加入后续分析对象集合

作为准备开展专业分析的用户，我想在浏览总览时把当前 **L0 产业**加入系统共享对比篮，并在需要时从系统悬浮入口自行打开全局对比篮浮层，以便页面对象操作与全局工具保持一致心智。

## 场景 walkthrough

### 主路径 A：从总览建立 L0→L1 全景认知并可下钻

1. 用户从“产业链分析 → 产业链总览”进入；入口有有效 `industry_id` 时使用该 L0 产业，否则加载后台配置的默认推荐 L0 产业。
2. 顶部显示当前 L0 产业可检索下拉框（选项与企业查询「所属产业」同口径）和加入/移出产业对比篮按钮，不重复提供打开全局对比篮入口；默认 Tab 为“产业链全景”。
3. 首屏图谱按上游、中游、下游展示该 L0 下的 **L1 子链**（如半导体设备、晶圆制造），并通过有向、具业务语义的关系连接；不默认铺开 L2+ 工艺叶子，也不铺开所有企业、技术和机构。
4. 全景工作台常驻 60% 图谱与 40% 右侧面板；未选择对象时右栏只显示“选择产业链环节”的操作引导。
5. 用户点击 L1 子链节点，节点及一跳关系强高亮；右栏展示节点基础信息、简介与企业列表；若该节点有子结构，提供「下钻内部结构」。
6. 用户下钻后，图谱切换为更细层级；面包屑显示 `L0 › L1 › …`，可返回任意上级。
7. 用户点击关系时，右栏可展示关系语义摘要；点击节点即可回到节点详情。
8. 页面不出现「产业链演进」控件。

### 主路径 B：连续浏览整链门户内容

1. 用户切换到“产业整体概况”，看到整链介绍、关联企业数、关联机构数和默认全国省级分布地图。
2. 用户通过完整四级可搜索地域控件切换全球、全国、区域或深圳；全球只覆盖 G20，全国支持省—市—区县下钻。
3. 用户切换列表视图，看到与地图当前层级相同的一批地域聚合对象；点击“在地图中查看”回到地图并定位该地域。
4. 用户切换到“产业资讯”，按类型或时间筛选事件线，打开事件详情并访问原始报道。
5. 用户切换到“产业发展历程”，按阶段浏览里程碑、影响和证据。
6. 用户切换到“深圳产业现状”，查看深圳指标、各区地图/列表和三类区域特色研判。

### 主路径 C：切换 L0 产业并加入对比篮

1. 用户在顶部下拉框输入 L0 产业名称或别名（如“集成电路”），键盘选择目标产业。
2. 页面保留当前 Tab，但清除下钻栈、旧节点、关系和其他局部状态后加载新 L0 的 L1 子链图，右栏回到操作引导空态。
3. 用户点击“加入产业对比篮”，当前 `industry_id` 加入系统级 `industry` 对比篮；页面不跳转且按钮变为“移出产业对比篮”。
4. 用户需要查看对象集合时，自行点击系统悬浮入口打开全局对比篮；总览页不触发浮层、不写入打开信号、不自建 Drawer，也不直接运行模型。

## 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 入口 `industry_id` 无效或已下架 | 给出轻量说明，并回退后台配置的默认推荐 L0 产业 | 继续浏览或在顶部重新检索 |
| 顶部检索无结果 | 下拉保留输入并展示“未找到产业”；不清空当前对象 | 修改关键词或继续当前对象 |
| 当前 L0 暂无 L1 子链 | 全景空态说明“暂无已发布的 L1 子链结构” | 切换产业或稍后重试 |
| 下钻层无数据 / 失败 | 保留面包屑与上级上下文，局部错误 + 重试；不伪造子节点 | 返回上一级或重试 |
| 图谱整体加载失败 | 保留页面上下文、Tabs 和工具栏，显示错误态及重试；不伪造节点 | 重试或切换其他 Tab |
| 图谱只有部分节点缺企业列表 | 图谱可继续浏览；右栏企业列表显示局部空态 | 选择其他节点 |
| 图谱关系服务失败 | 保留节点和阶段分区，明确“关系暂不可用”；不得画无依据连线 | 重试关系层 |
| 地图底图失败 | 列表视图仍可用，并提供重试底图 | 切换列表或重试 |
| 当前地域无数据 | 地图与列表显示同一范围空态，不回退到其他地域伪装有数据 | 返回上一级或换地域 |
| 资讯缺少原始报道链接 | 事件明确标记“原始报道链接缺失”，不生成伪链接 | 返回事件线 |
| 发展阶段或深圳特色内容未发布 | 对应区块显示未发布空态，不展示前端自编文案 | 返回其他 Tab |
| 未登录用户点击加入对比篮 | 不创建匿名本地篮，触发登录流程并保留返回上下文 | 登录后重试 |
| 对比篮已存在当前产业链 | 按钮显示“移出对比篮”，不得重复加入 | 保持或移出 |
| 内部评审数据失败 | 业务内容不受影响；对应评审浮层显示加载失败与重试 | 重试评审数据 |
