## 模块：产业链总览

> **v1.3 对象修订**：用户先选择产业，五个 Tab 共用 `industry_id`；产业链全景在该产业内部解析链结构。对比篮加入产业对象，后续产业级分析继续使用 `industry_id`，只有关键环节和瓶颈识别再选择 `chain_id`。

本模块面向已经确定一条产业链的用户，提供“先看全景，再按需要看概况、资讯、历程和深圳现状”的连续认知路径。它是单条产业链的对象总览，不是产业查询页，也不运行趋势诊断、区域评价或深圳决策任务。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府产业管理与决策人员 | Bid 明确产业链分析为政府制定产业政策提供依据，并要求产业全景满足政府对格局、结构和趋势的掌握 | 看清产业结构与空间分布，理解深圳本地现状，选定后续分析对象 |
| 投资机构产业研究人员 | Bid 的产业全景可视化与内容管理明确服务投资机构 | 沿资讯与发展阶段理解重大变化，以原始证据支撑研究判断 |
| 企业战略与产业合作人员 | Bid 明确支持企业布局上下游合作，并要求产业全景服务企业 | 定位链位环节、企业主体和技术路线，寻找上下游协作位置 |

### 实现角色映射（继承全系统权限基线）

| 产品角色 | 当前 persona / 最低权限 | 映射用途 |
| --- | --- | --- |
| 三类浏览角色 | L0 `GUEST` 及以上 | 只读浏览产业链总览；L0 触发下钻时进入登录引导并保留上下文 |
| 已登录注册用户 | L1 `REGISTERED` 及以上 | 下钻节点详情、加入/移出并打开系统产业链对比篮 |

| 内部业务用户 | L3 `INTERNAL` 及以上 | 查看敏感明细或使用高级配置；本总览当前不新增此类业务控件 |

## 用户故事（As / Want / So that）

### US-CHAIN-OV-01 确定并切换当前产业链

作为政府产业管理与决策人员，我想通过顶部可检索下拉框快速确定一条产业链，以便下方所有内容始终围绕同一对象展开。

### US-CHAIN-OV-02 看清产业链完整结构

作为政府产业管理与决策人员，我想先看到当前产业链的上游、中游、下游、全部链位环节及其依赖关系，以便建立完整的产业结构认知。

### US-CHAIN-OV-03 下钻环节主体与技术

作为企业战略与产业合作人员，我想点击一个链位环节查看简介、企业、技术、科研与服务机构，以便定位合作主体和技术路径而不丢失图谱上下文。

### US-CHAIN-OV-04 查看同链动态演进

作为投资机构产业研究人员，我想在当前全景中选择同一产业链的演进时间状态并查看变化证据，以便识别新主体加入、技术替代、关系变化和环节退出。

### US-CHAIN-OV-05 沿事件线追踪产业资讯

作为投资机构产业研究人员，我想按事件时间浏览经整合确认的产业资讯并打开原始报道，以便验证信息而不是只阅读二次摘要。

### US-CHAIN-OV-06 查看整链概况

作为政府产业管理与决策人员，我想查看当前整条产业链的基本介绍以及企业、机构规模，以便形成不受局部节点选择影响的整体判断。

### US-CHAIN-OV-07 查看产业空间布局

作为政府产业管理与决策人员，我想在全球、全国、区域和深圳范围间检索地域，并在地图与同层列表间切换，以便从宏观到区县理解主体空间分布。

### US-CHAIN-OV-08 理解产业发展阶段

作为投资机构产业研究人员，我想按发展阶段查看关键里程碑、产业影响和证据，以便理解产业演进逻辑而不是浏览一组无结构新闻。

### US-CHAIN-OV-09 查看深圳产业现状

作为政府产业管理与决策人员，我想查看当前产业链在深圳的关键指标、各区布局及特色优势、集群效应和竞争地位，以便判断本地产业基本面。

### US-CHAIN-OV-10 加入后续分析对象集合

作为准备开展专业分析的用户，我想在浏览总览时把当前产业链加入系统共享对比篮，并在需要时从系统悬浮入口自行打开全局对比篮浮层，以便页面对象操作与全局工具保持一致心智。

## 场景 walkthrough

### 主路径 A：从总览建立单链全景认知

1. 用户从“产业链分析 → 产业链总览”进入；入口有有效 `chain_id` 时使用该对象，否则加载后台配置的默认推荐产业链。
2. 顶部显示当前产业链可检索下拉框和加入/移出对比篮按钮，不重复提供打开全局对比篮入口；默认 Tab 为“产业链全景”。
3. 首屏图谱按上游、中游、下游展示全部链位环节，并通过有向、具业务语义的关系连接；不铺开所有企业、技术和机构。
4. 全景工作台常驻 60% 图谱与 40% 右侧面板；未选择对象时右栏只显示“选择产业链环节”的操作引导。
5. 用户点击链位环节，节点及一跳关系强高亮，其他可达路径弱高亮，无关对象降噪；右栏固定展示节点概览，下方提供“关联企业 / 核心技术 / 科研与服务机构”三 Tab。
6. 用户点击关系时，右栏切换为关系详情单页，展示源/目标节点、业务语义、证据来源、更新时间和当前演进时间；点击节点即可回到节点详情。
7. 用户在“产业链演进”控件选择历史状态，系统在原 60% 图谱中标示新增、退出、技术替代和关系变化，并在同一右栏展示变化对象及证据；不进入独立对比模式或工作区。

### 主路径 B：连续浏览整链门户内容

1. 用户切换到“产业整体概况”，看到整链介绍、关联企业数、关联机构数和默认全国省级分布地图。
2. 用户通过完整四级可搜索地域控件切换全球、全国、区域或深圳；全球只覆盖 G20，全国支持省—市—区县下钻。
3. 用户切换列表视图，看到与地图当前层级相同的一批地域聚合对象；点击“在地图中查看”回到地图并定位该地域。
4. 用户切换到“产业资讯”，按类型或时间筛选事件线，打开事件详情并访问原始报道。
5. 用户切换到“产业发展历程”，按阶段浏览里程碑、影响和证据。
6. 用户切换到“深圳产业现状”，查看深圳指标、各区地图/列表和三类区域特色研判。

### 主路径 C：切换产业链并加入对比篮

1. 用户在顶部下拉框输入产业链名称或别名，键盘选择目标产业链。
2. 页面保留当前 Tab，但清除旧链节点、关系、演进时间、详情 Tab 和其他局部状态后加载新链内容，右栏回到操作引导空态。
3. 用户点击“加入对比篮”，当前 `chain_id` 加入系统级产业链对比篮；页面不跳转且按钮变为“移出对比篮”。
4. 用户需要查看对象集合时，自行点击系统悬浮入口打开全局对比篮；总览页不触发浮层、不写入打开信号、不自建 Drawer，也不直接运行模型。

## 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 入口 `chain_id` 无效或已下架 | 给出轻量说明，并回退后台配置的默认推荐产业链 | 继续浏览或在顶部重新检索 |
| 顶部检索无结果 | 下拉保留输入并展示“未找到产业链”；不清空当前对象 | 修改关键词或继续当前对象 |
| 图谱整体加载失败 | 保留页面上下文、Tabs 和工具栏，显示错误态及重试；不伪造节点 | 重试或切换其他 Tab |
| 图谱只有部分节点缺详情 | 图谱可继续浏览；右侧面板对应详情 Tab 显示局部空态和最后更新时间 | 切换其他详情 Tab 或选择其他节点 |
| 图谱关系服务失败 | 保留节点和阶段分区，明确“关系暂不可用”；不得画无依据连线 | 重试关系层 |
| 产业链演进仅有一个状态 | 不显示变化标记，显示“暂无历史演进数据”；当前图谱仍可浏览 | 继续浏览当前状态 |
| 切换演进时间后原选中节点不存在 | 清除 `node_id`，右栏回到操作引导空态，并提示“原节点已不存在或不属于当前产业链” | 选择当前图谱对象 |
| 市场规模无正式数据源 | 字段显示“暂无正式数据源”；评审模式显示 Pending(Q056) | 浏览其他环节信息 |
| 地图底图失败 | 列表视图仍可用，并提供重试底图 | 切换列表或重试 |
| 当前地域无数据 | 地图与列表显示同一范围空态，不回退到其他地域伪装有数据 | 返回上一级或换地域 |
| 资讯缺少原始报道链接 | 事件明确标记“原始报道链接缺失”，不生成伪链接 | 返回事件线 |
| 发展阶段或深圳特色内容未发布 | 对应区块显示未发布空态，不展示前端自编文案 | 返回其他 Tab |
| 未登录用户点击加入对比篮 | 不创建匿名本地篮，触发登录流程并保留返回上下文 | 登录后重试 |
| 对比篮已存在当前产业链 | 按钮显示“移出对比篮”，不得重复加入 | 保持或移出 |
| 内部评审数据失败 | 业务内容不受影响；对应评审浮层显示加载失败与重试 | 重试评审数据 |
