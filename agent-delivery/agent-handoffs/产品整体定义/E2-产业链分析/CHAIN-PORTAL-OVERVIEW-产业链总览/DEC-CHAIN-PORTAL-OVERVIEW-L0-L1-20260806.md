## D-SELECTOR｜顶部产业选择器

1. 控件：Arco 可检索 `Select`（名称 / 别名匹配、键盘可达），形态与企业查询同类可检索选择控件一致。  
2. 选项粒度：仅 **产业层级 L0**；示例：`集成电路`、`生物医药`、`新能源`、`智能机器人`、`低空经济`（与企业 `industry` 字段取值对齐）。  
3. 路由主参：`industry_id`；旧 `chain_id` 只读兼容解析。  
4. 五个 Tab 共享同一 `industry_id`；Tab 内不得再提供产业 / 子链切换器。  
5. 对比篮：加入 / 移出当前 L0 产业对象（`elementKey=industry`），不写入 `industry_chain`。  
6. 全景标题：`{L0产业名称}产业链全景`（例：`集成电路产业链全景`）。

---

## D-DRILLDOWN｜默认 L1 与逐级下钻

1. **默认首屏（全景 Tab）**：在当前 L0 下渲染 **L1 子链** 节点及子链间关系（上 / 中 / 下游分区可保留）；不得默认铺开 L2+ 工艺细节点冒充 L1。  
2. **L1 示例（集成电路）**：半导体设备、晶圆制造、芯片设计、封装测试等；具体目录以产业图谱服务 / Demo Mock 为准。  
3. **下钻**：L1（或更深）节点若存在子结构，详情区提供「下钻内部结构」；图谱切换为该层 nodes/edges；可递归。  
4. **返回**：面包屑展示 `L0产业 › L1 › …`；可点任一级返回；「返回上一级」等价返回父层。  
5. **切产业**：切换 L0 时清空下钻栈、节点 / 关系选中、演进局部状态；右栏回操作引导空态。  
6. **权限**：浏览 L1 默认结构可匿名；下钻查看主体 / 技术明细仍按权限基线（未登录引导登录）。  
7. **非目标**：不在总览顶部直接选择 L1 子链；不把专题全景 Modal 对象合同并入本页；不新增任务 / 报告。
