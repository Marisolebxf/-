## 模块：专题侧产业链分析

本模块让政府、园区和企业用户围绕产业或产业链对象完成专业全景认知、七项计算型分析、任务恢复、不可变结果阅读及报告交接。八项 Bid 能力保持独立追溯；产业查询、分析记录、系统对比篮、任务层和报告框架是支撑入口或共享依赖，不增加 Bid 叶子。

### 七项计算型分析的统一交互验收链

以下链路同时约束 `04→05`、`06→07`、`08→09`、`10→11`、`12→13`、`14→15`、`16→17`，属于共用交互合同，不新增故事或 Bid 叶子：

```text
选择对象与完成业务配置
  → 点击“生成分析”
  → 进入可视化分析过程
  → succeeded 后点击“查看结果”
  → 阅读该分析的不可变结果
  → 在有效结果中点击“生成报告”
```

| 统一场景 | 可验证结果 |
| --- | --- |
| 配置有效并点击“生成分析” | 冻结对象与配置快照，创建唯一 `task_id`，进入该任务的过程视图 |
| created / prechecking / queued / running | 显示任务摘要、该 `analysis_type` 注册的阶段 Steps、当前阶段和后台继续说明；不得只显示 Spinner 或虚构百分比 |
| succeeded | 停留在完成态并启用“查看结果”；不得自动跳转到最近结果 |
| 点击“查看结果” | 以 `task_id/result_id` 打开匹配的不可变结果，内容由对应产业分析故事提供 |
| 在有效结果点击“生成报告” | 进入 `US-CHAIN-TOPIC-20`；过期、失败或无权结果不得创建正式报告 |

复用边界：过程页壳层、状态反馈和动作顺序参考企业评估现有实现；企业对象、指标权重、阶段文案、图表与结论不进入本模块。七种产业分析各自注册阶段和结果内容。

| 对应 Frames | `F-CHAIN-01` |
| `split_exception_reason` | `N/A` |

作为产业园区招商与产业促进人员，我想发现并保存产业或产业链对象，以便为后续专业分析准备准确对象。

#### 主路径

1. 用户初次进入、切换模式或清空查询条件时，先看到带可解释理由的确定性推荐产业；推荐不冒充实时排序。
2. 用户以智能检索或查产业发现对象；智能检索把已识别的字段化匹配关键词显示在输入框下方，用户可逐项移除并按剩余关键词重算，结果卡不重复显示匹配关键词。点击“高级筛选”进入同路由独立高筛页面，点击“热门产业”也进入该页并预置对应父级产业条件，条件仍可编辑且需用户点击“应用筛选”后才执行查询。普通检索条件与结果之间显示当前模式的最近检索；有效执行后写入，点击记录恢复条件并立即重跑。
3. 推荐态不显示复选框与批量工具栏，用户通过单卡查看摘要、进入全景图谱或加入对比篮；进入检索结果态后，首个勾选对象锁定本次选择类型，用户可全选本页并将有效对象批量加入共享篮。卡片与对象摘要抽屉的跳转统一为「进入全景图谱」（`industry` / `industry_chain` 均进入专题全景并保留查询上下文）；不再提供去门户总览。
4. 系统保留稳定 ID、对象类型、父级产业、来源与返回上下文；入篮后用户停留原页，进入全景后可由返回上下文回到查询。

#### 异常、边界与降级

| 场景 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 混选两种对象类型 | 拒绝冲突对象并保留当前选择 | 清空本次选择后改选另一类型 |
| 对象已入篮 | 不重复加入并显示已入篮状态 | 移除或选择其他对象 |
| 对象或数据暂不可用 | 保留对象和非敏感元数据，显示普通不可用原因，禁止选择、进入全景图谱和加入对比篮 | 选择其他可用对象 |
| 权限不足或权限撤回 | 显示 Arco 锁图标与权限原因；保留允许公开的元数据，隐藏敏感摘要，并锁定查看摘要、进入全景图谱、选择和加入对比篮动作 | 返回、选择其他对象或按正式权限合同申请；不显示推断的 L 级 |
