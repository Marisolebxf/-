## 1. 模块目标与产品边界

围绕用户显式确认的分析对象，在「产业运行诊断」二级工作空间内完成：

1. **产业周期分析**：产业级参数配置、正式任务、过程阶段呈现（联网检索 + 大模型推理等 Bid 原文能力词）、结果区「回溯—诊断—预测」与决策摘要；
2. **产业关键环节识别**：产业链对象、固定模型因子只读确认、过程/结果呈现 `.4.1`/`.4.2` Bid 原文能力词（全链结构化图谱、高端化指数、关键标注、竞争格局/代表企业/技术趋势）；
3. **产业瓶颈堵点识别**：产业链对象、五维只读确认、过程/结果呈现 `.5.1`/`.5.2` Bid 原文能力词（时序数据、四核心指标、各环节健康度、卡脖子定位、成因与改进建议/靶向方案）；
4. 本工作空间内的诊断记录恢复与配置复制。

三项能力各自保留独立 Bid 叶子追溯；放入同一二级工作空间不等于合并需求叶子。

### 1.1 承接

- 路由 `/industry-center/diagnosis?tab=cycle|key-link|bottleneck|records`；
- 对象合同：周期仅 `industry`（单选）；关键环节与瓶颈仅 `industry_chain`（单选），Demo 兼容 `both` 时由服务端按分析类型校验；
- 三业务 Tab 共享兼容 `industry_id`；关键/瓶颈额外共享兼容 `chain_id`；配置、筛选、结果焦点互不共享；周期不消费 `chain_id`；
- 统一分析任务壳层交接（点击生成 → **可视化过程阶段** → 显式查看结果）；
- 周期过程阶段必须可见呈现 Bid 原文能力词（见 §5.1），用户不配置「如何联网」；
- 本工作空间「诊断记录」过滤与恢复。

### 1.2 不承接

- 产业链全景图谱、区域产业评价、深圳产业决策；
- 产业查询、门户产业总览；
- 关键环节/瓶颈的正式可编辑权重或前端自定阈值；
- 正式 metric readiness D1–D4 投影（专题矩阵未建）；
- 共享对比篮 / 任务中心 / 报告阅读器内部实现；
- 模型训练控制台、可操作的联网检索控制台、页内 PDF 引擎；
- 跨二级页面自动继承对象。

### 5.1 周期过程阶段（验收词汇面）

配置完成并点击「生成分析」后，共享任务壳的可视化过程阶段须完整体现展示 Bid `.2.2.2` 原文能力词（只读进度说明，非运维控制台）：

1. 任务提交与参数冻结  
2. 整合产业参数与联网检索的历史与市场数据  
3. 大语言模型推理与周期阶段判断（诊断）  
4. 基于全网检索动态归纳趋势预测、关键驱动因素与潜在拐点  
5. 结果可信性校验与分析报告组装  

结果页同步保留「回溯—诊断—预测」结构，与过程阶段同源。  
V1 服务未接通时：阶段文案仍用上述 Bid 词汇描述能力链路，并可见「当前为固定可回放检索快照 / 待正式联网检索与模型接通」；**禁止**「已完成实时全网检索」等完成态假话。

### 5.2 关键环节过程与结果（验收词汇面）

对应展示 Bid `.2.2.4` / `.4.1` / `.4.2`：

**过程阶段（生成分析后，页内 Steps）**

1. 任务提交与产业链对象冻结  
2. 全链路环节结构化拆解（研发/设计/制造/销售/服务）  
3. 基于附加值率、技术壁垒、市场集中度计算高端化指数  
4. 关键环节智能标注与竞争格局/代表企业/技术趋势归纳  
5. 结果可信性校验与分析报告组装  

**结果面（须同时可见）**

- `.4.1`：全链路结构化图谱（或等价可读结构）+ 各环节**功能边界**与**衔接逻辑**；标准环节含研发、设计、制造、销售、服务；禁止截断为仅关键节点。  
- `.4.2`：显式**高端化指数**、关键环节标注、竞争格局、代表企业、技术趋势；正式「报告」经 ENT-EXPORT 交接。  

**因子映射**：父段「技术含量、附加值等」→ 注册三因子「附加值率 / 技术壁垒 / 市场集中度」（技术含量并入技术壁垒语义，不另开第四可编辑因子）。

### 5.3 瓶颈堵点过程与结果（验收词汇面）

对应展示 Bid `.2.2.5` / `.5.1` / `.5.2`：

**过程阶段（生成分析后，页内 Steps）**

1. 任务提交与产业链对象冻结  
2. 整合各环节技术/人才/资本/政策等时序数据  
3. 基于技术成熟度、人才供给量、融资事件、政策覆盖率计算环节健康度  
4. 瓶颈智能识别与卡脖子环节归因/改进建议生成  
5. 结果可信性校验与靶向方案/报告组装  

**结果面（须同时可见）**

- 默认以**全链路环节健康图谱**呈现五标准化环节（研发、设计、制造、销售、服务）；节点显式健康度；窄屏可降级等价链式；禁止主区纸质报告体；禁止跳转全景冒充。  
- `.5.1`：节点健康度评分（禁止只给链级总分）。结果纵序：**①** 多维度瓶颈综合分析（左五环节健康图谱 + 右环节详情，**等高对齐以右侧为准**）→ **②** 诊断报告。四核心指标名（技术成熟度 / 人才供给量 / 融资事件 / 政策覆盖率）在过程 Steps 可见，作为环节健康度计算输入口径；**不**在结果页做链级五维雷达 / 四核心对齐表同值双展（属已收回的产品延展，非 Bid/算法契约）。正式「可用于政策或项目设计」以 ENT-EXPORT 报告下载为出口。时序长说明评审态。  
- `.5.2`：节点显式**卡脖子**/瓶颈点位标注；点选后展示成因、改进建议（可用于政策或项目设计）、趋势预警；正式「靶向方案/报告」经 ENT-EXPORT 交接。  
- 结果顶栏 KPI 含**卡脖子环节数**（与图谱 `choke` 点位同词同计数）；禁止借用企业供应链等模块的「断链风险」作为本 Tab 顶栏标签。  
- 结果顶栏须直接显示当前**分析对象**；从诊断记录打开时优先任务快照。  

**维度口径**：页面维名必须用「资本」；算法 Bid「资金」仅同维服务别名，不拆两维。父段四维（技术/人才/资本/政策）为必现维；页面保留「市场需求」以对齐五维服务合同。
