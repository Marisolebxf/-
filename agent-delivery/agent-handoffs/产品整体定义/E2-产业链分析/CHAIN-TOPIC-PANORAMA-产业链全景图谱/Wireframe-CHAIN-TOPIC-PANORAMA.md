## 3. F-PAN-02｜全景图谱工作区

### 3.1 ContextBar

| 字段 / 动作 | 显示 | 规则 |
| --- | --- | --- |
| 当前分析对象 | 名称 + 类型 Tag（产业 / 产业链） | 唯一主对象；产业入口可附「全链路 N 条」；无对象时走 §1.1 空态 |
| 所属产业 | 父产业名称 | 仅 `industry_chain` 对象只读展示；产业对象隐藏 |
| 数据截至 | `effective_at` | 无对象时隐藏；不用页面当前时间代替；业务界面不得显示“快照”或 schema 版本 |
| 来源 | 产业查询 / 对比篮 | 只作来源上下文；无对象时隐藏 |
| 打开对比篮 | 主/次按钮 | 无对象为主 CTA；有对象时用于更换对象；取消不清上下文 |

ContextBar 只承载对象和快照基础口径；节点类型、关系类型等放局部控制，不混入顶部。

### 3.2 模式与快照

| 模式 | 控件 | 结果 |
| --- | --- | --- |
| 当前状态 | Segmented 默认项 + 查看时间 Select | 一个已发布时间状态 |
| 状态对比 | 基准时间 / 对比时间两个 Select | 同一 chain 的两个兼容时间状态并列核对 |
| 演进时间轴 | 图谱下方范围 + 播放/暂停/步进 | 已发布时间状态序列，不宣称实时流；不得放在顶部控制行 |

Q062 V1：只使用同一 `chain_id` 两个固定、可回放快照；界面变化状态显示中文“待补证”，内部仍记为 `pending`。快照未校验通过前保留最近有效单点。

### 3.3 图谱内系统控件

- 视口工具栏固定在图谱左上角，直接复用系统 `SharedMapChrome` 及系统通用按钮样式，页面不得另造工具栏。
- 每个时间状态标识位于工具栏下方，垂直间距 16px。
- 演进图例固定在图谱左下角并竖向单列；新增、退出、关系变化、主体变化、技术替代采用五种可区分语义色。ReviewMode 同时显示系统 `IconExclamationCircle` +“待补证”，点击打开 Q062 浮层；BusinessMode 不显示该标识和浮层。
- 时间轴固定在图谱下方，仅在时间轴模式显示；顶部控制区只承载模式和快照选择。
- 结构列表是当前发布状态的键盘等价路径，不承担动态演进。进入时停止播放并回到当前状态，隐藏状态对比、演进时间轴、变化图例及详情变化标识；不改变主对象或详情分组。

### 3.4 中央图谱

```text
[原材料阶段]          [生产阶段]             [流通阶段]          [终端市场]
┌ 环节 A ┐ ───────→ ┌ 环节 C ┐ ─────────→ ┌ 环节 E ┐ ─────→ ┌ 环节 G ┐
└ 环节 B ┘           └ 环节 D ┘             └ 环节 F ┘        └ 环节 H ┘

[左上：系统工具栏 缩放/复位/全屏]
[左下：演进图例 新增 / 退出 / 关系变化 / 主体变化 / 技术替代（待补证）]
[图谱下方：时间轴播放 / 暂停 / 步进 / 当前快照]
[图谱视图] [结构列表]
```

- 画布只包含正式阶段、环节与关系；所有节点可达，不因性能策略静默折叠、聚合或分页。
- 关系完整性缺口使用红色虚线 + “断点”文本，可 click / Enter 打开关系详情；断点不得使用“瓶颈关注”节点标签替代。
- 图谱、结构列表与详情的环节状态使用彩色映射：瓶颈关注橙、关键环节蓝、稳健环节青；断点保持红色虚线，并保留中文文本。结构列表状态 Tag 按文本自适应宽度；企业“在营”使用深青色，演进“新增”使用绿色，三者相互区分。
- 超长链保持节点最低可读尺寸，允许内部平移；“适配”将完整链放入安全区。
- 节点 click / Enter 唯一选中并更新详情；边 hover 显示关系类型和证据摘要。
- 专业图谱内核负责节点、边、布局与命中；Arco 外围负责工具栏、图例、状态、Drawer。
- “结构列表”提供阶段、环节、上游、下游和变化状态的键盘等价路径。
- 图谱与详情工作区填满首屏剩余高度；双状态比较区域可用宽度小于 1100px 时自动改为上下排列，宽度恢复后回到左右排列。
- 左侧工作区外层不绘制卡片背景、边框或圆角，只承担下钻路径、图谱/结构列表和时间轴布局；实际内容区只保留一层可见容器。
- 时间轴模式下，图谱与时间轴共同占用首屏剩余高度，时间轴位于图谱下方并保持 16px 间距，不得追加到首屏之外。

状态：`loading / empty / error / permission / single / dual / timeline / fullscreen`。Loading 保留 ContextBar、工具栏与容器尺寸；错误保留对象和重试；无权不显示节点摘要。

评审挂点：`CHAIN-PAN-F02-PANORAMA-TITLE`，payload 同时引用展示 Bid 与算法 Bid。

## 4. F-PAN-03｜节点详情与演进证据

1920/1680 为固定右 Panel（建议 480–560px）；1440 使用右侧非模态 Drawer（`30vw / min 480 / max 640`）。Header 固定、Body 滚动、Footer 固定；关闭后焦点回当前节点。

### 4.1 详情结构

```text
产业链 > 环节名称 > 当前详情类型                     [×]
环节名称 / 阶段 / 当前时间状态
演进状态（双状态/时间轴时，仅此处显示一次）
职责摘要 | 主要投入 | 主要产出 | [下钻内部结构（仅复合环节）]
[关联企业] [主流技术路线] [市场规模]
────────────────────────────────────────────────────
当前分组列表 / 空态 / 错误
```

演进状态条紧随面包屑，先于概要与分组列表呈现；列表增长不得改变该顺序或把状态条挤出首屏。概要区不得重复显示同一个变化类型 Tag。

深度下钻路径为：`产业链 → 复合环节子结构（可选、可递归）→ 叶子环节 → 关联企业/主流技术路线/市场规模`。返回上一级时恢复刚才进入的复合节点选中、高亮和详情。
下钻路径栏位于图谱/结构列表上方的独立行，与内容间隔 16px，不在画布内浮层覆盖节点或列表。

| 分组 | 明细字段 | 来源与动作 |
| --- | --- | --- |
| 关联企业 | 企业名称、角色、地区、产品/能力摘要 | 主体清单只使用可解析的企业主记录；“查看企业”打开当前页共享企业画像抽屉 |
| 主流技术路线 | 路线名称、前置投入、技术/工艺步骤、产出/应用、方向 | 技术数据与关系证据；路径节点用箭头表达先后或流向，不跳技术分析 |
| 市场规模 | 市场规模、行业说明 | 市场规模绑定 `M_CHAIN_MARKET_SIZE` 和 Q056 |

### 4.2 字段表（6 列）

| 名称 | 类型 | 来源 | 必填 | 示例 / 空态 | metric_id |
| --- | --- | --- | --- | --- | --- |
| 环节名称 | string | 图谱服务 `node_id` | 是 | 原料药 | — |
| 关联企业 | entity[] | 主体查询服务 + 企业主数据 | 否 | 可解析的企业名称列表；无可解析记录时局部 Empty | —（明细） |
| 主流技术路线 | route[] | 主体/关系服务 | 否 | `投入 → 技术/工艺 → 产出` | —（明细） |
| 市场规模 | decimal / null | 指标目录 | 否 | `暂无正式数据源` | `M_CHAIN_MARKET_SIZE` |
| 变化类型 | enum | 快照差异服务 | 否 | 新增/退出/关系变化/主体变化/技术替代 | —（事件） |
| 变化证据 | evidence[] | 差异服务 | 否 | 来源与时间 | —（明细） |

市场规模规则：值必须为 `null`，不显示 0、示例数、估算数或 MockBadge；字段旁 ReviewMode 可显示 `CHAIN-PAN-F03-MARKET-SIZE-PENDING`，业务模式不显示评审标识，但保留“暂无正式数据源”业务空值文案。

`M_CHAIN_ENTERPRISE_COUNT`、`M_CHAIN_NODE_COUNT`、`M_CHAIN_EDGE_COUNT`、`M_CHAIN_ENTERPRISE_NEW_COUNT` 已登记但本页没有数值宿主；不得为了“丰富页面”新增 KPI 卡。

### 4.3 演进证据

| 变化 | 视觉编码 | 文本与证据 |
| --- | --- | --- |
| 新增 | 高亮轮廓 + `IconPlusCircle` | “新增” + 前后快照 + evidence_id |
| 退出 | 虚线/弱化 + `IconMinusCircle` | “退出” + 最后有效快照 |
| 关系变化 | 边线型变化 + `IconSwap` | 关系前值/后值 |
| 主体变化 | 节点角标 + `IconUserGroup` | 主体加入/离开 |
| 技术替代 | 技术标识 + `IconRefresh` | 被替代/替代技术及证据 |

不只依赖颜色；五类变化使用不同语义色并显示中文类型；所有变化界面标“待补证”，直到 Q062 正式 API 闭合。
节点详情、关系详情与演进记录中的变化 Tag 必须复用图例颜色：新增绿、退出红、关系变化蓝、主体变化紫、技术替代橙。

### 4.4 已确认视觉约束（2026-08-04）

- 页面内容容器四周内边距固定 16px。
- 右侧详情复用产业链总览的标题、摘要、圆角 Tabs、主体卡片和演进说明样式，不另造页面视觉体系。
- 概要中的职责、主要投入和主要产出不在任何分组重复展示。
- `schema v1.0` 只在 ReviewMode 显示；BusinessMode 顶部只显示“数据截至”日期。

评审挂点：`CHAIN-PAN-F03-EVOLUTION-TITLE`、`CHAIN-PAN-F03-MARKET-SIZE-PENDING`；业务模式均 absent。

## 5. 服务响应最小字段

| 响应 | 必须字段 | 禁止 |
| --- | --- | --- |
| graph | `chain_id/snapshot_id/stages/nodes/edges/evidence_refs` | 前端生成节点、关系或方向 |
| node detail | `chain_id/node_id/snapshot_id/subject_groups/attributes/evidence_refs` | 用旧节点详情覆盖当前选择 |
| snapshots | `snapshot_id/effective_at/schema_version/status` | 以请求时间代替快照时间 |
| diff | `base_snapshot_id/compare_snapshot_id/change_type/target_id/evidence_refs` | 无证据差异、跨 chain 比较 |
| permission | 字段/动作授权结果 | 前端 persona 自行放权 |

调用链固定为前端 → 网关 → Java 聚合 → 已登记算法/数据服务；前端不直连 Python、数据库或图数据库。
