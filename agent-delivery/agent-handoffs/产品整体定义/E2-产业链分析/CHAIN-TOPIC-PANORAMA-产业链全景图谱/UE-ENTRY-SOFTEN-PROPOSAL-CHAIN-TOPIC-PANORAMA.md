## 1. 问题诊断

### 1.1 当前进入路径（权威条款）

| 步骤 | 行为 | 权威落点 |
| --- | --- | --- |
| 1 | 用户点左侧「产业链全景图谱」，route=`/industry-center/panorama`，导航项保持 selected | UX-SPEC `PAN-J01` 步骤 1；Wireframe §1 |
| 2 | URL 无有效对象时，页面壳 ready 后**自动打开**顶层 Arco `Modal`（`F-PAN-01`） | IA §3.1.1；USM `US-CHAIN-PANORAMA-01` 主路径 1；UX-SPEC §1 边界 / `PAN-J01` 步骤 2 / §5.1；TRACE `F-PAN-01` |
| 3 | Modal 只列对比篮兼容 `industry` / `industry_chain`，单选；industry 须同 Modal 内显式确认所属链；未就绪时主按钮不可用；空态「去产业查询」 | IA §3.1.2–4；Wireframe §2；USM 异常表 |
| 4 | 校验成功后关 Modal，进入 `F-PAN-02` 工作区；初次无对象时**不允许关 Modal 后停在空页** | UX-SPEC §5.1；Wireframe §2.1「首次无对象取消则返回上一有效入口」 |

### 1.2 为何阻断感强（相对 D10 / 兄弟模块）

| 维度 | 当前全景 | D10 / 兄弟模块对照 | 偏差判断 |
| --- | --- | --- | --- |
| 导航语义 | 点菜单后立刻被全屏 mask + Modal 挡住 | D10 §4.1：左侧导航「点击进入模块」；整页阻塞「只用于首次加载」（§3 组件优先级表） | 模块已进 route，但用户感知仍是「进不去」 |
| Modal 用途 | 把「获得主对象」做成**进页门禁** | D10 §3.3 / §12.2：Modal 用于配置、确认、审批等**流程阻断**；详情与上下文保留优先 Drawer / 页内 | Modal 用对了「确认」语义，但触发过早、覆盖过满 |

## 2. 目标与非目标

### 2.1 目标

1. **先进页、后定对象**：点导航后先看到全景工作区壳（ContextBar + 图谱区占位），再完成对象确认。  
2. **保留业务硬规则**：单次唯一 `industry_chain`；industry 不静默代选链；对象源仍为共享对比篮；不创建任务；不新增私有对象体系。  
3. **降低门禁感**：无对象时不再用全屏强 Modal 作为唯一可见面；主 CTA 禁用仅绑定「尚未确认合法链」，而非「看不见页面」。  
4. **与诊断进入体感对齐**（页内空态引导），不照搬总览「默认链进页」。

### 2.2 非目标

- 不新增角色、字段、路由、权限点、分析类型、任务/报告能力。  
- 不引入页内私有产业 Select 平行体系（与诊断一致：对象来自对比篮 / 查询回流）。  
- 不把门户总览范围并入专题全景；不改对比篮内部实现。  
- 不在本方案实施 Demo / 注册任务 / 替甲方定默认产业口径。

## 3. 方案对比

### 方案 A（推荐）：页内先落地 + ContextBar 空态引导；Modal 降级为「主动选/换对象」

| 项 | 内容 |
| --- | --- |
| IA / 进入时序 | `shell_ready → workspace_shell_visible (no_object) → 用户点「选择分析对象」→ F-PAN-01 Modal → 确认链 → workspace_loading`；取消自动 `auto_open_modal` |
| UI 承载 | 页内：ContextBar 空态 + 图谱区引导 Empty（「请先选择分析对象」+ 主按钮「选择分析对象」+「去产业查询」）；**Modal 仅由用户主动触发**（及「更换对象」、对比篮 industry 链确认） |
| 默认对象 | **无**系统默认 / Demo 默认；有合法 URL/`chain_id` 时直入工作区（沿用现能力） |
| 空态 / 关闭 | 允许「有壳无对象」页内空态；Modal 可 Esc/取消回到空态壳（不再强制退上一入口）；有对象时取消「更换」仍保留工作区 |
| 故事验收影响 | **必须改** `AC-US-CHAIN-PANORAMA-01-01` 及故事叙述中的「自动打开 Modal」；US-02+ 在「已确认对象」后不变 |
| 范围 / 合规 | 触碰已批准 `DEC-…-OBJECT-MODAL` → 需**新决策废止/修订**；不新增能力，属进入时序与空态承载调整；**不能只改 UX-SPEC** |

**优点**：直接回应「阻断太强」；与诊断一致；用户能看见模块骨架与后续能力轮廓。  
**风险**：须同步改 IA/USM/Wireframe/TRACE/UX-SPEC；评审挂点文案从「强制 Modal」改为「选择器宿主」。

---

### 方案 B：保留 Modal 合同，叠加「会话内恢复上次已确认链」（弱化复发阻断）

| 项 | 内容 |
| --- | --- |
| IA / 进入时序 | 无 URL 对象时：若会话存在**用户曾显式确认**且仍合法的 `chain_id` → 直接进 `F-PAN-02`；否则仍 `auto_open_modal`（首次/失效仍门禁） |
| UI 承载 | Modal 形态不变；ContextBar 可显示「已恢复上次对象」轻提示（非阻断） |
| 默认对象 | 🟡 非 Demo 默认，但是「记忆上次」— 需产品确认是否算静默对象 |
| 空态 / 关闭 | 首次路径与现状相同；恢复失败回落 Modal |
| 故事验收影响 | 需新增 AC（恢复成功不弹 Modal）；AC-01-01 改为「无 URL 且无有效会话记忆时自动 Modal」 |
| 范围 / 合规 | 新增「会话记忆」行为规则 → 须回流 USM/IA；**不能只改 UX-SPEC**；首次进入痛点仍在 |

**优点**：改动面相对小，复访体验明显改善。  
**风险**：不解决首次/清会话用户的强阻断；易与「禁止默认对象」混淆。

### 方案 C（不推荐作主方案）：自动弹出非模态 Drawer / 弱引导条，仍强制先选

| 项 | 内容 |
| --- | --- |
| IA / 进入时序 | 进页后自动展开右侧/底部选择面板，背景壳可见但图谱操作禁用 |
| UI 承载 | Drawer / 页内面板替代 Modal；主按钮逻辑同现 |
| 默认对象 | 无 |
| 空态 / 关闭 | 可关面板留空态壳（若允许关）则接近方案 A；若不许关则阻断感几乎不降 |
| 故事验收影响 | Frame 宿主、Wireframe、AC 均需改 |
| 范围 / 合规 | 若仍「自动弹出且不可绕过」，用户评价可能不变；投入产出差 |

### 推荐结论

**推荐方案 A。**  
理由：用户原话针对的是「一点菜单就被挡住」，根因是**门禁时序**而非 Modal 视觉细节。方案 B 仅缓解复访；方案 C 若不放开「可关面板看空壳」，与现状同级阻断。

## 4. 推荐方案（A）详细交互规格

### 4.1 不变的业务规则（范围冻结）

1. 工作区主对象有且仅有一个已确认 `industry_chain`（+ `parent_industry_id`）。  
2. 候选仍来自共享对比篮兼容 `industry` / `industry_chain`；无兼容对象时引导「去产业查询」（`return_context=panorama`）。  
3. 选 `industry` 必须显式确认所属链；仅一条链也展示确认，不静默代选。  
4. 选 `industry_chain` 可直接确认。  
5. 对比篮单对象发起全景：chain 直入；industry 打开链确认；不创建 `task_id`。  
6. 未确认合法链前：**不加载图谱业务数据 / 不渲染节点摘要**（防泄密与误读）。  
7. 不提供页内私有对象 Select 平行体系。

### 4.2 主路径

#### PAN-J01'｜直接进入（修正）

1. 点击左侧「产业链全景图谱」→ route 进入，导航 selected。  
2. `shell_ready`：渲染 `F-PAN-02` 壳（ContextBar + 模式区占位禁用 + 图谱区引导空态 + 详情区引导）。**不自动打开 Modal**。  
3. ContextBar 显示「未选择分析对象」；主操作「选择分析对象」。  
4. 用户点击「选择分析对象」（或图谱区同义主按钮）→ 打开 `F-PAN-01` Modal（列表/Tabs/industry→链确认逻辑复用现 Wireframe §2）。  
5. 确认且服务端校验通过 → 关 Modal → `workspace_loading` → 加载图谱；焦点到 `F-PAN-02` 主标题 / ContextBar 对象名。  
6. 若 URL 已带有效已确认对象 → 跳过 3–4，直入加载（与现一致）。

#### PAN-J02｜对比篮发起（保持，微调时序表述）

- chain：直入工作区，不经空态。  
- industry：可先进页再开链确认 Modal，或在篮侧确认后进页（二选一须在落地时写死；**推荐**：先进页再开确认步，避免双遮罩）。  
- 仍禁止任务化。

#### 更换对象

- ContextBar「更换对象」打开同一 `F-PAN-01`。  
- 取消：保留当前对象、节点、快照、模式、视口（沿用 USM）。

### 4.3 异常路径

| 场景 | 系统行为 | 恢复 |
| --- | --- | --- |
| 对比篮无兼容对象 | Modal / 或页内空态区 `Empty` +「去产业查询」 | 查询入篮后 `return_context` 回全景；仍停在壳或重新打开选择器 |
| industry 无所属链 / 解析失败 | 保留产业选择，不代选链；步骤内错误 | 重试或换产业 |
| 对象失效 / 无权 | 保留壳与原因；图谱不渲染摘要 | 更换对象或申请权限 |
| 校验失败 | Modal 内错误 + 可重试；不关闭用户选择 | 修正后重试 |
| 图谱服务失败（已有对象） | 保留 ContextBar，局部 Result + 重试 | 同请求重试或更换对象 |

### 4.4 键盘 / 焦点

| 场景 | 规则 |
| --- | --- |
| 进页无对象 | 焦点落在 ContextBar「选择分析对象」（或图谱区主按钮，二者只保留一个主焦点入口） |
| 打开 Modal | 焦点进 dialog 标题后首个可用选项；Tab 序：类型 Tab → 列表 → 链确认 → 次按钮 → 主按钮 |
| 列表 | 方向键移 Radio；Enter 选中；主按钮 enabled 时 Enter 确认（避免与列表 Enter 冲突时：列表 Enter=选中，确认用主按钮或 Ctrl+Enter——落地 UX-SPEC 写死一种） |
| Esc | 关 Modal → 焦点回触发按钮；**允许停留在无对象壳** |
| 确认成功 | 焦点到 ContextBar 对象名或图谱主标题 |
| 有对象工作区 | 沿用现 UX-SPEC §7（图谱 / 结构列表 / 详情） |

### 4.5 状态机（简述）

```text
[route_enter]
  → shell_ready
  → has_valid_resolved_chain?
        yes → workspace_loading → workspace_ready
        no  → no_object_shell
                ├─ open_picker (user) → modal_object_list
                │     ├─ select industry → chain_resolution → ready → validating
                │     ├─ select chain    → ready → validating
                │     ├─ cancel/Esc      → no_object_shell
                │     └─ go_search       → search_redirect
                └─ go_search (from shell)
  validating ok → workspace_loading → workspace_ready
  change_object (from workspace_ready) → modal_* → cancel → workspace_ready (unchanged)
```

禁止态（保持）：`no_object_shell` 下图谱缩放/选节点/演进控件禁用或不可达；不得用 Skeleton 假装已有链。

### 4.6 与 D10 对齐说明

- 导航：先完成「进入模块」。  
- Modal：回到「用户发起的确认/更换」，而非 route 门禁。  
- 空态：页内可操作 Empty，符合「说明下一步」。  
- 遮罩：仅在用户打开选择器时出现。
