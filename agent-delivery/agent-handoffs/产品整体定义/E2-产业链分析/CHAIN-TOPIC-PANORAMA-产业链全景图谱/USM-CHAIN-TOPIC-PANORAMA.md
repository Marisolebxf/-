# USM-CHAIN-TOPIC-PANORAMA｜产业链全景图谱

> **版本**：v1.3-source-semantics  
> **状态**：与 IA、TRACE、Wireframe 同步  
> **体验 Owner**：高颖  
> **原始需求**：展示 Bid `1.1.1.2.4.2.2.1/.1/.2`；算法 Bid `1.1.1.1.1.1.1.3.1`

## 1. 模块结果

围绕一个明确产业链，即时完成对象确认、完整结构认知、主体与属性下钻、固定快照动态演进核对。不创建分析任务，不承接其余七项产业分析，也不把算法后台配置、导出服务或门户总览转成页面功能。

## 2. 产品角色

| 角色 ID | 产品角色与原始依据 | 实现映射 | 数据边界 |
| --- | --- | --- | --- |
| `ROLE-PAN-GOV` | 政府科技主管部门；算法 Bid 的布局与政策决策 | `GOV×L3` | 授权范围内内部或敏感字段 |
| `ROLE-PAN-PARK` | 产业园区招商与促进；展示 Bid 招商语境、IC-30 | `INNO×L3` | 园区授权范围 |
| `ROLE-PAN-ENTERPRISE` | 企业战略与业务；算法 Bid 协同发展语境、IC-30 | 认证后 `INNO×L2` | 公开、授权或服务端脱敏字段 |

产品角色不是权限 persona。前端不从 Mock 用户推断权限；服务端失败关闭。无权动作保留位置并解释，未授权敏感值不渲染。L4 只维护与审计。

## 4. 用户故事

### US-CHAIN-PANORAMA-01｜确认唯一产业链对象

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation` |
| 产品角色 | `ROLE-PAN-PARK` |
| 依赖 | `SYS-COMPARE-WORKSPACE` |
| Frame | `F-PAN-01` |
| 业务结果 | 一个有效 `industry_chain` 被用户显式确认，URL 与 ContextBar 一致 |

作为园区招商与促进人员，我想通过统一对象 Modal 确认一个产业链，以便从正确对象进入全景工作区。

主路径：

1. 直接无对象入口自动打开 Modal，或从对比篮选择一个兼容对象发起。
2. 用户单选对象；若为 industry，在同一 Modal 显式确认所属链。
3. 服务端校验身份、对象与权限；成功后关闭 Modal，进入工作区。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 无兼容对象 | Modal `Empty`，提供“去产业查询” | 查询并入篮后返回 |
| industry 无所属链 / 请求失败 | 保留产业，不自动代选 | 重试或更换产业 |
| 对象失效 / 无权 | 保留对象位置与原因，不泄露图谱摘要 | 更换对象或申请权限 |
| 更换对象后取消 | 保留当前对象、节点、快照、模式与视口 | 继续当前阅读 |

验收：

- `AC-US-CHAIN-PANORAMA-01-01`：无 URL 对象点击菜单，自动打开 Modal；无页内 Select、无整页空态。
- `AC-US-CHAIN-PANORAMA-01-02`：industry 未确认所属链前不得加载画布，即使只有一条链也显示确认结果。
- `AC-US-CHAIN-PANORAMA-01-03`：industry_chain 确认后加载同一 `chain_id`。
- `AC-US-CHAIN-PANORAMA-01-04`：对比篮单对象发起，不创建 `task_id` 或任务过程页。

不包含：共享篮容量、持久化与增删；默认 Demo 对象；页面私有对象 Select。

### US-CHAIN-PANORAMA-02｜浏览完整产业链结构

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-CHAIN-PANORAMA-STRUCTURE`、`REQ-CHAIN-PANORAMA-MODEL-SERVICE` |
| 产品角色 | `ROLE-PAN-PARK` |
| 依赖 | US-01 |
| Frame | `F-PAN-02` |
| 业务结果 | 完整上下游阶段、正式环节和关系稳定可达 |

作为园区招商与促进人员，我想看清完整产业链结构，以便识别上下游关系和断点。

主路径：

1. ContextBar 显示产业链、父产业、快照和来源。
2. 服务返回从原材料、生产、流通到终端市场的阶段、环节与正式关系。
3. 图谱内核稳定左到右呈现；完整关系使用实线，断点使用红色虚线与“断点”文本，用户可点击进入关系详情查看缺口与证据。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 图谱服务失败 | 保留对象与容器，局部错误 | 重试同一请求或更换对象 |
| 无正式结构 | 明确“暂无正式结构”，不生成示例链 | 更换对象 |
| 部分关系缺失 | 保留缺失状态和证据入口，不推断补齐 | 查看来源或等待更新 |
| 无权 | 保留页面壳、对象和恢复动作，画布不渲染摘要 | 申请权限或更换对象 |

验收：

- `AC-US-CHAIN-PANORAMA-02-01`：所有正式环节与关系可达，不静默折叠、聚合、分页。
- `AC-US-CHAIN-PANORAMA-02-02`：视口操作不改变对象、快照或请求业务重算。
- `AC-US-CHAIN-PANORAMA-02-03`：前端只渲染服务返回的节点和边，不用 Mock 规则推断关系。
- `AC-US-CHAIN-PANORAMA-02-04`：错误恢复后仍是原 chain 和 snapshot，不跳门户或技术链。
- `AC-US-CHAIN-PANORAMA-02-05`：断点作为关系完整性缺口可被视觉定位、文本识别、键盘/鼠标选中并在详情中说明；“瓶颈关注”仍是节点状态，两者不互相替代。

不包含：节点/关系数量 KPI；图谱模板、节点编辑和关系维护。

### US-CHAIN-PANORAMA-03｜下钻节点并查看关联详情

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-CHAIN-PANORAMA-DRILL-EVOLUTION`、`REQ-CHAIN-PANORAMA-MODEL-SERVICE` |
| 产品角色 | `ROLE-PAN-PARK` |
| 依赖 | US-02 |
| Frames | `F-PAN-02`、`F-PAN-03` |
| 业务结果 | 取得与 `chain_id + node_id + snapshot_id` 一致的主体与属性证据 |

作为园区招商与促进人员，我想从产业链宏观结构深度下钻到环节，以便查看关联企业、主流技术路线和市场规模。

主路径：

1. 用户 click / Enter 选择正式环节，完整链保留，当前节点唯一高亮；系统以 `chain_id + node_id + snapshot_id` 打开该环节深度详情。
2. 复合环节返回 `child_nodes/child_edges` 时，用户选择“下钻内部结构”进入子链/工艺链；返回上级后恢复该复合节点的选中、高亮与详情。无子结构时不显示该动作。
3. 叶子环节详情按关联企业、主流技术路线、市场规模三组显示展示 Bid 明确要求的内容。
4. 企业条目以企业域稳定 ID 解析共享企业主记录，“查看企业”在当前页打开共享企业画像抽屉；主流技术路线按“前置投入 → 技术/工艺步骤 → 产出/应用”显示路径，不以技术实体列表替代。

| 场景 | 系统行为 |
| --- | --- |
| 未选节点 | 详情引导选择，不默认第一节点 |
| 详情失败 | 画布与高亮保留，详情独立重试 |
| 关联类型无数据 | 对应分组局部 Empty，不删除其他分组 |
| 敏感字段无权 | 字段标签保留，原值不渲染，显示权限说明 |
| 市场规模无正式源 | `M_CHAIN_MARKET_SIZE` 值为空，显示“暂无正式数据源”（Q056） |

验收：

- `AC-US-CHAIN-PANORAMA-03-01`：任一详情响应的三重身份与当前上下文一致。
- `AC-US-CHAIN-PANORAMA-03-01A`：任一正式环节均可完成“产业链 → 环节 → 关联企业/主流技术路线/市场规模”的深度下钻；下钻不替换宏观图谱，不丢失节点高亮、当前分组、时间状态和视口。
- `AC-US-CHAIN-PANORAMA-03-01B`：复合环节有 `child_nodes/child_edges` 时可进入子结构；返回上级恢复复合节点选中、高亮、详情和原视口。无子结构时不显示伪下钻入口。
- `AC-US-CHAIN-PANORAMA-03-02`：三类信息分组只展示有据内容；主流技术路线必须呈现路径节点与方向，不得只展示技术标签。
- `AC-US-CHAIN-PANORAMA-03-03`：市场规模不得显示 Mock 数字、0 或推算值。
- `AC-US-CHAIN-PANORAMA-03-04`：共享企业详情关闭后，焦点返回触发企业条目，图谱不重载。
- `AC-US-CHAIN-PANORAMA-03-05`：人才科研、服务供应作为算法多源输入不自动转换为本页主分组；无独立展示需求时界面不得出现对应 Tab。
- `AC-US-CHAIN-PANORAMA-03-06`：企业卡、企业画像抽屉和企业对比篮的 `enterprise_id/enterprise_code` 一致；不得用节点内临时 ID 打开空详情，无法解析的引用不提供“查看企业”。

不包含：技术分析跳转、企业子图、主体数量 KPI、报告或导出。

### US-CHAIN-PANORAMA-04｜对比固定快照并观察动态演进

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-CHAIN-PANORAMA-DRILL-EVOLUTION`、`REQ-CHAIN-PANORAMA-MODEL-SERVICE` |
| `decision_refs` | `Q062` |
| 产品角色 | `ROLE-PAN-GOV` |
| 依赖 | US-02、US-03 |
| Frames | `F-PAN-02`、`F-PAN-03` |
| 业务结果 | 同一链固定快照的变化类型和证据可追溯 |

作为政府决策人员，我想比较同一产业链的固定快照，以便核对结构和主体变化，而不是把演示动画误认为实时数据。

主路径：

1. 用户选择当前状态、状态对比或演进时间轴；V1 的比较对象必须是同一 `chain_id` 的两个固定时间状态。
2. 空间位置保持稳定，显示新增、退出、关系变化、主体变化、技术替代。
3. 用户通过图谱下方时间轴暂停并选择变化项，详情展示前后快照、变化类型、证据引用和中文“待补证”状态。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 快照不兼容 | 阻止比较，保留最近有效单点 | 重选快照 |
| 范围无变化 | 保持结构，显示“该范围无已确认变化” | 调整快照 |
| 差异无证据 | 不标记为已确认变化 | 返回原视图 |
| 动画中更换对象 | 先停止播放，再打开对象 Modal | 确认或取消 |

验收：

- `AC-US-CHAIN-PANORAMA-04-01`：双快照的节点空间基线一致，五类差异均有文本/线型辅助，不只依赖颜色。
- `AC-US-CHAIN-PANORAMA-04-02`：时间轴播放、暂停和步进可操作，尊重 reduced motion。
- `AC-US-CHAIN-PANORAMA-04-03`：V1 明示固定快照 Pending，不出现“实时更新”声明。
- `AC-US-CHAIN-PANORAMA-04-04`：不兼容或无证据时不生成伪差异、伪变化数 KPI。
- `AC-US-CHAIN-PANORAMA-04-05`：系统通用工具栏位于图谱左上，五色中文图例位于左下，证据未闭合使用系统 `IconExclamationCircle` +“待补证”，点击可查看 Q062 的缺口、当前处理、责任人和关闭条件；时间轴位于图谱下方，页面容器保持 16px 内边距。
- `AC-US-CHAIN-PANORAMA-04-06`：业务界面不出现“快照”或 schema 版本；状态标识位于工具栏下方 16px，图例单列，工作区充满首屏，双状态区域不足 1100px 时自动纵向排列。
- `AC-US-CHAIN-PANORAMA-04-07`：Q062 状态入口、浮层及 schema 版本只在 ReviewMode 显示，BusinessMode 均 absent。
- `AC-US-CHAIN-PANORAMA-04-08`：进入结构列表自动停止演进并回到当前状态，所有动态演进控件、图例和详情变化标识均不显示。
- `AC-US-CHAIN-PANORAMA-04-09`：节点、关系及演进记录的变化 Tag 与图例同色映射：新增绿、退出红、关系变化蓝、主体变化紫、技术替代橙。

不包含：实时流、变化预测、模型参数配置。
