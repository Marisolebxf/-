## 1. 决策（一句话）

**全景图谱的「本次分析对象」在本页选定，不再经对比篮。**  
对比篮只做跨页收藏与分发；全局圆点不是换对象入口。产业链选择对齐产业周期分析的页内「本次分析上下文」。

---

## 2. 问题（现场）

用户路径：`产业查询` → `打开对比篮` → `对比篮（全局圆点）` → 全景工作区。  
跳跃重、不知道下一步操作什么；**评估对象被绑到对比篮**，与周期分析已跑通的页内选对象互相打架。

### 2.1 当前实际路径（Demo）

```text
侧栏「产业链全景图谱」
  → 无 URL 对象：静默写入推荐示例产业（source=default）
  → ContextBar「打开对比篮」/ 提示「更换」
      → URL 加 open_compare_basket=1 + picker
      → 右下角圆点展开系统浮层（产业/企业/机构…多 Tab）
      → 篮空：再跳「去产业查询」
产业查询
  → 检索结果同时给「进入全景图谱」和「加入对比篮」
  → 入篮后用户仍可能再点全局圆点，在篮里勾选 + 选分析类型
全景节点详情
  → 「加入企业篮」又写企业 Tab
```

同一任务里叠了 **4 套入口**：页内推荐示例、ContextBar 开篮、遗留对象 Modal、查询直达。主 CTA 却把用户从工作区拽到全局浮层。

### 2.2 为什么会「突然不知道要操作什么」

| 混淆点 | 用户看到的 | 系统实际在做 |
| --- | --- | --- |
| 分析对象 = 对比篮？ | 空态文案「请在系统对比篮中选择」 | 篮是跨页收藏夹，还可分发 8 项分析 |
| 全局圆点 | 始终在，点开是多类型 Tab + 勾选 + 分析类型弹窗 | 与本页「看哪条链」不是同一任务 |
| 查询两个主按钮 | 「进入全景」vs「加入对比篮」 | 一个改本页对象，一个写全局篮；无主次说明 |
| 周期分析已经页内选 | 同侧栏隔壁：Select「请选择产业或产业链」 | 全景仍禁止页内 Select（旧 DEC），两边规范相反 |
| 企业也进篮 | 环节详情「加入企业篮」 | 对象类型从产业/链跳到企业，篮 Tab 跟着跳 |

### 2.3 与周期分析的差距（本轮要对齐的）

产业周期分析配置区（已落地 `industryObjectSelect.ts`，头注释写明「不再依赖顶部对比篮模块」）：

| 字段 | 周期分析 | 全景图谱（现状） | 全景图谱（本 DEC 目标） |
| --- | --- | --- | --- |
| 分析对象 | 页内可搜索 Select，必填；空则红字「尚未选择分析对象」 | 开对比篮 / 推荐示例 / 可选 Modal | **同周期：页内 Select** |
| 所属产业链 | 只读「本分析不依赖产业链」 | 无此栏；产业按全链路直入（已拍板，保留） | **只读说明栏，不二次选子链** |
| 对比篮 | 不承担换对象 | 换对象主路径 | **不承担换对象** |

## 3. 两个概念钉死（禁止再混）

| 概念 | 是什么 | 宿主 | 禁止 |
| --- | --- | --- | --- |
| **本次分析对象** | 当前全景工作区看哪一个 `industry` 或 `industry_chain` | 全景页「本次工作上下文」Select；URL `object_type` + `object_id` | 用对比篮勾选代替；把篮容量/多 Tab/分析类型弹窗塞进换对象 |
| **对比篮** | 跨页暂存可对比实体，稍后分发到兼容分析 | 全局圆点浮层；查询/画像「加入对比篮」 | 当作本页对象选择器；空态主按钮「打开对比篮」 |

口诀：**对象在页内选；篮只收藏和分发。**

## 4. 目标交互（对齐周期分析）

### 4.1 全景页「本次工作上下文」（替换 ContextBar「打开对比篮」）

横向三栏，组件与周期分析同一套 `industryObjectSelect`（不是再造私有 Select）：

1. **分析对象**（必填）  
   - 可搜索 Select，placeholder「请选择产业或产业链」  
   - 未选：`validateStatus=error`，help「尚未选择分析对象」  
   - 单选；选产业 → 全链路直入（不改 `DEC-CHAIN-PANORAMA-INDUSTRY-FULLLINK`）  
   - 选产业链 → 该链单链全景  
   - 确认后写 URL，**不**创建 `task_id`，**不**打开篮

2. **所属产业链**（只读说明，对齐周期分析第二栏）  
   - 对象=产业：只读「按全链路展开，无需再选子链」  
   - 对象=产业链：只读锁定该链名  
   - 未选对象：只读「请先选择分析对象」  
   - **禁止**关键环节那种「再确认一条子链」步（全景已废止二次选链）

3. **数据截至**（原 ContextBar 时间，可留在第三栏或图谱工具条；不是对象选择）

空态：工作区壳 + 上述 Select 红校验；图谱区 Empty「请先选择分析对象」。  
**主 CTA 就是 Select，没有「打开对比篮」。**  
次入口可保留文字链「去产业查询」（带着 `return_context=panorama`，查完用「进入全景图谱」回填本页对象，不是先入篮）。

推荐示例：允许 Select 预填目录首条 available 产业，Tag「推荐示例」；**更换 = 改 Select**，不是开篮。用户主动清空后保持空态，不要再静默写回默认（避免「我以为没选，图却出来了」）。

### 4.2 废止的本页入口

- ContextBar / 空态主按钮「打开对比篮」「更换」开篮  
- 空态文案「请在系统对比篮中选择」  
- 页内对象 Modal（`F-PAN-01`）作为换对象主路径——周期分析已证明 Select 足够；Modal 与篮与 Select 三套并存正是跳跃源。若目录极长再议「Select 内远程搜索」，V1 不并行 Modal

### 4.3 产业查询

| 动作 | 语义 | 是否改全景对象 |
| --- | --- | --- |
| **进入全景图谱**（主路径，进工作区） | 直达 `/panorama?object_type&object_id`，`source=search` | 是 |
| **加入对比篮**（收藏，不跳页） | 写入系统篮对应 Tab；Toast「已加入对比篮」；**不**自动展开全局圆点 | 否 |
| 查看摘要 | 抽屉；脚部同样拆成「进入全景 / 加入对比篮」 | 按按钮 |

查询页不出现「先入篮再开全景」的引导句。

### 4.4 对比篮还做什么（保留，收窄）

全局圆点 **继续存在**，职责收窄为：

- 从查询 / 画像收藏产业、链、企业、机构  
- 在篮内勾选后**分发**到周期 / 关键环节 / 区域 / 深圳等分析（及可选「进入全景图谱」作为快捷深链）  
- 全景环节详情「加入企业篮」：只写 **enterprise** Tab，**不**改当前产业链分析对象，**不**切换篮到产业 Tab

从篮分发进入全景：允许（`source=compare-basket`），落地后本页对象以 URL 为准；之后换对象仍用页内 Select，不必再回篮。

全景页 **不**再调用 `open_compare_basket=1` / picker 模式回填对象。

## 5. 企业全景 / 企业分析（本轮边界）

用户同时点了「产业链 / 企业全景图谱」。拆开：

| 页面 | 对象怎么选（现状） | 本 DEC |
| --- | --- | --- |
| 专题 **产业链全景图谱** | 绑对比篮，跳跃重 | **本轮主改** |
| 门户 **重点企业全景图**（E-33） | 顶栏产业筛选，不经对比篮 | 不改；不是同一入口 |
| 企业评估 / 风险 / 领域等 | 多对象集合，对比篮作编组器有产品理由 | **不套用本 DEC**；单对象全景 ≠ 多对象评估。若企业侧也要把「本次对象」从篮拆出，另开 DEC，勿混进全景 |

全景节点「加入企业篮」保留，但是 **收藏企业**，不是选本页评估对象。
