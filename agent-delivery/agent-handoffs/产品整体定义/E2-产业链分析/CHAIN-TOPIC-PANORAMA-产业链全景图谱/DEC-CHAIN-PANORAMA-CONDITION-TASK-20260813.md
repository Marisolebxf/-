## 1. 决策

全景条件分三栏，对齐目录层级（0 级产业 / 1 级产业链），不是一条混合 Select。

| 栏 | 选什么 | 数据层级 |
| --- | --- | --- |
| 分析对象 | 只选**产业** | level 0 |
| 所属产业链 | 再选该产业下的**产业链** | level 1 |
| 数据截至 | 可选快照，控件同工作区「查看时间」 | 时间条件 |

默认条件 = 后台体检批量预跑结果，进页**秒开**图谱。  
用户改了任一条件后，出现 **【开始分析】**；任务走系统任务层并套 **分析过程壳**；完成后点「查看分析结果」刷新图谱。本页**不提供**「查看报告」「查看分析记录」。

---

## 2. 交互

1. 无 URL / 菜单直进：写入默认产业 + 其下第一条可用链 + 最新数据截至，`source=default`，直接出图。不出现「开始分析」。
2. 产业查询 / 对比篮分发带入的对象：同样秒开（视为打开已有目录对象）。
3. 改产业：第二栏只列出该产业下 1 级链；改链或改数据截至：图谱仍显示**上次已应用**结果，条件栏变脏。
4. 脏且产业+链+时间齐全 → 主按钮「开始分析」（与三个 Select 控件行对齐）。点后创建 `chain:panorama:graph` 分析任务，工作区换成 `AnalysisProcessingShell`（与诊断/深圳同构）。
5. 任务成功不自动刷图；点「查看分析结果」后应用新条件刷新图谱。本页无「查看报告」、无「查看分析记录」。
6. 对比篮仍不换对象；本页 Select 换条件。
