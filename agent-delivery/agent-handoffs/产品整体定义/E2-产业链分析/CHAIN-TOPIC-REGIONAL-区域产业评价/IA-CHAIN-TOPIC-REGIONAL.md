## 1. 模块目标与产品边界

围绕用户显式确认的 **产业 × 区域** 组合，完成：

1. 区域产业指数评价：预设指标勾选、权重配置、轻量预览、正式任务与不可变结果；
2. 区域产业竞争力评价：固定三维（企业能力 / 学术生态 / 配套环境）一级权重、正式任务与排名短板结果；
3. 本工作空间内的诊断/评价记录恢复与配置复制。

### 1.1 承接

- 二级工作空间路由 `/industry-center/regional?tab=index|competitiveness|records`；
- 对象组合合同：`1 产业 + 1～5 区域`，或 `2～5 产业 + 1 区域`；`1+1` 为单对象评价；
- 指数 Tab 的预设指标库勾选与权重（合计 100%）、不入历史的轻量预览；
- 竞争力 Tab 的固定三维与一级权重（合计 100%）、一键均分；
- 统一分析任务壳层交接（创建 → 过程 → 显式查看结果）；
- 本工作空间「分析记录」过滤与恢复。

### 1.2 不承接

- 产业链全景、产业运行诊断三项、深圳产业决策两项；
- 产业查询、门户产业总览、区域入篮（区域不是对比篮主对象类型）；
- 多产业 × 多区域笛卡尔积；
- 自定义指标的创建/删除（Bid 有要求，本轮以显式 Gap 降级，见 TRACE）；
- 正式 metric readiness D1–D4 投影（专题矩阵未建）；
- 共享对比篮 / 任务中心 / 报告阅读器内部实现；
- 技术链、企业画像复制、前端 Mock 推断权限或正式指数。

## 3. 对象与稳定身份

| 对象 | 稳定身份 | 职责 | 禁止 |
| --- | --- | --- | --- |
| `industry` | `industry_id` | 评价主对象（可 1 或 2～5） | 不静默转成 `industry_chain` |
| `region` | `region_code` + 层级版本 | 对比/承载区域（可 1 或 1～5） | 不入产业对比篮主域 |
| `evaluation_config` | 配置快照 ID | 指标、权重、对象、模型/数据版本 | 预览配置不入任务历史 |
| `analysis_task` / `result` | 共享任务/结果身份 | 过程与不可变结果 | 页面不私自造任务中心 |

### 3.1 对象进入合同

1. 无有效对象时，工作区展示对象空态，引导打开系统对比篮选择产业（区域在配置区选择）；禁止页内私有产业 Select 平行体系。
2. 两业务 Tab **共享兼容产业对象**；区域、指标、权重、模板、预览与结果焦点 **分别维护**。
3. 切换 Tab 不自动继承对方的区域/权重/预览。
