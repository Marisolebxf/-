## 决定

1. **适用范围**：仅「区域产业指数评价」Tab（`?tab=index`）的预设指标分组与结果维度文案。  
   **不改写**「区域产业竞争力评价」Bid 固定三维（企业能力 / 学术生态 / 配套环境）。
2. **原型加工词（UI 临时默认）**：页面使用四类——**商业力 / 技术力 / 学术力 / 支撑力**。  
   展示 Bid `1.1.1.2.4.2.2.3` **未写死**维度名；不得倒灌为原始需求原文。
3. **指标归属（临时默认）**：

| 原型维度 | 预设指标归属（示例口径） |
| --- | --- |
| 商业力 | 企业商业化能力、营收、融资事件 |
| 技术力 | 专利、技术成熟度、技术壁垒 |
| 学术力 | 科研机构、高校论文、人才结构 |
| 支撑力 | 服务机构、政策覆盖率、配套生态 |

4. **国标映射**：允许后台将上述原型维度 / 指标 **映射到国标（或甲方指定标准）分类**；前端展示名与后台标准码解耦。  
5. **与算法 Bid 的关系**：算法 `.3.10` 写「企业能力 / 学术生态 / 配套生态」三大核心维度——视为可映射的目标语义层，**不**在本 DEC 中把 UI 强制改回三维；最终命名与折叠规则以王慧/邵总对齐国标后的书面结论为准。  
6. **UI 标记**：确认前配置区与结果维度旁注 ⚠️「待甲方确认」（`QC11`）；评审态可展开映射说明。
