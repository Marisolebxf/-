### US-CHAIN-REG-01｜配置预览并提交区域产业指数评价

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-CHAIN-REG-01` |
| 产品角色 | `ROLE-REG-GOV` |
| `depends_on_stories` | `[US-SYS-JOBS-01, US-SYS-JOBS-02]` |
| 业务结果 | 创建绑定对象组合、预设指标和权重的指数评价任务 |
| Frames | `F-REG-02` |

作为政府科技主管部门决策人员，我想配置区域产业指数并预览后提交，以便按透明口径进行横向评价。

**主路径**：选择允许的产业×区域组合 → 勾选预设指标并调整权重至 100% → 轻量预览（不入历史）→ 最终校验通过后「生成分析」创建任务。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 多产业×多区域 | 禁止提交，不自动删对象 | 调整为允许组合 |
| 尝试添加自定义指标 | 明示本轮未开放并关联 Gap | 使用预设指标 |
| 权重≠100% | 阻止提交，定位差额；可一键均分 | 调整权重 |

| 验收 | 说明 |
| --- | --- |
| `AC-US-CHAIN-REG-01-01` | 预览不建任务；正式提交创建唯一任务 |
| `AC-US-CHAIN-REG-01-02` | 自定义指标入口不伪装已支持 |

不包含：创建/删除指标库条目；结果阅读（见 US-02）。
