### US-CHAIN-REG-01｜配置并提交区域产业指数评价

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-CHAIN-REG-01` |
| 产品角色 | `ROLE-REG-GOV` |
| `depends_on_stories` | `[US-SYS-JOBS-01, US-SYS-JOBS-02]` |
| 业务结果 | 创建绑定评价对象、模板快照（系统/个人/当次）、指标选集与权重的指数评价任务 |
| Frames | `F-REG-02` |

作为政府科技主管部门决策人员，我想基于官方模板配置区域产业指数，在配置区所见即所得地看到综合指数随权重变化，再提交正式分析，并把常用配置存成个人模板复用。

**主路径**：选择允许的产业×区域评价对象 → 选择**评估模板**（默认官方系统模板；或我的模板 / 当次配置）→ 拉取/使用指标底分快照 → 在工作集上勾选计入并调权，**配置即时汇总随调整刷新** → 按需「添加指标」追加或「移除」退出工作集 →（可选）「保存为个人模板」→ 「生成分析」创建任务。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 多产业×多区域 | 禁止提交，不自动删对象 | 调整为允许组合 |
| 拟添加指标不可用 | 禁止加入并说明原因（`GAP-CHAIN-REG-METRICS`） | 改选可用项 |
| 权重≠100%（已计入） | 阻止提交/保存个人模板；可一键均分已计入项；取消计入不自动均分；即时汇总可灰显 | 调整权重 |
| 无已计入指标 | 禁止提交与保存个人模板（工作集可仍有未计入行） | 勾选至少一项计入 |
| 底分未就绪 | 即时汇总不展示伪正式综合指数，明示缺口/Mock | 等待底分或改用可用对象 |
| 切换模板且当次有未保存改动 | 确认：应用模板 / 保留当次配置 / 取消 | 用户选择 |

| 验收 | 说明 |
| --- | --- |
| `AC-US-CHAIN-REG-01-01` | **无独立轻量预览**；配置即时汇总不建任务、不入历史；正式提交创建唯一任务；任务固化模板 ID/版本 + **已计入**指标权重快照 |
| `AC-US-CHAIN-REG-01-02` | 可配置评价对象；可调权重；可通过「添加指标」从库追加；**不**一次性铺开全库；取消计入≠移除 |
| `AC-US-CHAIN-REG-01-03` | 默认加载至少 1 个官方系统模板；模板下拉含系统模板 / 我的模板 / 当次自定义配置 |
| `AC-US-CHAIN-REG-01-04` | 「保存为个人模板」仅存名称+**已计入**指标+权重；不存未计入/评价对象/任务名；下次可在「我的模板」选用 |
| `AC-US-CHAIN-REG-01-05` | 工作集分组可见四力（⚠️ QC11）；旁注「调整默认仅对本次任务生效」直至保存个人模板 |
| `AC-US-CHAIN-REG-01-06` | Checkbox=计入；「移除」退出工作集且指标回落到添加下拉；≠删库 |
| `AC-US-CHAIN-REG-01-07` | 对象合法且底分就绪、已计入权重合计 100% 时，调整权重后配置区可见综合指数刷新（允许短防抖）；旁注区分「配置反馈 ≠ 正式分析结果」 |

不包含：运营改官方模板；运营建库/公式编辑器；独立轻量预览按钮；结果阅读（见 US-02）；竞争力 Tab 三维改写。
