## 决定

1. **禁止一次性铺开全库指标**  
   指数配置区默认只展示**当前模板已选指标**；全量指标库仅在「添加指标」选择器中按需出现。

2. **官方定义模板（系统模板）**  
   - 至少提供 1 个官方系统模板（建议名：`区域产业综合指数 V1.0`，正式命名可随 QC11/指标库闭合调整）。  
   - 首次进入指数 Tab 默认加载官方模板的指标子集 + 默认权重（合计 100%）。  
   - 模板下拉分组：**系统模板 / 我的模板 / 当次自定义配置**（与企业评估同构）。  
   - 切换模板恢复指标与权重，**不**恢复产业/区域评价对象。

3. **按需添加指标（Bid「添加自定义指标」的交互形态）**  
   - 配置区提供「添加指标」按钮 → 下拉/选择器列出**尚未在本次配置中的库内指标**（可按四力分组）。  
   - 选中后追加一行进入权重表（默认已计入），可调权。  
   - **移出工作集**用操作列「移除」，**不用**取消勾选（详见 `DEC-CHAIN-REG-INDEX-INCLUDE-VS-REMOVE-20260806`）。  
   - 数据状态「暂不可用」的库项不可加入或加入后禁用提交（走 `GAP-CHAIN-REG-METRICS`）。  
   - 仍禁止运营建库 / 无源造指标 / 删库项。

4. **保存为个人模板**  
   - 底栏提供「保存为个人模板」：保存模板名称、已选指标、权重、展示偏好。  
   - **不保存**：评价对象、任务展示名、预览结果。  
   - 个人模板仅本人可见可改；系统模板只读（OPS/L4 另轨维护，本页不提供改官方模板）。  
   - 提示文案（对齐企业评估）：「当前使用官方/默认模板时，用户调整仅对本次任务生效」；保存个人模板后可在「我的模板」复用。

5. **与竞争力 Tab**  
   本 DEC 仅约束指数 Tab（`?tab=index`）。竞争力仍用固定三维一级权重，不引入指标库添加/个人模板（除非另开 DEC）。

## 影响

- 废止「诊断同款长表一次勾选全库」的交互解释。  
- USM/IA/TRACE/Wireframe/UX-SPEC 同步模板选择器、添加指标、保存个人模板。  
- Demo 需有至少 1 个官方模板种子 + 空个人模板列表 + 添加指标选择器。
