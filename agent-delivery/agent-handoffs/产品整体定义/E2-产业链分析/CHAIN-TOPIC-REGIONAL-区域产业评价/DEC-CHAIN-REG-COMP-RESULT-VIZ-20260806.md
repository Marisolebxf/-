## 决议

1. **热力图形态 = C**：矩阵热力图（主体 × 三维+综合）**必达**；GIS 地理热力仅在 `multi-region` 且区域 ≥2 时展示。  
2. **柱状图必达**：综合竞争力指数横向排名（降序）；与矩阵/表同源。  
3. **结果阅读顺序**：KPI（写清主体）→ 柱状 → 矩阵热力 →（条件）GIS → 排名明细表 → 优势短板 → 版本边界 → 生成报告。  
4. **导出走共享「生成报告」**，本页不内嵌 PDF 引擎。  
5. **联动**：点击柱 / 矩阵行 / 表行（及 Demo-B GIS 区域）高亮同一主体。  
6. **分期**：Demo-A = 柱状+矩阵+表+报告；Demo-B = GIS；指数 Tab 不对齐全套图表（另开 DEC）。  
7. **开放项默认**：D1 GIS 默认映射=综合指数；D2 宽屏柱状/矩阵并排、≤1440 纵向；D3 Demo-A 表不排序；D4 指数 Tab 不同步。
