## 0. 一句话结论

竞争力结果从「仅表格」升级为：**KPI → 综合排名柱状图 → 三维矩阵热力图 →（多区域时）GIS 热力 → 排名明细表 → 优势短板 → 版本边界 → 生成报告**；图表与表格同源、可联动；导出走共享报告交接，不在本页自建导出引擎。

## 3. 区块交互细则

### 3.1 KPI 条

| 项 | 规则 |
| --- | --- |
| 内容 | 与指数结果一致：**必须写清主体名**；禁止裸写「领先 / 关注」 |
| 维度名 | 企业能力 / 学术生态 / 配套生态力 |
| 点击 | KPI 卡不可跳转；不打开抽屉 |
| 空态 | 无结果主体时不渲染 KPI（不应出现；有则回配置） |

### 3.2 综合竞争力排名 · 柱状图（必达）

| 项 | 规则 |
| --- | --- |
| 图表类型 | ECharts 柱状图；X=对比主体（区域名或产业名，随 `mode`）；Y=综合竞争力指数 |
| 排序 | **按综合指数降序**（与排名表一致）；第 1 名柱用主色 `#165DFF` 加粗/描边，其余中性色阶 |
| Tooltip | 主体名、综合指数、排名、三维三项分数 |
| 点击柱 | **高亮联动**：矩阵热力同行高亮 + 明细表同行选中滚动入视；再次点击取消高亮 |
| 图例 | 可不展示系列图例（单系列）；需有图标题「综合竞争力指数排名」 |
| 数据点少 | 主体 1 个时仍出柱状（单柱）+ 说明「当前仅 1 个对比主体，横向对比有限」 |
| 禁止 | 用饼图代替排名；用堆叠柱强行叠三维冒充综合（三维见矩阵） |

### 3.3 三维对比 · 矩阵热力图（必达）

| 项 | 规则 |
| --- | --- |
| 形态 | ECharts `heatmap`：**行=主体，列=企业能力 / 学术生态 / 配套生态力 / 综合指数** |
| 色阶 | 浅→深表示分值低→高；图例色条标注数值范围；色盲友好优先蓝系（对齐 Design 主色族，避免红绿对） |
| 单元格 | 中心显示数值（整数或 1 位小数，与表一致）；字号可读 |
| Hover | Tooltip：主体 · 维度 · 分值 · 该维排名（同维内） |
| 点击单元格 | 高亮该行（主体）；同步柱状与表格；**不**下钻叶子（无叶子） |
| 与表关系 | 矩阵=视觉摘要；明细表=完整核对；二者字段同源，禁止两套 Mock |
| 标题 | 「三维得分热力图」；旁注「色阶表示相对强弱，非地理分布」—避免与 GIS 混淆 |

### 3.4 GIS 区域热力（条件必达 · 选项 C）

| 项 | 规则 |
| --- | --- |
| 出现条件 | `mode === multi-region` **且** 对比区域数 ≥ 2 |
| 隐藏条件 | `multi-industry`：整块不渲染；单区域：不渲染 GIS（无横向地理对比意义），仅柱状+矩阵 |
| 技术 | Leaflet；Demo 可用简化行政区面/圆心 + 色阶填充（对标政策门户地图交互密度即可，不要求底图商用精度） |
| 映射值 | 默认上色字段=**综合竞争力指数**；控件切换：综合 / 企业能力 / 学术生态 / 配套生态力 |
| 交互 | 缩放/平移；点击区域 → 与柱状/矩阵/表同行高亮；Tooltip 同柱状 |
| 图例 | 色阶条 + 当前映射维度名 |
| 标注 | 「演示底图 · 🧪」+ 评审挂点（mock）；不宣称生产级测绘精度 |
| 禁止 | multi-industry 时用产业点硬塞进省市区地图；无坐标时伪造点位 |

### 3.5 排名明细表（必达 · 无障碍等价）

保留现有列：排名 | 主体 | 竞争力指数 | 企业能力 | 学术生态 | 配套生态力。

| 交互 | 规则 |
| --- | --- |
| 行点击 / 键盘选中 | 与图表高亮双向同步 |
| 排序 | 默认综合降序；表头允许按单列排序（可选 Demo V1.1）；排序后柱状/矩阵**同步重排行序** |
| 与图表 | 表不可删除；图表不可替代表作为唯一数据载体（D10） |

### 3.6 优势短板 / 版本边界

- 短板文案含主体 + 维度名；可引用矩阵中最低维。  
- 版本边界 Alert 仍在结果底部；跨版本禁止混排（既有 AC）。  
- 不因补图表而削弱版本边界提示。

### 3.7 生成报告（导出）

| 项 | 规则 |
| --- | --- |
| 入口 | 结果顶栏主按钮「生成报告」（对齐诊断/中心页共享报告触发） |
| 语义 | **共享报告交接**，非页内 PDF 引擎（IA 已定） |
| 报告内容（Demo 最低集） | 封面元数据（对象/模式/权重快照/时间）+ KPI + 排名表 + **柱状图截图或等价图** + **矩阵热力截图或等价图** +（若有）GIS 说明 + 优势短板 + 版本边界 |
| 失败 | 沿用共享报告错误反馈；结果页数据不丢 |

## 4. 跨组件联动状态机（结果页内）

```text
selectedSubject: string | null

用户点击柱 / 矩阵行 / 表行 / GIS 区域
  → selectedSubject = 该主体
  → 柱高亮、矩阵行高亮、表行 selected、GIS 区域描边

再次点击同一主体 或 点「清除高亮」
  → selectedSubject = null
```

- 仅视觉联动，**不**改 URL、不打开新任务。  
- 键盘：表行为主可达路径；图表点击为增强，焦点管理不抢表格 Tab 序。

## 6. 状态与异常

| 状态 | 表现 |
| --- | --- |
| `result` 正常 | 按 §2 全量或条件渲染 |
| `incomparable` | 不出排名柱/矩阵/GIS 伪对比；说明原因；可保留配置快照 |
| `partial_metric_gap` | 图表对缺失维显示「—」或灰格，Tooltip 说明未参与；不补造分 |
| 图表加载失败 | 保留明细表 + Alert「图表暂不可用，请以下表为准」 |
| GIS 底图失败 | 隐藏 GIS 块 + 一行说明；不影响 ②③⑤ |
