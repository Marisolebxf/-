## 决定

1. **拆分两层状态（指数 Tab）**  
   - **工作集**：表内可见的指标行（模板加载子集 +「添加指标」追加）。  
   - **计入**：Checkbox「计入」——是否参与本次评价与权重合计。  
   - **取消勾选 ≠ 移除**：行保留、灰显、权重冻结只读；可再勾回并恢复原权重参与合计。  
   - **移除**（操作列）：退出工作集，行消失，权重从本次配置清除；指标回到「添加指标」下拉。  
   - **≠ 删库项**（仍禁止）。

2. **权重规则**  
   - 合计 100% / 一键均分 / 提交与保存个人模板校验，**仅针对已计入集合**。  
   - 取消计入后**不自动均分**剩余项；原位提示合计偏差，用户可手调或点「一键均分」。  
   - 至少 1 项已计入方可预览 / 生成分析 / 保存个人模板。  
   - 工作集至少保留 1 行；仅剩 1 行时禁用「移除」。

3. **个人模板读写（已确认）**  
   - **保存**：仅固化「工作集 ∩ 已计入」的指标 key + 权重；未计入不进模板。  
   - **加载**官方 / 我的模板：工作集 = 模板指标，**全部默认已计入**。  
   - 不存评价对象、任务名、预览结果（沿用模板 DEC）。

4. **文案**  
   - 副标题：「工作集内指标 · 勾选表示计入本次评价」。  
   - 「移除」Tooltip：「从本次配置移除，指标仍在库中」。

5. **范围**  
   仅指数 Tab。竞争力 Tab 仍为固定三维，无工作集 / 计入拆分。

## 影响

- 废止「取消勾选 = 从本次配置删除行」的 Demo 行为。  
- USM / UX-SPEC / Demo 同步本交互；模板 DEC 的「可移除出本次配置」解释为操作列「移除」，非 Checkbox。
