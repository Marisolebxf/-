## 2. F-SYS-JOBS-01｜系统任务浮层收起态

### 2.1 线框图

```text
App Shell 任意业务页面

                                                ┌─────────────────────┐
                                                │ ◷ 系统任务  3       │
                                                │ 2 运行中 · 1 排队中 │
                                                └─────────────────────┘
```

### 2.2 位置与表现

- 默认固定在 App Shell 内容区右下角，距内容区右、下边缘各 24px。
- 不覆盖侧栏、全局导航、页面主按钮、抽屉和 Modal。
- 页面存在底部固定工具栏时，上移至工具栏上方 16px。
- 拖动位置不作为首期能力。
- 当前用户没有非终态或短暂保留任务时不显示空浮层。
- 数量只计算当前用户自己的任务。

### 2.3 字段表

| 名称 | 类型 | 来源 | 必填 | 示例 | metric_id |
| --- | --- | --- | --- | --- | --- |
| 当前用户可见任务总数 | integer | 系统任务服务 | 是 | 3 | N/A（任务运行状态） |
| 运行中数量 | integer | 系统任务服务 | 是 | 2 | N/A（任务运行状态） |
| 排队中数量 | integer | 系统任务服务 | 是 | 1 | N/A（任务运行状态） |
| 存在刚完成 / 刚失败 | boolean | 系统任务服务 | 否 | true | N/A（通知状态） |

### 2.4 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 点击浮层 | 打开 `F-SYS-JOBS-02` | 不跳离当前页面，不直接打开第一条任务 |
| 键盘聚焦后 Enter / Space | 等同点击 | 不仅依赖鼠标 |
| 新任务进入排队 / 运行 | 数量与摘要实时更新 | 不播放持续闪烁或遮挡业务内容 |
| 所有任务离开可见范围 | 浮层退出 | 不保留空壳占位 |

### 2.5 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 无可见任务 | 浮层不存在 | 继续当前业务 |
| 排队中 | 显示排队数量 | 展开查看位置或撤回 |
| 运行中 | 显示运行数量 | 展开查看阶段 |
| 刚完成 | 显示一次完成提示点 | 展开查看结果 |
| 刚失败 | 显示错误提示点，不用持续红色闪烁 | 展开查看错误 |
| 状态连接中断 | 显示“状态连接中断”弱提示 | 等待自动重连 |

### 3.2 分组与排序

- 默认展示全部，支持“分析任务 / 报告任务”本地分类切换。
- 排序优先级：运行中 → 排队中 → 刚失败 → 刚完成。
- 同状态按最近状态更新时间倒序。
- 浮层只展示当前用户任务。
- 刚完成 / 刚失败只在确认前或短暂通知周期内出现。
- 不提供完整历史分页；完整历史进入来源模块或个人资产中心。

### 3.4 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 点击运行中分析任务 | 跳到完整过程页 `F-SYS-JOBS-03` | 不只弹出简化提示卡 |
| 点击排队中分析任务 | 跳到完整过程页的排队态 | 不自动创建新任务 |
| 点击排队任务“撤回” | 二次确认后撤回并释放同类互斥 | 不对运行中任务显示撤回 |
| 点击报告任务 | 返回 `source_route` 并自动打开 `F-SYS-JOBS-04` | 不新建脱离来源页的报告过程页 |
| 点击刚完成分析 | 进入 `result_route` | 不停留在已完成过程页 |
| 点击刚完成报告 | 有权限且文件有效时下载，或打开来源页弹层 | 不绕过权限与有效期 |
| 点击“知道了” | 从浮层移除即时反馈 | 不删除来源历史或资产记录 |

| --- | --- | --- |
| 排队中 | 队列位置、提交时间 | 查看、撤回 |

| 刚完成 | 完成时间、结果 / 文件入口 | 查看、知道了 |
| 刚失败 | 失败阶段、错误编号 | 查看原因、知道了 |
| 已撤回 | 只做短暂反馈 | 知道了 |
| 管理员终止 | “因系统异常终止”+ 审计编号 | 查看说明、知道了 |
| 来源权限已失效 | 隐藏敏感摘要，显示“无权查看来源内容” | 返回 |

### 4.2 页面规则

- 与用户确认截图一致：保留系统侧栏、模块导航和当前分析类型 Tab。
- 主工作区整体切换为完整过程页，不显示新任务配置。
- 阶段由来源模块登记，系统层只承载统一状态和恢复。
- 只显示后台可证明的阶段、状态和时间，不伪造百分比。
- 排队态可撤回；进入运行后不显示普通用户取消。
- 用户进入同一 `task_type` 时恢复原任务，不创建第二个。

## 5. F-SYS-JOBS-04｜报告任务弹层

### 5.1 线框图

```text
来源业务结果页

┌──────────────────────────────────────────────────────────────────────┐
│                         报告生成任务                           [×]    │
├──────────────────────────────────────────────────────────────────────┤
│ [任务已提交 ✓]─[读取来源快照 ✓]─[权限与脱敏 ●]─[图表渲染]─[报告组装]─[文件完成] │
│                                                                      │
│ 当前阶段：权限与脱敏校验                                             │
│ 报告基于来源结果快照生成，不重新执行来源分析。                       │

├──────────────────────────────────────────────────────────────────────┤

└──────────────────────────────────────────────────────────────────────┘
```

### 5.2 规则

- 保持来源业务页面上下文，采用 Modal 展示，不创建独立报告过程页。
- 点击系统浮层中的报告任务时，先返回 `source_route`，再自动打开本弹层。
- 报告必须绑定 `source_snapshot_id`。
- 报告阶段统一为：
  1. 任务已提交；
  2. 读取来源快照；
  3. 权限与脱敏校验；
  4. 图表渲染；
  5. 报告组装；
  6. 文件生成完成。
- 禁止出现“评分计算”等重新执行来源业务计算的阶段。

### 5.3 字段表

| 名称 | 类型 | 来源 | 必填 | 示例 | metric_id |
| --- | --- | --- | --- | --- | --- |
| `report_task_id` | string | 系统任务服务 | 是 | REPORT-... | N/A（标识字段） |
| `report_type` | string | 来源模块登记 | 是 | 技术力评估报告 | N/A（分类字段） |
| `source_snapshot_id` | string | 来源模块 | 是 | EVAL-SNAPSHOT-001 | N/A（关联字段） |
| `report_fingerprint` | string | 报告服务 | 是 | sha256:... | N/A（去重字段） |
| `report_template_id` | string | 来源模块 | 是 | ENT-TECH-PDF-v1 | N/A（模板字段） |
| `format` | enum | 用户选择 / 模板 | 是 | PDF | N/A（格式字段） |
| `status` | enum | 系统任务服务 | 是 | running | N/A（任务状态） |
| 当前阶段 | string | 报告服务 | 运行中必填 | 报告组装 | N/A（任务状态） |
| 文件有效期 | datetime | 资产服务 | 完成时必填 | 2026-08-23 | N/A（资产字段） |
| 脱敏 / 审批标记 | enum | 权限服务 | 按模板 | masked | N/A（治理字段） |
| 错误编号 | string | 报告服务 | 失败时必填 | REPORT-RENDER-003 | N/A（错误字段） |

### 5.4 报告指纹规则

报告指纹至少包含：

- 来源模块；
- `source_snapshot_id`；
- 报告类型；
- 报告模板 ID 与版本；
- 文件格式；
- 当前用户权限视角；
- 字段分级与脱敏规则；
- 报告内容版本。

| 当前事实 | 系统行为 |
| --- | --- |
| 同指纹排队或运行 | 恢复原报告任务 |
| 同指纹有效文件存在 | 直接下载 |
| 原任务失败 | 创建新任务并关联原失败任务 |
| 文件过期 | 基于仍有效来源快照创建新任务 |
| 来源快照变化 | 生成新指纹和新报告，不覆盖旧文件 |

### 5.5 交互与禁止行为

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 点击关闭 / 后台继续 | 关闭 Modal，任务继续并进入浮层 | 不取消任务 |
| 重复点击生成 | 先查指纹，复用或直接下载 | 不盲目创建重复任务 |
| 点击完成报告 | 权限与有效期通过后下载 | 不下载其他快照文件 |
| 来源权限失效 | 中止下载并说明 | 不因任务曾由本人创建就绕过权限 |
| 报告失败后重试 | 新建报告任务并保留原失败事实 | 不覆盖错误记录 |

### 5.6 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 排队中 | 队列位置 | 后台继续 |
| 生成中 | 当前阶段、已用时间 | 后台继续 |
| 已完成 | 文件名、格式、有效期、脱敏标记 | 下载 / 去个人资产 |
| 失败 | 失败阶段、错误编号 | 重新生成 / 联系管理员 |
| 无权限 | 不创建或停止下载 | 返回 / 申请权限 |
| 来源快照无效 | 禁止生成 | 回来源页刷新结果 |
| 管理员终止 | 审计编号 | 联系管理员 |

## 10. 权限与隐私

- 本节同时承接 `US-SYS-JOBS-07` 的普通用户与管理员权限边界。
- 所有查询以当前登录 `user_id` 为个人任务过滤条件。
- 系统浮层不显示其他用户的任务或占用详情。
- 来源模块权限在任务创建、任务恢复、结果查看和报告下载时分别复核。
- 浮层摘要不得包含未经授权的企业名称、敏感对象或报告字段。
- 用户失去来源权限后，仍可看到最小任务状态，但不能查看敏感摘要、结果或文件。
- 管理员技术监控与普通业务浮层完全分离。

## 11. 响应式与视觉约束

- **屏幕层级**：`medium_1440_1920`，仅科技专题服务系统中屏。
- **设计系统**：`Design.md` 浅蓝白、Arco 组件与当前 App Shell。
- **推荐组件**：
  - 收起态：`Badge` + `Button` / 可访问自定义容器；
  - 展开态：`Drawer` 或定位浮层；
  - 任务状态：`Tag`；
  - 分析过程：`Steps`；
  - 报告过程：`Modal` + `Steps`；
  - 错误反馈：`Alert`；
  - 确认撤回：`Modal.confirm`。
- **尺寸原则**：展开浮层宽度建议 400–440px；不得遮挡主导航和来源页面关键操作。
- **小屏**：不在本包声明 `small_reflow`，不得从中屏规则推导移动端交付。
- **大屏**：不适用；Track-L 不继承本浮层。
- 状态颜色遵循语义色，不以持续动画表达运行中。
- 键盘可达、焦点回收、Esc 关闭和屏幕阅读器状态播报按通用 UE 规范执行。
