## 模块：系统分析与报告任务

本模块为科技专题服务系统中的长耗时分析和报告生成提供统一任务体验。它不定义业务算法和报告内容，只负责当前用户任务的提交约束、排队、进度、系统浮层、跨页面恢复、失败重试、报告文件生成与资产留痕。

本模块没有直接 Bid 叶子。Bid 中的各业务分析和报告能力仍由来源模块承接；系统任务浮层与统一队列属于用户批准的现有叶子内工作流增强。

## 2. 用户故事

### US-SYS-JOBS-01｜提交不同类型的长耗时分析

作为政府科技管理、产业决策或研究人员，我想在一个分析类型已经运行时继续提交其他不同类型的分析，以便并行推进多个研判，而不会重复启动同一种任务。

- 分析任务必须登记稳定 `task_type`。
- 当前用户同一 `task_type` 的排队中和运行中任务共同占用唯一名额。
- 不同 `task_type` 可以分别提交。
- 其他用户的同类任务不形成业务互斥。
- 重点企业领域分布等同步查询、统计聚合和确定性映射不创建分析任务。

### US-SYS-JOBS-02｜在系统容量内排队

作为分析发起人，我想在系统执行槽满载时让任务自动排队，以便无需反复提交，同时知道任务仍被系统接收。

- 分析队列有最大长度，队列满载后才拒绝。
- 排队显示位置，不承诺预计等待时间。
- 页面不说明谁占用了资源。
- 排队任务允许发起人撤回。
- 运行中任务不提供普通用户取消。

### US-SYS-JOBS-03｜从系统浮层查看自己的任务

作为当前登录用户，我想在系统任意页面看到自己的长耗时任务，以便切换模块后仍能掌握进度并快速返回来源位置。

- App Shell 显示系统任务浮层。
- 浮层只展示当前用户自己的任务。
- 收起态显示非终态任务总数。
- 展开态区分分析任务与报告任务，并展示排队中、运行中、刚完成和刚失败。
- 点击分析任务返回完整过程页；点击报告任务返回来源业务页并打开报告任务弹层。
- 浮层不长期保存全部历史。

### US-SYS-JOBS-04｜恢复完整分析过程

作为分析发起人，我想在切换页面、刷新、关闭浏览器或重新登录后恢复原任务的完整过程页，以便看到真实进度，而不是重新提交或只看到一张提示卡。

- 来源模块保留系统侧栏、模块导航和当前分析类型 Tab。
- 主工作区完整展示任务摘要、状态、真实阶段、当前阶段和已用时间。
- 不显示新任务配置表单。
- 不显示无法由后台证明的百分比。
- 多页面、标签页和设备读取同一服务端任务状态。

### US-SYS-JOBS-05｜处理成功、失败和重试

作为分析发起人，我想在任务结束后得到明确结果或错误反馈，以便继续查看结果，或在不覆盖失败事实的前提下重试。

- 成功后开放来源结果页。
- 失败保留失败阶段、错误编号和原配置摘要，并释放执行槽与互斥键。
- 重试创建新 `task_id`，通过 `retry_from_task_id` 关联原失败任务。
- 刚完成或刚失败在浮层保留到用户确认，或短暂通知周期结束。
- 完整历史进入来源模块或个人资产中心。

### US-SYS-JOBS-06｜从任一业务模块创建报告

作为拥有报告权限的分析或研究人员，我想让所有业务模块的报告创建使用同一后台任务机制，以便关闭弹层后继续生成，并从系统浮层恢复。

- 所有真正创建报告文件的位置接入 `report_generation`。
- 下载现成有效文件、查看在线结果或普通查询不创建报告任务。
- 报告绑定来源结果或查询上下文的不可变快照。
- 报告指纹相同且任务处理中时复用原任务；有效成品直接下载。
- 仅失败、过期或来源快照变化时创建新任务。
- 报告读取来源快照、执行权限与脱敏校验、渲染图表、组装报告并生成文件。
- 报告阶段禁止重新执行来源分析、评分、排名或结论生成。
- 完成文件进入个人资产中心并保留下载记录。

### US-SYS-JOBS-07｜管理员异常终止

作为系统运行维护人员，我想在任务故障或资源异常时强制终止任务，以便恢复系统容量，同时保留完整审计事实。

- 普通用户不能取消运行中任务。
- 管理员终止不出现在普通业务浮层的操作菜单。
- 每次终止必须记录操作者、原因、时间和审计编号。
- 终止任务释放执行槽与互斥键，但不能标为成功。

### US-SYS-JOBS-08｜在创建分析任务前校验日权益（待批准）

作为有权发起评估的业务用户，我想在进入无效配置或创建任务前知道当天对应评估类别是否仍有额度，以便在超限时理解原因并联系开通，而不是提交任务后才被拒绝。

- 本 Story 为 `product_enhancement`，待项目负责人和合规 PM 补充正式 `approved_scope_change` 后激活。
- 认证身份、专业用户类型和付费套餐分别维护，由共享权益服务计算 `entitlement_tier`；任务层和前端不按 GOV / INNO / THINK 等 persona 推导。
- 技术、商业、综合分别映射 `technology / business / comprehensive`，按北京时间自然日独立计数。
- 上游“下一步”或来源模块最终生成动作先做体验预检；任务创建接口再次校验。
- 服务端成功创建 `task_id` 时原子扣减；仅点击、预检失败或创建事务失败不扣减。
- 平台故障、算法系统错误、排队阶段用户撤回时幂等返还；正常完成和有效“数据不足”结果不返还。
- 权益服务不可用或配置无效时失败关闭，不临时放行。
- 具体等级、日额度和价格不在本四件套硬编码；生产开关默认关闭。

## 3. 主路径 walkthrough

### 3.1 分析任务主路径

1. 用户进入已接入的业务分析类型并完成配置。
2. 用户点击生成或开始分析。
3. 来源模块完成权限、参数和数据预检。
4. 限额开关开启时，来源模块按分析分类调用体验预检；超限时不创建任务，展示来源模块的简单弹窗。
5. 系统检查当前用户同一 `task_type` 是否已有排队或运行任务。
6. 若已有，系统不创建新任务，直接恢复原任务完整过程页。
7. 若无，创建接口再次校验日权益，并原子完成任务创建与额度扣减。
8. 系统创建任务快照并检查分析执行槽。
9. 有空闲槽时进入运行；无空闲槽但队列未满时进入排队。
10. 用户看到完整过程页，可离开当前页面。
11. 系统浮层在其他页面继续展示该任务。
12. 用户点击浮层或重新进入该分析类型，恢复同一 `task_id`。
13. 成功后进入来源结果；失败后显示错误，并按原因决定是否返还额度及允许基于原配置创建新任务。

### 3.2 报告任务主路径

1. 用户在来源结果页或其他具备报告能力的业务页面点击生成报告。
2. 系统冻结来源快照并校验报告权限、模板、格式和脱敏要求。
3. 系统生成 `report_fingerprint`。
4. 若同指纹报告仍在处理，恢复原报告任务弹层。
5. 若同指纹报告已完成且仍有效，直接下载现有文件。
6. 若原任务失败、文件过期或来源快照变化，创建新报告任务。
7. 报告进入独立报告队列；弹层可关闭，任务后台继续。
8. 用户在其他页面从系统浮层看到报告任务。
9. 点击报告任务返回其 `source_route`，并自动打开报告任务弹层。
10. 完成后允许下载，并在个人资产中心保存文件和记录。

### 3.3 跨页面与重新登录恢复

1. 用户离开正在显示的分析过程页或报告任务弹层。
2. 服务端任务继续运行，前端本地状态不作为任务事实。
3. 用户切换标签页或设备时，系统读取当前登录用户的任务列表。
4. 用户退出后重新登录，系统重新查询非终态和短暂保留的终态任务。
5. 浮层恢复；点击后回到原任务对应页面和状态。

## 4. 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 同类分析已经排队或运行 | 不创建第二个任务，恢复原任务完整过程页 | 查看原任务 |
| 分析执行槽已满 | 任务进入有界队列，显示队列位置 | 等待或撤回 |
| 队列也已满 | 不创建任务，保留配置并提示系统繁忙 | 稍后重新提交 |
| 网络断开 | 页面标记连接已断开，不把任务判为失败 | 重连后从服务端恢复 |
| 页面刷新或退出登录 | 不取消任务，不从本地伪造状态 | 登录后恢复 |
| 分析失败 | 显示失败阶段、错误编号和配置摘要 | 基于原配置新建任务 |
| 管理员异常终止 | 显示“任务因系统异常终止”及审计编号，不显示成功结果 | 联系管理员或重新提交 |
| 报告处理中重复点击 | 恢复同一报告任务 | 查看进度 |
| 报告已有有效成品 | 不创建新任务 | 直接下载 |
| 报告文件过期 | 明确提示过期，基于当前有效来源快照新建 | 重新生成 |
| 来源快照已变化 | 旧报告仍关联旧快照；新报告使用新指纹 | 确认生成新版 |
| 无报告权限 | 不创建报告任务，不泄露模板或敏感字段 | 返回或申请权限 |
| 来源结果无效或未完成 | 禁止创建报告 | 先完成来源分析 |
| 实时同步暂不可用 | 降级为服务端轮询，不回退到前端本地真源 | 等待刷新 |
| 当日分类额度已用完 | 不创建任务；来源模块展示类别、已用/总额、重置时间和联系开通 | 联系开通或关闭后保留配置 |
| 权益服务不可用 / 配置无效 | 失败关闭并返回稳定错误编号，不读取前端缓存放行 | 稍后重试 |
| 预检通过后被其他端抢占最后额度 | 最终创建校验拒绝，保持配置并展示同一超限反馈 | 联系开通或次日重试 |
| 平台故障 / 算法系统错误 | 保留失败事实并幂等返还原扣减流水 | 按原配置重新发起 |
| 排队阶段用户撤回 | 进入 withdrawn，释放互斥并幂等返还 | 返回配置 |

| `SYS-JOBS-USM-08` | Given 当前用户存在非终态任务，When 在任意业务页面查看系统 Shell，Then 浮层显示自己的任务数量和摘要。 |
| `SYS-JOBS-USM-09` | Given 系统内存在其他用户任务，When 当前用户展开浮层，Then 不出现其他用户的任务、对象、身份或占用详情。 |
| `SYS-JOBS-USM-10` | Given 用户点击浮层中的分析任务，Then 返回来源模块并展示完整过程页，而不是简化提示卡或配置页。 |
| `SYS-JOBS-USM-11` | Given 用户刷新、关闭浏览器或重新登录，When 任务仍非终态，Then 恢复相同 `task_id`、阶段和已用时间。 |
| `SYS-JOBS-USM-12` | Given 任务失败，When 用户点击重试，Then 创建新 `task_id`，原失败记录不被覆盖并存在 `retry_from_task_id`。 |
| `SYS-JOBS-USM-13` | Given 任一业务模块创建报告文件，When 权限和来源快照有效，Then 创建或复用统一报告任务并进入报告队列。 |
| `SYS-JOBS-USM-14` | Given 同报告指纹仍在处理，When 再次点击生成，Then 恢复原任务而不是创建重复任务。 |
| `SYS-JOBS-USM-15` | Given 同报告指纹已有有效文件，When 再次点击生成，Then 直接下载而不创建任务。 |
| `SYS-JOBS-USM-16` | Given 报告任务在浮层中，When 用户点击，Then 返回其来源业务页并自动打开报告任务弹层。 |
| `SYS-JOBS-USM-17` | Given 报告生成中，When 执行各阶段，Then 只读取来源快照并生成文件，不重新评分、排名或改写来源结果。 |
| `SYS-JOBS-USM-18` | Given 报告成功，When 用户查看个人资产中心，Then 能看到文件、来源结果链接、有效期和下载记录。 |
| `SYS-JOBS-USM-19` | Given 管理员因系统故障终止运行任务，Then 释放槽位和互斥，记录操作者、原因、时间和审计编号，任务不得显示成功。 |
| `SYS-JOBS-USM-20` | Given 刚完成或刚失败任务，When 用户确认或短暂通知周期结束，Then 从浮层移除，完整记录仍保留在来源模块或资产中心。 |
| `SYS-JOBS-USM-21` | Given 用户进入重点企业领域分布分析，When执行查询和映射，Then 不创建长耗时分析任务、不占分析槽、不进入系统浮层。 |
| `SYS-JOBS-USM-22` | Given 页面显示任务阶段、已用时间和队列位置，Then 这些字段标识为任务运行状态而非业务 metric，不创建伪 metric_id。 |
| `SYS-JOBS-USM-23` | Given 限额开关开启且用户仍有技术类额度，When 创建技术力任务成功，Then `task_id` 创建与 `technology` 额度扣减原子完成，商业类和综合类额度不变。 |
| `SYS-JOBS-USM-24` | Given 用户技术类额度已用完，When 在来源模块点击下一步或生成，Then 不创建任务，并返回技术类已用/总额与 `reset_at`。 |
| `SYS-JOBS-USM-25` | Given 体验预检曾通过但另一设备先消耗最后额度，When 最终创建，Then 服务端再次校验并拒绝，不发生超发。 |
| `SYS-JOBS-USM-26` | Given 权益服务不可用或额度配置无效，When 用户创建分析任务，Then 失败关闭并返回可重试错误，不使用前端缓存临时放行。 |
| `SYS-JOBS-USM-27` | Given 任务因平台故障、算法系统错误或排队撤回终止，When 触发返还，Then 按原扣减流水幂等返还并保留审计；重复事件不重复增加额度。 |
| `SYS-JOBS-USM-28` | Given 任务正常完成或返回有效“数据不足”结果，When 进入终态，Then 不返还额度。 |
| `SYS-JOBS-USM-29` | Given 生产未确认具体等级、额度和价格，When 部署本能力，Then 限额开关默认关闭且不创建虚假支付路径。 |

## 6. 与 Bid 的差异说明

| 原始能力 / 章节 | 当前 IA / 页面归位 | 是否影响范围 | TRACE 动作 |
| --- | --- | --- | --- |

## 7. USM 自检
