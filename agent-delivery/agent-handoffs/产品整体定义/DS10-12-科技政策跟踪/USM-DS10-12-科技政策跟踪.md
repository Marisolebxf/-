## 模块：DS10-12 科技政策跟踪

面向展示系统多场景（决策 / 创新 / 智库 / 接待）与三屏形态，集中展示多源科创政策并完成动向跟踪、舆情评估、重点比对、效能评价可视化、效果预估与科技政策推演；承接核增「政策对比功能升级」四叶子（数据治理 / 智能拆解 / 多维对比 / 智能研报），形成「检索—治理—拆解—对比—评价—推演—研报」展示侧全流程。

**承接**：DS-10 科创政策全景、DS-11 政策分析评价、DS-12 政策效果推演；核增 DS-PC-01~04（对应 bid `1.1.1.1.4.2.4.1~4`，子功能台账 PC-01~17）。三屏双轨：Track-L 大屏 + Track-MS 中/小屏。  
**不承接**：科技专题服务系统 `/policy/*`（E7 政策分析：查询工作台、系统对比篮政策 Tab、系统任务浮层三项分析）；智慧服务门户 `/policy-portal/*`；算法/ETL 后台实现细节（仅定义展示消费契约）；Java 内嵌 NLP。

## 用户故事（As / Want / So that）

### US-DS-POL-01 多维检索并浏览科创政策全景

作为政府用户、高校科研机构和企业、智库用户或政策受众，我想按类别/领域/部门/地区等维度检索地方、国家、海外科创及相关政策，并看到全景可视化与结果排序/筛选，以便快速定位决策或申报所需政策。

### US-DS-POL-02 跟踪政策动向并管理订阅

作为政府用户或智库用户，我想查看权威来源更新、重点领域分析与动态可视化，并按主题订阅推送，以便持续把握科创政策趋势。

### US-DS-POL-03 完成政策舆情侧查询对比与受众匹配

作为施政者，我想查询对比多地域政策并查看区域差异与效果跟踪/评估报告；作为政策受众，我想获得与自身登记信息匹配的政策推送，以便分别支撑施策优化与政策利用率。

### US-DS-POL-04 完成政策重点比对与标杆对标报告

作为政府用户或智库用户，我想进行新旧/详情/部门政策对比与标杆比对，一键生成并对标结果可视化与导出，以便借鉴领先城市做法。

### US-DS-POL-05 阅读政策分析评价三类报告可视化

作为政府用户或智库用户，我想在中屏查看分析报告可视化、结果解读多维展示与推荐方案交互（含多方案对比与参数模拟），以便从效能视角优化政策。

### US-DS-POL-06 完成效果预估与科技政策推演解读

作为政府用户（决策场景），我想输入或选择政策参数进行效果预估模拟，并查看文本智能解析、影响范围、关联分析与解读报告，以便预判政策影响后再施策。

### US-DS-POL-07 核增：治理底座可视化与可信溯源入口

作为政府用户或数据维护相关授权用户，我想在展示侧查看政策源清洗质量、结构化库状态、溯源索引与规划指标库入口状态，以便确认后续对比/研报所依赖底座可用（后台流水线本身不在本 USM 实现）。

### US-DS-POL-08 核增：智能拆解结果结构化呈现

作为政府用户或智库用户，我想查看政策语义理解结果、条款分层、关键指标提取与实体关联网络，以便把非结构化文本变成可对比对象。

### US-DS-POL-09 核增：交互式多维政策对比

作为政府用户或智库用户，我想自定义对比对象与维度，完成跨政策交叉对比并获得表格/雷达/图谱可视化与智能摘要导出，以便识别共性、差异、互补与冲突。

### US-DS-POL-10 核增：智能研报生成、溯源与导出

作为政府用户或智库用户，我想在对比/深度分析后生成模块化研报，双向溯源到原文与权威源，并导出 PDF/Word，以便存档报送且结论可复核。

### US-DS-POL-11 三屏双轨下的差异化消费

作为访问人员，我想在大屏只读浏览政策全景与亮点叙事；作为业务用户，我想在中屏完成完整交互、在小屏完成裁剪后的检索列表/关键图/报告阅读，以便同一叶子在不同屏幕完成不同深度任务而不混用视觉规范。

## 场景 walkthrough（主路径 + 异常路径）

### 主路径 A · 科创政策全景（DS-10 · Track-MS 中屏）

1. 从展示系统菜单进入「科技政策跟踪 → 科创政策全景」`/display/policy/panorama`（默认中屏）。
2. 看到多维筛选条 + 全景可视化（类别/领域/部门/地区）+ 结果列表。
3. 设置维度或高级条件（效力级别、状态、布尔组合）执行检索；结果可排序、二次筛选、分组。
4. 查看动向时间轴/热力；可选订阅；进入舆情对比或重点比对 Tab。
5. 选多项政策进入详情对比或标杆比对，生成对标报告并导出。
6. （可选）携带对象上下文进入核增多维对比 `/display/policy/compare` 或专题系统（明确外链提示，不共用路由）。

### 主路径 B · 政策分析评价（DS-11）

1. 进入 `/display/policy/evaluation`。
2. 选择分析报告 / 解读报告 / 推荐方案三个呈现区。
3. 组合时间·空间·类别维度查看趋势、分区对比、结构关联；解读看板点选主题；推荐方案可调参模拟。
4. 导出/归档报告模板产物。

### 主路径 C · 政策效果推演（DS-12）

1. 进入 `/display/policy/simulation`。
2. 在效果预估区输入未出台/新出台政策参数或选择区域，查看仿真结果多维评估。
3. 在科技政策推演区打开文本解析、重点可视化、影响范围、关联网络、实施路径与解读报告。
4. 授权用户可参与利益攸关方反馈；无权限用户仅只读结果。

### 主路径 D · 核增对比研报（DS-PC-03/04）

1. 从全景或拆解页选择 ≥2 份政策 → `/display/policy/compare`。
2. 配置维度与筛选 → 交叉对比可视化 → 智能摘要。
3. 「生成研报」→ `/display/policy/insight-report` 阅读、溯源、导出。

### 主路径 E · 大屏接待（Track-L）

1. 讲解员/访问人员进入大屏路由 `/display-large/policy/panorama`。
2. 自动或讲解控制播放政策热点、地域分布与亮点卡片；无检索表单深交互、无推演参数编辑。
3. 不下钻敏感受众反馈明细。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 数据不足 / 无命中 | 稳定空态 + 调整条件 CTA；🧪 MockBadge（Wave0） | 放宽筛选或查看动向默认窗 |
| 加载失败 | 错误条 + 重试；不伪造成功图 | 重试 / 返回全景 |
| 无权限（推演参数 / 敏感下钻） | 锁态或只读结果；提示申请 | 申请权限 / 仅浏览 |
| 核增底座未就绪 | 对比/研报入口禁用 + 治理状态说明 | 查看 DS-PC-01 状态或等待接入 |
| 口径待确认指标 | 数字旁 ⚠️「待甲方确认」+ ⓘ MetricSpecCard | 继续演示，不移除角标 |
| 误入专题 `/policy/*` | 边界说明条：不同系统不同入口 | 回 `/display/policy/*` |
