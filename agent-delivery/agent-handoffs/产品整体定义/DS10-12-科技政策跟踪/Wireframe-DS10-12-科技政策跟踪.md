### 2.1 线框图

```text
┌─ 科创政策全景 /display/policy/panorama ─────────────────────────────┐
│ 标题 · 数据批次 🧪 · [内部评审层由全局开关控制]                        │
│ [检索全景] [政策动向] [舆情评估] [重点比对]                            │
├─ 筛选条 ────────────────────────────────────────────────────────────┤
│ 类别 │ 领域 │ 部门 │ 地区 │ 效力 │ 状态 │ 关键词 │ [高级] [查询]     │
├─ 主区 ──────────────────────────────────────────────────────────────┤
│ 左：全景图（类别/地图/部门切换）  右：结果列表/卡片                     │
│ 政策卡：标题 · 层级 · 地区 · 效力 · ⓘ指标 · [对比] [详情]             │
├─ 次级（按 Tab）─────────────────────────────────────────────────────┤
│ 动向：时间轴/热力 │ 舆情：区域差异/效果/匹配推送 │ 比对：双栏/标杆向导 │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 政策总量 KPI | 把握库规模 | `M_POLICY_TOTAL_COUNT` | 最新批次；筛选后重算 |
| 层级分布 | 看国家/省/市结构 | `M_POLICY_LEVEL_DIST` | 环图；点击反筛列表 |
| 类型分布 | 看政策类型结构 | `M_POLICY_TYPE_DIST` | ⚠️ QPOL-01；带待确认角标 |
| 全国/深圳分布 | 地域感知 | `M_POLICY_NATIONAL_DIST` / `M_POLICY_SZ_DIST` | 地图下钻到列表 |
| 发布时序 | 动向趋势 | `M_POLICY_TIMESERIES` | 动向 Tab 默认年粒度 |
| 力度/支持强度 | 比对与标杆 | `M_POLICY_INTENSITY_SCORE` / `M_POLICY_SUPPORT_STRENGTH` | ⚠️ QPOL-02 |
| 落地成效/适配 | 舆情评估 | `M_POLICY_IMPLEMENTATION_EFFECT` / `M_POLICY_INDUSTRY_FIT` | ⚠️；Mock 可 |
| 检索历史/收藏 | 复用条件 | `search_history_id` / `favorite_policy_id` | 本地或账户级；不与专题共用 key |
| 对比勾选 | 进入比对 | `policy_id[]` | 上限 **5**（`DEC-DS10-SEARCH-REUSE-20260808`）；页内勾选非对比篮；满则提示 |

### 2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 查询 | 刷新图+列表；写入历史 | 跳转专题 `/policy/search` |
| 加入对比（页内） | 进入重点比对 Tab 或核增对比 | 写入 E7 系统对比篮 |
| 标杆一键报告 | 打开报告预览抽屉 | 无对象时生成空报告 |
| 导出/分享 | 下载列表或链接 | 导出未脱敏敏感字段（接待角色） |

### 2.4 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 全量或推荐窗 + 图 | 筛选/点卡 |
| 加载 | 骨架 | 等待 |
| 空数据 | 空态文案 | 放宽条件 |
| 错误 / 无权限 | 错误条 / 锁态 | 重试 / 申请 |

### 2.5 内部评审模式（本页特有）

开启后显示：requirement_trace（DS-10 子锚点）、MockBadge、MetricSpecCard、与 E7 分轨说明条。无额外页面内开关。
