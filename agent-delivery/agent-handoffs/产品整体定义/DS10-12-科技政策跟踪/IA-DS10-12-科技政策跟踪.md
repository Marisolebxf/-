## 1. 模块边界

- **解决的问题**：在展示系统三屏双轨下，完成科创政策全景感知、效能评价展示、效果推演呈现，以及核增智能对比与可溯源研报。
- **承接内容**：
  - DS-10 科创政策全景（多维检索、动向、舆情评估、重点比对）
  - DS-11 政策分析评价（分析/解读/推荐方案报告可视化）
  - DS-12 政策效果推演（效果预估 + 科技政策推演）
  - DS-PC-01~04 核增四叶子（治理看板、拆解、多维对比、智能研报）
- **不承接内容**：
  - 专题 E7 `/policy/*`（查询工作台、系统对比篮政策 Tab、系统任务浮层三项分析）
  - 门户 `/policy-portal/*`
  - ODS/ETL/大模型流水线本体（展示只消费状态与结果）
  - 前端直连 Python / Nebula（须 Java REST）

## 2. 用户入口与产品角色

| 产品角色 | 入口 | 核心目标 |
| --- | --- | --- |
| 政府用户 / 施政者 | 展示菜单「科技政策跟踪」；默认全景中屏 | 全景→评价→推演→对比研报 |
| 高校、科研机构和企业 / 政策受众 | 同上；匹配/推送入口在全景舆情 Tab | 找适用政策、比对条件 |

| 访问人员 | Track-L 大屏全景/评价亮点 | 只读接待演示 |

> 角色依据见 USM；权限 persona 映射待 Q030。

### 3.1 对象流

```text
全景检索/动向
  →（可选）拆解页结构化
  → 重点比对（DS-10）或 核增多维对比（DS-PC-03）
  → 评价页效能视图（DS-11）/ 推演页（DS-12）
  → 智能研报（DS-PC-04）+ 溯源回原文
```

外链到专题 E7 时须显示「进入专题分析工作台（另一系统）」确认条，**禁止**复用 `/policy` 路由或 storage key。

### 3.2 DS-10 重点比对 vs DS-PC-03 多维对比

| 维度 | DS-10 `#benchmark` | DS-PC-03 `/compare` |
| --- | --- | --- |
| 需求锚点 | `4.2.1.4` 新旧/详情/部门/标杆 | `4.2.4.3` 交叉对比+智能摘要 |
| 典型输入 | 版本对、部门集、标杆城市字段 | 拆解后的标准化条款/指标集 |
| 智能链路 | 对标报告生成 | 指令式配置→共性冲突识别→摘要 |
| 关系 | 并存；可从标杆「升级对比」跳核增页 | 不替代舆情评估工具 |
