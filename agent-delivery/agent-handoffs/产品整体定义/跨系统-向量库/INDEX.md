## 一句话

**一张产业锚点向量（受控词表 = 图上 chain/segment），展示与专题共用；只召回候选名，定码仍走图谱 VID + FETCH。** **建库挂在产业链灌数末段**（图点 VID 稳定后 rebuild）；政策/企业等业务灌数只消费检索，不负责建库。物理引擎复用现网 **Milvus 2.4 standalone**（`192.168.88.48:19530`）；**禁止**写入存量 `amcpdp-*`。Java 不跑向量算法；前端不直连向量库。

## 纪律封面

- 词表真源 = `dwd_industry_chain_info` + Nebula `chain`/`segment`（及已发布切面约定的产业点），禁止每页私有产业 embedding。
- **建库切面 = 产业链灌数**：GDF→DWD 链表→上图成功、VID 稳定后，**同管线末段**（或紧随其后的独立步）`embed/rebuild`。禁止灌每一条链时当场 embed。
- **消费切面 ≠ 建库**：政策 / 企业 **重灌同步链**默认不 rebuild、不调 Milvus、不调 LLM。语义抽槽 / L2 走 **独立入口**：按钮 **或** ETL 长任务跑批（02 §3.1），禁止塞进重灌同步 HTTP。
- 向量分数 **不得** 直接写成 `industry_link_code` / `chain:INB*`。
- L2 LLM **不进** 政策 ODS→DWD「重灌」默认同步链。
- `theme`（政策主题标签）不进产业槽；只进 DWD `ext5`。
- D12：lumen 不回落 `demo-*`；算法只在 Python `/internal/*`。

## 明确不做

- 各 DS 叶 USM / Wireframe（产品五件套另叶）
- 把 PigX/智能体「文档知识库」扩成产业本体
- 把产业锚点写入或查询 **`amcpdp-*`**（多模态帧向量，维度/模型均不同）
- 政策/企业「重灌」同步 rebuild 或打全文 embedding
- 产业链映射过程中逐条 embed（必须等点稳定后一次 rebuild）
- LLM 或检索结果伪造图 VID
- Java / 前端直连 Milvus（仅 Python `/internal` 连 `19530`）
- 为产业对齐再采购第二套向量云（先用现网实例；隔离不够再开 VEC-Q1b）
