## 1. 锚点记录（索引侧）

每条可检索文档对应图上一个产业点（可含别名行，同 `vid`）。

| 字段 | 说明 |
| --- | --- |
| `vid` | `chain:…` / `segment:…`（与 hang FETCH 一致） |
| `kind` | `chain` \| `segment` |
| `name` | 官方名 |
| `aliases` | 拆词（与/和/、）、父链名、配置同义词 |
| `text` | 送入 embed 的拼接串（name + aliases + parent） |
| `industry_code` | 可选 INB 短码，供 LIKE 兼容 |
| `model_version` | embedding 模型 |
| `index_version` | 重建批次 |
| `graph_source` | `nebula` \| `dwd_chain` \| `cut` |

**禁止**把政策 `theme`、随机关键词当作锚点文档。

## 2. 检索请求 / 响应（草稿）

请求：

```json
{
  "query": "日均产量超15亿块……集成电路产量增长",
  "top_k": 8,
  "kinds": ["chain", "segment"],
  "min_score": 0.0
}
```

响应：

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "vid": "chain:INB1303",
        "name": "集成电路",
        "kind": "chain",
        "score": 0.81
      }
    ],
    "source": "industry_embed",
    "model_version": "tbd",
    "index_version": "tbd",
    "degraded": false
  }
}
```

`degraded=true`：引擎不可用，调用方走 L1 字面匹配。  
引擎未部署：Java/Python 约定 **501** 或 `code≠0` + honesty，禁止用固定 `chain:INB1303` 凑 200。

## 3. 定码规则（与上图同源）

实现应复用 `polan.graph.entity.match_industry_anchors` / hang `_stable_codes` + `fetch_vid`，而不是另写一套 VID 生成器。

```text
候选名来自 L1 字面 或 embed top-k 或 L2 JSON
        ↓
match_industry_anchors(text 或 name, anchors)
        ↓
industry_link_code 仅当锚点 vid 命中
        ↓
写 DWD related_entities.industry
        ↓
上图 C：FETCH 失败 → skipped.no_stable_id
```

LLM 输出若含 `chain:` 前缀：**丢弃该码**，只信图锚点表。

## 5. 重建与运行

**建库只跟产业链走**（与 02 §1.1 一致）。

| 触发 | 动作 |
| --- | --- |
| 产业链灌数：DWD 链表 + 上图 VID 已稳定 | 管线 **末段** 调 `embed/rebuild`（整库一次，非逐行） |
| 挂链补点 / 发布切面批量变更 | 同上 API rebuild |
| 点尚未 FETCH 成功 / 灌链失败 | **不** rebuild；保留上一版 index_version |
| 政策 / 企业等业务重灌或追加 | **不** rebuild；**同步不** search / LLM |
| 语义抽槽按钮 | 可选 `embed/search` → 写槽；可 dry_run |
| **ETL Job A** `industry_embed_enrich` | 重灌**之后**跑批 search→对码；增量默认、全量审批；不 rebuild |
| **ETL Job B** `industry_llm_extract` | 默认关；显式打开；宜约束在 A 的 top-k；失败回退 A/L1 |

详见 02 §3.1 / §3.2。Hang 上图是知识图谱 SAD 的跑批，**不要**在本 Job 内 persist 图。

ponytail：生产 P1 走现网 Milvus 新 collection（锚点千级，负载可忽略）。本地单测可用内存假索引。**禁止**为产业对齐再引一套向量云依赖；**禁止**往 `amcpdp-*` insert。
