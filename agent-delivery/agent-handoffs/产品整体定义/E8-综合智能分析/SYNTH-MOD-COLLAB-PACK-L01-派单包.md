### 2.3 本轮已确认的产品交互

1. 系统默认条件固定为：目标区域 = **深圳**、对比范围 = **全国重点城市**、时间条件 = **最近 3 年**；三叶共享 `CT-SYN-CTX`。
2. 默认三元组通过后台跑批生成结果快照；快照存在时进入页面**秒开结果**，不创建用户分析任务、不跳过程页。
3. 用户修改默认条件任一项后，结果区进入待分析态；点击唯一主按钮「开始分析」后创建后台任务。
4. 后台任务复用 `SYS-ANALYSIS-JOBS` 统一任务壳与恢复机制，过程表现参照产业链分析，但阶段文案必须改为协同场景：条件冻结与数据快照 → 合作网络构建 → 完整度/中心度/密度计算 → 协同指数与集群/孤立诊断 → 结果校验与报告组装。
5. 结果面必须显性展示：
   - 指标：完整度、中心度、密度、区域创新协同指数，以及联合专利 / 合作项目 / 人才流动等输入统计；
   - 方法：三指标定义、输入与处理步骤、综合加权与历史校准说明；正式分母、聚合方式、权重未定时必须 `D1 missing/draft + Q`；
   - 结果：三指标值、协同指数、横向对比、纵向趋势、高效集群、孤立主体、优势与不足、协同-产出关联及报告入口。
6. 演示公式只可标为「团队临时默认 / 可复现演示口径」，不得冒充甲方已确认算法；运行状态、阶段、已用时间不创建伪 `metric_id`。
