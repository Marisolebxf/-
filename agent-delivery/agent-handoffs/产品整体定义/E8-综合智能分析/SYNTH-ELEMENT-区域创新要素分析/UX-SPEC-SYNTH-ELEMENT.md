## 1. 组件选型（Arco 边界）

| 场景 | 组件 | 约束 |
| --- | --- | --- |
| 上下文条 | Arco `Select` ×3 | 目标区域 / 对比范围 / 时间窗；高 32px；改值立即标脏，不自动提交任务 |
| 开始分析 | Arco `Button` type=primary | 页面底部操作栏右侧唯一主提交；脏态或无跑批时可用 |
| 秒开结果元信息 | `Tag` + 文本 | 「预计算结果」+ 跑批时间；正式视角可弱化，评审态完整 |
| 透镜切换 | Arco `Tabs` 或 Segmented | 综合 / 类型 / 层次 / 领域；切换不触发重算 |
| 七要素卡 / 指标行 | 自绘卡 + `Collapse`/`Table` | 展开 ≤200ms；Enter/Space 可展开 |
| 方法说明 | Arco `Drawer` 或 `Modal` | F-ELEM-03；ESC 关闭；焦点回触发元素 |
| 综合 / 雷达 / 趋势 / 权重 / 领域矩阵 | ECharts | 失败局部错误 + 重试；不伪造动画进度冒充计算 |
| 贡献路径 | 自绘列表或简化路径图 | 未定算法诚实空态；禁止伪因果动画 |
| 排名榜 | 自绘卡片（button 语义） | 当前卡 `aria-current`；点击切换区域并触发脏态规则 |
| 可视化过程 | Steps（horizontal 或 vertical label）+ Alert | 对齐 SYS-ANALYSIS-JOBS / 产业链过程壳；**文案换要素场景**；无百分比 |
| 提示 | `Message` / `Alert` | 非法参数、跑批缺失、任务失败 |

## 2. 状态机

### 2.1 上下文（`CT-SYN-CTX`）

```
初始化:
  URL(region,compare,window) 合法 → 用 URL
  否则 localStorage(v 匹配) → 用持久化
  否则 系统默认(深圳 / 全国重点城市 / 最近3年) 并标「系统默认」

切换任一字段:
  → dirty = (context ≠ defaults) OR (context==defaults AND !BatchSnapshot)
  → 若原为结果面：进入待分析遮罩/空结果提示，不自动开任务
```

### 2.2 秒开 vs 任务

```
dirty==false AND BatchSnapshot 存在:
  mode = result_instant   # 秒开；不进 F-ELEM-02

用户点击「开始分析」:
  冻结 context + 权重模板版本
  创建/恢复 taskId (同条件运行中不重复建)
  navigate F-ELEM-02
  nodes: submit → aggregate → type_level → domain_impact → synthesize

任务 succeeded:
  停留 F-ELEM-02；「查看分析结果」→ F-ELEM-01 mode=result_task
```

### 2.3 过程页动作（D10：动作不在标题栏）

| 状态 | Alert 语义 | 右下操作 |
| --- | --- | --- |
| queued | info | 撤回任务 / 稍后查看 |
| running | info | 稍后查看（无取消） |
| succeeded | success | 查看分析结果 / 查看分析记录 |
| failed | error | 重新尝试 / 按此配置新建分析 |

禁止：过程动作放在卡片标题栏；伪造 % 进度。

## 3. 五阶段文案（要素场景 · 禁止照搬产业链 / 活力）

| # | code | 对外名称 |
| --- | --- | --- |
| 1 | submit | 任务提交与分析条件冻结 |
| 2 | aggregate | 汇聚七类创新要素多源数据与全景快照 |
| 3 | type_level | 计算要素类型指数与层次指数 |
| 4 | domain_impact | 计算领域指数并量化要素贡献路径 |
| 5 | synthesize | 合成要素综合指数、优势短板与分析报告组装 |

对照：

- 产业链示例「产业×区域组合 / 四力指标」→ **必须替换**为本表  
- 活力叶「科技/产业/人才/政策四维」→ **不得复用**为本叶阶段文案

## 4. 「指标 / 方法 / 结果」显性布局契约

结果面必须同屏（或同页一滚）满足：

1. **结果**：综合指数 + 类型/层次/领域指数 + 七要素得分 + 权重 + 排名/趋势/优劣 + 贡献路径区  
2. **指标**：透镜→要素→指标明细（值与得分）  
3. **方法**：可打开的计算方法说明（汇聚、类型/层次/领域评价、综合合成、贡献路径口径）；未定项红问号  

不得只展示总分仪表盘而无方法与分项。

## 5. 持久化

- Key：`topic-synth-workbench`；与 VITALITY/COLLAB 共用  
- 持久化：`region` / `compareScope` / `window` / 可选 `lens` / 指标区展开维  
- 不持久化：任务过程 UI、方法抽屉开合（可用 URL `panel=method`）  
- 默认值引用 TRACE `CT-SYN-CTX.defaults`（与 VITALITY 一致）

## 6. 异常与空态

| 场景 | 表现 | 恢复 |
| --- | --- | --- |
| 默认三元组但无跑批 | 非秒开；Alert「默认结果尚未就绪」+「开始分析」 | 触发任务 / 等跑批 |
| 脏态未提交 | 结果区待分析；主按钮「开始分析」 | 提交或恢复默认 |
| 区级无排名 | 排名局部空态 | 切市级 |
| 指标无数据 | 「暂无数据」置灰，不填 0 | 换口径 |
| 贡献路径未定 | 红问号 + 诚实空态文案 | 等 `Q-SYNTH-E-02` |
| 任务失败 | 失败阶段 + 错误编号 | 重试 |
| 图表失败 | 局部错误 + 重试 | 重试 |

## 7. 键盘与无障碍

- 上下文 Select、开始分析、透镜 Tabs、要素卡、排名卡、过程操作均 Tab 可达  
- Drawer 焦点陷阱；关闭回触发器  
- 过程 Steps 提供文本等价状态（不仅靠颜色）  
- 角标 `aria-label="{mountId} 内部评审说明"`

## 8. D9 评审层

- 门控：全局内部评审模式；组件自闸  
- 排列：数字 → [ⓘ/❓] → [结构] → [⚠️] → [🧪]；≤3 枚、间距 4px  
- 跑批秒开：评审态可显示「跑批预计算」；关闭评审 DOM 零泄漏（无 metric_id / Q-SYNTH-*）  
- D1 missing（综合指数/权重/贡献路径）：红问号只显治理引用

## 9. 观测埋点

`region/compare/window` 变更、开始分析、过程阶段到达、查看结果、打开方法说明、透镜切换、顺链下钻、报告触发。沿用仓内 `observability` 惯例。
