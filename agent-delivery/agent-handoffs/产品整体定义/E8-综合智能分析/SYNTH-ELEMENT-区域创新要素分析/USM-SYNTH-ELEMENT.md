### US-ELEM-01｜分析上下文确认（含默认）

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` + `product_interpretation` |
| `requirement_refs` | §8.2 总述（区域选择隐含于专题综合分析上下文）；共享 `CT-SYN-CTX` |
| 产品角色 | `ROLE-SYN-GOV` |
| Frames | `F-ELEM-01` |
| 业务结果 | 目标区域 + 对比范围 + 时间窗显式确认；默认值明确；与活力/协同叶共享 |

作为政府科技战略决策用户，我想先看到并确认分析的目标区域、对比范围与时间窗，并知道系统默认是什么，以便要素指标与结果都基于同一口径。

主路径：

1. 进入 `/intelligence/elements`，上下文条显示目标区域 / 对比范围 / 时间窗。
2. **系统默认**：目标区域 = **深圳**；对比范围 = **全国重点城市**；时间条件 = **最近 3 年**。首次进入若无 URL/持久化，直接采用默认并明示「系统默认」。
3. 用户可切换市/区级区域、对比范围、时间窗；URL 同步 `region` / `compare` / `window`；`CT-SYN-CTX` 持久化。
4. 切换后若离开默认三元组，结果面进入「待重新分析」脏态（见 US-ELEM-04）；若回到默认且跑批存在，可再次秒开。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| URL 参数非法 | Message + 清参 + 回落默认三元组 | 重新选择 |
| 区级无横向对比 | 排名等对比区局部空态；单区域结果仍可算 | 切回市级 |
| 持久化损坏 | 回落默认三元组 + Message | 重新选择 |

验收：

- `AC-US-ELEM-01-01`：无 URL/持久化时，上下文条三字段分别为深圳 / 全国重点城市 / 最近 3 年，并有「系统默认」标识。
- `AC-US-ELEM-01-02`：切换后进活力/协同叶，三字段一致（`CT-SYN-CTX`）。
- `AC-US-ELEM-01-03`：刷新后保留当前上下文（URL + 持久化）。
- `AC-US-ELEM-01-04`：非法参数不导致空白页或 NaN。

不包含：自定义区域组合维护；对比城市池字典编辑。

主路径：

1. 结果面「指标与方法」区默认展示算法库透镜：**类型 / 层次 / 领域 / 综合**；七要素对象清单与算法库一致（人才、企业、政策、服务机构、科研机构、资金、空间）。
2. 展开透镜可见指标行：名称、口径、预设权重、原始值、得分；覆盖系统方案「规模、质量、结构及活跃度」并映射到对应透镜（规模/质量/活跃度→类型；结构→层次）。
3. 打开 F-ELEM-03「指标与方法说明」：展示计算步骤摘要（汇聚 → 类型评价 §10.6 → 层次评价 §10.7 → 领域评价 §10.8 → 综合 §10.9），公式未定处显示红问号治理引用（`Q-SYNTH-02` / `Q-SYNTH-E-01`），不伪造已闭合公式。
4. 每个统计数字旁有 D9 角标。

### US-ELEM-03｜计算结果显性展示

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | §8.2.2–8.2.3；算法库 §10.6–10.9 输出 |
| 产品角色 | `ROLE-SYN-GOV` |
| Frames | `F-ELEM-01` |
| 业务结果 | 综合指数、三透镜指数、七要素得分、权重、排名、趋势、优势短板、贡献路径均可见且相互一致 |

作为政府科技战略决策用户，我想直接看到目标区域的要素综合指数、各透镜得分与七要素配置结果、对比排名和优劣结论，以及要素对产业/成果的贡献路径入口，以便识别驱动要素与配置瓶颈。

主路径：

1. **综合指数总览**：区域创新要素指数、同比/较对比均值差值、评级说明（演示态诚实标注）。
2. **三透镜结果**：类型指数 / 层次指数 / 领域指数 + 权重分布；与方法区权重一致。
3. **七要素得分**：人才…空间各维得分条或雷达；与类型指数口径一致。
4. **层次达标**：七大结构达标/未达标标记 + 成熟度/均衡度摘要。
5. **领域覆盖**：产业领域 × 技术领域摘要矩阵（可折叠）。
6. **贡献路径**：要素→产业/成果贡献度列表或路径图；未定算法处红问号 + 结构化占位（禁止伪造因果链）。
7. **排名榜 / 趋势 / 优势短板**：对比范围内 TOP；时间窗趋势；优劣与分数一致；策略建议入口可进报告（US-ELEM-05）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 区级无排名 | 排名区局部空态 | 切市级 |
| 图表失败 | 局部错误 + 重试 | 重试 |
| 两处综合指数不一致 | 禁止交付；实现必须以同一结果快照渲染 | — |
| 贡献路径无算法结果 | 诚实空态 + Q 引用，不填伪路径 | METRIC-OPEN |

验收：

- `AC-US-ELEM-03-01`：页面同时可见：综合指数、类型/层次/领域至少一组指数、七要素得分、至少一组指标明细计算结果。
- `AC-US-ELEM-03-02`：综合指数旁红问号（`M_SYNTH_ELEM_INDEX`）+ 🧪；七要素挂 `M_SYNTH_ELEM_TYPE_SCORE`。
- `AC-US-ELEM-03-03`：排名排序与综合指数值一致；当前区域有「当前」标识。
- `AC-US-ELEM-03-04`：优势/短板结论文本中的要素名与分数与七要素卡一致。
- `AC-US-ELEM-03-05`：最近 3 年窗口趋势点位数 = 3（或按年粒度明确说明）。
- `AC-US-ELEM-03-06`：贡献路径区存在且未闭合时为诚实态（红问号 / 空态），不得展示无依据的「已验证因果」。

不包含：把演示态指数对外决策展示（上线前须 METRIC-OPEN 闭合）。

### US-ELEM-04｜默认秒开与改条件可视化分析过程

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation`（对齐 SYS-ANALYSIS-JOBS / 产业链「生成分析」过程壳；补强可运维实现） |
| 产品角色 | `ROLE-SYN-GOV` |
| Frames | `F-ELEM-01`、`F-ELEM-02` |
| 业务结果 | 默认三元组秒开；非默认「开始分析」走后台任务 + **要素场景**五阶段过程 |

作为政府科技战略决策用户，我想在默认深圳对比全国重点城市、最近 3 年时立刻看到要素分析结果；若我改了条件，希望能看到分析在后台如何推进，而不是无反馈等待。

主路径 A — 默认秒开：

1. 上下文 = 深圳 × 全国重点城市 × 最近 3 年，且存在对应 `BatchSnapshot`。
2. 进入 F-ELEM-01 直接渲染结果面（US-ELEM-02/03），**不**创建 `ElementTask`，**不**进入 F-ELEM-02。
3. 结果元信息显示「预计算结果 · 跑批时间」；评审态可标跑批来源。

主路径 B — 改条件分析：

1. 用户修改任一上下文字段 → 结果区切换为待分析态，主按钮「开始分析」可用。
2. 点击「开始分析」→ 冻结当前三元组与权重模板版本 → 创建 `taskId` → 进入 F-ELEM-02。
3. **可视化分析过程**五阶段（**要素场景**，对齐 SYS-ANALYSIS-JOBS 壳；**禁止**照搬产业链「产业×区域 / 四力」或活力「四维」文案）：
   1. 任务提交与分析条件冻结
   2. 汇聚七类创新要素多源数据与全景快照
   3. 计算要素类型指数与层次指数（§10.6 / §10.7）
   4. 计算领域指数并量化要素贡献路径（§10.8 / §8.2.3）
   5. 合成要素综合指数、优势短板与分析报告组装（§10.9）
4. 完成后停留过程页；用户点「查看分析结果」回到 F-ELEM-01 结果面（绑定该任务快照）。
5. 可离开页面；任务后台继续；可从系统任务浮层 / 本叶「分析记录」恢复（`CT-SYN-JOBS`）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 默认三元组但跑批缺失 | 不伪装秒开；提示「默认结果生成中」+ 可「开始分析」补算 | 触发任务或等跑批 |
| 任务失败 | 过程页失败阶段 + 错误编号 + 「重新尝试」 | 重试 / 改条件新建 |
| 重复提交同条件运行中任务 | 恢复原 `taskId`，不建第二任务 | — |
| 排队中 | 显示队列位；可撤回 | 撤回或等待 |

验收：

- `AC-US-ELEM-04-01`：默认三元组 + 有跑批时，首屏可交互结果出现时间满足「秒开」（无过程页跳转）。
- `AC-US-ELEM-04-02`：修改任一默认字段后，必须点击「开始分析」才进入过程页；过程五阶段文案为本叶要素场景（非产业链四力、非活力四维文案）。
- `AC-US-ELEM-04-03`：过程页含任务摘要卡 +「可视化分析过程」卡；阶段仅已完成/进行中/等待中/失败；无伪造百分比。
- `AC-US-ELEM-04-04`：完成后不自动跳结果；「查看分析结果」后指标/方法/结果与任务快照一致。
- `AC-US-ELEM-04-05`：离开后可经系统任务浮层恢复同一 `taskId`。

不包含：用户取消已进入 running 的任务（与 SYS-ANALYSIS-JOBS 一致）。
