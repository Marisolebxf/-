## F-ELEM-02 可视化分析过程

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 分析生成中                                              [运行中 Tag]     │
│ 任务 ID：TASK-…  类型：区域创新要素分析                                   │
│ 对象：深圳 →（示例）南山区 × 大湾区 × 近5年    已用：00:42                │
├──────────────────────────────────────────────────────────────────────────┤
│ 可视化分析过程                                                            │
│                                                                          │
│ (1)任务提交与分析条件冻结 ●                                              │
│ (2)汇聚七类创新要素多源数据与全景快照 ○ 等待中                            │
│ (3)计算要素类型指数与层次指数 ○ 等待中                                    │
│ (4)计算领域指数并量化要素贡献路径 ○ 等待中                                │
│ (5)合成要素综合指数、优势短板与分析报告组装 ○ 等待中                      │
│                                                                          │
│ Alert：当前阶段说明（可离开，后台继续；系统任务浮层可恢复）               │
│                                                    [稍后查看]            │
└──────────────────────────────────────────────────────────────────────────┘
```

> 阶段文案必须用上表**要素场景**，禁止使用「产业×区域组合 / 四力指标」或活力「科技/产业/人才/政策四维」文案。

| 2 | Steps | nodeCode / nodeName / nodeStatus | — | 完成/进行中/等待/失败 | N/A |
| 3 | Alert+操作 | message / queuePos | 撤回(仅排队)/稍后查看/查看结果/重试 | 见 UX-SPEC §2.3 | N/A |
