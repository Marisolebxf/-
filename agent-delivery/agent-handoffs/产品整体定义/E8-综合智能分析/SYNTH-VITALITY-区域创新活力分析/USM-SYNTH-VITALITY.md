## 4. 用户故事

### US-VIT-01｜分析上下文确认（含默认）

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` + `product_interpretation` |
| `requirement_refs` | §8.1.3「用户可灵活选择目标区域（如深圳市、南山区等）」 |
| 产品角色 | `ROLE-SYN-GOV` |
| Frames | `F-VIT-01` |
| 业务结果 | 目标区域 + 对比范围 + 时间窗显式确认；默认值明确；与要素/协同叶共享 |

作为政府科技战略决策用户，我想先看到并确认分析的目标区域、对比范围与时间窗，并知道系统默认是什么，以便后续所有指标与结果都基于同一口径。

主路径：

1. 进入 `/intelligence/vitality`，上下文条显示目标区域 / 对比范围 / 时间窗。
2. **系统默认**：目标区域 = **深圳**；对比范围 = **全国重点城市**；时间条件 = **最近 3 年**。首次进入若无 URL/持久化，直接采用默认并明示「系统默认」。
3. 用户可切换市/区级区域、对比范围、时间窗；URL 同步 `region` / `compare` / `window`；`CT-SYN-CTX` 持久化。
4. 切换后若离开默认三元组，结果面进入「待重新分析」脏态（见 US-VIT-04）；若回到默认且跑批存在，可再次秒开。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| URL 参数非法 | Message + 清参 + 回落默认三元组 | 重新选择 |
| 区级无横向对比 | 排名等对比区局部空态；单区域结果仍可算 | 切回市级 |
| 持久化损坏 | 回落默认三元组 + Message | 重新选择 |

验收：

- `AC-US-VIT-01-01`：无 URL/持久化时，上下文条三字段分别为深圳 / 全国重点城市 / 最近 3 年，并有「系统默认」标识。
- `AC-US-VIT-01-02`：切换后进要素/协同叶，三字段一致（`CT-SYN-CTX`）。
- `AC-US-VIT-01-03`：刷新后保留当前上下文（URL + 持久化）。
- `AC-US-VIT-01-04`：非法参数不导致空白页或 NaN。

不包含：自定义区域组合维护；对比城市池字典编辑。

### US-VIT-02｜指标体系与计算方法显性展示

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | §8.1.1；算法库 §10.5(1) 指标体系/阈值与权重/指数计算 |
| 产品角色 | `ROLE-SYN-RESEARCH` |
| Frames | `F-VIT-01`、`F-VIT-03` |
| 业务结果 | 用户能看到：有哪些指标、如何计算、当前权重/阈值说明（未定则诚实标缺口） |

作为科研机构 / 研究分析用户，我想看清区域创新活力由哪些指标构成、各维权重与合成方法是什么，以便理解指数含义而不是只看到黑盒总分。

主路径：

1. 结果面「指标与方法」区默认展示算法库四维：**科技 / 产业 / 人才 / 政策**，各维权重、维得分、输入来源引用（§10.1–10.4）。
2. 展开维度可见指标行：名称、口径、预设权重、原始值、得分；覆盖系统方案举例（高企数量、专利申请与授权量、高质量论文数量等）并映射到对应维。
3. 打开 F-VIT-03「指标与方法说明」：展示计算步骤摘要（标准化 → 阈值/权重 → 加权求和 → 活力指数），公式未定处显示红问号治理引用（`Q-SYNTH-01` / `Q-SYNTH-V-01`），不伪造已闭合公式。
4. 每个统计数字旁有 D9 角标。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 某指标无数据 | 「暂无数据」置灰，不用 0 填充，不参与维得分说明 | 换区域/时间 |
| 权重未正式发布 | 展示临时默认权重 + ⚠️「待甲方确认」+ 红问号 | 等 METRIC-OPEN |

验收：

- `AC-US-VIT-02-01`：四维命名与算法库 §10.5 一致（科技/产业/人才/政策），不得使用与算法库冲突的替代四维作为正式口径。
- `AC-US-VIT-02-02`：用户无需离开本页即可看到「指标列表 + 计算方法说明 + 当前计算结果」三者；方法说明含合成逻辑摘要。
- `AC-US-VIT-02-03`：系统方案列举的高企 / 专利 / 论文类指标在明细中可定位到所属维度。
- `AC-US-VIT-02-04`：算法未定指标旁为 D1 missing 红问号（只显 Q 引用）+ 🧪；不展示伪 8 件套。

不包含：用户自定义权重保存为生产口径（属算法定义卡 / 甲方确认）。

| 属性 | 内容 |

| 业务结果 | 指数、单维评分、权重分布、排名、趋势、优势短板均可见且相互一致 |

作为政府科技战略决策用户，我想直接看到目标区域的活力指数、各维得分与权重、在对比范围内的排名和优劣结论，以便横向评估竞争力。

主路径：

1. **指数总览**：区域创新活力指数、同比/较对比均值差值、评级说明（演示态诚实标注）。
2. **四维结果**：科技/产业/人才/政策单维评分 + 权重分布（饼或条）；与方法区权重一致。
3. **排名榜**：对比范围内 TOP 列表；当前区域高亮；点击其他区域切换目标区域（触发 US-VIT-04 脏态规则）。
4. **趋势**：时间窗内历年指数曲线。
5. **优势与短板**：结构化列表，数值与图表一致；策略建议入口可进报告（US-VIT-05）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 区级无排名 | 排名区局部空态 | 切市级 |
| 图表失败 | 局部错误 + 重试 | 重试 |
| 两处指数不一致 | 禁止交付；实现必须以同一结果快照渲染 | — |

验收：

- `AC-US-VIT-03-01`：页面同时可见：活力指数、四维评分、权重分布、至少一组指标明细计算结果。
- `AC-US-VIT-03-02`：指数旁红问号（`M_SYNTH_VIT_INDEX`）+ 🧪；四维挂 `M_SYNTH_VIT_DIM_SCORE`。
- `AC-US-VIT-03-03`：排名排序与指数值一致；当前区域有「当前」标识。
- `AC-US-VIT-03-04`：优势/短板结论文本中的维度名与分数与四维卡一致。
- `AC-US-VIT-03-05`：最近 3 年窗口趋势点位数 = 3（或按年粒度明确说明）。

不包含：把演示态指数对外决策展示（上线前须 METRIC-OPEN 闭合）。

### US-VIT-04｜默认秒开与改条件可视化分析过程

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation`（补强 §8.1.3「自动调用模型实时计算」的可运维实现） |
| 产品角色 | `ROLE-SYN-GOV` |
| Frames | `F-VIT-01`、`F-VIT-02` |
| 业务结果 | 默认三元组秒开；非默认「开始分析」走后台任务 + 活力场景五阶段过程 |

作为政府科技战略决策用户，我想在默认深圳对比全国重点城市、最近 3 年时立刻看到结果；若我改了条件，希望能看到分析在后台如何推进，而不是无反馈等待。

主路径 A — 默认秒开：

1. 上下文 = 深圳 × 全国重点城市 × 最近 3 年，且存在对应 `BatchSnapshot`。
2. 进入 F-VIT-01 直接渲染结果面（US-VIT-02/03），**不**创建 `VitalityTask`，**不**进入 F-VIT-02。
3. 结果元信息显示「预计算结果 · 跑批时间」；评审态可标跑批来源。

主路径 B — 改条件分析：

1. 用户修改任一上下文字段 → 结果区切换为待分析态，主按钮「开始分析」可用。
2. 点击「开始分析」→ 冻结当前三元组与权重模板版本 → 创建 `taskId` → 进入 F-VIT-02。
3. **可视化分析过程**五阶段（活力场景，对齐 SYS-ANALYSIS-JOBS 壳）：
   1. 任务提交与分析条件冻结
   2. 校验目标区域×对比范围×时间窗，装载四维专题库快照与权重合计
   3. 按科技/产业/人才/政策四维计算区域创新活力指数
   4. 生成单维评分、权重分布与优势短板
   5. 结果可信性校验与分析报告组装
4. 完成后停留过程页；用户点「查看分析结果」回到 F-VIT-01 结果面（绑定该任务快照）。
5. 可离开页面；任务后台继续；可从系统任务浮层 / 本叶「分析记录」恢复（`CT-SYN-JOBS`）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 默认三元组但跑批缺失 | 不伪装秒开；提示「默认结果生成中」+ 可「开始分析」补算 | 触发任务或等跑批 |
| 任务失败 | 过程页失败阶段 + 错误编号 + 「重新尝试」 | 重试 / 改条件新建 |
| 重复提交同条件运行中任务 | 恢复原 `taskId`，不建第二任务 | — |
| 排队中 | 显示队列位；可撤回 | 撤回或等待 |

验收：

- `AC-US-VIT-04-01`：默认三元组 + 有跑批时，首屏可交互结果出现时间满足「秒开」（无过程页跳转）。
- `AC-US-VIT-04-02`：修改任一默认字段后，必须点击「开始分析」才进入过程页；过程五阶段文案为本叶活力场景（非产业链四力文案）。
- `AC-US-VIT-04-03`：过程页含任务摘要卡 +「可视化分析过程」卡；阶段仅已完成/进行中/等待中/失败；无伪造百分比。
- `AC-US-VIT-04-04`：完成后不自动跳结果；「查看分析结果」后指标/方法/结果与任务快照一致。
- `AC-US-VIT-04-05`：离开后可经系统任务浮层恢复同一 `taskId`。

不包含：用户取消已进入 running 的任务（与 SYS-ANALYSIS-JOBS 一致）。
