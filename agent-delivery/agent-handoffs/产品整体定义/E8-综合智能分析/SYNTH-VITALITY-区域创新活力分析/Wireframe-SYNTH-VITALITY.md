## F-VIT-02 可视化分析过程

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 分析生成中                                              [运行中 Tag]     │
│ 任务 ID：TASK-…  类型：区域创新活力分析                                   │
│ 对象：深圳 →（示例）南山区 × 大湾区 × 近5年    已用：00:42                │
├──────────────────────────────────────────────────────────────────────────┤
│ 可视化分析过程                                                            │
│                                                                          │
│ (1)任务提交与分析条件冻结 ●                                              │
│ (2)校验目标区域×对比范围×时间窗，装载四维专题库快照与权重合计 ○ 等待中   │
│ (3)按科技/产业/人才/政策四维计算区域创新活力指数 ○ 等待中                │
│ (4)生成单维评分、权重分布与优势短板 ○ 等待中                              │
│ (5)结果可信性校验与分析报告组装 ○ 等待中                                  │
│                                                                          │
│ Alert：当前阶段说明（可离开，后台继续；系统任务浮层可恢复）               │
│                                                    [稍后查看]            │
└──────────────────────────────────────────────────────────────────────────┘
```

> 阶段文案必须用上表活力场景，禁止使用「产业×区域组合 / 四力指标」等产业链文案。

| # | 区块 | 字段 | 交互 | 状态覆盖 | metric_id |
| --- | --- | --- | --- | --- | --- |
| 1 | 任务摘要 | taskId / type / frozenContext / elapsed / status | — | queued/running/success/failed | N/A |
| 2 | Steps | nodeCode / nodeName / nodeStatus | — | 完成/进行中/等待/失败 | N/A |
| 3 | Alert+操作 | message / queuePos | 撤回(仅排队)/稍后查看/查看结果/重试 | 见 UX-SPEC §2.3 | N/A |

完成后不自动跳转；「查看分析结果」→ F-VIT-01 绑定该任务快照。

## F-VIT-03 指标与方法说明抽屉

```
┌─ 指标与方法说明 ─────────────────────────────────────────────┐
│ 计算步骤（算法库 §10.5）                                       │
│  1 指标体系：科技/产业/人才/政策（输入参照 §10.1–10.4）         │
│  2 数据标准化：缺失填补 / 异常剔除 / 一致性校验                │
│  3 阈值与权重：❓ Q-SYNTH-01 / Q-SYNTH-V-01（未定诚实态）       │
│  4 加权求和 → 区域创新活力指数                                 │
│  5 输出：指数 · 单维评分 · 权重分布 · 优势短板 · 趋势建议     │
│ 临时默认权重表（⚠️ 待甲方确认）🧪                               │
│ 指标树（只读，与主区③同源）                                    │
└────────────────────────────────────────────────────────────────┘
```

| # | 字段 | 交互 | 状态覆盖 | metric_id |
| --- | --- | --- | --- | --- |
| 步骤摘要 | methodSteps[] | 只读 | 公式未定红问号 | `M_SYNTH_VIT_WEIGHT` / `M_SYNTH_VIT_INDEX` |
| 权重表 | dim / weight | 只读 | ⚠️ 待确认 | `M_SYNTH_VIT_WEIGHT` |
