## 1. 组件选型

| 场景 | 组件 | 约束 |
| --- | --- | --- |
| 上下文条 | Arco `Select` ×3 | 区域 / 对比 / 时间；改变后标脏，不自动建任务 |
| 开始分析 | Arco `Button` primary | 页面底部唯一主提交；默认快照存在时隐藏或禁用 |
| 跑批元信息 | `Tag` + 文本 | 「预计算结果」+ 跑批时间 + 方法版本 |
| 指标结果卡 | 自绘 Card + Arco Tooltip | 指数、完整度、中心度、密度；数字旁 D9 角标 |
| 指标与方法 | Arco `Drawer` | ESC 关闭、焦点回触发器；公式分正式/临时演示 |
| 关系图谱 | ECharts Graph / 仓内既有封装 | roam + drag；同时提供中心主体/集群/孤立列表等价路径 |
| 对比/趋势/关联 | ECharts | 失败局部错误 + 重试；不伪造缺失结果 |
| 过程页 | Arco `Steps` + `Alert` | 复用 SYS-ANALYSIS-JOBS；无百分比 |
| 主体详情 | Arco `Drawer` | 企业/机构优先跨模块；无统一画像时本地只读 |
| 异常反馈 | `Message` / `Alert` / `Empty` | 参数非法、跑批缺失、任务失败、样本不足 |

## 2. 状态机

### 2.1 上下文与秒开

```text
初始化：
  URL 合法 → URL
  否则持久化版本合法 → 持久化
  否则 → 深圳 / 全国重点城市 / 最近3年

context == defaults 且 BatchSnapshot 存在：
  mode=result_instant；直接展示指标+方法+结果；不创建任务

修改任一字段：
  mode=config_dirty；结果灰显/占位；显示条件差异与「开始分析」
```

默认快照缺失时不得把旧快照冒充当前结果；显示「默认结果尚未就绪」并允许开始分析。

### 2.2 后台任务

```text
点击开始分析
  → 权限/参数/数据预检
  → 冻结 context + methodVersion
  → 检查 user_id + task_type 非终态互斥
      ├─ 已有：恢复原 taskId
      └─ 无：创建任务 → queued | running
  → /intelligence/collaboration/tasks/:taskId
  → succeeded 后「查看分析结果」绑定 resultSnapshotId
```

任务状态以服务端为真源。刷新、跨页面、跨标签页、重新登录均恢复同一任务。

### 2.3 过程页动作

| 状态 | Alert | 右下操作 |
| --- | --- | --- |
| queued | 已接收、队列位置；不显示预计时间 | 撤回任务 / 稍后查看 |
| running | 当前真实阶段、已用时间；可后台继续 | 稍后查看 |
| succeeded | 结果快照已生成 | 查看分析结果 / 查看记录 |
| failed | 失败阶段、错误编号、冻结条件 | 重新尝试 / 按此配置新建 |
| connection_lost | 状态连接中断，后台不受影响 | 等待自动恢复 |

运行中普通用户无取消入口；失败重试必须创建新 `taskId` 并关联原任务。

## 3. 协同场景五阶段

| # | code | 对外名称 | 当前阶段说明要点 |
| --- | --- | --- | --- |
| 1 | `submit` | 任务提交与分析条件冻结 | 区域、对比范围、时间窗、方法版本已冻结 |
| 2 | `network` | 装载创新主体与合作关系快照，构建区域协同网络 | 校验企业/机构/人才及联合专利/项目/人才流动关系 |
| 3 | `metrics` | 计算完整度、中心度与密度三项网络指标 | 只播报后台已证明的阶段，不展示估算百分比 |
| 4 | `diagnose` | 合成协同指数，识别高效集群、孤立主体与优势不足 | 权重/判据读取任务冻结的方法版本 |
| 5 | `assemble` | 校验横向对比与趋势结果，组装协同效率报告快照 | 生成不可变结果快照并完成一致性校验 |

禁止照搬产业链的「产业×区域组合 / 四力指标」，也禁止照搬活力叶「科技/产业/人才/政策四维计算」。

## 4. 指标 / 方法 / 结果显性布局

结果面同页一滚必须满足：

1. **指标**：完整度、中心度、密度、协同指数、联合专利/合作项目/人才流动输入统计。
2. **方法**：三指标语义、输入与预处理、建图、三指标计算、标准化/加权/历史校准、输出说明。
3. **结果**：三指标值、协同指数、对比排名、趋势、高效集群、孤立主体、优势不足、协同—产出关联及有证据的优化合作路径策略建议。

F-COLLAB-03 对公式分层：

- 「源需求已明确」：三指标业务语义、综合加权、历史校准、输入输出；
- 「团队临时演示」：可复现公式与等权合成，显示 🧪 / ⚠️；
- 「待正式确认」：图类型、分母、边去重加权、标准化、权重、校准窗口、相关方法，挂 Q。

不得只显示总指数，不得把 Tooltip 中一句话当作完整方法说明。

策略建议必须显示证据来源与「待审核/已审核」状态；`Q-SYNTH-C-04` 未闭合前不得自动发布。产业领域筛选 taxonomy 与合作关系贴源映射挂 `Q-SYNTH-C-05`，不得由前端自造分类或关系事实。

## 5. 图谱交互

```text
产业/主体/关系筛选 → 过滤当前展示子图
  → 图谱与「当前子图统计」同步
  → 若选中节点/集群被过滤，清除选中态

中心主体项 click/Enter → 高亮定位节点
集群卡 click/Enter → 高亮成员与内部边
孤立主体项 click/Enter → 高亮定位节点
节点 click：
  enterprise → CT-SYN-01
  serviceOrg → CT-SYN-02
  talent/institution 无稳定跨模块 ID → F-COLLAB-04
```

全网快照指标与当前子图指标必须加标签区分；默认总览不因纯展示筛选偷偷改写已冻结协同指数。

## 6. 异常与空态

| 场景 | 表现 | 恢复 |
| --- | --- | --- |
| 默认快照缺失 | Alert + 开始分析 | 触发任务 / 等跑批 |
| 脏态未提交 | 上次结果弱化并标「非当前条件」或不展示；方法模板可读 | 开始分析 / 恢复默认 |
| 图谱筛选无节点 | 图谱 Empty + 当前子图统计为 0 | 放宽筛选 |
| 指标无数据 | 暂无数据，不填 0、不参与指数 | 换口径 |
| 关联样本不足 | 不画相关线，不给系数 | 扩大时间或等数据 |
| 图表/图谱失败 | 局部错误 + 重试，其他区保留 | 重试 |
| 任务失败 | 失败阶段 + 错误编号 | 新任务重试 |
| 跨模块实体不存在 | 拦截 + Message | 留在当前页 |

## 7. 持久化与 URL

- Key：`topic-synth-workbench`，与 VITALITY/ELEMENT 共用。
- 持久化：region / compareScope / window / graphFilters / 指标区展开状态。
- 服务端持久：任务 ID、状态、阶段、结果快照。
- URL：`region` / `compare` / `window` / `industry` / `kinds` / `node` / `panel=method`。
- 任务过程 UI 不以 localStorage 为真源。

## 8. 键盘与无障碍

- Select、开始分析、方法入口、中心主体、集群卡、孤立主体、过程操作均 Tab 可达。
- 卡片交互使用 button 语义，Enter/Space 等价触发。
- 图谱提供列表和文本摘要等价路径；不能只靠颜色区分节点/边。
- Drawer 使用焦点陷阱；关闭后焦点回触发元素。
- Steps 同时播报阶段名称和「已完成/进行中/等待/失败」文本。
- 角标按钮 `aria-label="{指标中文名} 指标与数据说明"`。

## 9. D9 评审层

- 全部指标由集中评审层挂载；组件自闸。
- 排列：数字 → [ⓘ/❓] → [结构] → [⚠️/⏰] → [🧪/⟳]；≤3 枚、间距 4px。
- D1 missing（协同指数、关联结果）红问号只显治理引用。
- D1 draft（三指标、关系输入）可展示临时方法与待确认点。
- 默认跑批结果在评审态标「跑批预计算」；关闭评审模式 DOM 不泄漏 metric_id / Q / GAP。
- 任务状态、阶段、已用时间、队列位置不是业务 metric。
