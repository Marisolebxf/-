> **版本**：v1.0-r3
> **状态**：与 IA、Wireframe、UX-SPEC、TRACE 同步（AI 起草，待体验 Owner 确认）
> **原始需求**：专题系统 Bid `1.1.1.2.4.2.8.1`（区域创新活力分析：指标体系构建 / 综合评价模型 / 区域指数计算与可视化）、`.8.2`（区域创新要素分析：创新要素数据汇聚 / 要素评价模型构建 / 要素影响关联分析）、`.8.3`（区域创新协同分析：创新主体关系图谱 / 协同度计算模型 / 协同效果评估），共 9 个三级项

## 1. 模块结果

围绕用户显式确认的"目标区域 + 对比范围 + 时间窗"上下文，完成"看整体（活力指数总览与排名） → 析要素（要素全景、评价与影响关联） → 促协同（主体关系图谱、协同度与效果评估）"的分析闭环。三页共享同一区域上下文（持久化 + URL 可分享恢复）；活力排名榜可切换目标区域并顺链下钻要素、协同；协同图谱中企业 / 服务机构节点可跨模块下钻到企业统一画像（E-31）与 E7 机构画像。活力指数、要素评价、协同度三族算法均无甲方算法定义卡，全程保持 D1 missing/draft 诚实态（Q-SYNTH-01/02/03），不做伪闭合。不做产业链/技术链细分口径切换（Bid 8.x 未要求，旧原型的 8 项筛选属伪功能，删除）；不做区域数据维护；不做人才个体画像跨模块互认（无稳定人才主数据映射）。

## 4. 用户故事

### US-SYN-01｜区域分析上下文确认

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation`（8.1.3"灵活选择目标区域（如深圳市、南山区等）"、8.2/8.3 均以区域为对象，本故事是三页共同前置） |
| 产品角色 | `ROLE-SYN-GOV` |
| 依赖 | 无 |
| Frames | `F-SYN-01`、`F-SYN-02`、`F-SYN-03` |
| 业务结果 | 一个目标区域 + 对比范围 + 时间窗被显式确认，三页共享，URL 与本地持久化一致 |

作为科技战略决策者，我想先确认分析的目标区域、对比范围和时间窗，以便活力、要素、协同三个视角都基于同一区域口径，不因切换页面或刷新而丢失。

主路径：

1. 进入任一 intelligence 页面，上下文条显示当前目标区域 / 对比范围 / 时间窗（默认取上次持久化值；首次进入取字典第一项并明示"默认"）。
2. 用户在上下文条切换目标区域（含深圳市及区级口径）、对比范围（全国重点城市 / 大湾区）或时间窗（近 3 年 / 近 5 年）。
3. 切换即生效：本页所有视图基于新上下文重算；URL 同步 `region` / `window` 参数；localStorage 持久化（`topic-synth-` 前缀）。
4. 从活力页顺链进入要素页 / 协同页时，区域上下文随链路传递，不需重新选择。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| URL `region` 参数无法解析 | 回落持久化值并以 Message 提示"区域参数无效，已恢复上次选择"，清除非法参数 | 重新在上下文条选择 |
| 持久化数据损坏 / 版本不符 | 静默回落默认上下文，并以 Message 提示"已恢复默认区域上下文" | 重新选择 |
| 区级口径无对比数据 | 对比类视图局部空态"该口径暂无横向对比数据"，单区域视图正常 | 切回市级口径 |

验收：

- `AC-US-SYN-01-01`：上下文条在三页结构一致；任一页切换目标区域 / 时间窗后进入另两页，上下文保持一致（持久化共享）。
- `AC-US-SYN-01-02`：刷新页面后目标区域、对比范围、时间窗均保留（localStorage + URL）。
- `AC-US-SYN-01-03`：URL 携带 `region` 与 `window` 参数直达时，页面按参数恢复上下文且优先级高于持久化值。
- `AC-US-SYN-01-04`：非法 `region` 参数不导致空白页或 NaN，按异常表回落并提示。

不包含：区域字典维护；自定义区域组合。

### US-SYN-02｜活力指标体系分层浏览

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |

作为智库分析人员，我想分层查看系统预设的区域创新活力指标体系，以便理解指数由哪些维度和指标构成、各自权重与口径是什么。

主路径：

1. 活力页"指标体系"区默认收拢显示 4 个一级维度卡（创新主体 / 创新产出 / 创新投入 / 创新转化）及各自权重与维度得分。
2. 点击维度卡展开该维度下的二级指标行：指标名、口径说明、预设权重、目标区域当前值与得分。
3. 每个得分数字旁有 D9 角标（ⓘ 或红问号），可查指标 8 件套与就绪度四维。
4. 展开状态持久化；再次进入保持上次展开的维度。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 某指标在当前区域无数据 | 该指标行显示"暂无数据"，不用 0 填充，得分列置灰且不参与维度得分说明 | 切换区域或时间窗 |
| 全部维度收拢 | 仍显示维度卡摘要，不出现空白区 | 点击展开 |

验收：

- `AC-US-SYN-02-01`：指标体系覆盖 Bid 8.1.1 列举的高新技术企业数量、专利申请与授权量、高质量论文数量等维度，两层结构（维度 → 指标）完整渲染。
- `AC-US-SYN-02-02`：每个一级维度显示预设权重，所有启用维度权重合计 100%；二级指标行含口径说明文本。
- `AC-US-SYN-02-03`：维度展开 / 收拢不丢失页面其他区状态；展开状态刷新后保留。
- `AC-US-SYN-02-04`：指标得分数字旁必有 D9 角标：`M_SYNTH_INDICATOR_SCORE`（D1 draft ⚠️ Q-SYNTH-01）+ 🧪；无数据指标行不渲染伪造得分。

不包含：指标体系编辑 / 权重自定义（8.1.1 为"系统预设"；权重调整属算法定义卡范畴，Q-SYNTH-01）。

作为科技战略决策者，我想直观看到目标区域的创新活力指数、在对比范围内的排名和历年走势，以便横向评估区域竞争力并定位薄弱分项。

主路径：

1. 指数总览卡显示：综合指数仪表盘（演示态加权口径，D1 missing 红问号 + 🧪）、同比变化、评级说明。
2. 分项得分区按 4 个一级维度显示"目标区域 vs 对比均值"分组条形。
3. 排名榜按对比范围列出各区域指数卡（TOP10），当前目标区域高亮；点击其他区域卡即切换目标区域，全页（含指标体系区）重算，URL 同步。
4. 趋势区显示目标区域指数随时间窗的历年曲线；hover 显示逐年值。
5. "下钻要素分析"入口带当前上下文跳转要素页（US-04）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 区级口径无排名数据 | 排名榜区局部空态"区级口径暂无横向排名"，指数卡与趋势正常 | 切回市级口径 |

| 图表渲染失败 | 图表容器局部错误 + "重试"，页面壳与上下文保留 | 点击重试 |

验收：

- `AC-US-SYN-03-01`：综合指数值 = 演示态加权公式对分项得分的计算结果（前端可复现），与分项得分区数据一致，不出现两处不一致的指数值。
- `AC-US-SYN-03-02`：指数数字旁必有红问号（`M_SYNTH_VITALITY_INDEX` D1 missing，只显 Q-SYNTH-01 治理引用，不显伪 8 件套）+ 🧪；分项得分挂 `M_SYNTH_INDICATOR_SCORE`。
- `AC-US-SYN-03-03`：点击排名榜任一区域卡后目标区域切换，指数卡 / 分项 / 趋势 / 指标体系区全部重算，URL `region` 同步，刷新后保留。
- `AC-US-SYN-03-04`：排名榜排序与各卡指数值严格一致（降序），当前目标区域卡有视觉高亮与"当前"标识。
- `AC-US-SYN-03-05`：时间窗切换后趋势曲线年份范围与窗口一致（近 3 年 = 3 个数据点，近 5 年 = 5 个）。
- `AC-US-SYN-03-06`："下钻要素分析"跳转要素页后区域 / 时间窗上下文一致，浏览器返回可回到活力页原状态。

不包含：机器学习模型真实计算（8.1.2 算法属 Python 侧，前端仅消费；演示态加权口径标 🧪 且登记 Q-SYNTH-01）；自定义对比区域集合。

作为园区生态运营人员，我想在关系图谱中按产业领域筛选查看企业、机构、人才之间的合作网络，并能下钻任一主体详情，以便发现高效合作集群与可运营的孤立主体。

主路径：

1. 图谱区渲染力导向网络：节点分类（企业 / 科研机构·高校 / 人才 / 服务机构），边为合作关系（联合专利 / 合作项目 / 人才流动，hover 显示关系类型）。
2. 筛选条支持产业领域（单选）与主体类型（多选）过滤节点；筛选即重绘，选择持久化。
3. 图谱侧栏显示网络统计：节点数、边数、连接密度、TOP 中心性主体列表（D1 draft ⚠️）。
4. 点击节点：企业节点跳企业统一画像整页（CT-SYN-01，`/enterprise-center/profile/:code`）；服务机构节点跳 E7 机构画像（CT-SYN-02，`/service/institution-judgment?org=`）；人才 / 高校院所节点打开本地详情抽屉（F-SYN-05，声明无跨模块画像）。
5. 中心性列表项点击时对应节点在图谱内高亮定位。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 筛选后无节点 | 图谱容器局部空态"当前筛选无合作主体"，统计区显示 0 且不渲染空图例 | 放宽筛选 |
| 跨模块目标实体不存在 | 不跳转，Message"目标画像暂不可用"（防伪跳转） | 留在图谱 |
| 图谱渲染失败 | 局部错误 + "重试"，筛选与统计保留 | 点击重试 |

验收：

- `AC-US-SYN-06-01`：节点分类图例与配色一致；产业领域 / 主体类型筛选后图谱与统计区（节点数 / 边数 / 密度）同步更新且相互一致。
- `AC-US-SYN-06-02`：企业节点点击跳转 `/enterprise-center/profile/:code` 且能解析出对应企业（使用企业库真实 ID）；服务机构节点跳转 E7 机构画像并自动打开对应机构抽屉。
- `AC-US-SYN-06-03`：人才 / 高校节点打开本地抽屉，抽屉内明示"人才个体暂无跨模块统一画像"边界说明。
- `AC-US-SYN-06-04`：连接密度 / 中心性数字旁必有 ⓘ（`M_SYNTH_COLLAB_DENSITY` / `M_SYNTH_COLLAB_CENTRALITY`，D1 draft ⚠️ Q-SYNTH-03）+ 🧪。
- `AC-US-SYN-06-05`：筛选状态与图谱选中节点刷新后保留（持久化 + URL `industry` / `node` 参数）。
- `AC-US-SYN-06-06`：中心性列表点击后图谱对应节点出现选中高亮，再次点击取消。

不包含：图谱编辑；跨区域图谱对比；NebulaGraph 真实图数据（演示态确定性 Mock，正式态走 Java REST → Python /internal/*）。

### US-SYN-07｜协同度计算与效果评估

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SYN-COLLAB-INDEX`（8.3.2）、`REQ-SYN-COLLAB-EVAL`（8.3.3） |
| 产品角色 | `ROLE-SYN-GOV` |
| 依赖 | US-06 |
| Frame | `F-SYN-03` |
| 业务结果 | 区域协同指数、高效集群与孤立主体识别、协同-产出相关性与效率报告可视 |

作为科技战略决策者，我想看到目标区域的创新协同指数、哪些集群协同高效、哪些主体孤立，以及协同网络与创新产出的关联，以便针对性推动产学研融合。

主路径：

1. 协同度区显示：协同指数卡（联合专利 / 合作项目 / 人才流动三类协同指标构成，演示态口径 D1 missing 红问号 + 🧪）与逐类指标值。
2. 集群识别区列出高效协同集群卡（集群名 / 成员数 / 集群协同分 / 代表成员），与孤立主体列表（主体名 / 类型 / 建议动作文本 🧪）。
3. 点击集群卡在图谱中高亮该集群成员节点与内部边；点击孤立主体定位其节点。
4. 效果评估区显示协同度 × 创新产出（联合发明专利数）相关性图与结论文本；"生成协同效率报告"按钮走系统报告面（CT-SYN-03，data-system-report-trigger）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 当前筛选下无集群 | 集群区局部空态"当前范围未识别到协同集群"，孤立主体列表独立渲染 | 放宽筛选 |
| 相关性数据不足 | 效果评估区显示"样本不足，暂无法给出相关性结论"，不画伪相关线 | 扩大时间窗 |

验收：

- `AC-US-SYN-07-01`：协同指数数字旁必有红问号（`M_SYNTH_COLLAB_INDEX` D1 missing，Q-SYNTH-03）+ 🧪；三类协同指标逐项可见。
- `AC-US-SYN-07-02`：点击集群卡后图谱高亮成员节点与集群内边，取消选择恢复；集群成员与图谱节点 ID 一致。
- `AC-US-SYN-07-03`：孤立主体列表中的主体在图谱中确实无边或仅弱连接（数据一致性），点击可定位。
- `AC-US-SYN-07-04`：相关性数字旁必有红问号（`M_SYNTH_COLLAB_OUTPUT_CORR` D1 missing，Q-SYNTH-03）+ 🧪；结论文本数值与图表一致。
- `AC-US-SYN-07-05`："生成协同效率报告"触发系统报告面（复用既有 data-system-report-trigger 机制），不新造报告弹窗。

不包含：协同度真实计算模型与策略建议生成算法（Q-SYNTH-03）；报告导出格式定制。

## 5. 跨模块契约

| 契约 | 方向 | 语义 |
| --- | --- | --- |
| `CT-SYN-01` | SYNTH-REGION → E-31 企业发展 | 协同图谱企业节点 → `/enterprise-center/profile/:enterpriseCode` 统一企业画像整页（复用 `buildEnterpriseProfileUrl` 约定；实体 ID 取企业库 `ENTERPRISE_LIST` 真实 ID） |
| `CT-SYN-02` | SYNTH-REGION → E7 服务机构分析 | 协同图谱服务机构节点 → `/service/institution-judgment?org=<svc-org-id>`（E7 US-SVC-ORG-03 画像抽屉直达约定；实体 ID 取 `SERVICE_ORGS` 真实 ID） |
| `CT-SYN-03` | SYNTH-REGION → 系统报告面 | "生成分析报告 / 协同效率报告"按钮统一挂 `data-system-report-trigger`，由系统面收口 |

对比篮判断：SYS-COMPARE-WORKSPACE 语义中篮内对象为"可横向对比的实体"（企业 / 机构）；区域（region）是分析口径而非实体，活力页排名榜已内置区域横向对比，**region 不入系统篮**（避免语义混淆）。图谱内企业 / 服务机构节点的对比需求由各自模块（ENT-COMPARE / E7 US-08）承接，本叶子不重复建篮。
