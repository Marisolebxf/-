## 1. 全局 Token 合同（Design.md 落地子集）

### 1.1 色彩

| Token / 语义 | 色值 | ZMATE 用法 |
| --- | --- | --- |
| 页面底 | `#D8E7FC` | 创作壳 / Hub / 各站统一页底 |
| 主面板 | `rgba(255,255,255,0.8)` / `#FFFFFF` | 左轨、中工作区、右报告宿主卡片 |
| 主色 / Primary | `#165DFF` | 主 CTA、当前阶段、链接、焦点环 |
| Primary soft | `#E8F3FF` | 选中行底、阶段「当前」Chip 底 |
| Primary hover | `#4080FF` | 主按钮 hover |
| 主/次/弱文字 | `#1D2129` / `#4E5969` / `#86909C` | 标题 / 说明 / 占位与禁用 |
| 边框 | `#E5E6EB` | 卡片、输入、分割 |
| 成功 | `#00B42A` / `#E8FFEA` | 阶段「完成」Chip、Judge PASS |
| 警示 | `#FF7D00` / `#FFF7E8` | `known_gaps`、跳过辩论缺口标记、四态「待*」 |
| 错误 | `#F53F3F` / `#FFECE8` | `failed` 条、Judge `compliance_fail` |
| 锁定灰 | 文字 `#86909C` + 底 `#F2F3F5` | `locked` 阶段行；禁强进 |

**禁止**：紫蓝渐变主色、大面积深蓝/黑底、把合规 FAIL 做成「辩论败方」红胜负样式、假 live 绿冒充 D4。

### 1.2 间距 / 圆角 / 控件

| 项 | 值 | 落点 |
| --- | --- | --- |
| 间距阶梯 | `4 / 8 / 12 / 16 / 24 / 32` | 字段 gap 默认 `16px`；卡片 padding `16px`；大区块 `24px`；左导航行间 `4–8px` |
| 控件高 | `32px` | Select / Button / Checkbox 行 / 阶段导航行 / Chip 行高 |
| 圆角 | 输入/按钮 `2–4px`；面板/卡 `8–12px`；Chip `999px` 或 `12px` | 工作台风格，禁超大消费级圆角 |
| 字号 | 正文 `14px/22px`；卡标题 `16px`；模块标题 `18px`；辅助 `12px` | 禁海报巨字 |
| 三栏分屏 | 左阶段轨建议 `200–240px` · 中 flex · 右报告宿主 `360–420px`（中屏） | Hub 与各 Agent 站共用壳 |
| 对抗审查抽屉（V3 降级） | `30vw` / min `480` / max `640` | 挂报告旁，非独立强制页 |

### 1.3 Arco 选型边界（与 WF §14 对齐）

| 场景 | 组件 | 禁止 |
| --- | --- | --- |
| Query | `Input.TextArea` | 原生 textarea 私有皮肤 |
| 报告类型 | `Select` 高 32px | — |
| Skill 已安装 | `Tag` / Chip | 与「本次使用」合成一枚 |
| Skill 本次使用 | `Checkbox` | 静默等同已安装 |
| 主 CTA | `Button` type=primary | 一键跑完全链按钮 |
| 阶段态 | `Tag` + Tooltip | 仅靠色无文案 |
| 项目轨 | `Tree` / 列表 32px 行 | 当二级菜单删改仓内专题菜单 |
| 人闸确认 | 页内 primary 按钮即可 | 非必须强模态 |
| 图标 | `@arco-design/web-react/icon` | emoji 表状态（评审 Mock 角标除外，走评审层约定） |

## 2. 统一分屏壳视觉合同（Hub + 各站）

```text
┌─ medium · 页底 #D8E7FC · 外距 16–24 ───────────────────────────────┐
│ 顶栏 56–64px：返回壳 · run 摘要 · 阶段 Chip · [评审开关=用户面板]   │
├─ 左 200–240 ─┬─ 中工作区（白/半透明面板）─┬─ 右 360–420 报告宿主 ─┤
│ 阶段导航 32px │ 本站内容 · padding 16     │ 等待文案 / 占位骨架 /  │
│ 锁=灰+Tooltip │                            │ 终稿只读入口          │
└──────────────┴────────────────────────────┴───────────────────────┘
```

| 区 | 视觉 | 禁止 |
| --- | --- | --- |
| 顶栏 | 白/半透明底；返回为文字按钮+图标；阶段 Chip 当前=`#E8F3FF`+`#165DFF` | 在顶栏放「一键跑完」 |
| 左导航 | 行高 32px；当前项浅蓝底；锁定项灰字+锁图标；完成可用成功浅底点 | 锁定项可点进并跳过人闸 |
| 中区 | 白卡 `8–12px` 圆角、`1px #E5E6EB`；标题 16–18px | 露思维链 / CoT 长文 |
| 右宿主 | 等待态：居中弱文案 `#86909C`；生成中：骨架条，**不出正文**；完成后：只读入口按钮 | 生成中渲染未完成终稿 |

## 3. 关键帧对照 WF（视觉合同）

> 行为语义以 WF 为准；本节只定 **看起来像什么**。帧覆盖与 WF §1 清单一致。

### 3.1 F-ZMATE-SHELL 创作壳 · `/zmate-strategy-demo`

| 区块 | 视觉合同 |
| --- | --- |
| 布局 | 左项目轨（两级树）+ 右创作主区；页底 `#D8E7FC` |
| 项目轨 | 文件夹/任务行 32px；状态 Chip：空/进行/失败用 §5 |
| Query | 多行 TextArea；必填空态占位弱文字；通过后主 CTA 可点 |
| 报告类型 | Select 32px，必选 |
| 专家入口 | 卡片网格：白底、标题 14–16px、进入示意；hover `#F2F3F5` |
| Skill | **已安装** = Tag 只读清单；**本次使用** = Checkbox 分离；取消后不得残留时间线调用示意 |
| 主 CTA | 「创建报告任务」primary `#165DFF` 32px；loading 态禁用双击 |

**状态色**：empty 引导；running 按钮 loading；failed 顶/底错误条 `#FFECE8`+重试。

### 3.2 F-ZMATE-HUB Graph Hub · `/run/:runId`

| 区块 | 视觉合同 |
| --- | --- |
| 职责视觉 | 中区仅「当前站职责一句话 + 解锁条件 + 进入当前站」；**无**进度假 %、**无**一键跑完 |
| 阶段列表 | 澄清 → Planner → 辩论∥切片（同级）→ Seeker → Writer → Judge |
| 并行示意 | 「辩论 ∥ 切片」同一组标题；两入口均解锁后可点，互不冒充制品色标 |
| 右宿主 | 澄清未确认 →「等待需求确认」；生成中占位；Judge 后终稿只读入口 |

### 3.3 F-ZMATE-CLARIFY 澄清人闸 · `…/clarify`

| 区块 | 视觉合同 |
| --- | --- |
| 澄清卡 | 逐步字段（对象/行业/范围/时间/受众/深度/决策要点）；label 14px；控件 32px |
| 研判卡列表 | 卡面含 `slice_id` 示意位；空态 CTA「生成研判卡」 |
| 人闸 | 「确认需求」primary；未确认右侧固定等待文案；后续站锁 |
| 评审开时 | 术语对照卡挂载（卷宗 ≠ 切片）见 §6 |

### 3.4 F-ZMATE-PLANNER · `…/planner`

| 区块 | 视觉合同 |
| --- | --- |
| 任务树 | 章节/组件树；组件开关 = 只读 Chip，禁做成可乱改 metric-registry 入口 |
| 切片摘要 | 次级卡，弱边框 |
| 禁止视觉 | 思维链气泡、假「AI 思考中」长文 |

完成后：Hub 同时点亮辩论与切片入口（成功色点）。

### 3.5 F-ZMATE-DEBATE 辩论∥卷宗 · `…/debate`

| 区块 | 视觉合同 |
| --- | --- |
| 顶提示条 | 警示浅底：本站对象=**辩论知识卷宗**；无「胜负/采信方」文案 |
| 中左 | 正/反论点流：两列或 Tab；论点卡 padding 12–16 |
| 中右 | 卷宗三层（结论/推理/信源）分区；结束后整区只读灰底说明 |
| 操作 | 「新一轮」「引导轮」次按钮；「结束辩论」primary 或强调 |

与切片站并行：**禁止**把卷宗卡做成研判卡样式（研判卡用独立标题区+`slice_id`）。

### 3.6 F-ZMATE-SLICE 切片∥研判卡 · `…/slice`

| 区块 | 视觉合同 |
| --- | --- |
| 顶提示 | 本站=专题切片/研判卡（≠ 卷宗） |
| 研判卡 | 卡面标题 + `slice_id`；方面域摘要 |
| 指标四态表 | 可用 / 待建 / 待真接 / 待外网补数；**不得**整表成功绿冒充 live |
| 四态色 | 可用→成功浅底；三类「待*」→警示浅底+文案；Mock 角标仅评审开 |
| CTA | 「批准切片指标」primary → 解锁 Seeker |

### 3.7 F-ZMATE-SEEKER · `…/seeker`

| 区块 | 视觉合同 |
| --- | --- |
| 域列表 | 展示态势/产业链/政策/企业… 卡片或列表；Demo 可串行模拟并行（状态 Chip 示意） |
| 证据包 | 摘要清单；`known_gaps` 用警示条显式列出 |
| 锁定 | 切片未批准：整站灰+回切片 CTA |

### 3.8 F-ZMATE-WRITER · `…/writer`

| 区块 | 视觉合同 |
| --- | --- |
| 准入条 | 未满足条件时警示条写清辩论/取数条件 |
| 装配 | 四层十组件大纲（勾选或只读 Chip）；章节草稿宿主 |
| 溯源角标 | 关键结论旁占位：原文 / 口径 / 推断（图标+Tooltip；评审开可挂 id） |
| 右宿主 | **running 禁止出正文**；完成后可开结构草稿（仍须经 Judge） |

### 3.9 F-ZMATE-JUDGE · `…/judge`

| 区块 | 视觉合同 |
| --- | --- |
| 顶标注 | 「合规 Judge · Default-FAIL · ≠ 战略胜负裁判」 |
| 规则清单 | 缺 metric_id / 假 live / 绕过人闸… 列表 |
| PASS | 成功面板 + 右侧终稿只读 |
| FAIL | `compliance_fail` 错误面板 + 原因 + known_gaps + 回环按钮（回澄清/切片/Writer） |
| 服务失败 | `failed` 与合规 FAIL **文案分区**，勿混称 |

### 3.10 F-ZMATE-TASK-REDIR · `/task/:id`

视觉：瞬时过渡即可；落 Hub 未完成阶段，不单独高保真页。

## 4. 主路径视觉 walkthrough（对照 WF §13）

| 路径 | 视觉要点 |
| --- | --- |
| A · V1 最短 | 壳创建 → Hub → 澄清确认+研判卡 → Planner 示意 → Hub 标记跳过辩论缺口（警示 Chip）→ Writer 占位 → Judge 最小规则 → 右终稿可读 |
| B · Demo 完整 | Planner 后分站进入辩论与切片（两入口可点验）→ Seeker → Writer → Judge；禁单进度条跑完 |
| C · 项目轨恢复 | 轨内点任务 → Hub 停在未完成站；锁站仍灰 |

## 6. 内部评审模式 · 仅页特有（对齐 WF §12）

> 入口：**壳层**右上角用户/角色面板全局开关；页内不重复造入口。  
> 本文只列 **ZMATE 页特有**；通用自闸 / 关闭零泄漏 / 角标并存序不复制。

| mount_id | 帧 | 开启可见 | 关闭后 |
| --- | --- | --- | --- |
| `ZMATE-SHELL-HUB-TRACE` | SHELL / HUB | §3 三轴、§9.2 路由对照、阶段契约、非目标 | 无条款字样泄漏 |
| `ZMATE-TERM-DOSSIER-VS-SLICE` | CLARIFY / DEBATE / SLICE | 术语对照卡（卷宗 vs 切片/研判卡） | 隐藏 |
| `ZMATE-SLICE-FOUR-STATE` | SLICE | 四态说明 + Mock / known_gaps / 禁假 live | 业务可留数值但角标自闸 |
| `ZMATE-JUDGE-DEFAULT-FAIL` | JUDGE | Default-FAIL 规则 + ≠ 胜负裁判 | 隐藏规则评审块 |
| `ZMATE-REPORT-TRACE` | 报告宿主 | `slice_id` / `metric_id` 或 gap、HV-11 结构示意 | DOM 零泄漏 id/GAP |

关闭后保留：业务 Query、报告正文、任务状态、阶段导航。
