## 0. 结论（一句话）

把主工作台做成真正的对话应用壳：**左栏消息滚动 + 底栏固定；右栏「过程|终稿」双 Tab 头始终钉在右栏顶，内容只在右栏内独立滚动**——禁止右栏空白、Tab 头悬空无内容、高度塌缩、整页代替分栏滚。

## 1. 用户反馈 → 体验问题映射

| # | 用户说法 / 截图现象 | 体验判定 | 根因方向（布局，非业务） |
|---|---|---|---|
| F1 | 「过程/终稿」内容必须始终在右侧区域；出现大片白空白 | **P0** 右栏内容逃逸或高度塌成 0 | `.zmate-duo` / 右栏 / Arco Tabs 未形成「定高 flex 链」；`minmax(0,1fr)` 未吃满视口 |
| F2 | 右侧必须有独立滚动条 | **P0** 现多为整页滚或右栏不滚 | Tab pane / `.zmate-duo__process|final` 未独占 `overflow:auto`；滚动落在 `body` |
| F3 | 要更像 Cursor / 豆包 | **P0** 对话壳习惯未闭环 | 左底栏（Hub + 默认跑完 + 输入）须钉底；消息区独占中部滚动；双栏等高贴齐 |
| F4 | 左栏与右栏之间出现异常竖向空隙（红框） | **P1** 双栏未贴齐 / gap 过大 / 右栏未撑满 | grid 列未 `1fr` 吃满；父级 padding/gap 叠出「空带」感 |
| F5 | Tab 头可见但下方几乎空（或仅一行说明） | **P0** 「有 Tab 无板」 | 过程 Tab 须默认渲染**子 Agent 状态板**（非空壳）；终稿未就绪须有明确空态，禁止纯白 |

参考截图：过程 Tab 激活态已正确（主蓝字 + 底指示条）；定稿要求该 Tab 头**钉死在右栏顶**，其下始终有可滚动内容区。

## 3. 目标信息架构（对话应用习惯）

```text
┌─ 页底 #D8E7FC · 视口定高（减去系统壳顶栏） ─────────────────────────┐
│ 顶条（返回 · 标题 · Tag）— 非滚动                                    │
├─ 左栏 chat（白卡）──────────────┬─ 右栏 right（白卡）───────────────┤
│ 头：对话                        │ 【钉顶】过程 | 终稿   ← 始终可见  │
│ ─────────────────────────────── │ ─────────────────────────────── │
│ 【唯一滚】消息区 .msgs          │ 【唯一滚】Tab 内容                │
│  气泡 / 流式 / Plan 卡          │  过程：Agent 状态板 + 分站入口    │
│ ─────────────────────────────── │  终稿：目录开关 + 正文/空态       │
│ 【钉底】actions                 │                                   │
│  Hub · 协作枢纽 | 默认跑完      │                                   │
│ 【钉底】composer 输入 + 发送    │                                   │
└─────────────────────────────────┴───────────────────────────────────┘
```

### 3.1 行为合同（交互语义，FE 不得改反）

| 控件 | 必须 | 禁止 |
|---|---|---|
| Graph Hub · 协作枢纽 | **只** `setRightTab("process")`，右栏切到过程并露出状态板 | 跳到独立全屏 Hub 页替代右栏；清空右栏 |
| 默认跑完 | 流式编排输出落在**左对话**；过程板可同步刷新 Agent 态 | 把长流水日志只丢到右栏导致左空 |
| 过程 Tab | 主视觉 = 子 Agent 状态板；次 = 分站入口 | 仅一行灰字、无板 |
| 终稿 Tab | 顶工具条「显示目录」Switch；下接正文或空态/生成中文案 | 未生成时纯白；生成中出未完成全文 |
| 跑完后 | 可自动切「终稿」；过程 Tab 仍可回看 | 自动切走后过程内容消失或右栏塌空 |

## 4. 布局工程合同（高度链 · 给 FE 的硬约束）

> 现象「右栏空白 / Tab 悬空」在 CSS 上几乎都是：**祖先未定高 → flex/grid 子项 `height:auto` → Tabs content 高度塌缩 → 内容挤出或不可见**。

### 4.1 定高链（必须贯通）

1. 页面路由容器对工作台提供**可用高度**（`height: 100%` 或 `calc(100vh - 系统顶栏)`），禁止只靠内容撑高后整页滚。  
2. `.zmate-duo`：`display:grid`；行 = `顶条 | 1fr`；列 = `minmax(320px, 40%~42%) | minmax(0, 1fr)`；**自身高度 = 可用高度**（`height` 或 `min-height` + `max-height` 同值更稳）；`overflow: hidden`。  
3. `.zmate-duo__chat` / `__right`：`min-height:0`；`display:flex; flex-direction:column; overflow:hidden`；两栏**等高**贴齐，栏间 gap 建议 `8–12px`（避免「中间空一条」）。  
4. 右栏 Tabs：外壳 `flex:1; min-height:0`；**Tab 头不参与滚动**；`.arco-tabs-content` / 激活 pane `flex:1; min-height:0; overflow:auto`（或内层 `.zmate-duo__process|final` 独占 `overflow:auto`）。  
5. 左栏：`.zmate-duo__msgs` = `flex:1; min-height:0; overflow:auto`；`.zmate-duo__actions` + `__composer` = `flex-shrink:0` 钉底。

### 4.2 滚动边界（验收必测）

| 区域 | 滚动 | 验收 |
|---|---|---|
| 整页 `body` | **不滚**（工作台态） | 拉长消息 / 过程板 / 终稿，页面外框不动 |
| 左 `.msgs` | 独立滚 | 出现左栏滚动条；底栏始终可见 |
| 右 Tab 内容 | 独立滚 | 出现右栏滚动条；「过程\|终稿」头始终可见 |
| Tab 头 | 不滚 | 右栏内容滚时头不跟着走 |

### 4.3 空态 / 防白屏

| 态 | 右栏必须可见 |
|---|---|
| 初始 / 未跑 | 过程 Tab：完整 Agent 板（多为「待启动」）+ 分站入口；终稿：空态文案指引点「默认跑完」 |
| 流式中 | 过程：running/done 行实时变；终稿：可显示「生成中 · 请看左侧对话」 |
| 已收口 | 过程：7/7 板 + 回看；终稿：目录开关 + 全文 |

**禁止**：右栏只有 Tab 头 + 大片纯白；禁止过程内容渲染到左栏气泡替代右栏板。

## 5. 给 frontend 的可执行硬改清单（5–8 条）

> 实现文件：`ZmateWorkspacePage.tsx`（结构/类名）+ `zmate-strategy.css`（高度链/滚动）。**不改** `useRun` / `workspaceStore` 业务流，除非仅为挂载 DOM 类名。

1. **右栏固定双 Tab 始终可见**  
   「过程 | 终稿」钉在 `.zmate-duo__right` 顶部；`Tabs` 头 `flex-shrink:0`；激活色 `#165DFF` + 底指示条（Design 一级 Tab）。切换只换右栏内容，不卸载左栏。

2. **右栏独立 `overflow:auto`**  
   打通定高链（§4.1）；滚动只发生在 Tab 内容容器；**禁止**依赖整页滚动展示过程板/终稿。验收：右栏单独出滚动条。

3. **左栏消息滚 + 底栏钉死**  
   `.zmate-duo__msgs` 独占中部滚动；`actions`（Hub + 默认跑完）与 `composer`（输入 + 发送 32px）`flex-shrink:0` 贴底。验收：消息再长，底栏不随消息滚走。

4. **Hub 只切右栏「过程」**  
   `Graph Hub · 协作枢纽` → `rightTab=process`；右栏必须立刻露出子 Agent 状态板（可含分站入口）。禁止导航走丢右栏内容。

5. **默认跑完流式只在左对话**  
   编排进度/Plan 决策卡留在左气泡区；右栏过程板可同步状态色，但不替代左栏流式。跑完可自动切「终稿」，过程 Tab 内容仍在。

6. **过程 Tab 内容合同**  
   主：子 Agent 状态板（pending/running/done/skipped）；次：分站入口。默认进入工作台时过程 Tab 不得空白——至少渲染完整板。

7. **终稿 Tab 内容合同**  
   顶：目录 Switch 工具条；下：`FinalReportView` 或明确空态/生成中文案。未就绪禁止纯白。

8. **防高度塌缩 / 防栏间空带**  
   双栏 `min-height:0` + 父级定高；grid 右列 `minmax(0,1fr)` 吃满；栏间 gap ≤12px；小屏可改上下堆叠但各自仍独立滚。自检：刷新后右栏首屏可见 Tab 头 + 过程板首屏内容，无「悬空 Tab」。
