## 1. 模块边界

- **解决的问题**：在 Zmate（AaaS）壳上，让四类服务对象用自然语言命题发起战略咨询报告任务，经**可见的多 Agent Graph 协作**（人在回路、禁止黑盒一步成文）得到可溯源、可合规闸的装配报告。
- **承接内容**：
  - **创作壳**（项目轨两级 / Query / 报告类型 / 专家入口 / Skill「已安装 ≠ 本次使用」）
  - **Graph Hub**（协作枢纽：阶段进度、下一站解锁条件；**禁止**单页假进度跑完全链）
  - **Agent 协作站点**（澄清 → Planner → 辩论 ∥ 切片 → Seeker → Writer/Assembler → 合规 Judge）
  - **报告阅读区**（右侧：等待确认 / 生成中占位 / 完成后组件结构 + 基础溯源角标）
  - **术语强制**：辩论知识卷宗 ≠ 专题切片/研判卡；合规 Judge ≠ 战略胜负裁判
  - **内部评审模式 · 页特有差异**（仅本模块挂载；不复制通用规则）
- **不承接内容**：
  - 门户「研究报告 / 洞察报告 / 战略咨询报告」分类浏览、定向推送、成果库运营（另轨消费本台产出）
  - 专题八域分析工作区共性页（`05-功能-战略分析`）≠ 本工作台
  - 从零自研 Agent 运行时 / 替代 Zmate
  - 系统对比篮 / 系统任务浮层（企业·产业·政策共享壳）作为本台主发起路径
  - V1 强制完整辩论主舞台或指标进化闭环作为 11-30 阻断门禁（Demo 仍须可点验协作）
  - Agent 静默改绿 D1–D4、假 live、绕过人闸冒充已批准
  - Demo 直连 `lumen-*` 正式后端（D12）
  - 本单高保真视觉稿（属 Wireframe / 视觉叶）

**Agent 协作主序（与 harness Graph 一致）**：

```text
创作壳创建任务
  → Hub
  → 澄清（人闸：确认需求前禁 autoRun；右侧「等待需求确认」）
  → Planner（任务树 / 组件开关摘要；不露思维链）
  → 辩论 ∥ 切片（并行入口；术语对象分离）
  → Seeker（切片批准后取数；Demo 可串行模拟并行）
  → Writer/Assembler（须辩论结束（若启用）+ 取数齐备或显式缺口）
  → 合规 Judge（Default-FAIL；≠ 战略胜负裁判）
  → 报告可读 / 带着 known_gaps 交付
```

- **V1 最短路径**：澄清确认 + 研判卡可见后，可跳过完整辩论，经 Planner 示意进入 Writer 占位 → Judge 最小规则 → 报告可读（USM 主路径 A）。  
- **Demo 完整可点验**：主路径 B 必须能分站进入辩论与切片，禁止「一点即跑完」。  
- **菜单铁律（demo-ui-topic）**：仅**增量**挂「战略报告 Demo」入口；禁止删改仓内既有专题菜单集合。

### 3.1 术语合同（IA 强制）

| 正式名 | 英文 / ID | IA 落点 | 禁止混称 |
| --- | --- | --- | --- |
| **专题切片** | `ThematicSlice` / `slice_id` | `/slice` 站主对象；方面域 + 指标需求 | 勿叫「卷宗」 |
| **研判卡** | `ScopeCard` | 澄清确认后绑定/生成；切片的 UI 卡片形态 | — |
| **辩论知识卷宗** | Debate Dossier | `/debate` 站；结论 / 推理 / 信源三层；结束后只读 | 勿叫专题切片/研判卡 |
| **合规 Judge** | Compliance Judge | `/judge` 站；缺 id / 假 live / 绕过人闸 → Default-FAIL | ≠ 战略胜负裁判 |
| **对抗审查** | Adversarial Review | V3；Demo 可降级抽屉壳 + 静态清单（可挂在报告阅读旁，非独立强制二级页） | ≠ 研究阶段 Judge |

### 3.2 Graph Hub 与分站解锁合同

| 项 | 合同 |
| --- | --- |
| Hub 职责 | **只**展示阶段、制品交接摘要、解锁条件；不在 Hub 内静默执行全链 Agent |
| 人闸 | 澄清未「确认需求」→ 禁止进入后续自动长跑；右侧保持「等待需求确认」 |
| 并行 | Planner 完成后：`/debate` 与 `/slice` **均可进入**（∥）；互不冒充对方制品 |
| Writer 准入 | 若启用辩论：须「结束辩论」或产品允许的显式跳过（标记缺口）；取数齐备或显式 `known_gaps` |
| 生成中 | 右侧**不**渲染未完成正文 |
| 恢复 | 项目轨 / `task/:id` → Hub，停在上次未完成阶段，不得跳过人闸 |
| 禁止 | 单页 autoRun 假进度；安装 Skill 静默当成本次使用 |

## 5. 主路径导航

### 5.1 主路径 A · V1 最短（可独立走完）

```text
创作壳 → 创建任务 → Hub → 澄清确认 → 研判卡可见
  → Planner 示意 →（可跳过完整辩论）→ Writer 占位装配
  → Judge 最小规则 → 右侧报告可读 + 基础溯源
```

### 5.2 主路径 B · Demo 完整协作可点验

```text
同 A 至研判卡
  → Planner
  → 并行进入 辩论站 ∥ 切片站
  → Seeker → Writer（条件满足）→ Judge → 终稿
```

### 5.3 主路径 C · 项目轨恢复

```text
项目轨打开既有任务 → Hub（停在未完成阶段）→ 继续人闸 / 分站
```

### 5.4 导航规则（摘要）

| 规则 | 说明 |
| --- | --- |
| 前进 | 仅当当前站人闸/制品条件满足；Hub 显示下一站 |
| 回看 | 已完成站只读回看；不得静默重开并跳过已锁定人闸 |
| 并行 | 仅 Planner 后辩论∥切片；其余保持序贯 |
| 出口 | 本台不承接门户推送；完成后报告可被另轨消费 |
