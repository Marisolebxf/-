# 05 · 科技政策跟踪（DS-10～12 + 核增）

条款：`1.1.1.1.4.2`。核增：`科技信息展示系统(政策对比功能升级)核增需求.md`。  
CROSS-KG §8.2。

## 1. 需求来源

DS-10 全景、DS-11 分析评价、DS-12 效果推演。核增四叶子：数据治理、智能拆解、多维对比、智能研报。需求 Owner：外国专家和科技人才处（核增）。

## 2. 需求分析

用户浏览政策多维目录并看到适用企业/机构；阅读分析/解读报告；在明确假设下看推演结果（不宣称全社会因果）。核增补治理与拆解、对比工作区、研报生成。

## 3. 功能设计

全景：筛选 + 列表 + 可选政策挂接子图。对比：同一政策集多维，见 `SYS-COMPARE-WORKSPACE` 交叉引用。推演与研报：Job，阶段文案，不可变结果。治理/拆解：数据与结构化条款，偏后台+展示消费。
