# 09 · 科技成果展示（DS-25～29）

条款：`1.1.1.1.4.6`。出口：`lumen-ui-science-pc` **`/display/v1/**`**（成果走 `/display/v1/outcome/**`）。  
场景行真源：CROSS-KG `01` §8.5。

## 1. 需求来源

catalog DS-25～29：软科学 GIS+图表；创新生态（载体）；时空演进；仪器共享对接；孵化载体（分布/入驻/政策/绩效）。

## 2. 需求分析

用户浏览软科学成果空间分布与图表；看载体生态与孵化绩效；看时空变化；看大型仪器对接状态。软科学口径未绿（Q001～Q007）须 ⚠️。载体未升格前不当独立点类。

## 3. 功能设计

成果页以 GIS/图表为主。载体：卡片 + GIS，关系挂运营方/入驻企业/政策。DS-27 时空演进 = GIS+ADS 时间过滤，**不是**专题 B 面时间轴。DS-28 只展示对接结果，无预约闭环。
