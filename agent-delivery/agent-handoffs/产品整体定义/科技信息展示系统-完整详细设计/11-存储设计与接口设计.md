## 11.1 总则（展示侧）

展示不另建图库、不另建七要素 stores。页面读：

| 类 | 落点 | 经谁 |
| --- | --- | --- |
| 指标 / 驾驶舱数字 | MySQL ADS + metrics catalog | Java 只读 |
| 嵌图 / 知识图谱工作台 | Nebula（Python 适配）同一 A 面 JSON | `gkxlumen-topic` graph 资源 |
| 检索列表 | ES 派生 | Java → Python 门面 |
| GIS 图层 | 配置 + ADS 坐标/行政区划 | display BFF 拼装；**不是** B 面切面冻坐标 |
| 创新监测 | innov 域 ADS/ES | `gkxlumen-innov` |
| 运营视窗 DS-17～20 | 平台运营库 / 日志 | 非七要素图 |
| 报告 / 导出 | MinIO | 下载门面 |

禁止：display 专有 graph schema；前端直连 nGQL / Python；Java 扫 ODS/DWD。

## 11.3 接口清单（非正式）

调用链：网关 → `gkxlumen-display`（拼装）和/或共享 `gkxlumen-topic` / `gkxlumen-metrics`；DS-04 → `gkxlumen-innov`。  
下游 Python 仍只走 `/internal/*`。

| 面 | Java 前缀（建议） | 说明 |
| --- | --- | --- |
| 展示拼装 | `/display/v1/**` | 薄 BFF：GIS 配置 + metrics + 可选 graph/view；**禁止**第二套图适配 |
| 创新监测 | `/innov/v1/**` | M1；SQL 发挥见 as-built |
| A 图（复用） | `/topic/v1/{element}/graph/**` | DS-21～24 与嵌图；与专题同一资源 |
| 指标 | `/metrics/v1/**` | D9；innov 指标走 innov catalog，口径仍 D9 |
| 政策 | `/display/v1/policy/**` 或复用 `/topic/v1/policy/**` | 方案 A；Job 与专题 `.8.6` **分键** |
| 人才 / 成果 / 服务 | `/display/v1/talent|outcome|service/**` | 内部仍调 topic 同要素资源 |
| 数据资源运营 | `/display/v1/data-ops/**` | 运营库/日志，不扫全图 |
| Job | 已有 analysis/jobs 前缀 | 仅 DS-11/12/16 与 PC-2/4 等已标 G3 |

错误模型同专题 11.6：空 **200**；未建 **501**；无权 **4xx**；薄嵌图 **200 + honesty.payload_thin**。
