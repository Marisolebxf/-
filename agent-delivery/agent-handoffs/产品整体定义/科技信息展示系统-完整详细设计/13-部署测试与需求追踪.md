# 13 · 部署、测试与需求追踪

## 13.1 部署拓扑（lumen）

| 服务 | 仓 |
| --- | --- |
| 展示前端 PC | `lumen-ui-science-pc`（`/display/**`、`/innov`） |
| 展示前端移动 | `lumen-ui-science-mobile`（同一 API） |
| 网关 / display / innov / topic / metrics | `lumen-svc-platform` |
| 算法 / ETL / 检索门面 | `lumen-algo-py` · `lumen-etl-es-py` · `lumen-topic-py` |
| 管理 UI | `lumen-ui-admin`（指数智库后台另叶；不嵌亿集） |

K8s 服务名以 helm 为准。禁止 helm 回落 demo。专题前端 `lumen-ui-topic` 不在本套部署范围。

## 13.2 测试策略

| 类 | 必测 |
| --- | --- |
| 接口 | 空 200、未实现 501、无权 4xx |
| 嵌图 | 可薄可空；失败不挡驾驶舱数字 |
| GIS | DS-27 不用 B 面时间轴接口 |
| Job | 离开可恢复；结果不可变；与专题政策 Job **分键** |
| D12 | lumen 环境无 demo 依赖（含 `VITE_*`） |
| 评审模式 | 关闭后无内部 ID 泄漏 |
| 存储 | Java 不扫 ODS/DWD；不直连 nGQL；无 display 专有图库 |
| 运营视窗 | DS-17～20 不要求全要素图谱验收 |

性能基线：联调后回填，不在设计期编造毫秒数。
