## 13.1 部署拓扑（lumen）

| 服务 | 仓 | 说明 |
| --- | --- | --- |
| 展示前端 PC | `lumen-ui-science-pc`（**`/display/v1/**`**） | 对外唯一前缀（A4 裁决） |
| 展示前端移动 | `lumen-ui-science-mobile`（同一 API） | |
| `gkxlumen-gateway` | `lumen-svc-platform` | 统一网关（D5） |
| `gkxlumen-display` | `lumen-svc-platform` | **聚合 BFF**（A10）：页面聚合 / 读缓存 / 分区降级 / 就绪度注入 |
| `gkxlumen-element` **:7082** | `lumen-svc-platform` | 展示侧自建（A1），`@Inner` 不对外 |
| `gkxlumen-graph` **:7083** | `lumen-svc-platform` | 展示侧自建（A1），`@Inner`；图谱用现网 space **`entan`** |
| `gkxlumen-datacatalog` **:7084** | `lumen-svc-platform` | 展示侧自建（A1），`@Inner` |
| `gkxlumen-innov` | `lumen-svc-platform` | M1 创新监测（**过渡复用**） |
| `gkxlumen-metrics` | `lumen-svc-platform` | D9 指标唯一真源（共享） |
| `gkxlumen-topic-async-service` | `lumen-svc-platform` | **唯一例外复用**：异步任务（A1-b / A15） |
| 算法 / ETL / 检索门面 | `lumen-algo-py` · `lumen-etl-es-py` · `lumen-topic-py` | |
| 管理 UI | `lumen-ui-admin`（指数智库后台另叶；不嵌亿集） | |

K8s 服务名以 helm 为准。禁止 helm 回落 demo。专题前端 `lumen-ui-topic` 不在本套部署范围。
