# 04 · 科技发展态势（DS-01～09）

条款：`1.1.1.1.4.1`。出口：`lumen-ui-science-pc` **`/display/v1/**`** + `/innov/v1/**`（DS-04 创新监测，过渡复用）。  
场景行真源：CROSS-KG `01` §8.1。

## 1. 需求来源

catalog DS-01～09。总驾驶舱 + 技术/监测/评估/指数/规划支撑。

## 2. 需求分析

领导要全域一张图 + GIS；技术全景看技术点而非论文点；监测三页（全球/湾区/深圳）以指标对标为主；指数只做展示侧；规划页提供趋势与预警，不编制规划文本。

## 3. 功能设计

信息架构：态势一级菜单下九页。DS-01 为总览，可下钻到其余叶或专题。DS-04 路由 `/innov`（已有 M1）。DS-08 不进专家智库后台。

## 5. 详细实现

display BFF 拼 GIS 图层配置 + metrics catalog + 可选 `graph/view`。innov 走 `gkxlumen-innov`，SQL/表见 innov 承接包（内容发挥以 as-built 为准）。  
DS-02：技术点主键归一键；论文专利下钻列表，不进点类型。

## 6. 非功能增量

驾驶舱图失败不挡 KPI。GIS 与图坐标两套，不以切面冻坐标驱动态势地图。

## 7. 明确不做
