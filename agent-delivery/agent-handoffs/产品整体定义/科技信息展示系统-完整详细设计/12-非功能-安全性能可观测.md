## 12.1 性能（展示增量）

| 类 | 要求 |
| --- | --- |
| 驾驶舱 | 指标可先于嵌图；图失败不挡 KPI |
| GIS | 图层按视野/级别加载；不与全量子图并行拉爆 |
| A 面嵌图 | 默认节点/边上限；超出截断 + honesty |
| innov | 监测页同步读 ADS/ES；预测模型走 501 或 Job，禁止同步重算 |
| 政策对比 | 对比集大小上限；导出异步若超阈值 |
| Job（DS-11/12/16、PC-2/4） | 异步；离开不丢；禁止同步 REST 跑瓶颈模型 |

毫秒基线联调后回填 13 章，设计期不编造。

## 12.2 容量与限流

同专题：导出行数/频率。展示另限 GIS 瓦片/要素查询频控。缓存键含页码/图层/element + 参数 hash（基线 D6）。

## 12.3 安全

同专题 12.3。展示补充：

- DS-17～20 运营视窗权限 **严于** 业务态势页。  
- DS-24 对内赋能只经 Java REST，不把亿集凭证下发前端。  
- 仪器共享（DS-28）只读对接结果，不存对方业务库口令于前端。  
- D12：`lumen-ui-science-pc` / mobile 零 `demo-*` 依赖。

## 12.4 可用性

嵌图可空。G3 未注册 501。降级不用假指数 / 假颠覆标签凑 200。

## 12.5 可观测

OTel 全栈。图响应 `source`。Job `model_id`。前端 `observability.ts`（science-pc / mobile 必加）。GIS 失败与 graph 失败分事件，互不顶替。

## 12.6 前端体验

D8 / D10 指针。`lumen-ui-science-pc` Arco + Design.md。关闭评审模式后 DOM 不泄漏 `metric_id` / `GAP-*`。mobile 适配同一 API，不另造契约。
