## 1. 定位

面向领导与业务人员的 **态势与展示**：GIS、指标、嵌图、检索。深度「生成分析」、产业链时间轴在 **专题系统**。两系统只读 **同一张七要素图**。

## 1.2 在范围

- DS-01～30 每叶一行功能设计（可 M / 501）。  
- 政策对比核增四叶子（挂政策跟踪）。  
- 展示如何复用 topic graph/metrics；innov 监测域。

## 1.3 不在范围

- 专题查询/战略分析/项目/发布/运营/系统管理展开（见专题完整详设）。  
- DS-17～20 另造图点类型（默认运营视窗）。  
- 第二套本体；轨迹引擎；仪器预约闭环。  
- 科技指数后台「智库管理机制」（Q-TINDEX-01：展示侧只做指数可视化）。  
- lumen 打 demo（D12）。

## 1.4 边界

```text
lumen-ui-science-pc
  → gateway
    → gkxlumen-display（页拼装，复用 topic+metrics）
    → gkxlumen-innov（M1 创新监测）
    → gkxlumen-topic / gkxlumen-metrics（共享）
      → Python /internal/*
```

禁止 display 专有图库、前端直连 Python。
