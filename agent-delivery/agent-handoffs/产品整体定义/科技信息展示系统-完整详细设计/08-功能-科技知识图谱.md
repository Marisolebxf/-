# 08 · 科技知识图谱（DS-21～24）

条款：`1.1.1.1.4.5`。用图 **主入口**。出口：`lumen-ui-science-pc` `/display/v1/**`（知识图谱走 `/display/v1/graph/**`）。  
场景行真源：CROSS-KG `01` §8.4 + `03` A 面。

## 1. 需求来源

catalog DS-21～24：分析展示、指标展示、算法展示、服务展示（对内赋能）。

## 2. 需求分析

用户在工作台检索并展开子图；看已注册图指标与规则；看路径/中心性/社群等算法结果（未注册则禁用）；管理员看对内 REST 赋能清单。预测/推荐不是本页默认可跑能力。

## 3. 功能设计

工作台：检索 → 子图 → 详情。算法页只展示结果，不是 IDE。服务页声明赋能清单与权限。未注册能力按钮禁用或 501，禁止静默假网。

## 5. 详细实现

**展示侧自建 `gkxlumen-graph` :7083**（A1 裁决：**不复用专题侧 `gkxlumen-topic` 的 graph 资源**）。

**图谱选型（A8 裁决，2026-10-26）**：用**我方自建图谱，现网 space `entan`**；燕大 `gkx_local_1`（87.54 万实体）**本期不切源、不并行**，后期统一迁移。

前端自绘 G6（Q7）。`weight` 只读。display 不复制 graph controller。
