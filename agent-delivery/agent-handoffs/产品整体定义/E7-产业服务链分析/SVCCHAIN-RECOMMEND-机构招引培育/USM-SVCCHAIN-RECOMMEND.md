围绕用户设定的重点产业方向，完成"理解推荐模型（指标与权重可见可调）→ 生成招引/培育名单（评分、排名、理由/建议）→ 名单输出（导出、送入对比篮）"的决策输出闭环。招引面向外部（非深圳）机构引进，培育面向深圳本土机构扶持。不做链路/图谱/对比分析（ECOSYSTEM 叶子），不做机构集合评估（R1 叶子）。

## 4. 用户故事

### US-SVC-REC-01｜招引模型与指标

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-REC-ATTRACT-MODEL`（7.6.1） |
| `decision_refs` | `Q-SVCCHAIN-05` |
| 产品角色 | `ROLE-SVC-PARK` |
| 依赖 | 无 |
| Frame | `F-SVC-REC-02` |
| 业务结果 | 招引模型四指标（产业匹配度/技术领先性/发展潜力/对外合作意愿）与权重可见可调，合计校验与一键归一可用，配置持久化 |

作为园区招商人员，我想看到并调整招引推荐模型的评估指标与权重，以便让名单排序贴合本次招商目标，同时清楚当前模型是演示口径。

主路径：

1. 招引页签模型配置区展示四指标卡（Bid 7.6.1 列举：产业匹配度、技术领先性、发展潜力、对外合作意愿），每指标显示说明与权重（默认 35/30/20/15）。
2. 权重可调（0-100 整数）；实时显示合计；合计 ≠100% 时"生成名单"禁用并提示差值，提供"按比例归一"。
3. 模型区带 🧪 与 ⚠️（Q-SVCCHAIN-05）；配置持久化，提供"恢复默认权重"。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 权重合计 ≠100% | 禁用生成，红字提示合计与差值 | 手动调整或一键归一 |
| 持久化配置损坏 | 回落默认权重 + Message | 重新调整 |

验收：

- `AC-US-SVC-REC-01-01`：四指标名称与 Bid 7.6.1 列举一致；每指标有说明文案与权重输入。
- `AC-US-SVC-REC-01-02`：合计 ≠100% 时生成按钮禁用且显示差值；"按比例归一"后合计恰为 100。
- `AC-US-SVC-REC-01-03`：权重配置刷新后保留；"恢复默认权重"一键复位。
- `AC-US-SVC-REC-01-04`：模型区带"演示模型口径"可读声明（业务模式）与 ⚠️ Q-SVCCHAIN-05（评审模式）。

不包含：模型的服务端保存与共享；指标增删（招引固定四指标，区别于 R1 技术力模型的自定义维度——理由：7.6.1 为"系统内置模型"表述，未要求用户自定义指标）。

### US-SVC-REC-02｜推荐名单生成（招引）

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-REC-ATTRACT-LIST`（7.6.2） |
| `decision_refs` | `Q-SVCCHAIN-05` |
| 产品角色 | `ROLE-SVC-PARK` |
| 依赖 | US-01 |
| Frame | `F-SVC-REC-02` |
| 业务结果 | 设定产业方向后生成外部机构引进名单（各指标评分、综合排名、推荐理由），名单可复现、可导出 |

作为园区招商人员，我想设定重点发展的产业方向并生成引进机构推荐名单，以便高效锁定高价值招引目标。

主路径：

1. 用户选定重点产业方向（默认取持久化值），点击"生成推荐名单"。
2. 系统按演示口径计算：综合分 = Σ(指标值 × 权重)，产业匹配度取该机构对选定产业的匹配值；输出排名列表（名次、机构、城市、各指标分、综合分 ⓘ⚠️🧪、推荐理由 🧪）。
3. 推荐理由为规则生成文本（引用该机构最高分指标与匹配度数值，可与列表核对）。
4. 行内无额外动作；工具栏动作：导出 CSV（含全部列 + 演示口径声明行）。
5. 配置或产业方向变更后结果区提示"配置已变更，请重新生成"；重新生成结果可复现（确定性）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 未生成前进入页签 | 结果区引导空态"设定产业方向并生成名单" | 点击生成 |
| 该产业方向无匹配外部机构（匹配度全为 0） | 名单区显示"当前方向暂无高匹配外部机构"，不硬凑名单 | 更换方向 |
| 配置变更未重新生成 | 结果区顶部黄条提示，旧结果仍可读 | 重新生成 |

验收：

- `AC-US-SVC-REC-02-01`：名单列包含名次/机构/所在城市/四指标分/综合分/推荐理由；综合分 = Σ(指标 × 权重) 与配置一致。
- `AC-US-SVC-REC-02-02`：综合分数字旁必有 ⓘ（`M_SVC_REC_ATTRACT_SCORE` D1 draft ⚠️ Q-SVCCHAIN-05）与 🧪。
- `AC-US-SVC-REC-02-03`：推荐理由引用的指标名与数值与该行列值一致，带 🧪。
- `AC-US-SVC-REC-02-04`：同一配置重复生成结果完全一致（确定性）；配置变更后有"配置已变更"提示。
- `AC-US-SVC-REC-02-05`：导出 CSV 行数 = 当前名单行数，含表头与演示口径声明；文件名含产业方向。

不包含：外部机构入对比篮（外部机构未入库、无画像与技术力数据，入篮无从分析——差异点见 UX-SPEC §7）；名单行内收藏/关注名单（招标 7.6.2 未要求，v1.0-r3 移除原 US-05）；招商任务流转；联系触达。

| 属性 | 内容 |

| `source_relation` | `direct_requirement` |

| 产品角色 | `ROLE-SVC-GOV` |
| 依赖 | 无 |

| 业务结果 | 培育模型四维度（现有规模/技术创新能力/服务成效/市场缺口）与权重可见可调，筛选范围（机构类型/服务环节）可设置 |

作为政府科技主管人员，我想理解并调整本土机构培育模型的评估维度，以便发掘最值得扶持的高成长性本地机构。

主路径：

1. 培育页签模型配置区展示四维度卡（Bid 7.7.1 列举：现有规模、技术创新能力、服务成效、市场缺口），默认权重 20/30/25/25，可调可归一（同 US-01 规则）。
2. 筛选范围支持机构类型多选、服务环节多选（默认全选）；筛选与权重均持久化。
3. 模型区带 🧪 与 ⚠️（Q-SVCCHAIN-05）。

验收：

- `AC-US-SVC-REC-03-01`：四维度名称与 Bid 7.7.1 列举语义一致；权重校验与归一规则同招引模型。
- `AC-US-SVC-REC-03-02`：机构类型/服务环节筛选影响候选范围且持久化；全不选时生成禁用并解释。
- `AC-US-SVC-REC-03-03`：模型区演示口径声明与 ⚠️ 同 US-01 标准。

不包含：维度自定义；本土机构名录维护。

### US-SVC-REC-04｜培育名单与建议

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-REC-CULTIVATE-LIST`（7.7.2） |
| `decision_refs` | `Q-SVCCHAIN-05` |
| 产品角色 | `ROLE-SVC-GOV` |
| 依赖 | US-03 |
| Frames | `F-SVC-REC-03`、`F-SVC-05` |
| 业务结果 | 深圳本土机构培育名单（评分/排名/针对性建议标签与文本）可生成、可下钻画像、可导出/入对比篮 |

作为政府科技主管人员，我想得到本土机构培育名单和针对性培育建议，以便制定"一企一策"扶持方案。

主路径：

1. 用户选定产业方向并点击"生成培育名单"；系统按演示口径对筛选范围内深圳本土机构计算综合分并排名。
2. 名单行显示：名次、机构（可下钻画像抽屉）、类型/环节、四维度分、综合分 ⓘ⚠️🧪、建议标签（资金支持/市场对接/人才引进，规则生成 🧪）。
3. 展开行显示建议文本（"一企一策"演示文本，引用该机构维度短板数值）。
4. 行内动作：加入对比篮（本土机构在库，可送 R1 技术力对比，CT-SVC-ORG-03）；工具栏：导出 CSV。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 筛选范围内无机构 | 结果区"当前筛选范围内无本土机构"，不渲染空表 | 放宽筛选 |
| 机构画像参数非法 | 同 R1 规则：Message + 清参数 | 重新点击 |
| 对比篮已满 | Message"对比篮已满"，不写入 | 打开篮移除后重试 |

验收：

- `AC-US-SVC-REC-04-01`：名单仅含深圳本土在库机构；综合分 = Σ(维度归一 × 权重) 且确定性可复现。
- `AC-US-SVC-REC-04-02`：综合分旁必有 ⓘ（`M_SVC_REC_CULTIVATE_SCORE` D1 draft ⚠️）与 🧪；建议标签/文本带 🧪 且引用数值与该行一致。
- `AC-US-SVC-REC-04-03`：机构名可下钻画像抽屉（与 R1 同一组件同一 org_id）；URL `org` 可分享恢复。
- `AC-US-SVC-REC-04-04`：行内"加入对比篮/已加入"与系统篮 service_org Tab 即时同步（R2B 契约）。
- `AC-US-SVC-REC-04-05`：导出 CSV 含建议标签列与演示口径声明。

不包含：扶持资金测算；培育进度跟踪；名单行内收藏/关注名单（招标 7.7.2 未要求，v1.0-r3 移除原 US-05 / F-SVC-REC-04）。
