硬约束：

## 6. 状态与就绪度角标总表

- 每个统计数字：数字 → ⓘ（或 D1 missing 红问号）→ ⚠️/⏰ → 🧪，间距 4px，全部 Arco Icon，评审模式门控 + 组件自闸。
- 空态：集合空（整区引导）、搜索空（局部）、无覆盖行（行内）、序列不足（研判区诚实文案）、分组空（抽屉局部）。
- 失败态：图表容器局部错误 + 重试，不破坏页面壳。
- 业务模式（ReviewMode 关）：无 metric_id/Q 编号/GAP 字样泄漏；保留"演示口径"用户可读声明。
