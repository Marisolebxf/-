## 1. 模块结果

围绕用户显式选定的一组服务机构与一个产业/技术领域上下文，完成"机构检索发现（对齐企业检索模式） → 机构集合确认 → 领域覆盖认知（广度/深度） → 新增趋势与市场热度研判 → 技术力评估与横向对比（对比对象统一经对比篮） → 单机构画像下钻"的闭环。任意机构上下文（检索结果、分析集合、画像抽屉、图谱节点、培育名单）均可加入系统对比篮，篮内机构可导入技术力对比分析并回跳来源上下文。不做服务链路图/短板分析（7.4/7.5，R2 链路生态域），不做招引/培育名单生成（7.6/7.7，R2 招引培育域），不做深圳横向对比（7.8）。

## 4. 用户故事

### US-SVC-ORG-01｜组装分析对象集

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation`（7.1/7.3 均要求"用户选定单个或多个机构"，本故事是其唯一前置） |
| 产品角色 | `ROLE-SVC-PARK` |
| 依赖 | 无 |
| Frame | `F-SVC-01` |
| 业务结果 | 一个领域上下文（产业领域，可选服务链环节/机构类型过滤）与 1~50 家机构集合被显式确认（经系统对比篮两层组装），URL 与本地持久化一致 |

作为园区服务生态运营人员，我想先确认分析的产业领域和机构集合，以便后续覆盖、趋势、评估都基于同一组对象，不因切换页签或刷新而丢失。

主路径：【v1.2-r2b-c 修订：直选选择器 → 对比篮两层组装，产品侧 2026-10-20 确认】

1. 进入工作台，上下文条显示当前产业领域（默认取上次持久化值；首次进入取字典第一项并明示"默认"）。
2. 用户点击"打开对比篮"（已选时为"打开对比篮调整对象"）：系统对比篮浮层以 **picker 态**打开（`service_org` Tab，勾选上限 50、进入覆盖/趋势分析下限 1）；篮内机构复选勾选、支持关键词过滤；篮为空时引导"新增"。
3. 篮内点击"新增"弹出对应**企业/机构搜索框**（在库机构检索，只读 Java search/orgs）：检索结果行"加入对比篮"即时入篮（US-08 触点同源），可连续补员后关闭搜索框回到篮。
4. 在篮内勾选目标机构并"确定"：浮层关闭，勾选集合回填分析页（`org_ids[]` + `source=compare-basket`），已选机构以 Tag 集合呈现于上下文区并带"来源：对比篮"角标；选择持久化（localStorage），URL 同步 `field` 参数。
5. 切换产业领域时，已选机构集合保留，但覆盖/趋势/评估视图基于新领域重算。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 篮为空 | 浮层空态"对比篮暂无服务机构"+ 引导文案 + "新增"按钮 | 点新增从在库机构检索加入 |
| 篮内搜索无匹配 | 篮内局部 Empty"当前篮内无匹配机构" | 重置篮内关键词 |
| 新增搜索无匹配机构 | 搜索框内局部 Empty，篮内容不变 | 换词检索 |
| 勾选 0 家确定 | 确定按钮禁用 + 提示"请先选择机构"（picker 下限 1） | 勾选后重试 |
| 持久化数据损坏/版本不符 | 静默回落默认集合，并以 Message 提示"已恢复默认机构集合" | 重新选择 |
| 取消/关闭浮层 | 保留确认前的集合，不产生半提交状态 | 继续当前阅读 |

验收：

- `AC-US-SVC-ORG-01-01`：【v1.2-r2b-c】对象集组装唯一入口为系统对比篮 picker：浮层勾选（上限 50）+ 篮内关键词过滤 + 全选/取消；确定后分析页 Tag 集合与篮内勾选严格一致，并带"来源：对比篮"角标。
- `AC-US-SVC-ORG-01-02`：刷新页面后已选机构集合、产业领域与激活页签均保留（localStorage + URL）。
- `AC-US-SVC-ORG-01-03`：URL 携带 `field` 与 `tab` 参数直达时，页面按参数恢复上下文，不回落默认值。
- `AC-US-SVC-ORG-01-04`：已选机构为 0 时三个分析视图均显示引导空态（"尚未选择分析机构，请先在对比篮中组装分析对象"+ 打开对比篮按钮），不出现空坐标轴或 NaN。
- `AC-US-SVC-ORG-01-05`：取消/关闭对比篮浮层不改变已确认集合；篮内"确定"是集合变更的唯一提交点。
- `AC-US-SVC-ORG-01-06`：【v1.2-r2b-c】篮内"新增"弹出的机构搜索框为在库检索（只读，调 Java search/orgs），不提供机构数据新增维护。

不包含：机构数据的新增维护；跨领域机构推荐。（R2B-c 起分析集合的**组装入口**统一为对比篮（US-08）；集合仍是覆盖/趋势视图的驱动对象——篮提供"选哪些"，集合记录"选中了哪些"，篮 ≠ 集合本体，但不再存在绕开篮的直选第二入口，与 `AC-US-SVC-ORG-08-06` 互证。）

### US-SVC-ORG-02｜领域覆盖分析与呈现

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-ORG-COVERAGE`（7.1.1）、`REQ-SVC-ORG-COVERAGE-VIS`（7.1.2） |
| 产品角色 | `ROLE-SVC-GOV` |
| 依赖 | US-01 |
| Frame | `F-SVC-02` |
| 业务结果 | 已选机构在各产业领域的服务广度（覆盖领域数）与深度（得分）以热力图或矩阵图稳定呈现，可切换、可下钻 |

作为政府科技主管人员，我想看清一组机构在各产业领域的服务广度与深度，以便判断机构服务重心与跨界能力，辅助服务采购决策。

主路径：

1. 系统按已选机构 × 产业领域计算覆盖：广度 = 有服务记录的领域数，深度 = 该领域服务深度得分（演示态口径，标 ⚠️ Q-SVCCHAIN-02）。
2. 默认热力图（机构 × 领域，色阶=深度）；用户可切换矩阵图（X=广度，Y=平均深度，象限分区）。
3. hover 单元格/气泡显示机构、领域、深度值；click 机构行头/气泡打开该机构详情抽屉（US-03）。
4. 核心结论区自动给出广度 TOP3、深度 TOP 领域（按机构）与合作建议文本（🧪 演示态规则生成）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 某机构在全部领域无服务记录 | 该行保留并显示"暂无覆盖数据"，不用 0 填充色块 | 查看机构详情或移出集合 |
| 已选机构 > 12 家 | 热力图可纵向滚动，行头冻结；矩阵图气泡防重叠抖动 | 缩小集合获得更清晰视图 |
| 图表渲染失败 | 图表容器局部错误 + "重试"，页面壳与筛选保留 | 点击重试 |
| 切换图型 | 已选机构、领域、滚动位置保留；图型选择持久化 | — |

验收：

- `AC-US-SVC-ORG-02-01`：热力图行=已选机构、列=产业领域字典全集，色阶五档与图例一致；单元格值与 hover 提示一致。
- `AC-US-SVC-ORG-02-02`：矩阵图 X 轴=覆盖领域数（整数刻度）、Y 轴=平均深度得分（0-100），四象限有文本标注，气泡可点击。
- `AC-US-SVC-ORG-02-03`：热力/矩阵切换不丢失机构集合与领域上下文，图型选择刷新后保留。
- `AC-US-SVC-ORG-02-04`：服务深度得分数字旁必有 ⓘ（`M_SVC_ORG_COVERAGE_DEPTH`，D1 draft 带 ⚠️ Q-SVCCHAIN-02）与 🧪；广度数字挂 `M_SVC_ORG_COVERAGE_BREADTH`。
- `AC-US-SVC-ORG-02-05`：核心结论区文本带 🧪 演示态标识，其中出现的数值与图表当前数据一致，不出现图表外的编造数值。
- `AC-US-SVC-ORG-02-06`：无覆盖数据的机构行显示"暂无覆盖数据"局部空态，不参与 TOP 结论排名。

不包含：领域字典维护；覆盖数据的时间序列回溯；跨集合（未选机构）对比。

### US-SVC-ORG-03｜机构画像下钻

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation`（7.1"掌握机构服务重心与跨界能力"、7.3"客观识别高技术含量服务机构"的对象级落点） |

| 异常 | 系统行为 | 恢复 |

- `AC-US-SVC-ORG-03-01`：覆盖、趋势、评估三个视图中的机构实体均可下钻到同一抽屉组件，机构 ID 一致（不因视图不同打开不同详情）。
- `AC-US-SVC-ORG-03-02`：URL 带 `org` 参数分享后他人打开可恢复同一抽屉；关闭抽屉后 URL 参数移除。

- `AC-US-SVC-ORG-03-04`：抽屉内"加入集合"仅在机构不在集合时显示，加入后立即反映到各视图且持久化。

不包含：机构编辑/维护；机构与企业库画像的实体互认（无稳定主数据映射前不做伪跳转）。
