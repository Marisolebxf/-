# USM-SVCCHAIN-ORG-ANALYSIS｜服务机构分析（产业服务链 · 机构维度）

> **版本**：v1.0-r1-pilot
> **状态**：与 IA、Wireframe、UX-SPEC、TRACE 同步（AI 起草，待体验 Owner 确认）
> **原始需求**：展示 Bid `1.1.1.2.4.2.7.1`（服务机构产业领域分析）、`.7.2`（服务机构新增趋势分析）、`.7.3`（服务机构技术力评估分析），共 6 个三级项
> **registry**：TOPIC-SVCCHAIN-R1

## 1. 模块结果

围绕用户显式选定的一组服务机构与一个产业/技术领域上下文，完成"机构集合确认 → 领域覆盖认知（广度/深度） → 新增趋势与市场热度研判 → 技术力评估与横向对比 → 单机构画像下钻"的闭环。不做服务链路图/短板分析（7.4/7.5，R2 链路生态域），不做招引/培育名单生成（7.6/7.7，R2 招引培育域），不做深圳横向对比（7.8）。

## 4. 用户故事

### US-SVC-ORG-01｜组装分析对象集

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation`（7.1/7.3 均要求"用户选定单个或多个机构"，本故事是其唯一前置） |
| 产品角色 | `ROLE-SVC-PARK` |
| 依赖 | 无 |
| Frame | `F-SVC-01` |
| 业务结果 | 一个领域上下文（产业领域，可选服务链环节/机构类型过滤）与 1~N 家机构集合被显式确认，URL 与本地持久化一致 |

作为园区服务生态运营人员，我想先确认分析的产业领域和机构集合，以便后续覆盖、趋势、评估都基于同一组对象，不因切换页签或刷新而丢失。

主路径：

1. 进入工作台，上下文条显示当前产业领域（默认取上次持久化值；首次进入取字典第一项并明示"默认"）。
2. 用户点击"选择机构"打开选择器 Modal：按机构类型分组、支持关键词搜索、单类全选/取消、清空。
3. 确认后 Modal 关闭，已选机构以 Tag 集合呈现于上下文区；选择持久化（localStorage），URL 同步 `field` 参数。
4. 切换产业领域时，已选机构集合保留，但覆盖/趋势/评估视图基于新领域重算。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 搜索无匹配机构 | 选择器内局部 Empty"未找到匹配机构"，已选集合不变 | 清空关键词或换词 |
| 已选机构为 0 时进入分析视图 | 视图区 Empty + "去选择机构"引导按钮，不渲染空图表 | 打开选择器补选 |
| 持久化数据损坏/版本不符 | 静默回落默认集合，并以 Message 提示"已恢复默认机构集合" | 重新选择 |
| 取消选择器 | 保留确认前的集合，不产生半提交状态 | 继续当前阅读 |

验收：

- `AC-US-SVC-ORG-01-01`：机构选择器支持按类型分组、关键词过滤、单类全选/取消、全选所有、清空；确认后 Tag 集合与选择器勾选严格一致。
- `AC-US-SVC-ORG-01-02`：刷新页面后已选机构集合、产业领域与激活页签均保留（localStorage + URL）。
- `AC-US-SVC-ORG-01-03`：URL 携带 `field` 与 `tab` 参数直达时，页面按参数恢复上下文，不回落默认值。
- `AC-US-SVC-ORG-01-04`：已选机构为 0 时三个分析视图均显示引导空态，不出现空坐标轴或 NaN。
- `AC-US-SVC-ORG-01-05`：取消选择器不改变已确认集合；确认动作是集合变更的唯一提交点。

不包含：机构收藏夹/对比篮跨模块共享；机构数据的新增维护；跨领域机构推荐。

### US-SVC-ORG-02｜领域覆盖分析与呈现

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-ORG-COVERAGE`（7.1.1）、`REQ-SVC-ORG-COVERAGE-VIS`（7.1.2） |
| 产品角色 | `ROLE-SVC-GOV` |
| 依赖 | US-01 |
| Frame | `F-SVC-02` |
| 业务结果 | 已选机构在各产业领域的服务广度（覆盖领域数）与深度（得分）以热力图或矩阵图稳定呈现，可切换、可下钻 |

作为政府科技主管人员，我想看清一组机构在各产业领域的服务广度与深度，以便判断机构服务重心与跨界能力，辅助服务采购决策。

主路径：

1. 系统按已选机构 × 产业领域计算覆盖：广度 = 有服务记录的领域数，深度 = 该领域服务深度得分（演示态口径，标 ⚠️ Q-SVCCHAIN-02）。
2. 默认热力图（机构 × 领域，色阶=深度）；用户可切换矩阵图（X=广度，Y=平均深度，象限分区）。
3. hover 单元格/气泡显示机构、领域、深度值；click 机构行头/气泡打开该机构详情抽屉（US-03）。
4. 核心结论区自动给出广度 TOP3、深度 TOP 领域（按机构）与合作建议文本（🧪 演示态规则生成）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 某机构在全部领域无服务记录 | 该行保留并显示"暂无覆盖数据"，不用 0 填充色块 | 查看机构详情或移出集合 |
| 已选机构 > 12 家 | 热力图可纵向滚动，行头冻结；矩阵图气泡防重叠抖动 | 缩小集合获得更清晰视图 |
| 图表渲染失败 | 图表容器局部错误 + "重试"，页面壳与筛选保留 | 点击重试 |
| 切换图型 | 已选机构、领域、滚动位置保留；图型选择持久化 | — |

验收：

- `AC-US-SVC-ORG-02-01`：热力图行=已选机构、列=产业领域字典全集，色阶五档与图例一致；单元格值与 hover 提示一致。
- `AC-US-SVC-ORG-02-02`：矩阵图 X 轴=覆盖领域数（整数刻度）、Y 轴=平均深度得分（0-100），四象限有文本标注，气泡可点击。
- `AC-US-SVC-ORG-02-03`：热力/矩阵切换不丢失机构集合与领域上下文，图型选择刷新后保留。
- `AC-US-SVC-ORG-02-04`：服务深度得分数字旁必有 ⓘ（`M_SVC_ORG_COVERAGE_DEPTH`，D1 draft 带 ⚠️ Q-SVCCHAIN-02）与 🧪；广度数字挂 `M_SVC_ORG_COVERAGE_BREADTH`。
- `AC-US-SVC-ORG-02-05`：核心结论区文本带 🧪 演示态标识，其中出现的数值与图表当前数据一致，不出现图表外的编造数值。
- `AC-US-SVC-ORG-02-06`：无覆盖数据的机构行显示"暂无覆盖数据"局部空态，不参与 TOP 结论排名。

不包含：领域字典维护；覆盖数据的时间序列回溯；跨集合（未选机构）对比。

### US-SVC-ORG-03｜机构画像下钻

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `product_interpretation`（7.1"掌握机构服务重心与跨界能力"、7.3"客观识别高技术含量服务机构"的对象级落点） |
| 产品角色 | `ROLE-SVC-PARK` |
| 依赖 | US-01 |
| Frames | `F-SVC-02`、`F-SVC-03`、`F-SVC-04`、`F-SVC-05` |
| 业务结果 | 任一视图内点击机构即可打开画像抽屉，URL 可分享恢复，关闭后回到原视图状态 |

作为园区运营人员，我想从任何分析视图直接下钻单个机构的画像，以便在不丢失分析上下文的前提下核实机构详情。

主路径：

1. 用户在覆盖热力行头、矩阵气泡、趋势明细、评估排名/雷达中 click 或 Enter 选择机构。
2. 右侧 Drawer 打开：机构基本信息（类型/成立年份/服务环节）、领域覆盖细分（各领域深度条形）、技术力五维值、近三年新增服务记录摘要。
3. URL 同步 `org` 参数；直接携带 `org` 参数进入时自动打开对应抽屉。
4. 关闭抽屉后焦点返回触发元素，视图滚动位置、筛选、页签均不变。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| `org` 参数无法解析 | 不打开抽屉，Message"机构不存在或已下线"，并清除该参数 | 重新从列表选择 |
| 机构不在当前已选集合 | 抽屉正常打开并提示"该机构不在当前分析集合"，提供"加入集合"动作 | 一键加入后各视图重算 |
| 抽屉数据分组无数据 | 对应分组局部 Empty，不删除其他分组 | — |

验收：

- `AC-US-SVC-ORG-03-01`：覆盖、趋势、评估三个视图中的机构实体均可下钻到同一抽屉组件，机构 ID 一致（不因视图不同打开不同详情）。
- `AC-US-SVC-ORG-03-02`：URL 带 `org` 参数分享后他人打开可恢复同一抽屉；关闭抽屉后 URL 参数移除。
- `AC-US-SVC-ORG-03-03`：抽屉打开/关闭不重载页面主体，不丢失页签、筛选、滚动位置与已选集合。
- `AC-US-SVC-ORG-03-04`：抽屉内"加入集合"仅在机构不在集合时显示，加入后立即反映到各视图且持久化。
- `AC-US-SVC-ORG-03-05`：抽屉内技术力五维数字旁有 ⓘ（`M_SVC_ORG_TECH_SCORE` 维度分，D1 draft ⚠️）与 🧪。

不包含：机构编辑/维护；机构与企业库画像的实体互认（无稳定主数据映射前不做伪跳转）。

### US-SVC-ORG-04｜新增趋势可视化

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-ORG-TREND`（7.2.1） |
| 产品角色 | `ROLE-SVC-INVEST` |
| 依赖 | US-01（仅领域上下文；本故事不依赖机构集合） |
| Frame | `F-SVC-03` |
| 业务结果 | 选定领域的新增服务机构时间序列稳定呈现，最多 3 个对比领域可叠加，时间窗可切换且持久化 |

作为投资研究人员，我想看特定产业/技术领域下新增服务机构的时间序列，以便预判服务供给变化。

主路径：

1. 用户选择主领域（默认取工作台领域上下文），可添加最多 2 个对比领域（合计 ≤3 条曲线）。
2. 时间窗切换（近 3 年 / 近 5 年 / 近 8 年），选择持久化。
3. 折线图渲染新增数量序列；图例可开关曲线；hover 数据点显示领域、年份、数量。
4. 明细表列出主领域每年的新增机构数与代表机构（可下钻 US-03）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 对比领域已达上限 | "添加对比"禁用并解释"最多 3 个领域" | 移除一个后再添加 |
| 某领域该窗口无新增记录 | 曲线保留为 0 线并在图例标注"无新增"，不隐藏该领域 | 调整时间窗 |
| 全部曲线被图例关闭 | 图表区显示"至少保留一条曲线"提示，最后一条不可关闭 | — |

验收：

- `AC-US-SVC-ORG-04-01`：曲线数量上限 3，超限时添加入口禁用且有解释文案。
- `AC-US-SVC-ORG-04-02`：时间窗切换后 X 轴刻度、曲线数据同步更新，选择刷新后保留。
- `AC-US-SVC-ORG-04-03`：新增数量数字（图表 hover 与明细表）挂 `M_SVC_ORG_NEW_COUNT` ⓘ + 🧪。
- `AC-US-SVC-ORG-04-04`：图例开关只影响可见性，不改变已选领域集合；最后一条曲线不可关闭。
- `AC-US-SVC-ORG-04-05`：明细表机构名可下钻画像抽屉，返回后表格滚动位置保留。

不包含：新增机构的名单导出；跨领域自动归因分析。

### US-SVC-ORG-05｜市场热度判断

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-ORG-HEAT`（7.2.2） |
| `decision_refs` | `Q-SVCCHAIN-02` |
| 产品角色 | `ROLE-SVC-INVEST` |
| 依赖 | US-04 |
| Frame | `F-SVC-03` |
| 业务结果 | 基于趋势曲线特征（斜率/波动）的热度研判以可解释的方式呈现，评级算法未定前保持诚实演示态 |

作为投资研究人员，我想让系统基于曲线斜率与波动特征给出市场热度与资本关注度研判，以便快速形成投资判断，同时清楚知道当前评级是演示口径。

主路径：

1. 趋势图下方研判面板展示：主领域近段斜率、波动特征描述、热度星级与文字评级（🧪 演示态规则）。
2. 每条研判给出"依据"行（引用曲线上的具体区间与数值），用户可核对图表验证。
3. 对比领域各给一行简版评级；面板整体带 🧪 与 ⚠️（Q-SVCCHAIN-02）标识。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 序列长度不足以判读（<3 年数据） | 显示"数据长度不足，暂不给出热度研判"，不输出伪评级 | 扩大时间窗 |
| 曲线全为 0 | 评级显示"该领域暂无服务供给活动"，不显示星级 | 更换领域 |

验收：

- `AC-US-SVC-ORG-05-01`：热度评级数字/星级旁必有红问号或 ⚠️ 标识（`M_SVC_ORG_MARKET_HEAT` D1 missing，评审模式点开只显 Q-SVCCHAIN-02 治理引用，不显伪 8 件套）。
- `AC-US-SVC-ORG-05-02`：每条研判含"依据"行且引用数值与当前图表数据一致。
- `AC-US-SVC-ORG-05-03`：数据长度不足或全 0 时不输出评级，显示对应诚实空态文案。
- `AC-US-SVC-ORG-05-04`：切换主领域或时间窗后研判面板同步重算，不残留上一领域结论。
- `AC-US-SVC-ORG-05-05`：研判面板在业务模式（ReviewMode 关）下不出现 metric_id/Q 编号等内部字样，但保留"演示口径"用户可读声明。

不包含：热度预测（未来值外推）；资本事件明细数据接入。

### US-SVC-ORG-06｜技术力评估模型配置与横向对比

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-ORG-EVAL-MODEL`（7.3.1）、`REQ-SVC-ORG-EVAL-COMPARE`（7.3.2） |
| `decision_refs` | `Q-SVCCHAIN-01` |
| 产品角色 | `ROLE-SVC-GOV` |
| 依赖 | US-01 |
| Frame | `F-SVC-04` |
| 业务结果 | 内置多维模型可配置（启停/权重/自定义维度），2~5 家机构横向对比结果以雷达图或排名列表呈现且可复现 |

作为政府科技主管人员，我想在可配置的技术力模型下横向对比目标机构，以便客观识别高技术含量服务机构。

主路径：

1. 模型配置区展示内置五维（专利数量/研发投入/核心专家/成功案例/标准制定）+ 已添加的自定义维度；每维可启停、可调权重。
2. 系统实时显示权重合计；合计 ≠100% 时"开始评估"禁用并提示差值。
3. 用户从已选集合中勾选 2~5 家对比机构，点击"开始评估"；系统按"维度归一化 × 权重"计算综合得分（演示口径，⚠️ Q-SVCCHAIN-01）。
4. 结果默认排名列表（得分、名次、维度明细），可切换雷达图（每机构一图，维度轴动态跟随启用维度）。
5. 配置（维度启停、权重、对比机构、图型）全部持久化，刷新后评估结果可一键复现。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
