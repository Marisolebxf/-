# UX-SPEC-SVCCHAIN-PORTAL｜专题服务（门户展示）交互规格

> **版本**：v1.0（TOPIC-SVCCHAIN-R2C）
> **交互权威**：`UX-UE 通用交互组件规范.md`；视觉 token 以 `Design.md` 为准
> **配套**：USM（故事与 AC）、Wireframe（结构与字段）、TRACE（追溯）

## 1. 用户旅程

```text
J1 接待/公开浏览（VISIT）：进全球概况（KPI+趋势+类型+规模）→ 区域分布看格局 →
   深圳介绍看四类统计 → 重点机构卡片墙 → 详情四板块 → 形成"深圳产业服务活跃"的具象认知
J2 政府/园区分流（GOV/PARK）：全球概况 → 产业分布看链路薄弱环节 → 技术能力看本产业 Top30 →
   榜单行入篮凑候选 → 详情"进入分析侧画像" → 分析侧完成覆盖/评估等深度任务（离开门户）
```

## 2. 状态机

### 2.1 门户页通用

```text
loading ──数据装载──▶ ready ──切页签/产业──▶ ready（重算）
              │图表异常
              ▼
        section_error（局部）──重试──▶ ready
```

- 门户页无 empty_selection 前置（展示页默认可读，不依赖用户先选对象）。
- 单区图表失败只降级该区（`section_error`），KPI 与其他区保持 `ready`。
- 趋势序列 <2 可比点：数量分析区进入 `hidden` 态（模块整体隐藏，不渲染空坐标轴）。

### 2.2 重点机构详情抽屉

`closed ⇄ open(org_id)`；URL `org` 为唯一真源；参数非法 → 清参数 + Message，不进入 open。板块级 `partial` 态：扩展档案缺失的板块显示"资料完善中"，其余板块正常渲染。

### 2.3 与分析侧互通（CT-SVC-PT-02 / CT-SVC-ORG-03）

```text
门户详情抽屉 ──进入分析侧画像──▶ /service/institution-judgment?org={org_id}
             ──加入对比篮──▶ 系统篮 service_org（跨门户/分析侧即时同步）
门户榜单行  ──加入对比篮──▶ 同上（幂等切换"加入对比篮 ⇄ 已加入"）
```

- 门户不承接篮的"导入对比分析"分发（分发面板归系统篮层，目标仍是分析侧评估页）。
- 跳转分析侧为整页路由跳转；浏览器返回后门户页签/产业选择/滚动会话内恢复。

## 3. 反馈与错误恢复

| 场景 | 反馈 | 恢复 |
| --- | --- | --- |
| 图表渲染异常 | 容器内 Alert + 重试按钮 | 点击重试重新渲染该区 |
| URL 参数非法（field/tab/org） | 清除该参数 + Message | 页面按余下参数正常渲染 |
| 入篮成功/移除/满篮 | Message（成功/信息/警告）| 满篮移除后重试 |
| 环节代表机构为空（聚合>0） | 局部诚实空态"演示子集内暂无该环节代表机构" | — |
| 扩展档案缺失 | 板块级"资料完善中"空态 | — |
| localStorage 恢复失败 | 回落默认 + Message"已恢复默认" | 重新选择 |
| 底图瓦片离线 | 圆点/图例照常渲染（矢量层独立） | 网络恢复自动加载 |

## 4. 键盘与无障碍

- 页签 Tabs（区域层级/产业）：←/→ 切换，Enter 激活；`role=tablist/tab`，`aria-selected` 同步。
- 榜单机构名、环节代表机构、重点机构卡片：Tab 可达、Enter 触发下钻，带 `aria-label="查看{机构名}详情"`。
- 详情抽屉：打开焦点入内、Esc 关闭、关闭后焦点回触发元素；需显式关闭防误触。
- 图表信息不只靠颜色：环形/条形 hover 有文本；地图圆点 tooltip 有文本；服务空白环节除警示色外有"服务空白"文字。
- 演示态声明（🧪）在业务模式下用中文"演示口径/演示聚合数据集"可读文案表达，不用图标独扛语义。

## 5. 响应式（medium_1440_1920）

- ≥1680：全球概况类型/规模两卡并排；深圳页数量/类型并排、地图+列表并排。
- 1440：图表卡片单列堆叠；地图高度 420px 不变；详情抽屉 720px 不变。
- 榜单 >10 行分页（pageSize=10），列不横向滚动。

## 6. 持久化契约（localStorage，前缀 `topic-svc-portal-`）

| key | 内容 | 版本策略 |
| --- | --- | --- |
| `topic-svc-portal-field` | 产业分布/技术能力页当前产业 field_id | `v` 字段不符→回默认 |
| `topic-svc-portal-region-tab` | 区域分布激活层级 global/china | 同上 |

- URL 参数（`field/tab/org`）优先级高于 localStorage；两者随交互双向同步。
- 页签内点选高亮、列表滚动等会话状态走组件内存（sessionStorage 不落盘），跨会话不承诺。
- 对比篮持久化走系统篮统一存储（`compareBasketStore.ts`），不另建 portal key。

## 7. D9 徽章与评审层

- 全部统计数字挂 `SvcMetricBadges`（mount 前缀 `SVC-PT-{frame}-{block}`），排列：数字 → ⓘ/❓ → 结构 → ⚠️ → 🧪。
- 新指标（`M_SVC_PT_*`）登记进 `serviceReadinessSeed` + `serviceReviewData`（真源=TRACE `metric_registration`）；复用指标（`M_SVC_ORG_TECH_SCORE` / `M_SVC_ORG_COVERAGE_DEPTH`）不重复登记。
- 评审模式关闭时 DOM 零泄漏：无 `metric_id` / `Q-*` / `M_SVC_PT_*` 字样；业务态保留"演示口径"用户可读声明。
- 需求追溯锚点（`requirement_trace`）挂各区标题：`REQ-SVC-PT-*` 十一条（见 TRACE）。
