## 1. 模块结果

面向门户访问者（含接待场景公开浏览），以"全球概况 → 产业分布 → 区域分布 → 技术能力排名 → 深圳介绍（含重点机构详情）"五个展示视角呈现产业服务机构的发展活跃度，形成"产业孵化载体"的宏观认知；任一展示触点可下钻单机构详情（概况/规模/领域/业务分布四板块），并可进入分析侧（服务机构分析工作台 / 对比篮）继续深度任务。本叶子只做展示与分流，不做机构检索（US-SVC-ORG-07）、覆盖/趋势/评估分析（ORG-ANALYSIS）、链路生态（ECOSYSTEM）、招引培育名单（RECOMMEND）。

**数据诚实边界（Wave 0）**：全球/全国/深圳的聚合统计（总量、类型、规模、区域、产业链节点分布）为确定性聚合 Mock 数据集（`servicePortalData.ts`），实体级下钻仅覆盖与分析侧共享的深圳重点机构演示子集（`serviceCenterData.SERVICE_ORGS`，24 家）；两层数字的关系（聚合库 vs 重点子集）在 UI 以口径文案明示，不伪装聚合数可逐条下钻。统计口径与数据源未定项登记 Q-SVCCHAIN-06。

## 4. 用户故事

### US-SVC-PT-01｜全球服务机构概况（序号 97/98/99）

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-PT-GLOBAL-COUNT`（97）、`REQ-SVC-PT-GLOBAL-TYPE`（98）、`REQ-SVC-PT-GLOBAL-SCALE`（99） |
| 产品角色 | `ROLE-SVC-VISIT` |
| 依赖 | 无 |
| Frame | `F-SVC-PT-01` |
| 业务结果 | 全球服务机构总量、历年趋势、类型分布、规模分布四类统计以 KPI + 图表稳定呈现，形成全球供给规模认知 |

作为门户访问人员，我想一眼看到全球服务机构的总量、历年变化、类型构成与规模构成，以便快速建立产业服务供给全球盘面的认知。

主路径：

1. 进入"专题服务"门户默认落在全球概况页；顶部 KPI 区展示全球服务机构总数、本年新增数、覆盖产业领域数（均为全球全库口径，不随下方图表交互变化）。
2. 数量分析区（97）：历年总量趋势折线（2018-2025，至少两个可比时间点），hover 显示年份与数值。
3. 类型分析区（98）：高校/科研院所/企业三类环形占比图，hover 显示类型、数量、占比。
4. 规模分析区（99）：人员规模四档（<50 人 / 50-200 人 / 200-500 人 / >500 人）条形分布，hover 显示档位与数量。
5. 页面结论条给出一句话判断（🧪 规则生成，数值与图表同源）。切到产业分布/区域分布/技术能力/深圳介绍走页组顶部子导航；进入分析侧工作台由深圳介绍/重点机构详情等既有分流动作承接（全球概况页不设页尾快捷按钮）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 趋势序列不足两个可比时间点 | 隐藏趋势模块，不显示单点伪趋势；类型/规模区占满该行 | 数据补齐后自动恢复 |
| 某类型/档位数量为 0 | 图例保留该项并标注 0，不静默删除字典项 | — |
| 图表渲染失败 | 图表容器局部错误 + "重试"，KPI 与其他区不受影响 | 点击重试 |

验收：

- `AC-US-SVC-PT-01-01`：顶部 KPI 三项（全球总数/本年新增/覆盖领域数）均为全球全库口径，页面内任何图表交互不改变其值。
- `AC-US-SVC-PT-01-02`：历年趋势折线 X 轴为连续年份（2018-2025），hover 数值与数据集一致；序列不足两点时模块隐藏且无空坐标轴。
- `AC-US-SVC-PT-01-03`：类型环形图字典 = 高校/科研院所/企业（与机构主数据 `OrgType` 同一字典），占比合计 100%。
- `AC-US-SVC-PT-01-04`：规模条形四档全集展示（含 0 值档），hover 显示档位、数量、占比。
- `AC-US-SVC-PT-01-05`：全部统计数字旁有 ⓘ（`M_SVC_PT_GLOBAL_TOTAL` / `M_SVC_PT_GLOBAL_TYPE_DIST` / `M_SVC_PT_GLOBAL_SCALE_DIST`，D1 aligned/draft 按注册）与 🧪；口径文案注明"全球聚合为演示聚合数据集"（⚠️ Q-SVCCHAIN-06）。
- `AC-US-SVC-PT-01-06`：结论条文本内出现的数值与当前图表数据一致，不出现图表外编造数值。

不包含：全球机构名录逐条浏览（无全球实体级数据源，Q-SVCCHAIN-06）；机构检索（分析侧 US-SVC-ORG-07）。

### US-SVC-PT-02｜服务机构产业分布（33.2）

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-PT-CHAIN-DIST`（33.2"结合产业链全景图，展示服务机构在各产业链节点上的服务分布情况"） |
| 产品角色 | `ROLE-SVC-GOV` |
| 依赖 | 无 |
| Frame | `F-SVC-PT-02` |
| 业务结果 | 选定产业的服务链节点（上游研发→中试→检测→转移孵化→产业化支撑）× 服务机构数量分布可视化，节点可下钻代表机构 |

作为政府科技主管人员，我想结合产业链全景结构看服务机构在各链路节点上的分布，以便识别哪些环节服务供给充足、哪些环节薄弱。

主路径：

1. 产业选择器（15 个产业集群，与企业/产业链/展示/政策同一份；Q068 / P7）可选集群或再选 L0；**禁止**自动带第一个 L0。无映射走空态「无相关产业数据」，不回落生物医药。
2. 链路分布主视图：按服务链六环节（研发攻关/知识产权与标准/技术转移与中试/检测认证/孵化育成/产业化支撑，字典复用 ECOSYSTEM `CHAIN_STAGES`）分层呈现节点机构数（横向链路图 + 环节条形），环节 hover 显示机构数与占全链比例。
3. 点击环节展开该环节代表机构列表（演示子集内实体）；机构名下钻门户机构详情（US-06 同一抽屉）。
4. 切换产业后分布与代表机构同步重算；选择持久化。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 某环节机构数为 0 | 环节保留并标注"服务空白"警示样式，不从链路图中删除 | 换产业查看 |
| 代表机构列表为空（聚合数 >0 但子集内无实体） | 列表区显示"演示子集内暂无该环节代表机构"诚实空态 | — |
| 图表渲染失败 | 局部错误 + 重试，产业选择器保留 | 点击重试 |

验收：

- `AC-US-SVC-PT-02-01`：链路图环节字典与分析侧 ECOSYSTEM `CHAIN_STAGES` 同一来源（六环节名称一致），不自造第二套链路字典。
- `AC-US-SVC-PT-02-02`：环节机构数 hover 与条形图数值一致，均挂 `M_SVC_PT_CHAIN_NODE_ORG` ⓘ + 🧪。
- `AC-US-SVC-PT-02-03`：机构数为 0 的环节保留并有"服务空白"标注，视觉区别于正常环节。
- `AC-US-SVC-PT-02-04`：环节展开的代表机构与机构主数据一致（同一 org_id），机构名下钻与 US-06 打开同一详情组件。
- `AC-US-SVC-PT-02-05`：切换产业后链路分布、代表机构、结论文本同步更新且刷新后产业选择保留。

不包含：E2 产业链全景图组件的复制（展示分层语义经 CT-SVC-PT-01 引用，不复制 CHAIN 数据模型）；瓶颈判定算法（ECOSYSTEM 7.4.2，Q-SVCCHAIN-03）。

### US-SVC-PT-03｜服务机构区域分布（33.3）

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-PT-REGION`（33.3"通过地图/图表的方式，展示服务机构在全球/全国的区域分布情况"） |
| 产品角色 | `ROLE-SVC-VISIT` |
| 依赖 | 无 |
| Frame | `F-SVC-PT-03` |
| 业务结果 | 全球/全国两级区域分布以地图（比例圆点）+ 排名列表呈现，两级切换不丢失状态 |

作为门户访问人员，我想在地图上看服务机构的全球和全国分布，以便理解产业服务资源的空间集聚格局。

主路径：

1. 页签切换"全球分布 / 全国分布"，默认全球。
2. Leaflet 地图以比例圆点呈现区域机构数（圆点大小=数量，蓝梯度=密度），hover 显示区域与数量，点选圆点联动右侧列表高亮。
3. 右侧区域排名列表（区域、机构数、占比），与地图同一数据源。
4. 全国页签下附加"进入深圳介绍"入口（33.5 分流）。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 底图瓦片加载失败（离线） | 圆点与图例仍渲染（矢量层不依赖瓦片），底图灰 | 网络恢复自动加载 |
| 区域数据为空 | 地图区显示诚实空态，不渲染空图例 | — |
| 页签切换 | 各页签的点选高亮与列表滚动位置独立保留（会话内） | — |

验收：

- `AC-US-SVC-PT-03-01`：全球/全国两级页签均有地图 + 列表双呈现，数值同源一致（同一区域在地图 hover 与列表中的机构数相同）。
- `AC-US-SVC-PT-03-02`：圆点大小随机构数单调递增，图例说明梯度含义；点选圆点后列表对应行高亮并滚动可见。
- `AC-US-SVC-PT-03-03`：区域机构数数字（地图 hover 与列表）挂 `M_SVC_PT_REGION_ORG` ⓘ + 🧪，区域归属口径未定标 ⚠️（Q-SVCCHAIN-06）。
- `AC-US-SVC-PT-03-04`：页签切换后原页签的点选与滚动状态会话内保留，切回不重置。
- `AC-US-SVC-PT-03-05`：地图统一 Leaflet（circleMarker 矢量），不引入百度/高德 SDK。

不包含：省级以下三级下钻（GeoJSON 分级填色升级项，与政策地图同批升级）；区域机构名录明细（无全球实体源）。

### US-SVC-PT-04｜服务机构技术能力 Top30（33.4）

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | `REQ-SVC-PT-CAPABILITY`（33.4"设定固定指标维度，对服务机构的技术力进行评价排名，展示各产业中，服务机构技术力前30名"） |
| `decision_refs` | `Q-SVCCHAIN-01`（技术力评价模型算法定义卡未落地，沿用分析侧同一开放项） |
| 产品角色 | `ROLE-SVC-GOV` |
| 依赖 | 无 |
| Frame | `F-SVC-PT-04` |
| 业务结果 | 各产业下按固定指标维度计算的技术力 Top30 排名可查，评价口径与分析侧同源可解释 |

作为政府科技主管人员，我想按产业查看技术力排名前 30 的服务机构，以便快速锁定各产业的高技术含量服务载体。

主路径：

1. 产业页签（15 个产业集群）切换排名榜单；无映射空态，不默认偷选有数产业。
2. 榜单每行：名次（前三金银铜配色）、机构名（下钻 US-06 详情）、机构类型、技术力综合分、五维迷你条（专利/研发投入/核心专家/成功案例/标准制定）、"加入对比篮"动作。
3. 评价口径说明卡常驻榜单顶部：固定指标维度 = 分析侧内置五维**等权（各 20%）默认配置**，得分算法与分析侧 `computeEvaluation` 同一实现（归一基准 = 榜单集合内最大值），不另造第二套技术力口径；口径带 ⚠️（Q-SVCCHAIN-01）与 🧪。
4. 演示库在库机构不足 30 家时，榜单顶部诚实标注"演示库当前产业在库 N 家，Top30 按实际在库数展示"。

| 异常 | 系统行为 | 恢复 |
| --- | --- | --- |
| 某产业无覆盖机构 | 榜单区诚实空态"该产业演示库暂无服务机构"，不渲染空表头 | 切换产业 |
| 入篮已满 | Message 提示篮满，不写入 | 从篮移除后重试 |
| 榜单机构在主数据中失效 | 该行不渲染（数据装载期过滤），不出现死链 | — |

验收：

- `AC-US-SVC-PT-04-01`：排名分数使用分析侧 `computeEvaluation` 同一实现与内置五维字典（等权固定配置），页面不存在独立的第二套技术力计算或权重口径。
- `AC-US-SVC-PT-04-02`：综合分数字旁必有 ⓘ（复用 `M_SVC_ORG_TECH_SCORE`，D1 draft ⚠️ Q-SVCCHAIN-01）与 🧪；口径说明卡明示固定等权与归一基准。
- `AC-US-SVC-PT-04-03`：产业页签切换后榜单、口径说明中的产业名、在库数标注同步更新；同一产业重复进入排名结果一致（确定性）。
- `AC-US-SVC-PT-04-04`：前三名金银铜配色、第 4 名起统一普通排名色；在库不足 30 家时有诚实标注，不填充占位假机构。
- `AC-US-SVC-PT-04-05`：行内"加入对比篮"与系统篮 `service_org` 即时同步（幂等切换），机构名下钻与 US-06 同一详情组件。

不包含：权重/维度的用户自定义配置（分析侧 US-SVC-ORG-06 职责，门户为固定口径展示）；跨产业合并总榜（口径无依据）。

主路径：
