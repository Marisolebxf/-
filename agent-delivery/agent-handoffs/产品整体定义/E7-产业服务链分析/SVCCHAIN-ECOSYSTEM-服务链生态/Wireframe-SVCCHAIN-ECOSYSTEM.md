## 5. 状态与就绪度角标总表

- 每个统计数字：数字 → ⓘ（或 D1 missing 红问号）→ ⚠️/⏰ → 🧪，间距 4px，全部 Arco Icon，评审模式门控 + 组件自闸。
- 空态：环节无机构（卡内文案 + 空白判定）、过滤空结果（图区文案）、子网过小（统计不计算）、指标全取消（提示勾选）、城市无数据（柱位占位）。
- 失败态：链路图/网络图/柱状图容器局部错误 + 重试，不破坏页面壳。
- 业务模式（ReviewMode 关）：无 metric_id/Q 编号/GAP 字样泄漏；保留"演示口径/演示规则/待甲方确认"用户可读声明。
