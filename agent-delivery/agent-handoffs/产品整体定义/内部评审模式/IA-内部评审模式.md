# IA-内部评审模式

> **模块**：内部评审模式（跨模块评审辅助能力）
> **对应 USM / TRACE**：[USM-内部评审模式](USM-内部评审模式.md) / [TRACE-REVIEW-内部评审模式](TRACE-REVIEW-内部评审模式.yaml)
> **体验 Owner / 起草**：高颖
> **产品规则确认**：郭万迎（PM/合规）
> **语义状态确认**：何老师
> **阶段**：产品定义初稿；非 bid 业务叶子

## 1. 模块边界

- **解决的问题**：让内部评审者能在业务页面上完成组件级需求、数据状态与修订结果核对。
- **承接内容**：评审信息显隐、局部追溯、状态说明、角色模拟、模块复核状态、全局汇总入口。
- **不承接内容**：真实权限切换、飞书写入、业务数据编辑、正式会签签字、业务功能下钻。

## 2. 用户入口与角色

| 评审角色 | 入口 | 核心目标 |
| --- | --- | --- |
| 体验评审者 | 顶部用户菜单的评审开关；模块标题旁 `IconFile` | 按模块核对交互、解释和验收点。 |
| 语义/数据评审者 | 指标旁 `ⓘ`、`🧪`、`⚠️`；全局抽屉 | 判断口径、Mock 和开放项。 |
| 合规/交付评审者 | 全局评审抽屉 | 汇总 TRACE、门禁、问题与修订证据。 |

## 3. 信息架构

```text
内部评审模式
├─ 顶部用户菜单
│  └─ 评审模式开关（仅显隐；关闭后唯一重新开启入口）
├─ 页面级评审容器（仅开启时）
│  ├─ 当前版本 / 页面 / 角色模拟摘要
│  └─ 全局评审抽屉
│     ├─ 模块复核清单
│     ├─ USM / TRACE / 门禁与纪要链接
│     └─ 远端演示与修订证据
└─ 业务页面内的小模块
   ├─ 轻量复核状态
   ├─ ⓘ 局部追溯与验收点
   ├─ 🧪 Mock / 待接入说明
   └─ ⚠️ 开放项 / 风险说明
```

## 4. 节点职责

| 节点 | 页面职责 | 路由 / 状态 | 追溯 |
| --- | --- | --- | --- |
| 顶部用户菜单开关 | 显示或隐藏评审辅助信息 | 当前内部会话；默认开启；关闭后页面无残留入口 | `US-REV-02` |
| 页面级评审容器 | 挂载整体需求与原型说明 | 仅评审模式开启时渲染 | `US-REV-01` |
| 模块 `IconFile` | 展示当前模块的来源子项、解释、验收点和关联指标 | 卡片/图表/控件标题旁 | `US-REV-01` |
| `🧪`、`⚠️` | 说明数据真实性或待定风险 | 当前字段/卡片旁 | `US-REV-02` |
| 模块复核状态 | 呈现走查进度，不作正式审批 | 当前模块标题旁 | `US-REV-03` |
| 全局评审抽屉 | 汇总整页评审资料和外部证据链接 | 页面级入口 | `US-REV-01~03` |

## 5. 跨模块边界

| 来源或去向 | 可携带内容 | 不可携带 / 不可承担内容 |
| --- | --- | --- |
| 业务模块 | 模块名称、来源号、验收点、关联指标、Mock/Pending 状态 | 不改变模块业务操作、路由或数据权限。 |
| 评审纪要 / 飞书 | 问题编号、链接、修订版本证据 | 不从页面直接创建或更新外部任务。 |
| PDR/V1/V2/门2会签 | 门禁结果、签字文件链接 | 不以模块“已通过”替代正式会签。 |

## 6. IA 自检

- [x] 评审信息按页面级汇总与模块级内联分层。
- [x] 模块内联只展示局部证据，不重复整页需求。
- [x] 评审角色与业务产品角色、权限 persona 分离。
- [x] 页面不变更真实权限、不直接写飞书。
- [ ] 待确认关闭后的持久化方式与全局抽屉视觉形态。
