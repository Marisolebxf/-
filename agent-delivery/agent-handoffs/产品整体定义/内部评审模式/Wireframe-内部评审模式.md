## 1. Frame 清单

| Frame | 触发入口 | 目的 | 追溯 |
| --- | --- | --- | --- |
| 页面级评审默认态 | 内部用户打开远端演示 | 显示页面级评审容器与全局入口 | `US-REV-01~03` |
| 评审关闭态 | 顶部用户菜单关闭评审模式 | 隐藏整块页面级评审容器和所有评审辅助信息 | `US-REV-02` |
| 模块局部追溯态 | 点击模块标题旁 `IconFile` | 核对该模块的来源、解释、验收和指标 | `US-REV-01` |
| 数据/开放项态 | 查看 `🧪` / `⚠️` | 区分 Mock、待接入和待确认事项 | `US-REV-02` |
| 全局评审抽屉 | 点击页面级评审入口 | 汇总模块状态、文档和外部证据 | `US-REV-03` |

## 2. Frame：页面级评审默认态

```text
┌──────────────────────────────────────────────────────────────┐
│ 当前业务页面                                              │
│ 页面级评审容器（仅开启时）：整体需求 / 原型说明 / 抽屉入口 │
├──────────────────────────────────────────────────────────────┤
│ 小模块标题  [待核对]  IconFile                              │
│ 业务内容                                      🧪 / ⚠️（如有） │
└──────────────────────────────────────────────────────────────┘
```

| 区块 / 控件 | 用户目的 | 字段 / 编号 | 默认与联动规则 |
| --- | --- | --- | --- |
| 顶部用户菜单开关 | 隐藏/显示评审辅助信息 | `reviewMode` | 内部默认开；关闭后为唯一重新开启入口；不改变权限和业务数据。 |
| 页面级评审容器 | 挂载整体需求、原型说明和汇总入口 | 版本、页面、角色模拟 | 只在评审模式显示；关闭后整块隐藏。 |
| 模块状态 | 快速知道走查进度 | 待核对/有问题/待复核/已通过 | 只在评审模式显示；不等同正式门禁。 |
| 模块 `IconFile` | 查看局部追溯 | TRACE `leaf_id`、原文子项、`M_*`、`Q-*` | 只绑定当前模块；不显示整页需求。 |

## 3. Frame：模块局部追溯态

```text
┌─────────────────────────────────────────────┐
│ 未来产业企业数量排名                         │
│ 来源：E-32 · 企业总体数量                    │
│ 当前解释：按企业数排名；单/双产业趋势核对    │
│ 验收：最多两项对比；不足两点隐藏趋势          │
│ 指标：M_ENT_TOTAL_COUNT                      │
│ 状态：🧪 演示数据   ⚠️ 口径待确认（如有）    │
└─────────────────────────────────────────────┘
```

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 点击 `IconFile` | 打开当前模块的轻量 Popover/Popover 内详情。 | 不展示整页 E-32 原文或其它模块信息。 |
| 点击 `🧪` / `⚠️` | 展示数据状态、关联 `M_*` / `Q-*` 与处理说明。 | 不把 Mock 表述为已接入正式数据。 |
| 关闭评审模式 | 收起局部信息并隐藏图标。 | 不改变当前业务筛选、地图或图表状态。 |

## 4. Frame：全局评审抽屉

```text
┌──────────────────────────────────────────────┐
│ 当前页面评审                                  │
│ 版本 / 页面 / 角色模拟                         │
├──────────────────────────────────────────────┤
│ 模块复核清单                                  │
│ - 顶部 KPI              已通过 / 待复核       │
│ - 产业数量排名          待核对                │

├──────────────────────────────────────────────┤
│ 文档：USM | TRACE | IA | Wireframe | 纪要     │
│ 外部证据：远端演示 | 修订版本 | 录屏/截图     │
└──────────────────────────────────────────────┘
```

## 5. 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 评审开启 | 显示页面级入口、状态、`ⓘ / 🧪 / ⚠️` | 选择模块走查。 |
| 评审关闭 | 隐藏整块页面级评审容器和所有评审辅助信息 | 正常使用业务页面；仅通过顶部用户菜单再次开启。 |
| 待核对 | 中性状态标签 | 按验收点开始走查。 |
| 有问题 | 警示状态标签；关联外部问题编号/链接 | 在纪要、飞书人工登记并安排修订。 |
| 待复核 | 提示修订版本待验证 | 核对修订证据和验收点。 |
| 已通过 | 成功状态标签 | 等待正式门禁/后续版本变更。 |

## 6. 响应式与视觉约束

- **屏幕层级**：仅中屏（PC 工作台）；科技专题服务系统不做手机端评审模式。
- **设计系统**：`agent-delivery/Design.md`；遵循浅蓝白工作台和 Arco 组件规则。
- **呈现原则**：不遮挡业务主内容；模块信息优先 Popover，整页汇总使用抽屉；状态使用文字加色彩，不只依赖颜色或图标。
