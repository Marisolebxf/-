## 模块目标

本模块包含两个相邻但输入不同的任务：先按范围、产业和企业类型理解重点企业结构并形成企业集合；再对明确选择的 1～N 家企业分析其业务、产品、技术标签所映射的产业领域。模块不承担企业能力评分、风险评分、引育推荐指数、城市对标或重点企业门户概览。

## 用户故事

### US-KEYENT-01 按产业和企业类型发现对象

作为政府产业治理人员，我想在指定区域范围和时间内按产业以及外企、高企、小微、上市等企业类型筛选，以便理解重点企业总体结构并形成可继续使用的企业集合。

### US-KEYENT-02 透视区域企业结构

作为园区招商与企业服务人员，我想在已限定的区域范围内通过地图逐级查看国家、省、市的企业数量、规模、占比和集聚特征，并在区县展示企业点位，以便识别空间分布、同级差异并查看明确范围的企业清单。

> 国家/省/市为 Bid 直接需求；市级继续到区县并展示企业点位，是遵循系统地图一致性的 `product_interpretation`，不新增区县分析指标层。

### US-KEYENT-03 分析指定企业的领域布局

作为投资机构产业研究人员，我想选择一家或多家重点企业，查看其业务范围、产品线和技术标签如何映射到产业领域，并计算覆盖广度、参与深度和多元化程度，以便识别核心赛道及新兴布局方向。

> `DEC-KEYENT-DOMAIN-PRODUCT-LANGUAGE-20260723`：业务页面以“已选企业、领域布局概览、企业领域覆盖、跨领域布局、重点领域分布、领域识别依据”表达任务；Frame 名、组件名和数据结构名只用于内部定义。

### US-KEYENT-04 编组并复用企业对象

作为园区招商与企业服务人员，我想把类型分析得到的企业加入对比篮，也能从对比篮选择企业发起领域分布分析，以便在发现对象与指定对象分析之间连续工作。

> 本故事为 `product_interpretation`：Bid 要求 E-21 形成匹配企业集合、E-22 选择一家或多家企业，但未直接规定“对比篮”。

### US-KEYENT-05 查看映射依据并继续研判

作为政府产业治理人员，我想查看企业业务、产品、专利等领域映射依据，并把选定企业带入画像或其他研判模块，以便验证结论并继续工作。

## 场景 walkthrough

### 主路径 A：类型与区域分析

1. 用户进入“重点企业分析”，页面先显示两个分析类型 Tab，默认选中“类型与区域分析”。
2. 当前 Tab 下方显示其专属输入：区域范围、时间、产业、企业类型；页面共享位置仅显示一次“数据更新至”。
3. 用户修改顶部区域范围后，系统重置“重点企业空间分布”地图到该范围根节点，并刷新匹配企业数、覆盖企业类型数、覆盖区域数和区域洞察。
4. 用户在地图内通过面包屑和区域对象逐级浏览。地图下钻只改变局部地图状态，不反向修改顶部区域条件，也不出现第二个区域选择器。
5. 在国家层查看省级对象，在省层查看城市对象，在市层继续到区县展示层；到区县后显示企业点位。所有浏览均受顶部范围约束。
6. 右侧“区域洞察”同步展示当前地图区域概览和企业类型结构。只有存在至少 2 个真实同级区域时，才显示同级区域排行或区域×类型矩阵。
7. 用户点击洞察标题区的紧凑次级动作“查看企业清单（N）”；若已选类型，则入口可写“查看高企清单（N）”。
8. 系统在右侧宽 Drawer 展示来源摘要、企业列表、搜索/筛选和多选操作；用户可加入对比篮。
9. 关闭 Drawer 后保留顶部条件、地图层级、当前选中区域和滚动位置。

### 主路径 B：从对比篮分析指定企业

1. 用户在对比篮选择 1～N 家企业，发起“重点企业领域分布分析”。
2. 页面直接进入“领域分布分析”Tab；其专属输入区展示对象清单、对象来源和“返回对比篮”。类型分析的区域、产业和企业类型条件不显示，也不参与计算。
3. 系统校验 `enterprise_codes[]`，去重并汇总无效对象。
4. “已选企业”展示本次对象及来源；系统基于业务范围、产品线和技术标签形成领域识别关系。
5. “领域布局概览”展示已覆盖领域、涉及企业、跨领域企业和识别依据；“企业领域覆盖”“跨领域布局”“重点领域分布”共同使用同一对象集。
6. 用户可打开“领域识别依据”，理解为什么识别为某一领域，并进入企业画像或其他研判模块。
7. Q013 未闭合前，覆盖广度、参与深度和多元化指数不在业务模式占位，仅在评审模式保留指标定义和 Pending。
8. 返回对比篮时恢复篮内选择；切回类型分析时恢复其独立条件，但不把企业对象当成类型筛选。

### 路径 C：无对象进入领域分析

1. 用户直接点击“领域分布分析”Tab或打开兼容链接。
2. 页面显示对象待选择态和对比篮入口。
3. 系统不得用类型分析的全部匹配企业自动补齐对象。

## 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 默认条件无匹配企业 | 保留专属条件与稳定空态，不自动放宽 | 修改条件 |
| 顶部区域变化 | 重置地图到新范围根节点并清除越界局部选择 | 在新范围内浏览 |
| 地图下级无数据 | 当前层显示“暂无数据”，保留地图返回 | 返回上一级 |
| 同级区域不足 2 个 | 不显示同级排行与区域×类型矩阵，不补造对象 | 查看当前区域洞察 |
| 企业规模/区域占比缺数据 | 省略字段或使用业务可理解不可用态 | 继续查看其他有效指标 |
| 企业点位缺坐标 | 聚合数保留，点位层显示“暂无可定位企业” | 打开企业清单 |
| 对比篮未选企业 | 分析任务不可发起并提示至少选择 1 家 | 选择企业 |
| 部分编码无效 | 移除并汇总，剩余对象继续 | 继续或返回补选 |
| 全部对象无效 | 显示对象空态 | 返回对比篮 |
| Q010/Q012/Q013 未闭合 | 业务模式不显示内部编号；评审模式挂 Pending | 评审人员查看挂点 |
| 数据/算法内部信息缺失 | 不阻断业务界面；评审追溯中标缺口 | 继续业务或内部补齐 |

## 业务模式禁止行为

- 不得把两类分析条件放在 Tab 之前形成“全局条件”错觉。
- 不得在地图内设置第二个可编辑区域选择器，不得让地图下钻反向改写顶部范围。
- 不得用柱状图、静态卡片替代地图，不得把地图压缩成小卡片并留下大量空白。
- 不得固定显示只有一个对象的区域比较表；没有至少两个真实同级区域时不显示比较。
- 不得用贯穿洞察卡片的主按钮承载企业清单入口，也不得点击地图后突兀打开列表。
- 不得在业务模式显示“产品解释”“数据说明”“尚未接入”“正式指标”“Mock”“GAP”“Q010/Q012/Q013”“calc_batch_id”等内部内容。
- 不得用高企占比冒充区域企业占比，不得在各行政层复用同一企业总数冒充真实聚合。
- 不得把多标签企业类型按互斥分类计算“主导类型占比”，不得在顶部重复右侧区域类型结构。
- 不得在类型结构图下重复显示顶部已有的企业类型条件或“全部重点企业类型”状态行。
- 不得把类型分析全部匹配企业自动作为领域分析对象。
- 不得把“领域分析对象、领域分布结果、企业 × 领域矩阵、跨领域布局图谱、领域明细、映射依据”等内部定义名原样平铺为业务标题。
- 不得在 Q013 未闭合时用连续“暂不可用”KPI 卡片占据业务主视图。
