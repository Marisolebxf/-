## 3. 用户故事

### US-ENT-EVAL-OBJ｜接收和确认评估对象

**作为**任一有权评估的产品角色，**我想要**从对比篮自动带入或在评估页添加企业，**以便**不重复选择对象并保留返回现场。

- 接收 `enterprise_codes[]`、`source=compare-basket`、`analysis_type`、`return_context_id`。
- 显示“来自对比篮 · X 家”和企业名称；有效对象自动成为本次对象。
- 本次增删不回写或清空对比篮；返回同一上下文时恢复篮内筛选、勾选和滚动位置。
- 无权 / 失效对象剔除后明确提示；仍需按模式重新校验最少对象数。

### US-ENT-EVAL-TECH｜配置技术力评估

**作为**政府、园区、投资研究、行业协会或企业自身用户，**我想要**用至少两家企业的技术指标和可调整权重创建技术力评估，**以便**比较技术能力、排名和差异。

- 可加载系统 / 个人模板，选择技术力指标并当次调权。
- 关联 `M_ENT_TECH_POWER_SCORE`、`M_ENT_TECH_RANK`、`M_ENT_PATENT_GRANT_COUNT`、`M_ENT_RD_INVESTMENT_RATIO`。
- 两家显示双企业雷达、差异和排名；三家及以上改用排名 / 条形 / 矩阵 / 明细。

### US-ENT-EVAL-BIZ｜配置商业力评估

**作为**上述产品角色，**我想要**用至少两家企业的经营指标和可调整权重创建商业力评估，**以便**识别经营竞争力和短板。

- 关联 `M_ENT_BUSINESS_POWER_SCORE`、`M_ENT_REVENUE_LATEST`、`M_ENT_REVENUE_GROWTH_RATE`、`M_ENT_PROFIT_MARGIN`、`M_ENT_MARKET_SHARE`。
- 两家显示得分、排名、关键经营指标对比与短板；三家及以上使用排名 / 条形 / 矩阵 / 明细。
- 市场份额在 `Q019` 未闭合前标为不可用，不以样例数据替代正式口径。

### US-ENT-EVAL-COMP｜配置综合竞争力评估

**作为**上述产品角色，**我想要**从至少一家企业出发配置维度权重和维度内指标权重，**以便**获得综合竞争力画像与短板。

- 关联 `M_ENT_COMPETITIVENESS_SCORE`、`M_ENT_COMPETITIVENESS_RANK`、`M_ENT_SHORTBOARD_COUNT`、`M_ENT_INNOVATION_INDEX`。
- 一家展示维度雷达和短板；两家展示双企业维度雷达与差距；三家及以上使用排名 / 矩阵 / 差异。
- 维度权重与维度内权重分层配置，默认折叠展开，避免单表混淆。

### US-ENT-EVAL-QUALITY｜校验模板、权重和数据质量

**作为**评估发起人，**我想要**在生成前看清指标有效性、权重错误、数据覆盖和可信度，**以便**避免把不可比或缺数据的结果当成正式结论。

- 权重用 0～100 的整数输入；支持一键平均分配，不静默自动归一化。
- 所需权重层级都必须合计 100；错误定位到具体维度 / 指标。
- 缺失不记 0；覆盖度 <50% 或关键指标全部缺失时阻止生成。
- 每家企业分别给出高 / 中 / 低可信度；数据结构不同提示可比性风险。

### US-ENT-EVAL-RESULT｜生成并理解正式结果

**作为**评估发起人，**我想要**生成有任务快照、指标依据和可信度说明的正式结果，**以便**复核结论并采取后续行动。

- 只有用户明确生成且后台成功，才创建 `evaluationTaskId` 和历史记录。
- 结果固定关联对象、模式、模板版本、权重、数据批次、算法版本、权限范围和生成时间。
- 页面先给 4 个以内 KPI 和一个结论条，再展示模式适配图表、明细及短板。
- 内部评审模式在页面 / 配置 / 关键结果标题展示正确 REQ 追溯；业务模式隐藏。

### US-ENT-EVAL-REPORT｜生成受控评估报告

**作为**有报告权限的评估发起人，**我想要**从结果页提交后台报告任务并查看状态，**以便**获得可审计、可下载的评估材料。

- 仅结果页提供报告；默认 PDF，Word 后续开放。
- 状态为提交、数据准备、评分计算、图表生成、报告组装、完成 / 失败。
- 同指纹的处理中或有效报告复用，不由前端缓存冒充后台事实。
- 下载受字段分级、脱敏 / 审批、对象数量、报告模板和审计约束。

### US-ENT-EVAL-HISTORY｜找回和复用评估任务

**作为**评估发起人，**我想要**查看最近正式评估并恢复结果或基于旧配置创建新任务，**以便**持续研判而不覆盖历史事实。

- 展示任务 ID、模式、企业摘要、模板 / 版本、数据批次、时间、可信度和报告数。
- 支持恢复结果、基于配置新建、查看关联报告。
- “基于配置新建”复制配置形成新草稿，不覆盖旧任务；历史不扩展为团队协作或复杂版本管理。

## 4. 主路径

### 4.1 从对比篮发起

1. 用户在对比篮选择企业和评估类型，确认“下一步：前往配置”。
2. 企业评估解析对象并显示来源；用户处理无权 / 失效对象提示。
3. 页面按 `analysis_type` 打开对应模式，用户加载模板并调整指标 / 权重。
4. 预检展示每家企业的数据覆盖和可信度，阻止不满足条件的生成。
5. 用户触发生成，后台按登记算法 / ADS 计算并固化任务快照。
6. 结果页展示结论、可视化、明细、短板和报告入口。
7. 用户可返回对比篮恢复现场，或进入最近评估找回任务。

### 4.2 直接进入

1. 用户从企业中心进入企业评估，选择模式。
2. 用户添加有权企业，或主动选择“从对比篮带入”。
3. 后续与主路径第 3～7 步一致。

## 5. 异常与权限路径

| 场景 | 系统行为 | 用户可行动作 |
| --- | --- | --- |
| 无对象 | 展示空态，不加载空图表 | 添加企业 / 从对比篮带入 |
| 对象数量不足 | 技术力 / 商业力少于 2 家时说明原因 | 继续添加或切换综合竞争力 |
| 对象无权或失效 | 剔除无效对象并逐类汇总提示 | 使用有效交集或返回对比篮 |
| 权重不等于 100 | 阻止生成并定位层级，不自动归一化 | 修改或一键平均分配 |
| 部分指标缺失 | 不记 0，重算可用指标并降低可信度 | 查看缺失说明后继续或换对象 / 指标 |
| 覆盖度 <50% / 关键指标全缺 | 禁止正式生成 | 更换对象、指标或等待数据 |
| 低可信度 | 允许生成但显著警示；报告同步带入 | 确认继续或返回调整 |
| 生成中 | 保留任务进度，防止重复提交 | 离开后从最近评估查看 |
| 生成失败 | 保留失败阶段与可审计错误编号 | 重试或基于配置新建 |
| 无报告权限 | 保留入口位置并说明权限原因 | 查看在线结果 |
| 同指纹报告已存在 | 复用处理中 / 有效任务 | 查看状态或下载 |
