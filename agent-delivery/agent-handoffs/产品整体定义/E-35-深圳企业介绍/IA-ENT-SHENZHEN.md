# IA-ENT-SHENZHEN

> **模块**：E-35 深圳企业介绍
> **阶段**：门 1 PDR 输入
> **体验 Owner**：高颖
> **范围真源**：`bid-reference/智慧服务门户系统-要素相关.md` → `1.1.1.1.1.1.1.4 深圳企业介绍`

## 1. 模块边界

- **解决的问题**：用户了解深圳在八大未来产业中的企业数量、领域、规模和重点企业发展状况。
- **承接内容**：深圳企业数量及趋势、深圳企业领域分布、深圳企业规模分析、深圳重点企业。
- **不承接内容**：全国/城市对标、产业链角色下钻、企业评价评分、供应链风险、招引培育、复杂筛选、企业清单下钻、导出和 CMS 编辑。
- **地域边界**：全页固定深圳市；八大未来产业是统计分组，不是地理筛选。
- **内容责任**：数据侧提供统计和映射；CMS 提供已发布本地企业介绍与专家观点；前台只读消费。

## 5. 分类与字段边界

### 资质荣誉

复用系统通用枚举：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

### 企业性质与规模

- “国有企业”通过 `enterprise_nature=国有` 表达，不并入资质荣誉。
- 企业规模候选分类为大型、中型、小型、微型；正式阈值和数据字段由 Q049 确认。
- “小微”资质标签与“小型/微型”规模分类不可直接互换。
