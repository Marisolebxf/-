## 模块：E-35 深圳企业介绍

深圳企业介绍是企业总览中的深圳地域专题，以深圳企业群体为观察对象，按八大未来产业展示企业数量与历年趋势、领域分布、规模分布和重点企业情况。它固定深圳地域，不承担全国或城市横向对标、产业链角色下钻、企业评价模型、供应链风险、复杂筛选或导出。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 访客（未登录用户） | E-31 已确认门户公开信息角色；原始需求为深圳企业发展状况展示 | 快速了解深圳在八大未来产业中的企业数量、结构与代表企业。 |
| 科研人员 | E-31 已确认产品角色；原始需求包含产业领域分布 | 理解深圳企业在各未来产业链领域中的分布及重点方向。 |
| 政府科技管理与决策部门 | 原始需求强调统一框架下分析深圳企业发展状况 | 查看深圳企业趋势、产业结构、规模结构和重点企业基础。 |

## 用户故事

### US-E35-01 查看深圳企业数量与趋势

作为政府科技管理与决策部门用户，我想按八大未来产业查看深圳企业数量和历年趋势，以便理解深圳企业发展的总体规模与变化。

### US-E35-02 查看深圳企业领域分布

作为科研人员，我想结合各未来产业链全景查看深圳企业在产业领域中的分布，以便识别深圳企业较集中或覆盖不足的领域。

### US-E35-03 查看深圳企业规模结构

作为政府科技管理与决策部门用户，我想比较八大未来产业中深圳企业的大、中、小、微规模分布，以便理解不同产业的企业梯度结构。

### US-E35-04 浏览深圳重点企业

作为访客，我想按未来产业浏览深圳重点企业的公开基础档案、企业性质和资质荣誉，以便认识本地具有代表性的企业并进入企业画像。

## 口径与分类规则

### 固定地域与产业分组

- 地域固定为深圳市，不提供全国、省际或城市切换。
- 默认以八大未来产业作为数量、趋势、规模和重点企业的统计分组，不默认收窄为单一产业。
- 领域分布允许在区块内轻量聚焦一个未来产业并查看其产业链领域分布；只更新展示摘要，不进入企业集合或产业链角色下钻。

### 资质荣誉与企业性质

深圳重点企业复用企业查询/企业档案的系统通用资质荣誉枚举：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

“高企”统一展示为“国高企”。“国有企业”属于企业性质 `enterprise_nature`，不加入资质荣誉枚举；同一企业允许多资质标签展示。

## 场景 walkthrough

### 主路径

1. 用户从企业总览切换到“深圳企业介绍”，页面稳定显示科技专题服务、深圳市、八大未来产业和数据批次。
2. 首屏展示深圳企业总数、重点企业数、上市企业数、国有企业数等公开概况；没有正式 metric_id 的字段标记 DEMO/Q049。
3. 用户查看八大未来产业的深圳企业数量对比和历年趋势；只有连续可比数据满足条件时展示正式趋势。
4. 用户在领域分布区聚焦某一未来产业，查看该产业链领域/环节中的深圳企业分布摘要。
5. 用户查看八大未来产业的大、中、小、微企业规模结构；正式分级口径未确认前标记待确认/DEMO。
6. 用户按未来产业浏览深圳重点企业卡，查看企业名称、区域、企业性质、资质荣誉和 CMS 已发布的定位/优势摘要；点击名称进入统一企业画像。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 八大未来产业目录或映射未确认 | 使用独立 DEMO 数据结构并明确“模拟产业目录”，不冒充正式目录 | 浏览页面结构与交互 |
| 只有一个有效时间点 | 隐藏正式趋势图，不显示单点折线或机械补齐历史 | 查看当前批次数量 |
| 某产业无深圳企业 | 保留产业分组并显示 0/无数据，说明数据批次 | 查看其他产业 |
| 产业链领域映射不足 | 显示“领域映射待完善”及覆盖情况，不生成虚假链位分布 | 切换产业或查看数量结构 |
| 规模口径未确认 | 大/中/小/微结构标 DEMO/Q049，不将资质标签当作规模 | 查看演示结构说明 |
| 深圳重点企业未配置 | 显示业务空态，不用明星企业或外地企业补位 | 查看其他统计区块 |
| CMS 介绍未发布 | 仅展示数据侧公开基础档案，隐藏未发布专家观点 | 进入企业画像查看公开信息 |
| 加载或接口失败 | 使用稳定骨架；局部失败隔离并提供重试 | 重试失败区块 |
| 无权限查看非公开字段 | 隐藏非公开字段和 CMS 草稿，不影响公开统计 | 浏览公开内容 |

## 模块边界与依赖

- 深圳企业清单、产业归属、统计批次、指标和产业链领域映射依赖数据侧，正式口径由 Q049 闭合。
- 重点企业识别标准复用 Q038；本页不自行计算或修改阈值。
- 深圳本地企业的定位、优势和专家观点只消费 E-37 CMS 已发布内容。
- 企业基础档案、企业性质和资质荣誉复用企业查询/统一企业画像的数据定义。
- 页面不提供 CMS 编辑、查询式筛选、清单下钻、对标、评估、风险、推荐或导出。
