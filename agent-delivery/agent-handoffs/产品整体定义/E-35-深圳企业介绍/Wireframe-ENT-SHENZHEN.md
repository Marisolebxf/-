### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 共享上下文 | 确认统计范围 | `topic_service`、`region_code=440300`、`future_industry_scope`、`data_batch` | 地域固定深圳；全页默认八大未来产业 |
| 概况 KPI | 快速了解总体及代表企业基础 | 企业总数、重点企业数、上市企业数、国有企业数：`metric_id: null`，Q049 / DEMO；重点判定 Q038 | 只展示当前批次值与单位，不显示无依据比较百分比 |
| 八产业数量对比 | 比较深圳企业产业分布 | `shenzhen_enterprise_count_by_industry`：`metric_id: null`，Q049 / DEMO | 默认展示八个产业；点击只更新轻量说明，不进入企业清单 |
| 历年趋势 | 理解数量变化 | `shenzhen_enterprise_count_trend`：`metric_id: null`，Q049 / DEMO | 正式有效可比点≥2才显示；不足时该区隐藏并由数量对比占满 |
| 领域分布 | 理解产业领域覆盖 | `shenzhen_enterprise_domain_distribution`：`metric_id: null`，Q049 / DEMO | 默认八产业概览；聚焦单产业后显示该产业链领域/环节摘要 |
| 产业链摘要 | 理解领域与链的对应 | 产业链名称、领域/环节、企业数量或结构、映射覆盖 | 不显示企业集合，不做链位角色下钻 |
| 规模分析 | 理解企业梯度 | `shenzhen_enterprise_scale_distribution`：`metric_id: null`，Q049 / DEMO | 八产业 × 大中小微；正式阈值待确认 |
| 重点企业卡 | 认识代表企业 | 企业名称、行政区、`enterprise_nature`、资质荣誉、公开摘要、数据时间 | 按八产业组织；名称进入画像，不提供勾选/批量操作 |
| CMS 摘要 | 理解本地定位与优势 | 定位、优势、专家观点、发布状态 | 只展示已发布内容；缺失时不影响基础档案 |

### 2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 点击数量对比中的产业 | 高亮产业并更新旁侧轻量说明 | 不收窄全页统计，不进入企业集合 |
| 在领域区选择未来产业 | 更新对应产业链名称、领域/环节分布和映射覆盖 | 不把多条产业链混为一条，不进入产业链角色分析 |
| 点击领域或环节 | 展示该领域的数量/结构摘要 | 不弹出企业清单，不加入对比篮 |
| 点击规模分段 | 高亮当前产业/规模组合并显示数量说明 | 不跳转查询，不把“小微”资质当规模分段 |
| 点击重点企业名称 | 进入统一企业画像并携带来源 `E-35` | 不在本页开放评估、风险、招引或培育动作 |
| 点击资质荣誉 | 展示标签解释或企业公开事实 | 不作为筛选器，不生成评分 |

### 2.4 领域单产业聚焦态

| 区域 | 展示规则 |
| --- | --- |
| 聚焦产业 | 显示未来产业全称；可返回八产业概览 |
| 当前产业链 | 显示产业链全称；多链时仅在该区轻量切换，一次展示一条 |
| 领域/环节分布 | 展示深圳企业数量或结构及映射覆盖情况，正式 metric_id 待 Q049 |
| 禁止项 | 不展示企业名单、链位角色、城市对标、短板评分或供应链风险 |

### 2.5 深圳重点企业卡片

| 字段 | 规则 |
| --- | --- |
| 基础档案 | 企业名称、深圳行政区、成立时间或简介等公开字段 |
| 企业性质 | 使用独立 `enterprise_nature`；“国有”不并入资质荣誉 |
| 资质荣誉 | 统一枚举：外企、国高企、小微、上市、专精特新、小巨人、链主龙头、独角兽、瞪羚 |
| 产业归属 | 用于八大未来产业分组；不与企业类型/资质混用 |
| 定位与优势 | 只展示 CMS 已发布摘要；专家观点标明内容来源和时间 |
| 入口 | 企业名称进入统一企业画像；无勾选、批量、评估或导出动作 |

### 2.6 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 深圳固定地域 + 八产业四项内容完整展示 | 浏览区块 |
| 加载 | KPI、图表、领域和卡片使用稳定骨架 | 等待 |
| 目录/映射 DEMO | 显示模拟产业目录、DEMO 和 Q049，不冒充官方目录 | 评审结构与交互 |
| 单时间点 | 隐藏趋势，数量对比自动占满整行 | 查看当前值 |
| 某产业 0 数据 | 保留产业项并显示 0/无数据及批次 | 查看其他产业 |
| 领域映射不足 | 显示映射覆盖和“待完善”，不生成虚假分布 | 切换产业 |
| 规模口径待确认 | 显示 DEMO/Q049，不把资质标签代替规模 | 查看说明 |
| 重点企业未配置 | 显示业务空态，不用外地或明星企业补位 | 浏览统计区块 |
| CMS 部分缺失 | 展示基础档案，隐藏未发布定位/观点 | 进入企业画像 |
| 接口错误 | 局部错误隔离并提供重试 | 重试失败区块 |
| 无权限 | 隐藏非公开字段和 CMS 草稿 | 浏览公开内容 |

## 3. 内部评审模式

- 每个 KPI/图表展示字段名、数据批次、`metric_id` 状态和 Q049。
- 重点企业标识显示 Q038 来源说明；E-35 不重新计算重点企业。
- 八大产业目录、深圳企业归属、产业链领域映射和规模分级显示 DEMO/正式状态。
- CMS 定位、优势和专家观点显示发布状态；草稿不得作为前台内容。
- 资质荣誉、企业性质、企业规模三个分类体系分别标明来源，避免混用。

## 4. 响应式与视觉约束

- **屏幕层级**：medium；PC 门户工作台，不建设手机端。
- **布局**：数量对比与趋势可双栏；趋势隐藏后数量对比占满；领域、规模和重点企业纵向展开。
- **设计系统**：遵循 `Design.md` 和 Arco 公共组件；图例、标签、空态和 DEMO 状态使用统一语义。
- **裁剪规则**：窄中屏图表改为单栏；不出现整页横向滚动；产业链分布只在区块内滚动/切换。
