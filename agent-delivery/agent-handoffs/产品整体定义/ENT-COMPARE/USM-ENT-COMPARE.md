## 模块定位

对比篮是系统级基础业务对象暂存与分发浮层，规划承接企业、产业链、政策文档、服务机构和区域五类对象。当前一期只完整迁移企业对象能力；产业链、政策、服务机构和区域 Tab 仅显示开发中占位。它不占用企业分析左侧二级菜单，也不生成任何对比或分析结果。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府科技管理与决策人员 | E-20 明确企业分析面向政府 | 将重点企业集合送入评估、风险研判或政策服务动作 |
| 产业园区运营 / 企业服务人员 | E-20 明确企业分析面向园区 | 汇集园区关注企业，维护候选集合并衔接招引 / 培育 |
| 投资机构产业研究人员 | E-20 明确企业分析面向投资机构 | 从检索和画像中暂存候选企业并开展横向研判 |

### 实现角色映射

| 产品角色 | 当前能力要求 | 映射用途 |
| --- | --- | --- |

## 用户故事

### US-ENT-CMP-01 收集企业并保持全局一致

作为政府、园区或投资机构用户，我想从企业查询、总览、重点企业分析和画像中加入企业，以便跨页面持续积累同一个待分析对象集合。

- 同一企业按企业 ID / 统一社会信用代码全局去重。
- 已加入企业在所有入口显示“已加入”；再次点击执行移除。
- 新来源重复加入不新增记录，可追加来源并更新最近操作时间。

### US-ENT-CMP-02 找回并管理单用户单篮

作为业务用户，我想从系统 Shell 的对比篮入口打开浮层，并在刷新或跨页面后恢复最近一次对比篮，以便通过搜索、轻筛、选择、移除和清空继续未完成的研判准备。

- 对比篮入口在已登录后的业务页面保持可访问，显示“共 X 项”；本期 X 只统计企业对象。企业 Tab 显示 `X/50`，企业分析左侧不再出现“对比篮”二级菜单。
- 点击入口在当前页面展开对比篮浮层，不先跳转到独立页面；旧 `/enterprise-center/basket` 链接只负责兼容并打开浮层。
- 默认最多 50 家，按最近操作时间倒序。
- 仅支持企业名称搜索和企业类型筛选；统一社会信用代码只作为识别和去重字段。
- 筛选条件旁的恢复动作统一显示“重置”，恢复企业名称和企业类型默认值；不使用“清空筛选”。
- 列表提供“全选当前筛选结果”三态复选框，范围仅为当前企业名称与企业类型筛选下的全部可见企业；当前筛选无结果时不可用。
- 勾选全选将当前可见企业并入已有选择；取消全选只取消当前可见企业；筛选后不可见的既有选择继续保留，“取消选择”清除全部选择。
- “全选当前筛选结果”不承载评审说明，业务 / 评审模式共用同一选择集合；本交互的 `review_mounts: []`。
- 企业卡片不展示统一社会信用代码和加入来源标签；来源仅用于内部追溯，不提供页面筛选。
- 单个移除无需二次确认；清空篮需要二次确认。
- 有对象时筛选区固定在浮层顶部，批量操作栏固定在底部；企业超过可视区域后只滚动中间列表，短列表也不把操作栏上推。

### US-ENT-CMP-03 将对象送入企业评估或风险洞察

作为需要开展专业研判的用户，我想勾选企业后进入企业评估或风险洞察，以便目标模块使用同一对象集合生成正式分析结果。

- 已选对象工具栏使用“发起分析”单一主动作；“取消选择”紧邻“已选 X 家”，只取消勾选，不清空对比篮。
- 点击“发起分析”打开“选择分析任务”浮层；企业评估分组提供技术力评估、商业力评估、综合竞争力评估，风险洞察分组提供供应链关系分析、发展痛难点分析。
- 供应链关系分析只接受 1～2 家企业。已选超过 2 家时该任务仍保留在浮层中，但置灰并显示“最多选择 2 家企业”；用户须返回篮内缩减选择，不静默截断前两家。其他任务不因该规则禁用。
- 选择具体任务只更新浮层内选中态，不立即跳转；选择可用任务并点击“下一步：前往配置”后，才携带 `enterprise_codes[]`、来源、`analysis_type` 和必要上下文进入目标模块。
- 关闭或取消浮层后留在对比篮，篮内容、筛选和勾选不变；未选任务时“下一步：前往配置”不可执行。
- 跳转前保存本次筛选、勾选与滚动位置；目标页显示“来自对比篮 · X 家”并提供“返回对比篮”。
- 目标页直接将 `enterprise_codes[]` 解析为本次分析对象并展示企业名称，不强制二次选对象；3 种企业评估和 2 种风险洞察仍保留“从对比篮带入”，以支持直接进入页面后导入或主动调整对象。
- 从目标页显式返回或浏览器后退时恢复本次工作现场，不自动清空篮或勾选；刷新或从菜单重新进入只恢复篮内容。
- 对比篮不展示评分、雷达、排名、差距、图谱或风险结论。
- 未选择企业时“发起分析”不可执行；权限不足的分析任务在浮层中保留并说明原因。供应链 2 家上限在任务选择浮层前置校验，目标模块仍保留同一规则作为防御校验；其他对象数量、字段和模型条件进入目标模块后再校验。

### US-ENT-CMP-04 加入招引或培育候选

作为政府或园区企业服务人员，我想把选中企业批量加入招引或培育候选名单，以便在引育推荐模块继续形成推荐理由和一企一策。

- 已在候选名单的企业不重复写入。
- 完成后提示“已加入 X 家，Y 家已在名单中”，不自动跳转。
- 对比篮浮层标题区“查看引育名单”提供“招引候选名单 / 培育候选名单”两个入口，进入引育推荐页后自动切换到对应 Tab 并显示已加入对象。
- 推荐理由、建议、名单导出均不在对比篮生成。

### US-ENT-CMP-05 从空篮继续发现企业

作为首次进入或清空篮的用户，我想得到明确的添加入口，以便前往企业查询开始收集对象。

- 主操作为“去企业查询”。
- 空篮说明可从企业查询、重点企业分析、总览或企业画像加入企业。
- 对比篮空态不展示推荐企业。

### US-ENT-CMP-06 与系统任务窗口无冲突地使用可拖动浮层

作为同时使用系统任务与对比篮的业务用户，我想让两个系统入口都保持可访问，并能拖动到不遮挡当前工作的安全位置，以便在任务状态和企业对象集合之间切换。

- 系统任务入口与对比篮入口可同时显示；系统任务无可见任务时沿用既有隐藏规则。
- 系统任务入口默认右上，对比篮入口默认右下，距离视口安全边界与彼此均不小于 16px。
- 同一时间只允许一个系统浮层面板展开。打开对比篮时任务面板自动收起为入口；打开任务面板时对比篮自动收起为入口，收起不清空业务状态。
- 两个入口与各自展开面板标题均可拖动。拖动结束若与另一入口 / 面板重叠，当前浮层吸附到最近无冲突位置并保留至少 16px 间距。
- 当前操作浮层临时置顶；交互结束后回到统一系统浮层层级，不以永久提高层级掩盖碰撞。
- 任务与对比篮位置分别按用户保存；页面切换不重置。窗口缩放或面板尺寸变化后重新夹取与避让，优先保证两个收起入口可访问。
- 两个系统浮层均提供“还原默认位置”；键盘用户无需拖动即可打开、关闭、完成篮内业务操作或恢复默认位置。

### US-ENT-CMP-07 在系统篮中完整使用企业能力

作为当前企业篮用户，我想在新的五 Tab 系统篮中继续使用全部企业篮能力，并保留既有数据与旧链接，以便入口升级不造成对象或工作现场丢失。

- 系统篮按企业、产业链、政策、服务机构、区域排列五个对象 Tab，默认进入企业 Tab。
- 企业 Tab 完整保留企业恢复、搜索、企业类型筛选、三态全选、查看画像、移除、清空、企业评估、风险洞察、招引 / 培育候选和分发返回恢复。
- 五类对象目标容量各自为 50，不共享总额；本期只有企业容量和计数实际生效。
- 既有企业篮数据首次加载时迁移到 `enterprise` 类型空间。迁移须幂等，新结构写入成功前不得删除旧数据。
- 迁移失败时继续读取旧企业篮并显示可重试反馈，不把失败显示成空篮。
- `/enterprise-center/basket` 旧链接打开系统篮并定位企业 Tab，不渲染独立页面。
- 各类型未来独立计数、去重、选择和清空；不同对象类型不得混合发起同一分析任务。

### US-ENT-CMP-08 识别尚未开放的对象类型

作为业务用户，我想在系统篮中看到已经明确规划但尚未接入的对象类型，以便理解后续范围，同时不把占位误认为可用能力。

- 产业链、政策、服务机构、区域四个 Tab 均可进入统一开发中空页。
- 空页明确未来对象分别是产业链 / 细分产业、政策文档、服务机构和行政区域。
- 开发中 Tab 不显示数量、`0/50`、Mock 对象、搜索、选择、添加、分析、清空或批量动作。
- 产业链分析、政策分析、产业服务链分析和综合智能分析来源页本期不出现“加入对比篮”入口。
- 业务模式只显示面向用户的开发中状态；评审模式可额外挂载本次批准范围追溯，但不得改变业务状态。

## 场景 walkthrough

### 主路径 A：发现对象 → 暂存 → 企业评估

1. 用户在企业查询或重点企业分析中发现企业并点击“加入对比篮”。
2. 系统按唯一键去重，反馈“已加入对比篮”，并提供“查看对比篮”。
3. 用户点击系统 Shell 的对比篮入口，在当前页面展开浮层并恢复本人最近单篮，搜索或筛选对象，并逐项勾选或使用“全选当前筛选结果”。
4. 用户点击“发起分析”，系统打开“选择分析任务”浮层；用户在企业评估分组中选择技术力评估、商业力评估或综合竞争力评估，选择后页面不跳转。
5. 用户点击“下一步：前往配置”，系统携带 `enterprise_codes[]`、来源和 `analysis_type` 跳转 `/enterprise-center/evaluation`；目标模块完成对象数量、字段和模型条件校验。
6. 企业评估页显示“来自对比篮 · X 家”、企业名称和“返回对比篮”；带入对象自动成为分析对象，同时保留“从对比篮带入”供主动调整，用户可直接配置指标、权重或模型并开始分析。
7. 用户点击“返回对比篮”或浏览器后退，页面恢复跳转前的筛选、勾选与滚动位置，篮内对象和勾选不自动清空。

### 主路径 B：暂存 → 加入引育候选

1. 用户在对比篮勾选企业。
2. 用户点击“加入招引候选”或“加入培育候选”。
3. 系统校验候选名单写权限并去重写入。
4. 页面提示新增与重复数量，保留当前选择，不自动跳转。
5. 用户可通过右上角“查看引育名单”选择“招引候选名单”或“培育候选名单”，进入 `/enterprise-center/attraction` 对应 Tab 查看已加入对象。

### 主路径 C：任务窗口与对比篮浮层切换

1. 系统任务入口与对比篮入口同时位于应用 Shell；任务面板当前已展开。
2. 用户点击对比篮入口，任务面板自动收起，系统在当前位置展开对比篮浮层；两个收起入口仍保持可访问。
3. 用户拖动对比篮标题，拖动结束位置与任务入口重叠；系统将对比篮吸附到最近安全位置并保留至少 16px 间距。
4. 用户完成篮内操作后收起对比篮，再打开任务入口；对比篮的筛选、选择和篮内容保持不变。
5. 用户调整窗口大小导致已保存位置越界；系统重新夹取并避让两个入口，用户也可通过“还原默认位置”恢复任务右上、对比篮右下。

### 主路径 D：旧企业篮迁移并查看开发中 Tab

1. 已有企业篮数据的用户首次打开系统对比篮，系统先读取旧企业篮并幂等写入 `enterprise` 类型空间。
2. 写入成功后默认进入企业 Tab，企业数量、对象顺序、筛选、选择与可执行动作遵循原企业篮契约。
3. 收起入口显示“对比篮 · 共 X 项”，X 等于当前企业对象数；企业 Tab 显示“企业 X/50”。
4. 用户切换到产业链、政策、服务机构或区域 Tab，看到对应对象类型和“开发中”空页，不出现任何可执行对象操作。
5. 用户返回企业 Tab，先前企业筛选、选择和滚动位置保持不变。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 对比篮为空 | 显示来源说明与“去企业查询”主操作，不展示推荐企业 | 去企业查询 |
| 单个加入已满 50 家 | 不写入，提示“对比篮已满，请移除部分企业后再加入” | 移除对象后重试 |
| 批量加入超限 | 依当前顺序加入剩余容量前 N 家，并提示未加入数量 | 查看篮或调整选择 |
| 重复加入 | 不新增；更新来源 / 最近操作时间并显示已加入反馈 | 查看篮或取消加入 |
| 未选择企业 | 批量动作保持不可执行，提示“请先选择企业” | 勾选企业 |
| 当前筛选无结果 | “全选当前筛选结果”禁用；筛选前已选但当前不可见的企业仍保留在选择集合中 | 重置或调整筛选，或点击“取消选择”清除全部选择 |
| 已打开任务浮层但未选任务 | “下一步：前往配置”保持不可执行 | 选择一个可用分析任务或取消 |
| 取消 / 关闭任务浮层 | 留在对比篮，保留篮内容、筛选和勾选 | 继续选择任务或执行其他批量动作 |
| 权限不足 | 动作置灰或拦截，明确缺少的目标能力，不静默隐藏 | 申请权限或选择可用动作 |
| 返回时部分对象失效 | 按当前篮与权限恢复有效对象交集，提示“已恢复 X 家，Y 家不可用” | 继续使用有效对象或重新选择 |
| 返回上下文失效 | 仅恢复单用户篮内容；筛选、勾选、滚动位置回到默认态 | 重新筛选和选择 |
| 打开对比篮时任务面板已展开 | 任务面板自动收起为入口，对比篮在当前位置展开；任务状态不丢失 | 使用对比篮，或点击任务入口切回 |
| 拖动结束与另一系统浮层重叠 | 当前浮层吸附到最近无冲突位置，保持至少 16px 间距 | 继续使用或再次拖动 |
| 窗口缩放后位置越界 / 空间不足 | 重新夹取和避让；只展开当前活动面板，两个收起入口保持可访问 | 继续使用或还原默认位置 |
| 位置持久化失败 | 保留入口可用并回退默认安全位置，不影响篮内容 | 继续使用；需要时重新拖动 |
| 恢复失败 / 接口错误 | 保持页面壳层，显示错误与重试，不清空本地已知状态 | 重试或返回来源页 |
| 旧企业篮迁移成功 | 企业对象进入 `enterprise` 类型空间且不重复；旧数据只在新结构写入成功后标记已迁移 | 继续使用企业 Tab |
| 旧企业篮迁移失败 | 继续从旧结构只读恢复并提示重试；不显示为空篮、不删除旧数据 | 继续使用或重试迁移 |
| 点击开发中 Tab | 显示对象类型、未来用途和“开发中”空页 | 返回企业 Tab |
| 开发中 Tab 被深链 / 恢复 | 允许显示对应占位，不创建存储、不写入数量 | 返回企业 Tab |

| 原始 / 既有内容 | 当前归位 | 范围影响 | TRACE 动作 |

## PDR 就绪度

对比篮不再承接空态推荐，本模块当前无业务开放项。四件套 v2.0 已冻结系统多对象壳层、五类独立 50 的目标规则，以及“企业完整迁移、其余四类开发中占位”的一期边界；Demo / lumen 的 `GAP-IMPL-06`、`GAP-IMPL-07`、`GAP-IMPL-08` 与 lumen 容量差距仍须在后续 V1 / Demo 对齐中修正。本文件不重新宣告门 1 通过。
