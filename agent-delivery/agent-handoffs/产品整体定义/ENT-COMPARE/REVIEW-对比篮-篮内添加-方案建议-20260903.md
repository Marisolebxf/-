## 1. 评审诉求（原文口径）

从原始页（例如企业竞争力分析）点击打开「对比篮」，查询对比篮中**不存在**的对象时（企业 / 产业 / 服务机构）：

- **不要**跳转到系统对应的查询页面；
- 应支持直接在**【对比篮中查询】**或**【简易查询页】**可点添加；
- 添加后 **原始页不动**。

---

## 2. 问题定性

对比篮定位不变：派生暂存 / 分发容器（Decision 088），不展示分析结果。

变的是补对象路径：从分析页打开浮层后，**不得用 `router.push` 冲掉宿主页**。

| 现行（与定义一致，与评审冲突） | 出处 |
|---|---|
| 空篮主按钮「去企业查询 / 去产业查询 / 去服务机构查询」→ 全站查询路由 | Wireframe `F-CMP-01`、UX-SPEC `US-ENT-CMP-05`、QA `FUNC-00025` |
| 实现：`EnterpriseCompareBasketView.openSearch`、产业/服务 Panel 同构 `router.push` | `lumen-ui-topic` |
| 篮内搜索框只过滤**已入篮**对象；无命中仅「当前篮内无匹配」 | 现交互 |

---

## 3. 验收口径草案（未生效）

1. 从任意业务页打开系统对比篮浮层后，补对象**不** `router.push` 到全站查询页。
2. 可在对比篮内或简易查询层检索企业 / 产业 / 服务机构，点「添加」写入当前 Tab。
3. 添加成功后：宿主路由、分析草稿、滚动、勾选不变；浮层可保持打开或收起为球，但不离开原页。
4. 全站查询页「行内加入对比篮」能力保留（用户主动进查询页的路径不变）。

## 4. 方案（待选）

### 方案 A（建议默认）

浮层搜索双模式：

| 模式 | 行为 |
|------|------|
| 篮内筛选（现有） | 只过滤已入篮对象 |
| 发现并添加（新增） | 调现有轻量检索 API；行内「添加」/「已在篮」 |

空篮 CTA：「去××查询」改为「添加企业 / 添加产业 / 添加服务机构」，进入发现态，不跳路由。

### 方案 B

点「添加××」后，浮层内容区切到简易查询子面板（关键词 + 少量筛 + 结果 + 添加），底部「返回篮」。仍不改宿主路由。

### 方案 C（不推荐）

宿主页再叠一层 Modal 简易查询。易与任务窗 ↔ 对比篮互斥打架。

## 5. 硬约束与简易边界（若采用 A/B）

- 主路径禁止跳到 `enterprise-search` / `industry-center/search` / `service-center/search`。
- 「去完整查询页」仅可作为次级离开确认；默认可不做。
- 容量满、重复加入、权限不足：沿用现提示，不跳转。
- 政策：现契约「查询页不入篮」则发现入口不出现政策 Tab 添加。

| 对象 | 简易能力 | 明确不做 |
|------|----------|----------|
| 企业 | 名称/关键词、少量类型 | 不整页高级筛、不以画像深链为主路径 |
| 产业 | 集群→L0 / 名称检索 | 不打开产业全景工作区 |
| 服务机构 | 名称 + 服务类型 | 不跳服务中心全页 |

复用现有 search/meta API，不新造第二套查询系统。
