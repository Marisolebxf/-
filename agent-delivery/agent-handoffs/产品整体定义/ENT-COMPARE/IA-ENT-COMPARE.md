## 1. 模块边界

- **解决的问题**：为企业分析、产业链分析、政策分析、产业服务链分析和综合智能分析提供一个系统级对象暂存与分发入口。本期只把已完成的企业对比篮完整迁移到企业 Tab；其余四类对象只展示“开发中”占位，不开放真实接入。
- **承接内容**：系统级五 Tab 壳层、企业对象的加入 / 取消加入、全局去重、单用户单篮恢复、搜索与轻筛、逐项勾选 / 全选当前筛选结果、移除、清空、查看画像、来源追溯和批量分发，以及四个开发中占位页。
- **不承接内容**：技术力 / 商业力 / 综合竞争力结果、雷达图、排名、指标矩阵、差距分析、风险诊断结果、推荐理由、一企一策、报告生成与导出。
- **合规属性**：对比篮是 Decision 088 确认的派生能力，不新增 bid 叶子；E-20～E-35 仅作为来源或去向触点，原叶子的结果责任仍归各自模块。
- **本次会议变更**：`ASC-ENT-COMPARE-SYSTEM-FLOAT-20260731` 将对比篮从企业分析左侧二级菜单升级为系统 Shell 可拖动浮层入口。该变更属于已批准产品增强与导航重组，不新增、不删除、不合并任何 Bid 叶子。
- **本次多对象变更**：`ASC-ENT-COMPARE-MULTI-OBJECT-SHELL-20260731` 将系统篮规划为企业、产业链、政策、服务机构、区域五类基础业务对象；每类目标容量独立为 50，不共享总额。本期仅企业 Tab 启用真实存储与业务动作，其他 Tab 为明确的开发中占位。该变更属于已批准产品增强，不把未来接入描述成已交付能力。
- **本次交互复核**：`DEC-ENT-COMPARE-SINGLE-ROW-DISPATCH-COLLAPSE-20260731` 冻结五个 Tab 在 1920 / 1680 / 1440 三档均完整单行显示，桌面浮层基准宽度为 760px 并按安全视口夹取；分析任务成功分发后保存工作现场、收起面板并保留系统入口，取消或关闭任务选择仍保持对比篮展开。
- **目标页联动复核**：`DEC-ENT-COMPARE-TARGET-INPLACE-OPEN-20260731` 冻结企业评估和风险洞察不再通过“返回对比篮”离开当前页面，而以 `open_compare_basket=1` 原位展开系统浮层；对比篮分发时 `analysis_type` 与 `enterprise_codes[]` 是本次配置态权威输入。
- **候选名单跳转复核**：`DEC-ENT-COMPARE-CANDIDATE-NAV-COLLAPSE-20260731` 冻结“加入招引 / 培育候选”成功后留在当前页面；从标题区查看招引或培育候选名单并成功进入目标工作台后收起对比篮面板，只保留系统图标入口与篮内现场。
- **重点企业分发复核**：`DEC-ENT-COMPARE-KEYENT-DOMAIN-DISPATCH-20260731` 冻结“重点企业领域分布分析”为企业任务选择器中的第六项；以 `analysis_type=key-enterprise-domain`、`enterprise_codes[]` 和 `return_context_id` 分发到 `/enterprise-center/key-enterprise-analysis?view=domain`，目标页原位打开系统对比篮调整对象。

## 6. 对象、数据与架构边界

- 通用规划键为 `object_type + object_id`；不同类型互不去重。本期只有 `object_type=enterprise` 生效，其唯一键继续使用企业 ID / 统一社会信用代码，重复加入只更新来源集合和最近操作时间。
- 统一社会信用代码仅作为内部去重与跨模块传参键，不在对比篮卡片中展示。
- 加入来源仅保留为内部追溯元数据，不作为页面筛选条件，也不在企业卡片中展示来源标签。
- 五类对象的目标容量分别为 50，不共享总额；本期只有企业容量 50 生效。批量企业超限按当前列表顺序加入剩余容量内前 N 家，并返回未加入数量。
- 当前正式数据 / 权限调用仍须遵守 `前端 → 网关 → Java 聚合 → Python / ADS`，前端不得直连 Python、数据库或图谱。
- 对比篮本身无统计业务指标；“共 X 项”“企业 X/50”“已选 X 家”是交互状态计数，`metric_id=N/A`。开发中 Tab 不显示 `0/50`，避免把未接入误解为真实空篮。

### 6.1 分发与返回状态契约

- **持久状态**：篮内企业属于单用户单篮，跳转、返回和刷新均不自动清空。
- **本次工作现场**：发起分析前保存企业名称关键字、企业类型筛选、`selected_enterprise_codes[]` 与列表滚动位置，并生成 `return_context_id`。
- **分析任务选择**：批量工具栏只显示一个“发起分析”主动作；点击后打开“选择分析任务”浮层。“已选择 X 家企业”按现有实现保留在浮层标题下、任务分组前，不因底部操作栏已有“已选 X 家”而删除或挪动。从通用入口打开时不预选；从携带有效 `analysis_type` 的目标分析页原位打开时预选对应任务。预选或手动选择只更新浮层内选中态，不立即跳转；只有点击“下一步：前往配置”才生成分发上下文并进入目标模块。
- **重点企业领域分布任务**：任务选择浮层新增“重点企业分析”分组及“领域分布分析”任务；1～50 家可选，确认后携带 `analysis_type=key-enterprise-domain` 进入领域视图。该任务只应用当前勾选对象，不扩大为篮内全部企业，也不在对比篮生成领域结果。
- **成功分发后的表面状态**：目标路由接管成功时立即收起对比篮展开面板，保留可拖动系统入口和篮内数据；取消、关闭或校验失败不收起面板。返回命中同一 `return_context_id` 时重新展开并恢复工作现场。
- **供应链对象上限**：供应链关系分析继承风险洞察已确认的 1～2 家对象契约。已选超过 2 家时，浮层保留该任务但禁用，显示“最多选择 2 家企业”；用户须关闭浮层并缩减选择，不得静默截断。其他分析任务按各自数量契约处理。
- **选择操作术语**：“取消选择”紧邻“已选 X 家”，仅取消当前勾选，不清空对比篮；加入招引 / 培育候选继续作为次级即时动作，成功后留在当前页。
- **操作栏位置**：企业 Tab 沿用现有实现的底部固定操作栏，不重新排版。控件顺序固定为“全选当前筛选结果 → 已选 X 家 → 取消选择 → 分隔线 → 发起分析 → 加入招引候选 → 加入培育候选”；不得把全选移入筛选栏、把已选数量移入标题区，或交换三个业务动作的相对位置。
- **全选范围**：“全选当前筛选结果”选择当前企业名称与企业类型筛选下的全部可见企业；篮内无分页，不扩展为全库企业选择。筛选后不可见的既有选择继续保留，当前复选框三态只按可见集合计算。
- **全选与取消**：勾选全选把当前可见企业合并进已有选择；取消全选只移除当前可见企业的选择；“取消选择”清除全部已选企业，包括当前筛选下不可见的选择。当前筛选无结果时全选禁用。
- **评审挂载**：系统浮层变更说明使用 `ENT-COMPARE-F06-SCOPE-CHANGE-TRACE`；多对象范围说明使用 `ENT-COMPARE-F07-MULTI-OBJECT-SCOPE-TRACE`；开发中占位分别使用 F-CMP-08～11 的唯一挂载。“全选当前筛选结果”是纯业务交互，在业务 / 评审模式下共用同一选择集合且 `review_mounts: []`。
- **目标页状态**：目标模块接收所选企业与分析类型，在上下文区显示“来自对比篮 · X 家”及企业名称；无对象时提供“打开对比篮”，有对象时提供“打开对比篮调整对象”，均在当前页原位展开系统浮层。这批企业自动成为分析对象，无须强制重选。
- **浮层恢复**：通过目标页对象区入口或浏览器后退命中同一分发上下文时，恢复筛选、勾选和滚动位置，不自动清空选择；再次分发立即同步当前配置草稿。
- **失效收敛**：返回时若篮内对象已被删除、失效或无权访问，只恢复当前有效对象的交集，并提示“已恢复 X 家，Y 家不可用”。
- **新会话边界**：刷新页面、通过兼容路由重新打开对比篮或 `return_context_id` 失效时，仅恢复篮内容；筛选、勾选和滚动位置回到默认态。
- **实现边界**：`return_context_id` 只引用会话级工作现场，不把筛选快照和滚动位置展开到业务 URL，也不把目标模块的分析配置回写对比篮。
- **筛选术语**：企业名称和企业类型旁的筛选恢复动作统一命名为“重置”；“清空对比篮”只用于删除篮内全部对象，“取消选择”只用于取消当前勾选。
- **浮层布局**：对比篮有对象时采用稳定的纵向浮层；筛选区固定在顶部，企业列表占据中间剩余空间并独立纵向滚动，批量操作栏按现有实现固定在浮层底部且保持既有控件顺序。短列表不把操作栏上推，长列表不推动浮层或整页增长。

### 6.2 系统浮层协调契约

- **默认位置**：系统任务入口保留既有右上位置；对比篮收起入口默认位于右下安全区。两个系统浮层统一以 Header 下沿 `top: 80px` 为最小顶部安全线，距其他视口边界与彼此均不小于 16px。
- **同时可见**：两个收起入口可以同时显示；系统任务无可见任务时沿用其既有隐藏规则，对比篮入口不因此改变位置或状态。
- **单面板展开**：同一时间只允许一个系统浮层面板展开。打开对比篮时，已展开的任务面板收起为任务入口；打开任务面板时，对比篮收起为对比篮入口。收起不清空任一业务状态。
- **拖动与点击分离**：入口和展开面板标题均提供拖动把手；移动未超过拖动阈值时仍按点击打开 / 聚焦处理，完成拖动后不得误触打开、关闭或业务动作。
- **碰撞处理**：首次挂载、读取旧坐标、页面切换、拖动结束与窗口缩放都先夹取到 `top ≥ 80px`，再与另一入口 / 面板执行至少 16px 的碰撞避让。两个表面同时变化时采用确定性优先级：任务窗保留其夹取后坐标，对比篮在任务窗出现、移动、展开或收起后重新让位，避免双方同时吸附形成竞态。不得用永久提高 `z-index` 掩盖重叠或让任一入口进入 Header。
- **层级规则**：当前操作浮层临时置顶；交互结束后回到统一系统浮层层级。Modal / Drawer 等阻塞弹层按系统弹层规范覆盖系统浮层，系统浮层不得穿透遮罩接收点击。
- **位置持久化**：任务与对比篮分别按用户保存位置；切换页面不重置。窗口缩放或面板尺寸变化后重新夹取并避让，优先保证两个收起入口可访问。
- **空间不足**：无法同时容纳两个展开面板时仍只展开当前面板；两个收起入口按最近安全槽位排列，不允许移出视口或彼此完全覆盖。
- **可恢复性**：每个展开面板标题栏提供“更多”菜单，其中包含“恢复默认位置”；当前位置已是该浮层默认值时置灰。执行后只恢复当前浮层坐标，不改变篮内容、当前 Tab、筛选、勾选、面板展开状态或任务状态。标题栏不常驻展示独立恢复按钮；键盘用户无需执行拖动即可打开、关闭、操作面板或恢复默认位置。

### 6.3 多对象壳层与本期迁移契约

- **基础对象而非分析场景**：系统篮只规划保存企业、产业链、政策文档、服务机构、区域五类基础业务对象；区域范围、时间窗口、指标权重、对标条件等在进入目标模块后配置。
- **类型隔离**：各 Tab 独立计数、去重、选择和清空；不同类型不得混合提交到同一个分析任务。当前 Tab 的选择状态可在切换 Tab 后保留，但批量动作只作用于当前类型。
- **容量**：每类目标容量独立为 50；一个类型满额不影响其他类型。本期只启用企业 50 家，不建立四个占位类型的真实存储。
- **企业完整迁移**：企业 Tab 必须完整保留企业恢复、搜索、轻筛、三态全选、查看画像、移除、清空、企业评估、风险洞察、招引 / 培育候选和分发返回恢复，不以迁移为由删减能力。
- **旧数据迁移**：既有企业篮数据首次加载时写入 `enterprise` 类型空间；迁移须幂等。新结构写入成功前不得删除旧数据；失败时继续读取旧企业篮并显示可重试反馈，不得呈现为真实空篮。
- **旧路由兼容**：`/enterprise-center/basket` 命中后打开系统篮并默认进入企业 Tab，不渲染独立页面。
- **开发中占位**：产业链、政策、服务机构、区域 Tab 只显示对象类型、未来用途和“开发中”；不显示数量、Mock 对象、搜索、选择、添加、分析或清空动作，来源模块本期也不出现加入入口。
- **入口总数**：本期“共 X 项”仅统计企业对象；其他类型真实启用后才纳入总数。

## 8. 明确排除

- 不做多套命名篮、团队共享篮、收藏夹。
- 不做地区、产业领域、风险等级、引育标签等复杂筛选。
- 不做对比结果、报告、导出、分享或任务历史。
- 不恢复企业分析左侧“对比篮”二级菜单，不新增第二个页面级主入口。
- 不把任务状态与对比篮合并成一个业务面板；只共享定位、展开互斥、层级与碰撞协调能力。
- 不允许两个完整系统浮层面板同时展开并相互遮挡。
- 不把“查看引育名单”放入批量工具栏；它是对比篮展开浮层标题区的固定入口。
- 不在未选择企业时静默执行任何批量动作。
- 本期不接入产业链、政策、服务机构或区域对象，不在对应来源模块增加“加入对比篮”。
- 本期不实现跨类型联合分析，不把分析条件或完整分析场景保存为篮对象。
- 不把开发中占位显示成真实空篮，不显示 `0/50`、虚假卡片或可执行动作。
