# IA-ENT-COMPARE.md

> **模块**：E1 企业 · 对比篮（COMPARE）
> **版本**：v1.0 · 2026-07-15
> **阶段**：既有门 1 结论的四件套纠偏补齐，不重新宣告门 1 通过
> **体验 Owner**：高颖
> **屏幕 / 轨道**：medium · Track-MS
> **主路由**：`/enterprise-center/basket`

## 1. 模块边界

- **解决的问题**：让用户把从企业总览、企业查询、重点企业分析和企业画像中发现的企业暂存为一个可恢复集合，再把选中对象分发到企业评估、风险洞察或引育候选名单。
- **承接内容**：加入 / 取消加入、全局去重、单用户单篮恢复、对象搜索与轻筛、勾选、移除、清空、查看画像、来源追溯、批量分发、空态推荐。
- **不承接内容**：技术力 / 商业力 / 综合竞争力结果、雷达图、排名、指标矩阵、差距分析、风险诊断结果、推荐理由、一企一策、报告生成与导出。
- **合规属性**：对比篮是 Decision 088 确认的派生能力，不新增 bid 叶子；E-20～E-35 仅作为来源或去向触点，原叶子的结果责任仍归各自模块。

## 2. 产品角色与入口

| 产品角色 | 角色依据 | 入口 | 核心目标 |
| --- | --- | --- | --- |
| 政府科技管理与决策人员 | `catalog-topic-enterprise.yaml#E-20` 明确企业分析面向政府 | 左侧对比篮、企业总览、重点企业分析、企业画像 | 汇集研判对象并送入评估、风险或引育处置 |
| 产业园区运营 / 企业服务人员 | `catalog-topic-enterprise.yaml#E-20` 明确面向园区 | 企业查询、重点企业分析、推荐名单 | 管理园区关注企业集合并形成后续服务动作 |
| 投资机构产业研究人员 | `catalog-topic-enterprise.yaml#E-20` 明确面向投资机构 | 企业查询、榜单 / 重点对象、企业画像 | 暂存候选企业并发起能力或风险研判 |

> GOV、INNO、THINK、L0～L4 只用于实现与权限映射，不替代上述产品角色。

## 5. 跨模块边界

| 来源或去向 | 可携带内容 | 不可携带 / 不可承担内容 |
| --- | --- | --- |
| 企业总览、企业查询、重点企业分析、企业画像 | `enterprise_code`、企业名称、来源路由、来源条件摘要、最近操作时间 | 不把来源页的统计结果复制进对比篮 |
| 企业评估 | 选中的 `enterprise_codes[]`、来源=`compare-basket` | 评分、权重、雷达图、排名和差距均由企业评估生成 |
| 风险洞察 | 选中的 `enterprise_codes[]`、来源=`compare-basket` | 供应链图谱、风险等级和痛难点报告均由风险洞察生成 |
| 引育推荐 | 选中对象加入招引 / 培育候选，返回新增与重复数量 | 不在对比篮生成推荐理由、一企一策或导出名单 |
| 企业画像 | 单个企业标识与返回来源 | 不在对比篮展开完整画像信息 |

## 6. 对象、数据与架构边界

- 唯一键使用企业 ID / 统一社会信用代码；重复加入只更新来源集合和最近操作时间。
- 单用户单篮默认最多 50 家；批量超限按当前列表顺序加入剩余容量内前 N 家，并返回未加入数量。
- 当前正式数据 / 权限调用仍须遵守 `前端 → 网关 → Java 聚合 → Python / ADS`，前端不得直连 Python、数据库或图谱。
- 对比篮本身无统计业务指标；`已选 X 家`、`X/50` 是交互状态计数，`metric_id=N/A`。

## 8. 明确排除

- 不做多套命名篮、团队共享篮、收藏夹。
- 不做地区、产业领域、风险等级、引育标签等复杂筛选。
- 不做对比结果、报告、导出、分享或任务历史。
- 不把“查看引育名单”放入批量工具栏；它是页面右上角固定入口。
- 不在未选择企业时静默执行任何批量动作。
