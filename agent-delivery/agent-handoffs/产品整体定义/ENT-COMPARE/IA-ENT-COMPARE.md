# IA-ENT-COMPARE.md

> **模块**：E1 企业 · 对比篮（COMPARE）
> **版本**：v1.6 · 2026-07-20
> **阶段**：既有门 1 结论的四件套纠偏补齐，不重新宣告门 1 通过
> **体验 Owner**：高颖
> **屏幕 / 轨道**：medium · Track-MS
> **主路由**：`/enterprise-center/basket`

## 1. 模块边界

- **解决的问题**：让用户把从企业总览、企业查询、重点企业分析和企业画像中发现的企业暂存为一个可恢复集合，再把选中对象分发到企业评估、风险洞察或引育候选名单。
- **承接内容**：加入 / 取消加入、全局去重、单用户单篮恢复、对象搜索与轻筛、逐项勾选 / 全选当前筛选结果、移除、清空、查看画像、来源追溯、批量分发。
- **不承接内容**：技术力 / 商业力 / 综合竞争力结果、雷达图、排名、指标矩阵、差距分析、风险诊断结果、推荐理由、一企一策、报告生成与导出。
- **合规属性**：对比篮是 Decision 088 确认的派生能力，不新增 bid 叶子；E-20～E-35 仅作为来源或去向触点，原叶子的结果责任仍归各自模块。

## 6. 对象、数据与架构边界

- 唯一键使用企业 ID / 统一社会信用代码；重复加入只更新来源集合和最近操作时间。
- 统一社会信用代码仅作为内部去重与跨模块传参键，不在对比篮卡片中展示。
- 加入来源仅保留为内部追溯元数据，不作为页面筛选条件，也不在企业卡片中展示来源标签。
- 单用户单篮默认最多 50 家；批量超限按当前列表顺序加入剩余容量内前 N 家，并返回未加入数量。
- 当前正式数据 / 权限调用仍须遵守 `前端 → 网关 → Java 聚合 → Python / ADS`，前端不得直连 Python、数据库或图谱。
- 对比篮本身无统计业务指标；`已选 X 家`、`X/50` 是交互状态计数，`metric_id=N/A`。

### 6.1 分发与返回状态契约

- **持久状态**：篮内企业属于单用户单篮，跳转、返回和刷新均不自动清空。
- **本次工作现场**：发起分析前保存企业名称关键字、企业类型筛选、`selected_enterprise_codes[]` 与列表滚动位置，并生成 `return_context_id`。
- **分析任务选择**：批量工具栏只显示一个“发起分析”主动作；点击后打开“选择分析任务”浮层。选择某个分析类型只更新浮层内选中态，不立即跳转；只有点击“下一步：前往配置”才生成分发上下文并进入目标模块。
- **选择操作术语**：“取消选择”紧邻“已选 X 家”，仅取消当前勾选，不清空对比篮；加入招引 / 培育候选继续作为次级即时动作，成功后留在当前页。
- **全选范围**：“全选当前筛选结果”选择当前企业名称与企业类型筛选下的全部可见企业；篮内无分页，不扩展为全库企业选择。筛选后不可见的既有选择继续保留，当前复选框三态只按可见集合计算。
- **全选与取消**：勾选全选把当前可见企业合并进已有选择；取消全选只移除当前可见企业的选择；“取消选择”清除全部已选企业，包括当前筛选下不可见的选择。当前筛选无结果时全选禁用。
- **目标页状态**：目标模块接收所选企业与分析类型，在标题 / 上下文区显示“来自对比篮 · X 家”及企业名称，提供“返回对比篮”；这批企业自动成为分析对象，无须强制重选，同时 3 种企业评估和 2 种风险洞察始终保留“从对比篮带入”，供直接进入页面或主动调整对象时使用；用户调整指标权重、模型参数或诊断配置后开始分析。
- **返回恢复**：通过目标页“返回对比篮”或浏览器后退返回同一分发上下文时，恢复筛选、勾选和滚动位置，不自动清空选择。
- **失效收敛**：返回时若篮内对象已被删除、失效或无权访问，只恢复当前有效对象的交集，并提示“已恢复 X 家，Y 家不可用”。
- **新会话边界**：刷新对比篮、点击左侧菜单重新进入或 `return_context_id` 失效时，仅恢复篮内容；筛选、勾选和滚动位置回到默认态。
- **实现边界**：`return_context_id` 只引用会话级工作现场，不把筛选快照和滚动位置展开到业务 URL，也不把目标模块的分析配置回写对比篮。
- **筛选术语**：企业名称和企业类型旁的筛选恢复动作统一命名为“重置”；“清空对比篮”只用于删除篮内全部对象，“取消选择”只用于取消当前勾选。
- **工作区布局**：对比篮有对象时采用稳定的纵向工作区；筛选区固定在顶部，企业列表占据中间剩余空间并独立纵向滚动，批量操作栏固定在工作区底部。短列表不把操作栏上推，长列表不推动整页增长。

## 7. 与既有材料的差异

| 既有材料 | 差异 | 本次归位 |
| --- | --- | --- |
| `ENT-compare-basket-product-design.md` | 旧导航把对比篮放在企业总览之后，并以名词型下拉直接选择分析类型后跳转 | 对比篮位于重点企业分析之后；统一使用“发起分析”动作打开任务选择浮层，按企业评估与风险洞察展示 3+2 种目标分析，确认“下一步：前往配置”后才跳转，不在篮内配置分析模型 |
| 旧 TRACE v0.1 | 用 INNO / THINK 充当产品角色；把触点叶子写成对比篮拥有的功能 | 改为政府、园区、投资机构三类有来源角色；标明 `source_context / target_handoff`，不改变叶子 Owner |
| 当前 Demo / lumen 实现 | 对比篮上限仍为 12 | 产品口径保持 Decision 088 的 50；列为实现差距，不反向修改产品定义 |
| 2026-07-15 人工评审反馈 | 旧四件套在空篮展示推荐企业，并支持按统一社会信用代码搜索 | 对比篮不做推荐；篮内只按企业名称搜索，信用代码仅作为识别和去重字段 |

| 2026-07-16 对比篮操作反馈 | “企业评估 / 风险洞察”名词型下拉外观近似筛选器，选择菜单项即跳转，用户难以预期 | 合并为“发起分析”主动作；浮层内分组选择任务，选择本身不跳转，以“下一步：前往配置”显式确认；“清空选择”改为“取消选择”并紧邻已选数量 |
| 2026-07-16 对比篮列表反馈 | 企业较少时操作栏跟随列表停在页面中部；企业超过一屏时整页增长，用户需滚到底部才能操作 | 对比篮工作区保持稳定高度；企业列表在中间区域独立滚动，批量操作栏始终固定在工作区底部 |
| 2026-07-20 用户反馈 | 对象列表只能逐项勾选，缺少快速选择当前筛选集合的能力 | 增加“全选当前筛选结果”三态复选框；保留筛选后不可见的既有选择，并区分取消当前可见选择与取消全部选择 |

## 8. 明确排除

- 不做多套命名篮、团队共享篮、收藏夹。
- 不做地区、产业领域、风险等级、引育标签等复杂筛选。
- 不做对比结果、报告、导出、分享或任务历史。
- 不把“查看引育名单”放入批量工具栏；它是页面右上角固定入口。
- 不在未选择企业时静默执行任何批量动作。
