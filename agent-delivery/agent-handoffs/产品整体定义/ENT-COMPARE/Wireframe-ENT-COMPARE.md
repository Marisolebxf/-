| 规则 | Wireframe 约束 |
| --- | --- |
| 默认位置 | 任务入口保持既有 `right: 24px / top: 80px`；对比篮入口为 `right: 24px / bottom: 24px`；两个系统浮层的最小顶部安全线统一为 Header 下沿 `top: 80px`，距其他视口边界及彼此至少 16px。 |
| 入口呈现 | 对比篮收起态为 `40 × 40px` 圆形纯图标主按钮，不显示“对比篮 / 共 X 项”可见文本；数量使用右上红色数字角标，0 时隐藏、超过 99 显示 `99+`；Tooltip 与 `aria-label="打开对比篮，共 X 项"` 保留完整语义。 |
| 同时可见 | 两个收起入口可同时出现且始终可访问；不把任务状态和对比篮合并成一个业务面板。 |
| 单面板展开 | 同一时间只允许一个系统面板展开。打开对比篮时任务面板自动收起；打开任务面板时对比篮自动收起。自动收起只改变壳层状态，不清空任务进度、篮内容、筛选、勾选或滚动位置。 |
| 拖动与点击 | 收起入口整体、展开面板标题区可拖动；按钮与业务控件不充当拖动区。指针移动超过拖动阈值后不得再触发入口点击。 |
| 碰撞避让 | 首次挂载、旧坐标恢复、页面切换、拖动结束和窗口缩放均先执行 `top ≥ 80px` 的 Header 安全区夹取，再与另一入口 / 面板保持至少 16px；两个系统表面同时变化时任务窗保留坐标，对比篮监听任务窗出现、移动、展开与收起并重新让位；拖动期间当前浮层跟随指针并临时置顶。不得用永久提高 `z-index` 掩盖重叠。 |
| 保存与缩放 | 任务与对比篮位置按用户分别保存并跨业务页面恢复；窗口缩放后重新夹取到视口并执行避让。空间不足时优先保留当前活动面板和两个可访问入口。 |
| 恢复与无障碍 | 两个系统浮层的展开标题栏均提供“更多”菜单，内含“恢复默认位置”；当前位置已是该浮层默认值时置灰。执行只恢复当前浮层坐标，不改变业务或展开状态；入口、更多菜单、关闭与篮内操作均可通过键盘完成。 |
| 上层容器 | 分析任务选择浮层、Modal、Drawer 等临时容器在当前系统面板之上，并阻止指针穿透；关闭后焦点回到触发控件。 |
| 目标页跳转 | “加入招引 / 培育候选”成功只反馈、不跳转；从标题区查看招引或培育候选名单并成功进入候选工作台后，对比篮面板收起为纯图标入口，篮内容、筛选、选择和滚动现场不清空。 |

### 3.3 交互与禁止行为

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 搜索 | 仅按企业名称过滤当前篮 | 不按统一社会信用代码搜索，不发起全库搜索 |
| 重置 | 恢复企业名称与企业类型的默认筛选条件 | 不取消当前勾选，不清空对比篮 |
| 勾选全选 | 将当前名称与类型筛选下的全部可见企业合并进已有选择；三态按当前可见集合计算 | 不选择全库企业，不清除筛选后不可见的既有选择 |
| 取消全选 | 只取消当前可见企业的选择；隐藏选择继续保留 | 不等同于“取消选择”，不清空对比篮 |

## 6. 响应式、设计与无障碍约束

- **当前交付**：`medium_1440_1920`；Track-MS。small 尚未登记为本任务交付范围，不以简单缩放冒充。
- **设计系统**：`Design.md` + Arco；视觉高保真由独立 `ENT-MOD-COMPARE-V1-HIFI` 任务冻结。
- **中屏浮层**：1920 / 1680 / 1440 下展开宽度以 760px 为基准，并以 `min(760px, calc(100vw - 32px))` 夹取安全视口；最大高度 `calc(100vh - 96px)`。筛选栏可换行但不隐藏容量；底部操作栏保持既有控件顺序，空间不足时允许在操作栏内部按原顺序换行，但不得把控件迁移到筛选栏、标题区或其他菜单。
- **Tab 布局**：五个对象 Tab 在三档中屏均完整横向单行显示，不折行、不截断、不使用横向滚动隐藏对象类型；“开发中”是状态文本而非可操作按钮，企业数量与全部对象类型始终可见。
- **纵向布局**：有对象时浮层使用稳定可视高度，最小高度保证筛选、至少一行企业卡片和操作栏可用；企业列表使用 `flex: 1 / min-height: 0 / overflow-y: auto`，操作栏使用不可收缩的底部固定区。短列表保留空余空间并将操作栏压在底部，长列表只滚动列表。
- **系统浮层层级**：任务与对比篮共用系统浮层层级，由协调器临时提升当前拖动 / 交互面；Modal、Drawer、任务选择浮层等临时容器位于其上并阻止指针穿透。
- **键盘 / 读屏**：系统入口、关闭、标题栏“更多”菜单及其“恢复默认位置”、“全选当前筛选结果”三态复选框、逐项选择框、移除、信息浮层、任务单选、禁用原因、取消与“下一步：前往配置”均须可聚焦；恢复项置灰时使用 `aria-disabled` 并说明“已在默认位置”；半选使用 Arco / 原生 indeterminate 语义；任务选择浮层打开后焦点进入标题或首个可用任务，关闭后回到“发起分析”；键盘用户不依赖拖动。
- **稳定性**：加载、错误和权限态保持浮层骨架；窗口缩放后重新夹取与避让，避免布局跳变、入口越界或永久遮挡。
