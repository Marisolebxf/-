## 4. F-CMP-03 有对象 / 已选择

### 4.1 工具栏与任务选择浮层

```text
已选 X 家 [取消选择]  |  [发起分析] [加入招引候选] [加入培育候选]

点击“发起分析”
┌────────────────────────── 选择分析任务 ──────────────────────────┐
│ 已选择 X 家企业                                                   │
│                                                                  │
│ 企业评估                                                         │
│ ○ 技术力评估     ○ 商业力评估     ○ 综合竞争力评估              │
│                                                                  │
│ 风险洞察                                                         │
│ ○ 供应链关系分析                 ○ 发展痛难点分析                │
│                                                                  │
│                                      [取消] [下一步：前往配置]   │
└──────────────────────────────────────────────────────────────────┘
```

“发起分析”是工具栏唯一主动作；加入招引 / 培育候选是次级即时动作。“取消选择”紧邻“已选 X 家”，只取消当前勾选。“查看引育名单”位于页面右上角，不进入此工具栏，下拉提供“查看招引候选名单 / 查看培育候选名单”并直达对应 Tab。

未选企业时“发起分析”和候选动作均不可执行。打开浮层后默认不预选分析任务；选择任务只改变单选选中态，不跳转。未选任务时“下一步：前往配置”不可执行；权限不足的分析任务保留、置灰并说明原因。关闭或取消浮层后回到对比篮，篮内容、筛选与勾选不变。

### 4.3 F-CMP-05 分发后 / 返回

```text
目标分析页
┌──────────────────────────────────────────────────────────────────────────┐
│ 企业评估 / 风险洞察       来自对比篮 · X 家        [ 返回对比篮 ]       │
│ 分析对象：企业 A · 企业 B · …（已自动带入） [从对比篮带入 / 调整]      │
│ [模型参数 / 指标权重 / 诊断配置]                         [开始分析]    │
│ 目标模块校验对象数量、字段、模型与权限，并生成本模块结果                 │
└──────────────────────────────────────────────────────────────────────────┘
                                  │ 返回 / 浏览器后退
                                  ▼
对比篮
┌──────────────────────────────────────────────────────────────────────────┐
│ 恢复：企业名称关键字 · 企业类型筛选 · 已选 X 家 · 滚动位置            │
│ 若 Y 家对象失效：[已恢复 X 家，Y 家不可用]                               │
└──────────────────────────────────────────────────────────────────────────┘
```

| 触发 | 状态处理 | 不应发生的行为 |
| --- | --- | --- |
| 点击“下一步：前往配置”并分发 | 保存会话级工作现场并生成 `return_context_id`；篮内容与勾选保持不变 | 不在任务单选时提前生成上下文；不把筛选和滚动快照展开到业务 URL；不清空篮 |
| 目标页加载 | 显示“来自对比篮 · X 家”、企业名称和“返回对比篮”；带入对象自动成为分析对象，同时保留“从对比篮带入”供直接进入或主动调整；用户配置参数后开始分析 | 不强制用户重复选对象；不把目标页结果或配置回写对比篮 |
| 显式返回 / 浏览器后退 | 命中同一 `return_context_id` 时恢复筛选、勾选和滚动位置 | 不默认回到未选择状态 |
| 部分对象失效 | 恢复当前篮中仍有效且有权限对象的交集，并提示失效数量 | 不静默保留无效对象，不把失效解释为清空篮 |
| 刷新对比篮 / 菜单新进入 / 上下文失效 | 只恢复篮内容；筛选、勾选和滚动位置回到默认态 | 不跨新会话恢复旧的临时选择 |

## 5. F-CMP-04 状态矩阵

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 恢复最近单篮；按最近操作时间倒序 | 搜索、筛选、勾选或查看画像 |
| 加载 | 保持标题、筛选和列表容器，列表显示骨架 | 等待；不重复提交 |
| 空篮 | F-CMP-01；来源说明 + “去企业查询”主操作，无推荐企业 | 去企业查询 |
| 筛选无结果 | 显示“当前篮内无匹配企业”，保留“重置” | 重置或调整筛选 |
| 恢复失败 | 错误提示 + 重试；不把失败解释为真实空篮 | 重试或返回来源页 |
| 单个加入超限 | 提示“对比篮已满，请移除部分企业后再加入” | 移除后重试 |
| 批量加入超限 | 加入剩余容量前 N 家并提示未加入数量 | 查看篮或调整选择 |
| 未选对象 | “发起分析”和候选动作均不可执行，提示“请先选择企业” | 勾选企业 |
| 任务浮层未选分析任务 | “下一步：前往配置”不可执行 | 选择一个可用任务或取消 |
| 取消 / 关闭任务浮层 | 返回已选对象状态，保留篮内容、筛选与勾选 | 重新发起分析或执行其他动作 |
| 权限不足 | 具体分析任务保留、置灰并说明所缺能力 | 申请权限或使用可用分析 |
| 候选名单部分重复 | 提示“已加入 X 家，Y 家已在名单中” | 留在当前页或查看名单 |
| 已分发至目标页 | 目标页显示来源与对象数，篮内容和本次勾选不自动清空 | 分析或返回 |
| 同一往返返回 | 恢复筛选、勾选与滚动位置 | 继续分发或调整选择 |
| 返回时部分对象失效 | 恢复有效交集并提示不可用数量 | 重新选择或继续 |
| 返回上下文失效 / 新进入 | 只恢复篮内容，临时工作现场回到默认态 | 重新筛选与选择 |

## 6. 响应式、设计与无障碍约束

- **当前交付**：medium；Track-MS。small 尚未登记为本任务交付范围，不以简单缩放冒充。
- **设计系统**：`Design.md` + Arco；视觉高保真由独立 `ENT-MOD-COMPARE-V1-HIFI` 任务冻结。
- **中屏布局**：筛选栏可换行但不隐藏容量；“发起分析”主动作始终可见，空间不足时候选名单动作进入可访问的更多菜单；任务浮层内保持企业评估 / 风险洞察分组和单选关系。
- **纵向布局**：有对象时工作区使用稳定可视高度，最小高度保证筛选、至少一行企业卡片和操作栏可用；企业列表使用 `flex: 1 / min-height: 0 / overflow-y: auto`，操作栏使用不可收缩的底部固定区。短列表保留空余空间并将操作栏压在底部，长列表只滚动列表。
- **键盘 / 读屏**：选择框、移除、信息浮层、任务单选、禁用原因、取消与“下一步：前往配置”均须可聚焦；浮层打开后焦点进入标题或首个可用任务，关闭后回到“发起分析”；禁用动作通过 `aria-disabled` 与说明关联。
- **稳定性**：加载、错误和权限态保持页面骨架，避免布局跳变。
