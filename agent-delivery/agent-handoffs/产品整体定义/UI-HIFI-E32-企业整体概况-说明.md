## 2. 已落实的评审结论

| 纪要项 | V1 落实方式 | 复核点 |
| --- | --- | --- |
| R-01 模块边界 | 页面仅保留整体概况、产业排名/趋势和企业分布；不出现企业查询、高筛、评估、风险、推荐、导出。 | 菜单之外的页面主体无上述入口。 |
| R-03 全球 KPI | 三张顶部卡改为“全球企业总数 / 全球企业科研人数 / 覆盖未来产业数”，说明其库内全量与当前快照口径。 | 切换产业或地域后顶部值不变。 |
| R-04 删除批次与对比 | 删除数据批次、上期/同比/环比与趋势箭头；原型状态仅以“内部评审模式”标识。 | 页面不出现批次和比较文案。 |
| R-05 产业趋势 | 产业可选择 1 个或最多 2 个；选中 2 个时显示双线；第 3 个选择给出上限提示。 | 不足 2 个可比时间点时隐藏趋势，产业排名区占满整行。 |
| R-06 企业分布 | 地域选择器默认深圳，可切换全球/全国/区域/深圳；地图和列表仅更新本卡片。列表固定为地域、企业数、科研人员数、覆盖未来产业数、操作；字段本身不触发跳转或地图联动，仅操作列提供“在地图中查看 / 进入企业查询”。 | “在地图中查看”切回地图并高亮、脉冲闪烁对应地域点位；“进入企业查询”进入智能搜索，将地域作为智能输入自动解析为筛选条件并自动展示结果列表。 |
| R-07 后续修订：统计口径收口 | 企业科研人数和企业总数统一由顶部全球 KPI 覆盖；企业分布卡片不再追加选中产业统计卡。 | 切换产业或地域后顶部 KPI 仍保持全局汇总，不出现底部重复卡片。 |
| R-08 小屏范围 | 不输出手机端裁剪或移动端交互。 | 本 V1 仅验收中屏。 |
| R-09 规范与复用 | 按 `Design.md` 使用 Arco；复用科技全域态势“科创要素”Tab 的 Leaflet 地图、级联层级、热力和列表回跳行为。 | 未直接引入 Ant Design Cascader/图标控件。 |

## 3. 复用边界

- **复用来源**：`repos/demo-ui-science/src/SharedRegionMap.jsx`、`src/data.js` 的 `regionCascadeOptions`、`src/App.jsx` 的地图/列表状态模式。
- **目标实现**：`EnterpriseDistributionMap.tsx` 以 Leaflet 重用地图初始化、缩放、复位、热力和区域点击行为；地域选择器以 Arco `Select` 呈现 E-32 所需的四级收敛口径。
- **不复用**：`SearchableCascadeFilter.jsx`，因为其依赖 Ant Design，与科技专题服务系统的 Arco 规范冲突。
