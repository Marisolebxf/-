- 视图切换只切换业务对象池和当前工作区；不共享筛选、配置草稿或结果。

| 主维度 | 成长性权重 | 调整任务侧重点 | 任务参数 | 与另两项合计 100% | M_ENT_GROWTH_POTENTIAL |
| 主维度 | 区域适配性权重 | 调整深圳适配侧重点 | 任务参数 | 与另两项合计 100%；正式语义受 Q015 约束 | M_ENT_POLICY_MATCH_SCORE |

### 3.3 交互与禁止行为

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 从外部加入招引候选 | 按企业标识去重，提示新增/重复并保留来源 | 不自动运行模型，不生成理由 |
| 输入候选名称 | 只筛当前候选列表 | 不查询全国企业库，不显示推荐企业 |
| 调整权重 | 实时校验合计并标出差额 | 不静默归一，不修改全局模板 |
| 选择模板 | 加载模板版本与默认参数到本次草稿 | 不覆盖历史任务，不允许编辑已发布模板 |
| 点击生成名单 | 校验必填、权重、权限和数据状态；创建任务快照 | 不在前端计算指数，不同步等待完整结果 |

## 5. F-RECRUIT-03 生成过程

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 招引/培育名单生成 · TASK-XXXX                               [后台运行]     │
├────────────────────────────────────────────────────────────────────────────┤
│ ● 任务创建  →  ● 企业库筛选  →  ◉ 指标计算  →  ○ 推荐依据  →  ○ 完成    │
│ 当前阶段：指标计算             已用时间：服务端返回 / 本地仅显示经过时间 │
│ 配置摘要：类型、对象范围、模板版本、数据批次、权重状态                    │
│ [取消任务]                                                   [返回历史]   │
└────────────────────────────────────────────────────────────────────────────┘
```

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 待开始 | 任务已创建，等待调度；显示任务 ID | 后台运行或取消 |
| 计算中 | 高亮企业库筛选/指标计算阶段，不显示假百分比 | 等待或后台运行 |
| 生成依据中 | 指标已完成，正在装配推荐依据 | 等待 |
| 已完成 | 展示结果数和“查看招引推荐名单/建议培育名单” | 进入结果 |
| 失败 | 显示失败阶段、错误编号、保留配置 | 重试或按此配置新建 |
| 已取消 | 显示取消时间和配置摘要 | 按此配置新建 |

## 10. 全局状态矩阵

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |

| 结果内筛选无匹配 | 保留任务结果总数和筛选控件，仅列表局部空态 | 重置结果内筛选 |

| Q015 待确认 | 指数、阈值、权重显示 PendingBadge / DEMO | 仅内部评审；等待语义闭合 |

| 敏感字段无权 | 字段级脱敏并提示，不隐藏整个对象 | 按授权继续 |

## 11. 响应式与视觉约束

- **屏幕层级**：本包交付 `medium`；小屏需另行定义裁剪，不以简单缩放冒充。
- **设计系统**：`agent-delivery/Design.md` 浅蓝白 + Arco；V1 位于 `demo-ui-topic` 参照沙箱。
- **布局**：中屏配置页候选与配置双栏；窄中屏折叠为“候选 → 配置”两步，但不得隐藏对象范围和 `Q015` 状态。
- **结果表**：排序字段必须常驻可见；长列表在工作区内滚动，任务摘要保持可见。
- **状态色**：业务好坏不与系统成功/失败色混用；Pending/Mock/无源使用统一语义组件。
- **正式模式**：隐藏 TraceInfoIcon、DEMO 解释性批注和评审辅助标记；指标自身待确认状态不得隐藏。
