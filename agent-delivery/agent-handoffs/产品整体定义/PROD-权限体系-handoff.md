## 3. 核心决策

1. **双维度授权**：级别（L0–L4，能力深度）× 身份场景（GOV/INNO/THINK/VISIT/OPS/SYS，范围+视图）。
2. **按级别开通**：入门级 = L1 解锁、分析级 = L2 解锁、敏感下钻/名单/口径配置 = L3、维护发布 = L4。
3. **L3 同级不同视图**：政府领导（驾驶舱）与业务分析师（工作台）同为 L3、身份不同——已经人确认认可。
4. **统一身份 + SSO + 网关统一鉴权**（对齐架构基线 D6），消除 demo 三套角色并存。
5. **展示系统细化到二级页面（DS-01~30）× 级别 × 屏幕**；屏幕三形态规则：大屏纯展示无个人定义、中屏最全无酷炫、小屏裁剪。
6. **屏幕维度仅展示系统**；**专题系统（含企业）仅 PC=中屏单形态**（甲方澄清 2026-06-22）。
