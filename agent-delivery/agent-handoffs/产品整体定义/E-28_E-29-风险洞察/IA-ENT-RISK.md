## 2. 模块边界

### 2.1 解决的问题

风险洞察以已选企业对象为主语，帮助政府、园区和投资机构看清企业供应链结构、关键节点和断链风险，或识别企业发展中的技术研发、市场拓展、融资和管理问题，并把结果沉淀为可追溯报告。

### 2.2 承接内容

- 从对比篮带入企业对象，完成当次对象确认与数量校验。
- `供应链关系`、`发展痛难点`两个页面级分析 Tab，共用同一对象上下文和任务体系。
- 单企业供应链图谱；两企业供应链轻量对比；最多三级关系下钻。
- 核心供应商、关键节点、单点依赖、节点异常和路径脆弱风险识别。
- 单企业痛难点诊断；企业集合共性诊断；技术研发、市场拓展、融资、管理四个维度。
- 分析生成过程、不可变结果快照、最近分析、按此配置新建、报告生成与下载。
- 供应链关系分析报告和企业发展痛难点分析建议报告；两类报告都进入个人资产中心。
- 内部评审模式的需求追溯、metric_id、Q 项和 DEMO / 数据缺口说明。

### 2.3 明确排除

- 不在风险洞察页内搜索、新增或维护企业；补充对象返回对比篮。
- 不生成无对象风险态势、高风险企业榜、供应链总评分、企业综合排名或推荐企业清单。
- 不做替代供应商推荐、替代路径计算、备选名单或自动生成备份方案；报告只记录结构、风险、依据和建议关注方向。
- 不做企业评估的技术力、商业力、综合竞争力评分，也不把严重度转成企业排名。
- 不生成完整一企一策，不做政策匹配、服务派单或招引 / 培育候选管理。
- 普通业务用户不维护图谱关系、算法参数、阈值、专家知识库、报告模板或数据批次。

## 6. 核心任务流

1. 从对比篮接收 `enterprise_codes[]`、`source=compare-basket`、`analysis_type` 和 `return_context_id`；风险洞察页不提供企业搜索。
2. 确认对象：供应链允许 1–2 家；痛难点允许单企业或企业集合。移除只影响当次配置，不回写对比篮。
3. 选择分析 Tab。切换到供应链且对象超过 2 家时保留对象上下文，但要求缩减后才能分析，不静默截断。
4. 配置关系层级 / 关系类型，或痛难点诊断维度；执行权限、数据覆盖和模型条件预检。
5. 用户明确触发“开始分析”，系统固化对象、Tab、配置、数据 / 算法 / 权限版本，创建 `riskTaskId` 并进入独立过程页。
6. 分析完成后进入相应结果；结果观察操作不得修改任务快照。
7. 仅结果页可以创建对应报告；报告异步生成，完成后下载当前任务报告或前往个人资产中心。
8. 最近分析与个人中心读取同一任务源，可恢复结果或“按此配置新建分析”，不覆盖旧任务。

## 7. 与企业评估一致的共享交互

| 交互 | 一致规则 | 风险洞察差异 |
| --- | --- | --- |
| 企业选择 | 对比篮负责新增 / 暂存；业务页负责确认和当次移除 | 供应链上限 2 家；痛难点支持集合共性诊断 |
| 来源与返回 | 记录来源、数量、`return_context_id`；返回恢复对比篮现场 | 按当前 Tab 预选风险洞察分析类型 |
| 生成过程 | 独立过程页、真实阶段、已用时间、可离开恢复 | 阶段名称按图谱 / 诊断计算变化 |
| 报告生成 | 仅结果页创建；后台任务；重复指纹复用；完成后下载当前报告 | 供应链报告与痛难点建议报告使用不同模板 |
| 历史 / 资产 | 最近任务与个人资产中心同源，不复制状态 | 以 `analysis_type` 区分两类任务和报告 |

## 8. 跨模块边界

| 来源或去向 | 可携带内容 | 不可携带 / 不可承担内容 |
| --- | --- | --- |
| 对比篮 → 风险洞察 | 企业对象、分析类型、来源、返回上下文 | 对比篮不生成风险结果或报告 |
| 企业画像 / 查询 / 重点企业分析 → 对比篮 | 候选企业和来源条件，再由对比篮分发 | 不绕过对比篮直接在风险洞察新增对象 |
| 风险洞察 → 企业画像 | 图谱节点或典型企业标识 | 企业画像不承接风险任务状态 |
| 风险洞察 → 个人资产中心 | 任务 ID、报告 ID、状态、下载权限 | 资产中心不复制任务、重新计算或改写报告 |
| 风险洞察 → 引育推荐 / 企业评估 | 只允许用户重新选择对象并发起独立任务 | 不把风险结论直接变成评分、推荐或名单 |
| 维护管理 → 风险洞察 | 已发布关系、模型、阈值、知识库和报告模板版本 | 业务用户不在风险洞察页修改全局配置 |

## 9. 指标、数据与架构

- 供应链：`M_ENT_SUPPLIER_COUNT`、`M_ENT_CORE_SUPPLIER_COUNT`、`M_ENT_NODE_CENTRALITY`、`M_ENT_SUPPLY_CHAIN_RISK`、`M_ENT_RELATION_STRENGTH`。
- 痛难点：`M_ENT_PAINPOINT_COUNT`、`M_ENT_PAINPOINT_SEVERITY`、`M_ENT_PAINPOINT_GAP`。
- `Q017 / Q018` 未闭合时，上述阈值、评级和诊断结果只能按已登记 DEMO / 待语义核对状态展示；不得伪造正式公式或批准结论。
- 正式链路固定为前端 → 网关 → Java 聚合 → Python 算法 / ADS；前端不计算官方风险或诊断指标。
- 供应链图谱正式图数据来自 NebulaGraph；不得新建 Neo4j 或由前端拼接权威关系。
