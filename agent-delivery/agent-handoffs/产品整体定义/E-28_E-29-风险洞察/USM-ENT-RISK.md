## 模块：风险洞察

风险洞察围绕已选企业对象提供供应链关系分析和企业发展痛难点分析。它帮助用户看清关系结构、关键节点、断链风险、发展问题和改进方向，并把两类分析沉淀为可追溯报告；它不承担企业搜索、企业评分、替代供应商推荐、招引培育名单或完整一企一策。

## 1. 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府科技 / 产业管理人员 | `科技信息展示系统和科技专题服务系统.md#企业分析` 明确面向政府 | 识别关键企业供应链脆弱点和企业共性发展障碍，形成精准施策与服务依据 |
| 产业园区运营 / 企业服务人员 | 同章节明确面向园区 | 对园区授权企业开展风险排查和痛难点诊断，沉淀服务材料 |
| 投资机构产业研究人员 | 同章节明确面向投资机构；算法库痛难点模型明确支持投资机构 | 对授权企业开展供应链稳定性和发展问题研判，形成尽调辅助材料 |

行业协会和企业自身只作为算法能力适用对象记录，不作为本期风险洞察页面的直接产品角色。权限等级、persona 和 Mock 用户不得替代以上角色来源。

### US-ENT-RISK-OBJECT 从对比篮确认风险洞察对象

`source_relation: product_interpretation`

作为政府、园区或投资机构分析人员，我想从对比篮带入已经筛选的企业并确认当次对象，以便复用工作现场且避免在每个分析模块重复找企业。

**验收：**

- 有效对象自动带入，显示“来自对比篮 · X 家”和来源摘要。
- 本页可移除当次对象，但不回写或清空对比篮。
- 补充对象返回同一 `return_context_id`，恢复对比篮筛选、勾选与滚动位置。
- 供应链只允许 1–2 家；超过 2 家时明确提示缩减，不静默取前两家。
- 痛难点允许单企业或最多 50 家企业集合；集合进入共性诊断，不逐家批量生成完整诊断。
- 来源与对象作为两个分析 Tab 的共享上下文，稳定显示在 Tab 上方；切换 Tab 不改变对象，仅恢复各自配置草稿。
- “最近分析”作为第三个页面级 Tab，固定排在“发展痛难点”之后；进入后显示 F-RISK-05，页面标题区不再重复显示同名按钮。
- 当次移除对象同步影响两个 Tab 的共享对象集合，但不清空供应链关系范围或痛难点诊断维度草稿。
- 与企业评估共用对象区布局和交互：空态只保留居中的蓝色主按钮“前往对比篮选择企业”，标题右侧不渲染重复入口；存在对象时才显示“返回对比篮调整对象”。
- 配置态对象区 1–5 家完整显示可移除标签；6–50 家仅显示快照顺序前三家与“管理全部对象”。管理抽屉支持名称搜索、每页 10 家和当次移除；不提供新增入口，且移除不回写对比篮。
- 评审模式在 Tab 下方的供应链关系配置标题 / 发展痛难点配置标题展示对应追溯；业务模式完全不渲染 Marker，且不改变对象字段或权限。

### US-ENT-RISK-SUPPLY 查看供应链关系、关键节点和断链风险

`source_relation: direct_requirement`

作为产业管理或研究人员，我想围绕一至两家企业展开供应商、客户和合作伙伴网络，以便识别关键依赖、异常节点和脆弱路径。

**验收：**

- 单企业展示中心辐射图谱；两企业展示双中心图谱，共同节点居中，差异节点分区。
- 配置页不要求用户选择展开层级；结果默认展示一级关系，带展开标识的节点可按需逐层加载，系统最多三级。
- 已展开节点可折叠，当前路径和深度持续可见；加载中、无子节点、加载失败、已达三级均有明确反馈。
- 图谱顶部只以普通文本显示“当前展示：N 级 · 节点 N 个 · 共同节点 N 个”；不使用 KPI 卡或标签。“系统最多 3 级”放在“展开下一层”的动作提示中。
- 中心企业、供应商、客户、合作伙伴图例以“色点＋文字”的静态样式独立放在图谱画布右下角，不与顶部状态、筛选或操作混排。
- 图谱与关键节点 / 断链风险列表双向定位，节点详情包含来源和更新时间。
- 风险只包含单点依赖、节点异常、路径脆弱三类，不产生供应链总评分或企业排名。
- 关键节点风险、断链风险项及供应链报告显示“建议提前制定备份方案”；不推荐替代供应商、替代路径或备选名单，不提供备份方案入口、编辑器或自动生成内容。
- 评审挂载采用 `ENT-RISK-F01-SUPPLY-TITLE`、`ENT-RISK-F01-Q017`、`ENT-RISK-F02-GRAPH-TITLE`、`ENT-RISK-F02-KEYRISK-TITLE`、`ENT-RISK-F02-OVERVIEW-METRIC`、`ENT-RISK-F02-KEYNODE-METRIC`、`ENT-RISK-F02-RISK-METRIC`、`ENT-RISK-F02-MOCK`；两个区块标题只挂需求追溯，三个指标挂点分别位于实际关系概览值、节点影响度值和风险类型 / 等级值旁，Mock 位于统一图谱数据说明区域，业务模式均不存在。

### US-ENT-RISK-PAIN 识别企业发展痛难点

`source_relation: direct_requirement`

作为企业服务或研究人员，我想从技术研发、市场拓展、融资和管理四个维度查看问题、成因、最佳实践和解决方向，以便形成可解释的服务建议。

**验收：**

- 单企业结果按“维度 → 问题 → 成因 → 行业最佳实践 → 解决方向”展开。
- 企业集合结果展示共性痛点分布、影响企业数最高的 5 个共性问题和典型企业入口，不逐家生成完整诊断；1–5 家显示全部对象名，6–50 家显示前三家与“等 N 家”，完整对象通过只读抽屉查看。
- “查看全部对象”固定放在对象摘要文字下方并左对齐；只读抽屉内“对象列表只读，顺序固定为任务创建时的对象快照；搜索与筛选不改变任务。”挂载于 `ENT-RISK-F03-OBJECT-SNAPSHOT-NOTE`，仅在评审模式展示，业务模式不渲染。
- 每个共性问题首屏最多显示 3 家典型企业；“查看受影响企业”进入可搜索、筛选、分页的只读名单，并可查看某企业在当前任务中的问题命中摘要，但不创建第二份单企任务或报告。
- 严重度只用于阅读优先级，不转换为企业评分、排名或培育推荐指数。
- 每个结论可查看命中依据、数据来源和缺失影响；数据不足时显示“暂不判断”。
- 不生成完整一企一策，不做政策匹配或服务派单。
- 页面可见维度采用专题系统 Bid 的技术研发、市场拓展、融资、管理；算法库的经营竞争力、盈利能力、生产效率、人才状况作为底层指标域，二者映射由 `Q018` 闭合，不假定一一对应。
- “四维诊断”和“问题清单 / 共性问题”标题分别挂原需求追溯；标题旁不叠加指标、Mock 或 Pending 徽标。
- 技术研发、市场拓展、融资、管理四张维度卡片分别使用唯一指标挂点，且只挂在卡片实际 `问题项数 / 严重度 / 影响企业数` 数值旁；无实际数值时不显示指标挂点。
- “行业最佳实践”是 Bid 要求的解释性文本，不等同于量化行业差距；当前不显示 `M_ENT_PAINPOINT_GAP` 挂点，待 Q018 明确定义并新增实际可见量化字段后方可启用。
- 评审挂载采用 `ENT-RISK-F01-PAIN-TITLE`、`ENT-RISK-F01-Q018`、`ENT-RISK-F03-DIAGNOSIS-TITLE`、`ENT-RISK-F03-ISSUES-TITLE`、`ENT-RISK-F03-TECH-METRIC`、`ENT-RISK-F03-MARKET-METRIC`、`ENT-RISK-F03-FINANCE-METRIC`、`ENT-RISK-F03-MANAGEMENT-METRIC`、`ENT-RISK-F03-MOCK`；业务模式均不存在。

### US-ENT-RISK-PROCESS 创建并恢复风险分析任务

`source_relation: product_interpretation`

作为分析人员，我想在提交后看到真实处理阶段并可以离开页面，以便长时图谱或诊断计算不阻塞当前工作。

**验收：**

- “数据与权限预检”只展示校验状态、缺失项和阻断原因，不在卡片标题栏放置“开始分析”。
- “开始分析”作为配置页唯一主提交动作，固定放在页面底部操作栏右侧；风险洞察没有个人模板能力时，底栏不增加“保存为个人模板”等无关操作。
- 对象为空、对象超限、预检未通过或无权限时，“开始分析”保持禁用，禁用原因在预检区明确可见。
- 开始分析后创建不可变任务快照并进入独立过程页。
- 过程页只显示真实阶段、已完成阶段和已用时间，不伪造百分比。
- 过程页与企业评估使用同构结构：上方任务摘要卡展示任务 ID、分析类型、企业数量、已用时间和状态，下方“可视化分析过程”卡以纵向阶段状态和语义 Alert 展示进度；所有状态动作位于 Alert 下方右侧。
- 离开不取消任务；最近分析和个人资产中心可恢复同一 `riskTaskId`。
- 分析完成后仍停留在过程页，显示“分析结果已生成”，不自动跳转；用户点击“查看分析结果”后才进入对应结果页，也可先查看最近分析。
- 失败显示失败阶段和审计错误编号，可重试或按此配置新建。
- 评审模式只在 `ENT-RISK-F04-PROCESS-TITLE` 挂载过程说明；业务模式不渲染该 Marker。

### US-ENT-RISK-REPORT 生成并下载当前分析报告

`source_relation: direct_requirement`

作为分析人员，我想把当前供应链或痛难点结果生成受控报告，以便用于内部研判、服务沟通或尽调留档。

**验收：**

- 只有结果页可以创建报告，报告绑定当前不可变分析任务快照。
- 结果页顶部任务摘要只提供“按此配置新建分析”；该动作以当前配置创建新草稿 / 新任务，不修改旧任务快照。
- 报告入口位于供应链图谱 / 痛难点问题结果之后的独立报告区块；不与任务摘要动作混排，也不使用“创建 / 查看报告”合并不同状态。
- 报告区块按任务状态显示“创建报告”“生成中”“查看报告 / 下载当前报告”；重复指纹优先恢复既有任务。
- 供应链报告包含对象、关系结构、关键节点、风险线索、依据和数据说明；不包含替代供应商或自动备份方案。
- 痛难点建议报告包含对象、诊断结论、问题、成因、最佳实践、解决方向和数据说明。
- 报告生成阶段、失败重试、完成下载、权限、水印、审计和个人资产中心交互与企业评估一致。
- 同一报告指纹的处理中或有效报告复用后台任务；完成后只能下载当前任务报告。
- 两类报告评审挂载分别为 `ENT-RISK-F06-SUPPLY-REPORT`、`ENT-RISK-F06-PAIN-REPORT`；业务模式均不存在。

### US-ENT-RISK-HISTORY 找回分析和报告资产

`source_relation: product_interpretation`

作为分析人员，我想从最近分析或个人资产中心找回任务，以便继续查看结果、下载报告或复用配置，而不重复计算和维护两套状态。

**验收：**

- 最近分析与个人资产中心读取同一任务 / 报告源。
- 可恢复不可变结果或“按此配置新建分析”，不覆盖旧任务。
- 无权限、对象失效或数据版本不可用时保留任务摘要并说明原因。
- 评审模式在 `ENT-RISK-F05-HISTORY-TITLE` 标明历史链路为产品解释；业务模式不渲染该 Marker。

## 3. 主路径 walkthrough

### 3.1 供应链关系分析

1. 用户在企业查询、画像或重点企业分析中把企业加入对比篮。
2. 用户在对比篮选择“风险洞察 → 供应链关系”，点击下一步前往配置。
3. 风险洞察在分析 Tab 上方自动带入对象与来源；用户确认共享对象后选择供应链 Tab，配置关系类型且不选择展开层级。
4. 系统在“数据与权限预检”区展示对象权限、图谱数据与模型条件；用户在页面底部操作栏右侧点击唯一主按钮“开始分析”。
5. 过程页显示任务阶段；完成后停留并显示完成态，用户点击“查看分析结果”进入供应链结果。
6. 结果页顶部显示不可变任务摘要和“按此配置新建分析”；用户通过顶部轻量状态行了解当前层级、节点数和共同节点数，通过画布右下角静态图例识别关系类型；点击带展开标识的节点逐层加载关系，可折叠、查看当前路径，并在图谱、关键节点和断链风险间联动定位。
7. 用户查看关键节点或断链风险依据时看到“建议提前制定备份方案”；该提示同步进入供应链报告，但页面不生成方案或推荐替代供应商。
8. 用户在业务结果后的独立“供应链分析报告”区块创建报告；后台完成后下载当前报告或去个人资产中心。

### 3.2 企业发展痛难点分析

1. 用户从对比篮选择“风险洞察 → 发展痛难点”，带入单企业或企业集合。
2. 页面在分析 Tab 上方显示共享对象；对象超过 5 家时只展示前三家，用户可从“管理全部对象”抽屉搜索、分页并移除当次对象。用户切换到发展痛难点 Tab 并确认诊断维度，系统检查数据覆盖和权限。
3. 预检通过后，用户在页面底部操作栏右侧点击唯一主按钮“开始分析”，进入真实过程页；完成后页面不自动跳转，用户点击“查看分析结果”。
4. 结果页顶部显示不可变任务摘要和“按此配置新建分析”；单企业查看四维诊断；集合查看四维影响分布、影响企业数最高的 5 个共性问题和每项最多 3 家典型企业，完整对象与受影响企业进入只读二级视图。
5. 用户展开问题依据、成因、最佳实践和解决方向。
6. 用户在业务结果后的独立“发展痛难点分析建议报告”区块创建报告并在完成后下载。

## 4. 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 无对象 | 在 Tab 上方保留共享对象空态，不展示伪造风险总览；底部“开始分析”禁用 | 前往对比篮选择企业 |
| 供应链对象超过 2 家 | 在预检区显示当前数量和上限，底部“开始分析”禁用 | 当次移除或返回对比篮调整 |
| 对象失效 / 无权限 | 只保留有效交集，说明不可用企业数量和原因 | 返回对比篮或申请权限 |
| 图谱无关系数据 | 保留对象摘要和稳定图谱容器，说明暂无可用关系 | 查看数据说明或返回配置 |
| 节点超过可读规模 | 默认只呈现一级并按需加载，不丢失总量说明 | 按关系类型或关键 / 风险节点筛选、折叠已展开分支 |
| 节点没有下级关系 | 不显示可展开标识；点击详情时说明“暂无下级关系” | 查看节点详情或选择其他节点 |
| 下级关系加载失败 | 保留当前图谱和路径，在节点旁显示失败状态 | 重试该节点，不重跑整个分析 |
| 已达三级保护上限 | 节点显示“已达最大展开深度” | 沿当前路径查看或折叠返回 |
| 痛难点数据不足 | 对应维度显示“数据不足，暂不判断” | 查看缺失数据说明 |
| `Q017 / Q018` 未闭合 | DEMO / 评审态标记待语义核对，不冒充正式口径 | 等待何老师、算法与 PM 闭合 |
| 分析失败 | 显示失败阶段、错误编号和已保留配置 | 重试或按此配置新建 |
| 报告无权限 / 未完成 | 下载禁用并显示原因 | 等待完成、申请权限或去资产中心查看状态 |
