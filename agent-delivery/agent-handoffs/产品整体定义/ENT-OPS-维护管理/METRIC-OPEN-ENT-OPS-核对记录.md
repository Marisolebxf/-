## §2 CMS 数据能力摘要（algorithm-agent）

### 2.1 模块特殊性声明

维护管理是 **CMS 写侧运营模块**，其 15 项能力的「数据」语义与读侧分析模块根本不同：

| 对比维度 | 读侧分析模块（评估/引育/风险/查询） | 写侧 OPS 模块（维护管理） |
|----------|--------------------------------------|---------------------------|
| 数据流向 | 读：ODS → DWD → ADS → 指标卡 | 写：用户 → CMS 表 → 发布 → 前台消费 |
| 数据本质 | 计算字段（computed fields） | 运营内容（authored content） |
| 指标产生 | 每条 metric = 一个算法公式 | 无 metric 产生（C1 是配置工具，非算法） |
| 缺口判断 | ODS 某字段是否存在 | CMS 某表/某字段是否已定义 |
| 数据真源 | ODS/DWD 贴源表 | CMS 内容表 + 企业实体表（dwd.enterprise_base）+ 图谱存储（NebulaGraph） |

**结论**：本模块的 METRIC-OPEN 核对应从「CMS 基础设施表是否就绪」出发，而非「ODS 字段是否覆盖所有分析指标」。
