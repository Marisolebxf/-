## 6. 完整样例：门户内容 → 企业发展内容管理（E-37）

### 6.1 需求归位

| 招标叶子 | 产品能力 | 不承担 |
| --- | --- | --- |
| 企业基础与成长内容维护 | 基础介绍、成长轨迹内容条目 | 不替代企业主体工商档案（A2） |
| 重点企业与竞争力榜单维护 | 重点全景编排、Top30 榜单 | 不计算技术力/商业力得分（ADS / C2） |
| 明星企业与深圳企业介绍维护 | 明星/深圳专维内容 | 不在前台 E-34/E-35 提供编辑入口 |

### 6.2 用户故事

#### US-ENT-OPS-01 维护门户内容并提交审核

作为内容运营团队成员，我想创建或编辑企业发展相关门户内容（基础介绍、成长轨迹、荣誉资质、能力榜单、专家观点、关系变化，以及明星/深圳专维），并提交审核，以便前台只消费已发布内容。

#### US-ENT-OPS-02 审核与发布门户内容

作为科技主管部门或具备审核职责的内容运营用户，我想核对变更摘要与材料来源后通过或退回，并在发布中心立即或定时发布 / 下线，以便控制门户展示质量。

#### US-ENT-OPS-03 版本回滚与审计

作为内容运营或科技传播部门用户，我想查看已发布版本历史并创建基于历史版本的新草稿或回滚为新发布版本，以便错误内容可追溯纠正。

### 6.3 主路径 / 异常路径

- **主路径**：待我处理 → 编辑 → 提交审核 → 审核通过 → 待发布 → 发布 → 前台 E-33/E-34/E-35 可读。  
- **异常**：冲突保存；审核退回；发布失败保留待发布；无权限动作保留并说明原因。  
- **主数据**：门户内容页只读展示企业主数据摘要；纠错走「发起主数据纠错」。

### 6.4 验收场景（样例 · 可测试）

| 场景 ID | 前置 | 步骤 | 期望 |
| --- | --- | --- | --- |
| AC-E37-01 | 内容运营用户进入门户内容 | 新建明星/深圳或六类内容草稿并保存 | 状态=draft；列表可见 |
| AC-E37-02 | 存在 draft/returned | 提交审核 | 状态=pending_review；审核中心可见 |
| AC-E37-03 | 审核职责用户打开待审项 | 通过或退回 | 通过→pending_publish；退回→returned；审核不可改正文 |
| AC-E37-04 | 待发布项 | 立即或定时发布 | publish_status=published；前台可消费 |
| AC-E37-05 | 已发布项 | 查看版本并回滚/建草稿 | 产生新版本记录；可追溯操作者 |
| AC-E37-06 | 任意门户编辑页 | 尝试改工商主数据 | 仅只读+纠错入口；无直接写 |

补充规则：业务态不展示 Q 号 / CMS 内部字段名；内部评审模式可显示溯源 ⓘ；前台 E-33/E-34/E-35 无编辑/发布按钮。
