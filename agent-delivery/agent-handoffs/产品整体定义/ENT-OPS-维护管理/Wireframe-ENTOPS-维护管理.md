## 10. 用户 / 角色切换与内部评审模式

入口仅为右上角**用户 / 角色切换**下拉面板中的全局「内部评审模式」开关；`SYS` 只是角色之一，页面内不另造开关。

| 状态 | 本页行为 |
| --- | --- |
| 评审模式关闭 | 仅业务操作界面与业务权限结果；无 Q 号泄漏 |
| 评审模式开启 | 额外显示：招标章节/LF-id ⓘ、CMS/APP 分区、Q-OPS-01~04 与 Q041/Q048–Q050 角标、MockBadge、C 区「深化规格/角色待确认」⚠ |
| 切换到无维护权限角色 | 菜单锁态或不可见（按正式规则）；评审模式可演示锁态说明 |
