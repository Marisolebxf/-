### 1.3 导航行为（强制）

1. **左侧分组导航固定 15 项**：分组标题「内容运营 / 图谱运营 / 分析配置」+ 叶子项；**禁止**把 15 项压回顶部三项 Tab 而隐藏其余叶子。

4. **切换保留上下文**：
   - 离开再回 `portal`：恢复上次门户二级 `view`（及筛选，若未主动清空）。  
   - 带 `enterprise_code` 的 URL：在 `entity` / `entity_dynamics` / `lifecycle` 间切换时保留该码。  
   - 再次点击当前叶子：**不重复查询**。  
5. **门户二级不得冒充一级**：`mine/all/review/publish/versions` 仅在 `tab=portal` 工作区内出现。  
6. **深链**：`?tab=<id>`；门户可叠加 `&view=` / `&frame=`；非法 `tab` → 回落 `portal` 并 toast「已回到门户内容」。  
7. **键盘**：左侧叶子 ↑↓ 切换；焦点在当前项；无权限项可聚焦读原因（`aria-disabled` + Tooltip）。  
8. **侧栏关系**：企业中心侧栏仅暴露「维护管理」一项（权限态）；**页内左侧**完成 15 项分组导航（不拆成 15 个企业中心侧栏二级）。

## 3. 可演示项 — 门户内容（`portal`）

对齐 Wireframe F-OPS-01~05；保留 0.1 细则并升版。

### 3.1 门户二级职责 Tab

仅在 `tab=portal` 内出现。对齐 Design.md §7.3 Tabs（轻量蓝字 + 浅蓝底指示）。

| view | 标签 | 默认队列 | 主 CTA | 对应 Frame |
| --- | --- | --- | --- | --- |
| `mine` | 待我处理 | 当前用户可编辑/待处理草稿与退回项 | 新建内容 / 继续编辑 | F-OPS-01 |
| `all` | 全部内容 | 权限范围内全量内容 | 新建内容 / 打开详情 | F-OPS-01 |
| `review` | 审核中心 | `pending_review` | 通过 / 退回（禁改正文） | F-OPS-03 |
| `publish` | 发布中心 | `pending_publish` 及可下线已发布 | 立即/定时发布、下线、退回编辑 | F-OPS-04 |
| `versions` | 版本与审计 | 已发布/已下线版本快照 | 回滚 / 基于版本建草稿 | F-OPS-05 |

### 3.2 职责 Tab 规则

1. **切换职责 Tab**：重置本区列表分页到第 1 页；保留类型/关键词筛选（若用户未主动清空）。  
2. **无审核/发布职责**：对应 Tab **禁用**（非隐藏），Tooltip：「当前账号无审核/发布职责」。  
3. **「新建内容」**：仅 `mine` / `all` 可见可用；审核/发布/版本视图隐藏或禁用该 CTA。  
4. **Frame 叠加**：`frame=editor|review|publish|versions` 打开时，左侧导航与二级 Tab 仍可见但工作区替换为 Frame；返回列表回到进入前的 `view`。  
5. **状态机可见性**：draft/returned→编辑/提交；pending_review→仅审核职责可见通过/退回；pending_publish→发布动作；published→版本/下线。

### 3.3 主路径与异常

| 路径 | 行为 |
| --- | --- |
| 主路径 | 待我处理 → 编辑 → 提交审核 → 审核通过 → 待发布 → 发布 → 前台 E-33/E-34/E-35 只读消费 |
| 冲突保存 | 提示本地/服务端版本冲突；禁止静默覆盖；用户选择保留本地草稿或拉取服务端 |
| 审核退回 | 状态=`returned`；运营在待我处理继续编辑；审核角色不可改正文 |
| 发布失败 | 保留 `pending_publish`；错误可恢复（重试/退回编辑） |
| 无权限动作 | 按钮禁用 + 原因文案；不提交请求 |

### 3.4 内容类型与明星/深圳专维

类型枚举须覆盖：基础介绍、成长轨迹、荣誉资质、能力榜单、专家观点、关系变化、**明星企业介绍**、**深圳企业介绍**。

| 规则 | 说明 |
| --- | --- |
| 类型枚举 | 「新建内容」类型选择必须出现明星/深圳；未实装标 `占位` Tag |
| 列表筛选 | 选中后若 0 条 → 空态：「招标专维已登记，样例字段待 CMS 契约（Q041/Q048/Q049）」+ 可选 CTA「创建占位草稿」 |
| 编辑页 | 占位类型可进最小字段（标题/摘要/企业引用）；字段不全处 ⚠「待甲方确认」 |
| 评审模式 | 可显示 Q041/Q048/Q049 ⓘ；业务态不展示 Q 号 |

### 3.5 门户禁止行为

1. **禁止**在编辑页直接改写 ODS/APP 工商真源字段。  
2. **禁止**展示算法得分编辑器或权重配置。  
3. **禁止**未发布内容进入前台 E-33/E-34/E-35。  
4. **禁止**审核角色直接编辑正文。

## 8. 权限锁态

### 8.1 菜单级

| 条件 | 正式业务态 | 内部评审模式 |
| --- | --- | --- |
| 无维护权限 | 侧栏「维护管理」**不可见** | 可显示菜单项，进入后整页锁态 |
| 有维护权限 | 可见可进；左侧 15 项均列出 | 同左，可叠加溯源 ⓘ |

**整页锁态文案（示例）**：  
「当前账号无维护管理权限。本入口仅面向内容运营、数据治理等具备写侧职责的用户。如需开通请联系管理员。」  
提供：返回企业总览；评审模式下显示权限映射 ⓘ（Q020/Q029 🟡）。

### 8.2 项 / 动作级

| 场景 | 表现 |
| --- | --- |
| 可进菜单但无审核职责 | 门户「审核中心」Tab 禁用 + 原因 |
| 可进菜单但无主体/动态写权限 | 对应页只读；保存禁用 |
| 可进菜单但无阶段字典写权限 | 字典只读；监控只读或仅可看 |
| 可进菜单但对某占位叶子无配置权 | 叶子可进只读占位；写 CTA 禁用 + 原因（**不删叶子**） |
| 访客 | 不可达本路由（重定向或 403） |

### 8.3 内部评审模式

- 开关仅在右上角用户/角色面板全局开关；页内不另造。  
- 开启：招标章节 ⓘ、CMS/APP 分区说明、Q 角标、MockBadge、占位项锚点展开。  
- 关闭：仅业务操作与权限结果。
