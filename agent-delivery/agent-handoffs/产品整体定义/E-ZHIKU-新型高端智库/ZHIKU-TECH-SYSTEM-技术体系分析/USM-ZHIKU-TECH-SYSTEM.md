## 1. 模块结果

围绕"一个技术领域的体系结构长什么样、证据在哪里"这一研判主线，让智库分析用户完成"技术体系建管（新建/树编辑/专家会审）→ 论文证据分析 → 专利证据分析 → 科研项目证据分析 → 社会网络关系分析"的完整闭环；专利深度分析节点直接引出"生成专利分析报告"跨叶子出口（进入 ZHIKU-WRITING 预填任务）。不承接聚类/共性网络/趋势预警（归 ZHIKU-TECH-TREND），不承接真实文献/专利检索服务与图算法——demo 阶段任务执行进度、混合检索、调度限流等算法层能力（序号 19/20）以 🧪 演示态与能力说明卡呈现，禁止伪闭合。

## 4. 用户故事

### US-ZHIKU-TS-01｜新建并管理技术体系

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 8（集中管理展示、新建按钮、筛选区、体系卡片、操作按钮） |
| 产品角色 | `ROLE-TS-OWNER` |
| 依赖 | 无（模块入口故事） |
| Frame | `F-TS-01` |
| 业务结果 | 技术体系可新建（真实入库持久化）、按关键词筛选、可删除（防误删确认），卡片直达在线编辑器 |

作为技术体系负责人，我想集中查看全部技术体系并新建、筛选、删除，以便维护本领域的体系资产库。

主路径：

1. 用户进入"技术体系分析"页，默认停在"技术体系"标签。
2. 统计卡显示体系总数（ⓘ `ZHIKU-TS-SYSTEM-TOTAL`）；体系卡片显示名称、更新时间、节点数。
3. 用户点"新建体系"，输入名称并选择模板（空白/三层示例），新体系真实入库并置顶。
4. 用户按关键词筛选体系；点卡片"在线编辑"进入 US-02 编辑器。
5. 用户删除体系时二次确认；删除后卡片消失、统计卡 -1。
6. 刷新页面后新建/删除结果与筛选条件保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 新建名称为空/重名 | 表单校验拦截，弹窗不关闭 | 修改名称 |
| 筛选无结果 | 局部 Empty + "清空筛选" | 一键清空 |
| 删除含专家意见的体系 | 确认文案额外提示"关联的 N 条专家意见将一并归档" | 确认或取消 |

验收：

- `AC-US-ZHIKU-TS-01-01`：新建体系真实入库置顶（非 toast），刷新后保持；名称空/重名被校验拦截。
- `AC-US-ZHIKU-TS-01-02`：关键词筛选实时过滤体系卡片，无结果出现局部 Empty 与"清空筛选"。
- `AC-US-ZHIKU-TS-01-03`：删除需二次确认，删除后统计卡与卡片区同步变化且刷新保持。
- `AC-US-ZHIKU-TS-01-04`：体系总数统计卡带 ⓘ（`ZHIKU-TS-SYSTEM-TOTAL`）与 🧪，弹卡含 8 件套与就绪度四行。
- `AC-US-ZHIKU-TS-01-05`：卡片"在线编辑"直达编辑器并选中该体系（URL `?system=` 同步）。

不包含：体系版本管理与回滚；多人协同编辑锁。

### US-ZHIKU-TS-02｜在线编辑体系树与评估指标

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 9（可视化树形编辑器、层级关系管理、成熟度/重要性评估指标） |
| 产品角色 | `ROLE-TS-OWNER` |
| 依赖 | US-01（体系选择） |
| Frame | `F-TS-02` |
| 业务结果 | 树节点可增删改、成熟度（TRL 1-9）/重要性（1-5）可设置，编辑结果与展开态持久化，URL 可分享 |

作为技术体系负责人，我想在树形编辑器里维护层级关系并为节点设置成熟度、重要性，以便把领域认知沉淀为结构化资产。

主路径：

1. 用户在编辑标签选择体系（或从 US-01 卡片直达，URL `?system=` 同步）。
2. 树形区展示层级结构；选中节点右侧出现属性面板（名称/TRL/重要性）。
3. 用户修改属性即时生效并持久化；体系"更新时间"同步刷新。
4. 用户"添加子节点""删除节点"（删除带确认，级联提示子节点数）。
5. 树展开/折叠态被记住；复制 URL 可让同事直达同一体系编辑视图。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 删除含子节点的节点 | 确认文案提示"将级联删除 N 个子节点" | 确认或取消 |
| URL 指向不存在的体系 | 提示并回落到第一个体系 | 重新选择 |
| 节点名称为空 | 校验拦截不保存 | 补全名称 |

验收：

- `AC-US-ZHIKU-TS-02-01`：节点名称/TRL/重要性修改即时反映在树上并刷新保持。
- `AC-US-ZHIKU-TS-02-02`：添加/删除节点真实变更树结构；删除含子节点时确认文案含级联数量。
- `AC-US-ZHIKU-TS-02-03`：URL `?system=<id>` 可分享恢复同一体系编辑视图；非法 id 提示回落。
- `AC-US-ZHIKU-TS-02-04`：树展开态与选中节点刷新后保持（localStorage `zhiku-ts-` 前缀）。
- `AC-US-ZHIKU-TS-02-05`：任一编辑动作后体系卡片"更新时间"同步变化（US-01 联动）。

不包含：拖拽排序（demo 用按钮增删）；节点级权限。

不包含：真实专家账号体系与通知；意见发起入口（demo 预置意见+可回复确认）。
