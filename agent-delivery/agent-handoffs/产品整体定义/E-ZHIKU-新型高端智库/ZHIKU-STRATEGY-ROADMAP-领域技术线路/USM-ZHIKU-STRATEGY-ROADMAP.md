### US-ZHIKU-RM-01｜概览速航与最近项目

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 46（集成德尔菲问卷系统 + 可视化技术路线图设计工具 + 最近项目列表） |
| 产品角色 | `ROLE-RM-PLANNER` |
| 依赖 | 无（模块入口故事） |
| Frame | `F-RM-01` |
| 业务结果 | 用户进入模块即可掌握问卷与路线图两条工作线的总体状态，最近项目可一键续作 |

作为技术规划人员，我想在模块首页速览德尔菲问卷与路线图项目的总体进展，并从最近项目直接续作，以便不用在多个标签间来回找入口。

主路径：

1. 用户进入"领域技术线路"页，默认停在"概览"标签。
2. 统计卡展示：问卷总数（ⓘ `ZHIKU-RM-SURVEY-TOTAL`）、平均回收完成率（ⓘ `ZHIKU-RM-DELPHI-COMPLETION`）、在建路线项目数（ⓘ `ZHIKU-RM-PROJECT-INPROGRESS`）。
3. "最近项目"列表混排最近更新的问卷与路线图项目（各带类型标签），按更新时间倒序。
4. 用户点击任一最近条目，跳转到对应标签并自动定位该条目（问卷展开详情/路线打开设计器）。
5. 创建/推进问卷、编辑路线后回到概览，最近项目排序与统计卡即时更新。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 尚无任何项目 | 最近项目区 Empty："暂无项目，去创建问卷或路线图"，附两个入口按钮 | 点击进入创建 |
| 统计口径为 0（如无问卷） | 统计卡显示 0，不隐藏卡片 | 无需处理 |

验收：

- `AC-US-ZHIKU-RM-01-01`：三张统计卡带 ⓘ（`ZHIKU-RM-SURVEY-TOTAL` / `ZHIKU-RM-DELPHI-COMPLETION` / `ZHIKU-RM-PROJECT-INPROGRESS`）与 🧪 MockBadge，弹卡含 8 件套与就绪度四行。
- `AC-US-ZHIKU-RM-01-02`：最近项目混排问卷与路线两类条目且带类型标签，按更新时间倒序。
- `AC-US-ZHIKU-RM-01-03`：点击最近条目可真实跳转对应标签并定位该条目（非仅切换标签）。
- `AC-US-ZHIKU-RM-01-04`：新建/推进/编辑动作完成后，概览统计卡与最近项目即时反映变化。
- `AC-US-ZHIKU-RM-01-05`：无项目时出现 Empty 态与双入口按钮，可直达创建。

不包含：跨模块全局工作台（归平台级导航）；项目收藏/置顶。

### US-ZHIKU-RM-02｜德尔菲问卷全流程管理

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 47（专家问卷全流程管理，创建、分发、回收、进度跟踪） |
| 产品角色 | `ROLE-RM-SURVEYOR` |
| 依赖 | 无 |
| Frame | `F-RM-02` |
| 业务结果 | 问卷可创建并沿"草拟→发放中→回收中→已归档"流转，回收进度可跟踪可催办，归档问卷可研判结果分布，全程刷新后保持 |

作为德尔菲问卷管理员，我想创建专家问卷并跟踪发放回收进度、对未答复专家催办、在回收完成后查看评分分布，以便把专家共识过程完整管起来。

主路径：

1. 用户切到"德尔菲问卷"标签，看到问卷列表（标题/阶段/回收进度条/截止日期），可按阶段筛选。
2. 用户点"新建问卷"，填写标题、专家人数、截止日期，创建成功后新问卷以"草拟"态置顶。
3. 用户对草拟问卷点"发放"，进入"发放中"；系统开始模拟专家答复（🧪 回收数随时间推进），进度条与完成率实时更新。
4. 回收中问卷可点"催办未答复专家"，弹出催办摘要（已答 N / 催办 M，🧪 站内演示）；催办记录追加到问卷动态。
5. 回收完成（或用户手动归档）后问卷进入"已归档"，点开可查看各题评分 1-5 分布图与共识度结论。
6. 刷新页面后问卷列表、阶段、回收进度、催办记录全部保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 新建标题为空或专家数 < 1 | 表单校验拦截，弹窗不关闭，逐项标红提示 | 修正后重试 |
| 截止日期早于今天 | 校验提示"截止日期不能早于今天" | 重选日期 |
| 已归档问卷再操作 | "发放/催办"按钮隐藏，仅保留"查看结果" | 查看结果 |
| 重复催办 | 催办幂等：同一批未答复专家 5 分钟内重复催办给出"刚刚已催办"提示，不重复记录 | 无需处理 |
| 阶段筛选无结果 | 局部 Empty + "查看全部" | 一键恢复 |

验收：

- `AC-US-ZHIKU-RM-02-01`：新建问卷经校验后真实进入列表（非仅 toast），以草拟态置顶；空标题/专家数<1/过期截止日均被拦截。
- `AC-US-ZHIKU-RM-02-02`：问卷沿"草拟→发放中→回收中→已归档"单向流转，各阶段可用操作按钮随阶段变化。
- `AC-US-ZHIKU-RM-02-03`：发放后回收数模拟推进（🧪 标注），进度条、完成率统计卡（ⓘ `ZHIKU-RM-DELPHI-COMPLETION`）实时联动。
- `AC-US-ZHIKU-RM-02-04`：催办产生动态记录且幂等；催办摘要明确标注"🧪 站内演示，非真实触达渠道"。
- `AC-US-ZHIKU-RM-02-05`：归档问卷可查看各题 1-5 评分分布可视化与共识度结论。
- `AC-US-ZHIKU-RM-02-06`：刷新后问卷列表/阶段/进度/催办记录全部保持（localStorage `zhiku-rm-` 前缀）。

不包含：真实问卷题目编辑器与专家名单管理（demo 预置题目模板）；邮件/短信真实分发渠道。

### US-ZHIKU-RM-03｜路线图项目管理、里程碑设计与版本快照

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 46（可视化技术路线图设计工具）、48（宏观统计数据、搜索筛选、路线图项目列表） |
| 产品角色 | `ROLE-RM-PLANNER` |
| 依赖 | 跨叶子 ZHIKU-WRITING（报告生成出口） |
| Frame | `F-RM-03` |
| 业务结果 | 路线项目可检索筛选与新建；设计器内里程碑可增删改、时间轴可视化即时反映；版本快照可保存/回看/恢复；设计态 URL 可分享恢复；"生成路线研判报告"真实创建写作预填任务 |

作为技术规划人员，我想管理路线图项目并在设计器里编辑里程碑节点、保存版本快照，最后把路线结论一键转成研判报告，以便让路线设计从草稿到决策支撑形成闭环。

主路径：

1. 用户切到"技术发展路线"标签：宏观统计卡（路线总数/覆盖领域数/在建项目数 ⓘ）+ 关键词/领域/状态筛选 + 项目列表。
2. 用户点"新建路线"，填名称/领域/起止年月，新项目带一个默认"启动"里程碑进入列表。
3. 用户点击项目进入路线图设计器（URL 带 `?project=` 可分享恢复）：时间轴按里程碑日期顺序可视化，节点按状态着色（已完成/进行中/规划中）。
4. 用户添加里程碑（名称/日期/状态/说明）、编辑或删除已有里程碑，时间轴即时重排；项目进度=已完成里程碑占比自动重算。
5. 用户点"保存版本快照"，输入快照说明；历史快照列表可回看任一版本的里程碑组成，可"恢复此版本"（当前态先自动存为新快照再恢复，不丢数据）。
6. 用户点"生成路线研判报告"，确认后在 ZHIKU-WRITING 真实创建预填任务（大纲注入项目名、里程碑统计与最新快照说明）并跳转大纲确认页。
7. 刷新后筛选条件、项目、里程碑、快照全部保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 筛选组合无结果 | 局部 Empty + "清空筛选" | 一键清空 |
| 新建路线名称为空/起止年月倒挂 | 表单校验拦截并标红 | 修正后重试 |
| 里程碑日期超出项目起止范围 | 提示"日期超出项目周期"，允许"确认扩展项目周期"或改日期 | 二选一 |
| 删除仅剩一个里程碑 | 拦截："至少保留一个里程碑" | 无需处理 |
| URL 指向不存在的项目 | 提示"该路线项目不存在或已被删除"，回落到项目列表 | 重新选择 |
| 恢复历史快照 | 恢复前自动把当前态另存快照并提示，可从历史找回 | 无需处理 |

验收：

- `AC-US-ZHIKU-RM-03-01`：关键词/领域/状态筛选可叠加、实时生效、刷新后保持；无结果有局部 Empty 与"清空筛选"。
- `AC-US-ZHIKU-RM-03-02`：新建路线经校验真实入列（名称空、起止倒挂被拦截），默认带"启动"里程碑。
- `AC-US-ZHIKU-RM-03-03`：设计器内里程碑可增删改，时间轴按日期即时重排、按状态着色；项目进度随已完成里程碑占比自动重算。
- `AC-US-ZHIKU-RM-03-04`：删除到仅剩一个里程碑被拦截；日期越界给出"扩展周期/改日期"双选项且选择生效。
- `AC-US-ZHIKU-RM-03-05`：版本快照可保存（带说明）、回看（只读展示该版里程碑）、恢复（恢复前自动另存当前态）；快照历史刷新后保持。
- `AC-US-ZHIKU-RM-03-06`：`?project=` URL 可直接还原设计器态（可分享可恢复）；非法 id 有提示并回落列表。
- `AC-US-ZHIKU-RM-03-07`："生成路线研判报告"真实调用写作模块 `createTask` 创建预填任务（大纲含里程碑统计与快照说明）并跳转大纲确认（跨叶子契约 CT-RM-01）。
- `AC-US-ZHIKU-RM-03-08`：宏观统计卡带 ⓘ（`ZHIKU-RM-PROJECT-INPROGRESS` 等）与 🧪。

不包含：多人协同编辑与审批流；甘特图依赖线（demo 为顺序时间轴）；报告写作本体（归 ZHIKU-WRITING）。
