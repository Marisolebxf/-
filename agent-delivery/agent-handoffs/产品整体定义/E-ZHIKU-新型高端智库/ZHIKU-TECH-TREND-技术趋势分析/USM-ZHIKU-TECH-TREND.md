### US-ZHIKU-TT-01｜运行聚类任务并查看主题结果

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 29（创建/管理/查看聚类任务）、30（结果自动归纳为主题聚类） |
| 产品角色 | `ROLE-TT-ANALYST` |
| 依赖 | 无（模块入口故事） |
| Frame | `F-TT-01` |
| 业务结果 | 聚类任务可创建并模拟运行出结果，结果散点与主题簇卡联动，任务与结果跨会话保留 |

作为趋势研究分析人员，我想创建聚类任务并把海量数据自动归纳为核心技术主题，以便快速看清领域的主题版图。

主路径：

1. 用户进入"技术趋势分析"页，默认停在"聚类分析"标签；统计卡显示聚类簇总数（ⓘ `ZHIKU-TT-CLUSTER-TOTAL`）。
2. 用户新建聚类任务（名称+算法 K-Means/DBSCAN），任务入列 → 模拟运行 → 完成（🧪 演示进度）。
3. 结果区散点图按簇着色；点击簇卡高亮对应散点，反向点击散点定位簇卡。
4. 失败任务可"重跑"；任务可删除（确认）。
5. 刷新页面后任务列表、状态与选中簇保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 任务名为空 | 校验拦截 | 补全 |
| 运行中重复触发 | 运行中任务禁用重跑按钮 | 等待完成 |
| 删除任务 | 二次确认 | 确认或取消 |

验收：

- `AC-US-ZHIKU-TT-01-01`：新建任务真实入列并模拟推进（created→running→done 可见），刷新后保持。
- `AC-US-ZHIKU-TT-01-02`：结果散点按簇着色，簇卡↔散点双向联动选中。
- `AC-US-ZHIKU-TT-01-03`：聚类簇总数统计卡带 ⓘ（`ZHIKU-TT-CLUSTER-TOTAL`）与 🧪，弹卡含 8 件套与就绪度四行。
- `AC-US-ZHIKU-TT-01-04`：聚类计算带"🧪 演示态：预置聚类结果+模拟运行"诚实性标注。
- `AC-US-ZHIKU-TT-01-05`：删除/重跑动作真实生效且刷新保持。

不包含：真实聚类算法执行（预置结果 🧪）；数据源选择与特征配置。

### US-ZHIKU-TT-02｜调整三级筛选权重并定制主题清单

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 31（初级/中间/最终三级筛选独立模块、权重展示与调整）、32（清单定制：编辑、导出、重新计算） |
| 产品角色 | `ROLE-TT-ANALYST` |
| 依赖 | US-01（同页结果上下文） |
| Frame | `F-TT-01` |
| 业务结果 | 三级权重可调（和为 100 校验）、重算刷新结果排序，主题清单可编辑/导出/重新计算且持久化 |

作为趋势研究分析人员，我想调整三级筛选的权重并重新计算，再把主题清单按需编辑导出，以便让聚类产出贴合我的研究口径。

主路径：

1. 用户在"三级筛选"卡查看初级/中级/终级三档权重与说明。
2. 用户拖动滑杆调整权重；权重和 ≠100 时"重新计算"禁用并提示差值。
3. 权重合法后点"重新计算"，🧪 模拟重算，簇排序按新权重刷新，Message 反馈。
4. 用户在清单定制区重命名主题项、导出 CSV（真实下载）、"重新计算"恢复默认清单。
5. 刷新页面后权重与清单编辑保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 权重和 ≠100 | 重算按钮禁用 + 差值提示 | 调整滑杆 |
| 清单项重命名为空 | 校验拦截还原原名 | 重新输入 |
| 导出空清单 | 导出按钮禁用 | 先恢复清单 |

验收：

- `AC-US-ZHIKU-TT-02-01`：三级权重滑杆可调，权重和 ≠100 时重算禁用且提示差值（零和校验）。
- `AC-US-ZHIKU-TT-02-02`：重算后簇排序真实变化（按加权得分），带 🧪 模拟重算标注。
- `AC-US-ZHIKU-TT-02-03`：清单项可重命名、导出 CSV 真实下载、重新计算恢复默认。
- `AC-US-ZHIKU-TT-02-04`：权重与清单编辑刷新后保持（localStorage `zhiku-tt-` 前缀）。

不包含：真实权重敏感度分析；清单多版本管理。
