### US-ZHIKU-SQ-01｜管理多源数据接入

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 55（标准化连接器框架：本地文件/关系型数据库/数据仓库/RESTful API；语义层构建、数据质量校验、业务语义映射）——**智谱承建，本页为集成边界演示** |
| 产品角色 | `ROLE-SQ-ADMIN` |
| 依赖 | 无（模块入口故事） |
| Frame | `F-SQ-01` |
| 业务结果 | 四类连接器可新增（模拟连通测试成功/失败可重试）、可停用/启用；每个数据源可查看语义层映射表与质量校验状态；全部持久化 |

作为数据接入管理员，我想按标准化连接器接入各类数据源并查看语义映射与质检状态，以便问数引擎有可信的数据底座。

主路径：

1. 用户切到"数据接入"标签：数据源卡片列表（名称/类型/状态/质检徽标），顶部接入数统计卡（ⓘ `ZHIKU-SQ-SOURCE-CONNECTED`）。
2. 用户点"新增数据源"，选类型（本地文件/关系库/数仓/RESTful API）填名称与连接串（演示格式），点"测试连接"：🧪 模拟校验约 1.5 秒返回成功或失败（失败给出原因并可重试）。
3. 测试通过后保存，新数据源入列并标"正常"；用户可"停用/启用"切换状态。
4. 用户点开数据源详情抽屉：语义层映射表（物理字段→业务语义，🧪 预置）、质量校验清单（完整性/一致性/时效性，状态徽标）。
5. 刷新后数据源列表与状态全部保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 名称/连接串为空 | 校验拦截，弹窗不关闭 | 修正后重试 |
| 测试连接失败 | 显示失败原因（🧪 演示随机场景），保留表单可重试 | 重试或取消 |
| 停用的数据源被问数引用 | 问数侧提示"该问题涉及已停用数据源"（US-02 联动） | 启用后重问 |

验收：

- `AC-US-ZHIKU-SQ-01-01`：四类连接器可选择新建，空名称/空连接串被拦截。
- `AC-US-ZHIKU-SQ-01-02`：测试连接经历模拟校验（🧪 标注），失败可见原因并可重试，通过后才允许保存。
- `AC-US-ZHIKU-SQ-01-03`：数据源可停用/启用，状态徽标与接入数统计卡（ⓘ `ZHIKU-SQ-SOURCE-CONNECTED`）联动。
- `AC-US-ZHIKU-SQ-01-04`：详情抽屉含语义层映射表与质量校验清单（均 🧪 预置标注）。
- `AC-US-ZHIKU-SQ-01-05`：页面常驻"序号 55 智谱承建，本页为集成边界演示"归属声明。
- `AC-US-ZHIKU-SQ-01-06`：刷新后数据源与状态保持（localStorage `zhiku-sq-` 前缀）。

不包含：真实数据库连接/驱动、真实语义层构建（智谱侧能力）。

### US-ZHIKU-SQ-02｜多轮自然语言问数

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 56（口语化问题转 SQL：维度指标/条件过滤/分组聚合/多表连接/排序分页/时序对比；自动可视化）——**智谱承建，本页为集成边界演示** |
| 产品角色 | `ROLE-SQ-ANALYST` |
| 依赖 | US-01（数据源状态联动） |
| Frame | `F-SQ-02` |
| 业务结果 | 问数以会话组织（可新建/重命名/删除），每轮含问题→生成 SQL→图表/表格双视图；图表样式可切换；结果可收藏、可导出 CSV；会话与收藏刷新后保持 |

作为业务分析人员，我想用大白话连续追问数据问题，每个回答能看到生成的查询语句和图表，好的结果能收藏和导出，以便把口头分析变成可复用的数据资产。

主路径：

1. 用户切到"智能问数"标签：左侧会话列表（可新建/重命名/删除），右侧当前会话的多轮问答流。
2. 用户输入问题回车：识别中状态（识别→生成 SQL→生成图表三阶段提示）约 1 秒后返回一轮结果：生成的 SQL（🧪 预置样例标注）、图表（柱/折/饼可切换）、数据表格视图。
3. 用户继续追问，新一轮追加到会话流；会话自动保存，切换会话再切回上下文不丢。
4. 用户对某轮结果点"收藏"，进入"收藏结果"区（US-04 报告底料来源）；点"导出 CSV"下载该轮数据。
5. 未匹配预置样例的问题返回边界提示："演示环境仅覆盖预置问题样例（列出可试问题），正式环境由智谱大模型解析"，该轮标记为未命中，可一键换预置问题重试。
6. 刷新后会话、轮次、收藏全部保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 空问题提交 | 输入框标红提示"请输入您想查询的问题" | 输入后重试 |
| 问题涉及停用数据源 | 该轮返回提示"涉及已停用数据源【x】，请先启用"（US-01 联动） | 去启用 |
| 未命中预置样例 | 诚实边界提示 + 可试问题清单 + 一键填入重试 | 换问题 |
| 删除当前会话 | 确认弹窗；删除后切到最近会话或空态 | 无需处理 |
| 无任何会话 | 空态"新建会话开始问数"+按钮 | 新建 |

验收：

- `AC-US-ZHIKU-SQ-02-01`：会话可新建/重命名/删除（删除有确认），多会话切换上下文不丢，刷新后保持。
- `AC-US-ZHIKU-SQ-02-02`：每轮结果含生成 SQL（🧪 预置样例标注）+ 图表 + 表格双视图，图表柱/折/饼可切换且该轮记住选择。
- `AC-US-ZHIKU-SQ-02-03`：未命中样例时给出诚实边界提示与可试问题清单（不返回伪造结果），可一键填入重试。
- `AC-US-ZHIKU-SQ-02-04`：收藏/取消收藏幂等，收藏区独立可查，刷新保持；导出 CSV 可下载该轮数据。
- `AC-US-ZHIKU-SQ-02-05`：问题涉及停用数据源时给出联动提示（与 US-01 状态真实联动）。
- `AC-US-ZHIKU-SQ-02-06`：会话数统计卡带 ⓘ（`ZHIKU-SQ-SESSION-TOTAL`）与 🧪；页面常驻智谱承建声明。

不包含：真实 NL2SQL/大模型解析、语音输入；查询真实执行。

3. 用户点"生成报告"，先展示数据校验清单（结果时效/数据源状态/口径一致，🧪 演示三项校验逐条打勾），校验含停用数据源的结果时给出警告项。
4. 校验通过确认后，真实调用 ZHIKU-WRITING `createTask`（大纲注入每条结果的问题与结论摘要），跳转写作大纲确认页（CT-SQ-01）。
5. 生成记录追加（时间/结果构成/任务回链），刷新后保持。

## 5. 跨故事走查

1. **接入 → 问数 → 联动**：US-01 停用某数据源 → US-02 相关问题返回停用提示 → 启用后重问成功——数据源状态为单一真源。
2. **问数 → 收藏 → 报告闭环**：US-02 收藏两轮结果 → US-04 勾选生成 → 写作大纲可见各结果问题与结论摘要 → 任务回链可回看生成记录（CT-SQ-01）。
3. **看板独立走查**：US-03 看板集合管理与页内拖拽互不影响会话数据；两者持久化前缀同为 `zhiku-sq-` 但 key 独立。
4. **刷新恢复走查**：US-01 数据源、US-02 会话/收藏、US-03 看板/布局/标签、US-04 生成记录，刷新后全部还原。
5. **归属声明走查**：四个 Tab 均常驻智谱/智树归属声明（Alert），不可被关闭后消失（会话级重现）。
