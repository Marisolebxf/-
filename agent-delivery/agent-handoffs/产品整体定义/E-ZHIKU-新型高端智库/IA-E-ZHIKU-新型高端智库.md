## 2. 角色 × 权限降级态（PDR-12 对照，本轮草稿仅记录已知信息）

| 层级 | 说明 | 本模块适用性 |
|---|---|---|
| L0 公众访客 | 无登录访问 | 拆解表未提及公众访问场景，本模块**默认不适用**，需业务确认后再纳入 IA |
| L1 注册用户 | 登录后基础功能 | 待业务确认（R3 角色未定） |

| L4 管理运营 | 系统管理/权限配置 | 拆解表未覆盖，超出 110 项范围，不纳入本轮 IA |

## 3. IA 重组说明（与 bid-reference 差异）

| 重组点 | 原因 | 影响 |

| "战略咨询成果"（`strategy/case-show`）与"案例广场"（`writing/cases`）共享同一视图组件 | 拆解表条目 54"战略咨询案例展示"与"AI 智能报告创作"模块下的案例呈现在业务语义上是同一批数据（战略咨询案例）；原型规划方案将其设计为两个导航入口指向同一页面，避免用户在不同任务链路中找不到入口 | 门 2 SIG-08（无重复入口）检查时需明确标注"刻意双入口，非重复功能点"，不算 IA 违规 |

## 4. 完整样例章节：AI 智能报告创作（R2 智库报告创作人员）

> 按规程"父文档以当前跑通叶子作为完整样例章节"要求，选取已在 `demo-ui-gaoduanzhiku-view` S1 批次落地/进行中的"AI 智能报告创作"模块作为完整 IA 样例。

### 4.1 页面层级

```text
写作模块（顶部导航）
├── 报告创作（侧栏，路由 writing/create）
│   ├── 首页视图：入口卡片（研究报告/战略咨询报告/洞察报告） + 我的报告任务预览 + 案例/研报推荐
│   ├── 任务配置表单（研究/战略/洞察三态，同组件按 type 切换）
│   ├── 大纲确认（树形大纲编辑器）
│   ├── 报告编辑器（正文 + 脚注 + 版本状态 + AI 改写入口）
│   └── 自定义模板管理（挑选/复制系统模板/编辑/删除/分享个人模板）
├── 案例广场（侧栏，路由 writing/cases，= 战略咨询成果第二入口）
├── 我的素材库（侧栏，路由 writing/materials）
│   ├── 知识库文件夹（资料包列表 + 解析状态）
│   └── 素材上传（多源选择）
└── 我的报告任务（侧栏，路由 writing/tasks）
    ├── 任务列表（状态筛选：配置中/大纲确认中/AI写作中/草稿完成/待发布审核/已发布）
    ├── 任务工作台（大纲 + 生成计划进度 + 版本管理）
    └── 发布审核流程（提交 → 审核中 → 通过/拒绝）
```

### 4.2 状态流转（写作任务生命周期）

```text
draft_config（配置中）
   └─ 提交表单 → outline_confirm（大纲确认中）
         └─ 确认大纲 → writing（AI 写作中，后台执行，可离开页面）
               └─ 生成完成 → draft_done（草稿完成）
                     └─ 保存版本（可重复，版本号递增）
                     └─ 提交发布审核 → pending_review（待发布审核）
                           └─ 审核通过 → published（已发布）
                           └─ 审核拒绝 → 回到 draft_done（附拒绝原因，不丢失草稿）
```
