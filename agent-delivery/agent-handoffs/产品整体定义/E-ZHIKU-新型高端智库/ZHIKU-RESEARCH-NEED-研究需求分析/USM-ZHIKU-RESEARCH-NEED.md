## 1. 模块结果

围绕"战略研究从哪里发现值得研究的对象"这一入口问题，让智库分析用户完成"科技实体定位 → 实体画像下钻 → 颠覆性/前沿技术识别 → 技术趋势宏观速览 → 媒体舆情联动研判"的完整闭环，并在媒体聚焦节点直接引出"生成舆情研判报告"跨叶子出口（进入 ZHIKU-WRITING 预填任务）。不承接技术体系的结构化管理（归 ZHIKU-TECH-SYSTEM），不承接聚类/预警等趋势深挖（归 ZHIKU-TECH-TREND），不做真实的大数据挖掘与相似度推荐算法——demo 阶段"批量导入校验""前沿技术自动挖掘"均为标注 🧪 的演示态，禁止伪闭合。

## 4. 用户故事

### US-ZHIKU-RN-01｜检索、筛选并导入科技实体

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 1（搜索框、多维度筛选栏、视图切换、数据批量导入）、2（信息卡片呈现）、3（模糊匹配、多维筛选、批量导入校验算法） |
| 产品角色 | `ROLE-RN-ANALYST` |
| 依赖 | 无（模块入口故事） |
| Frame | `F-RN-01` |
| 业务结果 | 用户能按关键词与领域/地区/类型组合快速定位科技实体，批量导入的实体真实进入清单，筛选与视图偏好跨会话保留 |

作为智库研究分析人员，我想按关键词与领域、地区、类型多维组合筛选科技实体并在卡片/列表视图间切换，还能批量导入新实体，以便快速构建研究对象底盘而不必逐条录入。

主路径：

1. 用户进入"研究需求分析"页，默认停在"科技实体清单"标签。
2. 顶部统计卡显示筛选命中实体数（ⓘ `ZHIKU-RN-ENTITY-TOTAL`）。
3. 用户输入关键词（模糊匹配名称），叠加领域/地区/类型多选筛选，结果实时更新。
4. 用户切换卡片/列表视图，偏好被记住。
5. 用户点"批量导入"，上传演示文件后确认，🧪 校验摘要弹出（成功 N 条 / 跳过重复 M 条），新实体真实置顶出现在清单中。
6. 刷新页面后筛选条件、视图偏好与导入的实体全部保持。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 筛选组合无结果 | 列表区局部 Empty，提示调整条件并提供"清空筛选"按钮，筛选条保留 | 一键清空或调整条件 |
| 重复导入相同实体 | 导入校验幂等：重复项跳过并在结果摘要中列明，不产生重复条目 | 查看摘要即可 |
| 导入未选择文件 | "确定"给出提示"请先选择演示文件"，弹窗不关闭 | 选择文件后重试 |

验收：

- `AC-US-ZHIKU-RN-01-01`：关键词、领域、地区、类型四类筛选可叠加使用，结果实时更新，"清空筛选"一键恢复全量。
- `AC-US-ZHIKU-RN-01-02`：卡片/列表两种视图可切换且刷新后保留偏好。
- `AC-US-ZHIKU-RN-01-03`：批量导入后新实体真实出现在清单（非仅 toast），带"导入 🧪"标记；重复导入被幂等跳过。
- `AC-US-ZHIKU-RN-01-04`：刷新页面后筛选条件、视图偏好、导入实体全部保持（localStorage `zhiku-rn-` 前缀）。
- `AC-US-ZHIKU-RN-01-05`：命中实体数统计卡带 ⓘ（`ZHIKU-RN-ENTITY-TOTAL`）与 🧪 MockBadge，弹卡含 8 件套与就绪度四行。
- `AC-US-ZHIKU-RN-01-06`：筛选无结果时出现局部 Empty 与"清空筛选"按钮，点击后恢复全量清单。

不包含：真实文件解析与格式校验（demo 用预置候选池模拟导入）；实体的编辑/删除管理后台。

### US-ZHIKU-RN-02｜下钻科技实体画像

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 2（信息卡片呈现）、3（可视化生成、相似度推荐） |
| 产品角色 | `ROLE-RN-ANALYST` |
| 依赖 | US-01（从清单进入） |
| Frame | `F-RN-02` |
| 业务结果 | 任一实体可下钻查看画像详情（基础信息+热度趋势+相似实体推荐），详情态 URL 可分享恢复 |

作为智库研究分析人员，我想点开任一科技实体查看其画像详情与热度走势，并看到相似实体推荐，以便对研究对象形成立体认知并顺藤摸瓜扩展研究面。

主路径：

1. 用户在实体清单点击任一卡片/行。
2. 右侧抽屉打开：基础信息（领域/地区/类型/热度）、近 6 期热度趋势折线、相似实体推荐（🧪 演示推荐，按同领域规则）。
3. 用户点击推荐中的相似实体，抽屉切换为该实体详情，清单选中态同步。
4. 用户复制当前 URL（含 `?entity=` 参数）发给同事，对方打开后直接还原同一实体的详情态。
5. 关闭抽屉，URL 参数清除，回到清单。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| URL 指向不存在的实体 | 提示"该实体不存在或已被移除"，回落到清单全量态 | 重新选择 |
| 详情中的实体被当前筛选过滤 | 详情仍可打开（以 URL 为准），关闭后回到筛选后清单 | 无需处理 |

验收：

- `AC-US-ZHIKU-RN-02-01`：任一实体可打开详情抽屉，含基础信息、热度趋势图与相似推荐三个区块。
- `AC-US-ZHIKU-RN-02-02`：相似实体推荐可点击跳转，抽屉内容与清单选中态同步切换。
- `AC-US-ZHIKU-RN-02-03`：带 `?entity=` 的 URL 可直接还原详情态（可分享可恢复）；非法 id 有明确提示并回落。
- `AC-US-ZHIKU-RN-02-04`：相似推荐区带"🧪 演示推荐（同领域规则），非相似度算法产出"诚实性标注。
- `AC-US-ZHIKU-RN-02-05`：关闭抽屉后 URL 参数清除，刷新不再弹出详情。

不包含：真实相似度推荐算法（Embedding/协同过滤）；实体关系图谱（归共性网络/知识图谱能力）。

### US-ZHIKU-RN-05｜研判媒体舆情并生成报告

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |

| 产品角色 | `ROLE-RN-INTEL` |
| 依赖 | US-01/US-02（实体回链）、跨叶子 ZHIKU-WRITING（报告生成） |
| Frame | `F-RN-05` |
| 业务结果 | 舆情按层次筛选研判、预警可处理且处理态持久化、关联实体可回链下钻、"生成舆情研判报告"真实创建写作预填任务 |

作为舆情研判人员，我想按层次浏览媒体舆情、处理预警条目、并把研判结论一键转成报告任务，以便让舆情信号真正进入决策支撑流程。

主路径：

1. 用户切到"媒体聚焦"标签。
2. 统计卡显示待处理预警数（ⓘ `ZHIKU-RN-MEDIA-WARNING-PENDING`）；舆情列表含标题、层次、情感、关联实体。
3. 用户按层次（国际/国家/省市/城市/机构/学科）过滤列表；层次分布可视化同步高亮。
4. 用户对预警条目点"标记已处理"，条目移入"已处理"分组，统计卡 -1，刷新后保持。
5. 用户点击关联实体名，回链打开该实体详情抽屉（US-02 复用）。
6. 用户点"生成舆情研判报告"，确认后在 ZHIKU-WRITING 真实创建预填任务（大纲注入当前层次过滤与预警统计）并跳转大纲确认页。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 层次过滤无结果 | 局部 Empty + "查看全部层次" | 一键恢复 |
| 预警全部处理完 | 待处理分组 Empty 态"当前无待处理预警"，统计卡为 0 | 无需处理 |
| 关联实体不在清单中 | 提示"关联实体未收录"，不打开空抽屉 | 无需处理 |

验收：

- `AC-US-ZHIKU-RN-05-02`：预警条目可标记已处理，待处理统计卡（ⓘ `ZHIKU-RN-MEDIA-WARNING-PENDING`）随之变化，刷新后处理态保持。
- `AC-US-ZHIKU-RN-05-03`：关联实体可回链打开实体详情抽屉（与 US-02 同一组件，上下文不丢失）。
- `AC-US-ZHIKU-RN-05-04`："生成舆情研判报告"真实调用写作模块 `createTask` 创建预填任务（大纲含当前统计数值）并跳转大纲确认（跨叶子契约 CT-RN-01）。
- `AC-US-ZHIKU-RN-05-05`：知识图谱深度联动能力带"🧪 演示态：预置关联关系"诚实性标注（真实图谱联动依赖 NebulaGraph 接入，登记 GAP）。

不包含：真实舆情采集与情感分析；知识图谱实时联动（demo 用预置关联）；报告写作本体（归 ZHIKU-WRITING）。

## 5. 跨故事走查

1. **实体底盘 → 画像 → 报告**：US-01 导入/筛选实体 → US-02 下钻画像 → US-05 舆情联动看到同一实体的舆情并生成报告——实体 id 全程一致，抽屉组件复用。
