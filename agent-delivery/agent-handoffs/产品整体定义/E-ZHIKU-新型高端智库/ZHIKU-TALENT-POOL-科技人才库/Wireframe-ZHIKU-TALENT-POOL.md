## 全局约束

- 所有统计数字：数字 → ⓘ（或红问号）→ 结构 → ⚠️/⏰ → 🧪/⟳ 排列，间距 4px，最多 3 枚。
- 空/加载/失败三态：列表用局部 Empty + 引导动作；导出/保存前置校验禁用态。
- 演示态标注点：影响力/成长指数公式、智能推荐、资讯池、推送生成、心理信息全维度。
