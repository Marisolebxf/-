## 1. 模块结果

围绕一次明确的报告创作诉求，让智库用户完成"模板/自然语言两种方式发起 → 大纲确认 → 后台 AI 写作 → 编辑器内引用溯源与改写 → 导出/发布进入成果沉淀"的完整闭环。不承接战略咨询报告的选题管理与洞察发布运营（归 ZHIKU-STRATEGY-REPORT），不承接智能问数的问答式取数工作台（归 ZHIKU-SMART-QUERY），不做真实大模型推理——demo 阶段所有 AI 产出为标注 🧪 的演示文本。

## 4. 用户故事

### US-ZHIKU-WR-01｜挑选、预览并复用报告模板

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 88（挑选与预览模板）、96（复制系统模版并编辑） |
| 产品角色 | `ROLE-WR-ANALYST` |
| 依赖 | 无（模块入口故事） |
| Frame | `F-WR-02` |
| 业务结果 | 用户在创建任务前确认了模板的框架、排版样式与示例内容，或以系统模板为底创建了可编辑的个人副本 |

作为智库研究分析人员，我想按行业与场景筛选模板并预览其框架、排版样式与示例内容，以便在动笔前选对报告骨架。

主路径：

1. 用户从报告创作首页进入模板库，或在创作配置步骤点击"去模板库挑选"。
2. 模板库按"系统模板 / 我的模板"分区，支持按报告类型（研究/战略/洞察）与行业标签筛选。
3. 用户点击模板卡打开预览抽屉：左侧章节框架树、右侧示例内容与排版样式说明。
4. 用户在预览抽屉内选择"用此模板创建"（进入 US-02 配置）或"复制为我的模板"（进入 US-06 编辑）。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 筛选后无模板 | 分区内局部 Empty，提示放宽筛选，保留筛选条 | 调整筛选或切换分区 |
| 我的模板为空 | Empty 态给出"从系统模板复制一份开始"引导按钮 | 一键跳到系统模板分区 |
| 预览内容缺失（模板未配示例） | 预览抽屉保留框架树，示例区显示"该模板未提供示例内容" | 仍可创建或复制 |

验收：

- `AC-US-ZHIKU-WR-01-01`：模板库可同时按报告类型与行业标签过滤，过滤结果实时更新且清空筛选可恢复全量。
- `AC-US-ZHIKU-WR-01-02`：任一模板卡可打开预览抽屉，抽屉内可见章节框架树（≥2 层）、示例内容段落与排版样式说明三个区块。
- `AC-US-ZHIKU-WR-01-03`：预览抽屉的"用此模板创建"直达创作配置且模板已选中；"复制为我的模板"后我的模板分区立即出现副本（名称带"副本"后缀）。
- `AC-US-ZHIKU-WR-01-04`：复制产生的个人模板可直接进入编辑（US-06），系统模板本体不可被编辑或删除。
- `AC-US-ZHIKU-WR-01-05`：模板库操作全程不创建报告任务，任务列表数量不变。

不包含：模板的后台运营管理（上架/下架）；模板市场付费逻辑。

### US-ZHIKU-WR-02｜自定义大纲并注入分析思路

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 89（自定义模版大纲内容）、90（自定义分析思路自动生成段落） |
| 产品角色 | `ROLE-WR-ANALYST` |
| 依赖 | US-01（已选模板）或 US-04（NL 发起） |
| Frame | `F-WR-03`、`F-WR-04` |
| 业务结果 | 任务的大纲结构与各章节分析思路成为 AI 写作的显式输入，用户对最终骨架有完全控制权 |

作为智库研究分析人员，我想打破固定模板、自由组合分析章节并为特定章节写下分析思路，以便 AI 按我的思路而不是模板默认套路生成内容。

主路径：

1. 创建任务后进入大纲确认工作区，左侧为模板生成的章节树（支持二级）。
2. 用户可新增、删除、重命名、上下移动章节，可从"常用分析章节"面板（宏观环境、竞争格局、政策法规、核心建议等）拖入或点选插入。
3. 用户选中任一章节，在右侧"分析思路"输入框写入自然语言思路（如"重点对比深圳与新加坡的政策力度"）。
4. 确认大纲后系统提交 AI 写作任务（进入 US-03）；带思路的章节生成的段落会标注"依据您的分析思路生成 🧪"。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 删空全部章节 | 确认按钮禁用并提示"至少保留一个章节" | 恢复或新增章节 |
| 章节标题为空 | 该节点标红，确认时定位到首个空标题 | 补全标题 |
| 中途返回配置步骤 | 大纲草稿保留在任务内，再次进入不丢失 | 继续编辑 |

验收：

- `AC-US-ZHIKU-WR-02-01`：章节可新增、删除、重命名、上移下移，操作即时反映在章节树且刷新页面后仍保留（持久化）。
- `AC-US-ZHIKU-WR-02-02`：常用分析章节面板至少提供 6 个预置章节，点选后插入当前选中位置之后。
- `AC-US-ZHIKU-WR-02-03`：任一章节可保存独立的分析思路文本，切换章节后各自思路互不串扰。
- `AC-US-ZHIKU-WR-02-04`：确认大纲后，编辑器中带思路章节的段落可见"依据您的分析思路生成"的 🧪 标注，且段落文本包含思路关键词的演示化转写。
- `AC-US-ZHIKU-WR-02-05`：大纲为空时无法提交，且不产生状态为 `writing` 的任务。

不包含：大纲的多人协同编辑；模板结构的版本对比。

### US-ZHIKU-WR-03｜后台执行写作任务并可回溯历史

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 91（后台运行执行 AI 写作任务）、102（历史创作内容保存） |
| 产品角色 | `ROLE-WR-ANALYST` |
| 依赖 | US-02 |
| Frame | `F-WR-06` |
| 业务结果 | 用户提交任务后可离开页面，任务在后台推进；任何历史创作可从任务列表回溯打开 |

作为智库研究分析人员，我想提交写作任务后去做别的事、回来再看结果，并能随时找回历史创作内容，以便不被页面等待绑架且积累可复用的写作资产。

主路径：

1. 大纲确认提交后，页面提示"任务已进入后台写作"，用户可立即离开。
2. "我的报告任务"列表展示任务状态（配置中/大纲确认中/AI 写作中/草稿完成/待发布审核/已发布）与进度条；`writing` 状态任务的进度随时间推进（demo 以定时器模拟，🧪 标注）。
3. 写作完成后状态自动翻转为"草稿完成"，列表内出现"进入编辑器"动作。
4. 历史任务（含已发布）永久保留在列表，点击可打开只读或可编辑视图；创作历史区支持按类型与关键词检索。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 写作中打开任务 | 编辑器只读，展示进度与"生成中"骨架段落 | 等待完成或返回列表 |
| 任务列表为空 | Empty 态引导"去报告创作发起一个" | 点击直达创作首页 |
| 刷新/重开浏览器 | 任务与进度从持久化存储恢复，不回退不丢失 | 无需操作 |

验收：

- `AC-US-ZHIKU-WR-03-01`：提交任务后离开页面再回到任务列表，任务存在且状态/进度正确；无需停留在创作页等待。
- `AC-US-ZHIKU-WR-03-02`：`writing` 状态任务的进度在打开列表时可观察到推进，完成后自动转为"草稿完成"且出现编辑入口。
- `AC-US-ZHIKU-WR-03-03`：任务全量持久化：刷新页面后任务列表、状态、正文、版本记录完整保留。
- `AC-US-ZHIKU-WR-03-04`：创作历史可按报告类型过滤与标题关键词搜索，命中项可直接打开对应任务。
- `AC-US-ZHIKU-WR-03-05`：模拟进度带 🧪 标识，不出现"实时算力"或伪真实时间承诺文案。

不包含：任务优先级调度、失败重试策略（正式接入后由服务端定义）。

### US-ZHIKU-WR-04｜自然语言交互式写作

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 98（自然语言写作输入）、99（对话意图确认与追问引导）、100（自动调取数据与图表生成）、101（图表样式切换） |
| 产品角色 | `ROLE-WR-ANALYST` |
| 依赖 | 无（与 US-01 并列的第二入口） |
| Frame | `F-WR-03`（NL 模式）、`F-WR-05` |
| 业务结果 | 一句大白话诉求经确认后转化为带数据图表的报告任务，图表样式可按需切换 |

作为智库研究分析人员，我想用大白话直接说出分析需求、让系统确认我的意图并自动配上数据图表，以便不学习复杂菜单也能产出专业报告。

主路径：

1. 创作首页选择"自然语言发起"，输入如"帮我分析深圳人工智能产业近三年的竞争格局"。
2. 系统解析输入并弹出意图确认卡：识别出的主题、报告类型、时间范围、拟采用章节，模糊项以选项形式追问（如"竞争格局侧重企业维度还是区域维度？"）。
3. 用户确认/修正后生成任务，进入大纲确认（US-02 复用）。
4. 写作完成的正文中，数据型章节自动插入图表卡（🧪 演示数据），图表卡右上角提供样式切换（柱状/折线/饼图），切换即时生效且保存。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 输入过短或无法解析 | 意图卡显示"需要更多信息"并给出示例句式，不生成任务 | 补充描述后重试 |
| 用户取消意图确认 | 返回输入态，已输入文本保留 | 修改后重新提交 |
| 图表数据为空 | 图表卡显示局部 Empty"该主题暂无演示数据"，不渲染假轴 | 更换主题或忽略 |

验收：

- `AC-US-ZHIKU-WR-04-01`：NL 输入提交后必先出现意图确认卡，用户未确认前不产生任务。
- `AC-US-ZHIKU-WR-04-02`：意图确认卡包含主题、报告类型、时间范围三项识别结果，且至少一项支持选项式追问修正。
- `AC-US-ZHIKU-WR-04-03`：确认后的任务标题与章节可见 NL 输入的关键词转写，与模板发起的任务走同一大纲确认与后台写作流程。
- `AC-US-ZHIKU-WR-04-04`：生成正文中至少一个章节带图表卡，图表卡可在柱状/折线/饼图间切换，切换后刷新页面仍保留所选样式。
- `AC-US-ZHIKU-WR-04-05`：图表卡与意图解析均带 🧪 演示标识，图表数据来源在卡片脚注注明 mock 来源名。

不包含：语音输入（demo 仅文字，语音为正式阶段能力）；跨库真实取数。

### US-ZHIKU-WR-05｜引用溯源、原文跳转与 AI 改写

| 属性 | 内容 |
| --- | --- |
| `source_relation` | `direct_requirement` |
| `requirement_refs` | 序号 103（自动生成规范脚注）、104（引用内容查看来源出处）、105（一键跳转原文/研报页面）、106（报告文本 AI 改写）、107（自动生成数据溯源附录） |
| 产品角色 | `ROLE-WR-ANALYST`、`ROLE-WR-REVIEWER` |
| 依赖 | US-03（草稿完成后进入编辑器） |
| Frame | `F-WR-05` |
| 业务结果 | 报告中每个引用可核查来源与提炼过程、可跳原文；不满意的段落可按需求改写；附录自动汇总所有引用 |

作为智库研究分析人员，我想让报告的每个引用自动带规范脚注、可查提炼过程、可跳原文，并能框选文本按我的要求 AI 改写，以便交出可信且合意的报告。

主路径：

1. 编辑器正文中引用句尾自动带脚注角标（`[1]` `[2]`…，按行业规范格式）。
2. 点击角标打开来源抽屉：来源标题、类型（研报/新闻/数据库/用户素材）、原文摘要、"提炼过程"说明（原始信息 → 加工逻辑 → 报告结论）。
3. 来源抽屉内"查看原文"打开原文预览弹窗（demo 内置原文页，🧪 标注；正式态为外链研报/新闻页）。
4. 用户框选正文任意文本 → 浮出"AI 改写"入口 → 输入修改需求（如"更简洁、面向决策者"）→ 生成改写稿并排对照 → 用户选择替换或放弃；替换记入版本历史。
5. 正文末尾"数据溯源附录"区块自动汇总全部脚注来源与参考文献，随引用增删实时更新。

| 异常 | 系统行为 | 用户下一步 |
| --- | --- | --- |
| 无引用的段落 | 不显示角标，附录不出现空条目 | 无需操作 |
| 未框选文本点击改写 | 改写入口禁用并提示"请先框选要改写的文本" | 框选后重试 |
| 改写结果不满意 | 对照视图可"放弃"，正文保持原样，不产生版本 | 重新输入需求 |
| 原文缺失 | 来源抽屉保留摘要，"查看原文"置灰并注明"原文暂未接入" | 以摘要核查 |

验收：

- `AC-US-ZHIKU-WR-05-01`：demo 正文中脚注角标 ≥3 个且编号连续，格式统一为方括号数字。
- `AC-US-ZHIKU-WR-05-02`：任一角标可打开来源抽屉，抽屉含来源标题、类型标签、原文摘要、提炼过程四要素。
- `AC-US-ZHIKU-WR-05-03`：来源抽屉"查看原文"可打开原文预览（或在原文缺失时显式置灰说明），关闭后焦点回到角标位置。
- `AC-US-ZHIKU-WR-05-04`：框选文本后可发起 AI 改写，输入需求后展示原文/改写稿并排对照；选择替换后正文更新且版本历史新增一条 🧪 改写记录。
- `AC-US-ZHIKU-WR-05-05`：数据溯源附录自动列出全部引用来源（含用户素材），删除正文中某引用后附录同步移除对应条目。
- `AC-US-ZHIKU-WR-05-06`：AI 改写产物带 🧪 演示标识，不声明为真实大模型输出。

不包含：批注协作、多人评审留痕（归正式阶段协同能力）。
