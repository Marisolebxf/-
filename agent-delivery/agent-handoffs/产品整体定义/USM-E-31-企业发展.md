## 1. 产品定义结论与适用边界

企业发展是科技专题服务系统快速入口中的企业态势能力：通过产业内企业的总体规模、结构、空间分布与重点对象信息，帮助用户建立企业发展判断，并进入对应的后续分析任务。

当前产品将该能力呈现为“企业分析”工作区。它不是单一页面，也不等同于任一三级 Tab；它承接企业总览、企业查询、重点企业分析、对比篮、企业评估、风险洞察、引育推荐和维护管理等相关能力。

本文件定义企业发展 / 企业分析的产品目标、用户、能力层级、模块边界、用户任务、故事、walkthrough、验收与需求差异。TRACE 负责 bid 叶子和 route 的追溯；指标语义卡负责指标口径与数据来源；IA 与 Wireframe 负责信息结构和体验方案，不替代本文件的产品定义结论。

## 6. 完整样例：企业总览 → 企业整体概况（E-32）

### 6.1 需求归位与产品定义

原始需求 E-32 包含企业总体数量、企业分布情况和科研人数。产品定义将其归位为三类彼此独立但共同支持宏观判断的能力：

| 原始需求内容 | 产品能力归位 | 用户获得的判断 | 不承担的任务 |
| --- | --- | --- | --- |
| 企业总体数量 | 顶部全球 KPI 与未来产业企业数量排名 | 企业规模、产业覆盖和产业规模差异 | 企业对象查询或集合下钻。 |
| 历年发展趋势 | 选中一个或最多两个产业的趋势比较 | 产业企业数量是否具备可比变化 | 单一时间点的伪趋势或同比营销表达。 |
| 企业分布情况 | 独立的四级地域地图 / 列表卡片 | 企业空间布局与地域聚合差异 | 对顶部 KPI 或产业排名施加全局筛选。 |
| 科研人数 | 顶部全球企业科研人数 KPI | 企业发展中的科研人力规模 | 在企业分布卡片重复增加选中产业统计。 |

### 6.2 模块定位与相邻边界

企业整体概况是企业总览的三级门户展示：用户在此形成“规模—产业—空间—科研人力”的初步判断，再按需要进入重点企业概览、企业查询、重点企业分析、评估、风险或推荐模块。

它不承接企业查询、高级筛选、企业集合下钻、竞争力评估、风险诊断、引育推荐、维护或导出。上述能力出现时，应路由到相应产品模块，不得以“概况补功能”为由侵入 E-32。

### 6.3 用户故事

#### US-E32-01 查看总体态势

作为科研人员，我想先查看标明“全球”的企业总数、企业科研人数和覆盖未来产业数，再比较八大未来产业的企业数量及趋势，以便判断产业发展规模和变化。

#### US-E32-02 查看空间分布与科研人力

作为政府科技管理与决策部门用户，我想在企业分布卡片中从深圳逐级缩放至全球、并切换热力地图或列表视图，以便形成对产业空间布局的总体判断。

### 6.4 场景 walkthrough

#### 主路径

1. 用户从左侧菜单进入“企业分析”，进入“企业总览”，默认落在“企业整体概况”三级 Tab。
2. 页面展示全球企业总数、全球企业科研人数和覆盖未来产业数；三项均为库内全量 / 全球视角，不随下方产业或地域选择变化。
3. 用户查看按企业数量排序的八大未来产业（或实际覆盖产业）；可选一个产业查看趋势，或最多选择两个产业比较趋势。
4. 当存在至少两个连续可比时间点时，页面展示所选产业的历年企业数量趋势；否则隐藏趋势模块，产业排名区占满整行。
5. 用户在独立的企业分布卡片内操作全球、全国、区域、深圳四级地域选择器；默认深圳，不影响顶部 KPI 和产业统计。
6. 用户在地图与列表视图之间切换；地图按当前层级返回聚合数据，深圳不逐企业点位打点。
7. 用户完成宏观判断后，按后续任务进入相邻企业分析模块；本页不直接发起对象集合下钻或评估操作。

#### 异常与降级路径

| 场景 | 产品行为 |
| --- | --- |
| 正式数据不足两个可比时间点 | 隐藏趋势模块；不显示单点折线或虚假比较。 |
| 企业科研人数数据未接入 | 顶部 KPI 展示“数据待接入”，不伪造数值。 |
| 地图 / 趋势加载中、失败或无数据 | 保持容器尺寸，分别展示加载、可重试错误或空态；不影响其他判断区。 |
| 正式地域口径未闭合 | 保持 DEMO 标识与 Q-E32-02，不能将原型聚合数据表述为正式来源。 |

### 6.5 验收场景

| 编号 | 可验证的用户结果 |
| --- | --- |
| E32-USM-01 | 用户在企业整体概况看到企业总体数量、企业分布情况和科研人数三类原始功能，不会看到企业查询或重点企业分析能力混入页面主体。 |
| E32-USM-02 | 用户切换产业或地域后，顶部“全球企业总数”“全球企业科研人数”“覆盖未来产业数”仍保持全局汇总。 |
| E32-USM-03 | 用户可比较一个或两个产业的企业数量趋势；尝试选择第三个产业时得到明确提示。 |
| E32-USM-04 | 数据没有至少两个连续可比时间点时，用户看不到伪趋势，产业排名区保持可用。 |
| E32-USM-05 | 用户在企业分布卡片内切换全球、全国、区域、深圳和地图 / 列表视图；这些操作不影响顶部 KPI 与产业排名 / 趋势。 |
| E32-USM-06 | 用户看到企业科研人数与企业总数均由顶部 KPI 覆盖，企业分布卡片底部不重复出现选中产业统计卡。 |
| E32-USM-07 | 地图或趋势处于加载、失败、空数据或数据待接入状态时，用户仍能理解当前状态并继续使用其他模块内容。 |

### 6.6 与 bid-reference 的差异说明
