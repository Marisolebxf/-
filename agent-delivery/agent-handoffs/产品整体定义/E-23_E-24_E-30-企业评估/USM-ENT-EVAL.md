## 3. 用户故事

### US-ENT-EVAL-OBJ｜接收和确认评估对象

**作为**任一有权评估的产品角色，**我想要**从对比篮自动带入企业并在评估页确认或剔除本次不参与对象，**以便**新增来源唯一、无需重复选择且能恢复原工作现场。

- 接收 `enterprise_codes[]`、`source=compare-basket`、`analysis_type`、`return_context_id`。
- 显示“来自对比篮 · X 家”和企业名称；有效对象自动成为本次对象。
- 评估页不提供企业搜索、候选池或新增；可移除本次对象且不回写对比篮，补充对象返回对比篮，同一上下文恢复篮内筛选、勾选和滚动位置。
- 无权 / 失效对象剔除后明确提示；仍需按模式重新校验最少对象数。

### US-ENT-EVAL-TECH｜配置技术力评估

**作为**政府、园区、投资研究、行业协会或企业自身用户，**我想要**用至少两家企业的技术指标和可调整权重创建技术力评估，**以便**比较技术能力、排名和差异。

- 可加载系统 / 个人模板，选择技术力指标并当次调权。
- 关联 `M_ENT_TECH_POWER_SCORE`、`M_ENT_TECH_RANK`、`M_ENT_PATENT_GRANT_COUNT`、`M_ENT_RD_INVESTMENT_RATIO`。
- 结果使用归一化技术维度解释能力结构，不把专利数量、研发投入比例或排名直接混在同一雷达量纲中。
- 两家直接进行双企业技术维度对比；三家及以上保留全对象技术力加权排名，并允许从任务对象集中任取两家进入双企雷达和指标差异诊断。

### US-ENT-EVAL-BIZ｜配置商业力评估

**作为**上述产品角色，**我想要**用至少两家企业的经营指标和可调整权重创建商业力评估，**以便**识别经营竞争力和短板。

- 关联 `M_ENT_BUSINESS_POWER_SCORE`、`M_ENT_REVENUE_LATEST`、`M_ENT_REVENUE_GROWTH_RATE`、`M_ENT_PROFIT_MARGIN`、`M_ENT_MARKET_SHARE`。
- 全部对象对比营业收入、收入增长率和利润率，并保留全对象商业力综合排名；排行只在主排名图表达一次，下方合并诊断明细不再重复排名。
- 商业指标各自保留亿元 / % 等原单位，不以雷达或营收 / 专利双轴图混合量纲；营收趋势只在任务快照具有连续年度数据时出现。
- 市场份额在 `Q019` 未闭合前标为不可用，不以样例数据替代正式口径。

### US-ENT-EVAL-COMP｜配置综合竞争力评估

**作为**上述产品角色，**我想要**从至少一家企业出发配置维度权重和维度内指标权重，**以便**获得综合竞争力画像与短板。

- 关联 `M_ENT_COMPETITIVENESS_SCORE`、`M_ENT_COMPETITIVENESS_RANK`、`M_ENT_SHORTBOARD_COUNT`、`M_ENT_INNOVATION_INDEX`。
- 一家进入单企诊断，对比对象集均值和对象集领先值；两家展示双企业竞争力雷达与差距。
- 三家及以上仍展示全对象综合排名，同时允许在“单企诊断 / 双企对比”间切换；双企雷达最多两条企业曲线。
- 维度权重与维度内权重分层配置，默认折叠展开，避免单表混淆。

### US-ENT-EVAL-QUALITY｜校验模板、权重和数据质量

**作为**评估发起人，**我想要**在生成前看清指标有效性、权重错误、数据覆盖和可信度，**以便**避免把不可比或缺数据的结果当成正式结论。

- 权重用 0～100 的整数输入；支持一键平均分配，不静默自动归一化。
- 所需权重层级都必须合计 100；错误定位到具体维度 / 指标。
- 缺失不记 0；覆盖度 <50% 或关键指标全部缺失时阻止生成。
- 每家企业分别给出高 / 中 / 低可信度；数据结构不同提示可比性风险。
- 点击指标说明“查看”打开业务抽屉，展示目的、维度、业务口径、单位、方向、范围、状态和缺失影响；内部评审模式追加 `metric_id`、公式、源表、源系统、更新频率、版本和开放问题，业务模式不渲染内部字段。

### US-ENT-EVAL-RESULT｜生成并理解正式结果

**作为**评估发起人，**我想要**生成有任务快照、指标依据和可信度说明的正式结果，**以便**复核结论并采取后续行动。

- 只有用户明确触发生成，才创建 `evaluationTaskId` 和任务记录并进入处理中；仅保存配置不产生任务。后台成功后同一任务转为已完成并开放结果，失败则保留失败阶段供恢复或重试。
- 用户触发生成后先进入独立过程页，按任务提交、权限与配置校验、企业数据汇聚、指标计算、可信度与可比性校验、结果图表组装展示；不伪造后台百分比，允许离开并从最近评估或个人中心恢复。
- 结果固定关联系统生成的只读 `task_display_name`、对象、模式、`template_id` / 模板版本、已选指标、每项整数权重、可信度、数据批次、算法版本、权限范围和生成时间；任务展示名不来自个人模板名称。
- `data_batch` 是正式快照字段，但当前 DEMO 未接入数据批次；评审态只说明“数据批次未接入”，业务态不显示该内部缺口，任务与报告不得写入 `mock_20260618` 等伪造值。
- 页面先给 4 个以内 KPI 和一个结论条，再展示模式适配图表、明细及短板。
- 所有模式的全对象排名只按任务快照中的模式综合得分排序，不得以第一个已选指标值替代；刷新和历史恢复保持同一结果。
- 结果页切换当前诊断企业或企业 A / B 只改变观察视角，不修改任务快照、综合得分或报告指纹。
- 内部评审模式展示顶部“企业评估”评审标题及页面 / 配置 / 关键结果 REQ 追溯；业务模式隐藏该评审标题与追溯信息。
- 内部评审模式下，数据覆盖及每个结果子模块标题可查看原需求摘要、来源位置、当前落位和“直接承接 / 产品化展开”分类；业务模式不渲染这些评审信息。

### US-ENT-EVAL-REPORT｜生成受控评估报告

**作为**有报告权限的评估发起人，**我想要**从结果页提交后台报告任务并查看状态，**以便**获得可审计、可下载的评估材料。

- 仅结果页提供报告；默认 PDF，Word 后续开放。
- 状态为提交、数据准备、评分计算、图表生成、报告组装、完成 / 失败。
- 同指纹的处理中或有效报告复用，不由前端缓存冒充后台事实。
- 下载受字段分级、脱敏 / 审批、对象数量、报告模板和审计约束。
- 报告完成态提供“下载当前报告”，下载文件必须关联当前 `task_id` 并由当前不可变结果快照生成；未完成、无权限或任务不一致时不可下载。

### US-ENT-EVAL-HISTORY｜找回和复用评估任务

**作为**评估发起人，**我想要**查看最近已提交的评估任务并恢复过程、结果或基于旧配置创建新任务，**以便**持续研判而不覆盖历史事实。

- 展示任务 ID、模式、企业摘要、模板 / 版本、数据批次、时间、可信度和报告数。
- 支持恢复结果、按此配置新建评估、查看关联报告。
- “按此配置新建评估”复制配置形成新草稿，不覆盖旧任务；历史不扩展为团队协作或复杂版本管理。
- 最近评估与个人中心“评估任务”读取同一任务集合和状态；个人中心只提供跨场景继续查看入口，不复制第二份任务、报告数或状态。

## 4. 主路径

### 4.1 从对比篮发起

1. 用户在对比篮选择企业和评估类型，确认“下一步：前往配置”。
2. 企业评估解析对象并显示来源；用户可移除本次不参与对象，并处理无权 / 失效对象提示。
3. 页面按 `analysis_type` 打开对应模式，用户加载模板并调整指标 / 权重。
4. 预检展示每家企业的数据覆盖和可信度，阻止不满足条件的生成。
5. 用户触发生成，系统创建任务快照并进入独立生成过程页；过程页展示六个业务阶段、已用时间和可离开提示。
6. 生成完成后进入结果页，展示结论、模式解释型分析、全对象综合排名、指标诊断、短板和报告入口；用户可在任务对象集中切换当前诊断企业或双企 A / B。
7. 用户可返回对比篮恢复现场，或从最近评估、个人中心找回同一任务。

### 4.2 直接进入

1. 用户从企业中心进入企业评估，选择模式。
2. 页面不预填演示企业，显示空对象状态和“前往对比篮选择企业”。
3. 对比篮按当前评估模式预选分析类型；用户完成对象选择后进入主路径第 2～7 步。

## 5. 异常与权限路径

| 场景 | 系统行为 | 用户可行动作 |
| --- | --- | --- |
| 无对象 | 展示空态，不加载空图表 | 前往对比篮选择企业 |
| 对象数量不足 | 技术力 / 商业力少于 2 家时说明原因 | 返回对比篮调整或切换综合竞争力 |
| 对象无权或失效 | 剔除无效对象并逐类汇总提示 | 使用有效交集或返回对比篮 |
| 权重不等于 100 | 阻止生成并定位层级，不自动归一化 | 修改或一键平均分配 |
| 部分指标缺失 | 不记 0，重算可用指标并降低可信度 | 查看缺失说明后继续或换对象 / 指标 |
| 覆盖度 <50% / 关键指标全缺 | 禁止正式生成 | 更换对象、指标或等待数据 |
| 低可信度 | 允许生成但显著警示；报告同步带入 | 确认继续或返回调整 |
| 生成中 | 保留任务进度，防止重复提交 | 离开后从最近评估查看 |
| 生成失败 | 保留失败阶段与可审计错误编号 | 重试或按此配置新建评估 |
| 无报告权限 | 保留入口位置并说明权限原因 | 查看在线结果 |
| 同指纹报告已存在 | 复用处理中 / 有效任务 | 查看状态或下载 |
