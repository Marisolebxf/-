# 企业模块深化 UE 规格

## 版本

Draft v0.1

## 文档定位

本文件定义企业模块的 UE 层规则，用于把已确认的产品边界转成页面组织、对象流转、状态反馈、任务进度、追溯浮层和后续 frontend-agent 可执行规则。

本文件不重新定义企业模块产品能力、字段口径、指标模型、权限角色矩阵或原需求编号。上述内容以 `企业完整深化规格.md`、`需求追溯标号规范.md` 和已确认决策为准。

平台级通用交互规范仍由 `UX-UE 通用交互组件规范.md` 约束。本文件只写企业模块业务页面的深化 UE，不重复平台级组件规范。

## 企业模块 UE 总则

| 规则 | 说明 |
| --- | --- |
| 不重复页面标题 | 内容区不默认重复左侧菜单已经表达的页面标题；页面定位由左侧菜单、必要时的面包屑和浏览器 / route title 承担 |
| 顶部承载业务上下文 | 内容区顶部优先放视图切换、对象确认、筛选配置、任务状态或上下文信息 |
| 页面级导航按业务语义组织 | `企业总览 / 企业查询 / 重点企业分析 / 对比篮 / 企业评估 / 风险洞察 / 引育推荐 / 维护管理` 是当前企业模块二级菜单基准 |
| 分析前先确认对象 | 进入企业评估、风险洞察、引育推荐等分析型页面前，需要对象选择或对象确认；外部带入对象时展示来源和数量 |
| 跨模块动作带上下文 | 从查询、总览、画像、对比篮等入口带入后续模块时，必须携带企业对象、来源入口、条件摘要和数据批次 |
| 统一反馈状态 | 查询、筛选、保存、导出、报告生成、权限受限、数据异常等状态使用统一反馈口径 |
| 后台生成按异步任务处理 | 报告、导出、名单生成、诊断生成等能力展示任务状态，不以同步页面刷新伪装生成完成 |
| 追溯浮层隔离 | `TraceInfoIcon` 只在演示 / 内部评审模式显示；普通业务模式隐藏，不改变业务权限和数据可见范围 |

### 企业结果列表通用复用规则

企业查询结果、企业总览下钻结果、候选名单、对比篮相关对象列表优先复用同一套企业结果列表模型，避免每个页面重新定义筛选、视图、选择、对象状态和权限反馈。

| 通用能力 | 复用规则 |
| --- | --- |
| 来源摘要 | 列表顶部必须说明当前企业集合来源、命中 / 集合数量、条件摘要、数据批次或更新时间。不同业务页可改名，例如企业查询为 `查询方案摘要`，企业总览下钻结果为 `来源摘要` |
| 轻量筛选 | 只作用于当前结果集合，不改变原始来源条件；复杂组合条件、字段范围扩展、AND / OR 关系回到高级筛选字段库处理 |
| 排序 | 排序字段必须是结果可解释字段；进入排序下拉的字段必须在卡片视图或表格视图中可见 |
| 视图切换 | 支持 `卡片视图 / 表格视图`；切换不丢失来源条件、轻量筛选、排序、分页和已选状态 |
| 卡片视图 | 用于单企业快速判断和单企业流转，遵循 `主识别 -> 标签 -> 核心字段 -> 行级操作` 的结构 |
| 表格视图 | 用于批量核对、排序和批量操作；默认显示选择框，首批按当前页选择处理，跨分页选择作为后续增强 |
| 对比篮状态 | 同一企业在查询、画像、详情、总览、对比篮和引育推荐等企业对象入口中同步已加入状态 |
| 候选状态 | 招引候选和培育候选分别同步；重复加入不重复添加，并反馈已存在数量或状态 |
| 权限反馈 | 统一使用 `可用 / 禁用 / 锁态 / 不可见` 四类状态；无权限字段按脱敏、隐藏、禁用或审批提示处理 |
| 分页与加载 | 切换分页不清除来源条件、轻量筛选和排序；列表区域展示稳定 loading，工具条保留当前来源摘要 |
| 失败反馈 | 加入对比、加入候选、导出、保存等失败时保持原上下文，提示失败原因并提供重试或修正入口 |

业务页只定义差异项：是否允许导出、是否允许保存为查询方案、来源摘要命名、默认视图、首屏筛选字段、可用批量动作和跨模块带入上下文。若没有明确业务差异，默认继承企业结果列表通用复用规则。

## 企业总览 UE 规格

`企业总览` 改为门户展示型页面，承接原“企业发展”。页内一级 Tab 固定按 `企业整体概况 / 重点企业概览 / 明星企业介绍 / 深圳企业介绍` 排列。`E-33` 重点企业产业链全景放在“重点企业概览”内。

> **迁移说明：** 本章下方原“五个分析区”规则改属 `重点企业分析 UE 规格`。其中“重点企业产业链全景”整节迁回企业总览，不再属于重点企业分析。本说明优先于下方尚未完成文字替换的历史页态名称。

### 企业总览页内结构

| 页内 Tab | UE 定位 |
| --- | --- |
| 企业整体概况 | 展示企业总体数量及趋势、全球/全国分布和企业科研人数 |
| 重点企业概览 | 展示重点企业产业链全景、企业基础信息、规模统计和领域统计 |
| 明星企业介绍 | 展示产品功能、技术优势、团队实力和产业生态 |
| 深圳企业介绍 | 固定深圳地域，按各未来产业展示深圳企业数量及趋势、领域分布、规模和重点企业；领域分布结合各未来产业链全景图 |

### 企业总览专题产业上下文

企业总览虽然展示企业对象，但共同业务上下文是科技专题服务的八大未来产业。原文同时要求“各未来产业”聚合 / 对比展示，以及进入某一未来产业组织全产业链内容；因此不能把门户扩大到传统产业或一般战略性新兴产业，也不能把不同未来产业直接混成一条产业链。

原型先支持八大未来产业：`企业整体概况` 的默认首屏展示八大未来产业的聚合或并列对比；`重点企业概览` 进入其中一个具体未来产业后，再按“当前未来产业 + 当前产业链”展示全链重点企业。八大产业的具体目录及产业链映射保留为待确认事项，不阻塞原型按该范围组织。

原型展示可使用合理模拟数据：构造 8 个未来产业、对应产业链、重点企业、明星企业和深圳统计数据，并保证跨 Tab 的名称、关系和数值叙事一致。模拟数据必须通过独立数据结构提供，以便后续替换为专题目录和真实数据批次；不在页面中宣称模拟产业名称或数值为已确认正式数据。

| 位置 | UE 规则 |
| --- | --- |
| 页面级上下文 | 在四个 Tab 共享的稳定位置展示 `科技专题服务 / 八大未来产业或当前未来产业 / 数据时间或批次`；切换 Tab 时保持专题上下文，不静默清空 |
| 企业整体概况 | 企业总体数量与企业分布默认按“八大未来产业”聚合 / 对比，标题、图例和数据范围明确表达该统计分组；科研人数展示产业科研人数规模，不使用企业从业者总人数替代 |
| 深圳企业介绍 | 固定深圳地域，以八大未来产业为数量、规模和重点企业的统计分组；领域分布关联各未来产业链全景。可聚焦其中一个具体未来产业，但不默认收窄为单产业，也不提供城市横向对标或企业集合下钻 |
| 企业所属产业 | 原始需求未要求作为企业卡片、表格或节点的必显字段。仅在后续新增跨产业企业对象列表时，可用 `所属未来产业` 作为辅助标签，并标记为产品增强，不与企业资质 / 企业类型混用 |
| 重点企业概览 | 使用 `当前未来产业` 与 `当前产业链` 两层口径；先显示当前未来产业名称，再显示当前产业链名称和全链重点企业 |
| 明星企业介绍 | 当前产业下按预设标准固定展示一家具代表性的明星企业。同一产业、同一标准版本的候选企业共用入选标准；首屏显示所属未来产业、该企业的 `入选理由` 摘要与标准版本 / 数据时间，提供 `查看入选标准` 浮层或抽屉；不提供用户自行选择、换一换或跨产业混排 |
| 切换影响 | 从多产业范围进入具体产业，或切换具体产业后，依赖产业的企业、链位和代表对象统一刷新，旧产业下的局部选中态清除 |
| 产业链区块 | 产业链画布必须显示当前产业链全称；若当前产业包含多条产业链，一次只展示一条并允许区块内轻量切换 |
| 标题规则 | 禁止单独使用无上下文的 `全链重点企业`；建议使用 `集成电路产业链 · 全链重点企业`，或在标题旁稳定显示 `当前产业链：集成电路产业链` |
| 混合边界 | 多产业可以做聚合或并列对比，但不得把多个产业或多条产业链的上中下游、链位节点和重点企业混合成一条全链 |

`查看入选标准` 展示适用产业、候选范围、标准名称 / 版本、已确认维度和更新时间；这是当前产业候选企业共用的规则。企业页面另展示各自不同的 `入选理由`，说明该企业匹配的具体亮点和可展示证据摘要。两者都不展示具体权重、内部阈值、排名或敏感原始证据。标准尚未定稿时，原型以“入选标准待配置”明确标识，不伪造已生效规则。

## 重点企业分析 UE 规格

> **当前权威纠正：** 重点企业分析是专业分析入口，不是企业模块默认主入口；企业总览才承接门户“企业发展”四项展示。重点企业分析位于对比篮之前，页面内的对象操作只在图表或分析项下钻形成明确企业集合后的结果页态出现。结果页可执行加入对比篮、进入企业评估、进入风险洞察、加入招引 / 培育候选；对比篮负责跨菜单暂存与分发，不是重点企业分析的默认数据来源。本说明覆盖本章及历史段落中“企业总览下钻结果页态”“企业总览五个分析区”等旧称，均应理解为“重点企业分析下钻结果页态”和重点企业分析的四个分析区。

### 确认状态

本章用于把 `企业完整深化规格.md` 中已经确认的企业总览产品边界，转成可逐项讨论和后续执行的 UE 规则。当前为 UE 讨论稿：页面级 UE 规格完成并经业务确认前，不进入前端修改；即使局部规则已经写入本文，也必须在用户明确同意后才能生成或执行 frontend-agent 任务。

| 事项 | 当前状态 | 处理口径 |
| --- | --- | --- |
| 页面定位 | 已确认 | 重点企业分析是企业生态结构理解和对象发现的专业入口，不是企业模块默认主页，也不替代企业总览、企业查询、企业评估、风险洞察或引育推荐 |
| 页面结构 | 已确认 | 一页纵向结构，可使用页内锚点；不恢复旧 `态势概览 / 企业分布 / 重点对象` 强制 Tab |

| 区块状态 | 已确认 | 五个分析区采用统一状态模板；空态和数据不足说明按分析区业务语义定制 |
| 跨模块动作 | 已确认 | 在下钻结果页勾选企业后，可加入对比篮或进入评估、风险洞察、引育候选；必须携带企业对象、来源分析区、触发点、全局口径、下钻条件、数据批次和操作信息 |
| 前端修改 | 未开始 | 必须等本章 UE 规格经用户确认后才允许进入前端任务 |

### 页面组织

企业总览页不在内容区重复展示 `企业总览` 大标题。左侧二级菜单已经承担页面定位，内容区顶部优先展示当前分析口径、必要的页内锚点和数据批次信息。

| 区域 | UE 规则 | 讨论状态 |
| --- | --- | --- |
| 顶部筛选 / 当前口径 | 只在企业总览首页展示，作为全局口径控件控制整页分析区；进入企业总览下钻结果页态后不再显示顶部筛选，结果页通过来源摘要展示进入时的全局口径和下钻条件 | 已确认 |
| 页内锚点 | 首屏不常驻；页面滚动后可吸顶显示 `区域分布 / 重点全景 / 领域覆盖 / 产业链位置 / 城市对标` 锚点。锚点只用于定位，不作为一级 Tab，也不改变路由主结构 | 已确认 |
| 生态摘要 KPI | 与当前口径分离，独立展示企业总量、企业类型覆盖、可下钻企业量、覆盖领域数等摘要；不展示综合竞争力均值、评分排名或正式报告入口；企业类型覆盖展示命中类型数 / 当前可见类型数，不展示筛选后恒为 100% 的占比；可下钻企业量表达当前口径下可进入结果页态的企业对象数，不使用深圳固定口径文案 | 已确认 |
| 主分析区 | 按五个分析区纵向组织，每个分析区只承接对应原需求，不混入其它模块能力 | 已确认 |
| 企业总览下钻结果页态 | 点击图表、矩阵、链位或城市指标后进入企业总览内新页态，展示当前条件下的企业列表；结果页与触发来源形成明确路径关系 | 已确认 |

页面顶部不放常驻智能搜索，不提供跳转 `企业查询` 的专门入口，也不在总览页内嵌高级筛选字段库。顶部当前口径只控制总览分析口径，不承接企业查询式复杂筛选。用户需要主动检索、复杂筛选、保存查询方案或导出查询清单时，应通过左侧二级菜单进入 `企业查询`。

### 全局口径与局部下钻关系

重点企业分析的全局口径控制整页 KPI、地图、类型结构、领域覆盖、深圳企业产业链位置和城市对标。产业链 / 链位环节是深圳企业现状分析的二级细化条件。局部图表点击默认只影响当前分析区和重点企业分析下钻结果页态，不直接改写顶部全局筛选。

| 交互 | UE 规则 | 待确认点 |
| --- | --- | --- |
| 修改全局口径 | 用户在顶部口径控件中调整产业、地域、企业类型、领域标签或数据批次后，整页分析区按新口径刷新 | 已确认 |
| 点击图表元素 | 在当前分析区内选中图表元素，并进入或刷新该分析区对应的企业总览下钻结果页态；局部下钻不跨分析区保留 | 已确认 |

下钻结果页态不提供高级筛选字段库、保存查询方案、复杂 AND / OR 条件构造或导出。用户需要这些能力时，应进入 `企业查询`，但企业总览下钻结果页本身不设置跳转企业查询的专门入口。

企业总览下钻结果页态相对企业查询结果列表的业务差异：

| 差异项 | 企业总览下钻结果页态规则 |
| --- | --- |
| 来源摘要 | 使用 `来源摘要`，展示来源分析区、来源图表或指标、当前全局口径、当前下钻条件、数据批次和企业集合数量 |
| 查询资产 | 不提供 `保存为查询方案`，不生成最近查询或查询方案资产 |
| 导出 | 不提供 `导出当前结果`、`导出选中` 或 `导出单个企业` |
| 高级筛选 | 不提供高级筛选字段库、复杂 AND / OR 条件构造或保存筛选方案 |
| 默认视图 | 默认使用表格视图承接批量核对；卡片视图作为同一结果页内的视图切换 |
| 批量动作 | 在查询页批量工具栏基础上移除导出，增加进入企业评估和进入风险洞察 |

### 对象操作与跨模块动作

企业总览的对象操作必须基于明确企业集合。未选择对象时，不允许裸跳转到企业评估、风险洞察或引育推荐，也不把无对象页面包装成下钻。

| 操作 | 触发位置 | UE 规则 | 反馈 |
| --- | --- | --- | --- |
| 查看企业详情 | 企业名称 | 复用企业结果列表通用规则，进入企业详情页或既有详情承载，不改变当前总览全局口径 | 返回后保留当前分析口径和下钻路径 |
| 查看画像 | 单行操作 | 复用企业查询结果规则，打开企业画像抽屉或画像入口，携带企业 ID、数据批次、来源分析区和下钻路径 | 抽屉关闭后回到当前下钻结果页 |
| 加入对比篮 | 单行或批量工具栏 | 复用对比篮状态规则，以企业 ID / 统一社会信用代码去重；已加入状态在查询、总览、画像、引育候选等入口同步 | 单个提示 `已加入对比篮`；批量提示 `已加入 X 家，Y 家已在对比篮` |
| 进入企业评估 | 批量工具栏 | 必须先选择企业；进入时只携带企业对象、来源入口、条件摘要和数据批次，不直接生成评估结果 | 未选择提示 `请先选择企业`；对象不满足评估模式时在评估页配置阶段校验 |
| 进入风险洞察 | 批量工具栏 | 必须先选择企业；携带来源分析区和下钻条件；进入后先做对象确认，不展示无对象风险总览 | 未选择提示 `请先选择企业` |
| 加入招引候选 | 批量工具栏 | 只写入招引候选名单，不直接生成招引推荐名单 | 提示 `已加入 X 家，Y 家已在名单中` |
| 加入培育候选 | 批量工具栏 | 只写入培育候选名单，不直接生成建议培育名单 | 提示 `已加入 X 家，Y 家已在名单中` |

批量工具栏只在企业总览下钻结果页态中展示，基于企业查询表格批量工具栏复用：保留 `已选 N 家`、`加入对比`、`加入招引候选`、`加入培育候选`、`清空选择`；移除 `导出选中`；增加 `进入企业评估` 和 `进入风险洞察`。建议顺序为：`已选 N 家 / 加入对比 / 进入企业评估 / 进入风险洞察 / 加入招引候选 / 加入培育候选 / 清空选择`。未选择企业时批量按钮禁用或不展示；权限不足时按通用权限反馈显示禁用、锁态或不可见；重复加入按通用反馈说明已存在数量。

### 跨模块带入上下文

企业总览下钻结果页态的跨模块动作必须携带对象和来源上下文。目标模块只能先进入对象确认、任务配置或候选池，不得因为来自企业总览就直接生成评估结果、风险结论、招引推荐名单、建议培育名单或一企一策建议。

| 字段 | 携带规则 |
| --- | --- |
| 企业对象 | 企业 ID / 统一社会信用代码 / 企业名称；批量动作携带企业对象集合 |
| 来源入口 | 固定为 `企业总览` |
| 来源分析区 | `企业类型与区域分布`、`重点企业产业链全景`、`重点企业领域覆盖`、`当前区域企业产业链位置`、`城市横向对标` |
| 来源触发点 | 地图区域、企业类型、类型 x 区域矩阵单元、领域节点、领域-企业关系边、产业链环节、链中角色、城市指标单元等 |
| 全局口径摘要 | 产业 / 产业链、地域范围、企业类型、产业领域 / 技术标签、数据批次 / 时间口径 |
| 下钻条件摘要 | 当前结果页的业务路径，例如 `南山区 + 专精特新`、`半导体 / 封测环节 / 配套企业` |
| 数据批次 / 更新时间 | 用于目标模块判断结果可信度和可复现性 |
| 选中数量 | 批量动作携带当前选中企业数量 |
| 操作人 / 操作时间 | 用于审计、候选池来源记录和对比篮最近操作 |

| 目标动作 | 补充规则 |
| --- | --- |
| 加入对比篮 | 复用对比篮去重规则；同一企业允许记录多个来源，例如同时保留 `区域分布 / 南山区` 和 `产业链位置 / 封测环节`；再次加入时可追加来源并更新最近操作时间 |
| 进入企业评估 | 只携带企业对象集合、来源上下文和数据批次；不预设评估模式、指标模板、权重或结果页 |
| 进入风险洞察 | 只携带企业对象集合、来源上下文和数据批次；目标模块先进入对象确认，不展示无对象风险总览，不直接生成风险结论 |
| 加入招引候选 | 写入招引候选池，候选类型为 `招引`；不生成招引推荐名单 |
| 加入培育候选 | 写入培育候选池，候选类型为 `培育`；不生成建议培育名单 |

### 区块状态与反馈

企业总览需要在每个分析区和下钻结果页态补齐稳定状态。状态展示不改变页面结构，不用大段说明文替代数据或操作。

| 状态 | 触发场景 | UE 规则 |
| --- | --- | --- |
| 初始态 | 页面首次进入或切换全局口径后数据已就绪 | 展示当前口径、摘要 KPI 和五个分析区；下钻结果页态不常驻 |
| 加载态 | 切换全局口径、刷新图表、进入下钻结果页态或翻页 | 当前区块或结果页显示骨架 / 局部加载；其它已加载区块保持可读，不整页白屏 |
| 空态 | 当前口径下无企业或无匹配下钻结果 | 在对应区块或结果页展示空态，提供调整全局口径或清除局部下钻动作；不跳转企业查询 |
| 数据不足 | 指标、领域映射、链位或城市对标数据不足 | 展示 `数据不足` 标记、影响范围和当前区块业务原因；不使用 0 值伪装有效结论 |
| 权限受限 | 用户无权查看部分企业字段或跨模块动作 | 保留可见结构，隐藏或禁用受限动作，并给出权限提示 |
| 异常态 | 图表服务、地图服务、关系图或列表数据加载失败 | 在失败区块展示错误反馈和重试入口；不影响其它区块 |
| 下钻后态 | 用户已选中图表元素并进入企业总览下钻结果页态 | 保留来源分析区、来源图表或指标、全局口径、下钻路径和结果列表；允许通过面包屑返回来源分析区 |

五个分析区使用同一套状态结构，但空态和数据不足说明必须按业务语义定制，不使用泛化的 `暂无数据` 作为唯一说明。

| 分析区 | 空态说明口径 | 数据不足说明口径 |
| --- | --- | --- |
| 企业类型与区域分布 | 当前产业、地域或企业类型口径下没有匹配企业 | 地图区域数据、企业类型标签或区域归属数据不足 |
| 重点企业产业链全景 | 当前产业、地域或企业类型口径下没有可展示的重点企业 | 重点企业标识、产业链归属、链位环节或基础信息不足 |
| 重点企业领域覆盖 | 当前企业集合没有可展示的领域覆盖结果 | 领域映射、技术标签、产品 / 业务标签或覆盖深度数据不足 |
| 深圳企业产业链位置 | 当前产业链或链位条件下没有深圳相关企业 | 产业链环节、链中角色或深圳相关标注数据不足 |
| 城市横向对标 | 当前城市组或指标下没有可比企业集合 | 城市指标、样本数量或可比口径数据不足 |

加载态和异常态只影响当前区块或当前下钻结果页，不触发整页白屏。空态优先提供 `调整口径` 或 `清除下钻`，不提供跳转 `企业查询` 的专门入口。

### 非目标

企业总览 UE 不引入以下内容：

- 不新增企业总览排行榜页。
- 不新增企业总览正式分析报告。
- 不新增总览图表或下钻列表导出。
- 不新增统一重点对象货架。
- 不新增额外推荐模型。
- 不在总览页生成企业评估式评分 / 排名。
- 不在总览页生成风险洞察式风险诊断。
- 不在总览页生成招引推荐名单、建议培育名单或一企一策建议。
- 不新增左侧菜单、固定企业检索 Tab 或系统级全局搜索。

## 企业查询 UE 规格

### 页面定位

企业查询用于找企业、筛企业、构造企业集合、查看初步信号，并把企业对象带入画像、对比篮、企业评估、风险洞察或引育推荐。查询页不生成深层分析结论，不替代评估、风险、引育等后续模块。

### 页面组织

企业查询页不在内容区重复展示 `企业查询` 大标题。左侧二级菜单已经承担页面定位，内容区顶部只放查询入口、对象确认、筛选配置、任务状态和上下文信息。

| 区域 | UE 规则 | frontend-agent 执行口径 |
| --- | --- | --- |
| 顶部入口 | 普通查询页显示为 `智能搜索 | 查企业 | 高级筛选`，顺序固定不变；`智能多字段检索`、`关键词检索` 只作为文档解释口径，不进入页面标题 | 默认落在 `智能搜索`；不得降级为单一搜索框；`智能搜索` 不出现自然语言问答、大模型解析或自动意图识别承诺 |
| 智能搜索 | 作为默认入口，使用一个主输入框承接企业名、产业、资质、区域、专利等多字段关键词 | 交互本质是原自然语言检索需求的弱化交付，即传统关键词匹配 + 多字段条件匹配；`智能解析` 只能作为当前触发按钮文案，不表达大模型语义解析能力 |
| 查企业 | 作为关键词检索入口，以单输入框为主，支持企业名称、统一社会信用代码、产业领域、技术标签、产品 / 业务关键词 | 与 `智能搜索` 共用普通查询初始内容区和查询后结果区 |
| 高级筛选 | 点击后进入 `高级筛选 · 字段库 / 构造企业集合` 下级页面态 | 不改为右侧抽屉；字段库是完整页面能力，不是普通查询的辅助面板；下级页返回依赖面包屑导航 |
| 热门场景 | 作为初始态快捷入口 | 点击后跳转字段库，并带入预置筛选条件 |
| 最近查询 / 查询方案 | 作为个人历史资产恢复入口 | 按记录来源恢复普通查询页或高级筛选字段库；VISIT 不记录最近查询 |

`智能搜索` 和 `查企业` 共用普通查询首屏，包括热门场景、示例查询、最近查询 / 查询方案。`高级筛选` 点击后进入字段库构造器下级页面，不参与普通查询首屏主结构，也不在字段库页继续保留普通查询页的顶部三入口。

`智能搜索` 和 `查企业` 共享普通查询页内的查询后结果区。高级筛选应用后进入 `高级筛选结果态`，复用企业查询结果列表模型、常用筛选条、排序、视图切换、对象操作、对比篮状态和导出规则，但不与普通查询页共用顶部查询模块。

### 高级筛选页面态导航

高级筛选是企业查询下的下级页面态，不是普通查询页内的展开面板，也不是右侧抽屉。

普通查询页不常驻面包屑；只有进入高级筛选字段库、高级筛选结果态等更深层页面后才展示面包屑导航。

| 进入来源 | 进入后状态 | 返回方式 |
| --- | --- | --- |
| 普通查询页点击 `高级筛选` | 进入空字段库，等待用户添加条件 | 顶部面包屑返回 `企业查询` 普通查询页 |
| 点击热门场景 | 进入字段库，并带入该场景的预置条件 | 面包屑返回普通查询页；条件可在字段库内清空或修改 |
| 点击最近查询中的字段库记录 | 进入字段库，并恢复历史条件集合 | 面包屑返回普通查询页；条件保留为可编辑状态 |
| 点击查询方案 | 进入字段库，并恢复保存的方案条件 | 面包屑返回普通查询页；方案条件先展示，用户确认后再应用 |
| 从无结果状态进入高级筛选 | 进入字段库，可带入当前普通查询条件摘要作为参考 | 面包屑返回来源结果态或普通查询页，具体由来源状态决定 |

字段库页顶部使用面包屑表达路径，例如 `企业分析 / 企业查询 / 高级筛选`。面包屑中的上级节点可点击返回；`企业查询` 返回普通查询页，当前页 `高级筛选` 不可点击。面包屑下方可保留固定热门场景行，作为字段库预置条件快捷入口。页面主体展示 `高级筛选 · 字段库`、条件构造区和操作按钮；不继续展示 `智能搜索 | 查企业 | 高级筛选` 三入口。

点击 `应用筛选` 后进入高级筛选结果态，来源标识为 `字段库`。结果态提供 `编辑高级筛选` 入口，点击后回到字段库并保留当前条件。

### 高级筛选字段库布局

高级筛选字段库采用 `字段分组 + 字段列表 + 已选条件 + 操作区` 的构造器布局。页面可适配当前实现为上下结构，不强制左中右三栏，但必须保留四个语义区域。

| 区域 | 职责 |
| --- | --- |
| 字段分组 | 帮助用户按业务域找字段 |
| 字段列表 | 展示可添加字段 |
| 已选条件 | 展示当前企业集合的构造逻辑 |
| 操作区 | 应用筛选、重置、保存查询方案、使用查询方案 |

#### 标题工具区

字段库标题区右侧放轻量工具：

```text
[已选 N 个条件] [搜索字段名 / 别名] [展开字段库 / 收起字段库]
```

| 控件 | 规则 |
| --- | --- |
| 已选 N 个条件 | 始终展示；点击可定位到已选条件区 |
| 搜索字段名 / 别名 | 轻量辅助能力，只在字段库展开时有效；搜索字段名、字段说明和别名 |
| 展开字段库 / 收起字段库 | 只控制字段分组和字段列表显隐，不清空条件 |

字段库收起后保留条件摘要和操作区，给结果区更多空间。搜索字段不作为核心结构，不做复杂联想，不做企业搜索。

#### 字段分组

字段分组沿用产品规格中的 11 类，不重新发明分类：

1. 基础信息
2. 组织信息
3. 企业规模
4. 经营 / 资质
5. 评估分值
6. 技术能力
7. 商业能力
8. 供应链关系
9. 风险舆情
10. 引育推荐
11. 数据追溯

字段分组规则：

- 默认展示 `基础信息` 或推荐字段。
- 有已选条件的分组显示数量或轻提示。
- 权限受限字段按权限规则置灰、隐藏或提示。
- 不在 UE 层重排字段业务归属。

#### 字段列表

字段列表负责展示可添加字段。字段项至少包含字段名、字段类型、推荐标记、数据状态、简短说明或样例值、添加动作。

| 字段信息 | 说明 |
| --- | --- |
| 字段名 | 使用产品规格中的字段名称 |
| 字段类型 | 文本、枚举、多选枚举、标签、数值、金额、百分比、日期、年份、布尔、等级等 |
| 推荐标记 | 推荐字段优先展示；法定代表人不标记为推荐字段 |
| 数据状态 | 有数据、部分缺失、权限受限 |
| 添加动作 | 未添加时显示 `添加`，已添加后显示 `已添加` |

字段添加规则：

- 同一字段首批只允许添加一次。
- 字段已添加后显示 `已添加`。
- 点击 `已添加` 定位到已选条件区对应条件。
- 多值、区间、范围在同一个条件内编辑完成。
- AND / OR 只作用于不同字段条件之间，不改变字段添加规则。

#### 已选条件区

已选条件区展示当前企业集合构造逻辑。

```text
已选条件（3）
关系：全部满足 AND / 任一满足 OR

[资质荣誉 = 专精特新]  编辑  删除
[注册区县 = 南山区]    编辑  删除
[成立时间 介于 2011 至 2012] 编辑 删除
```

已选条件规则：

- 每个条件显示字段名、操作符、取值。
- 支持编辑条件值。
- 支持删除单个条件。
- 支持清空全部条件。
- 条件为空时显示 `从字段库添加条件，构造企业集合`。
- 条件为空时，`应用筛选`、`保存为查询方案` 禁用。
- 日期 / 数值字段用 `介于` 表达区间，不通过重复添加同一字段表达区间。
- 枚举 / 标签字段用多选表达多个值。

#### 字段类型控件与校验

字段库条件编辑必须按字段类型渲染专用控件和校验规则，禁止把所有字段统一做成自由文本输入。

| 字段类型 | 编辑控件 | 校验规则 |
| --- | --- | --- |
| 文本 | 输入框 | 限制长度；去除首尾空格；支持模糊 / 精确匹配选择 |
| 枚举 | 单选 / 下拉选择 | 只能选择字典项，不允许自由输入 |
| 多选枚举 | 多选下拉 / 标签选择 | 只能选择字典项；可限制最大选择数量 |
| 标签 | 标签选择 / 可搜索下拉 | 从标签字典选择；不允许新增临时标签 |
| 数值 | 数字输入框 | 只能输入数字；支持单位；限制小数位；支持最小 / 最大值 |
| 金额 | 数字输入框 + 单位 | 只能输入数字；按字段配置限制小数位；支持万元 / 亿元等单位 |
| 百分比 | 数字输入框 + `%` | 只能输入数字；限制 0-100；按字段配置限制小数位 |
| 日期 | 日期选择器 | 只能选择合法日期；支持起止日期；起始不得晚于结束 |
| 年份 | 年份选择器 | 只能选择年份，不用普通文本 |
| 区间 | 起止输入 / 起止选择器 | 起始值不得大于结束值 |
| 布尔 | 是 / 否选择 | 不允许空文本输入 |
| 可信度 / 风险等级 | 等级选择 | 只能选择预设等级 |

操作符也必须跟字段类型绑定：

| 字段类型 | 支持操作符 |
| --- | --- |
| 文本 | 包含、等于、不包含 |
| 枚举 / 标签 | 属于、包含任一、包含全部、不属于 |
| 数值 / 金额 / 百分比 | 等于、大于等于、小于等于、介于 |
| 日期 / 年份 | 等于、早于、晚于、介于 |
| 布尔 | 是、否 |
| 等级 | 等于、高于等于、低于等于 |

非法输入、区间起止冲突、超出字段允许范围、权限受限和数据缺失都需要就地提示。存在非法条件时不允许应用筛选。

#### AND / OR 规则

首批只支持全局关系切换：

- `全部满足 AND`
- `任一满足 OR`

不做条件组嵌套、组内 / 组间关系、括号逻辑、字段权重和复杂表达式编辑器。`添加组合条件`、`添加同类型属性` 可作为后续增强，不进入本期首批。

#### 热门场景带入字段库

热门场景可在普通查询初始空态展示，也可在高级筛选字段库页面的面包屑下方保留。它在字段库页中作为预置条件快捷入口，不是动态推荐或热门榜单。

热门场景点击后进入或留在字段库，并自动带入预置条件。

```text
来源：热门场景 · 专精特新企业
已选条件（1）
[资质荣誉 = 专精特新]
```

预置条件可编辑、可删除、可继续添加条件、可直接应用筛选，也可保存为查询方案。预置条件不锁死。

#### 操作区

操作区包含：

```text
[应用筛选] [重置] [保存为查询方案] [使用查询方案]
```

| 操作 | 规则 |
| --- | --- |
| 应用筛选 | 主操作；条件合法时可用；点击后进入高级筛选结果态 |
| 重置 | 清空当前字段库条件，不退出页面 |
| 保存为查询方案 | 用户命名后保存条件集合、AND / OR 关系、字段范围、数据版本和恢复方式，不保存静态结果清单 |
| 使用查询方案 | 打开用户已保存的查询方案列表；选择后回填字段库条件，不自动执行，用户确认后再应用 |

页面文案如果沿用 `使用模板 / 存为模板`，业务语义按 `查询方案` 理解。VISIT 不支持保存或使用个人查询方案。

### 普通查询初始态布局

普通查询初始态以搜索框和热门场景为主，不展示大段功能说明，不展示排行式推荐榜单、统计图表或企业总览页的分析口径筛选；仅允许新增一个推荐企业列表，作为未查询时的对象入口。

| 区块 | UE 规则 | 交互规则 |
| --- | --- | --- |
| 搜索框 | 位于顶部入口下方，默认随 `智能搜索` 展示；placeholder 只说明能力范围，不写具体样例 | 输入企业名、产业、资质、区域、专利等多字段关键词后触发普通查询 |
| 示例查询 | 位于搜索框与热门场景之间，作为轻量输入样例；内容随 `智能搜索 / 查企业` 切换 | 点击后填入搜索框，不默认立即查询；用户可编辑后再触发 `智能解析` 或 `查询` |
| 热门场景 | 首批固定 6 个预置标签：`专精特新企业`、`国高企`、`上市企业`、`南山区企业`、`集成电路企业`、`近三年新增企业` | 点击后进入 `高级筛选 · 字段库 / 构造企业集合`，并自动带入对应预置筛选条件 |
| 最近查询 / 查询方案 | 展示系统最近查询和用户主动保存的查询方案 | 按来源恢复普通查询页或高级筛选字段库 |
| 推荐企业列表 | 展示 3-5 条推荐企业；单条包含企业名称、在营状态、资质标签、产业 / 领域标签、区域和推荐理由；Demo 数据需标注示例 / Mock | 可查看画像、加入对比篮或以此查询；只有“以此查询”进入正式结果态 |

示例查询和 placeholder 的职责必须区分：placeholder 用于说明输入能力范围，示例查询用于给出可点击的具体输入样例，避免出现两组重复示例。

| 当前入口 | placeholder 口径 | 示例查询口径 |
| --- | --- | --- |
| 智能搜索 | 输入企业名、产业、资质、区域或专利关键词，自动关联多字段匹配企业 | 展示 1-2 条多字段组合样例，例如 `南山区 专精特新 集成电路`、`近三年新增 国高企` |
| 查企业 | 输入企业名称、统一社会信用代码或业务关键词 | 展示 1-2 条直接定位样例，例如 `华为技术有限公司`、`半导体设备` |

示例查询不是热门场景，不进入字段库；点击只填入当前入口的搜索框。示例查询属于顶部查询模块的还原状态内容，执行查询后不影响结果区展示；当用户清空查询或回到普通查询初始空态时按当前入口恢复展示。

热门场景不是动态推荐、热门榜单或算法生成结果。标签数量和顺序首批固定；如果某个预置条件当前无数据，不隐藏标签，在字段库或结果区展示无结果 / 条件不可用反馈。

#### 查询入口切换状态

`智能搜索`、`查企业`、`高级筛选` 是独立查询入口。切换入口时必须重置当前已提交查询态，避免上一入口的结果列表继续挂在新入口下造成来源误判。

| 切换动作 | UE 状态变化 |
| --- | --- |
| 智能搜索结果态 -> 查企业 | 清空智能搜索输入、识别条件、普通查询结果区、结果内筛选和分页；进入查企业初始态 |
| 查企业结果态 -> 智能搜索 | 清空查企业关键词、普通查询结果区、结果内筛选和分页；进入智能搜索初始态 |
| 普通查询结果态 -> 高级筛选 | 进入 `高级筛选 · 字段库 / 构造企业集合` 初始态；不展示普通查询旧结果 |
| 高级筛选结果态 -> 智能搜索 / 查企业 | 清空字段库结果态，进入目标普通查询初始态 |
| 热门场景 -> 高级筛选 | 进入字段库并带入预置条件，但仍处于待应用状态；用户点击 `应用筛选` 后才生成结果 |
| 最近查询 | 用户明确恢复历史查询，可恢复对应入口条件并直接执行 |
| 查询方案 | 用户明确恢复保存方案，可按来源回填条件；字段库方案先展示条件，用户确认后再应用 |

切换入口时不清除：最近查询、查询方案、热门场景、对比篮、已加入候选状态和个人资产。切换入口时应清除：当前入口输入、已识别条件、已提交结果、结果内筛选、分页和表格选择态。

#### 搜索框一键清除

普通查询页搜索框在有输入值时显示一键清除按钮。该按钮只作用于当前入口的普通查询状态。

点击一键清除后，清除：

- 当前入口输入内容。
- 智能搜索已识别条件。
- 当前普通查询条件摘要。
- 当前入口下的临时输入状态。
- 当前普通查询结果区。

点击一键清除后，不清除：

- 最近使用记录。
- 查询方案。
- 热门场景。
- 高级筛选字段库条件。
- 对比篮。
- 已加入候选状态。

| 当前状态 | 点击清除后 |
| --- | --- |
| 初始空态输入中 | 清空输入框，回到普通查询初始空态 |
| 查询后有结果 | 清空输入框、识别条件和当前普通查询结果区，回到普通查询初始空态 |
| 查询后无结果 | 清空输入框和筛选条件，回到普通查询初始空态 |
| 高级筛选结果态 | 不显示普通搜索框清除按钮；通过 `编辑高级筛选 / 重置` 管理条件 |

清除关键词不产生新的最近查询，不需要二次确认。

### 最近查询 / 查询方案

`最近查询 / 查询方案` 在普通查询初始空态中统一表现为 `最近使用` 区，位于热门场景之后。该区只承担历史恢复和方案复用，不作为输入教学，也不替代个人资产中心。

| 类型 | 产生方式 | 生命周期 | 保存对象 | 主要用途 |
| --- | --- | --- | --- | --- |
| 最近查询 | 用户执行查询后系统自动生成 | 近 30 天、最多 20 条；重复条件合并更新时间 | 查询来源、条件摘要、原始关键词、筛选条件、查询时间、命中数量、数据版本、恢复方式 | 快速恢复最近执行过的查询 |
| 查询方案 | 用户主动点击 `保存为查询方案` 生成 | 长期保留，除非用户删除、权限失效或完整系统策略调整 | 用户命名、查询来源、条件摘要、字段范围、条件关系、数据版本、恢复方式、命中数量摘要 | 复用稳定、有业务意义的查询条件 |

查询方案保存的是查询条件和恢复方式，不保存静态企业结果清单。恢复查询方案时按当前数据版本重新查询，结果数量可能变化。

#### 展示规则

| 场景 | UE 规则 |
| --- | --- |
| 首屏展示 | 初始空态最多展示 3-5 条 `最近使用` chip，超过数量显示 `查看全部` |
| 展示内容 | chip 至少包含条件摘要和来源类型；查询方案需要显示方案名称 |
| 来源标识 | 来源类型包括 `智能搜索`、`查企业`、`字段库`、`查询方案` |
| 视觉层级 | 使用轻量 chip 或文本标签，不做大面积卡片，不压过搜索框、示例查询和热门场景 |
| 查看全部 | 进入个人资产中心的 `查询历史 / 查询方案`，或由后续实现选择轻量弹层承接 |

`最近使用` 需要根据当前入口区分展示：

- `智能搜索` 下优先展示智能搜索记录和智能搜索来源的查询方案。
- `查企业` 下只展示查企业关键词记录和查企业来源的查询方案，不混入智能搜索和高级筛选记录。
- `高级筛选` 字段库页展示字段库记录、热门场景查询记录和字段库来源的查询方案。
- `查看全部` 可进入完整个人资产列表，不受当前入口过滤限制。

示例展示：

```text
最近使用：
[南山区 专精特新 · 智能搜索]  [集成电路企业 · 字段库]  [已保存：招商候选企业池]  查看全部
```

#### 保存入口

| 来源 | 保存入口 | 保存内容 |
| --- | --- | --- |
| 普通查询 | 查询后态提供 `保存为查询方案` | 当前入口、关键词 / 多字段输入、常用筛选、排序可选、数据版本、命中数量摘要 |
| 高级筛选字段库 | 字段库内提供 `保存为查询方案` | 字段条件集合、AND / OR 关系、字段范围、条件摘要、数据版本、命中数量摘要 |

保存查询方案时需要用户命名。VISIT 不保存查询方案。

#### 恢复规则

| 来源 | 点击后行为 |
| --- | --- |
| 智能搜索最近查询 | 切到 `智能搜索`，恢复输入内容和普通查询条件 |
| 查企业最近查询 | 切到 `查企业`，恢复关键词、企业名、统一社会信用代码或业务关键词 |
| 高级筛选最近查询 | 进入 `高级筛选 · 字段库 / 构造企业集合`，恢复条件集合 |
| 热门场景查询 | 进入字段库，恢复该热门场景的预置条件 |
| 查询方案 | 按保存来源恢复普通查询页或字段库，并显示方案名称 |

最近查询可恢复并直接执行，因为它代表用户曾经执行过的查询动作。查询方案恢复后先展示条件，用户确认后再应用；字段库方案尤其需要先展示条件集合，避免用户误以为保存的是静态结果。

#### 空状态与权限状态

| 场景 | 展示规则 |
| --- | --- |
| 普通用户无记录 | 展示轻提示：`暂无最近使用，可先输入关键词或选择热门场景` |
| VISIT 访客 | 不记录最近查询；可隐藏该区，或展示 `登录后可保留最近查询` |
| 只有最近查询 | 只展示最近查询，不强行占位查询方案 |
| 只有查询方案 | 展示查询方案，标题仍可用 `最近使用` |
| 权限变化 | chip 置灰或标记状态，点击提示 `该查询包含当前无权限字段，已脱敏或不可恢复` |
| 数据版本变化 | 恢复后提示 `结果将按当前数据版本重新计算`，不拦截恢复 |

### 查询方案保存与使用

`保存为查询方案` 保存查询条件和恢复方式，不保存静态企业结果清单。普通查询结果区和高级筛选字段库均可保存查询方案；普通查询初始空态不提供保存入口。

#### 保存入口与内容

| 来源 | 保存入口 | 保存内容 |
| --- | --- | --- |
| 普通查询结果区 | 查询后态工具条提供 `保存为查询方案` | 当前入口、输入内容、常用筛选条件、排序可选、数据版本、命中数量摘要、恢复方式 |
| 高级筛选字段库 | 字段库操作区提供 `保存为查询方案` | 字段条件集合、AND / OR 关系、字段范围、字段库来源、数据版本、命中数量摘要、恢复方式 |

保存时必须让用户命名。名称必填并限制长度；同名时首批提示用户改名，不做覆盖逻辑。VISIT 不支持保存查询方案。

保存弹窗建议包含：

```text
保存为查询方案
方案名称：[                    ]
条件摘要：南山区 · 专精特新 · 集成电路
数据版本：2026Q2
[取消] [保存]
```

#### 使用与恢复

| 方案来源 | 恢复行为 |
| --- | --- |
| 智能搜索方案 | 回到 `智能搜索`，填入输入内容和筛选条件 |
| 查企业方案 | 回到 `查企业`，填入关键词、企业名、统一社会信用代码或业务关键词 |
| 字段库方案 | 进入 `高级筛选 · 字段库 / 构造企业集合`，回填字段条件集合 |
| 热门场景保存方案 | 进入字段库，回填预置条件和用户追加条件 |

查询方案恢复后先展示条件，不自动执行。用户确认后再查询或应用筛选。最近查询可以恢复并直接执行，因为它代表用户曾经执行过的查询动作。

#### 变化与异常处理

| 情况 | UE 规则 |
| --- | --- |
| 字段权限变更 | 无权限字段置灰、脱敏或提示不可恢复 |
| 字段已下线 | 标记不可用，提示删除后再应用 |
| 字典值失效 | 标记失效值，提示修改 |
| 数据版本变化 | 提示按当前数据版本重新计算 |
| 敏感字段 | 按当前权限脱敏、禁用或触发审批提示 |

### 查询状态与反馈

企业查询需要保持稳定的工作台状态反馈，不以页面跳转或空白重绘替代反馈。

| 状态 | 触发条件 | 页面反馈 | 后续动作 |
| --- | --- | --- | --- |
| 初始态 | 未输入查询条件或清空条件 | 展示热门场景、示例查询、最近查询 / 查询方案和一个推荐企业列表 | 支持进入普通查询或高级筛选；推荐企业列表仅作为查询起点，不计入命中结果 |
| 输入中 | 用户编辑关键词或多字段条件 | 保持结果区不刷新；只更新条件草稿 | 用户点击查询后再发起匹配 |
| 查询中 | 普通查询或高级筛选应用后 | 普通查询页或高级筛选结果态展示稳定 loading；保留当前条件摘要 | 查询完成后进入对应结果态 |
| 查询后 | 有命中结果 | 展示命中数量、常用筛选、排序、视图切换、结果列表和可用操作 | 支持加入对比、查看画像、加入候选、导出 |
| 无结果 | 查询完成但命中为 0 | 展示无结果状态，并保留当前条件；不展示推荐企业或相近推荐 | 支持修改条件、清空条件、进入高级筛选 |
| 条件错误 | 必填字段缺失、区间非法或字段值无效 | 在对应字段就地提示，不清空其它条件 | 用户修正后重新查询 |
| 权限受限 | 字段、导出或候选操作受角色限制 | 展示禁用态或锁态说明；正式权限不可见的能力不显示 | 演示 / 内部评审模式可显示锁态和权限说明 |
| 数据异常 | 查询服务失败或数据批次不可用 | 展示错误提示、数据批次信息和重试入口 | 支持重试或切换查询条件 |

`智能搜索`、`查企业` 和高级筛选结果态都必须保留当前条件摘要。条件摘要至少包含查询来源、关键词 / 字段条件、常用筛选、数据版本和命中数量；涉及敏感字段时按权限脱敏展示。

#### 智能搜索识别条件删除

智能搜索识别条件支持单项删除。识别条件删除只移除该结构化条件，不修改原始输入框内容。

| 场景 | UE 规则 |
| --- | --- |
| 删除单个识别条件 | 删除该结构化条件，立即按剩余识别条件和原始关键词重新计算结果 |
| 删除后反馈 | 更新条件摘要、命中数量和结果列表 |
| 本轮查询内 | 被删除条件不自动恢复 |
| 用户重新编辑输入 | 清空本轮删除记录，按新的输入重新识别条件 |
| 用户重新点击搜索 | 按当前输入重新识别条件并执行查询 |
| 删除全部识别条件但输入框仍有内容 | 按原始关键词普通匹配，不回到初始空态 |
| 输入框也被清空 | 回到普通查询初始空态 |
| 最近查询记录 | 保存用户最终确认后的条件集合，而不是系统最初识别条件 |

### 异常状态与空状态

企业查询页状态统一分为初始空态、结果空态、结果内筛选空态、条件错误、权限 / 数据不可用、任务失败六类。

| 状态类型 | 典型场景 | UE 规则 |
| --- | --- | --- |
| 初始空态 | 未输入查询，未产生结果 | 展示搜索框、示例查询、热门场景、最近使用和一个推荐企业列表；不展示排行式推荐榜单、统计图或大段说明 |
| 结果空态 | 查询执行成功但命中 0 | 保留查询条件，提供修改关键词、清空筛选、编辑高级筛选等动作；不展示推荐企业或相近推荐 |
| 结果内筛选空态 | 主查询已命中企业，但结果内筛选 / 二次筛选后为 0 | 保留查询方案摘要、当前条件、结果列表标题和结果内筛选工具条；只在列表内容区展示局部 Empty，并提供清除结果内筛选 |
| 条件错误 | 字段值非法、区间冲突、必填缺失 | 就地提示，保留用户输入，阻止应用筛选和保存查询方案 |
| 权限 / 数据不可用 | 字段无权限、字段下线、字典值失效、数据批次不可用 | 字段置灰、脱敏、要求删除后再应用或提示按当前数据版本重新计算 |
| 任务失败 | 导出失败、保存方案失败、加入候选失败、加入对比失败、查询失败 | 保留上下文，提示失败原因，提供重试或修正入口 |

#### 无结果空态

无结果空态是查询已执行但命中 0，不等同于普通查询初始空态。

无结果空态不承载推荐企业列表，也不展示“相近推荐 / 可尝试企业”。推荐企业列表只属于普通查询初始空态，避免用户误以为推荐对象是本次查询命中或放宽条件后的结果。

| 来源 | 建议动作 |
| --- | --- |
| 智能搜索 / 查企业 | 修改关键词、清空查询后筛选、进入高级筛选 |
| 高级筛选结果态 | 编辑高级筛选、清空部分条件 |
| 热门场景 | 编辑字段库条件，不隐藏热门场景 |

建议文案：

```text
未找到匹配企业
可尝试修改关键词、清除部分筛选条件，或进入高级筛选字段库重新构造企业集合。
[清空查询后筛选] [编辑高级筛选]
```

#### 结果内筛选空态

结果内筛选空态是主查询已有结果，但用户在结果列表内追加常驻筛选后当前列表为 0。它不等同于普通查询初始空态，也不等同于高级筛选字段库空态。

规则：

- 保留查询方案摘要和当前主查询条件，避免用户误以为主查询被清空。
- 保留结果列表标题、结果内筛选控件、排序、视图切换和对比篮入口。
- 只在卡片 / 表格内容区域展示局部 Empty。
- 主操作为 `清除结果内筛选`，恢复主查询结果集；可选辅助操作为调整主查询条件。

建议文案：

```text
结果内筛选无匹配企业，主查询仍命中 N 家企业
[清除结果内筛选] [调整主查询条件]
```

#### 条件错误

条件错误需要在字段附近就地提示，不使用大弹窗替代字段校验。

示例：

- `起始年份不能晚于结束年份`
- `注册资本只能输入数字`
- `比例需在 0-100 之间`
- `请选择至少一个资质标签`

存在条件错误时，`应用筛选` 和 `保存为查询方案` 禁用。

#### 权限 / 数据不可用

| 场景 | UE 规则 |
| --- | --- |
| 查询方案含当前无权限字段 | 条件置灰或脱敏，并提示 `该查询包含当前无权限字段，已脱敏或不可恢复` |
| 字段已下线 | 标记不可用，提示删除该条件后再应用 |
| 字典值失效 | 标记失效值，提示修改 |
| 数据版本变化 | 提示按当前数据版本重新计算，不阻断恢复 |
| 数据批次不可用 | 提示批次不可用，提供重试或切换条件入口 |

#### 任务失败

| 操作 | 失败反馈 |
| --- | --- |
| 查询失败 | 保留条件摘要，提示失败原因，提供重试 |
| 导出失败 | 显示任务失败原因，提供重试 |
| 保存方案失败 | 保留方案表单，提示保存失败 |
| 加入对比失败 | 保持原按钮状态，提示失败原因 |
| 加入候选失败 | 保持原候选状态，提示失败原因 |

### 查询后结果区 / 高级筛选结果态

`智能搜索` 和 `查企业` 使用普通查询页内的查询后结果区。`高级筛选` 应用后进入高级筛选结果态。两者不共用普通查询页顶部模块，但复用同一套企业结果列表模型和对象操作规则，用于展示命中企业、快速收窄结果、切换视图、执行对象流转和导出。

| 来源 | 结果承接方式 |
| --- | --- |
| 智能搜索 | 普通查询页内展示查询后结果区 |
| 查企业 | 普通查询页内展示查询后结果区 |
| 高级筛选字段库 | 应用筛选后进入高级筛选结果态，保留面包屑和字段库条件摘要 |

#### 查询后常用筛选条

查询后常用筛选条位于结果区工具条内，用于在当前结果集合上做二次收窄。它不是高级筛选字段库，不负责构造新的企业集合。

| 项 | 查询后常用筛选条 | 高级筛选字段库 |
| --- | --- | --- |
| 所在位置 | 查询后结果区工具条 | `高级筛选 · 字段库 / 构造企业集合` 页面态 |
| 作用对象 | 当前结果集合 | 构造新的企业集合 |
| 字段范围 | 少量高频筛选字段 | 字段库全量字段组 |
| 条件关系 | 默认简单叠加筛选 | 支持 AND / OR 条件关系 |
| 复杂度 | 快速、轻量 | 专业、完整 |

首屏工具条最多展示 4 个高频筛选项，优先保持单行不换行。当前默认四项为：

| 首屏筛选项 | 产品字段映射 | 说明 |
| --- | --- | --- |
| 经营状态 | 商业状态 / 基础有效性 | 用于快速排除注销、异常或不可用企业 |
| 企业规模 | 企业类型 / 规模维度 | 用于按大中小微、规模标签等收窄 |
| 注册区县 | 区域 | 用于深圳区县或其它区域快速收窄 |
| 资质荣誉 | 企业资质 | 用于国高企、专精特新、上市等资质筛选 |

产品口径中的常用筛选字段首批仍为七类：产业、区域、企业类型、技术标签、商业状态、企业资质、引育状态。UE 首屏只展示其中最高频的 4 个轻筛，其余字段后续可进入 `更多筛选` 或高级筛选字段库，不在当前结果区首屏强行铺开。

筛选条规则：

- 只作用于当前结果集合，不改变原始查询来源。
- 筛选后更新命中数量和条件摘要。
- 支持清除单个筛选项，也支持清除全部查询后筛选。
- 清除查询后筛选不清除原始搜索词、字段库条件或热门场景预置条件。
- 复杂组合条件、字段范围扩展、AND / OR 关系回到高级筛选字段库处理。

#### 查询方案摘要

查询方案摘要位于结果区顶部，用于让用户核对当前结果集合来源、命中情况和当前条件。`保存为查询方案` 和 `导出当前结果` 必须放在同一个模块内，让用户明确保存或导出的结果集对应什么查询条件。

| 信息 | 展示规则 |
| --- | --- |
| 命中数量 | 显示当前筛选后命中企业数，例如 `命中企业数 128 家` |
| 条件摘要 | 展示原始查询词、字段库条件摘要或热门场景名称 |
| 数据版本 | 展示当前数据批次或更新时间；无批次时至少展示数据更新时间 |
| 来源标识 | 区分 `智能搜索`、`查企业`、`字段库`、`热门场景`、`查询方案` |
| 查询资产动作 | 右侧放 `保存为查询方案` 和 `导出当前结果`；`导出记录` 进入个人资产中心，不在结果区常驻展示 |

高级筛选来源需要展示字段库条件摘要，例如 `资质荣誉=专精特新 AND 注册区县=南山区`。查询方案摘要不展示大段解释，只用于核对集合来源、当前条件和保存 / 导出的上下文。

#### 排序与视图切换

排序、视图切换和结果列表常驻操作位于结果列表标题下方。`结果内筛选` 标题单独一行；筛选控件、排序、视图切换和对比篮入口放在下一行，优先保持单行展示。`导出当前结果` 不放在结果列表操作区，而放在查询方案摘要中。

| 控件 | UE 规则 |
| --- | --- |
| 排序 | 排序字段必须是结果可解释字段。凡进入排序下拉的字段，必须在卡片视图或表格视图中常驻展示；不允许只出现在排序控件中。当前常驻排序字段包括 `综合竞争力`、`有效专利数`、`最新营收`、`成立时间` |
| 视图切换 | 支持 `卡片视图 / 表格视图`；切换不丢失查询条件、常用筛选、排序和已选状态 |
| 默认视图 | `智能搜索` 和 `查企业` 默认卡片视图；`高级筛选字段库` 默认表格视图 |
| 状态记忆 | 用户手动切换视图后，本次查询会话内保留用户选择 |

补充规则：

- 默认排序字段应优先选择结果卡片和表格的常显字段。
- 如果未来出现不适合常驻的排序项，切换到该排序项后也必须临时显式展示对应字段，例如表格动态插入“排序字段列”。
- 算法类排序字段必须带指标说明入口，例如综合竞争力旁保留 `i` 说明。

#### 对比篮状态

对比篮是结果区的全局对象暂存反馈，不只是单个按钮。

| 位置 | 规则 |
| --- | --- |
| 工具条入口 | 位于结果列表常驻操作区，显示轻量入口，例如 `对比篮 3`，数字表示当前篮内企业数量 |
| 单企业状态 | 已加入对比篮的企业在卡片 / 表格行中显示已加入态 |
| 重复点击 | 单企业入口采用 toggle 行为：未加入时加入对比篮，已加入时从对比篮移除 |
| 跨入口同步 | 同一企业在查询、画像、总览、对比篮和引育候选中出现时，已加入状态保持一致 |

#### 导出

导出只在查询后态出现，不在普通查询初始空态出现。

| 操作 | 可用条件 | 说明 |
| --- | --- | --- |
| 导出当前结果 | 有命中结果且用户具备导出权限 | 入口放在查询方案摘要右侧；导出当前条件下的完整命中结果集，保留筛选条件、字段范围、数据版本和追溯编号 |
| 导出选中 | 表格视图存在已选企业且用户具备导出权限 | 只导出选中企业 |
| 导出单个企业 | 卡片视图单企业存在且用户具备导出权限 | 只导出该企业在查询清单中的单条记录，不生成企业画像、企业评估或风险报告 |

VISIT 不提供正式导出。导出按权限、审计、水印、额度和任务进度规则处理。

#### 卡片视图

卡片视图用于单企业快速判断和单企业流转。首批不做批量选择。

卡片信息层级作为对象卡片通用规则，适用于企业查询结果、图表下钻结果、候选名单等对象卡片。业务场景可按字段和动作权限扩展，但默认遵循“主识别 -> 标签 -> 核心字段 -> 行级操作”的结构，避免把命中解释、筛选说明、批量动作混入卡片主体。

| 内容 | 规则 |
| --- | --- |
| 主识别 | 企业标识、企业名称、经营状态、资质 / 类型标签；企业标识优先使用真实 Logo，缺失时使用企业简称 / 首字 / 通用企业图标占位；企业名最多两行，超出显示省略号，鼠标移入显示完整名称 |
| 业务信号 | 产业 / 技术标签、区县、成立时间、注册资本、链位、竞争力分；进入排序下拉的字段必须在卡片或表格中可见，企业查询当前包括综合竞争力、有效专利数、最新营收和成立时间 |
| 单企业操作 | `查看画像`、`导出`、`加入对比`、`引育候选`；`导出`、`加入对比` 使用纯 icon 按钮并提供 tooltip |
| 不承接内容 | 不展示深度分析结论，不放泛化 `深度分析` 操作；不在卡片内重复展示命中原因，命中解释归属上方查询方案 / 命中区域 |

#### 表格视图

表格视图用于批量核对、排序和导出前检查。

| 内容 | 规则 |
| --- | --- |
| 选择框 | 默认显示，支持批量操作 |
| 单行操作 | 单行只保留 `查看画像` |
| 字段密度 | 保持紧凑字段，不在首批继续增加过多列 |
| 企业标识 | 表格视图不放 Logo / 企业标识列，避免破坏行高、列对齐和批量核对效率 |
| 批量选择 | 首批按当前页选择处理；跨分页选择作为后续增强 |

表格批量工具栏在存在勾选企业后显示：

```text
已选 N 家    加入对比    加入招引候选    加入培育候选    导出选中    清空选择
```

未选择企业时批量按钮禁用或不展示。批量加入候选只加入候选池，不直接生成招引推荐名单或培育建议。

#### 分页与加载状态

| 状态 | UE 规则 |
| --- | --- |
| 分页 | 结果列表支持分页；切换分页不清除查询条件、常用筛选和排序 |
| 加载中 | 列表区域展示稳定 loading，工具条保留当前条件摘要 |
| 无结果 | 保留查询条件和筛选条，提示修改条件、清空查询后筛选或进入高级筛选字段库 |
| 部分字段缺失 | 卡片 / 表格就地展示缺失或低可信状态，不隐藏企业 |

### 对象流转

企业查询只负责构造企业对象集合、展示初步信号和把对象带入后续模块，不在查询页直接生成评估、风险或引育结论。

| 流转动作 | 来源 | 目标 | 上下文携带 | UE 反馈 |
| --- | --- | --- | --- | --- |
| 查看画像 | 卡片、表格单行、下钻结果 | 企业画像抽屉或企业详情页 | 企业 ID、企业名称、数据批次、来源入口 | 抽屉用于快速核对；企业名称进入详情页 |
| 加入对比 | 卡片单企业、表格批量选择 | 对比篮 | 企业 ID、加入来源、查询条件摘要、加入时间 | 当前企业同步显示已加入状态；卡片单企业再次点击从对比篮移除 |
| 加入招引候选 | 卡片单企业、表格批量选择 | 引育推荐的招引候选名单 | 企业 ID、来源入口、查询条件摘要、推荐前置标签 | 只加入候选，不直接生成招引推荐名单 |
| 加入培育候选 | 卡片单企业、表格批量选择 | 引育推荐的培育候选名单 | 企业 ID、来源入口、查询条件摘要、培育前置标签 | 只加入候选，不直接生成培育建议 |
| 导出当前结果 | 查询方案摘要右侧 | 查询清单导出 | 查询条件、字段范围、数据版本、追溯编号、导出人 | 按权限、审计、水印和额度规则处理 |
| 导出单个企业 | 卡片单企业 | 查询清单导出 | 企业 ID、查询条件摘要、字段范围、数据版本、追溯编号、导出人 | 只导出当前企业单条清单记录 |
| 保存为查询方案 | 高级筛选或普通查询条件 | 个人资产中心 | 查询来源、条件摘要、字段范围、数据版本、恢复方式 | 保存后可在最近查询 / 查询方案中恢复 |

跨模块动作必须明确目标模块和对象来源。例如从查询页进入 `企业评估`、`风险洞察` 或 `引育推荐` 时，只能携带企业对象和条件摘要，不得替目标模块自动生成任务结果、风险结论或名单结论。

#### 跨模块带入边界

企业查询页不保留泛化 `深度分析 / 分析 / 一键研判` 操作。查询页首批跨模块流转只保留稳定承接动作：

| 查询页动作 | 后续承接 |
| --- | --- |
| 加入对比 | 对比篮 |
| 加入招引候选 | 引育推荐的招引候选池 |
| 加入培育候选 | 引育推荐的培育候选池 |
| 查看画像 / 查看详情 | 企业画像抽屉 / 当前内容区企业详情页 |

查询结果卡片、表格行和批量工具栏首批不放 `深度分析`、`智能分析`、`一键研判`、`生成报告`、`风险诊断`、`引育分析` 等泛化入口。

进入企业评估、风险洞察或引育推荐的正式分析流程，应通过对比篮、画像详情、候选池或后续明确入口完成，并先进入目标模块的对象确认 / 任务配置页，不直接生成分析结果。

#### 查看画像

企业查询结果中的企业名称和 `查看画像` 是两个不同入口。

| 入口 | 行为 | 用途 |
| --- | --- | --- |
| 企业名称 | 进入企业详情页 | 完整研判和深度查看 |
| 查看画像 | 打开企业画像抽屉 | 当前查询上下文内快速核对 |

画像抽屉只展示摘要层信息，包括企业标识、企业基础信息、统一社会信用代码、资质 / 类型标签、产业 / 技术标签、轻量竞争力摘要、轻量风险摘要、数据更新时间和数据来源。抽屉操作保留 `加入对比`、`加入招引候选`、`加入培育候选`、`查看详情`，并统一放在 Drawer 底部固定操作区；抽屉头部只保留企业标识、企业识别信息和标签，不放操作按钮，不重复展示竞争力分。企业标识优先使用真实 Logo；缺失时使用稳定占位。

竞争力分只在 `竞争力摘要` 中展示，指标说明 `i` 图标跟随竞争力指标标题展示。

画像抽屉不承接 `导出画像`、完整页签预览、复杂评估报告、风险诊断报告或引育建议结论。

`查看详情` 不打开浏览器新窗口或新标签；应在当前内容区进入企业详情页，并携带来源路径、来源查询串和来源 Tab。企业详情页面包屑中的来源节点应按原路返回到触发详情的页面，例如从企业查询结果进入时返回企业查询页。

从企业查询结果列表进入企业详情页时，不论入口是企业名称还是画像抽屉底部 `查看详情`，都属于同一条“结果上下文 -> 企业详情 -> 原路返回”链路。返回企业查询时必须恢复进入详情前的查询结果态，包括查询方式、关键词 / 智能解析条件 / 高级筛选条件、结果内筛选、排序、视图模式和分页，不应清空结果列表或回到普通初始态。该规则不影响用户主动切换 `智能搜索 / 查企业 / 高级筛选` 时重置查询态的规则。

结果列表中的表现：

- 卡片视图支持 `查看画像`、`加入对比`、`引育候选` 等单企业快速操作。
- 表格视图单行只保留 `查看画像`，批量动作放到批量工具栏。

#### 加入对比

`加入对比` 是对象暂存动作，不是分析动作。

| 场景 | 规则 |
| --- | --- |
| 卡片视图 | 支持单企业快速加入对比；加入后显示已加入态，再次点击从对比篮移除 |
| 表格视图 | 以批量选择为主；勾选后通过批量工具栏执行 `加入对比` |
| 重复点击 | 卡片单企业为加入 / 移除 toggle；表格批量加入时已存在企业不重复添加并在反馈中说明 |
| 批量反馈 | 反馈成功数量和已存在数量，例如 `已加入 5 家，1 家已在对比篮中` |
| 对比篮入口 | 结果列表常驻操作区显示轻量入口，例如 `对比篮 3` |
| 状态同步 | 同一企业在查询、画像、详情、总览、对比篮和引育推荐等企业对象入口中同步已加入状态 |

如完整系统设置对比篮上限，达到上限时提示用户先移除部分企业；本 UE 文档不写死具体数量。

#### 引育候选

企业查询页的引育动作统一命名为 `引育候选`。该动作只把企业加入候选池，不生成正式推荐名单、招引名单或培育建议。

| 动作 | 含义 |
| --- | --- |
| 加入招引候选 | 把企业作为后续招引推荐分析的候选对象 |
| 加入培育候选 | 把企业作为后续培育推荐分析的候选对象 |

卡片视图支持单企业加入候选。建议按钮为 `引育候选`，下拉项为：

- `加入招引候选`
- `加入培育候选`

表格视图单行不放候选按钮；勾选企业后，在批量工具栏提供 `加入招引候选` 和 `加入培育候选`。

候选状态按招引和培育分别同步：

| 状态 | 展示规则 |
| --- | --- |
| 未加入 | 显示 `引育候选` 下拉 |
| 已加入招引候选 | 显示 `招引候选` 状态，或下拉中该项标记为已加入 |
| 已加入培育候选 | 显示 `培育候选` 状态，或下拉中该项标记为已加入 |
| 两者都加入 | 同时显示 `招引候选`、`培育候选` 两个状态 |

重复加入时提示 `已在招引候选中` 或 `已在培育候选中`，不重复添加。

加入候选时记录企业 ID、来源入口、当前查询条件摘要、数据版本、加入时间、操作人和候选类型。VISIT 不允许加入候选；权限受限时按统一锁态、禁用态或不可见规则处理。

#### 查询清单导出

企业查询页导出只承接查询清单导出，不生成企业画像、企业评估、风险诊断、招引推荐、培育建议或一企一策报告。

| 导出类型 | 触发位置 | 导出范围 |
| --- | --- | --- |
| 导出当前结果 | 查询方案摘要右侧 | 当前查询 / 筛选条件下的完整命中企业清单 |
| 导出选中 | 表格批量工具栏 | 当前勾选的企业清单 |
| 导出单个企业 | 卡片单企业操作区 | 当前企业的单条查询清单记录 |

导出内容包括企业基础识别字段、当前结果列表字段、查询条件摘要、字段范围、数据版本 / 更新时间、追溯编号、导出人、导出时间、权限和水印信息。

导出不包含企业画像完整报告、企业评估报告、风险诊断报告、招引 / 培育推荐名单或一企一策建议。

权限与状态规则：

| 场景 | UE 规则 |
| --- | --- |
| 有权限 | 显示导出入口 |
| 无权限 | 按统一权限规则隐藏、禁用或锁态 |
| VISIT | 不提供正式导出；演示 / 内部评审模式可显示锁态 |
| 含敏感字段 | 导出前提示脱敏、字段裁剪或审批状态 |
| 数量超限 | 提示导出数量上限或进入异步任务排队 |

导出按异步任务处理：点击导出后确认导出范围、字段和脱敏提示，创建导出任务；顶部任务状态或通知展示处理中；完成后进入个人资产中心的报告导出记录，类型标识为 `查询清单`。查询页内的导出任务状态只归属当前查询方式和当前查询条件，和结果列表一样，切换到智能搜索 / 查企业 / 高级筛选的其它入口后不共享上一入口的查询清单任务提示。重新执行查询时，不自动恢复历史已完成或已失败的导出任务进度面板；进行中任务可继续显示，刚完成 / 刚失败的任务只作为短暂即时反馈保留。`查看导出记录` 必须跳转个人资产中心，不在企业查询结果区内打开抽屉、弹窗或临时记录面板。高级筛选结果导出必须保留字段库条件、AND / OR 关系、字段范围、数据版本和来源 `字段库`。

### 权限态与角色反馈

企业查询页权限反馈统一使用 `可用 / 禁用 / 锁态 / 不可见` 四类状态，避免不同按钮和字段各自定义权限表现。

| 状态 | 用法 |
| --- | --- |
| 可用 | 用户具备权限，当前条件满足，正常操作 |
| 禁用 | 用户具备能力入口，但当前条件不满足，例如未选中企业、条件为空、字段值非法 |
| 锁态 | 演示 / 内部评审模式展示权限边界，不代表真实可操作 |
| 不可见 | 正式业务权限下完全不应暴露的能力 |

企业查询页权限点：

| 能力 | 权限规则 |
| --- | --- |
| 查看基础企业信息 | 大多数角色可见；VISIT 可按权限脱敏 |
| 查看敏感字段 | 按字段权限脱敏、隐藏或禁用 |
| 高级筛选字段 | 无权限字段置灰、隐藏或不可恢复 |
| 加入对比 | 按业务权限可用；VISIT 不提供长期对象暂存能力 |
| 加入招引 / 培育候选 | 需要业务权限；VISIT 不可用 |
| 导出当前结果 / 导出选中 / 导出单个企业 | 需要导出权限；VISIT 不提供正式导出 |
| 保存 / 使用查询方案 | 需要登录用户；VISIT 不可用 |
| TraceInfoIcon | 只在演示 / 内部评审模式显示 |

敏感字段和查询方案恢复规则：

- 列表中无权限字段显示 `--`、脱敏值或不展示。
- tooltip 可提示 `当前权限不可查看该字段`。
- 导出时无权限字段自动裁剪、脱敏或触发审批提示。
- 恢复查询方案时，如果条件包含当前无权限字段，应提示 `该查询包含当前无权限字段，已脱敏或不可恢复`。

VISIT 访客规则：

- 可看基础结果，敏感字段按权限脱敏。
- 不记录最近查询。
- 不保存或使用查询方案。
- 不导出。
- 不加入招引 / 培育候选。
- 不提供长期对比篮对象暂存能力。
- 不显示追溯浮层，除非处于演示 / 内部评审模式。

演示 / 内部评审模式不是业务角色，不提升真实业务权限。该模式只用于显示锁态按钮、追溯浮层和权限说明，不绕过导出、候选、个人资产或敏感字段权限。

### 任务进度

企业查询中的普通匹配和高级筛选应用按同步查询反馈处理；导出、报告类输出和跨模块分析生成按异步任务处理。

| 能力 | 处理方式 | 进度展示 |
| --- | --- | --- |
| 智能搜索 / 查企业 | 同步查询 | 普通查询结果区 loading + 查询条件摘要 |
| 高级筛选应用 | 同步查询 | 字段库应用中状态 + 进入高级筛选结果态后的条件摘要 |
| 导出当前结果 / 导出选中 / 导出单个企业 | 异步任务 | 顶部任务状态或通知；完成后进入报告导出记录 |
| 进入企业评估 / 风险洞察 / 引育推荐 | 跨模块带参 | 目标模块先显示对象确认或任务配置，不直接显示生成结果 |
| 保存查询方案 | 同步保存 | 成功提示 + 最近查询 / 查询方案入口更新 |

异步任务至少展示 `排队中 / 处理中 / 已完成 / 失败` 四类状态。`排队中 / 处理中` 属于当前操作进度，可在查询页持续展示；`已完成 / 失败` 属于即时反馈，只短暂保留，之后归档到个人资产中心。失败状态需要保留失败原因、可重试入口和原始条件摘要，避免用户重新构造企业集合。

### 追溯浮层

追溯浮层只用于演示 / 内部评审模式，不作为业务用户能力，不改变业务权限和数据可见范围。追溯标识只挂在区块标题级，不在按钮、企业行、字段项或分页等细粒度控件上密集展示。

| 挂载位置 | traceId | 展示方式 |
| --- | --- | --- |
| 常用筛选区标题旁 | `REQ-ENT-001`、`REQ-ENT-002`、`REQ-ENT-005`、`REQ-ENT-006`、`REQ-ENT-007` | 单个 `TraceInfoIcon` 汇总展示，不在每个筛选项重复挂载 |
| 高级筛选字段库标题旁 | `REQ-ENT-001` 至 `REQ-ENT-010` | 浮层按字段组列出承接编号和本期解释 |
| 结果列表标题旁 | `REQ-ENT-001`、`REQ-ENT-002`、`REQ-ENT-003`、`REQ-ENT-004`、`REQ-ENT-010` | 说明结果列表用于对象集合展示和轻量判断信号 |
| 导出说明 | `REQ-DQ-007`，关联当前企业追溯编号 | 仅在导出说明或浮层内容中关联，不在每个导出按钮上挂 icon |

不单独挂追溯的位置：

- 普通查询顶部入口。
- 每个热门场景标签。
- 每个常用筛选下拉。
- 每个字段库字段。
- 每个企业卡片、企业行或企业名称。
- `查看画像`、`加入对比`、`引育候选`、`导出` 等按钮。
- 排序、分页、视图切换。

浮层字段遵循 `需求追溯标号规范`，并控制展示长度：追溯编号、原始标题、原文摘要、本轮解释、当前页面落位和状态。普通业务模式隐藏 icon；数据层可保留 `traceId` 用于 QA、验收和变更评审。

### frontend-agent 执行规则

| 规则 | 说明 |
| --- | --- |
| 不重复标题 | 普通查询页不新增 `企业查询` 大标题；高级筛选下级页通过面包屑和功能标题表达当前位置 |
| 保留三层入口 | 普通查询页必须同时保留 `智能搜索`、`查企业`、`高级筛选` |
| 保留字段库 | 高级筛选必须是字段库构造器，不做右侧抽屉替代 |
| 复用结果模型 | `智能搜索` 和 `查企业` 共享普通查询结果区；`高级筛选` 应用后进入高级筛选结果态，复用结果列表模型、视图切换、对象操作和对比篮状态 |
| 明确对象确认 | 进入评估、风险、引育等模块前需要对象确认或任务配置 |
| 操作状态同步 | 同一企业在查询、画像、总览、对比篮和引育候选中出现时，已加入状态必须一致 |
| 权限反馈统一 | 导出、维护、敏感字段、候选操作按角色显示可用、禁用、锁态或不可见 |
| 演示追溯隔离 | `TraceInfoIcon` 只在演示 / 内部评审模式出现，普通业务模式隐藏 |
