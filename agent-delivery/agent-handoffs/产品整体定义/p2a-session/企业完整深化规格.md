## 已确认企业 IA

企业二级菜单定稿为：

| 二级菜单 | 定位 |
| --- | --- |
| 企业查询 | 找企业、筛企业、进入画像、加入对比篮 |
| 企业总览 | 看企业类型、领域分布、深圳现状和重点对象态势 |
| 对比篮 | 暂存企业对象，发起技术力、商业力、竞争力对比 |
| 企业评估 | 技术力、商业力、综合竞争力评估、排名和差距分析 |
| 风险洞察 | 供应链关系、断链风险、发展痛难点和服务建议 |
| 引育推荐 | 招引名单、培育名单、推荐理由和一企一策建议 |

| 维护管理 | 权限态二级菜单；仅 OPS / SYS 或具备维护权限用户可见，用于维护企业图谱、字段指标、模型参数、报告模板和数据批次 |

企业画像作为横向对象能力，不进入左侧二级菜单。它从查询结果、总览卡片、对比篮、图谱节点、引育名单等位置进入。

`维护管理` 在正式权限中对非维护角色默认不可见；内部评审 / 演示模式可显示锁态，用于说明权限边界和后续维护能力，但不代表普通业务用户可访问。

## 企业总览分析结果定义

`企业总览` 不沿用当前实现中的企业全景类菜单命名，也不保留当前偏“数量态势看板”的布局。它重构为企业分析入口总览，用于看总体格局、发现对象并进入后续分析。

### 页面定位

企业总览用于在指定区域、时间、产业口径下，展示企业总体格局、重点类型分布、产业领域分布、链位结构和重点对象集合，并提供进入画像、对比篮、企业评估、风险洞察、引育推荐的动作入口。

企业总览不做完整技术力 / 商业力 / 竞争力评估详情，不做完整供应链风险诊断，不做引育名单管理，不做报告编辑，不做 OPS 维护。

### 分析模块重构

企业总览按已确认的二级菜单 `企业总览` 展开分析模块，不保留当前实现中的 `态势概览 / 企业分布 / 重点对象` 作为必选页签结构。若前端需要页内分组，可按分析模块组织，而不是沿用旧页签。

| 分析模块 | 定位 | 展示结果 |
| --- | --- | --- |
| 总体态势 | 当前口径下企业总体格局 | 企业规模、重点类型、创新能力、产业结构、趋势摘要、关键结论 |
| 企业类型分布 | 企业按类型和资质怎么构成 | 外企、高企、小微、上市、专精特新、小巨人、链主龙头等分布 |
| 产业领域分布 | 企业集中在哪些产业和技术方向 | 产业领域排行、技术标签矩阵、领域覆盖广度 |
| 当前区域企业现状 | 当前区域企业在产业链和区域对比中的状态；默认深圳时显示为 `深圳企业现状` | 当前区域企业数量、辖区 / 城市分布、链位覆盖、与全国 / 标杆区域对比摘要 |
| 重点对象态势 | 哪些企业值得进入后续动作 | 重点企业、高潜力企业、招引候选企业、培育候选企业、风险关注企业入口 |

### 当前分析口径

企业总览口径区采用分层口径，不把产业领域、产业链、链位环节混成一个筛选字段。

| 层级 | 字段 | 规则 |
| --- | --- | --- |
| 第一层主口径 | 区域、产业领域、时间 | 常驻展示；区域默认深圳，支持全国、省 / 区域、城市视角；产业领域是企业总览的主分析范围；时间默认最新数据批次 / 当前年度 |
| 第二层细化口径 | 产业链、链位 / 环节 | 在口径区可见，可收起 / 展开；产业链依赖产业领域，链位 / 环节依赖产业链；默认 `全部产业链`、`全部链位` |

产业链和链位 / 环节不是独立主口径，而是对产业领域的细化过滤。它们会影响总览所有模块的统计、图表、对象列表和下钻条件，因此不放入高级筛选深处。选择链位 / 环节后，KPI、类型分布、产业领域分布、当前区域企业现状、重点对象态势均按该链位 / 环节收敛。

时间只作为统计口径，不作为复杂时序分析入口。默认使用最新数据批次 / 当前年度，可支持近一年、近三年、近五年或自定义时间范围；趋势摘要使用时间范围，结构分布和对象清单默认按当前数据批次展示。

#### 总体态势

`总体态势` 回答“当前口径下企业整体处在什么状态”。它作为企业总览首个分析模块，只给出可被数据支撑的总判断，不展开完整评估模型。

| 项 | 规格 |
| --- | --- |
| 展示结果 | 首屏核心 KPI 固定不超过 5 个：企业总量、重点企业数、创新型企业数、近三年新增、风险关注企业数；产业覆盖和链位覆盖不进入首屏 KPI，归入下方结构分析模块 |
| 图表 / 列表形态 | 一行 KPI 卡 + 趋势摘要折线 + 关键结构小图；1440-1920 宽度下 KPI 卡必须单行展示，不占两行；趋势只展示总量、新增、重点企业、风险关注四类，不做大屏式主视觉 |
| 结论表达 | 生成 3-5 条结构化结论，每条结论必须绑定指标、时间口径和可点击对象集合 |
| 下钻动作 | KPI、趋势节点和结论点击后统一进入 `企业查询`，自动带当前口径、时间点和指标筛选条件；风险关注 KPI 可提供次级动作 `查看风险` 进入 `风险洞察` |
| 导出 / 追溯 | 企业总览不提供当前口径摘要导出；如需形成材料，进入 `分析导出`，并携带当前口径、指标时间、计算批次和支撑对象范围 |

#### 企业类型分布

`企业类型分布` 回答“当前企业由哪些类型和资质构成”。它用于发现结构偏态和重点类型对象，不替代企业查询中的筛选能力。

| 项 | 规格 |
| --- | --- |
| 展示结果 | 外企、高企、小微、上市、专精特新、小巨人、链主龙头七类企业分布 |
| 图表 / 列表形态 | 类型分布条形图 + 类型交叉矩阵 + 类型企业 Top 列表；多标签企业允许重复计入，但必须提示统计口径 |
| 结论表达 | 突出高占比类型、稀缺类型、增长最快类型和与产业口径不匹配的类型缺口 |
| 下钻动作 | 点击类型进入 `企业查询`，自动带当前口径和类型筛选条件；类型企业列表中的企业名称进入详情页，`查看画像` 打开画像抽屉；加入对比篮、进入企业评估作为业务动作按钮 |
| 导出 / 追溯 | 本模块不设独立导出；点击进入企业清单或 `分析导出` 后按字段分级和导出权限处理 |

#### 产业领域分布

`产业领域分布` 回答“企业集中在哪些产业、技术方向和链位”。它用于判断产业覆盖、技术集中度和链条短板。

| 项 | 规格 |
| --- | --- |
| 展示结果 | 产业领域排行、技术标签热度、链位覆盖、领域企业数量、重点企业占比、领域新增趋势 |
| 图表 / 列表形态 | 产业排行条形图 + 技术标签矩阵 + 链位覆盖图 + 领域企业列表 |
| 结论表达 | 标识优势领域、企业稀疏领域、链位缺口、重点企业高度集中的领域 |
| 下钻动作 | 点击产业、技术标签、链位进入 `企业查询`，自动带当前口径和对应结构条件；链位风险和补链候选通过明确业务动作进入 `风险洞察` 或 `引育推荐` |
| 导出 / 追溯 | 本模块不设独立图表导出；进入 `分析导出` 时必须携带产业分类版本、技术标签来源和统计批次 |

#### 当前区域企业现状

`当前区域企业现状` 回答“当前区域企业在产业链和区域对比中处于什么位置”。企业模块不是只做深圳：企业数据视野覆盖全国到城市，深圳是默认主场景和本地化决策对象。默认区域为深圳时，本模块标题显示为 `深圳企业现状`；切换为北京、上海、苏州、全国等区域时，标题和统计对象随当前区域切换。

区域范围口径：

| 场景 | 区域范围 |
| --- | --- |
| 企业总览 / 企业查询 / 类型分布 | 支持全国、省 / 区域、城市视角，至少覆盖国家、省、市三级地理维度和从全国到城市逐级下钻 |
| 深圳现状分析 | 聚焦深圳本地企业，并与全国、北京、上海、苏州等重点城市进行对标 |
| 招引推荐 | 从全国企业库筛选与深圳重点产业契合的目标企业 |
| 培育推荐 | 聚焦深圳市内企业，识别本地高潜力企业并生成培育建议 |

| 项 | 规格 |
| --- | --- |
| 展示结果 | 当前区域企业数量、当前区域重点企业数量、辖区 / 城市分布、产业领域覆盖、链位覆盖、与全国 / 标杆区域的数量和结构差异 |
| 图表 / 列表形态 | 当前区域辖区 / 城市排行图 + 当前区域与全国 / 标杆区域对比条形图 + 当前区域重点企业列表；默认深圳时可展示区县分布 |
| 结论表达 | 说明当前区域优势链位、薄弱链位、区域内集中度和相对标杆区域的结构差异；深圳场景可输出深圳本地化结论，其它区域不输出深圳本地政策建议 |
| 下钻动作 | 点击辖区 / 城市进入 `企业查询`，自动带当前口径和区域条件；点击对比项进入带当前区域 / 标杆区域条件的企业集合；企业名称进入详情页，`查看画像` 打开画像抽屉，加入对比篮作为业务动作 |
| 导出 / 追溯 | 本模块不设独立区域现状摘要导出；进入 `分析导出` 时必须记录当前区域、标杆区域选择、时间口径、产业口径和数据批次 |

#### 重点对象态势

`重点对象态势` 回答“哪些企业应进入后续动作”。它是从总览进入画像、对比、评估、风险和引育的对象入口。

| 项 | 规格 |
| --- | --- |
| 展示结果 | 重点企业、高潜力企业、招引候选企业、培育候选企业、风险关注企业、近期新增重点对象 |
| 图表 / 列表形态 | 分组对象列表 + 对象标签 + 推荐理由摘要 + 关键指标列；默认展示有限条数，支持查看全部 |
| 结论表达 | 每类对象必须说明入选原因，例如资质、规模、创新能力、链位价值、风险信号、引育价值 |
| 下钻动作 | 企业名称进入详情页，`查看画像` 打开画像抽屉；加入对比篮、进入企业评估、进入风险洞察、加入招引 / 培育候选、进入分析导出作为业务动作；加入类动作只轻提示，不自动跳转 |
| 导出 / 追溯 | 本模块不设独立导出；对象可加入对比篮、招引候选或培育候选，需导出时进入 `分析导出`，并保留入选规则、命中标签和数据批次 |

### 首屏结构

企业总览采用一页纵向结构，不恢复旧的强制 Tab。页面按“先口径、再判断、再结构、再区域、再对象”的顺序组织，不设置独立的后续动作入口区块。

| 区块 | 内容 | 说明 |
| --- | --- | --- |
| 当前分析口径 | 第一层：区域、产业领域、时间；第二层：产业链、链位 / 环节 | 第一层常驻展示，第二层为细化口径；区域默认深圳；产业链和链位 / 环节影响所有模块统计和下钻条件；不与企业查询搜索框混用 |
| 总体态势 | 核心指标卡、趋势摘要、总览结论摘要 | KPI 不超过 5 个，1440-1920 宽度下必须单行展示；结论必须由下方指标和对象集合支撑，不做空泛文案 |
| 结构分布 | 企业类型分布、产业领域分布、链位分布 | 支撑企业类型、产业方向和链位结构判断 |
| 当前区域企业现状 | 当前区域企业数量、辖区 / 城市分布、区域对标、当前区域重点企业 | 默认深圳时显示为 `深圳企业现状`；切换其它区域时随当前区域切换 |
| 重点对象入口 | 重点企业、高潜力企业、招引候选企业、培育候选企业、风险关注企业 | 支持进入画像、加入对比、加入招引 / 培育候选 |

跨模块动作不做成底部快捷入口。企业查询、企业评估、风险洞察、引育推荐、分析导出由左侧二级菜单承担；总览内只在 KPI、图表、对象列表和画像抽屉中提供有上下文的动作。

若页面内容较长，可使用页内锚点导航：`总体态势 / 类型分布 / 产业领域 / 区域现状 / 重点对象`。锚点只用于定位，不改变一页纵向结构。

### 企业总览下钻边界

企业总览的下钻只负责从概览发现进入可操作对象集合，不在总览内承载深层业务分析。

| 下钻类型 | 触发对象 | 去向 | 规则 |
| --- | --- | --- | --- |
| 结构下钻 | KPI、趋势节点、企业类型、产业领域、技术标签、区县、链位 | `企业查询` | 自动带当前口径和对应筛选条件，形成企业清单 |
| 对象下钻 | 企业名称、企业卡片中的查看入口 | 企业详情页 / 企业画像抽屉 | 企业名称进入详情页；`查看画像` 打开画像抽屉；对象卡片不整卡跳转 |
| 业务动作 | 加入对比、进入评估、查看风险、加入招引候选、加入培育候选、进入引育推荐、进入分析导出 | 对比篮、企业评估、风险洞察、引育推荐、分析导出 | 加入类动作只轻提示，不自动跳转；跳转类动作必须明确进入对应二级菜单并携带对象或对象集合 |

`风险关注企业数` 采用双入口：点击 KPI 主体进入 `企业查询` 并筛选风险关注企业；点击次级动作 `查看风险` 进入 `风险洞察`。

### 最近查询与查询方案

最近查询和查询方案分开管理：

| 类型 | 产生方式 | 保留规则 | 恢复方式 |
| --- | --- | --- | --- |
| 最近查询 | 用户执行普通关键词查询、结构化查企业、高级筛选应用、热门场景查询后系统自动记录 | 只保留近 30 天，最多 20 条；重复条件合并更新时间和命中数量 | 按来源恢复普通查询页或高级筛选字段库 |
| 查询方案 | 用户点击 `保存为查询方案` 后生成 | 长期保留，除非用户删除或权限失效 | 按保存来源恢复普通查询页或高级筛选字段库 |

最近查询不记录空查询。VISIT 访客不记录最近查询。涉及敏感字段的查询，记录条件摘要时需要脱敏。

最近查询至少记录查询来源、条件摘要、原始关键词、筛选条件、查询时间、命中数量、数据版本和恢复方式。查询方案在此基础上要求用户命名，并作为长期可复用资产管理。

指标模板必须标记模块和分析类型，避免跨模块误用。本期企业模板至少区分：

| 模板类型 | 复用位置 |
| --- | --- |
| 企业-技术力模板 | 企业评估、对比篮、技术力报告 |
| 企业-商业力模板 | 企业评估、对比篮、商业力报告 |
| 企业-竞争力模板 | 企业评估、对比篮、竞争力报告 |

### 指标配置生效规则

普通用户的指标配置分为临时配置和个人模板：

| 配置形态 | 生效范围 | 本期处理 |
| --- | --- | --- |
| 临时分析配置 | 当前分析任务 | 用户选择指标、调整权重后，立即影响本次技术力、商业力、综合竞争力计算、对比图和报告草稿 |
| 保存为个人模板 | 当前用户个人资产 | 用户可将本次指标组合和权重保存为个人模板，后续在企业评估、对比篮和分析导出中复用 |
| 全局指标模板 | 全系统默认模型 | 不给普通用户直接修改；由 OPS / SYS 按维护、审批和版本规则处理 |
| 团队共享模板 | 团队或机构范围 | 本期不作为企业模块必做，后续可在个人资产中心扩展 |

个人模板只影响当前用户后续使用，不直接改变全局默认模型。用户加载个人模板时，应基于当前数据版本重新计算，并在报告或浮层中标记模板名称、指标口径和数据更新时间。

### 报告导出记录规则

报告导出记录支持查看和有效期内重新下载。

| 状态 | 行为 |
| --- | --- |
| 有效期内且权限未变化 | 可查看记录并重新下载 |
| 超过有效期 | 只显示记录，不允许重新下载 |
| 权限变化或对象权限失效 | 只显示记录，不允许重新下载；提示权限变化 |
| 待支付 / 待审批 | 显示记录和状态，不提供正式下载 |

## 企业对象 schema 总体口径

企业对象 schema 采用“业务使用分组 + 画像页签承接”的方式组织。

截图中的画像页签可作为详情字段分组的基础：

- 工商概况
- 主要团队
- 资质荣誉
- 知识产权
- 经营财务
- 供应链关系
- 关系图谱
- 舆情动态
- 风险信息
- 招投标

在此基础上补充三组本期深化必需字段：

- 评估指标：技术力、商业力、综合竞争力、排名、短板。
- 引育推荐：招引/培育标签、推荐理由、匹配产业、建议动作。
- 追溯与来源：数据来源、更新时间、可信度、`REQ-*` 追溯编号。

### 字段分级规则

企业 schema 按 `必填 / 可选 / 预留` 分级。这里的必填不是数据库非空约束，而是产品交付和验收中的字段优先级。

| 分级 | 含义 | 前端和导出规则 |
| --- | --- | --- |
| 必填字段 | 支撑企业识别、查询、对比、评估、导出和追溯的核心字段 | 列表、画像、导出默认使用；缺失时显示 `暂无 / 待补充` 并进入数据质量提示 |
| 可选字段 | 增强详情、分析深度和报告解释力的字段 | 详情页和报告按可得性展示，可由模板或权限控制导出 |
| 预留字段 | 原始需求有方向或产品化有价值，但本期不强制完整落地 | schema 和对接说明中保留，页面不要求首批展示，不默认导出 |

### 字段分级清单

| 字段组 | 必填 | 可选 | 预留 |
| --- | --- | --- | --- |
| 基础信息 | 企业名称、统一社会信用代码、经营状态、注册区县、所属产业 | 法定代表人、成立时间、注册资本、官网、联系方式 | 详细工商变更 |

| 企业类型资质 | 企业类型、企业资质、高企/专精特新/上市标识 | 资质荣誉清单、企业规模 | 荣誉证书附件 |
| 技术能力 | 技术力分、有效专利数、核心技术标签 | 高价值专利、研发人员占比、专利引用 | 论文、标准、软著明细 |
| 商业能力 | 商业力分、营收规模或营收区间 | 营收增长率、利润率、市场份额、客户集中度 | 融资轮次、投资机构 |
| 综合竞争力 | 综合竞争力分、排名或分档、主要优势/短板 | 雷达图分项、差距分析 | 自定义评价版本对比 |
| 供应链关系 | 链位、供应链角色、断链风险等级 | 上游、下游、合作伙伴、核心供应商 | 多级供应链全量明细 |
| 风险痛点 | 风险等级、风险类型、痛点类型 | 舆情风险、经营风险、知识产权风险、改进建议 | 完整风险事件流水 |
| 引育推荐 | 推荐类型、招引/培育状态、推荐理由 | 产业匹配度、成长性评分、建议动作、所需支持 | 对接进度、项目跟踪 |
| 追溯来源 | 数据来源、更新时间、数据版本、追溯编号 | 字段来源明细、可信度等级 | 原始采集批次明细 |

### 字段使用规则

1. 查询列表只使用必填字段和少量高价值可选字段。
2. 企业画像头部只展示必填字段和核心评分，不堆完整字段。
3. 详情页承接可选字段。
4. 预留字段不要求本期页面完整展示，但 schema、导出模板和对接说明中保留。
5. 字段缺失不能让页面空白，应显示缺失状态，并在 OPS 数据批次或来源状态中可追踪。
6. 导出报告按模板控制字段：必填字段默认导出，可选字段按模板或权限选择，预留字段不默认导出。

### 高级筛选 · 字段库

高级筛选保留当前“字段库构造器”形态，定位为 `构造企业集合` 的专业筛选模式。它不改为右侧抽屉，也不作为普通查询首屏主形态；用户从字段库添加筛选条件，设置 AND / OR 条件关系后生成企业集合。

| 分组 | 字段 | 本期处理 |
| --- | --- | --- |
| 基础信息 | 企业名称、经营状态、注册区县、注册资本、成立时间 | 保留 |
| 组织信息 | 法定代表人、企业类型、所属产业 | 保留；法定代表人不标记为推荐字段 |
| 企业规模 | 企业规模、最新营收 | 保留 |
| 经营 / 资质 | 资质荣誉、是否上市、是否高企 | 保留 |
| 评估分值 | 技术力分、商业力分、综合竞争力分 | 补充；综合竞争力分从经营 / 资质移入本组 |
| 技术能力 | 有效专利数、高价值专利数、核心技术标签 | 保留有效专利数，补充高价值专利数和核心技术标签 |
| 商业能力 | 营收增长率、利润率 | 补充，保持轻量 |
| 供应链关系 | 供应链角色、关键节点标识、断链风险等级 | 补充 |
| 风险舆情 | 失信级别、风险等级、风险类型、舆情风险等级 | 保留失信级别，补充风险和舆情字段 |
| 引育推荐 | 招引状态、培育状态、产业匹配度、成长性评分 | 补充 |
| 数据追溯 | 数据更新时间、数据来源、可信度等级 | 补充轻量追溯字段 |

融资轮次、融资金额、投资机构、中标次数、项目金额、采购方类型等字段不进入企业查询高级筛选首批，放到企业详情页、专题分析或后续增强中处理。

| 系统后台 SYS | 管理权限和审计，不作为常规业务导出角色 |

### 导出审计与水印

所有正式导出都必须留审计记录并带水印。

| 审计字段 | 说明 |
| --- | --- |
| 导出人 | 当前用户 |
| 角色 | 当前角色/权限视角 |
| 导出时间 | 时间戳 |
| 导出类型 | 查询清单、画像摘要、对比报告、风险建议报告、引育名单 |
| 对象数量 | 导出企业数量 |
| 筛选条件 | 当前查询/筛选条件 |
| 字段范围 | 导出的字段模板 |
| 是否含敏感字段 | 如联系方式、财务、风险等 |
| 水印信息 | 用户名、时间、系统标识 |
| 追溯编号 | 关联 `REQ-*` 或导出模板编号 |

### 导出额度与收费

存在产品化需求：可能只可免费导出 1-2 份报告，后续再导出收费。

该能力纳入本期产品化范围，至少需要支撑额度提示、导出记录、收费状态和审计留痕。若项目当前不接入真实支付通道，也应保留订单/支付状态字段，支持后续与完整系统计费能力对接。

| 能力 | 本期处理 |
| --- | --- |
| 免费额度规则 | 支持按用户或机构配置免费导出份数，例如 1-2 份 |
| 超额提示 | 用户超出免费额度时，在导出前提示需付费或需审批 |
| 收费状态 | 导出记录中保留免费、待支付、已支付、审批通过、失败等状态 |
| 审计记录 | 记录导出人、角色、时间、对象范围、字段范围、水印和收费状态 |
| 订单/支付字段 | 本期保留对接字段；真实支付闭环按完整系统能力接入 |
| 发票/财务 | 不作为企业模块页面必做，可在完整系统商业化能力中承接 |

导出记录进入个人资产中心，与查询历史、对比暂存和指标模板统一查看。

## OPS 维护入口初步口径

OPS 在企业模块拥有维护类菜单使用权限，但不替代业务用户完成研判。

### 可见性规则

| 场景 | 维护管理菜单状态 |
| --- | --- |
| OPS / SYS / 有维护权限用户 | 可见且可进入 |
| GOV / INNO / THINK 等普通业务角色 | 正式权限下不可见 |
| VISIT 访客只读 | 不可见 |
| 内部评审 / 演示模式 | 可显示锁态，用于演示权限边界，不开放访问 |

| 维护项 | 一期能力 | 高风险操作 |
| --- | --- | --- |
| 企业图谱维护 | 查看节点、关系、链路、图谱刷新状态 | 直接编辑图谱、发布图谱 |
| 字段/指标配置 | 查看和维护筛选字段、指标口径、权重参数 | 发布高影响指标变更 |
| 模型状态 | 查看技术力、商业力、竞争力、引育模型运行状态 | 手动触发模型重跑 |
| 数据批次 | 查看企业数据批次、更新时间、来源状态 | 直接编辑原始数据 |
| 报告模板 | 维护字段模板、报告模板 | 发布全局模板变更 |
