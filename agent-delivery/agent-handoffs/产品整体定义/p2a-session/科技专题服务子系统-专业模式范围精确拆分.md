## 智能检索范围边界

原文中的 `科技专题数据查询` 包含完整的统一智能检索和分析面板能力，但本项目不承接单独智能检索模块页面的功能搭建。

本项目负责：

- 在产业链、企业、政策、产业服务链、综合智能分析模块内提供常驻查询入口。
- 查询能力限于传统关键词匹配、多字段条件匹配和高级筛选。
- 为完整科技专题服务系统或其它厂商的统一智能检索页面提供数据支持。
- 提供对象 schema、字段定义、筛选条件、结果数据、报告数据和来源标识。

本项目不负责：

- 单独的统一智能检索模块页面。
- 自然语言 / 大模型检索。
- 推荐图表分析总入口。
- 自定义图表创建器。
- 图表面板管理。
- 面板保存到个人或团队空间。
- 多格式面板导出和模板化看板管理。

## 建议的信息架构

### 已确认方案：前四模块统一二级菜单 + 综合智能分析简化

产业链、企业、政策、产业服务链四个对象域采用统一二级结构：

| 二级菜单 | 作用 |
| --- | --- |
| 智能查询 | 本模块对象检索、关键词匹配、多字段条件匹配、高级筛选、图谱/关系联动、结果集建立；本期不做自然语言 / 大模型检索 |
| 对比暂存 | 本模块对象集暂存、移除、继续添加、进入对比或研判 |
| 态势全景 | 承接图谱、趋势、分布、现状类能力 |
| 专题研判 | 承接评价、识别、诊断、推荐、短板分析类能力 |
| 分析导出 | 承接查询结果、对比结果、模块级研判报告导出；不承接图表面板导出 |

综合智能分析不强行套用对象域菜单，采用简化结构：

| 二级菜单 | 作用 |
| --- | --- |
| 创新活力 | 承接区域创新活力分析 |
| 创新要素 | 承接区域创新要素分析 |
| 创新协同 | 承接区域创新协同分析 |
| 综合报告 | 汇总产业链、企业、政策、产业服务链及外部结果，输出模块级综合报告 |
| 维护管理 | OPS 使用，维护图谱、指标、模板、数据批次和模型状态查看 |

对比篮一期采用“模块内入口常驻 + 全局篮轻量承接”：模块内入口支持加入、查看和移除本模块对象；全局篮一期只做统一入口和对象汇总，不做复杂跨对象混合分析。

综合智能查询本期口径：当前实现里的智能搜索只按传统关键词匹配 + 多字段条件匹配 + 高级筛选验收，不做自然语言问答、大模型语义检索或自动意图解析；自然语言 / 大模型检索作为后续演进方向保留。

| 通用保留能力 | 处理口径 |
| --- | --- |
| 条件查询 | 作为筛选目标区域、产业、创新主体、要素类型的入口，按全系统查询能力保留 |
| 对比暂存 | 暂存区域、要素集合或协同网络，用于横向查看，按全系统对比能力保留 |
| 分析导出 | 可导出创新活力指数、要素分析和协同效率报告；不承接图表面板保存和多格式面板导出 |

综合智能分析可以作为汇总层接收其它模块结果：

- 接收本项目范围内的产业链、企业、政策、产业服务链分析结果。
- 可接收技术链、科研机构、人才等外部厂商结果作为输入。
- 不承接技术链、科研机构、人才的页面、查询、对比、维护和导出流程。

## 摘出内容与对接边界

| 科研机构 | 用户明确说明由其它厂商负责 | 本项目不拆科研机构页面、查询、对比、导出任务；仅在综合智能分析中允许引用外部提供的科研机构指标结果 |

## 当前开放问题

1. 企业完整深化落地的对象 schema、筛选字段、结果/画像字段、对比篮字段需要继续细化。
2. 五模块需要继续细化 IA 结构、需求能力追溯标注和数据支持口径；企业额外补完整深化落地规格。
3. 轻量全局篮一期以企业对象为主，其它模块只预留对象类型和来源标识。
4. 企业模块级分析报告导出的模板字段、权限和审计口径需要继续细化；统一图表面板保存和多格式面板导出不纳入本项目。
5. 权限/演示模式位置的中文映射是否采用：政府驾驶舱、创新工作台、研判工作台、访客只读、运营后台、系统后台？
