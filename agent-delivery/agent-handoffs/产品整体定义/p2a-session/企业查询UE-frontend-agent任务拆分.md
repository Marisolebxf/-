# 企业查询 UE frontend-agent 任务拆分

## 文档定位

本文把 `p2a-session/企业模块深化UE规格.md` 中已确认的企业查询 UE 规则拆成 frontend-agent 可执行任务。

实现时以以下文档为准：

- 产品边界：`p2a-session/企业完整深化规格.md`
- UE 规格：`p2a-session/企业模块深化UE规格.md`
- 追溯规则：`p2a-session/需求追溯标号规范.md`
- 平台通用交互：`UX-UE 通用交互组件规范.md`
- GKX 视觉与组件约束：`gkx-orchestration/agent-delivery/Design.md` 与当前项目 Arco / wrapper 规则

本文不重新定义企业产品能力、字段口径、模型规则或权限矩阵。

## 总体边界

| 项 | 结论 |
| --- | --- |
| 页面范围 | 企业查询普通查询页、高级筛选字段库下级页、高级筛选结果态 |
| 不做内容 | 不做自然语言 / 大模型语义检索；不做完整条件树；不做企业评估、风险诊断、引育推荐结果生成 |
| 设计系统 | 使用当前 GKX 蓝白工作台、Arco 组件和项目已有 wrappers |
| 结果模型 | 普通查询结果区和高级筛选结果态复用企业结果列表模型和对象操作规则 |
| 权限 | 所有导出、候选、查询方案、敏感字段和追溯入口继承统一权限状态 |

## FE-ENT-QUERY-01 普通查询页入口与初始空态

### 目标

实现企业查询普通查询页的顶部入口、默认智能搜索、示例查询、热门场景和普通查询初始空态。

### 范围

- 普通查询页显示 `智能搜索 | 查企业 | 高级筛选`。
- 普通查询页不常驻面包屑。
- 默认落在 `智能搜索`。
- `智能搜索` 和 `查企业` 共用普通查询初始内容区。
- `高级筛选` 点击后进入下级字段库页面，不在当前页展开。
- placeholder 只写能力范围，不写具体样例。
- 示例查询位于搜索框与热门场景之间，随 `智能搜索 / 查企业` 切换。
- 热门场景固定 6 个：`专精特新企业`、`国高企`、`上市企业`、`南山区企业`、`集成电路企业`、`近三年新增企业`。

### 非目标

- 不实现自然语言 / 大模型语义检索。
- 不把热门场景做成动态推荐或榜单。
- 不在普通查询页保留高级筛选字段库面板。

### 验收点

- 页面只显示 `智能搜索 | 查企业 | 高级筛选`，不显示括号解释。
- `智能搜索` 默认选中。
- 示例查询点击只填入搜索框，不自动执行。
- 热门场景点击进入高级筛选字段库并带入预置条件。
- 初始空态不展示推荐榜单、统计图或大段功能说明。
- 搜索框有输入值时显示一键清除按钮；点击后清空当前入口输入、识别条件、普通查询条件摘要和普通查询结果区，回到普通查询初始空态。
- 一键清除不清除最近使用、查询方案、热门场景、高级筛选字段库条件、对比篮或候选状态。

## FE-ENT-QUERY-02 最近查询 / 查询方案与查询方案保存恢复

### 目标

实现普通查询初始空态中的 `最近使用` 区，并统一普通查询与字段库的查询方案保存和恢复规则。

### 范围

- `最近查询 / 查询方案` 统一表现为 `最近使用`。
- 首屏展示 3-5 条 chip，超过显示 `查看全部`。
- 最近查询系统自动记录，近 30 天、最多 20 条。
- 查询方案由用户主动保存，长期保留。
- 普通查询结果区提供 `保存为查询方案`。
- 高级筛选字段库操作区提供 `保存为查询方案` 和 `使用查询方案`。
- 查询方案恢复条件但不自动执行。
- 最近查询可恢复并直接执行。

### 非目标

- 不保存静态企业结果清单。
- 不做团队共享模板、模板审批、模板版本管理。
- 不给 VISIT 保存或使用查询方案。

### 验收点

- 查询方案保存时必须命名。
- 同名首批提示改名，不做覆盖。
- 字段库方案恢复后进入字段库并回填条件集合。
- 普通查询方案恢复到 `智能搜索` 或 `查企业`。
- 字段权限变化、字段下线、字典值失效和数据版本变化有明确提示。
- 最近使用按当前入口过滤展示：`查企业` 下只显示查企业关键词记录和查企业来源方案；`智能搜索` 和字段库上下文分别展示对应记录。

## FE-ENT-QUERY-03 高级筛选字段库下级页

### 目标

实现 `高级筛选 · 字段库 / 构造企业集合` 下级页面态。

### 范围

- 高级筛选页面顶部使用面包屑，例如 `企业分析 / 企业查询 / 高级筛选`。
- 面包屑上级节点可点击返回，当前页节点不可点击。
- 面包屑下方可保留固定热门场景行。
- 不保留普通查询页的 `智能搜索 | 查企业 | 高级筛选` 三入口。
- 字段库包含四个语义区域：字段分组、字段列表、已选条件、操作区。
- 标题工具区包含 `已选 N 个条件`、`搜索字段名 / 别名`、`展开字段库 / 收起字段库`。
- 字段分组沿用 11 类产品分组。
- 同一字段首批只允许添加一次。
- 字段条件编辑按字段类型渲染专用控件和校验规则。
- 首批只支持全局 `全部满足 AND / 任一满足 OR`。
- 操作区包含 `应用筛选`、`重置`、`保存为查询方案`、`使用查询方案`。

### 非目标

- 不做右侧抽屉。
- 不做条件组嵌套、括号逻辑、字段权重、复杂表达式编辑器。
- 不做 `添加组合条件`、`添加同类型属性`。

### 验收点

- 字段库可上下结构实现，但四个语义区域必须存在。
- 日期、年份、金额、数值、百分比、枚举、标签、布尔、等级字段使用对应控件。
- 非法输入、区间冲突、权限受限字段就地提示。
- 条件为空时 `应用筛选` 和 `保存为查询方案` 禁用。
- 热门场景带入的预置条件可编辑、可删除。
- 点击 `应用筛选` 后进入高级筛选结果态。

## FE-ENT-QUERY-04 普通查询结果区与高级筛选结果态

### 目标

实现普通查询结果区和高级筛选结果态，复用企业结果列表模型和对象操作规则。

### 范围

- `智能搜索` 和 `查企业` 使用普通查询页内结果区。
- `高级筛选` 应用后进入高级筛选结果态，保留面包屑和字段库条件摘要。
- 结果摘要展示命中数量、条件摘要、数据版本、来源标识。
- 常用筛选条首屏展示 4 个高频字段：`经营状态`、`企业规模`、`注册区县`、`资质荣誉`。
- 排序默认 `综合竞争力优先`。
- 视图支持卡片视图和表格视图。
- `智能搜索 / 查企业` 默认卡片视图。
- 高级筛选结果态默认表格视图。
- 卡片视图用于单企业快速判断，不做批量选择。
- 表格视图用于批量核对，默认显示选择框。

### 非目标

- 不把高级筛选结果态做回普通查询页顶部模块。
- 不在查询页生成深度分析结论。
- 不在卡片视图首批支持批量选择。

### 验收点

- 常用筛选只作用于当前结果集合，不改变原始查询来源。
- 清除常用筛选不清除原始搜索词、字段库条件或热门场景预置条件。
- 复杂筛选回字段库处理。
- 视图切换不丢失查询条件、筛选、排序和已选状态。
- 无结果时保留条件并提供修改、清空、编辑高级筛选入口。
- 智能搜索识别条件可单项删除；删除后不改原始输入框，立即按剩余条件重算结果并更新命中数量。
- 删除全部识别条件但输入框仍有内容时按原始关键词匹配；输入框也清空时回到普通查询初始空态。

## FE-ENT-QUERY-05 对象操作与状态同步

### 目标

实现查询结果中的查看画像、加入对比、加入招引 / 培育候选和跨模块带入边界。

### 范围

- 企业名称进入企业详情页。
- `查看画像` 打开企业画像抽屉。
- 画像抽屉只做快速核对，不承接导出画像、完整页签、评估报告、风险诊断或引育建议。
- 卡片视图支持单企业 `加入对比`、`引育候选`、`查看画像`。
- 表格视图单行只保留 `查看画像`。
- 表格批量工具栏提供 `加入对比`、`加入招引候选`、`加入培育候选`、`导出选中`、`清空选择`。
- `引育候选` 下拉包含 `加入招引候选` 和 `加入培育候选`。
- 候选状态按招引和培育分别同步。

### 非目标

- 不放泛化 `深度分析 / 分析 / 一键研判`。
- 不直接进入评估、风险、引育并生成分析结果。
- 不把加入候选误写成生成推荐名单。

### 验收点

- 重复加入对比提示已在对比篮中。
- 批量加入对比反馈成功数量和已存在数量。
- 对比篮数量在工具条同步。
- 同一企业在查询、画像、详情、总览、对比篮、引育推荐中的已加入状态同步。
- 加入候选记录企业 ID、来源入口、查询条件摘要、数据版本、加入时间、操作人和候选类型。

## FE-ENT-QUERY-06 导出、任务进度与导出记录入口

### 目标

实现企业查询清单导出和异步任务反馈。

### 范围

- 导出类型包括 `导出当前结果` 和 `导出选中`。
- 导出内容为企业清单及查询条件追溯。
- 导出保留查询条件摘要、字段范围、数据版本 / 更新时间、追溯编号、导出人、导出时间、权限和水印信息。
- 导出按异步任务处理。
- 完成后进入个人资产中心导出记录，类型标识为 `查询清单`。
- 高级筛选结果导出保留字段库条件、AND / OR 关系、字段范围、数据版本和来源 `字段库`。

### 非目标

- 不生成企业画像报告、企业评估报告、风险诊断报告、招引 / 培育推荐名单或一企一策建议。

### 验收点

- VISIT 不提供正式导出。
- 敏感字段导出前提示脱敏、字段裁剪或审批状态。
- 导出失败保留任务上下文并提供重试。
- 导出当前结果和导出选中的可用条件区分清楚。

## FE-ENT-QUERY-07 权限态、异常态与空状态

### 目标

统一企业查询页的权限、异常和空状态反馈。

### 范围

- 权限态统一为 `可用 / 禁用 / 锁态 / 不可见`。
- VISIT 可看基础结果但敏感字段脱敏。
- VISIT 不记录最近查询，不保存或使用查询方案，不导出，不加入招引 / 培育候选，不提供长期对比篮对象暂存。
- 初始空态展示搜索框、示例查询、热门场景和最近使用。
- 结果空态保留条件并提供修改关键词、清空筛选、编辑高级筛选。
- 条件错误就地提示。
- 权限 / 数据不可用覆盖字段无权限、字段下线、字典值失效、数据批次不可用。
- 任务失败覆盖查询、导出、保存方案、加入对比、加入候选。

### 非目标

- 不通过演示模式提升真实业务权限。
- 不用全局弹窗替代字段级校验。

### 验收点

- 条件错误时禁用 `应用筛选` 和 `保存为查询方案`。
- 查询失败保留条件摘要并提供重试。
- 查询方案含无权限字段时提示脱敏或不可恢复。
- 数据版本变化提示重新计算但不阻断恢复。

## FE-ENT-QUERY-08 追溯浮层与演示模式隔离

### 目标

实现企业查询页追溯浮层的区块级挂载和普通业务模式隔离。

### 范围

- 追溯浮层只在演示 / 内部评审模式显示。
- 普通业务模式隐藏。
- 只在区块标题级挂载：
  - 查询后常用筛选区标题
  - 高级筛选字段库标题
  - 结果列表标题
- 导出只在导出说明中关联 `REQ-DQ-007`，不在每个导出按钮上挂 icon。
- 浮层展示追溯编号、原始标题、原文摘要、本轮解释、当前页面落位和状态。

### 非目标

- 不在热门场景标签、常用筛选下拉、字段库字段、企业卡片、企业行、企业名称、按钮、排序、分页、视图切换上挂追溯。
- 不让演示模式绕过真实权限。

### 验收点

- 普通业务模式无 TraceInfoIcon。
- 演示 / 内部评审模式显示区块级 TraceInfoIcon。
- 按钮级、行级、字段级不出现密集追溯 icon。

## frontend-agent 总体验收清单

- 页面符合 GKX 蓝白 PC 工作台风格，不引入第二套设计系统。
- 常见控件优先使用 Arco 或项目已有 wrappers。
- 不新增 Ant Design 或页面私有基础控件实现。
- 普通查询页不重复 `企业查询` 大标题。
- 高级筛选使用下级页面态和面包屑，不做抽屉。
- 普通查询页和高级筛选结果态边界清晰。
- 查询页不生成深层分析结论。
- 所有对象操作携带来源入口、条件摘要和数据版本。
- 权限、空状态、异常状态、任务状态可验证。
