# 五模块 IA/追溯标注清单

## 版本

Draft v0.1

## 目的

本清单用于把本轮纳入范围的五个专业模块统一完成 IA 拆分和原始需求能力追溯标注，后续作为 product-agent、UE 和 frontend-agent 的共同对照基准。

本清单只定义：

- 五个模块的二级菜单结构。
- 每个二级菜单承接的原始需求能力。
- 本期处理层级：企业完整深化落地，其余模块只做 IA/追溯标注和数据支持口径。
- 搜索查询、对比暂存、分析导出等通用能力在各模块中的落位。

本清单不定义：

- 单独统一智能检索模块页面。
- 自然语言 / 大模型语义检索。
- 推荐图表、自定义图表、图表面板管理、面板保存和多格式面板导出。
- 技术链、科研机构、人才三个外部厂商模块的页面 IA。

## 追溯标号使用方式

本清单中的需求追溯以 `REQ-*` 编号为准。编号可用于：

- 在产品文档中点击或搜索定位源需求。
- 在原型中以能力标题旁的 `i` icon 浮层展示原文摘要和源文档行号，完整原文作为二级展开或查看入口。
- 在 UE / frontend-agent 派单中标注能力来源。
- 后期正式开发时通过统一开关隐藏或移除浮层，不影响业务页面。

追溯标注只在演示模式 / 内部评审模式显示，不新增全权限演示角色，不改变 `GOV / INNO / THINK / VISIT / OPS / SYS` 的业务权限。

详细编号、源文档行号、浮层字段和移除策略见：

- `p2a-session/需求追溯标号规范.md`
