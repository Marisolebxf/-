## 模块目标

围绕固定的深圳城市锚点和用户选择的产业链，本模块完成两项相邻任务：定位深圳相关企业及其链中角色；将深圳企业群与全国参照及重点城市进行同口径对标。模块不承担单企业能力评估、风险诊断、招引培育推荐或报告导出。

本模块权威入口为 `/enterprise-center/shenzhen-enterprise-status-analysis`；旧 `/enterprise/status-analysis` 不复用、不继续修改，兼容策略另行评审。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府产业治理人员 | Bid 企业分析面向“政府”并支撑产业链治理 | 识别深圳产业链基础、位置、优势、短板和生态完整性 |
| 园区招商与企业服务人员 | Bid 企业分析面向“园区”并支撑招商育商 | 找到指定产业链/环节内的深圳企业并核验、编组对象 |
| 投资机构产业研究人员 | Bid 企业分析面向“投资机构” | 比较深圳与全国及重点城市的企业群体指标 |

## 用户故事

### US-SZSTATUS-01 定位深圳企业的产业链角色

作为政府产业治理人员，我想选择产业链和环节，查看深圳相关企业数量、环节分布、链中角色与链条完整性，以便掌握本地产业基础并识别薄弱环节。

### US-SZSTATUS-02 核验并编组深圳企业对象

作为园区招商与企业服务人员，我想在匹配企业清单中查看企业详情并选择企业加入对比篮，以便确认服务对象并在后续模块继续分析。

> 查看详情和加入对比篮是经确认的 `product_interpretation`；本模块只传递企业对象，不生成后续分析结果。

### US-SZSTATUS-03 对标深圳与全国及重点城市

作为投资机构产业研究人员，我想在同一产业链和统计周期下比较深圳、全国参照以及北京、上海、苏州等重点城市的平均技术力、平均商业力、企业密度和产业链完整度，以便识别深圳的相对优势和短板。

### US-SZSTATUS-04 在两个任务间保持同一坐标系

作为政府产业治理人员，我想在产业链定位和多城市横向对标之间切换时继续围绕同一条产业链分析，以便把本地企业基础与外部参照联系起来理解。

## 场景 walkthrough

### 主路径 A：产业链定位

1. 用户从企业分析菜单进入“深圳企业现状分析”，默认进入“产业链定位”。
2. 页面明确显示固定城市“深圳”、产业链选择和数据更新时间；未选择产业链时不生成隐藏默认结果。
3. 用户选择产业链，环节默认为“全部环节”。
4. 系统展示深圳相关企业数、覆盖/重点环节、产业链完整度，以及链条环节与角色分布。
5. 用户选择某个产业链环节，摘要、分布和企业清单使用同一筛选结果集刷新。
6. 企业清单直接显示在定位页，展示企业名称、所在区、所属环节和链中角色。
7. 用户可以“全选当前结果 / 取消全选”；有搜索词时仅影响当前搜索结果，翻页后保留已选对象。
8. 用户点击“查看详情”，系统打开宽幅 Drawer，展示与企业详情页一致的企业头部和完整页签：工商概况、主要团队、资质荣誉、知识产权、经营财务、供应链关系、关系图谱、舆情动态、风险信息、招投标。
9. 企业详情默认打开“工商概况”；关闭 Drawer 后保留产业链、环节、角色、搜索、分页、滚动位置和已选对象。
10. 用户可将一家或多家已选企业加入对比篮；加入成功后保留当前定位上下文，不自动跳转。

### 主路径 B：多城市横向对标

1. 用户在已选择产业链的情况下切换到“多城市横向对标”。
2. 页面继续使用同一深圳锚点和产业链；默认对标城市临时为北京、上海、苏州、广州。
3. 深圳和全国参照固定存在，用户可以增减重点城市，但不能移除深圳或全国参照。
4. 系统按同一产业链、统计周期和指标版本计算各对象的平均技术力、平均商业力、企业密度和产业链完整度。
5. 对标城市多选形成完整城市池；雷达对象 A 固定深圳，对象 B 从全国参照与当前已选重点城市中单选，默认全国参照。
6. 可比指标不少于 3 个时，独立雷达工作区最多展示 A / B 两条轮廓；城市对比表始终承载完整城市池的原始值、单位和更新时间。
7. 城市对比表每页 5 行，对象列固定左侧、数据状态列固定右侧，中间指标列可横向滚动；翻页和滚动不改变雷达与相对观察。
8. 系统仅依据当前 A / B 的可比指标生成深圳相对对象 B 的优势与短板说明，不生成综合竞争力得分或总排名。

### 主路径 C：切换产业链

1. 用户在任一 Tab 修改产业链。
2. 系统将定位视图环节恢复为“全部环节”，清除旧链企业勾选。
3. 系统保留仍有效的对标城市选择，并按新产业链重新计算。
4. 对比篮中已保存企业不被页面切链操作删除或改写。

## 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 未选择产业链 | 保留页面壳和两个 Tab，结果区显示待选择态 | 选择产业链 |
| 当前环节无深圳企业 | 显示当前链/环节空态，不自动放宽条件 | 改为全部环节或更换产业链 |
| 企业缺链中角色 | 该行显示“暂未标注”，不按名称推断 | 查看详情或其他企业 |
| 搜索结果为空 | 表格显示当前搜索空态，全选不可用，原有已选对象不清空 | 清除搜索词 |
| 部分结果已选择 | 全选控件显示部分选择态 | 全选当前结果或取消当前结果 |
| 已达对比篮容量上限 | 禁止继续选择并说明剩余容量 | 减少选择 |
| 部分企业编码无效 | 有效对象继续加入，无效对象集中提示 | 修正选择 |
| 对比篮重复或超限 | 使用对比篮统一反馈，不覆盖已有对象 | 调整当前选择 |
| 企业详情单个页签无权限 | Drawer 保留企业头部和其他可用页签，目标页签显示锁态 | 切换页签或申请权限 |
| 企业详情页签加载失败 | 只在当前页签显示错误和重试，不关闭 Drawer | 重试或查看其他页签 |
| 某指标缺公式或来源 | 表格显示正常不可用态，评审模式显示 Pending | 查看其他可比指标 |
| 某城市缺单项数据 | 不以 0 补齐；该单元显示不可用 | 调整城市或继续查看 |
| 当前雷达对象 B 被移出城市池 | 对象 B 自动回退为全国参照，雷达和相对观察同步刷新 | 继续查看或重新选择对象 B |
| 可比指标少于 3 个 | 隐藏雷达图，只保留对比表，不输出强结论 | 查看表格 |
| 所有城市均不可比 | 保留选择条件和原因提示，不生成优势/短板 | 调整城市或等待数据补齐 |
| 加载 / 错误 | 稳定容器显示骨架或错误重试 | 等待或重试 |
| 无权限 | 结果与业务动作进入锁态 | 返回或申请权限 |

## 业务模式禁止行为

- 不得把深圳改造成可切换的“当前区域”，不得允许从本页选择其他主城市。
- 不得在未选产业链时用隐藏默认链直接生成结论。
- 不得把产业链环节与链中角色混为同一字段。
- 不得依据企业名称、简介或规模猜测链中角色。
- 不得把企业清单放进 Drawer 后再嵌套企业详情 Drawer。
- 不得把“查看详情”降级为企业摘要或画像概览；必须承载完整企业详情页签。
- 不得由 E-25 复制或重定义企业详情字段、权限、脱敏和内部评审挂点。
- 不得用全市全部企业指标替代当前产业链城市指标。
- 不得用综合竞争力、营收或利润率替代缺失的城市平均商业力。
- 不得以 0 补齐缺失城市指标，不得在不可比时仍绘制完整雷达。
- 不得生成城市综合竞争力总分、总排名、风险结论、推荐名单或报告。
- 不得在加入对比篮后自动跳转或改写篮内已有对象。
- 不得在 E-25 嵌入态新增“查看对比篮”作为第三个企业动作。
- 不得在业务模式显示内部评审、数据血缘或算法缺口文案。
