## 1. 模型（方案 B）

```
CurrentUser
├── level: L0…L4          ← 能力轴（已有）
├── persona / subroles    ← 已有
└── paid: boolean         ← 用户级付费权益（Wave 0 mock）
```

### 1.1 `paid` 默认与切换规则（演示）

| 级别变化 | `paid` 默认行为 |
|---|---|
| 进入 / 切到 **L2** | 置 `paid = false`（除非用户刚在本会话手动打开过付费开关——见下） |
| 进入 / 切到 **L3 / L4** | 置 `paid = true` |
| 进入 / 切到 **L0 / L1** | `paid` 无关紧要（无深分析）；可保持原值或 false |
| **L2 且用户打开「付费权益」Switch** | `paid = true`，持久化；用于演示 **L2 + 付费** |
| L2 用户关闭 Switch | `paid = false` |

实现建议：`setLevel` 时按上表写默认；另提供 `setPaid(boolean)`，**仅当 level≥L2** 时 Switch 可操作（L3/L4 默认开，仍允许关以便反例演示，可选；最低要求是 **L2 可开可关**）。

| 动作 | 交付物 | 门槛 | UI |
|---|---|---|---|
| 深度分析 | 过程 + 结果 | ≥ L2 | 现有 PermGate |
| **创建 / 查看报告** | HTML Reader | ≥ L2 + `BTN_REPORT_GENERATE` | 可点 |
| **导出**（PDF） | PDF 文件 | ≥ L2 且 `paid === true` | 未付费：可见**锁态** +「付费」角标 + Tooltip「付费用户可导出」 |

命名：

- 「创建报告」/「查看 HTML 报告」= 生成 + HTML  
- 「导出」/「导出 PDF」= 带走型（本方案对外主文案）

与矩阵：本 Wave **不改** `LEVEL_PERMS`；PDF 闸门只读 `paid`。`BTN_EXPORT`（L1 表图导出）**不**混用于报告 PDF。

## 2. UI 规范（两枚角标 + 锁态）

### 2.1 顶栏

1. **能力角标**：`L0`…`L4`  
2. **权益角标**：`付费` / `未付费`  
3. **演示 Switch**：「付费权益」——**L2 必须可切换**；用于 `L2 + 付费` 演示

### 2.2 按钮

| 控件 | 有资格 | 无资格 |
|---|---|---|
| 创建 / 查看 HTML | 可点 | L0/L1 不可达 |
| **导出**（PDF） | 可点 | **禁用** + Tooltip「付费用户可导出」+「付费」角标 |

锁态：**不隐藏**导出入口；**不弹假成功**。
