### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 当前未来产业 | 确定 E-33 的产业范围 | `future_industry_code/name`；非指标 | 单选；切换后刷新三项功能并清除旧产业链、链位和领域状态 |
| 当前产业链 | 确定单条产业链 | `industry_chain_code/name`；非指标 | 选项只来自当前产业；一次仅一条；切换后刷新三项功能 |
| 链位画布 | 浏览链位及重点企业数量 | `chain_node_code/name`、`enterprise_count`；正式 metric_id 待 Q047 | 默认选择首个有数据链位；只在画布内部滚动/缩放 |
| 代表企业 | 识别链位代表对象 | `enterprise_code/name`、地区、资质荣誉、档案发布状态 | 最多 3 家；单企业进入画像；CMS 未发布显示档案待维护 |
| 资质荣誉 | 统一展示企业标签 | 系统通用枚举；非页面私有字段 | 外企、国高企、小微、上市、专精特新、小巨人、链主龙头、独角兽、瞪羚 |
| 规模统计 | 判断重点企业结构 | `key_enterprise_count_by_qualification`；`metric_id: null`，Q047 / DEMO | 当前产业 + 当前产业链；国家/省/市三级；多标签重复计数 |
| 领域重点分布 | 判断领域在产业链中的聚集 | `key_enterprise_domain_distribution`；`metric_id: null`，Q047 / DEMO | 跟随当前产业和链；选择领域更新右侧证据 |
| 关键词证据 | 理解领域关联依据 | 论文关键词、专利关键词、来源类型、来源时间、关联领域/链位、关联企业；非聚合指标 | 只展示可公开摘要；无证据不生成映射或排名 |

### 2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 切换未来产业 | 三个区块统一刷新；默认可用产业链；清除旧局部状态 | 不保留旧产业的链位、企业或领域选中态 |
| 切换产业链 | 全景、规模统计、领域统计统一刷新 | 不把多条产业链混成一条全景 |
| 点击链位 | 更新画布选中态和右侧链位详情 | 不直接跳转评估、风险或推荐模块 |
| 点击企业名称/画像 | 打开企业画像并携带来源上下文 | 不以单企业点击触发批量结果页 |
| 点击查看全部 N 家 | 打开只读企业清单浮层 | 不提供勾选、批量加入、导出、评分或风险分析 |
| 切换国家/省/市 | 仅更新规模统计地域层级 | 不改写当前未来产业和产业链 |
| 点击领域/环节/链位 | 更新重点分布选中态及关键词证据摘要 | 不展开无限知识图谱，不自动生成推荐排名 |

### 2.4 全部企业只读浮层

| 内容 | 规则 |
| --- | --- |
| 来源摘要 | 显示当前未来产业、产业链、链位、数据批次和企业数量 |
| 企业行 | 名称、所在地、资质荣誉、公开简介状态、查看画像 |
| 分页 | 仅用于浏览；不改变页面共享上下文 |
| 禁止项 | 无勾选、无批量动作、无导出、无评分、无风险和推荐按钮 |

### 2.5 领域证据态

| 内容 | 规则 |
| --- | --- |
| 重点分布 | 在产业链领域、环节或链位上展示企业数量或结构，正式指标待 Q047 |
| 关键词 | 区分论文关键词与专利关键词；展示规范化词及其关联领域/链位 |
| 证据摘要 | 展示来源类型、标题摘要、公开时间、关联企业；不展示受限全文 |
| 覆盖情况 | 显示已映射企业数/可分析企业数或证据不足说明，正式指标待 Q047 |
| 禁止项 | 不将关键词频次直接解释为竞争力，不生成企业或领域排名 |

### 2.6 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 显示当前产业、默认产业链、默认链位及三项功能 | 浏览或切换产业/产业链 |
| 加载 | 三个区块保留稳定尺寸并显示骨架 | 等待 |
| 无产业链映射 | 显示“当前产业的产业链映射待维护” | 切换产业 |
| 无重点企业 | 链位可见，详情显示“暂无已发布重点企业” | 切换链位或产业链 |
| CMS 档案未发布 | 企业名称和统计可见，简介区显示“档案待维护” | 查看其他企业 |
| 关键词证据不足 | 显示覆盖率或“证据不足”，不生成排名 | 切换领域或查看已有证据 |
| 错误 | 显示错误原因、最近更新时间和重试 | 重试 |
| 无权限 | 显示权限原因，不泄露受限企业档案或算法参数 | 登录/申请权限 |

## 3. 内部评审模式

- 标题旁显示 `TraceInfoIcon(E-33)`；普通业务模式隐藏。
- 重点企业识别显示 Q038/Q039，算法说明与 Q045 保持一致。
- 三项正式统计缺少 `metric_id` 时显示 Q047 与 `DEMO` 状态。
- CMS 档案显示“已发布 / 待维护 / 待审核”来源状态；普通业务模式只消费已发布版本。

## 4. 响应式与视觉约束

- **屏幕层级**：medium；手机端 N/A。
- **设计系统**：`agent-delivery/Design.md`，使用 Arco 控件和共享 ContextBar。
- **产业链画布**：高度控制在 `440–480px`，节点较多时仅画布内部滚动或缩放，页面不随节点数量无限增高。
- **布局**：链位详情固定最多展示 3 家代表企业；统计区块保持明确标题、口径和更新时间。
