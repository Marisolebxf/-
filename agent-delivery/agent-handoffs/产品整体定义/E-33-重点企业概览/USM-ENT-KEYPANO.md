## 模块：E-33 重点企业概览

重点企业概览帮助用户在当前未来产业和当前产业链口径下，理解重点企业位于哪些链位、具有什么资质与规模结构、覆盖哪些产业领域。它完整承接“重点企业全景、重点企业规模统计、重点企业领域统计”三项原始功能，不承担企业查询式复杂筛选、批量对象操作、企业评估、供应链风险、推荐排名或独立导出。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 访客（未登录用户） | E-31 已确认的门户公开信息角色 | 浏览当前产业链中的代表性重点企业和公开基础信息。 |
| 科研人员 | E-31 已确认产品角色；原始需求要求结合论文、专利关键词分析领域分布 | 理解重点企业的产业链位置、资质结构和技术领域覆盖。 |
| 政府科技管理与决策部门 | E-31 已确认产品角色；原始需求以重点企业判断产业发展状况 | 判断当前未来产业及产业链的重点企业基础、地域层级结构和领域聚集情况。 |

> 产品角色不由 `VISIT / INNO / GOV`、L0–L4 或 Mock 用户反推；权限 persona 只用于后续访问映射。

## 用户故事

### US-E33-01 查看重点企业产业链全景

作为科研人员，我想在当前未来产业和当前产业链中查看上游、中游、下游及具体链位的重点企业，以便理解重点企业在全产业链中的位置和代表对象。

### US-E33-02 查看重点企业规模与资质结构

作为政府科技管理与决策部门用户，我想按国家、省、市三级查看重点企业在外企、国高企、小微、上市等资质荣誉维度上的数量与结构，以便判断不同地域层级的重点企业基础。

### US-E33-03 查看重点企业领域在产业链中的分布

作为科研人员，我想查看从重点企业论文、专利中抽取的关键词如何关联到产业链领域、环节和链位，以便识别重点企业技术领域在产业链中的重点分布及其证据。

## 系统通用资质荣誉枚举

企业查询、企业档案、E-33～E-35 及后续业务模块统一引用同一枚举源，不在页面内另建私有列表：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

- 原始需求“高企”统一展示为“国高企”。
- 同一企业可命中多个标签；统计允许多标签重复计数，页面必须说明“各标签数量不可直接相加为企业总数”。
- 内部数据结构保留稳定编码及企业性质、规模、资质、上市状态、成长类型等分类属性；前台统一在“资质荣誉”控件和标签区消费。

## 场景 walkthrough

### 主路径

1. 用户进入企业总览并切换到“重点企业概览”。
2. 页面稳定展示 `科技专题服务 / 当前未来产业 / 当前产业链 / 数据时间或批次`。
3. 用户选择一个未来产业；页面加载该产业可用产业链，默认展示一条产业链。
4. 用户在产业链画布中选择具体链位，右侧查看该链位重点企业摘要和最多 3 家代表企业。
5. 用户展开“查看全部 N 家”，在当前页只读浮层中浏览全部重点企业；点击单个企业进入企业画像。
6. 用户继续查看四项原始统计标签在国家、省、市三级的数量或结构分布。
7. 用户在领域统计中选择领域或链位，查看关键词、论文/专利证据摘要及关联重点企业。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 当前产业无产业链映射 | 保留稳定页面骨架，说明“产业链映射待维护”，内部评审模式显示开放项 | 切换未来产业或返回企业整体概况 |
| 当前链位无重点企业 | 链位保持可见，右侧显示“当前链位暂无已发布重点企业” | 切换链位或产业链 |
| 重点企业识别口径未正式确认 | 业务模式展示当前已发布名单；内部评审模式显示 Q038/Q039 说明 | 查看口径说明，不展示虚构评分 |
| 领域关键词或映射不足 | 显示覆盖率与“证据不足”状态，不用空值生成排名 | 查看已有证据或切换领域 |
| CMS 企业档案未发布 | 统计与链位仍可展示；企业卡片显示“档案待维护”，不展示空白详情 | 浏览其他企业或稍后查看 |
| 加载失败 | 保留区块尺寸并显示错误、重试和更新时间 | 重试 |
| 无访问权限 | 显示权限原因；不泄露未发布档案或内部算法参数 | 登录或申请权限 |

## 验收场景

| 编号 | 可验证结果 |
| --- | --- |
| E33-USM-01 | E-33 三项原始功能均有页面落点，重点企业全景不会挤掉规模统计或领域统计。 |

| E33-USM-06 | 统计数据、算法候选和 CMS 已发布档案来源可区分；未发布或待维护内容不冒充正式数据。 |

## 模块边界与依赖

- 重点企业初始识别口径复用 Q038；内部评审溯源说明复用 Q039；算法描述一致性复用 Q045。
- 企业基础档案、专家说明及描述性关系来自 E-37 企业发展内容管理的已发布结果；E-33 前台不提供编辑、审核或发布入口。
- 供应商/客户关系、断链风险与合作网络深挖属于风险洞察或企业画像，不在 E-33 展开。
- 正式指标、地域层级聚合及关键词到产业链的映射口径由 Q047 闭合；闭合前相应统计标记 `DEMO`。
