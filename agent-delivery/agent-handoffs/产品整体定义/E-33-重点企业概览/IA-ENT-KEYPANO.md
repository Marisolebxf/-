# IA-ENT-KEYPANO

> **模块**：E-33 重点企业概览
> **阶段**：门 1 PDR 输入
> **体验 Owner**：高颖
> **范围真源**：`bid-reference/智慧服务门户系统-要素相关.md` → `1.1.1.1.1.1.1.2 重点企业全景图`

## 1. 模块边界

- **解决的问题**：用户在当前未来产业和产业链中理解重点企业的链位分布、规模与资质结构、领域重点分布。
- **承接内容**：重点企业全景、重点企业规模统计、重点企业领域统计。
- **不承接内容**：复杂查询、高级筛选、企业集合批量操作、企业评估、供应链风险、推荐排名、独立导出和 CMS 编辑。
- **上下文边界**：稳定显示科技专题服务、当前未来产业、当前产业链、数据时间或批次；一次只展示一条产业链。
- **内容责任**：数据和算法提供候选、统计及关键词映射；E-37 CMS 提供已发布企业档案和描述性内容；前台不编辑内容。

## 2. 用户入口与产品角色

| 产品角色 | 入口 | 核心目标 |
| --- | --- | --- |
| 访客（未登录用户） | 企业总览 → 重点企业概览 | 浏览公开的重点企业和产业链位置。 |
| 科研人员 | 企业总览 → 重点企业概览 | 研究重点企业的产业链与领域覆盖。 |
| 政府科技管理与决策部门 | 企业总览 → 重点企业概览 | 判断重点企业基础、地域层级结构和领域聚集情况。 |

## 3. 信息架构

```text
企业分析
└─ 企业总览
   └─ 重点企业概览（E-33）
      ├─ 共享上下文（专题 / 未来产业 / 数据批次）
      ├─ 当前产业链轻量切换
      ├─ 重点企业全景
      │  ├─ 上游 / 中游 / 下游与链位画布
      │  ├─ 链位详情与代表企业
      │  └─ 全部企业只读浮层 / 单企业画像
      ├─ 重点企业规模统计
      │  ├─ 外企 / 国高企 / 小微 / 上市
      │  └─ 国家 / 省 / 市三级结构
      └─ 重点企业领域统计
         ├─ 领域 / 环节 / 链位重点分布
         ├─ 论文与专利关键词映射
         └─ 证据摘要与关联企业
```

## 4. 页面 / Tab 职责

| 节点 | 页面职责 | 路由 / 状态 | 原始需求 / TRACE |
| --- | --- | --- | --- |

## 5. 系统通用资质荣誉枚举

E-33 不定义私有枚举。企业查询、企业档案和所有使用资质荣誉的模块共同引用：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

原始需求“外企、高企、小微、上市”对应统一枚举中的“外企、国高企、小微、上市”。同一企业可多标签命中；统计值不可直接相加为企业总数。

## 6. 跨模块边界

| 来源或去向 | 可携带内容 | 不可携带 / 不可承担内容 |
| --- | --- | --- |
| 企业整体概况 | 当前专题、当前未来产业、数据批次 | 地域列表状态、查询条件、企业集合 |
| 企业画像 | 单个 `enterprise_code`、来源 Tab、未来产业、产业链、链位 | 批量企业集合、评估或风险结论 |
| 企业查询 | 无固定入口；用户通过左侧菜单独立进入 | E-33 不代替高级筛选或保存查询方案 |
| 风险洞察 / 企业评估 / 引育推荐 | 不从 E-33 直接发起 | 不展示风险、评分、排名和推荐动作 |
| E-37 CMS | 消费已审核发布的企业档案和描述性内容 | 前台不出现编辑、审核、发布按钮 |

## 7. 与 bid-reference 差异说明

| 原始功能 | IA 归位 / 重组方式 | 追溯动作 |
| --- | --- | --- |
| 按产业分类展示全产业链重点企业 | 归入当前未来产业 + 当前产业链的单链画布 | TRACE 映射 US-E33-01；旧路由保留兼容 |
| 重点企业规模统计 | 四项原始分类复用系统通用资质荣誉枚举，并增加国家/省/市层级切换 | TRACE 映射 US-E33-02；Q047 管理正式指标 |
| 重点企业领域统计 | 与同一产业链画布建立领域、环节、链位关系，保留论文/专利关键词证据 | TRACE 映射 US-E33-03；Q047 管理映射规则 |
