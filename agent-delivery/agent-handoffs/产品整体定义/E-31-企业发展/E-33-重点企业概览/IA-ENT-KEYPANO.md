# IA-ENT-KEYPANO

> **模块**：E-33 重点企业概览
> **阶段**：门 1 PDR 输入
> **体验 Owner**：高颖
> **范围真源**：`bid-reference/智慧服务门户系统-要素相关.md` → `1.1.1.1.1.1.1.2 重点企业全景图`
> **本轮决策（Q068）**：页内上下文为「当前集群 + 当前 L0」。源需求「重点企业全景图」不改。

## 1. 模块边界

- **解决的问题**：用户围绕当前产业链，沿上游—中游—下游链路理解重点企业对象、国家/省/市三级资质数量分布、领域重点分布。
- **承接内容**：重点企业全景、重点企业规模统计、重点企业领域统计。
- **不承接内容**：复杂查询、高级筛选、企业集合批量操作、企业评估、供应链风险、推荐排名、独立导出和 CMS 编辑。
- **上下文边界**：页面顶部先选产业集群、再选该集群下 L0；一次只展示一条 L0 产业链。无映射走空态。链位是 L0 之下的局部浏览状态，不替代集群/L0 选择。
- **内容责任**：数据和算法提供候选、统计及关键词映射；E-37 CMS 提供已发布企业档案和描述性内容；前台不编辑内容。

## 2. 用户入口与产品角色

| 产品角色 | 入口 | 核心目标 |
| --- | --- | --- |
| 访客（未登录用户） | 企业总览 → 重点企业概览 | 浏览公开的重点企业和产业链位置。 |
| 科研人员 | 企业总览 → 重点企业概览 | 研究重点企业的产业链与领域覆盖。 |
| 政府科技管理与决策部门 | 企业总览 → 重点企业概览 | 判断重点企业基础、地域层级结构和领域聚集情况。 |

## 3. 信息架构

```text
企业分析

   └─ 重点企业概览（E-33）

      └─ 产业链主从联动工作台
         ├─ 左侧：上游 → 中游 → 下游链路导航
         │  └─ 链位名称 / 重点企业数 / 重点领域数

            ├─ 整链重点企业资质分布
            │  ├─ 外企 / 国高企 / 小微 / 上市
            │  └─ 深圳市 / 广东省 / 全国完整口径横向分组条形图

               ├─ 论文与专利关键词映射
               └─ 证据摘要与关联企业
```

## 5. 上下文与联动规则

| 上下文层级 | 控件 / 状态 | 影响范围 | 重置规则 |
| --- | --- | --- | --- |
| 页面共享上下文 | 顶部“当前产业链”选择器 | 左侧完整链路、右侧企业列表、整链统计、领域摘要 | 切换产业链后清除旧链位、页码、领域和证据选中态，默认选中首个有数据链位 |
| 链位局部上下文 | 左侧当前链位 | 右侧企业列表、领域摘要和关键词证据 | 切换链位后企业列表回到第 1 页，清除旧领域/证据选中态 |
| 整链统计上下文 | 当前产业链 | 右侧整链重点企业资质分布 | 切换产业链刷新；点击链位、列表翻页或领域选择均不改写统计口径；图表只读且不筛选企业列表 |
| 列表浏览状态 | 企业列表页码 | 当前链位的企业列表 | 翻页不改变产业链、链位、统计或领域状态 |

## 6. 系统通用资质荣誉枚举

E-33 不定义私有枚举。企业查询、企业档案和所有使用资质荣誉的模块共同引用：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

原始需求“外企、高企、小微、上市”对应统一枚举中的“外企、国高企、小微、上市”。同一企业可多标签命中；统计值不可直接相加为企业总数。

## 7. 跨模块边界

| 来源或去向 | 可携带内容 | 不可携带 / 不可承担内容 |
| --- | --- | --- |
| 企业整体概况 | 当前专题、当前集群、当前 L0、数据时间 | 地域列表状态、查询条件、企业集合 |
| 企业画像 | 单个 `enterprise_code`、来源 Tab、当前集群、当前 L0、链位 | 批量企业集合、评估或风险结论 |
| 企业查询 | 无固定入口；用户通过左侧菜单独立进入 | E-33 不代替高级筛选或保存查询方案 |
| 风险洞察 / 企业评估 / 引育推荐 | 不从 E-33 直接发起 | 不展示风险、评分、排名和推荐动作 |
| E-37 CMS | 消费已审核发布的企业档案和描述性内容 | 前台不出现编辑、审核、发布按钮 |
