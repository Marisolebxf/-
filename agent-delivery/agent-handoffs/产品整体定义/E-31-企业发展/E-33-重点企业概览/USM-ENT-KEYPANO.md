## 模块：E-33 重点企业概览

重点企业概览帮助用户围绕一条当前产业链，沿上游—中游—下游链路理解重点企业位于哪些链位、在国家/省/市三级的资质数量分布、覆盖哪些产业领域。页面采用“左侧链路导航 + 右侧同屏联动工作区”，完整承接“重点企业全景、重点企业规模统计、重点企业领域统计”三项原始功能，不承担企业查询式复杂筛选、批量对象操作、企业评估、供应链风险、推荐排名或独立导出。

## 目标用户角色

> 与 E-31 v0.6 角色口径一致：企业分析业务角色 = 政府 / 园区 / 投资机构（`§1.1.1.2.4.2.3`）；访客仅用于公开浏览。

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府 | §企业分析「面向政府」；原始需求以重点企业判断产业发展状况 | 判断当前集群下所选 L0 产业链的重点企业基础、地域层级结构和领域聚集情况。 |
| 园区 | §企业分析「面向园区」 | 浏览产业链中的代表性重点企业，支撑招商育商对象认知。 |
| 投资机构 | §企业分析「面向投资机构」；领域分布依赖论文/专利关键词证据 | 理解重点企业的产业链位置、资质结构和技术领域覆盖。 |
| 访客（未登录公开浏览） | 展示系统接待场景；公开基础信息 | 浏览当前产业链中的代表性重点企业和公开基础信息。 |

> 产品角色不由 `VISIT / INNO / GOV`、L0–L4 或 Mock 用户反推；权限 persona 只用于后续访问映射。废止「科研人员」正式角色（见 `Q-ENT-ROLE-ALIGN-01`）。

## 用户故事

### US-E33-01 查看重点企业产业链全景

作为投资机构用户，我想在当前集群和当前 L0 产业链中查看上游、中游、下游及具体链位的重点企业，以便理解重点企业在全产业链中的位置和代表对象。

### US-E33-02 查看整链重点企业资质分布

作为政府用户，我想比较当前产业链在深圳市、广东省、全国三级范围内外企、国高企、小微、上市的绝对数量，以便判断不同地域层级的重点企业基础。

### US-E33-03 查看重点企业领域在产业链中的分布

作为投资机构用户，我想查看从重点企业论文、专利中抽取的关键词如何关联到产业链领域、环节和链位，以便识别重点企业技术领域在产业链中的重点分布及其证据。

## 系统通用资质荣誉枚举

企业查询、企业档案、E-33～E-35 及后续业务模块统一引用同一枚举源，不在页面内另建私有列表：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

- 原始需求“高企”统一展示为“国高企”。
- 同一企业可命中多个标签；统计允许多标签重复计数，页面必须说明“各标签数量不可直接相加为企业总数”。
- 内部数据结构保留稳定编码及企业性质、规模、资质、上市状态、成长类型等分类属性；前台统一在“资质荣誉”控件和标签区消费。

## 场景 walkthrough

### 主路径

1. 用户进入企业总览并切换到“重点企业概览”。
2. 页面顶部稳定保留“当前产业链”选择器，一次只展示一条产业链。
3. 用户切换当前产业链；左侧上游—中游—下游链路和右侧全部内容统一刷新，默认选中首个有数据链位。
4. 左侧每个链位只显示链位名称、重点企业数和重点领域数；用户选择链位后，右侧企业列表、领域摘要和论文/专利关键词证据统一联动。
5. 用户在右侧单列企业列表中分页浏览当前链位重点企业；翻页不改变产业链和链位，点击单个企业进入企业画像并携带来源上下文。
6. 用户查看当前产业链整链的“重点企业资质分布”：四项资质按固定顺序排列，每项并列显示深圳市、广东省、全国完整口径的绝对数量；点击链位不改写该统计口径。
7. 用户查看当前链位的领域重点分布、关键词、论文/专利证据摘要及关联企业。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 当前集群无 L0 映射 | 保留稳定页面骨架，说明“无相关产业数据”，内部评审模式显示 Q068 | 切换集群或返回企业整体概况 |
| 当前链位无重点企业 | 链位保持可见，右侧单列列表显示“当前链位暂无已发布重点企业”；整链统计仍可展示 | 切换链位或产业链 |
| 重点企业识别口径未正式确认 | 业务模式展示当前已发布名单；内部评审模式显示 Q038/Q039 说明 | 查看口径说明，不展示虚构评分 |
| 领域关键词或映射不足 | 显示覆盖率与“证据不足”状态，不用空值生成排名 | 查看已有证据或切换领域 |
| CMS 企业档案未发布 | 统计与链位仍可展示；企业列表行显示“档案待维护”，不展示空白详情 | 浏览其他企业或稍后查看 |
| 加载失败 | 保留区块尺寸并显示错误、重试和更新时间 | 重试 |
| 无访问权限 | 显示权限原因；不泄露未发布档案或内部算法参数 | 登录或申请权限 |

## 模块边界与依赖

- 重点企业初始识别口径复用 Q038；内部评审溯源说明复用 Q039；算法描述一致性复用 Q045。
- 企业基础档案、专家说明及描述性关系来自 E-37 企业发展内容管理的已发布结果；E-33 前台不提供编辑、审核或发布入口。
- 供应商/客户关系、断链风险与合作网络深挖属于风险洞察或企业画像，不在 E-33 展开。
- 正式指标、地域层级聚合及关键词到产业链的映射口径由 Q047 闭合；闭合前相应统计标记 `DEMO`。
