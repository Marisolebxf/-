### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 当前产业链 | 确定单条产业链 | `industry_chain_code/name`；非指标 | 页面顶部保留；选项只来自当前产业；一次仅一条；切换后刷新左、右全部内容 |
| 左侧产业链路 | 浏览上游、中游、下游链位及概要 | `chain_node_code/name`、`enterprise_count`、`domain_count`；正式 metric_id 待 Q047 | 纵向单链；节点只显示链位名称、企业数、领域数；默认选择首个有数据链位；链位较多时区域内滚动 |
| 重点企业列表 | 浏览当前链位重点企业 | `enterprise_code/name`、地区、资质荣誉、档案发布状态 | 右侧单列分页；切换产业链或链位回到第 1 页；单企业进入画像；CMS 未发布显示档案待维护 |
| 资质荣誉 | 统一展示企业标签 | 系统通用枚举；非页面私有字段 | 外企、国高企、小微、上市、专精特新、小巨人、链主龙头、独角兽、瞪羚 |
| 整链重点企业资质分布 | 比较不同地域层级的重点企业资质绝对数量 | `key_enterprise_count_by_qualification`；`metric_id: null`，Q047 / DEMO | 当前产业链整链口径；外企/国高企/小微/上市固定顺序；深圳市/广东省/全国完整嵌套值；横向分组条形图；统一绝对数量轴；条形末端固定显示数值；零值显示 `0`；不随链位改写口径 |
| 领域重点分布 | 判断领域在产业链中的聚集 | `key_enterprise_domain_distribution`；`metric_id: null`，Q047 / DEMO | 跟随当前产业链和当前链位；选择领域更新证据 |
| 关键词证据 | 理解领域关联依据 | 论文关键词、专利关键词、来源类型、来源时间、关联领域/链位、关联企业；非聚合指标 | 只展示可公开摘要；无证据不生成映射或排名 |

### 2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 切换产业链 | 左侧完整链路、右侧企业列表、整链统计和领域摘要统一刷新；默认首个有数据链位 | 不把多条产业链混成一条全景；不保留旧链位、页码或领域状态 |
| 点击链位 | 更新左侧选中态；右侧企业列表回到第 1 页，并更新领域摘要和关键词证据 | 不改写整链重点企业资质分布口径；不直接跳转评估、风险或推荐模块 |
| 点击企业名称/画像 | 打开企业画像并携带来源上下文 | 不以单企业点击触发批量结果页 |
| 点击企业列表页码 | 只更新当前链位企业列表 | 不改变当前产业链、链位、统计、领域或证据状态 |
| 阅读/悬浮资质条形 | 固定数值直接可读；悬浮可补充资质、地域和数量说明 | 不点击筛选企业列表，不切换地域口径，不改变产业链、链位、分页、领域或证据状态 |
| 点击领域/环节/链位 | 更新重点分布选中态及关键词证据摘要 | 不展开无限知识图谱，不自动生成推荐排名 |

### 2.4 企业单列列表与分页

| 内容 | 规则 |
| --- | --- |
| 列表标题 | 显示当前产业链、当前链位和企业数量 |
| 企业行 | 单列展示名称、所在地、资质荣誉、公开简介状态、查看画像 |
| 分页 | 仅用于浏览；切换产业链或链位回到第 1 页；翻页不改变其他上下文 |
| 禁止项 | 无勾选、无批量动作、无导出、无评分、无风险和推荐按钮 |

### 2.5 整链重点企业资质分布

> **原始需求 / TRACE**：E-33「重点企业规模统计」/ US-E33-02

| 内容 | 规则 |
| --- | --- |
| 标题 | 固定为“整链重点企业资质分布” |
| 资质维度 | 外企、国高企、小微、上市固定四行，顺序不按数量重排 |
| 地域系列 | 深圳市、广东省、全国；均为完整嵌套范围，不转换为“广东省其他 / 全国其他”增量分段 |
| 图形 | 横向分组条形图；四项资质共用一个绝对数量轴，不堆叠、不按行归一化 |
| 数值 | 每根条形末端固定显示精确数量；零值行保留并显示 `0` |
| 固定说明 | “国家、省、市为嵌套统计范围，各层级数量不可相加。”“同一企业可命中多个资质标签，各资质数量不可相加为企业总数。” |
| 交互 | 只读；Tooltip 可辅助说明，点击不联动当前链位企业列表 |

### 2.6 领域证据态

| 内容 | 规则 |
| --- | --- |
| 重点分布 | 在产业链领域、环节或链位上展示企业数量或结构，正式指标待 Q047 |
| 关键词 | 区分论文关键词与专利关键词；展示规范化词及其关联领域/链位 |
| 证据摘要 | 展示来源类型、标题摘要、公开时间、关联企业；不展示受限全文 |
| 覆盖情况 | 显示已映射企业数/可分析企业数或证据不足说明，正式指标待 Q047 |
| 禁止项 | 不将关键词频次直接解释为竞争力，不生成企业或领域排名 |

### 2.7 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 显示当前产业、默认产业链、默认链位及三项功能 | 浏览或切换产业/产业链 |
| 加载 | 三个区块保留稳定尺寸并显示骨架 | 等待 |
| 无产业链映射 | 显示“当前产业的产业链映射待维护” | 切换产业 |
| 无重点企业 | 链位可见，详情显示“暂无已发布重点企业” | 切换链位或产业链 |
| 某项资质为零 | 保留该资质及深圳市、广东省、全国三组位置，条形末端显示 `0` | 继续比较其他资质；不将零值误作缺失数据 |
| CMS 档案未发布 | 企业名称和统计可见，简介区显示“档案待维护” | 查看其他企业 |
| 关键词证据不足 | 显示覆盖率或“证据不足”，不生成排名 | 切换领域或查看已有证据 |
| 错误 | 显示错误原因、最近更新时间和重试 | 重试 |
| 无权限 | 显示权限原因，不泄露受限企业档案或算法参数 | 登录/申请权限 |

## 3. 内部评审模式

- 标题旁显示 `TraceInfoIcon(E-33)`；普通业务模式隐藏。
- 重点企业识别显示 Q038/Q039，算法说明与 Q045 保持一致。
- 三项正式统计缺少 `metric_id` 时显示 Q047 与 `DEMO` 状态。
- CMS 档案显示“已发布 / 待维护 / 待审核”来源状态；普通业务模式只消费已发布版本。

## 4. 响应式与视觉约束

- **屏幕层级**：medium；手机端 N/A。
- **设计系统**：`agent-delivery/Design.md`，使用 Arco 控件和共享 ContextBar。
- **主工作区**：左侧链路约占 `28%–32%`，右侧联动工作区约占 `68%–72%`；链位较多时仅左侧区域内滚动，页面不随节点数量无限增高。
- **企业列表**：右侧单列展示并支持分页，不在左侧链位节点重复显示企业名称。
- **统计区块**：标题固定为“整链重点企业资质分布”；横向分组条形图使用统一绝对数量轴并固定显示数值；领域区块显式标注“当前链位”口径。
