#### 2.2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 全球汇总 KPI | 了解全局规模 | `M_ENT_TOTAL_COUNT`、`M_ENT_RESEARCHER_COUNT`、`M_ENT_FUTURE_INDUSTRY_COVERAGE_COUNT` | 文案标“全球”；库内全量，不受下方选择器影响。 |
| 产业数量排名 | 比较产业规模 | 各未来产业企业数量 | 按企业数量降序；默认 Top10，超过 10 个时显示“展开全部”，展开后显示全部并可“收起”；第 1/2/3 名使用设计系统金/银/铜，第 4 名起统一普通排名色；纵轴仅显示产业名称，不重复显示排名数字；支持单选与最多两产业对比。 |
| 趋势图 | 观察产业变化 | 所选产业历年企业数量 | 少于 2 个可比时间点隐藏；内部评审 Mock 必须标识。 |
| 地域选择器 | 选择局部地域 | 全球 / 全国 / 区域 / 深圳 | 默认深圳，仅作用于企业分布卡片；复用科技信息展示系统“科技全域态势 / 科创要素”Tab 的地域级联交互逻辑，并按企业口径收敛为四级。 |
| 企业分布视图 | 查看空间分布 | 当前快照聚合数据 | 热力地图 / 列表可切换；地图与选择器同步；地图画布高度跟随并填满地图内容容器；列表固定展示地域、企业数、科研人员数、覆盖未来产业数和操作列；复用“科技全域态势 / 科创要素”Tab 的 `SharedRegionMap` 地图能力。 |
| 地图悬浮控件 | 操作地图与热力层 | 左侧地图工具栏、右侧“显示热力” | 两组控件采用相同顶部内边距并保持顶边对齐；不得因地图高度或容器变化产生上下错位。 |

#### 2.2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 选择产业 | 更新趋势；选择第二个产业后展示对比趋势 | 产生企业集合、列表下钻或改变全球 KPI。 |
| 选择第三个产业 | 阻止新增选择并提示“最多对比两个产业” | 静默覆盖已有选择。 |
| 点击 `展开全部` / `收起` | 在当前排名卡片内切换全部产业与 Top10；展开时随产业数量增加图表高度 | 改变排名顺序、筛选产业数据或打开新页面 / 抽屉。 |
| 操作地域选择器 | 更新本卡片地图 / 列表 | 改变顶部 KPI、产业排名或趋势选择。 |
| 切换地图 / 列表 | 保留当前地域与趋势产业选择 | 丢失卡片内局部状态。 |
| 地图卡片尺寸变化 | 地图画布按容器高度同步铺满，左右悬浮控件保持同一顶部基线 | 保留画布下方空白、裁切地图或让热力开关独立下沉。 |
| 点击列表字段 | 无跳转、无地图联动，仅保留表格展示/排序语义 | 地域、企业数、科研人员数、覆盖未来产业数字段直接触发查询或地图高亮。 |
| 点击 `在地图中查看` | 切换到地图视图，高亮并脉冲闪烁当前地域点位 | 改变顶部 KPI 或进入企业查询。 |
| 点击 `进入企业查询` | 进入智能搜索，将当前地域作为智能输入自动解析为筛选条件，并自动展示结果列表 | 在本页打开企业详情或直接发起分析任务。 |

#### 2.2.4 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 默认深圳地域、热力地图视图和全局汇总 KPI | 选择地域、视图或产业。 |
| 产业数超过 10 | 默认仅展示按企业数量降序的 Top10，并提供“展开全部” | 展开查看全部；点击“收起”恢复 Top10。 |
| 趋势数据不足 | 隐藏趋势图，产业排名占满对应空间 | 保持产业选择；内部评审可查看 Mock 示意。 |
| 科研人数未接入 | 顶部全球企业科研人数 KPI 展示“数据待接入” | 继续查看其他统计。 |
| 地图加载 / 失败 | 保持容器尺寸，展示骨架 / 可重试错误反馈 | 等待或重试。 |
| 地域无数据 | 当前地图或列表内展示空态，不影响全局汇总 | 切换地域或视图。 |

| 评审辅助说明 | E-32 挂载位置 | 关闭评审模式后的处理 |
| --- | --- | --- |
| 模式开启 / 关闭 | 右上角用户 / 角色切换下拉面板的全局“内部评审模式”开关 | 关闭后全部评审辅助信息隐藏；业务页面保持可用。 |

## 3. 响应式与视觉约束

- **屏幕层级**：`medium_1440_1920` / Track-MS。
- **设计系统**：以 `agent-delivery/Design.md` 为权威来源；遵循其科技专题服务系统浅蓝白工作台、Arco 控件与通用四级地域选择器规则。
- **复用边界**：地图与地域级联的行为、缩放、复位、热力和列表回跳复用 `repos/demo-ui-science` 的“科技全域态势 / 科创要素”实现；目标 demo 仍使用 Arco 控件，不直接引入其 Ant Design 级联选择器或图标控件。
- **地图高度**：当前中屏 Frame 的地图内容区最小高度为 `420px`，地图画布使用 `100%` 高度填满该区域；后续容器高度变化时由父容器统一决定，不在地图子组件形成第二套固定高度。
- **地图控件对齐**：左侧工具栏与右侧“显示热力”均使用内容区顶部 `16px` 内边距，顶边对齐。
- **终端范围**：本线框仅覆盖中屏（PC 工作台）。小屏定义为手机端；科技专题服务系统不做手机端，因此不输出小屏裁剪、移动导航或移动端交互方案。
- **数据表达**：不展示数据批次、上期对比、同比/环比、趋势箭头或比较说明；Mock 数据仅在评审模式按通用 `🧪` 规则标识。
