### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 共享上下文 | 确认当前专题和数据时间 | `topic_service`、`data_time` | 产业不只作为隐含共享上下文，必须在 E-34 Tab 内显式落为控件 |
| 未来产业选择器 | 确认明星企业所属产业并切换浏览范围 | `future_industry_code/name`、产业 `sort_order/status` | 始终显示；选项为共享字典中的前台有效未来产业，0 家产业仍保留；URL 有效产业优先，否则按继承/默认规则恢复 |
| 明星企业选择器 | 在当前产业已发布名单内选择介绍对象 | `enterprise_code/name`、`selection_tag`、`sort_order`、`publish_status` | 0 家禁用并进入空态；1 家隐藏选择器；2 家及以上显示可搜索下拉框和“共 N 家”；支持名称/入选标签检索；默认选中 `sort_order` 第一家 |
| 明星企业首屏 | 理解当前展示对象及其代表性 | `enterprise_code/name/summary`、`selection_reason`、`standard_name/version`、`data_time` | 当前企业同步到 URL；只允许选择当前产业已发布名单，不支持名单外自由选企或随机换一换 |
| 查看入选标准 | 理解共用标准 | 适用产业、候选范围、标准名称/版本、已确认维度、更新时间 | 不展示权重、内部阈值、排名或敏感证据 |
| 资质荣誉 | 识别企业公开资质 | 系统通用枚举 | 复用企业查询/档案；多标签展示，不推导评分 |
| 产品功能全景 | 理解多个核心产品及当前产品的产业影响 | `product_id/product_name/product_summary/impact_summary/sort_order/publish_status`；`product_module_id/module_name/module_summary`；`scenario_refs/case_refs/media_refs`；内容字段非统计指标 | 产品为 `0..N`；默认选择已发布产品 `sort_order` 第一项；中屏每页最多 3 个，超过 3 个手动非循环翻页；选择产品后联动其功能模块、场景、案例和媒体 |
| 产品分页 | 在有限宽度中浏览全部产品 | `product_page`、当前页/总页数、上一页/下一页 | 1~3 个隐藏；4 个及以上显示；首尾页禁用相应按钮；页码为局部状态，不写入 URL |
| 媒体内容 | 直观理解当前产品和技术 | `product_id/media_id/media_type/title/cover/url/publish_status/source` | 支持视频、3D、案例、操作演示；只消费当前产品已发布关联资源 |
| 技术优势 | 理解公开技术基础 | `patent_count`、`rd_investment_ratio`：`metric_id: null`，Q048 / DEMO；核心技术、原理、成果为内容字段 | 量化指标显示对应数据时间；不转化为评分排名 |
| 团队实力 | 理解核心成员、成员画像与人才结构 | `team_member_id/name/avatar_url/title/profile_summary/professional_domains/industry_achievements/leading_projects/external_profile_url/sort_order/publish_status/portrait_authorization_status/external_link_authorization_status`；团队成果；`scientist_talent_ratio`：`metric_id: null`，Q048 / DEMO | 位于技术优势下方且独占一行；默认选中已发布成员 `sort_order` 第一位；人物照片与外链还须授权有效；字段模型与接口由 Q041 闭合 |
| 产业生态图谱 | 理解合作网络 | 企业节点、关系类型、关系说明、来源时间；Q040 / DEMO | 默认聚焦当前企业，只读浏览；点击节点显示关系摘要 |
| 发展历程 | 理解成长脉络 | 事件时间、标题、摘要、公开来源；内容字段 | CMS 正式内容优先；演示可用开放官网事实摘要并标 DEMO/来源 |
| 公开口碑 | 查看公开评价主题 | 主题词、来源范围、时间；内容字段 | 仅展示已发布摘要，不展示未经授权原始评价或生成满意度评分 |

### 2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 切换未来产业 | 更新 `future_industry_code`，刷新明星企业名单，按 `sort_order` 选择第一家并更新 `enterprise_code`，清除旧企业状态并回到首屏 | 不保留旧企业内容，不跨产业混排，不隐藏 0 家产业 |
| 搜索明星企业 | 仅按当前产业已发布名单中的企业名称或入选标签过滤候选项 | 不查询全库企业，不按用户行为个性化推荐，不把标签解释为评分 |
| 选择明星企业 | 更新 `enterprise_code`，清除旧企业局部状态，刷新全部内容区并返回首屏 | 不保留旧企业内容，不生成排名或评分 |
| 点击查看入选标准 | 打开只读浮层/抽屉 | 不暴露权重、阈值、企业排名或敏感证据 |
| 点击产品卡 | 选中对应 `product_id`，显示明确选中态并原位更新功能模块/产品架构、场景、案例、影响摘要和媒体；关闭旧产品媒体层，重置旧 `product_module_id` | 不改变企业或 URL，不触发企业查询或添加对比篮，不混用其他产品子内容 |
| 点击产品上一页/下一页 | 每次移动 1 个产品页，每页最多 3 个；选中目标页 `sort_order` 第一项并同步当前产品详情；首尾页禁用相应按钮，显示当前页/总页数 | 不循环、不自动轮播、不用整页横向滚动承载产品溢出，不保留不可见的旧产品选中态 |
| 键盘操作产品区 | 产品卡可聚焦并用 Enter/Space 选择；翻页控件使用按钮语义；页码变化和当前产品名称通过可访问状态播报 | 不把悬停作为唯一入口，不抢占页面滚动 |
| 点击当前产品功能模块 | 更新 `product_module_id` 并展开对应已发布模块详情；未配置模块时显示局部空态 | 不从其他产品拼接功能模块，不改变 `product_id` |
| 点击视频/3D/案例 | 仅打开当前产品的已发布关联媒体；失败显示资源状态 | 不自动播放失效资源，不读取 CMS 草稿，不回退到其他产品媒体 |
| 点击团队成员卡 | 选中对应 `team_member_id`，同步替换当前人物照片、姓名、职务/领域、画像摘要、专业领域、行业成就、主导项目及外部主页入口；成员卡选中态清晰可见 | 不改变企业选择，不刷新整页，不混入未发布成员 |
| 点击上一位/下一位 | 按 CMS `sort_order` 循环切换成员；少于 2 位时隐藏切换控件 | 不自动轮播，不因图片加载失败跳过成员 |
| 键盘操作团队轮播 | 成员卡可聚焦并用 Enter/Space 选择；聚焦轮播后左右方向键切换；切换后将当前成员姓名通过可访问状态播报 | 不抢占页面滚动，不把仅悬停作为唯一入口 |
| 点击“了解更多” | 仅当外部人物主页已发布且授权有效时，在新窗口打开明确目标链接 | 不使用空链接、搜索结果页或前端拼接 URL，不泄露后台字段 |
| 点击生态节点或关系 | 展示合作主体、关系类型、公开说明和来源时间 | 不自动生成供应链风险、中心性排名或推荐结论 |
| 点击企业名称 | 进入统一企业画像并携带来源 `E-34` | 不在本页复制画像全部能力 |

### 2.4 入选标准只读浮层

| 内容 | 展示规则 |
| --- | --- |
| 适用产业 | 当前未来产业名称与编码 |
| 候选范围 | 展示范围摘要；未确认时写“候选范围待配置” |
| 标准信息 | 标准名称、版本、已确认维度、更新时间 |
| 企业入选理由 | 展示本企业匹配共用标准的公开亮点与证据摘要 |
| 禁止项 | 不展示权重、内部阈值、排名、敏感原始证据，不允许页面内修改 |

### 2.5 产品功能全景多产品规则

| 产品数量 / 操作 | 展示与状态规则 |
| --- | --- |
| 0 个已发布产品 | 显示“核心产品待完善”业务空态；不展示空产品卡、分页和媒体入口。 |
| 1~3 个已发布产品 | 按 `sort_order` 单行展示全部产品，默认选中第一项；隐藏分页控件。 |
| 4 个及以上已发布产品 | 每页最多 3 个；标题右侧显示上一页、下一页和当前页/总页数；手动、非循环翻页，翻页后选中目标页 `sort_order` 第一项，首尾页禁用相应按钮。 |
| 选择产品 | 设置局部 `product_id`，联动当前产品功能模块、场景、案例、影响摘要与媒体；当前选中产品始终位于可见产品页。 |
| 切换产品 | 关闭上一产品媒体查看层，将 `product_module_id` 重置为新产品第一项或未展开态；不更新 URL。 |
| 切换企业 | `product_page` 重置为 1，`product_id` 重置为新企业已发布产品 `sort_order` 第一项，同时清除旧企业产品子状态。 |

- 翻页同时选择目标页 `sort_order` 第一项并更新详情，确保卡片选中态与下方详情始终一致；更新前关闭旧媒体层并重置旧模块状态。
- 产品卡区不自动轮播，不循环翻页，不使用自由横向拖动或整页横向滚动；产品超过 3 个的事实通过页码明确呈现。
- 产品字段、排序、发布状态和子内容关联由 Q041 闭合；前端不得按热度、点击量或影响力自行重排。

### 2.6 媒体双模式规则

| 模式 | 视频 / 3D / 案例 / 操作演示表现 |
| --- | --- |
| 内部评审模式 | 使用占位图，展示媒体类型、字段、来源、CMS 发布状态、接口依赖和 DEMO 标识，便于评审数据闭环。 |
| 非评审演示模式 | 模拟真实封面、播放、3D 旋转或案例浏览效果；明确标注演示内容，不宣称来自 CMS 正式发布。 |
| 正式发布态 | 只加载 CMS 已发布资源；草稿、失效和无授权资源不得对外展示。 |

### 2.7 团队模块双模式与布局规则

| 模式 | 团队实力多维展示 |
| --- | --- |
| 内部评审模式（按钮开启） | 模块仍位于技术优势下方；优先展示成员字段、数据来源、CMS 发布状态、人物照片授权、外链授权、Q041 及缺失项，可使用紧凑表格/字段卡，不以展示型视觉掩盖问题。 |
| 非评审展示模式（按钮关闭） | 使用本线框的全宽杂志式轮播：当前成员大图 + 人员画像正文 + 其他成员视觉卡 + 上一位/下一位；隐藏评审说明、字段名、来源状态和 Q 编号。演示数据仍按现有规则标识 DEMO，正式数据不显示 DEMO 标识。 |
| 正式发布态 | 沿用非评审展示布局，但只呈现 CMS 已发布且授权有效的成员信息；不得使用截图人物、虚构履历或未授权照片替代正式数据。 |

- 截图只约束信息层级、横向构图和切换方式，不复刻其品牌红色、人物素材或文字内容。
- “人员画像”是当前页面内的公开成员介绍，不新增独立人员画像路由。
- 当前成员切换是模块局部状态，不写入 URL；切换企业后重置为该企业 `sort_order` 第一位已发布成员。

### 2.8 发展历程演示规则

- 正式态以 CMS 已发布事件为准。
- 演示态可选用开放企业官网的公开事实，例如华为官网企业信息中的发展历程，进行摘要改写和来源标注。
- 不复制官网长文或受限媒体，不把开放网页事实写成 CMS 已审核内容。

### 2.9 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 默认 | 展示固定企业首屏与已发布四区内容 | 浏览区块或查看标准 |
| 加载 | 首屏和各内容区使用稳定骨架，避免布局跳变 | 等待 |
| 产业加载 | 产业选择器保留宽度并显示加载态；企业选择器暂时禁用 | 等待产业字典与当前产业恢复 |
| URL 产业编码无效 | 回退 E-31 继承产业或字典 `sort_order` 第一项，替换 URL 后加载该产业名单 | 浏览默认产业或重新选择 |
| 明星企业未配置 | 显示“本产业明星企业待配置”及返回入口 | 返回概况或切换产业 |
| 仅 1 家明星企业 | 隐藏选择器，直接展示企业并显示“本产业共 1 家明星企业” | 浏览企业介绍 |
| 多家明星企业 | 显示可搜索选择器、候选项和“共 N 家” | 选择企业或浏览默认企业 |
| URL 企业编码无效 | 回退到当前产业 `sort_order` 第一家并替换 URL；无候选企业则进入空态 | 浏览默认企业或切换产业 |
| 标准待配置 | 首屏保留企业与内容，标准位置显示待配置 | 浏览公开内容 |
| 名单条目/基础介绍未发布 | 企业不进入前台候选列表，草稿不对外展示 | 选择其他已发布企业 |
| CMS 其他内容部分缺失 | 缺失区块显示业务空态；已有区块正常展示 | 浏览其他已发布区块 |
| 无已发布产品 | 产品区显示“核心产品待完善”，隐藏产品卡、分页和媒体入口 | 继续浏览技术优势 |

| 产品子内容部分缺失 | 保留产品卡与选中态，只渲染已发布模块、场景、案例和媒体；缺失位置使用局部空态 | 切换产品或继续浏览 |
| 核心团队未发布 | 团队模块显示“核心团队资料待完善”，不生成成员卡或虚构履历 | 继续浏览产业生态 |

## 3. 内部评审模式

- 标出固定明星企业表、标准版本和入选理由的字段来源及 Q048。
- 专利数、研发投入占比、人才比例没有正式 `metric_id` 时显示 DEMO/Q048。
- CMS 产品主数据、排序、功能模块/场景/案例/媒体关联及团队内容显示字段、发布状态与 Q041；草稿不可冒充正式内容。
- 团队成员逐项显示人物照片授权与外部人物主页授权；未闭环时不得以截图或生成素材作为正式人物事实。
- 生态图谱显示 Q040、关系来源和数据时间，不生成风险结论。
- 系统通用资质荣誉枚举在本页只读复用，不允许页面私有扩展。

## 4. 响应式与视觉约束

- **屏幕层级**：medium；PC 门户工作台，不建设手机端。
- **布局**：内容纵向叙事，产品全景优先；产品卡区中屏固定最多 3 列并保持卡片等高，分页控件位于标题右侧；技术优势独占一行，团队实力紧随其后独占一行；生态图谱保持可读固定高度。
- **设计系统**：遵循 `Design.md` 和 Arco 公共组件；媒体容器使用统一宽高比与加载/错误状态。
- **企业标识**：遵循 `Design.md` §1.1，不展示企业 Logo、简称首字或色块替代标识；以企业名称和业务字段识别对象。
- **团队桌面布局**：宽中屏按“当前成员照片约 22% / 画像正文约 36% / 其他成员约 42%”组织；成员照片统一纵向比例并避免裁切头部，切换不改变模块总高度。
- **裁剪规则**：窄中屏时产品卡仍使用受控分页并按可用宽度降为 1~2 列，不改为自由横向拖动；团队改为“当前成员照片 + 画像正文”上层、横向可滚动成员卡下层；不整页横向滚动。图谱和时间轴保持局部交互。
