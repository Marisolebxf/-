# IA-ENT-STAR

> **模块**：E-34 明星企业介绍
> **阶段**：门 1 PDR 输入
> **体验 Owner**：高颖
> **范围真源**：`bid-reference/智慧服务门户系统-要素相关.md` → `1.1.1.1.1.1.1.3 明星企业介绍`
> **验收细化**：`验收文档/企业要素需求规格说明书SRS(v1).md` → `FR-04 明星企业介绍（E-34）`

## 1. 模块边界

- **解决的问题**：用户先选集群再选 L0，再从该 L0 已发布的明星企业名单中选择一家代表企业，理解其为何入选，以及其产品、技术、团队和产业生态优势。旧 `future_industry_code` 只读兼容（Q068 / P5）。
- **承接内容**：产品功能全景图、技术优势可视化、团队实力多维展示、产业生态图谱。其中团队实力承接原文“核心团队轮播”，每位成员展示专业领域、行业成就、主导项目，并可在具备已发布链接时进入外部人物主页（原文为 LinkedIn）。
- **会议补充**：基础量化信息、视频/3D/案例等媒体、企业发展历程、公开口碑及合作网络作为原四区的内容深化。
- **不承接内容**：全库企业查询、名单外自由选企、随机换一换、跨产业混排、企业评分排名、竞争力评估、供应链风险、招引培育结论、CMS 编辑与内容发布。
- **内容责任**：数据侧提供固定企业与基础指标；CMS 提供已发布描述性/媒体内容；图数据库提供关系；前台只读消费。

## 2. 用户入口与产品角色

| 产品角色 | 入口 | 核心目标 |
| --- | --- | --- |
| 访客（未登录用户） | 企业总览 → 明星企业介绍 | 直观了解代表企业产品、故事及产业影响。 |
| 科研人员 | 企业总览 → 明星企业介绍 | 查看技术成果、专利、研发与团队公开信息。 |
| 政府科技管理与决策部门 | 企业总览 → 明星企业介绍 | 理解固定代表企业入选依据及产业带动作用。 |

## 3. 信息架构

```text
企业总览
└─ 明星企业介绍（E-34）
   ├─ 产业与企业两级选择
   │  ├─ 未来产业选择：显示当前产业名称，可切换有效未来产业
   │  ├─ 产业切换：刷新本产业名单、总数与详情，清除旧企业状态
   │  └─ URL 状态：`future_industry_code` + `enterprise_code`
   ├─ 明星企业名单选择（当前产业内）
   │  ├─ 0 家：业务空态
   │  ├─ 1 家：直接展示，不显示选择器
   │  └─ 2 家及以上：可按企业名称或入选标签搜索 / 共 N 家 / `sort_order` 第一家默认选中
   ├─ 明星企业首屏
   │  ├─ 企业名称、简介、资质荣誉
   │  ├─ 入选理由、标准版本、数据时间
   │  └─ 查看入选标准 / 进入企业画像
   ├─ 产品功能全景
   │  ├─ 已发布产品集合：`0..N`，按 `sort_order` 排序
   │  ├─ 产品选择：中屏首屏最多 3 张；超过 3 张时手动上一页 / 下一页
   │  ├─ 当前产品：功能模块 / 产品架构、应用场景与行业案例
   │  └─ 当前产品关联媒体：视频 / 3D 模型 / 操作演示
   ├─ 技术优势可视化
   │  ├─ 专利数、研发投入占比
   │  ├─ 核心技术与技术原理
   │  └─ 科研成果
   ├─ 团队实力多维展示
   │  ├─ 位置：技术优势可视化下方的独立全宽模块
   │  ├─ 当前成员：人物照片、姓名、职务 / 领域、人物画像摘要
   │  ├─ 人员画像：专业领域、行业成就、主导项目
   │  ├─ 成员切换：成员缩略卡 + 上一位 / 下一位
   │  ├─ 外部人物主页：仅在 CMS 已发布且授权有效时展示
   │  └─ 团队概况：科学家 / 人才比例、团队成果
   └─ 产业生态与企业故事
      ├─ 上下游 / 供应链 / 战略合作关系
      ├─ 发展历程时间轴
      └─ 公开口碑摘要或词云
```

## 4. 页面 / Tab 职责

| 节点 | 页面职责 | 路由 / 状态 | 原始需求 / TRACE |
| --- | --- | --- | --- |
| 明星企业介绍 | 组织“集群 → L0 → 固定明星企业 → 单企业门户介绍”浏览 | `/enterprise-center/overview?tab=star-enterprises`；产业态追加 `cluster_id` + `industry_id`；旧 `future_industry_code` 只读兼容；选中态同时追加 `enterprise_code={code}` | E-34 / US-E34-01~04 |
| 集群与 L0 选择 | 显示当前集群与当前 L0，并允许在有效范围内切换 | URL 有效 `cluster_id`/`industry_id` 优先；否则继承 E-31；切换重置企业态；无映射空态 | US-E34-01 |
| 明星企业名单选择 | 在当前产业已发布名单内选择介绍对象 | 0 家 / 1 家 / 多家按企业名称或入选标签可搜索态 | US-E34-01 |
| 明星企业首屏 | 解释当前展示对象及其入选原因 | 默认态 / 标准待配置态 / 无效编码降级态 | US-E34-01 |
| 产品功能全景 | 在 `0..N` 个已发布产品中选择当前产品，查看其功能模块、场景、案例和关联媒体 | 无产品 / 1~3 个产品 / 4 个及以上分页 / 产品选中 / 媒体可用、缺失或失败态；`product_id`、`product_page` 为模块局部状态，不写入 URL | US-E34-02 |
| 技术优势可视化 | 展示公开技术指标、原理和成果 | 正式指标/DEMO态 | US-E34-03 |
| 团队实力多维展示 | 在技术优势下方展示 CMS 已发布核心成员轮播、当前成员人员画像、人才结构与团队成果 | 默认成员/成员切换/部分资料/未发布态；内部评审与非评审展示模式 | US-E34-03 |
| 产业生态与企业故事 | 展示只读合作关系、历程和口碑 | 节点选中/关系不足态 | US-E34-04 |

## 5. 系统通用资质荣誉

明星企业首屏统一消费企业查询/企业档案的资质荣誉枚举：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

页面不建立另一套明星企业标签；“高企”规范为“国高企”。资质是企业事实，不直接作为页面可见评分。

## 7. 与 bid-reference 差异说明

| 原始功能 | IA 归位 / 重组方式 | 追溯动作 |
| --- | --- | --- |
| 产品功能全景图 | 产品功能全景区；产品为 `0..N` 个已发布内容，中屏每页最多展示 3 个，超过 3 个使用非循环手动翻页；选择产品后联动其功能模块、场景、案例与媒体，不自动轮播 | TRACE 映射 US-E34-02 / Q041；属于原功能的多产品交互细化，不新增验收叶子 |
| 技术优势可视化 | 技术优势区；基础指标与内容字段分开治理 | TRACE 映射 US-E34-03 / Q048 |
| 团队实力多维展示 | 团队实力区置于技术优势下方；按原文落为“当前成员画像 + 成员切换”的全宽轮播，只消费 CMS 已发布且具备公开授权的内容 | TRACE 映射 US-E34-03 / Q041；截图仅作为布局参考，不作为人物事实或内容来源 |
| 产业生态图谱 | 产业生态与企业故事区；关系可点详情但不做风险分析 | TRACE 映射 US-E34-04 / Q040 |
| 发展历程、口碑 | 归入企业故事辅助内容，不作为新增验收叶子 | TRACE 记录会议/CMS 来源 |
| SRS FR-04 列表页“产业 / 标签筛选” | 当前 IA 将独立列表页与详情页合并进企业总览 E-34 Tab：产业落为显式一级选择；标签落为当前产业企业候选的检索维度；选择后直接刷新同页详情 | TRACE 映射 US-E34-01；保留输入能力，不新增验收叶子 |
