## 模块：E-34 明星企业介绍

明星企业介绍面向门户浏览场景，先显式展示并允许切换产业集群及该集群下 L0，再在该 L0 固定运营名单中展示 `0..N` 家明星企业；存在多家时允许用户按企业名称或入选标签检索并选择当前介绍对象，解释其入选理由，并通过产品功能全景、技术优势、团队实力和产业生态四个区块呈现其产业带动作用。页面不承担全库企业查询、名单外自由选企、随机换一换、跨产业混排、企业评分排名、风险诊断或招引培育结论。

## 目标用户角色

> 与 E-31 v0.6 角色口径一致。本页含门户公开介绍，故保留访客（接待场景）。

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府 | §企业分析「面向政府」；强调产业带头作用 | 理解代表企业的入选依据、产业贡献和合作生态。 |
| 园区 | §企业分析「面向园区」 | 浏览产业代表企业公开介绍，支撑招商语境认知。 |
| 投资机构 | §企业分析「面向投资机构」；技术优势与团队实力 | 查看公开技术成果、专利及人才团队信息，理解企业技术基础。 |
| 访客（未登录公开浏览） | 展示系统接待场景；原始需求为企业重点介绍 | 快速理解当前产业代表企业的产品、技术、团队和生态影响。 |

## 用户故事

### US-E34-01 理解代表企业及其入选理由

作为政府用户，我想明确当前明星企业所属的集群与 L0，并能切换后在其已发布名单中选择介绍对象、查看入选理由和适用标准版本，以便理解该企业为何能作为该产业代表被介绍。

### US-E34-02 查看产品功能全景

作为访客，我想在明星企业已发布的多个核心产品之间清晰翻页和选择，并联动查看当前产品的功能模块、应用场景、行业案例和公开媒体内容，以便直观理解不同产品的能力构成及产业影响。

### US-E34-03 理解技术优势与团队实力

作为投资机构用户，我想在技术优势之后切换查看不同核心成员的公开人员画像，包括专业领域、行业成就和主导项目，以便理解企业技术能力背后的团队构成与代表人物。

### US-E34-04 浏览产业生态与企业故事

作为访客，我想浏览企业上下游合作网络、发展历程和公开口碑摘要，以便理解企业在产业生态中的位置及成长脉络。

## 系统通用资质荣誉枚举

本模块不建立页面私有资质枚举，统一消费企业查询/企业档案的系统通用枚举：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

原始数据中的“高企”统一展示为“国高企”。同一企业允许多标签命中；标签用于事实展示，不直接推导明星企业评分或排名。

## 场景 walkthrough

### 主路径

1. 用户从企业总览切换到“明星企业介绍”，Tab 内显式展示“未来产业”选择器、当前产业名称和数据时间；用户不需要返回其他 Tab 才能确认明星企业所属产业。
2. 系统优先恢复 URL `future_industry_code`；仅有 `enterprise_code` 时由已发布名单反查所属产业；否则继承 E-31 当前产业，仍无上下文时默认共享未来产业字典 `sort_order` 第一项。
3. 用户可切换有效未来产业。系统写入 `future_industry_code`，读取该产业已发布的固定明星企业名单，并按 CMS `sort_order` 选择第一家作为默认企业；名单条目和基础介绍未发布的企业不进入前台名单。
4. 当前产业只有 1 家时直接展示且隐藏企业选择器；有 2 家及以上时展示可搜索下拉框、“{产业名称} · 共 N 家明星企业”，候选项包含企业名称和一句入选标签，并支持按企业名称或入选标签检索。
5. 当前企业写入 URL `enterprise_code`。用户选择另一家企业后，系统更新 URL、清除旧企业局部状态、刷新详情并返回明星企业首屏。
6. 首屏展示企业名称、所属未来产业、公开基础档案、资质荣誉、入选理由、标准版本和数据时间。用户点击“查看入选标准”，只读查看适用产业、候选范围、标准名称/版本、已确认维度和更新时间；不展示权重、内部阈值、排名或敏感原始证据。
7. 用户向下进入产品功能全景。系统按 CMS `sort_order` 展示该企业 `0..N` 个已发布产品，默认选中第一项；中屏每页最多展示 3 个产品，1~3 个不显示分页控件，4 个及以上显示上一页、下一页和当前页/总页数。
8. 用户点击产品卡或通过键盘选择产品后，页面显示明确选中态，并原位更新当前产品的功能模块/产品架构、应用场景、行业案例、公开影响摘要及关联视频、3D 模型或操作演示。切换产品会关闭旧媒体层并重置旧功能模块状态；产品选择和页码不写入 URL。
9. 产品分页只由用户手动触发；翻页后选中目标页 `sort_order` 第一项并同步详情，保证当前选中产品始终在可见卡片中。首尾页禁用相应按钮，不循环、不自动轮播，也不用整页横向滚动承载溢出产品。切换企业后产品回到第 1 页并选中该企业 `sort_order` 第一项。
10. 用户继续浏览技术优势；技术优势结束后，团队实力以独立全宽模块展示，不与技术优势并排压缩。
11. 非评审展示模式默认选中 CMS `sort_order` 第一位已发布成员，左侧展示当前成员主视觉，中部展示姓名、职务/领域、人物画像摘要、专业领域、行业成就和主导项目，右侧展示其他成员卡；点击成员卡或上一位/下一位切换全部当前成员信息。
12. 当前成员存在已发布且授权有效的外部人物主页（原始需求为 LinkedIn）时展示“了解更多”；链接在新窗口打开。无链接、未发布或授权失效时隐藏入口，不用空链接或搜索结果页替代。
13. 产品、视频、3D 模型、案例、团队介绍、人物照片、发展历程和口碑等内容只读取 CMS 已发布版本；基础指标由数据侧提供。内部评审模式保留产品关联、团队字段、来源、发布和授权状态，不以展示型交互掩盖待闭环项。
14. 用户点击生态节点查看合作关系摘要，或点击企业名称进入统一企业画像；页面不生成风险或推荐结论。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 当前产业未配置明星企业 | 展示“本产业明星企业待配置”，不随机推荐或跨产业补位 | 返回企业整体概况或切换产业 |
| URL `future_industry_code` 无效 | 回退到从 E-31 继承的产业；无继承值时回退未来产业字典 `sort_order` 第一项并替换 URL | 浏览默认产业或切换产业 |
| 当前产业仅配置 1 家 | 隐藏选择器，直接展示该企业并提示“本产业共 1 家明星企业” | 浏览企业介绍 |
| URL `enterprise_code` 无效或不属于当前产业 | 回退到当前产业 `sort_order` 第一家并替换 URL；名单为空则进入空态 | 浏览默认企业或切换产业 |
| 入选标准未定稿 | 保留明星企业展示并标记“入选标准待配置”；不伪造版本、阈值或排名 | 查看已公开企业内容 |
| 名单条目或基础介绍未发布 | 该企业不进入前台候选名单，不读取 CMS 草稿 | 选择其他已发布企业 |
| CMS 其他内容部分缺失 | 企业仍可进入名单；只展示已发布内容，缺失区块使用业务空态 | 浏览其他已发布区块 |
| 未发布任何产品 | 产品区显示“核心产品待完善”，不渲染产品卡、分页或虚构产品 | 继续浏览技术优势 |
| 已发布 1~3 个产品 | 单行展示全部产品并默认选中 `sort_order` 第一项，隐藏分页控件 | 选择产品或查看当前产品详情 |
| 已发布 4 个及以上产品 | 每页最多 3 个，显示当前页/总页数和手动上一页/下一页；首尾按钮禁用 | 翻页后选择产品 |
| 当前产品子内容部分缺失 | 保留产品选中态；只显示已发布功能模块、场景、案例和媒体，缺失子区使用局部空态 | 切换产品或继续浏览 |
| 当前产品媒体不可用 | 关闭或保留稳定媒体层并显示封面、资源不可用说明与重试，不回退到其他产品媒体 | 重试、关闭媒体层或切换产品 |
| 核心团队未发布 | 团队模块显示“核心团队资料待完善”，不生成虚构成员或人物履历 | 继续浏览产业生态 |
| 成员资料部分缺失 | 保留已发布姓名和可公开字段；无照片时使用中性人物占位，不用姓名首字或生成肖像；缺失字段不留空标签 | 切换其他成员 |
| 外部人物主页缺失或未授权 | 隐藏“了解更多”，人物画像仍可在模块内阅读 | 切换成员或继续浏览 |
| 媒体资源不可用 | 保持区块高度并显示封面、资源不可用说明和重试，不自动播放失效资源 | 重试或继续浏览 |
| 产业生态关系不足 | 展示已确认关系摘要或“生态关系待完善”，不生成虚假节点 | 查看企业画像或其他区块 |
| 加载或接口失败 | 使用稳定骨架；局部失败隔离并提供重试 | 重试失败区块 |
| 无权限查看非公开字段 | 隐藏非公开字段并说明公开展示边界，不泄露 CMS 草稿 | 查看公开内容 |

## 模块边界与依赖

- 当前产业固定明星企业名单、`sort_order`、推荐标准版本与基础指标依赖数据/算法侧；名单与基础介绍发布准入、排序唯一性及正式指标由 Q048 闭合。
- 产品主数据、`sort_order`、功能模块/产品架构、场景、案例与媒体关联，以及视频、团队、详细介绍、发展历程和口碑内容依赖 E-37 CMS 已发布版本，遵循 Q041；其中团队成员照片和外部人物主页还须具备公开授权状态。
- 产业生态关系先按 Q040 使用图数据库 demo 接口占位，正式关系不得由前端推断。
- 企业基础档案和资质荣誉复用企业查询/统一企业画像的数据定义。
