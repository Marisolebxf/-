## 模块：E-35 深圳企业介绍

深圳企业介绍是企业总览中的深圳地域专题，以深圳企业群体为观察对象，按当前有效 **15 个产业集群** 展示企业数量与历年趋势、领域分布、规模分布和重点企业情况。源需求「各未来产业」保留；本轮决策不再把 DEMO 八项当作现行目录。它固定深圳地域，不承担全国或城市横向对标、产业链角色下钻、企业评价模型、供应链风险、复杂筛选或导出。

## 用户故事

### US-E35-01 查看深圳企业数量与趋势

作为政府用户，我想从当前 15 个产业集群数量对比中选择一个集群查看趋势，或最多选择两个集群进行趋势对比，以便理解深圳企业发展的总体规模与变化。

### US-E35-02 查看深圳企业领域分布

作为投资机构用户，我想结合各未来产业链全景查看深圳企业在产业领域中的分布，以便识别深圳企业较集中或覆盖不足的领域。

### US-E35-03 查看深圳企业规模结构

作为政府用户，我想比较当前未来产业目录中深圳企业的大、中、小、微规模分布，以便理解不同产业的企业梯度结构。

### US-E35-04 浏览深圳重点企业

作为访客，我想通过可见产业 Tab 或“更多产业”快速选择一个未来产业，浏览该产业深圳重点企业的公开基础档案、企业性质和资质荣誉，以便在未来产业目录扩展后仍能稳定认识本地代表企业并进入企业画像。

## 口径与分类规则

### 固定地域与产业分组

- 地域固定为深圳市，不提供全国、省际或城市切换。
- 默认消费当前有效 15 个产业集群作为数量、趋势、规模和重点企业的统计分组；控件不得假定目录只有八项，也不得把招标八大写成现行上限。
- 数量对比中的产业选择只驱动趋势局部状态：优先采用有效的当前专题产业，否则默认选择深圳企业数量排名第一的产业；支持单产业或最多双产业对比。
- 选择第三个产业时阻止新增并提示“最多对比两个产业”；不得静默覆盖已有选择，也不得由趋势选择收窄概况 KPI、领域分布、规模分析或深圳重点企业。
- 领域分布使用独立 `domain_industry_code` 单选状态，允许在区块内轻量聚焦一个未来产业并查看其产业链领域分布；标题旁固定显示原始需求说明“结合各未来产业链全景图，展示深圳企业在产业领域中的分布情况。”；区块使用上方产业选择与产业链概况、下方领域/环节分布的上下结构；只更新展示摘要，不进入企业集合或产业链角色下钻。
- 上方概况显示“已识别领域/环节 X 个”，X 为当前产业领域/环节数据集合总项数。该数字不等同映射覆盖率；覆盖率的分子、分母、`metric_id` 和 ADS 来源由 Q049 闭合，闭合前业务态不展示覆盖百分比或进度条，评审态只提示口径未确认。
- 领域/环节分布默认按企业数量降序展示前 12 项，每次“查看更多”追加 12 项，全部展示后提供“收起”，并显示“已展示 X / 共 Y”；总数不超过 12 时不显示展开控件，不使用页码分页，切换产业后恢复前 12 项。
- 深圳重点企业使用独立 `key_enterprise_industry_code` 单选状态，通过容器内可见横向 Tab 与支持名称搜索的“更多产业”下拉切换；未容纳的产业不得丢失入口，从下拉选择后当前产业必须保持可见。
- 重点企业产业切换只更新该区块，一次只展示当前产业企业卡，不改变全页统计口径或其他区块局部选择。

### 资质荣誉与企业性质

深圳重点企业复用企业查询/企业档案的系统通用资质荣誉枚举：

`外企 / 国高企 / 小微 / 上市 / 专精特新 / 小巨人 / 链主龙头 / 独角兽 / 瞪羚`

“高企”统一展示为“国高企”。“国有企业”属于企业性质 `enterprise_nature`，不加入资质荣誉枚举；同一企业允许多资质标签展示。

## 场景 walkthrough

### 主路径

1. 用户从企业总览切换到“深圳企业介绍”，页面稳定显示科技专题服务、深圳市、当前有效未来产业目录和数据时间。
2. 首屏展示深圳企业总数、重点企业数、上市企业数、国有企业数等公开概况；没有正式 metric_id 的字段标记 DEMO/Q049。
3. 用户从当前未来产业目录数量对比中选择一个产业查看单线趋势，或选择第二个产业查看双线对比；选择第三个产业时得到上限提示。每条所选产业序列只有满足连续可比数据条件时才进入正式趋势图。
4. 用户在“深圳企业领域分布”标题旁看到原始需求说明，选择某一未来产业后，先在上方确认当前产业链与“已识别领域/环节 X 个”，再在下方查看领域/环节中的深圳企业分布摘要。
5. 用户查看当前未来产业目录的大、中、小、微企业规模结构；正式分级口径未确认前标记待确认/DEMO。
6. 用户在深圳重点企业区通过可见横向 Tab 选择常用产业；目标产业未显示时，从“更多产业”中搜索并选择。页面只展示当前产业企业卡，用户查看名称、区域、企业性质、资质荣誉和 CMS 已发布定位/优势摘要，点击名称进入统一企业画像。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 当前产业集群目录或映射未确认 | 使用 15 集群种子（Q068 🟡）；无 L0 映射走空态/占位，控件按可变目录设计，不冒充甲方已批正式目录 | 浏览页面结构与交互 |
| 某个所选产业少于 2 个连续可比时间点 | 不展示该产业趋势序列，并明确提示该产业数据不足；其他满足条件的所选产业仍可展示 | 查看有效产业趋势或更换选择 |
| 全部所选产业均少于 2 个连续可比时间点 | 隐藏正式趋势图，数量对比区占满整行；不显示单点折线或机械补齐历史 | 查看当前数量及数据时间 |
| 已选择两个产业后继续选择第三个 | 阻止新增并提示“最多对比两个产业”，保留原有两个选择 | 取消一个已选产业后再选择 |
| 某产业无深圳企业 | 保留产业分组并显示 0/无数据，说明数据时间 | 查看其他产业 |
| 产业链领域映射口径未闭合 | 业务态只显示当前数据集合“已识别领域/环节 X 个”，不显示覆盖百分比或进度条；评审态提示 Q049 | 切换产业或查看数量结构 |
| 领域/环节超过 12 项 | 首屏显示前 12 项和“已展示 12 / 共 Y”，每次点击“查看更多”追加 12 项；全部展示后提供“收起”，不出现页码分页 | 继续展开或收起 |
| 重点企业产业数量超过可见宽度 | 容器内保留可见横向 Tab，其余产业进入支持名称搜索的“更多产业”下拉，不出现横向滚动 | 搜索或选择目标产业 |
| 从“更多产业”选择目标产业 | 目标产业成为当前选中项并保持可见；其他产业仍可从 Tab 或“更多产业”访问 | 浏览当前产业重点企业 |
| “更多产业”搜索无匹配 | 下拉显示“未找到相关产业”，不改变当前选中产业 | 修改搜索词或关闭下拉 |
| 当前选中产业被目录下线 | 回退到目录第一个有重点企业数据的产业；再否则回退目录第一项，并给出目录更新提示 | 浏览回退产业 |
| 规模口径未确认 | 大/中/小/微结构标 DEMO/Q049，不将资质标签当作规模 | 查看演示结构说明 |
| 深圳重点企业未配置 | 保留当前产业选中态并显示业务空态，不用明星企业或外地企业补位 | 选择其他产业或查看其他统计区块 |
| CMS 介绍未发布 | 仅展示数据侧公开基础档案，隐藏未发布专家观点 | 进入企业画像查看公开信息 |
| 加载或接口失败 | 使用稳定骨架；局部失败隔离并提供重试 | 重试失败区块 |
| 无权限查看非公开字段 | 隐藏非公开字段和 CMS 草稿，不影响公开统计 | 浏览公开内容 |

## 模块边界与依赖

- 当前有效未来产业目录、深圳企业清单、产业归属、数据时间、指标和产业链领域映射依赖数据侧，正式口径由 Q049 闭合。
- 重点企业识别标准复用 Q038；本页不自行计算或修改阈值。
- 深圳本地企业的定位、优势和专家观点只消费 E-37 CMS 已发布内容。
- 企业基础档案、企业性质和资质荣誉复用企业查询/统一企业画像的数据定义。
- 页面不提供 CMS 编辑、查询式筛选、清单下钻、对标、评估、风险、推荐或导出。
