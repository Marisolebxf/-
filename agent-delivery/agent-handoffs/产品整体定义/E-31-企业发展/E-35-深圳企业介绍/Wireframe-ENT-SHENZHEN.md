### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 共享上下文 | 确认统计范围 | `topic_service`、`region_code=440300`、`future_industry_scope`、`data_time` | 地域固定深圳；全页消费当前有效未来产业目录；当前 DEMO 为八项但不设固定上限 |
| 概况 KPI | 快速了解总体及代表企业基础 | 企业总数、重点企业数、上市企业数、国有企业数：`metric_id: null`，Q049 / DEMO；重点判定 Q038 | 展示当前值、单位和数据时间，不显示无依据比较百分比 |
| 未来产业数量对比 | 比较深圳企业产业分布并选择趋势产业 | `shenzhen_enterprise_count_by_industry`：`metric_id: null`，Q049 / DEMO；局部状态 `trend_industry_codes` | 展示当前目录产业；优先选中有效的当前专题产业，否则选中数量排名第一产业；支持 1 个或最多 2 个选择，不进入企业清单 |
| 所选产业历年趋势 | 理解所选产业数量变化 | `shenzhen_enterprise_count_trend_by_industry`：`metric_id: null`，Q049 / DEMO | 每个所选产业有效连续可比点≥2才显示该序列；全部不满足时隐藏趋势区并由数量对比占满 |
| 领域分布标题说明 | 直接对应原始需求 | 固定文案“结合各未来产业链全景图，展示深圳企业在产业领域中的分布情况。” | 挂载标题旁；非按钮、非 Tooltip，不随产业切换消失 |
| 领域分布 | 理解产业领域覆盖 | `shenzhen_enterprise_domain_distribution`：`metric_id: null`，Q049 / DEMO；局部状态 `domain_industry_code` | 单产业聚焦；采用上方产业链概况、下方领域/环节分布的上下结构 |
| 产业链概况 | 理解领域与链的对应 | 产业链名称、`identified_domain_stage_count`：`metric_id: null`，Q049 / DEMO、数据时间 | 固定在领域区上方；显示“已识别领域/环节 X 个”，X 取当前分布集合总项数；不显示未闭合覆盖百分比或进度条 |
| 领域/环节列表 | 浏览当前产业分布摘要 | 领域/环节名称、企业数量或结构、`shown_count`、`total_count` | 两列；按企业数量降序默认前 12 项；每次“查看更多”追加 12 项，全部展示后提供“收起”；总数≤12 时无展开控件；不使用页码分页 |
| 规模分析 | 理解企业梯度 | `shenzhen_enterprise_scale_distribution`：`metric_id: null`，Q049 / DEMO | 当前未来产业目录 × 大中小微；正式阈值待确认 |
| 重点企业产业导航 | 在可变目录中选择一个产业 | `key_enterprise_industry_code`、当前有效未来产业目录 | 容器内可见横向 Tab +“更多产业”可搜索下拉；未容纳产业不丢失入口；从下拉选择后当前项保持可见 |
| 重点企业卡 | 认识代表企业 | 企业名称、行政区、`enterprise_nature`、资质荣誉、公开摘要、数据时间 | 一次只展示当前选中产业；名称进入画像，不提供勾选/批量操作 |
| CMS 摘要 | 理解本地定位与优势 | 定位、优势、专家观点、发布状态 | 只展示已发布内容；缺失时不影响基础档案 |

### 2.3 交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 点击未选中的产业（当前少于 2 个选择） | 高亮产业并在趋势图增加对应序列；单产业显示单线，双产业显示双线 | 不收窄全页统计，不改变概况 KPI、领域、规模或重点企业，不进入企业集合 |
| 已选择两个产业时点击其中一个已选产业 | 取消该产业并保留另一个产业的单线趋势 | 不允许清空为 0 个选择；不改变其他区块状态 |
| 仅选择一个产业时再次点击该产业 | 保持该产业选中和单线趋势 | 不取消最后一个选择，不隐藏仍有有效数据的趋势 |
| 已选择两个产业后点击第三个产业 | 阻止新增并提示“最多对比两个产业”，保留原有两个选择 | 不静默覆盖最早或最近选择，不改变全页专题产业 |
| 在领域区选择未来产业 | 更新对应产业链名称、“已识别领域/环节 X 个”和领域/环节分布 | 不把多条产业链混为一条，不进入产业链角色分析，不展示模拟覆盖率 |
| 点击领域或环节 | 展示该领域的数量/结构摘要 | 不弹出企业清单，不加入对比篮 |
| 领域/环节超过 12 项时点击“查看更多” | 在当前区块追加后续 12 项并更新“已展示 X / 共 Y”；全部展示后操作变为“收起”，点击后恢复前 12 项 | 不使用页码分页，不跳转新页，不改变当前产业 |
| 切换领域产业 | 更新上下两层内容并将列表恢复为前 12 项 | 不保留上一产业的展开高度或旧领域条目 |
| 点击规模分段 | 高亮当前产业/规模组合并显示数量说明 | 不跳转查询，不把“小微”资质当规模分段 |
| 点击重点企业名称 | 进入统一企业画像并携带来源 `E-35` | 不在本页开放评估、风险、招引或培育动作 |
| 点击资质荣誉 | 展示标签解释或企业公开事实 | 不作为筛选器，不生成评分 |
| 点击重点企业区可见产业 Tab | 将该产业设为 `key_enterprise_industry_code` 并只展示其企业卡 | 不联动趋势、领域、规模或全页统计口径 |
| 打开“更多产业” | 展示当前可见 Tab 未容纳的有效产业，并支持按名称搜索 | 不出现重复产业，不把搜索词写入全局筛选 |
| 从“更多产业”选择产业 | 将目标产业设为当前项并保持在可见 Tab 中；被替换的非固定 Tab 回到“更多产业” | 不改变目录顺序，不丢失任何有效产业入口 |

### 2.6 状态

| 接口错误 | 局部错误隔离并提供重试 | 重试失败区块 |
| 无权限 | 隐藏非公开字段和 CMS 草稿 | 浏览公开内容 |

## 3. 内部评审模式

- 每个 KPI/图表展示字段名、数据时间、`metric_id` 状态和 Q049。
- 重点企业标识显示 Q038 来源说明；E-35 不重新计算重点企业。
- 当前未来产业目录、深圳企业归属、产业链领域映射和规模分级显示 DEMO/正式状态；当前八项不代表产品上限。
- 产业链覆盖率的分子、分母、`metric_id` 和 ADS 来源未闭合时显示 Q049 说明；业务态只展示当前数据集合的已识别领域/环节数。
- CMS 定位、优势和专家观点显示发布状态；草稿不得作为前台内容。
- 资质荣誉、企业性质、企业规模三个分类体系分别标明来源，避免混用。

## 4. 响应式与视觉约束

- **屏幕层级**：medium；PC 门户工作台，不建设手机端。
- **布局**：数量对比与趋势可双栏；趋势隐藏后数量对比占满；领域、规模和重点企业纵向展开。领域区内部固定上下结构，不使用左右分栏。
- **设计系统**：遵循 `Design.md` 和 Arco 公共组件；图例、标签、空态和 DEMO 状态使用统一语义。
- **标题说明**：领域分布原始需求说明与标题同一标题行；可在窄中屏换行但不得截断、省略或收进 Tooltip。
- **裁剪规则**：窄中屏图表改为单栏；不出现整页横向滚动；重点企业产业 Tab 按可用宽度收纳到“更多产业”，不使用横向滚动；领域/环节用“查看更多 / 收起”增量展开，不使用页码分页。
