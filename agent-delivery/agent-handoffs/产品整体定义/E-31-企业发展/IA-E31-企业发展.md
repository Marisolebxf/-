## 1. E-31 信息架构定位

企业发展在产品侧呈现为“企业分析”工作区。它以企业总览建立宏观认知，再按用户任务进入企业查询、重点企业分析、对比篮、企业评估、风险洞察、引育推荐或维护管理；各模块不以页面堆叠方式互相替代。

```text
企业分析（E-31 企业发展）
├─ 企业总览
│  ├─ 企业整体概况（E-32，本轮完整样例）
│  ├─ 重点企业概览
│  ├─ 明星企业介绍
│  └─ 深圳企业介绍
├─ 企业查询
├─ 重点企业分析
├─ 对比篮
├─ 企业评估
├─ 风险洞察
├─ 引育推荐
└─ 维护管理
```

> **跨页面评审挂载约束**：上述每个业务页面均接入 [USM-内部评审模式](../内部评审模式/USM-内部评审模式.md) 定义的评审层。其全局开关固定在右上角用户 / 角色切换下拉面板内；`系统后台 SYS` 仅为可切换角色之一。开启后显示本页评审信息，关闭后恢复正式视角。该能力不构成企业分析的业务导航节点；各页面仅在有专属评审内容时补充差异说明。

## 3. 本轮完整样例：企业总览 → 企业整体概况（E-32）

### 3.1 模块边界

- **解决的问题**：在八大未来产业口径下理解企业规模、趋势、地域分布与企业科研人力。
- **承接内容**：企业总体数量、企业分布情况、科研人数。
- **不承接内容**：企业查询、高级筛选、企业集合下钻、评估、风险诊断、推荐、导出。
- **终端范围**：仅中屏（PC 工作台）。小屏即手机端，科技专题服务系统不做手机端，E-32 不产生小屏裁剪或移动端适配要求。

### 3.2 用户入口与产品角色

| 产品角色 | 入口 | 核心目标 |
| --- | --- | --- |
| 访客（未登录用户） | 企业总览 | 了解专题下的企业发展概况。 |
| 科研人员 | 企业总览 | 对比未来产业的企业规模、趋势与科研人力。 |
| 政府科技管理与决策部门 | 企业总览 | 观察全球与区域企业分布及产业覆盖。 |

### 3.3 企业总览内的信息架构

```text
企业总览（门户展示）
├─ 企业整体概况（E-32）
│  ├─ 全球汇总 KPI（不联动）
│  ├─ 未来产业企业数量排名与趋势
│  └─ 企业分布独立卡片（地域选择器、地图/列表）
├─ 重点企业概览（E-33）
├─ 明星企业介绍（E-34）
└─ 深圳企业介绍（E-35）
```

### 3.4 页面 / Tab 职责

| 企业分布卡片 | 以局部地域选择查看当前快照分布 | E-32 页内卡片 | E-32 / US-E32-02 |

| --- | --- | --- |

### 3.6 与 bid-reference 差异说明

| 原始功能 | IA 归位 / 重组方式 | 追溯动作 |
| --- | --- | --- |
| 企业总体数量 | 全球汇总 KPI + 未来产业排名 / 趋势 | TRACE E-32 / US-E32-01 |
| 企业分布情况 | 独立地域卡片，不影响全球汇总 | TRACE E-32 / US-E32-02 |
| 科研人数 | 顶部全球企业科研人数 KPI；企业内科研人员指标 | TRACE E-32 / US-E32-01 |

### 3.7 企业分布列表视图交互边界

企业分布列表是地图视图的地域聚合明细，不是企业对象清单。列表字段固定为：地域、企业数、科研人员数、覆盖未来产业数、操作。

| 列 | IA 行为 |
| --- | --- |
| 地域 | 只展示当前层级地域名称，不点击、不联动地图。 |
| 企业数 | 只展示当前地域企业聚合数量，不点击、不进入查询。 |
| 科研人员数 | 只展示当前地域企业科研人员聚合数量，不点击。 |
| 覆盖未来产业数 | 只展示当前地域覆盖的未来产业数量，不展开、不跳转。 |
| 操作 | 仅在此列提供动作：`在地图中查看` 切回地图并高亮地域；`进入企业查询` 跳转企业查询并带入地域条件。 |
