# IA-E1-ENT-SEARCH-企业查询

> **父需求编号**：E1-企业
> **模块**：企业查询（SEARCH）
> **阶段**：门 1 PDR 输入
> **体验 Owner**：高颖
> **范围真源**：`§1.1.1.2.4.2.3`；`USM-E1-ENT-SEARCH-企业查询.md`；`TRACE-E1-ENT-SEARCH-企业查询.yaml`

## 1. 模块边界

- **解决的问题**：主动找企业、筛企业、构造可解释的企业集合并衔接后续对象任务。
- **承接内容**：查企业、智能搜索、高级筛选、结果排序与再筛、对比篮、导出、初始态推荐。
- **不承接内容**：企业总览态势统计、自然语言 / LLM 意图识别、复杂条件组嵌套、企业评估 / 风险 / 引育结论生成。

## 2. 用户入口与产品角色

| 源需求服务对象 | 入口 | 核心目标 |
| --- | --- | --- |
| 政府 | 左侧菜单 `企业查询` → `/development/search` | 用查询与筛选形成企业集合，支撑产业治理、梯度培育和“一企一策”服务。 |
| 园区 | 左侧菜单 `企业查询` → `/development/search`；搜索页内热门场景标签 | 以预置或自定义条件构造候选企业集合；热门场景点击后按当前入口直接提交查询并展示结果，支撑产业链招商与生态研判。 |
| 投资机构 | 左侧菜单 `企业查询` → `/development/search` | 查找、比较目标企业并进入后续技术、商业或竞争力分析。 |

> 服务对象来源为投标实施方案《科技信息展示系统和科技专题服务系统》`§1.1.1.2.4.2.3 企业分析`：“面向政府、园区与投资机构”。该源需求未定义岗位角色和权限 persona；二者待业务确认，不从页面功能或 SRS 推导。

## 5. 查询入口规则

| 入口 | 召回口径 | 进入 / 切换规则 | 禁止行为 |
| --- | --- | --- | --- |
| 智能搜索 | 经营范围、产业、技术、专利、资质、区域等多字段关键词匹配 | 默认入口；热门场景按当前入口直接提交查询；切换至其它入口时清空本入口已提交结果 | 不称为自然语言理解、LLM 或意图识别。 |
| 查企业 | 仅企业名称关键词模糊查询；搜索框提示“输入企业名称关键词” | 热门场景按当前入口直接提交查询；与智能搜索共用初始态和结果列表，但不共用召回逻辑 | 不检索曾用名、统一社会信用代码或其他字段。 |
| 高级筛选 | 字段条件构造 | 进入独立下级页；热门场景可带入预置条件 | 不做抽屉；不支持任意 AND/OR 嵌套。 |

## 6. 跨模块边界

| 来源或去向 | 可携带内容 | 不可携带 / 不可承担内容 |
| --- | --- | --- |
| 企业总览 → 企业查询 | 仅显式 URL / 对象上下文；不继承总览 ContextBar | 不把总览口径偷偷写入查询条件。 |
| 企业查询 → 企业画像 | enterprise_code、查询条件摘要、排序、分页、来源入口 | 不丢失返回查询页的结果上下文。 |
| 企业查询 → 对比篮 | enterprise_codes、来源查询条件、数据批次 | 不在查询页选择评估模式或产生评估结果。 |
| 企业查询 → 评估 / 风险 / 引育 | 企业对象集合与来源上下文 | 不直接生成评分、风险结论、推荐名单或一企一策。 |
| 个人资产中心 | 异步导出记录、最近检索、保存的查询方案 | 不在查询页长期展示完整历史。 |

> 普通查询页只提供最近检索；保存 / 使用查询方案仅属于高级筛选字段库及其结果态。所有企业结果与推荐卡片均不展示企业 Logo / 标识。

> 推荐企业卡片的业务态保留企业业务信息、单企业推荐理由、查看画像与加入对比；“Top 30”“按竞争力倒排”“不使用个人行为数据”及 Mock / 指标状态属于评审解释，不得在业务态常驻展示。它们仅在右上角全局“内部评审模式”开启后随评审层显示。

> 全局内部评审模式开启后，页面标题和推荐企业标题均显示源需求章节溯源图标；弹层说明源章节、原文摘要、本轮解释、当前落位和状态。关闭开关后完整隐藏，不影响业务查询与推荐理由。

> 企业画像预览抽屉只展示企业业务摘要与可用详情页签，不展示来源追溯或 Mock 数据版本；数据侧的口径、来源与更新时间不在此抽屉承载。指标说明与“数据待接入”说明仍仅在全局内部评审模式开启后显示；评审模式关闭后，待接入页签以普通业务空态替代评审提示，不改变画像的信息架构。

> 终端范围遵循 `agent-delivery/Design.md`：科技专题服务系统仅支持 PC 工作台；企业查询不提供小屏裁剪、移动端重排或替代交互。

## 7. 与原始需求差异说明

| 原始功能 | IA 归位 / 重组方式 | TRACE 动作 |
| --- | --- | --- |
| 自然语言大模型检索 | 保留智能搜索入口，改为多字段关键词匹配 | `Q033`，`US-E1-SCH-02`。 |
| 卡片 / 表格双视图 | 统一横向长卡片结果列表 | `Q034`，`US-E1-SCH-05`。 |
| 复杂条件组合 | 高级筛选只支持简单条件叠加 | `Q036`，`US-E1-SCH-04`。 |
| 导出 | 单企业、已选企业和当前结果均走异步 PDF 导出；单次最多 1000 条，Excel 模板转 PDF，水印含平台名、用户名、时间 | `Q035`。 |
| 注册区县再筛 | 复用企业总览企业分布地图的四级地域级联组件，按最终地域收窄当前结果 | `Q037`。 |
