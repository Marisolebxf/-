### 2.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 入口分段控件 | 选择查询方式 | `smart / company / advanced` | 默认 `smart`；切换入口清除已提交结果。 |
| 蓝色搜索主视觉 | 建立普通查询入口的强引导 | 无新增 metric | 固定四层顺序；只在普通查询页展示，高级筛选下级页不继承。 |
| 主搜索框 | 输入查询条件 | 企业名称、曾用名、USCC、产业、技术、专利、资质、区域 | 智能搜索使用多字段提示；查企业提示“输入企业名称关键词”，仅按企业名称模糊查询。 |
| 示例查询 | 理解输入方式 | 文本示例 | 点击只回填输入框，不立即搜索。 |
| 热门场景 | 快速构造字段条件 | 预置筛选条件 | 点击后进入 F3，带入对应条件并保持待应用；点击“应用筛选”后才生成结果。 |
| 最近检索 | 恢复普通查询 | 查询条件、来源入口 | 普通查询仅展示最近检索；VISIT 不展示个人记录。 |
| 推荐企业 | 无条件时理解对象范围 | 企业标签、单企业推荐理由 | 业务态不显示推荐策略；单企业推荐理由属于业务内容；主查询无结果时隐藏。 |

### 2.3 交互与状态

| 触发 | 页面行为 | 不应发生的行为 |

| 点击高级筛选 | 进入 F3 | 不在当前页展开抽屉。 |
| 点击示例查询 | 将完整示例文本回填到当前搜索框 | 不立即提交，不进入结果态。 |
| 点击热门场景 | 进入 F3 并自动带入对应预置条件 | 不立即提交，不展示结果，不丢失已带入条件。 |
| 点击推荐企业 | 查看画像或加入对比 | 不提供“以此查询”，不把推荐视为个性化排序结论。 |
| 加载 | 仅推荐列表使用骨架，输入区稳定 | 不整页白屏。 |
| 无权限 | 隐藏最近检索 / 保存方案等个人资产能力 | 不隐藏基础查询入口。 |

> 推荐企业与结果卡片均不展示企业 Logo / 标识。

### 3.1 线框图

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [智能搜索] [查企业] [高级筛选]  当前关键词：南山区 专精特新             │
│ [修改关键词]                                                             │
├─────────────────────────────────────────────────────────────────────────┤
│ 常用筛选 Chips                     排序：[综合竞争力 v]  共 N 家 [导出] │
│ □ 全选本页   已选 0 家   [加入对比篮] [加入候选] [取消选择]              │
├─────────────────────────────────────────────────────────────────────────┤
│ □ 企业 A  状态 / 资质 / 产业标签                                         │
│   有效专利数 · 最新营收 · 成立时间 · 综合竞争力(ⓘ)  [查看画像] [加入对比] │
│ □ 企业 B  ...                                                            │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.2 区块、字段与指标

| 区块 / 控件 | 用户目的 | 字段 / metric_id | 默认与联动规则 |
| --- | --- | --- | --- |
| 查询摘要 | 确认当前集合来源 | 入口、关键词 / 条件、数据批次 | 切换入口时整体清除。 |
| 排序 | 优先查看目标企业 | `M_ENT_COMPETITIVENESS_SCORE`、有效专利数、最新营收、成立时间 | 排序字段必须在卡片常驻可见。 |
| 结果内再筛 | 缩小当前结果 | 常用筛选字段；注册区县复用企业总览企业分布地图四级地域级联组件 | 只影响列表，不清空主查询摘要；地域按最终选中行政地域收窄。 |
| 全选本页 | 快速选择当前分页全部企业 | 当前页 enterprise_codes；`metric_id=N/A` | 三态复选框；只作用于当前分页，空结果禁用。 |
| 批量工具栏 | 操作已选企业 | enterprise_codes | 未选企业时禁用；重复加入给出数量反馈。 |
| 导出 | 导出单企业、已选企业或当前查询上下文 | 本轮产品增强 `Q035` | ≤1000 条、Excel 模板转 PDF、批量 PDF 打包；水印含平台名、用户名、时间；异步记录进个人资产中心。 |

智能搜索与查企业的初始态、结果态均不展示“保存为查询方案”；保存/使用查询方案仅在高级筛选字段库及高级筛选结果态出现。

### 3.3 选择交互

| 触发 | 页面行为 | 不应发生的行为 |
| --- | --- | --- |
| 勾选“全选本页” | 选中当前分页全部企业；复选框进入全选态 | 不选择其他分页或全部命中结果 |
| 取消“全选本页” | 取消当前分页全部选择 | 不改变查询条件或对比篮内容 |
| 逐项选择 / 取消 | 根据当前页已选数量显示未选、半选或全选态 | 不用两个独立按钮模拟三态 |
| 重新查询、结果内再筛、排序或翻页 | 清除当前选择并在新结果上恢复未选态 | 不保留不可见页的隐形选择 |
| 当前页无结果 | “全选本页”禁用 | 不沿用上一页或上一查询的选择计数 |

### 3.4 状态

| 状态 | 表现 | 用户下一步 |
| --- | --- | --- |
| 主查询无结果 | 只显示修改关键词、清空条件、切换模式、进入高级筛选 | 修正查询。 |
| 结果内再筛无结果 | 保留查询摘要与工具栏，在列表区域局部提示 | 清除结果内筛选。 |
| 指标无源 | 指标旁标 `❌ 无源` 或 `⚠️ 待确认` | 查看说明或调整排序。 |
| 导出处理中 | 当前查询摘要旁显示轻量进度；历史不常驻 | 到个人资产中心查看记录。 |
| 当前页部分选中 | “全选本页”显示半选态，批量工具栏显示准确已选数量 | 继续选择、批量操作或取消选择。 |

## 4. F3：高级筛选字段库

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ 企业分析 / 企业查询 / 高级筛选                                           │
│ 热门场景：[专精特新] [国高企] ...                                         │
├──────────────────────┬───────────────────────┬──────────────────────────┤
│ 字段分组              │ 字段列表               │ 已选条件（N）             │
│ 基础信息              │ 企业类型      [添加]    │ [资质 = 专精特新] [编辑][删]│
│ 技术能力              │ 有效专利数    [添加]    │ 关系：[全部满足 AND v]     │
│ 商业能力              │ 最新营收      [添加]    │                          │
├──────────────────────┴───────────────────────┴──────────────────────────┤
│ [保存为查询方案] [使用查询方案 v]          [清空条件] [应用筛选（N）]    │
└─────────────────────────────────────────────────────────────────────────┘
```

| 控件 | 规则 | 禁止行为 |
| --- | --- | --- |
| 字段列表 | 按 11 类字段组组织；字段显示类型、数据状态与添加动作；字段搜索无匹配时显示“未找到相关字段”空态，并提供“清空字段搜索”恢复全部字段 | 不把字段搜索当企业搜索，也不将无匹配误作企业查询无结果。 |
| 已选条件 | 一字段一次；支持编辑、删除、清空；区间用单一条件表达 | 不用重复字段模拟区间。 |
| 全局关系 | 仅 `全部满足 AND` / `任一满足 OR` | 不提供条件组、括号和嵌套逻辑。 |
| 应用筛选 | 所有条件合法时进入 F4 | 条件非法时不得执行。 |
| 保存方案 | 仅保存高级筛选字段条件、运算符、AND / OR 关系与必要数据版本，作为可复用的高级筛选模板 | 不保存智能搜索 / 查企业关键词，不保存静态企业结果；VISIT 不可保存。 |
| 画框固定 Footer | 吸附于高级筛选画框底边；字段库展开或收起时均保持同一宿主、宽度、左右分组与按钮顺序 | 不吸附视口底部，不移动到页面顶部，不随字段库高度漂移。 |
| 使用查询方案 | F3 / F4 均可用；下拉仅展示高级筛选模板；恢复字段条件与逻辑后回到 F3，等待用户手动应用 | 不展示普通关键词历史，不在进入 F4 后隐藏或移入其它摘要卡。 |

## 5. F4：高级筛选结果态

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ 高级筛选结果                                命中 N 家 · N 个条件 · AND │
│ 当前条件：[资质荣誉：上市] [企业规模：大型]                               │
├─────────────────────────────────────────────────────────────────────────┤
│ [保存为查询方案] [使用查询方案 v]          [清空条件] [编辑高级筛选]      │
└─────────────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────────┐
│ 结果列表工具区：结果内再筛 · 排序 · 对比篮 · [导出当前结果]              │
├─────────────────────────────────────────────────────────────────────────┤
│ □ 全选本页 · 横向长卡片结果列表 · 批量对象操作                            │
└─────────────────────────────────────────────────────────────────────────┘
```

- 使用 F2 的横向长卡片、排序、结果内再筛、“全选本页”、选择、导出和对象操作规则。
- 高级筛选画框在 F4 收敛为条件摘要，但保留与 F3 同一画框底部 Footer；保存、使用、清空三个操作的位置不变。
- F3 的“应用筛选（N）”在原槽位切换为“编辑高级筛选”；点击后返回 F3 并保留全部条件。
- “使用查询方案”在 F4 保持可用；下拉仅显示高级筛选条件模板，恢复后返回 F3，等待用户手动应用。
- “导出当前结果”归入结果列表工具区，不进入高级筛选 Footer。
- 切换到智能搜索或查企业时清除字段库结果态。

## 6. 响应式与视觉约束

- **屏幕层级**：medium（Track-MS）；不适配展示大屏样式。
- **设计系统**：`agent-delivery/Design.md`；React + Arco 组件，主色 `#165DFF`。
- **终端范围**：仅支持 PC 工作台；不提供小屏裁剪、移动端重排或替代交互，小屏不纳入本期验收。
- **状态标识**：统计指标提供 `ⓘ` 说明；Mock、待确认、无源按评审模式规则显示。
- **无障碍**：入口、排序、“全选本页”三态复选框、逐项勾选和批量工具栏可键盘操作；半选使用原生 / Arco indeterminate 语义，禁用态说明原因。
