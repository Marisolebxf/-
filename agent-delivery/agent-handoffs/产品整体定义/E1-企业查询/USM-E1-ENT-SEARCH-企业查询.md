## 模块定位

企业查询用于主动查找企业、构造企业集合、查看初步对象信号，并将明确的企业对象带入企业画像、对比篮、企业评估、风险洞察或引育推荐。它不生成评估、风险或招引结论，也不承担企业总览的态势统计。

入口固定为 `智能搜索 / 查企业 / 高级筛选`。普通查询与高级筛选的结果均使用横向长条形卡片（类列表），不提供卡片/表格双视图切换。

## 目标用户角色（源需求服务对象）

| 源需求服务对象 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府 | 企业分析直接面向政府；用于产业治理、梯度培育与“一企一策”服务 | 通过查询与筛选构造企业集合，支撑政策与服务对象识别。 |

## 用户故事

### US-E1-SCH-01 查企业：企业名称关键词查询

作为政府、园区或投资机构用户，我想按企业名称关键词模糊查询企业，以便快速定位对象并进入企业画像。

- 源需求章节：`§1.1.1.2.4.2.3`；查企业入口与企业名称关键词查询规则为本轮产品定义。
- 验收：仅以企业名称参与关键词模糊查询，不检索曾用名、统一社会信用代码或其他字段；查企业搜索框提示为“输入企业名称关键词”；结果保持无企业 Logo / 标识的横向长卡片列表形态。

### US-E1-SCH-02 智能搜索：多字段关键词匹配

作为政府、园区或投资机构用户，我想按经营范围、产业、技术标签、专利、资质或区域等线索搜索企业，以便形成研究对象集合。

- 源需求章节：`§1.1.1.2.4.2.3.2`；多字段关键词召回为本轮产品定义。
- 验收：仅执行关键词与多字段模糊匹配；不承诺自然语言理解、LLM 意图识别或自动推理。

### US-E1-SCH-03 初始态引导：示例、热门场景与最近检索

作为政府、园区或投资机构用户，我想看到可点击的搜索示例、热门场景和最近检索，以便快速开始而不必先理解字段体系。

- 源需求章节：`§1.1.1.2.4.2.3`、`§1.1.1.2.4.2.3.1.1`、`§1.1.1.2.4.2.3.2`；搜索示例、热门场景与最近检索为本轮产品增强。
- 验收：智能搜索和查企业的热门场景按当前入口直接提交查询，不进入高级筛选字段库；普通查询初始态与结果态均仅保留最近检索，不展示或保存查询方案；最近检索恢复对应查询上下文；访客不记录个人最近检索。

### US-E1-SCH-04 高级筛选：简化条件构造

作为政府、园区或投资机构用户，我想按字段逐项添加条件构造企业集合，以便得到可复现的候选名单。

- 源需求章节：`§1.1.1.2.4.2.3.1.1`；高级筛选的字段组织与交互为本轮产品定义。
- 验收：本期仅支持单次添加条件和简单叠加；不支持任意 AND/OR 条件组嵌套。

### US-E1-SCH-05 结果列表：排序、再筛与对象确认

作为政府、园区或投资机构用户，我想在横向长卡片列表中排序、再筛和勾选企业，以便识别值得进一步分析的对象。

- 源需求章节：`§1.1.1.2.4.2.3.3`、`§1.1.1.2.4.2.3.4`、`§1.1.1.2.4.2.3.10`；结果列表的卡片形态和排序为本轮产品定义。
- 验收：排序仅包括综合竞争力、有效专利数、最新营收、成立时间；每个排序字段均在无企业 Logo / 标识的结果卡片中可见并可查看指标说明。
- 验收：选择区常驻“全选本页”三态复选框；未选、部分选中、当前页全部选中均可辨识，当前页无结果时不可用。
- 验收：“全选本页”不跨页；重新查询、结果内再筛、排序或翻页均清除当前选择，避免不可见页保留隐形选择。
- 验收：“全选本页”不承载评审说明，业务 / 评审模式共用同一选择集合；本交互的 `review_mounts: []`。

### US-E1-SCH-06 对比篮与跨模块分析

作为政府、园区或投资机构用户，我想将一个或多个结果企业加入对比篮，并从该集合进入竞争力、供应链难点或引育推荐等后续模块，以便连续完成研判。

- 源需求章节：`§1.1.1.2.4.2.3.6`～`§1.1.1.2.4.2.3.10`；对比篮与跨模块带参为本轮产品定义。
- 验收：逐项勾选或“全选本页”形成的选择集合使用同一批量加入、权限与重复项反馈契约；目标页接收企业对象与查询来源上下文，不在查询页直接生成分析结论。对比篮不提供“去高级筛选”快捷入口；“保存为企业集合”“生成分析报告”等尚未形成正式业务能力的后续动作仅在全局内部评审模式开启时作为评审说明显示。

### US-E1-SCH-07 导出当前查询结果

作为政府、园区或投资机构用户，我想导出当前查询结果，以便在线下审核或汇报中使用。

- 源需求：企业分析章节未定义查询结果导出；本轮产品增强，决策号 `Q035`。
- 验收：支持单企业、已选企业和当前结果导出，单次最多 1000 条；统一按 Excel 模板转换为 PDF，批量结果打包 PDF；水印包含平台名、用户名、时间；异步任务完整记录在个人资产中心查看。

### US-E1-SCH-08 初始空态推荐企业

作为政府、园区或投资机构用户，我想在初始空态看到有限的代表企业，以便理解可查询对象并快速开始。

- 需求追溯：服务 `E-33 / E-34` 触点的产品增强。
- 验收：正式业务态展示“推荐企业”、企业业务信息和单企业推荐理由，卡片仅提供查看画像、加入对比动作，不提供“以此查询”；主查询无结果时不展示推荐，只提供纠错动作。固定 Top 30、按竞争力倒排、非个性化和 Mock / 指标状态等推荐机制说明仅在全局内部评审模式开启后显示。

## 场景 walkthrough

### 主路径：智能搜索形成企业集合

1. 用户从左侧二级菜单进入企业查询，默认停在智能搜索。
2. 用户输入多字段关键词，或点击搜索示例 / 热门场景；热门场景按当前入口直接提交查询。
3. 系统执行关键词与多字段匹配，显示横向长卡片结果列表。
4. 用户按可解释字段排序、结果内再筛，并逐项勾选或使用“全选本页”；翻页、重新查询、再筛或排序后选择清空。
5. 用户加入对比篮，或打开企业画像；跨模块动作携带企业对象和来源查询条件。

### 主路径：高级筛选构造候选集合

1. 用户从普通查询页进入高级筛选字段库；高级筛选页内的预置条件可带入字段库。
2. 用户逐项添加或编辑条件，确认后点击“应用筛选”。
3. 系统进入高级筛选结果态；用户可编辑条件、保存查询方案、导出或加入对比篮。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 普通查询主查询 0 命中 | 显示修改关键词、清空条件、切换模式、进入高级筛选等纠错动作；不展示推荐企业。 | 调整查询。 |
| 结果内再筛 0 命中 | 保留原查询方案与结果操作区，仅在列表区显示局部空态。 | 清除结果内筛选。 |
| 指标无源或口径待定 | 对应字段显示无源 / 待确认标识，不用 0 值伪装。 | 查看指标说明或按 DEMO 使用。 |
| 无导出权限或超过上限 | 禁用并说明权限 / 数量限制。 | 缩小结果集或申请权限。 |
| 当前页无结果 | “全选本页”禁用，不保留上一查询 / 分页的选择。 | 调整查询、筛选或返回有结果分页。 |

结果内“注册区县”筛选复用企业总览企业分布地图的四级地域级联组件；按地域层级逐级选择，结果仅按最终选中的行政地域收窄。
