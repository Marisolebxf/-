## 模块定位

对比篮是企业对象的全局暂存与分发工作区。它帮助用户保存当前关注的企业、恢复集合、管理选择，并把企业对象交给企业评估、风险洞察或引育推荐；它不生成任何对比或分析结果。

## 目标用户角色

| 产品角色 | 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府科技管理与决策人员 | E-20 明确企业分析面向政府 | 将重点企业集合送入评估、风险研判或政策服务动作 |
| 产业园区运营 / 企业服务人员 | E-20 明确企业分析面向园区 | 汇集园区关注企业，维护候选集合并衔接招引 / 培育 |
| 投资机构产业研究人员 | E-20 明确企业分析面向投资机构 | 从检索和画像中暂存候选企业并开展横向研判 |

### 实现角色映射

| 产品角色 | 当前能力要求 | 映射用途 |
| --- | --- | --- |

## 用户故事

### US-ENT-CMP-01 收集企业并保持全局一致

作为政府、园区或投资机构用户，我想从企业查询、总览、重点企业分析和画像中加入企业，以便跨页面持续积累同一个待分析对象集合。

- 同一企业按企业 ID / 统一社会信用代码全局去重。
- 已加入企业在所有入口显示“已加入”；再次点击执行移除。
- 新来源重复加入不新增记录，可追加来源并更新最近操作时间。

### US-ENT-CMP-02 找回并管理单用户单篮

作为业务用户，我想刷新或重新进入后恢复最近一次对比篮，并通过搜索、轻筛、选择、移除和清空管理对象，以便继续未完成的研判准备。

- 默认最多 50 家，按最近操作时间倒序。
- 仅支持企业名称 / 统一社会信用代码搜索、加入来源和企业类型筛选。
- 单个移除无需二次确认；清空篮需要二次确认。

### US-ENT-CMP-03 将对象送入企业评估或风险洞察

作为需要开展专业研判的用户，我想勾选企业后进入企业评估或风险洞察，以便目标模块使用同一对象集合生成正式分析结果。

- 跳转只携带 `enterprise_codes[]`、来源和必要上下文。
- 对比篮不展示评分、雷达、排名、差距、图谱或风险结论。
- 未选择、对象数量不足或权限不足时，动作不可执行并说明原因。

### US-ENT-CMP-04 加入招引或培育候选

作为政府或园区企业服务人员，我想把选中企业批量加入招引或培育候选名单，以便在引育推荐模块继续形成推荐理由和一企一策。

- 已在候选名单的企业不重复写入。
- 完成后提示“已加入 X 家，Y 家已在名单中”，不自动跳转。
- 推荐理由、建议、名单导出均不在对比篮生成。

### US-ENT-CMP-05 从空篮继续发现企业

作为首次进入或清空篮的用户，我想得到明确的添加入口和有限推荐，以便不离开任务上下文也能开始收集对象。

- 主操作为“去添加企业”；可进入企业查询。
- 按 Q037 展示固定重点 / 明星企业列表，最多 30 条，不按用户行为个性化。
- 推荐企业只提供查看画像与加入对比篮，不在空态生成分析结论。

## 场景 walkthrough

### 主路径 A：发现对象 → 暂存 → 企业评估

1. 用户在企业查询或重点企业分析中发现企业并点击“加入对比篮”。
2. 系统按唯一键去重，反馈“已加入对比篮”，并提供“查看对比篮”。
3. 用户进入 `/enterprise-center/basket`，恢复本人最近单篮，搜索或筛选对象并勾选企业。
4. 用户点击“进入企业评估”。
5. 系统执行权限与对象条件校验，通过后携带 `enterprise_codes[]` 和来源跳转 `/enterprise-center/evaluation`。
6. 企业评估模块负责指标、权重、评分、排名和差距结果。

### 主路径 B：暂存 → 加入引育候选

1. 用户在对比篮勾选企业。
2. 用户点击“加入招引候选”或“加入培育候选”。
3. 系统校验候选名单写权限并去重写入。
4. 页面提示新增与重复数量，保留当前选择，不自动跳转。
5. 用户可通过右上角“查看引育名单”进入 `/enterprise-center/attraction`。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 对比篮为空 | 显示添加入口、Q037 固定推荐和各目标能力说明 | 去企业查询、查看画像或加入推荐企业 |
| 单个加入已满 50 家 | 不写入，提示“对比篮已满，请移除部分企业后再加入” | 移除对象后重试 |
| 批量加入超限 | 依当前顺序加入剩余容量前 N 家，并提示未加入数量 | 查看篮或调整选择 |
| 重复加入 | 不新增；更新来源 / 最近操作时间并显示已加入反馈 | 查看篮或取消加入 |
| 未选择企业 | 批量动作保持不可执行，提示“请先选择企业” | 勾选企业 |
| 权限不足 | 动作置灰或拦截，明确缺少的目标能力，不静默隐藏 | 申请权限或选择可用动作 |
| 恢复失败 / 接口错误 | 保持页面壳层，显示错误与重试，不清空本地已知状态 | 重试或返回来源页 |
| 空态推荐无数据 | 保留添加企业主操作，不展示伪造推荐 | 去企业查询 |

| 编号 | 可验证结果 |

| ENT-CMP-USM-10 | 清空篮有二次确认，单个移除无需确认并可提供撤销增强。 |

## 与需求和既有设计的差异

| 原始 / 既有内容 | 当前归位 | 范围影响 | TRACE 动作 |
| --- | --- | --- | --- |
| E-20～E-35 未定义独立“对比篮”叶子 | 作为跨叶子对象暂存与分发派生能力 | 不新增叶子 | 每个触点标 `source_context` 或 `target_handoff` |
| 旧产品设计把“选择分析类型 / 配置分析口径”放入篮内 | 采用 Decision 088：直接分发到目标模块，由目标模块配置与计算 | 无，职责收敛 | `US-ENT-CMP-03~04` |
| 旧导航对比篮位于企业总览之后 | 采用最新企业 IA，位于重点企业分析之后 | 无，导航重组 | IA 与 route 统一 |
| 现有实现容量 12 | 产品定义保持已确认的 50 | 实现差距 | TRACE `GAP-IMPL-01` |
