## 一分钟版（全员先看完这 8 句）

1. 展示系统和专题系统 **共用一张知识图谱**，不要各画一套点。
2. 这张图的骨架是 **产业链上下游**；企业、机构、人才、技术、政策、服务机构挂在上面。
3. **看现在的关系** 走 A 面（当前查图）；**看已发布的链结构历史** 走 B 面（发布切面）；**跑深度分析** 走 Job。三套不能混表。
4. 页面上的 GDP、规模、指数 **不是图算法**，是表格指标。
5. 能力还没接上，接口回 **501** 并说明原因；空图回 **200** 空结果。禁止用假分、假图凑 200。
6. 建图：数据产线编排 + 亿集能力面。**Demo** 用模拟器把图画进 Nebula（`graph-engine.md`）。本仓 Java/前端 **不直连图库**。要素上图 / 推理 / 发布切面走 **ETL 长任务**，不要绑在「重灌」按钮上。
7. 大模型检索（RAG）和智能体 **不是建图开工条件**；以后可以消费这张图，但不能挡建图。
8. 「生成分析」是 **G3 读切面出报告**，不是上图；会签前，三卷 **不是** 生产 OpenAPI。

## 与内部评审模式的关系

打开评审模式是为了看 Mock / 缺口 / 指标 ⓘ。本 SAD 的 **501 / M / 【算法补】** 是设计期诚实性，上线后评审模式关闭 **不应** 把 `GAP-*`、`metric_id` 泄漏到业务 DOM。两件事分层：设计文档对内说清楚；产品对用户保持干净。
