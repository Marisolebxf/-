## 纪律封面（FDE 裁剪）

**FDE = Forward Deployed Engineer（前线部署工程师）**，不是前端岗，本项目不新增编制。写入本 SAD 的只有：从真实模块发现需求、接已有 API、生产可用、重复模式反哺同一本体、501/M 合法。

**不写进建设方案**：驻场外包叙事；每页私有 Ontology；把 RAG/Agent/MCP 写成建图开工条件；把 Zion/低代码当本仓栈；用 FDE 替代架构/算法分工。
