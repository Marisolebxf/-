## 1. 建图详细

### 1.1 点类型（分析名 → 实现键）

主键 = **项目归一键**（DWD / 权威域），禁止用亿集内部 vid 当对外 `entity_id`。

| 分析名 | `entity_type` / 结构键 | 权威域（逻辑） |
| --- | --- | --- |
| 企业 | `enterprise` | 企业 DWD |
| 科研机构 | `institution` | 机构 DWD |
| 产业环节 | `chain_node` + `chain_id` | `industry_chain` / `node` |
| 技术 | `technology` | 技术权威域 【算法补字段】 |
| 人才 | `talent` | 人才权威域 |
| 政策 | `policy` | 政策权威域 |
| 服务机构 | `service_institution` | 服务机构权威域 |

区域是属性或 GIS，不单列点类型。载体在 01 §6 未升格前：挂企业 / 机构 / 服务机构，不新增 `carrier` 扩散。

### 1.2 边类型

| 边族 | 存储 | 进 B 面？ |
| --- | --- | --- |
| 产业链上下游 / 供给 / 断点 | DWD `node_rel` `[valid_from, valid_to)` | 是 |
| 要素挂环节 | DWD `entity_rel` 同期账本 | 企业必裁；其余可空（CUT-D5） |
| 技术/人才/政策/服务跨类型 | 亿集当前图 + 可选 DWD 事实边 | **否**（CUT-D6）；只走 A |
| 推理边 | 亿集产出后 **必须回写 DWD** 新 `valid_from`（CUT-D7） | 回写后下一次发布才进 B |
| 股权 / 社交 | 仅 A | 否 |

### 1.3 五大流程落点（算法 `.2`）

| 流程 | 落点 | 本仓实现叶 |
| --- | --- | --- |
| （1）环节与上下游 | DWD 链/节点/`node_rel` | 数据 + 切面 |
| （2）要素与属性 | 权威域 + `entity_rel` | 数据；全景只读挂接 |
| （3）实体构建与消歧 | GDF 触发 → 亿集实体脚本 | **不在**展示页 |
| （4）知识推理 | 亿集推理脚本 → 回写 DWD | 可空 |
| （5）图谱入库 | 亿集当前投影 + ADS 发布切面 | 切面 = 历史入口 |

`.2.1`～`.2.14` 对应（2）（3），脚本在亿集，GDF 只触发与观测。

### 1.4 GDF 触发序（推荐）

```text
Wave A 贴源 ODS
  → Wave B Mapping DWD
    → DAG：ADS/ES 作业（Python 仓执行）
    → DAG：亿集 Schema 校验（破坏性变更人工门禁 Q8）
    → DAG：事实关系任务（先）
    → DAG：实体/属性更新
    → DAG：推理任务（后；成功才回写 DWD rel）
    → （独立发布作业）裁切 ADS graph_snapshot
```

禁止绕过亿集直写图存储。管理凭证 ≠ 查询凭证（Q9）。建图输入强制项目 DWD，禁直连供应方 `gkx`（Q1）。

### 1.5 切面

整节指针：

`agent-handoffs/产品整体定义/E2-产业链分析/CHAIN-TOPIC-PANORAMA-产业链全景图谱/系统设计说明书-CHAIN-PANORAMA-Published-Cut.v0.md`

## 2. 本仓接口详细（评审骨架）

调用链：前端 → 网关 → Java → Python `/internal/*`。Java 原样透传图 JSON，不扫 DWD 拼历史图。

### 2.1 A 面 · `.2.15`

路径与 Published-Cut §8.1 A 面一致：

| 招标 | 方法 | 成功 | 未就绪 |
| --- | --- | --- | --- |
| （1）实体检索 | `GET .../graph/entities` | 200 分页目录 | 权威域空 = 200 空列表 |
| （2）关系查询 | `GET .../graph/relations` | 200 子图 + `source` | 无权不返回邻居摘要 |
| （3）live 可视化 | `GET .../graph/view` | 200 nodes/edges，无冻结坐标 | **禁止**驱动时间轴 |
| （4）语义相似度 | `POST .../graph/similarity` | 200 + `model_id` | **501** |
| （5）网络指标 | `GET .../graph/metrics` | 密度/中心度 200 | `community`/`path` → **501** |

`weight` 只读，禁止回写。招标「知识扩充 / 智能交互」不单开 Agent：扩充 = 推理回写；交互 = 既有 Job/检索叶。

### 2.2 B 面 · 全景切面

路径见 Published-Cut §8.1 B：`snapshots` / `graphs/{id}` / `diffs` / `nodes/{id}` / 秒开 snapshot。仅 `publish_status=published`。

### 2.3 G3 Job

指针：`系统设计说明书-Analysis-Job-Runtime.v0.md`。  
分析键与图谱发布包无关。样板 `chain:diagnosis:key_link`；瓶颈等同构。前端轮询 Job，不把 Result 写入 `graph_snapshot`。

### 2.4 展示复用

DS-21～24 与专题检索共用 A 面资源。display BFF 不得复制一套 graph controller。嵌图组件读同一 JSON，自绘 G6（Q7）。

## 4. 失败态与可观测

| 情况 | HTTP / 行为 |
| --- | --- |
| 无图 / 无包 | 200 诚实空；文案「暂无结构」 |
| 能力未建 | **501** + honesty.reason |
| 薄包（无坐标） | `honesty.payload_thin=true`；演进禁用 |
| 无权 | 4xx；不泄露邻居 |
| 图库错误 | 200/5xx 策略与现网一致；`source=error` |
| Q5 切换 | 仅 `source` 变化，路径不变 |

全链路 `traceparent`。包内 `snapshot_id`。图接口响应必含 `source`。OTel：Python instrument + Java Agent；前端 `observability.ts`。

指标数字遵守 D9，不在图 JSON 内发明无 `metric_id` 的 KPI。
