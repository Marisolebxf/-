## 0. 文档定位与分层口径

本文是《UX-UE 通用交互组件规范》的**视觉落地接力**，只补"看起来怎样、用哪些 token"，不重述交互行为细节。两份文档分层互补，遇冲突各管各层、不互相覆盖语义（D10 决策）：

| 层 | 权威文档 | 本文角色 |
| --- | --- | --- |
| 交互行为 / 状态覆盖 / 键盘 / 无障碍 / Arco 组件选型边界 | 《UX-UE 通用交互组件规范》 | 引用，不改写 |
| 视觉 token / 配色 / 字号 / 圆角 / 描边 / 阴影 / 控件高度 / 间距 | `Design.md` + Arco 主题 | 本文逐组件落地 |

### 0.1 阅读约定

- 本文所有色值、字号、圆角、阴影均来自 `Design.md` §4/§5/§6/§13，并在 token 表中标注出处；落地时一律引用 CSS 变量 / Arco token，**禁止在业务代码里散落硬编码**。
- 顶部导航、左侧导航为 **Figma 定制组件**，本文给视觉规则，但保留菜单/页签语义、键盘与无障碍，不验收"是否直接用 Arco `Menu` / `Tabs`"。
- 图表 / 地图 / 图谱按"**Arco 外围 + 可视化内核**"两段描述：外围（容器/工具栏/状态/弹层/图例位置）归 UI + Arco，内核（图形/空间/关系渲染）归 ECharts / Leaflet / G6。

### 0.2 全局视觉气质（来自 Design.md §2）

浅蓝白、轻科技、低阴影、高留白、强结构、弱装饰。**禁止**深色大屏、霓虹/紫蓝发光、毛玻璃模糊到文字不清、营销 hero、emoji 状态、巨字海报。选中态统一走主蓝 `#165DFF` 文字或浅蓝 `#E8F3FF` 底。

## 8. 筛选器组（FilterBar）

Arco `Select` / `Cascader` / `TreeSelect` / `DatePicker` / `Input.Search`。视觉补充：

| 元素 | 视觉规则 | token |
| --- | --- | --- |
| label | 控件上方，`14px`，`#1D2129` 或 `#4E5969`，下间距 `8px` | §7.2 |
| 输入区 | 高度 `32px`（Figma 参考 28px 可按栅格扩展），白底，边框 `#E5E6EB`，圆角 `2-4px`，placeholder `#86909C` | §7.2 |
