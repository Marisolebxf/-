## 模块：E7 政策分析

构建智能化政策感知与评估引擎，帮助用户把握特定产业/技术领域的政策演进、区域差异与深圳本地实效，支撑从「被动响应政策」到「主动塑造政策环境」。

**承接**：门户（浏览与画像）+ 政策查询（**仅核对语料**，非分析对象准备）+ 系统对比篮**产业 Tab**（政策三项分析发起）+ 系统任务浮层 + 维护管理（复用 ENT-OPS）+ 三项分析。  
**不承接**：对比篮政策文档 Tab；以政策文档入篮；经政策查询发起分析；展示系统政策跟踪与核增对比结果页；对比篮/任务/报告壳层内部实现；独立政策任务中心或下载中心；结果/报告收藏；前端内嵌 NLP/图谱算法。  
**决策**：`DEC-E7-POLICY-LAUNCH-FROM-INDUSTRY-BASKET-20260807`（对象=产业；经产业 Tab 发起；**移除政策 Tab**）；政策查询暂定仅为语料核对入口（非主路径）。

## 用户故事（As / Want / So that）

### US-E7-POL-01 发现并准备产业分析对象（对比篮路径）

作为政府科技主管部门、产业园区、投资机构或研究团队，我想在产业查询中找到目标**产业**并加入系统对比篮产业 Tab 暂存，以便后续经产业 Tab 发起时序、区域对比或深圳三维政策分析（系统自动关联相关政策；查询本身不发起分析）。

### US-E7-POL-01b 在分析配置页选定产业或技术领域（页内路径）

作为业务用户，我想在政策分析配置页选择分析锚点类型——**产业（恰好 1 个）或技术领域（可多选 ≥1）二者互斥**——其中产业可预填自对比篮或页内直选，技术领域**仅页内多选、暂不进对比篮**，以便在生成分析前确认对象并预览系统自动关联的政策语料。

> 决策：`DEC-E7-POLICY-SCOPE-MUTEX-20260807`（方案 A：XOR；技术领域可多选；不进篮）。

### US-E7-POL-01c 在政策查询中核对关联语料（辅助，非主路径）

作为研究团队或政府科技主管部门，我想在专题政策查询（`/policy/search`）中按关键词/层级/地域检索并打开政策摘要，以便**核对**系统将自动关联到的政策语料是否覆盖关键文件；查询**不**入篮、**不**发起三项分析，也不替代配置页「关联政策概要」。

> 暂定产品解释：Bid 叶子为「选定产业/领域后自动关联」；专题政策查询现阶段仅作语料核对辅助，主路径对象准备见 US-E7-POL-01 / 01b。与门户多维检索分轨。

### US-E7-POL-05 经系统对比篮产业 Tab 分发政策分析

作为业务用户，我想在系统 Shell 对比篮的**产业 Tab**中勾选产业对象，并在「发起分析」中选择政策时序 / 区域政策对比 / 深圳政策现状，分发到对应分析页，以便以产业为锚点统一发起分析，且不在篮内查看分析结果。

> 依赖共享系统对比篮浮层（`ENT-COMPARE`）；**无政策文档 Tab**、**无技术领域 Tab**（`DEC-E7-POLICY-LAUNCH-FROM-INDUSTRY-BASKET-20260807` + `DEC-E7-POLICY-SCOPE-MUTEX-20260807`）。

### US-E7-POL-02 完成选定领域的政策时序洞察

作为政府科技主管部门或研究团队，我想在配置页确认锚点（1 个产业 **或** ≥1 个技术领域）、查看关联政策概要、选择时序粒度并提交分析任务，经系统任务过程后查看不可变结果（密度/支持强度趋势与关键节点），以便预判政策窗口期并提前布局。

### US-E7-POL-03 完成跨区域政策标准化对比

作为政府科技主管部门、产业园区或投资机构，我想配置区域集合并提交对比分析任务，经系统任务过程后查看矩阵/雷达/热力与差异结论，以便借鉴先进经验并优化本地或招商策略。

### US-E7-POL-04 完成深圳政策三维框架评估与短板定位

作为政府科技主管部门或研究团队，我想在三维框架的三张固定指标卡上看深圳政策供给：支持力度只展示政策条数与政策层级（扶持力度档位不可算），产业或技术领域锚点只改变产业适配性，落地实效在数据齐之前整卡不可算；提交后查看深圳在城市截面中的供给规模与层级合成，而不是一份由用户勾选拼出来的资金竞争力分。

> 招标：`§1.1.1.2.4.2.6.3.1 指标体系构建`。2026-10-24 偏离「自由选择核心指标」：源侧无金额档位，合成分与条数秩相关 0.9467，不得称资金强度。权重与档位定义仍 ⚠️ QPOL-02。功能合同见 `FUNC-DESIGN-E7-政策分析.md` §3.6 v0.5。

### US-E7-POL-06 跟踪、恢复并在排队阶段撤回政策分析任务

> 依赖共享 `SystemTaskLayer`；不复制队列/槽位内部故事。

### US-E7-POL-08 在门户政策扶持展示中浏览

### US-E7-POL-09 在政策维护管理中完成内容运营与配置治理

作为内容运营或数据治理人员，我想在复用企业 ENT-OPS 菜单形态的政策维护管理中维护门户内容与政策主体/配置，以便前台展示与分析消费已发布数据，且不在前台页内编辑发布。

> 依赖共享能力 ③ `ENT-EXPORT`（企业/产业链已落地）；政策只提供 `report_template_id`、章节数据与 fingerprint。

## 场景 walkthrough（主路径 + 异常路径）

### 主路径 0 · 准备产业分析对象（US-E7-POL-01）

1. 从专题菜单进入产业查询（或已有产业篮对象）。
2. 将目标**产业**加入系统对比篮产业 Tab；角标同步；**停留原页**。
3. 门户仅浏览与画像；政策查询见辅助路径 0c；二者均**不**提供政策文档入篮；技术领域不进篮。

### 主路径 0a · 配置页直选锚点（US-E7-POL-01b）

1. 进入时序（或区域/三维）配置页；选择对象类型「产业」或「技术领域」（互斥）。
2. 产业：从对比篮预填或页内两框选集群（可再选 L0）；只选集群=查全部映射产业；无映射禁生成。技术领域：页内多选 **≥1**（不写篮）。
3. 查看「关联政策概要」；配置粒度（时序）等后「生成分析」。

### 辅助路径 0c · 政策查询核对语料（US-E7-POL-01c）

1. 可选：在发起分析前/后进入 `/policy/search`，用智能检索或高级筛选定位关键政策。
2. 打开摘要核对是否在预期语料范围内；**无**「加入对比篮」「深度分析」。
3. 返回配置页或产业篮继续主路径；核对结果不写回分析任务配置。

### 主路径 0b · 产业对比篮分发政策分析（US-E7-POL-05）

1. 打开系统对比篮 → **产业** Tab；勾选 **1** 个产业。
2. 「发起分析」→ 任务选择中除产业任务外，增加分组「政策分析」：时序 / 区域对比 / 深圳现状。
3. 选择任务并「下一步：前往配置」；目标页接管 `object_type=industry` + `object_ids[]` + `analysis_type`。
4. 目标页显示「来自对比篮 · 产业」；「调整对象」原位重开**产业** Tab。
5. 篮内不展示分析结果；系统按选定产业自动关联政策语料（演示阶段可用 Mock）。

### 主路径 A · 时序洞察（US-E7-POL-02 + 06/07）

1. 经产业对比篮分发 **或** 菜单进入配置页后页内选定锚点，进入 `/policy/overview`。
2. 确认对象类型（产业 XOR 技术领域）、关联政策概要与时序粒度，点击「生成分析」→ 系统 analysis 任务过程视图（阶段 Steps，非虚构百分比）。
3. 可离页；从系统任务浮层恢复；`queued` 可撤回，`running` 不可取消。
4. succeeded 后显式「查看结果」：阅读密度/支持强度趋势与关键节点明细。
5. 在有效结果上「生成报告」→ 系统 report 任务（统一模板）→ **先**打开 HTML 预览 → 再下载同源 PDF。

### 主路径 B · 区域对比（US-E7-POL-03 + 06/07）

1. 进入 `/policy/analysis`，配置区域集合与评价维度。
2. 「生成分析」走同一系统任务过程壳层（政策阶段文案）。
3. 显式查看结果：矩阵 / 雷达 / 热力与差异结论、条款明细。
4. 有效结果可生成/阅读/下载区域对比报告。

### 主路径 C · 三维框架（US-E7-POL-04 + 06/07）

1. 进入 `/policy/recommendation`，确认产业或技术领域锚点。三张卡已固定：支持力度（条数、层级、档位不可算）、产业适配性（随锚点）、落地实效（不可算）。没有一级权重输入，没有二级勾选。
2. 「开始分析」只校验锚点。落地实效为空不挡提交。不创建「每维至少 1 个勾选」或「权重合计 100%」任务。
3. 显式查看结果：支持力度为深圳城市截面（分数、名次、条数、层级均值，档位 null，标明条数主导、非资金强度）。适配性只在实包有字段时展示。落地实效整卡空。不出三维综合分。
4. 有效结果可生成/阅读/下载深圳政策评估报告；报告不得把空的落地实效或 null 档位写成 0 分。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 查询零命中 | 结果空态；不回退伪造推荐冒充命中 | 调整条件或清空回推荐态 |
| 仅预填示例/进热门未应用 | 不写入最近检索 | 执行查询或应用筛选 |

| 关联政策为空 | 分析区空态 | 更换产业对象后重跑 |
| 加载 / 接口失败 | 骨架或错误条 + 重试 | 等待 / 重试 |
| 无报告权限 | 「生成报告」/下载禁用或失败关闭 | 申请权限；结果仍可读 |
| 三维权重≠100% | 阻断计算 | 修正权重 |
| 与门户检索混淆 | 专题路由保持 `/policy/search`，不跳转 portal | — |
| 系统篮出现「政策」Tab | 不符合合同（已移除） | 仅企业/产业/服务机构/区域等既有 Tab |
| 空选/多选产业发起政策三项 | 阻断 | 恰好勾选 1 个产业 |
| 产业链对象发起政策三项 | 禁止 | 改选产业（非产业链）对象 |
| 页内聚合对比篮按钮 | 不得出现 | 改用系统 Shell 入口 |
| 查询/门户「加入对比篮」写政策 / 「深度分析」 | 不符合合同 | 引导产业查询入篮 → 产业 Tab |

| running 任务 | 无取消入口 | 等待或联系管理员 |
| 过期结果点生成报告 | 失败关闭，结果仍可读 | 复制配置重跑分析 |
| 报告框架未激活 | 正式生成/下载失败关闭并说明 | 保留结果阅读 |
