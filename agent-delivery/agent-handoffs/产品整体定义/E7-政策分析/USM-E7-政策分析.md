## 模块：E7 政策分析

构建智能化政策感知与评估引擎，帮助用户把握特定产业/技术领域的政策演进、区域差异与深圳本地实效，支撑从「被动响应政策」到「主动塑造政策环境」。

**承接**：政策查询（只入篮）+ 门户政策扶持展示（只入篮）+ 系统对比篮政策 Tab（**唯一分析发起**）+ 系统任务浮层 + 维护管理（复用 ENT-OPS）+ 三项分析。  
**不承接**：展示系统政策跟踪与核增对比结果页；查询/门户「深度分析」直达；对比篮/任务/报告壳层内部实现；独立政策任务中心或下载中心；结果/报告收藏；前端内嵌 NLP/图谱算法。

## 用户故事（As / Want / So that）

### US-E7-POL-01 发现并准备政策分析对象

作为政府科技主管部门、产业园区、投资机构或研究团队，我想用与企业/产业查询相同的工作台模式（智能检索 / 查政策 / 高级筛选）找到政策对象，并加入系统对比篮暂存，以便后续在对比篮中发起时序、区域对比或深圳三维分析（查询本身不发起分析）。

### US-E7-POL-05 经系统对比篮暂存并分发政策分析

作为业务用户，我想在系统 Shell 对比篮的**政策 Tab**（已预留位置）中管理最多 50 份政策文档，并选择分析任务分发到政策时序 / 区域对比 / 深圳现状页，以便跨页面汇集对象后统一发起分析，且不在篮内查看分析结果。

> 依赖共享系统对比篮浮层能力（`ENT-COMPARE`）；本故事只定义政策域激活、入篮字段、分发任务与来源页接入，不复制浮层壳层内部故事。

### US-E7-POL-02 完成选定领域的政策时序洞察

作为政府科技主管部门或研究团队，我想在已准备的对象上下文下配置并提交时序分析任务，经系统任务过程后查看不可变结果（密度/支持强度趋势与关键节点），以便预判政策窗口期并提前布局。

### US-E7-POL-03 完成跨区域政策标准化对比

作为政府科技主管部门、产业园区或投资机构，我想配置区域集合并提交对比分析任务，经系统任务过程后查看矩阵/雷达/热力与差异结论，以便借鉴先进经验并优化本地或招商策略。

### US-E7-POL-04 完成深圳政策三维框架评估与短板定位

作为政府科技主管部门或研究团队，我想配置三维指标与权重并提交评估任务，经系统任务过程后查看得分、优势短板与优化建议，以便制定针对性政策优化方案。

### US-E7-POL-06 跟踪、恢复并在排队阶段撤回政策分析任务

作为业务用户，我想通过系统任务浮层跟踪政策分析任务，在离页后恢复过程或结果，并在排队阶段撤回未开始的任务，以便与企业/产业链分析使用同一套任务规则。

> 依赖共享 `SystemTaskLayer`；不复制队列/槽位内部故事。

### US-E7-POL-08 在门户政策扶持展示中浏览并入篮

作为产业研究决策者或业务用户，我想在门户政策扶持六页中浏览政策展示，并将政策对象加入系统对比篮暂存，以便后续在对比篮中发起专题分析（门户不发起分析）。

### US-E7-POL-09 在政策维护管理中完成内容运营与配置治理

作为内容运营或数据治理人员，我想在复用企业 ENT-OPS 菜单形态的政策维护管理中维护门户内容与政策主体/配置，以便前台展示与分析消费已发布数据，且不在前台页内编辑发布。

### US-E7-POL-07 从有效政策分析结果生成、阅读并下载报告

作为研究团队或政府科技主管部门，我想在成功且有效的政策分析结果页点击「生成报告」，由统一报告模板先生成系统性 HTML 预览页，再下载与该预览同一修订的 PDF，以便对外引用与归档。

> 依赖共享能力 ③ `ENT-EXPORT`（企业/产业链已落地）；政策只提供 `report_template_id`、章节数据与 fingerprint。

## 场景 walkthrough（主路径 + 异常路径）

### 主路径 0 · 政策查询准备（US-E7-POL-01）

1. 从专题菜单进入 `/policy/search`（默认 `mode=smart`）。
2. 看到与企业/产业查询同序的工作台：模式栏 → 搜索框 → 示例/热门 → 最近检索 → 推荐政策。
3. 以智能检索或查政策发现对象；智能检索在框下显示可关闭 SmartChip，移除后按剩余条件重算；结果卡不重复显示匹配关键词。
4. 点击「高级筛选」或「热门政策」进入 `mode=advanced` 独立高筛页；热门仅预置条件，需「应用筛选」后才执行。
5. 有效执行后写入当前模式最近检索；点击记录恢复并重跑。
6. 在结果卡点击「加入对比篮」（按钮变为「已加入」）；系统 Shell 角标同步；**停留原页**。查询工具栏不出现聚合「对比篮」按钮。
7. **不提供**「深度分析」或任何直达分析页动作；要分析必须走系统对比篮。

### 主路径 0b · 对比篮分发（唯一分析发起 · US-E7-POL-05）

1. 点击系统 Shell 对比篮入口展开浮层，切换到 **政策** Tab（显示 `X/50`，不再是「开发中」空页）。
2. 筛选/勾选政策对象；底部「发起分析」打开任务选择：政策时序分析 / 区域政策对比 / 深圳政策现状分析。
3. 选择任务并「下一步：前往配置」；目标页接管 `policy_ids` 与 `return_context_id` 后，面板收起、入口保留。
4. 目标页显示「来自对比篮」；可通过系统入口或页内「调整对象」（仅触发系统浮层，非第二套篮页）原位重开政策 Tab。
5. 篮内始终不展示时序图、对比矩阵、三维得分或报告。
6. 查询页、门户页、摘要 Drawer **均不得**绕过本路径发起分析。

### 主路径 A · 时序洞察（US-E7-POL-02 + 06/07）

1. **仅**经对比篮分发进入 `/policy/overview`，ContextBar 展示对象摘要（来自对比篮）。
2. 配置时序粒度等参数，点击「生成分析」→ 进入系统 analysis 任务过程视图（阶段 Steps，非虚构百分比）。
3. 可离页；从系统任务浮层恢复；`queued` 可撤回，`running` 不可取消。
4. succeeded 后显式「查看结果」：阅读密度/支持强度趋势与关键节点明细。
5. 在有效结果上「生成报告」→ 系统 report 任务（统一模板）→ **先**打开 HTML 预览 → 再下载同源 PDF。

### 主路径 B · 区域对比（US-E7-POL-03 + 06/07）

1. 进入 `/policy/analysis`，配置区域集合与评价维度。
2. 「生成分析」走同一系统任务过程壳层（政策阶段文案）。
3. 显式查看结果：矩阵 / 雷达 / 热力与差异结论、条款明细。
4. 有效结果可生成/阅读/下载区域对比报告。

### 主路径 C · 三维框架（US-E7-POL-04 + 06/07）

1. 进入 `/policy/recommendation`，配置三维指标与权重（合计 100%）。
2. 「生成分析」提交系统任务；权重非法时不创建任务。
3. 显式查看结果：仪表盘、优势/短板、策略卡。
4. 有效结果可生成/阅读/下载深圳政策评估报告。

### 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 查询零命中 | 结果空态；不回退伪造推荐冒充命中 | 调整条件或清空回推荐态 |
| 仅预填示例/进热门未应用 | 不写入最近检索 | 执行查询或应用筛选 |
| 未带上下文进分析页 + 政策篮为空 | 对象空态；**仅** CTA「去政策查询入篮」；不提供打开对比篮主 CTA | 查询入篮后再经对比篮发起 |
| 未带上下文进分析页 + 政策篮有对象 | 对象空态；CTA「去查询入篮」**或**「打开对比篮」发起分析 | 打开系统浮层政策 Tab 勾选并发起，或先补入篮 |
| 页内私有对象选择器冒充发起 | 禁止 | 一律走对比篮分发 |
| 关联政策为空 | 分析区空态 | 返回查询更换对象 |
| 加载 / 接口失败 | 骨架或错误条 + 重试 | 等待 / 重试 |
| 无报告权限 | 「生成报告」/下载禁用或失败关闭 | 申请权限；结果仍可读 |
| 三维权重≠100% | 阻断计算 | 修正权重 |
| 与门户检索混淆 | 专题路由保持 `/policy/search`，不跳转 portal | — |
| 政策 Tab 仍为开发中 | 不符合本包激活合同 | 应显示可操作列表与 `X/50` |
| 第 51 份入篮 | 阻断并提示已满 | 移除后再加入 |
| 跨 Tab 混选分发 | 禁止；提示仅可分发当前政策 Tab 选择 | 取消跨类勾选 |
| 页内聚合对比篮按钮 | 不得出现 | 改用系统 Shell 入口 |
| 查询/门户出现「深度分析」 | 不符合合同 | 仅保留加入对比篮 |
| 同类型已有 queued/running | 不创建新 analysis 任务，引导恢复原任务 | 从系统任务浮层进入 |
| running 任务 | 无取消入口 | 等待或联系管理员 |
| 过期结果点生成报告 | 失败关闭，结果仍可读 | 复制配置重跑分析 |
| 报告框架未激活 | 正式生成/下载失败关闭并说明 | 保留结果阅读 |
