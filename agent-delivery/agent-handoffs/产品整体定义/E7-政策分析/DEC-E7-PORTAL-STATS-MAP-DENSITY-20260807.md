## 决策

门户「政策概览」内 **概况统计（P-17 / view=stats）** 与 **政策地图（P-18 / view=map）** 为**同一数据域的两种读法**，不是两套业务对象：

1. **共享数据域**：按全国 / 省 / 市（及地图下钻区域）汇总的**政策发布量**（件数及约定派生）。
2. **概况（stats）**：表/图读**政策数量**与**发布连续性**（国/省/市地域尺度），可含时序与明细；**不**挂级别分布/类型分布结构图（招标未点名，已确认不承接）。
3. **地图（map）**：概况数据的**空间投影**；主视觉用**热力 / 色阶**表达「发布密度」；点选区域下钻相关政策列表。
4. **密度代理（门户 V1 默认）**：以区域政策**件数**驱动热力/色阶；**不**把专题「政策密度指数」强行等同为本视图主指标。
5. **与力度分离**：P-20 `view=rank` 走**支持力度**榜单语义；**不得**用力度分充当地图密度主色阶。
6. **地图无对照需求**：map 工具条只保留产业 + 地域；不出现对照选择；点选不入对照集（见 STATS-INDUSTRY-COMPARE）。
7. **地图铬**：复用 `SharedMapChrome`——工具栏左上、热力图例左下、右上「显示热力」开关；关闭热力后保留点位。
8. **双视图**：主区支持 **地图 | 列表** 切换（对齐产业链总览 / 企业分布）；列表为区域×件数表，点行等同地图点选下钻；右侧政策列表保留。

## 不变

- Bid 六叶子不删；概览内仍为 `stats | map | rank` 三视图（见 TAB-MERGE-A）
- 门户只入篮、不发起分析
- 无页级全局 ContextBar（见 NO-GLOBAL-FILTER）

## Demo as-built（2026-08-07）

- 概况/地图共用产业 Cascader + `PolicyPortalRegionSelect`（URL `industry` / `geo`）
- `PolicyLeafletMap` + `SharedMapChrome`：件数热力；图例「发布密度（件数）」
- 右侧列表：点标题开政策画像抽屉；「加入对比篮」；分页每页 15
