## 13.1 部署拓扑（lumen）

| 服务 | 仓 |
| --- | --- |
| 专题前端 | `lumen-ui-topic` |
| 网关 / topic / metrics | `lumen-svc-platform` |

| 类 | 必测 |
| --- | --- |
| 接口 | 空 200、未实现 501、无权 4xx |
| 切面 | 仅 published；薄包演进禁用 |

| D12 | lumen 环境无 demo 依赖 |
