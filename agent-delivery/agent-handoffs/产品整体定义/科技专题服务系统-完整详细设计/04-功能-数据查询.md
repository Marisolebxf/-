# 04 · 功能设计 · 数据查询

条款：`1.1.1.2.4.1`。出口：`lumen-ui-topic` 查询工作台。catalog：查询侧条目待补，暂用条款号追踪。

---

## 1. 需求来源

招标：数据智能呈现（综合查询 + 统一结果展示）+ 数据智能分析（推荐图表、自定义图表、图表面板）。  
角色：招标「科技治理、产业研判与创新决策」使用者；具体岗位待业务确认。

## 2. 需求分析

| ID | 需求 | 优先级 |
| --- | --- | --- |
| QRY-01 | 关键词与语义融合探查 | P0 |
| QRY-02 | 结构化条件与图谱联动探查 | P0 |
| QRY-03 | 列表 + 图谱两种结果，可筛选排序 | P0 |
| QRY-04 | 术语解释与主体详情（产业/技术/企业等七要素） | P0 |
| QRY-05 | 查询结果导出 Excel/JSON，可定制字段 | P1 |
| QRY-06 | 按结果语义推荐图表 | P1 |
| QRY-07 | 自定义字段/图表类型 | P1 |
| QRY-08 | 多图表面板、模板、导出 | P2 |

数据：ES 检索派生 + ADS 指标 + A 面子图。不在查询页做 NER 建图。

## 3. 功能设计

入口：专题「数据查询」。主路径：输入 → 解析（关键词/语义/过滤器）→ 结果区（列表默认，图谱可切）→ 点开详情或导出。  
异常：无权限不返回邻居摘要；引擎未就绪 501；无命中 200 空列表。  
权限：查询范围随角色数据域裁剪。

## 4. 算法映射

| 能力 | 算法 | 标签 |
| --- | --- | --- |
| 关键词/语义 | `lumen-topic-py` 检索门面；语义模型未注册则降级关键词并 honesty | M / 501 |
| 图谱联动 | `.2.15`（1）（2）（3）live | G1 |
| 相似度探查 | `.2.15`（4） | 未注册 **501** |
| 推荐图表 | 规则匹配字段类型；若上模型须 registry | M |
| 热度词云等 | `.1` 资讯/论文类指标 | M |

## 5. 详细实现

调用链：前端 → `/topic/v1/.../search|graph|metrics` → Java → `/internal/*`。

| 组件 | 职责 |
| --- | --- |
| Java | 鉴权、分页、把 ES/ADS/图 JSON 聚合；不写算法 |
| Python 检索 | ES 查询、语义向量（若有） |
| Python 图适配 | 子图截断、`source` |
| 存储 | ES 索引见各域 `stores/elasticsearch/`；实体主键=项目归一键 |

时序（查询）：解析 → 并行 ES +（可选）A 面 relations → 统一结果 DTO → 前端。  
导出：异步若超阈值；写审计（谁、条件、条数）。

错误：无权 4xx；未实现 501；截断时 honesty.truncated=true。

## 6. 本模块非功能

检索 P95 目标（dev 基线待测后写入 13 章）：列表 < 2s（万级命中分页）。子图默认上限节点数截断。导出行数上限 + 频控。

查询页抽取实体；用论文引用网当默认图；把展示驾驶舱检索搬来另造契约。  
产品五件套：企业查询见 `E1-企业查询/`（交叉引用，不摘线框）。
