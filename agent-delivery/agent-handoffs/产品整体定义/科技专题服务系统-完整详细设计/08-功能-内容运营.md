# 08 · 内容运营中心

条款：`1.1.1.2.4.5`。

## 1–2. 需求

基础数据管理（七要素内容工具）、专家知识管理（八类）、全要素图谱管理、可视化管理、工单申请、门户内容。

## 3. 功能设计

运营改的是 **DWD/CMS 账本与门户稿件**，不是在线改亿集内部 vid。图谱管理：实体/关系/属性生命周期 + 绘制预览（自绘 G6）。破坏性 Schema 走人工门禁（Q8）。  
可视化管理 / 门户：配置展示用的全景、报告入口，不另造本体。  
工单：系统工单与咨询回复；与 09 用户侧工单列表打通同一工单域。

## 4. 算法映射

图谱运营对齐 `.2` 建图面：GDF 触发亿集任务。专家知识为 CMS。不在运营台跑 NER 当生产建图。

## 5. 详细实现

管理 API 与业务查询凭证分离（Q9）。本仓运营台 **禁止嵌亿集管理 UI**。绘制工具读 A 面预览 JSON。  
五件套：`ENT-OPS-维护管理` / `CHAIN-OPS-维护管理` 交叉引用。

## 6. 非功能增量

运营写操作全审计。管理凭证不出前端。

## 7. 明确不做

把运营台当第二套 Ontology IDE；绕过 DWD 直写图存储。
