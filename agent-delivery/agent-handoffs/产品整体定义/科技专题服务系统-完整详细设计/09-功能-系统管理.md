# 09 · 系统管理中心

条款：`1.1.1.2.4.6`。

## 1–2. 需求

账户（注册/登录退出/信息）、消息、工单、任务、历史关注。

## 3. 功能设计

账户与网关 SSO 对齐，专题不自建第二套登录（若招标「注册」存在，走统一账户服务）。  
消息：列表/查看/红点。  
工单：用户侧列表（已发起/未完成）与 08 运营侧同一域。  
任务：**系统待办 ≠ 分析 Job**。分析任务跳转到 Job 详情，不在本模块复制状态机。  
关注：浏览与收藏，数据域按权限过滤。

## 4. 算法映射

无。

## 5. 详细实现

账户/权限走平台用户服务 + 网关。消息/工单/关注落应用库。Job 列表 API 只读 Runtime 状态。

## 6. 非功能增量

会话安全、密码策略跟平台。关注数据不出无权对象。

## 7. 明确不做

业务服务各自实现 SSO；把 Job Runtime 塞进「任务管理」表混用。
