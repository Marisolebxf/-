## 2.1 业务闭环

```text
数据查询（发现） → 战略分析（研判 / 生成分析）
        ↓
项目管理 / 内容运营 ← → 信息发布
        ↓
系统管理（账户、消息、工单、任务、关注）
```

查询吃 `.1` 指标 + `.2` 图谱 API。战略分析八域分别吃 `.3`～`.10`。项目 / 发布 / 系统管理无独立深度模型章。

## 2.4 存储需求

不在此列表字段。要求：

- 契约面 = ADS；Java 只读。  
- 检索派生 = ES。  
- 图谱主存按 storage 树（Nebula）；在线查图经适配，应用不感知 Q5。  
- 报告/切面大对象 = MinIO（平台级一份）。  
- Demo 与正式同一套 `stores` 结构，实例 `demo_*` 隔离。  
- 真源：[storage/README.md](../../../data/data-design/storage/README.md)。

## 2.5 接口需求分类

| 类 | 用途 | 失败 |
| --- | --- | --- |
| 同步查询 | 指标、列表、A 面子图、详情 | 空=200；未实现=501 |
| B 面切面 | 全景目录 / 整图 / diff | 仅 published |
| Job | 生成分析 | 轮询状态；结果不可变 |
| 指标 catalog | 8 件套 + 就绪度 | 禁止前端改绿 |
| 导出 | Excel/JSON/面板 | 审计 + 限流 |
