## 10.1 基础指标 `.1`（每类总卡 + 名录）

共性五步：源对接 → 清洗 → 计算 → API → 同步 ADS。Java 只读 ADS。未接源则 D3/D4 诚实，禁止假数。

### 产业链指标

- **职责**：市场规模、企业/机构规模、投融资、全球/全国分布、资讯热点、深圳要素与分布。  
- **读**：产业 ADS。**写**：Python/GDF。  
- **名录**：市场规模及增速、企业成立数、机构成立数、投融资额及增速、分国家企业机构数、分省企业机构数、热点资讯量、深圳要素量、深圳分区分布。

### 技术指标

- **职责**：论文/专利/交易/资讯从全球到区域。  
- **名录**：论文量及增速、深圳论文、区域论文、前沿论文机构、专利量、深圳专利、区域专利、领先专利主体、技术交易额及区域、技术资讯。

### 企业指标

- **职责**：重点企业提取、类型与领域分布、资讯、新增。  
- **名录**：与招标 `.1.3` 对齐；页面指标 `metric_id` 以 ENT seed 为准。

### 人才 / 科研机构 / 政策 / 服务机构

各一类总卡：分布、机构或领域结构、供给或产出、资讯、新增、区域切片。名录以算法库对应小节标题为准，注册进 catalog 后再绑 `metric_id`。

## 10.3 深度模型 `.3`～`.10`

每模型一节压缩为表。输入默认：对象 ID + 产业/区域过滤 + 已注册特征。输出：结构化 Result + honesty + `model_id`。未进 `cfg_model_registry` → 501。

### `.4` 技术链

### `.5` 企业

### `.6` 机构
