## 11.1 总则

本树回答：数据在哪、结构入口、谁写谁读。不回答页面交互。细表在 `storage/{域}/stores/*`，禁止在详设复制 DDL。  
写作顺序（域内）：`00-context` → `01-data-flow`（架构师会签）→ `sources` → `etl` → `stores`。

## 11.2 四引擎

| 存储 | 角色 | 写 | 读 |
| --- | --- | --- | --- |
| MySQL ODS | 贴源 | 正式三方入站；Demo 按 `doc/` 约定写 `demo_*` | ETL |
| MySQL DWD | 标准明细 | GDF/ETL | ETL、算法按需 |
| MySQL ADS | **契约面** | Python / 工厂 | **Java 只读** |
| MySQL DIM | 码表 | 数据任务 | 服务/ETL |
| Elasticsearch | 检索派生 | ETL/Python | 经 Java→Python 或约定门面 |
| NebulaGraph | 图谱主存 | Python | Python（Java 禁 nGQL） |
| MinIO | 对象/报告 | 编排/Python | 下载门面 |

关系库仅 MySQL。Demo 与正式 **同一套 stores 结构**，实例隔离。Q5：在线契约用 `source`，不暴露存储品牌。

## 11.4 其余要素缺口

技术、人才、科研机构、政策、服务机构：**尚未建** `storage/{TECH|TALENT|ORG|POLICY|SVC}`。  
处理：按 ENT/CHAIN 同构扩域；未建前专题详设只写指针与缺口，**禁止**在本目录发明平行 `stores`。项目/发布/关注等用户态可用应用库，不升格为七要素点。

## 11.6 接口清单（非正式）

调用链：网关 `/topic/**` → Java → `/internal/v1/...`。

| 面 | Java 前缀（建议） | Python |
| --- | --- | --- |
| A 图 | `/topic/v1/{element}/graph/**` | `/internal/v1/.../graph/**` |
| B 全景 | `/topic/v1/industry/panorama/**` | 切面 sync |
| Job | 已有 analysis/jobs 前缀 | 见 Job Runtime |
| 指标 | `/metrics/v1/**` | 计算写 ADS |
| 查询 | `/topic/v1/search/**` | `lumen-topic-py` |
| 项目/发布/运营/账户 | `/topic/v1/project|publish|ops|account/**` | 多数无 Python |

错误模型：

| 情况 | HTTP |
| --- | --- |
| 无数据 | 200 空 + 文案 |
| 能力未建 | **501** + honesty.reason |
| 无权 | 4xx，不泄露邻居 |
| 薄切面 | 200 + honesty.payload_thin |

展示复用同一 graph 资源，禁止 display 专有图库。
