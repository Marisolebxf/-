# 05.6 · 政策分析

条款：`1.1.1.2.4.2.6`（**三叶子**）。算法：`.8`（**六模型**）。catalog：`catalog-topic-policy.yaml`。

## 1. 需求来源

页面叶子：政策时序、区域政策对比、深圳政策现状。  
模型另有：焦点、力度、效果、短板、机遇、布局推荐。

## 2. 需求分析

页面先交付三叶子。六模型作为 Job/报告能力，**不发明招标没有的四级菜单**。展示侧政策跟踪（DS-10～12）只引用，菜单仍在展示系统。

## 3. 功能设计

时序/对比/深圳现状 = 列表 + 图表 + 可选政策挂接子图（G1）。效果推演、布局推荐 = Job，入口可放在「生成分析」而非新菜单。

## 4. 算法映射（页面 vs 模型）

| 页面叶子 | 可用模型 | 标签 |
| --- | --- | --- |
| 时序 | `.1` 政策指标 + `.8.1` 焦点（可选） | M |
| 区域对比 | 指标对比；`.8.2` 力度 | M |
| 深圳现状 | 地域切片 | M |
| （无独立菜单）效果 | `.8.3` | G3；与 DS-12 分清：推荐≠因果仿真 |
| （无独立菜单）短板/机遇/布局 | `.8.4` `.8.5` `.8.6` | G3；未注册 501 |

## 5–7. 实现 / 非功能 / 不做

`/topic/v1/policy/**`。政策存储域未建 → 缺口。不做全社会因果仿真。五件套：`E7-政策分析/` 交叉引用。
