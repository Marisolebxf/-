# 05.2 · 产业链分析

条款：`1.1.1.2.4.2.2`。算法：`.3`。  
全景切面 **只引用** Published-Cut。生成分析 **只引用** Job Runtime。

## 1. 需求来源

八叶子：全景图谱、产业周期、区域产业指数、关键环节、瓶颈堵点、深圳情况对比、深圳产业发展、区域竞争力。

## 2. 需求分析

用户要：看一条链的结构（可对比、可沿 published 时间轴）→ 指数与周期 → 诊断关键环节/瓶颈 → 深圳与推荐。历程 `.3.3` 走 CMS，≠ 图谱演进。

## 3. 功能设计

全景三态：当前状态 / 状态对比 / 演进时间轴 = **只播已发布切面**。企业挂接数组可空（诚实）。开始分析不新建相册。

## 4. 算法映射

| 招标叶子 | 算法 | 标签 | 读面 |
| --- | --- | --- | --- |
| 结构可视化 / 下钻与演进 | `.3.1` `.3.2` | G1 | **B** |
| 周期模型与预测 | `.3.6` `.3.7` | M | ADS/Job |
| 区域产业指数 / 竞争力 | `.3.10` | **M** | ADS |
| 关键环节 | `.3.8` | G3 | Job（样板 `chain:diagnosis:key_link`） |

| 热点领域 | `.3.4` | M/G3 | 【算法补】 |
| 发展路线历程 | `.3.3` | M | CMS |

## 5. 详细实现

B 面路径、包字段、无坐标拒发布：Published-Cut。Job 状态机、Input/Result：Job Runtime。  
存储：`storage/CHAIN/`（流图已会签）。切面包进 ADS/对象存储约定见 [11](./11-存储设计与接口设计.md)。

## 6. 非功能增量

切面包大小、时间轴只列 published 刻度。薄包 `honesty.payload_thin`，演进禁用。

## 7. 明确不做

live 播放历史；前端私自 diff；七键结论进切面包。五件套：`E2-产业链分析/` 各 CHAIN-TOPIC-* 交叉引用。
