# 07 · 信息发布

条款：`1.1.1.2.4.4`。

## 1–2. 需求

编辑工具（模板、报告/资讯样式、数据关联、预览保存）+ 推送配置（模板审核、发送对象、多渠道、发送记录）。

## 3. 功能设计

草稿 → 预览 → 提交审核 → 定时/立即发送 → 记录。数据关联只读 ADS/已发布分析结果，发送时固化快照，避免事后口径漂移。

## 4. 算法映射

无深度模型。关联查询复用 04 / 05 已有 API。

## 5. 详细实现

`/topic/v1/publish/**` 或管理端网关路由。对象名单与权限绑定。外发渠道适配器隔离密钥。正文与附件可落 MinIO（`storage/platform/minio.md`）。

## 6. 非功能增量

审核流不可绕过。发送审计（操作者、对象、渠道、时间、模板版本）。外发限流。

## 7. 明确不做

未审核直发生产渠道；把发布模块做成第二个分析引擎。
