# 06 · 项目管理

条款：`1.1.1.2.4.3`。无算法深度模型章。标签默认 **M / CMS**。

## 1. 需求来源

驾驶舱、跟踪管理、内容管理、资源管理（招标叶子见 02 章功能树）。

## 2. 需求分析

运营人员看项目统计与进展，跟踪单项目动态/价值/问题，维护导入与生命周期，管理合作资源标签。可引用战略分析 Job 结果作为「价值分析」附件，不在项目模块重跑模型。

## 3. 功能设计

驾驶舱：统计卡片 + 分布 + 筛选 + 导出 + 个性面板。跟踪：列表→详情（基础/动态/资讯/评价）。内容：导入、字段维护、状态机。资源：标签与合作资源库。权限：项目域与角色绑定。

## 4. 算法映射

无 `.3`～`.10` 专属模型。成效评价若复用综合/企业模型，走已注册 Job 键，否则 501 或纯人工填写。

## 5. 详细实现

建议 Java 前缀 `/topic/v1/project/**`。表落 CMS/ADS（项目存储未单列域 → 缺口，先用应用库 `app_*` 或专题 CMS，不进图本体）。Job 结果只存引用 ID。

## 6. 非功能增量

导出审计。驾驶舱指标须 D9 `metric_id`。

## 7. 明确不做

项目当七要素新点类；用图谱时间轴播项目历程。
