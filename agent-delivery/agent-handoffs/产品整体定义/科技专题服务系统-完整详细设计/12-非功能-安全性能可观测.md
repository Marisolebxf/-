# 12 · 非功能设计（安全 / 性能 / 可观测）

横切要求。模块增量仍写在各功能卷第 6 节。

---

## 12.1 性能

| 类 | 要求（目标，dev 实测后回填 13 章） |
| --- | --- |
| 同步列表/指标 | 分页；避免一次拉全量 |
| A 面子图 | 默认节点/边上限，超出截断 + honesty |
| B 面切面 | 无坐标拒发布；时间轴只请求 published 目录 |
| Job | 异步；离开页面不丢；禁止用同步 REST 跑瓶颈模型 |
| 指标批处理 | 离线写入 ADS，在线只读 |
| 前端首屏 | 指标可先于嵌图；图失败不挡驾驶舱数字 |

## 12.2 容量与限流

导出行数/频率限制。相似度/社群重计算走 Job 或 501。缓存键含 `element` + 参数 hash（基线 D6）。

## 12.3 安全

- 认证鉴权：网关 SSO；业务校验权限点。  
- 授权：图查询无权不返回邻居摘要。  
- 数据分级与审计：导出、发布、运营写、管理凭证使用。  
- 注入/SSRF：禁用 NL2SQL 直查图库。  
- 密钥：亿集管理凭证 ≠ 查询凭证（Q9）。  
- D12：lumen 环境零 demo 服务依赖。

## 12.4 可用性

Job 可恢复。切面不可变。降级用 501 / 诚实空，不用假数据凑 200。薄包禁用演进。

## 12.5 可观测

OTel 全栈（`observability.md`）。图响应必带 `source`。切面带 `snapshot_id`。模型带 `model_id`。前端 `observability.ts`。

## 12.6 前端体验

D8 / D10 指针，不复制 Design.md。关闭评审模式后 DOM 不泄漏 `metric_id` / `GAP-*`。

## 12.7 合规

范围 ±10%。Mock 与正式实例隔离。指标 D9。业务口径走客户决策表。
