## 1. 引言与范围

### 1.1 定位

专题系统给政府、园区、高校、科研机构、智库与科研企业做：查询 → 战略分析 → 项目与内容运营 → 发布 → 账户与任务。  
算法库提供指标、全要素图谱、深度模型。两系统（展示 + 专题）**共用** `gkxlumen-topic` + `gkxlumen-metrics` + 同一张七要素图。

### 1.2 在范围

- `1.1.1.2.4.1`～`.4.6` 六大模块全部叶子（功能设计到服务 / 存储指针 / 接口 / 权限）。  
- 算法 `.1` 七类指标（每类总卡 + 名录）；`.2` 图谱（引用 CROSS-KG）；`.3`～`.10` 深度模型。  
- 共享底座：四平面、A/B/Job、网关鉴权、存储四引擎。

### 1.3 不在范围

- 展示 34 页 USM / Wireframe（只引用 CROSS-KG 覆盖矩阵与 `catalog-display-7modules.yaml`）。  
- 第二套本体；`carrier` 点类升格前不发明。  
- 嵌亿集管理 UI；NL2SQL 直查图库。  
- Palantir 五层运行时；轨迹引擎。  
- 把 RAG/Agent 写成建图开工条件。  
- 「颠覆性技术」产品标签（`Q068`，临时默认不上）。  
- 把 `数据库设计.md` 当总纲（已作废 stub）。

### 1.4 系统边界

| 系统 | 角色 |
| --- | --- |
| `lumen-ui-topic` | 专题前端 |
| `gkxlumen-gateway` | 鉴权、路由、trace |
| `gkxlumen-topic` / `gkxlumen-metrics` | Java 聚合；只读 ADS；Feign Python |
| `lumen-algo-py` / `lumen-etl-es-py` / `lumen-topic-py` | `/internal/*`；写 ADS / ES / 图适配 |
| GDF | ODS→DWD；触发亿集建图任务 |
| 亿集 | 建图/融合/查图能力面（对方路径不进本仓 OpenAPI） |
| `lumen-ui-admin` | 权限与运营，不嵌亿集台 |

调用链：**前端 → 网关 → Java → Python `/internal/*`**。前端不直连 Python / DB / 图库。

### 1.5 假设与依赖

- 物理图库 Q5 未决：应用只经查图 API，`source` 区分实现。  
- ENT / CHAIN 存储域已有；技术 / 人才 / 机构 / 政策 / 服务 **按同构扩域**，未建前登记缺口。  
- 深度模型进 `cfg_model_registry` 后才标 V1，否则 501。
