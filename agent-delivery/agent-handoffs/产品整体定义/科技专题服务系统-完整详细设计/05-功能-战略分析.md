## 5.0 共性

### 需求

用户在选定产业/区域/对象后：看全景或指标 → 必要时 **生成分析** → 对比或下钻 → 导出/进报告。  
服务对象按各域招标原文，缺则待确认。

### 功能设计

- **分析工作区**：左筛选（产业、区域、时间）+ 中主视图 + 右分析/生成。交互边界见 D10，视觉见 D8。  
- **生成分析**：走 Job Runtime（状态、阶段文案、不可变 Result）。正式「开始分析」不 INSERT 图谱 published 包。  
- **对比**：同一 `chain_id`（或对象类型约定键）的两个已发布切面或两份 Job 结果；禁止前端自己 diff 当正式变化数。  
- **时间轴**：仅产业链全景 B 面 published 刻度。技术/企业「历程」走 CMS/ADS，**≠** B 面播放。

### 算法 / 实现共性

| 读面 | 何时 |
| --- | --- |
| A | 技术链全景 V1、关系链、检索 |
| B | 产业链全景结构历史 |
| Job | 诊断、推荐、潜力、瓶颈、多数「识别」 |
| M | 指数、规模、历程、纯统计 |

调用链同 [03](./03-总体设计-共享底座.md)。Java 透传，不写模型。

### 明确不做（全局）

第二套本体；瓶颈五维画成五种点；论文当点；颠覆标签（`Q068`）；lumen 打 demo。
