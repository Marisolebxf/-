## 模块：引育推荐

引育推荐通过一个二级页面中的两个独立视图完成两类任务：从全国企业中识别招引目标，从深圳市内企业中识别培育对象。两类结果都必须可筛选、可排序、可解释，并支持报告和数据导出；本模块不承担候选名单管理、异步任务中心、历史资产、模型公式编辑或完整一企一策生成。

## 1. 目标用户角色

| 产品角色 | bid-reference 角色依据 | 需要完成的业务任务 |
| --- | --- | --- |
| 政府招商与产业管理人员 | 企业分析面向政府；招引模型面向政府招商部门；培育模型面向政府部门 | 形成招引优选名单或本地培育名单，为招商、政策和资源配置提供依据 |
| 园区运营与企业服务人员 | 企业分析面向园区；两类模型分别面向园区运营方 / 管理机构 | 识别园区招引目标与需重点培育的本地企业 |
| 投资机构 / 投资平台产业研究人员 | 企业分析、招引模型和培育模型均明确投资机构 / 平台 | 复核企业推荐指数、价值与潜力，辅助投资和合作匹配 |
| 行业协会产业服务人员 | 培育模型明确面向行业协会 | 查看培育排名、行业分布和所需支持，辅助行业服务 |

> 权限等级、persona、Mock 用户和既有深化材料不替代以上角色来源。行业协会仅进入培育推荐故事。

## 2. 用户活动与故事地图

```text
选择推荐类型
├─ 招引推荐 E-26
│  ├─ US-ENT-RECRUIT-A1 设置条件并执行招引分析
│  ├─ US-ENT-RECRUIT-A2 查看招引名单与企业价值
│  └─ US-ENT-RECRUIT-A3 生成招引报告并导出数据
└─ 培育推荐 E-27
   ├─ US-ENT-RECRUIT-C1 设置条件并执行培育分析
   ├─ US-ENT-RECRUIT-C2 查看培育排名、行业分布与所需支持
   └─ US-ENT-RECRUIT-C3 生成培育报告并导出数据
```

### US-ENT-RECRUIT-A1 设置条件并执行招引推荐分析

作为政府招商、园区运营或投资机构研究人员，我想按企业标签、行业领域和地域来源筛选全国企业并执行招引推荐分析，以便从全国范围锁定与深圳产业方向契合的目标企业。

**验收：**

- 招引视图明确显示对象范围为全国企业。
- 支持按企业标签、行业领域或地域来源设置条件。
- 页面说明综合模型使用产业相关度、政策匹配度和深圳连接度，但不提供无依据的公式或权重编辑器。
- 用户显式点击执行分析后才进入处理中状态；未执行时不显示默认名单或 DEMO 分数。
- 分析条件不会联动或覆盖培育推荐视图的条件。

### US-ENT-RECRUIT-A2 查看招引名单与企业价值

作为招商或产业研究人员，我想从招引名单中选择企业并查看推荐依据和合作价值，以便判断优先对接对象。

**验收：**

- 招引名单以排名为主，展示企业名称、行业领域、地域来源和招引推荐指数。
- 企业行业领域排名在语义闭合后可展示；未闭合时标记 GAP，不展示伪排名。
- 选择名单行后，企业详情与名单联动，不跳离筛选现场。
- 详情呈现产业相关度、政策匹配度、深圳连接度三类综合推荐维度。
- 技术匹配度、成长性、区域适配性作为高潜挖掘证据；若没有独立 `metric_id`，只作解释字段，不显示伪分数。
- 核心优势、关键指标和合作价值均有落点；关键指标中的每个统计项携带自身 `metric_id`。

### US-ENT-RECRUIT-A3 生成招引分析报告并导出数据

作为招商或产业研究人员，我想从当前招引结果生成分析报告并导出数据，以便开展招商对接、内部研判和后续协作。

**验收：**

- 当前招引结果页提供“生成分析报告”和“导出数据”入口。
- 生成中、可用和失败状态在当前页面反馈；失败不清空当前名单。
- bid 未定义文件格式、报告模板和字段范围时，页面不预先宣称具体格式。
- 不新增历史任务中心、个人资产中心或独立导出菜单。

### US-ENT-RECRUIT-C1 设置条件并执行培育推荐分析

作为政府、园区、投资平台或行业协会人员，我想按产业类别、政策导向和企业规模筛选深圳市内企业并执行培育推荐分析，以便发现具有培育价值的本地企业。

**验收：**

- 培育视图明确显示对象范围为深圳市内企业。
- 支持按产业类别、政策导向或企业规模设置条件。
- 页面说明综合模型使用产业相关度、政策匹配度和企业潜力，但不提供无依据的公式或权重编辑器。
- 用户显式点击执行分析后才进入处理中状态。
- 全国招引企业、招引筛选和招引结论不会混入培育视图。

### US-ENT-RECRUIT-C2 查看培育排名、行业分布与所需支持

作为企业培育或产业服务人员，我想从培育排名中查看企业潜力、行业分布和所需支持，以便制定精准扶持政策和“一企一策”。

**验收：**

- 企业排名为主工作区，展示排名、企业名称、产业类别、企业规模和培育推荐指数。
- 行业分布作为补充结果视图，不遮挡或取代企业排名。
- 选择名单行后联动展示产业相关度、政策匹配度和企业潜力。
- 技术壁垒、市场增速、团队背景作为本地潜力识别证据；无独立 `metric_id` 时不显示伪分数。
- 详情明确展示所需支持，并说明其可作为定制“一企一策”的依据；不在本模块直接生成完整政策方案或服务工单。

### US-ENT-RECRUIT-C3 生成培育分析报告并导出数据

作为企业培育或产业服务人员，我想从当前培育结果生成详细分析报告并导出数据，以便开展政策制定、投资决策和合作匹配。

**验收：**

- 当前培育结果页提供“生成分析报告”和“导出数据”入口。
- 报告保留培育排名、行业分布、推荐维度和所需支持的业务语境。
- 报告或导出失败时保留当前结果和筛选条件，并允许重试。
- 不把培育报告扩展为风险洞察报告、企业评估报告或完整一企一策。

## 3. 主路径 walkthrough

### 3.1 招引推荐

1. 用户从企业分析进入“引育推荐”，默认或主动选择“招引推荐”。
2. 页面显示全国企业范围，以及企业标签、行业领域和地域来源筛选。
3. 用户设置条件并执行推荐分析；页面保留条件并显示分析中状态。
4. 分析完成后展示优选企业清单、招引推荐指数和可用的行业领域排名。
5. 用户选择企业，右侧详情联动展示综合维度、高潜挖掘依据、核心优势、关键指标和合作价值。
6. 用户生成分析报告或导出数据。

### 3.2 培育推荐

1. 用户选择“培育推荐”，页面切换为深圳市内企业范围。
2. 页面显示产业类别、政策导向和企业规模筛选。
3. 用户设置条件并执行推荐分析；页面保留条件并显示分析中状态。
4. 分析完成后展示企业排名；用户可切换查看行业分布。
5. 用户选择企业，右侧详情联动展示综合维度、识别证据和所需支持。
6. 用户生成详细分析报告或导出数据。

## 4. 异常与降级路径

| 场景 | 页面行为 | 用户下一步 |
| --- | --- | --- |
| 初始未分析 | 展示当前视图条件，不展示默认名单或虚构分数 | 设置条件并执行分析 |
| 分析中 | 保留条件，防止重复提交，不用旧结果冒充本次结果 | 等待结果 |
| 空结果 | 明确“分析成功但无匹配企业”，保留全部条件 | 调整条件后重新分析 |
| 部分数据缺失 | 保留可用名单；缺失字段显示“暂无数据”，报告披露缺失项 | 查看可用结果或调整条件 |
| 指标语义待确认 | 在具体字段旁显示 `GAP / pending_data_lead` | 等待 Data / 算法 / 何老师闭合 |
| 分析失败 | 保留条件并说明失败，不表现为空结果 | 按原条件重试 |
| 无权限 | 不显示结果数量、排名、详情或导出内容 | 返回或申请授权 |
| 报告 / 导出失败 | 保留当前结果，显示当前操作失败 | 重试或继续查看结果 |
