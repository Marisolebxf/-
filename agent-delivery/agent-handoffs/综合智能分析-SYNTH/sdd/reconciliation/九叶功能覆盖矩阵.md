## 闭环 DoD（每叶）

- 活力：默认三元组快照 200 同构；`USE_MOCK=false` 任务全链成功；135④ 区级裁定落文档；排名榜接 `synth_vit_rank`。
- 要素：三透镜接真数；**四维=blocked（`[]+reason`，页面红问号，无演示数据；解锁四步完成后接 `synth_elem_four_dim_score`）**；136 全景区上线读真实聚合。
- 协同：图谱接口（region/compare/window + 不可变 snapshotId 绑定）+产业筛选上线；预填含 RELATION_INPUT → 图谱非空无重复；`batch_meta` 持久化；`cache_key` 可改指最新批、旧 snapshotId 不串批；指定快照无映射不可用（禁回落最新批）；集群/孤立接 `synth_collab_cluster`；报告=前端真快照 PDF；策略=LLM 证据锚定+待审核。
- 活力：任务/快照 fp 含 `weight_profile`（默认 INDEX_MAIN）；换档不复用他档；旧三段无权重信息 → `legacy_unknown` 禁复用；`snapshotId` 含批次不可变，与 `cache_key` 分离。
- 通用：缺行 null+reason；只读 succeeded 最新批；预填 🧪；D4 改 live 须实算。
