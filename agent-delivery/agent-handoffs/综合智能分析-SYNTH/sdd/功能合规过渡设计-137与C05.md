## 4. C-05 gapfill 设计

### 4.1 关系年化输入

表：`demo_gkxlumenx_ads`（demo）/ `gkxlumenx_gapfill`（正式）`.gapfill_synth_collab_relation_year`。

关键字段：地区/对比范围、关系类型、事件年、起点/终点主体及行业、权重、源事件 ID、`source_has_year`、`fill_method`、`gapfill_batch_id`、`is_mock`。

- 唯一键：`(region_code, compare_scope, relation_type, source_entity_id, target_entity_id, source_event_id, event_year, gapfill_batch_id)`
- 窗口由表中最大 `event_year` 回推：1y/3y/5y。
- 本期 seed 为深圳默认范围 2021–2025 共 15 条演示边，`fill_method=demo_year_proxy`、`is_mock=1`。

### 4.2 年度产出序列

表：`demo_gkxlumenx_ads`（demo）/ `gkxlumenx_gapfill`（正式）`.gapfill_synth_collab_output_year`。

关键字段：地区/对比范围、事件年、`collab_score`、`joint_patent_count`、`output_metric_id`、`fill_method`、`gapfill_batch_id`、`is_mock`。

- 唯一键：`(region_code, compare_scope, event_year, output_metric_id, gapfill_batch_id)`
- 本期 seed 为 2021–2025 共 5 行，`fill_method=demo_year_series`。

### 4.3 计算链

```text
gapfill relation_year
  → 按 window 截取年份
  → 构图：nodes / edges
  → completeness / centrality / density / collabIndex

gapfill isolate_year
  → 追加零度节点
  → 连通分量识别协同集群
  → 输出孤立主体与待审核建议

gapfill output_year
  → Pearson(collab_score, joint_patent_count)
  → effectEval points / relationResult

gapfill relation_year
  → relationInput(jointPatent/project/talentFlow 事件数)
  → 结果快照 snapshotId=batch:...|gapfill_transitional
```

返回 `dataSource=gapfill_transitional`，页面和报告标记“功能合规过渡 · gapfill is_mock=1”。

- C-05 图/网络统计回退到 gapfill 时，Python 用合成批号 `gapfill_transitional` 生成可读结果快照，避免被 ADS relation_input 的旧批号或缺失 batch_meta 误拦截；Java 不再把它误判为无批。
- 图谱接口仅对 `gapfill_transitional` 过渡快照回读同一 conditions 的 gapfill 关系；任意缺失的 `task:*` / 正式 `batch:*` 快照仍严格返回 `batch_meta_missing`，不回落。
- 任务链走 gapfill 时，仍由 Python 发布 `synth_collab_batch_meta`，以保留 task snapshot 的不可变追溯与 A/B 批隔离。
- 集群归属使用功能合规过渡规则：关系图连通分量；集群分=内部关系密度；响应和方法摘要必须标过渡态。正式 C-02 规则定稿后替换。
- 策略建议优先调用 LLM；LLM 不可用时使用关系输入和相关性事实生成确定性建议，全部 `reviewStatus=待审核`，不得编造数值。

## 7. 验收

1. 137：要素快照返回四条 `evaluationDimensions`，页面和报告可见，且带 `pending_registration/is_mock=1`。
2. C-05：默认三窗均返回非空 relationInput/nodes/edges、网络统计、年度相关性序列、协同集群和孤立主体；结果及图谱响应可追溯 `gapfill_transitional`。

5. 正式真源恢复后：停止 gapfill 读取，改读正式输入/ADS；137 完成 METRIC-OPEN 后将 `metric_status` 切为 `registered`。
