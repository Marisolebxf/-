# 活力趋势时间范围与分项权重修复

日期：2026-11-07。适用：区域创新活力工作台、新任务装包、网页报告及 PDF 分项表。

## 现象与根因

- 新成功任务选择最近1年，结果 trend 仍为空。原演示历史只在最近3年条件下有数据，严格按条件读取时最近1年/5年无历史。
- 分项指标表有权重列但全部为空。`M_SYNTH_VIT_INDICATOR` 定义的12分项用于解释，不参与重新合成维分；没有单项权重定义，`synth_vit_indicator` 也无权重字段。实际权重在 `synth_vit_weight` 的四维行。

## 处理规则

1. 继续严格匹配区域×对比范围×时间范围×权重档；不把最近3年真实结果回填最近1年/5年。
2. 05 SQL 在已有指数表补2020–2023年度 mock 行，保留2024基期。07 SQL仅复制指定的 mock seed/history 批到最近1年/5年，五表成套、独立批号。所有复制行均保留 `is_mock=1`。此为演示数据，不能当作真实历史。
3. 展示最近1/3/5个年度点，最近1年显示可见圆点；同比另读取相邻上一年，缺年/零基数不计算同比。
4. 前端 real 模式可查询任意受支持条件快照，不能用本地 mock 的默认条件限制 API。旧任务为空时，仅在同条件快照末点与任务指数一致时补显示趋势；不修改任务冻结结果。
5. 页面、网页报告、Java PDF去掉无定义的分项权重列，保留四维权重。不得将维度权重复制到每个分项。
