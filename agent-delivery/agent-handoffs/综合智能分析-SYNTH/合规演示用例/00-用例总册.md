## 1. 条件枚举声明（照抄总控 §1.2；**与代码一致，禁止另选**）

> 枚举真源：`lumen-ui-topic/src/composables/useSynthCtx.ts`（`REGION_OPTIONS` / `COMPARE_OPTIONS` / `WINDOW_OPTIONS` / `SYNTH_DEFAULTS`）。M1b/M3/M5 不得另造城市、对比范围、窗口或权重档。

1. `region`：**深圳 / 广州 / 东莞 / 惠州**（`REGION_OPTIONS`，四城均已 seed 扩展）
2. `compare`：**全国重点城市**（唯一 `COMPARE_OPTIONS`）
3. `window`：**最近1年 / 最近3年 / 最近5年**（URL 码 `1y | 3y | 5y`）
4. 活力 `weight_profile`：**`INDEX_MAIN`（默认）/ `EQUAL`** 两档为可演示正档；**`WEIGHT_MAIN` 为登记档（可演示，页面下拉未露出，经 URL 直达）**；legacy 档 `WEIGHT_MAIN`/`TEMP_*` 形态中无法从冻结权重 / `dimScores.weight` / `methodVersion` 确认档位的存量任务一律 **`legacy_unknown`，禁复用，仅作反例用例**
5. **默认三元组（秒开）**：深圳 × 全国重点城市 × 最近3年（`Q-SYNTH-V-02` 🟡，UI 带 ⚠️「待甲方确认」角标策略）
6. 活力 `analysis_fp` 四段 = `region|compare|window|weight_profile_norm`（缺省归一 `INDEX_MAIN`）；要素/协同三段 = `region|compare|window`。同条件 running 任务单飞恢复；`legacy_unknown` 永不参与自动复用。
7. 非默认三元组无快照 → 快照接口 404（`IntelBatchSnapshotNotFound`），前端进 no_batch/config 待分析态，**必须显式点击「开始分析」才建任务**（切条件不自动起任务，`Q-ANALYSIS-01`）；当天同指纹成功任务直接恢复（单飞）。
