## 工作过程

1. 按纪要初版实现「奖金四卡 + 社区讨论 Tab + 类型下拉」。
2. 用户走查「奖金去除掉 不要了」→ 删除全部奖金展示（不做空态占位）。
3. 用户问「竞赛级别这个查询是否接口有返回」→ 实测深势返回 `competitionLevel` 真实 5 值（国家级 / 省级 / 市级 / 行业级 / 学校级），据此替换原型 4 值枚举，**不按报名人数推断**。
4. 用户「筛选框再增加全部选项 去除社区讨论」→ 筛选补「全部」，移除讨论 Tab。
5. 用户「排行榜现在没有数据」→ 实测 36 场中仅 11 场有榜（全部 `completed`）；页面原先取首条（`reviewing`）必然空。改为竞赛选择器 + 并发探测前 8 场（`pageSize=1` 轻量探测）。
6. 竞赛类型改「常规赛 / 认证赛」本地过滤（接口无该维度）。

## 决策记录（含 human 走查裁定 6 项）

| 决策 | 结论 | 依据 |
|---|---|---|
| 奖金 | **全部移除**，不做空态 | 用户裁定「奖金去除掉 不要了」；深势无奖金数据 |
| 社区讨论 | **移除 Tab** | 用户裁定「去除社区讨论」 |
| 竞赛级别枚举 | 用接口真实 5 值 | 实测接口有返回，无需按人数推断 |
| 竞赛类型 | 常规赛 / 认证赛，本地过滤 | 接口无该维度 |
| 筛选下拉 | 每个筛选补「全部」 | 用户裁定；避免 `value=""` 假选项 |
| 排行榜 | 竞赛选择器 + 自动探测有榜竞赛 | 11/36 有榜，取首条策略不可行 |
| 级别值映射 | 不做「原型 4 值 → 深势 6 值」映射（原 DoD 写法已作废） | 直接用接口真实值，减少一层失真 |
