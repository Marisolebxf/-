## 工作过程

1. 首版分类导航点击不生效（`filteredItems` 直接返回全量）→ 改为**服务端过滤**，`selectCategory(code)` 传 `contentTypes: [code]`。
2. 用户「列表做分页展示 顶部的筛选卡片应该和列表做关联」→ 改服务端分页（`page`/`pageSize`/`total`，8/16/24），分类与列表同源。
3. 用户「时间轴应该按照原型样式做」→ Arco 无 `Timeline mode="alternate"`，按原型自绘左右交替时间轴（中轴竖线 + 左右分支 + 圆点光晕）。
4. 分类计数需要全量但列表分页 → `loadTypeCounts()` 循环分页拉全量（最多 20 页防御）。
5. 排序切换 `LATEST` / `HOTTEST`（BFF 透传深势排序参数）。

## 决策记录

| 决策 | 结论 | 依据 |
|---|---|---|
| 分页模式 | **服务端分页** | 用户要求筛选与列表联动；前端全量拉取在 47 条尚可但不可扩展 |
| 分类过滤 | 服务端 `contentTypes` | 与分页同源，避免「分页后前端过滤只剩几条」 |
| contentTypes 字典 | 直接用深势 7 值 | 深势已提供字典，不自造 |
| 点赞排序 | 不做 | 深势无点赞数据 |
| 跨源综合聚合 | 不做 | 各数据源独立分页排序 |
| 时间轴 | 自绘交替时间轴 | Arco 无 `alternate` 模式；原型为左右交替 |
