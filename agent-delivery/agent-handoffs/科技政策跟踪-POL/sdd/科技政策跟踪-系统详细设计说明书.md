**已定**

1. Tab 文案：智能检索 / 关键词搜索 / 高级检索功能。
2. 示例：智能用 `POLICY_QUERY_EXAMPLES`，关键词用 `POLICY_KEYWORD_EXAMPLES`；高级不挂文案示例；只复制常量进展示仓，禁 D12 运行时依赖。
