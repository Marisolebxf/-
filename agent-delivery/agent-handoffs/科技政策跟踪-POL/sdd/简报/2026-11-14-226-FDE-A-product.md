## 功能点

| 功能点 | 谁在什么情况下做什么 | 做完看见什么 |
|---|---|---|
| 226-1 | 已选一条政策的人，点【智能摘要】 | 只 toast 成败，**不出现**政策名单表。成功后卡内出现图 1 三区块；失败只说智能摘要未成功，可稍后重试 |
| 226-2 | 同一条政策已经生成过，再次进入或再次点【智能摘要】（非强制重算） | 直接读出缓存的四块文案，不重复跑模型 |
| 226-3 | 点【重新发起智能摘要】（或【重新生成】） | 强制重新生成；成功后四块换成新文案；失败保留旧文案并提示未更新成功 |
| 226-4 | 有摘要结果时，编辑结论、政策摘要、关键点、应用建议 | 当页可改；换政策不带走；是否落库由波次 B 定，产品默认：推送前以当页文案为准，不要求先落库 |
| 226-5 | 点【推送管理层】；可选勾选「同时勾选邮件通道（仅文案，不发信）」 | 写入站内推送队列并成功提示；可打开队列查看。不真实外发邮件 |
| 226-6 | 未选政策时 | 不出三区块；提示先选择政策；生成与推送不可用 |

## 状态清单

| 状态 | 表现 |
|---|---|
| 未选政策 | 空态「请先选择政策」；【智能摘要】【推送】不可用 |
| 已选、无缓存 | 显示【智能摘要】；无三区块 |
| 生成中 | 按钮 loading；仍不出表 |
| 生成成功 | toast 成功；展示三区块 |
| 生成失败 | toast 失败；无三区块（或保留旧缓存） |
| 有缓存 | 直接展示三区块；可【重新发起】 |
| 重新发起失败 | toast 未更新；旧三区块仍在 |
| 推送成功 | toast；队列 +1；勾选邮件时提示仅文案未外发 |
| 读失败 | 「暂时读不到这条政策的解读，可稍后再试」 |
