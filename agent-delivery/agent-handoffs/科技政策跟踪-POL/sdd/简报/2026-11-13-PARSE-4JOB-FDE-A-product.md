## 1. 功能点 · 界面必见

| 分句 | 界面必见 | 空态 / 失败 |
|---|---|---|
| **606** 政策语义理解 | 点「拆解」后语义 Tab 出现主旨 / 适用场景 / 约束 / 条款分类等理解结果（业务文案） | 进行中：该 Tab 可见「正在理解…」；失败：「暂无语义理解结果」可重试 |
| **607** 条款精细化拆解 | 条款树分层呈现（章/条/细则等）；可切换到本 Tab 查看 | 无条款：「暂无拆出条款」；失败不抹掉其它 Tab 已有结果 |
| **608** 关键指标自动提取 | 指标表（或分类组）出现量化指标 / 补贴 / 资质 / 时间节点等行 | 未抽出：「这条政策没有抽出指标」；指标库未就绪仍走既有闸门 |
| **609** 政策实体关联 | 实体清单 + 关联网络（受「结合知识图谱」开关约束，既有闸门保留） | 无实体 / KG 关：既有空态；失败诚实提示 |
| **KPI-1** 力度指数 | 页头卡显示计算后的分值（或诚实「—」） | 未完成对应 Job：保持「—」，不写死假分 |
| **KPI-2** 关联度 | 同上 | 同上 |
| **KPI-3** 拆解完整度 | 有完整度分或残缺说明（业务话） | 未抽实体前可「未抽取实体」；完成后刷新 |
| **KPI-meta** 文本类型 / 级别 / 地区 / 部门 | 页头元信息卡显示计算结果（非空壳） | 暂无则空或「—」，禁止用占位假部门 |

共性：

1. 未选政策：「拆解」禁用。  
2. 一点「拆解」：按钮进入进行中；**四个计算同时启动**（用户不必按 Tab 分别点算）。  
3. 进行中可切换四 Tab；各 Tab / KPI **各自**显示进行中或已出结果。  
4. 关评审模式：用户可见文案无 Job / gapfill / mock / 表名黑话。

## 2. 状态清单

| 状态 | 表现 |
|---|---|
| 未选政策 | 空态引导先检索；拆解禁用；KPI 区可不展示或全空 |
| 已选未拆解 | 可点拆解；四 Tab / KPI 可为上次结果或空（B 波裁定是否清场） |
| 拆解进行中 | 按钮 loading/进行中；四 Job 并行；部分先完成则对应 Tab/KPI 先亮 |
| 四 Job 全成功 | 四 Tab 有业务结果；三卡与元信息有数或诚实「—」 |
| 部分失败 | 成功块保留；失败块空态 + 可再点拆解（是否只重跑失败项由 B 波裁定） |
| 全部失败 | 业务提示「暂无拆解结果」；不造演示分 |
