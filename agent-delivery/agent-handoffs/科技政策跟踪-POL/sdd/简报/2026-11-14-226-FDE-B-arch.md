## 定档

**中档**。226 从「只读 `ads.policy_text_parse.summary`」改为「真 LLM 生成四块结构化文案 + 按政策缓存 + 站内推送演示」。不退定义规程。不新建正式 ADS 表。不调用 `polan.text.parse.run`。不改 225 形态与选政策交互。D4 仍记 mock（生成结果进缺项缓存表，不算 live 接入）。

## 读法（钉死）

### 1. 调用链

```text
lumen-ui-science-pc
  → gateway
  → gkxlumen-display
       POST /display/v1/policy/evaluation/intelligent-summary
  → Feign → lumen-algo-py
       POST /internal/policy/eval/intelligent-summary
  → ZHIPU LLM（已有 llm_client）
```

- 同步请求。不进 `evaluation/jobs` 白名单，不建 topic-async 任务。
- Java 不写算法、不直连模型；Python 不对外暴露给浏览器。
- **禁止**展示路径调用 `polan.text.parse.run`（会清空整张 `ads.policy_text_parse`）。

### 2. 请求 / 响应形状（字段名波次 C 冻进 API；语义本波钉死）

请求体：

| 字段 | 含义 |
|---|---|
| `policyId` | 必填。与 225 共用选中的政策 |
| `force` | 默认 `false`。`false`：有缓存直接返回；无缓存才调 LLM 并写入缓存。`true`：强制 LLM，成功后覆盖缓存 |

成功响应四块（对齐 demo / 需规）：

| 字段 | 界面 |
|---|---|
| `conclusion` | ① 结论 |
| `policySummary` | ① 政策摘要 |
| `keyHighlights` | ② 高亮关键点（字符串数组） |
| `recommendations` | ③ 应用建议（字符串数组） |

另可带只读元数据：`cached`（是否命中缓存）、`updatedAt`。失败：HTTP 业务失败或空体 + 前端 toast「智能摘要未成功」；**不**返回政策名单表。

### 3. LLM 输入

- 用已有只读源拼上下文：优先 `ads.policy_text_parse` 同行的 `title` + 已有 `summary`（若有）+ 政策详情正文（若详情口已有）；没有正文则只用标题与已有摘要列。
- 拼上下文只做 **SELECT**。不 UPDATE 该表，不调 `parse.run`，不把四块写回 `summary` 单列。
- Prompt 强制 JSON 四字段；解析失败视为生成失败，不写半截缓存。

### 4. 缓存落点（决策卡 · 缓存 1）

| 项 | 裁定 |
|---|---|
| 库 | `gkxlumenx_gapfill`（缺项库，**不是**正式 ADS） |
| 表 | `gapfill_policy_intel_summary`（新建；utf8mb4 / utf8mb4_general_ci） |
| 键 | `policy_id` 唯一 |
| 列 | `conclusion`、`policy_summary`、`key_highlights`（JSON 数组）、`recommendations`（JSON 数组）、`model`、`updated_at` |
| 读写 | 仅 Python internal 在生成成功后 UPSERT；`force=false` 先 SELECT |
| 不做 | 不建 `ads.*` 新表；不灌 ODS/DWD；不写供应方库；不把用户当页改稿自动回写（见下） |

打开页 / 换政策：前端可对当前 `policyId` 发一次 `force=false`。命中 → 直接出三区块；未命中 → 仍显示【智能摘要】，不自动烧 LLM（避免误触耗额度）。点【智能摘要】= 同接口 `force=false`；点【重新发起/重新生成】= `force=true`。

### 5. 当页编辑

- 四块可编辑，**只留在浏览器状态**。
- 推送以当页文案为准，不要求先落库。
- 本中档不提供「保存改稿」接口；换政策丢弃未推送改稿。

### 6. 推送（决策卡 · 推送 1）

- **站内队列**：前端会话态（对齐 demo `inbox`），写入成功 toast + 抽屉可看。本中档**不**新建服务端推送表、不接真实消息中心。
- **邮件勾选**：仅文案提示「未外发」；不调 SMTP / 第三方信箱。
- 队列条目至少带：时间、通道文案（站内 / 站内+邮件文案）、受众「管理层」、标题一句。
