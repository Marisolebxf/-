## 功能点

| 功能点 | 谁在什么情况下做什么 | 做完看见什么 |
|---|---|---|
| 225-CMS-1 | 门户内容管理员打开「政策新闻内容管理」 | 一级 Tab 在原有三叶后多出「政策多媒体辅助解读」 |
| 225-CMS-2 | 在该 Tab 查看列表 | 可按产业、发布状态、关键词（标题 / 关联政策名）筛选；表列含标题、关联政策、类型标签、状态、更新时间 |
| 225-CMS-3 | 新建或编辑一条多媒体解读 | 表单必填：关联政策（与展示 225 下拉同一宇宙：已有摘要的政策标题，可带 `policy_id`）、类型标签（专家视频点评 / 关键数据动画 / 多维图形）、标题、一句说明；媒资：上传文件（经后端写入对象存储），保存后可见已上传文件名与可预览/可替换 |
| 225-CMS-4 | 对某条记录存草稿 / 发布 / 下架 / 删除 | 与现有政策新闻 CMS 同语义：草稿不进展示；已发布可被展示 225 读到；下架变草稿；删除后列表与展示均不可见 |
| 225-CMS-5 | 同一条政策挂多条 | 列表与展示侧均可有多条；展示侧仍按现行卡交互切换/展示（**不改样式**） |
| 225-1′（展示接线） | 结果解读页已选政策的人看多媒体卡 | **布局、文案样式、播放控件外观不变**；内容改为该政策下 CMS 已发布条目（标题、说明、类型标签、可播媒资）。无发布条目时仍是「这条政策还没有多媒体解读」。未选政策仍是「请先选择政策」 |

## 界面上必须看见什么

### 专题 CMS · Tab「政策多媒体辅助解读」

| 位置 | 必须看见 |
|---|---|
| 一级 Tab | 「政策多媒体辅助解读」与本体 / 统计与区域 / 力度评估并列 |
| 列表区 | 筛选（产业、状态、关键词）+ 表格 + 新建入口；空列表业务提示「暂无多媒体解读，可新建」 |
| 表单 | 关联政策、类型标签、标题、说明、媒资上传（选文件 → 上传成功显示文件名；失败只说「上传未成功，可稍后重试」）；草稿保存 / 发布 |
| 关联政策 | 选项来自与展示 225 相同的「已有摘要政策」宇宙；未选关联政策不可发布 |

### 展示 · 多媒体辅助解读卡（只换数，不换皮）

| 位置 | 必须看见（与现行一致） | 本次禁止改动 |
|---|---|---|
| 卡标题 | 「多媒体辅助解读」 | 不改卡布局、间距、播放器外观、按钮样式 |
| 内容 | 类型标签、标题、说明、播放 | 不新增 CMS 管理入口到展示页；不出现库表名 / 桶名 / content_type |

## 状态清单

| 状态 | CMS | 展示 |
|---|---|---|
| Tab 无记录 | 空列表 + 可新建 | 选中政策后「这条政策还没有多媒体解读」 |
| 仅草稿 | 列表可见草稿 | 展示读不到该条 |
| 已发布 | 列表为已发布 | 选中对应政策可见该条标题/说明/可播媒资 |
| 上传中 / 失败 | 上传中禁用重复提交；失败可重试，不丢已填表单 | 不影响 |
| 读失败 | 「暂时读不到列表，可稍后重试」 | 「暂时读不到这条政策的解读，可稍后再试」（沿用现行） |
| 下架 / 删除 | 下架→草稿；删除从列表消失 | 展示立即不再出现该条 |
