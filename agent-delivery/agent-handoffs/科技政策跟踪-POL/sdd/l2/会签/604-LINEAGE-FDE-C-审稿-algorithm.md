3. **有无把非本叶口径的指标挂过来？** 说明书「#### 604」和读法方案没有挂 `M_POLICY_*`。指标稿写明不挂 `M_POLICY_*` 统计卡顶替索引。605 本波不改口径，617 不改、不共用表。页眉「库内政策数」不是本叶口径，见 ALG-2。
