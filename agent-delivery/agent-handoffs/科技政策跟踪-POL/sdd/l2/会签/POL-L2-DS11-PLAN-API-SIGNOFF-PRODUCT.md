## 观察与偏离

1. **观察（不构成不同意）**：230 需规写「用户和专家可对推荐方案进行评价、评论和建议，系统自动分类归集意见并纳入后续优化」。分册读侧已覆盖分类归集展示（行上分类只用评价、评论、建议），但用户在页面新打的评价留在浏览器、不落库，「收集/纳入后续优化」的提交链路实质缺位。分册已如实登记（「直到另有采集单。本分册不建那张单」），符合诚实示空口径；采集单出现前该缺口保持如实示空，建议后续排期另立采集单，仅记录，不改本分册结论。
2. **观察（不构成不同意）**：231 需规写「支持多格式归档、政策汇报和内部流转」。分册从当次读到的行生成导出内容、格式名由 `BE-POL-CONTRACT-01` 冻结，但不写对象存储、不建文件表，真实归档无落点，「归档」语义收窄为「导出内容生成」。此处理与架构签收口径（不灌文件）一致；建议契约单冻结格式名时同步确认导出交付形态（前端生成/浏览器下载），仅记录。
3. 分册「偏离」一节三处与上游 DoD 及旧空态字面不一致均为收窄而非扩张（2026-11-03 架构已把五叶改成读缺项表），产品侧接受，与 VIZ 侧同类处理一致。
