# 602 · 说明书补两句

身份：product-agent。只改说明书「#### 602」里搜索和空源这两处，并在第 12 节变更记录加一行。不改四单、线框、Storage。

1. 智能搜索改成：国内按标题、文号或发文部门。海外只按标题。文号和发文部门不参与海外搜索，也不把没搜到说成该 ID 不存在。
2. 空源改成：表在、当前行一条都没有，才写「这一源还没有贴源数据」。表不存在是「读取失败」，两句分开。

3. 成功、部分、失败按监管人刚定的写进 602-8：能判定的都过了、没有失败样例 = 成功；既有过的也有失败样例，或者有的能判定、有的仍无加工事实 = 部分；能判定的都带失败样例 = 失败。读取失败和无加工事实不占用这三句。
