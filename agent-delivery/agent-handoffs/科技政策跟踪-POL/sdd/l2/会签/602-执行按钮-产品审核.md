# 602 · 产品审核 · 「执行」按钮

- 日期：2026-11-10
- 身份：product-agent
- 依据：规程 §4.2.0。只读补审，不改说明书、线框、读法方案、代码。

## 种类

监管人自己给的方案。原话指定了控件「执行」，并指定步骤：选择政策之后，点了才跑这一批的清洗。

## 结论

说得通。说明书「#### 602」和 `sdd/602-选择政策-线框.md` 里现在这一写法可以收。按钮保持这一写法。

## 四问

1. 谁、什么情况、完成什么：清洗页签的使用人，从贴源勾上至少一条之后（规则可先开关），点「执行」，按当前勾选和当前启用的规则跑这一批清洗。
2. 做完能看见什么：批次头有批次名，条数等于这次勾选的条数。批次明细出现这一次的判定或命中、脱敏样例、更新时间、状态。有六条规则对应的加工事实时，状态是成功、部分、失败之一。点过之后仍没有这种事实，命中处空白，状态不写成功。去重合并、格式标准化仍是「应合并」「待标准化」，贴源原文不动。
3. 四种下场各自一句。没做：未选时按钮不可用，规则区和批次都空；未执行时规则可看可开关，批次仍空，不写成已经清洗过，也不写成无加工事实。失败：读不出的那一块写「读取失败」；有加工事实而本批没过，状态写「失败」；点过仍无加工事实，命中空白、不写成功。做一半：执行中，标明还在执行，不能再点出第二遍，不写成已经清洗完。改了条件再做：跑完后改勾选或开关，旧结果留着，并标明还不是最新一次，再点「执行」才按新选择重跑；清空后回到未选。
4. 需规这一句的分句都还有着落：系统引用多源、采集接入、去重合并、格式标准化、噪声过滤、建立校验规则、准确性完整性一致性、高质量数据源，仍分别落在 602-1 至 602-8。按钮只卡住何时跑、何时出本批。

## 仍未闭合（不改按钮）

1. 待裁定四条仍开：库是演示还是正式；谁来读贴源；准确性算不出时是空白还是演示数；规则启停只记本页还是长期保存。
2. 正在跑的时候就改勾选或开关，说明书只写了跑完之后再改。这一边还没写死。
