补进界面上必须看见的行为：

- 条件栏在已选集合旁有按钮「执行」。一条都没选时，按钮不可用。
- 没点「执行」之前，规则行可以看、可以开关，批次明细是空的，不写成功，也不写成已经清洗过。
- 点「执行」之后，才按当前勾选的政策和当前启用的规则，跑这一批的清洗过程，然后批次明细出现这一次的结果。
- 跑完之后如果又改了勾选或开关，旧结果留着，并标明还不是最新一次；要再点「执行」才按新的选择重跑。改勾选不自动跑。
- 同一次选择正在跑时，不能再点出第二遍。
