## 硬清单五问

1. **需规原文每个分句是否都有功能点编号**：异议。原文只有一句：「建立政策原文、条款内容、分析结论之间的关联索引，支撑后续研报结论的精准溯源、查证与复核。」索引落到 604-1，精准溯源、查证、复核落到 604-2、604-3、604-4。「后续研报结论」这半句没有功能点编号。见 P3。

2. **每个功能点是否写了「界面上必须看见什么」，能否被截图验证**：604-1、604-2、604-4 有可截图的句子，线框也画了表、溯源弹层、复核弹层和行上「已复核」。604-3 写的是「分析结论或洞察标识」，两种画面都可能算过；没有洞察标识时该看见什么，只在线框里有，说明书没有。见 P2。

3. **状态清单是否覆盖：未选、未命中、停用、无数据、失败**：未选有。所选政策对不上行，用「该政策无行」盖住了未命中和无数据，空态文案是「这条政策还没有关联索引」，不出现数字 0。停用没写，本叶也没有可停用的开关。失败没写。见 P1。

4. **设计稿是否把功能点落到了某个区块、接口字段或表列**：604-1 落到关联索引表三列。604-2 落到溯源弹层。604-4 落到复核弹层和该行「已复核」（当次打开，不落库，所以没有表列，这是故意的）。604-3 的「洞察标识」只有线框上的一块字，接口稿不写字段，数据稿没有这一列。见 P2。按条款、按结论拣行仍留在架构和接口稿里，没有落到本叶线框。见 P4。

5. **影响清单是否清零，旧口径是否已标「已被取代」**：没有清零。架构里「只建索引读面、三个动作不在本叶」和「不选则读全部」已经标了已被说明书取代。同文还有「打开就读行数概览」「按条款查」「按结论查」没标。接口稿仍写政策 id 不必选，还可按条款号、结论键拣，全文没有取代注记。说明书影响清单仍写架构要等波次 B 改、本波不改架构，和已经补过的架构稿对不上。见 P4。

## 异议

[product] P1 · 请求失败时，溯源页签上必须看见什么没有写死，截图无法验收 · 依据：说明书「#### 604」状态清单只有未选、有行、该政策无行、溯源弹层、查证结果、复核未填、复核已提交、重开丢失，没有失败；ARCH 2026-11-16 补段写「失败沿用说明书」，说明书却没有这一行；读法方案 §3 写「请求失败：不清空治理页其他区块，不新写失败文案」。三处互相空指。硬清单还要求「停用」：本叶没有规则开关，状态清单也没写「停用不适用」 · 建议：在说明书状态清单补两行再收口。失败：这一次索引没读出来时，写一句业务话（例如「关联索引没有读出来，可稍后重试」），不出现数字 0，不清空治理页其他页签已有内容，三个按钮不出现在空行上。停用：写明本叶没有停用；没选政策或没有行时，三个按钮不出现，不是灰掉。读法方案不要再写「不新写失败文案」。
