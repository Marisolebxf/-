## 观察与偏离

1. **观察（不构成不同意）**：230 的意见行只能由灌数单预置，「页面上新打的评价留在浏览器，直到另有采集单」——用户表达的意见不持久，这一产品影响分册已如实登记（第 6 节）。与 API 分册观察一致：采集单出现前，230 的「收集」语义只落在读侧展示，建议后续排期另立采集单，仅记录，不改本分册结论。
2. **观察（不构成不同意）**：灌数单尚在 backlog，五叶上线即空的窗口期由「空表返回空」兜底；若验收演示需要非空对比（至少两方案），需先推动 `POL-L2-DS11-PLAN-GAPFILL-L01` 进 ready，属排期事项，不改本分册结论。
