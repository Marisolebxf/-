这些接口已经有门户页或详情页在读。可视化页只新增调用方。Java 不改路径、不改已有字段、不改缺省查询结果。

| 编号 | 现有能力 | 可视化用来做什么 | 保持不动的原因 |
|---|---|---|---|
| R-1 | `POST /enterprise/topic/v1/profile/finance/trend` | 企业营收、利润随时间的曲线 | 企业详情 `EnterpriseProfileTabPanel` 已调用。序列类型有营收和利润，没有研发投入趋势 |
| R-2 | `POST /enterprise/topic/v1/profile/competitiveness` | 目标企业与同行的多维对比 | 详情页已用。不改维度字段 |
| R-3 | 服务 `portalRegionMap`（全球 / 全国） | 服务机构地理分布底图 | 专题服务门户区域页只认现有 `china` / `global`。不增加必填参数 |
| R-4 | 政策 `indicators.national` | 影响范围柱状（各省政策量） | 政策新闻展示页已读。不改 `national` 结构 |
| R-5 | 产业链 panorama snapshot（nodes / edges） | 产业链层级图的节点和边 | 只给结构。占比不塞进 snapshot |

研发投入如果以后要进财务曲线，另开字段、另评审，不塞进 R-1 的现有序列。

## 2. 本单要新增的只读接口

全部新路径，挂在各模块已有前缀下：`/chain/topic/v1/industry`、`/enterprise/topic/v1`、`/svc/topic/v1`、`/policy/topic/v1/policy`。无行返回空数组，并带一句原因。不改第 1 节的旧路由。

| 编号 | 建议能力 | 服务的可视化项 | 空态条件 |
|---|---|---|---|
| N-1 | 产业总体规模 + 年增长率序列，查询参数含区域、行业 | 产业全景 · 总量与增长率 | 无指标行则空 |
| N-2 | 产业密度点：经纬度 + 权重 | 产业全景 · 地理热力 | 无坐标则空。不改企业发展门户已打开的热力图层 |
| N-3 | 产业链各环节占比 | 产业全景 · 层级图补数 | 无口径则空。可按环节企业数聚合，口径写进响应说明 |
| N-4 | 产业分类构成，支持行业 / 领域切换 | 产业全景 · 饼图 | 不用企业侧「企业按产业分布」顶替 |
| N-5 | 产业过去多年规模序列，另附事件列表 | 产业全景 · 历史趋势 | 无事件则 `events: []`，曲线仍可单独返回 |
| N-6 | 企业散点：一个企业一个点，带两个可筛选的数值维，以及行业、地区 | 企业发展 · 行业定位 | 无企业级指标则空 |
| N-7 | 已发布的企业关键事件（读 CMS `star_story` 已发布块） | 企业发展 · 成长时间轴 | 未发布或不存在则空。不改 CMS 写接口 |
| N-8 | 服务机构地理分布，可选「服务类型」筛选 | 产业服务 · 机构分布 | **新路由**。不把筛选参数加到 R-3 上。缺省不传类型时，结果应与 R-3 同口径，但是独立路径 |

服务供给热力若只是把 R-3 / N-8 的点再聚合一次，由前端用已有 `leaflet.heat` 画，不单开接口。密度口径与 N-2 一样写进说明，没有权重就不画。

## 3. 本单不做（不新建路由，不返回假数）

没有表、没有已注册口径，或会用相邻指标顶替。前端对应面板只显示空态。

| 编号 | 项 | 原因 |
|---|---|---|
| X-1 | 产业未来 3–5 年预测、参数情景 | 无预测模型。算法新需求，不在本单 |

| X-3 | 服务需求分布 | 现网只有供给侧 |
