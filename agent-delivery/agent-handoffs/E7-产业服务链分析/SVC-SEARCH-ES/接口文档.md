  "org_kind": "企业",            // 机构类型：企业/高校/科研院所（高筛 type）

## 3. filters DSL 协议（字段 × 操作符矩阵）

**语义**：数组内多条为 AND；`in/nin` 的 value 数组内为 OR；非法 field/op 返回 `data_source: "invalid_filters"` + `reason`（**诚实拒绝，不静默丢弃**——根治旧接口七字段静默丢弃问题）。

| field | ES 字段 | 支持的 op | value 类型 | 说明 |
|---|---|---|---|---|
| `city` / `province` / `area` | 同名 keyword | eq/neq/in/nin | str / [str] | 精确匹配 |
| `industry` | industry | eq/neq/in/nin | str / [str] | 精确匹配（注意：**非** LIKE 子串，见 §6 语义差异） |
| `service_type` | service_type | eq/neq/in/nin | str / [str] | 六类码 |
| `org_kind` | org_kind | eq/neq/in/nin | str / [str] | 企业/高校/科研院所 |
| `stage_code` | stage_codes[] | eq/neq/in/nin | str / [str] | 数组字段，单值命中即可；枚举见下 |
| `fields` | fields_flat[] | eq/neq/in/nin | str / [str] | 领域词（真实产业标签优先） |
| `tech_score` | tech_score | gte/lte/gt/lt/eq | number | 缺分文档不命中 range |
| `patent_valid_count` | patent_valid_count | gte/lte/gt/lt/eq | number | 有效专利数 |
| `employees_number` | employees_number | gte/lte/gt/lt/eq | number | 从业人数 |
| `incorporation_year` | incorporation_year | gte/lte/gt/lt/eq/exists | number | 注册年份 |
| `pending_client_confirm` | pending_client_confirm | eq | boolean | 待核验标记 |

`stage_code` 枚举（ETL 物化 `stage_of()`，与 svcmodels.py 同源）：
`stage-research`（研发）/ `stage-ip`（知识产权）/ `stage-transfer`（技术转移）/ `stage-pilot`（中试）/ `stage-testing`（检测）/ `stage-market`（市场化）

## 5. 灰度与回退

- 环境变量 `SVC_SEARCH_ENGINE`（**默认 `mysql`**，零风险基线）；`es` 按页灰度
- ES 连接失败/索引缺失/查询异常：**单次请求级自动降级 MySQL**，日志 `[gkx-svc] es engine unavailable, fallback mysql`
- filters 非法输入（未知 field/op）：**不降级**，返回 `data_source: "invalid_filters"` + `reason`（避免掩盖协议错误）
- **ES-only 参数在 MySQL 引擎下诚实拒绝**（code review P1 修复）：`filters`/`org_kind`/`stage_code`/`tech_score_gte`/非默认 `sort` 到达 MySQL 路径（默认引擎或 ES 降级）时返回 `data_source: "unsupported_under_mysql"` + `reason`——**绝不静默忽略导致未过滤全集**；旧参数（keyword/service_type/city/province/area/industry/page/size）行为与改造前逐字一致
- 回退 DoD：`SVC_SEARCH_ENGINE` 删除/改 mysql 后，旧参数三 tab 行为与改造前逐字一致（已验证）

## 6. 已知语义差异（ES vs 旧 MySQL，前端需知）

| 场景 | 旧 MySQL | 新 ES | 说明 |
|---|---|---|---|
| `industry` 参数 | `LIKE '%检验检测%'` 跨词子串，命中 15 | 分词边界匹配，`检验检测` 命中 0（ES 内行业词为「检验检疫服务」等） | **ES 更精确**；前端高筛请改传 filters `industry in [...]` 用 meta 接口字典值精确匹配 |
| `keyword` | LIKE 子串 | term/match_phrase + **wildcard 子串兜底**，已对齐（华大 22=22、深圳 13,455=13,455） | wildcard 对 43k 索引 <50ms；索引涨到百万级需换 ngram（代码已留升级注释） |
