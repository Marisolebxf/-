## 1. 结论

企业检索是企业中心内的横向能力，不是系统级全局搜索，不进入左侧二级菜单，也不成为企业中心固定 Tab。四个二级页顶部保持 L03a 结构：ContextBar 在一级 Tab 上方；当前 Tab 只由一级 Tab 选中态表达；页面顶部不放常驻搜索。

`/development/search` 作为企业高级检索兼容/落地页保留。页面可见标题使用“高级检索”，内部继续承载 SearchHub 三模式、结果区、统一企业画像抽屉和整页画像跳转。

## 3. 来源与返回

进入 `/development/search` 时 URL 可以携带 `source/tab/mode/task/industry/region/time`。其中：

- `source` 表示来源二级页路径。
- `tab` 表示来源页当前一级 Tab。
- `mode` 表示默认打开 SearchHub 的关键字、智能或高级筛选模式，只是入口推荐起始模式，不是模式锁定。
- `task` 表示来源入口的场景任务文案，如 `筛选深圳企业`、`查找重点企业`、`导入候选企业集合`，用于 SearchHub 局部提示。
- `industry/region/time` 只作为来源上下文元数据保留，不在搜索页默认参与筛选，也不显示“沿用来源口径”入口。

搜索页顶部使用“返回条”而不是面包屑。返回条显示来自哪个二级页和 Tab，并提供“返回来源页”。用户返回来源页时，不静默覆盖企业中心 ContextBar；只有用户在来源页或搜索页执行明确动作，才改变来源页状态。

无 `source` 直达 `/development/search` 时，默认归属企业总览，左侧 active 和返回条都回企业总览。

## 4. 模式切换与搜索状态

三模式 SearchHub 必须保持可切换。场景入口只决定初始高亮模式，不限制用户切到关键字、智能搜索或高级筛选。原因是同一任务下用户可能先按入口建议进入高级筛选，再用关键字缩小范围，或用智能搜索改写条件。

为避免用户把默认高亮误解为“只能使用该模式”，SearchHub 区域内需显示局部提示，不放页面顶部，不做全局说明条。推荐文案：

- `已为“筛选深圳企业”打开高级筛选，可切换关键字或智能搜索。`
- `已为“查找重点企业”打开关键字检索，可切换智能搜索或高级筛选。`
- 无 `task` 直达时不显示来源任务提示，只显示常规 SearchHub。

用户切换模式后，当前工作模式以 SearchHub 选中态为准；不回写来源页，也不静默改变企业中心 ContextBar。

搜索页结果区必须区分四种状态：

| 状态 | 触发条件 | 展示规则 |
| --- | --- | --- |
| 初始态 | 用户尚未输入关键词、未应用高级筛选、未点击模板或热词 | 不展示固定企业结果列表；展示推荐条件模板、最近查看或常用筛选入口 |
| 有结果态 | 用户明确执行检索或应用筛选后命中企业 | 展示结果工具条、结果列表、画像/对比/名单/收藏等动作 |
| 空结果态 | 用户明确执行检索或应用筛选后无命中 | 展示空态说明，提供放宽条件、清空筛选、切换模式 |
| 示例数据态 | Demo 阶段使用 Mock seed 作为结果来源 | 在结果工具条、结果来源或字段旁标注“示例数据 / Mock”，不得伪装为真实命中 |

当前前端若使用 `ENTERPRISE_LIST` 等固定 seed，必须将其视为 Mock 示例数据。不得在搜索页初始态直接渲染一批固定结果，避免用户误以为系统已按“筛选深圳企业”等入口任务自动完成检索。

## 5. 结果与画像闭环

结果动作优先级为：画像优先；加入对比、加入名单、收藏、深度分析、导出为次级动作。

列表或卡片中的企业名打开统一企业画像抽屉；抽屉提供整页画像入口。整页画像保留来源和返回能力，便于从高级检索回到企业中心深层场景。

对比篮、收藏、最近查看属于企业中心工作上下文，不扩展为全系统能力。

## 6. 提示与数据维护

来源、更新时间、Mock、待维护、待确认等可信度提示应贴近字段、模块或指标显示，不在搜索页顶部放常驻说明条。

E-36/E-37 继续归后台内容管理，前台只消费维护结果，不在本次新增前台维护入口。

## 7. 验收要点

- 四个企业中心二级页顶部无常驻搜索、无面包屑、无重复路径型标题。
- `/development/search` 不进左侧菜单，不作为企业中心固定 Tab，不出现在系统 Header。
- 场景按钮进入搜索页时 URL 含 `source/tab/mode/task`，可带 `industry/region/time`，但搜索页不默认应用这些口径。
- 搜索页显示“高级检索”和来源返回条；无 `source` 直达默认回企业总览。
- `mode` 只决定 SearchHub 初始模式，三模式仍可切换；有 `task` 时只在 SearchHub 局部提示来源任务。
- 搜索页初始态不自动展示固定结果列表；无命中有空态；Mock 结果必须标注示例数据。
- 画像抽屉、整页画像、加入对比/名单/收藏/导出保持可用。
