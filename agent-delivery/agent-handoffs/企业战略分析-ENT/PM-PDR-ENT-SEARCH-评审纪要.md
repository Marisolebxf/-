## 3. 门 1 讨论要点（来源：企业维度 2026-07-12 会议纪要）

### 3.1 会议结论

| # | 要点 | 纪要条目 | 客户决策清单 |
|---|------|----------|--------------|
| M1 | **智能搜索**不做大模型 NL 解析，仅**关键词 + 多字段匹配** | 智能搜索条款 | **Q033** |
| M2 | **查企业/智能搜索**结果统一**横向长卡片（类列表）**；暂不强行卡片/表格双视图切换 | 结果列表展示 | **Q034** |
| M3 | **高级筛选**本期不做条件重复组合（AND/OR 嵌套）；简化版实现，是否搬企查版后续评估 | 高级筛选条款 | **Q036** |
| M4 | **导出**：最多 **1000 条**、**异步下载**、记录在个人中心；单企业 **Excel 模板转 PDF** + 水印（平台名+用户名）；批量**打包 PDF** | 导出限制 | **Q035** |
| M5 | **空态推荐**：默认展示重点/明星企业列表，**≤30 条**，不按用户行为个性化 | 推荐企业空态 | **Q037** |
| M6 | **四级地域筛选**等通用组件封装（全球/G20、全国、区域、深圳），全系统复用 | 通用组件 | 执行待办（曹丽影） |
| M7 | 列表形态便于**横向对比与批量操作**（为加入对比篮提供入口） | 结果列表 | 联动 COMPARE |
