## 3. 总体决策路径（三选一，PM 拍板）

> 决策时间：____年__月__日 ____ 主持人：PM ____ 参与：UE lead ____ + （可选）architect ____

### 选项 A：全回补（推荐 IF 红项 ≥3）

**做法**：
- 派 ux-agent 重跑 DS-15，按 D8 规范全量更新 4 份 md
- 派 ui-agent 接力按新 wireframe 局部刷新 demo2 沙箱页（仅改动差异部分，不重写）
- 写新 handoff `UX-DS-15-d8-retrofit.md` + `UI-DS-15-d8-retrofit.md`
- 在 DS-15 原 handoff 末尾加"已回补"链接

**成本**：UX 0.3 d + UI 0.5 d；约 \$5–10 token；UE/PM 联审 0.5 h

**收益**：DS-15 成为 D8 之后的标杆产物，未来所有试点都可以放心参考

### 选项 B：部分回补（推荐 IF 红项 0–2、黄项较多）

**做法**：
- 只补 IA/wireframe md（§4.2 5 段 + §9 命名 + §18 8 条自检）
- demo2 沙箱页**不动**（视觉问题等后续工程化复刻到 lumen 时一起处理）
- 写轻量 handoff `UX-DS-15-d8-retrofit-light.md`

**成本**：UX 0.2 d；约 \$3–5 token；PM 联审 0.3 h

**收益**：文档层面对齐 D8；沙箱页历史遗留显式标记

### 选项 C：标记历史遗留（推荐 IF 红项 0、且 DS-25 已成为 D8 标杆）

**做法**：
- 在 `demo2/docs/ia/sandbox/talent-2026-06-17/README.md` 顶部加横幅：
  ```
  ⚠️ pre-D8 产物（2026-06-17 上午跑通，D8 决策于同日下午确立）
  本目录仅作为"早期试点参考"，不再代表 D8 之后的标杆做法。
  D8 之后的标杆请参考：demo2/docs/ia/sandbox/soft-science-2026-06-17/
  ```

- 在 `UX-DS-15-trial.md` 末尾加同样标记
- 在 `repo-registry.yaml` 注释段补一条"pre-D8 试点产物名单"

**成本**：5 min

**收益**：透明记账，避免新人/agent 误用 DS-15 做模板
