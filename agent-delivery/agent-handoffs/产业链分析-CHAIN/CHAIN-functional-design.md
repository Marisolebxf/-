## 1. 问题诊断（D1–D4）

### D1. 用户不知道产业链全貌

| 维度 | 描述 |
|------|------|
| **问题** | 政府决策者无法直观了解某产业链的完整结构、上下游关系与关键环节分布 |
| **影响** | 无法识别链条断点、无法精准定位招商目标、资源投放盲目 |
| **当前解法** | 依赖行业报告 PDF，信息分散、更新滞后、无法交互 |
| **期望状态** | 交互式知识图谱，一屏掌握产业链全貌，可下钻、可演进 |

### D2. 无法判断产业发展阶段

| 维度 | 描述 |
|------|------|
| **问题** | 缺乏科学的周期判定工具，对产业处于"成长/成熟/衰退"靠经验判断 |
| **影响** | 投资节奏错位，政策窗口期把握不准 |
| **当前解法** | 专家定性判断，标准不统一、不可复现 |
| **期望状态** | 基于多指标模型的周期阶段量化判定，支持趋势预测与拐点预警 |

### D3. 区域产业竞争力无法量化对比

| 维度 | 描述 |
|------|------|
| **问题** | 不同区域同一产业发展水平缺乏统一评价体系，横向对比困难 |
| **影响** | 无法客观评估深圳产业定位，区域优势/短板识别模糊 |
| **当前解法** | 单一 GDP/产值指标对比，维度单一 |
| **期望状态** | 多维评价体系（企业能力+学术生态+配套生态），可配置权重，可横向排名 |

### D4. 瓶颈堵点识别缺乏系统归因

| 维度 | 描述 |
|------|------|
| **问题** | "卡脖子"环节识别依赖经验，缺乏多维度量化归因 |
| **影响** | 解决方案"治标不治本"，无法精准施策 |
| **当前解法** | 逐个环节人工排查，效率低、覆盖面窄 |
| **期望状态** | 五维度（技术/人才/市场/资金/政策）自动评分，智能归因+改进建议 |

## 2. 决策链（DC1–DC6）

### DC1. 产业链结构认知 → 全景图谱探索

```
关注什么 → 产业链完整结构、上下游关系
为什么 → 识别断点与缺失环节
重点对象 → 关键环节（高附加值/高壁垒）
趋势/异常 → 演进变化（新加入/退出节点）
下钻明细 → 节点关联企业/专利/技术
```

**决策输出**：识别链条完整性、定位关键环节、发现断点

### DC2. 产业发展阶段判定 → 周期分析

```
关注什么 → 产业当前所处周期阶段
为什么 → 把握投资节奏与政策窗口期
重点对象 → 处于拐点的产业、增长异常产业
趋势/异常 → 周期趋势预测、拐点预警
下钻明细 → 历史重大事件、驱动因素
```

**决策输出**：周期阶段判定、趋势预测、拐点时间窗口

### DC3. 区域产业定位 → 区域指数评价

```
关注什么 → 各区域产业指数与竞争力排名
为什么 → 识别区域优势与短板
重点对象 → 指数最高/最低区域，排名跃升/下降区域
趋势/异常 → 指数时序变化
下钻明细 → 区域内企业贡献、人才分布
```

**决策输出**：区域产业排名、优势/短板维度、对标差距

### DC4. 关键环节聚焦 → 关键环节识别

```
关注什么 → 高价值关键环节
为什么 → 聚焦资源投入核心环节
重点对象 → 高端化指数 TOP5 环节
趋势/异常 → 技术替代趋势
下钻明细 → 代表企业、专利分布
```

**决策输出**：关键环节清单、高端化排名、竞争格局

### DC5. 瓶颈诊断 → 瓶颈堵点识别

```
关注什么 → 产业链瓶颈堵点
为什么 → 精准定位"卡脖子"环节
重点对象 → 高严重度瓶颈
趋势/异常 → 瓶颈恶化/改善趋势
下钻明细 → 归因分析、改进建议
```

**决策输出**：瓶颈环节清单、严重度排序、归因建议

### DC6. 深圳产业战略 → 深圳分析对比

```
关注什么 → 深圳产业的相对优势与短板
为什么 → 客观定位深圳产业能级
重点对象 → 深圳优势领域、短板领域、高潜力领域
趋势/异常 → 深圳位次变化、新兴机遇
下钻明细 → 发展建议、机遇推荐、布局策略
```

**决策输出**：深圳产业定位、发展建议、机遇推荐、重点布局

## 3. 全局工作台模型

### 3.1 统一筛选上下文

所有分析层页面共享筛选上下文：

| 筛选项 | 控件 | 默认值 | 数据源 |
|--------|------|--------|--------|
| 产业 | IndustrySelect（单选） | 集成电路 | `dwd_industry_chain_info.chain_name` |
| 时间窗口 | TimeWindowPicker | 近3年 | — |
| 区域 | RegionSelect | 全国 | 行政区划 |
| 关键词 | SearchInput | — | — |

### 3.2 页面切换

PrimaryWorkbenchTabs 贯穿全分析层：

```
[概述] [全景图谱] [周期阶段] [区域评价] [关键环节] [瓶颈堵点] [深圳分析]
```

切换 Tab 不重置筛选上下文，仅刷新主视图区。

### 3.3 跨页面联动

| 联动方向 | 触发 | 效果 |
|---------|------|------|
| CP0 → CP1 | 点击"全景图谱"Tab | 切换到G6图谱视图，保留当前产业 |
| CP1 → 企业画像 | 点击节点→查看关联企业 | 打开企业列表Drawer |
| CP2 → CP1 | 查看某产业周期后下钻 | 切到全景图谱并聚焦该产业 |
| CP3 → CP6 | 选择深圳下钻 | 切到深圳分析页 |
| CP4 → CP5 | 关键环节是瓶颈 | 切到瓶颈堵点页并高亮该环节 |
| CP5 → CP6 | 深圳瓶颈 | 切到深圳分析并定位短板 |
| CP6 → CP4 | 查看关键环节 | 切到关键环节页 |
