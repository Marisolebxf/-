## 3. 关键技术决策（可复用）

1. **stats 口径陷阱**：深势交流四类 `stats` 完全相同（247/2243/79/107）。任何「跨类累加」都会翻倍数。正确做法＝取首份，分类占比另按列表真实计数。
2. **BFF 剥层统一**：深势统一 `{code, data}` 双层，`list` / `detail` / `recommendation` 三处都必须剥；只剥一处会出现「列表正常、推荐空白」。
3. **Arco 栅格横向溢出**：`a-row` 的 `gutter` 用负 margin 实现，页根 `padding: 0` 时必然溢出约 8px。解法＝页根 `overflow-x: hidden`（不要给 `a-row` 打补丁）。
4. **无坐标地图**：地址文字三级匹配（精确场馆 → 区域 → 城市）+ 确定性抖动（禁 `Math.random`，保证同数据同位置）。
5. **有榜竞赛探测**：`/ranking` 对未完成竞赛返回空。「取首条」不可行，需按候选逐场轻量探测（`pageSize=1`）。
6. **Arco 无 `Timeline mode="alternate"`**：左右交替时间轴需自绘（中轴竖线 + 左右 `calc(50% - 28px)` 分支）。
7. **详情内嵌可行性**：上线前先实测 `X-Frame-Options` / CSP `frame-ancestors`，再决定弹窗方案；保留「在新窗口打开」兜底。
8. **筛选枚举**：一律用接口真实返回值；接口无该维度时，明确降级为本地过滤（竞赛类型→常规赛/认证赛）或删除（奖金）。
