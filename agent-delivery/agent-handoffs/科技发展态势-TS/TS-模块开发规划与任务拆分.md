## 1. 全局技术约束（9 子模块统一遵守）

1. **地图**：Leaflet + 天地图瓦片（`src/config/tianditu.ts`：`vec_w` 底图 + `cva_w` 注记 + 0–7 子域）。key 迁 `VITE_TIANDITU_KEY`（S02 内完成）。禁止高德瓦片进正式仓。
2. **Mock 统一开关**（S03 落地，先于一切业务页）：
   - 真源机制已存在：`src/config/app.ts` `USE_MOCK`（`VITE_APP_USE_MOCK` 未设时回退 `ENABLE_MOCK_AUTH`，对齐 lumen-ui-topic 约定）；
   - `src/mock/index.ts` 提供 `setupMocks()`：`USE_MOCK=true` 时在 axios 实例注册 mock adapter，`main.ts` **全局注册一次**；
   - mock 数据按模块拆 `src/mock/modules/*.ts`，冻结自 demo `data.js`（头注释标真源路径 + 同步任务 ID，禁止新造）；
   - `src/api/**` 只写真实调用，**不感知 mock**；`USE_MOCK=false` 时零 mock 代码执行，直连 `gkxlumen-platform-gateway`（D12）；
   - CI 构建显式 `VITE_APP_USE_MOCK=false`；`USE_MOCK=false` 禁止 fixture 填数。
3. **UI 栈**：Vue3 `<script setup>` + **Arco Design Vue**（Select/Cascader/Tabs/Drawer/Modal/Pagination/Tooltip/Message 等）+ **UnoCSS 原子类**（attributify + icons 已配）；token 按 `Design.md`（主色 `#165DFF`、底 `#D8E7FC`、正文 14px、控件 32px）。demo 的手写 styles.css 类不复刻，按视觉等价重写。
4. **图表**：ECharts（vue-echarts 6.x 已装）；图谱用 ECharts graph（禁 G6 直连；图谱存储仍是 Nebula，经 Java→Python 链路）。
5. **调用链铁律**：前端 → Java REST → Python `/internal/*`；Java 不写算法；只读 ADS；可观测 `X-Trace-Id`/`traceparent` 请求头 + 前端埋点。
6. **D9 血缘**：每个统计数字旁 ⓘ（MetricSpecCard）+ Mock 态 🧪 MockBadge；指标 8 件套经 `/metrics/v1/catalog`；镜像为空不传 metric_id。
7. **demo→lumen 复刻五件套**：布局、交互、样式、评审、Mock 开关数据；禁止以「更简」为由另起 UI；互斥 display 不叠同一节点。
