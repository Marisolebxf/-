## 2. 为什么配置写侧不挂指标

1. `cfg_*` 四表（DATA 分册）是运营配置真源：行数十行级、随用户操作即时读写、无算法语义。指标口径（八件套：`metric_id`/中文名/口径/公式/`algorithm_type`/源表/源系统/更新频率/`version`）对配置行无意义——没有可写的公式与更新频率。
2. D9 指标血缘约束的是「展示端数字」的可追溯。本二级界面不出现统计数字（图层开关、分组色值、数据源行、要素显示名均非统计量），血缘链不适用。前端四维就绪度角标（D1–D4）对配置页**不渲染**（无指标可标）；D4 是否 mock 的讨论仅存在于种子行占位语义，见 §3。
3. 配置 CRUD 无算法语义：写路径经 Python `/internal/gkx-show/maintain/config/**`（2026-11-06 监管人裁定后修订，ARCH §3），但那是纯配置转发与写库，不生成任何统计口径；种子灌数是一次性脚本。无 `algorithm_type` 可填。
