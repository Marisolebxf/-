## 5. 技术约束（铁律）

- **写数归 Python（D7）；Java 只读 ADS（D3）；前端禁自算正式值**。
- 计数口径 = `要素 key × region_key × time` 去重计数；占比 = 本 region 内占比；增长 = 相邻时间窗环比。
- 演示口径必须带 🧪 MockBadge；**禁直接灌 demo `data.js` 硬编码**，须由 Python 按标准表写 Mock。
- 排除政策要素；`demo_gkxlumenx_ads` 仅演示用，**产品站禁调 `demo-*`（D12）**。
- 聚合语义三层一致：AD S 层 / 接口层 / 前端展示层同一口径。
