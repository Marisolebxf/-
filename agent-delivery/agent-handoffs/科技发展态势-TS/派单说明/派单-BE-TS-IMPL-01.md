## 5. 技术约束（铁律）

- **Java 不写算法**：算法走 Python `/internal/*`，Java 只做聚合与转发。
- **只读 ADS（D3）**：业务数据只读 `*_ads` 已发布批次；写数归 Python（D7）。
- **禁造数**：`USE_MOCK=false` 时零 mock；Mock 数据由 Python 按标准表写入，Java / 前端不造。
- 带写面只有两类：收藏/标签、导出任务中心（落 `app_user` 家族，审计服务端）。
- 服务归属：`gkxlumen-display`（Wave4 基线）；若抢 V1.0 窗口先落 `gkxlumen-innov`，**由 M0 拍板 U1**。
- 网关：`/display/**` 是展示侧唯一对外前缀（A4 裁决 / D15），域服务 `@Inner` 不对外。
