## 5. 技术约束（铁律）

- 调用链：前端 → 网关 `/display/**` → `gkxlumen-display` → Feign 域服务；算法走 Python `/internal/*`，**Java 不写算法**。
- 读：业务数据只读 `*_ads`；**Java 只读已发布批次**（D3），写数归 Python（D7）。
- 带写面只有两类：收藏/标签、导出任务中心，落 `app_user` 家族，审计落服务端。
- 观测：`X-Trace-Id` / `traceparent` 请求头贯通。
- D9：算法输出必须带 `metric_id` 映射，不另造指标目录。
- Mock：`USE_MOCK=true` 时按模块冻结 demo 种子；`false` 时零 mock 直连网关；**禁 Java / 前端造数**。
