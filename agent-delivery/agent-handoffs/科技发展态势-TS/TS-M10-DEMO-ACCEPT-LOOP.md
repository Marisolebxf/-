### 缺口

本轮无缺口，未建子任务。轮内发现并当轮修掉的问题如下，均属实现缺陷，不是数据缺口：

| 问题 | 修复 |
|---|---|
| 人工改关系类型 / 年份后再删关系或解挂，回推荐的年份变成人工值（2024 → 2025） | 成员表加 `snapshot_strength / snapshot_time_to`，按挂接时快照回写；新增 2 条单测，LOOP 加「回推荐为原值」检查 |
| 前端 validate 请求漏 `base_version` | 预览前现取 R2 版本 |
| 首屏推荐未进跨页缓存，勾选后提示「请先勾选」 | 监听推荐列表并入缓存 |
| 全局请求去重中止同 URL 并发 GET，图层配置加载显示「canceled」 | store 遇取消重试一次 |
| 画布右键菜单刚打开就被遮罩的原生 contextmenu 关掉 | 遮罩在打开 400ms 内忽略右键 |
| v2 脚本：src-1 未复原到知识产权组，「公网 API 连通样例」被解挂；src-2 指向不存在的占位表 | 脚本改为复原 src-1 / src-4 挂组；src-2 改指 `dwd.dwd_zh_paper`（条件更新） |
