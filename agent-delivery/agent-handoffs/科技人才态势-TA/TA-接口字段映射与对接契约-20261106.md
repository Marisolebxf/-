## 4. 画像页 / 推荐页（双档 + 501 档）

- `TalentProfileDataset.talents[]` = **MVP 15 名重点人才**（`ads_talent_public_enrichment`/`ads_talent_honor_detail` 覆盖集），地图/机构「代表人物」点击全部落在该集合，保证画像页有完整真实数据。
- 真实字段：基础（`ads_talent_profile`：姓名/ORCID/机构/国家城市/教育经历 `ads_talent_experience`/论文专利项目计数与被引/h_index）、荣誉（`ads_talent_honor_detail` 93 条正式事实）、合作网络（`ads_talent_collaborator` + `ads_talent_institution_cooperation_*`，节点=合作者/机构）、相似学者（`ads_talent_similarity_card`）、学科演化（`ads_talent_yearly_discipline`）。
- 无源/演示字段（诚实空态或 null，nature 随 DTO 注释）：`overseasVisits/overseasExchanges`（叶 1122 无源 → []）、`nlpFieldProfile`（无 NLP 产出 → 空骨架+说明）、`socialInfluence`（media_report 仅 15 人 30 条，真实计数；invitedTalks/societyRoles 无源 null）、`difficultyEstimate/costEstimate`（深度算法 T7/T12/T13 未建 → 不造分，推荐页 Difficulty/Cost Tab 走 501 档语义）。
- 推荐页 `recommendations[]`：**自算口径 v1**（本文件拍板）：`ads_talent_capability_assessment`（人才级四维综合分 + 总学科匹配度，99,996 人真实值）TopN + `matchReasons` 来自 `ads_talent_research_problem_discipline_match` 最佳问题分；`aiScore/matchScore` 区分标注口径版本 `ta_recommend_self_v1`。`contributionScores[]` 用真实五维（papers=citations_count 分位、impact=h_index 分位、projects/patents=真实计数、network=合作机构数）。`sources` 计数全部真实。
- 风险字段：`risks`（合作/诚信/有效性/IP）无源 → null + 空态，不写「无风险」。
