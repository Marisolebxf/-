# TA · 四层联调指引（2026-11-07，按 v1.3 代码现场实测配置）

- 适用：科技人才态势四页（global/region/profile/recommend）本地全链路验证
- 链路：FE(lumen-ui-science-pc dev server) → **display :7099**（local profile，直连模式）→ show_py :8082（FastAPI）→ 久新 Doris
- 本地联调**不需要 Nacos / gateway**（application-local.yml 已关服务发现，Feign 走 url 直连；浏览器直打 display，不经 gateway）

## 2. 预热四端点（先 curl 一轮，避免 FE 首屏超时）

```
for p in global region profile recommend; do
  curl -s -X POST http://127.0.0.1:8082/internal/gkx-show/talent/%p%-dataset -H "Content-Type: application/json" -d "{}" -o nul
done
```

- 首跑实测：global ~75s / region ~51s / profile ~3s / recommend ~14s；缓存后秒级
- **FE 默认超时 50s（VITE_APP_REQUEST_TIMEOUT）**——预热不做好，全球页/区域页首开必超时

## 6. 常见故障对照

| 现象 | 原因 | 处置 |
|---|---|---|
| 四页全空 | RemoteShowPythonClient 方法漏 `@NoToken`，内部链路拒掉 | 现代码已标，勿删；现象=「数据全空」与「久新无数」极像 |
| display 日志 Connection refused | show_py 没起 / 端口不对 | 步骤 1；确认 `gkxlumen.show.python-base-url=127.0.0.1:8082` |
| 久新 SQL 报错 / 全空 | GKX_JIUXIN_* 未生效（新终端窗口） | 环境变量随 uvicorn 启动会话走 |
| FE 页面 502/超时 | 首跑 >50s 未预热 | 步骤 2 预热 + REQUEST_TIMEOUT=120000 |
| 数据是旧口径 | uvicorn 旧进程 | 重启 show_py |
| R code!=0 data 空 | display 降级 emptyDataset | 看 display 日志 `[talent] *-dataset failed` 栈 |
