## 二、156 个跨系统指标的差异分级

| 分级 | 数量 | 占比 | 含义 | 处置建议 |
|---|---:|---:|---|---|
| D1 名称级冲突 | 0 | 0.0% | 同名指标核心定义实质不同 | 拆分或会签择一 |
| D2 口径级分歧 | 19 | 12.2% | 维度构成/计算方法/权重实质差异 | 三方会签统一 |
| D3 详略级差异 | 69 | 44.2% | 算法侧完整定义 vs 系统侧功能级要求 | 以算法侧为准 |
| D4 互补级差异 | 59 | 37.8% | 各侧侧重不同可互补 | 合并口径卡 |
| D5 表述级差异 | 9 | 5.8% | 语义基本一致 | 登记同义词 |

> 注：本轮 D1 为 0 的原因——三文档由同一项目总体方案衍生，同名指标未见「对象级冲突」（如一个是企业级一个是区域级仍属 D2 范畴）；最接近 D1 的案例（如商业力六维 vs 四维）按实质判 D2。

### 通俗版分级标准（详见《差异分级标准通俗解释.md》）

五个级别回答同一个问题：**同一指标在不同文档里，说法差多远？** 从重到轻：

- **D1 名称级冲突**：同名不同物，根本是两个指标（本轮 0 个）
- **D2 口径级分歧**：是同一个指标，但「怎么算」打架了——按谁算结果不一样（19 个，唯一会产生两个答案的级别，评审最优先）
- **D3 详略级差异**：算法库写清了「怎么算」（五步法施工图），系统文档只写了「页面上要展示什么」（菜单上的卖点）——不是矛盾，是详略差（69 个，以算法侧为准实现即可）
- **D4 互补级差异**：一边讲「怎么生产」、一边讲「怎么消费」，各说一半，拼起来才完整（59 个，合并口径卡）
- **D5 表述级差异**：同一件事只是用词不同（9 个，登记同义词即可）

各级别的真实案例原文对照（如 M_ENT_BUSINESS_POWER_SCORE 的六维 vs 四维、M_CHAIN_PATENT_COUNT 的五步法 vs 一句话展示要求、M_CHAIN_NEWS_SENTIMENT_RATIO 的生产侧 vs 消费侧）见《差异分级标准通俗解释.md》。

### 典型 D2 案例（最需会签的一组）

| 指标 | 算法库口径 | 系统(展示/专题)侧口径 |
|---|---|---|
| M_ENT_BUSINESS_POWER_SCORE 商业力 | 六维：市场/产品/品牌/技术合作/链覆盖率/关键环节参与 | 四维：年营收/利润率/客户集中度/品牌声量（用户可调） |
| M_CHAIN_REGION_INDEX 区域产业指数 | 固定三维：企业能力/学术生态/配套生态竞争力 | 用户自定义指标、权重、评价对象（全链路可配置） |
| M_ENT_COMPETITIVENESS_SCORE 综合竞争力 | 财务/人力/市场表现多维加权 | 「技术+市场+组织」三维一体框架 |
| M_CHAIN_STAGE_SCORE 产业阶段 | 四维（产能/销售/份额/利润率）+周期模型阈值判定 | 大模型生成周期阶段判断（观点维护） |
| M_POLICY_SUPPORT_STRENGTH 支持力度 | 政策基础指标：级别/类型/时序统计 | 区域政策评价三维框架之「支持力度」（档位×权重待定） |

## 三、20261021 调研实现的倾向性（详见《倾向性深度调研报告.md》）

| 倾向方 | 数量 | 占156比例 | 其中100%压倒性 |
|---|---:|---:|---:|
| 算法库 | 79 | 50.6% | 28 |
| 展示+专题文档 | 63 | 40.4% | 42 |
| 项目内部口径（calc-logic/王惠） | 12 | 7.7% | 11 |
| 未定向 | 2 | 1.3% | — |

**一句话结论**：20261021 调研的实现口径总体**偏向算法库文档**（51% vs 40%），其中页面拆件族（`M_INNOV_DS_*` 等）明显偏向展示系统；11 个指标三方文档均无定义、纯靠项目内部拍板，是验收风险最高的一组。

## 五、方法与边界说明

1. **出现判定四路证据**：①20261021 调研 MD 附录A 的三文档检索登记（110 份含交叉结论）②指标名全文检索 ③别名/语义域检索 ④需求出处 §编号归档。四路证据并集判定，反证行（「未检索到」）已排除。
2. **「无直接文档对应」不等于无价值**：131 个指标大多有明确的上位功能语义（挂在某页面/模型下），只是指标名与口径为项目自建，正式交付前需甲方逐一见签。
3. **差异分级为自动初判+人工校准**：D2 案例经人工逐一阅读三文档原文确认；D3/D4 依据证据文本体裁特征（算法阐述/五步法 vs 功能包括/用户可）判定；如需复议，每份报告 §二 保留了三文档原文摘录可直接比对。
4. **倾向性为文档倾向**：判定「倾向某文档」描述的是调研实现引用与遵循的证据来源，不等于实现满足该文档全部要求（大量指标本身「文档未给定义」，实现按推测口径，均已在 20261021 调研中标注待会签）。
