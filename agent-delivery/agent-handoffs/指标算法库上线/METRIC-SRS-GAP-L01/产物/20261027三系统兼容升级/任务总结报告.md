## 三、兼容接口契约（164 份核心 py 统一）

统一入口 `compute(params: dict|None) -> dict`，返回五段式：

```text
{ value, detail, display, assumptions, applicable_systems, params_effective }
```

- **算法库**：全参数传入，流水线精确计算；
- **专题系统**：缺参走缺省（DEFAULTS 声明 + assumptions 回填依据）；
- **展示系统**：消费 `display` 段（雷达/柱状/榜单结构位）。
- 契约全文：`过程文件/04_兼容接口设计规约.md`；样板：`M_CHAIN_PATENT_COUNT`（D3）/ `M_CHAIN_NEWS_SENTIMENT_RATIO`（D4）/ `M_ENT_BUSINESS_POWER_SCORE`（D2 可兼容）。
