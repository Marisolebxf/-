## 摘要

本指标把「区域创新要素」拆成人才、企业、政策、服务机构、科研机构、资金、空间七个结构，
结构内叶子批内极值归一等权，七结构等权合成 0—100。在 gkx 上重算的结果是：
深圳 76.5、广州 69.1、东莞 12.5、惠州 6.5，排序为深圳 > 广州 > 东莞 > 惠州。

深圳赢在五个结构：政策 100.00 对 63.94、科研机构 100.00 对 51.23、资金 100.00 对 24.28、
空间 100.00 对 70.00、企业 96.03 对 74.20。广州赢在两个结构：人才 100.00 对 13.96
（学者密度 185.1 对 25.8 人/万家企业）、服务机构 100.00 对 25.59（科技服务业占比 36.25% 对 10.46%）。
深圳与广州只差 7.4 分，是七结构互相抵消后的净值。

两个必须写进发布口径的限定：其一，人才结构维用的是学者底册（四市只覆盖 1,174 人、占全表 5.51%），
深圳 247 人明显低于其实际人才体量，这一维对深圳是系统性低估；其二，空间结构维只有
企业名称关键词代理（59/44/13/9 家），不是园区名录，不能对外称「创新空间面积」。

### 1.2 口径定义（王惠原文要点）

王惠表对该指标的定义是：把一个区域的创新要素分成**七个结构**——创新人才、企业、政策、
服务机构、科研机构、资金、空间——每个结构下挂若干叶子指标，叶子极值归一后结构内等权，
七个结构再等权，得到 0—100 的类型结构指数。

三处需要讲明：

1. **「类型」指的是要素的结构构成，不是要素总量**。同样是人才，187 看「每万家企业有多少学者」，
   184 看「人才的四维画像」；同样是政策，187 只看文件数与类型数，185 才做政策三维。
2. **七结构等权是口径决定**。七个结构里空间维只有一片叶子、企业维有三片，等权意味着
   「结构」比「叶子」重要——这是王惠框架的设计，不是统计拟合。
3. **叶子必须可复现**。187 的产物同时是 188 的输入，所以叶子的键名、单位、缺失标记都要固定，
   任何改名都会让 188 直接 `KeyError`（本批把这个契约写死在两边脚本里，见 §1.5）。

### 1.3 计算公式与本批实现式

批内极值归一（跨四城）：

$$\tilde{x}_{c,\ell}=\frac{x_{c,\ell}-\min_{c'}x_{c',\ell}}{\max_{c'}x_{c',\ell}-\min_{c'}x_{c',\ell}}\times 100$$

结构内叶子等权（缺叶不进分母）：

$$S_{c,s}=\frac{1}{|L_s^{ok}|}\sum_{\ell\in L_s^{ok}}\tilde{x}_{c,\ell}$$

七结构等权：

$$I_c=\frac{1}{7}\sum_{s=1}^{7}S_{c,s}$$

本批十五片叶子与七个结构：

| 结构 | 叶子 | 单位 | 数据来源 |
|---|---|---|---|
| 人才结构 | D1_学者密度 | 人/万家企业 | 学者底册 ÷ 企业底册 |
| 人才结构 | D1_高学历人才占比 | % | 学位记录内硕博占比（**只披露，不进分**） |
| 企业结构 | D2_新注册企业数2024 | 家 | `incorporation_year=2024` |
| 企业结构 | D2_科技型企业占比 | % | 国家级高企 ÷ 企业数 |
| 企业结构 | D2_大型企业占比 | % | `org_size='大型'` ÷ 企业数 |
| 政策结构 | D3_政策文件数 | 条 | 市级政策存量 |
| 政策结构 | D3_政策类型数 | 类 | 文件体裁去重（非主题） |
| 服务机构结构 | D4_科技服务业企业数 | 家 | 行业一级「科学研究和技术服务业」 |
| 服务机构结构 | D4_科技服务业企业占比 | % | 同上 ÷ 企业数 |
| 科研机构结构 | D5_科研机构数 | 家 | 机构底册 2,074 行 |

`leaves_degenerate_excluded` 里的叶子虽然出现在 `leaves` 里，但 188 必须同样排除，
否则两件的口径会分叉（本批 188 已读取该字段）。

这个契约是 §3.20 事故的直接产物：旧版 188 的 `leaf_source` 指向一个不存在的
`M_SYNTH_187_1_out.json`，脚本跑不起来；本版把「上游产物必须在同目录、可独立运行」
和「键名必须逐字一致」两件事都写进了脚本（188 缺叶子会 `SystemExit`，不会静默少算）。

### 2.2 归城与重名处理

企业类叶子直接按底册的 `city` 列聚合，不需要名称匹配；`city` 已是市级全称，
不做模糊归并（DATA_FACTS §3.8）。

需要名称匹配的只有两处：其一，学者归城（机构串三级规则：城市名 → 14 所高校白名单 → 机构串），
全表 21,316 位学者判出 17,118 位（80.31%）；其二，科研机构授权（机构名册 2,074 个名称
与 2024 申请人库精确匹配，命中 120 家）。

重名摊权只在按名称 JOIN 时使用：底册 47 个重名名称按 1/k 摊到各城（DATA_FACTS §3.5）。
本批企业类叶子按 `org_id` 聚合，不触发重名问题；机构授权按名称精确匹配，命中即唯一，
也不摊权。这一点与 184 的专利归城不同，读表时不要以为漏了。

### 2.3 维内归一与权重

十五片叶子全部批内 min-max（跨四城）。这里有一个必须解释的现象：**min-max 会把小差距放大**。
例如 D2_大型企业占比四市是 1.18% / 1.23% / 0.77% / 1.15%，极差只有 0.46 个百分点，
归一后却变成 88.08 / 100.00 / 0.00 / 82.78——东莞单独落到 0，看起来像「东莞没有大型企业」，
实际是 0.77% 对 1.23%。这类叶子的信息量很低，但它不是「错」，所以保留；
真正会误导的是「只有两城有值、差距又统计不显著」的叶子（D1_高学历），那一片才被退出。

结构内等权时，缺叶不进分母：人才结构对东莞、惠州只剩一片叶子（学者密度），
企业/政策/科研/资金四结构四城都是三/二/三/二片全齐。

### 2.4 指数合成与缺维处理

七结构等权，每个结构的得分已经吸收了「缺叶不进分母」。本批没有整结构缺失，
所以没有触发缺结构分支；脚本仍保留「某结构四城全 null 时该结构不进指数」的逻辑。

D1_高学历人才占比的处理单独说明。它能算出两个值：深圳 100.00%、广州 97.40%，
东莞与惠州无学位记录；两城差异 Fisher 精确检验 p=0.5498。若照常归一，
深圳 100、广州 0，人才结构从「广州 100 / 深圳 13.96」变成「广州 50 / 深圳 56.98」——
一个 2.60 个百分点、统计不可区分的差异，直接改写人才结构的排序。
本批的处理是：原始值与归一值都写进 `out.json`，`dim_scores` 不用它，
理由写进 `leaves_degenerate_excluded`。这与 184 的 D2/D3 处理是同一套原则：
**能算出数 ≠ 有数据支持**。

### 四.2 结构性缺口（扩量救不了）

1. **学者表与「产业创新人才」不是同一口径**。这张表以高校院所为骨架，扩量补不出企业研发人员。
   与 184 的同款问题，见 184 §四.2。
2. **`funding_amount` 的文本格式不是「脏」，是「没有结构化」**。它把币种、金额、单位写在
   同一个字符串里（「8320.0万人民币」「4.70049747亿人民币」「1.1亿美元」），
   任何 `SUM()` 都是在加不同量纲的数。扩量只会让这个列更长，不会让它可加。
3. **园区代理数不是园区数**。企业名称里带「园区」的公司可能是园区运营方，也可能是注册在园区
   的企业；这个代理只能做「空间要素活跃度」的弱信号，不能做存量统计。

### 四.4 缺口对判档的影响

七结构都可算，但人才维口径偏、服务机构维降级、空间维只有代理、一叶退出。
「完全转换支持」要求结构与数据量都够，这四条里任何一条都足以否掉；七结构又都不是空的，
所以也不是「完全不支持」。判「部分支持」，档位由最弱的四叶决定。

做了三项检查（改口径重算）：

1. **去掉人才结构**（六结构等权）：深圳 86.94、广州 63.94、东莞 14.29、惠州 7.60。
   排序不变，深圳领先从 7.4 扩到 23.0——人才维是唯一让广州接近深圳的结构。
2. **把退化叶退回人才结构**（旧式四叶处理）：深圳 82.7、广州 62.0、东莞 12.5、惠州 6.5。
   排序不变，但深圳领先扩到 20.7，因为广州在学历叶上拿 0。这说明「退不退出」这一片叶子，
   会改变两市间距 13 分，但不会改变排序。
3. **十五叶直接等权（不分结构）**：深圳 82.37、广州 65.91、东莞 12.61、惠州 8.68。
   排序不变，深圳领先扩到 16.5。结构等权与叶子等权的差别在于「空间结构只有一叶要不要和
   三叶的企业结构等重」，本批按王惠口径用结构等权。

三项的共同结论：**排序稳健（深圳 > 广州 > 东莞 > 惠州），间距不稳健（7.4—23.0 分区间）**。
发布时应强调排序，弱化绝对分差。

### 五.5 反常识点与解释

**反常识一：深圳的综合分只有 76.5，却有四个结构拿满 100。**
因为七结构等权，另外三个结构（人才 13.96、服务机构 25.59、企业 96.03）把均分拉下来。
这正是「结构等权」的设计意图：不让单一强项决定城市画像。

**反常识二：东莞的科技服务业占比（22.52%）高于深圳（10.46%）。**
深圳的科技服务业企业绝对值是东莞的 1.32 倍（10,002 对 7,565），但它的分母（95,600 家企业）
是东莞的 2.85 倍，所以占比反而低。占比与总量在这里指向相反结论，本批两个叶子都保留，
正是为了不让单一口径独占解释权。

**反常识三：广州上市研发只有深圳的 13.5%，但它的综合分只低 7.4 分。**
因为资金结构在七结构里只占 1/7，而广州在人才与服务机构两结构拿满，足以抵消。
这也是「等权」与「按总量加权」会给出不同排序的典型场景——本批按王惠口径等权，
不做数据驱动调权。

## 六、结论与发布建议

### 六.1 可用结论

1. 在 gkx 可归属范围内，四市创新要素类型指数为深圳 76.5、广州 69.1、东莞 12.5、惠州 6.5，
   由七个结构等权合成。
2. 深圳在政策（879 条）、科研机构（1,014 家）、上市研发（1,545 亿元）、园区代理（59 家）
   四项上都是四市第一；广州在学者密度（185.06 人/万家）与科技服务业占比（36.25%）两项第一。
3. 深圳与广州的差距只有 7.4 分，属于「结构互补型竞争」，不存在单方面碾压。
4. 东莞与惠州与前两名不在同一量级（12.5 / 6.5），但两者都有非零结构（东莞服务机构 41.52、
   惠州企业 28.68），不是全零。

### 六.2 不可用结论

1. **不能用人才结构维论证「广州人才是深圳 7 倍」**。学者密度基于 5.51% 覆盖的表，
   深圳企业研发人才不在其中。
2. **不能引用「深圳有 59 个园区」**。59 是企业名称关键词命中数，不是园区名录计数。
3. **不能引用「融资总额」**。本版只有笔数，旧稿的 6,688,003 是自由文本求和的产物，不可用。
4. **不能拿服务机构维做「服务业发达程度」比较**。它是行业口径（科学研究和技术服务业），
   不是六类科技服务机构。
5. **不能与旧稿读数相减**。评价集、叶子、口径全变，87.2 → 76.5 不是「下降」。

### 六.3 发布口径建议

对外建议用这样一句话：「在深圳都市圈四市范围内，按人才、企业、政策、服务机构、科研机构、
资金、空间七结构等权评价，2024 年区域创新要素类型指数为深圳 76.5、广州 69.1、东莞 12.5、
惠州 6.5；政策为存量口径（采集止于 2022），人才为学者底册口径（四市覆盖全表 5.51%），
空间为名称关键词代理。」

同时建议在脚注写三个覆盖率：企业底册四市 99.82%、学者四市 5.51%、政策四市 6.06%。
