### 0.3 本指标套用（一句话）

## 摘要

痛点不是一个分数，而是五次「问诊」。本件对每一路单独出读数，再做四市 min-max 对比，最后给一个自拟权重的合成分——合成分只作排序参考，不对外发布。

| 读数 | 值 |
|---|---|
| 四市科研机构底册 | 2,074 家（唯一名 2,070） |
| 深圳机构 | 1,014 家（占底册 48.891%） |
| 深圳可识别（任一路有值） | 128 家（12.6233%） |
| 深圳不可识别 | 886 家（87.3767%） |
| 纵向项目 | 20 家 / 212 笔 / 经费 10,748.6 |
| 专利转让 | 5 家 / 12 笔 |
| 中文论文 | 80 家 / 558 篇 |
| 专利 | 87 家 / 3,425 件（授权 1,929 件，56.3212%） |
| 政策提及 | 29 家 / 93 次 |
| 项目集中度（前 5 家） | 78.3019% |
| 经费集中度（前 5 家） | 82.9373% |
| 每百家机构项目数 | 20.9073（广州 44.6472） |
| 每百家机构转让笔数 | 1.1834（广州 6.5693） |
| 每百家机构论文数 | 55.0296（广州 305.7178） |
| 每百家机构专利数 | 337.7712（广州 326.764） |
| 四市综合痛难度 | 61.5（自拟权重） |
| 判档 | 部分支持 |

第一个事实是**覆盖率**。1,014 家深圳机构里 886 家在五路上一条记录都没有（87.3767%），只有 128 家可识别。这不是「深圳机构都不产出」，而是底册口径把大量非科研主体也纳进来了：按登记类型，民办非企业单位 789 家（77.8107%）、事业单位 214 家（21.1045%），前者包含大量教育培训、医疗、社工类机构，它们本来就不发论文、不申专利。把 886 家读成「零产出机构」是错的，正确读法是「不可识别」。

第二个事实是**产出结构**。深圳专利每百家 337.7712 件，四市最高（广州 326.764、东莞 240.9449、惠州 123.4234）；但论文每百家 55.0296 篇只有广州的 0.18 倍，转让每百家 1.1834 笔只有广州的 0.1801 倍。也就是说，深圳机构「会申请专利，但不怎么写中文论文，也不怎么把专利卖出去」。痛点落在成果转化端，而不是研发端。

第三个事实是**集中度**。项目前 5 家占 78.3019%、经费前 5 家占 82.9373%，转让维前 5 家占 100%（只有 5 家有值）。这意味着任何「机构平均痛点」的统计都被少数头部机构主导，中位数比均值更有代表性。

| 下游 | 机构培育名单、四市科研对比、政策投放评估 |

### 1.2 为什么需要「机构痛点」

科研机构的政策需求与它的卡点直接相关。一家拿不到纵向项目的机构，需要的是「申报辅导」；一家专利很多但卖不掉的机构，需要的是「转化对接」；一家论文多但没项目的机构，需要的是「产学研通道」。如果只按规模（人数、经费）分类，这三类机构会被混在一起，政策投放就会失焦。

痛点分析的作用是把机构按「卡在哪一环」分组，而不是按「有多大」分组。它的输出不是排名，而是分型：缺钱型、缺转化型、缺学术型、缺关注型。每一型对应不同的政策工具。

### 1.3 口径定义

五路观测面，每路一个计数：

$$x_{i,k}=\text{count of dimension } k \text{ for institution } i,\quad k\in\{\text{project},\text{transfer},\text{paper},\text{patent},\text{policy}\}$$

四市 min-max 痛难度（越高越痛）：

$$P_{c,k}=100\times\frac{\max_{c'} r_{c',k}-r_{c,k}}{\max_{c'} r_{c',k}-\min_{c'} r_{c',k}},\qquad r_{c,k}=\frac{\sum_{i\in c}x_{i,k}}{n_c}\times 100$$

其中 $r_{c,k}$ 是「每百家机构」的产出率，用每百家而不是总量，是为了消除城市机构数差异——深圳 1,014 家、惠州 111 家，直接比总量没有意义。

三条补充约定：

第一，**分母固定为全量机构**。每百家用的是本市全部机构数（深圳 1,014），不是可识别的 128 家。理由是政策投放面向全量机构，用可识别集作分母会把「不可识别」当成「不存在」。

第二，**零值不插补**。886 家全零机构保留在分母里，不按均值插补、不剔除。

第三，**合成分只作参考**。权重（项目 0.3、转让 0.25、论文 0.2、专利 0.15、政策 0.1）为本工程自拟，`weights_are_authored=true`、`main_is_official=false`，不得对外发布为「官方痛难点指数」。

### 1.4 计算公式与本批实现式

```python
def per_100(total, n):
    return total / n * 100 if n else None

def pain(rate, lo, hi):                 # 越高越痛
    return 100 * (hi - rate) / (hi - lo) if hi > lo else None

composite = sum(w[k] * pain_score[k] for k in w)   # w 自拟，和为 1
```

实现上有一个容易忽略的点：min-max 的极值来自四市本身，所以「痛难度 0」只表示「四市中最好」，不表示「不痛」。深圳专利痛难度 0，是因为它的每百家专利数最高；如果把广州换成北京，这个 0 可能变成 40。产物里因此把 `city_pain_scores` 与 `city_baseline` 同时落盘，让读者能看到原始率而不只是分数。

## 二、计算过程

### 2.1 底册与城市归属

底册 `dwd_research_institute_base_info` 四市共 2,074 家，按名称去重后 2,070 个唯一名（4 家同名不同 id，保留全部）。按注册地 A 列切分：深圳 1,014、广州 822、东莞 127、惠州 111，合计 2,074，无未归属机构。

按 A 列而不是按办公地归属，是因为底册只有注册地字段。这带来一个已知偏差：在深圳设研究院但注册在广州的机构会被算进广州。P13 已就此定规：机构归属一律按注册地，跨市分支不重复计。本件遵守该裁定，并在正文披露。

### 2.2 五路桥接

五路都要把外部记录桥到机构 id，桥接方式各不相同。项目按承担单位名称精确匹配；转让按转出方与转入方名称双向匹配（同一笔转让对两家机构各计一次，方向分别记 `transfer_out` / `transfer_in`）；论文按作者单位名称匹配；专利按申请人名称匹配；政策按机构全称在政策文本中的出现次数计。

名称匹配是本件最大的误差源。机构更名、简称、多块牌子（如「深圳市第二人民医院（深圳市转化医学研究院）」）都会导致漏计。面板快照 `org_family_panel_20261021.json` 里 `patent_matched_orgs` 只有 219/2,074，说明专利桥接的覆盖率本身就不高。这一点必须在读数旁边写明，否则「零专利」会被误读成「不申请专利」。

### 2.3 覆盖率与可识别集

五路任一有值的深圳机构共 128 家（12.6233%），全零 886 家（87.3767%）。全零不等于无产出：一家教育培训类民非机构本来就不该有专利和论文，它在底册里但不在「科研」语义里。

可识别集的 128 家里，分路有值数为：项目 20、转让 5、论文 80、专利 87、政策 29。五个数相加远大于 128，因为一家机构可以同时有论文和专利。这个重叠结构决定了后面「单路痛难度」不能相加成总分——相加会把同一家机构重复计五次。

### 2.4 四路集中度

项目：20 家有值、共 212 笔，中位 4 笔、p90 17 笔、最大 102 笔，HHI 0.259879，前 5 家占 78.3019%，零值机构占 98.0276%。
转让：5 家有值、共 12 笔，中位 2 笔、最大 6 笔，HHI 0.319444，前 5 家占 100%，零值占 99.5069%。
论文：80 家有值、共 558 篇，中位 2.5 篇、p90 10 篇、最大 95 篇，HHI 0.070374，前 5 家占 51.2545%，零值占 92.1105%。
专利：87 家有值、共 3,425 件，中位 9 件、p90 76 件、最大 943 件，HHI 0.109502，前 5 家占 58.1314%，零值占 91.4201%。
政策：29 家有值、共 93 次，中位 1 次、p90 3 次、最大 45 次，HHI 0.250549，前 5 家占 68.8172%，零值占 97.14%。

五个 HHI 里，转让（0.319444）与项目（0.259879）最高，论文（0.070374）最低。含义是：项目与转让高度集中在少数机构手里，论文相对分散。政策 HHI 0.250549 也偏高，说明「被政策点名」本身就是稀缺事件，集中在少数几家。

## 四、数据缺失情况

### 4.1 产学研合作痛点：结构性无源（拒拟维）

gkx 无 `enterprise_cooperation`；`information_schema.TABLES WHERE TABLE_SCHEMA='gkx'` 命中 0 行；开发库 `gkxlumenx_dwd` 有结构但 0 行；演示库同名表为全量装载，铁律禁引，不构成支持。

**拒拟理由**：没有机构—企业的合作边，无法回答「想合作但找不到企业」这类关系型痛点。
**替代口径**：专利转让 × 纵向项目 × 论文三路独立刻画。
**与原文差别**：三路只能反映机构「已经做成了什么」，看不到「想做什么但没做成」。合作缺口往往表现为「有技术、没场景」，这在三路里完全没有痕迹。

### 4.2 经费强度：无分母（拒拟维）

`employees_number` 整列为空（DATA_FACTS §3.71），机构人数缺失；`project_fund` 单位未在表结构中标注。没有人数就没有「人均经费」，没有单位就不能跨机构相加。

**拒拟理由**：缺分母与单位。
**替代口径**：项目经费绝对额与集中度。
**与原文差别**：只能比「谁拿的钱多」，不能比「谁的钱效率高」；也无法区分「项目多而小」与「项目少而大」。

### 4.3 痛点年度演化：时间不可用（拒拟维）

论文年列受采集批次峰污染（2024 年占 32.09%，§3.74），不是真实的年度分布；项目只有起始年、无结题年；转让无时间序列。

**拒拟理由**：年列不可信，无法做趋势。
**替代口径**：快照截面。
**与原文差别**：不能判断痛点在改善还是恶化，也不能做政策效果的事前事后对比。

### 4.4 不可识别 886 家

87.3767% 的深圳机构在五路上全零。这不是数据错误，而是底册口径包含了大量非科研主体（民办非企业 77.8107%）。但也不能反过来断言「它们都没有科研活动」——有些机构有科研活动，只是没有进这五张表（比如横向课题、技术服务合同、国际论文）。本件把这一块标为「不可识别」，而不是「无痛点」。

### 4.5 中文论文的口径偏差

论文只取 `dwd_zh_paper`（中文论文），不含英文论文。广州有中山大学、华南理工等高校及其附属机构，中文论文产出天然高；深圳机构（尤其港校研究院）的论文大量发在英文期刊，不进这张表。因此「深圳论文只有广州的 0.18 倍」这个读数，至少有一部分是语言口径造成的，不能全归因于科研能力。

### 4.6 不得外推的三件事

1. **不得把 886 家读成零产出**：它们是不可识别，不是无活动。
2. **不得用合成分对外排名**：权重自拟，min-max 只在四市间可比。
3. **不得用转让笔数判断转化能力**：许可、作价入股、技术开发合同都不进专利转让表。

### 4.7 停用与重估条件

出现以下任一情况应重估：① 合作边入湖（可算产学研痛点）；② 机构人数补齐（可算经费强度）；③ 英文论文入湖（论文口径可比）；④ 底册口径收紧到「严格科研机构」（分母变，全部率重算）。

## 五、结论与发布建议

### 5.1 可用结论

第一，深圳 1,014 家机构中 128 家可识别（12.6233%），886 家不可识别。第二，专利每百家 337.7712 件四市最高，论文 55.0296 篇只有广州的 0.18 倍，转让 1.1834 笔只有广州的 0.1801 倍。第三，项目前 5 家占 78.3019%、经费前 5 家占 82.9373%，集中度极高。第四，7 家双薄弱机构可作培育候选。第五，合作维无表，判部分支持。

### 5.3 与旧稿的取舍

旧稿（镜像面）曾用演示合作表给出「产学研合作痛点」，本版不再引用。本版的五路全部来自 gkx 真实表；档位仍判「部分支持」，但缺口从「数据不可信」换成「合作维缺失 + 论文语言口径偏差」。

### 5.4 后续

三条路径：① 合作边入湖；② 英文论文入湖；③ 机构人数补齐。三者任一落地都要重跑四市基准与痛难度——尤其英文论文，一旦并入，「论文 0.18 倍」这个结论可能大幅收窄。

## 附录 D　「专利强、转化弱」这一结论的证据边界

这个结论是本件最重要的业务判断，所以把它的证据边界单独写清。

支持它的证据有三条。第一，深圳专利每百家 337.7712 件，四市最高，且授权率 56.3212%，说明不是「只申请不授权」的虚高。第二，转让每百家 1.1834 笔，广州 6.5693、东莞 16.5354，深圳在四市中偏低。第三，转让维前 5 家占 100%，只有 5 家有转让记录，说明转让行为本身在深圳机构里极不普遍。

削弱它的证据也有三条。第一，转让表只收专利转让登记，许可、作价入股、技术开发合同都不在内，而深圳的技术转移大量走这三条路径。第二，专利按申请人名称桥接，面板里 `patent_matched_orgs` 只有 219/2,074，深圳 87 家有专利记录可能只是「桥上的」，没桥上的没算。第三，转让的受让方多为企业，按机构侧统计会漏掉「机构转给企业」的完整链路——本件只数了机构作为转让方/受让方的笔数，没有追踪去向。

结论：可以说「在专利转让登记这一口径下，深圳机构转化率显著低于广州、东莞」，不能说「深圳机构不转化」。发布时必须带口径限定词。
