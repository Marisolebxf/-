## 摘要

本指标要回答的是「深圳科研机构的现状到底怎么样」：有多少家、结构如何、成长快不快、产出高不高、经费和人才够不够。用 gkx 机构底册 + 专利 + 国基金 + 学者四张表拼出七维记分卡后，深圳在四城比较中综合得分 **88.8**（满分 100），排名第 1，但七个维度里有三个是**靠不到 10% 的样本撑起来的**。

具体数字：深圳 1,014 家机构，是广州 822 家的 1.23 倍、东莞 127 家的 7.98 倍、惠州 111 家的 9.14 倍；类型结构以民办非企业单位为主（789 家，77.81%），事业单位 214 家（21.10%），结构均衡度 35.00，四城中最低（惠州 47.04、广州 46.63）。成长维取 2021—2025 年登记数，深圳 174 家，低于广州 243 家，得分 71.6。产出维每家有专利机构平均 39.37 件，四城最高；经费维每家 537.43 万元（NSFC 资助额），与广州 534.55 万元几乎持平；人才维每家 5.5 位学者，略高于广州 4.88 位。

问题在第七维：深圳的证据覆盖率只有 **11.83%**（120/1,014 家至少有一类证据），低于广州的 21.05%、东莞的 16.54%，只高于惠州 9.91%。也就是说，深圳有 894 家机构（88.17%）在四张证据表里**一条记录都没有**——不是它们不存在，而是名称匹配不上或确实没有专利/项目/论文。这一维拿 56.2 分，是七维里唯一的「短板」。

**结论**：规模、结构、成长三维可作城市级结论；产出、经费、人才三维只能作「有证据子集」的结论，不能外推到 1,014 家；产业切片完全不可得。按 §〇 判**部分支持**。复现代码见 `code/M_ORG_SZ_STATUS.py`，结果见 `code/M_ORG_SZ_STATUS_out.json`。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

「科研机构深度分析模型构建」下的**深圳科研机构现状分析**。产品形态是一张城市画像页：顶部关键数字（机构数、类型结构、登记趋势），中部七维雷达/条形，底部重点机构清单。

需求原文给的是一组观察面而不是公式：规模、结构、成长、产出、经费、人才，再加一句「在该产业」。这句话把指标从「城市画像」变成了「产业切片画像」，是本件最大的口径难点。

### 1.2 为什么需要这个指标

深圳的科研机构底册长期被诟病「数量多、质量参差」：1,014 家里 789 家是民办非企业单位，名称带「研究院」的有 748 家。到底有多少是真正在做研发的？这个问题不能靠名单回答，只能靠证据（专利、国基金、论文、学者）回答。

七维记分卡的价值在于把「数量叙事」和「质量叙事」分开：规模维深圳必胜，结构维深圳垫底，产出维深圳靠 87 家撑起，证据覆盖维深圳输给广州。四个结论指向四种政策动作，比一句「深圳科研机构数量领先」有用得多。

### 1.3 需求文档是否给出定义方法

**需求文档没有给出计算方法。** 缺以下关键项：

- **维度权重**：六个观察面各占多少？需求没说。
- **归一化**：不同量纲（家、件、万元、人）如何合成？需求没说。
- **比较基准**：跟谁比？全国、全省、还是四城？需求没说。
- **「在该产业」**：产业分类用「20+8」还是国标？机构如何归属到产业？需求没说。
- **经费口径**：R&D 经费、科技经费、还是财政资助？需求没说。

本件因此必须自定义权重与归一化，并在正文标注「本件自定义、待甲方确认」。

## 二、计算过程

### 2.1 方法选择：为什么用「城市均值 + 四城 min-max」而不是全国分位

需求要的是「深圳现状」，本质是城市画像。城市画像有两种做法：一是跟全国比（分位/标准分），二是跟周边比（四城相对位置）。前者需要全国机构底册，库内没有——底册 99.82% 在深圳都市圈，省外只有 342 家，做全国分位会得到荒谬的结果（深圳几乎每家都在全国前 1%）。

因此只能做四城相对比较：深圳、广州、东莞、惠州。这四个城市恰好是深圳都市圈的核心圈层，政策语境上也是深圳最常被拿来对标的对象。min-max 的基准取四城最优值，0 点取 0（而不是四城最差值），这样得分可以跨维比较：100 分意味着「四城第一」，0 分意味着「该项为零」。

这个选择的代价是：得分是**相对值**，广州换成北京，深圳的分数会变。因此正文所有分数都必须与「四城」一起读，不能单独说「深圳 88.8 分」。

### 2.2 步骤 1｜宇宙与城市归属

宇宙 = `org_family_panel_20261021.json` 的 2,074 家机构，城市字段来自 `dwd_research_institute_base_info.city`。四城分布：深圳 1,014、广州 822、东莞 127、惠州 111，合计 2,074。

自检：面板城市字段无空值，四城合计等于总数，说明底册没有「其他城市」的漏项——这与 DATA_FACTS §3.1 的「底册 100% 广东、四城占 99.82%」一致。省外 342 家不在面板内（面板只保留四城），因此本件无法做「深圳 vs 全国」。

### 2.3 步骤 2｜D1 规模与 D2 结构

D1 直接取城市机构数，深圳 1,014。D2 结构均衡度用 $1-\sum p_k^2$（1−HHI）乘 100，$p_k$ 是第 k 类机构占比。深圳八类占比：民办非企业 789（77.81%）、事业单位 214（21.10%）、基金会 5、空 2、司法鉴定 1、社会团体 1、编办管理其他 1、机关 1，算得 HHI = 0.6500，结构均衡度 = **35.00**。

必须强调：这个数**高不代表好**。惠州 47.04 最高，是因为它只有两类机构（民办非企业 69、事业单位 42），分布更「均匀」；广州 46.63 是因为事业单位占比 34.79%，比深圳的 21.10% 高。结构均衡度只描述「类型分散程度」，不描述「机构质量」。把它放进记分卡并给 0.10 权重，是本件自定义，待甲方确认。

### 2.4 步骤 3｜D3 成长

成长维取 2021—2025 年登记年计数，深圳 174 家、广州 243 家、东莞 39 家、惠州 35 家。深圳得分 71.6（=174/243×100），排第 2。

这里复用了 `M_ORG_NEW_TREND` 的同一套登记年口径，但只取近 5 年、只取四城合计，不做斜率。原因是记分卡要的是「近 5 年增量」这个水平量，不是趋势方向；趋势方向由 NEW_TREND 单独回答。两件共用同一份面板，因此深圳近 5 年新增必须都是 174，实测一致。

2026 年是残年（13 家），按 NEW_TREND 的同一规则排除在分母外。

### 2.5 步骤 4｜D4 产出、D5 经费、D6 人才

D4 产出 = 有专利机构的专利件数之和 / 有专利机构数。深圳 87 家有专利，合计 3,425 件，均值 **39.37 件/家**；广州 112 家、2,686 件、23.98；东莞 14 家、306 件、21.86；惠州 6 家、137 件、22.83。

D5 经费 = 有国基金项目机构的资助额之和 / 有项目机构数。深圳 20 家、212 项、10,748.6 万元，均值 **537.43 万元/家**；广州 32 家、367 项、17,105.6 万元、534.55；东莞 1 家、2 项、54.0 万元；惠州 0 家（无值，不参与 D5 的 min-max，综合指数按可用权重归一）。

D6 人才 = 有学者机构的高被引学者数 / 有学者机构数。深圳 12 家、66 位、均值 **5.5 位/家**；广州 16 家、78 位、4.88；东莞 1 家、3 位、3.0；惠州 0 家（无值）。

这三个维度的共同问题是**分母极小**：87、20、12 家，分别占 1,014 家的 8.58%、1.97%、1.18%。它们描述的是「头部机构的表现」，不是「全市机构的平均表现」。深圳 39.37 件/家高于广州 23.98，只能读作「深圳有专利的 87 家机构平均产出更高」，不能读作「深圳 1,014 家机构平均产出更高」——后者的分母里还有 927 家专利为 0 的机构。

### 2.6 步骤 5｜D7 证据覆盖与综合指数

D7 = 至少有一类证据（专利/项目/论文/学者）的机构数 / 城市机构数。深圳 120/1,014 = **11.83%**；广州 173/822 = 21.05%；东莞 21/127 = 16.54%；惠州 11/111 = 9.91%。深圳排第 3，只高于惠州。

综合指数按权重加权：$0.15\times100 + 0.10\times74.4 + 0.15\times71.6 + 0.20\times100 + 0.15\times100 + 0.15\times100 + 0.10\times56.2 = 88.80$。七个维度全部有值，`weights_available` = 1.0，`missing_dims` 为空。

88.8 这个分数的结构值得拆开看：D1/D4/D5/D6 四个 100 分贡献了 65 分（权重合计 0.65），D2/D3/D7 三个非满分贡献了 23.8 分。也就是说，深圳的高分主要来自「规模大 + 头部机构强」，而不是「结构优 + 成长快 + 覆盖广」。这个结构本身就是结论。

### 4.2 后果归因：哪些话不能说

- **不能说「深圳科研机构平均专利产出 39.37 件」**：分母是 87 家有专利机构，不是 1,014 家。
- **不能说「深圳科研经费高于广州」**：按全部机构算，广州 20.81 万元/家高于深圳 10.60 万元/家。
- **不能说「深圳机构结构最差」**：结构均衡度低只说明类型集中，不代表质量差。
- **不能说「深圳 88.17% 的机构没有研发活动」**：894 家零证据里含匹配失败，不能等同于无研发。
- **不能说「该产业内深圳有多少家机构」**：产业切片不可得。
- **不能说「深圳科研机构现状全国第几」**：无省外样本。

### 4.3 判档说明

不属于「完全直接支持」（无结果表）、不属于「完全转换支持」（D4/D5/D6 覆盖不足且产业切片缺失）、不属于「完全不支持」（D1/D2/D3 完整可算），落**部分支持**。

曾考虑把 D7 证据覆盖作为「数据质量说明」而非记分维度，这样七维变六维、综合分升到 92.5。但旧稿把覆盖率作为一维，且它确实反映了「城市级证据完备度」这一产品关心的属性，故保留并给 0.10 权重，同时在正文说明其语义。

### 4.4 补齐关键字段后的规模预估

补齐统一社会信用代码（专利/项目匹配）后，D4/D5 覆盖率可从 8.58%/1.97% 提到 60% 以上，产出与经费维可从「子集结论」升级为「城市结论」。补齐产业标签后，D8 可开。两项合计约 5 人日。

## 附录 D　构建方法可行性报告（完整版）

**D.1 为什么用城市均值而不是总量**：总量会让规模维吞掉其他维（深圳 1,014 家必然第一），均值才能看出「每家机构的强度」。但均值对小分母敏感，故 D4/D5/D6 同时给出分母与覆盖。

**D.2 为什么 0 点取 0 而不是四城最差**：取最差会让「最差城市」得 0 分、最好得 100 分，中间城市的分数依赖第三者；取 0 点则分数有绝对含义（占最优城市的比例），跨维可比。

**D.3 为什么保留 D7 证据覆盖**：它是唯一能揭示「前三维高分是否可信」的元指标。若去掉，综合分升到 92.5，但会把「894 家零证据」这个事实藏起来。

**D.4 与权威方法的差距**：区域创新评价用全国分位与多年面板，本件用四城相对与单年截面；前者可做趋势与全国排名，后者只能做静态对比。这是「部分支持」的方法论根源。

**D.5 与旧稿的差异**：旧稿用 `demo` 库的机构表与产业标签，能出产业切片；本件换 gkx 后产业标签失效，切片维度整体缺失。旧稿的七维权重被沿用，但产出/经费/人才三维的分母从「全部机构」改为「有证据机构」，因此旧稿的分数不可与本件直接比较。
