## 〇、数据支持度与四判定口径

四档口径沿用 20261021/20261022 派单书，判档只看「当前库内数据能不能把口径算出来」：

| 档位 | 定义 | 本指标是否满足 |
|---|---|---|
| 完全直接支持 | **开发库+三方库（gkx）**中直接就有该指标（或 100% 语义一致指标/结果面）可用，且数据量完全支持直查/直算 | 否：三维全要现算，无结果表 |
| 完全转换支持 | 两库均无现成结果面，但依赖侧的表结构与当前数据量均已足够，现在即可通过转换与加工生成该指标；数据量不足不得入本档 | 否：效果维整维不可算、类型维只能代理 |
| **部分支持** | 无论如何构建，始终有部分依赖维度无法从**开发库+三方库（gkx）**得到足够数据 | **是**：数量维与类型维出数，效果维整维剔除 |
| 完全不支持 | 该指标及其关键依赖维度，在**开发库与三方库（gkx）**均无法构建（结构与数据均不具备可算闭环） | 否：数量维四市均有真实读数（含 0） |

> **数据源口径**：本件支持度按「开发库 + 三方库（gkx，183.240.141.251:3318 只读）」评估，仅排除 `demo_*`；本机开发库事实面为空壳（`gkxlumenx_dwd/ods/ads` 逐表实测非空 0 张），实际取数面为 gkx。

判「部分支持」的四条实测依据：

1. **效果维整维不可算**。`implementation_date` 与 `expire_date` 全表 20,000 行**都是 `'0000-00-00'`
   零日期**（用范围谓词 `< '1900-01-01'` 实测：impl_zero=20,000、exp_zero=20,000）。
   它们不是 NULL、也不是空串——`IS NOT NULL` 会返回 20,000（看起来「100% 有值」），
   `TRIM()<>''` 也返回 20,000。这是本批最典型的「看着有值、实际全是占位符」陷阱。
   以 2026-10-22 为基准日代入在效窗口，四市 1,212 条政策的在效数全部为 0。
2. **政策可见度的两个子项都是常数**。`link` 20,000 行全部非空（四市 1,212 行全部非空），
   `status` 20,000 行全部为「有效」。四市的可见度都是 100%，极值归一后整列无定义——
   常数不是「高」，是「测不出差异」。
3. **王惠的四类政策主题在库内没有字段**。`theme` 19,998 / 20,000 行为 0，`keypoints` 是 `'NULL'`
   占位。「科研扶持 / 成果转化 / 产业促进 / 人才引进」这四类无法复原，类型维只能改用
   **文件体裁**（通知、办法、意见、规划…）覆盖度代理，且必须声明它不是王惠的四类。
4. **评价集内有采集边缘**。四市合计只有 1,212 条（占全表 6.06%），其中东莞 8 条、惠州 0 条。
   惠州 0 是「库内没有记录」，不是「惠州没有出台政策」；东莞 8 条同样处在采集边缘，
   两市的分差没有比较意义。

## 摘要

本指标把「区域产业创新政策」拆成数量、类型、效果三维，维内子项批内极值归一、三维等权，
得到 0—100 的综合指数。在 gkx 上重算的结果是：深圳 92.3、广州 57.0、东莞 15.8、惠州 0.0。
效果维因时间戳两列全为 `'0000-00-00'` 零日期、可见度与状态两列全为常数，整维退出指数，
实际参与合成的是数量维与类型维。

深圳领先的全部来源是政策存量：879 条对广州 325 条，归一后 100.00 对 36.97；类型维深圳 11 类、
广州 10 类，按 13 类词表的覆盖率是 84.62% 对 76.92%，差距不大。东莞 8 条、惠州 0 条，
两市的分差（15.8 对 0.0）来自「东莞有 4 类体裁、惠州一条政策都没有」，不是政策质量的差别。

发布口径要写清两件事：其一，这张政策表是**全国表**，20,000 行里只有 1,212 行（6.06%）落在四市，
北京 2,268、上海 1,841、`city='NULL'` 的国家级分支 9,706；其二，`theme` 列 19,998 行为 0，
王惠的四类政策主题无法复原，本版类型维是「文件体裁覆盖度」代理，不能对外称「政策类型齐全度」。

### 1.2 口径定义（王惠原文要点）

王惠表对该指标的定义是：从**创新政策数量**、**政策类型**、**政策效果**三个侧面评价一个区域的
产业创新政策供给，各侧面极值归一后等权汇总为 0—100。

三处需要在文档里讲明：

1. **政策数量是存量，不是当年新增**。按年截断会把覆盖率打成 0（DATA_FACTS §3.7 实测：
   按 2021—2024 截断，广州政策池从 325 条砍到 39 条、深圳从 879 条砍到 313 条），
   所以数量维取全表存量，不做同比、不做增速。
2. **政策类型在王惠那里是四类主题**（科研扶持、成果转化、产业促进、人才引进）。
   库内 `theme` 列 19,998/20,000 行为 0，四类无法复原，本版改用文件体裁覆盖度代理，
   并在所有对外表述里写明「体裁」二字。
3. **政策效果 = 实施时效性 + 政策可见度**。前者需要 `implementation_date` / `expire_date`，
   后者需要 `link`。本批两列时间戳全是零日期、`link` 全是非空常量，故整维不可算。

### 1.3 计算公式与本批实现式

批内极值归一（数量维用）：

$$\tilde{x}_{c}=\frac{x_{c}-\min_{c'}x_{c'}}{\max_{c'}x_{c'}-\min_{c'}x_{c'}}\times 100$$

类型维用固定词表分母（不做二次归一，避免「覆盖度」被拉成 0/100）：

$$\tilde{t}_{c}=\min\left(\frac{|\text{体裁}_{c}|}{13},\,1\right)\times 100$$

三维等权，可算维数不足 2 时不出指数：

$$I_c=\frac{1}{|D_c|}\sum_{d\in D_c}S_{c,d},\qquad |D_c|\ge 2$$

本批三维的子项构成与实际状态：

| 维度 | 子项 | 状态 | 说明 |
|---|---|---|---|
| D1 创新政策数量 | 市级有效政策存量 | 可算 | 深 879 / 广 325 / 莞 8 / 惠 0 |
| D2 政策类型 | 文件体裁覆盖度 | 可算（代理） | 13 类词表，深 11 / 广 10 / 莞 4 / 惠 0 |
| D3 政策效果 | 实施时效性 | 不可算 | 两列时间戳 20,000/20,000 为零日期 |
| D3 政策效果 | 政策可见度 | 不可算 | `link` 四市 100% 非空，常数无区分度 |
| D3 政策效果 | 政策主题类型 | 不可算 | `theme` 19,998/20,000 为 0 |

类型维为什么不用批内 min-max？四市的体裁数是 11 / 10 / 4 / 0，若用 min-max，
广州会被压到 90.91、深圳 100、东莞 36.36、惠州 0，看起来和覆盖率差别不大，
但换一批城市（比如加进北京）分母就变了，读数不能跨批比较。覆盖率用固定分母 13，
含义是「该城用到过全国 13 类体裁里的几类」，可跨批比较，代价是天花板被压在 84.62%。

### 1.4 评价集与统计年

评价集为深圳、广州、东莞、惠州，与 184 / 187 / 188 保持一致，理由同 184：
企业底册 189,116 行里四市占 99.82%，京沪撑不起城市级分子。

但政策表的情况与企业底册**不同**：`dwd_policy_base` 是全国表，20,000 行里
`city='NULL'`（国家级）9,706 行、北京 2,268、上海 1,841、深圳 879、天津 666、杭州 446、
南京 334、广州 325……四市合计 1,212 行（6.06%）。也就是说，在这张表上做城市级比较，
分母天然是「被采集到的政策」，不是「实际出台的政策」。这一点决定了本指标只能做四市内部
相对比较，不能做全国排名，也不能拿深圳 879 条去论证「深圳政策数量全国第几」。

统计年取存量：四市公告的 `publish_date` 全部落在 1992—2022（深圳最早 2000、广州最早 1992、
东莞仅 2020—2022 共 8 条、惠州 0 条）。2023/2025/2026 全表零行，2024 只有 1 条北京记录
（标题「平谷区便民咨询服务电话」，明显是脏数据），四市一条都没有。

## 二、计算过程

### 2.1 数据装载与快照清单

本脚本不连数据库，读 `code/_snapshots21/` 下三份快照，装载层为 `code/_synth18x_common.py`：

| 快照 | 内容 | 规模 | 用途 |
|---|---|---|---|
| `policy_base_20261021.json` | 政策全表：id / title / date / province / city / district / ministry / body_len / theme / level | 20,000 行 | D1 存量、D2 体裁、D3 自检 |
| `pg_policy_rows_20261021.json` | 政策全表行级投影：id / title / type / rank / publish_year / city / ministry / 文本长度 | 20,000 行 | 全表城市/层级/体裁分布（§三） |
| `probe_synth18x_20261022.json` | 本批探针：`policy_zero_dates`（零日期自检）、`policy_type_status`（体裁词表）、`policy_inforce`（基准日在效数） | 见附录 B | D3 不可算的证据 |

装载顺序：先读政策全表建「城市 → 行」索引，再读探针里的零日期自检与词表。这样 D1、D2 的分子
和 D3 的否决证据来自同一批行，不会出现「分子按 A 口径、证据按 B 口径」的错位。
全部装载实测 0.03 秒。

### 2.2 归城与重名处理

政策表不需要名称归城：`city` 列已经是市级全称（`深圳市`/`广州市`/`东莞市`/`惠州市`），
直接等值匹配；`city='NULL'` 的 9,706 行是国家级政策，单独掷出，不摊到任何城市。
这里刻意不写 `LIKE '%深圳%'`——DATA_FACTS §3.8 明确记录过，模糊匹配会误命中区县名
（如「深圳市南山区」这类 district 值）。

「重名摊权」在本指标不适用：政策没有跨城主体，一条政策只属于一个 `city`。
这一点与 184/187 不同，读表时不要以为漏了 1/k 处理。

### 2.3 维内归一与权重

数量维只有一个子项，归一后即维度分；类型维用固定词表分母（见 §1.3）；效果维不进计算。
三维等权的「等权」在本批实际只落到两维上，各占 50%。

两个工程判断需要写清：

1. **数量维的 0 端是惠州**。惠州 0 条、东莞 8 条，批内 min-max 的分母是 879，
   所以东莞只有 0.91 分。这个 0.91 不是「东莞政策极少」的精确刻画，而是「8/879」的线性映射。
2. **类型维不复用数量维的归一**。如果两维都用 min-max，类型维的实际区分度只有 11/10/4/0，
   排序与数量维高度共线，等权就变成「同一件事数两遍」。用固定分母 13 后，两维的相关性下降，
   但代价是深圳也只能拿到 84.62，天花板不在 100。

### 2.4 指数合成与缺维处理

三维里 D3 整维记 `null`，四城都是「2 维可算」，达到 `MIN_DIMS=2` 的下限。
这里有一个必须交代的选择：**不给 D3 补中值**。旧稿给四城一律 50.0，效果是每城总分
被加 16.7 分（50/3），排序不变但所有读数虚高。补中值的本质是「用假设值参与排名」，
违反派单书「禁止 `.get(y, 0)` 式补零」的同一条原则——补零与补中值只是填的数不同。

缺维守卫保留：若某城只剩一维（比如政策存量与体裁同时为 0），脚本返回 `null` 而不是
把单维分冒充综合指数。本批惠州两维都有读数（0 与 0），所以它拿到的是 0.0 而不是 `null`——
这个区别很重要：`null` 是「算不出」，0.0 是「算出来是四市最低」。

### 2.5 参数与阈值

| 参数 | 取值 | 依据 |
|---|---|---|
| 体裁词表 | 13 类 | 全表 `type` 去重，探针 `policy_type_status` 实测 |
| 有效政策口径 | `status='有效'` | 全表 20,000 行全部为该值（无过滤收益，但保留口径） |
| 出指数最少维数 | 2 | 单维不构成综合指数 |
| 归一（数量） | 批内 min-max | 四城含 0 记录城市 |
| 归一（类型） | 固定分母 13 | 可跨批比较 |
| 在效基准日 | 2026-10-22 | 计算日 |

`status='有效'` 这一条要说明：全表 20,000 行全是「有效」，所以这个过滤条件在本批不筛掉任何行。
保留它是因为口径需要写明「有效政策存量」，而不是「全部政策」；将来若 status 出现其他取值，
分母会自动跟着变。

### 2.6 计算边界与不做事項

本批明确不做五件事：

1. **不做年度趋势**。存量表按年截断会把广州砍到 39 条（§3.7），任何「2024 年新增政策 N 条」
   都需要另一张按年采集的表。
2. **不做政策强度/力度评分**。库内没有资金规模、补贴比例、覆盖企业数，只有正文长度
   （`body_len`），用长度当力度是伪指标。
3. **不做政策主题分类**。`theme` 19,998/20,000 为 0，四类主题无法复原。
4. **不做效果评估**。时间戳全零日期，无法判断政策何时生效、是否过期。
5. **不与京沪比较**。京沪在表内有 2,268 / 1,841 条，但它们不在本批评价集，
   且采集口径未必与四市一致（四市仅 1,212 条，占 6.06%）。

## 三、数据支撑情况

### 三.1 数量维（D1）

| 项 | 深圳 | 广州 | 东莞 | 惠州 | 合计/说明 |
|---|---:|---:|---:|---:|---|
| 市级有效政策存量 | 879 | 325 | 8 | 0 | 1,212（四市） |
| 归一得分 | 100.00 | 36.97 | 0.91 | 0.00 | 批内极值 |
| 占四市比 | 72.5% | 26.8% | 0.7% | 0% | — |

支撑结论：维度可算，四市都有读数。但「存量」是采集存量：全表 20,000 行里四市只占 1,212 行
（6.06%），北京 2,268、上海 1,841、国家级 9,706。这个结构说明该表以国家级与京沪政策为主，
四市的采集完整度参差——深圳 879 条、广州 325 条尚可，东莞 8 条、惠州 0 条已到采集边缘。

### 三.2 类型维（D2）

| 项 | 深圳 | 广州 | 东莞 | 惠州 | 合计/说明 |
|---|---:|---:|---:|---:|---|

| 归一得分 | 84.62 | 76.92 | 30.77 | 0.00 | 不二次归一 |

支撑结论：维度可算但**是代理**。13 类体裁来自全表 `type` 去重：其他通知、政策文件-管理办法/实施方案、
公示公告、申报通知、政策文件-指导意见、政策文件-规划纲要、政策文件-其他文件、
规范性文件-规范条例、政策文件-政策指南、规范性文件-部门规章、政策解读、
规范性文件-法律法规、政策文件-评定标准。这 13 类衡量的是「政策工具箱的文书形态有多全」，

这 1 类差距不足以支撑「深圳政策类型更全」的结论。

## 四、数据缺失情况

### 四.1 缺口清单与修复路径

| 缺口 | 影响维度 | 实测后果 | 修复路径 |
|---|---|---|---|
| `implementation_date` 全表零日期 | D3 时效 | 无法算在效/过期/新出台 | 需重新抽取政策原文的成文日期与生效日期 |
| `expire_date` 全表零日期 | D3 时效 | 同上 | 同上 |
| `status` 全为「有效」 | D3 时效 | 无法区分废止 | 需政策清理/废止公告 |
| `link` 全非空 | D3 可见度 | 常数无语义 | 需官网可访问性探测（HTTP 200 率） |
| `theme` 19,998 行为 0 | D2 主题 | 四类主题不可复原 | 需主题标注（关键词或人工） |
| 四市仅 1,212 条（6.06%） | D1 数量 | 城市级存量不可比 | 需按城市重采集，或补地市级政策库 |
| 东莞 8 条、惠州 0 条 | D1/D2 | 两市落在采集边缘 | 同上 |
| `keypoints` 为 `'NULL'` | D2 主题 | 无法做关键词归类 | 需正文结构化抽取 |

### 四.2 结构性缺口（扩量救不了）

1. **时效性不是「缺几行」，是「整列都是占位符」**。`'0000-00-00'` 是 MySQL 的零日期，
   在宽松模式下写入、能被 `IS NOT NULL` 判为有值。扩量只会让 20,000 变成 30,000，
   零日期的比例不变。要救这一维，必须在抽取环节补时间解析，不能靠多采集。
2. **`status` 的单一取值说明这张表不是政策生命周期表**。它更像「政策文本库」，
   只收录当前有效的文本，废止与修订不进表。要算「失效政策占比」，需要另一套生命周期数据。

### 四.3 本批不采用的数据面

| 数据面 | 为什么不用 |
|---|---|
| `theme` | 19,998/20,000 为 0，不能当主题分类 |
| `keypoints` | `'NULL'` 占位，不能做关键词 |
| `body_len` | 只能当文本长度，不构成政策力度 |
| `quote` | 19,998/20,000 为 0，近似常数，无区分度 |
| `level` / `rank` | 同一套行政层级，两种写法：`rank` 是多值标签数组（省级 9,922、市级 8,622、国家级 2,174、区级 1,254、空 357、园区级 144，合计 22,473 > 20,000 行，一行可挂多级），`level` 是单值数字编码（3→9,922、2→6,149、4→2,174、1→1,398、0→357，合计 20,000）。两者都不是政策效力等级，不能拿来做力度加权 |

### 四.4 缺口对判档的影响

按四档定义逐条对照：D1 有数（四市均可算）、D2 有数但是代理、D3 整维不可算。
「完全转换支持」要求结构与数据量都够，D3 的 0% 可用率直接否掉这一档；
同时 D1/D2 不是空的，也不构成「完全不支持」。判「部分支持」，
且这个档位由 D3 决定——三维里缺一整维，不是「平均下来还行」。

### 五.4 敏感性与稳健性

做了三项检查（改口径重算）：

1. **只用数量维**：深圳 100.00、广州 36.97、东莞 0.91、惠州 0.00。排序不变，
   间距从 35.3 拉到 63.0，说明类型维确实在「拉平」差距。
2. **只用类型维**：深圳 84.62、广州 76.92、东莞 30.77、惠州 0.00。排序不变，
   但深圳与广州只差 7.7 分——如果只看类型，两城几乎并列。
3. **类型维改用批内 min-max**：深圳 100.00、广州 90.91、东莞 36.36、惠州 0.00；
   综合深圳 100.0、广州 63.9、东莞 18.6、惠州 0.0。排序不变，深圳顶到 100。
   本批不用这个写法，因为分母随批变化，读数不能跨批比较。

三项的共同结论：**排序稳健（深圳 > 广州 > 东莞 > 惠州），读数不稳健（92.3 会随归一方式在
92.3—100 之间变动）**。发布时应给出排序与口径，不要给两位小数的绝对分。

### 五.5 反常识点与解释

**反常识一：深圳政策数是广州的 2.7 倍，但两城的体裁覆盖率只差 1 类。**
这说明「数量」和「类型丰富度」不是同一件事：深圳是同一个工具箱用得更多，广州是工具箱也基本齐。
用数量代表「政策供给强度」会放大采集差异，用类型代表「政策工具箱完整度」会压缩差异，
两者都只能各说一半。

**反常识二：全表 20,000 条政策，四市只占 6.06%。**
这张表的主体是国家级（9,706 条）与京沪（4,109 条）。任何拿这张表做「城市政策数量排名」的做法，
排出来的都是「采集完整度排名」，不是「政策供给排名」。

**反常识三：`implementation_date` 看起来 100% 有值，实际可用率 0%。**
`IS NOT NULL` 返回 20,000，`TRIM()<>''` 也返回 20,000，唯一能识别它的是范围谓词
（`< '1900-01-01'`）。这个陷阱在旧稿里被写成「全空（0/20,000）」，方向对了但定性错了：
它不是没有值，是有一个永远不等于任何真实日期的值。

## 六、结论与发布建议

### 六.1 可用结论

1. 在 gkx 库内采集到的政策范围内，四市政策供给指数为深圳 92.3、广州 57.0、东莞 15.8、惠州 0.0，
   由存量（879 / 325 / 8 / 0 条）与体裁覆盖度（11 / 10 / 4 / 0 类）两维等权合成。
2. 深圳的存量是四市总量的 72.5%，广州 26.8%，两市合计 99.3%；东莞 8 条、惠州 0 条。
3. 体裁覆盖度深圳 84.62%、广州 76.92%，差距只有 1 类（7.69pp），不足以支撑「深圳政策类型更全」。
4. 全表 20,000 条政策的两列时间戳都是零日期，这是可复核的实测事实（范围谓词自检）。

### 六.2 不可用结论

1. **不能做全国城市政策排名**。四市仅占全表 6.06%，京沪与国家级分支未纳入，排序没有全国意义。
2. **不能引用「政策效果」的任何数字**。效果维整维退出，没有时效、没有可见度、没有失效比例。
3. **不能说「政策类型齐全」**。本版类型维是文件体裁覆盖度，不是王惠的四类主题；
   对外必须带「体裁」二字。
4. **不能把惠州 0.0 读成「惠州没有政策」**。它是库内零记录。
5. **不能与旧稿读数相减**。旧稿四城效果维各补 50 分，本版整维剔除，59.5 → 92.3 不是「上升」。

### 六.3 发布口径建议

对外建议用这样一句话：「在 gkx 采集范围内，按政策存量与文件体裁覆盖度两维等权评价，
四市政策供给指数为深圳 92.3、广州 57.0、东莞 15.8、惠州 0.0；评价集内共 1,212 条市级政策

## 七、王惠方法对照与选用建议

王惠口径给的是「数量 + 类型 + 效果」三维框架，没有指定字段。本批在框架内做了四处落地选择：

| 口径要素 | 王惠原文 | 本批实现 | 偏差与理由 |
|---|---|---|---|
| 数量维 | 有效政策数 | 库内市级有效政策存量 | 一致；但只能读作「采集到的」 |
| 类型维 | 四类主题（扶持/转化/产业/人才） | 13 类文件体裁覆盖度 | 主题字段 19,998 行为 0，只能代理；已声明不是四类 |
| 效果维 | 时效性 + 可见度 | 整维剔除 | 时间戳全零日期、可见度是常数，无可用读数 |
| 归一 | 极值归一 | 数量 min-max、类型固定分母 13 | 类型维改固定分母是为了跨批可比 |
| 权重 | 维内加权、维间汇总 | 维内等权、维间等权 | 一致（实际只有两维参与） |

选用建议：**采纳框架，但对外必须写明「两维、体裁代理、效果缺维」**。如果甲方坚持要效果维，
本指标应降为「完全不支持」，直到时间戳可用；如果接受现状，则维持「部分支持」，
并且不得在任何对外材料里出现「政策效果」「政策力度」这类词。
