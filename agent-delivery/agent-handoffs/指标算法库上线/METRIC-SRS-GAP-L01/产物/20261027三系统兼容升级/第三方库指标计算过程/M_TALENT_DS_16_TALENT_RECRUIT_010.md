## 摘要

本文对 20,420 名有姓名学者算「引进阻力」：学术势能 K（h 与引用各半，权重 0.35）、地理距离（深圳 0 / 广东省内 50 / 省外 100 / 未归属 100，有深圳履历或学历的省外 70，权重 0.25）、流动惯性（工作段数越少分越高，权重 0.20）、头衔（院士 100，权重 0.20）。缺失维按剩余权重归一。

结果：均值 52.6639、中位 53.8189、p10 42.6183、p90 60.3997、p99 67.4795、最大 90.6818、最小 0。A/B/C/D 为 2,043 / 4,083 / 6,126 / 8,168，正好是 10% / 20% / 30% / 40%——因为阈值就是全域分位，分档只表示相对位置。

前 29 名（同名去重后）**全部是院士**：田中群 90.6818（厦门大学）、戴民汉 82.0202（厦门大学）、郑树森 80.6692（浙大一院）、陈军 80.0（南开）、王广基 79.0803（中国药科大学）……这不是算法偏好，是权重结构决定的：院士头衔直接拿 100 分，叠上「省外」100 分，已经占 0.45 权重，学术力再高就进前列。

三个必须写进 UI 的事实：第一，地理维 96.09% 的人取 100（省外 16,682 + 未归属 2,573 + 广东省内非深 951），这一维几乎没有区分度；第二，履历只覆盖 1,766 人（8.65%），无履历者不补 0，按剩余权重归一；第三，院士在面板里 80 人、全库 112 人，32 人因姓名/机构未匹配而缺席。评分可用作「可测阻力的相对排序」，不可用作「引进成功率预测」。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

挂在「国际人才引进 → 引进阻力」。前端设想：给每位候选人才一个阻力分与分项（薪酬期望、家庭、语言、签证、学术势能），供引才团队判断「值不值得追、要配什么资源」。后端需要：候选池、薪酬期望、家庭情况、语言能力、签证状态、学术产出。

### 1.2 为什么需要「引进阻力量化评分」

引才资源有限，不可能人人都追。阻力分的作用是排序：先追阻力低、价值高的，后追阻力高、需要长期投入的。政策侧也想知道「哪类阻力最普遍」，以便设计针对性支持。

但「阻力」是个复合概念：有的来自候选人（薪酬期望、家庭），有的来自制度（签证、认证），有的来自机构（编制、启动经费）。本文只能测「学术势能 + 地理 + 惯性 + 头衔」，其中头衔其实不是阻力，是「价值/稀缺度」。这个语义混用必须在文档里讲清楚。

### 1.3 需求文档是否给出定义方法

没有。需求只给「量化评分」四字，未给维度、权重、阈值、方向。算法库无实现。按铁律第 6 条，本文不把「招聘岗位多」当「阻力大」——岗位是需求，不是阻力。

### 1.4 类似指标权威机构构建方法可行性分析概要

人才引进阻力在学术上有两类测法：一是「迁移成本」模型（Mincer 工资差异、迁移距离、家庭约束），二是「制度壁垒」指标（签证办理时长、认证周期、税负）。政策机构多用「引才竞争力指数」，把薪酬、平台、政策、生活成本加权。

`gkx` 只有「学术产出」与「机构/城市」，没有薪酬、家庭、签证、生活成本。因此本文的评分是「学术侧阻力 + 地理摩擦 + 流动惯性 + 头衔稀缺度」的混合，不是标准意义上的「迁移成本」。

### 1.5 引用来源（可核验）

1. Mincer, J. The Economics of Wage Differentials. https://doi.org/10.2307/1914232
2. OECD. International Migration Outlook 2025. https://www.oecd.org/migration/
3. 国家移民管理局. 外国人签证证件签发工作规范. https://www.nia.gov.cn/
4. 深圳市人力资源和社会保障局. 人才引进政策. http://hrss.sz.gov.cn/
5. 科技部. 外国人来华工作分类标准（试行）. https://www.most.gov.cn/
6. 中共中央办公厅. 关于深化人才发展体制机制改革的意见. http://www.gov.cn/xinwen/2016-03/21/content_5056113.htm

### 1.6 推测原意与推测定义

推测原意：给引才团队一个「谁难追、难在哪」的排序工具。推测定义应含五层：

- **A 学术势能**：产出与影响力，越高越难请（机会成本高）。
- **G 地理摩擦**：距离越远，搬迁与适应成本越高。
- **I 流动惯性**：越少迁移，越不愿动。
- **T 头衔/稀缺度**：院士、杰青等，越稀缺越难请。
- **M 市场因素**：薪酬期望、家庭、签证、语言。

现有数据：A/G/I/T 可算，M 全缺。因此本文的公式只覆盖 A/G/I/T，并在 §3、§4 明写 M 的缺口。

## 二、计算过程

### 2.1 公式出处与降级的必要性

公式无出处。降级两处：一是「市场阻力」整层缺失，无法测薪酬/家庭/签证；二是「头衔」用院士二值代替全部头衔体系（杰青、长江、千人等无字段）。两处降级都在 §4.1 写了修复路径。

方向问题：头衔分越高，代表「越值钱」，通常也「越难请」，所以放进阻力分方向是对的；但它同时会让「院士」独占榜首，把「阻力」变成「身价」。这是本件最大的语义风险，§5 会讲怎么用。

### 2.2 口径拆解：对象、四维、归一

对象 20,420 名有姓名学者。四维覆盖：

| 维度 | 定义 | 样本 | 中位 | p90 | 最大 | 权重 |
|---|---|---:|---:|---:|---:|---:|
| A 学术势能 | K（h 与引用 log-minmax 各半） | 20,420 | 52.8963 | 66.2445 | 100 | 0.35 |
| G 地理 | 深圳 0 / 省内 50 / 省外 100 / 未归属 100 | 20,420 | 100 | 100 | 100 | 0.25 |
| I 惯性 | `100×(1−min((段数−1)/4,1))` | 1,766 | 50 | 100 | 100 | 0.20 |
| T 头衔 | 院士 100 / 其他 0 | 20,420 | 0 | 0 | 100 | 0.20 |

总分 `S = Σ(w·x) / Σw`，缺失维不参与分母。

### 2.3 依赖分解（两跳停）

第一跳：`dwd_scholar` → 姓名/机构/城市/省/论文/引用。第二跳：`work_experience` → 工作段数；`dwd_scholar_talent_flag` → 院士。第三跳（不存在）：薪酬/家庭/签证/语言。链断在第三跳。

### 2.4 算路 / SQL

本件零 SQL，读 `code/_snapshots21/talent22_panel_20261022.json` 与 `code/_snapshots21/talent_flag_20261022.json`。算路：

1. 遍历 20,420 名学者，算 K（`C.academic_k`）。
2. 地理：`city=深圳市` 或机构名含深圳 → 0；`prov=广东省` 非深 → 50；省外 → 100；`未归属` → 100；有 `work_sz`/`edu_sz` 的省外 → 70。
3. 惯性：`work_filled>0` 时 `100×(1−min((work_n−1)/4,1))`，否则 None。
4. 头衔：`acad=1` → 100，否则 0。
5. 按 0.35/0.25/0.20/0.20 加权，缺失归一。
6. 全域 p90/p70/p40 切档。

### 2.5 清洗规则

- 地理的「未归属」按 100 计（最远），不补 0：未知不等于在深圳。
- 有深圳履历/学历的省外学者给 70，而不是 100：与深圳有连接，阻力略低。
- 无履历者 I=None，不按「从没动过」补 0：没记录 ≠ 没动过。
- 院士按 `dwd_scholar_talent_flag.academician=1`，只覆盖 80 人；全库 112 人，32 人未匹配。
- 同名多 scholar_id 在 top 列表中去重，只留最高分（刘忠范两行）。
- 学术力 K 与 162 同口径，不另造。

### 2.6 结果解读

分布：均值 52.6639、中位 53.8189、p10 42.6183、p90 60.3997、p99 67.4795、最大 90.6818、最小 0。A/B/C/D 为 2,043 / 4,083 / 6,126 / 8,168，对应 10% / 20% / 30% / 40%。

前 29 名全部是院士：田中群 90.6818（A 87.6622、G 100、T 100、I 75，4 维）、戴民汉 82.0202、郑树森 80.6692、陈军 80.0（A 100）、王广基 79.0803。第 29 名康振生 73.7518。院士之外最高分进不了前 29，因为头衔维直接差 20 分（0.20×100），学术力再高也补不回来。

分档是「相对位置」：A 档 2,043 人不是「都难引进」，是「在全域排前 10%」。真正可操作的解读是「在同一类人才内部比较」，而不是跨类比较。

#### 2.7.3 结果解读与评审

评审要接受三个限制：地理维几乎常数、履历覆盖 8.65%、头衔只有院士。三项叠加，导致分数主要由「学术力 + 是否院士」决定。这不是 bug，是数据可用维度的真实结构；但 UI 不能把它包装成「综合阻力」。

### 4.2 对结论的影响边界

S 只覆盖「学术侧可测阻力」。S 高不代表「引不进来」，只代表「学术价值高 + 距离远 + 头衔稀缺」。S 低不代表「容易引进」，可能只是「学术产出低」。分档是全域相对位置，不表示绝对难度。深圳样本 237 人，切片后稳定性差。

### 4.3 不可外推的三件事

第一，不可把 S 当「引进成功率」的反向预测：没有成功/失败标签。第二，不可把院士榜首当「最该放弃」：他们是「最难请」但可能「最值得请」。第三，不可把地理维当「距离效应」：96.09% 都是 100，没有区分度。

补充三条。第四，不可把「无履历」当「没动过」：覆盖只有 8.65%。第五，不可把「未归属城市」当「深圳」：本件按最远计。第六，不可用本件比较机构引才难度：机构样本与学科结构未控制。

## 五、王惠方法对照与选用建议

### 5.1 王惠原方法还原

王惠系方法在本指标无实现。可追溯做法是「一人一策」：引才团队按候选人的薪酬期望、家庭、签证、平台匹配度逐项评估，形成「可谈/可争取/暂缓」三档。样本小，但真实。

### 5.2 新方法概述

本文用公开数据做学术侧阻力排序：K + 地理 + 惯性 + 头衔，全域分位切档。优点是全覆盖、可复现；缺点是没有市场阻力、头衔过粗、地理几乎常数。

### 5.3 逐维对照表

| 维度 | 王惠方法 | 本文方法 | 差异与风险 |
|---|---|---|---|
| 学术 | 同行评议 | K | 本文只看量 |
| 薪酬 | 逐人谈 | 无 | 无法替代 |
| 家庭 | 面谈 | 无 | 无法替代 |
| 签证 | 个案 | 无 | 无法替代 |
| 头衔 | 全套 | 仅院士 | 过粗 |
| 地理 | 通勤/搬迁 | 城市二分 | 过粗 |

### 5.4 选用建议与理由

建议把本件定位为**学术侧阻力排序**，不是**引才决策**：榜单一律显示分项与 `dims`，A 档标「学术价值高/距离远/头衔稀缺」，不写「不建议引进」。院士榜单独列，避免与普通学者混排。

若业务要真阻力，需接三样：薪酬期望问卷、家庭随迁登记、签证/认证进度。接入前，本件只能用于「候选池初筛」，不能用于「预算与谈判」。

### C.4 数据可行性详细分析

#### C.4.1 覆盖漏斗

20,420 → 20,420（A/G/T）→ 1,766（I）→ 80（院士）。I 与 T 的覆盖是瓶颈。

#### C.4.2 地理常数问题

96.09% 取 100，导致 G 维实际只区分「深圳 237 人」与「其他人」。0.25 权重里有 0.24 是常数，等于给所有人加 25 分。这不会改变排序（常数不影响秩），但会让分数看起来「都很高」。

#### C.4.3 头衔的二值问题

只有院士/非院士，杰青、长江、优青、职称全无。结果是「院士 80 人独占前 29」，普通学者之间只比 K。若业务要更细的头衔分层，必须补字段。

#### C.4.4 方向的一致性

A 高→难请；G 远→难请；I 高（少动）→难请；T 高→难请。四维方向一致，都是「分高=难」，这是本件可用的前提。

#### C.4.5 方法—数据对照矩阵

| 维度 | 理想数据 | 现有数据 | 可用度 | 结论 |
|---|---|---|---|---|
| 薪酬 | 薪资/问卷 | 0 | 无 | 不可构建 |
| 家庭 | 随迁登记 | 0 | 无 | 不可构建 |

### C.5 推荐构建方案（工程可执行）

### C.6 风险与残余不确定性

最大风险是「阻力=身价」的语义混淆。第二是「地理常数」被误读为「距离效应强」。第三是「无履历=没动过」。三项都在 §4.3 有禁令。
