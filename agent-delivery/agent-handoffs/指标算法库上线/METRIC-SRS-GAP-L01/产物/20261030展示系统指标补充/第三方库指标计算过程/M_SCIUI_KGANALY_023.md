### 1.2 为什么需要本指标

密度是社群发现结果的核心质检指标：模块度（划分好坏）是全局单值，密度（每个社群各自多紧）是逐社群局部值——「模块度高但某社群密度低」说明该社群是拼凑的。对比表把六算法的密度并排，回答「哪个算法找到的社群更内聚」；密度-规模散点（`:327`）回答「大社群是否必然松散」（真图实测：最大社区 4,151 节点密度 0.0093 vs 22 节点小社群 0.177——规模与密度负相关，符合图论预期）。对管理者的价值：识别「紧密技术集群」（高密度社群=技术组合成熟）与「松散关联域」（低密度大社群=跨域汇聚）。姊妹指标 avgLinkStrength（平均链强度）与密度同源供数，本件密度先行、链强度为扩展位。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**「社群连接密度」未在 SRS 任何叶出现（附录 A.2 检索 0 命中）——它是 `CommunityPanel.jsx` 对比表的 UI 层命名，公式由前端 `communityDensity` 闭合：`内部边数 / (n×(n-1)/2)`——这恰是标准图论密度定义（无向简单图），无待裁参数。唯一口径细节：自环与重复边是否计入（UI 邻接表构建去自环，重复边按集合语义去重——本件复现同口径）。核增需求与算法库 0 命中（附录 A.2）。

### 1.4 类似指标权威方法可行性分析概要

密度是图论教科书定义。其一，图密度标准定义（R1 Wasserman & Faust 1994《Social Network Analysis》）：无向简单图密度 $D = \frac{2m}{n(n-1)}$（$m$=边数，$n$=节点数）——与 UI 公式逐字一致（$2m/n(n-1) = m/[n(n-1)/2]$）；其二，NetworkX 工程实现（R2 `nx.density`）：同一公式，自环不计（与 UI 邻接表口径一致）；其三，社群发现密度应用（R3 Fortunato 2010 社区检测综述）：密度作为社区内聚度（internal density）标准度量，与模块度/传导性并列。方法族对照：

| 方法族 | 代表 | 本库承载 | 贴合度 |
|---|---|---|---|
| 图密度教科书（R1） | Wasserman & Faust | UI 公式逐字一致 | **锚** |
| 标准库（R2） | nx.density | 本件同构复刻 | 高 |
| 社区内聚度量（R3） | Fortunato 综述 | 标注+LPA 双口径实算 | 高 |
| 前端演示 | UI 16 节点 mock | 算法可用、数据需换真图 | 边界证据 |

结论：公式权威锚齐备且 UI 已实现——判定重心全在数据侧（真图+社区标注是否在库），本件实测在库。

### 1.6 推测原意与推测定义（含降档/升档触发器，B10 模板）

**定义（UI 公式闭合，口径无歧义）**：

$$\text{density}(C) = \frac{|\{(u,v) \in E : u \in C, v \in C, u \neq v\}|}{|C|(|C|-1)/2}$$

即社群 $C$ 内部边数（去自环、去重）除以理论最大边数。**双口径**：①标注口径——分组来自图库 node 表 community_id（上游 DWS 层产出，本件主读数）；②算法口径——LPA 在采样框内独立划分（UI 六算法之一，本件互证读数）。两口径并列落产物，正式接入时按「前端跑算法 or 直连图库标注」的架构决策取用。

### 2.1 图装载与社区标注提取（确定性，B5）

### 2.5 稳健性与口径敏感性

**（a）双口径差异。**标注口径（DWS 上游产出）与 LPA 口径（本件框内重算）的划分不必一致——LPA 是 LPA 的最优解、标注是上游算法的解。本件并列落产物不合并（B10 保守）；正式接入按架构决策取用（直连标注=轻；前端跑算法=交互灵活）。**（b）自环与重复边。**mock 原文含一条自环（量子集群自环边）——UI 邻接表构建自环不入度（`:349-358` 遍历邻接表无自环项），本件 mock 复现按去自环口径（三集群 0.667/0.667/0.7，与 UI 展示值一致）；真图边表未见自环（归属判定 u≠v 自然排除）。重复边：真图复合键分页按字典序拉全（重复边若有会重复计数），产物对账 587,252 与 COUNT(*) 一致——按表存语义逐行计。**（c）LPA 不稳定性披露。**LPA 标签传播顺序敏感（不同更新序可能不同解）——本件以确定性哈希序固定（同参数重跑同结果，B5），但换哈希函数可能得不同划分（LPA 已知属性，R3 综述有述）；六算法中 Louvain/GN 另有各自敏感性，本件不展开（只实算 LPA 一族）。**（d）采样框边界。**LPA 口径在 5,000 框内（诱导子图 38,383 边）——框外 14,430 节点未参与；标注口径是全图 19,430 节点（无框）。两口径框界不同，Top10 不可逐位对齐（结构性差异，非算法缺陷）。
