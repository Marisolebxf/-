## 摘要

「多维结构关联图」是政策分析报告可视化呈现的第二图组件（需求明列叶 seq 221）：弦线图/关系网/传导路径三模式，展示政策要素（资金/人才/平台/税收）与效果指标、产业领域的关联结构。现成图承载三源皆无——dev `policy_graph_node/edge` 表结构现成但全 0 行，gkx 政策表结构化标签列（theme/keywords/quote_policy）合计不足 5 行真值。本件以政策文献量化的主流方法**共词网络**（coword network）现算：以 gkx 20,000 行政策标题+摘要为语料，固定要素词典（政策工具 4 类/产业领域 4 类/效果指标 4 类）做文档级共现——12 节点全活（资金支持 3,052 / 产业发展 2,795 / 平台搭建 1,530…），31 种边实测，弦线主对（工具×产业）最强边资金支持↔新能源 76 行，传导链路（工具×效果）最强边资金支持↔产业发展 714 行。判**完全转换支持**。语义边界已披露：共现是语义关联不是因果效应。

- 需求判定：**需求明列叶**（seq 221 / excel_row 224），图表形式（弦线图/关系网）与需求原文逐字对齐。
- 复现状态：双共现矩阵（工具×产业 + 工具×效果）已跑通落产物。
- 档位结论：**完全转换支持**（语料全量在、节点全活、边密度可读）。
- 关键事实：gkx theme 列 20,000 行仅 2 行非 'NULL' 字面——结构化标签路线死、共现自建路线活。
- 升档路径：无需升档；分词级共词（NLP 工程）触发器在案。

## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技政策跟踪/政策分析评价/**政策分析报告可视化呈现**/多维结构关联图（1.1.1.1.4.2.2.1.3；SRS seq 221、excel_row 224）。UI 实现在政策分析评价页分析区：`StructureLinkPanel.jsx` 渲染 Card「多维结构关联图」（235 行 Card 声明），三模式 Radio（弦线图/关系网/传导路径）。弦线模式用 ECharts graph 布局 circular + 高曲率 ribbon 边模拟弦线（组件注释明确「非 sankey / 非伪 force 冒充弦线」——前端作者对图型语义的坚持值得记录）；关系网模式用力导向图；传导路径模式列出 `effectTransmissionPaths` 传导链（如「资金支持 → 研发投入 → 专利产出 → 产业发展」）。mock 数据两套：`policyElementCorrelation`（`policyData.js:1379`，12 节点三类 + links 权重）与 `chordMatrixData`（`policyData.js:2353`，12×12 对称强度矩阵）。

节点三类结构（组件与 mock 一致）：政策要素 4（资金支持/人才引进/平台搭建/税收优惠，category 0）+ 效果指标 4（研发投入/专利产出/产业发展/就业带动，category 1）+ 产业领域 4（人工智能/生物医药/新能源/半导体，category 2）——本件实证节点体系与这三类一一对应。

### 1.2 为什么需要本指标

政策效能的传导是链式的：资金投入 → 研发活动 → 专利产出 → 产业发展 → 就业带动。单指标看板回答「各环节值多少」，结构关联图回答「环节之间怎么连」——哪个政策工具连接的产业领域最多（工具的杠杆宽度）、哪条传导链最粗（政策合力的主通道）、哪些要素是孤岛（政策空白点）。弦线图的形式价值在于把 12×12 的关联矩阵压缩成一眼可读的环形图，决策者能看到政策组合的结构性拥挤与空洞。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**SRS seq 221 给出形式（弦线图/关系网）与目标（展示关联关系与效果传导链路、追踪影响路径），但关联怎么量化（共现？引用？因果推断？）、传导链怎么识别（语义模板？图算法？）均无定义。mock 的 12×12 强度矩阵是前端自拟的演示值。

### 1.4 类似指标权威方法可行性分析概要

政策文本关联量化是政策文献量化研究（R4，公共管理学报范式文献——内容分析+文献计量+网络分析入政策分析）的核心议题，主流方法族三支：其一，**共词网络**（R1 大数据政策共词网络——关键词同现矩阵 + 社会网络分析；R2 中美政策文本比较——TF-IDF 关键词 + 篇章/句子级共现 + Gephi 社群发现），政策要素关联的最常用量化；其二，**政策引用网络**（R3 政策引用视角的要素变迁——机器学习抽取引用关系 + 优化 PageRank 识别核心要素），适合纵向演进分析；其三，**政策工具二维编码**（R1 的补充框架：政策目标×政策工具匹配矩阵），适合横截面结构分析。

| 方法族 | 代表 | 关联量化 | 与本库匹配 |
|---|---|---|---|
| 共词网络 | R1/R2 | 同现计数/强度 | **最贴**（本件实现，语料全量在） |

### 1.6 推测原意与推测定义（含降档/升档触发器，B10 模板）

**推测定义**：

$$W(a, b) = |\{p \in P : a \in T(p) \wedge b \in I(p)\}|$$

政策工具 a 与产业领域 b（或效果指标 b）在政策文本 p 的标题+摘要中共现的文档数——文档级共现（R2 的篇章共现单元）。节点集 = 政策工具 ∪ 产业领域 ∪ 效果指标（12 节点），边集 = 工具×产业（弦线主对）+ 工具×效果（传导链路）。传导路径 = 工具→效果的 Top 边串联（资金→研发 286 / 资金→专利 …）。

**双口径**：关键词词典共现（本件，12 节点固定词典）vs 分词级共词（NLP 分词+高频词矩阵，节点自动涌现）——前者可复现、节点语义受控；后者节点自动但需 NLP 工程与停用词治理。**降档/升档触发器**：若甲方要求节点集超出固定词典（如政策要素扩到 8 类）→ 词典扩容即可（不降档）；若要求分词级共词 → NLP 工程立项（口径另立）；若要求因果传导（非语义关联）→ 需准实验方法（超本件范围，R5 层）。

## 二、计算过程

### 2.1 方法选择（文献依据）

选共词网络法（R1/R2 范式）。依据：其一，政策要素关联的文献主流（R1 大数据政策、R2 中美政策比较均以共现矩阵为核心量化）；其二，语料适配——gkx 政策标题+摘要 20,000 行全量在库，文档级共现直接可算，无需外部标注；其三，节点可控——固定词典（12 节点三类）与 UI mock 的节点体系一一对齐，弦线图的形式语义（环形三类节点 + 跨类弦）与共现矩阵的结构天然匹配。R3 引用网络路线因 quote_policy 列仅 2 行真值而排除（absence 在案）。

### 2.2 装载与语料全量拉取

经 `_gkxdb.py` 连 gkx，`SELECT title, abstract FROM gkx.dwd_policy_base` 全量拉取 20,000 行（`policy_text_rows_pulled=20000`）——政策库规模（2 万行）远低于大表阈值（dwd_zh_paper 10 万/dwd_patent 294 万），全量拉取合规（不走采样协议）。abstract 非空率 100%（POLPAN_002 件探测），语料面完整。

### 2.3 要素词典与三类节点命中

固定词典（脚本内版本化）：政策工具 4 类（资金支持=资金/补贴/经费/资助、人才引进=人才、平台搭建=平台、税收优惠=税收/减税/免税）；产业领域 4 类；效果指标 4 类（研发投入=研发、专利产出=专利、产业发展=产业、就业带动=就业）。节点承载量（`node_policy_counts`）：资金支持 3,052 / 产业发展 2,795 / 平台搭建 1,530 / 人才引进 1,020 / 研发投入 817 / 就业带动 375 / 税收优惠 328 / 新能源 256 / 专利产出 224 / 生物医药 104 / 人工智能 73 / 半导体 36——**12 节点全活**（最少半导体 36 行也够弦线图一个环位）。

### 2.4 弦线主对：政策工具 × 产业领域共现

```python
for (title, abstract) in rows:
    tools = hit_set(text, TOOL_KWS); inds = hit_set(text, INDUSTRY_KWS)
    for a in sorted(tools):
        for b in sorted(inds):
            cooc_tool_industry[(a, b)] += 1
```

Top6 边（`cooc_tool_industry_pairs`，全部 15 边中）：资金支持↔新能源 76、平台搭建↔新能源 36、平台搭建↔人工智能 31、平台搭建↔生物医药 22、资金支持↔生物医药 19、人才引进↔新能源 16。结构读法：**新能源是政策工具的第一落点**（四个工具的最强边全部指向或接近它）；资金与平台是连接产业最宽的两只手；税收优惠×生物医药无边（16 种组合实测 15 种——税率工具与医药领域无同文共现）。跨维语料覆盖：同文同时含工具+领域的政策 179 行（`rows_with_tool_and_industry`，占全库 0.8950%——`rows_with_both_dims_pct`）。

### 2.5 传导链路：政策工具 × 效果指标共现

Top8 边（`cooc_tool_effect_pairs`，全部 16 边中）：资金支持↔产业发展 714、平台搭建↔产业发展 538、人才引进↔产业发展 353、资金支持↔研发投入 286……传导链的实证形态：**资金→产业发展是主干道**（714 行政策同时谈及资金与产业），资金→研发投入（286）是次干——UI mock 的传导路径模板（资金支持→研发投入→专利产出→产业发展）在共现数据中前两环有强支撑、后两环（专利→产业）需产业维与专利维的同文共现（本件词典已含，边值在产物 16 边中可查）。

### 2.6 稳健性与口径敏感性

词典敏感性：关键词命中是宽口径（「产业」命中含「产业化」「产业集群」等），若收窄为「战略性新兴产业」标准名录则产业发展节点会显著缩量——两向口径差登记在附录 C 风险表。共现计数的确定性：Counter 聚合 + sorted 输出，重跑逐位一致。语料偏斜：企业类政策占比 34%（POLPAN_002 件读数）意味着共现结构向企业语境倾斜；「效果指标」节点是**文本提及**非效果实测值（产业发展 2,795 行政策谈产业不等于产业发生了发展）——语义关联与因果效应的边界在 §1.6 与附录 C 双重披露。
