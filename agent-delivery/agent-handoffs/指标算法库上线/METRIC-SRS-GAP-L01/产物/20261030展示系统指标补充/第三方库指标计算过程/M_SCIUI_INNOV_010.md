- 档位结论：**部分支持**（省内可算 + 全球无源双降档）。
- 关键事实：gkx 广东 100% 截断（24,598/24,598）；深圳占城市 Top12 合计 52.2%；久新金额覆盖 8.75%；region_snapshot investment_score 全空（9,367 行）。

## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技发展态势/全球创新监测/实时监测（UI `RealtimeMonitoring.jsx` + `realtimeModel.js`）+ 城市创新能力分析（seq 83 语境，投资规模的城市粒度）。本件挂载点集中在实时监测模型层：**指标系列定义**（`realtimeModel.js:26`）把 investments「投资额」设为三系列之一（与专利数/论文数并列），`yAxisIndex: 1` 绑定 y2 轴；**y2 轴命名**（`:238`）「金额(亿美元)」给了量纲与单位——这是三件套中唯一在 UI 层明示金额单位的挂载点（INNOV_007/009 的 mock 均无量纲）；**图例**（`:215`）「专利数/论文数/投资额」三列。mock 数据（`realtimeTrendMockData.investments`，`:62-67`）是 18 个月的等差递增序列（316→465 亿美元，月 +8 至 +16），且第 16-18 月为预测演示（`REALTIME_TREND_MEASURED_COUNT=15` 分割，`:32`）——mock 的月度投资流语义是「该月全球投资事件总额」，与 INNOV_007「实时投资金额」（累计/当前值）形成流-存量互补。次挂载点：领域分布对比（`domainDistributionSource:11-19`，七大产业×value/events）的柱状图形态（seq 68「可视化数据呈现：柱状图」语境）；另页参照：技术发展跟踪.md:48 气泡图投资额（不同页语境，仅登记不作本件挂载）。mock 值是 UI 需求证据（演示值，不参与支持度结论）。

### 1.2 为什么需要本指标

实时监测页的叙事是「全球创新的脉搏」：专利/论文/投资三条月度曲线并排，投资额是**资本维的实时信号**——前两者反映知识产出，投资额反映资本信心。区域切片后（城市/国家/省），问题变成「哪个区域在吸金」——这是 seq 83 城市创新数据监控（「监控全球主要城市的创新基金、投资规模」）的核心读数，也是趋势图 y2 轴与领域分布柱状图的共同数据需求。月度流的形态（mock 18 个月）还隐含环比/同比的衍生需求（INNOV_006 的增长率在月粒度上的应用）。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**「区域投资额」全称在三份 SRS 与《科技信息展示系统和公式专题服务系统.md》rg 检索未命中。近似叶：SRS 全球创新监测 seq 83「城市创新数据监控」——「监控全球主要城市的创新基金、投资规模…」（区域=城市粒度，无定义）；seq 68「可视化数据呈现」——「以折线图、柱状图等可视化形式呈现数据」（形态语境，无区域金额定义）；技术发展跟踪.md:48 气泡图投资额（另页）。三份说明书未出现该指标名的固定句式适用于本件全称。

### 1.4 类似指标权威方法可行性分析概要

「区域投资规模」的权威先例分三层：**官方统计**——中国科学技术发展战略研究院《中国创业投资发展报告》按地区（省市）统计创投金额（调查口径，R5）；**市场机构**——投中研究院（CVSource）年度报告按省市统计中国创投市场（广东/北京/上海/江苏/浙江五强格局，R4）；**全球口径**——CB Insights State of Venture 报告按国家/州/都市圈统计季度 VC 额（美国/亚洲/欧洲三板块 + 都市级拆解，R3），其区域口径（country/state/metro）与本件 UI 的「全球」语义直接对齐。方法族对照：

| 方法族 | 区域体系 | 金额处理 | 与本库匹配 |
|---|---|---|---|
| CB Insights（R3） | 国家/州/都市圈 | 季度聚合 | 需外部源（全球现成） |
| 投中 CVSource（R4） | 省市（中国） | 未披露估计纳入 | gkx 城市维可对齐 |
| 科技部战略院（R5） | 省市（调查） | 填报 | 无调查源 |
| gkx 直算 | 省/市/区（底册） | 六形态解析（007 规则） | **省内现在可算** |
| 久新聚合 | 机构国别（采样） | amount_cny 覆盖 8.75% | 参照面 |

结论：全球区域口径业界有成熟先例（CB Insights），但均属外部源；库内三源的区域×金额聚合各有截断（gkx 省内/久新低覆盖）——「区域投资额」的档位天花板本质是**数据源覆盖问题**而非方法问题。

## 二、计算过程

### 2.1 装载与规模校验

gkx 侧融资表 25,654 行（对账共享快照零漂移）经 `org_id` LEFT JOIN `dwd_org_base_info` 取 province/city——省份非空 24,598 行、城市非空行构成城市 Top12 分母池。久新侧 `ads_project_profile` 1,838,841 行（金额覆盖 160,822 行）与 `ads_project_institution` 22,571,355 关联行（20 万采样）。dev 侧 absence 探针（§2.2）。

### 2.2 dev 侧：区域维缺席（absence 探针）

### 2.3 gkx 省份/城市分布：池级截断证据（方法主体之一）

### 2.4 久新国别聚合：20 万行采样协议（方法主体之二）

项目-机构关联表 22,571,355 行无索引，全量 JOIN `ads_institution_profile` 后 GROUP BY country_name 在 Doris 实测**查询超时**——按派单书大表协议改用**20 万行采样子查询**：`FROM (SELECT project_id, institution_id FROM ads_project_institution LIMIT 200000) pi JOIN ads_institution_profile i`。采样结果国别 Top12（项目数/机构数双列）：**中国 10,658 项目/2,967 机构、美国 5,708/3,376、英国 2,417/1,030、德国 2,007/754、澳大利亚 1,503/375、法国 1,406/1,075、加拿大 1,343/369、日本 1,231/660、西班牙 1,129/543、荷兰 1,069/246、香港 1,058/61、意大利 1,003/440**（`facts.jiuxin_project_institution_country_top12`）。三点解读：其一，美国机构数（3,376）超中国（2,967）而项目数反低——单机构项目均值低，机构维与项目维的排序差异提示「区域投资活跃度」的度量选择（机构数 vs 项目数 vs 金额）本身是口径问题；其二，香港 61 机构承载 1,058 项目（17.3 项目/机构，Top12 最高）——小机构池高产的样本特征；其三，采样为无权重均匀采样，国别分布可作结构参照，金额聚合（若做）需乘以 11.29 倍扩样系数并披露采样误差——本件未出金额扩样读数（保守交付，B10）。
