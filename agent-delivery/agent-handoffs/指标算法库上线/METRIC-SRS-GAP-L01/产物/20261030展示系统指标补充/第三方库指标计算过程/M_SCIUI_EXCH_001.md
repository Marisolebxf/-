## 摘要

「活动类型分布」是科技创新服务全景平台科技交流页地图视图右栏的环形饼图（`TechExchange.jsx:344-349`，`getActivityTypeOption` 于 `:64-78` 定义）：按活动类型（学术会议/论坛/研讨会/峰会/竞赛/交流会）给出分布占比，tooltip 显示 `{b}: {c} ({d}%)`；上游是活动类型筛选器（`:236-244`）对 `techActivities` 主档的联动过滤（`:147-153`）。数据侧判定：**完全不支持**——活动台账三源零承载：jiuxin 3 表命中为科研难题事件/人才产业活动/人才流动事件；dev 10 表为创新事件与产业链事件族（投资/里程碑/新闻）；gkx 4 表为外汇牌价（foreign_exchange 金融语义，非科技交流）/并购事件/通用事件要素库。mock 六类分布（45/68/89/34/23/56，合计 315）与 KPI「年度活动 456 场」互不勾稽，演示值不可作基数。修复依赖活动主档数据源（会展/学会/政府办展登记）接入。

- 需求判定：指标名三份说明书未出现；科技交流页为全景平台 UI 挂载件（清单 row_01=721）。
- 复现状态：薄壳已跑通；三源词族异域命中登记落产物。

## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技创新服务全景平台/科技服务全景/科技交流（`TechExchange.jsx`）。页面结构：页头「科技交流」+ KPI 四卡（年度活动 456 场/参与人次 12.8 万/合作机构 234 家/专家讲者 567 人，`:138-143`）→ 筛选栏（视图模式/活动类型/技术领域/更多筛选：规模/时间/状态，`:225-291`）→ 主区左「活动地理分布」地图或「活动列表」（`:297-338`）+ 右栏「活动类型分布」饼图（`:344-349`）与「特邀专家讲者」（`:350-368`）→ 资源推荐列表（`:372-399`）。本件挂载位即右栏饼图卡：`ReactECharts option={getActivityTypeOption()}`，data 指向 mock `activityTypeDistribution` 六类。

### 1.2 为什么需要本指标

类型分布回答「平台汇聚的科技交流活动结构偏什么」：管理者看活动结构是否偏科（论坛多、竞赛少），用户按类型找活动入口。它与活动地理分布（空间）、KPI 年度活动（总量）构成交流页的三角：类型 × 空间 × 总量。筛选器与分布图共用 type 字段——分布图本质是主档 type 列的全量分组计数（筛选联动时为筛选集内计数），类型维是这个页面的骨架维度。

**需求文档没提及指标定义方法。**「活动类型分布」指标名在三份需求说明书中未出现（检索记录见附录 A）；科技交流页为主需求「科技创新服务全景平台」（1.2 域）的 UI 演示页，无 SRS 级功能叶给出分布口径（类目词典、计数单位、年度边界、活动状态过滤）。
