## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 科技时空演进展示 → 趋势报告（report stage）。挂载链：mock `report.trendSections[1]`（`spaceTimeEvolutionMock.js:809-814`，key=paths，title=路径强度抬升）→ `buildReportViewModel`（`SpaceTimeEvolutionPage.jsx:1186-1238`——trendSections 由 distributionCharts.map 覆盖 badge 后输出）→ `:2097-2110` report-chart-stack SoftChartFrame（renderSparkBars 渲染 + sr-only 序列播报）。

mock 值全部为演示常量（76/21/五点 15→60），不参与支持度结论。

### 1.2 为什么需要本指标

抬升幅度回答「重点路径的强度在多大程度上走高」：趋势报告以图表卡呈现路径强度的时间抬升，辅助管理者判断跨区协同链路的成长性。SRS 上位叶（科技时空演进展示）要求趋势报告输出——抬升是报告的核心趋势读数之一。

### 1.3 需求文档是否给出定义方法
