### 1.6 推测原意与推测定义（含降档/升档触发器，B10 模板）

**推测定义（双口径并列，须披露未裁定）**：

量环比（%）：

$$G(s, m) = \left( \frac{V(s, m)}{V(s, m-1)} - 1 \right) \times 100\%$$

份额环比（pp）：

$$\Delta(s, m) = \text{share}(s, m) - \text{share}(s, m-1)\ (\text{百分点})$$

其中 $V(s,m)$=来源 s 在月 m 的调用量。**前提双依赖：调用序列（按来源）+来源标签，三源实测双缺**（§3.3）——mock 的 `+v%` 渲染暗示量环比口径。公式列示仅作口径锚（F4：本件 §二 从缺）。

**降档/升档触发器（B10 模板）**：①网关日志（含来源标识或资产→来源映射）+标签落地 → **T+1 期起升完全直接支持**（首期无环比——标签落地当期只建基线）；②仅资产日志无来源维度 → **部分支持**（总量环比可算、来源环比不可）；③维持现状 → 完全不支持（环比列显示「—」；与 052 并条裁定口径）。

环比双件同断点（序列无——041 复用）+本件叠加轴缺（标签空——lane3 复用）：**双缺使修复须两线齐动**。四缺失情形归属：序列「表不存在」（网关日志线——调用族五件共用）；标签「结构在但语义缺位」（登记线——048/051 共用）。修复时序：日志与标签并行落 → 首期（标签落地当期）建基线 → **T+1 期起环比可算**（滞后一个统计期——本件是调用族恢复最慢件）。

### 4.2 期定义与变化量纲缺位（口径级，随 052 并条）

「较上期」期定义（建议自然月——与 052/047 对齐）与变化量纲（量环比 % vs 份额环比 pp——建议双列并存：量环比为主读数、份额环比 pp 为辅）待裁。mock 的 `+v%` 渲染暗示量环比；若产品要份额动量，pp 口径须另设列（% 渲染会误导）。与 052 并条一揽子裁定（期/粒度/基数三要素+量纲双列）。

### 4.3 修复建议与影响面

| 建议 | 类型 | 影响指标 | 说明 |
|---|---|---|---|
| 网关日志（含来源标识或映射） | 数据工程 | 本件 + 041/049/050/052 | 触发器①（调用族五件共用） |
| 来源标签落地+回填 | 数据工程 | 本件 + 048/051 | 触发器②（供给侧登记族共用） |
| 环比口径并条裁定（含量纲双列） | 口径裁定 | 本件 + 052 | 一揽子文件（期/粒度/基数/量纲） |
| 环比列暂无数据态+死分支测试样例 | 展示规范 | 本件 | mock 全正替换；红 Tag 分支补测 |

档位后果：两线齐动+一期积累 → **完全直接支持**（T+1 期）；仅日志无标签 → **部分支持**（总量环比可、来源环比不可）；现状 → 完全不支持。推荐：口径并条即期，两线随各自族主线，基线期在口径文档预告。
