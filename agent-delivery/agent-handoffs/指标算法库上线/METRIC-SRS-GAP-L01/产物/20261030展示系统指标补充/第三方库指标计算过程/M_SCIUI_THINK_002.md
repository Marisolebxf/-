## 四、数据缺失情况

### 4.1 供方主档与评分面零承载（结构级，主因）

供方分析能力评分是供方管理体系的输出，三源无供方主档（连供方清单表都没有），评分面更无从谈起。四缺失情形归属：**表不存在**。修复动作是**供方评价体系立项 + 数据源接入**（供方目录 + 履约记录 + 评审结果），库内无法凭空构建。
