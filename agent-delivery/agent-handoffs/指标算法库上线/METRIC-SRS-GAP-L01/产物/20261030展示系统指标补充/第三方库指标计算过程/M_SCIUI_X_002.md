值得记录的语义细节：新页六分项里「产业产值」是**水平维**（当期产值高低），旧页五分项里「产值增长」是**趋势维**（同比增速）——同名族不同语义；两版权重体系并存（25/30/25/20 四维 vs 旧版各 Tab 独立五分项），说明评估模型在迭代中，正式口径必须裁定（B10）。mock 六维分（`facts.ui_mock_scores_industry`：74/70/71/73/72/72）与综合评估 72 分是前端直给演示值。

### 1.2 为什么需要本指标

权重是综合评估的「政策旋钮」：产业发展潜力 = f(投入, 成熟度, 产值, 影响力)，各维权重决定「什么样的产业算有潜力」——重产值则存量大的产业占优、重增长则新兴赛道占优。需求把「用户可自定义指标权重」写进三处综合评估叶（seq 143/150/151 同句式），说明权重自定义是评估系统的**一等交互功能**而非硬编码常量；UI 用抽屉+校验+快照三件套实现了它。

数据侧本件的调研价值在「权重件怎么判档」的方法论：权重本体不是数据（没有「权重表」可查），它的支持度完全由**加权对象的可算性**传导——产值主链可算则权重有意义（乘出的综合分有据），产值主链缺则权重悬空（乘 mock 分）。因此本件探针双线：权重机制验证线（三源无表+前端闭环复算）与加权底册线（X_001 主链复用，B11 共享）。

### 1.3 需求文档是否给出定义方法

**需求文档定义了权重机制但未定义权重数值。**SRS seq 150（excel_row 153）原文：「将产业发展潜力的各项指标进行综合展示，用户可自定义指标权重，支持根据权重计算综合得分，提供产业发展潜力的综合评估结果和排名。」——机制三分句（自定义/按权重算综合得分/出结果排名）明文；但产值维该占多少权重、六分项还是五分项、一级二级权重怎么级联，全部空白。主需求文档同段复述。UI 的 16%（新）/20%（旧）均为前端作者的演示默认值——**不得当需求证据引用**（禁止事项 2），本件将其登记为待裁定口径而非结论。

### 1.4 类似指标权威方法可行性分析概要

综合评估权重的方法族三层：**德尔菲法/专家赋权**（UI MODEL_OPTIONS 第 2 项「专家评估-德尔菲法」对应）——专家两轮打分收敛权重（R1，需求侧认可的模型选项之一）；**熵权法/客观赋权**——按指标数据离散度自动定权（R2，信息熵越大权重越高，可脱离主观先验）；**AHP 层次分析法**——两两比较矩阵导出权重+一致性检验（R3）。UI 的「综合评估-系统仿真模型」选项对应主观+客观混合族。方法族对照：

| 方法族 | 权重来源 | 数据要求 | 与本库匹配 |
|---|---|---|---|
| 德尔菲（R1/UI 选项 2） | 专家打分 | 专家面板 | **无（三源无专家权重面；UI 交互可承载）** |
| 熵权法（R2） | 指标离散度 | 六维指标全量数据 | **部分（产值维 17 产业截面在、序列缺；其余五维另件）** |
| AHP（R3） | 两两比较 | 判断矩阵 | 无（同需外部输入） |
| UI 默认权重（现状） | 前端常量 | — | **在（16%/20% 双版，演示值）** |

结论：权威赋权法需要的外部输入（专家面板/判断矩阵）三源无承载；客观赋权（熵权）可部分落地（产值维截面可算熵）。完整版见附录 C。

## 二、计算过程

### 2.1 方法选择

权重件的方法轴从「数值复现」转为「机制验证+杠杆量化」：第一步验证 UI 加权公式（默认权重×mock 分复算 vs 页面直给值），第二步量化权重对读数的杠杆（gkx 底册归一化后按权重档位算贡献额），第三步登记三源权重表的负证据（0 表）。全部计算不依赖库内权重值（无此表），底册线复用 X_001 主链 SQL（B11）。

### 2.2 UI 权重体系登记与求和校验

`DEFAULT_WEIGHTS.industry.metrics = [17,17,16,17,16,17]` 对应六分项（`facts.ui_default_weights_industry`：产业投入 17/产品成熟度 17/产业产值 **16**/科学影响力 17/技术影响力 16/综合评估 17），求和 = **100**（`facts.ui_weight_sum_check`）——二级校验通过（UI 抽屉的 `metricTotal===100` 红绿提示以同为基准）。旧版等价：industryWeights 五分项（22/20/**20**/19/19）产值增长=20%（TechInnovationEvaluationPage.tsx:321）。两版并存登记，B10 双口径。

### 2.3 加权公式复算（口径 A：机制闭环验证）

mock 六维分（`facts.ui_mock_scores_industry`：74/70/71/73/72/72，来自 dimensionBaseConfigs industry 分项）× 默认权重：Σ(wᵢ×sᵢ) = 17×74+17×70+16×71+17×73+16×72+17×72 = 7,201；Σwᵢ=100 → 复算综合分 **72.01**（`derived.ui_industry_composite_score_weighted`，value=72.01，numerator=7,201，denominator=100，B3 同 UI 同快照）。页面综合评估分 72（industry.score 直给）——复算与直给一致（差 0.01 为四舍五入）。**结论**：mock 的综合分不是随机常量而是加权计算的结果，UI 加权公式语义（Σwᵢsᵢ/Σwᵢ）在实现层自洽——权重功能的前端链路（编辑/校验/应用/重算）无需后端改造即可对接真实分值。

```python
# 口径 A 复算（产物键 ui_industry_composite_score_weighted）
w = [17, 17, 16, 17, 16, 17]          # DEFAULT_WEIGHTS.industry.metrics
s = [74, 70, 71, 73, 72, 72]          # dimensionBaseConfigs industry.metrics[].score
weighted = sum(wi * si for wi, si in zip(w, s)) / sum(w)   # → 72.01
```

### 2.4 gkx 加权底册归一化（口径 B：杠杆量化前置）

17 产业 JDZ 增加值最新值（`facts.gkx_sz_industry_av_latest_yi`，与 X_001 同 SQL 同值：战新 4,146.04 / 网络与通信 2,046.53 / … / 安全节能环保 86.08）做 min-max 归一到 0-100 标尺：max=战新 4,146.04→100.0、min=安全节能环保 86.08→0，其余线性内插（`facts.gkx_sz_industry_av_norm100` Top10：战新 100.0 / 网络与通信 48.29 / 软件与信息 27.63 / 超高清视频显示 18.24 / 新能源 16.45 / 海洋经济 12.03 / 生物医药与健康 12.02 / 高端装备 10.92 / 绿色低碳 10.16 / 数字创意 8.83），17 产业归一均值 = **16.85**（`facts.gkx_sz_industry_av_norm_mean`）。归一的意义：综合评估的产值维分值须与其它维（0-100 分制）同标尺，归一表即产值维的真实分值候选面（替代 mock 的 71 分）。

### 2.5 权重杠杆三档演示（口径 B 主读数）

以归一均值 16.85 为产值维分值，权重 w% 时产值维对综合分的贡献额 = w% × 16.85：**16%→2.70 分**（`derived.gkx_output_dim_contribution_at_weight_16`）、**20%→3.37 分**（`_at_weight_20`）、**25%→4.21 分**（`_at_weight_25`）——权重从 16% 调到 25%，产值维贡献额抬升 1.51 分（杠杆率 0.084 分/百分点权重）。这组读数把「权重敏感性」从抽象概念变成可交付数字：管理权重抽屉每次拖动，产值维读数按此斜率响应。**限度披露**：以均值代表产值维是简化（逐产业综合分应逐产业乘各自归一分再聚合）；序列缺（X_001 继承，年度对齐 3 年）使「产值增长」维（旧页语义=同比增速）不可算——杠杆演示限「产值水平维」截面。

### 2.7 稳健性与口径敏感性

权重读数的两个敏感性方向：**权重版本敏感性**——新 16% vs 旧 20% 并存，贡献额差 0.67 分（2.70 vs 3.37），若正式版采旧口径则产值维读数抬升 25%；**分值源敏感性**——产值维分值取 mock 71 分 vs gkx 归一 16.85 分，综合分差量级完全不同（mock 底下产值维贡献 16%×71=11.36 分 vs 真实归一底下 2.70 分）——真实分值接入后综合分整体下移，页面各维分值的 mock→真实替换必须整体切换不可单维替换（否则标尺失衡）。两敏感性均已在产物 notes 登记，正式上线前须甲方裁定权重版+分值源双口径。

## 四、数据缺失情况

### 4.1 产值序列缺失（继承 X_001，主因）

权重体系唯一实质缺口是分值源的序列化：产值水平维可用截面（17 产业归一），产值增长维无年度序列（3/7 对齐）不可算。若正式权重采新版六分项（产值=水平维），缺口不阻塞——截面即可上线；若采旧版五分项（产值增长=趋势维），一维悬空。修复路径同 X_001：统计源接入补年度值。

### 4.2 权重数值未裁定（口径级）

新 16% / 旧 20% 双版并存 + 权威赋权法（德尔菲/熵权/AHP）的外部输入（专家面板/全维数据）三源无承载——正式权重须甲方裁定：沿用 UI 默认（改配置即生效）、专家重赋（德尔菲流程外部输入）或客观赋权（熵权法需六维数据齐）。本件杠杆读数（2.70/3.37/4.21）为裁定提供量化参照：每 1 百分点权重 ≈ 0.084 分综合分。

### 4.3 修复建议与影响面
