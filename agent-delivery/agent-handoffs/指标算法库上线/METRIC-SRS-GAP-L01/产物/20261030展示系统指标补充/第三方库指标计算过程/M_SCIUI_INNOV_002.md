### 1.2 为什么需要本指标

全球创新监测页的定位是「看全球创新的宏观走势」，趋势演进图是页面的第一视觉：用户打开页面第一眼要看到「创新在涨/在跌/在变轨」。本指标承担三职：①**总览叙事**——多指标并读给出「全球创新景气度」的复合印象；②**时间锚点**——事件层把抽象曲线锚到具体事件（某机构入库/某实验室上线），让曲线可解释；③**下游入口**——趋势的末端自然衔接预测（008 件）与区域下钻（001 件国别榜）。

数据侧本件是全批「UI 结构反推指标」最典型的一件：mock 的 7 条事件与 buildTrendSeries 的四指标线,完全是前端作者的产品想象,三源没有任何「趋势演进」结果面。但拆层后发现数字层有意外的强承载（久新 geo_yearly_metrics 宽表),只有事件层是真空白——这种「拆层判档」的方法(数字层/叙事层分别评估再合成)是本件给批内立的方法论样板:复合型 UI 组件不能整体判档,必须拆到最小可评估单元。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**「全球创新趋势演进」作为指标名在三份说明书 0 命中。语义最近三处（均功能描述非定义）：全球创新监测.md bid_desc『利用数据模型开展趋势预测和判断』；seq 71（excel_row 74）创新影响预测『提供创新影响预测工具，用户可查看预测结果和趋势分析，系统基于历史数据构建预测模型』；科技全域态势.md seq 12（excel_row 15）『时间轴趋势展示：以时间轴形式展示科技领域的重要事件、发展趋势和关键节点』——seq 12 给了「事件+趋势+节点」三要素,与本件 UI 双层结构(事件层+数字层)高度同构,是需求侧最有力的语义锚,但它挂在科技全域态势页非本页。主需求文档 :493-:495 为 bid_desc 同文。

### 1.4 类似指标权威方法可行性分析概要

全球创新趋势度量的权威范式有三支。OECD MSTI 的 **Trend/Growth 指标族**：以连续年份序列计算 CAGR 与近期加速率,专利维用 triadic families、论文维用 scientific articles,口径强调「同一统计域内跨年可比」（R1）;UNESCO 科学报告/UIS：以 researcher 数、GERD/GDP 等构成「创新投入趋势」,多指标并读但各指标独立叙事;WIPO GII（全球创新指数）：37 国+经济体复合指数逐年发布,趋势=指数差分,是「单一合成数字的演进」范式(R3)。方法族对照:

| 方法族 | 序列构成 | 三源承载 | 匹配度 |
|---|---|---|---|
| MSTI 增长族(R1) | 单指标年度序列+CAGR/加速率 | ads_geo_yearly_metrics 四指标 2015-2025 | **高（数字层直接套用）** |
| UNESCO 多指标并读 | 多指标独立趋势线 | 同表四列全量 | 高（并读模式同构） |
| GII 复合指数(R3) | 合成指数逐年差分 | 无（三源无全球复合指数面） | 低（需另建合成层） |
| 事件锚定叙事（UI 预期） | 年月+事件流水 | **无（absence_probe 0+1）** | **零（结构级缺失）** |

结论:数字层走 MSTI/UNESCO 范式完全可行(序列+CAGR+YoY 已在产物),事件层需上游立库。完整版见附录 C。

## 二、计算过程

### 2.1 装载与规模校验

久新 `ads_geo_yearly_metrics`（171,736 行,geo_level COUNTRY/LOCATION 两级）本件消费 COUNTRY 级:2015-2026 十二年 × 210-222 国 × 四指标（paper/project/talent/institution counts）。全序列连续无缺年（base_years_missing=[]）;2026 为残年（论文 133,932 仅为部分年度快照,国家覆盖缩至 198）,趋势解读截至 2025。

### 2.2 gkx/dev 侧负结论（absence_probe）

```sql
-- gkx 趋势演进结果面扫描
SELECT table_name FROM information_schema.tables WHERE table_schema='gkx'
AND (table_name LIKE '%timeline%' OR '%evolution%' OR '%advance%' OR '%milestone%');
-- → 0 hits（absence_probe[0]）
-- dev 同词扫描 → 唯一命中 gkxlumenx_dwd.industry_chain_milestone_event（产业链里程碑,语义不符创新叙事）
```

gkx 侧另有论文年份分布（官方快照 fix2,全表 100,900 行）——中文池单源,做不了「全球」趋势,仅作域内参照登记。dev 的 milestone 表是产业事件（轮融资/量产之类）非创新叙事事件,判语义不符。

### 2.3 数字层主序列（COUNTRY 级四指标）

```sql
SELECT report_year, COUNT(DISTINCT country_code) countries,
       SUM(paper_count) papers, SUM(project_count) projects,
       SUM(talent_count) talents, SUM(institution_count) institutions
FROM ads_geo_yearly_metrics WHERE geo_level='COUNTRY' GROUP BY report_year ORDER BY report_year;
-- → 2015: 210国/232,090/299,389/73,133/32,187 … 2025: 222国/1,287,996/392,032/159,546/48,444
```

十二行全序列落产物 `jiuxin_country_yearly_series`。三条主线读数：①论文维单调递增且加速——YoY 从 2016 的 4.4% 升至 2025 的 42.03%（`jiuxin_paper_yoy_pct` 十年全表）,但 note 在案:2024-2025 跃升（39.82%/42.03%）含采集口径扩张因素,非纯学术产出增长;②人才维稳健翻倍（73,133→159,546,+118%）;③机构维 32,187→48,444（+50.8%）。

### 2.4 专利维参照序列（jurisdiction）

```sql
SELECT jurisdiction_code, report_year, SUM(patent_count) FROM ads_patent_analysis_jurisdiction
WHERE jurisdiction_code IN ('US','CN') AND report_year BETWEEN 2020 AND 2025
GROUP BY jurisdiction_code, report_year ORDER BY 1,2;
-- → US 53,773/53,038/61,361/67,519/46,358/46,885；CN 36,082/42,592/32,948/29,862/2,880/1,976
```

US 线 2023 峰后缓降,CN 线 2024 断崖（29,862→2,880,−90%）——受理局口径的采集变更信号（非中国创新崩塌）,与 001 件 jurisdiction 榜（US 932,277/CN 273,396 ALL 期）同源零漂移。专利线入图必须带「受理局≠属地」标签（B9 纪律）。

### 2.5 反向信号与复合叙事检验

项目维 2015 299,389 → 2023 峰 603,004 → 2025 392,032（−35% vs 峰值）:与论文维（同期 +98%）方向相反。解读:两指标统计域不同（论文=学术产出,项目=科研立项/资助活动）,2024-2025 项目骤降更可能是资助数据采集口径收缩。**复合叙事结论:不存在单一「全球创新景气」方向,四指标并读必须分线叙事**——这直接约束 UI 文案:mock 的『全球创新持续繁荣』式总标题须按实况改写。

### 2.6 叙事层空集与上游立库需求

mock 7 条事件的三源探测=空集（§2.2）。上游立库最小结构建议:`innovation_event_stream(event_year_month, actor_type, actor_name, event_type, narrative, evidence_ref)`——actor_type 枚举机构/企业/平台,event_type 枚举数据入库/能力上线/合作达成。该结构同时可服务科技全域态势 seq 12 的时间轴需求（一库两用）。

## 四、数据缺失情况

### 4.1 叙事事件层结构级缺失（主降档因）

三源无「创新事件叙事流水」表——absence_probe 双库留证（gkx 四词 0 命中;dev 唯一命中为产业链里程碑,主体/语义均不符）。mock 7 条事件的形态（年月+主体+短句）无任何结果面承载。四缺失情形归属:**表不存在**。修复动作:上游立库（§2.6 最小结构建议）,一库可两用（本页事件轴+科技全域态势 seq 12 时间轴）。影响面:本件事件层 + 科技全域态势页时间轴节点。

### 4.2 多指标口径异构（并读风险）

四指标统计域不同（论文=学术产出/项目=立项资助/人才=学者计数/机构=机构计数）,且 2024-2025 论文跃升含采集口径扩张、项目骤降疑含采集收缩——两处口径漂移叠加使「全球创新景气」复合叙事不成立。这是数据真相层面的约束（非缺失）,须在 UI 文案与图注固化披露。

### 4.3 修复建议与影响面

| 建议 | 类型 | 影响指标 | 说明 |
|---|---|---|---|
| v1 只上数字层四指标线（事件轴占位） | 产品决策 | 本件即期 | 零成本止血,事件层留空披露 |
| 上游立 innovation_event_stream | 结构工程 | 本件+科技全域态势 | 升档第一杠杆,一库两用 |
| 专利线分轴+受理局标签 | 产品决策 | 本件+001 | 消除断崖误读 |
| 文案按实况改写（去「持续繁荣」） | 产品决策 | 本件即期 | 反向信号披露 |

四条路径的档位后果:数字层即期交付+事件空置 → 仍部分支持;立库落地 → 整体升**完全转换支持**;若进一步要求 GII 式合成指数 → 新增指标工程另议。推荐组合:v1 数字层 + 立库需求单 + 专利分轴 + 文案改写。
