## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技政策跟踪/**多维政策对比**·规划指标库·扶持力度维。UI 实际容器是 PC 端政策对比页的**规划指标库**（`policyPcData.js:299` 注释「4.2.4.1.4 规划指标库（扶持力度 / 适用范围 / 实施时效 / 申请条件）」——直接对应核增需求 4.2.4.1.4 的四维框架）：`planningMetricLib` 数组第 1 位 `pm1`——`{ name: '最高支持额度', dim: '扶持力度', unit: '万元', sample: '10000', scope: '核心技术攻关项目', validity: '2026-01-01 ~ 2028-12-31', applyCond: '揭榜挂帅立项且通过中期评估' }`（`:303`）。消费方是 mock 政策 pol-ai-2026 的详情卡 metrics 引用（`:417`：`{ key: 'm1', libKey: 'pm1', name: '最高支持额度', value: '10000', unit: '万元', dim: '扶持力度', kind: '量化指标' }`）。pm1 是规划指标库 5 槽之首、扶持力度维 3 槽之首（pm1 额度/pm3 风险补偿比例/pm4 加计扣除比例）——补贴类、担保类、税收类三类扶持工具的量化锚排成一个维度，本件是**补贴类**锚。

### 1.2 为什么需要本指标

最高支持额度是政策扶持力度的第一读数：企业与政策制定者对比两条政策，「单项最高能拿多少」是最直接的比选参数——补贴类政策的额度上限直接决定单个项目的政策让利规模。放多维政策对比语境，本指标与 pm3（信贷风险补偿比例）、pm4（加计扣除比例）构成扶持力度维的三类工具锚：补贴类（本件）/担保类/税收类，对比时需折算到可比口径（如每百元研发支出的政策让利额），额度值是折算核心参数。政策详情页 `:675` 的风险洞察也依赖它（「地方『最高支持额度』与财税『加计扣除』若重复计入同一研发支出，存在力度虚高风险」）——额度重复计抵的风险识别以结构化额度值为前提。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**三份需求真源检索记录：主需求与 SRS 政策族无「最高支持额度/支持额度」指标名；核增需求 17 叶中 PC-04（政策数据治理·规划指标库）给出四维框架（扶持力度/适用范围/实施时效/申请条件）——是维度语义源非指标定义。export 行的归类「无业务逻辑数值类」也无线索——实义以 UI 槽位为准：pm1 的 unit '万元' + sample '10000' + 揭榜挂帅 scope——即「政策条款规定的单项最高资助额度（万元）」。

### 1.6 推测原意与推测定义（含降档/升档触发器，B10 模板）

$$A_{max} = \text{Extract}(P_{amt})\ \text{（万元）}$$

## 二、计算过程

### 2.1 方法选择（文献依据）

条款量化抽取采用「语境窄窗正则 + 官方公告对表」两段法，与 POLCMP_009 §2.1 同构：抽取段用「最高」语境词锚定 + 金额模式窗口（「最高X万元」的正向 30 字符窗 + 反向 20 字符窗两段式——单段复杂嵌套正则在 MySQL ICU 引擎实测报 3699 超时，两段简化是工程必需）；对表段用官方额度公告（R1 深圳揭榜挂帅 3000 万元等）作外部锚。选择理由：额度值是强模式目标（数字+单位+语境词紧邻），规则法精度高于通用 NER 且可解释；两段窗的交叉计数以并集口径读（447 行），窗口参数敏感性验证留待 gold 标注集。

### 2.2 gkx 文本面盘点（转换构建的原料）

全文本（title+theme+content+keywords+keypoints 五字段拼接）四层扫描：**语境层**——「最高支持/最高资助/最高不超过」等语境命中 **433 行**（占全表 20,000 的 2.165%，派生键 `zuigao_mention_share_pct`）；**窄窗层**——金额模式（万元/亿元/元）紧邻「最高」语境，两段式正则并集 **447 行**（正向窗「最高…X万元」+ 反向窗「X万元…最高」，两段有交叉计数，作并集口径读——单段嵌套正则实测 MySQL ICU 报 3699 超时，两段简化是确定性等价的工程替代）；**title 层**——标题含「支持」语义 **1,126 行**（含「支持/资助/补助」的标题面，是抽取的种子候选层）；**金额面**——全文含「万元/亿元」金额表述 **3,143 行**（转换面的总量指示）。具名样本（`gkx_text_zuigao_sample` 8 行）：北京市传统工艺美术保护发展资金管理暂行办法实施细则（2018）、吉林省环保产业振兴发展若干意见（2019）、上海科技创新券兑现通知（2018）等——覆盖资金管理办法/若干意见/兑现通知多种政策形态。

四层的层次关系：金额面 3,143 是「政策文本里有数字」的总量池；语境层 433 是「谈最高额度」的语义池；窄窗层 447 ≈ 语境层的超集边界（两段并集把部分「X 万元封顶」类反向表述也纳入）；title 层 1,126 是政策名自证扶持语义的种子层。抽取管线的启动集 = 窄窗 447 行，黄金种子 = title 层含「最高」的子集。

### 2.3 窄窗候选集与语义警示

窄窗 447 行的可抽取性来自模式强度：「最高X万元」类表述中金额值与单位紧邻、语境词在窗口内，正则可稳定抽出数字+单位对。但**语义警示**在案：「最高X万元」语境混有多重语义——项目资助上限（本指标）/贷款额度上限/社保缴费基数上限/罚款上限/奖励封顶——窄窗正则须加「支持/资助/补助/奖励」动词锚并排除处罚语境（含「罚款/处罚/滞纳金」的行剔除）。gold 校准集（人工标注）是精度保证的前置：以 title 种子行 + 窄窗命中行分层抽样约 100 条建首版标注集，迭代窗口规则，目标精度 ≥95%（误抽率经标注验证后决定升档或降档触发器走向）。

### 2.4 结构化承载的排除证据
