### 1.2 为什么需要本指标

区级地图回答「深圳的创新在哪里」：宝安的制造业载体密度、南山的科技服务业集聚、光明的大科学装置布局——区级分布是产业政策（区级考核）、空间规划（园区选址）、资源调配（经费分配）的最小操作粒度。需求把它放在「多层级地理展示」（seq 112）的层级之首（区级→街道级→产业园级→园区级→主体），说明区级是逐级下钻的入口层。

数据侧本件的调研重心是「区级 GIS 粒度承载」——派单书 §0.3 特别提示：既有 GBA（大湾区）系调查只有城市级粒度，区级粒度是新查维度。结论是三源分层：gkx 有强区级面（机构底册 area 列）、久新有区级键但无区级数据面、开发库有区级列但量级小（精选层 46 家）。「格」（行政区划维）三源都给得出，「数」的领域语义只有 gkx 的行业分类学近似——这正是部分支持的典型形态。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**两叶原文：seq 126「分析各科技领域的空间分布特征，包括分布范围、中心位置、扩散方向，用户可查看各领域的空间分布模式和发展趋势。」；seq 112「基于GIS地理信息技术，将创新成果在地图上进行标注，用户可从区级、街道级、产业园级、园区级到具体主体（高校、研究机构、企业、工作室）逐级查看创新载体的分布情况。」——两段给了**展示形态**（GIS 地图/逐级下钻）与**分析目标**（分布范围/中心位置/扩散方向），但计量口径（数机构还是数成果？领域怎么划？「中心位置」是质心还是众数区？）一字未给。UI 的四维（企业/专利/研发投入/人才）是前端作者的实现选择。

### 1.4 类似指标权威方法可行性分析概要

空间分布分析的权威方法族三层：ESRI/ArcGIS 商业体系的**专题地图（choropleth）+ 核密度（KDE）**双件套——行政区划面填充计数是产业地图的标准形态（R1）；欧盟 RIS3 区域创新记分牌的**区域创新指数**——NUTS-2 级区域聚合多指标后分级填色（R2，区级聚合的方法学参照）；我国统计体系的**区级 GDP/专利分区统计**——行政区为统计单元的官方口径（R3，与 UI 区级格同构）。方法族对照：

| 方法族 | 聚合单元 | 指标形态 | 数据要求 | 与三源匹配 |
|---|---|---|---|---|
| 专题地图计数（R1） | 行政区划面 | 单指标计数/占比 | 区划边界+区级计数 | **有（gkx area 列 9 区，边界由前端 GeoJSON 承载）** |
| 区域创新指数（R2） | NUTS-2 区 | 多指标合成分 | 区级多指标 | 部分（区级只有机构数一个强维） |
| 官方分区统计（R3） | 行政区 | 官方指标 | 统计年鉴 | 无（三源无区级统计面） |
| KDE 热力（形态学） | 坐标点 | 密度面 | 机构经纬度 | 部分（gkx org 表有 addr_lng/addr_lat，量级未探） |

结论：区级计数形态（口径 A）三源支持最完整；形态学分析（中心位置/扩散方向）需坐标面，是 v2 扩展。完整版见附录 C。

## 二、计算过程

### 2.1 方法选择

区级分布的最小可交付形态选**行政区计数 choropleth**（§1.4 方法族 R1/R3）：行政区划面由前端 GeoJSON 承载，库侧只须交付「区名→计量」键值对。领域维按 B10 双口径并列：行业分类学暂代（口径 A）+ 领域映射待裁定标注。全部计数走 gkx `dwd_org_base_info` 单表聚合（无 JOIN，确定性最优），久新小盘仅作链路对照。

### 2.2 区级聚合主查询（口径 A）

gkx 侧按 `city='深圳市' AND area IS NOT NULL AND area != ''` 过滤后 GROUP BY area：95,600 家深圳机构中 95,581 家落 9 区（`facts.gkx_sz_org_by_district`），覆盖 99.98%（`derived.gkx_sz_district_org_coverage_pct`=95,581/95,600，`facts.gkx_sz_district_covered`）。分布读数（降序）：宝安 25,192 / 龙岗 17,445 / 南山 16,039 / 龙华 13,879 / 福田 8,810 / 光明 6,879 / 罗湖 3,630 / 坪山 3,027 / 盐田 680——Top1 宝安占全市 26.35%（`derived.gkx_sz_district_org_top_share_pct`=25,192/95,600，B3 同表同口径）。

```sql
SELECT area, COUNT(*) c FROM gkx.dwd_org_base_info
WHERE city='深圳市' AND area IS NOT NULL AND area != ''
GROUP BY area ORDER BY c DESC;
-- → 宝安 25192 / 龙岗 17445 / 南山 16039 / 龙华 13879 / 福田 8810
--   / 光明 6879 / 罗湖 3630 / 坪山 3027 / 盐田 680（9 区，大鹏 0 行）
```

### 2.3 领域维下钻：区级×行业 Top

## 四、数据缺失情况

### 4.1 领域×区级交叉面缺失（语义级，主因）

需求要「各科技领域的空间分布」，UI 给了八大未来产业清单，gkx 给的是国民经济行业分类——三个分类学两两不同构。缺口不是数据行（95,064 家机构有行业标注）而是**映射规则**：批发零售业 10,427 家宝安机构里哪些算「合成生物领域」？行业分类学无法回答。两条修复路径：静态映射表（行业门类→八大领域，粗粒度有争议）或动态反推（机构×专利 IPC→技术领域→八大领域，工程量在 gkx 专利表的机构关联覆盖率）。

### 4.2 大鹏新区数据格缺失（覆盖级，次因）

UI 10 格中第 10 格（大鹏新区）双源缺：gkx 机构 area 列 0 行（大鹏机构要么未采集要么 area 归入隔壁区）、久新 DISTRICT 无键。大鹏在深圳创新版图的权重低（以生态旅游为主、坝光生物谷在建设期），但地图空格在视觉上会放大缺失。修复动作：gkx 采集侧补大鹏机构或 area 归一；或 UI 侧大鹏格标注「暂无数据」。

### 4.3 修复建议与影响面

| 建议 | 类型 | 影响指标 | 说明 |
|---|---|---|---|
| 行业→八大领域映射表 | 口径工程 | 本件+SZINNOV_012 | 甲方裁定映射规则后区级×领域面即期可出 |
| 机构×专利 IPC 反推领域 | 数据工程 | 本件 | 动态口径，精度高工程量大 |
| 大鹏数据补采 | 采集工程 | 本件 | 10 格满格 |
| 机构坐标面量级探针 | 探针工程 | 本件 v2 | addr_lng/addr_lat 覆盖率未探，热力图/中心位置形态学的前置 |

档位后果：映射裁定 → 区级×领域面上线，可升完全转换支持；仅行业口径交付 → 维持部分支持（分类学标注随行）；坐标面探得高覆盖 → 形态学分句（分布范围/中心/扩散）可跟进，不改变本件档位（choropleth 主形态已支持）。

### C.4 风险登记

| 风险 | 等级 | 缓解 |
|---|---|---|
| 行业分布被误读为领域分布 | **高** | 图层标题带分类学标注；映射裁定前不挂「八大领域」名 |

### C.5 总判

**部分支持**：区级格与区级数双在（gkx 99.98% 覆盖），领域语义（分类学映射）与大鹏格是两个待裁定项——前者是主缺口（需求原文的「各科技领域」），后者是覆盖缺口；映射裁定后可升完全转换支持。
