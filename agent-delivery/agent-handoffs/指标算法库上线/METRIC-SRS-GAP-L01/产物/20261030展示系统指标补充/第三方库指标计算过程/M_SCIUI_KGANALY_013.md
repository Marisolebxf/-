## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技知识图谱/服务展示/图分析集成/丰富的可视化图表构建（1.1.1.1.5.3.2.3；SRS seq 451、excel_row 454）。UI 实际挂载：`graphMapAnalysis.js`（src 根级共享模块）`buildGraphRegionAnalysisState`——`:67` 组装 regionIndex：`Math.min(99, Math.max(36, getRegionIndex(activeRegion, objectCount) + contextAdjustment))`，`:104-112` metrics[0] 输出（key=heat/label=区域热度/meta=选中区域「综合指数」或总体「样本热度」）；上下文调整 `:32-38`：时间 `clamp(-4,5,(year-2020)*0.7)` + 事件 +1.8。城市数据源 `data.js:314-353`：globalTechCitySamples 20 城 → sharedMapRegions detail.innovationIndex=98.4−rank×1.18。消费方为图谱地图分析页（区域判定卡），配套 sibling 指标：关系活跃度（008 已判完全转换支持）/关键实体集中度。

### 1.2 为什么需要本指标

地图是图谱空间维度的入口：用户在 20 城全球样本地图上点选城市后，需要一眼判断「这个区域的创新热度处于什么档位」——区域热度就是空间下钻的第一读数（meta 文案「综合指数」），后续才有关系活跃度（结构）与实体集中度（要素）的细分。UI 三级 fallback 的设计痕迹（优先 detail.innovationIndex → value 解析 → 列表计数折算）说明原意是「城市有真实指数最好，没有就用启发式」——数据侧补的真指数正是这个意图的承接。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**seq 451 只给能力位（「内置多种可视化方式（传统二维柱状图、折线图、饼图及高级关系网络图、桑基图），可拖拉拽自定义图表组件」），「区域热度」的字面语义（城市创新活跃度复合指数）与读数域（36-99）由 UI 代码闭合。定义侧开放点：**复合公式无定义**——UI 三级 fallback 全是造数或启发式，真口径须产品裁定（本件给口径落点，B10）。

### 1.4 类似指标权威方法可行性分析概要

区域创新指数有权威范式。其一，国际创新指数标准（R1 WIPO GII）：多支柱复合（投入/产出）+min-max 归一+几何平均；其二，中国官方区域创新评价（R2 国家统计局/科技部《中国区域科技创新评价报告》）：多指标综合指数（等权/熵权）；其三，指数编制方法学（R3 OECD Handbook on Constructing Composite Indicators）：指标选取→标准化→加权→聚合的规范流程。方法族对照：

| 方法族 | 代表 | 本库承载 | 贴合度 |
|---|---|---|---|
| 多支柱复合（R1） | WIPO GII | **久新四指标可承载**（paper/institution/talent/project） | 原料贴合、公式须自建 |
| 区域创新综合指数（R2） | 中国区域科技创新评价 | 同上 | 同上 |
| 复合指标编制（R3） | OECD Handbook | 方法论直接适用 | 本件 log1p+min-max 即简化实现 |

结论：方法成熟（OECD 流程直接可套），原料久新真数据全有——断点只在「产品未定义复合公式」，这是口径裁定问题不是数据问题。

## 二、计算过程

### 2.1 计算对象与输入

- **对象**：久新地理年度族——`ads_location`（22,229 位置词条：CITY 19,729/PROVINCE 2,252/COUNTRY 232/DISTRICT 9/CONTINENT 7）× `ads_geo_yearly_metrics`（171,736 行：CITY 132,975 行 11,284 城/PROVINCE 33,518/COUNTRY 5,081/CONTINENT 162；年份 2000-2026）。
- **实算框**：CITY 层级 2025 年、paper_count 非空城市（9,121 城），Top10 按 paper_count 取框后复合。
- **UI 复现输入**：深圳（rank15）、时间 2026/2020、事件选中/未选四种组合。

### 2.2 计算公式与关键参数

1. **UI 公式复现**：innovationIndex = round(98.4 − rank×1.18, 1)；regionIndex = clamp(36, 99, innovationIndex + clamp(-4,5,(year−2020)×0.7) + (事件?1.8:0))。
2. **本件复合口径（OECD 简化）**：四指标 m∈{paper, institution, talent, project}，$\text{heat} = 36 + 63 \cdot \bar{m}_{norm}$，其中每指标先 log1p 压偏态再框内 min-max 归一（Top10 框极值 lo/hi），四指标均值线性映射到 [36,99]（对齐 UI 读数域）。
3. **跨年注意（B9）**：2026 为不完全年（深圳 2026 论文 2,666 仅为 2025 完整年 24,904 的 10.7%）——年度比较用完整年（≤2025）。

### 2.3 计算步骤（脚本流水）

步骤：①连久新拉地理族结构与计数（位置层级/年份范围/指数面行数）→ ②UI 20 城覆盖核验（中文 name_zh IN + 国际 LOWER(name) IN，词条+2025 指标双验）→ ③CITY 2025 按 paper_count 排序拉 Top10（JOIN ads_location 取城名）→ ④逐城 log1p→min-max→均值→36-99 映射 → ⑤深圳逐年序列（2020-2026）→ ⑥UI 公式复现（rank15 两组合）→ ⑦落盘。全程只读。

### 2.6 边界与不确定性披露

- **口径落点披露（B10）**：本件复合公式（log1p+min-max+等权）是**口径落点**非产品裁定——UI 无公式，OECD 流程下的权重/标准化选择（熵权/几何平均）会改变排序细节（Top4 序可能浮动），但「北京居首、深圳 66-67 档」量级稳定。
