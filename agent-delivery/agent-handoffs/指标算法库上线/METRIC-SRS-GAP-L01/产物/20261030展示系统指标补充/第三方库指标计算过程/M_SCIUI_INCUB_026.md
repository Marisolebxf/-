## 摘要

「载体成长活跃度」是孵化载体页 KPI 五卡之一（单位分）：当前筛选载体成长指数的均值，mock 4 载体 88/81/76/73（均值 80 分）；同一 mock 字段还复用于成长排榜（降序）与详情进度条。数据侧判定：**完全不支持**——dev `ads.carrier_index` 结构面齐（`index_score`/`sub_scores`/`weight_version`——加权复合分设计意图明确）但 0 行，且评分输入维「在孵企业-载体入驻关系+运营流水」三源无表（`enterprise_*` 35 表为全市企业通用画像面非入驻流水）；gkx 0 命中；久新 218 表 live 复核 0 命中。权威参照：火炬中心孵化器评价体系孵化绩效 55% 维度（收入增长/融资/毕业等 9 项加权）。

- 需求判定：指标名三份说明书未出现；语义锚序号 543「载体势能与成长路径可视化」+主需求 :3731 运行绩效指标族。
- 复现状态：三源探针已跑通；五件 absence_probe 留证。
- 档位结论：**完全不支持**（结果面空壳+输入维无表）。
- 关键事实：`carrier_index.sub_scores`/`weight_version` 列名证明 dev 侧已按「加权复合分」设计预留——升档只差输入流水灌数。
- 升档路径：入驻关系+运营序列落库 → 评分 run 灌 `carrier_index` → 完全转换支持。

## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 创新载体孵化载体 → 总览 KPI 卡（`IncubationCarrierPage.jsx:115`「成长活跃度」＝`buildKpis()` L106-108 `Math.round(ΣgrowthIndex/items.length)` 筛选集均值，trendLabel「较上期 +5.3%」）。mock 源 `incubationCarrierMock.js` `carriers[].growthIndex`。

### 1.2 为什么需要本指标

管理者需要单一数字回答「哪些载体在把企业养大」：成长活跃度是载体孵化效能的综合温度计——序号 543 语境（动态展示载体成长潜力、创新产出、资源聚集效果，便于评估区域创新势能与孵化产业升级方向）的量化入口，也是排榜（buildRankItems growthIndex 降序）依据。

### 1.3 需求文档是否给出定义方法

三份说明书未出现该指标名（检索记录见附录 A）。**固定句式：三份说明书未给出该指标的计算方法。**（序号 543 给展示要求；主需求 :3731 列指标族「孵化企业数量、毕业率、融资金额、创新成果和专利产出等」为构成参照。）

### 1.4 类似指标权威方法可行性分析概要

载体绩效评分方法族（完整版指向附录 C）：①火炬中心《科技企业孵化器评价指标体系》（2019）——综合加权：服务能力 30%+孵化绩效 55%+可持续发展 15%，孵化绩效 9 项（收入增长 6%/获投融资占比 6%/新增在孵 6%/新增毕业 6%/研发投入占比 8%/知识产权密度 8%/科技型中小企业占比/上市并购存量/高质量就业占比）；②广西体系（2023）——孵化绩效 42% 同构细化 11 项；③工信部《科技型企业孵化器管理办法》（2025）——认定条件式（在孵 ≥30 家/毕业 ≥10%/投融资 ≥20% 等阈值）。
