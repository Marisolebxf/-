### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技政策跟踪/科创政策全景/**政策舆情评估**/区域政策差异性分析（1.1.1.1.4.2.1.3.2；SRS seq 208、excel_row 211）。UI 实现在科创政策全景页（`PolicyPanorama.jsx`）政策舆情评估区：3739 行 Card 标题「区域政策差异性分析」，内部组件 `RegionalDifferencePanel`（977 行定义，注释直接标 `Bid §…4.2.1.3.2`——前端作者按需求编号实现）。交互：多选地区（至少 2 个、至多 5 个，默认深圳/北京/上海），表格展示各地区 × 三维（coverage 覆盖范围/support 支持力度/condition 实施条件）矩阵。mock 数据 `regionalPolicyDiffMatrix` 给出各地区三维的枚举值（如 coverage: '全面'/'重点领域'，support: '高'/'中高'，condition: '宽松'/'适中'）。

值得记录的口径分岔：需求原文说「自动识别和分析各地区政策的差异点」，UI mock 把三维值做成了有序枚举（全面/重点领域、高/中高、宽松/适中）——这是**定性分级**语义；本件复现走**定量代理**（存量数/金额命中数/刚性占比），分级阈值可在定量读数上套壳（如存量 Top25% → 「全面」）。分岔不影响支持度（原料同一批），只影响展示层语义。

### 1.2 为什么需要本指标

区域政策差异是政策借鉴的起点：深圳想学北京的覆盖广度、北京想学深圳的兑现效率，前提是知道差异在哪。需求原文的三个维度各有决策含义——覆盖范围回答「管多宽」、支持力度回答「给多少」、实施条件回答「门槛多高」，三者合成一个地区的政策环境画像。对政策制定者（外国专家和科技人才处等需求来源单位），这张差异矩阵是「政策旅游」前的功课：先看差异再决定学什么。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**SRS seq 208 给出三维名（政策覆盖范围、支持力度、实施条件）但无任何计算口径——覆盖范围按政策数还是按主题广度？支持力度按资金强度还是按工具数量？实施条件按申报门槛还是按文件刚性？全部未定义。UI mock 的枚举值是前端作者的自拟展示语义。

### 1.4 类似指标权威方法可行性分析概要

区域政策比较的权威方法族有三：其一，OECD 区域政策组合分类（R1，欧洲区域创新监测 RIM 数据——按干预算份额的干预类型/目标类别/EU 资金占比做 z 变换后质心聚类，识别「标准类型」区域）；其二，OECD STIP 政策组合跨国比较（R2，政策清单×工具×主题的布尔矩阵 + 对应分析 + 层次聚类）；其三，政策文献量化（R3，共词网络/引用网络的结构差异比较）。三族的共同范式：**政策清单结构化 → 多维编码 → 标准化距离 → 聚类/矩阵**——本件复现走的是该范式的最小实现（z-score 欧氏距离替代对应分析，四地小样本无需聚类）。

| 方法族 | 代表 | 差异量化 | 与本库匹配 |
|---|---|---|---|
| 区域政策组合聚类 | Fraunhofer RIM（R1） | z 变换+质心聚类 | **最贴**（本件简化版） |
| STIP 跨国比较 | OECD（R2） | 对应分析+层次聚类 | 可算（样本更大时） |

### 1.6 推测原意与推测定义（含降档/升档触发器，B10 模板）

**推测定义**：

$$\text{Diff}(a,b) = \sqrt{\sum_{d \in \{cov, sup, cond\}} \left(z_d(a) - z_d(b)\right)^2}$$

其中 $z_d(\cdot)$ 为地区在维度 d 上的组内 z-score；三维代理：cov = 政策存量 + 部门广度 + 行业广度（合成时取存量为主维）、sup = 含金额文本政策数、cond = 刚性文件占比。差异点识别 = 距离矩阵 + 单维极差归因。

**双口径**：支持力度文本代理口径（本件，含金额文本的存在性）vs 资金强度口径（需求原意的更严读法，金额加总/财政占比）——后者受「万元」单位陷阱制约（skill B9：万元/亿元/元三种字面单位互斥混排，同字面值可差万倍），保守不做加总。**降档/升档触发器**：若甲方要求资金强度真实值 → 需金额抽取+单位校准工程（单独立项，届时本件该维换口径不改档）；若地区对比扩展到 5 地以上 → 建议升级 R2 对应分析（方法升级非档位变化）。

## 二、计算过程

### 2.1 方法选择（文献依据）

选 RIM 区域政策组合比较的 z 变换+距离范式（R1），四地小样本用欧氏距离替代聚类。依据：R1 的三变量组（干预类型份额/目标类别份额/EU 资金占比）与本件三维（覆盖/力度/条件）同构——都是「结构份额 × 资金代理」的区域画像；z 变换消除量纲差（政策存量千级 vs 部门广度十级 vs 金额命中百级），距离矩阵直接对应需求的「差异点」。R2 的对应分析留给 5+ 地区的扩展场景（§1.6 触发器）。

### 2.2 装载与对比组选取

gkx `dwd_policy_base` 20,000 行（与共享快照一致）。对比组：UI 默认组（深圳/北京/上海）+ 广东（湾区语境补全）——深圳用 city 口径单列（879 行），北上粤用 province 口径（1,932/1,842/1,612 行）。**口径披露**：深圳是市级、其余是省级，量纲差（北京 1,932 vs 深圳 879）部分来自行政层级而非政策强度本身——这个口径差是差异点的一部分（直辖市的省级行政宽度），不是数据错误，派生键 `gkx_shenzhen_vs_beijing_policy_ratio` 的 note 已写明。

### 2.3 覆盖范围维：存量+广度三层

```sql
SELECT province, COUNT(*) FROM gkx.dwd_policy_base WHERE province='北京市';  -- → 1932
SELECT COUNT(DISTINCT ministry) FROM gkx.dwd_policy_base WHERE province='广东省';  -- → 38
```

覆盖维三层读数：存量（`region_policy_counts`，北京 1,932/上海 1,842/广东 1,612/深圳 879）；发布部门广度（`region_ministry_distinct`，广东 38/北京 25/上海 25/深圳 23——广东 21 个地市分散发文把部门数推到最高）；行业广度（`region_industry_breadth`，京沪 5/5 五行业全覆盖、粤深 4/5 缺先进材料）。三层合成的覆盖画像：北京=宽存量窄部门（部委集中）、广东=中存量宽部门（地市分散）、深圳=窄存量集中发力。

### 2.4 支持力度维：金额文本代理

```python
AMOUNT = re.compile(r"[0-9][0-9,\.]*\s*(万元|亿元|元)")
# 逐行扫描 title+abstract，含具体金额的政策计数
```

四地命中（`region_amount_policy_counts`）：北京 112、广东 103、上海 74、深圳 60。占本地政策比：北京 5.80%、广东 6.38%、上海 4.02%、深圳 6.83%——深圳的金额显性率最高（政策文本更倾向写明具体数额，特区政策的数字化表达风格）。**口径边界**：这是「文本含金额表述的存在性」不是资金强度（不做加总），万元/亿元混排的单位陷阱已在 §1.6 披露。全样本对照：gkx 全库 20,000 行中含金额文本 914 行（早期探测，属宽口径；本件四地合计 349 行）。

### 2.5 实施条件维：刚性文件结构

刚性类型 = 管理办法/实施方案/指导意见/规划纲要/条例（对应行政法规类，申报门槛与执行细则的载体）；柔性 = 通知/公告/公示（信息类）。四地刚性文件数（`region_rigid_type_structure`）：北京 565（29.24%）/上海 542（29.42%）/广东 541（33.56%）/深圳 216（24.57%）。广东刚性占比最高——省级域内管理办法类文件最密集；深圳最低与其「通知公告+申报指南」的实操风格一致。实施条件画像：广东重制度供给、深圳重流程指引。

### 2.6 差异点量化：z-score 欧氏距离矩阵

三维（存量/部门广度/金额命中）z 变换后两两欧氏距离（`region_diff_zscore_euclidean`）：

| | 北京 | 上海 | 广东 | 深圳 |
|---|---|---|---|---|
| 北京 | 0 | 1.8151 | 2.3487 | 3.5602 |
| 上海 | 1.8151 | 0 | 2.6336 | 2.4442 |
| 广东 | 2.3487 | 2.6336 | 0 | 3.6883 |
| 深圳 | 3.5602 | 2.4442 | 3.6883 | 0 |

最大差异对：**广东↔深圳 3.6883**（同域内省级 vs 市级的结构互补——存量/部门/金额三维全部反向）；最小差异对：**北京↔上海 1.8151**（双城同构，部门广度同 25 家、行业全覆盖同 5/5，仅存量与金额有差）。距离矩阵的决策读法：学覆盖广度找北京、学资金显性找深圳、学制度供给找广东。

### 2.7 稳健性与口径敏感性

z-score 的组内敏感性：四地样本下 z 变换对极端值敏感（深圳 879 的低存量是三维距离的主要贡献维）——扩展到 5+ 地区时 z 基准会漂移，已写触发器建议换 R2 对应分析。行业广度的关键词口径（五行业固定词典）与 POLPAN_002 同源复算零漂移（B11）。刚性类型的五分类是政策 type 列的语义映射（管理办法等子串匹配），type 列为 'NULL' 字面值时不匹配任何刚性子串（中性缺失，不计入任何侧，两端同扣）。
