## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技人才态势/**人才引进推荐评估·学者引进难度预测**（主需求 1.1.1.1.4.3.4.2）。UI 实际容器是人才引进评估页评估 Tab 第四行 GridCol span=8 的 DataCard：标题「引进障碍与风险合规评估」，内部左右两栏——左栏 `barrierCards.map` 渲染三张障碍小卡（`{title: 沟通障碍风险, level: 中, detail: 跨语境沟通需配置双语 PM 与学术协调人}`、`{文化融合风险, 中高, 团队协作风格差异较大，建议设置 3 个月融合期}`、`{国际流动壁垒, 高, 签证与国际竞争因素显著，建议提前锁定政策包}`）；右栏 `complianceItems.map` 渲染三行合规项（学术诚信=未发现异常/active、合作合规=存在跨境条款需复核/warm、出访敏感性=中等风险/subtle）。两组常量均为**组件内写死演示文案**（`EvaluationPage.jsx:134-142`），无 mock 生成器、无 props 数据流——前端作者把这张卡整体定位为「分维占位」，等正式评分面回填。同排右侧相邻卡：策略预警（综合阻力评分求和演示）。

### 1.2 为什么需要本指标

难度预测评分（引进阻力总分）回答「多难引进」，障碍分维卡回答「难在哪、哪类风险」：沟通障碍维决定要不要配双语项目管理人员（对应需求 .2.2「预测在团队协作和学术交流中可能出现的问题」）、文化融合维决定要不要设融合期与援助方案（.2.3「为管理者提供针对性的援助方案建议」）、国际流动维决定政策包与签证节奏（.2.4「为引进流程预警潜在限制因素」）；合规三维则是对用人单位的尽调义务面——学术诚信是科研底线（R2 失信清单八类行为）、合作合规是跨境法律风险、出访敏感性是安全审查风险。分维的价值在于**风险处置动作各不相同**（配翻译/设融合期/锁政策包/补充尽调），总分无法指导处置。本件的调研重心因此是「六维逐维盘点」：每维是结构缺还是数据缺、有无代理维、修复动作是什么——这是「无业务逻辑数值类」读数卡的典型判档结构。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**三障碍子叶需求明列但只给功能行为：.2.2「运用自然语言处理技术分析专家的语言能力与沟通习惯，自动识别语言不通和交流方式差异可能带来的障碍」、.2.3「结合学者的文化背景、宗教信仰、习惯偏好及以往文化适应记录，分析其在新环境中可能面临的文化冲突与融合难度」、.2.4「挖掘学者过往出访、工作流动、国际合作项目参与等数据，评估其迁徙意愿、全球流动性和可能的地理或政策壁垒」——「分析」「评估」「识别」的行为动词在，障碍等级怎么定档（中/中高/高阈值）、合规状态怎么判定（未发现异常/需复核/中等风险）无一字。卡片名「引进障碍与风险合规评估」本身三真源 0 命中（UI 拆件）。UI 写死 level/status 为演示值，不构成口径证据。

### 1.4 类似指标权威方法可行性分析概要

障碍/合规评估的权威方法锚分四层。其一，流动壁垒清单传统：OECD 跨境劳动力流动研究（R1）系统列举工作/居留许可规则、边境与身份证件检查、税收社保差异、技能认定、语言障碍等壁垒类目，并指出各国高技能流动 schemes 的准入限制构成事实壁垒——国际流动维的类目学锚。其二，科研诚信负面清单：《科研失信行为调查处理规则》（R2，国科发监〔2022〕221 号，现行有效）定义抄袭剽窃/伪造篡改/买卖代写/违反署名规范/重复发表等八类失信行为——学术诚信维的官方判定轴（撤稿是其中买卖代写等行为的结果面）。其三，科技人才评价分类框架（R3，国科发才〔2022〕255 号）：把品德与学术道德列为评价首要内容——合规维在官方评价体系中的位置。其四，跨文化适应研究传统（Hofstede 文化维度等，作为方法论背景）：文化融合维的经典框架是文化距离测量，但依赖文化背景申报数据。方法族对照：

| 方法族 | 代表 | 判定轴 | 数据要求 | 与三源匹配 |
|---|---|---|---|---|
| 流动壁垒清单 | OECD（R1） | 签证/居留/认定/语言类目 | 出访与跨国事件面 | **部分**（跨国迁移事件在；签证/认定维无） |
| 诚信负面清单 | 失信规则（R2） | 八类失信行为 | 诚信事件/撤稿面 | **部分**（撤稿位在、实测 0；行为面无） |
| 品德首要评价 | 试点方案（R3） | 学术道德列首要 | 品德/道德事件面 | 无（同 R2 缺口） |
| 文化距离测量 | Hofstede 维度（背景） | 文化背景申报 | 文化背景/适应记录 | **无**（三源零承载） |
| 前端演示 | UI 写死六格 | — | — | 结构披露（不作源） |

结论：六维中仅流动维与诚信维有库内事件面/结果面可代理，语言/文化/条款/敏感四维权威轴的观测数据三源均无。完整版见附录 C。

## 二、计算过程

### 2.1 方法选择（文献依据）

六维逐维选法：**流动维**选事件面计数法（R1 类目学的落地版）——壁垒不是属性而是事件史（过往出访/工作流动/国际合作参与，需求 .2.4 原文即事件史口径），迁移事件表的跨国/跨省位是事件史的唯一直接承载；**诚信维**选结果面二元判定（R2 清单的结果面子集）——撤稿位是唯一可直查的诚信结果面，八类行为面（剽窃/伪造/代写）无承载不代理；**语言/文化/条款/敏感四维**无从选法（观测源零承载），按两跳止步规则记缺口不展开第三层；**合成**不选任何加权法（四缺维默认化策略须裁定，B10）。这套「有数维用事件面、有代理维用结果面、缺维留空」的组合，是读数组装卡在口径未闭合时的标准保守形态。

### 2.2 装载与流动壁垒维读数（唯一有数障碍维）

经 `_gkxdb.py` 连 gkx、直连 dev 与久新（三源串行只读）。久新实测 210 张表（探测日，`jiuxin_table_count`）。流动维承载面 `ads_talent_mobility_event` 全量读数：总事件 298,384 行、涉及去重人才 78,826 人（`jiuxin_mobility_distinct_talents`）；事件类型三分（`jiuxin_mobility_event_type_dist`，按类型名排序）：EDUCATION_TO_WORK 7,991 / RESEARCH_FIELD_CHANGE 281,117 / WORK_TO_WORK 9,276——领域转换型占 94.3%（281,117/298,384），物理流动型（求职转换 17,267）占比小；跨国事件（is_cross_country=1）8,748 行，派生键 `jiuxin_cross_country_event_share_pct=2.93`（分子分母同表同全量）；跨省事件（is_cross_province=1）12,750 行。个体级流动壁垒读数路径：按 talent_id 下钻该学者的跨国/跨省事件有无与次数——评估页个体的「国际流动壁垒=高」演示文案在数据侧的对应物即此事件史（演示定档与事件史的相关性未经校验，登记不作结论）。

```sql
SELECT COUNT(*) AS total,
       SUM(CASE WHEN is_cross_country = 1 THEN 1 ELSE 0 END) AS cross_country,
       SUM(CASE WHEN is_cross_province = 1 THEN 1 ELSE 0 END) AS cross_province
FROM ads_talent_mobility_event;
-- → 298384 / 8748 / 12750（全量非采样）
```

### 2.3 学术诚信维代理读数与覆盖面

诚信维唯一可直查承载是撤稿位：`ads_paper_profile` 全池 4,000,000 行，`is_retracted=1` 计 0（`jiuxin_retracted_papers`）——全池零撤稿。这个 0 的两面性须同时写：正面，它是 UI 右栏「学术诚信=未发现异常」演示文案的库内结果面证据（该池确实无撤稿结果）；反面，撤稿位只覆盖 R2 八类失信行为中「买卖/代写/代投论文」等行为的结果面子集——剽窃指控、数据造假指控、伦理违规等行为面在该池无承载，「零撤稿 ≠ 零诚信风险」（与 TALENTIR_005/010 件对账一致，B11）。诚信维的判定语义因此只能写成「撤稿结果面：未发现异常（池级）」，不得升格为「学术诚信：合规」。

### 2.4 过往合作底料与合作合规维缺口

需求 .2.5「过往合作情况回溯」与合规栏「合作合规（跨境条款）」的承载盘点：合作边底料 `ads_talent_collaborator` 5,051,578 行在案（`jiuxin_talent_collaborator_rows`，与共享快照零漂移）——学者×论文×机构的合作边面可支撑「合作频次/合作网络」类读数；但「与引进单位的合作史」承载表 `ads_talent_institution_cooperation` schema 标注「预留」且实测 0 行（`jiuxin_institution_cooperation_rows`）——表存在但零行的缺失情形（修复动作是数据回填工程而非建表）。「跨境条款需复核」所需的合同/协议文本面三源无任何承载（词族探针 §3.3），合作边面不能冒充条款面（合作边是事实面、条款是法律文本面，B10 不偷换）。

### 2.5 三源排除与四缺维词族探针

**久新**：210 张实测表（探测日）barrier/obstacle/friction/difficulty/compliance 词族 0 命中（`jiuxin_barrier_like_tables=[]`）；language/culture/communication 词族 0 命中（`jiuxin_language_culture_like_tables=[]`）；export/visa/sanction/security/sensitive 词族 0 命中（`jiuxin_security_like_tables=[]`）——出访敏感性维三组词族全空。**gkx**：280 表 barrier/obstacle/compliance/difficulty/visa/sanction 词族 0 命中（`gkx_barrier_compliance_like_tables=[]`；风险词族命中仍为企业失信/税务/执行表族，与 013 件读数同构）。**dev**：`gkxlumenx_*` 全 schema barrier/obstacle/compliance/difficulty 词族 0 命中（`dev_barrier_compliance_like_tables=[]`）。三源交叉结论：障碍/合规评分面与语言/文化/条款/敏感四维观测面，库级-表级-列级三层零承载。

### 2.6 稳健性与口径敏感性

流动维读数的三个敏感性：其一，事件类型偏斜——94.3% 是领域转换事件，物理流动事件（EDUCATION_TO_WORK+WORK_TO_WORK=17,267）才是流动壁垒的强相关子面，跨国占比若改用物理流动子面做分母会从 2.93% 升至约 50%（8,748/17,267）——分子分母子池选择是口径裁定点（本件按全事件面保守口径，物理子面口径登记待裁）；其二，PARTIAL_YEAR——事件面不含 2026 正式事件（schema 口径），近期流动强度被系统性低估；其三，事件置信度两档（0.7/0.9，013 件在案）——RESEARCH_FIELD_CHANGE 全 0.7 档，跨国位若集中于高置信档则读数更稳。诚信维敏感性已在 §2.3 展开（结果面≠行为面）。四缺维无敏感性可谈（无观测源），任何「国别→语言」「国别→文化」的代理都是语义偷换（国籍≠语言能力≠文化认同），登记禁止。

## 四、数据缺失情况

### 4.1 语言/文化/条款/敏感四维零承载（结构级，主因）

六维中四维的观测源在三源库级-表级-列级三层零承载：语言能力与沟通习惯（.2.2 的 NLP 分析对象）无语言面；文化背景/宗教信仰/习惯偏好/文化适应记录（.2.3 的四观测项）无文化申报面；跨境合作条款无合同文本面；出访敏感性无安全审查/出口管制/签证政策面。四缺失情形均属「表不存在」，修复只能靠外部数据源接入——且语言/文化两维与 TALENTIR_004 适应性件是同一缺口（同构不重复立项，族级登记）。国别代理被明确排除：国籍≠语言能力≠文化认同，任何国别→障碍等级的映射都是语义偷换（B10）。
