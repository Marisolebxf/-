## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技数据资源/接入视窗/历史资源接入情况（挂靠 seq 362，组件注释自标「需规 seq 360/362/363」）·动态历史趋势可视化卡「历史接入量」bar。UI 实际挂载（派单 mount 行 84，实查确认）：`AccessHistorySituation.jsx:84` series name='历史接入量' type='bar'（data=trend.accessVolume）——「本期」= 序列末端点（labels 末月「5月」，值 3360）；前置依赖位 `:96-100`（yAxis 左轴 name='接入量'）。mock 语义源 `mockData.js:1426-1429`：labels 12月→5月 六点 + accessVolume [1860, 2100, 2350, 2680, 3010, 3360]。mock 结构披露：末端点 3360 与前期 3010 的环比差 +350（`ui_mock_period_over_period_delta`）为演示叙事（爬升曲线），不作数据证据（B10）。

### 1.2 为什么需要本指标

本期接入量是接入链路的**流量主读数**：与 042（累计存量）、040（期际变化率）构成「量」的三件套——042 看家底、045 看当期流量、040 看变化速度。运营侧典型用途：月度接入例会的「本月新接入多少」、渠道供给稳定性监控（连续两期骤降即预警）。权威对应物：ETL 日志的当期批次数（Airflow dag_run 当期计数）；数据目录的当期新增资产登记数（Apache Atlas）；国信数据治理「增量归集」口径（DGB/TC260 框架）——三者原料都是逐笔/逐批接入记录。

### 1.3 需求文档是否给出定义方法

**指标名级三份真源 0 命中。**seq 362 功能句含「接入量」功能词（「动态跟踪接入量、更新成功率与异常情况的历史变化」）——功能在，但：「本期」窗定义（自然月/周/滚动窗？）、增量口径（新增记录数/新增批次/新增表？）、跨源去重规则均无定义。核增需求与算法库 0 命中（附录 A.2）。UI 的 3360 是演示常量，不构成口径证据。

### 1.4 类似指标权威方法可行性分析概要

「当期数据接入量」的权威方法锚分三层。其一，ETL 运行日志（R2，Airflow）：当期 dag_run 计数 × 批大小，或当期任务写入行数（任务的 metrics 有 ti 成功计数）——粒度到批/任务；其二，数据目录登记（R3，Apache Atlas）：当期新增实体（entity create 事件）计数——粒度到表/字段级资产；其三，数据归集规范（R1，DGB/T 2403 数据资源归集）：「增量归集」要求接入台账逐笔登记时间戳——归集规范的台账形态。方法族对照：

| 方法族 | 代表 | 原料 | 与三源匹配 |
|---|---|---|---|
| ETL 当期批次 | R2（Airflow） | dag_run/任务日志 | **无日志**（xxl 0 行，043 同锚） |
| 目录新增登记 | R3（Atlas） | entity create 事件 | 无目录面 |
| 台账增量归集 | R1（DGB 口径） | 接入台账时间戳 | **无台账**（042 词族排除） |
| 挂库月切片 | 库内可行近似 | update_time 月界 | **可算 348**（语义漂移） |
| 前端演示 | UI mock | mock 六点 | 演示常量（不作源） |

当期增量的正式口径要求逐笔/逐批接入记录带时间戳（§1.6）。三源词族零命中（042 复用）；期际序列表空（040 复用）。**四缺失情形归属「表不存在」**：修复动作是新建台账（表级：access_ts+source+batch_rows+status 逐笔登记）——与 040/042 共用触发器（一因三果：台账落地三件全升）。备选轻量路径：源表加 created_time 双列（insert-only 语义）——月界切片语义即修正。

### 4.2 「本期」窗定义缺位（口径级，前置裁定）

「本期」是自然月、周还是滚动 30 天窗？期末定格还是实时滚动？窗定义直接决定读数（月窗 348 vs 周窗约 87 均分）。需求无定义、mock 六点按月标注（暗示月窗但不构成定义）。正式口径须先行裁定：建议自然月窗（与 047「本月」对齐、与 040 期际比率分母同窗），月界即台账 GROUP BY 月档。

### 4.3 修复建议与影响面

| 建议 | 类型 | 影响指标 | 说明 |
|---|---|---|---|
| 新建接入台账（逐笔 access_ts） | 数据工程 | 本件 + 040 + 042 | 触发器①（三件套共用主线） |
| 源表 created_time 双列 | 轻量备选 | 本件 | 触发器②（insert/update 可分） |
| 「本期」窗裁定（自然月） | 口径裁定 | 本件 + 047 + 040 | 与「本月」对齐（一纸文件） |
| UI 末端点暂无数据态 | 展示规范 | 本件 | 3360 替换；348 参考位标签「挂库月切片」 |

档位后果：台账落地 → **完全直接支持**；双列修正 → **完全转换支持**；现状 → 完全不支持。推荐：窗裁定即期（一纸文件），台账随族级主线（三件套共用）。
