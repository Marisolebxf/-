### 1.4 类似指标权威方法可行性分析概要

趋势预测的方法谱系从简单到复杂：指数平滑族（Holt 1957 两参数法，R1——本件演示所用，线性趋势外推的开山方法，适合 11 点短序列）；ARIMA 族（Box-Jenkins，需更长序列与平稳性处理）；系统动力学/仿真模型（SRS seq 158 叙述的方法论——德尔菲定参+环境因素，属结构化专家系统而非统计外推）；LLM 情景估计（久新现役——DeepSeek 生成+溯源五件套，免人工审核发布）。方法族对照：

| 方法族 | 代表 | 数据要求 | 与本库匹配 |

| Holt 指数平滑（R1） | 统计外推 | 年度序列 ≥8 点 | **可跑**（12 年满铺，演示在案） |
| ARIMA | 统计外推 | 序列 ≥30 点优 | 勉强（12 点偏短） |
| 系统仿真+德尔菲（SRS 叙述） | 结构化建模 | 专家流程+参数 | 流程型，无库内承载 |

### 2.2 对象轴与语义距离

预测面对象=研究问题（problem_id，406 个），target_metric 是问题粒度的论文/专利/项目/热点分计数——与 UI「评估对象的指标预测」（机构/领域粒度）存在两级语义距离（问题≠对象、计数≠评估分）。样例五条落产物（facts `jiuxin_forecast_samples`）。这层距离是口径 B 直供的最大障碍：即便接受 LLM 方法，对象轴还需一层问题→评估对象的映射。

### 2.3 统计外推对照复现（口径 A 演示）

取 P7_003 同一演示机构（`ORDER BY SUM(paper_count) DESC, institution_id` 双键，B5），2015–2025 十一年论文序列（训练窗剔除 2026 在途年）跑 Holt 两参数外推（α=0.8、β=0.2，批内统一参数）：2026 点预测 36,683.67，95% 区间 [35,606.03, 37,761.32]（半宽 1,077.65=37,761.32−36,683.67，全宽 2,155.29）；2027/2028 外推随产物（facts `jiuxin_holt_forecast_2026_2028_demo_inst`）。残差 σ=549.82（facts `jiuxin_holt_residual_sigma_demo_inst`）。

```python
# Holt 两参数（α=0.8, β=0.2 固定，B5 确定性；R1 方法）
new_level = alpha * v + (1 - alpha) * (level + trend)
trend = beta * (new_level - level) + (1 - beta) * trend
# 2026 点预测=level+trend；区间=±1.96·σ·√h（σ=残差标准差）
```

两个派生比（B3 同基：分子分母同一演示机构同源序列）：`jiuxin_holt_2026_vs_2025_actual_pct`（外推方向读数）与 `jiuxin_holt_2026_ci_width_pct`（区间相对宽度）——后者把「区间质量」量化成可审读数，是预测类件必须并列报告的读数（skill：预测类范式只报覆盖率会高估区间质量）。

### 2.4 两口径区间形态对照

LLM 面（口径 B）：lower/upper 由情景假设派生，区间宽度与 h 的关系不受 √h 律约束（样例可核）；Holt（口径 A）：区间按 $\sqrt{h}$ 扩张，2028 半宽 1,866.54（=45,217.68−43,351.14，全宽 3,733.08）。前者宽而不规则、后者窄而有分布假设——UI 的「95% 置信区间」文案在统计口径下才有严格语义，LLM 口径下只能标「情景区间」。这一对照写死在产物 notes，供甲方选口径时判读。

## 四、数据缺失情况

### 4.1 回测流水线缺失（方法级，主因）

`backtest_error` 0/4,872——没有任何一条预测经过留出验证。统计口径（A）的闭环需要：滚动留出（如 2019–2021 作验证窗）→ 误差统计（MAPE/区间覆盖率）→ 误差回填 `backtest_error` 列。工程量=一次建模脚本+流水线任务，数据量（12 年×68,010 对象）完全够用——这是「方法缺口」而非「数据缺口」，修复动作明确。

### 4.2 对象轴映射缺失（结构级）

口径 B 直供需 problem_id→评估对象（机构/领域）的映射层，三源均无。久新问题域表族（`ads_research_problem_*`）自成体系，与机构维表无外键关联。修复=一次语义映射工程（问题关键词→领域标签→对象池），或口径 B 仅在问题域页面使用（评估页不用）。

### 4.3 修复建议与影响面

| 建议 | 类型 | 影响指标 | 说明 |
|---|---|---|---|
| 口径 A 回测立项 | 建模工程 | 本件+INNOV_008+预测族 | 滚动验证+误差回填，升档主路 |
| 口径 B 标注直供 | 产品决策 | 本件即期 | UI 标「LLM 情景估计」，限问题域 |
| 对象映射层 | 数据工程 | 口径 B 前置 | 问题→领域→对象两级映射 |

三条路径的档位后果：A 立项回测通过 → 完全转换支持；B 标注接受 → 完全转换支持（限问题域）；都拒绝 → 维持部分支持。
