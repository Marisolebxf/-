## 摘要

SRS 叶「人才分布信息查看」（seq 243，excel_row 246）要求「通过颜色深浅或热力显示不同地区的人才密度」，但分层数、阈值、密度分母全部未定义；UI 在 `DistributionInsightView.jsx:376`（着色映射）、`:378`（阈值传递）、`:381`（图例渲染）实现三级热力，mock 端用 `value/8500*100` 归一（硬编码常数）。本件以「国别人才数 + 等频三分位」实跑 gkx：**136 国**可解析学者 **8,733** 人，三分位切为 高 46 国（≥33 人）/ 中 47 国（≥4 人）/ 低 43 国（<4 人）；**高档 46 国集中了可解析人才的 92.2478%**（8,056/8,733），头部 China 1,630 人、United States 1,339 人。可复算性满分，地理覆盖面是唯一降档点。

## 一、需求定义概述

### 1.1 所属功能模块

科技人才态势 → 全球领域人才态势 → 分布洞察视图（人才分布信息查看，1.1.1.1.4.3.1，excel_rows 246–268 邻域）。

### 1.2 为什么需要本指标

全球人才争夺需要「哪里密哪里稀」的空间读数：把国家级人才存量压缩成三档热力色带，是引才目标国排序与海外布局优先级的最快决策面。密度分级把重尾分布转译成人眼可辨的三色分区，是热力地图的标准读法。

### 1.3 需求文档是否给出定义方法

**需求文档没给出完整定义方法。** SRS 叶原文只到「通过颜色深浅或热力显示不同地区的人才密度」为止：几档？阈值怎么切？「密度」以什么为分母（国土面积？人口？还是纯计数归一）？全部缺位。UI mock 用 `value/8500*100` 做归一——8500 是拍脑袋常数，不是任何统计口径。本件走推测定义路径。

### 1.4 类似指标权威方法可行性分析概要

官方统计制图对分级地图有明确方法建议：英国政府统计署《Effective maps in official statistics》建议分级数不超过 6 类、非均匀分布优先分位数法（quantiles），并警告分位数可能把差异大的值并进同档（R1）；《分级统计地图的模型评价与应用》给出分级数一般取 3–7 级、分位数/自然断点/最优分割模型族的误差比较（分位数法级内差异小，MD=1.555）（R2）；《统计地图基本技术要求》国家标准（制定中，TC230 归口，自然资源部主管）将规定统计地图数据源与分级表达要求（R3）。本件 UI 图例 3 档、计数重尾，等频三分位与官方建议一致。结论：分级方法可行，地理覆盖与密度分母是降档点。完整版见附录 C。

### 1.6 推测原意与推测定义

**推测定义**：以国家为统计单元统计学者存量（在任履历国别归并），按人才数降序等频三分：

$$\text{tier}(c)=\begin{cases}\text{高} & r(c)\le \lceil N/3\rceil\\ \text{中} & \lceil N/3\rceil < r(c)\le \lceil 2N/3\rceil\\ \text{低} & r(c)>\lceil 2N/3\rceil\end{cases}\quad (N=136)$$

实测阈值：高档下切 **33 人**（`tier_cuts.high_min`）、中档下切 **4 人**（`tier_cuts.mid_min`）。

**降档/升档触发器**：非高校机构地理编码补全后（当前可解析面几乎全部来自高校履历），按同一三分位规则重算并扩覆盖 → 视覆盖恢复程度升档；若 UI 认定自然断点法或密度分母（面积/人口底表）接入，替换分级函数即可，计数面不变。

## 二、计算过程

### 2.1 装载与国别解析

gkx 连接（`_gkxdb.py` 唯一入口）后取在任履历，`org_country_en` 非空归并 distinct 学者：**136 国**、**8,733 人**。地理可解析覆盖率 = 8,733 / 21,316 = **40.9692%**（与批 1 GLOBAL_STOCK 口径 B 同链，数字一致，快照复核通过）。

```sql
SELECT org_country_en, COUNT(DISTINCT scholar_id) AS scholars
FROM gkx.dwd_scholar_work_experience
WHERE is_current = 1
  AND org_country_en IS NOT NULL AND org_country_en <> ''
GROUP BY org_country_en
ORDER BY scholars DESC;
-- → 136 行；Top2：China 1630 / United States 1339
```

### 2.2 等频三分与阈值

136 国按人才数降序：高档 = 第 1–46 名（46 国），中档 = 第 47–92 名（47 国），低档 = 第 93–136 名（43 国）。实测档下切值：**高档边界 33 人**、**中档边界 4 人**（`tier_cuts`）——即一个国家至少 33 名可解析学者才进高档、至少 4 名进中档。并列值不跨档（排序带国名次键，确定性成立，B5）。

### 2.3 档内聚集度

高档 46 国合计 **8,056 人**（92.2478%，8,056/8,733）；中档 47 国合计 **596 人**；低档 43 国合计 **81 人**。Top10（China 1,630 / United States 1,339 / United Kingdom 735 / Brazil 356 / Australia 286 / India 269 / Spain 231 / Canada 228 / Italy 193 / Germany 184）合计即占可解析集合过半——重尾显著，与 R1「skew 数据用分位数法」的适用判断一致（等差切档会使高/低档色差不可辨）。

|---|---:|---|

### 2.5 确定性声明

全 SQL GROUP BY + Python 端排序切档，无随机、无采样；同库同数据重跑逐位一致（B5）。聚合行数 21,515 段量级，无超时风险。

- 解读：三分之一的国家（高档 46 国）装下了 92% 的可解析人才；中低档合计仅 677 人——分级地图的视觉信息几乎全部由高档内部差异决定，正式版图例若要中低档有区分度，需在低档区间内再加局部色阶（R2 分级精度讨论）。

1. **地理覆盖仅四成**：8,733 / 21,316 = 40.9692%，未覆盖学者无法进入分层，地图存在高校集中偏差——本件降档主因；建议补全非高校机构地理编码后重算（升档触发器）。
