## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 创新载体孵化载体（New 页族）→ 运行绩效与增长趋势智能监控 tab →「服务频率与资源利用统计」卡（`IncubationCarrierNewPage.jsx:1325` SectionCard extra=MockBadge）。图表构建 `serviceOption`（`:283-294`）：x=五类目（`operations.service.categories`），双 y 轴——左=场次（柱系列 `counts`，紫色 #722ED1），右=利用率% max=100（线系列 `utilization`，绿色 #00B42A）。mock 源 `mockData.js:823-827`。同 tab 五卡：在孵毕业趋势/投资融资监控/创新成果与专利产出（`:1316-1323`）/本卡/用户评价与满意度报告（`:1333`，P10_008/021）。

### 1.2 为什么需要本指标

服务频率与资源利用率是载体运营效率的双读数：频率反映服务供给强度，利用率反映资源配置效率——管理者据此做资源调度与服务优化（SRS 555 需规原文「提升资源调度与服务优化能力」）。它是绩效监控 tab 运营面的核心图（与 P10_008 满意度构成供-需两侧）。

### 1.3 需求文档是否给出定义方法

**三份说明书未给出该指标的计算方法。** SRS 555 需规原文只给功能行为（动态统计服务频率、服务资源使用率、自动生成效率分析报告），无频率口径（场次/期间）、无利用率公式（使用量÷什么总量）、无服务分类法——五类目与双序列口径均为 mock 自设。

### 1.4 类似指标权威方法可行性分析概要

权威口径方法族（完整版指向附录 C）：①科技部孵化器评价指标体系（国科发火〔2016〕···服务能力项：公共服务场次/对接活动次数——事件计数口径权威锚）；②大型仪器开放共享考核（利用率=机时/可用机时，R1 族——INCUB_008 已证库内不可落地）；③火炬统计调查制度年报（孵化服务人次/公共技术服务场地面积等采集字段）。①③需载体运营系统对接（采集面非库内计算）；②机时族已判零承载。完整版见附录 C。
