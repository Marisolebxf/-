## 摘要

「指标环比增速（较上一统计周期）」是创新载体（New）页绩效监控 Tab 投资趋势图的副轴折线：前端对宿主序列「季度投资总额」（2024Q1–2026Q2 十季，8.2→18.2 亿元）现算环比——`(v[i]−v[i−1])/v[i−1]×100`，首点 null（`IncubationCarrierNewPage.jsx:249-264`，渲染于 `:1318`）。它是**复合指标**：数值完全由宿主序列决定，自身无独立数据面。数据侧判定：**完全不支持**——依赖链传导：宿主（孵化器投资台账）三源零承载（S3-08 INCUB 族已证，本批复扫互证）；三源 80+ 比例列命中全为产业链/政策/专利/论文域异域宿主的预计算列，且 yoy 列为同比口径与本件环比不同。mock 环比九点（+17.1/+18.8/−5.3/…/+11.0）经 B7 重算核验与前端公式逐点一致——公式实现正确，但公式正确≠数据支持。任一宿主序列入湖则本件随宿主即活（环比计算零边际成本）。

- 复现状态：薄壳已跑通；依赖链裁定+mock 重算断言落产物。

## 二、计算过程

从缺（依赖链判定：宿主零承载 → 环比无从差分）。本件为二阶复合指标，计算可行性完全取决于宿主序列的承载性，逐级裁定如下。

**第一级——宿主承载性**：清单场景宿主=孵化器「季度投资总额」。孵化器运营/投资台账三源零承载：dev `dim.carrier` 28 行静态维表（university 10/incubator 10/research 8）+ `dwd.enterprise_innovation_carrier` 0 行空壳（S3-08 laneC 快照）；gkx 280 表 carrier/incub 族 0 命中；jiuxin 218 表（SHOW TABLES 实数）incub/carrier 族 0 命中。宿主序列无从聚合。

**第二级——「环比引擎」复用性**：三源比例列全库扫描——dev 60+ 列命中（chain_*/policy_*/enterprise_* 族的 growth_rate/yoy/ratio）全为产业链/政策/企业域自建 ADS 预计算列；jiuxin 21 列命中（ads_patent_analysis_* growth_rate、ads_research_problem_monthly_metrics month_growth_rate、ads_research_outcome_yearly_metric year_over_year_growth_rate 等）全为专利/论文域。这些列是**各自宿主已算好的比例结果**，既无孵化器域宿主，也不构成可对任意序列插拔的通用环比引擎；且 yoy 列为同比口径，与本件环比不同。禁伪接。

**第三级——口径层**：即便未来接入宿主，季调口径需裁定（统计局环比须 X-13 季调；UI 现公式为原始值环比）——登记为正式化时的待裁定点。
