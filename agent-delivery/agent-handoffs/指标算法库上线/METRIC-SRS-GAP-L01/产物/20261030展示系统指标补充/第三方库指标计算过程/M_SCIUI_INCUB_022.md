## 摘要

「载体成果总览报表」是软科学全局头报表配置弹窗的模块清单首项（6 项之一：总览/领域分布/机构对比/年度趋势/课题进展/转化绩效）——UI 位为 `ScienceGlobalHeader.jsx:7` label 常量，配置保存是演示态（message 自带「（演示）」字样，无持久化后端）。数据侧判定：**完全不支持**——成果报表三层依赖全缺：dev `jimu_report` 15 表是有报表**工具**无成果**数据源**（语义辨析见 notes），政策报告表 0 行；软科学课题成果主档三源无表（dev 0 行空壳、gkx 英文报告文献语义排除、久新 `ads_research_outcome_*` 20 表为科研产出评价面非课题成果）。

- 需求判定：指标名三份说明书未出现；语义锚 SRS「数据导出与报告管理」功能族（主需求 :3241 软科学七功能之一）。
- 复现状态：三源探针已跑通；五件 absence_probe 留证。
- 档位结论：**完全不支持**（数据底座+配置面双缺；UI 位非数值）。
- 关键事实：dev 报表设计器（jimu）与成果数据源是两回事——工具在库不等于报表可出，二者不能互替。
- 升档路径：课题成果主档立项落库 → jimu 接成果数据源出总览报表 → 部分支持。

## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 软科学成果展示 → 系统全局头（`ScienceGlobalHeader.jsx`，由 `AchievementPreviewApp.jsx:555` 渲染）→ 设置图标 → 报表配置弹窗（`REPORT_MODULE_OPTIONS` 6 项复选，首项「成果总览报表」key=overview）。保存回调 `onReportConfigChange` 上抛但 App 层未消费；`message.success('报表配置已保存（演示）…')` 自认演示态。

### 1.2 为什么需要本指标

管理者需要按角色定制报表模块（总览/分布/对比/趋势…），「成果总览」是报表体系的入口模块——汇总成果盘面（数量/结构/进展）供一键导出汇报（SRS 数据导出与报告管理族：定制数据导出与自定义报告生成、多部门专项报告）。

### 1.3 需求文档是否给出定义方法

三份说明书未出现该指标名（检索记录见附录 A）。**固定句式：三份说明书未给出该指标的计算方法。**（SRS 报表族仅要求「自定义导出报表，按需选择维度、格式和内容模板」。）

### 1.4 类似指标权威方法可行性分析概要
