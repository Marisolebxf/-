## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技数据资源/接入视窗·资源接入情况总览 L6 段（组件注释「KPI概览 — 需规 L6：资源接入情况总览」）。UI 实际挂载：mock 语义源 `mockData.js:1661` `accessKPIs[0] = { label: '本月接入量', value: '1,256', unit: '个', trend: 'rise', change: 15.2 }`；渲染位 `AccessWindow.jsx:355`（`accessKPIs.map` → KPICard，`Col span={4}`）；同卡并列 KPI：问题资源数 23（fall -18.3%）/待处理任务 8（fall -5%）。mock 结构披露：单位「个」暗示计数对象是资源（非笔/批次），与「接入量」的笔数语义存在二次分叉（B9）；+15.2% 环比无前期基数可验。
