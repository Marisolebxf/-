## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 科技时空演进展示。两处挂载：①**图表卡**——mock charts[1]（`spaceTimeEvolutionMock.js:637-643`，key=path-strength，title=路径强度变化，五点 32→76）；②**流向排行徽标**——`buildFlowRanking`（`SpaceTimeEvolutionPage.jsx:733-748`）输出 strength/strengthChange，排行项渲染变化徽标（`:808-810` formatSignedDelta + up/down/flat tone）；`getPathStatusLevel`（`:482-490`）以 strengthChange 符号三态（enhanced/declining/stable）参与 pathStatusValues 筛选。mock paths[].strengthChange（`:319/:360/:399`）=+12/+6/−4。

mock 值全部为演示常量（五点序列与三徽标值），不参与支持度结论。

### 1.2 为什么需要本指标

路径强度变化回答「这条链路在升温还是降温」：徽标直读环比方向与幅度，状态筛选聚焦增强型路径、盯防回落型。SRS 上位叶（科技时空演进展示）要求流动路径动态观测——变化是路径演化的时序读数。

### 1.3 需求文档是否给出定义方法

### 1.4 类似指标权威方法可行性分析概要
