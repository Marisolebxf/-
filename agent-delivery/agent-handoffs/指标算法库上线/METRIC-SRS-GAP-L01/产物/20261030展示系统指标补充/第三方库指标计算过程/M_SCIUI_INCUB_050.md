## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 科技时空演进展示。两处挂载：①**路径控制筛选**——pathLayerPanel pathStrength 组（`SpaceTimeEvolutionPage.jsx:1840`，items=pathStrengthItems 三档，toggle 链 `handlePathStrengthToggle`）作用于 mock paths 筛选（pathStrengthValues 标签：南山-宝安=high、南山-坪山/光明-南山=medium）；②**路径详情抽屉**——`buildDrawerMetrics` 路径实体分支（`:293-296`）首项「路径强度」（value=entity.score，hint=scoreUnit=强度）。mock paths（`:308-349` 等）每条含 source/target（城市对）、score/strength（96/88/82）、strengthChange（+12/+6/-4）、driverFactors 四因子、coords、badges。

mock 值全部为演示常量（96/88/82 及四因子 49-80），不参与支持度结论。

### 1.2 为什么需要本指标

路径强度回答「哪条区域协作链路最紧密」：筛选组按强度聚焦重点路径，抽屉读数辅助管理者评估跨区协同的紧密度。SRS 上位叶（科技时空演进展示）要求时空流动可视化——路径强度是流动链路的量化依据。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。**「技术路径强度」指标名未出现；INCUB 清单（row_01=605）语义注为「科技知识图谱实体与连接的规模/结构统计」——与 UI 实挂载（区域流动路径强度）语义有偏差，本件以 UI 实挂载为准；强度模型（四因子权重）无任何定义。

### 1.4 类似指标权威方法可行性分析概要

路径强度在学术体系的对应物：知识流动网络边权重（专利引用网络/合作网络强度）、技术转移指数（区域间技术交易额）、协同创新联系强度（论文合作对）。方法族对照：

| 方法族 | 数据轴 | 数据要求 | 与本库匹配 |

| 技术转移强度（交易额） | 区域对×交易额 | 技术交易流水 | **无** |
| 平台自设四因子评分（UI 现行为） | 因子加权 | 因子面+权重 | **无（mock 常量）** |

**推测定义（负结论件，仅记录语义）**：$\text{strength}_{p} = \sum_i w_i \cdot f_i(p)$，$f_i$ 为路径 $p$（区域对）的第 $i$ 因子读数（政策/产业/人才/资本），$w_i$ 为权重（UI mock 隐含四因子但未给权重；分档 high/medium/watch 阈值亦自设）。此式在本库**不可计算**（区域对因子面与权重双缺）。

### 4.1 区域对路径强度面零承载（结构级，主因）
