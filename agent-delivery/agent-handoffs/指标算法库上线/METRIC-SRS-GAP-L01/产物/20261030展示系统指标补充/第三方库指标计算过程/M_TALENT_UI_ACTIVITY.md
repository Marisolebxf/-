## 摘要

SRS 叶「个人科研活跃度与合作网络分析」（excel_row 263 邻域）要求评估科研活跃度与合作网络，未给合成公式；UI 在 `DifficultyTab.jsx:134` 把它做成引进难度预测的因子卡（进度条 mock 值）。本件以「近 5 年论文产出流」实跑 gkx：**18,351 名学者**自 2022 年起有论文（86.0903% 覆盖），窗口内论文链接 257,952 条；高产层（≥5 篇）12,097 人占活跃学者 65.9201%；含「公司」共著论文 29,475 篇占 29.2121%（产学研网络边承载，29.2% 与先验复核一致）。三档中最稳的件：口径单跳、确定性、量大、无字典依赖，可直接排期。

## 一、需求定义概述

### 1.1 所属功能模块

科技人才态势 → 人才引进推荐评估 → 难度预测面板（个人科研活跃度与合作网络分析因子位）。

### 1.2 为什么需要本指标

「人才还在不在干活」比「在不在库里」更重要：存量库会沉淀离职/退休/转行学者，活跃度把库从「通讯录」变成「雷达屏」——引进难度预测用它做负向/正向因子（活跃者议价能力强、难挖；沉睡者触达成本低），合作网络用它评估候选人可借助的产学研关系面。

### 1.3 需求文档是否给出定义方法

**需求文档没给出定义方法**（叶有名、无口径）：SRS 叶要求「评估科研活跃度与合作网络」，但活跃窗口（3 年还是 5 年？）、产出类型（论文？专利？）、合作网络的边定义（共著？同机构？）、合成权重全部缺位。UI 进度条的单一分值暗示 mock 端自行虚构了权重合成——该「模型」在两份需求真源中均无定义。本件走推测定义路径，窗口参数化见 §1.6。

### 1.4 类似指标权威方法可行性分析概要

活跃度口径在科研计量中有成熟惯例：Hirsch 的 h-index 原文即以「论文产出流」度量学者持续产出（2005, PNAS, R1）；OECD MSTI 以 R&D 人员流量监测人力投入（R2）；科技部人才报告以「活跃科技人才」分析队伍状态（R3）。窗口期文献常用 3–5 年（引文半衰期与学科节奏相关），本件取 5 年（2022–2026）保守口径。结论：口径可行且有文献背书，桥接数据完整，无需降档。完整版见附录 C。

### 1.6 推测原意与推测定义

**推测定义**：活跃学者 = 考察窗口 [2022-01-01, 2026-12-31] 内至少 1 篇论文（桥接表 `cover_date`）的 distinct 学者。

$$\text{Active}_{5y} = |\{s : \exists\, p,\ \text{rel}(s,p) \wedge \text{date}(p) \ge 2022\text{-}01\text{-}01\}|$$

- 活跃覆盖率 = Active₅y ÷ 主档总学者（21,316）；
- 高产分层：≥2 / ≥5 / ≥10 篇学者计数；
- 合著网络边：`author_info_list` 含「公司」的论文占比。

**窗口/分层触发器**：甲方若认定 3 年窗口或不同高产阈值，换常量重跑即可（脚本窗口参数化）；判档不变（完全转换支持对窗口参数不敏感）。合成总分若甲方给出权重，两代理直接加权即得（维持本档，读数可即出）。

## 二、计算过程

### 2.1 桥接表核对

`dwd_scholar_paper_relation` **1,065,385 行**（实测，与库清单零漂移）。**注意**：`dwd_scholar_papers`（论文详情表）≠ `dwd_scholar_paper_relation`（桥接表）——20261031 轮踩坑已记录（1054 错误修正过程），桥接必须走 relation 表。

```sql
SELECT COUNT(DISTINCT scholar_id), COUNT(*)
FROM gkx.dwd_scholar_paper_relation
WHERE cover_date >= '2022-01-01';
-- → 18351, 257952
```

### 2.2 活跃面与高产分层

窗口内 distinct 活跃学者 = **18,351**（≥1 篇），覆盖率 18,351/21,316 = **86.0903%**；≥2 篇 16,610 人、≥5 篇 **12,097** 人（占活跃学者 **65.9201%**）、≥10 篇 7,607 人（分层序列见产物 `facts.scholars_ge1/ge2/ge5/ge10`）。非活跃学者 = 主档 − 活跃面，占 13.9097%——库内沉淀的「沉默学者」约三千人。篇均活跃学者 257,952/18,351 = **14.0566** 篇桥接，与多学科合作强度一致（R1 产出流视角成立）。

### 2.3 合著网络边（P4.2 语料偏斜强制披露）

`dwd_zh_paper.author_info_list` 含「公司」的论文 = **29,475 / 100,900 = 29.2121%**（与 20261021 轮 29.2% 先验复核一致）。**强制披露**：合著语料医学机构占比约 36.6%，合作网络读数被医学机构主导，正式上线须分学科分层或去偏斜复算对照。（本件不做逐年拆分；author_info_list 全量解析成功 23,020 篇的先验记录见共享快照。）

### 2.4 派生比（落产物）

| 派生键 | 数值 | 分子/分母 |
|---|---:|---|
| `active5y_share_pct` | 86.0903 | 18,351 / 21,316 |

### 2.5 确定性声明

全部为确定性 SQL 聚合（COUNT DISTINCT / 分层阈值计数），无采样、无随机；107 万行量级在连接窗口内全表可聚合（无超时——与招聘表 7.98M 形成对照，量级与索引差异已记录）。重跑逐位一致（B5）。

### 2.6 复现代码结果展示

- 代码：`code/M_TALENT_UI_ACTIVITY.py`（退出码 0）。
- 结果：`facts = {scholars_with_papers_since_2022: 18351, paper_links_since_2022: 257952, scholars_ge1: 18351, scholars_ge2: 16610, scholars_ge5: 12097, scholars_ge10: 7607, scholar_total: 21316, zh_paper_rows_with_author_info: 100900, papers_with_company_coauthor: 29475}`。
- 解读：86% 活跃覆盖率说明库的时效性好于典型通讯录型存量库；三分之二活跃学者 5 年内 ≥5 篇，产出流集中度健康；29.2% 公司共著率给出产学研网络的真实边密度（注意医学偏斜披露）。UI 单一进度条分值无模型依据，正式版建议以本件分布面替换或经甲方权重确认后合成。
- **需求符合性评审**：SRS 叶有名（named_in_srs = true），「活跃度 + 合作网络」双语义本件双代理覆盖；未满足点：合成总分无权重口径（需求未给），交付分布面等待权重输入。
