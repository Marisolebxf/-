## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 创新载体孵化载体 → 成长阶段（growth stage）。挂载链：mock `growthTrend`（`incubationCarrierMock.js:505-511`，六点 { month, enterprises, projects }）→ `buildGrowthOption`（双线折线）→ `SoftChartFrame title="载体成长趋势"`（`IncubationCarrierPage.jsx:555-566`，metric 头值=activeCarrier.growthIndex）。growthIndex（mock carriers 88/81/76/73）另挂：排行 `buildRankItems`（`:119-129` score=growthIndex 降序）、摘要 `buildSummaryMetrics`（`:255` 成长指数·综合评分）、详情进度条（`:1265`）。
