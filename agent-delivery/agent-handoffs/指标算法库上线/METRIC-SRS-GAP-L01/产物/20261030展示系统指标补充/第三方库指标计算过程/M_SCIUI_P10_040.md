## 摘要

「仪器开放共享率」是大型科学仪器共享（New）页平台概览 KPI 行第三张卡：label 共享率 / value 60.59% / unit %，lineage 自带完整口径链（公式 5,612÷9,262、源表 ads_is_share_rate、源系统深圳市大型科学仪器共享平台、T+1、v1.0）。数据侧判定：**完全不支持**——口径 v1.0 指定的源表族（ads_is_*）在久新 218 表零实存（派单「jiuxin 直查优先；若实存且数据足判完全直接/转换支持」的前件不成立）；dev 542 表与 gkx 280 表的仪器台账/开放标志词族同样零命中。分子（开放共享 5,612 台套）与分母（入网 9,262 台套）均来自深圳市大型科学仪器共享平台（外部系统），三源无镜像。60.59% 本身是主需求文档 3565 行的背景快照数（截止 2020 年 12 月底，依据深科技创新〔2017〕117 号：财政资金≥30% 且单台套原值≥30 万元须入网开放）。

- 需求判定：指标名三份说明书未出现；需规 3565 行背景口径段 + SRS :75「系统自动统计共享率及使用频率」上位覆盖。
- 复现状态：薄壳已跑通；三源 ads_is* 断言落产物。
- 档位结论：**完全不支持**（指定源表不存在，公式分子分母零承载）。
- 关键事实：jiuxin 218 表无 ads_is* 前缀表；60.59% 为需规 2020-12 底快照非库值。
- 升档路径：接入深圳市大型科学仪器共享平台 ADS 表 → 完全直接支持（一表即活）。

## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技成果展示/大型科学仪器共享（New）/平台概览 KPI 行（`InstrumentSharingNewPage.jsx:883-892` KPIS.map → KpiTile 五连卡：入网仪器 9,262 台套/开放共享 5,612 台套/共享率 60.59%/有效订单 1,336 个/服务机构 499 家）。mock 数据源 `mockData.js` 头部 PLATFORM_PROFILE 常量（`:14` shareRate=60.59）与 KPIS 数组（`:36-45` 第三卡 key=shareRate，`:44` lineage 全文）。mock 头注释（`:4-5`）自述「背景口径（需规原文）：……共享率 60.59%……全部数据为演示 Mock，正式环境由 Java REST /metrics/v1/catalog + ADS 标准表供给」——UI 侧已把 ADS 表名写进口径契约。

### 1.2 为什么需要本指标

共享率是仪器共享专题的头部读数：开放共享台套数占入网总量的比例，度量深圳大型仪器「入网之后开放了多少」。政策依据链完整：国发〔2014〕70 号（向社会开放意见）→ 深科技创新〔2017〕117 号（≥30% 财政资金且单台套≥30 万元须入网开放）→ 需规 3565 行以 60.59% 作为建设背景基线。管理者以该值对标国家网络管理平台开放率考核（科技部评价考核实施细则含开放率指标）。

### 1.3 需求文档是否给出定义方法

**需求文档给出背景口径数但未给计算方法条款。**主需求 3565 行给出「开放共享仪器 5612 台套，共享率 60.59%」背景数与入网口径依据（117 号文），SRS 大型科学仪器共享.md:75「系统自动统计共享率及使用频率」为功能要求——但公式、分子分母表、统计时点均未在需规条款化；公式定义实际由 UI mock lineage（口径 v1.0）补全。

### 1.4 类似指标权威方法可行性分析概要

权威口径方法族（完整版指向附录 C）：①科技部《国家重大科研基础设施和大型科研仪器开放共享评价考核实施细则》（R1）：开放率=对外提供共享服务机组数/全部机组数——**分子分母均需机组级台账**；②深科技创新〔2017〕117 号（R2，本 UI 口径的政策源）：入网（财政≥30%、单台套≥30 万元）+开放共享状态标志；③国发〔2014〕70 号（R3）：50 万元以上国家网络平台口径。三族方法一致依赖「入网台账+开放状态列」——正是三源缺失的结构。
