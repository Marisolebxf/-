### 1.2 为什么需要本指标

单期榜单回答「谁在前面」，历史序列回答「谁在上来」——排名变化趋势是竞争力动态的直觉语言（SRS 原文「分析其发展趋势和竞争力变化」）。对用户，一条十二年名次曲线比十二张年度榜单的信息密度高一个量级；对运营方，历史面也是榜单公信力的证据链（名次波动可回溯到指标波动）。seq 174 把它列为排行榜族独立叶，与 seq 171 综合排名的「系统提供排名变化趋势，显示与上一期相比的上升或下降情况」前后呼应——单期榜+历史曲线构成完整的排名叙事。

**需求文档给出了功能行为但没给计算口径。** seq 174 原文定义了展示物（历史变化情况）、交互（查看特定成果不同时间点排名）、输出形态（排名变化曲线图）——但「排名按什么指标算」「历史期数多长」「同期口径如何对齐」均无定义。mock 的四期序列与 `previousRank` 单期对比是前端作者的演示实现。检索记录见附录 A。

## 二、计算过程

### 2.1 装载与面板完整性校验

pymysql 直连久新只读库。承载面 `ads_institution_yearly_metrics`：816,120 行、版本 2026-09-18×institution_mvp_core_4m_v1 全表单版本（facts `jiuxin_inst_yearly_version`，与共享探针 B4 一致）；年分布 2015-2026 每年恰好 68,010 行（facts `jiuxin_inst_yearly_year_dist` 十二年全枚举）；同机构同年重复对 0（facts `jiuxin_inst_yearly_dupe_pairs`）——完全平衡面板，无缺口年、无重复行，这是逐年重算名次的结构前提（不平衡面板的名次跨年不可比）。

### 2.2 现成历史面排除

power 榜单多期检查：`GROUP BY metrics_as_of_date, metric_definition_version` 仅一组（2026-09-18×institution_technology_power_mvp_v1×64,698，facts `jiuxin_power_snapshots`）——现成名次只有一期，历史面不存在；dev `enterprise_ranking` 0 行（黑名单）；gkx 无 rank 表（absence_probe）。三源排除后，转换路径成为唯一即期解。

### 2.3 固定池逐年重算（核心复现）

池构造：2026 年 cited_by_count Top10 机构（跨期固定，池漂移控制）；逐年名次：对池内每机构，在每年全量行（68,010 家）上按 `RANK() OVER (PARTITION BY statistics_year ORDER BY cited_by_count DESC)` 取名次（Doris 窗口函数，全池重算保证名次语义是「当年全库第几」而非「池内第几」）。结果（facts `jiuxin_top10_cited_rank_series_2015_2026`，十机构×十二年全落产物）：榜首机构 ins_782f0676…（哈佛体系）2015-2026 名次恒为 1（被引 435,559→551,199→239 的量程内波动，名次稳态）——十二年全在榜证明面板跨期可用；序列同时暴露口径痕迹：2025（119,832）→2026（239）的被引量骤降是统计窗切换（累计窗→当年窗）的形态，解读时须按「同列同期可比」原则联读，产物 notes 已披露。

```sql
SELECT institution_id, statistics_year,
       RANK() OVER (PARTITION BY statistics_year ORDER BY cited_by_count DESC) rk
FROM ads_institution_yearly_metrics
WHERE institution_id IN (/* 2026 被引 Top10 池 */);
-- → 十机构×十二年名次矩阵（facts 全落）
```

### 2.4 一期名次变化（UI trend 语义映射）

2025→2026 名次差 `delta = rank_prev − rank_curr`（正=上升）：最大升幅 ins_0c8c2536…（第 10→第 2，+8）；降幅最大 ins_feda47a1…（第 2→第 6，−4）；Top10 池内上升 2 家/持平 4 家/下降 4 家（facts `jiuxin_top10_rank_change_2025_to_2026` 全枚举）。这组读数直接对应 UI 抽屉头部「排行变化 ↑N 名」与榜单行 trend 箭头——mock 的 trendValue 百分比手写值被真实名次差替代。

### 2.5 稳健性与口径敏感性

单指标（被引）名次的敏感性：与 paper_count 名次、四维加权名次必然有差异——头部机构通常多指标同强（序列形态稳），中段机构名次对指标选择敏感（一期变化表中 ±8 名的波动部分来自单指标极差放大）。综合口径（B）的名次历史建议在权重闭合后以同面板复算，并建议同时披露指标构成（何榜之名次）。面板的跨期一致性由单版本背书（全表一个 metric_definition_version，无中途换版），这是十二年序列内部可比的版本证据。
