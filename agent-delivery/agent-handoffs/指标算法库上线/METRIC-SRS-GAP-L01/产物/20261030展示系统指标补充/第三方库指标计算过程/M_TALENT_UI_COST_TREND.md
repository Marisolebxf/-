## 摘要

SRS 叶「历史成本趋势追踪」（人才引进推荐评估页，excel_row 266 邻域）要求展示历年引进成本变化趋势，未给口径与数据源；UI 在 `CostTab.jsx:528/:531` 用双折线（趋势线 + 市场热度线）呈现，数据为组件内 mock 常量。本件实跑：`dwd_org_recruit_info`（7,981,643 行）非索引全表按年分组会超时（absence_probe 登记），按既定协议采 50,000 行，年度分布为 **2022: 11,235 → 2023: 9,274 → 2024: 10,081 → 2025: 12,904 → 2026: 6,506**，2025→2026 同比 **−49.5815%**（2026 为部分年）。结论：时间轴与活跃度代理线可复算，金额纵轴无承载——正式版可交付「引才活跃度趋势」但不得冒名成本趋势。

## 一、需求定义概述

### 1.1 所属功能模块

科技人才态势 → 人才引进推荐评估 → 成本 Tab（历史成本趋势追踪；与个性化成本分布分析同页，DIST 件姊妹位）。

### 1.2 为什么需要本指标

引才预算逐年滚动：只看截面不知道市场价走势，趋势线回答「引进成本在涨还是在跌」，直接影响来年预算增速与补贴档位调整。UI 配了双折线（成本线 + 市场热度线），说明设计意图本身就包含「市场面代理」。

### 1.3 需求文档是否给出定义方法

**需求文档没给出定义方法**（叶有名、无口径）：SRS 叶要求「展示历年引进成本变化趋势」，但成本数值源（政策档位？市场薪酬？财政决算？）、统计窗口、名义值/实际值全部缺位。UI 的第二条「市场热度线」倒是给了一个可落地的代理方向——本件正是把它落实为岗位发布量年度分布。

### 1.4 类似指标权威方法可行性分析概要

薪酬趋势官方口径成熟：国家统计局分岗位工资数据（城镇单位就业人员平均工资，按行业与岗位类别年度发布，R1）；OECD MSTI 的 R&D 人员经费时间序列（R2）；人社部工资价位与企业薪酬调查制度（R3）。趋势方法论（同比/定基/平减）均为标准统计操作。结论：方法充分、金额数据缺失——时间维可用发布量活跃度验证，金额维待承载。完整版见附录 C。

## 二、计算过程

### 2.1 探测对象与量级

`gkx.dwd_org_recruit_info` 7,981,643 行；时间列 `release_date`。**全表非索引按年分组在连接窗口内超时**（pymysql InterfaceError(0,'')，absence_probe 登记）——7.98M 行量级 + 无索引是原因，属数据量事实。

### 2.2 采样协议（既定）

按 20261021 轮对大表的既定协议采 **LIMIT 50000** 行。采样随机性仅用于代表全量；采样完成后所有统计为确定性聚合。年份集合 = 采样年份并集（2022–2026），**非全量年份枚举**——base_years_note 已披露，全量分组因无索引未取证。

```sql
SELECT YEAR(release_date) AS yr, COUNT(*) AS cnt
FROM (
  SELECT release_date FROM gkx.dwd_org_recruit_info
  ORDER BY RAND() LIMIT 50000
) t
WHERE release_date IS NOT NULL
GROUP BY yr ORDER BY yr;
```

### 2.3 采样结果（年度岗位发布量）

| 年 | 采样岗位数 | 占采样比 |
|---|---:|---:|
| 2022 | 11,235 | 22.47% |
| 2023 | 9,274 | 18.55% |
| 2024 | 10,081 | 20.16% |
| 2025 | 12,904 | 25.81% |
| 2026 | 6,506 | 13.01% |

2026 为部分年（数据截至采集日），读数偏低属口径因素，已披露。

### 2.4 派生比（落产物）

| 派生键 | 数值 | 分子/分母 |
|---|---:|---|
| `release_yoy_growth_pct` | −49.5815 | (6,506−12,904)/12,904（2025→2026 同比；分子 −6,398，部分年效应） |
| `latest_year_share_pct` | 13.012 | 6,506 / 50,000 |

### 2.5 确定性声明

SQL 端 GROUP BY 与派生算术确定性；`ORDER BY RAND()` 仅作用于抽样环节（§2.2 已声明并落产物 base_years_note）。重跑时采样可能有微差，属抽样件允许差异；统计面（占比、同比）由样本唯一决定。

### 2.6 复现代码结果展示

- 代码：`code/M_TALENT_UI_COST_TREND.py`（退出码 0）。
- 结果：`facts = {org_recruit_info_rows: 7981643, release_year_dist_sample50k: {2022: 11235, 2023: 9274, 2024: 10081, 2025: 12904, 2026: 6506}, release_sample_rows: 50000}`。
- 解读：活跃度代理线五年走势先降后升再回落（2026 部分年），说明**时间维可支撑趋势图**；金额纵轴（UI 的「万元」刻度）无承载——若 UI 保留「成本」名义而喂活跃度数据，属指标造假，本件明确禁止并给出正名方案（v1 活跃度线正名上线）。
- **需求符合性评审**：SRS 叶有名（named_in_srs = true），功能意图明确；金额线「需求有叶、实现无路」；市场热度线（UI 第二条折线）与本件代理线同构，可先落地该条。
