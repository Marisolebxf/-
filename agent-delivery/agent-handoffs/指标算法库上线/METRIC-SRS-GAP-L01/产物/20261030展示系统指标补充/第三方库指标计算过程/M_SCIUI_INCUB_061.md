## 一、需求定义概述

### 1.1 所属功能模块

科技信息展示系统 → 科技成果展示 → 大型科学仪器共享。两处挂载语义：①**分析筛选器**——mock `analysisGroups[0].filters[0]` 能力标签多选（`instrumentSharingMock.js:70`：high-resolution=高分辨检测/fast-report=快速出报告/cross-agency=跨机构共享），页面 `CAPABILITY_LABELS`（`InstrumentSharingPage.jsx:107-111`）渲染标签并参与 `capabilityValues` 过滤链（`:144/154`）；②**服务订单流**——mock `serviceOrders`（`:358` 起）每单含 serviceItem（高分辨形貌观察/代谢组学分析等 8 项）+ 状态流转。清单「高分辨检测」取自标签名，指标含义「高分辨检测服务量（次）」= 标签×订单交叉计数。

mock 值全部为演示常量，不参与支持度结论。

### 1.2 为什么需要本指标

检测服务量回答「这台/这类仪器对外做了多少检测」：管理者看检测服务的品类结构（高分辨/热分析/理化分列——同族三件），创业者按检测能力找仪器。SRS 上位功能（服务内容与能力明细）要求展示机构的服务能力——服务量是能力的运营验证读数。
