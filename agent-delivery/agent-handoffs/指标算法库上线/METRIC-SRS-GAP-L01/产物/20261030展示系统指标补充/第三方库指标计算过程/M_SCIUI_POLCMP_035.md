## 摘要

「绿色产业占比」是政策效果推演·多维度效果评估「环境」维的分项评分件（UI score 74 演示值）：名称本体指向占比口径（绿色低碳产业增加值占 GDP 比重的国家统计局口径，R1/R2），分子侧需要「绿色产业」判定维——按《节能环保清洁产业统计分类（2021）》在国民经济行业分类中划定绿色子集。该判定维三源零承载：gkx 两大产业分类载体（`dwd_org_industry_tags` 3,852 组合标签全量正则扫 + `dwd_org_base_info` 一级行业 20 类）均无绿色维度词（标签口径是深圳 20 大战新产业集群，绿色不在其中）；280 表扫语义甄别后 0 张绿色表；dev 政策族 38 表无环境评估落位（`policy_effect_eval` 0 行）；久新表列双扫甄别后 0 张（无一张 `ads_carbon_*`/`ads_green_*` 表）。分母侧（区域 GDP/全域产值）同样零承载。政策文本叙述面（「绿色产业」68 行）是贯彻/规划语境非产业数据。判**完全不支持**。UI 槽位的 score 74 是 0-100 分制评分，与官方占比口径（%）量纲不同、无换算锚——本件按占比语义（名称本体）调研，评分口径视为 UI 演示形态。升档路径：接入国家统计局绿色产业分类映射表（行业代码→绿色子集标志）+ 产业产值/GDP 序列 → 分子分母闭合。

- 需求判定：三份需求真源无该指标名；主需求 1.1.1.1.4.2.3.1.4 多维度效果评估「从经济、社会、环境、创新等多个维度」是维度语义源（环境维）。
- 复现状态：负结论件无可算值；三源探针读数（分类载体全量扫/表扫/列扫/文本面）落产物。
- 档位结论：**完全不支持**（判定维+产值面双缺，分子分母双断）。
- 关键事实：两大产业分类载体全量实测无绿色维度——`dwd_org_industry_tags` 是深圳战新集群口径（区域+产业域双窄），绿色产业分类目录在其设计之外。
- 升档路径：国家统计局分类映射表（R1）+ 产值/GDP 序列 → 分子分母闭合，升完全转换支持。

## 一、需求定义概述

### 1.1 所属功能模块

智能服务集群/科技信息展示系统/科技政策跟踪/**政策效果推演**·效果预估·多维度效果评估·环境维分项。UI 实际容器是 `policyData.js:1839` 起的 `multiDimensionEvalData`：四维指标组（经济/社会/环境/创新，`dimensions` 数组），环境维（`:1863` 起）三个分项——碳强度改善（70，POLCMP_034）、**绿色产业占比（74，本件）**、资源利用效率（72，POLCMP_036）。消费方 `EstimateWorkbench.jsx:627-640`（效果预估工作台「多维度效果评估」Tab）按维度分组渲染指标卡（MockBadge 标注）——每分项给 0-100 分制评分 + 环比/达标差值类辅助读数。四维框架与主需求 1.1.1.1.4.2.3.1「多维度效果评估」对齐：「从经济、社会、环境、创新等多个维度对政策效果进行评估」——本件是环境维的产业结构分项。

### 1.2 为什么需要本指标

环境维评估政策效果有三条常规读数：碳强度（排放侧）、资源效率（消耗侧）、**产业结构（绿色转型侧）**——绿色产业占比度量政策引导下经济结构向绿色低碳转型的程度：绿色产业（清洁能源/节能环保/绿色制造等）在区域经济总量中的份额上升，是「政策催绿」成效的结构性证据。放效果推演语境，它与经济维的 GDP 贡献（量）、环境维的碳强度（质）互补——占比回答「转型的结构性深度」。它的政务对应物是「绿色低碳产业增加值占 GDP 比重」（国家统计口径下的绿色经济统计序列，R1/R2）。

### 1.3 需求文档是否给出定义方法

## 四、数据缺失情况

### 4.1 绿色产业判定维缺失（结构级，分子主因）

「绿色产业」分类目录（行业代码→绿色子集标志的映射表）在三源均不存在（§3.3 四件留证）。两大现有产业分类载体的口径都不含绿色维度：组合标签是深圳战新集群口径（20 集群设计里无绿色产业集群），一级行业是国民经济门类口径（门类粒度太粗且无绿色标志列）。修复路径：接入国家统计局《节能环保清洁产业统计分类（2021）》（R1）映射表——把国民经济行业代码（GB/T 4754）映射到绿色子集标志，挂到 `dwd_org_base_info` 的行业字段上——这是**轻量数据工程**（映射表公开、挂载字段已有），判定维可建。

### 4.2 产值/GDP 序列缺失（计量级，分子分母）

判定维闭合后还需计量维：绿色产业产值/增加值序列（分子）与区域 GDP/全域产值（分母）。三源现状：gkx 财务面有企业级营收列（`operating_revenue`/`main_business_revenue`，POLCMP_041 已探）但非区域加总口径——用「绿色标签企业营收合计/全库企业营收合计」会得到**库内样本占比**（深圳战新域企业样本）而非区域经济占比；官方 GDP 序列不在库内。修复路径：接入统计部门绿色低碳产业增加值序列（R2 口径，年度公开数据）作分子分母直读——绕开库内加总的口径失真。

### 4.3 口径裁定风险（UI 评分口径 vs 占比口径）

UI 槽位 score 74 是 0-100 分制评分——mock 作者把「绿色产业占比」实现为环境维评分分项（评分形态），而指标名称本体是占比（%）口径。两口径无换算锚：74 分 ≠ 74%（评分是相对刻度，占比是份额读数）。本件按占比口径调研（名称本体优先）；若甲方确认按评分口径交付，指标语义换为「环境维评分」——需评分模型调查（权重/打分逻辑），与本件不同物，须另立件裁定（B10 双口径并列写死）。

### 4.4 修复建议与影响面

| 建议 | 类型 | 影响指标 | 说明 |
|---|---|---|---|
| 国家统计局绿色分类映射表接入 | 数据工程 | 本件 | R1 分类→行业代码映射，挂载字段已有 |
| 绿色产业增加值/GDP 序列接入 | 外部数据源 | 本件 | R2 口径年度序列（统计部门公开数据） |
| 口径裁定（评分 vs 占比） | 甲方决策 | 本件 + POLCMP_034/036（环境维族） | 评分口径另立件 |

档位后果：映射表+序列双接入 → **完全转换支持**（判定+计量闭合）；仅映射表 → 部分支持（判定维有、计量维缺——库内样本加总口径失真随行披露）；两不做 → 维持完全不支持。推荐：双接入组合（映射表轻量，序列是统计公开数据）。
