## 二、冻结口径（权重算法定，报产品留痕）

| 要素 | 口径 | 说明 |
|---|---|---|
| 窗口 | **2021–2026 近 5 年合计** | 冻结口径明确含 2026；2026 为进行中年度，页面话术按「近 5 年学术活跃度」讲，本说明如实披露 |
| 空值 | NULL → 0 | 该年无记录即无产出 |
| 归一 | 各维 `log1p` 后按**全库 99,994 人** min-max（min=0 ⇒ x/max） | log1p 压缩极端高产者（论文 max 8,933、合作者 max 7,215）；基准为全库固定值，重复请求结果稳定（幂等），不随请求子集漂移 |
| **权重** | **论文 0.5 / 项目 0.25 / 合作者 0.25** | 论文是活跃度最直接证据给 0.5；项目/合作窗内 >0 覆盖 58.5%/60.8%，权重过高会让无项目/无合作记录者被系统性压低，故各 0.25。**权重值报产品留痕，确认前以此为准** |
| 分值 | 0–100 | `0.5*paper_norm + 0.25*project_norm + 0.25*collab_norm` |
| 显式禁用 | 不用累计 `paper_count`（profile 总论文数）、h_index、被引等邻近字段顶替 | 派单红线；本口径全部分量来自近 5 年窗 |

**不做**逐年衰减加权：冻结口径为「近 5 年合计后加权」，年衰减属口径变更，待产品另行裁定。

落库分布自检（99,994 人）：min 0 / p50 33.04 / p90 49.92 / max 86.14 / avg 32.22；distinct 值 52,991（非全同值）；0 分 346 人（0.35%，三维全零的真实不活跃者，保留不插补）。

## 五、范围边界与如实披露

1. **「学术活跃度」可视化视图（热力图/时间轴）不在本单**：该视图需逐月活跃序列，本单只交付专家榜活动度单值，`visualizationViews` 仍不下发 `activity` 视图，继续空态（Java 注释已写明原因）。
2. **2026 为进行中年度**：窗内 2026 行数据不完整（冻结口径含 2026），演示话术按「近 5 年学术活跃度」讲。
3. **归一基准为全库**：分数含义是「在近 5 年窗内相对全库 10 万人才的位置」，跨请求可比、幂等；不随页面筛选（topic/城市）变化——筛选只改变展示哪些专家，不改变每人分值。
4. **权重 0.5/0.25/0.25 为算法暂定值**，报产品留痕；产品如有裁定更新 rule_version 重跑 seed 即可（幂等）。
