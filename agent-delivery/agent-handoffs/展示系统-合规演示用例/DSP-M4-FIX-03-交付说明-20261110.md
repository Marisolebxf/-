## 2、中国归类规则（验收口径③，明示）

- **CN → CN_MAINLAND**：计入「中国大陆」占比，**不计入**国际合作分子；
- **HK / MO / TW → 单列**（中国香港 / 中国澳门 / 中国台湾）：既不并入中国大陆，也**不计入**国际合作分子，以 `hmt_ratio_pct` 单独披露；
- **其余 220 码 → FOREIGN**：计入国际合作分子。
- 分子分母口径：`intl_ratio_pct = Σ paper_fractional_count(FOREIGN) / Σ paper_fractional_count(全部已解析国别) ×100`（0–100 截断）；未解析国别的论文（全局加权解析率 87.2%）不进分子分母。
