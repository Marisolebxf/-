## 一、口径（演示口径 v1，页面需常显标注）

- **8 因子中 5 个真实化**（0–100「难度贡献分」，越高越难引进）：

  | 因子 | 源（久新只读） | 公式 |
  |---|---|---|
  | activity 学术活跃度 | `ads_talent_capability_assessment.active_year_ratio` | 对 99,996 人全库百分位（沿用 11-07 现口径） |
  | mobility 流动性 | `ads_talent_experience`（country_code 列 15/15 覆盖） | `100*(1-(0.45*min(moves,8)/8 + 0.25*min(countries,4)/4 + 0.30*(1-min(tenure,20)/20)))`，moves=机构数-1、tenure=2026-max(start_year) |
  | pastCooperation 既往合作 | `ads_talent_collaborator × ads_institution_profile(country_code='CN')` | `100*(1-(0.7*min(cn_works/200,1) + 0.3*max(0,1-(2026-cn_recent)/10)))`；无 CN 合作 → 100 |
  | adaptability 适应性 | `experience(country_code='CN')` | `100*(1-(0.7*min(cn_years/15,1) + 0.3*cn_current))` |
  | policy 政策匹配 | `ads_talent_capability_assessment.best_problem_match_score`（模型 talent_problem_match_shenzhen_v1） | `100 - best_problem_match_score`（**显式代理源**） |

- **无源 3 因子**：communication / culture / family（profile 无语言/宗教/家庭列，探针实测确认）→ 出参 **显式 null** + `factorSources=NO_SOURCE`，**禁止 0 掩码**。
- **overall**：`0.25*activity + 0.20*mobility + 0.25*pastCoop + 0.15*adaptability + 0.15*policy`（仅真实因子合成，权重已归一；缺测维不参与合成 = 王慧 V2.3 规则，同 FIX-06）。
- **level**：<40 低 / <65 中等 / else 高（demo 阈值）。
- **结果表**：我方库 `demo_gkxlumenx_ai.talent_recruit_difficulty`（PK talent_id，upsert 幂等；`weight_version=v1-demo.t7-2026-11-09`；全部 ev_* 证据列随行落库）。
- **数据源覆盖实测**（探针 `probe_fix08_difficulty.py`，2026-11-09）：experience country_code 15/15、segs 2-16、机构 1-12、国家 1-5；CN 合作 cn_works 1-1387、cn_recent 2023-2026；cn_years 0-45（李亚栋 45 / 杨焕明 32 / 徐讯 27）；深圳匹配分 36.3-85.8。
