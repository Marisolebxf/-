## 一、口径（演示口径，页面需常显标注）

- **权重**：一级 **45/35/20** = 创新产出 0.45 / 创新影响 0.35 / 创新队伍 0.20，源自指标树 v2024-02（AHP+德尔菲，`cfg_tech_index_indicator`，与 DS-08 指标树页同源同版本）；**Q-TINDEX-02 未闭合，演示口径，禁称「正式科技指数」**。
- **缺测维重归一**（王慧 V2.3 规则）：久新城市粒度无专利、专利被引/转移/价值、政策环境列，该三维不参与合成，剩余维按原权重比例重归一：
  - 产出 = 论文 `0.35/0.6`×P_norm + 项目 `0.25/0.6`×J_norm（专利产出 0.40 缺测）
  - 影响 = 被引 `1.0`×C_norm（技术影响 0.45 缺测）
  - 队伍 = 人才 `0.5/0.8`×T_norm + 机构 `0.3/0.8`×I_norm（政策环境 0.20 缺测）
- **归一**：各计数在**同年全球城市池**（location_level=CITY）内极值归一至 0–100；`index = 0.45×产出 + 0.35×影响 + 0.20×队伍`；名次为同年池内排名（同分按 paper_count desc、location_id 决胜，保证幂等）。
- **数据源**：久新 Doris `ads_geo_yearly_metrics × ads_location`（只读，零改动）；2000–2026 共 27 年 × 全球城市 132,975 行全量。
- **结果表**：我方库 `demo_gkxlumenx_ai.innov_sciindex_city`（模式复用 `innov_carrier_index`：city + score + rank + stat_year + calc_batch_id；主键 `stat_year+location_id`，upsert 幂等；`weight_version=v2024-02-demo.45-35-20` 随行落库，表注释含「演示口径 Q-TINDEX-02 未闭合」）。
