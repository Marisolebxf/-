### 2.2 ⚠️ 派单探针「100% 非空」复测不成立（同样本复跑）

派单探针口径（`city LIKE '%深圳%'`）逐字段复测：

| 指标 | 派单探针（11-09） | 本次复测（11-10，同池同样本） |
|---|---|---|
| 池人数 | 512 | 512 ✅ |
| 经历段数 | 1,560 | 1,560 ✅ |
| 最近一段 position 非空率 | **100%** | **269/512 = 52.54%** ❌ |
| 任一段 position 非空率 | — | 320/512 = 62.50% |

池规模与段数完全吻合，但「最近一段 position 非空率 100%」无法复现；实际仅约半数人才最近一段有 position 自报。DS-14 dataset 池（district 层级归属）503 人同口径：有非空段 314 人（62.43%）、最近段非空 264 人（52.49%）。
