#### 需规功能描述

该功能面向基础研究问题所需的核心能力及资源保障，依托系统底层科技情报数据，对基础研究所涉及的学科/领域、科研人员应具备的品质、深圳市现有科研资源（科研机构、经费投入、管理机制）进行系统化分析。系统能够识别当前资源优势与短板，提供科研能力评估、人员素质匹配分析及资源配置现状的可视化展示。
同时，系统支持引进或创新资源需求预测，生成针对深圳市科研布局优化的资源配置建议，包括机构建设、人才引进、经费投入及管理机制优化方案。用户可按学科、机构或研究方向维度进行查询和分析，系统提供可视化报表、趋势分析及智能推荐，辅助科研管理部门、政策制定者和学术机构科学规划科研资源，为深圳市基础研究能力提升和战略决策提供数据支撑。
（1）科研资源概览面板：页面核心区域展示深圳市基础研究相关科研资源概览，包括科研机构分布、经费投入总量、管理机制类型及科研能力评分。
点击任意机构名称，系统展示该机构的科研人员数量、重点学科、历史成果及资源投入明细。
点击“经费投入”字段，可查看各学科、研究方向及机构的资金分布情况，支持对比分析。
点击科研能力评分，可查看构成指标（科研人员素质、成果产出、创新能力），辅助用户评估机构科研能力。
（2）人员能力匹配分析：展示科研人员在科研毅力、创新能力、学科匹配度、政治倾向等维度的综合评分，并与深圳市基础研究问题需求进行匹配分析。
点击人员评分维度，可查看该维度下的详细指标和评分依据。
点击“匹配分析”按钮，系统展示该人员与科研问题或机构需求的契合度，并支持导出匹配报告。
可通过学科或研究方向筛选科研人员，系统实时更新匹配结果。
（3）资源短板识别与趋势分析：模块提供当前科研资源的短板识别，包括学科覆盖不足、人才缺口、资金不足，并通过趋势图呈现资源变化情况。
点击趋势图节点，可查看对应学科或机构在不同时间段的资源投入及科研能力变化。
支持按学科或机构筛选，查看特定领域的资源优势与不足。
系统自动标注“关键短板”，帮助管理部门快速识别亟需改进的科研领域。
（4）资源配置与优化建议：根据科研资源分析与能力匹配结果，系统生成优化建议，包括机构建设、人才引进、经费投入及管理机制改进方案。
点击“优化建议”条目，展开具体实施方案、建议优先级及预期效果。
用户可切换“按学科”“按机构”“按研究方向”视图，查看不同维度下的资源优化策略。
支持导出策略报告，用于科研规划、政策决策和投资布局参考。
（5）智能推荐与动态更新：系统基于最新科研数据和趋势分析提供动态更新与智能推荐功能。
当新科研成果或机构数据更新时，系统自动标注“新”或“变动”提示，确保用户获取最新信息。
点击“智能推荐”按钮，系统推荐潜在人才、资源配置方案及科研投资方向，支持用户进行针对性决策。
支持查看推荐来源及模型依据，确保透明可追溯。
（6）可视化报表与导出：系统提供多种可视化报表，包括科研能力雷达图、资源分布热力图、人才匹配柱状图，并支持导出。
点击“导出报表”，用户可选择导出格式（PDF、Excel、图片）及报表内容（资源概览、趋势分析、优化建议）。
点击“共享链接”，生成带权限控制的访问链接，实现跨部门协作与分析共享。
