## 0. 智能体怎么检索

1. 先读本文件，定位 **系统目录**。
2. 再读该系统 `README.md`（模块/页签表 + 行数对账）。
3. 打开 `模块/四级功能.md`，用标题或 `excel_row` / `序号` 定位叶子。
4. **验收正文只认叶子里的「需规功能描述」原文**，不要回退去读 Excel，除非 coverage 对不上。

```powershell
# 按页签名搜
Select-String -Path ".\02-科技信息展示系统\**\*.md" -Pattern "全球创新监测" -Context 0,8
# 按 Excel 行号搜
Select-String -Path ".\**\*.md" -Pattern "excel_row: 128"
```

## 2. 叶子文件约定

路径：`{系统}/{三级或页签}/{四级功能}.md`

每个 Excel **数据行** 必须出现一次：

```markdown
### {六级功能名} · 序号 {A}

- excel_sheet: {表名}
- excel_row: {行号}
- seq: {A列序号}
- path: {一级}/{二级}/{三级}/{四级}/{五级}/{六级}
- bid_desc: {本行 F 或 G 招标描述；空则写「（本行空，沿用同四级上一非空）」}
- notes: {N 列}

#### 需规功能描述

{M 或 N 列原文，禁止改写、禁止摘要}
```
