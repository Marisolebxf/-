# 产品边界与交付（团队临时默认）

> **不替甲方拍板。** 下表是产品对照建议，须经产品经理评审；屏幕口径以客户决策清单为准。

权限模型（`权限点清单-菜单与按钮.md` §2.5，仅展示系统）：

| 屏 | 代号 | 取向 |
|---|---|---|
| 大屏（超大屏） | LARGE | 展示为主：只读巡览、概览、轮播；无个人定义 |
| 中屏 | MEDIUM | 功能最全：分析 / 下钻 / 推演 / 配置；无酷炫 showcase |
| 小屏 | SMALL | 中屏核心裁剪 |

大屏开放：`display` + `showcase`。不含 `personal` / `deep` / `manage`；交互仅只读巡览。

## 建议上屏包

| 候选上屏包 | 依据强度 | 大屏应呈现 | 应留在中屏 |
|---|---|---|---|
| 科技指数可视化套件 | SRS 强（168） | 总览导航、H 指数/区域/趋势/活跃度、全屏轮播、详情大屏 | 指标计算方法、权重配置、导出报告 |
| 发展规划指标墙 | SRS 强（179） | 七库指标墙、热点动态、自定义布局后的只读巡览 | 推送条件配置、布局**编辑**动作 |
| 科技全域态势地图 | SRS 中（触控适配） | GIS 多图层全要素、触控平移/复位、接待巡览 | 卡片模板库编辑、复杂搜索与图层管理 |
| 政策展示大屏 | 数据需求强 / 功能叶弱 | 政策全景概览、评价结论、推演结果只读 | 多维检索布尔逻辑、推演参数、研报生成 |
| 关注地区人才态势 | 招标有 / SRS 未写大屏 | 分布、迁徙、影响力、合作网络只读 | 引进推荐评估、敏感画像、尽调导出 |

7 大模块（态势 / 政策 / 人才 / 数据资源 / 图谱 / 成果 / 服务全景）**没有**「各做一套独立酷炫大屏」的 SRS 授权。

## 交付双轨

见 `agent-delivery/产品定义评审规程.md` §1.5、`team-members.md` §2.6。

| 轨道 | 屏幕 | 视觉 | 负责 |
|---|---|---|---|
| Track-L | 大屏 | 联通数智蓝底传统展示大屏；不适用 `Design.md` 浅蓝白 | 王亚东团队；会签 V-L |
| Track-MS | 中屏 + 小屏 | `Design.md` + Arco（D8） | 高颖 + 孔东 |

两轨共享：TRACE、metric_id（D9）、Java API、ADS / GDF。大屏 UI 不经 lumen 专题复刻链。现有前端团队不要把中屏工作台做成大屏酷炫态，也不要把 SRS 未点名的模块擅自扩成独立大屏产品。
