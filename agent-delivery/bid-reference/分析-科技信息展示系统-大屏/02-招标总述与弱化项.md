# 招标总述与「招标有、SRS 弱」项

招标原文路径：`bid-reference/科技信息展示系统和科技专题服务系统.md`（核增概述同文见政策对比核增 MD 开篇）。

## 系统概述（§1.1.1.1.1）— SRS 未拆叶

**线上**：人机互动、感知交互、智能分析与集成研讨；实时监测全球科研学者 / 科技 / 成果的布局与流动；决策产出效果动态模拟与展示。

**线下**：依托展示与服务中心的**超大屏、音频灯光、直播间**等设备设施。

**展示层三形态**：超大屏、中屏、小屏；针对内容定位、使用场景与用户需求分别建设。

**四大场景可视化应用**：

| 场景 | 面向对象 |
|---|---|
| 决策 | 政府用户 |
| 创新 | 高校科研机构和企业 |
| 智库 | 智库用户 |
| 接待 | 访问人员 |

可视化专题还要求：实时动态监测；图表 / 统计 / 趋势 / 光影动效；统计与地理联动；多级下钻；决策输入接口与推演对比。这些是总述能力，**不是**「每个二级页都做一套大屏」的授权。

服务对象原文：政府、高校、科研机构、智库、科研企业。

## 态势「驾驶舱」（招标有、SRS 无此词）

`§1.1.1.1.4.1` 科技发展态势：为政府科技管理与决策部门、科技创新主体和国际科技信息中心等用户，提供全要素全领域多场景的科技发展态势「驾驶舱」。

SRS 02 无「驾驶舱」「指挥」字样。

## 人才大屏（招标正文有、SRS 叶子未写大屏）

`§1.1.1.1.4.3.2` 关注地区人才态势：通过大屏将不同领域的人才分布、学术影响力、合作网络等核心指标直观展现，全面呈现中国科技人才发展趋势及深圳地区人才结构。

SRS `科技人才态势/关注地区人才态势.md` 叶子写中国视角 / 热力图 / 迁徙图 / 区域比较，**未再写「大屏」**。

## 政策大屏（数据需求强、功能叶弱）

SRS 序号 704 明确「单独独立规划了政策的展示大屏」。  
`科创政策全景` / `政策分析评价` / `政策效果推演` 功能叶按检索、评价、推演写，不点名大屏形态。
