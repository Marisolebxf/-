## 一、任务背景与目标

### 1.1 背景

- 高端智库系统共 **110 项功能点**，分属 4 大一级模块：战略咨询智能支持（58）、科技人才智慧服务（23）、基础研究智能决策（6）、战略咨询报告智能写作（核增 23）。
- 团队分工：**智谱 31 项**（智能问数 3 + 战略咨询报告 4 + 智能写作 23 + 战略咨询成果 1），**智树 79 项**（其余全部）。
- 智谱侧已有 netlify 原型，覆盖智能写作链路（任务配置 → 大纲 → 编辑器 → 版本/溯源 → 案例/素材/模板/发布审核），是本次原型的重要组成部分参考。
- 目标仓库 `demo-ui-gaoduanzhiku-view`（GitLab `gkx-lumen` 组）当前为全新空仓。

### 1.2 目标

在 `demo-ui-gaoduanzhiku-view` 内交付一个 **100% 合规原型**，满足：

1. **功能全覆盖**：110 项功能点逐项有原型落点（页面 / 区块 / 交互 / 弹窗 / 空态），不遗漏、不降级；
2. **双向可追溯**：每项功能可反查所在页面，每页可列出覆盖的功能序号（功能覆盖矩阵）；
3. **纯前端可演示**：单页应用 + Mock 数据，开箱即跑（`npm i && npm run dev`），无后端依赖；
4. **符合团队 UI 铁律**：Vue 3 + Vite + **Arco Design Vue**（以 `lumen-ui-topic` 为架构参考），主色 `#165DFF`、底色 `#D8E7FC`、正文 14px、控件高 32px（Design.md §4/§5/§6/§7），Mock 数据带 🧪 MockBadge、统计指标带 ⓘ MetricSpecCard（D9 数据血缘，全部用 Arco Icon 表状态）；
5. **CI 可部署**：配置 GitLab CI（**参考 `lumen-ui-topic/.gitlab-ci.yml`**：build→package→scan→deploy，Docker 镜像推 Harbor + K8s dev 部署），push dev 后 Pipeline 自动构建部署到 dev 环境。

### 5.1 技术栈（**以 lumen-ui-topic 为架构参考**，非 demo-ui-science）

> ⚠️ **重要修正（2026-08-04）**：架构参考从 `demo-ui-science`（React 栈）改为 **`lumen-ui-topic`（Vue 3 栈）**。lumen-ui-topic 为科技专题服务正式前端，其技术栈、目录约定、D9 组件契约、调用链为本原型**唯一架构基准**。

| 层 | 选型 | 说明 |
|---|---|---|
| 框架 | **Vue 3**（Composition API + `<script setup>`）+ TypeScript | 与 lumen-ui-topic 一致 |
| 构建 | Vite | `vue-tsc` 类型检查 + 构建 |
| UI | **Arco Design Vue**（`@arco-design/web-vue`） | 团队铁律（D8）；全用 Arco Icon，**禁 emoji 表状态** |
| 状态 | **Pinia** | 页面共享状态、演示数据上下文 |
| 路由 | **Vue Router** | 按导航结构组织路由 |
| HTTP | Axios → Java REST（原型阶段以 mock 直代） | 调用链对齐 lumen-ui-topic |
| 样式 | **UnoCSS + Less + Design tokens**（`--sci-*` / Arco token） | 主色 #165DFF、底色 #D8E7FC |
| 图表 | ECharts（`vue-echarts`） | 词云/趋势/排行/雷达/热力 |
| 图谱 | AntV G6 5 | 技术体系树、社会网络、合作网络、知识图谱 |
| 地图 | Leaflet（`leaflet` + `leaflet.heat`） | 人才地图、地域分布 |
| Mock | `src/mock/`（`defineApi({ mock })`）+ `src/fixtures/`（静态样例） | mock 数据文件化，评审层门控 |
| 评审 | `src/review/` 评审模式集中入口 | 上线前统一清理（见 lumen-ui-topic 约定） |
