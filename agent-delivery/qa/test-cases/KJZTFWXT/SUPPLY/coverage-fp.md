## 3. 开放项

1. **图谱交互深度未勘**：结果态现场未深勘，00149 图谱渲染（交互式画布、三类节点区分、图例、状态行）与逐层下钻（默认一级 → 三级上限、折叠、路径反馈、末级提示）全部按 v8 需规 + USM（USM-03/04/11/12）observed 验证；无下钻数据或交互不可用时记 as-built 差异，不判 Fail。
2. **中心性算法黑盒**：中心性计算（#23–#24）、断链风险识别（#25）数值正确性归算法库用例（`SDWJSF/KJZTFWSFK`）；B 线只验 UI 呈现、排序、定位与门控。`M_ENT_NODE_CENTRALITY` / `M_ENT_SUPPLY_CHAIN_RISK` D4=mock，结果数值按评审态 Mock 规则核对。
3. **末级提示两形态**：#20 的「无下一级关系」与「已达三级上限」为两种提示，需分别构造无子节点节点与三级边界节点；结果态执行时核对，形态以现场为准记 observed。
4. **失败态难构造**：#19/#22/#38/#41（图谱构建失败/节点展开失败/中心性计算失败/断链识别失败）需断链或注入异常触发，本轮 as-built 记 observed 不判 Fail。
5. **空态难构造**：#17/#32/#36/#39（图谱为空/无供应商/识别结果为空）需挑选无关系数据的企业对象；无法构造时记 observed，缺数据说明按 gap catalog 口径核对。
6. **结果态任务可达性**：00149~00152 依赖至少 1 次成功分析任务且预检可构造通过对象；若环境数据不可构造，结果态全组降级为 observed 并按开放项 1 口径处理。
7. **备份方案 as-built 收敛**：v8「用户可提前制定备份方案」收敛为「建议提前制定备份方案」提示（`DEC-RISK-BACKUP-PROMPT-20260720`），无方案实体/编辑器/制定流程，故 #34（内容非空校验）/#42（为空提示）/#43（制定中）/#44（制定失败）无 UI 载体可验，标未覆盖；#29/#30/#33 按提示口径覆盖并记 as-built 差异。如评审要求方案实体载体则升级为需求变更项。
8. **路由与 IA 口径差异**：TRACE 目标态为 `/enterprise-center/risk` 三页面级 Tab（供应链关系/发展痛难点/最近分析，USM-16），现场 as-built 为 `/enterprise/risk?workspace=supply-chain&tab=supply-chain` + 「当前分析/最近分析」双 Tab；以现场为准，目标态差异不判 Fail。
9. **供应链对象 1–2 家上限**：00145 按 USM-02 验证三家不静默截断；若现场未实现上限拦截则记 as-built 差异并升级（需求回归项）。
