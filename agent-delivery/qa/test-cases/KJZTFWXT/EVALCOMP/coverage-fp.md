## 3. 开放项

1. **维度构成 GAP 核对**（#3 关联，USM-35/36）：综合框架必须首先覆盖 Bid 的技术、市场、组织三类维度；现场 3 项为创新能力/经营能力/成长能力（产品化解释维度），组织能力未显式呈现或未标注 `GAP-METRIC-BID-06` 时，00097/00104 记 observed 并按缺口处理；算法 Bid 的企业规模、财务状况、人力资源、市场表现须映射到框架或显式 GAP，不得静默删除。
2. **框架/指标库为空提示**（#15/#16）：框架与指标库随系统模板常驻渲染，黑盒无法构造空态；如需验证须后端注入，本轮标未覆盖。
3. **失败态三件**（#17/#18/#36）：框架加载失败、指标库加载失败、计算失败需断链或构造异常触发，本轮 as-built 记 observed 不判 Fail。
4. **数据覆盖空态构造**（00104 关联，USM-07/08）：需挑选指标数据缺失的企业对象；无法构造时记 observed；覆盖度 <50% / 关键指标全缺的生成阻断属后端预检职责，本轮不判 Fail。
5. **排名表排序入口**（#27/#28）：现场未勘察到结果态排序交互；结果态执行时确认，无入口则按 as-built 记差异（USM 口径：排名按任务快照综合得分，不为明细表提供第二套排序入口）。
6. **结果空态两件**（#33/#34）：评价结果为空、暂无短板需构造特定对象/数据，无法构造时 00105 记 observed。
7. **结果态整体**（#19–#26、#29–#36 关联呈现）：分析过程页、综合得分、雷达图、排名、短板提示现场未展开，全部按 00105 observed 验证；算法数值正确性归算法库用例（`SDWJSF/KJZTFWSFK`），B 线只验 UI 呈现、门控与状态。
8. **路由口径差异**：TRACE 目标态路由为 `/enterprise-center/evaluation?mode=competitiveness`，现场 as-built 为 `/enterprise/evaluation?workspace=competitiveness&mode=competitiveness`；以现场为准，目标态差异不判 Fail。
