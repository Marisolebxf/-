2. **失败态难构造**：#15/#18/#20/#34/#37（历史数据检索失败 / 周期判断失败 / 报告生成失败 / 动态检索失败 / 预测失败）需断链或异常注入触发，本轮 as-built 记 observed 不判 Fail。
3. **空态难构造**：#6/#14/#16/#24/#33/#35（未检索到历史数据不可判断 / 各空提示）需无数据产业对象或空结果场景；无法构造时记 observed，缺数据说明按 gap catalog 口径核对。
4. **算法黑盒与 V1 服务缺口**：#5/#7/#23/#25/#26/#28/#29 数值正确性归算法库（`SDWJSF/KJZTFWSFK` §1.1.1.1.1.1.1.3.6）；B 线只验 UI 呈现、门控与过程文案。`GAP-CHAIN-DIAG-API`：正式联网检索与大语言模型服务未接通，数据与结论用固定可回放快照，可见待接通说明，禁止「已完成实时全网检索」完成态假话。`GAP-CHAIN-DIAG-METRICS`：诊断专题指标与 D1–D4 真源未建，不投影伪就绪度。
5. **空参数校验 as-built 口径**：第 1 参数行空值 placeholder「空则提交时由 ADS 预填」——v8 #3/#4/#22「未填写不可生成」在 as-built 收敛为空参数提交不阻断、由 ADS 预填；按 as-built 差异记录不判 Fail，如评审恢复强制校验则升级为需求回归项。
