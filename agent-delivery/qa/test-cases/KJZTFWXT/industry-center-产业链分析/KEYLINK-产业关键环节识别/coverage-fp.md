1. **注册因子命名与目标态差异**（#19–#22 关联）：现场演示版命名「高价值环节占比 / 战略重要性评分 / 关键环节数」（权重 34/33/33）vs USM / TRACE 注册因子「附加值率 / 技术壁垒 / 市场集中度」；根因 Q052/Q053/Q054 权重阈值正式口径未闭合（`GAP-CHAIN-DIAG-SEMANTICS`，评审态角标「指标未登记」「口径待甲方确认（开放项 Q052）」诚实呈现）；权重阈值版本「固定演示版 · 正式口径待闭合」。以现场为准不判 Fail，待口径闭合后复验命名与权重。
2. **结果态未勘察**（00210 关联）：勘察时未执行分析任务，结果态（全链路五环节图谱 / 功能边界与衔接 / 高端化指数与排序 / 关键环节分色标注 / 竞争格局 / 代表企业 / 技术趋势）全部为 USM / TRACE 目标态 observed 口径；现场无结果不判 Fail、执行时以 00210 逐项核验。
3. **过程态与提交后行为**（00206 / 00204 关联）：过程 Steps 的 Bid 原文能力词呈现、任务创建后与版本快照绑定、同对象重复提交反馈、失败不建任务保留草稿，执行时核。
4. **空态与恢复深勘**（00201 / 00207 关联）：清空分析对象的配置空态（不静默写回默认）、诊断记录列表构成与过滤细目（对象 / 诊断类型 / 状态 / 时间）、恢复结果后顶栏分析对象回显（不因对比篮为空显示「未选分析对象」），执行时核。
5. **失败与级联场景未覆盖**（#18 / #32 / #38 / #40 关联）：拆解失败提示、高端化指数计算失败提示需断链或构造异常；未标注关键环节时报告生成级联需构造无标注链场景；本轮未覆盖为能力依赖（勘察未见结果态 + 出口在 ENT-EXPORT），非遗漏，待补场景后补验。
6. **单飞与当天复用**（00206 关联）：同用户同条件只允许一条任务在跑、当天已成功直接打开结果、「重新分析」可强制重跑（`产品实现规程` 附录 E / 客户决策 Q-ANALYSIS-01 口径），执行时补核。
7. **评审零泄漏**（00208 关联）：评审增量（三个需求追溯按钮 / GAP-CHAIN-DIAG-SEMANTICS 角标 / Q052 角标 / 指标说明按钮）关闭评审模式后须零泄漏（不含 `metric_id` / `Q0xx` / `GAP-` / `Q052` 字样）且不改变业务态。
