## 3. 开放项

1. **结果态勘察缺失**（01112~01116 与 #23–#34、#37–#39 关联）：勘察现场无已成功竞争力分析记录，综合竞争力排名（柱状降序）、三维矩阵热力、（多区域）GIS、明细表联动、优势短板、版本边界、共享生成报告全链按 USM/DEC 口径写预期，执行时构造（单产业×2–5 区域 + 三维 + 权重 100% → 开始分析）核验；无法构造则该条整条 observed。GAP-CHAIN-REG-METRICS 未闭合（区域评价专题指标与 D1-D4 readiness 真源未建立），结果数据可能为 Mock/Pending 态（`v1_disposition: gap_visible`），以角标与实际呈现为准，不发明口径。
2. **异步任务过程态**（01120、01118、01119 与 #35 关联）：任务提交 → 排队 → 完成的等待与过程态呈现（含分析记录列表状态流转）、同条件单飞、当天结果复用与重新分析均执行时 observed / 构造核验。
3. **配置细节执行时核**（01107~01110 与 #7/#9/#13/#16/#22 关联）：切换产业后权重回显、选定维度后是否默认均分（勘察初始态为 0 项 0% 未自动均分）、仅选 1 区域的排名对比边界、非法字符拦截，执行时按现场 observed。
4. **失败态需构造**（#10/#11/#36–#38 关联）：权重设置失败、竞争力计算失败、报告导出失败均需断链 / 构造异常触发；本轮不出伪预期，不判 Fail。
5. **空态文案**（#17/#34 关联）：勘察空态为选择器待选 + 汇总「已计入 0 项 · 权重合计 0%」，无显式「指标体系为空 / 数据为空」文案；数据不足区域呈现需构造核。
6. **评价/对比区域 as-built 合并形态**（#19/#20 关联）：需规拆分式「评价区域 + 对比区域」两个选择器在 as-built 合并为单一「评价区域（1–5）」多选集合（集合内天然去重，USM 对象组合合同 {industries:1, regions:1-5}）；按 as-built 覆盖不判 Fail，拆分形态如后续上屏再补用例。
7. **路由参数差异**（01100 关联）：as-built 路由含 `workspace=competitiveness&tab=competitiveness` 双参数；TRACE `route_contract` 契约为 `?tab=competitiveness` 单参数。语义一致，以 as-built 为准记 observed，待路由契约收敛后回填。
