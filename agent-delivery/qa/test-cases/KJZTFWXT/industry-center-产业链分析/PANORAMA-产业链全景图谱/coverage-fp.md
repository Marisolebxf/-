## 3. 开放项

1. **数据截至口径差异**（#1 关联）：USM 目标态为可搜索时间 Select（形态对齐「查看时间」，改条件后「开始分析」）；现场 as-built 只读、placeholder「请选择数据截至」。以现场为准不判 Fail，目标态差异记录待迭代对齐。
2. **空态与清空场景**（#14/#18）：勘察为默认已选态（推荐预跑秒开）；清空产业保持空态（红字「尚未选择分析对象」，`source=cleared` 不静默写回默认）与无正式结构空态（「暂无正式结构，不生成示例链」）为 USM 目标态，执行 00545 时构造核验。
3. **失败态与过程态**（#19/#20/#42/#43/#44/#45/#46 关联）：图谱生成失败、下钻失败、更新失败需断链或构造异常；生成中 / 下钻加载中 / 更新中过程态执行时 observed；USM 口径为保留对象与容器、局部错误、可重试，本轮不判 Fail。
4. **下钻详情数据深度**（#31/#41 关联）：三分组构成与市场规模空值口径（Q056）已核；分组局部 Empty、有数据逐项核对、复合节点集合、L1 子链深度、「查看企业」抽屉（企业稳定 ID、关闭后图谱不重载）执行时按现场 observed 深勘。
5. **对比与演进深度**（00543 关联）：五类差异 Tag 颜色映射、时间轴播放 / 暂停 / 步进、变化项前后快照与证据引用为 USM 验收口径（AC-04-01/02/04/09）；勘察确认三子块与快照条目存在，深度交互执行时核；仅一个快照时状态对比场景无法构造。
6. **断点族未覆盖**（#10–#13、#21、#22 共 6 条）：现场无断点标记 / 红色虚线 / 定位交互；`GAP-CHAIN-PANORAMA-SNAPSHOT-API`（Q062 快照版本与差异 API 未闭合）+ 需规允许分阶段实现；待能力上屏后补用例补验。
7. **完整性结论未覆盖**（#11）：现场无完整性结论呈现；USM 明确本页「不包含节点/关系数量 KPI」、业务界面不出现快照或 schema 版本；如后续版本补结论呈现再补用例。
8. **Q062 口径提示**（00544 关联）：评审增量角标「口径待甲方确认（开放项 Q062），当前为团队临时默认值」为团队临时默认；关闭评审模式后须零泄漏（不含 `metric_id` / `Q0xx` / `GAP-` 字样）。
