## 3. 开放项

1. **综合分口径差异（诚实性核心）**（#9/#11 关联）：USM v1.0 口径为结果态综合分带 ⓘ（`M_SVC_REC_CULTIVATE_SCORE` D1 draft）+ ⚠️ Q-SVCCHAIN-05 + 🧪、综合分 = Σ(维度归一 × 权重)；现场 as-built 为评审态角标「指标未登记：培育综合分」（指标未入正式注册表口径），综合分由 Java rec-list 上送 score / cultivation_index，前端不按四维度权重重算排名，权重与筛选仅演示配置、不进分析指纹与任务参数。以现场为准不判 Fail（01274 按 as-built 口径写期望）；口径演进记录待迭代对齐，评审态长提示文案真源以 01281 核对（全文见用例册附录 A.5）。
2. **USM v1.0 能力未上屏**（01263~01265/01268/01275 关联）：默认权重 20/30/25/25（现场 25/30/25/20）、权重合计=100 校验（合计 ≠100 禁用生成 + 差值提示）、「按比例归一」按钮、机构类型/服务环节筛选默认全选与持久化（刷新保留）、同步加权生成、机构名下钻画像抽屉（AC-04-03，CT-SVC-ORG-02）、行内「加入对比篮/已加入」即时同步（AC-04-04，CT-SVC-ORG-03）、导出 CSV（AC-04-05）、升序切换与名单条数（#37/#39）为 USM 目标态；现场未见。执行时如现场呈现再补核；口径差异不判 Fail。
3. **异步工作区过程态与记录深度**（01271/01272/01277/01278/01279/01282 关联）：在跑 / 排队 / 失败状态呈现、分析记录列构成、当天已成功结果直接打开与「重新分析」入口为 Q-ANALYSIS-01 异步语义口径；勘察时无在跑与已完成记录，执行时逐项核；失败态（#22/#44）由 01282 承载，需构造异常触发，本轮不判 Fail。
4. **门控形态细节**（01270 关联）：未选产业集群时「开始分析」的禁用 / 提示形态、全不选目标类型 Tag 时行为（USM「全不选时生成禁用并解释」）勘察未记录；执行 01270 时以现场为准 observed。
