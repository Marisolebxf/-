## 3. 开放项

1. **结果态全条 observed**（#15/#16/#31–#43 共 15 条关联）：勘察时现场无已完成评估结果，「评估对比」结果态结构不出具具体预期；执行时经 00676 发起（对象 2~5 家、五维默认权重）或从「分析记录」打开既有结果，核排名列表 / 雷达图 / 维度明细 / 优势短板凸显 / 排序方向 / 结果空态；USM AC-06-03/04/06 口径（同一次计算结果、雷达轴随启用维度、结论区数值一致）。
2. **校验与失败态构造**（#10–#13/#19/#21/#24–#26/#28/#30/#42/#44 关联）：权重非负 / 和=100 / 维度数下限 / 对象 1 家与超上限 / 无可用维度提示的拦截形态与文案需执行时构造核（勘察为默认合法态）；计算失败（#21）/ 对比失败（#44）由 00684 承载，需断链或构造异常，USM 口径为保留配置、可重试，本轮不判 Fail 不判遗漏。
3. **Q060 / Q-SVCCHAIN-01 口径未闭合**（00674/00680/00681 关联）：六类服务机构技术力指标权重与阈值待甲方确认；当前临时基线为五维等权归一写入 `svc_tech_power_score`（页面默认权重 25/25/20/20/10 为 UI 预设，评分基线归后端签发）；门户榜与画像只展示 Java 已算好的 score，缺 dimension_scores 不发明分、禁止改绿；评审态角标语义归 00680、零泄漏归 00681，甲方确认闭合前不伪闭合。
4. **默认权重口径差异**（#18 关联）：拆分规则「默认按已纳入维度均分权重」与 as-built 预设差异化权重 25/25/20/20/10（和=100）不一致；以现场为准不判 Fail；USM「按比例归一」快捷动作现场未见，均分 / 归一能力待迭代对齐后补验。
5. **自定义维度新增入口现场未见**（#22/#23 关联）：USM US-06 主路径含「已添加的自定义维度」，勘察模型区仅内置五维、无新增自定义维度控件；本集以五维启停 + 权重自定义承载（observed），自定义维度增删待能力上屏后补用例补验。
