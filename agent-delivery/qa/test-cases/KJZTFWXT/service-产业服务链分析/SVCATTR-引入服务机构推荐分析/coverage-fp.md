## 3. 开放项

1. **综合分口径差异（诚实性核心）**（#2/#11 关联）：USM v1.0 口径为前端演示加权（综合分 = Σ(指标 × 权重)、调权重影响排序）；现场 as-built 为「综合分由 Java rec-list 上送 score / attraction_index，前端不按四指标权重重算排名，权重仅演示配置不进分析指纹与任务参数」，且角标口径待核验引用为 **Q063 / Q-SVC-010 / Q-SVCCHAIN-05**。以现场为准不判 Fail（00334 按 as-built 口径写期望）；口径演进记录待迭代对齐，评审态长提示文案真源以 00338 核对。
2. **USM v1.0 能力未上屏**（00333 关联）：权重合计=100 校验（合计 ≠100 禁用生成 + 差值提示）、「按比例归一」按钮、同步加权生成、权重配置持久化（刷新保留）为 USM 目标态；现场 as-built 为演示配置口径（权重不进任务参数）。执行 00333 时如现场呈现合计校验再补核；口径差异不判 Fail。
3. **异步工作区过程态与记录深度**（00335/00336 关联）：在跑 / 排队 / 失败状态呈现、分析记录列构成、当天已成功结果直接打开与「重新分析」入口为 Q-ANALYSIS-01 异步语义口径；勘察时无在跑与已完成记录，执行时逐项核；失败态（#20/#40/#42）需构造异常触发，本轮不判 Fail。
4. **门控形态细节**（#22/#23 关联）：未选产业集群时「开始分析」的禁用 / 提示形态、全不选目标类型 Tag 时行为勘察未记录；执行 00335 步骤 1/6 时以现场为准 observed。
5. **结果态深勘**（#16/#25–#28/#31/#33/#34/#36–#38/#41 关联）：勘察时无已生成推荐名单结果，结果区列构成、排序、条数、空态、指标明细、推荐理由引用一致性、综合分呈现方式全部执行时 observed；00334/00337 已按需求字段口径写步骤，执行时如现场列构成差异大再回补用例与矩阵。
6. **空态构造**（#17/#18/#38 关联）：模型指标为空、评估数据为空、方向无匹配机构三类空态现场均无法构造（模型区恒有四指标、无结果区）；待有数据 / 可构造环境后补验。
7. **Q063 评审增量**（00338 关联）：角标「指标说明：招引综合分」+ 长提示「招引综合分口径待核验（Q063 / Q-SVC-010 / Q-SVCCHAIN-05）。只展示 Java rec-list 上送的 score / attraction_index，禁止前端按四指标权重重算，禁止改绿」为评审态增量；关闭评审模式后须零泄漏（不含 `metric_id` / `Q0xx` / `GAP-` 字样）；四个需求追溯按钮（引入服务机构推荐分析 / 分析配置 / 招引模型权重 / 招引模型配置）同开同关。
8. **算法维度功能点黑盒口径**（#7–#10/#13/#14/#29/#30/#35 关联）：单指标评估、综合评估覆盖校验、排名计算、推荐理由生成、评估完成性校验均为算法库 / 服务侧行为，前端无可观察接口；本轮以「未覆盖（算法维度）」登记，黑盒综合分口径由 00334 承载；待结果态上屏且有指标明细后补验。
