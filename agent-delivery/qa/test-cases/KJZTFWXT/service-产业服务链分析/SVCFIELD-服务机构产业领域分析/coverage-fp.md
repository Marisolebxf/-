## 3. 开放项

1. **结果态现场无结果**（#12、#14–#16、#20–#32 关联）：勘察时页面为配置空态（未选机构），热力图/矩阵图、hover 明细、ⓘ/🧪 角标、核心结论区、机构行头下钻画像均未见。相关功能点按 USM 口径写入 00646/00647/00648 期望并标 observed；执行时选定机构并「开始分析」构造结果态后逐项核验，本轮不判 Fail。
2. **选择器与门控细节**（#4、#5、#6 关联）：「选择机构」选择器内部构成（按类型分组、关键词搜索、单类全选/清空）、「开始分析」未选机构时的禁用态/提示文案、已选机构回显形态均为 USM 口径，勘察未深勘，执行 00643/00644/00645 时核。
3. **失败态需构造**（#19、#36 → 00655）：计算失败/呈现失败提示需断链或构造异常触发；USM 口径为图表容器局部错误 +「重试」、页面壳与筛选保留，本轮不判 Fail，待构造后补验。
4. **空行与过程态**（#17、#18、#34、#35 关联）：「暂无覆盖数据」机构行（不用 0 填充、不参与 TOP 排名）需构造无服务记录机构；计算中/呈现中过程态执行时 observed。
5. **分析记录与异步深度**（#12、#31 关联 + 00650/00652）：分析记录列表构成、当天同条件复用不重跑、同用户同条件单飞、「重新分析」强制重跑（`产品实现规程.md` I2-12/附录 E、Q-ANALYSIS-01）及三兄弟 workspace（field/trend/capability）隔离保留深度，勘察未勘，执行时 observed；demo 未实现项记口径差异不判 Fail。
6. **Q-SVCCHAIN-02 深度口径**（#11 关联）：`M_SVC_ORG_COVERAGE_DEPTH` D1 draft，深度得分=领域内服务记录强度归一 0-100 为演示态临时口径（⚠️ Q-SVCCHAIN-02，算法 Lead 待定义）；UI 侧深度数字旁必有 ⓘ+🧪，评审模式点开可见口径与治理引用，关闭评审模式零泄漏（00653）。
