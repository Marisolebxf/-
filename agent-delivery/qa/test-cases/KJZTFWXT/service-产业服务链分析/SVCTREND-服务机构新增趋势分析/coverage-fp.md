## 3. 开放项

1. **领域筛选 vs 显式选择口径**（#1/#2 关联）：as-built 领域筛选为过滤输入框（placeholder「筛选领域（不改分析指纹）」）+「开始分析」显式提交，异步分析工作区语义（切条件不自动起任务，Q-ANALYSIS-01）；USM / Bid 口径为「选择特定产业领域或技术方向」。「技术方向」独立选项组现场未见（下拉仅 15 个产业集群）；以现场字典为准不判 Fail，口径差异记录待迭代对齐。
2. **异步分析语义执行时核验**（#3/#4/#12/#17 关联）：同用户同条件单飞、当天已成功直接打开结果、「重新分析」强制重跑、在跑状态提示为 Q-ANALYSIS-01 口径；勘察为配置空态，执行 00287 / 00288 时逐项核验。
3. **结果态全量 observed**（#5–#11/#13/#14/#19/#21–#22/#31/#33/#36/#38 关联）：勘察现场无已完成分析结果态；趋势图形态（折线 / 坐标轴 / hover / 明细表下钻）、对比领域曲线 ≤3、时间窗切换、研判面板与「依据」行均按 USM 口径（AC-US-SVC-ORG-04-01～05 / AC-US-SVC-ORG-05-01～05）写期望，执行时先构造一次有效分析再核验，本轮不判 Fail。
4. **选择器与画像下钻深度**（00286/00290 关联）：选择器按类型分组 / 关键词过滤 / Tag 一致性、明细表机构名下钻同一画像抽屉（AC-US-SVC-ORG-04-05）执行时 observed 深勘。
5. **兄弟 workspace 归集**（00289 关联）：field（覆盖分析）/ capability（技术力评估）内部用例归 SVCFIELD / SVCCAP 用例集，本文件只核 URL 参数、条件与结果互不串扰。
6. **空态 / 失败态需构造**（#15/#16/#18/#20/#34/#35/#37/#39 关联）：字典空态、统计失败、趋势图生成失败、特征分析失败、研判判断失败需断链或构造异常触发；诚实空态（无新增 0 线标注 / 数据长度不足 / 曲线全 0）为 USM 口径，执行时构造核验，本轮不判 Fail，未覆盖 5 条均因需构造（#15/#18/#20/#37/#39），非遗漏。
7. **Q-SVCCHAIN-02 口径与评审零泄漏**（00292/00293/00294 关联）：市场热度评级判读算法未定义（`M_SVC_ORG_MARKET_HEAT` D1 missing）；评审模式点开只显治理引用不显伪 8 件套；业务模式（ReviewMode 关）下研判面板保留「演示口径」用户可读声明且无 `metric_id` / `Q-` / `GAP-` 内部字样泄漏（AC-US-SVC-ORG-05-01/05-05）。
