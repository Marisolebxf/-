## 3. 开放项

1. **对标城市覆盖校验**（#19–#21、#33）：多城市横向对标 Tab 现场未深勘；执行 00116 时核对城市池须含北京/上海/苏州（USM 临时默认另含广州，深圳与全国参照固定且不可移除）；缺城市记缺口并升级。TRACE Q016（默认城市集合）待甲方确认，为 🟡 临时默认。
2. **对标 Tab 整体未深勘**（#22–#32、#35、#36 关联呈现）：预期按 v8 需规写 observed；城市对比表（每页 5 行、左右固定列）、雷达工作区（A 固定深圳 / B 默认全国、最多两条轮廓）、优势短板说明均以现场为准；Q014（技术力与商业力指标库构成及默认权重）未决，Demo 数值不得宣称为正式评分口径。
3. **失败态四件**（#16/#17/#18/#37）：提取失败/角色标注中与失败/对标计算失败需断链或构造异常触发，本轮 as-built 记 observed 不判 Fail。
4. **有数据场景补验**（#8/#10/#12 及 00113/00114/00115 执行深度）：现场选链后清单为「当前条件下暂无企业」「共 0 条」是事实；角色逐行标注、全量标注校验、全选/单选/部分选择态计数联动、翻页保留已选、切链清除旧链勾选与对比篮对象保留，均待有数据环境补验。
5. **未完成指标计算时不可识别优势与短板**（#34）：需构造计算未完成/可比指标 <3 场景；USM 口径为雷达不渲染、不输出强结论，执行时按现场 observed。
6. **城市指标缺口呈现**（#24/#25/#27/#28 关联）：`GAP-SZSTATUS-CITY-AVG-BUSINESS-POWER`（城市平均商业力无独立 metric_id）、`GAP-SZSTATUS-DENSITY-DENOMINATOR`（企业密度分母口径未定）业务模式须显示正常不可用态，不得以 0 或替代指标（综合竞争力/营收/利润率）补齐；执行 00116 核对。
7. **路由口径差异**：TRACE 目标态路由为 `/enterprise-center/shenzhen-enterprise-status-analysis`（views `chain-position` / `city-benchmark`），现场 as-built 为 `/enterprise/shenzhen-enterprise-status-analysis`；以现场为准，目标态差异不判 Fail。
