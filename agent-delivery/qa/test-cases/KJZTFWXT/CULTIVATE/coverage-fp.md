## 3. 开放项

1. **深圳范围限定校验**（#1、#15、#27）：对象范围固定深圳市内为视图语义（USM-04：培育视图固定为深圳市内企业）；结果企业全量深圳校验、培育候选深圳范围预检的服务端拦截为数据 / 服务侧职责，黑盒无法构造非深圳企业入池验证；如需验证须后端注入非深圳企业数据集。#1 按视图语义覆盖、#15/#27 按部分覆盖计。
2. **三指标算法黑盒归算法库**（#2~#4、#6~#9、#11~#13、#14、#24、#28）：技术壁垒 / 市场增速 / 团队背景指标供给、潜力识别计算、所需支持标注生成归培育企业综合推荐模型（`bid-reference/科技专题服务算法库.md` §1.1.1.1.1.1.1.5.8）与数据侧；数值正确性归算法库用例；B 线只验 UI 呈现（ⓘ / 证据字段 / 所需支持落点）、门控与状态。「未完成取数时不可识别 / 不可输出名单」的服务端门禁无法直接构造。
3. **#G5 政策导向空**（00133）：评审角标已声明「政策导向 #G5 未返回选项，下拉置空，不回落写死四项」；#G5（三方选项供应）闭合前政策导向下拉无选项且不硬编码回落，本轮不验证选项集内容与按政策导向筛选 / 分析路径；闭合后补验选项集、选择回显与联动。诚实降级本身为验证点（不回落写死选项）。
4. **失败态等异常三件**（#20、#38）：潜力识别失败 / 建议名单生成失败需断链或构造异常触发；状态图例 8 态已定义完整（含失败 / 无权限 / 输出任务失败 / 部分缺失），执行时能构造则验、不能构造则 observed 不判 Fail；无权限态不泄露结果数量 / 排名 / 详情（USM-09）。
5. **一企一策定制载体在模块外**（#30~#35、#39~#41）：按 USM C2「详情明确展示所需支持，并说明其可作为定制一企一策的依据；不在本模块直接生成完整政策方案或服务工单」与 TRACE `explicit_exclusions`「完整一企一策生成与服务派单」，完整定制功能（配置、生成中 / 失败态、结果展示）不属于本模块 UI；本模块只验名单 + 所需支持作为一企一策依据的呈现（00138）。模块外载体上线后由归属模块用例补验。
6. **结果态整体 observed**（#10、#16、#21~#26、#29）：推荐分析结果列表现场未展开（未实跑成功态），全部按 00138 执行时 observed 验证；行业分布补充视图数值受 GAP-RECRUIT-METRIC-04 约束（闭合前不显示真实计数）；详情「发展瓶颈 → 培育建议 → 所需支持」链路（USM-16）与三维联动随 00138 observed。
7. **候选工作台深度功能**：指定对象复核（L2，当前 Tab 参数配置与五阶段）、研判闭环（L3，return_context_id 返回挂载）、R1 大结果集（分页 20/50/100、跨页选择、全选当前筛选）现场未勘察到，归 E-27 产品定义 / 系统任务层用例；00140 只验入口、人工线索语义与深圳预检语义。
8. **路由口径差异**：TRACE 目标态 `route_family /enterprise/recommendation`，现场 as-built 为 `/enterprise/attraction?workspace=cultivation&recommendation_tab=cultivation`；以现场为准，目标态差异不判 Fail。
9. **Q015 未闭合**：培育推荐指数正式语义与阈值待客户决策（Q015 / M_ENT_CULTIVATION_INDEX 三维语义修订 + GAP-RECRUIT-METRIC-02 / GAP-RECRUIT-METRIC-04），闭合前 UI 只允许角标 + GAP 呈现（00137），不得出现正式阈值 / 权重表述或公式 / 权重编辑器。
