## 3. 开放项

1. **Bid 指标 GAP 核对**（#2–#5）：专利数量/引用、研发人员占比、核心技术覆盖度须有独立指标项、并入五维口径、或显式缺口（USM-31：研发投入强度不得替代研发人员占比）。00912 执行时核对，三者皆无则记缺口并升级。
2. **指标库为空提示**（#18）：指标库随系统模板常驻渲染，黑盒无法构造空态；如需验证须后端注入，本轮标未覆盖。
3. **失败态三件**（#20/#39/#41）：计算失败/对比失败/报告生成失败需断链或构造异常触发，本轮 as-built 记 observed 不判 Fail。
4. **排名表排序入口**（#30）：现场未勘察到排序交互；结果态执行时确认，无入口则按 as-built 记差异（USM-52 方向：不为明细表提供第二套排序入口）。
5. **数据为空构造**（#37）：需挑选指标数据缺失的企业对象；无法构造时 00906 记 observed。
6. **同壳层实勘迁移**：对象带入浮层（00903~00905 / 00921）、过程态（00913 / 00925 / 00926）、结果态（00914~00917 / 00923 / 00924）采综合竞争力 mode 2026-10-13 实勘口径；技术力 mode 专属文案与区块名为推定，执行时复核（observed）。
7. **路由口径差异**：TRACE 目标态路由为 `/enterprise-center/evaluation?mode=technology`，现场 as-built 为 `/enterprise/evaluation?workspace=technology&mode=technology`；以现场为准，目标态差异不判 Fail。
8. **六类型弹窗过时形态**：旧册 00075 记载「对比篮发起分析 → 六类型单选弹窗」路径，2026-10-13 同壳层实勘为「选择分析企业」浮层直回填；旧形态不写反向「不可见」校验，本条仅在档案说明。
