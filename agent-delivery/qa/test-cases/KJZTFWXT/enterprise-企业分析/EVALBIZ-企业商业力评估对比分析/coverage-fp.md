## 3. 开放项（保留沿用，编号不变）

1. **行业特性调整族**（#9~#11、#13、#16、#18、#20 及「行业特性调整失败提示」）：现场勘察未见行业特性选择/展示/调整交互（指标区固定 6 项，无行业选择器）。目标态交互（USM-33/41：选评价行业→加载行业适用指标与默认权重，已有改动三选一确认；评审挂载 `ENT-EVAL-F01-INDUSTRY-PREVIEW-NOTE`）在 00957 执行时全页查找：存在则按 USM-41 验证，不存在按 as-built 记差异（GAP-INTERACTION-BID-01）并升级，不判 Fail。
2. **Bid 指标 GAP 核对**（#2~#5）：年营收、利润率、客户集中度、品牌声量须有独立指标项、并入六维口径、或显式 `GAP-METRIC-BID-04/05`（USM-33：K-O7 未闭合前市场份额/品牌声量/客户集中度不可用于正式计算）。00942 执行时核对，三者皆无则记缺口并升级。
3. **指标库为空提示**（#19）：指标库随系统模板常驻渲染，黑盒无法构造空态；如需验证须后端注入，本轮标未覆盖。
4. **排名表排序入口**（#34/#35）：现场未勘察到排序交互；USM-52 方向为明细区不提供第二套排序入口，结果态执行时确认，无入口则按 as-built 记差异。
5. **数据为空构造**（#38）：需挑选指标数据缺失的企业对象；无法构造时 00936 记 observed。
6. **失败态**（#40）：对标计算失败需断链或构造异常触发，本轮 as-built 记 observed 不判 Fail。
7. **结果态整体**（#26~#33、#36~#40 关联呈现）：结果态结构为 2026-10-13 同壳层实勘迁移推定（综合竞争力 mode 实勘口径），排名表/可视化对比图/诊断明细区块名与构成为推定、执行时复核；算法数值正确性归算法库用例（`SDWJSF/KJZTFWSFK`），B 线只验 UI 呈现、门控与状态。
8. **路由口径差异**：TRACE 目标态路由为 `/enterprise-center/evaluation?mode=business`，现场 as-built 为 `/enterprise/evaluation?workspace=business`（同显 `mode=business`）；以现场为准，目标态差异不判 Fail。
9. **对象带入路径过时记载**：旧册（00087）「对比篮勾选 → 发起分析 → 六类型弹窗选商业力评估」为过时路径；2026-10-13 同壳层实勘为「评估页空态按钮 → 选择分析企业浮层直回填」。旧路径归档不删（六类型弹窗在对比篮侧的形态归 COMPARE 册核对），本册新号按浮层路径编写。
