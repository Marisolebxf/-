## 3. 开放项

1. **结果态未深勘**：痛难点结果态（诊断区块、特征展示、问题清单、维度归类、匹配依据、集合共性诊断、分析建议报告四段结构与顺序）现场未逐屏勘察；01080~01085、01093~01097 全条按 v8 需规 + USM（USM-05/06/08/14/21/22）observed 验证，区块名、字段与交互形态以现场为准记 observed，无载体或差异记 as-built 不判 Fail。
2. **诊断算法黑盒 + Q018 未闭合**：特征识别（#6）、特征-痛难点匹配（#8）、问题识别（#9）、报告四段生成（#21–#24）数值与内容正确性归算法库用例（`SDWJSF/KJZTFWSFK`）；B 线只验 UI 呈现、归类、依据展示与门控。Q018（痛难点诊断维度与阈值映射）无正式值：`M_ENT_PAINPOINT_COUNT` / `M_ENT_PAINPOINT_SEVERITY` 待语义复核，数值呈现按评审态 Mock 规则核对；`M_ENT_PAINPOINT_GAP` 当前不可见（行业最佳实践为解释性文本）。页面四维与算法库指标域分层按 `DEC-RISK-DIMENSION-LAYERING-20260720`。
3. **空态/校验态难构造**：#14（特征为空不可匹配）、#15（特征匹配未完成不可识别问题）、#17（特征为空提示）、#18（无问题空提示）、#34（报告数据为空）需挑选无数据/数据不足的企业对象或注入数据缺失；无法构造时按 as-built 映射（对象空态门控 / 预检阻断语义）覆盖并记 observed。
4. **失败态难构造**：#20（诊断失败提示）、#36（报告生成失败提示）需断链或注入异常触发，本轮记 observed 不判 Fail。
5. **维度映射语义**：页面四维（技术研发/市场拓展/融资/管理）与算法库四指标域（经营竞争力/盈利能力/生产效率/人才状况）映射由 Q018 闭合前不假定一一对应；01076/01081/01093 只验页面四维口径，不做算法域交叉断言。
6. **路由与 IA 口径差异**：TRACE 目标态为 `/enterprise-center/risk` 三页面级 Tab（供应链关系/发展痛难点/最近分析，USM-16），现场 as-built 为 `/enterprise/risk?workspace=pain-points&tab=pain-points` +「当前分析/最近分析」双 Tab；以现场为准，目标态差异不判 Fail。
7. **集合诊断深勘受限**：USM-20/21/22（6–50 家对象摘要收纳、共性问题 Top 5、典型企业 3 家、受影响企业名单、企业命中摘要）依赖 ≥6 家企业对象与分析成功；数据不可构造时该组降级为 observed，并按开放项 1 口径处理。
8. **类型名口径**：对比篮六类型弹窗内名称为「企业发展痛点分析」，页标题/侧栏为「企业发展痛难点分析」（一字之差，observed）；任务列表类型字段口径与现场一致记 observed，不判 Fail。
