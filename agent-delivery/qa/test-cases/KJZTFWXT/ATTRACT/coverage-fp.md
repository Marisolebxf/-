## 3. 开放项

1. **全国企业库范围与空库态**（#3、#8、#20）：全国企业库为筛选数据底座（范围归属后端 / 数据侧），黑盒无法验证「以全国企业库作为筛选范围」的实际边界，也无法清库构造「企业库为空」提示与拦截；如需验证须后端注入空数据集。本轮 #20 标未覆盖、#8/#3 分别按前端门控 / 实跑链路覆盖。
2. **三模型算法黑盒**（#4、#5、#6、#10、#26、#27、#28、#32、#33）：技术匹配度 / 成长性 / 区域适配性三模型与核心优势 / 关键指标 / 合作价值生成为算法侧职责，数值正确性归算法库用例（`SDWJSF/KJZTFWSFK`）；B 线只验 UI 呈现、门控与状态。「未完成计算时不可筛选 / 不可输出」的服务端门禁无法直接构造。
3. **排序切换入口**（#17、#18）：现场勘察未发现契合度升 / 降序切换入口；结果态执行时确认，无入口则按 as-built 记差异（默认降序 #16 已覆盖）。
4. **失败态三件**（#22、#40、#42）：挖掘失败 / 列表生成失败 / 价值分析（输出任务）失败需断链或构造异常触发；状态图例 8 态已定义完整，执行时能构造则验、不能构造则 observed 不判 Fail。
5. **结果态整体 observed**（#11、#15、#16、#24、#25、#29–#31、#34–#37）：推荐分析结果列表现场未展开（未实跑成功态），全部按 00126 执行时 observed 验证；目标特征命中展示（高成长 / 关键技术型 / 隐形冠军 / 专精特新，USM-15）与详情联动（USM-03）随 00126 / 00127 observed。
6. **候选工作台深度功能**：指定对象复核（L2，当前 Tab 内参数配置与五阶段）、研判闭环（L3，return_context_id 返回挂载）、R1 大结果集（分页 20/50/100、跨页选择、全选当前筛选）现场未勘察到，归 E-26 产品定义 / 系统任务层用例；00128 只验入口与人工线索语义。
7. **路由口径差异**：TRACE 目标态 `route_family /enterprise/recommendation`，现场 as-built 为 `/enterprise/attraction?workspace=attraction&recommendation_tab=attraction`；以现场为准，目标态差异不判 Fail。
8. **Q015 未闭合**：招引推荐指数正式语义与阈值待客户决策（Q015 / GAP-RECRUIT-METRIC-01/03），闭合前 UI 只允许角标 + GAP 呈现（00125），不得出现正式阈值 / 权重表述。
