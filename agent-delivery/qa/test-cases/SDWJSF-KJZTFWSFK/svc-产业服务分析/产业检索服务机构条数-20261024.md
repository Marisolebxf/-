# 服务机构维度 · 按产业检索可命中的机构条数

> 测试材料。2026-10-24 对 demo 库实查，不是正式 FUNC 用例册。
> 对照：`demo_gkxlumenx_dwd.industry_chain_entity_rel`、`demo_gkxlumenx_dwd.svc_org_graph_hang`、`demo_gkxlumenx_dwd.service_org`、`demo_gkxlumenx_ads.svc_org_card`、`demo_gkxlumenx_ads.svc_industry_layout`。

## 口径

政策和企业那份材料按产业链码归到「产业集群 - 产业」，节点码算进该产业。服务机构没有这套关联。

- `industry_chain_entity_rel` 只有 `enterprise` / `belongs_to`（206,593 行）和 `product` / `produced_at`（78 行），没有服务机构类型。
- `svc_org_graph_hang`（机构挂到产业节点）是 0 行。
- `service_org`、`svc_org_card` 上都没有 `INB` 链码或节点码。

按产业集群、产业或产业节点检索服务机构，命中是 0。

| 项 | 数量 |
|---|---:|
| 能按产业链码或产业节点检索到的机构 | 0 |
