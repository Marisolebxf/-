## 需规原文

企业基础指标模型基于企业专题数据，通过与企业数据库和资讯数据库的对接，采集并清洗包括企业名称、行业、地区、注册信息、专利数量、技术交易额、业务领域、融资并购记录及动态变化等多维数据，以构建反映企业发展状况和产业特征的核心指标体系。各指标均经过标准化数据预处理（去重、去噪、格式统一、补全），并结合业务规则和分析模型计算结果，确保指标的完整性、准确性和可比性。模型支持API接口及消息队列服务，将计算结果与指标数据按地域、时间、领域等多维条件提供给用户查询、分析与应用，实现政府、企业和投资机构在政策制定、市场分析、战略规划中的数据化决策，并通过定期更新与监测机制，保持指标数据的实时性和有效性。
企业基础指标模型涵盖五类基础指标：重点企业提取、企业类型分布、企业领域分布、企业重点资讯，以及新增企业数量。
（1）重点企业提取
通过对接企业数据库，针对专利数、技术交易额等指标设立阈值，进行重点企业提取。
1）数据源对接：通过对接企业数据库，建立数据获取渠道。获取包括专利数、技术交易额等指标在内的企业数据，包括企业名称、所属行业、所属地区等信息。
2）数据清洗：对于从企业数据库中获取的数据，需要进行数据清洗处理，包括去重、去噪、格式化、补全等操作。在此基础上，需要对数据进行指标业务的分析，例如对企业所属行业、所属地区、企业规模等进行分析，以确保数据准确性和可靠性。针对专利数、技术交易额等指标，需要设立相应的阈值，以区分重点企业和非重点企业。
3）数据处理：根据设立的阈值，筛选出符合条件的重点企业。针对重点企业的专利数、技术交易额等指标，进行统计和计算，得出相应的指标结果。需要对计算结果进行有效性验证和调整，确保指标结果准确和可靠。同时，需要进行指标业务的分析，例如对重点企业的行业分布、地区分布、企业规模等进行分析，以更好地理解和应用数据结果。
4）数据服务开发：开发API接口，提供根据企业行业、地区、企业规模等条件查询对应的重点企业专利数、技术交易额等指标结果。通过API接口，用户可以灵活地查询重点企业的专利数、技术交易额等指标结果，并进行相关分析和应用。
5）数据同步：采用API接口、消息队列等方式将计算结果同步到数据服务中，以便用户查询和使用。将计算结果同步到数据服务中，可以方便用户查询、下载和使用重点企业专利数、技术交易额等指标结果，帮助用户更好地了解企业的创新情况和技术水平。同时，需要定期更新数据和指标，并对其进行监测和分析，以确保数据和指标的有效性和可靠性。
（2）企业类型分布
通过对接企业数据库，计算企业的企业类型，类型按外企、高企、小微、上市等类型分类。
1）数据源对接：对接数据融合中枢中的企业数据库，建立数据获取渠道。通过数据源对接，获取企业数据库中的企业信息数据，包括企业名称、注册地、经营范围、企业类型等信息。
2）数据清洗：根据企业类型进行提取与企业类型相关的属性数据。在进行数据清洗处理时，需要针对不同类型的企业进行不同的处理，例如，对于外企需要根据其所属国别进行分类；对于高企需要根据其科技创新能力进行分类；对于小微企业需要根据其注册资本和员工人数进行分类。同时，需要进行指标业务的分析，例如对数据的时间范围、企业所属行业、地域分布等进行分析，以确保数据准确性和可靠性。
3）数据处理：根据提取的企业类型指标，综合计算不同类型企业的数量和占比指标，并通过环比计算增长率计算其趋势。需要对数据进行计算、归纳和统计等处理，得出企业类型指标和增长率指标。同时，需要对计算结果进行有效性验证和调整，确保指标结果准确和可靠。
4）数据服务开发：开发API接口，提供根据企业类型、时间等条件查询对应的企业数量和占比指标。通过API接口，用户可以灵活地查询不同类型企业的数量和占比指标，并进行相关分析和应用。
5）数据同步：采用API接口、消息队列等方式将计算结果同步到数据服务中，以便用户查询和使用。将计算结果同步到数据服务中，可以方便用户查询、下载和使用企业类型指标，促进企业发展和应用。同时，需要定期更新数据和指标，并对其进行监测和分析，以确保数据和指标的有效性和可靠性。
（3）企业领域分布
通过对接企业数据库，计算企业涉及的产业链/技术链领域。
1）数据源对接：对接数据融合中枢中的企业数据库，建立数据获取渠道。通过数据源对接，获取企业数据库中的企业领域分布数据，包括企业名称、所在地区、所属行业、从事业务领域等信息。
2）数据清洗：根据企业领域标签进行提取与产业链/技术链相关属性数据的关联。对于企业领域分布数据，需要进行数据清洗处理，包括去重、去噪、格式化、补全等操作。同时，需要进行指标业务的分析，例如对数据的时间范围、企业规模、地域分布等进行分析，以确保数据准确性和可靠性。
3）数据处理：根据提取的企业领域标签，综合计算企业所涉及的产业链/技术链领域指标，并通过环比计算增长率计算其趋势。需要对数据进行计算、归纳和统计等处理，得出产业链/技术链领域指标和增长率指标。同时，需要对计算结果进行有效性验证和调整，确保指标结果准确和可靠。在指标业务的分析中，需要注意对不同企业领域的划分和分类，以确保指标的准确性和可比性。
4）数据服务开发：开发API接口，提供根据企业领域标签、时间等条件查询对应的企业所涉及的产业链/技术链领域指标和增长率指标。通过API接口，用户可以灵活地查询企业所涉及的产业链/技术链领域指标和增长率指标，并进行相关分析和应用。
5）数据同步：采用API接口、消息队列等方式将计算结果同步到数据服务中，以便用户查询和使用。将计算结果同步到数据服务中，可以方便用户查询、下载和使用企业所涉及的产业链/技术链领域指标和增长率指标，促进企业的发展和应用。同时，需要定期更新数据和指标，并对其进行监测和分析，以确保数据和指标的有效性和可靠性。
（4）企业重点资讯
通过对接资讯数据库，抽取有关企业融资、并购、战略合作、新品发布的资讯。
1）数据源对接：对接数据融合中枢中的资讯数据库，建立数据获取渠道。通过数据源对接，获取有关企业融资、并购、战略合作、新品发布等方面的资讯，包括企业名称、融资金额、交易对手、发布时间等信息。
2）数据清洗：针对企业重点资讯数据，需要进行数据清洗处理，包括去重、去噪、格式化、补全等操作。同时，需要进行指标业务的分析，例如对数据的时间范围、行业领域、融资类型、融资阶段等进行分析，以确保数据准确性和可靠性。
3）数据处理：根据提取的融资金额等指标，综合计算企业融资规模指标，并通过环比计算增长率计算其趋势。同时，需要对并购、战略合作、新品发布等方面的资讯进行细化分析，提取出相关的指标，如交易金额、合作类型、新品发布数量。需要对数据进行计算、归纳和统计等处理，得出各个指标的结果和增长率指标。同时，需要对计算结果进行有效性验证和调整，确保指标结果准确和可靠。
4）数据服务开发：开发API接口，提供根据时间、行业领域、融资类型、融资阶段、交易对手等条件查询对应的企业融资规模指标、并购、战略合作、新品发布等方面的指标。通过API接口，用户可以灵活地查询企业的相关资讯和指标，并进行相关分析和应用。
（5）数据同步：采用API接口、消息队列等方式将计算结果同步到数据服务中，以便用户查询和使用。将计算结果同步到数据服务中，可以方便用户查询、下载和使用企业相关的指标，促进企业的发展和应用。同时，需要定期更新数据和指标，并对其进行监测和分析，以确保数据和指标的有效性和可靠性。
（5）新增企业数量
通过对接企业数据库，计算历年涉足某领域企业的新增数量。
1）数据源对接：对接数据融合中枢中的企业数据库，建立数据获取渠道。通过数据源对接，获取企业数据库中的企业动态数据，包括企业名称、注册时间、所属行业等信息。
2）数据清洗：根据领域标签及时间进行提取与新增企业相关属性数据，例如企业注册时间。针对企业动态数据，需要进行数据清洗处理，包括去重、去噪、格式化、补全等操作。同时，需要进行指标业务的分析，例如对数据的时间范围、所属行业、企业类型等进行分析，以确保数据准确性和可靠性。对于企业注册时间的数据清洗，需要注意对于重复注册的企业进行去重处理，以保证计算结果的准确性。同时，由于企业注册时间会受到政策法规、市场变化等因素的影响，需要对时间进行合理的选择和筛选，例如选择过去五年或者十年的数据进行计算，以获得更具代表性的指标结果。
3）数据处理：根据提取的企业注册时间等指标，综合计算历年涉足该领域企业的新增数量指标，并通过环比计算增长率计算其趋势。需要对数据进行计算、归纳和统计等处理，得出新增企业数量指标和增长率指标。同时，需要对计算结果进行有效性验证和调整，确保指标结果准确和可靠。对于企业新增数量指标的计算，需要考虑行业发展趋势、政策支持等因素的影响，以及数据的稳定性和连续性等方面的问题。同时，需要对计算结果进行分析，例如对新增企业数量的分布、变化趋势、行业类型等进行分析，以帮助用户更好地理解和使用指标结果。
4）数据服务开发：开发API接口，提供根据领域标签、时间等条件查询对应的新增企业数量和增长率指标。通过API接口，用户可以灵活地查询领域内的企业新增数量指标和增长率指标，并进行相关分析和应用。
5）数据同步：采用API接口、消息队列等方式将计算结果同步到数据服务中，以便用户查询和使用。将计算结果同步到数据服务中，可以方便用户查询、下载和使用新增企业数量和增长率指标，促进行业的发展和应用。同时，需要定期更新数据和指标，并对其进行监测和分析，以确保数据和指标的有效性和可靠性。
