## catalog 缺口（需规有、本页无 path）

1. **按政策 ID 查询**：需规「可根据政策ID、政策类别或时间区间进行力度指数计算与查询」，本页入参仅 scope_type、scope_code、limit；scope_code 点名为省/市编码，无独立 policy_id 入参。
2. **按政策类别查询**：需规点名政策类别，catalog 无对应入参/path。
3. **按时间区间查询 / 纵向趋势跟踪 / 历史回溯**：需规点名时间区间、趋势跟踪、历史回溯，本页无时间类入参、无趋势顶层结果体、无独立趋势 path。
4. **力度维度分析报告**：需规输出含「力度维度分析报告」，catalog 无 report 类 path。
5. **趋势变化图及预测分析结果**：需规输出含趋势图与预测分析，本页无预测/时序 path（图表化本身不计界面操作，此处记交付面缺口）。
6. **SDK 调用方式**：需规「RestfulAPI及SDK」，catalog 仅有 REST，无 SDK 契约。
7. **计算侧四类输入落地**：需规输入为政策文本信息、政策执行数据、成本与资源数据、辅助数据；本页仅为只读 GET 查询，无上述数据接入或计算入参 path。
8. **分类分级结果体**：需规「设定阈值…分类分级」已挂在本 path 的算法条；catalog 顶层结果体只点名 intensity_index，无独立分级字段/接口。
