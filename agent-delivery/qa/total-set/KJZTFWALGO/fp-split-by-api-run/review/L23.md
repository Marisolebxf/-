## catalog 缺口（需规有、本页无 path）

1. **按区域标签查询**：需规「支持按区域标签进行实时查询」「可按区域标签进行产业指数查询」，catalog 两个 path 仅有 chainId（产业链）路径入参，无区域标签（region / 区域编码）入参的查询接口（需规最核心的调用方式在契约中无对应 path）。
2. **趋势分析报告生成**：需规输出含「趋势分析报告」且调用方式含「支持生成趋势分析报告」，本页无独立报告生成类接口（趋势能力仅隐含在 region-index 结果语义内，无点名 report path）。
3. **优势短板评估结果接口**：需规输出含「优势与短板评估结果」并支持生成，无独立评估结果接口（同上，仅隐含在 region-index 语义内）。
4. **数据导出服务**：需规「支持生成趋势分析报告、优势短板评估及数据导出服务」，catalog 无导出类接口（download/export path）。
5. **SDK 调用方式**：需规「支持通过 RestfulAPI、SDK 方式调用」，catalog 仅有 REST 接口，无 SDK 契约（属交付形态缺口，非 REST path）。
6. **指标体系与权重参数读写**：需规输入含「指标体系与权重参数」，本页无权重/阈值配置读取或写入接口（若按「只读消费」口径可视为不缺口，此处如实记录）。

## 抽 3 条不同验收

1. 行 1（region-index 主验收）：调用 GET `/innov/v1/industry/{chainId}/region-index` 传 chainId，验收 = 返回顶层 region_index 结果体 —— 与行 2（三维度加权生成综合性指数）验收点不同（结构契约 vs 计算口径）。
2. 行 6（region-index 异常）：调用 GET `/innov/v1/industry/{chainId}/region-index` 传不存在的 chainId，验收 = 返回失败态（错误码/错误信息），与行 5（链存在但无指数数据返回空态非伪数值）验收不同（失败 ≠ 空态）。
3. 行 9（competitiveness 区域对比）：调用 GET `/innov/v1/industry/{chainId}/competitiveness`，验收 = 同一产业链下不同区域竞争力指数可比 —— 与行 8（竞争力评价覆盖三大维度）验收不同（跨区域可比性 vs 维度覆盖完整性）。
