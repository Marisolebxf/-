## catalog 缺口（需规有、本页无 path）

1. **六类专题库采集对接**：需规「与产业、技术、企业、人才、科研机构及服务机构等主题数据库建立数据接口，采集政策相关的结构化数据」，本页 4 个 path 均为图谱写边/浏览，无专题库采集类 path。
2. **定期同步调度**：需规「系统定期从专题库同步更新最新关系信息」，无定时任务/调度 path；本表仅能用再次调用 POST hang 表达更新。
3. **浏览侧维度/关系类型过滤**：需规「支持跨维度检索」，GET 入参仅 center、steps、limit；POST 侧 filter / relation_whitelist 不适用于浏览查询。
4. **当前波次主体覆盖不足（契约说明，非另开 path）**：catalog hang 摘要写明部分主体本波不上图（如技术/人才），与需规六类主体全覆盖不一致；功能点仍按需规做一次算法覆盖验收，并标明契约未交付。
5. **可视化形态**：需规「整合成可视化、可查询的政策实体关系图谱」，可视化属前端交付形态，不是本页 REST 缺口。

适用 / 监管 **不是** 缺 path：与扶持共用 POST `/policy/v1/policy/graph/hang`，由 relation_whitelist 配置。
