六级及需规原文：

企业实体识别构建旨在依托大规模企业数据库，自动识别并提取科研机构及企业相关的核心实体及属性信息，为产业分析、市场研究及决策支持提供结构化、可更新的数据基础。该过程通过将企业数据库数据导入实体识别系统，并结合业务需求执行预处理与数据清洗，确保输入数据的准确性与一致性。在系统构建完成后，支持持续的实体识别、属性提取、数据维护与更新，实现企业信息的动态管理和高质量输出。
通过对接工商注册信息、新闻、财务报表、招聘信息等多源数据，结合规则匹配（如正则表达式、关键词）和专业领域词典的命名实体识别（NER）方法，自动抽取企业名称、类型、所属行业、地理位置等基础属性及营收、员工人数、高管、融资额、市值、产品、技术等核心属性，并经数据清洗确保结构化与准确性；系统支持批量新增、删除、修改和定期更新企业实体信息，配备数据监控与异常报警机制维持数据质量；同时对接企业专题数据库提取关键属性并进行去重、纠错、补全，周期性刷新以反映企业的最新业务状态。

## 拆法（接口级）

一条 = 一个接口动作 + 一个对象 + 一条可验收规则。

每个去重后的 METHOD+path，有独立验收则分计：点名入参接收/校验、调用该 path、输出顶层主结果体、空态、失败（验收不同才分计）。catalog 或需规写了异步才计处理中。

禁止：嵌套字段 × 环节（那份技术/人才 Excel 的粒度，本轮不开）；同 path 再计网关转发；维度 × 空态；读实现仓补接口。

规则来源：原文直接 / 原文隐含 / 验收补充。  
拆分维度优先：校验 / 字段 / 算法 / 输出 / 状态 / 空态 / 异常。

图谱：ner/intra/hang 等按 path 分计；与兄弟六级共享 path 时本六级只写本页职责，合表去重。
