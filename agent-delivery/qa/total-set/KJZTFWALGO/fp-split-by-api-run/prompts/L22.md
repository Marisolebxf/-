六级及需规原文：

产业瓶颈堵点识别模型算法面向区域与行业发展中的关键制约因素，基于技术、人才、市场需求、资金、政策五大维度构建指标体系与阈值判断机制，通过计算各维度指标值，自动提取并标识产业瓶颈堵点。该算法可为政府、研究机构和企业提供精准的产业诊断结论，支持制定针对性解决方案和发展策略，并提供服务化接口供用户随时查询最新瓶颈信息。
（1）算法阐述
该算法通过对接政策法规库、市场调研、专家访谈及行业分析等多源数据，采集并标准化处理瓶颈分析所需信息。
在评价体系构建阶段，算法基于技术、人才、市场需求、资金、政策五大维度设计评价指标，并结合历史数据与专家经验设定阈值和权重。
在分析阶段，算法综合计算各维度指标值，识别并标注各领域的具体瓶颈类型，并对瓶颈成因、影响范围及可能的解决路径进行系统分析。模型具备动态跟踪与更新机制，能够实时监测产业瓶颈变化，并在方法与参数上持续优化提升识别精度。
输出阶段，算法可生成包含原因分析、影响评估及对应解决方案的分析报告，并通过API接口支持基于产业标签的瓶颈信息查询，实现在线监测与趋势预警，满足多场景的产业诊断与决策需求。
（2）算法输入与输出
输入：政策法规数据、市场调研数据、专家访谈信息、行业分析数据、技术指标、人才指标、市场需求指标、资金指标、政策支持指标、权重与阈值设定。
输出：产业瓶颈堵点清单、瓶颈成因分析报告、影响范围评估、解决方案建议、趋势预警图表。
（3）调用方式
支持通过RestfulAPI、SDK方式调用，可按产业标签或领域类别查询最新瓶颈信息，并支持生成报告、趋势预警及数据导出服务。

## 拆法（接口级）

一条 = 一个接口动作 + 一个对象 + 一条可验收规则。

每个去重后的 METHOD+path，有独立验收则分计：点名入参接收/校验、调用该 path、输出顶层主结果体、空态、失败（验收不同才分计）。catalog 或需规写了异步才计处理中。

规则来源：原文直接 / 原文隐含 / 验收补充。
