## 四、规则层（**模型级**；加深仍禁止笛卡尔积）

每个会出结果的**六级模型**，有独立验收则独立计数，**整模型一套，不按点名维度复制**：

校验入参、默认（需规有默认才写）、空态（无结果）、处理中、失败（计算失败 / 对接失败若验收不同才分计）、同步失败（需规写了同步才计）。

加深后可再计（仍挂整模型，须写出不同验收）：

- **全部源对接失败** vs **部分源对接失败**（部分失败时不得把缺失维当成已评估、不得生成完整指数）
- 需规写了权重时：权重缺失/不完整不生成指数（已有则不重复）；**未写**权重之和=100% / 默认权重则不发明
- 需规写了有效性验证/调整才计；T01 开篇有则计，深度模型没写则不加
- 需规写了同步/定时更新才计同步失败
- 需规点名排行榜且升序/降序验收不同才分计

禁止：维度 × 空态/失败交叉格。点名维度只拆 **计算、输出字段、该维结论**（优势/短板等），规则层挂在模型。

拆分维度优先：`算法 / 字段 / 校验 / 输出 / 状态 / 空态 / 异常`；少用 `定位 / 展示 / 筛选`（除非需规真有过滤条件）。
