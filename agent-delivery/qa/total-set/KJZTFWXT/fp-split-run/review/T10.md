## 每条能否写出不同验收标准（抽 3 条说明）

1. **以企业年报作为领域映射数据**（字段 / 原文直接）：领域映射入参包含企业年报；与「以专利作为领域映射数据」「以产品信息作为领域映射数据」入参名称不同，通过标准不同。
2. **未完成领域映射时不可计算参与深度**（校验 / 原文隐含）：尚未得到企业与预设产业领域的映射结果时，不计算各领域参与深度；映射完成后才允许出深度。与「无年报、专利与产品信息时不可映射产业领域」（阻断点在映射前）不是同一通过标准。
3. **依据各领域参与深度评估企业多元化程度**（展示规则 / 原文直接）：用户可依据已展示的各领域参与深度评估多元化程度；不单独发明多元化得分。与「按产业领域分别展示参与深度」（只验收分领域深度展示）不是同一通过标准。
