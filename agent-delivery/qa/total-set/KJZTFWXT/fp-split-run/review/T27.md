## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。四指标只在 L6-1「提供」与「评估」层分计，未与产业方向、名单行交叉成格；名单输出按「各项指标评分、综合排名、推荐理由」三列计，未把四指标再拆成名单列；空态/失败按模型评估链路与名单/理由链路计，未再乘。
- 套话：无。对象选择写成需规原句「设定拟重点发展的产业方向」，不是「选择××作为分析对象」。
- 未点名指标：无。「等多项指标」只取产业匹配度、技术领先性、发展潜力、对外合作意愿；未发明其它指标/城市，未补收藏/订阅/分享/LLM/导出。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供产业匹配度指标**（L6-1 / 字段 / 原文直接）：招引推荐模型指标项中出现可验收的「产业匹配度」；不含未点名指标。与「评估目标机构产业匹配度」（算出该指标值）不是同一通过标准。
2. **未设定产业方向时不可生成推荐引进机构名单**（L6-2 / 校验 / 原文隐含）：未设定拟重点发展的产业方向时阻断名单生成；已设定后方可运算。与「未完成招引综合评估时不可生成推荐名单」（门禁对象是评估完成态，不是产业方向）可单独判过/不通过。
3. **按综合排名升序排列推荐名单**（L6-2 / 排序 / 验收补充）：引进机构按综合排名从低到高排列；与「按综合排名降序排列推荐名单」顺序相反，可单独判过/不通过。
