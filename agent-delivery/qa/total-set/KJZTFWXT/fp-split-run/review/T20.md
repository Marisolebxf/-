## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。区域只在采集层分计长三角、粤港澳大湾区，未与政策条款/补贴标准/准入条件交叉成格；雷达图与热力图只在可视化层分计，未与区域或字段再乘；空态/失败按采集链路与对比链路各计，未按区域×字段×图表再乘。
- 套话：无。对象选择写成「指定目标产业或技术领域」，不是「选择××作为分析对象」。
- 未点名指标：无。「等」只取长三角、粤港澳大湾区；结构化字段只取政策条款、补贴标准、准入条件；未发明其它经济区/城市/指标，未补收藏/订阅/分享/NLP 独立点/排名表升序降序/导出。
