## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供技术壁垒指标**（L6-1 / 字段 / 原文直接）：潜力识别所用指标出现可验收的「技术壁垒」；不含未点名指标。与「提供市场增速指标」入参名称不同，通过标准不同。
2. **校验已识别企业均为深圳企业**（L6-1 / 校验 / 原文直接）：识别结果中不得出现非深圳企业；出现则不通过。与「限定潜力识别范围为深圳企业」（输入范围）不是同一通过标准。
3. **未识别出深圳高潜力企业时不可输出建议培育名单**（L6-2 / 校验 / 原文隐含）：尚无已识别的深圳高潜力企业时阻断名单输出；有识别结果后才允许出名单。与「未标注所需支持时不可定制一企一策」（名单已出、缺标注）前置不同，可单独判过/不通过。
