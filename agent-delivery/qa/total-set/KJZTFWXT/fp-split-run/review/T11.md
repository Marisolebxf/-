# T11 自检 · 企业技术力评估对比分析

## 条数是否在 32–44

是。合计 **42**（L6-1 **20** / L6-2 **22**），落在 32–44；两条六级分别落在建议的 15–22、16–22。

## 是否覆盖两条六级

是。

- L6-1 技术力模型构建与参数自定义：点名四指标入库、组合/移除、赋权、权重校验、实时计分与重算、得分展示、默认、空/计算中/失败。
- L6-2 多企业技术力对比分析：勾选两家及数量/同一性校验、雷达图、排名表（默认降序 + 升序/降序分计）、优势与差距分计、差距分析报告、对比与报告的空/处理中/失败、未完成对比不可出报告。

未拆其他五级。

## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。四指标只在指标库「提供」层分计，未与企业、雷达图轴、排名表列交叉；空态/失败按六级结果链路计，未按雷达图×排名表×报告再乘。
- 套话：无。「勾选两家对比企业」取自需规原文，不是「选择××作为分析对象」。
- 未点名指标：无。仅用专利数量、专利引用、研发人员占比、核心技术覆盖度；未发明其它指标，未补导出/收藏/订阅/分享/LLM。

## 每条能否写出不同验收标准（抽 3 条）

1. **提供专利数量指标**（L6-1 / 字段 / 原文直接）：指标库出现可勾选的「专利数量」；不含未点名指标。与「提供专利引用指标」入参名称不同，通过标准不同。
2. **校验指标权重之和为 100%**（L6-1 / 校验 / 原文隐含）：已选指标权重之和 ≠100% 时阻断计分并提示；=100% 时允许出分。与「校验单指标权重为非负数值」（单值符号）不是同一通过标准。
3. **按技术力得分升序排列排名表**（L6-2 / 排序 / 验收补充）：两家企业按技术力得分从低到高排列；与「按技术力得分降序排列排名表」顺序相反，可单独判过/不通过。
