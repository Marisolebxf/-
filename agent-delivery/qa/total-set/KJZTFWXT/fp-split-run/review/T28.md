# T28 自检 · 培育服务机构推荐分析

## 是否覆盖本五级全部六级

是。

- L6-1 培育模型与筛选：范围限定深圳本土服务机构；点名四指标入库与展示；四项均须参与综合评分的校验；汇聚取数、综合评分与高成长性发掘分计；综合评分及四指标取值展示；取数未完成不可计分、已评分机构属地校验、已发掘对象为本地企业校验；输入空/结果空、计算中、失败。
- L6-2 培育名单与建议：筛选最值得政策扶持和资源倾斜的培育对象；输出并展示本土机构培育名单；针对性建议生成；点名三项建议（资金支持、市场对接、人才引进）给出与展示分计；名单对象为本土机构、名单已给建议、建议与对象一一对应；未发掘出高成长性本地企业不可出名单；名单数量；默认按综合评分降序及升序/降序分计；名单与建议各自空态、名单生成中/失败。

未拆其他五级。未把「助力打造深圳本土的服务品牌」做成独立点。未补收藏/订阅/分享。

## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。四指标只在「提供 / 取值展示」层分计，计算按综合评分 1 条，未做指标×机构×建议交叉；三项建议只在「给出 / 展示」层分计，未按机构×建议类型再乘；空态/失败按六级结果链路计，未按名单×建议×四指标再乘。
- 套话：无。写成「限定培育推荐范围为深圳本土服务机构」，不是「选择××作为分析对象」。
- 未点名指标：无。指标只取现有规模、技术创新能力、服务成效、市场缺口；建议只取资金支持、市场对接、人才引进。未发明其它城市/指标/建议类型，未补导出/收藏/订阅/分享/LLM/一企一策。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供现有规模指标**（L6-1 / 字段 / 原文直接）：培育推荐所用指标出现可验收的「现有规模」；不含未点名指标。与「提供技术创新能力指标」入参名称不同，通过标准不同。
2. **校验已评分机构均为深圳本土服务机构**（L6-1 / 校验 / 原文直接）：综合评分结果中不得出现非深圳或非本土服务机构；出现则不通过。与「限定培育推荐范围为深圳本土服务机构」（输入范围）不是同一通过标准。
3. **给出资金支持培育建议**（L6-2 / 输出 / 原文直接）：针对性培育建议中出现「资金支持」类建议。与「给出市场对接培育建议」建议类型不同，可单独判过/不通过。
