## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。三指标只在体系「提供/校验/分项展示」层分计，未与深圳市/南山区交叉成「深圳×论文」格；加权与机器学习按「或」分计建模手段，未与区域、排名榜再乘。
- 套话：无。「选择目标区域」取自需规「灵活选择目标区域」，不是「选择××作为分析对象」。
- 未点名指标/区域：无。指标仅研发高新技术企业数量、专利申请与授权量、高质量论文数量；区域仅深圳市、南山区。未发明其它城市/指标，未补雷达图/地图/导出/收藏/订阅/分享，未把 LLM 实现手段单独成点。
