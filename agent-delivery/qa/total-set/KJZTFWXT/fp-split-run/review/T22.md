## 每条能否写出不同验收标准（抽 3 条说明）

1. **选定单个重点服务机构**（L6-1 / 动作 / 原文直接）：已选集合恰好为一个重点服务机构即可进入覆盖计算；与「选定多个重点服务机构」（集合须为多个）入参数量不同，通过标准不同。
2. **计算各产业领域服务广度**（L6-1 / 算法 / 原文直接）：对已选机构按产业领域算出服务广度数值；与「计算各产业领域服务深度」（另一指标）输出字段不同，可单独判过/不通过。
3. **以矩阵图呈现分析结果**（L6-2 / 展示 / 原文直接）：覆盖分析结果以矩阵图形式可见；与「以热力图呈现分析结果」图表形态不同，不是同一通过标准。
