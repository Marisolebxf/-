## 是否覆盖本五级全部六级

是。

- L6-1 多维度评价模型：内置模型展示；点名五维度（专利数量、研发投入、核心专家、成功案例、标准制定）入库；纳入/移除配置；赋权及权重校验；按模型计算并展示评价结果与各维度取值；默认纳入预设维度与均分权重；空/计算中/失败。
- L6-2 自定义对比分析：按分析目标自定义指标与权重及校验；选取目标机构横向对比（未写成两家）；排名列表与雷达图分计；雷达图维度随自定义指标生成；排名列表默认降序及升/降序分计；技术优势与相对短板识别与凸显分计；对比空/计算中/失败。

未拆其他五级。

## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。五维度只在评价模型「提供」层分计，未与排名列表列、雷达图轴交叉；空态/失败按六级结果链路各计一次，未按排名列表×雷达图再乘。
- 套话：无。对象动作为「选取目标机构进行横向对比」，不是「选择××作为分析对象」。
- 未点名指标：无。「等」只取专利数量、研发投入、核心专家、成功案例、标准制定；未发明专利引用/研发人员占比/核心技术覆盖度等企业技术力指标；未补两家、差距分析报告、实时计算、导出、收藏/订阅/分享/LLM。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供专利数量评价维度**（L6-1 / 字段 / 原文直接）：内置模型出现可配置的「专利数量」维度；不含未点名指标。与「提供研发投入评价维度」入参名称不同，通过标准不同。
2. **未选取目标机构时不可进行横向对比**（L6-2 / 校验 / 原文隐含）：未选取目标机构时阻断横向对比结果；已选取后方可计算对比。不要求「两家」，与「校验所选目标机构互不相同」（同一性）不是同一通过标准。
3. **按评价结果升序排列排名列表**（L6-2 / 排序 / 验收补充）：排名列表按评价结果从低到高排列；与「按评价结果降序排列排名列表」顺序相反，可单独判过/不通过。
