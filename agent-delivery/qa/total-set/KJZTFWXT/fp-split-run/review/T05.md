- 笛卡尔积：无。四指标只在「提供」层分计，未与环节、排序、空态交叉成格；标记链路与原因/建议输出链路分计，未按环节×原因×建议再乘。
- 套话：无。未写「选择××作为分析对象」。对象取自需规「每个产业环节」「瓶颈环节」。
- 未点名指标：无。仅用技术成熟度、人才供给量、融资事件、政策覆盖率；健康度为需规点名结果指标。未发明城市/图表/导出/收藏/订阅/分享/LLM。

## 每条能否写出不同验收标准（抽 3 条）

1. **提供技术成熟度指标**（L6-1 / 字段 / 原文直接）：分析所用指标中出现「技术成熟度」；不含未点名指标。与「提供人才供给量指标」入参名称不同，通过标准不同。
2. **对每个产业环节计算健康度评分**（L6-1 / 算法 / 原文直接）：每个产业环节均有健康度评分；缺环节则该条不通过。与「整合四项指标用于健康度评分」（入参是否齐）不是同一通过标准。
3. **按健康度评分升序排列产业环节**（L6-1 / 排序 / 验收补充）：产业环节按健康度评分从低到高排列；与「按健康度评分降序排列产业环节」顺序相反，可单独判过/不通过。
