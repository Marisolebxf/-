## 每条能否写出不同验收标准（抽 3 条说明）

1. **选取评估指标**（L6-1 / 动作 / 原文直接）：用户可从评估框提供的指标中自由纳入已选集合；不校验具体指标名称。与「为已选指标设置权重」（对已选集赋权，不改变选集成员）入参不同，通过标准不同。
2. **校验指标权重之和为 100%**（L6-1 / 校验 / 原文隐含）：已选指标权重之和 ≠100% 时阻断完成赋权；=100% 时允许进入评价。与「校验单指标权重为非负数值」（单值符号）不是同一通过标准。
3. **按综合竞争力得分升序排列排名**（L6-2 / 排序 / 验收补充）：排名按综合竞争力得分从低到高排列；与「按综合竞争力得分降序排列排名」顺序相反，可单独判过/不通过。
