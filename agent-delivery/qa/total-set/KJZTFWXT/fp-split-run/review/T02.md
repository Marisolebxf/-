## 每条能否写出不同验收标准（抽 3 条）

1. **输入或调整关键产业参数**（L6-1 / 动作 / 原文直接）：可写入或改已有关键产业参数并保留当前值；与「展示关键产业参数」（只读可见）通过标准不同。
2. **未完成周期阶段判断时不可生成分析报告**（L6-1 / 校验 / 原文隐含）：尚无周期阶段判断时阻断出报告；已有判断后允许生成。与「未填写关键产业参数时不可生成周期阶段判断」（拦判断而非拦报告）不是同一通过标准。
3. **识别潜在拐点**（L6-2 / 算法 / 原文直接）：预测结果给出潜在拐点；与「识别关键驱动因素」（驱动因素对象）及「在未来产业预测中展示潜在拐点」（呈现而非识别）通过标准不同。
