## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。四类标签只在「提供」层分计，未与产业、清单列交叉；数量/规模/占比只在计算与字段展示层分计，未与全国/城市层级交叉成格；空态/失败按筛选→清单、透视计算→可视化两条结果链路计，未再按层级×指标×可视化相乘。
- 套话：无。对象选择写成「选择目标产业」「勾选企业类型标签」，不是「选择××作为分析对象」。
- 未点名指标/城市：无。仅用外企、高企、小微、上市、企业数量、规模、占比；地理只用全国、城市、各区域、三级，未发明省级名称或未点名城市，未补地图/热力图/导出/收藏/订阅/分享/LLM。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供外企类型标签**（L6-1 / 字段 / 原文直接）：企业类型标签中出现可勾选的「外企」；不含未点名类型。与「提供高企类型标签」入参名称不同，通过标准不同。
2. **产业或企业类型变更后自动重筛匹配企业集合**（L6-1 / 筛选 / 原文直接）：已选产业或类型发生变化后，匹配企业集合随即按新条件更新，无需额外确认。与「按已选产业与企业类型自动筛选匹配企业集合」（给定当前条件产出集合）不是同一通过标准。
3. **校验地理下钻路径为三级**（L6-2 / 校验 / 原文直接）：从全国到城市的下钻须经过三级路径才视为完整透视；与「校验城市层级为下钻终点」（城市层不可再往下钻）约束对象不同，可单独判过/不通过。
