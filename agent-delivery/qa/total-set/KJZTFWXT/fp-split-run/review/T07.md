## 每条能否写出不同验收标准（抽 3 条）

1. **按政策维度生成发展建议**（算法 / 原文直接）：系统产出的建议内容可归属「政策」维度；与「按技术维度生成发展建议」入参维度不同，通过标准不同。
2. **提供多套发展路径**（输出 / 原文直接）：结果给出不少于两套发展路径方案；仅一套则本条不通过。与「展示多套发展路径」（界面可见）不是同一通过标准。
3. **未识别短板与优势时不可生成建议**（校验 / 原文隐含）：短板与优势均未识别时阻断建议生成；已识别后才允许出建议。与「未识别短板与优势时不可提供发展路径」阻断对象不同。
