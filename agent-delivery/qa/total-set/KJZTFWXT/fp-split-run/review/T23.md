## 是否覆盖本五级全部六级

是。

- L6-1 趋势可视化呈现：按需规拆「特定产业领域」「特定技术方向」选择（或关系，非同时必选）；统计该领域下新增服务机构数量及数量变化；生成并以时间序列趋势图展示；图内展示时间序列与新增服务机构数量；切换后重统；未选定不可统计、未完成统计不可出图；已选对象展示；默认趋势图；对象列表空 / 无新增数据；统计与出图的处理中/失败。
- L6-2 市场热度判断：特征只取已写「波动」「斜率」；判断对象只取「服务市场热度」「资本关注度」；须先有趋势曲线；特征分析与热度/关注度判断分计并分别展示；曲线变更后重分析；特征空 / 判断空；特征分析与判断的处理中/失败。未把「为投资决策与政策制定提供数据参考」作成点。

未拆其他五级。

## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。产业领域与技术方向只在对象选择层分计，未与趋势图/数量交叉成格；波动、斜率只在特征层分计，未与热度、关注度交叉成「波动×热度」等；空态/失败按统计链路、出图链路、特征分析链路、判断链路分计，未再按对象×特征×判断相乘。
- 套话：无。对象选择写成需规原句「特定产业领域」「特定技术方向」，不是「选择××作为分析对象」。
- 未点名指标：无。「等」只取波动、斜率；未发明拐点/振幅/城市名；未补收藏/订阅/分享/导出/LLM。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **选择特定产业领域**（L6-1 / 动作 / 原文直接）：用户选定一个产业领域后，后续统计按该产业领域取数；与「选择特定技术方向」（对象类型为技术方向）入参不同，通过标准不同。
2. **分析趋势曲线的波动特征**（L6-2 / 算法 / 原文直接）：对已有趋势曲线给出波动特征；与「分析趋势曲线的斜率特征」（斜率对象）及「展示趋势曲线的波动特征」（呈现而非分析）通过标准不同。
3. **未完成数量变化统计时不可生成时间序列趋势图**（L6-1 / 校验 / 原文隐含）：尚无数量变化统计结果时阻断出图；已有统计后允许生成趋势图。与「未选定产业领域或技术方向时不可统计新增服务机构数量」（拦统计而非拦出图）不是同一通过标准。
