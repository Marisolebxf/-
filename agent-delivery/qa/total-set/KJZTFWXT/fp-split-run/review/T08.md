## 每条能否写出不同验收标准（抽 3 条）

1. **提供企业能力维度**（L6-1 / 字段 / 原文直接）：指标体系出现可赋权的「企业能力」维度；不含未点名维度。与「提供学术生态维度」「提供配套生态力维度」入参名称不同，通过标准不同。
2. **校验三大维度权重之和为 100%**（L6-1 / 校验 / 原文隐含）：三维权重之和 ≠100% 时阻断适配并提示；=100% 时允许按产业特性适配。与「校验单维度权重为非负数值」（单值符号）不是同一通过标准。
3. **按综合竞争力指数升序排列排名对比**（L6-2 / 排序 / 验收补充）：各区域按综合竞争力指数从低到高排列；与「按综合竞争力指数降序排列排名对比」顺序相反，可单独判过/不通过。
