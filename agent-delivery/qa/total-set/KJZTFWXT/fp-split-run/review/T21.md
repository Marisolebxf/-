## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。未把三维×三指标交叉成格；未把产业与技术领域拆成必须同时具备的两点；未按指标分别再乘深圳得分；未把优势/短板再乘三维或三指标。
- 套话：无。对象选择写成「选定目标产业或技术领域」，不是「选择××作为分析对象」。
- 未点名指标/城市：无。「等」只取政策数量、资金规模、创新激励；三维只取政策支持力度、产业适配性、落地实效性；对标对象只取深圳，未补其他城市。未写收藏/订阅/分享、赋权、实时计算、雷达图/排名表、LLM。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供政策数量指标**（L6-1 / 字段 / 原文直接）：核心指标清单中须存在「政策数量」且可被选入模型；与「提供资金规模指标」「提供创新激励指标」字段名不同，缺任一项即该项不通过。
2. **选定目标产业或技术领域**（L6-2 / 筛选 / 原文直接）：用户选定产业或技术领域之一即可进入计分范围；不要求产业与技术领域同时具备，与「固定以深圳为政策对标对象」（对象锁定深圳、不可改成未点名城市）通过标准不同。
3. **以仪表盘展示深圳政策短板环节**（L6-3 / 展示 / 原文直接）：仪表盘须呈现已识别的短板环节；与「以仪表盘展示深圳政策优势领域」（展示对象为优势领域）以及「无短板环节时展示空提示」（无短板时出空态而非短板列表）可单独判过/不通过。
