## 每条能否写出不同验收标准（抽 3 条说明）

1. **按所选产业链限定企业提取范围**（L6-1 / 筛选 / 原文直接）：清单内企业须属于用户所选产业链；不属于该链的不得出现。与「校验所提取企业范围为深圳」（属地约束）入参不同，可单独判过/不通过。
2. **纳入北京作为对标城市**（L6-2 / 字段 / 原文直接）：对标集合出现「北京」；不含未点名城市。与「纳入上海作为对标城市」城市名称不同，通过标准不同。
3. **识别深圳企业群优势**（L6-2 / 算法 / 原文直接）：在已计算的平均技术力、商业力、企业密度上给出深圳相对对标城市的优势结论。与「识别深圳企业群短板」（结论方向相反）可单独判过/不通过。
