# T12 自检 · 企业商业力评估对比分析

## 条数是否在预算内

是。合计 **40**（L6-1 **20** / L6-2 **20**），落在 32–44；两条六级分别落在建议的 15–22、16–22。

## 是否覆盖本五级全部六级

是。

- L6-1 商业力模型配置与指标选择：点名四指标（年营收、利润率、客户集中度、品牌声量）入库、选择/取消、行业特性设置与按行业调整/变更重调、至少一指标与行业特性校验、调整后展示、默认勾选、空/调整中/失败。
- L6-2 商业竞争力对标分析：纳入/移除对标企业及不可重复、未纳入不可出结果、未完成模型配置不可计分、评分/排名/可视化对比图分计、识别并在图中展示市场地位差异、排名表默认降序 + 升序/降序分计、图与排名同一批对象、空/计算中/失败。

未拆其他五级。

## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。四指标只在指标库「提供」层分计，未与对标企业、可视化对比图轴、排名表列交叉；空态/失败按六级结果链路各计一次，未按评分×排名×图再乘。
- 套话：无。「纳入对标企业」服务对标/评分/排名成立所必需，不是「选择××作为分析对象」。
- 未点名指标：无。仅用年营收、利润率、客户集中度、品牌声量；未发明其它商业指标或行业名；未补专利/雷达图/两家/赋权/实时计算/差距分析报告/导出/收藏/订阅/分享/LLM。

## 是否误用了原型或五件套

否。未读 demo-ui-topic / 页面组件 / USM/TRACE/IA/UX/Wireframe / 既有用例 / v1–v7 Excel。L6-2 按需规「评分、排名及可视化对比图」三项拆，未改成五件套式「两家」或「点生成才出结果」，也未把可视化对比图改成雷达图。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供年营收指标**（L6-1 / 字段 / 原文直接）：商业指标库出现可选择的「年营收」；不含未点名指标。与「提供利润率指标」入参名称不同，通过标准不同。
2. **按行业特性调整商业指标**（L6-1 / 动作 / 原文直接）：已设置行业特性后，已选商业指标按该行业特性完成调整；与「设置行业特性」（只写入特性、尚未完成调整）不是同一通过标准。
3. **按商业力评分升序排列排名表**（L6-2 / 排序 / 验收补充）：对标企业按商业力评分从低到高排列；与「按商业力评分降序排列排名表」顺序相反，可单独判过/不通过。

## 结论

**通过。**
