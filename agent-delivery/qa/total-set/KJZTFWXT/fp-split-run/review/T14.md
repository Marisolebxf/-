## 每条能否写出不同验收标准（抽 3 条说明）

1. **按技术匹配度模型计算企业技术匹配度**（L6-1 / 算法 / 原文直接）：对全国企业库中的企业给出技术匹配度结果；不含成长性、区域适配性。与「按成长性模型计算企业成长性」模型名称与输出字段不同，可单独判过/不通过。
2. **筛选与深圳重点产业高度契合的目标企业**（L6-1 / 筛选 / 原文直接）：结果企业须与深圳重点产业高度契合，且来源为全国企业库；不得混入未点名城市或非该产业对象。与「以全国企业库作为筛选范围」（只约束来源、不判定契合）通过标准不同。
3. **校验推荐企业列表附带核心优势、关键指标及合作价值**（L6-2 / 校验 / 原文直接）：列表同时具备核心优势、关键指标、合作价值三类附带内容才可通过；缺任一字段则阻断。与「在推荐企业列表中展示核心优势」（只验核心优势一列是否展示）不是同一通过标准。
