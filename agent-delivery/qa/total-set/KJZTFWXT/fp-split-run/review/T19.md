## 是否覆盖本五级全部六级

是。

- L6-1 政策数据自动关联：选定目标产业或技术领域（「或」合一条）、点名两渠道入库、渠道范围校验、自动抓取与关联匹配、纳入并建立动态政策数据库、数量展示、选定后自动抓取与变更后更新、抓取中/抓取失败/库更新失败/空态。
- L6-2 时序模型智能分析：点名三维度入库、维度齐全校验、构建时序分析模型、汇聚政策数据、无库不可分析、政策密度指数与支持强度趋势图的生成与展示、默认按发布时间展趋势、演变规律与关键节点的识别/展示/按发布时间定位、数据变更后自动更新、空/计算中/失败。

未拆其他五级。

## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。国家部委、地方政府只在渠道「提供」层分计，未与产业/技术领域交叉成格；发布时间、效力层级、支持力度只在维度「提供」层分计，未与指数/趋势图再乘；空态/失败按六级结果链路计，未按指数×趋势图×规律×节点再乘。
- 套话：无。对象选择写成需规原句「选定目标产业或技术领域」，不是「选择××作为分析对象」。
- 未点名指标：无。「等」只取国家部委、地方政府；时序维度只取发布时间、效力层级、支持力度；量化输出只取政策密度指数、支持强度趋势图。未发明城市、未补导出/收藏/订阅/分享/LLM。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **提供国家部委权威渠道**（L6-1 / 字段 / 原文直接）：抓取来源列表含「国家部委」；不含未点名城市或其它渠道。与「提供地方政府权威渠道」入参名称不同，通过标准不同。
2. **未选定目标产业或技术领域时不可抓取关联政策**（L6-1 / 校验 / 原文隐含）：未选定产业且未选定技术领域时阻断抓取；已选定其中之一则允许自动抓取。与「未建立动态政策数据库时不可进行时序分析」（阻断对象是时序分析而非抓取）不是同一通过标准。
3. **自动生成政策密度指数**（L6-2 / 算法 / 原文直接）：模型输出可验收的政策密度指数数值；与「以支持强度趋势图展示支持强度」（图表形态，不是指数值）入参与通过标准不同。
