## B 杠杆（有独立验收才落）

**B1 点名采集字段（主增量）**  
顿号列出的采集字段，从「对接××采集 A、B、C」拆成各 1 条。拆完**删除**那条总述对接。  
「等」「如」「包括但不限于」只取已写名称。  
「或」保留 1 条（企业标识或名称、企业或机构名称）。  
不要发明专利号、申请日等未写字段。不要字段 × 失败。

**B2 查询入参**  
开篇或调用方式点名的时间 / 地域 / 产业标签：缺的补「接收」+ **模型级**「按该条件查询」。  
禁止把三个条件乘到每一个维度的 API 上。T01 各维 API 保持该小节原文写的条件。

**B3 消息队列 ≠ API 同步**  
需规点名 API 同步 **和** 消息队列：模型级补消息队列通道（及失败，若与 API 同步失败验收不同）。禁止通道 × 维度。

**B4 年 ≠ 月**  
仅当需规写「年/月」且两口径验收不同。把含糊的「年或月」拆开。未点名粒度不拆。

**B5 训练失败 / 验证不通过不发布**  
已有「训练与优化」才补「训练失败」。需规写了有效性验证、且还没有「验证不通过则不发布/不提供查询」才补。没写就不加。

**B6 更新触发**  
「定期更新」与「根据数据变化自动更新」都写了且触发不同才分计。「持续监测」若与自动更新同义则不加。

**B7 对标三步**  
点名对标/对比才拆。对象值若已有指数/指标计算则不重复。对照对象必须需规点名（全国 / 行业基准 / 历史）。仅有「对标分析」无对照对象：可 1 条「计算对标基准」（原文隐含），禁止发明对标城市。已有「输出对标结果」则保留。

**B8 推荐三步**  
需规已有候选/召回、评分、排序三个动作才分计。只有「指数 + 排名」不要发明召回。
