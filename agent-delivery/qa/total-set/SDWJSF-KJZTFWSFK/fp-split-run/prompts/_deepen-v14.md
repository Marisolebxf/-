## 加深口径 1–6（全开，写不出不同验收就不拆）

质量优先。4000 是理想目标，禁止灌水。禁止为冲 67 条/六级凑数。

1. **点名维度补输出字段 / 结论**  
   每维一条结果体字段；点名的优势/短板按维分计。  
   不计：再套「按维度输出」总述；维度 × 空态/失败。  
   **T01（L01–L04）**：已有「按维计算 + 按维 API 查询 + 按维同步」的，不要再叠同义「输出该维字段」。缺的才补（例如有效性验证、全部/部分源失败）。

2. **指标与阈值分开**  
   「设定 XX 指标」与「设定 XX 判断阈值」分计。  
   不计：把「训练与优化」拆成两条。原文只有指标没有阈值就不发明阈值。

3. **清洗只拆需规点名步骤（整模型一套）**  
   原文列出的去重/去噪/补全/格式等才拆。只写「标准化」则保持 1 条。  
   不计：清洗 × 维度；T01 已按维「清洗 X 数据」的不要再叠四步 × 维度。

4. **规则层加深（仍挂整模型）**  
   可加且须不同验收：全部源对接失败 vs 部分源对接失败（部分失败不得把缺失对象当已评估/不得生成完整结果）；需规写了权重才校验权重缺失；需规写了有效性验证才计；需规写了同步才计同步失败；点名排行榜且升/降序验收不同才分计。  
   不计：超时、鉴权、LLM、未写的默认权重、权重之和=100%（需规没写就不发明）。

5. **报告点名章节**  
   输出段点名、且尚未单独成点的章节 +「生成该报告」。  
   不计：与已有「输出指数/分维/建议」同义的伪章节。

6. **图谱（L05–L12）按点名关系/实体类型补输出**  
   抽取已按类型分计的，输出字段也按类型分计。可视化按结果体，不拆图表控件。
