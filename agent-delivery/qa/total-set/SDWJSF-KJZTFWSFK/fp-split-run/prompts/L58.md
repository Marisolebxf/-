模型支持通过RestfulAPI、SDK方式调用，可按区域标签、产业领域、技术领域等条件获取综合评价结果。调用接口可返回区域创新要素领域指数及优势短板分析，并支持在线监测、区域间横向比较及发展趋势预测功能，实现与区域决策支持系统的无缝对接。
