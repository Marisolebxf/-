## 需规原文

产业全要素图谱API服务基于已构建的产业实体与关系，面向数据检索、关系查询、知识扩充、智能交互、可视化分析及网络计算等多类应用场景提供标准化接口。该服务支持与外部系统灵活集成，使用户能够高效调用知识图谱核心功能，满足产业信息检索、语义分析、结构化计算等业务需求，并便于在科研、产业分析、投资决策及情报监测中直接应用。其包含以下核心能力：
（1）实体检索API：
支持用户根据关键词或实体名称等条件，在知识图谱中检索实体信息。支持分页查询和排序等功能，以便用户快速找到所需信息。
（2）实体关系查询API：
支持用户查询知识图谱中实体之间的关系信息。用户可以查询产业、技术、企业之间的股权关系、人物之间的社交关系。支持不同类型实体之间的关系查询，以及关系的方向、权重等信息的获取。
（3）图谱可视化API：
支持用户将知识图谱中的信息进行可视化展示。用户可以选择不同的可视化方式，如关系图、词云图，以便更好地理解和分析实体之间的关系和属性。
（4）语义相似度计算API：
支持用户计算两个实体之间的语义相似度。用户可以输入两个实体的名称或其他属性，例如产品名称、关键词，获取它们之间的相似度分值。该API使用基于深度学习的语义模型进行相似度计算，以便更准确地反映实体之间的语义关系。
（5）网络指标计算API：
支持计算指定图谱网络中的网络密度、中心度等网络指标。
