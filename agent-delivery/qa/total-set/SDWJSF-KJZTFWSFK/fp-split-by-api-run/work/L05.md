# L05 产业实体识别构建（by-api）

- 三级：算法工具库
- 四级：科技专题服务算法库
- 五级：产业全要素图谱
- 六级：产业实体识别构建
- 页面列：产业链全景
- catalog：chain.panorama
- 条数：10
- 拆分维度：校验 / 输出 / 算法 / 空态 / 异常 / 状态
- 规则来源：原文直接 / 原文隐含 / 验收补充

## 需规原文

产业实体识别构建旨在通过对接多源产业相关数据库，自动识别并提取产业领域内的实体及其属性，为产业分析、情报挖掘和决策支持提供高质量的基础数据。系统将产业数据导入实体识别平台，并依据具体业务需求执行数据预处理与清洗，以确保数据的准确性和可靠性。在实体识别系统构建完成后，结合规则识别、词典识别、实体维护更新和属性提取等方法，实现产业实体的持续更新和精确管理。
通过对接工商信息、产业专题库、新闻、专利及行业报告等多源数据，建立稳定的数据采集与传输机制，并对导入数据进行标准化预处理（去重、缺失值补全、异常值修正、格式统一）以确保可用性；在实体识别阶段，支持基于规则的高精度结构化抽取和基于专业词典的命名实体识别（NER），可以提取名称、类型、行业、地理位置等信息；在维护环节可按规则或人工添加、删除、修改实体并定期更新；在属性提取环节根据实体名称抽取投融资规模、市场容量、区域分布、企业与机构数量等核心属性，并通过去重、纠错、补全及周期更新保持数据完整性与时效性。

## 绑定接口

| method | path | catalog status | runtime |
|---|---|---|---|
| POST | `/chain/v1/chain/graph/ops/{op_id}` | running | java_api |
| GET | `/chain/v1/chain/{chainId}/panorama` | running | java_api |

（两接口均 status=running，契约已交付，无「契约未交付」标注项。）

| 子功能项 | 功能点 | 拆分维度 | 规则来源 |
|---|---|---|---|
| 产业实体识别构建 | 调用 POST `/chain/v1/chain/graph/ops/{op_id}`，接收点名入参 op_id 并按 op_id 将识别出的产业实体（A/B/C）写入图谱，返回顶层结果体 written_nodes | 校验/输出 | 原文直接 |
| 产业实体识别构建 | 调用 POST `/chain/v1/chain/graph/ops/{op_id}`，按点名入参 scope、id、filter 过滤待写入的实体范围，仅写入符合条件的实体 | 校验 | 原文隐含 |
| 产业实体识别构建 | 调用 POST `/chain/v1/chain/graph/ops/{op_id}`，按点名入参 relation_whitelist、dest_types 限定实体间可写入的关系边类型，返回顶层结果体 written_edges | 校验/输出 | 原文隐含 |
| 产业实体识别构建 | 调用 POST `/chain/v1/chain/graph/ops/{op_id}`，按点名入参 mode、dry_run 执行（dry_run 模式下不实际写入仅返回写入结果体），返回顶层结果体 skipped | 状态/输出 | 原文隐含 |
| 产业实体识别构建 | 调用 POST `/chain/v1/chain/graph/ops/{op_id}`，对导入数据经标准化预处理（去重、缺失值补全、异常值修正、格式统一）后再写入，保证写入实体的准确性与可用性，返回顶层结果体 source、space | 算法 | 原文直接 |
| 产业实体识别构建 | 调用 POST `/chain/v1/chain/graph/ops/{op_id}`，因实体识别/词典/规则未产出任何可写入实体时返回 written_nodes、written_edges 为空且 skipped 记录跳过原因的空态 | 空态 | 原文隐含 |
| 产业实体识别构建 | 调用 POST `/chain/v1/chain/graph/ops/{op_id}`，指定不存在的 op_id 或 filter/relation_whitelist 等入参非法时返回失败态（与空态验收不同） | 异常 | 验收补充 |
| 产业实体识别构建 | 调用 GET `/chain/v1/chain/{chainId}/panorama`，接收点名入参 chainId，返回该产业链全景图谱（顶层结果体 nodes、edges），nodes 中实体含名称、类型、行业、地理位置等识别提取属性 | 校验/输出 | 原文直接 |
| 产业实体识别构建 | 调用 GET `/chain/v1/chain/{chainId}/panorama`，指定 chainId 下经识别构建后无可展示实体/关系时返回 nodes、edges 为空的空态而非报错 | 空态 | 原文隐含 |
| 产业实体识别构建 | 调用 GET `/chain/v1/chain/{chainId}/panorama`，指定不存在的 chainId 时返回失败态（与空态验收不同）；实体维护更新（规则/人工增删改）后可查询到更新后的图谱数据 | 异常/状态 | 验收补充 |
