## 需规原文

政策实体关系抽取结合政策文本数据与政策实施情况，通过自然语言处理技术（NLP）与可配置规则，将政策与政策主题、政策目标、实施主体、受益对象、监管机构等重要关联实体的关系自动识别并建模，构建政策实体关系图谱。该模块对接各类业务专题库，包括产业、技术、企业、人才、科研机构及服务机构数据库，系统化抽取政策与这些主体的扶持、适用或监管关系，为政策分析、效果评估及决策支持提供结构化的数据基础。
通过与产业、技术、企业、人才、科研机构及服务机构等主题数据库建立数据接口，采集政策相关的结构化数据，并针对不同关系类型（如扶持、适用、监管）配置抽取规则，结合字段结构与业务语义实现精准识别；经去重、纠错、缺失值补全等预处理后，系统定期从专题库同步更新最新关系信息，并在各维度分别抽取政策与对应产业领域、技术方向、企业、人才群体、科研机构及服务机构的关联数据，最终整合成可视化、可查询的政策实体关系图谱，支持跨维度检索与深度分析，全面呈现政策覆盖范围与实施效果。
