## catalog 缺口（需规有、本页无 path）

1. **按时间查询（多数统计口未点名）**：需规开篇及（1）（2）（3）（4）（7）（8）（9）均要求按时间条件查询；catalog 仅 `market-stats` / `enterprise-stats` 点名入参 `statYear`。`institution-stats`、`investment-stats`、`global-dist`、`national-dist`、`news-stats`、`sz-elements`、`sz-dist` 仅点名 `chainId`，无时间入参。
2. **按国家/地区查询全球分布**：需规（5）4）「根据国家或地区查询对应的企业或机构总数」；`global-dist` 仅点名 `chainId`，无国家/地区入参。
3. **按行业分类、省份查询全国分布**：需规（6）4）「根据行业分类、省份等条件查询」；`national-dist` 仅点名 `chainId`，无省份/行业分类入参。
4. **热点指标平均值 / 浏览量·评论数**：需规（7）要求查询热点资讯数量**和**热点指标平均值，并以浏览量、评论数设阈值；catalog `news-stats` 顶层仅点名 `news_count`，无平均值及浏览量/评论数顶层字段（阈值判定并入该口算法行，不单列嵌套字段）。
5. **深圳产业要素口径**：需规（8）为投融资、人才引进、科技创新等「产业要素数量」；catalog `sz-elements` 顶层为 `enterprise_count`、`institution_count`，无独立要素数量字段、无时间入参。
6. **深圳分布按地理位置/时间查询**：需规（9）4）「根据产业标签、时间、地理位置等条件查询」；`sz-dist` 仅点名 `chainId`。
7. **下载**：需规开篇「灵活查询与下载」；本页无 export/download path。
8. **消息队列同步 / 定期更新监测**：需规各维度「数据同步」及开篇定期更新；catalog 为只读 GET，无 MQ 或写入/调度 path（属交付形态，不发明接口，不拆处理中）。
