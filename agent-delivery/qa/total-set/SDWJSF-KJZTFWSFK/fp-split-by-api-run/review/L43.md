## catalog 缺口（需规有、本页无 path）

1. **按机构名称检索**：需规「可按机构名称、标签或时间周期进行检索」，本页 catalog 仅点名入参 `kind`，无机构名称入参或独立检索 path。
2. **按标签检索**：同上，catalog 未点名标签入参。
3. **按时间周期检索 / 历年趋势分析报告**：需规输出含「跨机构比较与历年趋势分析报告」，catalog 无时间周期入参、无独立报告 path（本页不得发明新 path）。
4. **SDK 调用方式**：需规「RestfulAPI与SDK接口调用」，catalog 仅有 REST，无 SDK 契约（交付形态缺口，非 REST path）。
5. **优势与不足分析报告体**：需规输出「机构能力优势与不足分析」，本页顶层结果体仅 `tech` 名单，无独立分析/报告结果体。
6. **外部系统集成**：需规「支持与金融监管平台、投融资分析系统及金融机构内部管理系统集成」，catalog 无集成/推送类 path。
7. **独立批量契约**：需规「调用接口具备批量处理能力」；本页无独立 batch path，工作稿按 tech 名单一次返回多机构作部分覆盖，不另发明 path。

口径差（不另拆点）：catalog 本页示例维与需规四维（资金规模、融资成本、资金风险、服务质量）不一致；本轮不拆嵌套示例字段，算法验收以需规四维为准。
