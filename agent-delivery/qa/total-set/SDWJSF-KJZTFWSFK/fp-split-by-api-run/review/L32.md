## catalog 缺口（需规有、本页无 path）

1. **按企业名称评估**：需规「可按企业名称或标识进行商业力评估」，catalog 仅 orgId 路径入参，无按 name 查询接口（企业名称 → orgId 的检索/映射接口缺失）。
2. **SDK 调用方式**：需规「支持通过 RestfulAPI、SDK 方式调用」，catalog 仅有 REST 接口，无 SDK 契约（属交付形态缺口，非 REST path）。
3. **跨企业/行业对比分析独立接口**：需规「支持跨企业对比分析」及输出「行业对比分析结果」，本页有 rank（列表）与 report（单企业报告，已拆一条对标内容验收），无显式「多企业横向对比（compare/benchmark）」独立接口（部分能力可能由 rank+详情隐含覆盖，但无点名 path）。
4. **数据导出服务**：需规「支持生成报告、对比分析及数据导出服务」，catalog 无导出类接口（如报表/数据导出 download/export path）。
5. **指标体系与权重参数写入/更新**：需规输入含「评价指标体系与权重参数」，catalog 仅有只读 GET `/entan/v1/eval/weights`，无指标体系定义或权重配置的写入接口（若按「只读消费」口径可视为不缺口，此处如实记录）。
