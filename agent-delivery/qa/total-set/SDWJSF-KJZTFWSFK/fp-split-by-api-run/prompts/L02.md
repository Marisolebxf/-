六级及需规原文：

企业基础指标模型基于企业专题数据，通过与企业数据库和资讯数据库的对接，采集并清洗包括企业名称、行业、地区、注册信息、专利数量、技术交易额、业务领域、融资并购记录及动态变化等多维数据，以构建反映企业发展状况和产业特征的核心指标体系。各指标均经过标准化数据预处理（去重、去噪、格式统一、补全），并结合业务规则和分析模型计算结果，确保指标的完整性、准确性和可比性。模型支持API接口及消息队列服务，将计算结果与指标数据按地域、时间、领域等多维条件提供给用户查询、分析与应用，实现政府、企业和投资机构在政策制定、市场分析、战略规划中的数据化决策，并通过定期更新与监测机制，保持指标数据的实时性和有效性。
企业基础指标模型涵盖五类基础指标：重点企业提取、企业类型分布、企业领域分布、企业重点资讯，以及新增企业数量。
（1）重点企业提取
通过对接企业数据库，针对专利数、技术交易额等指标设立阈值，进行重点企业提取。
1）数据源对接：通过对接企业数据库，建立数据获取渠道。获取包括专利数、技术交易额等指标在内的企业数据，包括企业名称、所属行业、所属地区等信息。
2）数据清洗：对于从企业数据库中获取的数据，需要进行数据清洗处理，包括去重、去噪、格式化、补全等操作。在此基础上，需要对数据进行指标业务的分析，例如对企业所属行业、所属地区、企业规模等进行分析，以确保数据准确性和可靠性。针对专利数、技术交易额等指标，需要设立相应的阈值，以区分重点企业和非重点企业。
3）数据处理：根据设立的阈值，筛选出符合条件的重点企业。针对重点企业的专利数、技术交易额等指标，进行统计和计算，得出相应的指标结果。需要对计算结果进行有效性验证和调整，确保指标结果准确和可靠。同时，需要进行指标业务的分析，例如对重点企业的行业分布、地区分布、企业规模等进行分析，以更好地理解和应用数据结果。
4）数据服务开发：开发API接口，提供根据企业行业、地区、企业规模等条件查询对应的重点企业专利数、技术交易额等指标结果。通过API接口，用户可以灵活地查询重点企业的专利数、技术交易额等指标结果，并进行相关分析和应用。
5）数据同步：采用API接口、消息队列等方式将计算结果同步到数据服务中，以便用户查询和使用。将计算结果同步到数据服务中，可以方便用户查询、下载和使用重点企业专利数、技术交易额等指标结果，帮助用户更好地了解企业的创新情况和技术水平。同时，需要定期更新数据和指标，并对其进行监测和分析，以确保数据和指标的有效性和可靠性。
（2）企业类型分布

## 拆法（字段级 + 呈现层 3.1）

一条 = `endpoint.id` + `field_key` + **算法环节** + **具体描述**（可独立验收）。

| 契约 | 行数 | 算法环节 | 功能点命名提示 |
|------|------|----------|----------------|
| 入参 `params[]` | **1 行/参数** | 查询条件处理 | `算法输入-{name}{中文}` |
| 出参（数值/汇总/比率） | 1 行/字段 | 指标计算 | `算法输出-{name}{中文}` |
| 出参（标识/维度/列表成员） | 1 行/字段 | 结果组装 | `算法输出-{name}{中文}` |
| 哨兵 | 分行 | 分析结果生成 / 异常处理 | 功能点写空态或失败语义 |
| req_only（需规算法，无 catalog 字段） | 按需 | 模型计算 / 结果同步 等 | 功能点写需规短语；**不写数据源对接** |

**具体描述**须写清：针对哪一字段、本环节处理什么、校验失败或空态如何表现（勿空话）。

禁止：sample/viz 发明字段；`metricIds` 逐 id 拆行；同一入参拆成「处理」「传递」两行。
