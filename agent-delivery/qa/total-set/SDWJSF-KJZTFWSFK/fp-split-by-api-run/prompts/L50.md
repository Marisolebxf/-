六级及需规原文：

服务机构培育推荐模型用于评估与推荐具有发展潜力和培育价值的服务机构，基于竞争力、产业相关度、政策匹配度、机构潜力四个维度构建指标体系与阈值判断，通过综合计算形成培育推荐指数，为政府部门、行业协会、投融资平台等提供科学的机构认定与扶持依据。模型不仅适用于现有服务机构的优选推荐，也能根据不同区域、行业及政策环境，动态调整推荐结果以匹配最新发展需求。
（1）算法阐述
服务机构培育综合推荐模型旨在从竞争力、产业相关度、政策匹配度和发展潜力四个维度对服务机构进行系统量化分析，形成可用于优选、扶持和培育的推荐指数，支持政府部门、行业协会和投融资平台开展精准机构认定与资源配置。
模型首先对接行业协会信息库、政府开放数据平台及投融资系统等多源数据，采集并标准化处理服务机构的基础信息、业务能力、行业经验、典型服务案例等内容。在此基础上，构建涵盖四大维度的量化指标体系：
1）竞争力：以市场份额、客户满意度、技术能力、经营稳定性等为核心评价指标；
2）产业相关度：衡量机构服务范围与目标产业发展的契合度，包括产业链位置、上下游资源获取能力；
3）政策匹配度：评估机构与现行政策目标及重点扶持方向的符合程度；
4）发展潜力：综合分析创新能力、扩展能力、资本注入潜力及成长空间。
算法根据历史数据和专家经验设置各维度指标阈值，并采用加权计算方式生成综合推荐指数。推荐指数不仅反映现有竞争状态，还可揭示机构的培育价值及未来发展可能。
(2)算法输入与输出
输入：基础信息数据、业务能力指标、行业与政策数据、潜力数据。
输出：培育推荐指数（0–100分或分级结果）、单维度评分、推荐排序列表、推荐说明和培育建议。
(3)调用方式
模型支持通过标准化RestfulAPI和SDK接口调用，并可在可视化平台上提供按地域、机构类型、产业领域等条件的推荐及详细信息查询。调用时可指定筛选条件、时间区间及数据来源类型，快速返回推荐指数、排名及分析报告，支持与机构管理系统、政策管理平台及投融资决策系统对接，实现机构培育与推荐的智能化、自动化分析。

## 拆法（字段级 + 呈现层 3.1）

一条 = `endpoint.id` + `field_key` + **算法环节** + **具体描述**（可独立验收）。

| 契约 | 行数 | 算法环节 | 功能点命名提示 |
|------|------|----------|----------------|
| 入参 `params[]` | **1 行/参数** | 查询条件处理 | `算法输入-{name}{中文}` |
| 出参（数值/汇总/比率） | 1 行/字段 | 指标计算 | `算法输出-{name}{中文}` |
| 出参（标识/维度/列表成员） | 1 行/字段 | 结果组装 | `算法输出-{name}{中文}` |
| 哨兵 | 分行 | 分析结果生成 / 异常处理 | 功能点写空态或失败语义 |
