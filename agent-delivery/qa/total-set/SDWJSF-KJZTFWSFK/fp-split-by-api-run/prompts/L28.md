六级及需规原文：

企业发展历程模型算法基于企业基础指标（如财务与经营数据）及资讯基础指标（如新闻报道、行业动态），系统化采集并分析企业在发展过程中的重大事件信息。通过定义重大事件指标并设定阈值，当指标超出该阈值时，即认定为重大事件。模型据此生成企业重大事件时间线，用于刻画企业演进路径并为决策分析提供依据。
（1）算法阐述
该算法通过对接财务报表、经营数据、新闻媒体及行业数据库等多源数据，采集并标准化处理企业运营与舆情信息。基于企业发展特征，构建涵盖基础指标、资讯指标及重大事件指标的评价体系，并结合历史数据与专家经验设定阈值。
在事件识别阶段，算法能够检测并计算并购、上市、股权变更、重大投资等类型的重大事件，并按时间顺序生成事件时间线，形成企业发展历程视图，用于分析企业演化路径、战略变化以及关键节点。
该算法支持动态监测与优化，能够随数据变化自动标识新发生的重大事件；并通过API接口按企业标识查询重大事件及其时间线，满足政府、投资机构、行业研究机构在评估、决策与风险管理等多类场景下的应用需求。
（2）算法输入与输出
输入：企业财务报表数据、经营数据、新闻与行业资讯数据、重大事件指标体系及阈值设定。
输出：企业重大事件列表、重大事件时间线、发展历程可视化视图、分析报告。
（3）调用方式
支持通过RestfulAPI、SDK方式调用，可按企业标识或名称查询企业发展历程，获取重大事件分析结果，并支持导出报告及可视化图表。

## 拆法（字段级 + 呈现层 3.1）

一条 = `endpoint.id` + `field_key` + **算法环节** + **具体描述**（可独立验收）。

| 契约 | 行数 | 算法环节 | 功能点命名提示 |
|------|------|----------|----------------|
| 入参 `params[]` | **1 行/参数** | 查询条件处理 | `算法输入-{name}{中文}` |
| 出参（数值/汇总/比率） | 1 行/字段 | 指标计算 | `算法输出-{name}{中文}` |
| 出参（标识/维度/列表成员） | 1 行/字段 | 结果组装 | `算法输出-{name}{中文}` |
| 哨兵 | 分行 | 分析结果生成 / 异常处理 | 功能点写空态或失败语义 |
