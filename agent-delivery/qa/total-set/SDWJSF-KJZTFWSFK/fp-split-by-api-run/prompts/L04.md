1）数据源对接：对接数据融合中枢中的服务数据库，建立数据获取渠道。通过数据源对接，获取服务数据库中的相关数据，包括服务机构名称、所属产业领域、服务项目等信息。

3）数据处理：根据提取的服务机构和产业领域指标，综合计算全球服务机构在各个产业领域的服务规模指标，并通过环比计算增长率计算其趋势。需要对数据进行计算、归纳和统计等处理，得出服务规模指标和增长率指标。同时，需要对计算结果进行有效性验证和调整，确保指标结果准确和可靠。在数据处理的过程中，需要对不同产业领域中服务规模指标进行对比和分析，以确定全球服务机构在不同产业领域中的服务优势和劣势。同时，需要对服务规模指标进行细分，以确定服务规模的变化和趋势。

## 拆法（字段级 + 呈现层 3.1）

一条 = `endpoint.id` + `field_key` + **算法环节** + **具体描述**（可独立验收）。

| 契约 | 行数 | 算法环节 | 功能点命名提示 |
|------|------|----------|----------------|
| 入参 `params[]` | **1 行/参数** | 查询条件处理 | `算法输入-{name}{中文}` |
| 出参（数值/汇总/比率） | 1 行/字段 | 指标计算 | `算法输出-{name}{中文}` |
| 出参（标识/维度/列表成员） | 1 行/字段 | 结果组装 | `算法输出-{name}{中文}` |
| 哨兵 | 分行 | 分析结果生成 / 异常处理 | 功能点写空态或失败语义 |
| req_only（需规算法，无 catalog 字段） | 按需 | 模型计算 / 结果同步 等 | 功能点写需规短语；**不写数据源对接** |

**具体描述**须写清：针对哪一字段、本环节处理什么、校验失败或空态如何表现（勿空话）。

禁止：sample/viz 发明字段；`metricIds` 逐 id 拆行；同一入参拆成「处理」「传递」两行。
