六级及需规原文：

产业链关键环节识别模型算法旨在结合产业创新水平、企业规模和产业附加值等核心维度，对产业链结构进行量化分析，识别其中具有战略重要性和引领作用的关键环节。该算法通过系统采集产业相关数据，构建指标体系与阈值判定标准，经过模型训练与优化，计算各指标值并准确定位产业链的关键节点，为产业规划、政策制定及企业战略布局提供精确参考。
（1）算法阐述
该算法通过对接企业财务报表、产业统计年鉴、政策法规等多源数据，采集并标准化处理涵盖产业创新能力、企业规模、产业附加值等领域的指标信息。
在指标体系构建阶段，结合产业特征与用户需求，定义具有代表性和区分度的指标，并设定权重与阈值。
在计算与分析阶段，算法通过训练与优化识别模型，对采集数据进行量化计算，精准提取在产业链中具有核心支撑或引领作用的关键环节，并分析这些环节的战略重要性及对产业整体发展的影响。
该模型具备动态监测与自适应能力，能够根据最新产业数据实时更新分析结果；通过API接口支持基于产业标签的关键环节查询与分析服务，满足资源配置、政策评估和投资决策等应用需求。
（2）算法输入与输出
输入：企业财务报表数据、产业统计年鉴数据、政策法规数据、产业创新能力指标、企业规模指标、产业附加值指标、权重与阈值参数。
输出：产业链关键环节清单、战略重要性分析报告、可视化环节结构图、环节影响力评估结果。
（3）调用方式
支持通过RestfulAPI、SDK及可视化平台调用，可按产业标签或环节类型查询关键环节信息，并支持生成分析报告及数据导出服务。

## 拆法（字段级 + 呈现层 3.1）

一条 = `endpoint.id` + `field_key` + **算法环节** + **具体描述**（可独立验收）。

| 契约 | 行数 | 算法环节 | 功能点命名提示 |
|------|------|----------|----------------|
| 入参 `params[]` | **1 行/参数** | 查询条件处理 | `算法输入-{name}{中文}` |
| 出参（数值/汇总/比率） | 1 行/字段 | 指标计算 | `算法输出-{name}{中文}` |
| 出参（标识/维度/列表成员） | 1 行/字段 | 结果组装 | `算法输出-{name}{中文}` |
| 哨兵 | 分行 | 分析结果生成 / 异常处理 | 功能点写空态或失败语义 |
