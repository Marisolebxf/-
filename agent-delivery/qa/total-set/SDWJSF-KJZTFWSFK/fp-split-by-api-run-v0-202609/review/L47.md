## catalog 缺口（需规有、本页无 path）

1. **按机构名称查询**：需规「可按机构名称……获得技术力指数与分析报告」，catalog 仅点名入参 `kind`，无机构名称/机构标识 path 或 query。
2. **按行业类型过滤**：需规「按……行业类型……等条件」，catalog 无行业类型入参。
3. **按评估时间范围过滤**：需规「按……评估时间范围……等条件」，catalog 无时间范围入参。
4. **SDK 调用方式**：需规「标准化 RestfulAPI 和 SDK」，catalog 仅有 REST，无 SDK 契约（交付形态缺口，非 REST path）。
5. **分析报告独立接口**：需规输出含优势与短板分析清单、改进建议与潜在发展方向、趋势分析报告；本页仅 GET `/entan/v1/svc/models` 顶层 `tech`，无独立 report path。上述三项已挂在该 GET 上拆验收，此处记契约缺口。
6. **批量分析专用契约**：需规「批量分析」；顶层 `tech` 为数组可部分覆盖多机构列表，无独立批量/异步任务 path。
7. **外部系统对接**：需规「与政府部门、企业决策系统及投资机构分析平台无缝对接」，catalog 无对接/回调类接口。
8. **结果可视化展示**：需规「结果可视化展示」属界面能力，本轮禁止界面操作条目，不计入功能点表。
9. **权重/阈值只读查询**：需规「专家权重设定」「评价指标及阈值」，本页无 weights/阈值查询 path。
