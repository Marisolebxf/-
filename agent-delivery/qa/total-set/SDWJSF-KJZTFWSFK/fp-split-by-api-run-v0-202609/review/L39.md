## catalog 缺口（需规有、本页无 path）

1. **政策机遇清单 / 趋势分析报告 / 策略建议独立出口**：需规输出含「政策机遇清单、政策机遇趋势分析报告、策略建议」，本页仅 `GET /policy/v1/policy/analysis/opportunity` 且顶层结果体只点名 `opportunity_cnt`，无 list / report / advice 类 path；本轮把可验收部分挂在该 GET，独立契约仍缺。
2. **可视化图表独立出口**：需规「返回结构化机遇数据及可视化图表」「可视化结果」，catalog 无 viz / chart / download 类 path；本轮仅计接口返回结构化图表数据，不把联调台图表控件当界面操作。
3. **按政策标签 / 时间区间 / 分析维度查询入参**：需规「可按政策标签、时间区间及分析维度进行查询」，catalog 点名入参仅 `region_code`、`limit`，无 tag / time_range / dimension 点名参数。
4. **自动推送 / 平台集成**：需规「与政策管理系统或情报分析平台集成，实现对机遇信息的实时监测与自动推送」，catalog 无 push / webhook / subscribe path（实时监测按再次 GET 计 1 条状态；自动推送无独立契约）。
5. **SDK 调用方式**：需规「支持通过标准化 RestfulAPI 和 SDK 接口调用」，catalog 仅有 REST 接口，无 SDK 契约（属交付形态缺口，非 REST path）。
6. **多源采集入站**：需规输入含政策文本、解读与行业分析、历史政策指标，并接入政府部门/行业组织/权威信息平台的政策文件原文、权威解读、分析报告；catalog 无采集/接入 path（只读机遇分析结果口；预处理挂在该 GET 的算法条）。
7. **指标体系与阈值写入**：需规「建立基于关注度、影响力、稳定性等维度的评价指标体系及阈值判断标准」「依据历史分析数据及领域专家经验设定各维度阈值」，catalog 仅只读 GET，无阈值/指标配置写入或只读配置 path。
