1. **趋势监测 / 趋势变化图表**：需规点名「趋势监测」「趋势变化图表」，本页仅 score / ranking 两个 GET，无趋势查询 path。
2. **竞争力分析报告生成 / 数据导出**：需规「生成竞争力分析报告」「支持生成报告与数据导出」，本页无报告生成或导出 path（优势与短板挂在 ranking 的 dim 主结果体验收，不另发明 path）。
3. **按行业或区域筛选**：需规「可按企业名称、行业或区域进行竞争力水平分析」；catalog 仅 score.keyword（按企业名称）及 ranking.dim，无行业/区域点名入参或独立 path。
4. **分析指标体系与权重设置的写入/查询**：需规输入含「分析指标体系与权重设置」，本页无权重配置只读或写入 path（不发明其它六级已有的权重 path）。
5. **SDK 调用方式**：需规「支持通过 RestfulAPI、SDK 方式调用」，catalog 仅 REST 接口，无 SDK 类 path（SDK 属调用通道，接口级不拆条，仅记缺口）。
6. **多源输入对接**：需规输入财务报表、税务、人力资源、市场表现、企业调查等，catalog 仅查询类 GET，无多源采集/预处理写入 path。
