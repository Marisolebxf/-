六级及需规原文：

政策实体识别构建旨在通过对接多源政策相关数据库，自动化识别政策文本中的关键实体及属性信息，为政策制定、政策研究、法规解析等应用提供高质量数据支撑。系统将政策文档导入实体识别平台，并依据具体业务需求执行预处理与数据清洗，以确保数据准确、一致并可直接用于分析。在系统构建完成后，结合规则识别、词典识别、实体维护更新与属性提取，实现政策实体的精准识别、动态管理和持续优化。
通过稳定对接政府官方网站、新闻媒体、法规库及政策专题数据库等多源数据，采集政策文本并经统一预处理与清洗以确保质量；在识别环节，结合基于规则（正则匹配、关键词抽取）与基于词典（专业词典+分词与词性标注的NER方法）两种方式，提取政策实体的名称、级别、类型、发布地点及发布时间等信息；在维护更新方面，支持规则或人工方式新增、删除、修改实体并周期性批量更新；在属性提取方面，通过专题数据库获取并去重、纠错、补全政策级别、类型、地点、时间等核心属性，并定期同步更新，以保持政策实体库的完整性与时效性。

## 拆法（接口级）

一条 = 一个接口动作 + 一个对象 + 一条可验收规则。

每个去重后的 METHOD+path，有独立验收则分计：点名入参接收/校验、调用该 path、输出顶层主结果体、空态、失败（验收不同才分计）。catalog 或需规写了异步才计处理中。

禁止：嵌套字段 × 环节（那份技术/人才 Excel 的粒度，本轮不开）；同 path 再计网关转发；维度 × 空态；读实现仓补接口。

规则来源：原文直接 / 原文隐含 / 验收补充。  
拆分维度优先：校验 / 字段 / 算法 / 输出 / 状态 / 空态 / 异常。

图谱：ner/intra/hang 等按 path 分计；与兄弟六级共享 path 时本六级只写本页职责，合表去重。
