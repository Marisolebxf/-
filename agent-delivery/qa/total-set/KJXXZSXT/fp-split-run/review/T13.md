## 每条能否写出不同验收标准（抽 3 条说明）

3. **识别各成果的地理分布差异**（L6-6 / 算法 / 原文直接）：对比分析须给出各成果在地理分布上的差异结论；仅有创新价值或技术领域差异、无地理分布差异结论则不通过。与「展示各成果在地理分布方面的差异」（展示层）可单独判过/不通过。
