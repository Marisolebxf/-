## 每条能否写出不同验收标准（抽 3 条说明）

1. **以年度折线图展现课题递进变化**（L6-1 / 展示 / 原文直接）：给出年度折线图且表达课题递进变化；仅有饼/柱、无年度折线则不通过。与「以类型分布饼图展现课题结构变迁」图种与语义不同。
2. **联动多维图表与地理分布地图**（L6-2 / 展示规则 / 原文直接）：饼图或柱状图与地理分布地图联动；仅并排展示、互不联动则不通过。与「以地理分布地图展示课题贡献度」（有图即可）可单独判过/不通过。
3. **未完成维度格式与内容模板选择时不可导出报表**（L6-4 / 校验 / 原文隐含）：维度、格式、内容模板未选齐时阻断导出；三项选齐后允许自定义导出。与「未完成统计分析时不可生成专项报告」（阻断对象是专项报告而非导出报表）不是同一通过标准。
