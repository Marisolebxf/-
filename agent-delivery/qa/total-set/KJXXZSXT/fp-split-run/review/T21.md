## 抽 3 条可写出不同验收标准

1. **通过勾选选择需要展示的指标**：勾选后仅展示被勾选指标；与「提供创新产值指标」（体系中是否存在该字段）验收不同。

3. **将选定指标数据导出为 Excel 格式**：导出结果为 Excel 且含已选定指标数据；与「将选定指标数据导出为 CSV 格式」验收不同。
