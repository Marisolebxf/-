## 每条能否写出不同验收标准（抽 3 条说明）

1. **统计调用频率**（L6-1 / 算法 / 原文直接）：对每个主题数据算出调用频率；不算「展示调用频率」（有值才算展示通过）。与「展示调用时间」（原始时间字段、不要求算出频率）对象不同。
2. **识别调用高峰期**（L6-3 / 算法 / 原文直接）：时间序列统计完成后标出高峰期；仅有趋势曲线、未标高峰则不通过。与「识别调用低谷期」对象不同，通过标准不同。
3. **按被调用次数升序排列排行榜**（L6-4 / 排序 / 验收补充）：排行榜按被调用次数从低到高排列才通过。与「按被调用次数降序排列排行榜」方向相反，可单独判过/不通过。
