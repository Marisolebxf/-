## 每条能否写出不同验收标准（抽 3 条说明）

1. **自动显示预约服务状态**（L6-1 / 字段展示 / 原文直接）：地图上给出服务状态；仅有周期或频率、无状态则本条不通过。与「自动显示预约服务周期」对象不同，通过标准不同。
