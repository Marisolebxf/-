## 每条能否写出不同验收标准（抽 3 条说明）

1. **按类别筛选结构化数据**（L6-1 / 筛选 / 原文直接）：查询结果仅含所选类别；未按类别收窄则不通过。与「按时间筛选结构化数据」「按主题筛选结构化数据」维度不同，通过标准不同。
2. **提供传播内容图片**（L6-2 / 字段 / 原文直接）：详细数据接口返回图片；仅有文本/元数据、无图片则本条不通过。与「提供传播内容文本」对象不同。
3. **校验前端应用与展示渠道数据一致**（L6-3 / 校验 / 原文直接）：分发后各前端应用与展示渠道数据相同才通过；仅完成分发但端间不一致则不通过。与「识别多端数据不一致」（检出差异本身）可单独判过/不通过。
