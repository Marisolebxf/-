## 每条能否写出不同验收标准（抽 3 条说明）

1. **点赞课题成果**（L6-1 / 动作 / 原文直接）：在课题成果页完成点赞；仅展示评论区或仅提交评论、未点赞则不通过。与「提交评论」对象与动作不同。
2. **推送相关案例动态**（L6-2 / 输出 / 原文直接）：对已关注课题推送相关案例；只推更新成果或社区活动、缺相关案例则本条不通过。与另两类动态可单独判过/不通过。
3. **未生成专属链接时不可分享成果**（L6-3 / 校验 / 原文隐含）：专属链接未生成时阻断一键分享；已生成后三渠道分享才可执行。与「未发生分享时不可统计传播路径」（分享发生后才统计）不是同一通过标准。
