## 每条能否写出不同验收标准（抽 3 条说明）

1. **为创新载体提供分项数据接口**（L6-1 / 动作 / 原文直接）：存在面向创新载体的分项接口并可调用；人才/专利/企业接口不能替代本条。与「为企业提供分项数据接口」对象不同，通过标准不同。
2. **联合推送地理信息、视频图片与资讯多维数据**（L6-2 / 动作 / 原文直接）：三类数据可一次联合到达；仅推送其中一类不算通过。与「推送资讯数据」（单维推送）可单独判过/不通过。
3. **校验刷新后前端与接口信息一致**（L6-3 / 校验 / 原文直接）：实时刷新完成后，专题页面展示与接口返回一致；仅刷新成功但展示与返回不一致则不通过。与「对前端专题页面实时刷新数据」（刷新动作本身）不是同一通过标准。
