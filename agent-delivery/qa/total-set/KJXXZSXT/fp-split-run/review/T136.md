## 每条能否写出不同验收标准（抽 3 条说明）

1. **开展政策实施效果的深度分析**（算法 / 原文直接）：对已具备的政策对比结果完成实施效果分析；不含社会经济效益/产业影响/发展趋势。与「开展社会经济效益的深度分析」对象不同，通过标准不同。
2. **未具备行业数据时不可形成专业分析结论**（校验 / 原文隐含）：无行业数据时阻断「基于模型算法形成专业分析结论」；仅有对比结果与四维分析、缺行业数据仍不可出结论。与「未具备政策对比结果时不可开展政策深度分析」（入口拦截，分析尚未开始）通过标准不同。
3. **展示专业分析结论**（展示 / 原文直接）：模型算法形成结论后展示综合结论；仅有四维分项结果、无综合结论则不通过。与「展示政策实施效果分析结果」（单维分项）可单独判过/不通过。
