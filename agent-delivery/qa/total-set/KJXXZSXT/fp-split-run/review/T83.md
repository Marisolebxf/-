## 每条能否写出不同验收标准（抽 3 条说明）

1. **以内置广度优先搜索（BFS）执行路径查找**（L6-1 / 算法 / 原文直接）：路径查找走 BFS；不含 DFS/Dijkstra/Bellman-Ford/A* 的执行结果。与「以内置深度优先搜索（DFS）执行路径查找」算法不同，通过标准不同。
