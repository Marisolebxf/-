## 每条能否写出不同验收标准（抽 3 条说明）

1. **展示资源所属学科领域**（L6-1 / 字段展示 / 原文直接）：归类完成后资源侧可见学科领域取值；缺该字段则不通过。与「展示资源所属业务专题」对象不同，可单独判过/不通过。
2. **按来源机构分区展示接入数据资源**（L6-2 / 筛选 / 原文直接）：分区方式切到来源机构后，明细按来源机构聚合；仍按区域或分库聚合则不通过。与「按区域分区展示接入数据资源」不是同一通过标准。
3. **校验时间范围起点不得晚于终点**（L6-3 / 校验 / 验收补充）：按时间检索时起点晚于终点须阻断并提示；起止合法才出检索结果。与「按时间检索接入资源详情」（维度是否生效）不是同一通过标准。
