## 每条能否写出不同验收标准（抽 3 条说明）

1. **统计专利申请数量**（L6-1 / 算法 / 原文直接）：对已选领域算出专利申请数量；不含授权量。与「统计专利授权数量」对象不同，通过标准不同。
2. **校验指标权重之和为 100%**（L6-4 / 校验 / 原文隐含）：已纳入指标权重之和 ≠100% 时阻断计分并提示；=100% 时允许出综合得分。与「校验单指标权重为非负数值」（单值符号）不是同一通过标准。
3. **展示预测置信区间**（L6-6 / 展示 / 原文直接）：预测完成后给出置信区间；仅有点预测、无区间则不通过。与「展示技术创新力预测结果」（点预测本身）可单独判过/不通过。
