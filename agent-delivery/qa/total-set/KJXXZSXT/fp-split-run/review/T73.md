## 每条能否写出不同验收标准（抽 3 条说明）

1. **详尽列出数据资源的列名称**（L6-1 / 字段展示 / 原文直接）：识别完成后给出每个数据资源的列名称清单；仅有列类型或字段描述、缺列名称则不通过。与「详尽列出数据资源的列类型」对象不同。
2. **多维筛选条件同时生效**（L6-3 / 展示规则 / 原文隐含）：同时设置两个及以上已写维度时，结果须同时满足全部条件；只生效单一维度则不通过。与「按数据表名称筛选数据资源」（单维）不是同一通过标准。
3. **以饼图展现数据资源使用情况**（L6-4 / 展示 / 原文直接）：使用情况以饼图呈现；仅有柱状图或趋势线、无饼图则本条不通过。与「以趋势线展现数据资源使用情况」图种不同。
