## 每条能否写出不同验收标准（抽 3 条说明）

1. **自动识别数据调用对应的应用系统名称**（L6-1 / 算法 / 原文直接）：每次数据调用能得到应用系统名称；只识别出部门、无应用名称则本条不通过。与「自动识别数据调用对应的业务来源部门」对象不同。
2. **按调用时间维度筛选数据调用详情**（L6-3 / 筛选 / 原文直接）：按调用时间条件过滤后只保留时间命中的调用详情；仅按应用名称或业务部门过滤、时间条件不生效则本条不通过。与「按应用名称筛选数据调用详情」维度不同。
3. **批量导出业务应用调用详细日志**（L6-4 / 输出 / 原文直接）：批量导出结果含调用详细日志；只出统计数据、无详细日志则本条不通过。与「批量导出业务应用调用统计数据」「自动生成数据报告」输出物不同。
