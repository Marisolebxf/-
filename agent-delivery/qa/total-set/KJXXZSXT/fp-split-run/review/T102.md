## 每条能否写出不同验收标准（抽 3 条说明）

1. **按地理位置分层高亮各类型仪器**（L6-2 / 展示规则 / 原文直接）：各类型仪器按地理位置分层高亮；仅有服务区域高亮、无地理位置分层则不通过。与「按服务区域分层高亮各类型仪器」分层依据不同。
2. **弹窗展示仪器原值**（L6-5 / 字段展示 / 原文直接）：弹窗给出该仪器原值；有型号无原值则本条不通过。与「弹窗展示仪器服务价格」字段不同。
3. **生成实时分析报告**（L6-6 / 输出 / 原文直接）：在已收集反馈评价、使用频率且历史数据足够时产出实时分析报告；仅有收集结果、无报告则不通过。与「展示实时分析报告」（查看已生成报告）可单独判过/不通过。
