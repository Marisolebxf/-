## 每条能否写出不同验收标准（抽 3 条说明）

1. **对多源政策数据去重合并**（算法 / 原文直接）：多源接入后同一政策记录合并为一条；仍保留重复则不通过。与「对政策数据格式标准化」（统一字段格式，不负责消重）对象与通过标准不同。
2. **按完整性校验政策基础数据**（校验 / 原文直接）：按已建规则检查必填/覆盖是否完整；缺项则该条不通过完整性校验。与「按准确性校验政策基础数据」（对错而非缺全）可单独判过/不通过。
3. **质量校验未通过时不可作为高质量数据源输出**（校验 / 原文隐含）：准确性/完整性/一致性未通过的数据不得进入「向政策智能分析提供高质量政策数据源」；仅清洗完成但校验未过仍阻断输出。与「向政策智能分析提供高质量政策数据源」（输出动作本身）通过标准不同。
