## 有无笛卡尔积 / 套话 / 未点名指标

- 笛卡尔积：无。四类机构只按类别高亮各计一次，未与地理分布/资源状态交叉出格；三弹窗字段未再乘导出报告；三检索条件未再乘三展示字段成 9 格；三项实时指标未再乘高亮/高效机构。空态/失败按六级结果链路计，未按类别×图层×报告再乘。
- 套话：无。对象操作为「点击机构节点打开机构信息弹窗」「选择待批量导出的服务机构」，不是「选择××作为分析对象」。
- 未点名指标：无。「等」只取已写名称（科研院所/高校/企业/检测机构；机构优势资源/历史服务评价/共享能力评分；仪器服务项目/服务流程/适用范围；仪器资源开放率/当前活跃状态/使用频率）。未发明未点名城市、收藏/分享/订阅、排名升降序、LLM。需规已写导出已拆。

## 每条能否写出不同验收标准（抽 3 条说明）

1. **按科研院所类别在地图高亮展示服务机构**（L6-1 / 展示 / 原文直接）：地图上科研院所类别机构被高亮；高校/企业/检测机构高亮不代替本条。与「按高校类别在地图高亮展示服务机构」对象类别不同。
2. **未选择待导出机构时不可批量导出机构分析报告**（L6-2 / 校验 / 原文隐含）：未选中任何待导出机构时阻断批量导出、不产出报告文件。与「批量导出机构分析报告」（已选机构后产出报告）门禁 vs 输出不同。
3. **高亮显示热门资源**（L6-4 / 展示规则 / 原文直接）：已识别的热门资源在界面被高亮；仅有开放率数值、无高亮则不通过。与「实时统计仪器资源开放率」（算出开放率）及「识别热门资源」（判定哪些算热门）可单独判过/不通过。
