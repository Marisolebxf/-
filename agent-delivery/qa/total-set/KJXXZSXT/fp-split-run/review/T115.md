## 每条能否写出不同验收标准（抽 3 条说明）

1. **按领域属性分类整理活动**（L6-1 / 字段 / 原文直接）：分类结果须带领域属性；仅有规模而无领域则本条不通过。与「按规模属性分类整理活动」对象属性不同。
