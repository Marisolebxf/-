## 每条能否写出不同验收标准（抽 3 条说明）

1. **自动提炼政策分析的核心观点**（算法 / 原文直接）：从政策分析抽出核心观点；不含决策建议/风险提示/发展机遇。与「自动提炼政策分析的决策建议」对象不同，通过标准不同。
2. **未完成核心观点、决策建议、风险提示与发展机遇提炼时不可形成洞察结论**（校验 / 原文隐含）：四类提炼未齐时阻断「形成洞察结论」；四类均完成后才允许形成。与「未具备政策分析时不可提炼洞察结论」（源侧拦截，发生在提炼前）不是同一通过标准。
3. **展示洞察结论**（展示 / 原文直接）：展示已形成、具备决策支撑价值的整段洞察结论。与「展示核心观点」（仅四类之一的字段展示）可单独判过/不通过。
