## 每条能否写出不同验收标准（抽 3 条说明）

1. **自动定位全球各区域研究主体分布密度**（L6-1 / 定位 / 原文直接）：选定时间段后在地图上给出各区域研究主体分布密度；仅有轨迹、无密度则不通过。与「自动定位全球各区域研究主体演化轨迹」对象不同。
2. **校验比对时间段不少于两段**（L6-6 / 校验 / 原文隐含）：已选比对时间段不足 2 段时不可出比对结果；满 2 段才允许生成图表/报告。与「比对不同时间段主体分布数据」（比对动作本身）不是同一通过标准。
3. **一键导出预警提示与趋势报告**（L6-3 / 输出 / 原文直接）：预警提示与趋势报告均已生成后一次导出；缺任一产物则不通过。与「未生成预警提示或趋势报告时不可导出」（门禁）及「生成趋势报告」（报告生成）可单独判过/不通过。
