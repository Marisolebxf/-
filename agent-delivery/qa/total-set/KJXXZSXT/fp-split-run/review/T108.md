## 每条能否写出不同验收标准（抽 3 条说明）

1. **自动统计每个载体的毕业企业占比**（L6-1 / 算法 / 原文直接）：按载体算出毕业企业占比；不含孵化企业总数本身。与「自动统计每个载体的孵化企业总数」对象不同，通过标准不同。
2. **未关联企业融资信息时不可统计投资金额与融资动态**（L6-2 / 校验 / 原文隐含）：无企业融资信息关联结果时阻断季度投资统计；已关联后才允许出投资总额/增长趋势。与「展示企业融资信息为空提示」（空态提示、不阻断）不是同一通过标准。
3. **自动归纳服务劣项**（L6-5 / 算法 / 原文直接）：从已收集评价与评分中归纳服务劣项；仅有优项或仅有改进建议、无劣项归纳则本条不通过。与「自动归纳服务优项」「自动归纳改进建议」可单独判过/不通过。
