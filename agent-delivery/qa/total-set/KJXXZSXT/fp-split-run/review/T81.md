## 每条能否写出不同验收标准（抽 3 条说明）

1. **纳入知识图谱分析指标进行整合**（L6-1 / 字段 / 原文直接）：整合池中出现知识图谱分析指标；不含「仅有传统统计指标或模型特征即算纳入本类」。与「纳入传统统计指标进行整合」对象不同，通过标准不同。
2. **校验各类指标权重之和为 100%**（L6-2 / 校验 / 原文隐含）：已纳入指标权重之和 ≠100% 时阻断配置确认并提示；=100% 时允许展示指标体系配置结果。与「校验单指标权重为非负数值」（单值符号）不是同一通过标准。
3. **对科研项目进行综合评分**（L6-5 / 算法 / 原文直接）：对科研项目算出综合评分；不含科研人员/科研机构得分。与「对科研人员进行综合评分」对象不同，通过标准不同。
