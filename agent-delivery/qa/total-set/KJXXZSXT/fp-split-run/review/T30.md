## 抽 3 条可写出不同验收标准

1. **以树状结构展示指标项**：验收为指标项按父子层级以树呈现；与「以表格形式展示指标项」互斥于呈现形态，不可用同一断言。
2. **展示计算公式**：验收为当前指标出现计算公式字段；与「展示计算方法示例」不同，后者验收示例样本，公式缺失时仍可单独判示例空态。
3. **未完成关联识别时不可展示关联内容**：验收为关联算法未完成则不展示「与其他指标的关联」；与「未选中指标项时不可查看意义解读」不同，后者卡在未点选指标，本条卡在已选指标但关联未识别。
