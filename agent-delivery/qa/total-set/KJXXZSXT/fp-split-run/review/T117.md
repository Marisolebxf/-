## 每条能否写出不同验收标准（抽 3 条说明）

1. **按标签条件筛选活动**（L6-1 / 筛选 / 原文直接）：按已给标签条件返回匹配活动；不含多维检索的其它条件组合。与「返回活动多维检索结果」（检索结果整体）通过标准不同。
