## 每条能否写出不同验收标准（抽 3 条说明）

1. **抽取政策中的量化指标**（算法 / 原文直接）：从已选政策中抽出量化指标；不含补贴标准。与「抽取政策中的补贴标准」对象不同，通过标准不同。
2. **输出标准化指标数据集支撑多维对比**（输出 / 原文直接）：形成后的标准化指标数据集可被后续多维对比消费；仅能做单点数值查看、不能按维度对比则不通过。与「输出标准化指标数据集支撑量化分析」（数值测算/比较）可单独判过/不通过。
3. **展示关键指标抽取为空提示**（空态 / 验收补充）：已选政策但抽不出四类关键数据时给出空提示。与「展示关键指标抽取失败提示」（抽取过程失败）不是同一通过标准。
