## 每条能否写出不同验收标准（抽 3 条说明）

1. **一键导出Excel格式**（L6-1 / 输出 / 原文直接）：按已选范围一键得到 Excel 文件；仅 PDF/CSV、无 Excel 则不通过。与「一键导出PDF格式」对象不同，通过标准不同。
2. **超过导出频次限制时不可导出**（L6-3 / 校验 / 原文隐含）：已达频次上限时阻断导出并提示；未超限时允许导出。与「未通过安全审查时不可导出」（审查结论而非次数）不是同一通过标准。
3. **在专题报告中展示趋势分析**（L6-2 / 展示 / 原文直接）：生成后的专题报告含趋势分析章节；仅有分布结构、无趋势分析则不通过。与「在专题报告中展示分布结构」可单独判过/不通过。
