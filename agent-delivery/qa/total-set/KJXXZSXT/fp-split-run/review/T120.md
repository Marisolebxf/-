## 每条能否写出不同验收标准（抽 3 条说明）

1. **推送举办方**（L6-1 / 输出 / 原文直接）：专用接口返回举办方数据；仅有竞赛基础信息、无举办方则不通过。与「推送赛事详情」对象不同，通过标准不同。
2. **未完成查询时不可输出学习资源**（L6-2 / 校验 / 原文隐含）：项目查询未完成时阻断学习资源输出；查询完成后才允许输出。与「未完成查询时不可输出应用资源」（应用资源对象）不是同一通过标准。
3. **按成绩升序排列排行榜**（L6-3 / 排序 / 验收补充）：成绩排行榜按成绩从低到高排列；与「按成绩降序排列排行榜」方向相反，可单独判过/不通过。
