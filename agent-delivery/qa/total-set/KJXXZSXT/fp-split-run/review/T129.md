## 每条能否写出不同验收标准（抽 3 条说明）

1. **拆分政策章节**（算法 / 原文直接）：政策内容拆出章节层节点；不含条目层、细则层。与「拆分政策条目」层级不同，通过标准不同。
2. **提取责任主体核心条款**（算法 / 原文直接）：从政策内容抽出责任主体；不含政策目标/扶持措施/保障机制。与「提取政策目标核心条款」对象不同，可单独判过/不通过。
3. **分层展示政策章节、条目与细则**（展示 / 原文直接）：拆解结果按章节→条目→细则层级呈现，而非平铺单一列表。与「展示政策目标核心条款」（核心条款字段，非层级树）可单独判过/不通过。
