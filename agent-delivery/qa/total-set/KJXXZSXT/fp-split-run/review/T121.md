- 表头拆分维度：动作 8、校验 7、算法 6、异常 4、筛选 3、展示 3、空态 3、状态 3、输出 3；逐行分计一致，合计 40 = 条数。
- 表头规则来源：原文直接 20、验收补充 10、原文隐含 10；逐行分计一致，合计 40 = 条数。
- 覆盖全部六级：传播内容多维数据归档 15、数据清洗与标准化 12、内容关联与聚合 13。
- 无笛卡尔积：八类内容只按归档各计一次，未与分类/主题/时间交叉；内容属性与内在联系只作用于关联，聚合作为已关联后的下一步，未做 2 依据 × 2 动作。
- 无套话「选择××作为分析对象」；「等」只取需规已写名称（展览/讲坛/院士/期刊会议/图书/讲堂/文化交流/新媒体，分类/主题/时间）。未发明未点名城市、指标或展示主题名。
- 需规未写订阅/导出/收藏/分享，未拆。
- **是否误用了原型或五件套**：否。未读 demo-ui-science、页面/路由/组件、USM/TRACE/IA/UX/Wireframe、既有测试用例、专题 v8 Excel、其它 Txx 业务功能点；唯一需求源为本提示词六级需规全文，金样 T27 只学表头与拆法。

抽 3 条说明不同验收标准：

1. `归档展览内容`：归档对象仅为展览，不得混入讲坛或图书；与「归档讲坛内容」以内容类型区分。
2. `未完成归档时不可清洗与标准化`：无已归档数据时去重/纠错/格式统一不可执行、不产出清洗结果；与「对归档数据去重」以门禁 vs 计算区分。
3. `未完成关联时不可聚合`：关联未完成时不得产出聚合结果；与「对已关联数据执行聚合」以门禁 vs 计算区分。

结论：通过。建议进入全量。
