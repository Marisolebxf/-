## 每条能否写出不同验收标准（抽 3 条说明）

1. **集成标签传播（LPA）算法**（L6-1 / 算法 / 原文直接）：算法清单中具备标签传播（LPA）并可完成社区检测；不含「仅有 Louvain 或谱聚类即算具备 LPA」。与「集成Louvain算法」对象不同，通过标准不同。
2. **校验时间范围起点不得晚于终点**（L6-4 / 校验 / 验收补充）：时间范围起点晚于终点时阻断追踪并提示；起止合法时允许按时间范围追踪。与「按时间范围追踪社群动态变化」（维度筛选本身）不是同一通过标准。
3. **以热力图展示社群划分结果**（L6-5 / 展示 / 原文直接）：划分结果以热力图呈现；仅有网络图或颜色分区、无热力图则不通过。与「以网络图展示社群划分结果」图种不同，通过标准不同。
