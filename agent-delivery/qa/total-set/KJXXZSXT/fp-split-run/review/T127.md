抽 3 条说明不同验收标准：

1. `提供扶持力度指标`：指标库须含「扶持力度」；不含适用范围/实施时效/申请条件的入库存活。与「提供适用范围指标」以指标名称区分。
2. `未梳理政策核心指标维度时不可搭建标准化政策指标库`：核心指标维度未梳理完成时不得产出标准化政策指标库；与「搭建标准化政策指标库」以门禁 vs 构建动作区分。
3. `为政策拆解提供数据支撑`：库建成后须能向政策拆解供数；仅能支撑对比分析、不能支撑拆解则不通过。与「为政策对比分析提供数据支撑」以下游用途区分。

结论：通过。
