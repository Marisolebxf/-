六级及需规原文（唯一需求源）：

**L6-1 基础信息展示**  
展示人才的姓名、性别、国籍、出生年份、教育背景、工作单位、职位等基础数据，方便管理人员进行初步识别和筛选。

**L6-2 科研成果统计**  
汇聚并统计人才的代表性论文、著作、专利、科研项目等详细信息，包括发表数量、被引用次数、成果影响力，便于评估学术实力。

**L6-3 学术影响力分析**  
利用文献引用数据及领域热点分析，对人才的学术影响力、h指数、学科贡献度进行量化评估，为引进决策提供参考。

**L6-4 研究领域与方向标签**  
通过自然语言处理技术自动识别人才的主要研究领域、专业方向和技术标签，便于精准匹配机构需求或团队合作。

**L6-5 合作网络与关联专家**  
展示人才与国内外专家的合作关系、合作机构及团队分布，帮助了解其学术社交与资源网络。

**L6-6 最新动态跟踪**  
实时更新人才的最新活动，如论文发表、项目申报、学术交流、受邀讲座等内容，让管理者及时掌握其活跃度和进展情况。

**L6-7 人才评估与匹配度分析**  
综合各项数据，对人才的潜力、风险、与需求岗位的匹配度进行智能分析并生成评估报告，辅助引进与选拔决策。

**L6-8 荣誉及奖项展示**  
展示人才获得的各类重要奖项、荣誉称号及社会影响力相关数据，提升全面认识人才的优质资源特征。

**L6-9 国际合作与出访记录**  
详细列举人才参与的国际合作项目、出访经历以及海外学术交流情况，助力引进具有全球视野的专家。
