六级及需规原文（唯一需求源）：

**L6-1 动态查询**  
科技知识图谱支持用户根据自定义条件（如关键词、实体属性、时间范围），实时检索和访问海量科技数据。无论是文献、专利、机构还是技术领域，用户都能瞬时获得精准的查询结果，实现数据的高效检索和即时反馈。这一功能有助于快速定位所需的信息，加速科研或管理决策。

**L6-2 数据过滤与筛选**  
内置多维度、多类型的过滤条件，比如按地域、时间、技术分类、作者、合作关系等进行筛选。用户可以自由组合过滤项，排除无关信息，专注分析关注的目标数据子集。强大的过滤与筛选功能让用户能精准掌控大规模知识网络的数据视角与深度。

**L6-3 多维度分析**  
支持对数据进行多层次、跨领域的切片与切块分析，例如按机构、领域、时间发展、合作网络等展开，揭示数据背后复杂的结构、关系和潜在规律。多维度分析可以帮助用户洞察技术发展趋势、发现关键人物和创新路径，全面把握知识图谱的价值

**L6-4 交互式可视化**  
分析结果以直观的图表、网络图、时序演化图等方式呈现，用户可通过拖拽、缩放、点击等交互操作自由探索数据结构及其关联。动态图谱展示不仅便于理解复杂关系，也赋能用户逐层深入分析，实现科技情报的可视化洞察与发现。
