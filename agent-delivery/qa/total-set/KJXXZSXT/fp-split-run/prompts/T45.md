六级及需规原文（唯一需求源）：

**L6-1 人才分布信息查看**  
人才分布信息查看的具体功能包括区域分布概览、城市与区域详情。
（1）区域分布概览
用户可以在地图上查看各国家或地区的人才分布概览，通过颜色深浅或热力显示不同地区的人才密度。例如，查看人工智能领域在北美、欧洲、亚洲等地的人才集中情况。
（2）城市与区域详情
支持点击地区或城市，弹出该地具体人才分布详情，包括行业、学历、类型等统计数据。例如，点击“旧金山”，可查看该地AI领域硕士及以上人才数量与主要院校。

**L6-2 地图多层级浏览与筛选**  
地图多层级浏览与筛选的具体功能包括多级缩放、定制筛选。
（1）多级缩放
从全球、国家、省州到具体城市，支持地图多级缩放，用户可逐级深入查看人才的分布变化。例如，从全球分布逐步放大到深圳市，分析该市在某领域人才的聚集度。
（2）定制筛选
用户可通过筛选栏自定义行业类别、人才类型和时间维度，地图展示会随之动态调整。例如，筛选“生物医药领域”，地图只显示对应人才分布热力图。

**L6-3 交互式操作与动态追踪**  
交互式操作与动态追踪的具体功能包括鼠标滚轮缩放、自动定位放大、动态筛选互动。
（1）鼠标滚轮缩放
支持鼠标滚轮进行地图放大与缩小，便于用户灵活调整视图范围。
（2）自动定位放大
当用户搜索特定城市或机构时，地图可自动定位并放大至相关区域，方便查看详细人才分布。例如，输入“慕尼黑工业大学”，地图自动放大并显示该区域人才数据。
（3）动态筛选互动
用户可点击区域或标签，地图实时响应，联动更新分布信息和下方数据面板。例如，点击“英国伦敦”，地图高亮并展示伦敦各领域的人才统计及流动趋势。

**L6-4 人才流动和迁移图示**  
人才流动和迁移图示的具体功能包括流动路径动画、区域热点自动高亮。
（1）流动路径动画
可展示人才从一个地区流向另一区域的迁移动画和趋势线。例如，看到近年AI人才从硅谷流向新加坡的变化。
（2）区域热点自动高亮
根据数据变化，人才密集区域自动高亮，提示用户重点关注。例如，自动标注“柏林”为区块链工程师聚集地。

**L6-5 地图数据联动与报表导出**  
地图数据联动与报表导出的具体功能包括信息弹窗与明细面板、数据导出。
（1）信息弹窗与明细面板
点击分布区域后弹出详细人才信息，包括数量、学历、主流行业。
（2）数据导出
支持将当前地图展示的人才分布数据导出为报告或表格格式，用于线下分析和决策参考。例如，企业导出全球半导体人才分布表用于制定招聘策略。
