六级及需规原文（唯一需求源）：

**L6-1 华人占比分析**  
华人占比分析的具体功能包括分区展示、机构筛选。
（1）分区展示
支持按国家或地区展示全球各领域人才中的华人占比。用户可直观查看不同区域华人科技人才比例。例如，点击美国或英国区域，即可显示本地华人科技人才占比详情。
（2）机构筛选
用户可以选择顶尖高校和研究机构，系统自动统计并展示其中华人学者或专家的比例。如，点击“麻省理工学院”，弹出该机构华人教师与研究员人数的统计图。

**L6-2 地区分布洞察**  
地区分布洞察的具体功能包括多层级分布、多维数据联动。
（1）多层级分布
允许用户由全球视角逐级放大至各大洲、国家或城市，查看不同地区的科技人才分布及结构变化。例如，从全球分布逐级放大至旧金山市，了解该市各学科人才分布状况。
（2）多维数据联动
通过筛选学科、领域或时间段，实时调整地图和统计面板的地区分布结果。如，筛选“过去三年生物医药领域”，即可展示相关人才在主要城市的分布热度。

**L6-3 顶尖机构洞察**  
顶尖机构洞察的具体功能包括机构排名可视化、机构详情弹窗。
（1）机构排名可视化
自动整合全球顶尖学术机构和科研单位的人才汇聚情况，并展示排名与分布。例如，查看全球前20所高校的人工智能方向人才主要来源。
（2）机构详情弹窗
点击机构后，可弹出详细人才分析，包括学历结构、研究领域及核心成果。如，点击“斯坦福大学”弹窗显示近三年人才论文数量及主要成果。

**L6-4 产研对比分析**  
产研对比分析的具体功能包括产业与科研分布并列展示、一键切换视图。
（1）产业与科研分布并列展示
可分别筛选企业与高校/科研院所在全球科技人才分布图中的数量与比例，支持对比分析。例如，比较深圳科技企业与当地大学人才分布和特色领域。
（2）一键切换视图
用户可快速切换“产”与“研”视图，分别看到两者的人才分布与动态升级情况，为政策和引才决策提供依据。

**L6-5 人才迁徙情况展示**  
人才迁徙情况展示的具体功能包括动态迁徙路径、热点流入流出地区分析。
（1）动态迁徙路径
利用职位变动与机构流动历史，展示人才迁徙轨迹，支持按时间轴追踪人才流动趋势。例如，查看高水平科研人才从欧美流向中国的迁移路径动画。
（2）热点流入流出地区分析
可自动高亮人才主要流入或流出区域，方便用户识别人才聚集或流失风险。如，标注新加坡为近三年人工智能人才流入热点。
