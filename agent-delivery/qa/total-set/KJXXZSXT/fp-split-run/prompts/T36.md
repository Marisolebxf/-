六级及需规原文（唯一需求源）：

**L6-1 多维度检索条件设置**  
系统支持对地方、国家、海外的科创政策、行业政策、园区政策、招商政策、人才政策等多源政策进行数据集成。用户可在检索界面通过政策类别、行业领域、发布部门、地区等多个维度进行筛选，系统整合所有来源的政策信息，自动生成全景可视化展示。

**L6-2 高级检索功能**  
提供高级检索选项，支持用户设置更复杂的检索条件，如政策关键词、发布机构、政策效力级别、政策状态（有效、失效、修订中），并支持布尔逻辑运算（AND、OR、NOT）组合多个检索条件，实现更精准的政策检索。

**L6-3 检索结果智能排序**  
根据政策的相关性、时效性、重要性等多个因素对检索结果进行智能排序，用户也可选择按发布时间、政策级别、浏览量等不同维度对结果排序，快速找到最相关的政策信息。

**L6-4 检索结果筛选与分类**  
提供检索结果的二次筛选功能，用户可在已有检索结果基础上，进一步按政策类型、发布时间、地域等维度进行筛选，同时支持自动将检索结果按类别进行分组展示，便于用户快速浏览和定位。

**L6-5 检索历史与收藏**  
自动记录用户的检索历史，用户可快速查看和重复执行之前的检索操作；同时支持用户将重要的政策信息添加到收藏夹，便于后续查看和管理。

**L6-6 检索结果导出与分享**  
用户可将检索结果导出为Excel、PDF等格式，便于离线查看和分析；同时支持将检索结果通过链接或邮件形式分享给其他用户，促进政策信息的共享和交流。
