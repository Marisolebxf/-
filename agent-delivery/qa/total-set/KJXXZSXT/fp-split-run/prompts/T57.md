六级及需规原文（唯一需求源）：

**L6-1 可视化层级分析**  
可视化层级分析的具体功能包括多级放大、关系网络放大、模块自动聚焦。
（1）多级放大
支持贡献度分析的多级视图，用户可从整体学科概览逐步放大到具体学者，甚至单个成果，细致查看不同层面的贡献分布和影响力动态。
（2）关系网络放大
通过智能关系网络分析，用户可以聚焦某一领域或团队，放大查看专家与其它学者的合作关系和学科交互作用，掌握核心学术圈层贡献结构。
（3）模块自动聚焦
在人才搜索或报告生成过程中，页面会自动对专家贡献高的学科方向进行聚焦放大，让用户直观感知引进后的潜在增益领域。

**L6-2 多维数据联动**  
多维数据联动的具体功能包括指标缩放展示、贡献图谱放大、可交互热力图。
（1）指标缩放展示
支持对贡献度分析核心指标如论文质量、影响因子、项目数、专利量等进行缩放对比，便于用户针对不同评价维度调整视图深入了解专家学科价值。
（2）贡献图谱放大
利用学科知识图谱技术，支持贡献路径的放大显示，从分领域到跨学科动态，展示专家带来的内外部协同增益。
（3）可交互热力图
结合贡献度分布生成可交互热力图，通过放大操作突出贡献密集区域，辅助单位精准锁定短板领域的补位专家。

**L6-3 智能分析与推荐**  
智能分析与推荐的具体功能包括自动深度分析、预测视图缩放、智能交互反馈。
（1）自动深度分析
支持自动识别高潜力专家并放大其贡献分析，包括历年变化趋势、关键成果、重大影响事件，助力单位动态锁定学科发展核心力量。
（2）预测视图缩放
在引进模拟场景中，支持对贡献度预测结果的缩放，用户可切换整体预期、局部影响及阶段性增长视图，灵活掌控分析细节。
（3）智能交互反馈
用户可通过缩放和聚焦操作，触发更多维度数据与专家画像展示，实现贡献度分析的深度定制与业务高效支撑。
