六级及需规原文（唯一需求源）：

**L6-1 度中心性计算与展示**  
实时统计知识图谱中各节点的度数，量化其直接影响力；通过热力图形象展示节点重要性分布，并支持按度中心性值排序和筛选，便于快速识别高影响力节点；同时提供趋势分析，展示节点在不同时间段的度数变化；还可按节点类型如人员、机构、论文等进行分组统计和比较。

**L6-2 紧密中心性计算与展示**  
通过计算节点到其他所有节点最短路径的倒数和，评估其信息传播效率，并以雷达图形式直观展示节点中心性和接近程度；支持与度中心性对比分析，识别多元重要节点；结合聚类分析，对相似紧密中心性的节点分组展示；同时可自定义节点子集，聚焦特定领域核心节点分析。

**L6-3 中介中心性计算与展示**  
统计节点在最短路径上的出现次数，衡量其在网络中的信息控制力和桥梁作用；通过网络图突显高中介中心性节点关键连接位置，支持路径追踪展示重要信息流经节点；并可分析节点移除后对网络连通性的影响范围，还提供时间序列展现节点控制力的动态变化。

**L6-4 PageRank算法计算与展示**  
通过链接分析评估节点的重要性，兼顾链接质量和数量，支持参数设置以适应多场景需求；以列表与图表展现节点PageRank排名，并可与其他中心性指标进行相关性分析；同时提供算法迭代过程的可视化，直观展示收敛过程和稳定性。

**L6-5 多维度中心性综合分析**  
全面展示四种中心性指标对比矩阵，支持自定义权重实现多指标灵活组合评分；提供异常检测，识别中心性异常波动并预警；同时支持分析结果导出生成报告，及历史版本对比，便于监测节点重要性动态变化趋势。
