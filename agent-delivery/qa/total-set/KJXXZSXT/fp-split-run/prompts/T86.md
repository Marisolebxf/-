六级及需规原文（唯一需求源）：

**L6-1 一键分享功能**  
用户可通过一键操作，迅速将当前可视化图表或分析结果分享给其他用户、团队或业务线，提升协作效率。

**L6-2 多格式导出支持**  
支持将知识图谱、分析报告等内容导出为多种格式，如PNG图片、PDF文档、HTML页面、Excel表格，满足各类应用场景需求。

**L6-3 链接生成与访问权限控制**  
自动生成专属分享链接，支持设置访问权限（如公开、私密、仅限团队），确保数据安全与隐私。

**L6-4 嵌入式分享**  
支持将图表以嵌入代码形式集成到第三方网站、企业门户或报告，实现跨平台数据展示。

**L6-5 历史分享记录与管理**  
自动记录所有分享操作，方便用户随时查找、管理和撤回已分享内容，提升可追溯性。

**L6-6 实时同步与消息通知**  
图表或分析结果发生改变时，可自动同步给所有已分享用户，并通过邮件、消息等方式通知对方，确保信息时效性和一致性。

## 拆法（门户最细颗粒度 + 专题原则方法）

一条功能点 = 一个动作 + 一个对象 + 一条可验收规则或结果。命名：`动作 + 对象 + 条件/字段/维度/规则/状态/输出`。

规则层（有独立验收标准才计）：校验、默认、空态、处理中、失败；排名表升序与降序分别计。
