六级及需规原文（唯一需求源）：

**L6-1 基础信息查看功能**  
支持按类别浏览各类科创要素（论文、期刊、专利、专家学者、会议、组织机构、课题、项目、成果）；提供要素详情查看功能，点击特定要素可查看其完整基础信息，包括名称、属性、描述、关联关系；支持要素信息的多维度筛选，如按时间范围、学科领域、地区等条件进行筛选；提供要素收藏和标签管理功能，便于用户重点关注和管理重要科创要素。

**L6-2 统计指标展示功能**  
提供丰富的统计指标可视化展示，包括数量统计、分布比例、增长趋势；支持自定义统计维度，用户可根据需求选择不同的统计口径和指标；提供统计数据的图表展示，包括柱状图、饼图、折线图等多种可视化形式；支持统计数据的导出功能，便于用户进行进一步分析和报告制作。

**L6-3 分析数据展示功能**  
提供科创要素关联分析功能，展示不同要素之间的关联关系和影响程度；支持要素影响力分析，通过算法模型评估各要素的重要性和影响力；提供要素聚类分析，将相似要素进行自动分类和归纳；支持要素比较分析，用户可选择多个要素进行横向对比。

**L6-4 监测数据趋势变化查看功能**  
提供时间轴趋势展示，用户可查看特定要素随时间变化的趋势；支持趋势预测功能，基于历史数据预测未来发展趋势；提供异常监测功能，自动识别和标记数据异常点和突变点；支持多时间维度查看，包括日、月、季、年等不同时间维度的趋势展示。

**L6-5 地图可视化展示功能**  
基于GIS地图展示各类科创要素的地理分布情况；支持热力图展示，直观呈现科创要素的密集程度和分布热点；提供地图交互功能，包括缩放、平移、图层切换等操作；支持地图与列表联动，点击地图上的要素可查看详细信息。

## 拆法（门户最细颗粒度 + 专题原则方法）

一条功能点 = 一个动作 + 一个对象 + 一条可验收规则或结果。命名：`动作 + 对象 + 条件/字段/维度/规则/状态/输出`。

对每条六级做七层检查（没有就不拆）：对象选择 → 指标/参数 → 取数计算 → 结论识别 → 展示 → 下钻 → 输出。

规则层（有独立验收标准才计）：校验、默认、空态、处理中、失败；排名表升序与降序分别计。

「等」「如」只取已写名称，不发明未点名城市/指标。禁止笛卡尔积；禁止「选择××作为分析对象」套话；禁止需规未写的收藏/分享；禁止 LLM 实现手段单独成点；禁止同义重复。需规已写订阅/导出则要拆。

规则来源只允许：原文直接 / 原文隐含 / 验收补充。
