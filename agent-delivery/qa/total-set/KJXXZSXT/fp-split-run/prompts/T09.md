六级及需规原文（唯一需求源）：

**L6-1 关键实体推荐列表展示**  
支持根据算法自动计算并展示与技术领域相关的Top关键实体列表，包括人、机构、论文、专利等类型。实体列表以卡片或表格形式呈现，每个实体显示名称、类型、关联强度等基本信息，支持按实体类型、关联强度、时间等维度进行排序和筛选，并提供实体搜索功能。

**L6-2 实体添加到全景图操作**  
用户点击推荐列表中的实体卡片或复选框选中一个或多个实体，点击"添加到全景图"按钮，系统将选中的实体添加到当前技术知识图谱中。添加的实体自动与相关技术节点建立关联关系，系统智能计算关联强度，添加成功后，实体在全景图中以节点形式展示，并提供视觉反馈。

**L6-3 全景图实体删除操作**  
用户在全景图中点击选中要删除的实体节点（支持单选或多选），通过右键菜单选择"删除实体"选项或按Delete键执行删除操作。系统弹出确认对话框，提示用户该操作将同时删除与该实体相关的所有关系，确认后，实体及其关联关系从全景图中移除，但保留在推荐列表中以便重新添加。

**L6-4 实体关系删除操作**  
用户直接点击全景图中要删除的实体间关系连线，连线高亮显示后，通过右键菜单选择"删除关系"选项。系统弹出确认对话框，说明删除该关系的影响，确认后，关系连线从全景图中移除，但相关实体节点保持不变。

**L6-5 实体属性编辑功能**  
用户双击全景图中的实体节点或右键选择"编辑属性"选项，系统弹出实体属性编辑对话框，显示实体的详细信息。用户可修改实体的名称、类型、描述、重要性等级等属性，修改后点击保存按钮更新实体信息，系统自动更新相关展示内容。

**L6-6 实体关系编辑功能**  
用户点击全景图中的实体关系连线，右键选择"编辑关系"选项，系统弹出关系属性编辑对话框，显示关系的详细信息。用户可修改关系类型（如"合作"、“引用”、"影响"）、关系强度、时间范围等属性，修改后点击保存按钮更新关系信息，系统自动更新连线的视觉样式。

**L6-7 实体及关系批量管理**  
支持通过框选方式批量选择多个实体或关系，提供批量操作菜单，包括批量添加、删除、属性修改等功能。批量操作前系统会显示预览效果，确认后执行操作，批量操作完成后，系统提供操作结果统计和反馈。
