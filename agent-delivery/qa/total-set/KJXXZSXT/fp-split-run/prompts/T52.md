六级及需规原文（唯一需求源）：

**L6-1 关联数据展示**  
关联数据展示的具体功能包括多级穿透、关联可视化、动态聚合。
（1）多级穿透
支持从人才主体逐级穿透其论文、专利、科研项目等多源数据，用户可按需展开，深入了解人才与各类成果的具体关联情况。
（2）关联可视化
采用图谱、列表、标签等多种方式动态呈现人才与成果间的关联关系，让用户直观掌握人才与知识产出的联系网络。
（3）动态聚合
根据最新数据自动更新，将新发表论文、新授权专利、新立项项目即时纳入人才关联画像，实现数据动态聚合与同步。

**L6-2 智能检索与筛选**  
智能检索与筛选的具体功能包括多条件筛选、语义检索。
（1）多条件筛选
支持按成果类型（论文、专利、项目）、时间范围、领域关键词等多维度组合筛选人才相关成果，精准定位关联信息。
（2）语义检索
利用自然语言处理技术，实现对成果名称、摘要、核心技术等文本内容的语义理解和智能查找，提高检索效率和准确度。

**L6-3 关联关系挖掘**  
关联关系挖掘的具体功能包括隐含关系发掘、重点关联标注。
（1）隐含关系发掘
通过大数据分析、图谱构建和机器学习算法，自动发现并揭示人才与其成果、合作方之间的隐含或潜在关联，助力深度洞察。
（2）重点关联标注
对高影响力成果、重大项目或关键技术专利进行高亮、标注，提升核心关联内容的可见性和关注度。

**L6-4 可视化图谱操作**  
可视化图谱操作的具体功能包括缩放与拖拽、聚焦展示。
（1）缩放与拖拽
用户可通过鼠标滚轮缩放关联网络图谱，也可以对节点自由拖拽调整布局，便于个性化查看人才的合作网络和成果分布。
（2）聚焦展示
点击某一节点（如某论文或项目），页面自动聚焦并放大相关区域，突出显示该成果与人才及其它相关要素之间的关系。

**L6-5 数据溯源与详情展示**  
数据溯源与详情展示的具体功能包括原始数据链接、变更记录。
（1）原始数据链接
每项成果或项目均链接溯源至原始文献、专利全文或项目详细介绍，方便用户深度阅读和验证关键信息。
（2）变更记录
记录人才成果及关联数据的历史变更情况，支持时间轴回溯关联画像的演化过程。
