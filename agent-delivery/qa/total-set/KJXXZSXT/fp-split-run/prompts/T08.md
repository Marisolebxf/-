六级及需规原文（唯一需求源）：

**L6-1 技术节点增加操作**  
用户可通过右键点击图谱空白区域或使用工具栏中的"添加节点"按钮创建新技术节点。页面弹出节点属性编辑对话框，用户需填写节点名称、技术分类、描述等基本信息，确认后新节点将出现在图谱中指定位置，并自动生成唯一标识符。

**L6-2 技术节点删除操作**  
用户选中要删除的技术节点（单击或框选），通过右键菜单选择"删除节点"选项或按Delete键执行删除操作。系统会弹出确认对话框，提示用户该操作将同时删除与该节点相关的所有关系，确认后节点及其关联关系将从图谱中移除。

**L6-3 技术关系增加操作**  
用户按住Ctrl键依次点击两个需要建立关系的技术节点，然后通过右键菜单选择"添加关系"选项。系统弹出关系属性编辑对话框，用户可设置关系类型（如"包含"、“依赖”、"促进"）、关系强度、时间范围等属性，确认后两节点间将显示连接线表示新建立的关系。

**L6-4 技术关系删除操作**  
用户直接点击要删除的关系连线，连线会高亮显示，然后通过右键菜单选择"删除关系"选项或按Delete键执行删除操作。系统会弹出确认对话框，确认后该关系将从图谱中移除，但相关节点保持不变。

**L6-5 节点属性编辑操作**  
用户双击技术节点或右键选择"编辑属性"选项，系统弹出节点属性编辑对话框，用户可修改节点的名称、分类、描述、重要性等级等各项属性，修改后点击保存按钮更新节点信息。

**L6-6 图谱修改历史管理**  
支持自动记录用户对图谱的所有修改操作，提供"撤销"和"重做"功能，用户可通过工具栏按钮或快捷键（Ctrl+Z/Ctrl+Y）回退或恢复之前的操作状态，确保编辑过程的可追溯性。

**L6-7 图谱保存与版本控制**  
用户完成图谱修改后，可点击"保存"按钮将当前图谱状态保存到系统。同时支持版本管理功能，用户可创建新版本或回滚到历史版本，并查看各版本的修改记录和操作人员信息，便于团队协作和变更追踪。
