六级及需规原文（唯一需求源）：

**L6-1 科技成果综合排名**  
展示科技成果的综合排名榜单，用户可查看排名前N位的科技成果及其得分情况，系统提供排名变化趋势，显示与上一期相比的上升或下降情况。

**L6-2 分类排名展示**  
提供多种分类排名方式，用户可按科技领域、成果类型、机构类型、地域范围等条件查看分类排名，支持多条件组合筛选，满足不同用户的查看需求。

**L6-3 排名详情查看**  
用户点击排行榜中的具体成果，可查看该成果的详细信息和排名依据，包括各项指标得分、评价方法、数据来源等内容，增强排名的透明度和可信度。

**L6-4 排名历史变化**  
展示排名的历史变化情况，用户可查看特定成果在不同时间点的排名变化，分析其发展趋势和竞争力变化，提供排名变化曲线图，直观展示变化轨迹。

**L6-5 排名对比分析**  
用户可选择多项科技成果进行对比分析，提供对比视图，展示各成果在不同指标上的表现差异和优劣势，帮助用户深入了解成果的特点和价值。

**L6-6 排名筛选与搜索**  
用户可通过关键词搜索特定科技成果，或按排名范围、得分区间、时间范围等条件筛选排名结果，提供快速定位功能，帮助用户高效查找目标成果。

**L6-7 排名结果导出**  
用户可将排名结果导出为Excel、PDF等格式，也可生成排名报告，包含排名分析、趋势解读和关键发现，便于分享和进一步分析。

## 拆法（门户最细颗粒度 + 专题原则方法）

一条功能点 = 一个动作 + 一个对象 + 一条可验收规则或结果。命名：`动作 + 对象 + 条件/字段/维度/规则/状态/输出`。

规则层（有独立验收标准才计）：校验、默认、空态、处理中、失败；排名表升序与降序分别计。
