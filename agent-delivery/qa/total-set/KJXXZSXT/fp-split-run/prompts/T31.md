六级及需规原文（唯一需求源）：

**L6-1 专家H指数排行可视化**  
以柱状图、雷达图等形式展示专家H指数排行情况，用户可按学科领域、机构类型、地域范围等条件筛选查看，也可点击图表中的专家名称查看详细信息和H指数计算依据。

**L6-2 科技指数分布区域可视化**  
通过热力图、区域分布图等形式展示科技指数在地理空间上的分布情况，用户可缩放、平移地图查看不同区域的科技指数表现，也可点击特定区域查看该区域的详细指数数据。

**L6-3 科技影响力趋势可视化**  
以折线图、面积图等形式展示科技影响力随时间的变化趋势，用户可选择不同时间范围、不同科技领域查看趋势变化，系统支持多指标对比展示，帮助用户分析科技发展的动态变化。

**L6-4 专家活跃度可视化**  
通过活动热力图、时间轴等形式展示专家的科研活跃度，包括发表论文数量、参与项目情况、学术活动参与度等指标，用户可查看特定专家或专家群体的活跃度变化趋势。

**L6-5 大屏导航切换**  
提供大屏导航功能，用户可点击导航部分切换到具体的大屏详情页面，查看更深入的分析内容和更详细的数据展示，大屏页面支持全屏展示和自动轮播。

**L6-6 可视化图表交互**  
提供丰富的图表交互功能，包括数据筛选、维度切换、指标选择、时间范围调整，用户可根据需求自定义可视化展示内容，系统实时更新图表展示结果。

**L6-7 可视化结果导出**  
用户可将可视化图表导出为图片、PDF等格式，也可生成可视化报告，包含图表解读和关键发现，便于分享和进一步分析。
