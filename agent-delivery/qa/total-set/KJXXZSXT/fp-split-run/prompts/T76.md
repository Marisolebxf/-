**L6-1 需求方名称自动归集与展示**  
自动识别并归集所有数据调用主体，展示每一个需求方的名称（如部门、业务组、项目团队），便于管理者快速定位业务需求来源。

通过调用日志分析技术，全面统计每个需求方的数据资源累计调用次数，帮助管理团队评估各需求方对数据的整体需求强度和使用趋势。

**L6-3 调用行为分布可视化**  
采用柱状图、折线图等方式，直观展示各需求方在不同时间段的数据调用分布状况，让用户快速发现业务高峰期和潜在增长点。

**L6-4 多维检索与筛选功能**  
支持按部门、业务类型、项目组等多维条件进行需求方过滤和检索，方便管理者针对重点业务或重要用户进行专项分析和资源优化。

## 拆法（门户最细颗粒度 + 专题原则方法）

一条功能点 = 一个动作 + 一个对象 + 一条可验收规则或结果。命名：`动作 + 对象 + 条件/字段/维度/规则/状态/输出`。

规则层（有独立验收标准才计）：校验、默认、空态、处理中、失败；排名表升序与降序分别计。
