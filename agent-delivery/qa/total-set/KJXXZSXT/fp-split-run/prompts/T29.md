六级及需规原文（唯一需求源）：

**L6-1 发展战略引导力评估**  
收集并分析特定领域的发展战略规划、产业政策文件，评估战略规划的前瞻性、系统性和针对性，用户可以查看战略规划的关键内容、实施路径和预期目标，了解发展战略的引导力。

**L6-2 政策扶持力度分析**  
收集并统计特定领域的政策数量、政策类型、政策覆盖面等数据，评估政策扶持的广度和深度，用户可按政策类型（如财税政策、人才政策、金融政策）、时间范围、地域等维度查看政策分布情况。

**L6-3 经费支持分析**  
收集并统计特定领域的科研经费、产业基金、补贴资金等经费支持数据，用户可按经费来源、支持方向、时间范围等维度查看经费支持情况，系统提供饼图、柱状图等可视化形式展示经费结构和变化趋势。

**L6-4 项目支持分析**  
收集并统计特定领域的科技项目、产业项目等支持项目数据，用户可按项目类型、资助机构、时间范围等维度查看项目分布情况，系统提供项目数量、资助金额、实施效果等指标的分析结果。

**L6-5 政策实施效果评估**  
基于政策实施后的数据变化，评估政策的实际效果，用户可以查看政策实施前后的关键指标对比，了解政策的实际影响和效果。

**L6-6 政策与条件保障力综合评估**  
将政策与条件保障力的各项指标进行综合展示，用户可自定义指标权重，系统根据权重计算综合得分，提供政策与条件保障力的综合评估结果和排名。

**L6-7 政策优化建议**  
基于评估结果，提供政策优化建议，包括政策重点调整、支持力度加强、实施路径优化等方面，用户可查看详细的政策优化建议报告，为政策制定提供参考。
为提升创新未来发展方向评估的准确性，该功能还引入了德尔菲法来预判技术趋势。通过召开德尔菲会议，将科学计量和数据挖掘的数据分析结果提供给专家参考，结合专家的经验和专业素养，做出前瞻性判断。最终，在数据和专家评价的基础上，运用系统工程的视角，构建学术及科技创新系统评估模型。该模型综合考虑传统评估模型及德尔菲法评估结构，同时增加环境因素及愿景分析，涵盖政治、社会和经济领域与被评产业或领域的相互影响关系。基于这样的指标体系，可以模拟成系统仿真模型，实现对各种可能的趋势和前景进行预测，并能得到对评估结论更为直观、可视化的效果。
