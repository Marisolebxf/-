六级及需规原文（唯一需求源）：

**L6-1 专家画像智能生成**  
功能利用大数据和自然语言处理技术，从论文、专利、项目档案及学术社交平台自动采集数据，融合学术成果、科研经历、合作网络等信息，生成精准详实的专家画像，助力单位全面了解候选人才的专业能力与学术影响力。

**L6-2 多维综合评价与评分**  
功能基于权威度、创新性、项目经验、社会影响等多维量化指标，通过人工智能算法进行综合评分，帮助用人单位快速对专家进行定量评价，优选具备潜力和实力的人才。

**L6-3 定制化尽调报告生成**  
用户可根据需求定制尽调维度，系统自动生成可视化尽调报告，包括学术背景、行业贡献、以往合作、奖项荣誉及风险点分析，满足各类招聘、评审和机构管理的精细化要求。

**L6-4 专家智能推荐**  
借助智能匹配算法，系统根据用人单位的学科方向、合作历史及项目需求，自动筛选并推荐最契合发展目标的专家，实现高效的精准人才对接。

**L6-5 动态跟踪与更新**  
持续动态抓取专家新成果和最新履历，实时更新专家画像与报告内容，保障信息的时效性和准确性，提升后续管理和人才储备的持续性。

**L6-6 风险与合规性评估**  
支持智能分析专家在合作风险、学术诚信、成果有效性等方面的信息，为单位规避引进风险、优化用才决策提供有力支撑。

**L6-7 团队组合与协同分析**  
支持多专家尽调报告并行生成，分析团队成员之间的协同潜力与互补优势，为单位打造高效创新团队提供数据参考和人才组合建议。
