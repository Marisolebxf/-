六级及需规原文（唯一需求源）：

**L6-1 多维度分析展示**  
多维度分析展示的具体功能包括多级穿透、动态可视化、综合评分展示。
（1）多级穿透
支持从人才整体画像多级分层查看，用户可由总览界面依次深入至学科贡献度分析、研究领域细节、合作网络等单项维度，便于细致洞察。
（2）动态可视化
采用雷达图、柱状图、关系网络图等可视化方式，将人才在不同领域的贡献度、学术影响力及与他人合作状况立体展示，提升解读效率。
（3）综合评分展示
根据多项数据自动生成综合评价分数和图示，如领域影响力指标、贡献度分布，使用户直观把握人才整体水平。

**L6-2 智能筛选与比较**  
智能筛选与比较的具体功能包括多条件筛选、相似人才比对、历史数据分析。
（1）多条件筛选
允许用户按照研究领域、学科方向、贡献度分级等指标筛选目标人才，实现个性化分析和精准定位。
（2）相似人才比对
基于深度语义分析和机器学习算法，自动推荐与当前人才研究方向及成就相近的学者，支持横向对比功能。
（3）历史数据分析
支持选择不同时间段，分析人才在各领域的持续贡献和变化趋势，把握发展轨迹。

**L6-3 人才引进评估**  
人才引进评估的具体功能包括难度/成本预测、影响因子测算。
（1）难度/成本预测
结合大数据分析，对每位人才的引进难度、潜在成本进行智能评估，并以可视化方式展现，为决策提供参考。
（2）影响因子测算
自动计算人才成果影响因子、合作网络活跃度等核心指标，用于科学评估人才价值。

**L6-4 可视化操作支持**  
可视化操作支持的具体功能包括缩放与聚焦、聚焦分析。
（1）缩放与聚焦
用户可通过鼠标滚轮缩放各类分析图表，如贡献度雷达图、研究领域分布图、合作网络图，实现细粒度操作。
（2）聚焦分析
点击某一分析维度或具体数据点，页面自动聚焦并高亮该部分内容，突出关键信息，便于深入分析。

**L6-5 交互与报告输出**  
交互与报告输出的具体功能包括个性化报告生成、数据导出功能。
（1）个性化报告生成
支持一键生成包括领域分布、贡献度分析、引进评估和相似学者推荐等内容的可定制化分析报告。
（2）数据导出功能
所有分析画像及相关数据可按需导出为Excel、PDF等多种格式，便于各类管理、交流和归档。

一条功能点 = 一个动作 + 一个对象 + 一条可验收规则或结果。命名：`动作 + 对象 + 条件/字段/维度/规则/状态/输出`。

规则层（有独立验收标准才计）：校验、默认、空态、处理中、失败；排名表升序与降序分别计。
