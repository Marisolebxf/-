六级及需规原文（唯一需求源）：

**L6-1 城市创新数据监控**  
监控全球主要城市的创新基金、投资规模，创新机构、企业在创新上的投入、产生的创新成果等数据，用户可查看各城市的创新数据详情。

**L6-2 创新能力排名计算**  
基于数据模型分析计算各大城市的创新能力排名，用户可查看排名结果和计算方法。

**L6-3 城市对标分析**  
用户可选择多个城市进行创新对标分析，系统提供对比视图，展示各城市在创新投入、创新产出、创新环境等方面的差异。

**L6-4 创新能力要素分析**  
分析影响城市创新能力的关键要素，如人才、资金、政策，用户可查看各城市在不同要素上的表现。

**L6-5 城市订阅功能**  
用户可订阅关注的城市，平台将定期推送该城市的创新动态和创新能力变化信息。

**L6-6 创新政策建议**  
基于城市创新能力分析结果，提供针对性的创新政策建议，用户可查看这些建议并参考制定相关政策。
