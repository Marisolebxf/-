六级及需规原文（唯一需求源）：

**L6-1 产业投入分析**  
支持收集并统计特定产业内企业的研发投入、固定资产投资、人才投入等数据，用户可按企业规模、地域、时间范围等维度查看产业投入情况，同时提供饼图、柱状图等可视化形式展示投入结构和变化趋势。

**L6-2 技术产品成熟度评估**  
通过技术生命周期分析、市场渗透率分析等方法，评估特定产业内技术或产品的成熟度，用户可查看技术成熟度曲线、市场渗透率变化等指标，了解产业技术发展阶段。

**L6-3 产业产值分析**  
收集并统计特定产业的总产值、增加值、利润等经济指标，用户可按时间范围、地域、企业类型等维度查看产业产值情况，系统提供柱状图、折线图等可视化形式展示产值变化趋势。

**L6-4 科学影响力评估**  
基于论文引用、国际合作等数据，评估特定产业的科学影响力，用户可查看科学影响力指标（如论文被引次数、国际合作论文比例）的分布情况和排名，了解产业的科学影响力水平。

**L6-5 技术影响力评估**  
基于专利引用、技术标准等数据，评估特定产业的技术影响力，用户可查看技术影响力指标（如专利被引次数、标准必要专利数量）的分布情况和排名，了解产业的技术影响力水平。

**L6-6 产业发展潜力综合评估**  
将产业发展潜力的各项指标进行综合展示，用户可自定义指标权重，支持根据权重计算综合得分，提供产业发展潜力的综合评估结果和排名。
