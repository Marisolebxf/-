六级及需规原文（唯一需求源）：

**L6-1 成果信息分层展示**  
成果信息分层展示的具体功能包括多级展开、分类聚合显示、时间轴视图。
（1）多级展开
支持从专家整体视图逐级展开到其近期论文、专利、项目等详细成果列表，用户可按需查看每项成果的具体内容与关联信息。
（2）分类聚合显示
以类别（如论文、专利、项目）分区展示近期成果，支持用户按类别、时间等维度快速定位所需信息。
（3）时间轴视图
按成果发表/授权时间自动生成动态时间线，显示专家近期成果的发布节奏和研发进展轨迹，便于时序分析。

**L6-2 可视化操作**  
可视化操作的具体功能包括缩放操作、聚焦放大、全屏模式。
（1）缩放操作
用户可通过鼠标滚轮缩放成果展示页面，对成果图表、列表和关系网络等不同可视化模块进行细粒度放大或缩小。
（2）聚焦放大
点击某项成果，界面自动聚焦并放大相关详情区块，突出显示该成果的背景、摘要、关联专家等关键信息。
（3）全屏模式
支持一键切换至全屏展示，将专家近期成果以更大视野、丰富交互的方式集中呈现。

**L6-3 智能推送与动态更新**  
智能推送与动态更新的具体功能包括成果智能提醒、自动数据抓取。
（1）成果智能提醒
系统监测到专家有新成果发表时，自动推送实时更新通知至相关用户或订阅者，保证信息的时效性和全面性。
（2）自动数据抓取
后端定时爬取和同步权威网站、学术数据库信息，保证展示内容持续最新、完整。

**L6-4 成果详情与原文链接**  
成果详情与原文链接的具体功能包括深度详情页面、关联推荐。
（1）深度详情页面
每项成果支持深入查看，包括摘要、发表期刊、专利摘要、项目简介，并提供原文或原始信息源的链接，方便用户进一步查阅。
（2）关联推荐
展示某项成果时，系统可智能推荐相关成果或与之有合作关系的其他专家，拓展用户的获取视野。
