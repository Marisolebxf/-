六级及需规原文（唯一需求源）：

**L6-1 多方案对比展示**  
基于评估模型，自动生成多个政策改进或发展方案，并以并排对比图表（如雷达图、KPI分布）展现优劣，帮助用户科学筛选。

**L6-2 方案参数自定义模拟**  
用户可自定义关键参数，动态调整方案模拟条件，实时查看变动后的评估结果、趋势预测和效果归档，提升决策灵活性。

**L6-3 实施路径与风险辅助**  
系统自动生成每个推荐方案的落地路径图和时间进度表，分析方案实施关键节点及可能风险，辅助科学排期与风险防御。

**L6-4 互动意见收集与专家参与**  
提供在线互动模块，用户和专家可对推荐方案进行评价、评论和建议，系统自动分类归集意见并纳入后续优化。

**L6-5 方案报告导出与归档**  
一键导出所有推荐方案报告，内容包括方案描述、实施建议、对比分析和专家点评，支持多格式归档、政策汇报和内部流转。

一条功能点 = 一个动作 + 一个对象 + 一条可验收规则或结果。命名：`动作 + 对象 + 条件/字段/维度/规则/状态/输出`。

规则层（有独立验收标准才计）：校验、默认、空态、处理中、失败；排名表升序与降序分别计。
