# 档C 6-pc (21 条)

| Txx | 子功能项 | 功能点 | 需规 |
|---|---|---|---|
| T125 | 政策库结构化 | 未转化为结构化数据时不可快速检索政策数据 | 将非结构化政策文本转化为标准化结构化数据，构建政策分类标签体系、元数据规范与字段映射规则，实现政策数据的统一管理、快速检索与高效调用，打通政策文档数据孤岛。 |
| T127 | 规划指标库搭建 | 未完成标准化政策指标库搭建时不可为政策拆解提供数据支撑 | 梳理政策核心指标维度，搭建标准化政策指标库，涵盖扶持力度、适用范围、实施时效、申请条件等关键指标，为政策拆解、对比分析提供统一指标口径与数据支撑。 |
| T128 | 政策语义理解 | 未提供政策文本时不可做语义解析 | 基于大模型实现政策文本的深度语义解析、意图识别与条款分类，精准理解政策核心主旨、适用场景与约束要求，适配地方、国家、海外等多类型政策文本解析。 |
| T129 | 条款精细化拆解 | 未具备政策内容时不可拆解条款 | 自动拆分政策章节、条目、细则等层级内容，提取政策目标、扶持措施、保障机制、责任主体等核心条款，实现政策内容的结构化拆解与分层呈现。 |
| T130 | 关键指标自动提取 | 未选择政策时不可抽取关键指标 | 自动识别并抽取政策中的量化指标、补贴标准、资质要求、时间节点等关键数据，形成标准化指标数据集，支撑后续多维对比与量化分析。 |
| T131 | 政策实体关联 | 未结合政策知识图谱时不可关联实体信息 | 结合政策知识图谱，关联政策发布主体、适用领域、关联政策、服务对象等实体信息，构建政策实体关联网络，提升政策拆解的关联性与完整性。 |
| T131 | 政策实体关联 | 未完成实体关联时不可构建政策实体关联网络 | 结合政策知识图谱，关联政策发布主体、适用领域、关联政策、服务对象等实体信息，构建政策实体关联网络，提升政策拆解的关联性与完整性。 |
| T131 | 政策实体关联 | 未完成网络构建时不可展示政策实体关联网络 | 结合政策知识图谱，关联政策发布主体、适用领域、关联政策、服务对象等实体信息，构建政策实体关联网络，提升政策拆解的关联性与完整性。 |
| T133 | 可视化分析呈现 | 未识别政策差异时不可展示政策差异 | 以对比表格、柱状图、雷达图、知识图谱等多种形式，可视化展示政策对比结果，直观呈现政策差异与核心特征。 |
| T133 | 可视化分析呈现 | 未识别政策核心特征时不可展示政策核心特征 | 以对比表格、柱状图、雷达图、知识图谱等多种形式，可视化展示政策对比结果，直观呈现政策差异与核心特征。 |
| T136 | 政策深度分析 | 未具备行业数据时不可形成专业分析结论 | 基于政策对比结果，开展政策实施效果、社会经济效益、产业影响、发展趋势的深度分析，结合行业数据与模型算法形成专业分析结论。 |
| T137 | 洞察结论自动提炼 | 未具备政策分析时不可提炼洞察结论 | 自动提炼政策分析的核心观点、决策建议、风险提示与发展机遇，形成具备决策支撑价值的洞察结论。 |
| T137 | 洞察结论自动提炼 | 未完成核心观点、决策建议、风险提示与发展机遇提炼时不可形成洞察结论 | 自动提炼政策分析的核心观点、决策建议、风险提示与发展机遇，形成具备决策支撑价值的洞察结论。 |
| T137 | 洞察结论自动提炼 | 未形成洞察结论时不可展示洞察结论 | 自动提炼政策分析的核心观点、决策建议、风险提示与发展机遇，形成具备决策支撑价值的洞察结论。 |
| T138 | 模块化研报自动撰写 | 未加载标准化研报模板时不可撰写研报 | 依托标准化研报模板，自动整合分析数据、对比结果、洞察结论，完成研报的结构化撰写、内容排版与格式优化。 |
| T138 | 模块化研报自动撰写 | 未同时具备分析数据、对比结果与洞察结论时不可撰写研报 | 依托标准化研报模板，自动整合分析数据、对比结果、洞察结论，完成研报的结构化撰写、内容排版与格式优化。 |
| T138 | 模块化研报自动撰写 | 未完成结构化撰写时不可内容排版 | 依托标准化研报模板，自动整合分析数据、对比结果、洞察结论，完成研报的结构化撰写、内容排版与格式优化。 |
| T139 | 研报溯源展示 | 未具备研报结论时不可定位原始政策依据 | 提供研报结论与政策原文、权威数据源的双向溯源界面，支持从结论定位原始政策依据，也可从政策原文关联对应研判结论，实现结论可验证、可追溯、可复核 |
| T139 | 研报溯源展示 | 未具备政策原文时不可关联对应研判结论 | 提供研报结论与政策原文、权威数据源的双向溯源界面，支持从结论定位原始政策依据，也可从政策原文关联对应研判结论，实现结论可验证、可追溯、可复核 |
| T139 | 研报溯源展示 | 未完成双向溯源时不可判定结论可验证、可追溯、可复核 | 提供研报结论与政策原文、权威数据源的双向溯源界面，支持从结论定位原始政策依据，也可从政策原文关联对应研判结论，实现结论可验证、可追溯、可复核 |
| T140 | 结果智能输出 | 未具备研报内容时不可导出 | 支持将政策分析、研判结论、趋势报告等研报内容，以PDF、Word等常用格式导出，便于存档、分发与对外报送。 |
