## 3. 先开「内部评审模式」才能看到闸门 Switch

页头 / 角色菜单里有 **内部评审模式** Switch（`localStorage` 键 `ds_review_mode`，未设时默认 **开**）。

| 评审模式 | 行为 |
|---|---|
| **开** | 页头出现「演示闸门」Switch（政策已整合、有检索结果、各维评估已完成、解析完成……）。关掉某一项 → 对应区块 Empty / 按钮 disabled。 |
| **关** | 这些演示 Switch **从 DOM 消失**（`ReviewOnly`）。业务页仍按完成态渲染，避免隐藏开关后卡在 Empty。 |

闸门验收步骤一律默认：**先确认内部评审模式已开**，再关页内 Switch。

关评审后不应再看到：页头「演示闸门」Alert、分析页 T41/T42 闸门条、预估/推演 `GateSwitch`、趋势「核心数据」、分组「效果数据」、关联「要素整合」、导出「已自定义模板」。核增页头底座 Switch 同样包在评审层里。

## 4. 验收总原则（四行表底下那句）

1. **默认完成态**：打开菜单就能看到有数据的图、表、报告。
2. **切未就绪**：关对应 Switch，或把带允许清空的 Select 清掉。
3. **期望**：按钮 `disabled` + `Empty`（或 Alert），**不要**仍渲染完整 mock。
4. **本轮不做**：档 B 106 条；T124 清洗（档 D）；T132 交叉对比能力不改。
