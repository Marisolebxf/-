# 档C 3-estimate (8 条)

| Txx | 子功能项 | 功能点 | 需规 |
|---|---|---|---|
| T43 | 未出台政策仿真模拟 | 未完成关键参数输入时不可仿真模拟 | 用户可输入未出台政策的关键参数，包括政策类型、覆盖范围、支持力度、实施时间，系统基于历史数据和数学模型进行仿真模拟，预测政策实施后可能产生的效果，包括经济效益、社会影响、创新促进等方面，用户可调整参数进行多次模拟，比较不同政策方案的效果差异。 |
| T43 | 未出台政策仿真模拟 | 未具备历史数据时不可仿真模拟 | 用户可输入未出台政策的关键参数，包括政策类型、覆盖范围、支持力度、实施时间，系统基于历史数据和数学模型进行仿真模拟，预测政策实施后可能产生的效果，包括经济效益、社会影响、创新促进等方面，用户可调整参数进行多次模拟，比较不同政策方案的效果差异。 |
| T43 | 新出台政策效果预测 | 未完成政策文本解析时不可预测效果 | 功能将对新出台政策进行实时效果预测分析，基于政策文本解析和历史相似政策效果数据，预测政策实施后的短期和长期效果，包括对经济增长、产业发展、科技创新等方面的影响，用户可查看预测结果的时间变化趋势和空间分布特征。 |
| T43 | 新出台政策效果预测 | 未具备历史相似政策效果数据时不可预测效果 | 功能将对新出台政策进行实时效果预测分析，基于政策文本解析和历史相似政策效果数据，预测政策实施后的短期和长期效果，包括对经济增长、产业发展、科技创新等方面的影响，用户可查看预测结果的时间变化趋势和空间分布特征。 |
| T43 | 区域经济发展空间模拟 | 未选择特定区域时不可模拟区域经济发展 | 提供区域经济发展的空间模拟功能，用户可选择特定区域和政策类型，系统模拟政策对该区域经济发展的影响，包括GDP增长、产业结构变化、就业率变化等指标，以热力图、三维地图等形式直观展示空间分布特征。 |
| T43 | 区域经济发展空间模拟 | 未选择政策类型时不可模拟区域经济发展 | 提供区域经济发展的空间模拟功能，用户可选择特定区域和政策类型，系统模拟政策对该区域经济发展的影响，包括GDP增长、产业结构变化、就业率变化等指标，以热力图、三维地图等形式直观展示空间分布特征。 |
| T43 | 多维度效果评估 | 未完成各维度评估时不可展示综合效果 | 从经济、社会、环境、创新等多个维度对政策效果进行评估，用户可查看各维度的评估指标和得分，了解政策在不同方面的综合效果，系统提供雷达图、柱状图等多种可视化形式展示评估结果。 |
| T43 | 利益攸关方参与评估 | 未汇总各方意见时不可纳入效果评估模型 | 提供信息反馈与互动模块，支持决策者、评估者和利益攸关方等各方参与政策评估全过程，用户可通过在线问卷、意见征集、专家评审等方式提供反馈，系统汇总各方意见并纳入效果评估模型，确保评估活动目标合理、组织协调、程序公正规范、方法科学可行。 |
