### 1. 功能点「展示研报结论与政策原文、权威数据源的双向溯源界面」

- **语义**：界面须同时承载**研报结论、政策原文、权威数据源**，并支持双向查证。有「溯源」Card 不等于三对象齐全。

- **原型说明写法**：写清 Card/Select 文案与已有字段，并点名缺权威数据源；禁止只写「有溯源面板」。
- **原型路径**：`PolicyPcPages.jsx` `PolicyInsightReport` `traceDir` Select；`policyPcData.js` `reportInsights`（路径列不写评述）。
- **五件套**：故事写原文与权威源；线框/TRACE/UX 只给结论↔原文。→ **部分提及**（不因「双向溯源」四字记有设计覆盖权威源）。

### 2. 功能点「从研报结论定位原始政策依据」

- **语义**：动作是从**结论**定位到**原始政策依据**（政策/条款/摘录），不是目录里有「溯源附录」即算。

- **说明写法**：写清模式名、字段与列表按钮；禁止只写「可溯源」。
- **五件套**：DS-POL-USM-07 从结论溯源到原文锚点；WF 溯源面板。→ **有设计**。
