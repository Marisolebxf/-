### 2. 功能点「以 PDF 格式导出研报」

- **语义**：动作是把研报**以 PDF 落盘下载**，页上有 PDF 图标或 toast「导出成功」不等于已下载文件。
- **原型判定**：`exportReportPdf` 用 jsPDF A4 + canvas 绘制汇聚行后 `doc.save` `政策智能研报_*.pdf`。→ **已实现**。
- **说明写法**：写清 jsPDF、`doc.save` 与文件名；禁止只写「有 PDF 按钮」。
- **五件套**：DS-POL-USM-07 可导出一种格式；主路径 D / UX §3.4 / WF [PDF]。→ **有设计**。

- **语义**：无研报**内容**时须挡住导出；mock 正文恒在、或底座未就绪只禁入口，不等于本闸门。
