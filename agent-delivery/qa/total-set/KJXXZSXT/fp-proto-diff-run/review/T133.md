## 说明抽检（3 条）

抽检目的：读说明列能知道「哪里有什么」，不能只写「样例 / 有对比页 / US-DS-POL-09」。

### 1. 功能点「以知识图谱展示政策对比结果」

- **语义**：对象是**对比结果**的知识图谱呈现，不是页面上有任意图谱即算。PC02 拆解页实体关联图不等于本五级。
- **原型判定**：PC03 Card「可视化分析呈现 · 知识图谱」`kgRef` 在 `ran` 后出 echarts `type:'graph'`；`buildCompareGraph` 以对比政策为节点、互补/对照为边。→ **已实现**（mock 算能力）。
- **原型说明写法**：写清控件名、graph 类型、节点/边来源，并点明非 PC02 实体图；禁止只写「有图谱」。
- **原型路径**：`PolicyPcPages.jsx` `kgRef` `type:'graph'`；`policyPcData.js` `buildCompareGraph`（路径列不写评述）。
- **五件套**：故事/TRACE/WF/UX-SPEC 要求对比结果以图谱呈现。→ **有设计**。章节：`US-DS-POL-09`；TRACE `US-DS-POL-09`；WF `F-DS-POL-PC03` 图谱。

### 2. 功能点「识别政策核心特征」

- **语义**：动作是**识别**核心特征，有「核心指标」分值或智能摘要不等于已做该识别算法。
- **原型判定**：`compareDimensions` 含 `coreMetric`「核心指标」，摘要会点名领先维度；`buildCompareFindings` 只有共性/差异/互补/冲突，无「核心特征」类型。→ **部分实现**。
- **说明写法**：写清「有核心指标分值与摘要、缺核心特征识别类型」；禁止只写「有交叉对比」。
- **五件套**：US-DS-POL-09 写识别共性/差异/互补/冲突，未点名核心特征。→ **部分提及**。

### 3. 功能点「未具备政策对比结果时不可可视化展示」

- **语义**：无对比**结果**时不得出表/柱/雷达/图谱数据，有占位容器不等于未闸门；也不同于「未识别差异则不展示差异」。
- **原型判定**：未 `ran` 时对比表 Empty；三图 option 仅「运行对比后展示…」无 series；对象<2 时 `runCompare` 直接 return。→ **已实现**。
- **说明写法**：写清 Empty 文案、占位标题、对象数闸门；禁止只写「要先运行对比」。
- **五件套**：主路径 D / WF 为运行后出可视化；UX-SPEC 禁止单对象运行；未单写本校验条款。→ **部分提及**。
