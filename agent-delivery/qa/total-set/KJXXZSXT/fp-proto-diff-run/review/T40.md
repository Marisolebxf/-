## 说明抽检（3 条）

抽检目的：读说明列能知道「哪里有什么」，不能只写「样例 / 有筛选 / US-DS-POL-05」。

### 1. 功能点「按时间切换趋势分析图」

- **语义**：对象是趋势分析图，动作是按**时间**切换；维度条有时间下拉不等于图已按时间切片。
- **原型判定**：`DimensionBar`「时间」Select 有近1年/近3年/近5年；`onApply` 只把 `metrics` 传给 `TrendMetricsChart`，`trendMetricsSeriesData.months` 固定 12 个月，不随 `timeRange` 切片。→ **部分实现**。
- **原型说明写法**：写清「时间下拉有哪些、应用后只传指标、图不随时间变」；禁止只写「有维度条」。
- **原型路径**：`src/pages/policy-tracking/analysis/DimensionBar.jsx` `TIME_OPTIONS`；`PolicyAnalysis.jsx` `TrendMetricsChart metrics={appliedDimensions.metrics}`（路径列不写评述）。
- **五件套**：主路径 B 要求组合时间维度查看趋势；线框 DimensionBar 含时间。→ **有设计**（设计有时间维，不因原型未接线而改成无设计）。

### 2. 功能点「识别波动节点」

- **语义**：要在趋势序列上标出波动/拐点，不能因为有折线图就算识别。
- **原型判定**：`trendMetricsSeriesData.volatilityMarks` 为各指标写月份索引与说明（如支持力度「AI 专项加码」）；`TrendMetricsChart` 用红色 `markPoint` pin 标在对应坐标。→ **已实现**（mock 算能力）。
- **说明写法**：点名 pin 标注与 mock 说明文案，而不是「有趋势图」。
- **五件套**：US-DS-POL-05 / TRACE 只要求趋势落点，WF 未提波动节点。→ **无设计**（不因「多维指标趋势」四字记有设计）。

### 3. 功能点「未选取评估指标时不可查看动态趋势」

- **语义**：对象是动态趋势，闸门是**未选取指标则不可看**；组件里有 Empty 文案不等于闸门生效。
- **原型判定**：指标多选 `allowClear` 可清空，但 `activeMetrics` 在 `metrics?.length` 为空时回落到 `indicatorCategories` 前 3 项仍出图，页面走不到「请选择至少一个指标」。→ **未实现**。
- **说明写法**：写清「可清空、回落前三项、Empty 走不到」；路径仍标所查文件。
- **五件套**：DimensionBar 有指标多选，WF §4.3 四态未写该校验。→ **无设计**。
