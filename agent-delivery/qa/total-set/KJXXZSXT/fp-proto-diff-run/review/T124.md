- **五件套**：US-DS-POL-07 / WF PC01 写清洗质量看板与批次明细，未写采集接入作业。→ **无设计**。

### 2. 功能点「对多源政策数据去重合并」

- **语义**：要执行去重合并，不能因为规则表有「去重合并」文案就算页面能力。

- **五件套**：四卡/规则命中未点名去重合并算法。→ **无设计**（不因「清洗质量」三字记有设计）。

### 3. 功能点「质量校验未通过时不可作为高质量数据源输出」

- **语义**：对象是校验未通过的数据**不得作为高质量数据源输出**，不是「底座未就绪则不能点对比」。
