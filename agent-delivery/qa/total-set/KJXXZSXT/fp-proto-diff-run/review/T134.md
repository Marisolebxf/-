## 说明抽检（3 条）

抽检目的：读说明列能知道「哪里有什么」，不能只写「样例 / 有对比页 / US-DS-POL-09」。

### 1. 功能点「配置政策对比参数」

- **语义**：对象是**对比参数**（权重/阈值/时间窗等可改配置），不是页面上有「参数」二字或维度勾选即算。维度、筛选已拆成独立行。
- **原型判定**：Card「交互式对比配置」第三列仅只读「参数提示」招标五维清单；无 InputNumber/Slider 等参数控件；`runCompare` 不读独立参数。DS-12 推演参数不计入本叶。→ **未实现**。
- **原型说明写法**：写清「只有提示文案、无控件、执行不读参数」；路径仍标所查文件。
- **五件套**：POL-09 / 主路径 D / WF PC03 只有对象、维度、筛选与运行；IA「指令式配置」不是参数表单。→ **无设计**。

### 2. 功能点「未配置对比维度时不可执行政策对比」

- **语义**：零维度时必须挡住「运行对比」，有 Checkbox 不等于已做该闸门。
- **原型判定**：`runCompare` 在 `dims.length < 1` 时 warning「请至少勾选一个对比维度」并 return，不置 `ran`。→ **已实现**。
- **说明写法**：写清函数名、条件、warning 文案与不置 `ran`；禁止只写「有维度勾选」。
- **五件套**：USM-06 写自定义 ≥1 维度才产出可视化；WF 有维度勾选；未单写「零维度不可运行」。→ **部分提及**。

### 3. 功能点「配置变更后重新执行政策对比」

- **语义**：改对象/维度/筛选后能按新配置**再跑一遍对比**。「二次分析」备注 ≠ 重新执行；清结果但不提供再跑入口才算缺能力。
- **原型判定**：改 Select/Checkbox 会 `setRan(false)`；「运行对比」无已运行禁点，可按当前 `slots`/`dims` 重跑。`runSecondary` 只写冲突核查备注。→ **已实现**。
- **说明写法**：写清 `setRan(false)` + 可再点运行，并点明二次分析不是重跑。
- **五件套**：主路径 D / UX-SPEC 仅一次运行对比，未见「配置变更后重新执行」。→ **无设计**。
