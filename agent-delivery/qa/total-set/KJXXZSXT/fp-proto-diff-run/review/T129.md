## 说明抽检（3 条）

抽检目的：读说明列能知道「哪里有什么」，不能只写「样例 / 有条款树 / US-DS-POL-08」。条款树有节点 ≠ 已拆细则；有条款分层 ≠ 四类核心条款已设计。

### 1. 功能点「未具备政策内容时不可拆解条款」

- **语义**：对象是**无政策内容**时不得进入拆解，不是页上已有政策下拉。
- **原型判定**：`PolicyParse` Select 只绑 `parsePolicies` 三条均含 `clauses`；Tree 随选即渲，无空正文禁用。→ **未实现**。
- **原型说明写法**：写清无闸门、Tree 无条件渲染；禁止因「有政策选择器」记已实现。
- **原型路径**：`PolicyPcPages.jsx` `PolicyParse` Select / Tree；`policyPcData.js` `parsePolicies`。
- **五件套**：US-DS-POL-08 / WF PC02 写查看条款树；异常只写底座未就绪禁用对比/研报。→ **无设计**。

### 2. 功能点「拆分政策细则」

- **语义**：要拆出**细则**层级（章/条之下的款、项或细则），有章条两级不算。
- **原型判定**：`clauses` 仅 parent+children，无 grandchildren；标题无「细则/款/项」。→ **未实现**。
- **说明写法**：写清「只查到章→条、缺第三层」；路径仍标 `clauses` / `mapClauseTree`。
- **五件套**：条款树/分层未点名细则。→ **无设计**（不因「条款树」三字记有设计）。

### 3. 功能点「分层展示政策章节、条目与细则」

- **语义**：展示必须覆盖章、条、细则三级，有 Tree 不等于三级都在。
- **原型判定**：`Tree` `defaultExpandAll` 展章/条；无细则层。→ **部分实现**。
- **说明写法**：写清控件名与缺哪一层。
- **五件套**：故事「条款分层」、线框「条款树」，未写章/条/细则三级。→ **部分提及**。
