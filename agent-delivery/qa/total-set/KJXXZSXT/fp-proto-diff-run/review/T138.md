## 说明抽检（3 条）

抽检目的：读说明列能知道「哪里有什么」，不能只写「样例 / 有研报页 / US-DS-POL-10」。

### 1. 功能点「使用标准化研报模板」

- **语义**：动作是**使用**标准化研报模板作为撰写骨架，不是页面上有「报告」或评价页模板导出即算。DS-11 `ReportTemplateExport` 不是本五级。
- **原型判定**：PC04 左侧 List「模块化研报目录」固定渲染 `reportOutline` 八段；点击切 `activeSection` 填正文。→ **已实现**（mock 算能力）。
- **原型说明写法**：写清控件名、八段大纲、非评价页模板；禁止只写「有研报」。
- **原型路径**：`PolicyPcPages.jsx` `PolicyInsightReport` List「模块化研报目录」；`policyPcData.js` `reportOutline`（路径列不写评述）。
- **五件套**：故事生成模块化研报；WF PC04 目录大纲+正文模块。→ **有设计**。章节：`US-DS-POL-10`；WF `F-DS-POL-PC04`；IA §4。

### 2. 功能点「自动整合对比结果」

- **语义**：要把对比**结果**写入研报，页头有对比对象 Tag 或对比页能跳研报不等于已整合 findings/摘要。
- **原型判定**：`loadCompareSlots` 只驱动页头 Tag；第六模块「多维对比结论」为写死段落，未读 `findings`/`summary`。→ **部分实现**。
- **说明写法**：写清「槽对象有、对比结果未入正文」；禁止只写「能从对比进研报」。
- **五件套**：主路径 D / WF PC03 有生成研报入口；PC04 未写把对比表/摘要写入正文。→ **部分提及**。

### 3. 功能点「未同时具备分析数据、对比结果与洞察结论时不可撰写研报」

- **语义**：三类素材**同时**齐备才允许撰写；只禁未运行对比、或底座未就绪，不等于本闸门。
- **原型判定**：无三类齐备判断；槽空仅页头「暂无」，深度段/`cmp`/`reportInsights` 仍出；对比页「生成研报」只 `disabled={!ran}`。→ **未实现**。
- **说明写法**：写清已查何处、缺齐备闸、对比页只闸 `ran`；路径仍标所查文件。
- **五件套**：仅底座未就绪禁用研报，未见三类素材闸。→ **无设计**。
