## 说明抽检（3 条）

抽检目的：读说明列能知道「哪里有什么」；对象是核增 `/display/policy/compare` 的跨政策交叉对比，不是 DS-10 全景重点比对（T39）。

### 1. 功能点「在条款内容维度交叉比对政策文件」

- **语义**：要在**条款内容**这一维上对多份政策做交叉对照，不能因为全景有详情对比表或页面有「对比」就算。
- **原型判定**：核增页 `compareDimensions` 有 `clause`「条款内容」；运行后 `tableData` / 雷达 / 柱状取 `compareScoreMatrix[].clause`。未用 `PolicyPanorama` `ComparisonModal`。→ **已实现**（mock 分值算能力）。
- **原型说明写法**：写清 Checkbox 名、表/图用 `clause` 分值；禁止只写「有对比」。
- **原型路径**：`policyPcData.js` `compareDimensions` `clause`；`PolicyPcPages.jsx` `PolicyCompareUpgrade` Checkbox.Group / `tableData`。
- **五件套**：US-DS-POL-09 自定义维度交叉对比；IA 输入含标准化条款；WF 维度勾选未点名条款内容。→ **部分提及**。章节：`US-DS-POL-09`；IA §3.2；WF `F-DS-POL-PC03` 维度勾选。

### 2. 功能点「识别政策间互补」

- **语义**：要产出**互补**识别结果，有差异表或「共性/冲突」不等于互补已实现。
- **原型判定**：`buildCompareFindings` 返回 `type:'互补'`（地方场景承接国家级主体等）；图谱首对边 `formatter:'互补'`。→ **已实现**。
- **说明写法**：点名互补卡与图谱边文案，而不是「有四类识别」。
- **五件套**：故事「识别共性、差异、互补与冲突」。→ **有设计**。

### 3. 功能点「未选择多份政策文件时不可交叉比对」

- **语义**：闸门是对象 **≥2** 才能跑交叉比对，不是「有多选下拉」即算。
- **原型判定**：`runCompare` 在 `selectedPolicies.length < 2` 时 warning 并 return，不置 `ran`；表保持 Empty。→ **已实现**（按钮未 disabled，但无法出结果）。
- **说明写法**：写清 warning 文案与不置 `ran`；禁止只写「有对象槽」。
- **五件套**：WF 对象槽 ≥2；USM-06 ≥2 对象；UX-SPEC 禁止单对象运行。→ **有设计**。未引用 DS-10 勾选上限 5。
