- **语义**：对象是指标库内的**实施时效**这一关键指标维度，有时效列不等于已提供该维指标条目。

- **五件套**：US-DS-POL-07 / WF PC01 仅规划指标库就绪卡，未点名实施时效。→ **无设计**。
