## 一、与专题相同的拆法（不另起一套）

- 工作单元 = **五级**；一条六级是一行原始需求。
- 一条功能点 = 一个动作 + 一个对象 + 一条可验收规则或结果。
- 七层检查：对象选择 → 指标/参数 → 取数计算 → 结论识别 → 展示 → 下钻 → 输出。没有就不拆。
- 规则层（有独立验收才计）：校验、默认、空态、处理中、失败；排名表升/降序分计。
- 规则来源只允许：原文直接 / 原文隐含 / 验收补充。
- 「等」「如」只取已写名称。禁止笛卡尔积、套话、未点名指标。
- **禁止**读 `demo-ui-science` / 五件套 / 旧用例来增减点。需规怎么写就怎么拆。
- 不写测试步骤 / 前置 / 预期。整表 ≥6000（可以略多，不能少）；不要为压条数合并仍能独立验收的点。

金样对照拆法（不要抄专题业务点）：本系统 `fp-split-run/work/T27.md`。

每个五级 `work/Txx.md` 表头除总条数外，必须按 **拆分维度**、**规则来源** 分别计数（只列实际出现的取值，两类合计均 = 条数）。

## 三、倍率（不要机械套专题 18×）

专题 66 条六级 × 18 ≈ 1200。展示系统六级更碎：地图放大、图层开关本身已接近最小交互。

| 六级类型 | 建议倍率 | 例子 |
|---|---|---|
| 地图/图层/检索交互 | 8–14 | 放大/缩小、拖动平移、复位 |
| 字段/详情查看 | 10–16 | 成果详情、载体信息 |
| 指标/评估/对比/预测 | 12–16 | 点名指标 + 图/表 + 规则层（金样 T27 用此档） |
| 名单/排行/订阅推送 | 10–16 | 需规写了订阅/导出就拆，未写不发明 |
| 报告/看板输出 | 10–16 | 章节分计 + 生成中/失败 |

整表 **≥6000**（606 六级，均约 10 条/六级；可以略多，不能少）。地图类取下限、评估类取上限，避免总表掉到 6000 以下。
