## 报告章节骨架（自模板提取，2026-10-13）

1. 引言（标识 / 系统概述 / 文档概述）
2. 引用文档（编制依据、测试依据、测试实施依据）
3. 测试环境说明（运行环境 / 测试终端：**移动端+电脑端+大屏端**适配声明 / 测试工具：Postman、JMeter）
4. 测试报告内容
   - 功能测试与兼容性测试：结果概述 → 详细结果 → 评价
   - 集成测试：结果概述 → 详细测试结果 → 评价
   - 性能测试：结果概述 → 性能测试场景（并发参数 + **JMeter 设置截图**）→ 评价
   - 安全测试：结果概述 → 详细结果（**渗透测试**：测试维度×测试项）→ 评价
5. 附录

注意：
- 三屏（移动/电脑/大屏）适配范围是 COMP 用例与报告「测试终端」节的前置决策（待决策 H3）。
- 性能报告需嵌入 JMeter 场景参数与截图；jmx 工程文件存 `qa/tools/jmeter/`。
- 安全报告按渗透测试维度组织；**总集用例模板无 SEC 类型码**，安全相关用例以 INT 子集（功能项前缀「安全」）承载，不新增类型码（spec §3.3 禁自造）。
