# Bug 正文

编号仍在 `qa/bug-registry.yaml` 取。这里只放正文，按系统和轮次各一份 Markdown。

```
qa/bugs/{系统码}/R{n}-{轮次短名}.md
```

| 系统码 | 系统 |
|--------|------|
| `KJZTFWXT` | 科技专题服务系统 |
| `KJXXZSXT` | 科技信息展示系统 |
| `SDWJSF-KJZTFWSFK` | 算法库（目录名用连字符） |

轮次与 `test-records/{系统码}/R{n}/` 对齐。短名写这一轮在测什么，例如 `R1-20261023-脚本修订.md`。同一系统同一轮只追加这一份，不按模块再拆文件。

一条 bug 先在 `bug-registry.yaml` 占号，再把 `bugs/_template.md` 里的条目贴进该轮文件。号的格式是 `BUG-{板块}-{系统}-{YYYYMMDD}-{3位}`，板块现用 `ZNFWJQ`。脚本 blocked 或 fail 本身不是 bug，确认是产品、数据或环境问题后再登记。

登记分两种，写在索引列和条目里，不另建目录：`人工` 是对话里指定的单条；`轮次` 是该轮收口时从试跑结果归集。后补归集不改已经写上的 `人工` 行。
