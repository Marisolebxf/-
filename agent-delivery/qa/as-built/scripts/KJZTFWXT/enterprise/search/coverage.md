## as-built 与旧表差异（执行时以左列为准）

| 点 | 旧 FUNC 期望 | 50892 / 代码现状 |
|----|----------------|------------------|
| 热门场景 | 进字段库、条件待应用 | `applyScene` 立刻检索；高筛面板 `filterOpen=false` |
| 查询方案恢复 | 回编辑态，须再点应用 | `onApplyTemplate` / Hub「我的方案」会直接 `apply` |
| 全选本页 | 三态全选控件 | 仅行复选框 +「已选 N 家企业」批量条 |
| 对比篮 | 页内无聚合入口 | 结果工具区 / 推荐区有「对比篮」按钮 |
| 点名称 vs 查看画像 | 同一抽屉 | 名称 → `openDetail`；查看画像 → `openProfile`（都是抽屉、不跳路由） |
