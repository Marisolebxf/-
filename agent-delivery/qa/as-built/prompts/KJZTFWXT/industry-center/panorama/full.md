判定铁律见 `as-built/prompts/_result.md` / `schema.md`，此处只写顺序与易错点。

## 推荐顺序

1. **开场**：1920×1080；登录 admin；goto `/industry-center/panorama`；可见时关对比篮；业务态条目前关「内部评审模式」（`aria-label`，禁 `first()`）。
2. **金样**：P0-01 → P0-02 → P0-03 → P0-04 → P0-05（入口 / 筛选默认 / H1摘要 / 图谱 / 动态演进）。
3. **联动与下钻**：P0-06（15 集群+脏标+切回开始分析）→ P0-07 / P0-08（结构列表点「集成电路设计」）。
4. **视图与图控**：P1-02 → P1-03。
5. **演进边界**：P1-01 / P1-05（单快照预期 allow_skip）。
6. **复合下钻 / 评审 / 清空**：P1-04（常 skip）→ P1-06 → P1-07。

## 易错点

| # | 点 | 处理 |
|---|----|------|
| 1 | 改条件不自动刷新 | 认脏标文案；满级后点「开始分析」（I2-12） |
| 2 | 生物产业组合分析失败 | 勿依赖其成功结果；联动验选项后切回默认再开始分析 |
| 3 | 图谱 canvas 点不到节点 | 详情用「结构列表」点环节名 |
| 4 | 单快照 | 状态对比/时间轴 disabled → P1-01/P1-05 allow_skip |
| 5 | 筛选标签文案 | 集群/产业/所属产业链 ≠ 用例「产业/产业链/细分」字面 |
| 6 | 评审开关 | 必须 `aria-label="内部评审模式"` |
| 7 | 对比篮遮挡 | 仅 `isVisible` 时点「关闭对比篮」 |
