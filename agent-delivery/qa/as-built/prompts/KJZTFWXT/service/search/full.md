# 服务机构查询 · 全量执行顺序

先读 `prompts/_result.md` 与 `scripts/KJZTFWXT/service/search/scripts.yaml`（含 `includes: gold.yaml`）。

## 推荐顺序

1. **壳层金样**：P0-01 → P0-02 → P0-03 → P0-04 → P0-07（无需命中数据）
2. **检索链**：P0-09 → P0-10 → P0-08（示例语义偏差）→ P0-17
3. **两 Tab**：P0-11（查机构）→ P0-12 / P1-02（高级筛选）
4. **结果态**（关键词用 fixtures `keyword_hit=深圳`）：P0-13 → P0-05 → P0-15 → P0-14 → P0-06 → P0-16
5. **空结果 / 会话 / 评审**：P1-01 → P1-04 → P1-03
6. **边界**：P2-01 → P2-02

## 易错点

- 进入页后系统对比篮常默认展开，点行级按钮前先「关闭对比篮」（P3/X4）。
- 检索三 Tab 与对比篮 tab（企业/产业/服务机构）同页，定位须 exact name。
- 示例 chip「深圳 检验检测」智能解析后常 0 命中；结果态脚本用「深圳」。
- 业务态断言前关「内部评审模式」（`aria-label`，勿 `first()` 盲点）。
- 抽屉断言限定 `.arco-drawer`；画像内容深验不在本册。
- P0-05 / P0-13 排序入口现场缺失 → `manual` 项不升机检假绿。

冒烟只跑 `gold.yaml`（P0-01~P0-07）。
