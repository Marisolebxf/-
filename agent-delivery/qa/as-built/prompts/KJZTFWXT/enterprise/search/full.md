## allow_skip 口径（记 Pass-N/A，不 Fail）

- 分页类需命中 >9：智能搜索 4493 条满足；若当日数据变化 ≤9 → P0-15 allow_skip。
- P1-13 热门企业 chip 未配 / P1-07 查企业无热门场景 → allow_skip + observed。
- P1-09 再筛收不到 0 → allow_skip + observed。
- P1-01/P1-02 无推荐分区 → allow_skip + observed（记开放项）。
- P0-17 断链模拟不可行（浏览器 offline 受限）→ 主路径（请求前缀核对）仍须执行，断链项 observed 降级。

## 导出必须落盘

P1-11 / P1-22：`scripts/{id}/artifacts/` 必须有下载文件；无文件 = Fail（file: null + 原因），不得用任务条冒充。核对七字段：企业名称/经营状态/所属产业/区县/资质荣誉/企业规模/综合竞争力分（≥6/7，行数=弹层对象数）。

## 易错点

- 对比篮常驻侧面板会拦截坐标点击：优先 JS click / 先 Esc 关浮层。
- 结果标题形态：「智能搜索结果 · 命中 N 家企业」；命中数只记 observed 不钉死。
- 系统级对比篮 tab（企业 5/50）不是检索模式 tab。
- 评审模式默认关闭（实勘）；业务态断言前若发现开着，先经人设面板关闭。
