# 培育企业推荐分析 · 执行顺序提示

> entry_id=`ent-cultivate` · 脚本目录 `scripts/KJZTFWXT/enterprise/cultivate/`  
> 结果判定铁律见 `prompts/_result.md`（勿在此复制相反口径）

## 推荐顺序

1. **金样**：P0-01 → P0-02 → P0-03 → P0-04 → P0-05  
2. **条件/门控**：P0-07 → P0-08 → P0-09 → P0-10 → P0-11 → P0-12  
3. **隔离**：P0-06（会切招引 URL，随后须回到 cultivation）  
4. **Tab/候选/历史**：P0-17 → P0-18 → P1-01  
5. **成功态依赖**（可整段 allow_skip）：P0-13 → P0-14 → P1-02 → P1-04 → P1-05 → P1-06 → P1-08 → P1-09  
6. **对比篮**：P0-05 / P1-07（篮内需有企业；关闭钮可见再点）  
7. **防重 / 指标 / 评审**：P1-03 → P0-15 → P0-16 → P1-10  

## 易错点

- **先 login 再深链**；`survey-page.mjs` 直深链可能停在 `/login`。
- P7：点 `.arco-select-view`，勿点隐藏 `input`。
- P3：关评审用 `aria-label="内部评审模式"`，禁止 `first()` 盲点。
- P8：每条自含 goto；勿假设上一条已关抽屉/关篮/关评审。
- 对比篮关闭钮可能不可见——可见再点。
- 勿把招引条件区（企业标签/行业领域/地域来源）写进本套断言。
- 本环境分析任务常失败：成功名单类用 `ALLOW_SKIP`，过程反馈仍要验。
