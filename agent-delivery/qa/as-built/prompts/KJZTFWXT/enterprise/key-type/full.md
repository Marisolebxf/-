# 重点企业类型分析 · 全量执行顺序（2026-10-14 v2.0 重写，24 条；id 映射按 D-KEYENT-1 母表校准）

> 铁律引用 `prompts/_result.md`（空 scripts/{id}/ 不算执行；observed 必填）。本文件只写顺序与易错点。
> 编号母表 = 任务书 D-KEYENT-1：金样 P0-01~05 锁定；P0-06~15 / P1-01~09 顺延。
> 顺序原则 = 金样 → 筛选交互组 → 视图切换组 → 抽屉组 → 报告组 → 评审组 → 空态组（利用状态连续性，减少 reload）。

## 推荐执行顺序

### 第 0 组 · 冒烟
1. 登录确认（已在业务页且 URL 不含 /login 则不重复登录；会话保持可直达路由）
2. **金样 P0-01 → P0-02 → P0-03 → P0-04 → P0-05**（任一 Fail → 停止，环境问题记 C2 后报告）
3. P0-05 结束时抽屉留着打开 → 直接接 P0-12（关闭恢复）

### 第 1 组 · 筛选交互组（默认态起）
4. P0-08（产业勾选回显）→ P0-09（类型勾选回显；顺带记选项清单）→ P1-01（移除类型标签回全部）
5. P0-11（区域级联切热门城市；只验级联展开+刷新+其余筛选保持）
6. P1-03（改开始年份 2023；核对状态不重置）

### 第 2 组 · 视图切换与地图组
7. P0-06（默认地图视图）→ P0-07（工具栏/热力默认/图例四级，同态顺带）
8. P1-02（热力开关关-开往返）
9. P0-13（放大/缩小往返；记录 zoom 级数）
10. P0-14（返回上一级 disabled，单城默认态）
11. P0-10（区域洞察构成，默认态）

### 第 3 组 · 抽屉组
12. P1-08（零匹配清单空态；默认 N=0 时直接用，否则调年份构造再还原）

### 第 4 组 · 报告组
13. P1-04（打开报告→目录七节→返回）→ P1-05（重开报告核下载禁用→返回）

### 第 5 组 · 评审模式（最后跑，避免污染业务态断言；结束必须关）
14. P0-15（评审开关往返 + 零泄漏核对）
15. P1-06（评审态 ⓘ 说明卡：覆盖企业类型数）
16. P1-07（评审态未登记图标：匹配企业数 / 覆盖区域数）

### 第 6 组 · 空态组（数据前提允许时）
17. P1-09（列表视图空态文案；与 P1-08 同零匹配态顺跑）

## allow_skip 口径（记 Pass-N/A，不 Fail）

- P1-08 / P1-09：正常筛选下无法构造零匹配（清单 N>0 且年份调整无效）→ allow_skip + observed 说明（数据前提不足）。
- 其余条目无预置 allow_skip；被测功能自身行为缺失不得 skip（retro R9 口径）。

## 易错点

- 评审模式默认态不定：业务态断言前先经 persona 菜单确认关闭；开关默认态记 observed（P0-15）。
- 评审组（P0-15/P1-06/P1-07）结束后必须确认评审模式已关闭，防污染。
- 清单按钮文案「查看企业清单（N）」N 以现场为准（含 0）；不钉死家数与公司名。
- KPI 数值 0/0/0 属正常数据态：只记 observed，不判 Fail。
- 地图缩放断言用 zoom 级数（天地图瓦片 TILEMATRIX 等价）/容器 data 属性，不核像素。
- 系统对比篮浮层（右上「打开对比篮，共 N 项」）非本册对象；坐标被挡时先 Esc 收起或 JS click（SEARCH retro R5 同款）。
- **槽位警示（本任务实际踩坑）**：id 与 func_id 映射必须以任务书母表为唯一真源逐条核对，不得沿用旧脚本槽位直觉（SEARCH R11 同款陷阱）。
