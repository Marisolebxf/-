## 推荐顺序

1. **结构冒烟**：P0-01 → P0-08 → P0-13（入口 / 操作栏 / Tab；不改篮数据）
2. **轻筛与选择**：P0-04 → P0-05 → P0-06 → P1-09
3. **发起与分组**：P0-09 → P0-10 → P1-13（取消不收起）
4. **分发到达**（会跳页）：P0-12 → P0-11 → P0-07 → P1-06（回篮恢复）
5. **候选 / 名单**：P1-03 → P1-05
6. **收集 / 排序**（改数据）：P0-02 → P0-03 → P0-14
7. **数量矩阵**：P0-16（需 ≥3 家）
8. **宿主去重**：P1-10 → P1-11
9. **互斥 / 旧链**：P1-01 → P1-02
10. **空态 / 清空（破坏性，放后）**：P1-04 → P0-15
11. **边界只读**：P1-07
12. **allow_skip 优先人工**：P1-08（满员）· P1-12（断网）

金样烟测：只跑 `gold.yaml`（P0-01~05）。

## 易错点

- **登录**：先 `/login` 再进宿主页；`survey-page.mjs` 直开 `/enterprise/search` 易停在登录页。
- **打开浮层**：优先 `getByRole('button', { name: /打开对比篮/ })`（dock）；页头另有「对比篮」按钮，勿点侧栏（侧栏无此项）。
- **评审模式**：业务态断言前关 `aria-label=内部评审模式`（P3）；菜单开着会挡点击。
- **遮挡**：对比篮浮层打开时可能挡主区（X4）；测宿主页前先关浮层（`关闭对比篮`）。
- **政策 Tab**：现场缺失，勿硬等第五 Tab。
- **痛点文案**：断言用 `/企业发展痛点/`，勿写死「痛难点」。
- **清空 / 空态**：改会话数据，勿插在分发条之前。
- **同路由隔离**：只测篮本身；评估/领域/风险页内部不写进本套。
