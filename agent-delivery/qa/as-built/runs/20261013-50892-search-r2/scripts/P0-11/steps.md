# P0-11 逐步实际操作

1. 编辑高级筛选面板 → 地区条件卡（值=广东省 / 深圳市）click → 级联面板展开（arco-cascader-panel）
2. 断言一列省级清单（34 项，北京市…新疆维吾尔自治区）✅
3. click 一列「广东省」→ 二列出现 21 地市 ✅（广州市…云浮市）
4. click 二列「深圳市」→ 三列出现深圳 9 区 ✅（罗湖区/福田区/南山区/宝安区/龙岗区/盐田区/龙华区/坪山区/光明区）
5. click 三列「福田区」→ active 链路 = 广东省→深圳市→福田区 三级高亮 ✅
6. 点「应用筛选（3）」→ 面板收起；条件摘要地区值仍为「深圳市」（市级粒度）✅
7. 判定 Pass（三列级联联动 + 逐级加载正确；区级不落卡值记 observed 现场口径）
