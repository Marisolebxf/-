# P0-10 逐步实际操作

1. 字段库（展开态）click「经营状态」tag → 条件区新增条件卡；已选计数 2→3；应用按钮变「应用筛选（3）」
2. 新卡值选择器（placeholder 可多选）click → 下拉：在营/注销/迁出/吊销
3. 选「在营」→ 卡回填「经营状态 · 属于 · 在营」（注：操作符下拉「属于/全部不包含」也在位）
4. click「应用筛选（3）」→ 结果态刷新：「高级筛选结果 命中 0 家企业 · 3 个字段条件 · AND」
5. 条件摘要三条：企业所属地区：深圳市 / 资质标签：high_tech / 经营状态：在营 ✅
6. 判定 Pass（组合条件添加→填值→应用→摘要同步 全链路通过；命中 0 记 observed）
