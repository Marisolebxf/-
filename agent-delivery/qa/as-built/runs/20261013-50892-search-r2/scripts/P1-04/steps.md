# P1-04 逐步实际操作

1. 结果态，click 结果卡「查看画像」按钮
2. .arco-drawer 打开：头部「企业画像快览 / 深 / 深圳市三通连接系统有限公司 / 在营」；URL 不变
3. 快览态无页签（基础摘要/竞争力摘要/风险摘要 + 加入对比/引育候选/查看详情按钮）
4. click「查看详情」→ 抽屉切换「企业详情」形态：十页签 [SEL:工商概况, 主要团队, 资质荣誉, 知识产权, 经营财务, 供应链关系, 关系图谱, 舆情动态, 风险信息, 招投标]
5. （顺带核对）关闭抽屉 → 结果列表仍在（承接后续用例直接使用）
6. 判定：抽屉打开路由不变 ✅ + 默认工商概况（经查看详情达十页签形态）✅ → Pass
