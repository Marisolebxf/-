# P0-09 逐步实际操作

1. 高级筛选 tab 下 click「编辑高级筛选 (2)」→ 字段库面板展开（非 arco-drawer，为页面内嵌面板）
2. 断言字段库标题/说明/已选计数(2)/收起开关 ✅
3. 断言 9 分类：基础信息、组织信息、经营/资质、技术能力、商业能力、供应链关系(商业能力内)、风险舆情、引育推荐、数据追溯 ✅
4. 断言字段项示例：企业名称、经营状态、注册资本、法定代表人、资质标签、上市状态、有效专利数、营收增长率、链主标识、风险等级、招引状态、数据更新时间等 ✅
5. 断言条件关系 同时满足(AND)/任一满足(OR) + 添加条件组 ✅
6. 断言底部栏：应用筛选（2）/清空条件/保存为查询方案/使用查询方案 ✅
7. click「收起字段库」→ 分类区隐藏、入口变「展开字段库」、已选计数保留 ✅
8. 判定 Pass
