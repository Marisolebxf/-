# P0-13 逐步实际操作

1. 承接 P0-05 后结果态（智能搜索 人工智能，排序默认综合竞争力优先）
2. JS mousedown+click 展开 .arco-select-view-single（排序）→ 下拉选项读取：综合竞争力优先/有效专利数/最新营收/成立时间（4/4 齐）
3. click「有效专利数」→ 等 2s → cards=36、标题在
4. 重复展开 → click「最新营收」→ cards=36、标题在、sort=最新营收
5. 重复展开 → click「成立时间」→ cards=36、标题在、sort=成立时间
6. 重复展开 → click「综合竞争力优先」→ cards=36、标题在（恢复默认）
7. 判定：四类选项齐 ✅ + 每次切换列表可见 ✅ → Pass
