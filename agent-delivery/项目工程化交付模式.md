## 修改原则

1. 优先复用 demo 仓已验证代码，**复制到 lumen 后独立演进**。
2. 不破坏 03 API 契约；变更走 **Python 算法 + Java API + 前端** 三侧会签。
3. **算法只在 Python**：ETL、NLP、图谱、模型、深度分析一律 Python 仓；Java 不写 ADS、不算法。
4. **Java 只做业务 API**：只读 ADS、SQL 级聚合、缓存、用户态（订阅/导出）。
5. **Python 不对外提供业务 REST**：仅 `/internal/*` 触发流水线；前端只调 Java。
6. 数据库变更必须有 SQL 脚本；索引变更说明原因；总纲见 `数据库设计.md`。
7. 无法完成的事项：handoff 中写明原因与后续建议。
8. **禁止仅本地验证**：必须 push + CI + K8s dev 测试通过后，方可将 task 标为 done。
