## 1. 技术栈（C1：Arco + Vant 分层共存）

| 项 | 选择 |
|----|------|
| 框架 | Vue 3 + `<script setup>` + TypeScript + Vite + Pinia |
| 壳 / Icon / D9 | **`@arco-design/web-vue`**：`Menu` / `Popover` / `Tooltip` + `@arco-design/web-vue/es/icon`。Arco **按需 CSS**，禁止整包 `arco.css` |
| 页内控件 | **Vant 4**：Field / Button / Picker / Popup / Switch / Tag / Empty / Form / NoticeBar / Toast / **Tabbar（仅页内）** / Tabs / **Steps** / Stepper / Checkbox。按钮高 **32px**、min-width **44px** |
| 图标 | 统一 Arco Icon（含导航与 D9）。禁止用 Vant Icon 顶 D9 契约 |
| 图表 | ECharts（`vue-echarts`）；**图谱页允许 AntV G6**（v1.2 解禁，见 §10.1） |
| 地图 | Leaflet + 天地图（`UnifiedLeafletMap` / `MapChrome`）；区域分布类页面保留 |
| 路由 | Vue Router **`createWebHistory`**（C6）；两仓统一。nginx 须 `try_files` 回 `index.html` |

**不选**：antd-mobile / NutUI / RN / uni-app / 小程序。**禁止** Vant `Tabbar` 做 App 一级 IA（C2）；同菜单页内容分块多时可用 Tabbar 做页内导航，与 `van-tabs` 按需选用。

分层规矩：一个 `.vue` 文件只写一套前缀（壳文件用 `a-menu`，页/筛选/登录用 `van-*`）。禁止同一模板混用。

优先复用（**按页选用，不是每页全上**）：`MobileShell` / `StatCard` / `ListCard` / `QuickFilter` / `ProfileDrawer` / `EnterpriseSearchPicker` / `PageTabs` / `BackToTop` / `SectionTitle` / `VChart` / `UnifiedLeafletMap` / `MapChrome`。

## 3. 骨架（C2：双层导航）

禁止 PC 三栏同屏。

**App 级**：顶栏（菜单 ≥44 / 标题 / 次要动作）+ **滑入侧栏**（L1/L2 白名单，非常驻）。**禁止** Tabbar / `van-tabbar` 做一级菜单。

**页内**：按该页信息架构堆叠，**一页一 vue**。分块较多时**酌情**用 **Vant Tabbar**（`PageTabs` 封装，不改路由；例：SPIKE 四块）；分块少用 `van-tabs`、分段按钮或单页滚动。二者按需，不叠两套。无统计不塞 KPI，无地理不塞地图，分块少不用底 Tab。

**详情**：见 §3.1。返回与关闭同义时只留关闭。筛选：见 §3.1（默认收纳，勿常驻占满首屏）。

拆仓后展示仓去掉「展示/专题」切换；专题仓只留专题白名单。

**仅地图页**（本页确有地理主舞台）：顶筛选摘要 + 中地图（≥55% 高）+ 底抽屉或页内 Tab。禁止左图层/右分析常驻。地图工具条 / 热力 / 图例 z-index 低于侧栏 Menu。非地图页不要套这套舞台。

### 3.1 列表 / 筛选 / 详情 / 分步分析（企业维试点 · 2026-09-01）

> 源自专题小屏企业查询 / 评估 / 引育走查；**其它模块按页复用语义，禁止整页抄企业评估壳**。

#### 列表卡（`ListCard`）

| 规则 | 说明 |
|------|------|
| 信息密度 | 检索/名单结果做成**简卡**：名称 + 2～4 行关键字段（状态/规模、区县/行业、链位、评分等）+ 可选标签；禁止只露名称 |
| 右箭头 `›` | **仅**可进入详情 / 可导航 / 可点选的行显示；只读展示（如「统一判定模型」权重行、优劣势说明、对标只读行）**禁止**箭头 |
| 关键热区 | 可点行整卡可点；只读行勿伪装成按钮（`show-chevron=false`） |

#### 分页

API 支持 `page/size` 时，UI **必须**有续载入口。三选一按场景定（同页只选一种）：

| 场景 | 优先 |
|------|------|
| 普通检索名单（企业查询等） | **「加载更多」按钮**（默认首选） |
| 短名单、强滚动沉浸 | 上拉 / `van-list` |
| 需精确定位页码 | 底部分页器 |

首屏勿只打 `page=1` 却无续载，导致「共 N 条」名不副实。

#### 筛选

| 规则 | 说明 |
|------|------|
| 外层常驻 | **筛选按钮** + **已选条件芯片**（可点清除）；给列表留纵向空间 |
| 条件本体 | 收进**半屏底弹**（`QuickFilter`）；扁平 ≤8 项 |
| 禁止 | 把完整筛选树长期铺在列表上方占满首屏 |

#### 详情抽屉（`ProfileDrawer`）

| 规则 | 说明 |
|------|------|
| 全屏画像 / 主详情 | 优先 **右侧滑出**（`position=right`，宽 100% 或 ≥86%）；避免主详情长期用底部大半屏 |
| 次要点选 / 轻量摘要 | 仍可用 **底部半屏** |
| 无画像数据 | 禁止静默失败：至少打开摘要抽屉（检索已有字段 + 说明文案） |
| 关闭 | 头/底只留「关闭」；返回与关闭同义时不重复两个按钮 |

#### 对象多选（评估 / 分析起评）

| 规则 | 说明 |
|------|------|
| 页内 | 只展示**已选**对象 +「添加」入口；可移除 |
| 全量检索 | 进**半屏/高屏弹层**，列表 + **复选框**；勿用带箭头的假「选择」行冒充勾选 |
| 起评门槛 | 文案写明「N 家起评」；**未达 `min` 禁止调用 precheck / 创建分析任务** |

#### 分步流程（明显先后步骤的分析页）

优先 `van-steps`（或等价步骤条），不要把选对象、模板、预检、发起、过程、结果堆成一屏长滚动。推荐顺序：

`选择对象 → 选模板（含可调权重若产品允许）→ 数据预检 → 发起分析 → 分析过程 → 结果查看`

步骤间用「上一步 / 下一步」；过程态与结果态切步骤高亮，勿假进度百分比。

#### 权重展示

| 场景 | 小屏做法 |
|------|----------|
| 统一判定模型等**只读权重**（引育推荐等） | 列表只读、无箭头、无滑块；合计校验可展示 |
| 企业评估等**当次可调权重** | 允许勾选指标 + Stepper；合计须 100%；改后记当次自定义，**不落个人模板** |
| PC 完整权重工作台 / 推演 | 仍仅 PC（§10） |

### 10.1 图谱 G6 小屏条款（v1.2 · 2026-11-11 用户裁定解禁）

> 适用：产业链全景图谱、服务链图谱等以图为主舞台的页面（`E-FE-SMALL-SCREEN` 专题侧）。

| 项 | 要求 |
|---|---|
| 允许 | AntV G6 只读浏览：`fitView`、双指/滚轮缩放、拖拽平移、节点/边 tap 选中 |
| 交互 | 选中节点/边 → `ProfileDrawer` 右侧滑出详情；返回与关闭同义只留关闭（§3.1） |
| **禁止** | 图谱**编辑**（增删节点/连线/布局保存）、小地图 minimap 常驻、右键上下文菜单；建模仍仅 PC |
| 降载 | 首选 G6 `mode: 'compact'` 或简化样式（去阴影/动画）；节点/边规模超过约 **300 节点 / 800 边** 时按层级折叠（先收叶子层），提供「展开下一层」入口；超限仍卡顿则回退层级列表形态（§5 映射） |
| 布局 | 布局算法与 PC 同源（dagre/force 配置复制后调参：`linkDistance` 缩小、开启 `animation: false`）；禁止另起一套图视觉 |
| 性能 | 首帧渲染 >1.5s 或交互掉帧明显即触发降载；页面须提供无图兜底（列表形态）开关 |

地图：Leaflet 保留（§1 不变）；工具条/热力/图例 z-index 低于侧栏 Menu（§3）。

## 12. AI 自检

1. Vue3；壳/D9 用 Arco，页内用 Vant；Tabbar 只在页内、不进侧栏；主色/页底正确  
2. 无 PC 三栏；App 导航是滑入侧栏  
3. 按钮高 32 / 宽 ≥44；图标热区 44×44；产品门 ≤767  
4. 筛选已降维（外层按钮+芯片、条件进半屏）；D9 追溯仍在  
5. 只经 gateway；路由 **history**  
6. 专题页不进 `lumen-ui-topic`  
7. handoff 写明裁自哪页、砍了什么、目标仓、Mock 开关  
8. 无统计不塞 KPI；无地理不塞地图；分块少不用底 Tab；一页一 vue、无配置驱动套版  
9. 地图控件不盖侧栏；抽屉同义按钮不重复（只留关闭）  
10. 列表卡有关键字段；只读行无箭头；名单有续载（加载更多 / 上拉 / 分页三选一）  
11. 主详情优先右侧滑出；无数据时仍开摘要抽屉，禁止静默无响应  
12. 分步分析用 Steps；未达起评家数不调 precheck / create
