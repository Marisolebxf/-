## 怎么改

1. 改阶段指针、日期、责任人、状态 → 只改 [`project-plan.yaml`](./project-plan.yaml)，再同步本 MD。智树三线叙述可同步 [02-进度](./工程过程/02-策划与监控/02-智树工作计划/02-进度/02-进度.md)。  
2. 大节点已有 `task_ids`（Epic `E-PM-DELIVERY`，默认 **backlog**）。要派工须 **confirm 解锁**，禁止手改 ready。S3 草案 ID 见 `PLAN-ZHISHU-PMBOK-L01` handoff，本页不自动建单。  
3. 阶段切换：出阶段条件满足且成果在仓 → PM 把 `current_stage_id` 改到下一阶段。  
4. 对外日期与范围承诺仍由 PM 拍板；AI 不得把节点标 `done`。
