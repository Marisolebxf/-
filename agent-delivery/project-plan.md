## 怎么改

1. 改阶段指针、日期、责任人、状态 → 只改 [`project-plan.yaml`](./project-plan.yaml)，再同步本 MD。  
2. 大节点已有 `task_ids`（Epic `E-PM-DELIVERY`，默认 **backlog**）。要派工须 **confirm 解锁**，禁止手改 ready。S3 / 工程叶仍按模块另拆，不在本页自动生成。  
3. 阶段切换：出阶段条件满足且成果在仓 → PM 把 `current_stage_id` 改到下一阶段。  
4. 对外日期与范围承诺仍由 PM 拍板；AI 不得把节点标 `done`。
