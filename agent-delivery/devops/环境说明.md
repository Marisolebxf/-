## 和发布有关的进程

模型调用都在 Python 进程里。Java 不持有模型密钥。

| Deployment | 镜像来自 | `origin/dev` 发布 |
|---|---|---|
| `gkxlumen-platform-entan-py` | `lumen-algo-py` 的 entan api | `deploy:entan-api` 在 dev 自动 |
| `gkxlumen-platform-entan-py-worker` | `lumen-algo-py` 的 entan worker | 默认手动 |
| `lumen-platform-algo-py` / `-worker` | `lumen-algo-py` 的 api / worker | 自动 |
| `gkxlumen-platform-innov-py` | `lumen-algo-py` 的 innov 制品 | 默认手动 |
| `demo-platform-innov-py` | demo 创新监测。Deployment 由 `gkx_service_demo` 的 Helm 创建 | 见 `demo-algo-science` CI 注释 |

正式 lumen 不调用 `demo-*` 服务。`demo-platform-innov-py` 仍在同一命名空间，模型配置已挂到同一份 Secret，避免集群里留两份模型密钥。

可观测入口见 [observability.md](../observability.md)。对象存储目录见架构基线 D14。
