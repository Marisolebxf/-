## 2. 现状基线（2026-11-11 盘点）

**PC 仓 `lumen-ui-topic`（门户接入已完成，`LUMEN-PORTAL-IFRAME-L01`）**：
- `src/portal/` 10 文件：`embed`（iframe 识别，`window.parent!==window`）/ `messenger`（iframe-bridge postMessage SDK + origin 白名单）/ `auth`（`portal_access_token` 主域 Cookie + Bearer）/ `perms`（`/admin/get-permission-info` + 菜单 URL 反查 navItem 授 permCode）/ `route-sync`（ROUTE_CHANGE 双向 + PAGE_READY）/ `device-switch`（device.change 整页切站，保留 path/query/hash，读 `VITE_TOPIC_MOBILE_URL`/`VITE_TOPIC_PC_URL`）/ `sessionExpired` / `noPermission`
- 路由守卫已接：嵌入态门户 Cookie 鉴权、未登录跳门户 SSO、无权限上报、401 会话过期分流

**mobile 仓 `lumen-ui-topic-mobile`**：
- ✅ 拆仓壳（MobileShell/断点/review 层）、`/tts/msvcz` base、CI/K8s（NodePort 30902）、企业维 12 项真页（`FE-TOPIC-SMALL-ENT-L01` integration）
- ❌ 无 `src/portal/` 模块；request.ts 仅本地 storage token；nav 无权限；**nav path 与 PC 不一致**（自造 `/enterprise-center/...`，PC 实为 `enterprise/enterprise-search` 等，见 §3 P1 对照）；26 项业务页 + 全部 CMS/VIZ/门户页为 placeholder 或缺路由

## 3. 第一阶段：门户接入与站点切换（本次指令范围）

> 目标里程碑 **M1「门户接入可用」（11-24）**：`https://edu.itic-sci.com/tts/msvcz` 在统一门户 iframe 内完整运行——登录态继承、菜单权限过滤、深链下发/上报、无权限/会话过期分流、device.change 双向切站、独立访问自动按设备落站。

### P0 · portal 模块移植（mobile 仓）≈ 3 人日 · 11-11 ~ 11-13

| 工作 | 说明 |
|---|---|
| 复制 `src/portal/` 10 文件 | 从 PC 仓整目录移植；`route-sync` 中 PC 专属注释（「移动端仓另行消费」）在本仓落地 |
| `perms.ts` 适配 | URL 反查目标从 PC `navGroups` 换 mobile `nav.ts`（P1 对齐后同 path 恒等映射）；`source` 标识改 `lumen-ui-topic-mobile` |
| `request.ts` 接线 | 嵌入态 `resolveAccessToken` 读门户 Cookie 作 Bearer；401 走 `sessionExpired` 上报 |
| `main.ts` / `MobileShell` 挂载 | `setupPortalRouteSync` + `setupDeviceSiteSwitch`；PAGE_READY source/title |
| env | `.env.production` 补 `VITE_PORTAL_ORIGINS`、`VITE_PORTAL_LOGIN_URL`、`VITE_TOPIC_PC_URL`（=PC 站 `/tts/svcz` 地址） |

### P1 · nav path 对齐 PC + 路由全量化 ≈ 3 人日 · 11-13 ~ 11-18（与 P0 尾部重叠）

| 工作 | 说明 |
|---|---|
| `nav.ts` 重写 | 全部 item path 改为 PC `menu.ts` 完整 path（`{groupKey}/{pathKey}` + 必要 query）。对照示例：`/development/search`→`/enterprise/enterprise-search`；`/enterprise-center/evaluation/technology`→`/enterprise/evaluation?workspace=technology`；`/industry-center/diagnosis/cycle`→`/industry-center/diagnosis?workspace=cycle`；`/service-center/search`→`/service/service-center/search`；`/intelligence/vitality`→`/intelligence/vitality`（本就一致） |
| 路由表全量 | 覆盖 PC **全部**菜单 path：40 个可见菜单项 + `showInMenu:false` 的门户页（policy-portal、service-portal 系列）、CMS（enterprise/policy/service/panorama 4 组 workspace）、VIZ（4 页）、deep-link（industry results/reports、enterprise/:orgId、intelligence tasks/report）、login/auth-error/404 |
| 降级承载组件 | 未适配页统一挂 `NotAdaptedView`（标题 + 数据状态 + 「该功能建议在 PC 端使用」引导 + 仍可跳 PC 深链），保证门户任意 subPath 下发不 404；后续批次逐页替换 |
| 企业维 12 项 path 迁移 | 已有 9 个 vue 的路由 path 更新 + 站内跳转/返回逻辑同步；`SPIKE_PAGES` 映射表按新 path 重建 |
| selfcheck | 路由与 PC menu path 全量 diff 断言（`pnpm test` 加一条：nav 路径集合 ⊆ PC 菜单路径集合） |

### P2 · 菜单权限接线 ≈ 2 人日 · 11-18 ~ 11-19

- 嵌入态：`get-permission-info` → 菜单 URL 反查授 navItem；未授权路径 → `noPermission` 上报门户 + 本地引导页
- 独立态：对齐 PC `shouldLoadPortalPerms()`（SSO 登录态拉真实权限；仅 mock 登录跳过）
- 侧栏白名单与权限交集渲染：侧栏仍按 nav 白名单展示核心项，权限再过滤一层（无权限不显示/不可进）

### P3 · 设备/尺寸自动切站（两仓）≈ 1.5 人日 · 11-19 ~ 11-20

| 场景 | 逻辑 |
|---|---|
| 门户 iframe 内 | `device.change`（PC 仓 `device-switch.ts` 已实现，补 mobile 侧同款）：整页跳目标站，**path/query/hash 原样保留**（P1 对齐后天然成立） |
| 独立访问·移动站 | 首载 UA（mobile UA）或 viewport ≥768 且非触屏 → 跳 `VITE_TOPIC_PC_URL` 同路径 |
| 独立访问·PC 站 | 首载移动 UA / viewport ≤767 → 跳 `VITE_TOPIC_MOBILE_URL` 同路径（PC 仓新增，约 1 人日） |
| 防抖 | `sessionStorage` 记忆手动切回（门户下发的切换不记忆），避免跳转抖动；两站对称 |

### P4 · 门户端到端联调 ≈ 2 人日 · 11-20 ~ 11-24（含缓冲）

清单：iframe 加载 `/tts/msvcz` → Cookie 登录态 → 权限拉取过滤 → 侧栏渲染 → 菜单点击下发 code/subPath 深链 → 页内路由上报 ROUTE_CHANGE → 无权限页 → token 过期 SESSION_EXPIRED → device.change 往返切站（path 保持）→ 独立访问自动落站 → K8s dev（30902/域名反代）验证 nginx `try_files` 与 `/tts/msvcz` 前缀。

**第一阶段合计 ≈ 11.5 人日。**

### 外部配合项（非本队可控，需提前发起）

1. 门户侧：`/tts/msvcz` 应用注册/入口挂载、菜单配置是否复用 PC 同一份 URL（path 对齐后应可复用——**需门户管理员确认**）
2. 运维：`edu.itic-sci.com` 反代 `/tts/msvcz` → topic-mobile K8s 服务（对照 `/tts/svcz` 现有配置）
3. 网关：mobile 站经 `gkxlumen-platform-gateway` 的 `/api` 转发与 PC 同链路（应无增量，验证即可）

## 5. 每批 DoD（第一阶段 P0~P4 适用第 1~5 条，第二阶段全量）

1. 五维复刻：布局（一页一 vue）/ 交互（§3.1 + I2-12）/ 样式（`--sci-*`，主色 `#165DFF` 页底 `#D8E7FC`，按钮高 32 宽≥44 热区 44）/ 评审（`@/review` 门控，关后零泄漏）/ Mock 开关（`USE_MOCK=false` 无 fixture 填数）
2. D9 血缘：每个统计数字旁 ⓘ / 角标齐全；抽屉 8 件套 + 就绪度四行
3. 工程自检：`pnpm test` / `pnpm type-check` / `pnpm build` 绿；只经 `gkxlumen-platform-gateway`
4. **门户联调项**（第一阶段新增）：深链恢复、路由上报、权限过滤、会话过期、切站 path 保持
5. handoff：写明裁自哪页、砍了什么、Mock 开关、`ponytail: full`
6. G6/地图页：小屏交互可达（缩放/拖拽/点选），性能走查（节点数上限降载策略）
