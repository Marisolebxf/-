## P06 重难点与应对

**目的**：先说清「难在咨询、窗口、接口前置」，再用注册表类型分布作证；**不讲 11-10 窗口挤。**

**画面：一句总判 + 指标类型分布条 + 三条横条（左难点、右应对）**

总判：统计页能建；难点在咨询口径、展示作为全项目窗口，以及多厂商接口前置。

分布条（指标注册表粗分，**不是已实现数**）：统计 STAT 158（28%）· 加权 COMPUTE 5（1%）· 模型 MODEL 203（36%）· 混合 MIX 31（6%，注册表键 MIXED）· 图谱 GRAPH 32（6%）。另三方/接口 103、未定 25，登记合计 **557**。

| # | 难点 | 要点 | 应对 |
|---|---|---|---|
| 1 | **深度分析难于统计建单** | 统计看板可建；企业评估、政策效果推演要专家级战略咨询。指标须符合国内外常用规范；数据不够全就必须降级裁剪 | **靠算法中台解耦工程链路和算法模型** |
| 2 | **展示是全项目成果窗口** | 展示系统综合呈现全部算法与 AI 战略咨询成果，对齐工作量大。成败依赖总体方案合理分工，不能把跨厂商责任压给展示一家 | **靠严谨的指标定义迎接各方挑战** |
| 3 | **外部依赖体量大、接口须前置** | 基础指标、API、图谱、算法能力多厂商分阶段提供。指标与算法接口须前置并预留联调，质量与进度风险大 | **靠 DWD 前置设计屏蔽等待三方数据源的进度风险** |

**口播**  
「统计能建，深度难。类型分布是口径登记，不是已经做完。三条应对：算法中台把工程链路和模型解开，换模型不换链路；展示窗口靠严谨指标定义迎接各方对口径的挑战；外部依赖靠 DWD 前置设计，不把工程进度绑死在三方到数日上。」

**被问数据缺口**：承认「先冻应用层标准表，源未齐时诚实降级或 DEMO 登记」，不承诺源没有也能 FULL。

## P07 集成成功长什么样

**目的**：用总集语言定义成功，而不是「页面做完」。

**画面：图 B · 验收闭环（横链）**

```
范围可对账  →  接口可联调  →  环境可部署  →  核验包可收  →  预生产可进
（叶子±10%）    （接口包）      （CI→环境）     （智谱/总集）    （总集准入）
```

**四条成功标准（对总集）**
1. **范围可核验**：报价内项有入口；超出 ±10% 必走变更，不静默加删。
2. **接口可联调**：他队/智谱能力按接口包提供样例后可测，而不是口头「能连」。
3. **口径可追溯**：界面统计数字能回到口径、公式、源表，便于监理/确收。
4. **分层交付诚实**：完整链路 / 三方集成 / 演示兜底三级分开登记，**不用 Mock 冒充完整链路**。

**口播**  
「总集成败不看页面张数，看能不能进你们的集成和确收。智树按这四条设计方案和工期。」

## P12 规范驱动开发（1）· 双轨三门

**时长：本页+下页合计 2–3 分钟。**

**目的**：让总集相信「不是能人项目」，而是可审计的定义→实现。

**画面：图 G · 双轨**

```
【定义轨】需规/范围 → 指标适用 → 体验（故事/线框）
         → 门1 梳理 → 门2 会签 → 门3 拍板
                                    │
                                    ▼  门3 之后才批量开工
【实现轨】拆工程单 → 开发联调 → 流水线 → 环境 → 人签收
```

**三条硬边界（给总集记）**
1. **没拍板，不批量开工**（防止「先做了再补需求」导致集成对不上）。
2. **合规坐标与体验坐标分开**：招标叶子管「有没有」；故事地图管「好不好用」；允许信息架构重组，**禁止静默删叶子**。
3. **业务口径不外包**：歧义进决策清单，不由实施方替甲方拍板。

**口播**  
「规范驱动的意思是：先冻结『做什么、长什么样、口径是什么』，再进入可联调的实现。总集看到的每个功能点，都能回到需规章节和验收口径。」

**禁讲**：Cursor、MCP、状态机内部名。

## P17 投标优势

**五条（总集视角，克制）**

1. **边界清楚**：做应用层，不抢智算/图谱/门户/智库/大屏，总集集成路径短。
2. **架构可进总图**：统一网关、共享算法出口、ADS 契约、前端不直连，便于总集观测与准入。
3. **指标与数据诚实**：缺口可对外沟通，三级交付不造假闭环。
4. **接口按包管理**：展示依赖可治理，不靠口头联调。
5. **规范驱动 + 证据链**：需规→追溯→契约→环境→核验包，抽查成本低。

**口播只念 1、2、5**；3、4 作补充。不要把编排当第一条。
