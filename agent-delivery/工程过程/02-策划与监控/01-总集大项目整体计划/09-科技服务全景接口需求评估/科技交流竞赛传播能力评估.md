# 科技交流、科技竞赛、科技传播数据与功能提供能力评估

## 0. 需求方结论摘要

本章节面向需求提出方，先给出当前系统能够提供和不能提供的结论；后续章节再说明字段、接口和数据依据。

| 需求 | 当前结论 | 说明 |
|---|---|---|
| 科技传播文章分类查询 | 支持 | 现有 7 种文章类型：顶级期刊、学术会议、前沿成果、活动资讯、技术课程、成果转化、需求发布 |
| 科技交流活动分类查询 | 支持 | 现有 6 种活动类别：学术交流、专题研讨、技术讲座、专业论坛、合作项目、行业资讯 |
| 期刊查询 | 支持分类查询 | 期刊数据来自独立期刊服务，不与科技传播文章混在同一数据源中 |
| 科技人才/人物查询 | 支持分类查询 | 人才数据来自独立学者服务，不与文章、活动、期刊做混合排序 |
| 文章、活动、期刊、人才统一搜索 | 不建议提供 | 各数据源分页、排序和字段不一致；综合搜索需要本地重新实现聚合分页和排序，存在性能和一致性风险 |
| 热门标签搜索/热门标签统计 | 不支持 | 标签只能随单篇文章或单个活动返回，当前没有热门标签统计接口，也不能按标签查询现有列表 |
| 展览、图书、视频 | 当前不支持 | 没有对应的稳定数据类型、数据源或查询接口 |
| 科技传播国际/国内/区域/市级等“级别” | 不支持 | 科技传播没有统一级别字段；活动状态也不等同于级别 |
| 活动讲者关联学者 | 不支持直接关联 | 当前活动只稳定保存和返回讲者姓名文本，没有可用的学者 ID 绑定 |
| 精确地图分布 | 不支持 | 只有地点文本，没有稳定经纬度 |
| 实际到场人数 | 不支持 | 当前只能提供报名人数，不能代表实际到场人数 |

### 0.1 需求方需要注意的三点

1. **分类搜索**：文章、活动、期刊、人才分别进入对应分类后查询；输入一次关键词不会跨所有数据源混合返回结果。
2. **字段有值的前提**：接口有字段不代表一定有内容。如果原始录入没有填写，返回值可能为空、0、空数组或 `null`。
3. **不支持的含义**：表示当前表结构、录入流程或接口没有足够数据，不能通过标签、文本推断或前端展示直接替代。

## 1. 文档目的

本文档结合已提供的产品原型、S-01～S-09 接口需求说明，以及现有项目中已具备的业务数据，评估可对外提供的数据和功能


## 2. 评估结论

| 清单 | 业务内容 | 结论 | 说明 |
|---|---|---|---|
| S-01 | 活动数据及地图分布 | 部分支持 | 活动列表、详情、时间、地址、主办方、报名人数和状态可提供；精确 GIS 点位不支持 |
| S-02 | 资源推荐与专家信息 | 部分支持 | 可提供活动附件和活动中填写的讲者姓名文本；不支持资源重要性/关联度及讲者—学者画像关联 |
| S-03 | 多场景数据流转 | 部分支持 | 可新增组合接口保证列表和详情数据一致；无法补齐本身不存在的地理和专家关联数据 |
| S-04 | 竞赛信息 | 基本支持 | 可新增面向展示端的竞赛列表、详情、筛选和统计接口 |
| S-05 | 竞赛项目查询 | 部分支持 | 可提供已存在的数据集、开源成果和学习资源；无独立的“项目/课题”业务实体 |
| S-06 | 成绩榜单 | 基本支持 | 排名、队伍、成员、分数和提交次数可提供；项目名称、机构信息和奖金设置不支持 |
| S-07 | 标准化传播内容查询 | 部分支持 | 现有内容可按类型、学科、时间、机构、关键词查询；原型分类与现有分类不一致 |
| S-08 | 传播内容详情 | 基本支持 | 文本、封面、作者、机构、标签和链接可提供；结构化图片/音频/视频元数据不支持 |
| S-09 | 多端数据同步与分发 | 不支持完整能力 | 可提供内容发布状态和更新时间；无渠道级发布状态、同步水位和分发记录 |

总体上，在当前系统的前提下，可以完成三个板块的基础展示、详情查询、条件筛选、排行榜以及基于当前累计值的统计。对精确地图、竞赛项目实体、结构化媒体、历史流量趋势和多渠道分发等能力，新增接口也无法解决底层数据缺失问题。

## 3. 科技交流

### 3.1 可提供的数据

#### 活动基础数据

- 活动 ID、标题、摘要、正文、封面。
- 数据和查询层存在活动类别、学科领域、标签。当前活动类别仅包括：学术交流、专题研讨、技术讲座、专业论坛、合作项目、行业资讯，不包含“竞赛”；现有学科领域不等同于原型中的技术领域。C 端活动列表可按活动类别和学科筛选。
- 活动地点文本和原活动链接。
- 主办单位。
- 已报名人数；报名人数上限存在于活动扩展数据。
- 浏览量、发布时间、最后更新时间。
- 活动日程、日程时间和讲者姓名。

#### 活动资源

- 活动附件名称、文件大小、资源地址和上传时间。
- 当前资源响应不返回文件类型和资源审核状态，不能将其列为稳定展示字段。
- 与当前活动直接关联的资源列表。

#### 讲者信息

- 讲者姓名和议程信息。
- 当前“负责人/嘉宾”是自由文本输入，不能直接从活动讲者关联学者画像。
- 已有的独立学者列表、学者详情、论文和学术关系数据可继续对外提供，但它们与活动讲者目前是两个独立入口，无关联关系。

### 3.2 可新增的功能性接口

| 功能 | 可提供内容 |
|---|---|
| 科技交流总览 | 活动总数、年度活动数、已报名人次、同比/环比（历史数据完整时） |
| 活动分类查询 | 现有 C 端列表实际支持关键词、活动类别、学科领域、综合/最新/最热排序和分页；状态、时间、主办方、地点、报名人数区间和人数上限筛选需另行新增 |
| 活动地点分布 | 按现有地点文本进行分组统计，返回活动数和报名人次 |
| 活动详情 | 返回基础详情、日程、讲者文本、报名状态和标签；附件、资源列表、相关活动分别调用对应接口 |
| 活动榜单 | 按浏览量、报名人数、开始时间等现有字段排序 |
| 活动档案 | 按年份、类型、学科和主办方查询已结束或已归档活动 |

### 3.3 不支持的数据和功能

| 不支持项 | 原因 | 在当前约束下的处理方式 |
|---|---|---|
| 精确地图点位 | 活动数据没有经度和纬度 | 只能提供城市/地址文本分布，不保证在地图上精确落点 |
| 地理半径搜索 | 没有可用于距离计算的坐标 | 不支持“附近活动”、按距离排序 |
| 稳定的城市分布 | 当前录入流程只填写活动地点文本，没有单独填写城市 | 不支持 |
| 资源重要性和关联度 | 活动资源只保存文件信息，没有重要性、阅读量和关联分数 | 可按上传时间或固定规则排序 |
| 完整专家画像 | 当前活动录入流程只保存讲者姓名| 只提供活动中填写的讲者姓名；不能承诺活动直接跳转学者画像 |
| 活动讲者与学者关联 | 不支持 | 不支持 |
| 原型中的“竞赛”活动类型 | 科技交流活动类别只有学术交流、专题研讨、技术讲座、专业论坛、合作项目、行业资讯，不包含竞赛；科技竞赛属于独立业务模块 | 不支持作为科技交流活动类型筛选或展示 |
| 活动规模 | 没有活动规模字段及国际、国内、区域、市级等枚举；报名人数上限只是人数容量，不等同于活动规模 | 不支持活动规模展示和筛选 |
| 原型中的技术领域 | 当前只有 `subjectAreaId` 学科领域（哲学/经济学/法学/教育学等 13门类）和活动标签，没有技术领域树、行业分类或层级多选数据 | 不支持技术领域展示和筛选 |
| 真实参会人数 | 当前主要是报名数和预计人数，不等于实际到场人数 | 对外需明确标注为“报名人数” |

## 4. 科技竞赛

### 4.1 可提供的数据

#### 竞赛基础数据

- 竞赛 ID、名称、主题、简介、公告、详细说明和封面。
- 竞赛类型、系统竞赛级别（国家级、省级、市级、区县级、行业级、学校级）、主办方、组织方和联系方式。
- 报名、提交、评审、结果发布等时间节点。
- 参赛人数、队伍人数上限和竞赛状态。
- 赛事说明、排名说明和数据集说明；当前不提供奖金设置能力。

#### 数据集和学习资源

- 竞赛关联的训练、测试、评测数据集。
- 数据集名称、版本、更新时间、下载地址和运行环境。
- 竞赛相关 Notebook、文章、开源成果和结果文件。

#### 队伍、排名和参赛行为

- 队伍名称、队伍成员、成员角色和参赛人数。
- 实时排名、最终排名、周期排名和成果排名。
- 得分、提交次数、提交时间和采用的提交结果。
- 奖项、奖牌、证书和开源成果；不包含奖金设置能力。
- 报名信息和提交记录。

### 4.2 可新增的功能性接口

| 功能 | 可提供内容 |
|---|---|
| 竞赛总览 | 竞赛总数、进行中/即将开始/已结束数量、参赛人数和队伍数 |
| 公开竞赛列表 | 按关键词、标题、主办方、类型、系统竞赛级别、状态和时间筛选；不直接提供原型的国际/国内/区域级别 |
| 公开竞赛详情 | 在不暴露管理字段和私密信息的情况下，提供竞赛详情聚合数据 |
| 竞赛资源包 | 可提供数据集、Notebook、文章和开源成果 |
| 竞赛榜单 | 提供实时榜、结果榜、周期榜、成果榜和队伍信息 |
| 参赛行为查询 | 在权限允许的前提下，提供报名、提交、提交次数和最近提交时间 |
| 竞赛数据统计 | 按竞赛类型、系统竞赛级别、状态、主办方和时间统计数量；可统计报名和提交数 |

### 4.3 不支持的数据和功能

| 不支持项 | 原因 | 可替代内容 |
|---|---|---|
| 独立的竞赛项目/课题列表 | 现有数据模型中没有项目/课题实体 | 可提供数据集和竞赛资源 |
| 项目与应用场景映射 | 没有项目及应用场景关系数据 | 只能返回竞赛整体说明和数据集说明 |
| 标准化的竞赛领域 | 当前主要是自由文本主题，不是统一领域字典 | 可按竞赛类型和系统竞赛级别筛选，主题使用关键词检索 |
| 原型竞赛级别 | 原型级别为国际、国内、区域、市级；系统级别为国家级、省级、市级、区县级、行业级、学校级 | 仅“市级”同名支持；国际、国内、区域不支持直接显示或转换 |
| 竞赛影响力/影响范围 | 没有业务认定的影响力和范围字段 | 可提供系统竞赛级别、浏览量、参赛人数等客观指标 |
| 举办需求 | 没有结构化的举办需求数据 | 可展示竞赛详细说明，不能按举办需求查询 |
| 榜单中的项目名称 | 排名数据没有统一项目字段 | 可返回队伍名称、动态列和开源成果 |
| 完整参赛机构数据 | 报名信息中可能有单位名称，但队伍成员并不保证全部可关联 | 有报名单位时条件返回，无数据时留空 |
| 榜单增量同步 | 没有榜单同步水位和变更日志 | 可提供全量或分页查询，不宣称为增量同步 |
| 奖金设置 | 当前竞赛没有奖金设置功能 | 不返回奖金；可返回赛事说明等已有内容 |

| ID | 系统分类 |
|---:|---|
| 1 | 顶级期刊 |
| 2 | 学术会议 |
| 3 | 前沿成果 |
| 4 | 活动资讯 |
| 5 | 技术课程 |
| 6 | 成果转化 |

此外，内容还带有学科领域、所属门类、机构类型和用户/系统标签字段；这些只作为筛选或内容属性，不用于补齐原型分类。

活动数据另有独立的**活动类别**：学术交流、专题研讨、技术讲座、专业论坛、合作项目、行业资讯。活动类别只适用于科技交流活动，不等同于上述科技传播内容类型。

### 5.2 原型分类适配结论

下表只判断“现有系统是否有该原型分类”。不使用标签补齐、别名转换或虚拟分类；名称不同或数据结构不同，均按不支持直接显示处理。

| 原型分类 | 当前系统数据基础 | 支持方式 | 说明 |
|---|---|---|---|
| 文章 | 有 | 支持分类查询 | 对应科创热点现有 7 个内容类型 |
| 讲座 | 有 | 支持分类查询 | 对应科技交流活动类别“技术讲座”，不是科创热点文章类型 |
| 期刊 | 有，但来自独立期刊数据服务 | 支持分类查询 | 通过现有期刊接口独立查询，不与文章、活动、人才做综合聚合 |
| 人物/科技人才 | 有，但来自独立学者数据服务 | 支持分类查询 | 通过现有学者接口独立查询，不与文章、活动、期刊做混合排序 |
| 学术会议 | 有 | 支持 | 对应科创热点内容类型“学术会议” |
| 展览/创新成果展览 | 无 | 不支持 | “前沿成果”“成果转化”不能等同于展览，活动类别中也没有“展览” |
| 图书/科技图书 | 无 | 不支持 | 当前没有图书数据源和图书查询接口 |
| 视频/新媒体 | 无独立结构化类型 | 不支持直接显示 | 当前没有科技传播视频内容类型和视频数据接口 |
| 科普展、科学家讲坛、院士风采、信息素养大讲堂、科学文化交流 | 无同名分类 | 不支持 | 不支持 |

| 科技交流活动类别 | 1 学术交流、2 专题研讨、3 技术讲座、4 专业论坛、5 合作项目、6 行业资讯 | 支持分类筛选；与文章内容类型不是同一套分类 |
| 学科领域 | 哲学、经济学、法学、教育学、文学、历史学、理学、工学、农学、医学、军事学、管理学、艺术学 | 文章有筛选参数；活动有学科筛选参数，但 C 端列表不回显名称 |
| 文章门类 | 细胞与基因、合成生物、智能机器人、前沿新材料、光载信息、深地深海、脑科学与脑机工程、量子信息、其他 | 文章支持筛选和详情展示 |
| 发布机构类型 | 学校、机构、媒体、企业 | 文章支持筛选；列表不回显机构类型 |
| 成果转化状态 | 可以量产、通过中试、已有样品、其他 | 仅成果转化内容详情有意义，不是通用内容类型 |
| 推广范围 | 全体用户、认证用户 | 是访问范围，不是内容级别 |
| 科技传播级别 | 没有国际、国内、区域、市级等统一级别字段 | 不支持按级别展示或筛选 |
| 活动状态 | 报名中、进行中、已结束 | 是时间状态，不是活动级别 |

文章列表排序支持综合、时间/最新、热度、参与度、评分等参数，其中参与度排序当前实际复用浏览量；活动列表支持综合、最新和热度排序。两者均只在各自数据源内排序。

### 5.4 搜索方式与聚合边界

科技传播本期采用**按内容分类搜索**，不提供文章、活动、期刊和人才的综合聚合搜索。

原因如下：

1. 科创热点文章和科技交流活动使用本地科技传播业务表；期刊和科技人才使用独立的期刊/学者数据服务，不在科技传播业务表中。
2. 各数据源的 ID、字段、更新时间、排序规则和分页规则不一致，无法通过一条本地查询直接得到统一结果。
3. 如果做综合聚合搜索，需要同时调用多个数据源，并在本地重新实现混合结果的分页、排序、去重和异常降级；为了保证全局分页，通常还需要过量拉取各数据源结果，存在响应延迟和外部服务波动带来的性能风险。
4. 因此本期按分类分别查询、分别分页、分别排序，不将不同数据源的结果混合成一个统一列表。

| 分类 | 查询数据源 | 查询方式 | 本期边界 |
|---|---|---|---|
| 科创热点文章 | 科技传播本地业务表 | 按关键词、内容类型、学科、门类、机构和时间查询；标签作为返回属性 | 仅返回现有 7 个文章内容类型；标签筛选需另行新增或确认 |
| 科技交流活动 | 科技传播本地活动表 | 按关键词、活动类别、学科和活动状态查询 | 与文章列表分开分页和排序 |
| 期刊 | 独立期刊数据服务 | 通过现有期刊接口按关键词和期刊条件查询 | 不与文章、活动、人才做综合排序 |
| 科技人才/人物 | 独立学者数据服务 | 通过现有学者接口按学者条件查询 | 不与文章、活动、期刊做综合排序 |

因此，原型中的单一搜索框如果保留，前端应先选择或进入对应分类后再搜索；不能承诺输入一次关键词后返回跨数据源的统一分页结果。

说明：期刊和人才分类页可复用各自独立服务；如果科技传播对外路由尚未暴露所需的关键词查询，只增加薄的路由转发即可，不需要把期刊或人才数据落入本地科技传播表，也不需要在本地重新做跨源分页和排序。

### 5.5 可新增的分类功能接口

| 功能 | 可提供内容 |
|---|---|
| 科技传播首页总览 | 已发布内容总数、当期新增内容数、累计浏览量、累计分享量 |
| 传播分类导航 | 文章返回系统已有的 7 个内容类型及其数量；期刊、讲座、人物/科技人才分别进入各自分类查询；不新增原型中不存在的分类 |
| 内容分类查询 | 按关键词、内容类型、学科、所属门类、机构类型、时间和排序查询；标签作为返回属性；仅在同一数据源内分页 |
| 分类内容详情 | 返回对应数据源的基础详情、作者/机构、标签、外部链接、热度数据、评分和相关内容 |
| 热门内容榜 | 按浏览量、分享量、评分或综合规则排序；仅限已有对应统计字段的内容 |
| 内容发布趋势 | 按发布时间统计日/月/年新增内容数 |
| 内容类型分布 | 按内容类型、学科、所属门类和机构类型统计内容数量 |
| 内容审核与发布统计 | 统计待审核、已发布、已下线和已归档内容数量 |
| 热门标签搜索/热门标签统计 | 不支持 | 没有科技传播热门标签接口；现有标签只能随文章或活动逐条返回，不能按热度聚合，也不能作为现有列表查询条件 |

### 5.6 科技传播统计能力边界

#### 可以真实统计

| 统计项 | 是否支持 | 口径 |
|---|---|---|
| 已发布内容总数 | 支持 | 按当前有效、已发布的内容计数 |
| 分类内容数 | 支持 | 按现有类型/门类/标签分组计数 |
| 日/月/年新增内容数 | 支持 | 按内容发布时间计数 |
| 当前累计浏览量 | 支持 | 汇总当前内容浏览累计值 |
| 当前累计分享量 | 支持 | 汇总当前内容分享累计值 |
| 评分平均值、人数和分布 | 支持 | 按评分记录计算 |
| 热门内容排行 | 支持 | 使用浏览、分享、收藏和评分排序 |
| 审核、上线、下线、归档数量 | 支持 | 按当前状态计数 |

#### 不能真实统计

| 统计项 | 不支持原因 |
|---|---|
| 月度/日度浏览量趋势 | 现有内容保存的是当前累计浏览量，没有按时间分解的浏览快照或完整访问事件 |
| 日活/月活用户 | 缺少科技传播访问者的按日去重行为数据 |
| 真实 UV | 浏览累计值只能表示次数，无法去重为用户数 |
| 用户留存和转化漏斗 | 没有完整、连续的用户行为链路 |
| 分类的历史流量变化 | 没有分类+时间粒度的浏览统计快照 |
| 渠道触达量 | 没有分发渠道、终端和渠道阅读记录 |


### 5.7 不支持的其他数据和功能

| 不支持项 | 原因 | 可替代内容 |
|---|---|---|
| 结构化多媒体资源 | 没有内容级多媒体明细，无音频/视频时长、大小、排序和状态 | 可展示 Markdown 正文内的媒体链接和封面图 |
| 媒体有效期和媒体级权限 | 没有媒体级权限和到期时间 | 只能使用内容整体的访问范围 |
| 跨文章/活动统一的期刊、地点、主讲人元数据 | 文章没有统一期刊字段；活动只返回地点文本和议程主讲人姓名，不返回学者 ID；两类数据没有统一结构 | 可展示已有文本字段，不建议作为跨分类精确筛选或关联条件 |
| 多端增量同步 | 没有变更序列、同步水位和删除/下线事件流 | 可按最后更新时间分页查询，但不能保证严格的增量同步语义 |
| 多渠道发布跟踪 | 没有渠道级发布状态和失败记录 | 只能返回内容本身的上架、下架和归档状态 |
| 清洗和关联聚合结果 | 科技传播查询数据中没有可对外返回的清洗/聚合结果 | 只返回当前已审核、已发布的业务内容 |

## 7. 数据口径和验收建议

1. **活动参与人数**：默认指已报名人数，不表示实际到场人数。
2. **活动地区分布**：默认只表示地点文本分布；不表示精确经纬度分布。
3. **原型传播分类**：文章只返回系统已有的 7 个内容类型；讲座、期刊和人物/科技人才分别从对应分类数据源查询；原型中没有数据基础的展览、图书、视频等分类不直接显示。
4. **综合搜索边界**：不对文章、活动、期刊和人才做跨数据源聚合分页和排序；各分类独立返回结果。
5. **科技传播浏览量**：仅对外表达为当前累计浏览量。
6. **统计同比/环比**：只在对应历史周期数据完整时返回；无历史数据时返回空值。
7. **权限边界**：公开展示接口只返回已审核、可展示、未删除且符合访问范围的数据。
8. **缺失数据**：条件性字段无数据时返回空值，不使用文本推断或随机生成填充。

## 8. 最终结论

在当前系统功能下：

- **科技交流**可以交付活动列表、详情、档案、统计、地区文本分布、附件和活动中填写的讲者姓名，但不能交付精确 GIS 分布、资源智能推荐和活动讲者到学者画像的直接联动。
- **科技竞赛**可以交付竞赛列表、详情、数据集、队伍、榜单、报名和提交统计，但不能交付独立的竞赛项目/课题、应用场景映射和严格增量榜单同步。
- **科技传播**可以交付基于现有 7 个文章内容类型的内容查询、详情、推荐、版本、订阅、当前热度统计和新增内容趋势；期刊、科技人才和技术讲座分别按各自数据源分类查询，不做综合聚合搜索；标签只能逐条返回，不支持热门标签统计或热门标签搜索；原型中没有数据基础的展览、图书、视频等分类不直接提供，也不能交付真实流量时序、活跃用户、结构化多媒体和多渠道分发。

产品原型可保留三个板块的整体展示框架，但需将不具备数据基础的演示指标和功能替换为本文档中的可提供口径。
