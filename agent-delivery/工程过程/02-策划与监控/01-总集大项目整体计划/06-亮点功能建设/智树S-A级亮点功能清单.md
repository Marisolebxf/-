## 一、科技信息展示系统（中观战略咨询：看资源、做对标、配政策）

> 牵头：智树
> 战略定位：围绕区域、企业、机构、人才、政策等科技要素，形成"谁有基础、谁有潜力、该扶谁"的态势呈现能力。

### S 级亮点

#### S-DISP-01 · 区域科技创新态势全景驾驶舱

| 项 | 内容 |
|---|---|
| 模块 / 子模块 / 页面 | 科技发展态势 / 科技全域态势 / 区域创新全景驾驶舱 |
| 功能名称 | 区域科技创新态势全景驾驶舱 |
| 入选理由 | 直接面向政府科技管理部门"看资源、判态势"的高频决策场景，可独立包装为区域科技态势年度订阅服务，具备付费冲动。输出指数+看板+对比三类成果，符合 S 级"至少 2 类成果"标准。 |
| 功能描述 | 集成专利、论文、企业、人才、政策、资金、载体等多源科技要素，以区域（省/市/区）为粒度，动态生成科技创新态势综合指数，叠加结构热力、趋势曲线、对标雷达，实时呈现"谁有基础、谁有潜力、短板在哪"。 |
| 设计方案 | **数据层**：dwd_patent / dwd_zh_paper / dwd_en_paper / dwd_org_base_info / dwd_scholar / dwd_policy_base / dwd_macro_index_data 等源表，按月更新，标注可信/分析数据。**模型层**：区域创新综合指数 = 科技产出 + 创新主体 + 人才结构 + 政策环境 + 资金投入 五维等权（或 AHP 赋权），极值归一化至 0-100。**呈现层**：大屏驾驶舱（指数总览 + 五维分解 + 区域对标雷达 + 趋势曲线 + 短板预警）。**血缘层**：每个指数维度下钻至指标口径、源表字段、更新时间、计算逻辑。 |

#### S-DISP-02 · 政策精准匹配与智能推送引擎

| 项 | 内容 |
|---|---|
| 模块 / 子模块 / 页面 | 科技政策跟踪 / 政策分析评价 / 政策精准匹配 |
| 功能名称 | 政策精准匹配与智能推送引擎 |
| 入选理由 | 面向企业"找政策、报政策"的刚需场景，可独立包装为政策订阅服务（按企业规模/领域分级收费）。支撑"配资源、促转化"两类决策动作，符合 S 级决策支撑标准。 |
| 功能描述 | 基于企业画像（领域、规模、资质、研发投入、知识产权），从政策库中智能匹配适用政策，输出匹配度评分、申报要点、材料清单、截止提醒，并生成"一企一策"政策包。 |
| 设计方案 | **数据层**：政策库 dwd_policy_base（全文+元数据）+ 企业画像 dwd_org_base_info / dwd_org_tech_tag / dwd_org_annual_financial_info。**模型层**：政策-企业双向匹配 = 领域匹配（产业标签 × 政策适用领域）+ 资质匹配（高新技术企业/专精特新 × 政策门槛）+ 规模匹配（营收/人数 × 政策适用范围）+ 研发强度匹配。匹配度 0-100 分，分档推荐。**呈现层**：企业政策匹配清单（匹配度排序）+ 政策详情卡（申报条件/材料/流程/截止）+ 一键生成申报材料草稿。**血缘层**：每条匹配结果标注匹配依据与引用来源。 |

#### S-DISP-03 · 科技指数与区域对标分析

| 项 | 内容 |
|---|---|
| 模块 / 子模块 / 页面 | 科技发展态势 / 科技创新评估 / 科技指数与区域对标 |
| 功能名称 | 科技指数与区域对标分析 |
| 入选理由 | 科技指数是政府决策核心抓手，可独立包装为指数定制服务（按区域/领域收费）。支撑"选赛道、做对标"决策，输出指数+榜单+对比报告三类成果，数据血缘完整。 |
| 功能描述 | 构建多维度科技指数体系（综合创新指数、产业创新指数、人才指数、政策环境指数等），支持深圳与全国重点城市、粤港澳大湾区城市的多维对标，输出差距分析与改进建议。 |
| 设计方案 | **数据层**：宏观指标 dwd_macro_index_data + 区域科技要素汇总表。**模型层**：指数体系按"目标层-准则层-指标层"三级构建，准则层含创新投入/产出/主体/环境/绩效，指标层取权威统计口径。对标方法：极值归一化 + 加权合成 + 偏差分析。**呈现层**：指数排行榜 + 区域对标雷达图 + 差距清单 + 改进路径建议。**血缘层**：指数公式、权重来源、数据更新频率全链路可追溯。 |

## 二、科技专题服务系统（智树负责五模块）

> 智树负责模块：企业分析、产业链分析、服务机构分析、政策分析、综合智能分析
> 战略定位：宏观战略咨询——看方向、选赛道、找瓶颈。形成"产业往哪走、卡在哪、往哪投"的判断能力。

| 项 | 内容 |
|---|---|

| 功能名称 | 产业链全景图谱与瓶颈堵点识别 |
| 入选理由 | 直接支撑"选赛道、找短板"核心决策，是端到端主线"产业链短板识别与招引培育"的起点。可独立包装为产业链咨询服务（按产业链收费），具备强付费冲动。输出图谱+清单+建议三类成果。 |
| 功能描述 | 构建上中下游全链条图谱，标注各环节企业/机构/技术分布，通过供需缺口分析识别瓶颈堵点（断链/弱链/卡脖子环节），输出瓶颈清单与补强建议。 |
| 设计方案 | **数据层**：产业链标准表 dwd_industry_chain_info + 企业产业标签 dwd_org_industry_tags + 专利技术领域 + 供应链关系。**模型层**：链条完整度 = 各环节主体数/标准环节数；瓶颈识别 = 环节主体数低于阈值 OR 对外依存度高于阈值 OR 技术自给率低于阈值；按严重度分级。**呈现层**：产业链全景图谱（节点=环节，边=上下游关系）+ 瓶颈堵点清单（按严重度排序）+ 补强建议（招引方向/补链路径）。**血缘层**：每个瓶颈结论标注数据来源、计算逻辑、更新时间。 |
