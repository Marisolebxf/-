### 1.3 久新必须返回 vs 不需要返回

> **派生归属总注**：贡献度 / 热点预警 / 匹配度权重等算法产物统一由展示系统后台（BFF）**②派生**，久新只返回原始事实值；②派生字段久新不返（见各接口判定列标注）。

| 类别 | 久新必须返回 | 久新不需要返回 |
|---|---|---|
| 业务主键 | project_id / talent_id / entity_id / paper_id / patent_id / node_id / edge_id | — |
| 业务数据值 | count / growth / heat / citation_count / budget | contribution_score / hotspots score·rank / 匹配度 score（②派生，BFF 计算）；total/page/size（分页） |
| 业务文本 | title / lead_unit / lead_person / difficulty_type / research_path / name / stage_achievement / rating / summary | — |
| 坐标 | lng / lat | — |
| 时间 | year / date / updated_at | — |
| metric_id | 每个统计数字挂编码值 | 8 件套 + 四维就绪度（展示系统后台查 /metrics/v1/catalog） |
| 空态 | empty_reason 编码 | 中文 empty_message（data-gap-catalog 注入） |
| 诚实性 | status 事实状态（done/in_progress/todo），缺数返 null | 进度百分比、凑整数、假数据 |
| 枚举 | **编码值** | 中文名 / 色值 / 默认开关（查 /topic/v1/meta/all-dicts） |

> 三问题法判定：所有 `count` / `growth` / `regions[].count` / `disciplines[].count` / `talents[]` → ①事实，留；`talent_carrier_match[].score` → **②派生**（BFF 按权重计算，久新只返原始 `talent` / `carrier` / `field` / `distance_km`）；`talent_category_label` / `region_label` / `discipline_label` → 字典砍；**凑整数是 PIPL 风险**（324 不能显示成 400），久新 `count` 必须返实际整数。
