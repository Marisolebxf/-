> **公共入参与枚举中文对照（久新必读，复用 06 §2.1）**：凡入参/出参出现枚举编码，其含义一律以本表为准；中文名由展示系统后台查 `/topic/v1/meta/all-dicts` 注入前端。

| 枚举参数 | 取值（编码 → 中文） | 说明 |

| `start_time` / `end_time` | ISO 8601 日期，**精确到年月日**（`2020-01-01` / `2026-10-15`；需要时分秒可传 `2026-05-08T10:00:00+08:00`） | **本文件唯一的时间区间筛选入参**：闭区间含边界，+08:00；`end_time` 缺省当前时间。不使用 `year_range`/`start_year` 等年份入参。单年快照类入参 `year`（A2/A4 年度统计）为离散年度版本选择，语义不同，保留 |
| `sort_key`（TSX-A1） | `year` 按立项年度 · `contribution` 按贡献度评分 · `difficulty` 按难题分类 | 软科学课题排序字段 |

| `result_type` | —（本文件未使用该枚举） | 本文件（06c）正文未出现 `result_type` 编码；其编码含义以兄弟文件 06 §2.1 为准 |

| `relation_type` | `advisor` 师承 · `paper_coauthor` 论文合作 · `project_cooperator` 项目合作 · `institution_partner` 机构合作 | 协作关系 4 类（TSX-A4 出参 `edges[].relation_type`） |
| `empty_reason` | `no_source` 无数据源 · `filter_empty` 筛选无命中 · `sample_empty` 样本为空 | 空态原因编码；**中文 `empty_message` 由展示系统后台查 catalog 注入** |

### 1.3 久新必须返回 vs 不需要返回

| 类别 | 久新必须返回 | 久新不需要返回 |
|---|---|---|
| 业务主键 | project_id / talent_id / entity_id / paper_id / patent_id / node_id / edge_id | — |
| 业务数据值 | count / growth / contribution_score / heat / citation_count / score | total/page/size（分页） |
| 业务文本 | title / lead_unit / lead_person / difficulty_type / research_path / name / summary | — |
| 坐标 | lng / lat | — |
| 时间 | year / date / updated_at | — |
| metric_id | 每个统计数字挂编码值 | 8 件套 + 四维就绪度（展示系统后台查 /metrics/v1/catalog） |
| 空态 | empty_reason 编码 | 中文 empty_message（data-gap-catalog 注入） |
| 诚实性 | status 事实状态（done/in_progress/todo），缺数返 null | 进度百分比、凑整数、假数据 |
| 枚举 | **编码值** | 中文名 / 色值 / 默认开关（查 /topic/v1/meta/all-dicts） |

## 二、久新侧接口契约清单（4 条）

### 2.1 TSX-A1 软科学成果课题接口
- **展示系统后台对外**：`GET /v1/achievements/soft-science/projects`
- **久新占位路径**：`GET /v1/third-party/ts/achievements/soft-science`
- **供方**：久新

> **用途**（规划 M11-BE ①）：软科学课题列表 + 承担单位贡献度 + 难题领域分布 + 年度变化 + 类型结构。**原型对应**：数据资源 页面 · 软科学成果 Tab（ApplicationWindow 表格 + 年度变化趋势图 + 难题领域分布饼图）。

**入参表**

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `region_scope` | enum | 否 | `global` | 查询地域范围：`global` 全球 · `gba` 粤港澳大湾区 · `shenzhen` 深圳 |
| `start_time` / `end_time` | string(date) | 否 | 最近 5 年 | **立项时间区间**（ISO 8601 日期，精确到年月日，如 `2020-01-01`～`2025-12-31`，闭区间，+08:00）；缺省最近 5 年 |
| `difficulty_types[]` | string[] | 否 | 全部 | 难题分类编码（编码由久新提供，中文名由展示系统后台查字典注入） |
| `unit_types[]` | string[] | 否 | 全部 | 承担单位类型编码（高校/科研院所/智库机构/政府部门/企业）。原型：soft-science-new/mockData.js:95 `unitType` |
| `province_code` / `city_code` / `district_code` | string | 否 | — | 省/市/区三级区划筛选。原型：soft-science-new/mockData.js:95 `province`/`city`/`district`（REGION_TREE:64） |
| `keyword` | string | 否 | — | 课题名/承担单位关键词 |
| `page` / `size` | int | 否 | `1` / `20` | 久新按入参分页 |
| `sort_key` | enum | 否 | `year` | `year` 按立项年度 / `contribution` 按贡献度评分 / `difficulty` 按难题分类 |
| `sort_order` | enum | 否 | `desc` | `asc` 升序 / `desc` 降序 |

**出参表**（久新必须返回）

| 字段 | 类型 | 判定 | 中文名 · 说明 |
|---|---|---|---|
| `records[].project_id` | string | ①事实 | **【主键，跨 A1/M1/M2 复用】** |
| `records[].title` | string | ①事实 | 课题名称 |
| `records[].summary` | string\|null | ①事实 | 课题摘要。原型：soft-science-new/mockData.js:95（课题对象） |
| `records[].year` | string | ①事实 | 立项年度 |
| `records[].lead_unit` | string | ①事实 | 承担单位名称 |
| `records[].unit_type` | enum | ①事实 | 承担单位类型编码（高校/科研院所/智库机构/政府部门/企业）。原型：soft-science-new/mockData.js:95 `unitType` |
| `records[].lead_person` | string | ①事实 | 负责人姓名 |
| `records[].difficulty_type` | enum | ①事实 | 难题分类编码（久新自有；展示系统后台查字典翻中文名） |
| `records[].research_path` | string | ①事实 | 研究路径描述文本 |
| `records[].stage` | enum | ①事实 | 阶段编码（`planning` / `ongoing` / `completed` / `archived`） |
| `records[].stage_achievement` | string\|null | ①事实 | 阶段成果摘要 |
| `records[].contribution_score` | number | ①事实 | 承担单位贡献度评分（数值） |
| `records[].regions[].region_code` | string | ①事实 | 课题关联地域编码 |
| `records[].tags[]` | string[] | ①事实 | 成果标签编码数组（政策评估/指标体系/机制设计/…）。原型：soft-science-new/mockData.js:95 `tags`（ACHIEVE_TAGS:11） |
| `records[].progress` | number | ①事实 | 课题整体进度（%，数据源事实，**禁预估伪造**）。原型：BottomTabs.jsx:1059 |
| `records[].schedule_delay_days` | number\|null | ①事实 | 滞后预警天数；无滞后返 `null`。原型：BottomTabs.jsx:1101-1110 |
| `records[].metric_id` | string\|null | ①事实 | 指标编码 |
| `empty_reason` | enum\|null | ①事实 | 空态原因编码 |

> 三问题法判定：`records[].title` / `lead_unit` / `lead_person` / `difficulty_type` / `research_path` / `contribution_score` → 全是数据源事实，留；`records[].stage_label` / `difficulty_type_label` → 字典翻译砍；`total` / `page` / `size` → BFF 派生砍。

**展示系统后台组装逻辑**：`filter_echo.*` 回显；`total` / `page` / `size` 回显；`metric_ids[]` 聚合；`difficulty_type_label` / `stage_label` / `region_label` 查 `/topic/v1/meta/all-dicts`；`empty_message` 查 `data-gap-catalog`；`metric_id` → 8 件套查 `/metrics/v1/catalog`。

**边界**：筛选无命中 → `empty_reason=filter_empty`；久新返 `stage=completed` 必须真实完成——**禁伪造完成状态**（诚实性约束）。

### 2.2 TSX-A2 高端人才统计接口
- **展示系统后台对外**：`GET /v1/achievements/top-talents`
- **久新占位路径**：`GET /v1/third-party/ts/achievements/top-talents`
- **供方**：久新

> **用途**（规划 M11-BE ②）：全职院士/千人计划/孔雀团队/高层次人才 数量/结构/年度增量/学科细分/地域分布。**原型对应**：人才态势 页面 · 高端人才统计卡 / focusRegion 卡片 L464-482。

**入参表**

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `region_scope` | enum | 否 | `global` | 查询地域范围：`global` 全球 · `gba` 粤港澳大湾区 · `shenzhen` 深圳 |
| `year` | string | 否 | 当前年 | 统计年份 |
| `talent_categories[]` | string[] | 否 | 全部 | 人才类型编码（久新：`full_academician` 全职院士 / `thousand_talent` 千人计划 / `peacock_team` 孔雀团队 / `high_level` 高层次人才） |

**出参表**（久新必须返回）

| 字段 | 类型 | 判定 | 中文名 · 说明 |
|---|---|---|---|
| `year` | string | ①事实 | 统计年份 |
| `as_of` | string | ①事实 | 数据时间 |
| `inflow_rate` | number\|null | ①事实 | 近三年人才流入比例（0–1）；**缺失返 `null`**。原型：innovation-ecosystem-new/mockData.js:129 `inflow3y` |
| `gather_score` | number\|null | ①事实 | 人才空间聚集强度；**缺失返 `null`**。原型：InnovationEcosystemNewPage.jsx:822「人才空间聚集」 |
| `categories[]` | array | ①事实 | 各人才类型统计 |
| ↳ `talent_category` | enum | ①事实 | 人才类型编码 |
| ↳ `count` | int | ①事实 | 当前数量（**必须是实际整数，禁凑整**） |
| ↳ `growth` | number\|null | ①事实 | 年度增量百分比；无去年同期 → `null` |
| ↳ `regions[].region_code` | string | ①事实 | 地域编码 |
| ↳ `regions[].count` | int | ①事实 | 该地域该类型人才数 |
| ↳ `disciplines[].discipline_code` | string | ①事实 | 学科编码 |
| ↳ `disciplines[].count` | int | ①事实 | 该学科该类型人才数 |
| `by_position[]` | array | ①事实 | 岗位层次细分；子字段 `name`（string）+ `count`（int）。原型：InnovationEcosystemNewPage.jsx:791「岗位层次细分」 |
| `by_tech_field[]` | array | ①事实 | 技术领域对比（vs 全国基准）；子字段 `field`（string）+ `value`（number）+ `benchmark`（number）。原型：InnovationEcosystemNewPage.jsx:796「技术领域对比」 |
| `talent_carrier_match[]` | array | ①事实 | 人才-载体空间匹配（学科契合 50%+空间邻近 30%+协作历史 20%）；子字段 `talent`（string）+ `carrier`（string）+ `field`（string）+ `distance_km`（number）+ `score`（number）。原型：InnovationEcosystemNewPage.jsx:791-897 |
| ↳ `metric_id` | string\|null | ①事实 | 指标编码 |
| `empty_reason` | enum\|null | ①事实 | 空态原因编码 |

> 三问题法判定：所有 `count` / `growth` / `regions[].count` / `disciplines[].count` → ①事实，留；`talent_category_label` / `region_label` / `discipline_label` → 字典砍；**凑整数是 PIPL 风险**（324 不能显示成 400），久新 `count` 必须返实际整数。

**展示系统后台组装逻辑**：`filter_echo.*` 回显；`metric_ids[]` 聚合；`talent_category_label` / `region_label` / `discipline_label` 查字典；`growth` 的符号（+/-）展示系统后台本地派生；`metric_id` → 8 件套查 `/metrics/v1/catalog`。

**边界**：`count=0` 的人才类型仍返回（但 `growth=null` 无去年数据时）；**绝对禁凑整**（诚实性约束：`count=324` 必须显示 324，不得四舍五入到 400）。

### 2.3 TSX-A3 科技时空演进接口
- **展示系统后台对外**：`POST /v1/achievements/spatial-evolution`
- **久新占位路径**：`POST /v1/third-party/ts/achievements/spatial-evolution`

> **用途**（规划 M11-BE ③）：全球机构/论文/专利/人才 时空分布热力 + 时空流转路径 + 主题演化。**原型对应**：科技全域态势 大屏 · 时空演进 Tab / 人才态势 页面 · 全球人才地图 GlobalTalentPage。

**入参表**（请求体）

|---|---|---|---|---|

| `time_granularity` | enum | 否 | `year` | `year` 按年 · `quarter` 按季度（主题季度分布）。原型：space-time-evolution-new/mockData.js:417-426 |
| `bbox` | string | 否 | — | 视口裁剪 `lng1,lat1,lng2,lat2` |
| `field_scope` | string | 否 | — | 领域集群编码 |

| `hotspots[]` | array | ①事实 | 热点区域自动识别；子字段 `region_code`（string）+ `score`（number）+ `rank`（int）+ `warning_level`（enum：`high` / `mid` / `low`）。原型：space-time-evolution-new/mockData.js:346-362 |

> 三问题法判定：`entities[]`（id/name/type/year/lng/lat/heat）+ `flows[]`（from/to/type/count/year）+ `topics[]`（id/label/year/heat）→ 全是数据源事实，留；`entity_type_label` / `flow_type_label` / `region_label` → 字典砍；热力渐变色值 → Design.md 砍；`flows[].weight`（0-1 归一化）→ 展示系统后台按 `entity_count` / max(count) 本地归一化派生，久新不返 weight 返 entity_count 即可。

**展示系统后台组装逻辑**：`filter_echo.*` 回显；`metric_ids[]` 聚合；`entity_type_label` / `flow_type_label` / `region_label` / `topic_label` 查字典；`flows[].weight` 展示系统后台按 `entity_count` / 当前窗口 max(count) 派生（久新返 `entity_count`）；热力渐变色值 Design.md token；`metric_id` → 8 件套查 `/metrics/v1/catalog`。

**边界**：`bbox` 无命中 → `entities[]=[]` + `empty_reason=sample_empty`；坐标必须可落图（久新不得返空串/NaN）；**密度稀疏时**（某区域 heat < 阈值）展示系统后台置灰并提示"数据稀疏"——久新如实返 `heat` 低值，**禁凑假值**（诚实性约束）。

### 2.4 TSX-A4 科研主体协作网络接口（久新+燕大 共供）
- **展示系统后台对外**：`GET /v1/achievements/collaboration-graph`

## 三、图谱能力拆包（燕大侧，A4 科研主体协作网络）

> 本节**不规定久新契约**，而是声明：展示系统后台在调用 TSX-A4 协作网络接口时，**同时并发调用燕大图谱能力**，将两边返回组装成前端需要的完整协作图谱形状。燕大对外接口契约另行约定（与 06 §五 共用同一份燕大契约）。

| 燕大能力域 | 对展示系统后台暴露的能力 | 触发时机 |
|---|---|---|
| G-02 图谱算法 | 社区检测（Leiden / Louvain）、中心性（PageRank / Betweenness / Degree）、聚类分组、图谱相似度计算 | TSX-A4 返回实体数据后，展示系统后台并发调用；与 M2/M10 共用同一算法实例 |
| G-03 图谱指标 | 图谱密度、平均度、连通分量数、模块度、平均聚类系数 | 展示系统后台按需调用 |
| G-05 图谱分享与集成 | 图谱快照导出、图谱嵌入向量化、跨图谱映射 | 展示系统后台导出/分析时调用 |

**职责拆分原则**（与 06 §五 完全对齐）：

| 层 | 负责什么 | 不负责什么 |
|---|---|---|
| 久新（协作网络实体数据） | 节点/边的业务 ID、实体类型、业务名称、关系结构、年份、权重、坐标 | 社区检测标签、中心性数值、聚类分组、相似度、算法路径 |
| 燕大（图谱算法产物） | 社区标签、中心性数值、聚类分组、相似度、图谱嵌入 | 节点/边的业务名称、业务文本、业务 ID（久新说了算） |
| 展示系统后台 | 聚合两边 → 查字典 → 派生 timeline/色值 → 返回前端 | **不写 Nebula**、不写图谱算法 |

**跨模块 node_id / edge_id 复用规则**：

TSX-A4 返回的 `nodes[].node_id` / `edges[].edge_id` **必须跨 M2（科技知识图谱）/ M9（规划图谱）/ T5（人才合作网络）/ A4（科研主体协作）四模块复用同一标识**。展示系统后台一次聚合多模块图谱时按 node_id 去重——久新若返回了不同格式的 ID（如 `inst-123` vs `institution-123`）必须先做统一归一化。
