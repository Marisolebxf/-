# 科技信息展示系统 · 知识图谱接口需求清单

> 需求方：深圳国际科技信息中心 · 科技信息展示系统
> 供应方：燕山大学 · 亿级科技知识图谱引擎
> 版本：v1.0 · 日期：2026-10-26
> 用途：作为燕大封装图谱接口（ 查询+写入 ）的接口需求清单
> 状态：待燕大逐项确认

---

## 一、范围与口径

### 1.1 目的

本清单明确科技信息展示系统需要燕大知识图谱引擎提供的**实体类型、关系类型、属性、计算能力与写入能力**，作为燕大封装图谱接口的依据。

### 1.2 纳入模块（8 个）

| # | 模块 | 需规叶数 | seq 区间 |
|---|---|---:|---|
| 1 | 科技发展态势 | 196 | 1–196 |
| 2 | 科技成果展示 | 102 | 455–556 |
| 3 | 科技人才态势 | 87 | 243–329 |
| 4 | 科技数据资源 | 70 | 330–399 |
| 5 | 科技知识图谱 | 55 | 400–454 |
| 6 | 科技政策跟踪 | 46 | 197–242 |
| 7 | 科技服务全景 | 45 | 557–601 |
| 8 | 政策对比功能升级（核增需求） | 17 | 602–618 |
| | **合计** | **618** | 1–618 |

### 1.3 范围口径

1. **字段级**：实体、关系均落到字段，标注必选/可选；粒度到接口出参可组装。
2. **接口范围**：本清单覆盖燕大向展示系统供数的**读接口**（第二至第五章），以及实体/关系增删改、构建、版本管理等**写入类接口**（第六章）。
3. **图谱侧计算单列**：中心性、社群、路径、影响力、预测、聚类等作为接口能力清单（见第五章），不混编进实体属性。
4. **接口待确认**：本清单所列实体/关系/属性/计算能力均为展示系统需求，是否支持、接口形态由燕大评估确认。
5. **不臆造**：未明确枚举口径的字段，由燕大回复确认。

### 1.4 核心需求规模

| 项 | 数量 |
|---|---:|
| 实体类型 | **14 类** |
| 关系类型 | **17 类** |
| 属性 | **99 条**（公共 10 + 实体专有 68 + 关系属性 21） |
| 图谱计算能力 | **31 项** |
| 写入类接口 | **10 项**（实体/关系增删改 + 批量导入 + 版本管理 + 审计日志） |

## 三、关系类型清单（17 类）

> 方向性：`→` 有向、`↔` 无向/双向；基数：1:1 / 1:N / N:1 / N:N。
> 以上 17 类关系为展示系统所需，请燕大按「可供给 / 需扩展（给工期）/ 不可供给（给替代方案）」三态逐条回复。

| 关系ID | 关系名 | 起点 → 终点 | 方向 | 基数 | 关系属性 | 业务语义 | 待燕大提供 |
|---|---|---|---|---|---|---|---|
| `cooperate` | 合作 | `person↔person`；`institution↔institution`；`person↔institution` | 无向 | N:N | `cooperation_type`、`weight`、`start_time`、`end_time`、`evidence_refs`、`confidence` | 论文合作、项目合作、师承、技术交流 |  |
| `belong` | 隶属 | `person→institution`；`institution→institution`（上级） | 有向 | N:1 | `role`、`start_time`、`end_time` | 人员任职/隶属机构，机构上下级 |  |
| `research` | 研究 | `person→field`；`person→topic`；`institution→field`；`enterprise→field` | 有向 | N:N | `relevance`、`weight`、`is_primary` | 人员/机构/企业研究或从事的领域与主题 |  |
| `cite` | 引用 | `paper→paper`；`patent→paper`；`patent→patent` | 有向 | N:N | `weight`、`year`、`evidence_refs` | 文献/专利引用关系 |  |
| `participate` | 参与 | `person→project`；`institution→project` | 有向 | N:N | `role`、`weight`、`start_time`、`end_time` | 人员/机构参与科研项目 |  |
| `belong_to` | 属于 | `paper/patent/project/technology→field` | 有向 | N:1 | `weight`、`is_primary` | 成果/技术归属学科或技术领域 |  |
| `author_of` | 著作 | `person→paper/patent` | 有向 | N:N | `weight`、`evidence_refs` | 作者与论文/专利的著作关系 |  |
| `technology_hierarchy` | 技术层级 | `technology→technology` | 有向 | N:1 | `relation_subtype`（包含）、`level_gap` | 技术点上下位/包含层级 |  |
| `technology_influence` | 技术影响 | `technology→technology` | 有向 | N:N | `influence_type`（依赖/促进）、`weight`、`start_time`、`end_time` | 技术间依赖、促进、影响路径 |  |
| `publish` | 发布 | `institution→policy` | 有向 | 1:N | `publish_time`、`evidence_refs` | 政策发布主体 |  |
| `policy_relate` | 政策关联 | `policy↔policy` | 无向 | N:N | `relation_type`、`weight`、`evidence_refs` | 政策间引用、配套、替代、上下位等关联 |  |
| `policy_apply_to` | 政策适用 | `policy→field/enterprise/person/institution` | 有向 | N:N | `target_role`（适用领域/服务对象）、`weight` | 政策适用领域与服务对象 |  |
| `dataset_link` | 数据集关联 | `dataset↔dataset` | 无向 | N:N | `link_type`（引用/衔接/主题交叉）、`weight` | 数据集之间的引用、衔接、主题交叉 |  |
| `about_topic` | 主题相关 | `paper/patent/project/dataset→topic` | 有向 | N:N | `relevance`、`is_primary` | 成果/资源与主题、关键词的关联 |  |
| `event_link` | 事件关联 | `event↔event`；`event→institution/person` | 无向/有向 | N:N | `event_role`、`weight` | 事件与其他事件、机构、人员的关联 |  |
| `activity_link` | 活动关联 | `activity→person/institution/dataset` | 有向 | N:N | `link_type`（专家讲者/科技资源/主办）、`read_count`、`importance`、`relevance` | 活动与专家、机构、科技资源的关联及推荐属性 |  |
| `carrier_cooperate` | 载体协同 | `innovation_carrier↔innovation_carrier`；`innovation_carrier→person/institution` | 无向/有向 | N:N | `coop_project_count`、`cooperation_density`、`weight` | 载体间联合创新、资源共享、人才协同 |  |
