## 边界（谁供数）

| 维度 | 归属 | 说明 |
|---|---|---|
| **技术维度**（技术路线 / 技术领域 / 研究领域 / 技术链） | **久新** | 数据 + 评估/分析/计算全归久新 |
| **人才维度**（科技人才 / 专家学者） | **久新** | 数据 + 画像 / 评估 / 推荐 / 合作网络全归久新 |
| **科研机构维度**（高校 / 研究机构 / 创新载体） | **久新** | 数据 + 排名 / 关系 / 分析全归久新 |
| **科技知识图谱** | **久新 + 燕大** | 图谱实体数据 + 图谱算法/指标/服务能力 |
| 企业 / 产业链 / 政策 / 综合智能分析 | **智树** | 不在本清单（智树五维） |
| 数据资源 / 接入统计 | 数据资源平台 | 已在 04 清单 |
| 科技服务全景（交流/竞赛/传播） | 久新 / 电信 | 已在 04 清单 |

> 判定规则：凡属技术/人才/机构维度，**数据 + 分析/评估/推荐/图谱计算全归久新**；需规中「企业、产业、政策、资金」相关指标不向久新要接口（详见 §四排查结论）。

## 共性约定

| 项 | 要求 |
|---|---|
| 交付物 | OpenAPI / 字段字典、鉴权、≥20 条样例、刷新频率、错误码、空态 |
| 主键 | 人才 / 专家 / 机构 / 技术 / 成果稳定 ID，跨接口可关联（人才↔机构↔成果↔技术领域） |
| 时间 | 统一时区与 `updated_at`；列表支持时间窗 |
| 权限 | 最小权限、限流、调用审计；人才敏感信息（联系方式）单独授权 |
| 验收 | 可重复请求、字段校验、空值 / 异常、分页性能 |
