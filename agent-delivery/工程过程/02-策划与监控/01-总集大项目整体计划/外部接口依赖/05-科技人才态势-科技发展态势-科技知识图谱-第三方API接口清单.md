| 创新监测（全球/湾区/深圳创新监测） | **智树** | 创新能力指数 / 城市排名 / 创新载体，不向久新要接口 |
| 创新载体（孵化器/加速器/众创空间） | **智树** | 载体分布 / 增量 / 详情，不向久新要接口 |
| 企业 / 产业链 / 政策 / 综合智能分析 | **智树** | 不在本清单（智树五维） |
| 数据资源 / 接入统计 | 数据资源平台 | 已在 04 清单 |
| 科技服务全景（交流/竞赛/传播） | 久新 / 电信 | 已在 04 清单 |

> 判定规则：凡属技术/人才/科研机构维度，**数据 + 分析/评估/推荐/图谱计算全归久新**；凡属**图谱维护**（增删改）归**久新+燕大**；需规中「创新监测、创新载体、企业、产业、政策、资金」相关指标不向久新要接口（详见 §四排查结论）。

## 共性约定

| 项 | 要求 |
|---|---|
| 交付物 | OpenAPI / 字段字典、鉴权、≥20 条样例、刷新频率、错误码、空态 |
| 主键 | 人才 / 专家 / 机构 / 技术 / 成果稳定 ID，跨接口可关联（人才↔机构↔成果↔技术领域） |
| 时间 | 统一时区与 `updated_at`；列表支持时间窗 |
| 权限 | 最小权限、限流、调用审计；人才敏感信息（联系方式）单独授权；**图谱维护写接口需单独授权** |
| 验收 | 可重复请求、字段校验、空值 / 异常、分页性能 |
