## 一、对接总览

### 1.1 调用链

```
前端 (lumen-ui-science-pc)
  ↓ 只调 /display/**
网关 (gkxlumen-gateway)
  ↓ StripPrefix
展示系统后台 (gkxlumen-display，Java 薄 BFF)
  ├→ ADS 本地表 / 平台字典 /topic/v1/meta/** / 指标中心 /metrics/v1/catalog   ← 不调久新
  ├→ 久新 REST /v1/third-party/ts/{域}                                        ← 本文件规定契约
  └→ 燕大 REST /v1/third-party/graph/{域}                                     ← 图谱算法（§五）
  ↓ 组装成前端形状
前端
```

**久新/燕大不直接对前端暴露**，所有请求经展示系统后台中转。本文档只规定「展示系统后台 → 久新/燕大」这一跳的契约。

### 1.2 供数边界

| 维度 | 供方 | 说明 |
|---|---|---|
| 技术 / 人才 / 科研机构 维度的数据 + 分析/评估/推荐 | **久新** | 数据 + 计算全归久新 |

## 二、共性约定（所有接口必须遵守）

### 2.1 响应与字段

| 项 | 要求 |
|---|---|
| 响应包络 | 统一 `R<T>`：`{ "code": 0, "msg": "ok", "data": {...} }`；`code≠0` 时 `data` 空 |
| 字段命名 | 全部 `snake_case` |
| 时区 | 统一 +08:00 |
| 错误码 | 400 参数非法 · 401/403 未登录/无权限 · 404 对象不存在 · 409 冲突 · 410 结果过期需重算 · 500 服务异常 |

### 2.2 公共入参

| 参数 | 取值（编码 → 中文） | 说明 |
|---|---|---|
| `region_scope` | 态势/成果模块：`global` 全球 · `gba` 粤港澳大湾区 · `shenzhen` 深圳；人才模块：`global` 全球 · `china` 中国 · `shenzhen` 深圳 | 查询地域范围，默认 `global`。**两者不可混用** |
| `start_time` / `end_time` | ISO 8601 日期，精确到年月日（如 `2020-01-01`～`2026-10-15`，可传时分秒 `2026-05-08T10:00:00+08:00`） | **唯一时间筛选入参**，闭区间含边界，+08:00，`end_time` 缺省当前时间。**不再使用年份入参** |
| `year` | 四位年份字符串（如 `2026`） | 仅用于**单年度版本选择**（年度评估/指数/排行榜/规划），不是区间筛选 |
| `field_scope` | 产业集群编码 | 合法性由展示系统后台查字典确认 |
| `keyword` | 字符串 | 空串按"不过滤" |
| `page` / `size` | int | 列表分页，默认 `1` / `20` |
| `sort_order` | `asc` 升序 · `desc` 降序 | 默认 `desc` |

### 2.3 诚实性约束

- 缺数返 `null`，**不返 `0`**（不补假值）；
- 禁伪造进度百分比（只返事实状态 `done`/`in_progress`/`todo`）；
- 禁裁剪最新 N 条冒充"全部"；
- 禁凑整（`count=324` 必须返 324，不得四舍五入到 400）；
- 尽调风险 `risk_level` 必须如实，不得降级。

### 2.4 合规红线（人才特有）

- 联系方式（email/phone/address）**不得返回**，确需须单独授权；
- 人才流动**只返机构级聚合**（地区/机构净流入计数），**不得返回个人流动明细**。

### 2.5 空态

返 `empty_reason` 编码：`no_source` 无数据源 · `filter_empty` 筛选无命中 · `sample_empty` 样本为空。中文 `empty_message` 由展示系统后台注入。

#### TSX-M1-01 要素图层与统计

**对应模块**：M1 科技全域态势 · **对应页面**：科技全域态势地图页（图层统计面板）

**入参**

| 参数 | 中文名 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|---|
| `region_scope` | 地域范围 | enum | 否 | `global` | `global` 全球 · `gba` 粤港澳大湾区 · `shenzhen` 深圳 |
| `start_time` / `end_time` | 时间区间 | string(date) | 否 | 近 6 年 | ISO 8601 日期，精确到年月日，闭区间，+08:00 |
| `field_scope` | 学科领域 | string[] | 否 | 全部 | 学科领域（产业集群）编码**多选**（如 `合成生物`），空数组不过滤 |
| `factor_keys` | 科创要素 | string[] | 否 | 全部 | 科创要素 11 类编码**多选**：`scholar` 专家学者 · `meeting` 会议 · `institution` 组织机构 · `enterprise` 企业 · `service` 服务机构 · `topic` 课题 · `project` 项目 · `paper` 论文 · `journal` 期刊 · `patent` 专利 · `result` 成果；空数组不过滤 |

**出参**

| 字段 | 中文名 | 类型 | 说明 |
|---|---|---|---|
| `factors[]` | 要素列表 | array | 11 类要素统计数组 |
| `factors[].factor_key` | 要素编码 | string | 科创要素 11 类编码：`scholar` 专家学者 · `meeting` 会议 · `institution` 组织机构 · `enterprise` 企业 · `service` 服务机构 · `topic` 课题 · `project` 项目 · `paper` 论文 · `journal` 期刊 · `patent` 专利 · `result` 成果 |
