## 一、范围与边界（先划清「要什么 / 不要什么」）

### 1.1 本文件范围

只覆盖**科技人才态势**模块（对应骨架 `EXT-B3-TALENT`，需规 seq 243–329，14 骨架合并为 **8 条**久新侧接口契约（其中 1 条为 **久新+燕大** 共供）。每条接口在 §四中给出：**入参表**（展示系统后台传给久新的参数，不含"自己能算的"）+ **出参表**（久新必须返回的字段；展示系统后台自行派生的字段**不出现在出参表中**，见 §二 2.1 / §三）。

### 1.2 模块边界

| 维度 | 归谁 | 说明 |
|---|---|---|
| 人才数据 + 画像 + 评估 + 推荐 + 合作网络 | **久新** | 05 §边界明确：凡属**人才/专家**维度的「数据 + 分析/评估/推荐/图谱计算」归久新 |
| 个人敏感信息（联系方式：邮箱/电话/住址） | **合规红线** | 久新**不得返回**；若确需获取，须经§二 2.2 单独授权 |
| 人才流动数据合规边界 | **久新只返机构级聚合** | U6 未定稿项：不得返回个人流动明细，只返地区/机构净流入计数 |
| 图谱算法产物（社区/中心性/聚类） | **燕大** | T-09 合作网络图谱的算法产物由燕大 G-02 提供，见 §五 |
| 图谱实体数据（节点/边/业务 ID） | **久新** | T-09 合作网络图谱的实体数据由久新提供 |
| 枚举字典（编码→中文名/色值） | **平台字典** | `/topic/v1/meta/all-dicts` 一次性返回，久新只返编码值 |
| 指标血缘 / 8 件套 / 四维就绪度 | **指标注册中心** | `/metrics/v1/catalog`，久新只返 `metric_id` 编码值 |
| 报告产品格式（PDF/Word 模板、图标、title） | **展示系统后台产品常量** | 久新只返报告结构化正文，产品格式由展示系统后台组装 |

### 1.3 久新接口路径约定

久新对外暴露 REST 供展示系统后台调用，**不与 lumen 内部服务共用路径前缀**。本文档入参表中用占位路径（如 `GET /v1/third-party/ts/talent/regions-flow`）标识能力域，**久新可自定具体路径**，但须满足 §二 的共性约定（包络 / 错误码 / 鉴权）。

## 二、共性约定（久新对外接口全部遵守）

| 项 | 要求 |
|---|---|
| 交付物 | OpenAPI / 字段字典、鉴权方式说明、≥20 条真实样例、刷新频率、错误码、空态处理；**字段名 `snake_case`** |
| 响应包络 | 统一 `R<T>`：`{ "code": 0, "msg": "ok", "data": {...} }`；`code≠0` 时 `data` 空，展示系统后台走空态，**不伪造数据** |
| 错误码 | 400 参数非法（枚举越界 / 数组传单值字段）· 401/403 未登录/无权限 · 404 对象不存在 · 409 冲突（乐观锁 / 重名）· 410 结果已过期需重算 · 500 服务异常 |
| 公共筛选入参 | `region_scope`（`global` 全球 / `china` 中国 / `shenzhen` 深圳）· **`start_time`/`end_time` 查询时间区间（ISO 8601 日期，精确到年月日，闭区间，时区 +08:00）——本文件统一，不使用年份入参** · `field_scope`（产业集群编码，**展示系统后台已查字典确认合法**）· `field_tag`（领域标签编码）· `talent_type`（`leading` 领军 / `young` 青年 / `engineer` 工程技术 / `management` 管理型）· `keyword` |
| 主键与跨接口关联 | **`person_id` 稳定主键，跨模块复用**（M10 人才 ↔ M2 图谱 ↔ M9 规划 ↔ M8 指数排行榜）；**图谱 `node_id` / `edge_id` 跨 M2/M10 复用同一标识** |
| 人才特有枚举 | 动态类型 `activity_type`：`paper`（学术发布）/ `job`（职位变动）/ `project`（项目动态）/ `award`（获奖荣誉）/ `event`（会议活动）；人才类型 `talent_type`：`leading`（领军人才）/ `young`（青年学者）/ `engineer`（工程技术）/ `management`（管理型人才） |
| h_index 说明 | **久新本地计算**（非外部数据源直取），计算口径在交付物中说明（如：Google Scholar 口径 / Web of Science 口径）；`h_index=null` 表示该人才暂无论文或无被引数据（**不返 0**） |
| 时间 | 统一时区（+08:00）；列表支持时间窗 |
| 指标血缘编码 | 每个统计数字挂 `metric_id`（编码值即可，**8 件套 + 四维就绪度由展示系统后台查 `/metrics/v1/catalog` 注入**） |
| 空态原因编码 | 返 `empty_reason` 编码即可（`no_source` / `filter_empty` / `sample_empty`）；**中文 `empty_message` 由展示系统后台查 catalog 注入** |
| 诚实性约束 | 禁伪造进度百分比（只返事实状态 `done/in_progress/todo`）；缺数返 `null` 不返 `0`；**禁补假**；T8 尽调风险 `risk_level` 必须如实，不得降级为 `low`；T2 动态 list 按时间真实序排，禁裁剪最新 N 条冒充"全部" |
| 权限 | 最小权限、限流、调用审计；**人才联系方式字段（email/phone/address）不开放**，若业务确需获取须单独授权；**图谱维护写接口需单独授权** |
| 验收 | 可重复请求、字段校验、刷新频率与证据链接 |

### 2.1 久新**不需要返回**的字段（完整清单见 §三）

下列字段属于展示系统后台 / 前端 / 平台字典自有，**久新不得在返回体中出现**；若久新自行加上，展示系统后台也会忽略：

| 类别 | 字段 | 谁来处理 |
|---|---|---|
| BFF 派生 | `filter_echo` 全部子字段 | 展示系统后台从请求参数直接回显 |
| BFF 派生 | 分页 `total` / `page` / `size` | 展示系统后台执行分页（久新只返当前页 + 当前页 `count` 即可） |
| BFF 派生 | `metric_ids[]` 聚合 | 展示系统后台遍历 records 收集去重 |
| BFF 派生 | 三方案成本**系数本身**（薪酬权重、科研权重、住房权重、团队权重、津贴权重） | 久新**只返实际计算结果**，方案系数是产品常量由展示系统后台乘上去 |
| BFF 派生 | 成本单位 / 币种 / 风险横幅文案 | 产品常量（单位：万元；币种：CNY；风险横幅文案如"稳健型方案，适合重点引才对象"） |
| BFF 派生 | 报告 PDF/Word 格式/模板/图标 | 展示系统后台产品常量 |
| BFF 派生 | 热力图例渐变色值 / 图例档位标签 | Design.md token / 固定 3 档，前端注入 |
| BFF 派生 | `empty_message` 中文文案 | 展示系统后台查 `data-gap-catalog.yaml` 注入 |
| 平台字典 | 所有枚举的**中文名 / 色值 / 默认值**（含 `activity_type_label` / `talent_type_label` / `field_label` / `region_label` / `education_label` / `title_label` / `result_type_label` / `difficulty_dimension_label` / `risk_level_label` / `scheme_label` / `risk_key_label` / `recommendation_label`） | `/topic/v1/meta/all-dicts` 一次返回；久新只返**编码值** |
| 平台字典 | 领域 6 类配色（ai/bio/material/comm/mfg）· 地区 5 大区配色 · 行业 5 类配色 · 人才类型 4 类配色 | 前端 Design token / 展示系统后台查平台字典 |
| 产品定义 | 权重方法描述 / 报告 title / 筛选默认值 / 导出 role policy | 产品定义常量，展示系统后台或前端本地 |

### 2.2 合规红线（人才特有）

| 字段 | 结论 | 依据 |
|---|---|---|
| `email` / `phone` / `address` | **久新不得返回** | 个人敏感信息合规红线；若业务确需获取，须**单独申请授权**（走隐私合规流程），不在本接口契约内 |
| 个人身份证号 / 护照号 | **久新不得返回** | 同上，合规红线 |
| `person_id` | **久新必须返回** | 业务主键，不含个人身份信息，仅用于跨接口关联 |
| `name` / `nationality` / `birth_year` | **久新必须返回** | 数据源事实，业务核心字段（骨架 T-03 明确要求） |
| 人才流动明细（具体某人从 A 机构到 B 机构） | **久新不得返回** | U6 未定稿项；只返**机构级聚合**（地区/机构净流入计数） |

### 3.2 展示系统后台可以自行派生的字段（**不需要久新返回**）

| 字段 | 派生逻辑 | 适用接口 |
|---|---|---|
| `filter_echo.*` 全量 | 从当前请求参数直接拷贝 | 所有 8 条 |
| 分页 `total` | 展示系统后台 MySQL COUNT（久新返当前页即可） | 列表接口 |

> 三问题法判定：`report_sections[].section_title`（章节中文名）→ ②砍（字典翻译，固定 5 章顺序由展示系统后台组装）；`recommendation_level_label` / `risk_level_label` / `risk_key_label` → ②砍（字典翻译）；报告 title / PDF/Word 格式 / 模板图标 → ②砍（产品常量）；报告 `generated_at` 展示系统后台不再覆盖（久新直接返回生成时间即可）。
>
> **诚实性约束（特别）**：T8 尽调风险 `risk_level` 必须**如实**，不得降级。久新算法/人工评估判定为 `high` 就必须返 `high`，展示系统后台不做降级处理。

**展示系统后台组装逻辑**：`filter_echo.*` 回显；`metric_ids[]` 聚合；`section_title` / `recommendation_level_label` / `risk_level_label` / `risk_key_label` 查 `/topic/v1/meta/all-dicts`；报告 PDF/Word 格式 / 模板图标 / 报告 title（如 "2026 年 [姓名] 人才尽调报告"）查产品常量；`recommendation_level` 文案按产品常量映射；`similar_experts[].person_id` → 合作人才中文名直接用久新返回的 `person_name`；`empty_message` 查 catalog。

**边界**：人才不存在 → 404；`risk_assessment[]` 必须返回 4 个维度（若某维度无数据，`risk_level=null` 而非省略该维度）；`similar_experts[]` 允许空（无相似专家推荐时）；`contribution_score=null` 时不展示学科贡献度卡。
