## 一、范围与边界（先划清「要什么 / 不要什么」）

### 1.1 本文件范围

只覆盖**科技发展态势**模块 6 个子域（对应 API-TS-M1/M2/M3/M7/M8/M9），共 **41 条**久新侧接口契约（其中 8 条为 **久新+燕大** 共供）。每条接口在 §四中给出：**入参表**（展示系统后台传给久新的参数，不含"自己能算的"）+ **出参表**（久新必须返回的字段；展示系统后台自行派生的字段**不出现在出参表中**，见 §二 2.1 / §三）。

### 1.2 不列入本文件的项（**不得**据此向久新要接口）

| 项 | 结论 | 依据 |
|---|---|---|
| M4 全球创新监测 / M5 湾区创新监测 / M6 深圳创新监测 | **智树自建**，不向久新要接口 | 05 §边界「创新监测归智树」；05 §4.2 排查结论（seq 56～135） |
| 创新载体（孵化器/加速器/众创空间，含 M9 重点领域 3 集群 22 载体） | **智树自建**，仅「高端人才」部分归久新 | 05 §边界 + §4.2（seq 538～556、485～488/493～496） |
| 政策 / 资金 / 产业链 / 企业维度 | **智树**（不在本清单） | 05 §边界 |
| M1 收藏与标签（`/v1/situation/favorites`、`/tags`） | **智树自建**（app_user 家族带写面） | API-TS-M1 §3.7；05 无对应条目 |
| M1 导出任务中心（`/v1/situation/export/**`） | **智树自建**（审计/签名下载均为平台侧） | API-TS-M1 §3.8；05 无对应条目 |
| M3 参数配置导入（`/tracking/evaluation/imports`） | **智树自建**（服务端校验闸） | API-TS-M3 §3.6（校验规则为平台硬闸） |
| M9 资源推送订阅设置（`/planning/resource-push/subscriptions`） | **智树自建**（app_user 家族带写面） | API-TS-M9 §3.6 |
| 数据资源 / 接入统计 | **数据资源平台**，已在 04 清单 | 05 §边界 |
| 科技服务全景（交流/竞赛/传播） | **久新 / 电信**，已在 04 清单 | 05 §边界 |

> 判定规则沿用 05 §边界：凡属**技术 / 人才 / 科研机构**维度的「数据 + 分析/评估/推荐/图谱计算」归 **久新**；**图谱维护**（增删改）与**图谱实体数据**归 **久新+燕大**；**图谱能力**（算法/指标/查询/分享/集成，G-02～G-05）归 **燕大**。

### 1.3 久新接口路径约定

久新对外暴露 REST 供展示系统后台调用，**不与 lumen 内部服务共用路径前缀**。本文档入参表中用占位路径（如 `GET /v1/third-party/ts/situation/layers`）标识能力域，**久新可自定具体路径**，但须满足 §二 的共性约定（包络 / 错误码 / 鉴权）。

## 二、共性约定（久新对外接口全部遵守）

| 项 | 要求 |
|---|---|
| 交付物 | OpenAPI / 字段字典、鉴权方式说明、≥20 条真实样例、刷新频率、错误码、空态处理；**字段名 `snake_case`** |
| 响应包络 | 统一 `R<T>`：`{ "code": 0, "msg": "ok", "data": {...} }`；`code≠0` 时 `data` 空，展示系统后台走空态，**不伪造数据** |
| 错误码 | 400 参数非法（枚举越界 / 数组传单值字段）· 401/403 未登录/无权限 · 404 对象不存在 · 409 冲突（乐观锁 / 重名）· 410 结果已过期需重算 · 500 服务异常 |
| 公共筛选入参 | `region_scope` 查询地域范围（`global` 全球 / `gba` 粤港澳大湾区 / `shenzhen` 深圳）· **`start_time`/`end_time` 查询时间区间（ISO 8601 日期，精确到年月日，闭区间，时区 +08:00）——全文件统一，不再使用年份入参** · `field_scope` 产业集群编码（**展示系统后台已查字典确认合法**）· `field_tag` 领域标签编码 · `factor_keys[]` 科创要素 11 类编码 · `keyword` 关键词（空串按"不过滤"）。**全部枚举值的中文义见 §2.1** |
| 主键与跨接口关联 | 人才 / 专家 / 机构 / 技术 / 成果 / 事件稳定 ID；**图谱 `node_id` / `edge_id` 跨 M2/M9 复用同一标识** |
| 时间 | 统一时区（+08:00）；列表支持时间窗 |
| 指标血缘编码 | 每个统计数字挂 `metric_id`（编码值即可，**8 件套 + 四维就绪度由展示系统后台查 `/metrics/v1/catalog` 注入**） |
| 空态原因编码 | 返 `empty_reason` 编码即可（`no_source` / `filter_empty` / `sample_empty`）；**中文 `empty_message` 由展示系统后台查 catalog 注入** |
| 诚实性约束 | 禁伪造进度百分比（只返事实状态 `done/in_progress/todo`）；缺数返 `null` 不返 `0`；**禁补假** |
| 权限 | 最小权限、限流、调用审计；人才敏感信息单独授权；**图谱维护写接口需单独授权** |
| 验收 | 可重复请求、字段校验、刷新频率与证据链接 |

### 2.1 公共入参与枚举中文对照（久新必读）

> **凡入参/出参出现枚举编码，其含义一律以本表为准**；接口小节内只写编码，不再重复中文名。中文名由展示系统后台查 `/topic/v1/meta/all-dicts` 注入前端。

| 枚举参数 | 取值（编码 → 中文） | 说明 |
|---|---|---|
| `region_scope` | `global` 全球 · `gba` 粤港澳大湾区 · `shenzhen` 深圳 | 查询地域范围，默认 `global`。**本文件（M1~M9）只用到这 3 级**（对应"全球/湾区/深圳"三级地域树）；人才模块（06b）另有 `china` 中国，因其页面含"中国科技人才分布"层级 |
| `start_time` / `end_time` | ISO 8601 日期，**精确到年月日**（`2020-01-01` / `2026-10-15`；需要时分秒时可传 `2026-05-08T10:00:00+08:00`） | **全文件唯一的时间筛选入参**：查询时间区间，**闭区间含边界**，时区 +08:00；`end_time` 缺省为当前时间。不再提供 `start_year`/`end_year` 年份入参。按年/季聚合的时序接口（如 M1-06 / M3-03 / M8-03）也只收时间区间，由久新按接口自身统计口径（年/季）把与区间相交的聚合点返回，**不按日返回**；日/周/月等展示分桶由前端本地完成，不作为入参（见 TSX-M1-05） |
| `field_scope` | 产业集群编码（如 `CL-FUT-05`） | 领域/集群过滤；合法性由展示系统后台查字典确认 |
| `field_tag` | 领域标签编码 | 比 `field_scope` 更细粒度的自由标签过滤 |
| `factor_keys[]` | `scholar` 专家学者 · `meeting` 会议 · `institution` 组织机构 · `enterprise` 企业 · `service` 服务机构 · `topic` 课题 · `project` 项目 · `paper` 论文 · `journal` 期刊 · `patent` 专利 · `result` 成果 | 科创要素 11 类过滤（真源 API-TS-M1 §2.1） |

| `hot_trend` | `hot` 热门 · `stable` 平稳 · `cold` 冷门 | 技术热度趋势 |
| `sort_key` | 按接口取值：`count` 数量 / `importance` 重要性 / `time` 时间 / `type` 类型 / `level` 等级 / `heat` 热度 / `growth` 增长率 | 排序字段（各接口取值见其入参表"默认"列）；`type`/`level` 仅 M1-03 要素检索列表使用 |

### 2.2 久新**不需要返回**的字段（完整清单见 §三）

下列字段属于展示系统后台 / 前端 / 平台字典自有，**久新不得在返回体中出现**；若久新自行加上，展示系统后台也会忽略：

| 类别 | 字段 | 谁来处理 |

| BFF 派生 | `metric_ids[]` 聚合 | 展示系统后台遍历 records 收集去重 |
| BFF 派生 | `composite_breakdown` 四子项 40/30/20/10 | 展示系统后台按权重反推 |
| BFF 派生 | `timeline[]` 年度演化 | 展示系统后台按 nodes/edges.year 聚合 |
| BFF 派生 | 热力图例渐变色值 / 图例档位标签 | Design.md token / 固定 3 档，前端注入 |
| BFF 派生 | 六源结构补全（稀疏→6 键齐全） | 久新只返有值的源，展示系统后台补全 |
| BFF 派生 | `empty_message` 中文文案 | 展示系统后台查 `data-gap-catalog.yaml` 注入 |
| 平台字典 | 所有枚举的**中文名 / 色值 / 默认值** | `/topic/v1/meta/all-dicts` 一次返回；久新只返**编码值** |
| 平台字典 | 要素 10 类配色 / 区清单 / 地域树 | 前端 Design token / 展示系统后台查平台字典 |
| 产品定义 | 权重方法描述 / 报告 title / 筛选默认值 / 导出 role policy | 产品定义常量，展示系统后台或前端本地 |

**展示系统后台组装逻辑**：`filter_echo.*` 回显；`change`（较上一期变化）= 展示系统后台按 `history_records[].final_score` 相邻期差值派生（久新不返回）；KPI「综合热度指数较上一周期 delta」= 展示系统后台取最近两期 `final_score` 派生；并排对比基准期选项（上一期/首期/本次）、阶段对比维度切换、方法对比切换 = 前端本地交互；`stage_label` / `trend_key_label` / `method_key_label` / `dimension_key_label` 查 `/topic/v1/meta/all-dicts`；「当天已成功直接打开结果」（附录 E）= 展示系统后台按本接口当日记录判定；`metric_id` → 8 件套查 `/metrics/v1/catalog`。

**边界**：无历史记录 → `history_records=[]` + `comparison_matrix` 省略 + `empty_reason=no_source`（对应原型历史空态，不构造演示数据）；`cells` 允许稀疏；维度分值缺数返 `null` 不造 0。

> **2026-10-18 重构判定**：原「技术评估工作流接口」（`GET /tracking/workflow/{tech_id}`）以 `tech_id` 为主键与原型不符——原型评估工作流是**任务级**（setup 按筛选范围+方法+权重发起，无单技术选择交互），且缺「开始评估」启动动作。重构拆分：启动 → **M3-02**（POST start，含冻结范围回执）、运行态 → **M3-03**（5 阶段步骤状态，`step_key` 枚举沿用原 `prep`/`collect`/`method`/`compute`/`result`）、历史 → 本接口；`evaluation_methods[]` 方法清单移至 **M3-01**；`parameter_configs[]` 参数快照由 **M3-02 `frozen_scope`** 回执取代（启动时冻结，久新不再单独返回快照）。
