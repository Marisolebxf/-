## 二、公共约定（燕大对外接口全部遵守）

| 项 | 要求 |
|---|---|
| 交付物 | OpenAPI / 字段字典、鉴权方式说明、≥20 条真实样例、刷新频率、错误码、空态处理；**字段名 `snake_case`** |
| 响应包络 | 统一 `R<T>`：`{ "code": 0, "msg": "ok", "data": {...} }`；`code≠0` 时 `data` 空，展示系统后台走空态，**不伪造数据** |
| 错误码 | 400 参数非法（枚举越界 / 数组传单值字段）· 401/403 未登录/无权限 · 404 对象不存在（`entity_id`/`share_id` 不存在）· 409 冲突 · 410 结果已过期需重算 · 500 服务异常 |
| 主键与跨接口关联 | **`entity_id` / `relation_id` / `share_id` / `rule_id` 为稳定主键，跨 KG-01～KG-09 可关联**；与久新图谱实体 `node_id`/`edge_id` 的映射关系由展示系统后台对齐（久新为实体真源，见统一文档 §四主键表） |

| 空态 | 缺数返 `null` 不返 `0`；整组无数据返 `empty_reason` 编码（`no_source` 无数据源 / `filter_empty` 筛选无命中 / `sample_empty` 样本为空）；**中文 `empty_message` 由展示系统后台查 catalog 注入** |

### 4.1 KG-01 图谱动态查询与切片（供方 燕大）

- **展示系统后台对外**：`POST /v1/graph/dynamic-query`

- **供方**：燕大

> **用途**（骨架 G-01 检索段 + G-02 交互可视化段，覆盖 **seq 400～403**）：按关键词 / 实体属性 / 多维过滤动态查询图谱实体与关系，并按切片视角（总览 / 机构 / 领域 / 时间线 / 合作）返回切片结果集，驱动网络图 / 列表 / 统计图三视图。**原型对应**：`AnalysisDisplay.jsx:487-627`（关键词场景下拉 + 实体属性三维筛选 + 时间范围 + 关系类型 / 作者进阶过滤 + 三视图切换）。

> 三问题法判定：类型 / 格式 / 权限中文名与图标 → ②砍（字典 / 产品常量）；「已撤回」标签色 → ②砍（Design token）；分享统计卡（有效 N / 已撤回 N）→ ②砍（前端实时计数）。

**边界**：**分享台账 / 操作历史 / 通知中心归智树用户态**（G-06 混合拆分拍板 2026-10-19，§一 1.2⑤），本接口**仅**负责图内容快照、链接生成、权限校验、多格式导出——燕大不建分享操作流水台账；**导出渲染（PNG/PDF/HTML/Excel）为燕大快照渲染能力**（按 `snapshot` 服务端渲染，渲染失败 → 500 + `msg` 说明）；`access=private` 的分享不参与公开链接访问校验（直接 `allow=false` + `reason`）；撤回后 `share_url` 访问一律 `allow=false`。
