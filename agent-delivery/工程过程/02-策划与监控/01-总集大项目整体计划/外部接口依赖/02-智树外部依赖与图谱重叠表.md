## 图谱能力面验收口径

| 能力面 | 覆盖需规 | 最小验收证据 |
|---|---|---|
| 查询 | 动态查询、过滤、关键词、详情 | OpenAPI、过滤字典、样例请求响应 |
| 分析 | 多维切片、模式识别、预测、推荐 | 可复现样例、算法版本、输入输出说明 |
| 指标 | 中心性、社群、融合指标、评分 | 指标定义、口径、时间窗、结果样例 |
| 可视化 | 子图、路径、社群、时序、交互 | 图数据结构、节点边样例、前端渲染验收 |
| 服务 | 分享、导出、嵌入、权限、审计 | 权限矩阵、审计样例；能否嵌入需安全确认 |
| 管理 | 节点/边维护、版本、发布 | 默认验收跳转或发布 API，不建设第二套管理 UI |

## 待确认冲突

1. 需规表要求大量图谱“维护”交互，与智树范围“不嵌后台”冲突；默认采用跳转或能力 API。
2. 0702 多条被依赖方写“智树”，需要区分内部供数与对总集的外部承诺。
3. 图谱预测、推荐、自动建模等描述偏能力愿景，需燕大给出现有能力清单后再承诺。
4. 政策对比核增项不自动进入本期；由 PM / 总集明确范围和变更来源。
