## 边界

- **科技数据资源**：智树做界面 + 对接他队 API；后台供数由数据资源平台 / 数据中台等提供（调用统计亦见智谱 `EXT-B3-RESOURCE`）。
- **科技服务全景**：除「科技创新生态服务」外，智树侧以跳转 / 对接展示为主；下列接口为第三方业务系统须对外提供的数据能力。
- **需规序号**：展示系统 SRS `seq`（与算法库 05 序号不是同一编号体系）。「主」= 需规点名的接口叶；「支撑」= 同子模块归档 / 专题叶，供数应覆盖其字段。
- 建议供方以总集 0702 为准，**最终责任方待总集签认**；本表不替厂商承诺日期。

## 共性约定

| 项 | 要求 |
|---|---|
| 交付物 | OpenAPI / 字段字典、鉴权、≥20 条样例、刷新频率、错误码、空态 |
| 主键 | 资源 / 活动 / 竞赛 / 内容 / 专家稳定 ID，跨接口可关联 |
| 时间 | 统一时区与 `updated_at`；列表支持时间窗 |
| 权限 | 最小权限、限流、调用审计；媒体 / 导出单独授权 |
| 验收 | 可重复请求、字段校验、空值 / 异常、分页性能 |

## 一、科技数据资源（DS-17～20）

接口包：`EXT-B3-RESOURCE` · 建议供方：数据资源平台 / 数据中台 / 智谱（调用统计）

### 1.1 总体视窗

| 清单序号 | 接口名称 | 需规序号 | 接口简介 | 业务场景 | 具体需求描述 |
|---:|---|---|---|---|---|
| R-01 | 资源接入总览统计接口 | **主 330**；支撑 333、334 | 返回已接入资源类型、数量、分布与增长 | 运营驾驶舱一键看全局接入态势 | 提供资源类型 / 数量、分布比例、年度增长趋势、来源机构接入活跃度；支持按时间窗汇总；支撑多维统计报表与多源整合归类统计 |
| R-02 | 资源来源分析接口 | **主 331** | 按来源类型归纳结构与变化 | 判断数据质量与来源可靠性 | 返回国内外数据库、科研院所、企业、开源平台等来源结构、占比及变化；含来源可靠性相关字段 |
| R-03 | 接入资源详情查询接口 | **主 332** | 单条 / 批量资源元数据查询 | 定位、筛选所需数据资源 | 返回元数据、学科领域、采集时间、更新频率、关联项目；支持 ID / 关键词 / 批量查询与分页 |
| R-04 | 主题库与资源中心目录接口 | **主 335** | 主题库分类与资源中心概览 | 大数据资源中心分类浏览 | 按主题结构返回科技要素库、领域主题库等分类树 / 列表；支持领域、技术类型等标签 |
| R-05 | 资源详情深度浏览接口 | **主 336** | 中心内单资源深度信息 | 资源详情页 / 抽屉 | 提供资源完整属性、更新流、近期待办增长、热点等运营可读字段 |
| R-06 | 资源关联关系查询接口 | **主 339～342**；支撑 337、338 | 资源间关联与主题聚合读面 | 关联检索、关系导航（非全要素图谱验收） | 返回资源节点 / 边或目录交叉引用、语义主题聚合；支撑关联检索与实时更新台账；可空挂接；不另造资源 Ontology、不验收全要素图谱 |
| R-07 | 应用系统与接口状态监控接口 | **主 343、344** | 可用性、响应、告警与接口健康 | 保障供给稳定与接口质量 | 按资源 / 应用系统返回服务可用性、接口响应、异常告警；API 活跃度、调用频率、失败率（日志级） |
| R-08 | 应用主体与调用趋势接口 | **主 345、346** | 调用主体清单与累计 / 趋势 | 评估资源使用价值 | 返回机构 / 项目 / 用户类型等应用主体列表；累计调用次数、分时调用频率与趋势 |
