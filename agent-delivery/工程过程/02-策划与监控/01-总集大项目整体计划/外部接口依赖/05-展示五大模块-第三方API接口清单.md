## 供数口径

- **第三方供数维度**：论文 / 专利 / 项目 / 会议 / 期刊 / 人才 / 科研机构 / 技术 / 亿级知识图谱
- **我方自研维度**：企业 / 产业链 / 政策 / 服务机构（不入本清单）
- **需规序号**：展示 SRS `seq`。「主」= 该接口主要覆盖的叶号段；「支撑」= 同场景相邻叶供数字段。
- 建议供方以总集 0702 为准，**最终责任方待总集签认**。
- 共性约定（OpenAPI/样例/鉴权/主键/`updated_at`/限流）同 04 清单。
