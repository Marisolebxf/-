## 二、智树在本维度做什么、不做什么

**做**：

- 按 [scope-baseline.md](../../../scope-baseline.md) 实现本项范围内的功能与对接
- 需求梳理、字段契约、样例对齐、联调与验收

**不做**：

- 不实现对方系统后台
- 不把未接入写成已接入；对方未承诺的数据在页面上用空态
- 不在本夹修改 scope-baseline 的范围
- **菜单在方案里分节，不各开一夹**（规约 §2）
- 基础数据管理里**技术链、科研机构、人才不在本块，归第 2 项**
- 同 epic `CMS-JX-INT` 的专家知识、全要素图谱、门户回写**不计入本块**
- 现网另有新兴科技、科研力量、领军人才、产研报告、平台介绍等内容项，未标（智树），**不写入本项**，除非方案签收时点名纳入
- 第 3 项开发完成后要到总集统一权限配置后台配置菜单和用户权限，**写进该叶的完成条件**，不单独再开一类工作
- 可视化管理四菜单**注册表里还没有接口任务**；接口叶在方案签收后另拆，**不复用**基础数据写侧任务
- [`CMS-JX接口规格书.md`](../../../工程过程/02-策划与监控/01-总集大项目整体计划/07-内容运营中心接口需求评估/CMS-JX接口规格书.md) 把可视化管理标成不在本期。2026-10-22 定稿后，这句不再作为分工依据：可视化四菜单前后端都由智树做

### 三块分工（规约 §2 第 3 项）

|---|---|---|
| 1. 基础数据管理 | 产品链、企业、政策、产业服务机构，通过接口对接 | 智树（epic `CMS-JX-INT`） |

| 3. 可视化管理四菜单 | 产业全景 / 专题服务 / 企业发展 / 政策扶持可视化，**前后端由智树全部自己实现**，做完后把菜单配置到统一用户中心 | 智树 |
