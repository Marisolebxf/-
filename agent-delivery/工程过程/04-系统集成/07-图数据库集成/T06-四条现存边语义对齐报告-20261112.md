## 3. support：端点全量重复，但权重不同

同样抽取 20 条，并对两条边各自全部 **10,957 行**分页导出。比较键为有方向的 `(起点VID, 终点VID)`；附加按 `(起点VID, 终点VID, rank)` 核验属性。

| 核验 | 实测 |

| 去重端点对 | 各 10,957 |
| 同端点交集 | 10,957 |
| 交集 / apply_to；交集 / support；Jaccard | 均 100% |
| apply_to 独有 / support 独有 | 0 / 0 |

重合率超过 DoD 的 90% 阈值，明确建议：**停读一条，优先保留 apply_to，support 保留存量但不双读。** 不将两条边分别映射成两项必须关系。权重差异须随报告提交：单读 apply_to 时保留原值 0.6，不把两条权重相加为 1.4，不自动取最大值或回写；0.6 / 0.8 的业务含义及是否采用权重由裁定人确认。不存在因端点独有子集而必须保留双读的理由。
