## 二、智树在本维度做什么、不做什么

**做**：

- 按 [scope-baseline.md](../../../scope-baseline.md) 实现本项范围内的功能与对接
- 需求梳理、字段契约、样例对齐、联调与验收

**不做**：

- 不实现对方系统后台
- 不把未接入写成已接入；对方未承诺的数据在页面上用空态
- 不在本夹修改 scope-baseline 的范围
- **不嵌图库管理界面**，**不在本仓写图算法**
- 与第 5 项交叉的读图部分归本项；第 5 项保留该菜单的其余对接对象
- 图谱**写入与构建**侧（15 叶）归 06 M2 施工阶段，不在本项展开字段
- 维护能力优先 API 或跳转；嵌入、分享、导出需过权限与安全评审
