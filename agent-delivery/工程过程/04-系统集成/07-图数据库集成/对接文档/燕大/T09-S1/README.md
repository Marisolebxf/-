## 方向口径：入射 = 入边 + 出边

任务卡部分位置写“有向入边”，但明确要求复用 T09 无向投影算法并复现 2,914 / 1,478.05。唐绍祖《T02/T09 技术验收记录》§7.2 和《答复李周：T07认领恢复与T09补数》§二均支持**入射边**口径。因此本次采用：

- 无权度：原 T09 `dict(graph.degree())`，无向简单图的邻接边数，全图计算。
- 加权度：同一图每节点所有入射边的 `Σ(relation_confidence_score/100)`。
- 原快照无自环、无重复无向端点对，已全量验证。因此在这份数据上，无向度等于有向原记录的入边数＋出边数，加权度也等于两个方向的权重和。此等价关系不能无条件推广到有反向重复边的新快照。

| 榜首“生物序列比较计算方法” | 边数 | 置信度和 / 100 |
|---|---:|---:|
| 原始有向入边 | 2,347 | 1,177.65278141 |
| 原始有向出边 | 567 | 300.39236183 |
| **入射合计（正式交付）** | **2,914** | **1,478.04514324** |

加权合计保留两位小数是 **1,478.05**，满足锚点；不能为了匹配旧文档的截断中间小数改写原始结果。只算入边会得到 2,347 / 1,177.65，明显不满足验收锚点。
