## 计算口径

| 项目 | 本次口径 |
|---|---|
| 图投影 | `demo_gkx_chain` 的 tech_point + tech_rel，无向简单图；保留全部证据等级 |
| 度榜 | 按任务卡直接读取 `tech_point.weighted_degree`；另算全图无权度数，与该字段做 Pearson 核验 |
| PageRank | 全图，alpha=0.85，NetworkX tol=1e-8，max_iter=1000，边权为 `e.relation_confidence_score` |
| 子图 | 全图无权度数前 1,500 个点的诱导子图；同度按 VID 升序，避免查询返回顺序影响选择 |
| 紧密 | 子图无权最短路，Wasserman–Faust 连通性修正；不把置信度直接当距离 |
| 中介 | 同一子图，300 个源采样，seed=42，归一化、无权最短路 |
| 综合 | 只对四项均已计算的 1,500 个点评分；每项在这同一集合内 min-max，再以 0.25 等权求和；常量列归零 |
| 输出 | 四项 Top20、综合 Top20、1,500 行完整综合表；子图以外节点没有紧密/中介结果，不补零 |

NetworkX 的 tol 是按节点数缩放的迭代停止阈值，本次另独立检查 PageRank 固定点方程的 L1 残差 `< N × 1e-8`，不宣称全局残差 `< 1e-8`。

旧基线的度榜是现算无权度数，SDD 已改为使用 weighted_degree，因此度榜及综合榜不要求逐项复刻旧排名。旧材料没有记录中介采样种子及同度节点选择顺序，本次固定并留存，榜单重合度仅作差异描述，不作为精确复现证明。综合榜采用共同 1,500 点范围，与旧 JSON 显示的子图内标准化尺度一致；不能解释成全图综合榜。旧 Markdown 综合分表的部分分项与其 JSON 不一致，本次以明确公式和完整分项为准，不覆盖历史文件。

## 交付物与核验

- `result.json`：四榜及综合 Top20、参数、版本、源码 SHA256。
- `composite.json`：1,500 行完整综合排名，含四项原始值、标准化值与综合分。
- `snapshot-metadata.json`：查询模板、导出前后计数、快照 SHA256 和读取时间。
- `verification.json`：空值/非法权重、缺端点、自环、重复边检查；度数握手定理、相关性、PageRank 总和及固定点残差；历史 Top20 重合度。
- `independent-verification.json`：不用 NetworkX 中心性函数，按 BFS 距离与 Brandes 依赖累加独立复核全部子图得分，检查完整综合表和五个榜单排序。
- `baseline-diagnostics.json`：无权 PageRank 对照及子图截断处的同度节点数量，仅作历史差异诊断。

快照及全部中间得分保存在本机 `.local/t09-20261112/`，不提交原始图数据。快照读取是有序分页加前后数量守卫，**不是数据库事务快照**；同数量的并发属性变更无法据此排除。复跑应在源数据稳定窗口进行。
