## 一、「100% 满足」的定义（先把话说明白）

**不是「所有数据都灌满」**，而是：每一个用图的叶子，都落到下面四档之一，**不允许第 5 档**。

| 档 | 含义 | 验收物 |
|---|---|---|
| **A 有数** | 有数据、有接口、页面可点，查询能命中（写操作则「可保存且落点正确」） | 接口 200 + 命中条数 > 0 + 页面截图 |
| **B 空态** | 有数据、有接口、页面可点，但当前查询命中为 0，且能说清为什么 0 | 接口 200 + `items=[]` + 书面空态理由 |
| **C 501** | 源侧确实没有数据，接口按契约返回 501 + 原因码，页面明示「不可用」 | 501 + `reason.code` + 页面文案 |
| **D 不做** | 已书面裁定本期不做（报价划掉/工作量 0），页面明示「本期不支持」 | 书面裁定 + 页面文案 |
| ~~E 悬空~~ | 既没数、又没裁定、接口也没做 | **禁止出现** |

> 一句话：**「查不到」可以，「说不清」不行。**
