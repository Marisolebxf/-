## 现行范围

## 实现

- `scripts/t02_m02.py`：新写的专用执行器，不冒称原企业脚本。复用nebula3-python客户端，Doris只读使用pymysql。
- 凭据仅环境变量`DORIS_USER/DORIS_PASSWORD/NEBULA_USER/NEBULA_PASS`；不保存到文件。
- 默认dry-run；明确`--write`才写；只允许demo_gkx_chain，只有INSERT EDGE IF NOT EXISTS，无建点/DDL/更新/删除。
- 按institution_id < collaborator_institution_id先选机构对，再获取其全部年份；避免按年度行LIMIT造成不完整聚合。
- 根据机构画像排除任一company端点；画像缺失单独记录；跨年SUM co_paper_count作weight，不平均strength；原始年度strength保留在props并注明不可跨年比较。
- props含first_year/latest_year/year_count/co_paper_count_total/match_method/batch/source_table等。重复pair/year、非法计数或超长VID直接失败，避免静默丢数。
- 只检查research端点，缺失不造点；查双向及所有rank已有cooperate边，已存在跳过；新写rank=0，每条写后核对weight及完整props。
