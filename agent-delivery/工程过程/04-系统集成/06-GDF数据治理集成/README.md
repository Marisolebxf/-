- 按 [scope-baseline.md](../../../scope-baseline.md) 实现本项范围内的功能与对接

**不做**：

- 不实现对方系统后台
- 不把未接入写成已接入；对方未承诺的数据在页面上用空态
- 不在本夹修改 scope-baseline 的范围
- **Java 只读 ADS**，不把三方源直接接到页面
- 来稿未要求第 6 项进统一权限后台，**不追加统一权限收口**（区别于第 2～5 项）
- 缺表 / 字段对不上先回写 GDF Skill，不必先升级架构（§6.5 分工）
