## 一、其他要素照此拆

对一个要素 `DIM`，GDF 派单包要覆盖 DWD 之后的三块工作，三块各是独立任务，不并进同一个 MDC。

| 任务名 | 范围 |
|---|---|
| `{DIM}-MDC` | T+1 增量之后，按调度把指标结果写入指标表。只收需要离线加工的指标 |
| `{DIM}-Graph` | 实体识别、关系抽取、关系落入本要素的关系表；图上的实体和边属性走图谱引擎 API 增量写入 |
| `{DIM}-MRC` | 用户触发才计算的实时指标。MRC = 指标实时计算 |

MDC 明确排除两类：实体 / 关系抽取；匹配、推演这类交互指标。这两类仍在该要素的 GDF 派单包范围内，只是不放进 MDC。

### 1. 溯源

该要素的指标从 `metrics/calc-logic/{DIM}/README.md` 逐条对到口径文档，再对到 `metrics/repro` 里的复现脚本。复现脚本是公式验收件，不是调度作业。GDF 要读的加工逻辑是另一套 Python：读本项目的 DWD / ODS，把结果写入已有 ADS。不引入 dbt，不另建指标中台。一条指标一份口径、一次离线执行、一张结果表。

### 2. MDC 内按算法类型归类

在 MDC 集合里按口径文档上的算法类型分组（政策样例是 STAT / MODEL / GRAPH / COMPUTE）。同一类型共用刷新方式，不共用一张结果表。

### 3. 三类缺口

算不了的指标先归类，再决定动不动表、灌不灌数。

| 缺口 | 含义 | 动作 |
|---|---|---|
| 缺表 | 公式要的事实没有落点 | 在本派单包的 ODS 新建表，前缀 `mt_{dim}_`（政策为 `mt_policy_`）。demo 与 lumen 的 ODS 用同一份建表语句，编码与本包其他 ODS 主表一致。不写供应方库 |
| 缺样本 | 表结构大体够，供应方样本盖不住计算场景 | 可控的 LLM 灌数，只灌本包贴源 ODS（含关系表），不灌供应方库。批次号可逆 |
| 口径未闭合 | 列和行数都在，但业务规则未签（客户决策清单仍为待甲方） | 只列表。不建表，不灌数 |

口径未闭合的指标必须逐条写出指标号。不得并进缺表或然缺样本后悄悄开工。

### 4. 刷新

- STAT：按当前行数全量刷新。
- 全文模型：只重算变更过的主键（政策为 `policy_id`），并带回看窗口。
- 口径仍未闭合的全文模型先不调度。增量规则写在规约里，口径闭合后套用同一条。

### 5. 边与度

边只在 `{DIM}-Graph` 生产。MDC 里的关联度等指标等边落地后再算。不为度指标平行再建一张边表。

### 6. 灌数闸门

灌数是单独任务。批次上限、词表、提示词由负责人确认之后才能做。确认之前不写灌数脚本，不向 ODS 写 mock。算法平台上的基础数据 mock 是另一条通道，不替代本包 ODS 灌数。

### 7. 发布

口径未闭合、或算出来恒为同一个数、或把未签权重填成 0，都不发布。人口范围若只有临时默认，结果上写明这个限定。

## 二、政策样例：三条派单

35 条全部有归宿。下表是归宿，后面按归宿列指标号。

| 派单 | 政策里收什么 |
|---|---|
| `POLICY-MDC` | 调度写入指标表。第一批只跑分组键已在行上、且公式不挂未关闭决策项的 STAT |
| `POLICY-Graph` | 实体识别、关系抽取、产业节点写入 `policy_industry_rel` |
| `POLICY-MRC` | 匹配、推演，以及详情页上用户触发的摘要推送、实施路径辅助 |

### POLICY-Graph

- `M_POLICY_GRAPH_106_1` 政策实体识别构建
- `M_POLICY_GRAPH_107_1` 政策实体关系抽取
- 产业节点落入 `policy_industry_rel`（关系落地，不是指标号）

图侧增量写入走图谱引擎 API。本任务不算关联度，不写指标结果表。与第 07 项的边界见第四节。

### POLICY-MRC

- `M_POLICY_MATCH` 政策匹配推送
- `M_POLICY_SIMULATE` 政策效果推演
- `M_POLICY_DS_11_POLICY_EVAL_012` 智能摘要与结论推送
- `M_POLICY_DS_11_POLICY_EVAL_015` 实施路径与风险辅助

这四条不进 T+1 调度。其中匹配、推演同时出现在下面的口径未闭合名单里：规则未签之前，实时任务也不计算、不灌数。

### POLICY-MDC 第一批可调度

全量刷新。人口范围沿用 QPOL-05 的临时默认：只计国内。国际平面是否并入仍待甲方，结果上保持这个限定。

- `M_POLICY_LEVEL_DIST` 政策级别分布
- `M_POLICY_NATIONAL_DIST` 全国政策分布
- `M_POLICY_SZ_DIST` 深圳政策分布
- `M_POLICY_TOTAL_COUNT` 政策总数
- `M_POLICY_TIMESERIES` 的发布量计数

`M_POLICY_TIMESERIES` 的连续性子项不在这一批，见 QPOL-07。深圳各区计数不在这一批：区县几乎为空，属缺样本，灌数闸门未开。

全文模型的增量规则（变更 `policy_id` + 回看窗口）先记在这里。当前全文模型都在口径未闭合名单里，这一批不调度。

### 捆在一起的基础模型

`M_POLICY_BASE_100_1` 不单开一包，也不进第一批。它把级别、文种、时序、全国、深圳捆在一起。可调度的子项已在第一批；文种的主题口径在 QPOL-01；深圳各区在缺样本。

## 三、政策样例：口径未闭合

这些指标不建表、不灌数、不进第一批调度。决策项仍为待甲方。

### QPOL-01 类型分类

- `M_POLICY_TYPE_DIST`

注册口径要的是产业 / 人才 / 企业扶持。库里的 `type` 是文种（通知、公示、办法）。文种计数可以算，不能当作这条指标的结果发布。

### QPOL-02 权重、阈值、弹性

- `M_POLICY_DEEP_166_1`、`M_POLICY_FOCUS_INDEX`
- `M_POLICY_DEEP_167_1`、`M_POLICY_INTENSITY_INDEX`、`M_POLICY_INTENSITY_SCORE`
- `M_POLICY_DEEP_168_1`、`M_POLICY_EFFECT_SCORE`、`M_POLICY_IMPLEMENTATION_EFFECT`
- `M_POLICY_DEEP_169_1`、`M_POLICY_SHORTBOARD_COUNT`
- `M_POLICY_DEEP_170_1`、`M_POLICY_OPPORTUNITY_COUNT`
- `M_POLICY_DEEP_171_1`、`M_POLICY_LAYOUT_REC_COUNT`
- `M_POLICY_DS_07_POLICY_GUARD_001`、`M_POLICY_DS_07_POLICY_GUARD_008`
- `M_POLICY_SUPPORT_STRENGTH`
- `M_POLICY_TEXT_PARSE`（词表和阈值仍是临时口径）
- `M_POLICY_SIMULATE`（弹性系数未签；同时属于 `POLICY-MRC`）

### QPOL-03 相似度与匹配规则

- `M_POLICY_RELATION_DEGREE`
- `M_POLICY_INDUSTRY_FIT`
- `M_POLICY_MATCH`（同时属于 `POLICY-MRC`）

`M_POLICY_RELATION_DEGREE` 还要等 `POLICY-Graph` 的边落地。等边，不为它建第二张边表。

### QPOL-07 连续性

- `M_POLICY_TIMESERIES` 的连续性子项。发布量计数不在此项。独立指标号尚未从时序指标拆出。

### 主口径尚未指定

- `M_POLICY_VALIDITY_RATE`。空的失效日是「长期有效」还是「未标注」，以及「有效」是否等于「未标注」，口径文档写明待甲方裁决。在这之前不灌失效日，也不为它建废止事实表。
- `M_POLICY_INDUSTRY_COVERAGE`。覆盖率取哪一层为主口径，待甲方裁决。产业节点表由 `POLICY-Graph` 生产。

## 四、政策样例：第一张 `mt_policy_` 与灌数

第一张 `mt_policy_` 表是扶持事实，服务 `M_POLICY_SUPPORT_STRENGTH`，不是边表。demo 与 lumen 的 ODS 用同一份建表语句，编码与本包其他 ODS 主表一致。列只放政策标识、扶持方式、金额这类事实，权重不进表。

该指标仍在 QPOL-02。表的结构可以在后续获准的任务里建；本文不建。加工与灌数都不启动。

灌数单独成任务。批次上限、词表、提示词由负责人确认之后才能进行。负责人未确认之前，不编写灌数脚本，不向 ODS 写 mock。

## 五、与第 07 项（图数据库集成）的边界

| 放在哪 | 内容 |
|---|---|
| 第 06 项 `POLICY-Graph` | 从政策正文抽出实体和关系，写入 `policy_industry_rel`，再按图谱引擎 API 增量写实体和边属性 |
| 第 07 项 | 图数据库集成：读图、查图、已上图之后的消费。不在本项里重写抽取规则 |
| `POLICY-MDC` | 边已经存在之后，才计算关联度等图指标。规则未签（QPOL-03）的不计算 |
| `POLICY-MRC` | 匹配与推演是实时计算，不写成图的构建作业 |

其他要素的 `{DIM}-Graph` 与第 07 项沿用同一条边界：抽取和写入在 GDF 派单包的 Graph 任务，读图和查图在第 07 项。
