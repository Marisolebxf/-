## 最需要先定的一件事

**问题 1**：政策 `12` 号文写「退出码 7 表示未追平，**不算作业失败**」，但 GDF 执行器是「**非 0 即失败**」。两者冲突，导致 C1/C2 每天都被记成 `Run Failed`。

实测两作业的失败原因字符串完全一致：

```
运行"scriptExec"失败。根源错误 : 脚本退出码 7（非 0 即失败），详见上方运行日志
```

三个出路（详见问题清单 §1）：

| 方案 | 做法 | 代价 |
|---|---|---|
| A（推荐） | 脚本把「未追平」也返回 0，改在 stdout 打结构化标记 | 改客户只读脚本，需确认 |
| B | 平台侧配退出码白名单，7 视为成功 | 改 SUDF + 结构，需回归所有脚本作业 |
| C | 投产侧标记「允许失败」 | 最省事，但失败信号永久失效 |
