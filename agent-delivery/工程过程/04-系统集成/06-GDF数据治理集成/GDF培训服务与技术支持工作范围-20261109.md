## 0. 启用条件与总原则

### 0.1 何时可对外提供（启用闸门）

| 条件 | 说明 | 不算启用 |
|---|---|---|
| **典型场景齐备** | GDF 侧已纳入并形成可演示 / 可教学的最佳实践场景（贴源、Mapping、DWD 后调度、协作平台使用等），足以支撑培训 1～3 | **不是**要求附件一所列全部实施叶跑通、全部执行结果回传 |
| **教材可举证** | 培训案例取自已跑通或已书面确认可讲的场景；未回传执行结果不得当教材 | 把未填域、未成包域编成「已上线案例」 |
| **边界书面确认** | 合同双方确认：自实现域见附件一；本附件仅培训 + 产线/模板 + 疑难技术支持 | 把本附件扩成「代他方填 Mapping、代跑实施全流程」 |

**一句话**：典型场景都包含进 GDF 后即可开训与对外技术支持；**不**以「所有实施完成」为前置。

### 0.2 角色分工（铁律）

| 角色 | 负责 | 不负责 |
|---|---|---|
| **智树 / GDF 团队**（本附件义务方） | 培训交付；数据产线开发；Mapping **模板**开发；协作平台用法指导；疑难技术问题支持 | Mapping 模板**填写**；他方域的日常实施与调度值守；替他方验收业务数据质量；发明业务指标口径 |
| **智谱**（协同） | 培训讲义编排协同；模板上传至约定平台 | 代填 Mapping；代他方实施跑通 |
| **具体实施团队**（论文 / 专利 / 项目报告 / 人才等责任方） | 按模板填写 Mapping；按培训完成贴源 / Mapping / 后加工实施；回传执行结果；业务验收 | 要求智树代填、代跑、代验收 |

### 0.3 与前期工作内容的衔接（参考、不重复计费范围）

前期已开展或约定的研讨与说明，作为本附件服务的输入与边界参考，**不**另扩成「再做一遍总方案」：

| 前期项 | 目标 | 与本附件关系 |
|---|---|---|
| **工作范围和方案研讨会议** | 确定基本工作边界和实现方案 | 已划定：数据总量 / 指标类型与基本加工方案、如何配合 GDF 实施；深圳国科信 GDF 工作内容（数据产线、同步+Mapping+后续离线计算基本方案、**自实现部分 vs 培训部分**、数据相关管理平台规范用法）；GDF 产品迭代 + AI 联合研讨。本附件落实其中的「培训部分」与辅助他方实施 |
| **三方数据源数据说明文件** | 三方数据（总集）提供的数据源说明 | 培训与模板开发以该说明及现行行数/字段报告为输入；说明文件本身的维护归属三方/数据总集，本附件不承诺代写全量源说明 |

## 1. 培训服务范围

> 将最佳实践场景总结为培训服务。频次与课时：工作计划曾列「不少于 2 次」「10–30 小时」——**合同若需写死次数与课时，须双方另行书面确认**；未确认前按本表交付物验收，不擅自写成已承诺工时包。

### 1.1 培训总表

| 编号 | 课程 | 对应阶段（联通附件一） | 内容要点 | 完成判据 | WBS |
|---|---|---|---|---|---|
| **培训 1** | 基础数据 ODS 贴源 + Mapping | 附件一阶段 **①** | 供应方表 → ODS 贴源；Wave B Mapping 到项目 DWD；字段矩阵 / 过滤 / 抽检；派单包结构与回传要求 | 能按**已跑通或书面确认可讲**的贴源+Mapping 场景完整讲授；学员能按模板启动同类作业 | `WBS-06-08` |
| **培训 2** | DWD 之后的生产调度、已上线典型场景与一般实现方法；**含数据血缘加工与获取标准方案** | 附件一阶段 **②**；跨域血缘见实施范围 §6 / WBS §2.8 | Mapping 后调度；圈定 / 指标 / ADS / ES / 向量 / 图谱触发等典型路径；**血缘三类、工位导入、对外血缘 API 查询、禁编造**；他域（论文/专利/项目报告/人才）按标准方案自落血缘；禁令与不可当教材的未填域明示 | 能讲清已有调度与已上线典型场景；能按标准方案启动他域血缘接入；不把未填域/未接入血缘编成「API 已可全量追溯」 | `WBS-06-09` |
| **培训 3** | 团队协作管理平台的使用 | 跨阶段 | 数据相关管理 / 协作平台规范用法；产线上线过程规范（是否强制各厂商统一流程以双方裁定为准） | 能讲平台用法与约定流程；教材或操作手册可交付 | `WBS-06-10` |

### 1.2 培训交付物

| 交付物 | 说明 |
|---|---|
| 培训大纲 | 培训 1～3 各一份（目标学员、前置条件、课时建议、案例清单） |
| 讲义 / 演示材料 | 基于典型场景；标注案例来源包名与是否已执行回传 |
| 操作指引（可选合并进讲义） | 贴源、Mapping、调度、回传目录约定 |
| 培训记录 | 期次、日期、参训方、签到或等价记录（合同约定形式） |

### 1.3 培训不做

- 不以「全部要素实施完成」为开课条件拖延启用闸门通过后的开课。
- 不把附件一红标未成包域（金融 / 宏观 / 行业分析等）或禁令域（如产业资讯业务使用禁令未解除）讲成已可业务上线。
- 不替代他方实施团队的 Mapping 填写与作业值守。
- 不承诺固定课时包，除非合同正文或补充协议写死。
- 不把「对外血缘 API」讲成已可追溯未接入域；无作业/未导入工位的血缘**禁止**当作教材成功案例。

## 2. 技术支持与辅助实施范围（他方要素域）

> 以下域：**智树完成培训、产线开发、Mapping 模板开发**；**不负责 Mapping 模板填写与实施过程**（由具体实施团队完成）。GDF 侧可提供疑难技术问题支持。

### 2.1 域清单与分工

| 一级 | 二级 | 智树 / GDF 提供 | 实施团队负责 | WBS | 派单包现状 |
|---|---|---|---|---|---|
| 论文 | 中文论文 | 培训；数据产线；Mapping 模板 | 填模板；贴源/Mapping/后加工实施；回传 | `WBS-06-11` | 无独立包（启用后按模板+产线新建或复用约定包结构） |
| 论文 | 外文论文 | 同上 | 同上 | `WBS-06-11` | 同上 |
| 专利 | 全球专利数据 | 培训；产线；Mapping 模板 | 填模板；实施；回传 | `WBS-06-12` | 无独立包 |
| 项目报告 | 中文报告 | 培训；产线；Mapping 模板 | 填模板；实施；回传 | `WBS-06-13` | 无独立包 |
| 项目报告 | 外文报告 | 同上 | 同上 | `WBS-06-13` | 同上 |
| 项目报告 | 国内项目 | 同上 | 同上 | `WBS-06-13` | 同上 |

### 2.2 「产线 + Mapping 模板」交付定义

| 项 | 智树交付 | 验收口径 | 明确排除 |
|---|---|---|---|
| **数据产线** | 可在 GDF（或约定环境）运行的贴源 / Mapping（及约定的后加工骨架）作业或等价配置说明 | 空跑或样例行可演示通路；文档说明入参/出表/调度入口 | 不保证他方填全映射后的业务数据正确性；不代配他方生产密钥与网络白名单以外的现场运维 |
| **Mapping 模板** | 字段级映射表（含源表/目标表/转换规则占位、过滤占位、验收抽检项） | 模板可下载/上传至约定平台；字段覆盖与三方说明可对齐抽检 | **不填写**业务侧具体映射值；不代做全量字段业务裁定 |
| **血缘标准方案** | 血缘加工（作业可知 / 工位导入）与对外 API **获取**的标准步骤与字段约定；培训 2 讲授 | 实施团队能按方案把本域真实血缘接入同一对外服务；抽检：有作业才可查、无导入返回未就绪 | **不代做**他域血缘灌入；不保证他域未按方案落地时 API「看起来有血缘」；禁止编造链路 |
| **培训** | 纳入培训 1～2 案例或专项辅导场次（与 §1 统筹） | 实施团队能按模板开工；能按血缘方案对接对外 API | 不包干实施人天 |
| **疑难技术支持** | 产线报错、模板结构、平台用法、与自实现域接口冲突等技术问答 | 在约定响应期内给出原因判断或改模板/产线建议 | 不承包业务口径争议；不代替监管人签收 |

### 2.3 与附件一两阶段的对齐（辅助域同样适用）

他方实施时仍建议按附件一铁律拆分，培训与模板按两阶段组织：

| 阶段 | 名称 | 培训对应 | 模板 / 产线侧重 |
|---|---|---|---|
| **①** | DWD Mapping | 培训 1 | 贴源 + Mapping 模板与产线 |
| **②** | Mapping 后 | 培训 2 | 调度与后加工骨架（若该域合同约定含后加工） |

未完成 ① 的填写与回传，不得要求智树声明该域「业务可消费」。

## 3. 技术支持服务边界（通用）

| 支持类型 | 包含 | 不包含 |
|---|---|---|
| **培训期内答疑** | 课程相关操作、案例复现、模板字段含义 | 代写全量 Mapping；代跑生产全量 |
| **启用后疑难支持** | 产线故障、模板结构缺陷、平台使用、与附件一自实现域接口冲突 | 7×24 驻场；无限人天；业务指标重新定义 |
| **模板 / 产线缺陷修复** | 智树交付物本身的缺陷（结构错误、无法空跑、与书面说明不符） | 因实施团队填错、漏填、改口径导致的返工（可另行委托） |
| **文档协同** | 更新本附件相关大纲、模板版本说明 | 代维护三方总集全量数据源说明文件 |

**响应与人天**：具体 SLA、人次上限、是否含驻场，以合同正文或补充协议为准；本说明书只定**工作内容边界**，不定默认无限支持。

## 4. 不在本附件范围（防膨胀）

下列事项**不属于**本培训与技术支持附件，除非合同正文另条单列：

1. **附件一自实现域**的日常 Mapping 填写、作业值守与执行回传（见附件一；由 GDF 自实现路径承担）。  
2. 论文 / 专利 / 项目报告 / 全球科技人才的 **Mapping 填写与实施过程**。  
3. 建图算法、读图页面、在业务仓开发业务功能；GDF 不直写图库。  
4. 统一用户中心收口、前端直连三方源。  
5. 发明或变更业务指标口径（须产品 / 甲方 / 监管人路径）。  
6. 把未回传执行结果写成「已跑通 / 可对端」。  
7. 行业分析洗进项目 DWD、产业资讯业务上屏等现行禁令项（禁令解除前不得纳入培训「可上线」案例）。  
8. 科研机构 / 技术链 / 人才等仅「分析、不作为智树实现」的深度分析义务（见 scope-baseline §0.2）。

## 5. 验收与签收建议

| 项 | 建议验收证据 |
|---|---|
| 培训 1～3 | 大纲 + 讲义 + 至少约定期次的培训记录；案例清单标注是否已执行回传 |
| 产线 | 空跑或样例通路演示记录；作业/配置说明版本号 |
| Mapping 模板 | 已发布模板文件 + 字段覆盖抽检记录；上传至约定平台的凭证 |
| 疑难支持 | 工单或沟通流水中的问题与结论（缺陷类须有修复版本） |
| 与附件一联读 | 自实现 vs 培训辅助域清单无交叉重复计费；启用闸门日期双方确认 |

签收角色建议：培训与模板由约定监管人确认；他方域实施跑通由**该域实施团队监管人**签收，**不得**因实施未完成反向认定本附件未交付。

## 7. 一句话收口

**典型场景纳入 GDF 后**，智树对外提供培训 1～3，并对其余约定要素交付**产线与 Mapping 模板 + 疑难技术支持**；**填写与实施归具体实施团队**。本文档与《GDF 实施工作范围》构成合同两项附件：一管自实现，二管赋能与辅助。
