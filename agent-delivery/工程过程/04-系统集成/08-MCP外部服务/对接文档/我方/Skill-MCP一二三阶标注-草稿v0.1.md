## 1. 判定规则（标注时只按这三条）

| 阶 | 问一句 | 形态 | 命名倾向 |
|---|---|---|---|
| **一阶** | 是不是「垂向域里查对象 / 取记录」？ | 多为单个 MCP 工具 | `search_` / `get_` / `monitor_`（纯监测列表） |
| **二阶** | 是不是「同一垂向域里的专题战略分析」？ | MCP 工具，或「小 Skill + 少量工具」 | `analyze_` / `compare_` / `identify_` / `recommend_` / `evaluate_` / `rank_` / `build_*_landscape` |
| **三阶** | 是不是「跨垂向域的综合分析」（产业综合战略；某技术的科研 + 产业化 + 政策支持）？ | **必须是 Skill**，编排多个一、二阶工具；不能做成一个黑盒大工具 | 目录名如 `solid-state-battery-strategy`；不另起 MCP 工具前缀 |

补充约定：

1. **一、二阶是通用能力**（可复用到多个领域）；**三阶是特定领域**（每个领域可以少，但不能一个都没有）。
2. **区域综合指数 ≠ 三阶**。现有 `synth-index` / `synth-collab` 仍按二阶（区域合成指标），不得标成三阶。
3. **报告装配 / 引用溯源**（HV-11、HV-12）本身不是「分析阶」，标为 **报告装配层**；它们被三阶 Skill 调用，不单独算一/二/三阶。
4. **边界项**（如「监测里带城市对比」「全景图既是结构也是查询」）先按下方预标，11-20 前集中拍板一次，拍板结果回写本表 `status=confirmed`。
