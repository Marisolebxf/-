V2.0 （20260924）
<!-- b:Gvmbdbzb0okYwpxSAeHcx3aYnwc text -->
Z.Mate V2.0 版本正式发布。
<!-- b:AWPud6HHBo95HvxuqzKcrKjeneb text -->
本次 V2.0 聚焦数字员工能力闭环与产品体验升级，带来三项核心更新：新增「应用中心」，打通数字员工从孵化、评测到发布应用的完整链路；评测模块从 MVP 升级为正式版，进一步完善文件制品、多轮任务等复杂场景的评测能力；同时围绕用户核心使用动线完成系统性体验优化，全面升级视觉、会话制品管理、项目创建、上下文用量可视化等功能。
<!-- b:Bu9hdvXlWo4xCUxG5d3cTq5JnAd text -->
从数字员工的培养与验证，到能力的发布与使用，V2.0 进一步完善了 Z.Mate 数字员工全生命周期闭环。
<!-- b:EhG6d90XvoTjPkxKmkrcnUJnn9d text -->
「应用中心」与员工孵化全闭环：新增应用中心一级模块，将孵化完成的数字员工能力封装为面向高频业务场景的专项应用，无需多轮交互开箱即用，快速响应业务；打通「助手培养 → 快照固化 → 自动评测 → 服务发布 → 持续迭代」完整链路，Agent 孵化与迭代全程在 Z.Mate 内闭环完成。当前已上线「Z.Write」深度报告写作应用，「合同智审」「智能审单」等应用持续建设中。
<!-- b:TbxsdzqJQo4IvrxWR0YcdPlsnNd text -->
评测模块正式版上线：在 V1.5 MVP 基础上完成系统性升级，新增文件制品评测与 Tau-bench 多轮任务评测，支持独立 Judge 沙箱、多轮交互与工具调用记录等能力；覆盖 Agent 综合指标、文件任务、RAG 与 Deep Research 等评测场景，并支持在客户环境独立部署交付。
<!-- b:D86CdHQZxovnDVxDoAscZDRKnOd text -->
用户交互与视觉体验升级：全面重构视觉体系，统一页面布局、信息层级与图标语义；新增会话制品目录，自动归集并联动展示会话产出；优化项目创建流程，支持手动直接创建；新增上下文用量可视化，实时感知会话窗口使用情况；重构数字员工卡片，精简核心信息与操作入口，整体使用动线更加简洁高效。

V1.5 （20260828）
<!-- b:CqcSdqlfUoyHZSxFx5acdimMnfb text -->
Z.Mate V1.5 版本正式发布，本次版本迭代围绕"X·Y·Z"三维体系全面推进——X 轴夯实数字员工平台底座，Y 轴拓展数字员工场景广度，Z 轴深化数字员工效果深度，在评测模块建设、信创交付能力、安全治理与平台稳定性等方面进行了系统性升级。
<!-- b:OhHEd76I3oodw4xOfz2cgM0Anxd text -->
X 轴 · 数字员工平台建设： 解决沙箱持久化存储与部署权限等关键问题，保障待交付项目低成本正常交付；完成全组件 ARM 架构适配与 SQL 向国产数据库迁移，支撑信创场景交付；核心组件支持代码加密与软件 License 生成，强化私有化交付能力；优化前端交互链路，提升用户使用体验。
<!-- b:V58QdK99PofWeCxB70ocfmomnph text -->
Y 轴 · 数字员工场景广度： 基于团队数字员工模式实现无状态沙箱拉起，支持作为纯计算节点运行，具备用户标识透传与消息队列分发能力；围绕工作目录越界、危险文件操作等行为设计并实现安全钩子，保障数字员工行为安全可控。
<!-- b:JQvddb5mjo9Mr5xrtoqc4QLonle text -->
Z 轴 · 数字员工效果深度： 实现独立评测模块端到端闭环，支持评测状态可视化面板、AB 测试、消融实验与版本管理，模块可解耦独立运行，为数字员工效果度量提供系统化能力支撑。

V1.4    (20260811)

<!-- b:PMFgdg6tQoR2Usx3IRUcPBl1nw8 text -->

<!-- b:VoN8dGg4lof5d1xlxwKc2C3znzf text -->
用户交互升级： 「创建」与「管理」合并为统一的数字员工广场，模板市场、我的员工、团队员工分区清晰；会话全面升级为项目制管理，项目收纳会话与文件，新增默认工作区消除空白状态，文件上传入口收敛至输入框工具栏并自动加入引用；日程新增任务执行四宫格看板，支持按状态一览今日定时任务执行情况；人格与技能文件改为能力卡片式直观展示，侧边栏新增团队数字员工折叠区，整体交互更加简洁流畅。
<!-- b:KL4adPSVSopwegxUXZvc24Jen5g text -->
后管能力升级： 新增团队数字员工管理一级导航，提供资源概览、员工列表、用量成本组织级看板；沙箱管理新增类型字段区分个人与团队数字员工，原"沙箱名"更名为"员工名"；团队数字员工详情页集审阅与配置于一体，支持按沙箱实例维度查看用户列表与完整对话记录，满足合规审计需求。
<!-- b:QsUSdfigfo58uXxCsujcovc0n3Y text -->
问题修复与性能优化： 后端剥离非业务参数提升请求效率，优化目录上报与多实例场景性能表现，进一步提升平台稳定性与响应速度。
