# 门户专题一张图 · 接口对接说明

| 项 | 值 |
|---|---|
| 版本 | v1.2 |
| 日期 | 2026-11-07 |
| 提供方 | 科技专题服务系统 |
| 调用方 | 智慧服务门户「专题一张图」页面 |
| 接口 | 6 个，均为 `POST` + JSON |
| 集合文件 | 同目录 `2026-11-07-专题一张图.postman_collection.json`（Apifox、Postman 均可导入） |

技术、人才、科研三类指标不在这 6 个接口里，由久新另行提供。

---

## 1. 接入

### 1.1 地址

```
http://10.50.69.111:30895/topic/v1/portal/one-map
```

接口路径接在该地址后面，例如：

```
POST http://10.50.69.111:30895/topic/v1/portal/one-map/industry-stats
```

### 1.2 请求头

```
Authorization: Bearer {token}
Content-Type: application/json; charset=utf-8
```

`token` 由统一用户中心签发，与门户其他专题接口相同。未带或无效时 HTTP 状态为 `401`。

### 1.3 约定

| 项 | 约定 |
|---|---|
| 参数位置 | 业务参数都在 JSON body，不放在 URL 路径里 |
| 字段名 | `snake_case` |
| 分页 | 仅企业检索有分页。`page` 从 1 起，`size` 默认 10，最大 50 |
| 缺数 | 没有数时 `value` 为 `null`，`metric_id` 仍返回。`code` 仍为 `0` |
| 单块失败 | 某一个统计块取数失败时，只把该块置空，整包仍是 `code=0` |
| 地图 | 用 `district` 区名全称匹配（含「区」字）。`lat`、`lng` 固定为 `null` |
| 年份 | 趋势只返回实际有数的年份，缺年不补行 |

### 1.4 响应信封

成功：

```json
{ "code": 0, "msg": null, "data": {} }
```

业务参数不合法时 HTTP 仍为 200，`code=1`，`msg` 为下表枚举，无 `data`。

| msg | 接口 |
|---|---|
| `INDUSTRY_CODE_REQUIRED` | 产业统计、企业统计、政策统计 |
| `INDUSTRY_CODE_AND_DISTRICT_REQUIRED` | 行政区统计 |
| `KEYWORD_REQUIRED` | 重点企业检索 |
| `INDUSTRY_CODE_AND_THEME_REQUIRED` | 专题图 |
| `THEME_INVALID` | 专题图，`theme` 不是规定的三个值 |

| HTTP | 含义 |
|---|---|
| 200 且 `code=0` | 成功 |
| 200 且 `code=1` | 参数不合法，看 `msg` |
| 401 | token 缺失或无效 |
| 404 | 路径不正确 |
| 5xx | 服务故障 |

## 3. 接口明细

### 3.1 产业维度统计

`POST /industry-stats`

用于产业页签：产业规模、企业机构数量及历年趋势。

请求：

```json
{ "industry_code": "INB1309" }
```

`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| scale | stat_block | 产业规模，单位亿元。无数据时 `value=null`，`metric_id=M_ONE_MAP_INDUSTRY_SCALE` |
| scale_trend | trend_point[] | 规模历年趋势。无数据时为 `[]` |
| org_count | stat_block | 该产业最新一年企业数，单位家。无数据时 `value=null`。`metric_id=M_ENT_REGIONAL_COUNT_TOPIC` |
| org_count_trend | trend_point[] | 历年企业数 |

响应示例：

```json
{
  "code": 0,
  "msg": null,
  "data": {
    "scale": { "value": null, "unit": "亿元", "metric_id": "M_ONE_MAP_INDUSTRY_SCALE" },
    "scale_trend": [],
    "org_count": { "value": 1280, "unit": "家", "metric_id": "M_ENT_REGIONAL_COUNT_TOPIC" },
    "org_count_trend": [
      { "year": 2023, "value": 1100 },
      { "year": 2024, "value": 1280 }
    ]
  }
}
```

### 3.2 企业指标统计

`POST /enterprise-stats`

用于企业页签：企业数量、规模分布、中大型占比、从业人数。

请求：

```json
{ "industry_code": "INB1309" }
```

`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| count | object | `value`、`unit`（家）、`metric_id`（`M_ENT_SZ_COUNT`）、`trend`（trend_point 数组，历年企业数） |
| scale_dist | dist_block | 规模四桶，label 依次为 `大型`、`中型`、`小型`、`微型`。`metric_id=M_ENT_GAP_03`。下游无数据时各桶 `count=0` |
| medium_large_ratio | stat_block | 中大型占比，单位 `%`，保留一位小数。口径为 `(大型+中型) / 四桶合计`。四桶都是 0 时 `value=null`。`metric_id=M_ENT_GAP_09` |
| employee_count | stat_block | 从业人数，单位人。无数据时 `value=null`。`metric_id=M_ENT_GAP_10` |
| employee_dist | dist_block | 人数四桶，label 依次为 `<50`、`50–199`、`200–499`、`≥500`。`metric_id=M_ENT_GAP_03B`。无数据时各桶 `count=null`，四个 label 仍返回 |

响应示例：

```json
{
  "code": 0,
  "msg": null,
  "data": {
    "count": {
      "value": 1280,
      "unit": "家",
      "metric_id": "M_ENT_SZ_COUNT",
      "trend": [{ "year": 2024, "value": 1280 }]
    },
    "scale_dist": {
      "metric_id": "M_ENT_GAP_03",
      "buckets": [
        { "label": "大型", "count": 20 },
        { "label": "中型", "count": 80 },
        { "label": "小型", "count": 400 },
        { "label": "微型", "count": 780 }
      ]
    },
    "medium_large_ratio": { "value": 7.8, "unit": "%", "metric_id": "M_ENT_GAP_09" },
    "employee_count": { "value": null, "unit": "人", "metric_id": "M_ENT_GAP_10" },
    "employee_dist": {
      "metric_id": "M_ENT_GAP_03B",
      "buckets": [
        { "label": "<50", "count": null },
        { "label": "50–199", "count": null },
        { "label": "200–499", "count": null },
        { "label": "≥500", "count": null }
      ]
    }
  }
}
```

### 3.3 政策指标统计

`POST /policy-stats`

用于政策数量、年度趋势和各区分布。

请求：

```json
{ "industry_code": "INB1309", "district": "南山区" }
```

| 字段 | 必填 | 说明 |
|---|---|---|
| industry_code | 是 | 产业码 |
| district | 否 | 不传时 `count` 为全市该产业政策数；传入时 `count` 为该区政策数 |

`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| count | stat_block | 政策数，单位条。无数据时 `value=null`。`metric_id=M_POLICY_SZ_DIST` |
| trend | trend_point[] | 按年的发布数量 |
| by_district | array | `[{ "district": "南山区", "count": 12 }]`。传入 `district` 时这里仍是各区列表，不会收成单个区 |

### 3.4 行政区指标统计

`POST /district-stats`

用于地图上切换行政区后的指标卡：发展指数、企业数、政策数。科研机构数和人才数不在本接口。

请求：

```json
{ "industry_code": "INB1309", "district": "南山区" }
```

`industry_code`、`district` 都必填。

`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| development_index | stat_block | 区级产业发展指数。无单位，无数据时 `value=null`。`metric_id=M_ONE_MAP_DISTRICT_DEV_INDEX` |
| enterprise_count | stat_block | 该区企业数，单位家。`metric_id=M_ENT_REGIONAL_COUNT` |
| policy_count | stat_block | 该区政策数，单位条。`metric_id=M_POLICY_SZ_DIST` |

### 3.5 重点企业检索

`POST /key-enterprises/search`

按企业名检索。科研机构检索不在本接口。

请求：

```json
{
  "keyword": "生物",
  "district": "南山区",
  "industry_code": "INB1309",
  "page": 1,
  "size": 10
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| keyword | 是 | 关键词，首尾空格会去掉 |
| district | 否 | 行政区 |
| industry_code | 否 | 产业码 |
| page | 否 | 从 1 起，默认 1 |
| size | 否 | 默认 10，大于 50 时按 50 |

`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| total | integer | 命中总数 |
| records | enterprise_record[] | 当前页。响应里不回传 `page`、`size` |

地图定位用记录里的 `district`，不要用 `lat` / `lng`。

### 3.6 产业专题图

`POST /thematic-map`

一次请求一张图。`theme` 必填。

请求：

```json
{ "industry_code": "INB1309", "theme": "enterprise" }
```

`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| values | thematic_row[] | 各区的渲染值。`development` 固定返回 9 个区，无数据时 `value=null`。`enterprise` 的值是企业数，`policy` 的值是政策数 |
| legend | object | `min`、`max` 为 `values` 里有效数字的最小、最大；全是空时这两个字段为 `null`。`unit`：企业分布为 `家`，政策支持为 `条`，产业发展不返回 `unit` |

`development` 的 `metric_id` 为 `M_ONE_MAP_DISTRICT_DEV_INDEX`，`enterprise` 为 `M_ENT_REGIONAL_COUNT`，`policy` 为 `M_POLICY_SZ_DIST`。

## 4. 公共结构

### stat_block

| 字段 | 类型 | 说明 |
|---|---|---|
| value | number 或 null | 统计值 |
| unit | string | 单位：家、条、%、人、亿元。没有单位时不返回该字段 |
| metric_id | string | 指标标识，联调对照口径用 |

企业数量块在此基础上多一个 `trend` 数组。

### trend_point

| 字段 | 类型 | 说明 |
|---|---|---|
| year | integer | 年份 |
| value | number 或 null | 当年值 |

### dist_block

| 字段 | 类型 | 说明 |
|---|---|---|
| metric_id | string | 指标标识 |
| buckets | array | `{ "label": string, "count": number 或 null }` |

### enterprise_record

| 字段 | 类型 | 说明 |
|---|---|---|
| enterprise_id | string | 企业 ID |
| name | string | 企业名称 |
| district | string | 行政区全称 |
| industry_node | string | 产业链环节 |
| type | string | 企业类型 |
| lat | null | 固定 `null` |
| lng | null | 固定 `null` |

### thematic_row

| 字段 | 类型 | 说明 |
|---|---|---|
| district | string | 行政区全称 |
| value | number 或 null | 渲染值 |
| metric_id | string | 指标标识 |
