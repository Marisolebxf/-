## 二、智树在本维度做什么、不做什么

**做**：

- 按 [scope-baseline.md](../../../scope-baseline.md) 实现本项范围内的功能与对接
- 需求梳理、字段契约、样例对齐、联调与验收

**不做**：

- 不实现对方系统后台
- 不把未接入写成已接入；对方未承诺的数据在页面上用空态
- 不在本夹修改 scope-baseline 的范围
- **菜单在方案里分节，不各开一夹**（规约 §2）
- **门户四页与第 3 项的内容管理菜单不是同一页**：内容管理是运营后台，本项是门户上的展示页
- 2026-10-09 建议稿里的页面嵌入做法**只作输入，不作为这四块的做法**
- 第 4 项开发完成后要到总集统一权限配置后台配置菜单和用户权限，**写进该叶的完成条件**
