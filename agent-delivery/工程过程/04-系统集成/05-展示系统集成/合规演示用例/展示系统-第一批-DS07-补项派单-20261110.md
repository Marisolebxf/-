## DSP-DS07-SUP-01 · 158 政策建议（方案 C）

- **责任方**：算法主责（生成端点）+ 后端（任务与缓存）+ 前端（中间态页与建议卡）。
- **影响行**：TS-L2-DS07 序号 158；同卡片的 157「政策优化建议」呈现同步改善。
- **现状（2026-11-10 实测）**：`snapshot.policySuggestions = []`、`methodEvidence` 空；台账 `指标入库详情.xlsx` 无「政策建议生成」指标行（真缺口）。但**基础设施已具备**，不需从零建：
  1. K8s Secret `gkx-zhipu-llm`（`base-url` / `model` / `api-key` / `chat-url`）已注入 `lumen-algo-py` 的 api 与 worker，也已注入展示系统 Java 侧（`helm/gkxlumen-platform/values.yaml` L804–845）；
  2. `lumen-algo-py/lumen_common/algorithms/enterprise/llm_client.py` 现成 OpenAI 兼容客户端（默认 `glm-5.3-flash`，无 key 显式抛错由上层降级）；
  3. `lumen-algo-py/lumen_common/algorithms/cms/rel_insight.py` 已有 `policy` prompt 模板，端点 `POST /internal/v1/cms/kg/rel-insight`；
  4. `gkxlumen-cms` 的 `KgRelInsightService` 已有「落库缓存 + 条件指纹 + force 重生成 + LLM 失败降级空文本」范式；
  5. `gkxlumen-display` 的 `PolicySimulationService` 已在同模块内 Feign 调算法补文并降级（照抄即可）；
  6. `lumen-algo-py/.../chain/key_link.py` 已有「输出数字必须出现在入参里」的事实校验与 prompt 版本化范式。
- **要做什么**：
  1. **算法侧**：`lumen-algo-py` 新增 `POST /internal/v1/display/policy-suggestion`。入参 `{dimensions:[{key,title,score}], weights, composite, filters}`；出参 `{items:[{title,text,evidence:[{metric,value}]}], model, promptVersion, degraded}`。复用 `OpenAICompatibleClient`，新 prompt pack 版本化（`policy_suggestion.v1`），输出强制 JSON；套用 `key_link` 的数字事实校验（出现入参外数字判违规重试，仍失败则降级）。
  2. **后端**：`gkxlumen-display` 新增异步任务能力（方案 C 核心）：
     - 任务表 `evaluation_job`（或复用统一 `report` 表挂 `report_type=innovation-evaluation`），字段含 `condition_key / user / status / stage / run_id / created_at / finished_at / error`；
     - `POST /display/v1/situation/innovation-evaluation/jobs` 提交（**幂等单飞**：同用户同条件已有 running 直接返该任务）；
     - `GET /display/v1/situation/innovation-evaluation/jobs/{id}` 查询（返回阶段事实状态，**不带百分比**）；
     - `POST /display/v1/situation/innovation-evaluation/jobs/{id}/rerun` 强制重跑；
     - `GET .../snapshot` 增加建议缓存读取：同条件当天已成功 → 直接带 `policySuggestions` 与 `suggestionMeta`，不再调模型；
     - 生成失败 → `policySuggestions=[]` + `suggestionMeta.degraded=true`，**不返回 5xx，不影响四维结果**。
  3. **前端**：
     - 点「开始评估」且无当天成功缓存 → 进入**独立路由**「评估进行中」页（骨架 + 阶段清单 + 失败重试 + 完成后自动跳结果）；
     - 四维分值 / 综合得分 / 48 行排名的同步链路**不进中间态**（毫秒级，立即可用）；
     - 同条件当天已成功 → 直接打开结果页，建议卡秒回；
     - 建议卡加角标「模型生成·非评估结论」并显式标注 `promptVersion`（评审模式下可见）；
     - 切条件**不自动起任务**；提供「重新分析」按钮对应 `rerun`。
- **验收口径（五条全满足）**：
  1. 首次评估：点「开始评估」→ 中间态页出现阶段清单 → 完成后自动跳结果页，建议卡有 3–5 条 `{title,text,evidence}`；
  2. 同用户同条件重复点击 → **不新建任务**，直接返同一条（单飞）；当天再次进入 → 直接打开结果，建议秒回、不重复调用模型；
  3. 建议文本中出现的数字**全部来自入参**（用 `key_link` 同款规则校验，人工抽样 ≥10 条零违规）；
  4. 断 key / 超时场景：`policySuggestions=[]`、`suggestionMeta.degraded=true`，四维结果与综合分照常显示，页面不白屏、不报 5xx；
  5. 中间态页只显示 `done / in_progress / todo / n/a`，**无百分比、无预估进度**；切条件不自动起任务。
- **红线**：模型输出**不得参与计分、排名、覆盖率**；不得用模板文案冒充模型输出；建议必须带证据指标；失败必须降级为空而非编造。
- **文档回填**：`TS-L2-DS07-合规演示用例.md` 158 行（覆盖不到 → 部分可演并注明"模型生成·非评估结论"）、口径文档补 `policy_suggestion` 口径小节、索引 DS-07 行计数同步。

## DSP-DS07-SUP-02 · 150 技术影响力（台账降级接法）

- **责任方**：算法主责 + 后端透传 + 前端雷达置灰。
- **影响行**：TS-L2-DS07 序号 150。
- **现状（2026-11-10 查台账）**：当前按 `M_INNOV_POT_TECH_INFL`「产业技术影响力」口径实现，台账判 **完全不支持**，故整维缺测、`dimensions.industry` 技术影响力指标为 null。同一业务口径在台账中另有两条可接：
  1. `M_ENT_DS_07_INDUSTRY_POTENTIAL_005`「技术影响力评估」，判 **部分支持**，源表 `dwd_bid_target_item_out / dwd_org_base_info / dwd_patent`，台账 UI 挂载列已写明边界：「产业潜力评估 → 技术影响力雷达图的**被引影响力**轴；**SEP 轴置灰并标注『未测』**」；
  2. `M_SCIUI_X_016`「技术影响力得分（技术扩散维度）」复用上述指标，复用深度 `covered`。
- **要做什么**：
  1. **算法侧**：按 `M_ENT_DS_07_INDUSTRY_POTENTIAL_005` 口径产出**按雷达轴拆分的**技术影响力，落我方库或 precompute JSON。**被引影响力轴**用真实被引数据（`dwd_patent` ⋈ 被引表）计分；**SEP 轴不产出数值**，返回 `null` + 轴级 `status=pending`；
  2. **后端**：`InnovationEvaluationController` 的 `dimensions.industry` 把「技术影响力评估」由 null 换成数值，并下发 `axes:[{key,label,score,status}]` 与 `pendingAxes:["sep"]`；`DATA_SOURCE_NOTE` 补该指标 ID 与缺轴说明；
  3. **前端**：详情页技术影响力雷达渲染按轴取值，`status=pending` 的轴置灰并标「未测」，tooltip 说明"SEP 轴无源"。
- **验收口径（四条全满足）**：
  1. `snapshot.dimensions.industry` 中「技术影响力评估」不再为 null，分值与算法侧逐轴加总一致；
  2. 被引影响力轴有真实计量依据（给出命中的专利/被引行数与覆盖率）；
  3. SEP 轴**始终为 null 且置灰**，页面上有「未测」文案，**不得由规则或模型生成任何 SEP 数值**；
  4. 口径文档新增/更新该指标条目（指标 ID、源表、缺轴原因、冻结上限），与页面文案一致。
- **红线**：不得用均值/中位数/模型推估填充 SEP 轴；不得把"被引影响力"改名为"技术影响力整体"。
- **文档回填**：`TS-L2-DS07-合规演示用例.md` 150 行（覆盖不到 → 部分可演）、校验矩阵与索引同步、台账 `指标入库详情.xlsx` 支持度由人工（唐绍祖/王惠）复核后维护。
