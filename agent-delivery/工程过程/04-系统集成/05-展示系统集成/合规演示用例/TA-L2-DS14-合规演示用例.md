## 备注与风险

1. **久新实探结论（2026-11-06 / 契约 v1.2 实测）**：`china.provinces[]` 覆盖 34 个省级行政区（`ads_talent_profile` 中国行按省聚合 + `ads_location` 经纬度）；`china.migration[]` 省际边实测 4,296 条（`ads_talent_mobility_yearly_flow`，2015–2025）；深圳 `districts[]` 实测 503 人有区县归属（南山 389 / 龙岗 55 / 福田 17 / 坪山 16 / 光明 16 / 罗湖 5 / 宝安 3 / 盐田 2），区级行无经纬度、用静态区质心定位；深圳 `flows` 出入边 40 条。
2. **明确无源 / 空态项**：`parks[]`（久新无产业园 / 创新载体维 → 空态，273 / 271 的园区层不可演到三级）；`shenzhen.structure`（年龄结构无源，出生年份仅 3 人确认 → 空态，275 结构 Tab 受限）；迁移原因（久新无原因字段 → 267 原因饼只作口径说明）；区级 `growthRate` 无区级年度序列 → 不造趋势。
3. **契约未闭合项**：职称字段未出现在 `TalentFocusRegionDataset` 字段映射中，274 的「职称」筛选来源待确认；`china.provinces[].industries` 为契约 v1.3 新增（`ads_institution_industry` 1,350,000 行 / 12,701 家机构，取 `institution_industry_rank=1` 主行业加权 Top5），M3 需按 v1.3 复核；省级代表专家（`INTERP127 1202`）在 FE 侧为红问号卡，代表人才区可能空态。
4. **口径**：省 / 市地图与榜单为「当前主机构位置」聚合口径，时间轴为「年度论文署名活跃人才」口径，两者不可互相校验。
5. **供数与契约边界**：四子页供数归 WBS-02-01；技术方案 §1.2 记「非三要素区块的对接对象清单：还没有」；本页无导出 / 报告接口，导出与报告均为前端本地生成。
