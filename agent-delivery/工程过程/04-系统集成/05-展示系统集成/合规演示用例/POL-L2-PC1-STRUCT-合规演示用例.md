# POL-L2-PC1-STRUCT · 政策库结构化 · 合规演示用例

- 规程：`agent-delivery/产品实现规程.md` §6.4
- 系统：科技信息展示系统 · 科技政策跟踪 · 政策数据治理
- 需规序号：603
- 需规全文：说明书「#### 603」
- 日期：2026-11-16
- 调度核对：见文末

检索：`GET /display/v1/policy/panorama/search`（关键字，不是页内已装列表过滤）。  
抽取：`POST /display/v1/policy/parse/clauses`（body `policy_id`）后再 `GET /display/v1/policy/governance/results?policyId=`。  
摘要字段：`structure.policySummary`（`hasClauses`、标题、发文机关、发布日期、地区）。

实例：政策 `18319069`，标题含「调整国家科学技术奖奖金标准」。只选定不点按钮时，摘要区不出现这一条。点「结构化抽取」成功且 `hasClauses=true` 后才出摘要。

## 一条主路径

1. 打开智能政策库构建 · 政策库结构化。两表已有行。
2. 政策选择输入「奖金标准」，选中 `18319069`。
3. 不点按钮时，下方没有这一政策的摘要。
4. 点「结构化抽取」。成功后出现摘要，且标明已结构化。

## 调度核对

可演：选择后点抽取才出摘要、未点不出摘要、两表非空。检索是否命中 `18319069` 需部署后用关键字再核一次。本机跳板超时，未复查询库。
