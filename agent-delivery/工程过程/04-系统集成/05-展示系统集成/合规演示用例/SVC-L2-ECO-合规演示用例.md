## 备注与风险

1. **界面未落地**：`lumen-ui-science-pc` 路由 `service/innovation-ecology-service` 当前无对应组件分支，`src/router/menu.ts` 的 `resolveNavComponent` 落到 `DevelopingView`。本文期望按 demo 原型 `repos/demo-ui-science/src/pages/tech-service/InnovationEcosystem.jsx` 的交互写，**不能当作已实现**，需人工确认 M3 前是否补落地。
2. **接口未冻结**：技术方案 §1.2 / §2.3 只写「有 ADS 行则读，否则空态」，未给 REST 路径、字段级清单与 `metric_id`。按 D9 与 §4.2，统计数字只消费指标库已有口径，禁止前端自算。
3. **供数缺失**：技术方案 §1.2 记「已签收供数：还没有」；ADS 无行则整页空态。
4. **契约冲突**：demo 原型用 `mockData` 并含 `Math.random` 扰动（态势模拟刷新）。`USE_MOCK=false` 时必须零 fixture，不得把演示台账写成归档记录，也不得把扰动值写成实时数据。
5. **缺列**：SRS 561 要求「人才结构 / 结构调整」，原型无对应列与字段，M3 需按缺口登记，不用文本推断补数。
6. **名称区分**：本页是服务全景下的「科技创新生态服务」（WBS-05-06），不是科技成果展示里的「科技创新生态展示」（WBS-05-05），两处不合并。
7. **视频 / 图片 / 新闻**：详情多媒体依赖供方台账，供数未到前只能演空态文案，不演「多媒体可播放」。
