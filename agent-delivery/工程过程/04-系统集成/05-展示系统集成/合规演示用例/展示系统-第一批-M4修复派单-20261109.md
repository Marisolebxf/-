## DSP-M4-FIX-01 · 专利权利要求数（`claim_count`）

- **责任方**：数仓
- **影响行**：TS-L2-DS07 序号 141（专利质量）
- **现状**：专利质量 V2.3 共 5 维，其中「权利要求数」维因无字段整维缺失，当前按 4/5 维重归一计分。
- **要做什么**：
  1. 在专利主档侧建立权利要求数字段（`dwd_patent_claim.claim_count` 或等效），与 `dwd_patent` 主键可关联。
  2. 回填历史专利；回填率需在交付说明中给出实测值。
- **验收口径**（三条全满足才算完成）：
  - 字段存在且可 join 到 `dwd_patent`，回填率实测值 ≥ 80%（低于则说明原因）；
  - `M_TECH_DS_07_TECH_INNOV_002` 计算返回的 5 维中「权利要求数」维不再为 null；
  - 专利质量分数与「按 4/5 维重归一」旧值有差异，且差异可解释（不接受完全相同的静默降级）。
- **备注**：本字段只补数据，不改算法；算法侧重归一分母的切换由算法侧在字段可用后自行调整。

## DSP-M4-FIX-02 · 专利法律事件 4 类码值

- **责任方**：数仓
- **影响行**：TS-L2-DS07 序号 142（技术市场潜力）
- **现状**：`dwd_patent_legal` 实测仅 20,000 行（覆盖率 0.68%），码值命中：诉讼 0 / 许可 56 / 质押 104 / 开放许可 6。许可、诉讼、质押、开放许可四类当前均不可算，市场潜力只能退化为「仅转让」口径。
- **要做什么**：
  1. 补齐 `legal_event_code` 四类取值（许可 / 诉讼 / 质押 / 开放许可声明）并扩全量事件（当前 2 万行为抽样）。
  2. 冗余 ipc4 字段，使法律事件可按行业归属聚合。
- **验收口径**：
  - 四类码值各有非零命中，且给出各类实测条数；
  - 覆盖率实测 ≥ 50%（当前 0.68%，明显偏低，需在交付说明里解释上限）；
  - 法律事件表可按 ipc4 聚合到行业，无需回连主表全扫。
- **备注**：本项是 142 从「整维缺测」转为「可演」的前置条件；未完成前市场潜力不参与计分。

## DSP-M4-FIX-03 · 国别映射表

- **责任方**：后端
- **影响行**：TS-L2-DS07（国际合作论文比例维）
- **现状**：论文侧国别/地区字段为原始字符串，无标准映射，国际合作论文比例不可算，整维缺测。
- **要做什么**：建 `country_alias` 映射表（原始写法 → ISO 国家码），覆盖 `dwd_zh_paper` 实际出现的全部国别写法；提供只读查询接口或在聚合层内联使用。
- **验收口径**：
  - 映射表覆盖 `dwd_zh_paper` 去重后国别写法的 ≥ 95%，未命中清单可见；
  - 国际合作论文比例可出数，取值范围 0–100，不得出现 >100 或负值；
  - 中国（含港澳台分列口径）需在交付说明中明示归类规则。
- **备注**：纯映射，不动模型；如需调整「国际合作」定义（是否含港澳台），由算法侧确认后再改。

## DSP-M4-FIX-04 · 政策前瞻词表

- **责任方**：算法
- **影响行**：TS-L2-DS07（政策前瞻性维）
- **现状**：政策文本侧无前瞻词表配置，政策前瞻性不可算。
- **要做什么**：在 config 中提供前瞻词表（支撑「规划/布局/培育/前瞻/储备」等语义），并接入政策文本匹配计算。
- **验收口径**：
  - 词表以配置文件形式存在（不硬编码在代码里），可版本化；

  - 命中率异常（0% 或 100%）需在交付说明中解释。
- **备注**：词表初版可参考已有政策分类字典，但不得直接把分类标签当前瞻性得分。

## DSP-M4-FIX-07 · 职称筛选

- **影响行**：TA-L2-DS14 序号 274（区级人才筛选）
- **现状**：契约 `TalentFocusRegionDataset` 未含职称字段，职称下拉置灰。
- **要做什么**：从 `ads_talent_experience` 解析职称，纳入 dataset 并在筛选契约中开放。
- **实测证据（2026-11-09 探针，久新只读）**：

## DSP-M4-FIX-08 · 综合难度模型 T7

- **责任方**：算法
- **影响行**：TA-L2-DS16 序号 308、314（难度 Tab 全族）
- **现状**：`difficultyEstimate` 仅 `factors.activity` 有真实百分位，其余 7 因子恒 0，`overall=0`。
- **要做什么**：建 T7 综合难度模型，把 activity 与其余因子按可解释口径合成为 overall。
- **验收口径**：
  - 8 个因子中至少 activity + 2 个新增因子有真实取值（其余明确标注「无源」而非 0）；
  - `overall` 为 0–100，且 15 名人才间有区分度（不全同值）；
  - 「无源因子」在返回结构中显式标记，不得用 0 掩码；
  - 未达上述三条前，页面维持 501 空态，`overall=0` 禁讲「难度低」。
- **备注**：本项由 M4 裁定从「不演」翻为「修复」（附录 A15），优先级按本单排序执行；若因子源不足，先交「部分因子 + 显式标注」版本，不阻塞整体。
