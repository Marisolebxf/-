## DSP-M4-FIX-01 · 专利权利要求数（`claim_count`）

- **责任方（2026-11-09 重路由）**：算法主责 + 后端配合（原数仓路径废止——数仓/久新冻结，详见 `M4修复-冻结约束重路由分析-20261109.md`）
- **影响行**：TS-L2-DS07 序号 141（专利质量）
- **现状**：专利质量 V2.3 共 5 维，其中「权利要求数」维因无字段整维缺失，当前按 4/5 维重归一计分。
- **要做什么（2026-11-09 重路由，数仓/久新冻结）**：
  1. **改道算法解析**：不建数仓字段，算法侧解析 `dwd_patent_claim.original_text` 整段原文计权利要求条数（王慧 V2.3 口径预留路径），结果落我方库（demo_gkxlumenx_ai）→ 后端读取。
  2. 覆盖率在交付说明中给出实测值并**如实标注上限**（claim 表现存约 2 万行、覆盖 0.68%，冻结下不可扩量）。
- **验收口径（李伟 2026-11-09 裁定：降级口径交付，四条全满足）**：
  - 「权利要求数」维由算法解析出数，`M_TECH_DS_07_TECH_INNOV_002` 返回的 5 维中该维不再为 null；
  - 覆盖率实测值在交付说明与页面如实标注，**不再要求 ≥80%**；
  - 解析口径可复现（词表/规则版本化），抽样 ≥20 件人工核对解析条数与原文一致；
  - 专利质量分数与「按 4/5 维重归一」旧值有差异，且差异可解释（不接受完全相同的静默降级）。
- **备注**：原「建字段回填」路径因数仓冻结废止；重归一分母切换由算法侧在出数后自行调整。

## DSP-M4-FIX-02 · 专利法律事件 4 类码值

- **责任方（2026-11-09 重路由）**：算法主责 + 后端配合（原数仓路径废止——数仓/久新冻结，详见 `M4修复-冻结约束重路由分析-20261109.md`）
- **影响行**：TS-L2-DS07 序号 142（技术市场潜力）
- **现状**：`dwd_patent_legal` 实测仅 20,000 行（覆盖率 0.68%），码值命中：诉讼 0 / 许可 56 / 质押 104 / 开放许可 6。许可、诉讼、质押、开放许可四类当前均不可算，市场潜力只能退化为「仅转让」口径。
- **要做什么（2026-11-09 重路由，数仓/久新冻结）**：
  1. **改道算法分类**：算法侧对 `dwd_patent_legal` 描述文本做关键词/规则分类，产出四类码值（许可 / 诉讼 / 质押 / 开放许可声明，语义按王慧 V2.3 口径，转让侧用 TA01/TR01/PC/PC1 交叉校验），结果落我方库 → 后端读取。
  2. 由算法 join 专利主表冗余 ipc4，使法律事件可按行业归属聚合。
  3. **不扩量**：现存约 2 万行事件（覆盖 0.68%）为冻结上限，交付说明如实标注。
- **验收口径（李伟 2026-11-09 裁定：降级口径交付，三条全满足）**：
  - 四类码值按分类结果出数，并给出各类实测条数（类间悬殊须解释，0 命中的类如实标注原因）；
  - 覆盖率 0.68% 上限在交付说明与页面如实标注，**不再要求 ≥50%**；
  - 分类规则版本化，抽样 ≥20 条人工核对分类正确；
  - 结果可按 ipc4 聚合到行业，无需回连主表全扫。
- **备注**：本项是 142 从「整维缺测」转为「部分可演」的前置条件；缺测维按王慧 V2.3「无源维不参与合成、剩余维重归一」处理。

## DSP-M4-FIX-03 · 国别映射表

- **责任方**：后端

- **现状**：论文侧国别/地区字段为原始字符串，无标准映射，国际合作论文比例不可算，整维缺测。

- **验收口径**：
  - 映射表覆盖 `dwd_zh_paper` 去重后国别写法的 ≥ 95%，未命中清单可见；

  - 中国（含港澳台分列口径）需在交付说明中明示归类规则。
- **备注**：纯映射，不动模型；如需调整「国际合作」定义（是否含港澳台），由算法侧确认后再改。
