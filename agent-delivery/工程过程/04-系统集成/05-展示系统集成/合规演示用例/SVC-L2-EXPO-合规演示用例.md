## 主路径一句话

进科技服务全景 → 科技交流（类型选「科技交流」、切地图视图，出现活动点位与四类图例）→ 点活动卡在 iframe 内打开详情；返回后进科技竞赛（级别选「国家级」、切「已结束」页签 → 排行榜选一场有榜单的竞赛）→ 再进科技传播（输入「科技」、排序「最多浏览」、卡片 / 时间轴切换）；任一对端不可达时页面显示对应空态，不显示编造数据。

## 备注与风险

1. **口径冲突（最需人工确认）**：技术方案 §1.2 WBS-05-08 原口径是「三个入口跳转，失败有提示」；现行 `lumen-ui-science-pc` 已实现为 BFF 代理真实页面（`/display/v1/exchange|competition|communication`），详情用 `DetailIframeModal` 内嵌 `detail_url`，**不是跳转**。本文按现有实现写接口；凡跳转类期望已写成「目标地址 X / 失败提示 Y」，需确认按哪个口径验收。
2. **失败提示不足**：`DetailIframeModal` 在 url 为空时显示「该条目未提供详情地址」，但对端 iframe 加载失败或被禁嵌（`X-Frame-Options` / CSP）没有显式错误文案，只有「在新窗口打开」外链，不满足「失败须有提示」。
3. **供数**：深势接口已由 BFF 代理（`SYSINT-05-08-03/04/05`），但供数进 ADS「还没有」；本仓不入库，仅展示代理结果。
4. **能力评估中不支持项（技术方案 §2.3）**：热门标签统计、展览 / 图书 / 视频、传播的区域级别、活动讲者关联学者、精确地图、实际到场人数、统一搜索、成绩榜的项目名称 / 机构 / 奖金，均不得补造成已有数据。
5. **地图口径**：交流地图按 `venueAddress` 文字模糊匹配坐标（`geo.ts`），不是对端经纬度；未匹配活动不上图，只提示数量。
6. **供方名称**：「北大深势」未核对（技术方案 §1.4）；本文件接口按清单登记名「深势对外开放接口」书写。
7. **页面与需规偏差（缺口汇总）**：交流页无关键词框、无规模 / 参与者标签、专家无 hover 弹窗与人才画像跳转；竞赛页无发布 / 组织入口，讨论区与资源接口未渲染；传播页无时间 / 主题筛选，详情未走结构化接口，信息图未实现。以上在 M3 按「覆盖不到」或补实现二选一登记。
8. **activityType 必填坑（现场演示最高危，2026-11-07 实测）**：`/display/v1/exchange/list` 与 `/display/v1/exchange/sync` 的 `activityType` 为必填，漏参直接 HTTP 400——现场漏参数会白屏，演示必须先选类型；合法值全集 exchange / reasoning / live / course，非法值（如 foo）返回 200 空壳（items=[]、_bff_source=deep-shi-biz-error）不报错。
9. **2026-11-07 实测三处对端行为（演示只演生效组合）**：① reasoning 类 subjectAreaId 筛选不生效（任意值恒返回 135 全量），exchange / live 生效；② communication `contentTypes` 多值组合（逗号分隔或重复参数）均返回 0，仅单值生效；③ `publishTimeOrder` 仅 ASC 生效，DESC 与非法日期均返回 200 空壳（deep-shi-biz-error）而非报错。
10. **传播口径两处照实讲**：分类 SRS 列 10 类而接口实测 7 类（顶级期刊 / 学术会议 / 前沿成果 / 活动资讯 / 技术课程 / 成果转化 / 需求发布），名称数量均不同，以接口为准；传播 stats 三卡（月浏览量 / 活跃用户 / 新增内容）实测均为 0，照实讲不编造。另交流 overview 的 activityCountByType 实测为 {} 空对象，类型分布若依赖该字段须确认前端取值路径。
