## D1 · 服务类型主档：我方运营目录 + 对端映射表

**裁定**：服务类型 5 类采用**我方运营目录**，标记来源 `ops`；同时维护一张 `ops_service_type` ↔ 对端 7 项分析能力的**映射表**，用于报告归属与筛选。

| 服务类型（我方运营目录，5 类） | 代码 |
|---|---|
| 政策研究 | `policy_research` |
| 战略咨询 | `strategy_consulting` |
| 评估评价 | `evaluation` |
| 人才培训 | `talent_training` |
| 学术交流 | `academic_exchange` |

**对端 7 项分析能力（不直接展示，仅入映射表）**：论文分析、专利分析、科研项目分析、社会网络分析、技术趋势分析、聚类分析、共性网络分析。

**约束**
1. 前端**禁止**把 7 项分析能力渲染为服务类型。
2. 服务类型筛选下拉取我方运营目录（前端只读镜像，后续可换对端主档接口）。
3. 映射表落 `agent-delivery/metrics/registry/` 下，真源单文件，页面只读消费，**禁止组件手写**。
4. 对端若后续提供正式主档，由 `SYSINT-05-07-02-L01` 契约变更流程替换，不改前端结构。

**风险处置**：`ops` 目录属我方自定，若甲方验收要求"服务类型须对端可证"，回退方案为"隐藏服务类型筛选、仅保留 Tab 导航"，由 PM 决定。

## D2 · 专家 H 指数 / 引用量：不展示

**裁定**：专家列表与详情**均不展示 H 指数与引用量**；仅保留论文数（`paperCount`）作背景信息。

| 对端字段 | 处置 |
|---|---|
| `hIndex` | **不展示**，字段映射层丢弃 |
| 引用量（若有） | **不展示**，字段映射层丢弃 |
| `paperCount` | 保留，作背景显示（不做指标、不参与统计） |
| `name` / `title` / `researchFields` / `avatarUrl` | 展示 |

**依据**：`DS-30-THINKTANK.yaml` 明确本页"智库专家情况"**不是**人才指数 / H 指数 / 引进匹配（`talent_ds13_16` 边界）。对端愿意给，但我方范围基线不允许在本页当指标展示。

**约束**：后端 DTO **不暴露** `hIndex` / 引用量字段，从源头收敛，避免前端误用。

---

## D3 · 活动 Tab：保留 + 列表 + 详情空态

**裁定**：智库活动 Tab **保留**；列表展示德菲尔问卷 7 字段（`questionnaireId` / `name` / `domain` / `startDate` / `endDate` / `timeTag` / `description`）；详情页展示问卷汇总 7 字段（`name` / `domain` / 起止日期 / `description` / `expectedExpertCount` / `expertCount` / `completionRate`），**不展示问答正文**；若接口返回空，则展示"该活动暂未提供对外明细"空态说明。

**依据**：对端自评"详情页是关于问卷的问答情况和统计结果，感觉不适合对外公开"；seq 569 要求五模块结构完整，隐藏 Tab 会造成验收缺口。

**约束**：空态文案统一走空态组件，**禁止**页面硬编码业务解释。

## D4 · 成果口径：接受现状 + 建议由 `report_type` 派生

**裁定**：
1. **接受**"成果 = 案例广场战略咨询成果案例"这一集合（ZK-02 口径）。
2. "成果 / 建议 / 案例"三分由 `strategy_sub_type` 承载（对端已给）。
3. "建议"类在**报告侧**由 `report_type` 派生（战略咨询报告 + `strategy_sub_type=建议`），不单独找数据源。
4. 三类聚合饼图（seq 568）**只画有数的类**；空类显示 0 并在图例保留，不伪造数据。

**约束**：若甲方要求"成果 / 建议"须为独立集合，升级为 `SYSINT-05-07-04-L01` 待办，由对端补清单或我方运营目录补录。

## D5 · 服务类型"关联 X 项"计数：我方派生

**裁定**：服务类型每类后的"关联 X 项"由**前端按列表数据派生**（按 `service_type` 分组计数），对端不给该字段。

**约束**
1. 该计数为**展示派生值**，**不作指标**、不进 `catalog`、不挂 D9 四维就绪度（避免伪指标）。
2. 派生结果须与列表同源同页，避免与成果统计（ZK-04）口径混用。
3. 前端在 ⓘ 中说明口径为"按当前列表口径派生"。
