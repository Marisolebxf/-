## B2 · 活动：保留 Tab，列表可看、详情仅汇总

**裁定**：
1. 活动类型**对外口径限定为"德尔菲问卷"一类**（对端仅有此数据）。
2. 列表展示 7 字段；详情展示 7 项汇总字段。
3. **问答明细 / 统计结果不入展示**（对端自评不适合公开，我方尊重该边界）。
4. 论坛 / 研讨会 / 发布会类活动**当前无数据源**，前端不预留伪入口。
5. 若后续对端提供其他活动类型，按契约变更补入，前端结构预留 `activity_type` 字段。

**对外动作**：书面请对端确认「对外可公开的活动类型是否仅德尔菲问卷」以及「是否另有论坛/研讨会类」。

**生效条件**：本函签字即生效；对端若回复另有类型，另行变更。

## B5 · 专家详情：本系统内 iframe 弹框嵌入（**核心裁定**）

### 裁定原文

> **专家详情不跳出新页签 / 新窗口；采用本系统内 iframe 弹框（`IframeDetailModal`）嵌入对端详情页。**

**裁定依据**：用户 2026-11-06 明确裁定「允许本系统内 iframe 弹框」。

### 与 DoD 的关系（关键）

原 DoD 表述「**不按前端跳转**」的**语义收敛**为：

| 原表述 | 裁后明确表述 |
|---|---|
| 不按前端跳转 | **不跳出新页签 / 不打开新窗口 / 不改变本系统路由**；**允许在本系统内以 iframe 弹框嵌入对端页面** |

**这条不是放宽，是澄清**：用户始终停留在本系统内，不离开、不丢失上下文、可随时关闭返回列表——比"跳新页签"更符合"不跳转"的本意。

### 技术形态

| 项 | 约定 |
|---|---|
| 组件 | `IframeDetailModal`（Arco `Modal` + `iframe`） |
| 尺寸 | `80vw × 80vh` |
| 标题 | 取专家 `name`（报告详情取 `title`） |
| 加载态 | `onLoad` 前骨架屏 |
| iframe 属性 | `loading="lazy"`、`referrerpolicy="no-referrer"`、`sandbox="allow-scripts allow-same-origin"` |
| 关闭 | 允许关闭；**禁用点击蒙层关闭**（防误触丢失上下文） |
| 空 `detail_url` 兜底 | 按钮置灰 + Tooltip「暂不支持在线预览」，**回落现有详情抽屉**（抽屉保留不删，延续 2026-10-24 裁定） |
| 对端禁嵌兜底 | 若 `X-Frame-Options` / CSP 不放行 → 降级为"跳新页签"，并在 UI 提示"在新窗口打开" |

### 前置条件（`SYSINT-05-07-04-L01` 必须闭环）

1. 对端书面确认 `edu.itic-sci.com`（专家详情）与 `zk.example.com`（报告详情）的 `X-Frame-Options` / CSP `frame-ancestors` **允许本系统域嵌入**。
2. `detail_url` **免登录可读**（iframe 打开不得跳登录页）。
3. 两端 **HTTPS 一致**（否则混合内容被浏览器拦截）。

**任一不满足 → B5 降级为"跳新页签"并升级 PM 决策，不改 DoD 主体。**

### 专家详情 URL 形态（对端直给）

```
https://edu.itic-sci.com/tts/svcj/strategy/talent/detail/{talentId}?scene=nurture
```

> `scene=nurture` 参数提示该页可能属对端内部培养系统；嵌入可行性由 04 号单确认。
