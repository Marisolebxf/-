# 科技服务全景对外开放接口文档

> 文档版本：1.2.13  
> 生成依据：`docs/科技服务全景对外开放接口.openapi.yaml`  
> 覆盖范围：科技竞赛、科技交流、科技传播

## 1. 接入约定

### 1.1 请求地址

| 环境 | 基础地址 |
| --- | --- |
| 测试环境 | `https://szc.test.dp.tech/ticsapi` |
| 其他环境 | `https://{host}/ticsapi` |

本文档中的接口路径均以 `/szc/v1/open/...` 开头，完整请求地址由基础地址与接口路径拼接。

### 1.2 请求方式与鉴权

- 本文档接口均为 `GET` 公开只读接口，不要求登录。
- 内容可见性由服务端固定，调用方不能通过参数放宽。
- 科技传播接口在网关能够识别登录用户时，会记录当日活跃用户；匿名用户不计入活跃用户。

### 1.3 统一响应

成功响应：

```json
{
  "code": 0,
  "data": {}
}
```

业务或参数错误：

```json
{
  "code": 148888,
  "error": "错误描述"
}
```

`gkx-tics-api` 直接透传 `gkx-core` 响应，不再次包装。代理、网络和超时等基础设施错误可能返回非 `200` HTTP 状态。

### 1.4 通用数据格式

| 项目 | 约定 |
| --- | --- |
| 时间 | RFC3339，如 `2026-06-01T10:00:00+08:00` |
| 可空时间 | 无值时返回 `null` |
| `page` | 从 1 开始，默认 1 |
| `pageSize` | 默认 20，普通列表上限 100，增量同步上限 200 |
| 数组空值 | 返回 `[]`，不返回 `null` |

## 3. 科技竞赛

### 3.1 竞赛列表

`GET /szc/v1/open/competition/list`

仅返回未删除、已发布、已上架且非“仅认证专家可见”的竞赛。本接口不配套竞赛详情接口，请使用 `detailUrl` 跳转。

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 模糊匹配赛事名称、简介、主办方和赛事主题，最长 100 |
| `theme` | string | 否 | 竞赛类型/赛题方向，自由文本模糊匹配 |
| `competitionLevel` | integer | 否 | 赛事层次，见枚举 8.1 |
| `stage` | string | 否 | 赛程粗分组，见枚举 8.1 |
| `registrationDeadline` | string | 否 | 报名截止时间：`thisWeek` / `thisMonth` |
| `page` | integer | 否 | 页码，默认 1 |
| `pageSize` | integer | 否 | 每页数量，默认 20，上限 100 |

#### 响应 `data`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `total` | int64 | 符合条件的总数 |
| `page` / `pageSize` | integer | 当前页与每页数量 |
| `publishUrl` | string | 竞赛发布入口；测试环境为 `https://szc.test.dp.tech/tics/competitions/create` |
| `items` | array | 竞赛列表 |
| `stats` | object | 全部对外可见竞赛的概览统计，不随筛选和分页变化 |

`items[]` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `competitionId` | int64 | 竞赛 ID，资源、榜单、讨论接口使用该 ID |
| `postId` | string | 对外混淆 ID，用于前端详情页路径 |
| `name` | string | 赛事名称 |
| `theme` | string | 赛题方向，可为空字符串 |
| `competitionType` / `competitionTypeName` | integer / string | 赛事类别及名称 |
| `competitionLevel` / `competitionLevelName` | integer / string | 赛事层次及名称 |
| `sponsor` | string | 主办方 |
| `organizer` | string | 举办方 |
| `overview` | string | 赛事简介 |
| `cover` | string | 封面地址，可能是对象存储相对路径 |
| `status` / `statusName` | integer / string | 原始赛程状态及名称 |
| `stage` | string | 赛程粗分组，建议展示和筛选使用 |
| `startTime` / `endTime` | datetime/null | 报名开始时间/结果公示结束时间 |
| `participantCount` | int64 | 参与人数 |
| `participantType` | integer | `1` 按人数，`2` 按队伍 |
| `viewCount` | int64 | 浏览量 |
| `detailUrl` | string | 本平台前端详情地址 |
| `updateTime` | datetime | 最后更新时间 |

`stats` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `competitionCount` | int64 | 对外可见赛事总数，不限年份 |
| `yearlyCompetitionStats` | array | 按报名开始时间归年的完整统计，年份倒序 |
| `participantCount` | int64 | 累计参赛人次，非跨赛事去重人数 |
| `teamCount` | int64 | 累计参赛团队数 |

`yearlyCompetitionStats[]` 字段：

| 字段 | 说明 |
| --- | --- |
| `year` | 自然年 |
| `competitionCount` | 该年度赛事数 |
| `participantCount` | 该年度赛事的当前有效参赛人次 |
| `teamCount` | 该年度赛事的当前有效参赛团队数 |

#### 调用示例

```bash
curl 'https://szc.test.dp.tech/ticsapi/szc/v1/open/competition/list?stage=registering&page=1&pageSize=20'
```

### 3.2 竞赛资源

`GET /szc/v1/open/competition/resource/list`

平台没有“竞赛项目/课题”实体，本接口返回竞赛绑定的公开训练数据集。测试集和评分集不对外暴露。

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `competitionId` | int64 | 是 | 取自竞赛列表的 `competitionId` |

#### 响应 `data`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `competitionId` | int64 | 竞赛 ID |
| `publishUrl` | string | 竞赛发布入口 |
| `detailUrl` | string | 竞赛前端详情页 |
| `datasets` | array | 公开数据集，无数据时为 `[]` |

`datasets[]` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dsId` / `dsPostId` | int64 / string | 数据集 ID/对外混淆 ID |
| `versionId` / `version` | int64 / integer | 版本记录 ID/版本号 |
| `dsName` | string | 数据集名称，上游不可用时可为空 |
| `dsType` / `dsTypeName` | integer / string | 数据集用途；当前对外口径实际恒为训练数据 |
| `envName` | string | 运行环境变量名；当前对外口径恒为空 |
| `downloadUrl` | string | 有效期内的预签名下载地址，不应长期缓存或转存 |
| `updateTime` | datetime | 数据集更新时间 |

```bash
curl 'https://szc.test.dp.tech/ticsapi/szc/v1/open/competition/resource/list?competitionId=1001'
```

### 3.3 成绩榜单

`GET /szc/v1/open/competition/ranking`

返回 A 榜，按得分倒序，同分时提交次数少者优先。提交截止前返回空榜。

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `competitionId` | int64 | 是 | 竞赛 ID |
| `page` | integer | 否 | 默认 1 |
| `pageSize` | integer | 否 | 默认 20，上限 100 |

#### 响应 `data`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `competitionId` | int64 | 竞赛 ID |
| `total` / `page` / `pageSize` | integer | 分页信息 |
| `publishUrl` | string | 竞赛发布入口 |
| `items` | array | 榜单行 |

`items[]` 包含 `rank`、`teamName`、`score`、`institution`、`submissionCount`、`submissionTime`、`awardName`、`members`。`score` 是按赛事精度格式化的字符串；`members[]` 仅含 `userName` 和 `avatar`，不返回联系方式。

```bash
curl 'https://szc.test.dp.tech/ticsapi/szc/v1/open/competition/ranking?competitionId=1001&page=1&pageSize=20'
```

### 3.4 竞赛社区讨论

`GET /szc/v1/open/competition/discussion/list`

仅返回审核通过且未删除的帖子，按置顶、最后回复时间和创建时间倒序。

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `competitionId` | int64 | 是 | 竞赛 ID |
| `partitionId` | integer | 否 | 讨论分区 `1..4`，见枚举 8.1 |
| `page` | integer | 否 | 默认 1 |
| `pageSize` | integer | 否 | 默认 20，上限 100 |

#### 响应 `data`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `competitionId` | int64 | 竞赛 ID |
| `total` / `page` / `pageSize` | integer | 分页信息 |
| `publishUrl` | string | 竞赛发布入口 |
| `items` | array | 讨论帖列表 |

`items[]` 包含 `postId`、`title`、`author`、`lastReplier`、`replyCount`、`likeCount`、`isTop`、`partitionId`、`partitionName`、`createTime`、`lastReplyTime`。`author` 和 `lastReplier` 仅含 `userName`、`avatar`，无回复时 `lastReplier` 和 `lastReplyTime` 为 `null`。

```bash
curl 'https://szc.test.dp.tech/ticsapi/szc/v1/open/competition/discussion/list?competitionId=1001&partitionId=1&page=1&pageSize=20'
```

## 4. 科技交流

### 4.1 活动列表

`GET /szc/v1/open/exchange/activity/list`

一次只查询一类活动，不支持四类混合分页。四类共有字段位于列表项顶层，类型特有字段分别位于 `exchange`、`reasoning`、`live`、`course` 对象中，只有与 `activityType` 匹配的对象非 `null`。

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `activityType` | string | 是 | `exchange` / `reasoning` / `live` / `course` |
| `keyword` | string | 否 | 标题与简介模糊匹配，最长 100 |
| `status` | string | 否 | `upcoming` / `ongoing` / `ended` |
| `timeRange` | string | 否 | `thisWeek` / `thisMonth` / `thisQuarter` |
| `categoryId` | integer | 否 | 仅 `exchange` 生效，取值 1..6 |
| `liveType` | string | 否 | 仅 `live` 生效，见枚举 8.2 |
| `subjectAreaId` | integer | 否 | 仅 `exchange`、`live` 生效，学科领域 1..13 |
| `sortType` | string | 否 | `LATEST` / `HOTTEST`；不传保持原发布时间倒序 |
| `page` | integer | 否 | 默认 1 |
| `pageSize` | integer | 否 | 默认 20，上限 100 |

`HOTTEST` 指标：`exchange` 按浏览量，`reasoning` 按审核通过报名数，`live` 按累计观看人数，`course` 按浏览量。

#### 响应 `data`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `activityType` / `activityTypeName` | string | 请求类型及名称 |
| `total` / `page` / `pageSize` | integer | 分页信息 |
| `items` | array | 活动列表 |
| `stats` | object | 四类活动合计概览，不随类型、筛选和分页变化 |

`items[]` 共有字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `activityType` / `activityTypeName` | string | 活动类型及名称 |
| `activityId` | string | 活动标识；四类 ID 空间相互独立 |
| `title` / `summary` | string | 标题/简介 |
| `coverImageUrl` | string | 封面地址 |
| `startTime` / `endTime` | datetime/null | 开始/结束时间 |
| `status` / `statusName` | string | 统一进度档位及名称 |
| `organizerName` | string | 主办方；课程恒为空 |
| `publishTime` | datetime/null | 发布时间；课程为版本上架时间 |
| `detailUrl` | string | 本平台前端详情地址 |
| `updateTime` | datetime | 最后更新时间 |
| `exchange` / `reasoning` / `live` / `course` | object/null | 互斥的类型特有对象 |

`exchange` 字段：

| 字段 | 说明 |
| --- | --- |
| `categoryId` / `categoryName` | 活动类别及名称 |
| `subjectAreaId` / `subjectAreaName` | 学科领域及名称 |
| `venueAddress` | 举办地点文本，无经纬度 |
| `registrationEndTime` | 报名截止时间，可为 `null` |
| `maxAttendeeCount` | 报名人数上限，0 表示不限 |
| `registeredCount` | 已报名人数 |
| `viewCount` | 累计浏览量 |
| `tags` | 活动标签 |
| `externalSourceUrl` | 外部原活动链接 |
| `isArchived` | 是否已归档 |
| `speakers` | 议程讲者姓名数组 |
| `resources` | 附件数组：`resourceId`、`fileName`、`fileExt`、`fileSize`、`fileUrl` |

`reasoning` 字段：

| 字段 | 说明 |
| --- | --- |
| `category` | 领域分类自由文本 |
| `keywords` | 主题关键词 |
| `maxTopics` | 最终入选话题数上限 |
| `isCaseLibrary` | 是否收入案例库 |
| `registrationCount` | 审核通过的报名人数 |
| `speakers` | 议程讲者姓名 |
| `experts` | 结构化专家数组 |

`reasoning.experts[]` 包含 `expertId`、`userId`、`name`、`role`、`organization`、`department`、`domain`、`researchFields`、`academicLevel`、`avatar`。

`live` 字段：

| 字段 | 说明 |
| --- | --- |
| `liveType` | 直播类型 |
| `subjectAreaId` / `subjectAreaName` | 学科领域及名称 |
| `hostName` / `speakerNames` | 主持人/讲者姓名 |
| `onlineViewers` | 当前在线人数 |
| `joinCount` | 累计观看人数 |
| `danmuCount` / `commentCount` / `likeCount` | 弹幕/评论/点赞数 |
| `reservationCount` | 预约人数 |

`course` 字段：

| 字段 | 说明 |
| --- | --- |
| `lecturers` | 讲师署名数组 |
| `introduction` / `teacherInfo` | 课程介绍/讲师介绍 |
| `courseHour` / `studyHour` | 课时数/预期学习小时数 |
| `difficulty` / `difficultyName` | 难度及名称 |
| `learnerCount` | 学习人数 |
| `viewCount` | 累计浏览量 |
| `isPracticalCourse` | 是否实战课 |

`stats` 字段：

| 字段 | 说明 |
| --- | --- |
| `activityCount` | 四类对外可见活动总数 |
| `yearlyActivityStats` | 按活动开始时间归年的完整统计数组，课程使用开课时间 |
| `participantCount` | 累计参与人次，四类按各自真实指标合计 |
| `organizationCount` | 合作机构数，按主办方名称去重，课程不计入 |
| `expertCount` | 按姓名去重的专家讲者数 |

> 年度数组内的合作机构数和专家数是“每年分别去重”。同一机构或专家跨年出现时，年度值之和可能大于总数。

`yearlyActivityStats[]` 字段：

| 字段 | 说明 |
| --- | --- |
| `year` | 自然年 |
| `activityCount` | 该年度活动数 |
| `participantCount` | 该年度活动的当前累计参与人次 |
| `organizationCount` | 该年度活动的主办方名称去重数 |
| `expertCount` | 该年度思辨绑定专家及交流/思辨议程讲者姓名去重数 |

#### 原“活动规模”替代口径

| 活动类型 | 取值优先级 |
| --- | --- |
| `exchange` | `maxAttendeeCount > 0` 时优先展示人数上限，否则展示 `registeredCount` |
| `reasoning` | `registrationCount` |
| `live` | `joinCount > 0` 时展示参与人数，否则展示 `reservationCount` |
| `course` | `learnerCount` |

```bash
curl 'https://szc.test.dp.tech/ticsapi/szc/v1/open/exchange/activity/list?activityType=exchange&subjectAreaId=8&sortType=HOTTEST&page=1&pageSize=20'
```

### 4.2 资源推荐与专家信息

`GET /szc/v1/open/exchange/recommendation`

不接收活动 ID 和活动类型。资源优先查询对外可见科技交流活动已上传的附件，按所属活动浏览量倒序。专家来自对外可见科技思辨活动关联的、已认证通过的结构化专家档案。

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | integer | 否 | 资源页码，默认 1；仅作用于资源列表 |
| `pageSize` | integer | 否 | 资源每页条数，默认 10，上限 100；仅作用于资源列表 |
| `expertLimit` | integer | 否 | 专家数量，默认 8，上限 100 |

#### 响应 `data`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `resourceTotal` | int64 | 对外可见科技交流活动下的有效资源总数 |
| `page` / `pageSize` | integer | 当前资源页码/每页条数 |
| `resources` | array | 推荐资源 |
| `expertTotal` | int64 | 符合条件的专家总数 |
| `experts` | array | 专家信息 |

`resources[]` 字段：

| 字段 | 说明 |
| --- | --- |
| `resourceId` | 资源标识 |
| `activityId` / `activityTitle` | 所属活动 ID/标题 |
| `fileName` / `fileExt` / `fileSize` / `fileUrl` | 文件名/扩展名/字节数/访问地址 |
| `viewCount` | 所属活动的累计浏览量 |
| `publishTime` | 所属活动发布时间，可为 `null` |
| `detailUrl` | 所属活动详情地址 |

`experts[]` 字段：

| 字段 | 说明 |
| --- | --- |
| `expertId` / `userId` | 专家档案 ID/平台用户 ID |
| `name` | 姓名 |
| `phone` / `email` | 认证申请填写的联系方式/邮箱，可为空 |
| `organization` / `school` / `department` | 机构/院校/院系 |
| `domain` / `professionalField` | 研究领域/专业领域原始文本 |
| `researchFields` | 拆分后的研究方向标签 |
| `academicLevel` / `major` / `timeRange` | 学历/专业/学习或任职时间范围 |
| `mainAchievements` / `academicPapers` | 主要成就/学术论文原始文本 |
| `reviewApprovedAt` | 认证通过时间，可为 `null` |
| `avatar` | 头像地址 |
| `relatedActivityCount` | 关联的对外可见思辨活动数 |
| `viewCount` | 关联活动累计浏览量合计 |

资质证明、审核状态、身份证号、驳回原因和审核轨迹不在本接口中下发。

```bash
curl 'https://szc.test.dp.tech/ticsapi/szc/v1/open/exchange/recommendation?page=1&pageSize=10&expertLimit=8'
```

### 4.3 活动增量同步

`GET /szc/v1/open/exchange/activity/sync`

四类活动需要各自维护一条水位线。记录按 `updateTime` 正序返回；已不可见记录以 `removed` 状态返回。

#### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `activityType` | string | 是 | `exchange` / `reasoning` / `live` / `course` |
| `updatedSince` | string | 否 | 只返回更新时间严格晚于该时刻的记录；支持日期、日期时间、RFC3339 |
| `page` | integer | 否 | 默认 1 |
| `pageSize` | integer | 否 | 默认 20，上限 200 |

#### 响应 `data`

| 字段 | 说明 |
| --- | --- |
| `activityType` / `activityTypeName` | 本次同步类型及名称 |
| `total` / `page` / `pageSize` | 分页信息 |
| `nextUpdatedSince` | 建议下次水位线；本页为空时为 `null` |
| `items` | 变更记录 |

`items[]` 包含 `activityType`、`activityId`、`status`、`title`、`isArchived`、`updateTime`。`status=removed` 时下游应移除对应展示。

```bash
curl 'https://szc.test.dp.tech/ticsapi/szc/v1/open/exchange/activity/sync?activityType=exchange&updatedSince=2026-10-01T00%3A00%3A00%2B08%3A00&page=1&pageSize=100'
```

## 9. 对接注意事项

1. 竞赛的 `competitionId` 用于资源、榜单和讨论接口；`postId` 只用于前端详情路由，两者不可混用。
2. 四类交流活动的 `activityId` 空间彼此独立，使用时必须同时保留 `activityType`。
3. 所有可空时间、专家档案文本和上游资源字段都需容忍 `null` 或空字符串。
4. 增量同步本页无数据时 `nextUpdatedSince=null`，下游应保持上一次水位线，不要清空。
5. 数据集 `downloadUrl` 是有效期内的预签名地址，需要使用时实时获取。
6. 年度统计只聚合具有可用开始时间的活动/赛事，因此年度数组中活动或赛事数之和可能小于总数。
7. 年度参与、机构、专家和参赛数据是当前有效记录按归属年份聚合，不是历史年末快照。
