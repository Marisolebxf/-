2026-11-05，`human:淮政玮` 裁定。

## 放哪里

科技信息展示系统在开发阶段写出的测试用例，一律放本目录：

`agent-delivery/工程过程/04-系统集成/05-展示系统集成/测试用例/{任务ID}.md`

一个任务一份，文件名用任务 ID。开发叶上的单元测试用例、主路径用例、当轮验收用例都算。

每条用例写前置、步骤、预期、实际结果。线上没测到的写成未测。

## 另见

科技政策跟踪 26 个需规二级的合规演示用例和 LOOP 计划不放本目录。用例在 `../合规演示用例/`，计划在 `../编排计划/`。本目录的实测不改写成那些用例的通过记录。

## 不放这里

- 代码仓里的 pytest、JUnit、`*.test.*`、`.mjs` 自检留在对应代码仓。
- 总集交付的 FUNC 用例和测试记录仍按 `agent-delivery/qa-test-case-spec.md`，放 `agent-delivery/qa/test-cases/` 与 `qa/test-records/`。
- 任务交接仍写 `agent-handoffs/{模块}/{任务ID}.md`，并指向本目录的用例文件。用例正文不只留在交接里。
