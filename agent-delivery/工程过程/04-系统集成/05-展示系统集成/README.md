## 二、智树在本维度做什么、不做什么

**做**：

- 按 [scope-baseline.md](../../../scope-baseline.md) 实现本项范围内的功能与对接
- 需求梳理、字段契约、样例对齐、联调与验收

**不做**：

- 不实现对方系统后台
- 不把未接入写成已接入；对方未承诺的数据在页面上用空态
- 不在本夹修改 scope-baseline 的范围
- **菜单在方案里分节，不各开一夹**（规约 §2.5）。五个对接方是本方案内的节，不是平级夹
- 页面施工序可引用展示集成工作计划，但该页**不代替**本项技术方案
- 两边冲突时：未签收的对接子项在页面上用空态，任务可排，**不把对方未承诺的数据写成已接入**
