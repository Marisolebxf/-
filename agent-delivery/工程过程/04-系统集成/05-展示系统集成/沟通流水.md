要点：

- 燕大平台现有能力：Schema 管理、任务调度、人工审核、图谱查询、内置图算法；支持 NGL 语句调用
- **接口能力边界**：当前暂未对外暴露节点删除、修改权限
- 平台适用边界：仅适配中等复杂度场景，数据溯源颗粒度较粗，低于 GDF 平台能力
- 抽取规则：高置信度直接入库、低置信度人工审核；政策抽取需 Python 脚本 + 大模型
- 存储共识：多跳关联查询存图谱，单点少量查询可直接存普通数据库
- 燕大侧将在内网发布数据抽取平台及登录信息供查阅

**燕大待办**：整理汇总业务侧需要的实体类型、关系类型、相关属性需求清单，由业务方（智树）提供。
