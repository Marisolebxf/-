## 二、怎么用本目录

1. **L01 初稿**：`初稿-甲方口径-AD-AI对照-SYSINT-XTEAM-L01.md` —— 按「模块级」给出每个系统 sheet 的 AD–AI 建议值 + 依据出处 + 待补项。各系统负责人把模块级结论落到自己 sheet 的具体功能行（同一模块的多行同值；`/` 齿轮行与纯 UI 行一般 AD=否）。
2. **L02 初稿**：`初稿-内部口径-集成登记-SYSINT-XTEAM-L02.md` —— 智谱内部集成登记 + 对外项移交清单。
3. **给总集的提需包（按模块）**：
   - `总集提需-科技数据资源-接口与数据-SYSINT-XTEAM.md` —— 展示系统科技数据资源（AD=是，AE=数据+接口；AH=D1～D5，AI=R-01～R-24）；字段级明细在 `05-展示系统集成/对接澄清-科技数据资源-字段级.md`。供方未定前经总集协调，不写成已对接。
4. **接口清单真源**：AI 列只写「见腾讯文档《跨系统调用接口清单》+ 登记 ID」；未登记的接口按大威宣贯要求**先在腾讯文档补登记**，xlsx 不展开接口明细。
5. **xlsx 写入纪律**（WPS 特性，务必遵守）：
   - 改前整文件备份一份（复制粘贴，命名加日期后缀）；
   - 禁止用会重写全簿的工具整簿重建；推荐 WPS/Excel 人工粘贴列，或 officecli 单格 set（已验证 outline 可读；写后用 `officecli view ... outline` + 总览 sheet 抽查公式未破坏）;
   - 总览 sheet（公式聚合）**不要修改**；`WpsReserved_CellImgList` sheet 保留不动。
