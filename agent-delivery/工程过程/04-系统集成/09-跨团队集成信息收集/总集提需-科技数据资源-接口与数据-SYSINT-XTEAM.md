## 3. 数据层提需（AH）

请总集要求责任方交付以下**可核对对象**（表或等价主数据；主键跨接口稳定）。我方消费面可经 ETL 写入 ADS/运营表后由 Java 组装四个 dataset，**不要求对端直出前端 JSON**。

| 数据对象 | 对应需规簇 | 关键字段（摘要） | 上线要求（团队临时默认） |
|---|---|---|---|
| D1 资源目录主数据 | 330–336、332、368–373 | `resource_id`、名称、类型、`srs_source`、学科/领域、采集时间、更新频率、关联项目、质量分、标签、体量 | **必须真数** |
| D2 主题库目录 | 335、368–373 | `theme_id`、分类（要素库/领域主题库）、库表数、记录量、存储量、来源、区域、更新频率、表结构（表名/字段/类型/含义/必填） | **必须真数**；表结构禁止用论文专利实体列顶替 |
| D3 接入与归集事实 | 347–363 | 接入任务状态（done/running/pending）、`ingest_method`、渠道、`grain` 时间序列（年/月/周/日）的 added/updated/volume、历史渠道—表名记录、更新周期、异常类型 | **必须真数**（归集量口径 ≠ 久新实体条数） |
| D4 质量问题台账 | 364–367 | 问题类型、级别、状态、渠道、详情、建议 | 无质量源可**空态**；有则真数；分级枚举待甲方 |
| D5 资源调用账 | 343–346、376–399 | 调用主体（机构/用户/应用系统）、主题/资产、接口、时间、次数、结果、供应方部门、需求方、业务应用、可导出明细 | **有则必须真数；无则整窗空态或砍范围（须甲方拍板）** |
| D6（辅）实体存量快照 | 非页面 KPI | 论文/专利/项目按年 COUNT（久新可读） | 可选；只进附加键，**禁止**写入「资源总量」 |

**三套分类枚举**须与责任方对齐（或书面映射）：`srs_source` / `org_activity` / `ingest_method`（定义见字段级澄清表 §0）。

**交付物**：字段字典、≥20 条样例、刷新频率、空态约定；主键与时间字段规范同 `04` 清单「共性约定」。
