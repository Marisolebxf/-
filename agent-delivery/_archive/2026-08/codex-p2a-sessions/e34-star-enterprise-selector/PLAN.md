# PLAN.md

## 当前版本

v1.0

## 目标

纠正 E-34“明星企业介绍”的对象模型：同一未来产业可配置多家明星企业，用户可在名单内切换当前介绍对象；IA、TRACE、USM、Wireframe 对名单、默认企业、切换交互与状态保持一致。

## 非目标

- 不把明星企业名单变成自由企业查询。
- 不在前端计算明星企业排名或 TopN。
- 不开放跨产业混排、任意选企、评分、对比或 CMS 编辑。

## 核心机制

固定运营名单（每产业 0..N 家） + 可搜索明星企业选择器 + 单企业内容详情。切换产业先刷新候选名单，再按 CMS `sort_order` 选中第一家；切换企业只刷新 E-34 详情内容，不改变产业上下文。当前企业写入 URL `enterprise_code`，支持刷新、分享和返回恢复；选择项展示 Logo、企业名称和一句入选标签。

## 工作流

1. 核对原始需求、SRS、会议决策和现有四件套。
2. 已确认选择器形态、默认选中规则、URL 状态和选择项信息。
3. 修订 IA / TRACE / USM / Wireframe，并更新 Q048 的临时默认。
4. 做四件套一致性检查，报告 PDR 就绪度与待审项。

## 输出

- E-34 产品定义四件套修订建议或修订稿。
- 明星企业选择交互与异常状态规则。
- Q048 需补充的名单及默认企业语义。

## 当前风险

- 当前四件套把“固定明星企业表”错误解释为“每产业固定一家”。
- 原始 bid 只要求重点介绍龙头明星企业；选择器形态和默认排序现已作为产品深化决定确认。
- 当前 E-34 四件套存在未提交修改，后续修订必须保留现有有效内容。
