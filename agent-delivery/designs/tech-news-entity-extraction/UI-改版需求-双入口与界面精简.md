# 科技新闻抽取界面改版需求纪要

> **状态**: 需求汇总（待开发落地）  
> **整理日期**: 2026-07-30  
> **范围**: 科技新闻四要素 / 实体扩展抽取的输入方式与复核界面精简  
> **说明**: 远程 `lumen-ui-science-pc` 已移除科技新闻复核页（`2b08f566`）；本文件作为**重新上线或改版时的 UI/交互真源**，不替代 PDR Schema。

---

## 1. 背景

现有/曾上线的科技新闻抽取复核页存在：

- 输入以「粘贴正文」为主，缺少产品化的「网页链接 / 本地文件」双入口；
- 页头与调试信息偏工程化（Java 路径提示、跨服务 Trace、Tempo/Loki 等），干扰业务复核；
- 「填入样例」「刷新历史」等研发辅助按钮不宜作为默认产品能力；
- 实体扩展结果表中的「归一」列对业务复核价值低，应去掉。

---

## 2. 输入方式（必须）

系统抽取入口**仅保留两种**，取消「直接粘贴正文」作为主入口（正文仅可作为解析后的只读预览）：

| 方式 | 说明 | 主操作文案（建议） |
|------|------|-------------------|
| **网页新闻链接** | 用户粘贴 `http(s)://` 科技新闻 URL，后端抓取正文后再抽取 | 抓取并抽取 |
| **本地文件上传** | 用户上传本地文件，后端解析正文后再抽取 | 上传并抽取 |

### 2.1 建议支持的本地格式

`txt` / `md` / `html` / `docx` / `pdf`（与现有 `innov.article.file_io` 能力对齐）。

### 2.2 调用链约束（架构不变）

```text
前端 → Java `/innov/v1/tech-news/**` → Python `/internal/tech-news/**`
```

- 抓取网页、解析文件、抽取算法均在 **Python**；
- Java 仅透传（可增加 `prepare-from-url` / `prepare-from-file` 或等价「解析+抽取」组合接口）；
- 前端**禁止**直连 Python `/internal/*`。

### 2.3 建议交互流程

1. 用户选择「网页抽取」或「本地上传」；
2. 点击主按钮 → 先解析得到 `title/content/source/published_at`（可只读预览）；
3. 再调用四要素 `extract` 或实体扩展 `entity-extract`（抽取模式开关是否保留另定，默认建议实体扩展）；
4. 右侧展示结构化结果；历史列表若保留，用列表内刷新/分页即可，不必单独大按钮。

---

## 3. 界面需删除 / 隐藏的内容

以下元素从**业务复核界面**中移除（开发调试可走独立 debug 面板或仅在 `VITE_DEBUG=true` 时显示，默认关闭）：

| # | 删除项 | 备注 |
|---|--------|------|
| 1 | 文案/标签 **「仅调 Java /innov/v1/tech-news」** | 工程实现提示，非业务信息 |
| 2 | **跨服务同一**相关展示 | 可观测性调试信息，不进默认 UI |
| 3 | **traceId** 展示（如 `c1d84a9ac8990c0132d5d6ad7ac02f52`） | 默认不展示；需要时走运维工具 |
| 4 | **复制**（针对 traceId / 调试信息的复制按钮） | 随调试信息一并去掉 |
| 5 | **Tempo / Loki** 入口或链接 | 观测深链不进业务页 |
| 6 | **填入样例** 按钮 | 研发辅助，产品默认不提供 |
| 7 | **刷新历史** 按钮 | 去掉独立按钮；若保留历史区，可用列表区小刷新或进入页自动加载 |

---

## 4. 实体扩展结果表调整

在「实体扩展」模式下的 **实体表 `entities[]`**：

| 列 | 处理 |
|----|------|
| 类型 `type` | 保留 |
| 名称 `name` | 保留 |
| **归一 `normalized`** | **删除** |
| 置信度 `confidence` | 保留（若产品确认可再议） |
| 证据 `evidence` | 保留 |

四要素事件区（公司 / 时间 / 事项 / 影响 / 证据折叠等）本纪要不强制改版，但页头调试信息仍按 §3 精简。

---

## 5. 验收清单（DoD 草案）

- [ ] 输入区仅有「网页抽取」「本地上传」两种方式，无粘贴正文主入口、无「填入样例」。
- [ ] 网页链接可完成：抓取 → 抽取 → 展示结果（失败有明确业务提示）。
- [ ] 本地文件可完成：上传解析 → 抽取 → 展示结果（不支持格式有提示）。
- [ ] 默认界面不可见：Java 路径标签、跨服务同一、traceId、复制、Tempo、Loki、「刷新历史」独立按钮。
- [ ] 实体表无「归一」列。
- [ ] 仍符合调用链：前端只调 Java，算法只在 Python。

## 7. 非目标（本纪要不覆盖）

- 不在本文冻结产业边界、事件类型等甲方业务口径（仍见客户决策清单 🟡）；
- 不改四要素/实体 Schema 主结构（除 UI 不展示 `normalized`）；
- 不要求本次一并做黄金评测集、纠错回写等质量专项（可另开任务）。
