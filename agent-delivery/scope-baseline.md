### 0.1 实现（报价内、智树交付）

| 块 | 口径（摘自报价表列 C 合并区及文件名） |
|---|---|
| 科技信息展示系统 | 中 / 大 / 小三屏工作量均在表内。完整链路：**态势、政策跟踪、成果展示**。界面+对接（他队 API）：**人才态势、数据资源、知识图谱**。服务全景：**他队做界面，此处只做跳转**。 |
| 专题战略 4 要素 | **企业分析、产业链分析、产业服务机构分析、政策分析**（表内 1 / 2 / 6 / 7；浅底）。含对应深度模型构建（1 / 2 / 6 / 7）及 **7 要素基础指标、产业全要素图谱 API** 等报价行。 |
| 综合分析 | **科技专题战略分析 - 综合智能分析**；算法侧 **产业综合分析模型构建**。 |
| 数据处理中台 | **数据 Mapping 过程实施**。表内写明智树完成：企业机构/科研机构、市场研究、政策。论文 / 项目报告：智树培训 + 产线/Mapping 模板，**实施由具体负责团队**。 |

列 C 注明「需要其他团队提供 API / 只做跳转」的，实现深度以该行原文为准，不擅自做成完整后台。

### 0.2 只分析、不实现（招标或报价表中的周边）

| 块 | 说明 |
|---|---|
| 专题战略其余 3 要素 | **科研机构、技术链、人才深度分析**（表内 3 / 4 / 5，橙色底）及对应深度模型 **3 / 4 / 5**：需求可分析、对接可摸清，**不作为智树实现交付**。 |
| 招标其余系统/模块 | 门户、智库、交流等未进本报价文件名的系统；展示服务全景的他队界面；Mapping 中由他队实施的论文/报告产线。 |
| 报价表划掉且金额为 0 的行 | 如科学技术全景「维护技术图谱…」、技术发展跟踪部分后台（strike + 工作量 0）：不实现。 |

派单 / 编码 / 验收「是否智树做」：**先对报价表，再对招标 MD**。不得用 62 叶子逼智树实现 0.2。

与 Track-L「大屏由联通数智交付」若冲突：报价表含大屏工作量，**以报价表 + PM 书面为准**，本文不擅自改分工。
