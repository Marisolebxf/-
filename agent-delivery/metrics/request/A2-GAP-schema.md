## 列定义（xlsx 表头顺序固定）

沿用半成品前 10 列，后接 A2 差集列：

| # | 列名 | 半成品？ | 说明 |
|---|------|----------|------|
| 1 | 模块 | ✅ | 展示=三级页签簇；专题=战略分析维度或三级 I |
| 2 | 页面 | ✅ | 页面/四级功能名 |
| 3 | 主项 | ✅ | 指标或能力主项 |
| 4 | 子项 | ✅ | 可空 |
| 5 | 指标含义 | ✅ | 一句话 |
| 6 | 建议取值/取值口径 | ✅ | 可写「需确认」 |
| 7 | 取值依据类型 | ✅ | `需求原文明确` / `根据原文归纳` / `需确认` |
| 8 | 调用系统 | ✅ | 半成品已见：深度挖掘算法、科技专题服务系统、基础数据… |
| 9 | 调用模块 | ✅ | 基础指标分析模型 / 深度分析模型 / 产业全要素图谱… |
| 10 | 取数依据 | ✅ | 原文依据说明 |
| 11 | 差集判定 | A2 | 见下枚举 |
| 12 | A1需规ID | A2 | 表1 `requirement_id`；无对应则空 |
| 13 | A1指标叶ID | A2 | A1 `leaf_id` / 指标行；mapped 时必填 |
| 14 | metric_id | A2 | 已有 `M_*`；缺口禁止编造正式 ID |
| 15 | 缺口说明 | A2 | `missing` 必填：功能要了、库未涉及什么 |

### 差集判定（列 11）

| 值 | 含义 | 是否进「库未涉及」主清单 |
|----|------|--------------------------|
| `missing` | 功能/页面要指标或算法结果，算法库未覆盖 | **是**（A2 主产物） |
| `mapped` | 算法库（或 A1 表）已有对应 | 否，只保留对应 |
| `third_party` | 人才/科研机构/技术实现等，库标第三方 | 否（对应第三方，不算我方库缺失） |
| `other_system` | 调用系统不是深度挖掘算法（门户/智库/基础数据/展示自身等） | 否 |
| `n/a_ops` | 运营/CMS/权限/发布，不进算法差集 | 否 |

展示叶：专题已记的 `missing` **不重列**；共有缺口填 `缺口说明` 写 `also_in: TOPIC-GAP-xxx`。

## yaml 形状（与 xlsx 一一对应）

```yaml
version: 1
task: TOPIC-ALGO-GAP-L01   # 或 DS-ALGO-GAP-L01
system: topic              # topic | display
updated: "YYYY-MM-DD"
source_excel_ref: "metrics/request/展示系统页面指标释义清单.xlsx"  # 列模板；专题叶可写 null
items:
  - row_id: TOPIC-ROW-001
    模块: 产业链分析
    页面: 产业链全景图谱
    主项: 产业链结构可视化
    子项: null
    指标含义: "…"
    建议取值/取值口径: "…"
    取值依据类型: 根据原文归纳
    调用系统: 深度挖掘算法
    调用模块: 深度分析模型
    取数依据: "…"
    差集判定: missing
    A1需规ID: null
    A1指标叶ID: null
    metric_id: null
    缺口说明: "算法库无对应叶子/指标"
```

`summary.md` 必含：按模块计数；`差集判定` 五档条数；`missing` 清单条数（主交付数字）。
