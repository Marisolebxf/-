## 1. M_CHAIN_PATENT_COUNT（产业链关联专利数）

### 现稿画像（seed v0.1.0）
- definition：链关联专利去重总数，对象 `dwd.industry_chain_patent` 全量，按 patent_id 去重
- formula：`COUNT(DISTINCT dwd.industry_chain_patent.patent_id)`；algorithm_type STAT；daily；mapping_status **✅**（乐观）
- source_tables：`dwd.industry_chain_patent <- ods: dwd_org_industry_chain_pat_dtl`；无 pending、无 QC 挂载、无 calc_logic_ref
- 矩阵：**NO-MX**；CL：**无**

### 探库实测引用
- `dwd_org_industry_chain_pat_dtl` **不存在**（seed 引用表名失真）
- `dwd_patent` 2,939,895 行可用，但**无链字段**；唯一入链路径 = 申请人名/信用代码 → 企业 → 上链表，而 `enterprise_industry_chain`=**0 行** → **三跳断在最后一跳**

### 建议口径（目标态，含 SQL）
```sql
-- 路径 B（三跳；桥表补数后生效）
SELECT COUNT(DISTINCT p.patent_id)
FROM demo_gkxlumenx_ods.dwd_patent p
JOIN demo_gkxlumenx_ods.dwd_org_industry_tags t      -- 行数待补测（CL 域内在用）
  ON p.first_applicant_name = t.company_name          -- 名配风险高，优先 credit_code 直配路径
WHERE t.industry_code = :industry_code;
-- industry_code → chain_id 经 dwd.industry_chain（43 链）映射，键待值域比对
```
- 申请人匹配建议双路径：`first_applicant_name`（当前申请人）为主、`first_current_assignee_name`（现权利人）为辅——取主取辅是口径点（SZ_PATENT CL 已同时引用两字段）
- 是否限定授权专利（granted_number IS NOT NULL）待拍板；默认全量（申请+授权）

### 风险点与待拍清单
1. **桥断**：上链空（0 行）→ 挂 GAP（建议登记 CHAIN 域缺口 GAP-CHAIN-PATENT-BRIDGE：`dwd_org_industry_tags` 行数补测 + 上链桥补数）
2. 拍板项：申请人 vs 权利人匹配口径；是否仅授权；时间窗（近 N 年 vs 全量）
3. **D1=draft**（挂新 QC 或 GAP；seed 现 ✅ 应降）、**D3=none**（无完整映射路径）、**D4=mock**
4. 改前→改后：`✅ / dwd_org_industry_chain_pat_dtl` → `draft+GAP / dwd_patent×链标签桥（credit_code 直配优先）`；矩阵补行 d1=draft, d3=none, d4=mock

## 9. M_CHAIN_MARKET_GROWTH（市场增长率）

### 现稿画像（v0.2.0）
- definition：链市场规模同比增长率，依赖 MARKET_SIZE 相邻两年结果
- formula：`(M_CHAIN_MARKET_SIZE(y)-M_CHAIN_MARKET_SIZE(y-1))/NULLIF(M_CHAIN_MARKET_SIZE(y-1),0)*100`
- source_tables：`ADS/指标引擎基于 M_CHAIN_MARKET_SIZE`；🔧 QC06；矩阵 NO-MX；CL 无独立稿（老 `M_CHAIN_GROWTH_RATE.md` Q-CHAIN-04 覆盖：chain_market.growth_rate 现成字段版）

### 探库实测引用
- 全部上游依赖同 MARKET_SIZE：上链空 + ENT 表名占位 → 本条当前纯派生不可算
- 隐患：ENT 年报表若两年企业集合不同（新入链/退链/缺报），直接两 SUM 相除会把"样本变化"当"增长"

### 建议口径（补一个同样本口径洞，含 SQL）
```sql
WITH rev AS (
  SELECT r.entity_id AS ent, ar.fiscal_year AS y, ar.operating_revenue AS rev
  FROM <ENT年报表> ar JOIN <链-企业关系表> r ON ar.enterprise_code = r.entity_id
  WHERE r.chain_id = :chain_id AND ar.fiscal_year IN (:y, :y-1))
SELECT ROUND((SUM(CASE WHEN y=:y THEN rev END) - SUM(CASE WHEN y=:y-1 THEN rev END))
       / NULLIF(SUM(CASE WHEN y=:y-1 THEN rev END),0) * 100, 2)
FROM rev
WHERE ent IN (SELECT ent FROM rev GROUP BY ent HAVING COUNT(DISTINCT y)=2);  -- 同样本锁两年
```
- **同样本（locked panel）条款建议写入 definition**：仅计两年均有年报的关联企业；否则派生口径失真

### 风险点与待拍清单
1. 拍板项：同样本锁两年 vs 全样本（建议同样本，全样本会虚高/虚低）
2. y-1 年无任何数据时输出 NULL（不造 0）→ UI 置灰规则随 I2 诚实性约束
3. **D1=draft（随 QC06 + 同样本口径）**、**D3=none**（派生链路未通）、**D4=mock**
4. 改前→改后：`v0.2.0 全样本两 SUM` → `v0.2.1 同样本锁两年 + NULL 语义入 definition`
