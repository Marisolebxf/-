## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标属于「产业链—服务机构图谱」模块的布局视图，回答：**给定一个区域和一个产业，服务机构在空间上如何分布、在行业上如何聚集、在服务链条上处于哪一段**。输出形态为「区域 × 行业 × 服务类型/环节」的三轴交叉表，供产业地图、招商图谱、区域对比三类前端页面消费。

### 1.2 为什么需要这个指标

- 区域产业规划需要知道本地服务供给集中在哪些门类、是否与本地主导产业匹配；
- 招商与补链需要识别「有产业无服务」的空格子（例如某市某门类机构数为 0 或极少）；
- 服务机构自身的选址与分支布局需要城市层与区县层的密度参照；
- 与 `M_SVC_GRAPH_DENSITY`、`M_SVC_GRAPH_CENTRALITY` 联动，可解释「密度高但中心性低」这类结构失衡。

### 1.3 需求文档是否给出定义方法

需求原文只给出「按区域、行业统计服务机构分布，输出布局表」这一层描述，未规定：

- 区域粒度（国家 / 省 / 市 / 区）；
- 行业分类标准（国民经济门类 / 中类 / 自定义产业链环节）；
- 集中度的度量方式（HHI / CRn / 熵）；
- 服务机构池的纳入规则（是否含个体工商户、是否含分支）。

本件按「可实测优先」原则自行补齐：区域用工商注册省/市/区三级，行业用 `dwd_org_base_info.ind` 的国民经济行业门类，集中度同时给 HHI、CR3、香农熵三套指标，池规则沿用同批十件统一的 `M_SVC_*` 池定义。

### 1.4 指标口径与维度拆解

| 维度 | 字段 | 粒度 | 覆盖率 | 本件用法 |
|---|---|---|---|---|
| 地理—省 | `prov` | 省级 | 99.95% | 仅作覆盖性说明（全为广东） |
| 地理—市 | `city` | 地级市 | 99.95% | 主布局轴，算份额、CR3、HHI |
| 地理—区 | `area` | 区县 | 90.17% | 次级布局轴，TOP10 区 |
| 产业—门类 | `ind` | 国民经济门类 | 99.88% | 主产业轴，算份额、HHI、熵 |
| 产业—中类 | 无 | — | 0% | 缺口，见 §四 |
| 服务—类型 | `svc_type`（派生） | 7 类 | 100%（含 UNCLASSIFIED） | 分类型看行业结构 |
| 服务—环节 | `svc_stage`（派生，多标签） | 6 类 | 100%（含未标注） | 分环节看城市混合 |

其中 `svc_type` 与 `svc_stage` 为派生标签，派生规则与同批 `M_SVC_DEEP_*` 保持一致：服务类型由 `main_activities` 关键词命中，服务环节由业务标签映射，允许一家机构命中多个环节，故环节占比之和 > 100%（69.70 + 1.76 + 31.43 + 0.02 + 10.27 + 24.24 = 137.42%），这是多标签设计的预期结果，不是错误。

### 1.5 与同域姊妹指标的分工

| 指标 | 回答的问题 | 与本件关系 |
|---|---|---|
| `M_SVC_INDUSTRY_LAYOUT`（本件） | 服务机构在哪儿、属于哪个行业 | 布局底座 |
| `M_SVC_GRAPH_DENSITY` | 机构之间的连接有多密 | 用本件的城市/行业分组做分层密度 |
| `M_SVC_GRAPH_CENTRALITY` | 谁在网络中心 | 本件提供节点属性（城市、行业） |
| `M_SVC_GRAPH_INFLUENCE` | 影响力沿链路如何衰减 | 本件提供链路两端的地理归属 |
| `M_SVC_DEEP_178_1` ~ `181_1` | 单机构的深度画像 | 本件是其聚合视图 |

本件不重复计算网络结构量，只做「属性分布」，避免与图谱三件口径打架。

### 1.6 本件的边界与不做什么

- 不做机构级评分，只做分布统计；
- 不做跨市分支归并（`subsidiary_edges` 目标端多不在池内，归并会引入选择偏差）；
- 不把「注册区」当作「实际经营地」，正文所有地理结论均标注为工商注册口径；
- 不对 `stage-pilot` 出结论（样本 8 家）；
- 不输出国家层布局（无字段，见 §四）。

## 二、计算过程

### 2.1 数据源与机构级截面

主表：`gkx.dwd_org_base_info`（189,116 行，机构主档），取 `org_id / name / prov / city / area / ind / inc_year / status`。
辅表：`gkx.dwd_org_org_product_info`（45,011 行，机构—产品/服务关系），取 `org_id / main_activities`，用于派生服务类型与服务环节。

池定义（与同批十件一致）：

```text
pool = SELECT DISTINCT org_id
       FROM gkx.dwd_org_org_product_info
       WHERE main_activities IS NOT NULL AND main_activities <> ''
```

得到 44,153 家。所有占比的分母统一为 44,153，**不用「该字段非空样本数」作分母**。这一点是 v5 铁律之一：换分母会让「缺字段」被悄悄转成「高份额」，例如区县覆盖只有 90.17%，若用 39,811 作分母，南山占比会从 16.01% 抬到 17.75%，虚增 1.74 个百分点。

### 2.2 地理布局：份额、CR3、HHI

城市份额：

$$s_c = \frac{n_c}{N},\quad N = 44153$$

城市层 HHI：

$$HHI_{city} = \sum_c s_c^2 = 0.4288$$

CR3：

$$CR3 = s_{深圳} + s_{广州} + s_{东莞} = 0.5797 + 0.2863 + 0.0974 = 0.9634$$

实测城市分布（`out.json → geo.city`）：

|---|---:|---:|---:|
| 深圳市 | 25,597 | 57.97% | 57.97% |
| 广州市 | 12,641 | 28.63% | 86.60% |
| 东莞市 | 4,300 | 9.74% | 96.34% |
| 惠州市 | 1,594 | 3.61% | 99.95% |
| （空） | 21 | 0.05% | 100.00% |

### 2.3 产业布局：门类份额、HHI、香农熵

$$
HHI_{ind} = \sum_i s_i^2 = 0.1741,\qquad
H_{ind} = -\sum_i s_i \ln s_i = 2.037
$$

最大熵 $\ln 19 = 2.944$，相对熵 $2.037 / 2.944 = 0.692$，即行业分布已达到最大分散度的 69.2%，属中度分散。

### 2.4 城市 × 行业格子

格子计数 $n_{c,i}$，只保留 $n_{c,i} \ge 30$ 的格子，共 **48 个**。两个份额口径：

$$
share\_in\_city = \frac{n_{c,i}}{\sum_i n_{c,i}},\qquad
share\_in\_ind = \frac{n_{c,i}}{\sum_c n_{c,i}}
$$

前者回答「这个行业占该市多少」，后者回答「这个市占该行业多少」。TOP20 格子（`out.json → layout_cells.top20`）：

| 城市 | 行业 | 机构数 | 占本市 | 占本行业 |
|---|---|---|---:|---:|
| 深圳市 | 制造业 | 6,680 | 26.10% | 50.88% |

### 4.3 降档论证（为什么不是更高一档）

要升到「完全支持」，必须同时满足：全球轴可算、产业维到中类、区县覆盖 ≥ 95%。当前三项均不满足：

- 全球轴：0 字段，覆盖率 0%；
- 中类：0 字段；
- 区县：90.17% < 95%。

因此不能定「完全支持」。也不降到「弱支持」，因为主体维度（市、门类）覆盖率均 ≥ 99.88%，主结论（单核结构、产业耦合）稳定可复现，故「部分支持」是唯一合规档位。

## 五、王惠方法对照与选用建议

王惠方法在本指标上的核心主张是「先按行政层级做完全分层，再在层内做集中度」。本件采纳分层思路，但对「全球层」做了删减：

| 方法要点 | 王惠原法 | 本件做法 | 差异原因 |
|---|---|---|---|
| 分层 | 国家→省→市→区 | 省→市→区 | 无国家字段 |
| 集中度 | HHI + CR4 | HHI + CR3 + 熵 | CR3 更贴合四城实际 |
| 产业分类 | 中类为主 | 门类 | 无中类字段 |
| 池规则 | 全量法人 | 有服务标签的机构 | 与同批十件对齐 |
