## 口径定义

根据深圳在服务机构数量、技术力得分、服务链完整度三个对比维度的表现，分别对每个维度进行独立梯队划分。每个维度均将参与对比的城市按指标值从高到低排序，排名前30%的城市划为第一梯队，中间40%划为第二梯队，后30%划为第三梯队。梯队越高，表明深圳在该维度的服务链能力越强。

## 计算逻辑说明

一、服务机构数量

直接统计深圳产业相关的“科学研究和技术服务业”法人单位数。以《国民经济行业分类》（GB/T 4754）为标准，筛选门类 M（科学研究和技术服务业，代码 73、74、75）中与目标产业相关的法人单位，进行去重计数。

二、服务链完整度

将服务链划分为四个核心环节，统计该产业在深圳已覆盖的环节数量。
$$
服务链完整度 = \frac{已覆盖的服务链关键环节数}{4} \times 100\%
$$
环节定义

| 环节     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 研发创新 | 区域内是否有从事基础研究、应用研究、技术开发等相关机构       |
| 成果转化 | 区域内是否有技术转移、中试熟化、知识产权服务等机构           |
| 企业孵化 | 区域内是否有孵化器、加速器、众创空间等机构                   |
| 产业加速 | 区域内是否有产业基金、上市辅导、市场拓展等服务               |
| 判定标准 | 某环节在目标产业对应服务链中存在 ≥ 1 个机构或相关服务能力，则判定为“已覆盖”。 |

三、技术力得分

技术力得分由研发投入强度、研发人才结构、创新产出三个子指标加权合成。

第一步：各子指标标准化

各子指标通过极值归一化法转换为 0—100 之间的标准化得分：
$$
子指标得分_{ij} = \frac{x_{ij} - \min(x_j)}{\max(x_j) - \min(x_j)} \times 100
$$

$$
其中，x_{ij} 为城市 i在第 j 个子指标上的原始值，\min(x_j) 和 \max(x_j) 分别为该子指标在所有对比城市中的最小值和最大值。
$$

第二步：技术力综合得分

三个子指标采用等权重（各占 1/3）加权汇总：
$$
技术力得分 = \frac{研发投入强度得分 + 研发人才结构得分 + 创新产出得分}{3}
$$
四、横向对比与梯队分档

对比城市：深圳、北京、上海、广州及其他省会城市。

对比指标：服务机构数量、技术力得分、服务链完整度。

数据口径：

| 对比项       | 数据口径                                                 |
| :----------- | :------------------------------------------------------- |
| **深圳数据** | 深圳对应产业的计算值                                     |
| **全国平均** | 全国所有城市对应产业指标值的算术平均值                   |
| **一线城市** | 北京、上海、广州、深圳各城市对应产业指标值分别计算后对比 |

梯队分档：在每个维度上分别对参与对比的城市进行排序和分档，划分标准如下：

| 梯队         | 划分标准          |
| :----------- | :---------------- |
| **第一梯队** | 排名前30%的城市   |
