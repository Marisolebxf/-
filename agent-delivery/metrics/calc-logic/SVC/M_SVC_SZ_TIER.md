## 口径定义

「深圳梯队位置」不是单一数字，而是「服务机构数量 / 技术力得分 / 服务链完整度」三维各自按 30/40/30 排名分档。三维里只有「服务机构数量」在池内可数（深圳 25,597），但排名需要与北京、上海、其他省会城市同口径比较，而池 100% 落广东、外省 0 家；技术力三维子指标里两个的分子列整列为空；完整度公式未签且无环节成员表。三维无法在同一城市集合上闭合，故判 **部分支持**，不产出任何梯队名次。

## 数据支持度与缺口

- **判档**：部分支持
- **判档理由**：三个维度里只有「服务机构数量」在池内可算（深圳 25,597），但梯队分档要求与全国城市同口径排序，而 gkx 服务机构池 100% 落在广东省、池外城市 0 家，无法构成全国对比集合；「技术力」三子指标有两个的分子列整列为空（研发投入/研发人员），只有专利代理可算；「服务链完整度」公式未签且无机构×环节成员表，六站代理在 12 个产业上恒为 5/6、无区分度。三维均无法在同一城市集合上闭合，故判部分支持，不产出梯队名次。
- **基期声明**：本件是截面排序（当期三维取值），不使用基期年份；技术力三子指标本应取同一会计年，但研发两列的分子整列为空、营收/员工最新有值年集中在 2014—2016（见 annual_report），年份无法对齐，这也是该维不可算的原因之一。
