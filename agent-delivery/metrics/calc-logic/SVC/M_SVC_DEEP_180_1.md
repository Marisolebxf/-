## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标面向「招商引机构」场景：对深圳市外（含省内其他市与省外）的服务机构打分，回答「先引谁、引来做哪条链、能跟深圳谁连上」。输出为 0—100 分与四档建议，供招商名单、产业补链、政策匹配三个页面消费。

### 1.2 为什么需要这个指标

- 深圳服务业供给虽大，但集成电路、合成生物、低空经济等链仍有缺口，需要定向引进；
- 招商不能只看企业规模，要看「与深圳产业链的互补度」和「落地后能否接上本地网络」；
- 政策资源有限，需要把「政策匹配度高」的机构排在前面，避免引进来却无政策可给；
- 与 `M_SVC_DEEP_181_1`（培育）形成「外引 / 内育」闭环。

### 1.3 需求文档是否给出定义方法

需求给出四维名称与等权原则，未给：

- 「竞争力」用研发投入还是产出；
- 「产业相关度」的产业词典；
- 「政策匹配」的匹配对象（政策文本 / 政策库 / 命中表）；
- 「深圳连接度」的分母。

口径说明：本件维度键名 `policy_match` 与历史 `demo_*` 造数表同名，但本件只读 gkx `dwd_policy_base` 标题，不含任何造数、演示值。

本件逐项落地：竞争力用专利产出 + 发明占比（因研发两列空挂）、产业相关度用深圳 20+8 十二个重点产业词典、政策匹配用 20,000 条政策标题关键词、连接度用「深圳对端边 / 已知对端边」并加样本量置信因子。

### 2.2 D1 竞争力：产出侧代理

理想公式：

$$comp_i = w_1 \cdot \text{RD强度}_i + w_2 \cdot \text{研发人员占比}_i$$

实测年报 `dwd_org_annual_financial_info` 无研发投入、无研发人员两列（全表 0 行非空），无法计算。改用产出侧：

$$comp_i = 0.6 \times \widetilde{patent}_i + 0.4 \times \widetilde{invshare}_i$$

- `patent` 为第一申请人名称精确对齐的专利总数，9,995 家；
- `invshare` 为发明占比，只对 9,995 家有专利的机构有值；
- 权重 0.6/0.4 沿用旧稿，体现「数量为主、质量为辅」。

该代理的三个偏差必须写明：专利多不等于研发投入高（华为型 vs 代工型）；无专利的机构不是无研发（软件、咨询类天然少专利）；发明占比对小型机构波动大。

### 2.3 D2 产业相关度：契合度

目标产业词典 T 为深圳 20+8 中的 12 个：

```text
T = [软件与信息服务, 智能终端, 人工智能, 具身智能, 机器人, 集成电路,
     数字创意, 传感器, 合成生物, 智能网联汽车, 生物医药, 低空经济]
```

$$fit_i = \frac{|K_i \cap T|}{|T|},\qquad |T| = 12$$

7,139 家有标签，链内机构 18,512 家。取值 0—1，步长 1/12 = 0.0833。无标签机构该维缺失，不补 0。

### 2.4 D3 政策匹配度：标题关键词

政策库 20,000 条，按产业关键词命中计数：

$$pols_i = \frac{\sum_{t \in K_i} cnt_t}{|K_i| \times pol\_max},\qquad pol\_max = 190$$

政策供给（`out.json → policy_supply.by_industry_all`）：

| 产业 | 全国条数 | 深圳条数 |
|---|---:|---:|
| 生物医药 | 190 | 4 |
| 软件与信息服务 | 142 | 10 |
| 智能网联汽车 | 94 | 2 |
| 集成电路 | 49 | 3 |
| 人工智能 | 27 | 3 |
| 机器人 | 19 | 6 |
| 数字创意 | 18 | 0 |
| 智能终端 | 8 | 0 |
| 传感器 | 3 | 0 |
| 合成生物 | 2 | 0 |

深圳政策单列统计：标题含「深圳」或 `city=深圳市` 共 **651** 条，另有 `city` 字段为深圳的 **879** 条。生物医药全国 190 条、深圳仅 4 条，政策密度与产业规模明显不匹配，这是招商时「引进来但无政策可给」的风险点。

### 2.5 D4 深圳连接度：比值 × 置信因子

纯比值：

$$conn\_raw_i = \frac{sz\_neighbors_i}{known\_neighbors_i}$$

问题：只有 1 个对端且恰好是深圳的机构会拿 1.0，实测前五名全是这类单边机构（`sensitivity_conn_raw.top5`：东莞领杰、广州天健兴业、广东普门、广东粤安、汇川东莞，`conn_raw` 均为 1.0，已知对端仅 1—4 个）。

修正：

$$conn_i = conn\_raw_i \times \min\left(1, \frac{\log(1+total_i)}{\log(1+20)}\right)$$

置信因子在 total=20 时达 1，低于 20 递减。这样保留「深圳占比」语义，同时惩罚样本过少。

对端可见性：30,219 个投资对端中只有 **8,820** 个有城市，其余对端不在池或无城市字段，故连接度是下界，不是真实客户占比。

### 3.3 口径陷阱与规避

1. **研发代理**：专利数≠研发投入，正文不使用「研发强度」措辞，统一写「竞争力（产出侧代理）」。
2. **政策近似**：标题关键词只能测「政策文本提到该产业」，不能测「该机构符合申报条件」，故政策维是近似，不是资格。
3. **连接下界**：对端城市仅 8,820/30,219 可见，连接度系统性偏低，不能跨城市比较绝对值。
4. **高校混池**：华南理工等高校落入外部池，业务侧应加 `ptype2` 或名称过滤。
5. **阈值不适配**：70 分档在外部池为空，正文如实报告，不调阈值凑档。

## 四、数据缺失情况

### 4.1 缺口清单

| 编号 | 缺口 | 影响 | 严重度 | 修复路径 |
|---|---|---|---|---|
| G1 | 年报无研发投入/研发人员 | 竞争力只能产出侧代理 | 高 | 接科技年报/高企认定 |

|---|---|---|

| P0 | 政策命中表建设 | 中 |
| P1 | 对端机构主档补全 | 中 |
| P2 | 池过滤规则（高校/事业单位） | 低 |

### 4.3 降档论证（为什么不是更高一档）

「完全转换支持」要求四维均可转换且语义可接受。本件 D1 是产出侧代理（研发投入不可得）、D3 是标题近似（命中表不可得）、D4 是下界（对端不可见），三处都不是「转换」而是「替代」。若判完全支持，等于承认「专利数=研发投入」「标题命中=政策资格」，与事实不符。

不降「完全不支持」：四维均有非空输入，合成可区分机构，OPPO/豪鹏/赢合的排序符合「深圳周边、有专利、有资本连接」的招商直觉，主结论成立。

### 4.4 缺口对下游的影响

- 招商名单页不能写「研发强度」，应写「创新能力（专利代理）」；
- 政策匹配列不能作为申报资格，只能作「政策关注度」参考；
- 连接度不能跨城市比绝对值，只能同城市内排序；
- 「优先引入」档为空，前端需隐藏该标签或改文案。
