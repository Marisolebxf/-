## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标面向「育机构」场景：对深圳本地服务机构打分，回答「重点扶谁、怎么扶（升规 / 上市 / 技术升级 / 稳存量）」。输出 0—100 分、四档梯度与一句培育建议，供培育名单、政策兑现、服务机构成长档案三个页面消费。

### 1.2 为什么需要这个指标

- 深圳服务业机构 25,597 家，政策资源无法平均覆盖，需要排序；
- 「引进来」之后要「育起来」，与 `M_SVC_DEEP_180_1` 形成闭环；
- 培育手段要分型：高成长小机构适合升规、技术强但增长平的适合稳存量、双高的适合上市；
- 需要可解释的分维证据，避免「拍脑袋定名单」。

### 1.3 需求文档是否给出定义方法

需求给出四维名称与等权原则，未给：

- 发展潜力用营收还是净利、用同比还是 CAGR；
- 负值年份如何处理；
- 培育建议的判定规则；
- 财务缺失机构是否入排序。

口径说明：本件维度键名 `policy_match` 与历史 `demo_*` 造数表同名，但只读 gkx 政策标题，不含任何造数、演示值。

本件落地：潜力用「最近两个正值年」的 CAGR（营收、净利各一，取可用者平均），负值年跳过不补 0；建议按竞争力/潜力相对位给四类；财务缺失不补 0，维数 <2 不入排序。

### 2.2 D1 竞争力：产出侧代理

年报无研发投入、无研发人员两列（全表 0 行非空），公式改为：

$$comp_i = 0.6 \times \widetilde{patent}_i + 0.4 \times \widetilde{invshare}_i$$

覆盖 13,378 家（52.26%）。偏差同 180：专利多≠研发强；无专利的软件/咨询机构被系统性低估；发明占比对小样本波动大。

### 2.3 D2 产业相关度

$$fit_i = \frac{|K_i \cap T|}{12},\qquad T = \text{深圳 20+8 中 12 个重点产业}$$

覆盖 10,778 家（42.11%），无标签机构该维缺失。取值为 0、1/12、2/12 … 1。

### 2.4 D3 政策匹配度

$$pols_i = \frac{\sum_{t \in K_i} cnt_t}{|K_i| \times 190}$$

190 是生物医药的全国政策条数（最大），用作归一上限。覆盖 10,778 家。深圳本地政策条数明显偏少（生物医药 4 条、软件 10 条、智能网联 2 条），因此深圳机构的政策匹配分普遍偏低，这是政策供给问题，不是机构问题。

### 2.5 D4 发展潜力：CAGR 的四个硬约束

```text
pts = [(y, v) for y, v in series if v is not None and v > 0]
if len(pts) < 2: return None
(y1,v1),(y2,v2) = pts[-2], pts[-1]
g = (v2/v1)^(1/(y2-y1)) - 1
g = clip(g, -0.95, 3.0)
```

四个约束必须写明：

1. **只取正值年**：负营收无经济意义，负利润年跳过，避免 `(-100 → 100)` 这类假增长；
2. **最近两个正值年**：不要求连续，允许中间缺年，折年用 `y2-y1` 实际间隔；
3. **上下截断**：下限 -95%（避免 -100% 除零），上限 +300%（触顶值，双禹王净利 CAGR 即 3.0）；
4. **营收与净利各算，取可用者平均**：只有营收算营收，只有净利算净利，两者都有取平均。

覆盖：营收 CAGR **161 家**、净利 CAGR **127 家**、有任何财务 **673 家**。发展潜力维只在这 161/127 家上成立，占池 0.63% / 0.50%。

### 2.8 结果解读与敏感性

- **榜首 70.80 靠潜力维单点拉满**：营收 CAGR 193.72%、净利 CAGR 触顶 300%，但专利 59 件、竞争力 0.5506，属「小体量高增速」，建议「小升规」符合规则；
- **华为 66.20 排第二**：竞争力 1.0、产业相关 0.75、政策 0.2361，无财务数据（发展潜力缺失），三维平均 0.662；
- **第 5 中盟科技 60.06 只有两维：产业 1.0 + 政策 0.2012**，平均 0.6006，说明「标签全中」即可进前五，产业维权重实际偏高；
- **第 6 爱车屋营收 CAGR -39.75% 仍排第 6**：净利 CAGR 触顶 300% 抵消了营收下滑，这是「取可用者平均」的副作用，业务侧应加「营收负增长一票否决」；
- **前十五有 7 家「常规跟踪」**：分维证据不足，只靠一维高分入榜，建议列不可直接用于政策兑现。

敏感性：若把净利 CAGR 上限从 300% 降到 100%，榜首双禹王分数从 70.80 降到约 62，仍第一但掉出「优先培育」；若营收负增长直接否决，爱车屋掉出前十五。两条规则都建议在正式化时由甲方确认。

### 3.3 口径陷阱与规避

3. **财务覆盖 2.63%**：发展潜力维对 97% 机构不可用，不能把「无财报」当「无潜力」。
4. **政策供给偏差**：深圳政策条数少，政策维整体偏低，不能跨城市比较。
5. **单维入榜**：维数 ≥2 即可入榜，出现「产业 1.0 + 政策 0.2」进前五，业务侧需加证据条数门槛。

### 4.3 降档论证（为什么不是更高一档）

「完全转换支持」要求四维均可转换且覆盖支撑全池。本件 D4 只有 161/127 家可算（0.63%/0.50%），D1 是产出侧代理，D3 是标题近似。发展潜力是培育模型的第二核心维，覆盖不足 1% 不能称「完全支持」。

不降「完全不支持」：D1/D2/D3 覆盖 42%—52%，合成可区分机构，双禹王/华为/磊鑫的排序与建议符合业务直觉，主结论成立。

### 4.4 缺口对下游的影响

- 培育名单页必须标注「潜力维仅 161 家可算」，其余机构只展示三维；
- 「优上市」「小升规」建议只能对有财务数据的机构给，无财报机构一律「常规跟踪」；
- 政策兑现不能用本分数做唯一门槛，需叠加认定状态；
- 与 180 的横向比较只能比排序相关性。
