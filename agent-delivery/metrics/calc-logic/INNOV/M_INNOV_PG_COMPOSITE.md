在北京市、上海市、深圳市、广州市这四城里，深圳以 **63.4377** 分排第一，北京 **55.6498**、上海 **43.7593**、广州 **8.0386**。

## 摘要

「政策与条件保障力综合评估」是需求里唯一一条**口径写全了**的指标：五维——发展战略引导力（前瞻性/系统性/针对性）、政策扶持力度（数量/类型/覆盖面）、经费支持（科研经费/产业基金）、项目支持（数量/金额/效果）、政策实施效果（实施前后对比）。`calc-logic` 有正本，逐叶给了公式与源字段，连"与 POLICY_GUARD_001 同一套覆盖率"都写清了。

写全了，不等于能算。本件先逐叶去 gkx 实测，结果是：**15 片叶子里只有 5 片能算**。

- 引导力 3 叶 → 只剩 1 叶。`quote_policy` 20,000 行里 19,998 行是字符串 `'NULL'`（系统性恒 0）；`policy_support` 是 JSON 列且整列为 JSON null（针对性恒 0）；前瞻性可算，但 `theme`/`keywords`/`keypoints` 三列也全是字符串 `'NULL'`，所谓"四字段命中"**退化为标题单字段**。
- 扶持力度 3 叶 → 剩 2 叶。数量与类型可算；覆盖面要 `COUNT(DISTINCT district)`，而 `district` 18,835/20,000 是 `'NULL'`，剩下的 1,165 行分布极偏，不能当覆盖面。
- 经费 2 叶 → 剩 1 叶。产业基金 `reg_region` 能解析到市；科研经费只有深圳 559 家、广州 204 家、东莞 88 家、惠州 25 家上市主体有研发投入，北京、上海**一家都没有**。
- 项目 3 叶 → **0 叶**。`funded_province` 与 `funded_institution` 全表都是字符串 `'None'`（58,453 行），项目无法归城。整维置 `null`。
- 效果 2 叶 → 剩 1 叶。中文论文可做近三年 vs 前五年；专利侧因 2017—2020 零行，做不了"实施前后"。

所以本件的合成是**四维、五叶、权重和 0.85**。这不是"我们选择只用四维"，是第五维在数据上没有落点。产物 `missing_policy` 把 `dims_used` / `gap_dims` / `weight_used_sum` / `renormalized` 全部落盘，禁止只报一个分数。

结果：深圳 63.4377、北京 55.6498、上海 43.7593、广州 8.0386。深圳的第一名有两个"人工"成分必须点明：其一，北京、上海在经费维上因为**没有数据**而拿 0 分（归一后 0），不是"经费少"；其二，深圳的效果维 +40.1869% 是在**论文语料**上算的，而 2024 年是回填孤峰（32,379 篇 = 全表 32.09%），本件刻意把窗口锁在 2021—2023 与 2016—2020，**不碰 2024**。

还有三个数字必须一起读。第一，政策表 `COUNT(*)` 恰好 **20,000** 整，而 `information_schema` 估算 18,808——这是导出时按 20,000 行截断的痕迹，所有"政策件数"只能当**抽样计数**，不能当全市政策总量。第二，城市字段缺 **48.53%**（9,706/20,000），东莞只有 8 件、惠州 0 件，所以四城不是"挑出来的"，是"有城市归属的只剩这四个"。第三，论文侧 2024 年是回填孤峰：深圳 3,245、北京 5,142、上海 1,963、广州 5,325 篇，是各自 2023 年的 3.6—5.2 倍，四市同步——所以效果维的窗口锁在 2021—2023 与 2016—2020，**不碰 2024**。

### 1.2 为什么需要这个指标

第一个用途是**把"政策好不好"从叙述变成可比的数**。用户点两个城市，看到 63 与 55，而不是两段政策总结。

第二个用途是**支撑"权重可自定义"这个产品承诺**。需求原文写"用户可自定义指标权重，系统根据权重计算综合得分"，这意味着底层必须把**叶级读数**交出来，而不是只交总分。本件产物给了 5 片叶的原始值与归一值，前端换权重可直接重算。

第三个用途是**暴露"保障力"的真实短板**。四城里广州 8.0386，不是因为广州没政策（325 件），而是因为它在引导力（前瞻性 3.3846%）、经费（基金 398 只但研发投入只覆盖 204 家）、效果（+14.0091%）三头都不高。这个分解比一个总分有用。

### 1.3 需求文档是否给出定义方法

给了，而且很细。正本逐叶写了公式：前瞻性 = 四字段含「规划/纲要/远景」的政策数 ÷ 政策总数；系统性 = `quote_policy` 非空且不为空数组 ÷ 总数；针对性 = `policy_support.support_way` 至少 1 条非空 ÷ 总数；覆盖面 = `COUNT(DISTINCT district)`，全空则退 `COUNT(DISTINCT theme)`；效果 = (近 3 年均值 − 前 5 年均值) / max(前 5 年均值, 1)。

正本也写了 `is_mock: true`、`mapping_status: ⏳`、`pending_ref: Q-MO-DS07-01`——即"公式有了，权重未签、数据未验"。本件的工作就是**验证这四个"未"**，并把验证结果原样落到产物里。

三个未定项：其一，五维权重（Q-MO-DS07-01 未答）；其二，"近 3 年/前 5 年"的锚点年份（本件锚到 2021—2023 与 2016—2020）；其三，城市入集门槛（本件取"政策件数 ≥300 且有城市归属"，结果恰好是四城）。

### 1.4 类似指标权威机构构建方法可行性

| 方法族 | 代表机构/实践 | 核心构架 | 与本指标贴合度 |
|---|---|---|---|
| A 政策文本计量 | 各地社科院政策量化研究 | 政策数量、类型、发文层级、关键词 | **本件采用（引导力+扶持）** |
| B 创新指数 | 中国创新指数（CNII）、欧盟 EIS | 制度、人力、投入、产出多维合成 | 中（本库无制度调查数据） |

### 1.6 推测原意与推测定义

推测原意：**给一个城市"政策环境够不够支撑创新"的综合分，并且允许用户改权重**。分要能拆到叶，否则改权重没有意义。

推测定义（本件采用）：四维（引导力/扶持力度/经费/效果）× 五叶（前瞻性、政策类型数、政策件数、产业基金数、论文增幅），叶级在四城同盘 min-max 到 0—100，按 0.20/0.25/0.25/0.15 加权后除以 `weight_used_sum` 0.85 得总分。项目维整维 `null`，不补 0、不重归一。

### 2.4 步骤 3｜五叶构造与判死

| 叶 | 正本公式 | 实测 | 处置 |
|---|---|---|---|
| L1 前瞻性 | 四字段含规划/纲要/远景 ÷ 总数 | `theme`/`keywords`/`keypoints` 全 `'NULL'` → 退化为 title 单字段 | **可算**（声明退化） |

| — 针对性 | `policy_support.support_way` 非空 ÷ 总数 | 20,000 全 JSON null | 判死（0 件） |
| L2 类型数 | `COUNT(DISTINCT type)` | 11/11/11/10 | **可算**（近退化） |
| L3 件数 | `COUNT(DISTINCT id)` | 2,268/1,841/879/325 | **可算**（抽样计数） |
| — 覆盖面 | `COUNT(DISTINCT district)` | 18,835/20,000 为 `'NULL'` | 判死 |
| L4 产业基金 | `COUNT(DISTINCT industrial_fund_id)` | 609/298/576/398 | **可算** |

L2 的"近退化"要说清：11、11、11、10，四城里三个同值。min-max 后北京/上海/深圳都是 100，广州 0——这一叶实际上只区分"广州 vs 其他"，对前三名的次序毫无贡献。产物 `leaves.L2_type_cover.degenerate` 记的是 `max==min`（false），但真实退化程度远高于这个布尔值，故在稳健场景里把 L2 与 L3 一起剔除。

L5 的窗口选择要写死理由：2024 年中文论文 32,379 篇（全表 32.09%），是相邻年的 4.9—5.1 倍，四市同步尖峰（深圳 3,245、北京 5,142、上海 1,963、广州 5,325 在政策侧也同步尖峰，属入库批次）。所以近窗取 **2021—2023**，前窗取 **2016—2020**，两窗都不含 2024。2025（796 篇）、2026（300 篇）是统计期未结束的残年，不入窗。

### 2.5 步骤 4｜归一、合成与三个场景

叶级在四城同盘 min-max 到 0—100：

$$S_{\text{leaf}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \times 100$$

总分：

$$S = \frac{0.20\,L1 + 0.125\,L2 + 0.125\,L3 + 0.25\,L4 + 0.15\,L5}{0.85} \times 100$$

分母 0.85 是 `weight_used_sum`——项目维 0.15 不进分子也不进分母。**这不是"重归一后偷偷补 0.15"**：`missing_policy` 里 `renormalized: true` 指的就是"按在场维收缩分母"，且 `gap_dims: ["项目"]` 明写缺哪一维。

### 4.1 缺口清单

| 缺口 | 影响的叶/维 | 证据 |
|---|---|---|
| `policy_type_dist` 表 | 类型分布（已用现算替代） | gkx `information_schema` 0 命中；live ads 5 行造数 |
| `quote_policy` 有效值 | 系统性叶 | 19,998/20,000 为 `'NULL'` |
| `policy_support` 有效值 | 针对性叶 | 20,000 全 JSON null |
| `district` 有效值 | 覆盖面叶 | 18,835/20,000 为 `'NULL'` |
| `funded_province` / `funded_institution` | 项目维 3 叶 | 58,453 行全 `'None'` |
| 北京/上海研发投入 | 经费·科研经费叶 | `dwd_org_stock_finance_info` 无两地主体 |
| 专利 2017—2020 | 效果·专利侧 | `apdt_year` 四年零行 |
| 政策金额列 | 任何"资金强度" | 33 列里 0 个金额列 |

### 4.2 逐条影响

- `policy_type_dist` 缺失 → 类型分布改为现算；现算结果 11/11/11/10，近退化，已在稳健场景剔除。
- `quote_policy` 缺失 → 系统性叶恒 0。若强行算，四城都是 0%，进归一就是常数，等于给所有城市送分。
- `policy_support` 缺失 → 针对性叶恒 0，同上。
- `district` 缺失 → 覆盖面不可算。若按 registry 的 fallback 退 `COUNT(DISTINCT theme)`，`theme` 99.99% 是 `'NULL'`，退化成常数，同样不可用。
- 项目无城市 → 整维 `null`。这是本件唯一"整维砍掉"的处置，权重 0.15 从分母剔除，`weight_used_sum` 落盘为 0.85。
- 研发只覆盖粤四市 → 经费维只剩基金叶。北京、上海在经费维拿 0 分，**不是"经费少"，是"没有数据"**。这一条必须在 UI 上标注，否则会误导成"北京上海不投研发"。
- 专利 2017—2020 零行 → 效果维只能做论文前后对比。若强行用专利，前窗均值为 0，增幅变成无穷大。
- `approval_year` 存的是日期（19860101、20230101）→ 按年份分组前必须整除 10,000，否则会把 1986 与 2023 当两个"年份值"。

### 4.3 明确不做什么（禁止的替代）

1. **不从政策正文正则抽金额当"经费"**。`DATA_FACTS §3.62` 已实测：正文与摘要都命中金额的 902 条里，333 条（36.918%）两处量级差 ≥100 倍。
2. **不用 `status` 造"有效性"叶**。全表单值「有效」，进加权等于给所有人送分（§3.64 的教训）。
3. **不把项目维补 0**。补 0 会让四城同时降 15 分，名次不变但分差失真；本件选择整维出分母。
4. **不用 live 造数表补 `policy_type_dist`**。live ads 5 行，进计算即违规。
5. **不画论文年度趋势**。2024 年四城同步 3.6—5.2 倍尖峰（全表 32.09% 集中在 2024），是入库批次，不是发文高峰；把它摊进任何窗口都会造出假增长。
6. **不用政策年份做"政策力度变化"**。政策表 20,000 行是截断样本，年份分布同样受导出口径影响，本件只在"是否 2021 年后"这类粗窗口上参考，不做年度序列。

## 附录 E 口径问答

**Q：为什么只有四个城市？是不是挑着算？**
A：不是。政策表 `city` 字段缺 48.53%，有城市归属的只剩四城政策件数过 300（北京 2,268、上海 1,841、深圳 879、广州 325）；东莞 8 件、惠州 0 件是字段缺失的结果，不是"城市不重要"。

**Q：深圳政策只有北京的四成，凭什么第一？**
A：靠经费与效果两维。深圳产业基金 576 只（归一 89.3891）、论文增幅 +40.1869%（归一 100）；北京虽然扶持 100、经费 100，但效果只有 5.1781。把政策数量与类型两叶剔除后，深圳 78.9561、北京 51.0830，差距更大——说明第一不靠"政策多"。

**Q：北京、上海的经费 0 分是不是说明它们不投研发？**
A：不是。`dwd_org_stock_finance_info` 只覆盖 876 个上市主体，全部在粤四市；北京、上海**没有数据**，不是"投入为 0"。这个 0 分是缺维的归一结果，UI 上必须标"无数据"。

**Q：为什么项目维整维砍掉，而不是补 0？**
A：补 0 会让四城同时少 15 分，名次不变但分差被压缩；更糟的是它把"没数据"伪装成"项目支持为零"。本件选择出分母，并在 `gap_dims` 明写。

**Q：论文增幅用"任一机构归城"，一篇多机构论文会不会重复计？**
A：会。四城合计大于全国论文数。所以它只用于**同城跨年比值**（本件正是比值），不能跨城加总。`DATA_FACTS §3.74` 的深圳读数来自第一作者口径，比本件的"任一机构"口径还要高，差在归城规则，不在数据量。

**Q：为什么熵权下广州从 8.0386 掉到 5.0866？**
A：广州在主口径里 L2/L3 两叶都是 0（类型 10 最少、件数 325 最少），熵权把权重更多分给分布更散的叶（L5、L1），广州在 L5 上是 0、L1 上也是 0，唯一有值的是 L4（32.1543），所以分数更低。三个场景都垫底，说明"广州保障力弱"这个结论不依赖权重。
