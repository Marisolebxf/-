## 口径定义

科技政策事件被关注的程度。统计对象为选定范围内的政策事件（代理科技事件），从正文规模、主题覆盖、引用政策数综合，取值 0—100。

## 计算逻辑说明

用政策库识别科技事件。正文规模优先取正文长度，没有则用摘要长度；主题覆盖取去重主题点数；引用政策数取去重引用条数。三维在本窗事件内标准化后等权合成 0 到 100。

| 指标二级 | 指标三级 | 口径定义 | 计算逻辑 | 源表字段 |
|---|---|---|---|---|
| 正文规模 |  | 政策正文（或摘要）文本规模，代理传播体量。 | 优先取正文长度；没有则用摘要长度；皆空当 0。 | dwd_policy_base(id, abstract, content) — 正文/摘要规模 |
| 主题覆盖 |  | 政策主题点数量，代理讨论面。 | 解析主题列表后按主题去重计数。 | dwd_policy_base(id, theme) — 政策主题 |
| 引用政策数 |  | 被引用政策条数，代理提及频次。 | 解析引用政策后按引用项去重计数。 | dwd_policy_base(id, quote_policy) — 引用政策 |

## 源表字段

dwd_policy_base(id, title, publish_date, publish_year, province, city, abstract, content, theme, quote_policy) — 政策事件入集,统计窗,正文规模,主题,引用政策
