## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

要支撑的功能模块是：**创新成果综合展示 → 创新价值排序 / 创新价值分类展示**（SRS §1.1.1.1.4.1.4.1.4 与 §1.1.1.1.4.1.4.1.1），隶属全球创新观察大屏。

该模块的产品任务是：把专利、论文、项目等异构成果折算成同一把尺子上的「价值分」，据此分类（高/中/低价值）与排序，并驱动地图上的高亮、闪烁、飞线等视觉强化。

### 1.2 为什么需要「创新价值」这个指标

页面上的每个视觉决策都依赖它：

| 页面能力 | 对指标的依赖（据需求原文归纳） |
|---|---|
| 创新成果分类展示 | 按价值分档打标签（高/中/低） |
| 重点成果突出显示 | 以价值阈值为高亮条件 |
| 创新价值排序 | 以价值分降序排列成果列表 |
| 地图落点与飞线 | 高价值成果优先落点、连线 |
| 成果详情与对比 | 展示价值分及其构成 |

没有该指标，「重点成果」只能靠发布时间或人工挑选，无法回应需求里「了解全球创新热点」的诉求。

### 1.3 需求文档是否给出定义方法

**需求只给出「有模型」这一事实，未给出模型内容。**

《科技信息展示系统和科技专题服务系统.md》§1.1.1.1.4.1.4 写「通过大数据检索、分析技术和创新价值数值计算模型……按照创新价值进行分类展示」；§1.1.1.1.4.1.4.1.4 写「根据创新价值数值计算模型对创新成果进行排序」。全篇没有出现维度名、权重、归一方式或阈值。

项目内王惠阶段性成果（`M_INNOV_ACHIEVE_VALUE`，calc-logic 记为「成果扩散潜力代理」，逻辑为「专利被引次数 / 论文期刊分区映射 / 项目级别映射」）是当前唯一可复用的闭合口径，故本文以其为定义基座。

### 2.1 方法选择：为何三类成果分算而不混排

最直接的做法是把专利、论文、项目混在一个池子里归一。本文没有这样做，原因是**量纲不可通约**：专利的被引次数最大数十、转化件数多为 0–2；论文的下载量动辄三位数；项目的资助金额以万元计。混排后极值会被某一类的量级独占，其余两类被压到接近 0——这正是复合指标文献反复警告的「量纲污染」 (OECD/JRC, 2008)。

分算的代价是「跨类型不可比」：一个 66.67 分的专利与一个 66.67 分的论文，含义不同。产品侧若需统一榜单，应把分档（高/中/低）作为跨类型比较的公共语言，而不是直接比较分值。这也解释了为什么需求同时要求「分类展示」与「价值排序」——前者解决可比性，后者解决类内排序。

第二个方法选择是「缺维不补 0」。若某维缺失就补 0，会把「查不到」误判为「价值低」：论文型的技术维（期刊分区）当日 100% 缺失，若补 0，全部论文都会被压到 33 分档。王惠口径选择在剩余维上重归一，本实现沿用；代价是不同成果的「有效维数」不同，须随分落库。

第三个选择是极值归一而非秩归一。此处与 `PATH_002/003` 不同：创新价值需要保留「头部差距」（科曼医疗式的高价值成果应显著高于中位），极值归一能保留差距；代价是对极值敏感（见 §2.4）。这一取舍与 GB/T 44731-2024 的「五元价值」框架并不冲突——标准规定评估维度，不规定归一方式 (全国科技评估标准化技术委员会, 2024)。

### 2.2 步骤 1｜三型成果抽样与时间窗

时间窗取 2019–2024（六年），目的是避开 2019 年前专利被引尚未累积、2024 年后数据未完整入库的两端偏误。三型各抽 5,000 条：

- **专利**：`dwd_patent` 中 `apdt_year BETWEEN 2019 AND 2024`，取 `pn`、`value`、`apdt_year`、`first_applicant_name`，并关联 `dwd_patent_transfer`（转化生效日在窗内）与 `dwd_patent_cited`（被引总数）。
- **中文论文**：`dwd_zh_paper` 中 `cover_year_start BETWEEN 2019 AND 2024`，左连 `dwd_zh_journal` 取 `impact_score` 与 `jn_zone`，并取 `download_num`。
- **国内项目**：`dwd_zh_project` 中 `approval_year BETWEEN 20190101 AND 20241231`，取 `funded_amount`、结题报告摘要是否非空、`project_level`。

深圳切片用 `dwd_org_base_info` 中 `city LIKE '深圳%'` 的机构名册与专利申请人名称做匹配，命中即记 `sz=true`。实测专利型 5,000 条中深圳切片 2,353 条（47.06%），与深圳在底册中 50.55% 的占比接近，说明申请人名称匹配没有系统性偏向。

### 2.3 步骤 2｜三型各自的三个观测量

专利型三维取「专利价值 `value`、转化件数、被引次数」。其中被引次数是专利价值研究中最经典的代理变量：Trajtenberg 用被引数衡量发明的社会回报 (Trajtenberg, 1990)，Harhoff 等进一步证明被引频率与专利经济价值显著正相关 (Harhoff et al., 1999)。转化件数对应《中国专利奖评奖办法》中权重最高的「运用及保护措施和成效」（35%），专利价值 `value` 则近似其「专利质量 + 技术先进性」两维的综合 (国家知识产权局, 2024)。

论文型三维取「期刊影响 `impact_score`、下载量、期刊分区（1 区记 4、2 区记 3、3 区记 2、4 区记 1、其他 0）」。分区是中文期刊评价中最常用的质量分层，下载量则近似「传播广度」。

项目型三维取「资助金额 `funded_amount`、结题报告完整性（摘要非空记 1）、项目级别（国家级 3、省部级 2、其他 1）」。这三项分别对应投入强度、结题质量与行政层级。

三型的共同点是：都有一维「影响/质量」、一维「应用/传播」、一维「投入/层级」，结构同构，便于在同一套归一与分档逻辑下处理。

### 2.4 步骤 3｜批内极值归一与合成

对每型每维做 min–max 归一：

$$n_{xk}=\frac{x_{xk}-\min_{x'\in\text{同型}}(x_{x'k})}{\max_{x'\in\text{同型}}(x_{x'k})-\min_{x'\in\text{同型}}(x_{x'k})}$$

随后对非缺失维等权平均：

$$V_x=100\times\frac{1}{|\mathcal{K}_x|}\sum_{k\in\mathcal{K}_x}n_{xk}$$

极值归一的头部压缩效应在本指标尤其明显：专利型 max=66.67 而非 100，是因为没有任何一条专利在三维上同时取到最大值——被引维的最大值持有者（`CN120264501A`，被引维归一值 1.0）在转化与价值两维只有 0.5，故总分 66.67。这与「极值归一后必有满分」的直觉相反，原因是「缺维不补 0 + 剩余维等权」：当某维在同批内全为同一值时（如转化件数全 0），该维被判定为无区分度，归一值取 0.5 而非 1.0。

这一细节必须写进口径说明，否则用户会问「为什么没有 100 分的成果」。实测专利型 5,000 条中最高分 66.67、次高 59.62，第三名起全部 50.0——说明绝大多数专利在「价值」与「转化」两维上取值相同（归一后 0.5），只有被引维在区分。

### 2.5 步骤 4｜分档与深圳切片

分档用本型 P70/P30：≥P70 为高价值、P30–P70 为中、<P30 为低。选 P70/P30 而非固定分值，是因为三型的分布形态差异大（专利型集中在中段、项目型铺满全域），固定阈值会让某一型全部落进同一档。

实测分档：

| 类型 | n | min | max | mean | median | P70 | P30 | 高 | 中 | 低 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 专利 | 5,000 | 33.33 | 66.67 | 38.57 | 33.34 | 50.0 | 33.34 | 1,532 | 1,719 | 1,749 |
| 中文论文 | 5,000 | 50.0 | 50.0 | 50.0 | 50.0 | 50.0 | 50.0 | 5,000 | 0 | 5,000 |
| 国内项目 | 5,000 | 17.42 | 83.33 | 51.51 | 50.87 | 51.94 | 50.67 | 1,531 | 1,966 | 1,503 |

**中文论文型的退化必须单独说明**：其 min = max = 50.0，P70 = P30 = 50.0，于是「≥P70」与「<P30」两个条件同时命中全部 5,000 条（高 5,000、低 5,000、中 0）。这不是分档代码的错误，而是「所有维都无区分度」时秩阈值失效的必然结果。工程上应对退化型直接标「不可分档」，而不是输出一个自相矛盾的三档计数。

### 2.6 步骤 5｜结果落地与页面映射

落地字段为 `value_score`、`value_tier`、`dims_json`（各维原始值与归一值）、`effective_dims`、`sz_flag`、`model_version`。页面侧：

- **分类标签**直接用 `value_tier`，但退化型显示「待补数」而非「高价值」。  
- **排序**用 `value_score` 降序，同分按时间倒序。  
- **地图高亮**用 `value_score ≥ P70` 作为默认阈值，用户可调。  
- **详情页**展示 `dims_json` 拆解，满足「可解释」要求。

深圳切片的独立统计（2,353 条、均值 39.29、中位 33.34）略高于全量（38.57 / 33.34），差异不显著，说明深圳专利在价值分布上与整体接近；这一结论可直接支撑「深圳创新成果质量不低于都市圈平均」的页面文案。

## 五、王惠方法对照与选用建议

### 5.1 王惠原口径（calc-logic 原文）

王惠对 `M_INNOV_ACHIEVE_VALUE` 的定义是「成果扩散潜力代理」，逻辑为 **专利被引次数 / 论文期刊分区映射 / 项目级别映射**，源表指定 `dwd_patent_cited(pn, cited_by_nums)`、`dwd_zh_journal(publication_id, jn_zone)`、`dwd_en_journal`（`jcr_zone`）、`dwd_zh_project(id, project_level)`、`dwd_en_project(id, project_level)`。

即：**每型只取一个维**（专利看被引、论文看分区、项目看级别），三型各自映射为一个价值量。

### 5.2 本实现口径（V1.5 升级版）

本文件复用王惠 V1.5 升级版：每型扩为三维（专利：价值 + 转化 + 被引；论文：影响 + 下载 + 分区；项目：资助 + 结题 + 级别），批内极值归一、缺维重归一、等权 ×100、P70/P30 分档。

| 对照项 | 王惠原口径 | V1.5 升级版（本实现） | 差异影响 |
|---|---|---|---|
| 每型维数 | 1 | 3 | 升级版能拉开梯度，但依赖更多字段 |
| 专利维 | 被引次数 | 价值 + 转化 + 被引 | 被引覆盖 <1%，价值维成了主力 |
| 论文维 | 期刊分区 | 影响因子 + 下载 + 分区 | 三项当日全空/全零 → 退化 |
| 项目维 | 项目级别 | 资助 + 结题 + 级别 | 级别全单值，实际上靠资助与结题 |
| 归一 | 未明示（推断极值） | 批内 min–max | 可复算 |
| 缺维处理 | 未明示 | 重归一、不补 0 | 避免「查不到=低价值」 |
| 分档 | 未明示 | P70/P30 | 退化型失效（已披露） |

### 5.3 一致性实测

在论文与项目两型上，升级版的第 1、2 维当日无信息量，实际退化为王惠原口径的单维映射（论文仅剩下载量恒 0 → 恒 50.0；项目仅剩资助金额 → 17.42–83.33）。也就是说：**升级版并未在两型上带来新增信息，只在专利型上把「被引单维」扩展成「价值 + 转化 + 被引」三维**，使专利型从「绝大多数为 0」变为 33.33–66.67 的可用分布。

这一实测结论很重要：它说明升级版的价值集中在专利型，而论文与项目型的升级要以字段补全为前提，否则只是把单维退化包装成三维退化。

### 5.4 选用建议（明确结论）

**建议采纳「V1.5 升级版 + 三型分算 + 退化检测」作为对外主口径，但在论文与项目两型上回退到王惠单维映射并把结果标为「参考值」。** 具体三条：

1. **专利型用升级版三维**——被引、转化、专利价值三项都有数据，分档 1,532/1,719/1,749 可用，是唯一可直接支撑排序与高亮的类型。  
2. **论文型与项目型回退单维**——升级版在这两型的第 1、2 维全空/恒值，三维只是把噪声摊成三份；回退到「分区映射」与「级别映射」后，结果虽仍退化，但口径更诚实，且与王惠原文一致。  
3. **强制退化检测**——对 min = max 或 P70 = P30 的类型，输出 `degenerate=true` 与 `tier=NA`，前端显示「待补数」，禁止给出自相矛盾的三档计数。

权重方面，三型等权（1/3）与维内等权均可配置，但**不建议**在此阶段引入数据驱动权重：论文与项目两型的数据质量不足以支撑权重估计，任何「优化」都会过拟合空壳字段。待期刊影响因子与下载量入湖后，再按 Cherchye 等的 benefit-of-doubt 思路做权重内生检验 (Cherchye et al., 2007)。

## 附录 C　创新价值类似指标权威构建方法可行性报告（完整版）

### C.1 报告目的与范围

本附录回答三个问题：

1. 权威机构如何定义「创新成果价值」？常用哪些维度与合成方式？  
2. 本项目能否在现有数据上落地这些维度？  
3. 综合方法与数据后，**该给何种支持度判定**？

范围限定：以单件成果（专利/论文/项目）为对象的 0–100 价值分，不含机构或区域层面的创新指数（后者见 `M_INNOV_CARRIER_*` / `M_INNOV_CITY_*`）。

### C.2 需求语义锚定

需求要求「跨成果类型分类 + 类内排序 + 阈值高亮」，隐含两个条件：分值必须**可分解**（能说明为什么高），分档必须**跨类型可读**（高/中/低）。因此方法必须输出维级明细，且分档不能依赖类型特有阈值。

### C.3 权威与学术构建方法谱系

#### C.3.1 方法族 A：五元价值框架

**代表**：GB/T 44731-2024《科技成果评估规范》构建「五元价值 + 转化推广潜力」指标框架，规定自然科学与技术领域成果的评估原则、内容、方法与流程 (全国科技评估标准化技术委员会, 2024)。

**构架要点**：科学价值、技术价值、经济价值、社会价值、文化价值五维并重，另加转化潜力；强调评估维度而非固定公式。

**对本指标的可迁移性**：高（语义层）。本实现的三型三维可映射到「技术价值（被引/分区/级别）—经济价值（转化/资助）—社会价值（下载/传播）」。

#### C.3.2 方法族 B：专利奖项评价指标

**代表**：《中国专利奖评奖办法（2023 年修订）》对发明与实用新型设定四维权重：专利质量 25%、技术先进性 25%、运用及保护措施和成效 35%、社会效益及发展前景 15% (国家知识产权局, 2024)。

**构架要点**：四维加权，权重公开；运用与效益权重最高。

**对本指标的可迁移性**：高。本实现专利型的「价值」维近似质量 + 先进性，「转化」维对应运用与成效（权重最高的一项），「被引」维对应技术影响力。

#### C.3.3 方法族 C：被引作为价值代理

**代表**：Trajtenberg 以专利被引数衡量发明价值与社会回报 (Trajtenberg, 1990)；Harhoff 等以被引频率预测专利经济价值 (Harhoff et al., 1999)。

**构架要点**：被引需控年龄（同窗比较）与领域（同型比较），否则老专利与热门领域会被高估。

**对本指标的可迁移性**：高。本实现用 2019–2024 同窗 + 同型归一，正是对该告诫的回应。

#### C.3.4 方法族 D：复合指标合成规范

**代表**：OECD/JRC 手册规定归一、加权、聚合、稳健性检验的标准流程 (OECD/JRC, 2008)。

**构架要点**：极值归一适合保留差距；等权适合无先验权重；须做敏感性检验。

**对本指标的可迁移性**：高（计算骨架）。本实现的 min–max + 等权 + 分档即其简化版；敏感性检验留作增强。

**放弃方案**：把三型混在一个池子里 min–max 归一——量纲不可通约，会把论文与项目压到接近 0。

### C.6 风险与残余不确定性

| 风险 | 影响 | 缓解 |
|---|---|---|
| 论文型恒值 | 全部同分，无法排序 | 标「待补数」，不参与榜单 |

| 被引覆盖 <1% | 多数专利被引维为 0 | 明确「被引非全量」 |
| 极值归一头部压缩 | 最高仅 66.67 | 口径说明 + 展示维明细 |
| 跨类型不可比 | 混排失真 | 用档位而非分值跨类比较 |
| 退化型分档矛盾 | 三档计数自相矛盾 | 强制退化检测 |
