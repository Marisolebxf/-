### 1.2 为什么需要「要素影响力（会议）」这个指标

会议是科技共同体的**即时交流载体**，与期刊（延时发表）互补：一个新方向往往先在会议被讨论，再进入期刊。管理部门要判断「某个学科方向是否正在形成共同体」，会议的热度、投稿规模与参与人数比论文引用更早给出信号。

在「科技全域态势」里，会议要素的作用是给「机构/人才/项目」的画像**补一层学术活动维度**：某机构承办或高频参与顶级会议，说明其在共同体中的位置；某地区会议稀少，说明学术交流基础设施薄弱。

### 1.6 推测原意与推测定义

**推测原意**：把「会议」当成可打分的要素，让「科技全域态势」能回答「哪些会议值得关注、哪个学科共同体活跃」。热度是主导维（0.5），投稿与参与是规模佐证（各 0.25）——这与学术界的通行判断一致：会议级别（热度代理）决定质量，投稿/参与说明规模。

**推测定义（沿用王惠，仅补工程细节）**：

$$S_c=100\times\left(0.5\,\tilde{H}_c+0.25\,\tilde{P}_c+0.25\,\tilde{A}_c\right)$$

其中 $H_c$=会议热度（`impact_score`，缺失用 $\sum$`download_num`）、$P_c$=统计年会议论文数、$A_c$=会议论文去重作者数，$\tilde{\cdot}$ 为批内 min-max 标准化。

**但本库无法构造会议实体集合 $C$** —— $C=\varnothing$，故上式无定义域（详见 §二、§三）。

**依赖维度（王惠式 L2 拆解 + 两跳止步分类）**：

## 二、计算过程

> **口径说明**：本章记录「按王惠口径逐步执行时，每一步在哪一步失败」，而不是给出一个虚假的计算结果。脚本 `metrics/repro/M_INNOV_DS_FACTORS_008.py` 已完成全部探针，产物 `M_INNOV_DS_FACTORS_008_out.json` 中 `compute` 段为空（无会议实体可算）。

### 2.1 方法选择：为何必须「先有会议实体」

王惠口径的三个维度全部以「会议 $c$」为下标：热度是会议的属性、投稿数是「该会」的论文数、参与人数是「该会论文」的作者数。**没有会议实体，三维无法定义**，任何评分都会退化为对期刊或对论文的评分，与指标语义不符。因此本次不是「选择算法」，而是执行王惠第一步「用出版物类型识别会议」并验证结果——这一步失败，后续三步无需执行。

### 2.2 步骤 1｜用出版物类型识别会议（D1）——失败

```sql
SELECT publication_type, COUNT(*) FROM gkx.dwd_zh_journal GROUP BY publication_type;
SELECT publication_type, COUNT(*) FROM gkx.dwd_en_journal GROUP BY publication_type;
SELECT publication_type, COUNT(*) FROM gkx.dwd_zh_paper  GROUP BY publication_type;
```

三张表的 `publication_type` 去重结果为：中文刊 **只有「期刊」**（2,796）、英文刊 **Journal / Book in series / Book**（578 / 21 / 6，合计 605）、中文论文 **只有「期刊」**（100,900，`paper_type` 全为「期刊论文」）。**会议类型 = 0，会议实体 = 0。**

两条旁证进一步排除了「名称误导」：英文刊名含 Conference/Proceedings 的 21 种经逐一核对全部是 `Book in series`（丛书），不是会议录；`gkx` 280 张表中表名含 conf/meeting/confer 的**表为 0 张**。唯一疑似会议的 `gkx.dwd_event` 仅 20 行（医药类论坛，来源 `gkx_prod`），只有名称/主办方/日期/网址，**无投稿数、无参与人数、无论文关联**，且未入白名单，不足以做王惠要求的「批内标准化」。详细探针与判读见 §3.4。

### 2.3 后续三步与结论：计算过程从缺

热度、投稿数、参与人数三维全部以会议为分母，会议集合为空则分母为 0：`impact_score` 在两张期刊表 0/2,796 与 0/605 全空，`download_num` >0 为 0/100,900（王惠的热度备选路径同时失效），会议论文为 0 篇故投稿数与参与人数无挂载点。合成式 $S_c=100\times(0.5\tilde H+0.25\tilde P+0.25\tilde A)$ 的 min-max 在空集上无定义。

**结论：本指标无计算过程可写。**不给出任何「替代算法」——用期刊影响力或期刊被引量顶替会议热度的做法属语义造假，明确不做（理由见 §5.4 禁止项）。

## 四、数据缺失情况

1. **无会议实体类型**（决定性）：出版物类型、论文类型、图书类型里都没有「会议/会议录」。**建议**：入湖会议主档（会议名称、届次、主办机构、级别、官网、举办地、起止日期），最小可行字段 7 个。
2. **无会议论文集与论文映射**：`dwd_zh_paper`/`dwd_en_paper` 只挂期刊。**建议**：补会议论文集表并把 `publication_id` 扩展到 proceedings。
3. **无会议影响指数**：`impact_score` 在期刊表亦全空。**建议**：接 CCF 目录级别、中国科协重要学术会议目录入选标记作为「级别型热度代理」，或接第三方会议计量（DBLP/Scopus 会议 h5 指数）。
4. **无投稿/参与规模**：投稿数、注册人数、接受率均不入湖。**建议**：接会议主办方年报或会议官网统计。
5. **`download_num` 全 0**：王惠的热度备选路径失效。**建议**：与论文数据库方确认下载量口径是否可开放。

### 5.1 王惠方法原式拆解

本指标王惠条目只有一句「同 M_INNOV_CONFERENCE_INFLUENCE-会议影响力」，故原式取自其指向的正式条目：

| 层 | 王惠定义 | 王惠计算逻辑 | 王惠源表字段 |
|---|---|---|---|
| 对象识别 | 用**出版物类型**识别会议 | `publication_type` 判定会议 | `dwd_zh_journal`/`dwd_en_journal`/`dwd_zh_paper`/`dwd_en_paper` |

### 5.3 王惠公式可用性判定

**结论：王惠公式「逻辑可用、数据不可用」。判定为「保留王惠口径，当前不可实施」。**

| 子项 | 王惠要求 | 库内可得性 | 判定 |
|---|---|---|---|
| 按出版物类型识别会议 | 类型枚举含会议 | 枚举**不含**会议（三类表全无） | **不可用（前置条件失败）** |
| 会议热度 = impact_score | 会议影响指数 | 字段全空（0/2,796、0/605） | **不可用** |
| 会议热度备选 = download_num | 会议论文下载量 | 全 0（0/100,900） | **不可用** |
| 投稿数 = 会议论文数 | 会议论文集 | 无会议论文 | **不可用** |
| 参与人数 = 去重作者 | 会议论文作者 | 作者表有，无挂载点 | **不可用** |
| 0.5/0.25/0.25 加权 | 权重明确 | 权重本身合理 | 可用（但无对象可加） |

**为什么不能「变通为可用」**：王惠的三维全部以会议为下标，而会议集合为空。任何「变通」都必然是换对象——用期刊替代会议、用期刊被引替代会议热度、用论文作者替代会议参与者。这类替换会产出**语义错误但数值漂亮**的结果，属于为升档编造，明确不做。

### 5.4 优先采用王惠的建议与工程处理细节

**建议：保留王惠口径（不发明新公式），但当前不实施；同时明确三条禁止项。**

1. **保留口径**：本指标与 `M_INNOV_CONFERENCE_INFLUENCE` 共用同一公式与权重（0.5/0.25/0.25），双 ID 同实现，避免口径分叉。王惠的「批内标准化」要求也被保留——它天然要求「一批会议」，可以作为上线门槛（会议数 <30 不出分）。
2. **禁止项 1：不得用期刊替代会议**。`dwd_zh_journal` 的 `cite_nums`（2,796/2,796 非空）与期刊 `impact_score` 都不可挪作会议热度；把期刊影响力改名为会议影响力是实质造假。
3. **禁止项 2：不得用名称模糊匹配造会议**。英文刊名含 Proceedings 的 21 种全部是 `Book in series`，若按名称匹配会凭空造出 21 个「会议」。
4. **禁止项 3：不得用 `dwd_event` 的 20 行做主档上评分**。20 行做 min-max 会让「第二届创新药智造未来论坛」这类单一会议拿到 100 分，且该表未入白名单、`organizer` 为非结构化文本。
5. **转档路径（若甲方补数）**：补「会议主档 + 会议论文集 + 热度值」三件后，本指标可由「完全不支持」直接升为「完全转换支持」——公式无需修改，只需把 `publication_type` 扩展出会议枚举。这是本批指标中**转档成本最低**的一个（无需新建模型，只需补数据）。
6. **中期替代（仍属王惠口径内）**：若短期拿不到热度数值，可用「会议级别」作热度的序数代理（CCF A/B/C 或中国科协目录入选 = 高/中/低），但这需要甲方书面同意改写 0.5 维的定义，不能由实现方自行替换。

**与王惠原意的最终偏差清单（必须随结果披露）**：

| 偏差 | 原因 | 影响 |
|---|---|---|
| 未产出任何评分 | 会议实体为 0 | 指标完全不可交付 |
| 热度维两路皆空 | `impact_score` 全空、`download_num` 全 0 | 即便补会议主档仍需补热度源 |
| 未使用 `dwd_event` | 20 行、未入白名单、字段非结构化 | 会议名录也不能直接用于评分 |
