## 摘要

「事件影响力」与「事件关注度」在需求原文里是同一句话中并列的两个指标：「基于事件影响力、关注度等指标自动计算等级」。需求没有区分二者的定义，也没有说明影响力如何度量。从业务语义看，影响力回答的是「这件事的分量有多重」——发文主体级别越高、覆盖地域越广、涉及的议题越多，事件的辐射力越强。

王惠 V1.3 口径把影响力拆成三个可观测子项：政策行政级别（`rank` 解析为国家级 4 / 省级 3 / 市级 2 / 区县级 1 / 其他 0，多标签取最高档）、区域覆盖（`province`、`city`、`district` 三字段非空计数，0—3）、主题广度（`theme` 非空，0/1），三子项本窗极值归一后等权 ×100。本报告采用该口径（§五 论证未显著更差），由 `code/M_INNOV_DS_01_EVENTS_002.py` 在 `gkx.dwd_policy_base` 上按同口径直接重算（20261021 改源，不再读上游产物）。

实测显示级别维质量远比关注度维好：五档齐全（国家级 2,174 / 省级 9,922 / 市级 6,149 / 区县园区 1,398 / 未定级 357），20,000 条全部完成解析。但两个问题仍然显著：其一，`theme` 只有 2 条非空，主题广度维近乎恒 0，影响力实际是「级别 + 区域」两维；其二，`rank` 是 JSON 数组串，同一政策常带多个层级标签，取 max 后省级占到 49.61%，与「政策发文层级应以单一主体判定」的常识不符——数组语义更可能是「政策适用范围」而非「发文机构级别」。因此判定**部分支持**：两维可算、排序可用，但语义校验未完成，主题维塌陷。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标挂载于**科技信息展示系统 → 科技发展态势 → 科技全域态势 → 科创事件 → 重要性分级功能**（SRS §1.1.1.1.4.1.1.4.2）。科创事件功能组要求「在 GIS 地图上直观查看科技热点、科技舆情等事件的空间分布，以不同颜色和大小的标记点区分事件类型及重要性等级」，重要性分级功能则负责「自动计算等级、按高/中/低筛选、优先展示高影响力事件、实时更新等级」。

影响力是这条链路里唯一被需求原文直接用「高影响力事件」这个词点名的维度：地图标记点的大小、事件列表的排序、三档等级的合成，都直接消费它。与关注度相比，影响力承担的是「权力层级与辐射范围」的判断，关注度承担的是「信息密度」的判断，二者共同构成需求所说的双维输入。

### 1.2 为什么需要「事件影响力」这个指标

从产品逻辑看，影响力解决的是「跨类型事件的纵向可比」。科创事件包含政策发布、舆情热点、技术突破三类，它们的文本体量差异极大（一份规划纲要几十万字，一条舆情几十字），若只用关注度排序，政策类必然霸榜，舆情与技术突破事件永远沉底。影响力换一个坐标系：用发文主体的行政层级与覆盖地域衡量分量，让「国务院发布的实施意见」与「某区发布的实施细则」在同一条标尺上区分开，而不依赖文本长度。

从需求原文的用词看，「高影响力事件」被明确要求优先展示，说明编写人默认影响力是重要性的主判据，关注度是辅助。这与政策量化研究的传统一致：政策力度/效力的测量通常以发文层级、政策类型、措施强度为核心变量 (彭纪生 等, 2008)，而不是以文本长短论轻重。换言之，影响力维才是「重要性」的主干，关注度维是补充信息。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。** SRS 仅在重要性分级功能中用一句话并列点名：

> 基于事件影响力、关注度等指标自动计算等级，用户可按高、中、低级别筛选事件。该功能提供重要性排序优先展示高影响力事件，并实时更新等级以反映事件发展动态。

该句未说明：①影响力由哪些子项构成；②行政层级如何映射成分数；③区域覆盖如何计量（按行政级别？按辖区面积？按人口？）；④是否考虑政策工具强度、发文主体权威性；⑤归一与加权方式。另两份需求说明书亦未出现「事件影响力」字样。

### 1.6 推测原意与推测定义（本报告采用王惠口径）

**推测原意（编写人意图）**：同一批事件里，国务院文件与区级通知的分量显然不同，用户在地图上应先看到前者；影响力的作用就是把这种「分量差」变成可排序的分数，且不依赖文本长度（否则长文件永远赢）。

**采用口径（王惠 V1.3-20260829）**：

> **事件影响力**：统计对象为选定范围内的政策事件（代理科技事件），从政策级别、区域覆盖、主题广度综合，取值 0—100。政策级别取 `rank` 数组最高档（国家级 4 / 省级 3 / 市级 2 / 区县级 1 / 园区级 1 / 其他 0）；区域覆盖取 `province`、`city`、`district` 非空计数（0—3）；主题广度取 `theme` 非空（0/1）。三子项本窗极值归一后等权 ×100。

**依赖维度（L2 拆解）**：

|---|---|---|---|

## 二、计算过程

> **口径说明**：本节按王惠 V1.3-20260829 口径撰写（公式定义人=王惠）；已由 `code/M_INNOV_DS_01_EVENTS_002.py` 在**三方库 `gkx`**（`183.240.141.251:3318`，只读）**实测跑通**，20,000 条政策事件全量解析、全量评分，产物为 `M_INNOV_DS_01_EVENTS_002_out.json`。本版不再读任何上游 out.json。文内引用为 SCI 叙述式；完整题录见文末「参考文献」。

### 2.1 方法选择：为什么用「行政层级 + 地域覆盖」度量影响力

影响力是「分量」而非「热度」，最贴切的观测面是制度性权威：谁发的文、管到哪一级、涉及哪些领域。这三者在政策文本里都有明确字段——`rank`（层级）、`province/city/district`（地域）、`theme`（领域），不需要外部数据即可自动化。因此王惠口径选择「级别 + 区域 + 主题」三子项，本质上是把制度权威拆成三个可读维度。

这一取向与彭纪生等提出的政策量化操作手册同源：该手册主张按发文层级与政策措施类型赋分，再对政策力度做加总或平均，用于刻画政策协同的演变 (彭纪生 等, 2008)。其核心假设是「发文主体层级越高，政策效力越强」——这正是本指标级别维的 4/3/2/1/0 映射所依据的假设。差别在于彭纪生的手册还包含「政策类型」与「措施强度」两个需要人工判断的维度，而王惠口径只保留机器可读的层级与地域，牺牲了一部分测量精度换取全量可复现。

方法族 B（PMC）在变量表中也包含「政策层级」「政策领域」等条目，但其设计目的是刻画政策内部一致性而非对外影响力，且 50 个变量需逐条人工编码 (Ruiz Estrada, 2011)，不适合 20,000 条批处理。方法族 C（政策引用网络）在理论上更接近「影响力」的学术定义——被引越多影响力越大——但 `quote_policy` 只有 2 条非空，网络无从构建；黄萃等主张的政策网络分析同样依赖完整的引用/合作关系数据 (黄萃 等, 2015)，本库尚不具备。方法族 D（传播影响力）语义最直接，但库内无转载、无媒体级别、无搜索指数，直接出局。四族比较后，王惠口径是唯一「结构上有字段、数据上能跑通、方法上有文献支撑」的选择，§五 再做严格对照。

### 2.2 步骤 1｜事件入集与层级解析：把 JSON 数组摊平成单一档位

统计对象为 `gkx.dwd_policy_base` 全量政策事件，`id` 去重后 **20,000 条**。关键预处理在 `rank` 字段：它不是标量，而是 JSON 数组串（形如 `["省级","市级"]`），表示该政策在库内可能被同时标注了多个层级。脚本用正则抽取所有中文字段，再按映射表（国家级 4 / 省级 3 / 市级 2 / 区级、区县级、园区级 1 / 其他 0）取**最大值**作为该事件的级别分。这一「取 max」规则是必要的工程妥协：数组本身不区分「发文层级」与「适用范围」，取 max 的隐含假设是「只要涉及高层级，就按高层级计」。

实测五档分布为：国家级 **2,174**（10.87%）、省级 **9,922**（49.61%）、市级 **6,149**（30.75%）、区县/园区 **1,398**（6.99%）、未定级 **357**（1.78%）。这个分布本身就是一条重要证据：省级接近一半，远高于「省级政府发文在全部政策中的真实占比」的常识判断（一个全国政策库通常以市级、区县级文件为绝对多数）。最可能的解释是数组里大量出现 `["省级","市级"]` 这类复合标签，取 max 后统一归入省级。若如此，则级别维系统性高估了中低层政策的层级，进而高估其影响力。这一点必须在方法页披露，并列为 §四 的第一优先校验项。

入集阶段还有两个已知限制：`status` 全库单值「有效」，无法剔除失效政策；统计窗未截断，早期高层级文件与近期文件同池比较。二者都会影响「影响力」的时效语义，但相对级别维的标签问题属次要。

**事件去重审计（本簇专项风险）**。`dwd_policy_base` 以 `id` 为主键，20,000 行 / 20,000 个 id，无主键重复；但题名不唯一：19,974 个不同 `title` 撑起 20,000 行，**24 组同题、多出 26 行**。按「`title` + `publish_date` + `province` + `city`」严格键检查仅 **13 组、多出 13 行**（0.065%）。由于本指标的分数只取 `rank` / 省市区 / `theme` 三个字段，同题重复行若字段相同会形成完全并列（本已大量并列），若字段不同则是两条独立事件；按 `id` 保留可避免把不同批次的同名「公告」错并成一条。审计明细写入 `_out.json` 的 `dedup_audit`，供甲方切换口径时复核。

### 2.3 步骤 2｜区域覆盖子项：为什么「非空计数」是一个粗刻度

区域覆盖 $G_e$ 的实现是把 `province`、`city`、`district` 三个字段逐个判空后相加，取值 0—3。设计意图是「政策覆盖的行政层级越深，落地越具体，影响力越实在」：只写省级说明是全省范围的原则性文件，写到区县说明有具体实施对象。这个逻辑与政策效力测量中「作用范围」变量的思路一致 (彭纪生 等, 2008)。

但「非空计数」是一个很粗的刻度，有三处系统性偏差。第一，它把「层级深度」与「地域广度」混为一谈：一份覆盖全国的政策可能只填 `province='全国'`，得 1 分；一份只管一个街道的文件若三级都填，得 3 分——后者影响力显然更小，却被判更高。第二，它假设字段填写规范一致，而实际政策库的地理字段常由采集管道自动回填（如从发文机关推断），存在「省级文件自动补市、区」的情况，这会让高层级文件反而拿不到高分（如果只填省级），或者让基层文件虚高。第三，它对「跨省覆盖」无表达力：一份覆盖长三角三省一市的政策与一份只管一个省的政策同为 1 分。

实测层面，区域维的三字段可用性远好于主题维（`theme` 仅 2 条），但具体各字段的非空率未在产物中单独留存，需在复算时补记。从打分结果反推，区域维确实产生了区分度：Top10 中排名第一的事件（id 18352858）影响力 69.4，而大量事件并列 47.2，说明区域维在级别相同的政策间拉开了差距。不过由于分数只落在少数刻度上（§2.6），这种区分是「档位式」而非「连续式」的。

### 2.4 步骤 3｜主题广度：又一处「有字段、无数据」

主题广度 $T_e$ 的口径是 `theme` 非空记 1、空记 0（单条事件的 theme 是标量，无法数议题个数，故退化为二值）。这一维在方法设计上承担「政策涉及领域多寡」的判断：一份同时涉及人工智能、生物医药、新材料的综合性政策，影响力应高于只讲单一技术的专项通知。方法族 B 的政策领域变量、方法族 A 的政策类型变量，都是这一思路的体现。

实测结果让这一维失效：`theme` 非空 **2 条**（0.01%），与关注度维的 `theme`、`quote_policy` 是同一批数据缺陷。20,000 条政策里只有 2 条被标了主题，等于这一维对 99.99% 的事件恒为 0。更值得注意的是，这 2 条恰好也是关注度维中 theme 与 quote 都非空的那 2 条（id 18352858、18394903），说明缺陷来自同一个采集环节而非两个独立问题——政策表的「主题/引用」扩展字段整体未接通。

后果是影响力从「三维」退化为「两维」：级别与区域都是离散小整数，两维归一等权后分数只能落在很粗的网格上。这也解释了为什么 Top10 里只有 2 个不同分值（69.4 与 47.2）——不是数据恰好如此，而是公式的取值空间本来就窄，去掉第三维后进一步塌缩。

### 2.5 步骤 4｜极值归一与等权合成

合成公式：

$$norm(x)=\frac{x-\min(x)}{\max(x)-\min(x)}\quad(\text{全窗同值时取 }0.5)$$

$$Influence_e=\frac{norm(S^{lvl}_e)+norm(G_e)+norm(T_e)}{3}\times 100$$

三子项等权，每维上限 $33.3$ 分。级别维原始取值 0—4，归一后步长为 0.25；区域维 0—3，步长 0.5（若 min=1 则步长更粗）；主题维 0/1。三者组合后，全库可能的分数取值只有几十个离散点，而不是 0—100 的连续谱。这是「等权 + 极值归一 + 离散小整数输入」三者叠加的必然结果，也是理解实测分数形态的关键。

等权的理由与关注度维相同：王惠口径未给权重依据，等权是无先验时的稳健默认。但从业务语义看，等权未必合理——行政级别对「影响力」的解释力显然强于「省市区填了几个字段」，后者更接近数据完整度而非影响力。若改为「级别 0.6 / 区域 0.3 / 主题 0.1」，排序会更贴近直觉。本报告不擅改王惠口径，将此列为 §五 的待裁决项。

归一方式沿用本窗极值，优点是透明可复算，缺点是受极值事件影响。本指标输入是离散小整数，极值固定（级别 4、区域 3、主题 1），因此归一实际上等价于「按最大档位折算」——比关注度维的文本长度归一稳定得多，这是影响力维相对关注度维的一个隐性优势。

### 2.6 步骤 5｜分数分布、刻度与「影响力」语义的距离

实测最高分 **69.4**（id 18352858，与 id 18394903 并列），第三名起骤降至 **47.2** 并出现大量并列（Top10 中 8 条同为 47.2）。Top10 仅 **2 个不同分值**，说明分数的区分度几乎全部来自「是否同时踩中两维的高档」，而不是连续的强度差异。最高分 69.4 而非 100，说明没有任何事件在三维上同时取满——这与主题维塌陷直接相关：主题维对几乎所有事件贡献 0，理论上限被压到 $66.7$（两维满分），实测 69.4 略高于 66.7，说明个别事件的归一取值组合存在更细的刻度（级别或区域维的极值区间并非 0 起），但总体仍被压在 70 分以下。

从语义距离看，当前分数能回答「谁的行政层级更高、地域字段更全」，不能完全回答「谁的影响力更大」。三个具体偏差：其一，复合层级标签取 max 使省级虚高（§2.2），可能把一批市级文件误判为省级；其二，区域维把「填了几个字段」当「覆盖多深」，与真实作用范围只有弱相关；其三，主题维缺失使综合性政策无法体现跨领域影响力。三者叠加，分数的排序结果在「国家级 vs 省级」这个大边界上大致可信（级别维贡献最大），但在同层级内部（尤其省级内部占 49.61% 的大群体）几乎不可信——同层级政策只能靠区域字段的填法区分，而这更像数据完整度而非影响力。

对下游分级的影响在 §2.7.4 说明：重要性等级 = 0.5×关注度 + 0.5×影响力，影响力维方差远大于关注度维（后者被压在 33.3 以下），因此三档划分实际上由影响力主导；而影响力内部的区分又主要来自级别维，所以最终等级近似等于「按行政层级分档 + 少量区域修正」。这与需求「基于影响力、关注度等指标自动计算等级」的双维设计有距离，但至少比关注度维的单维退化更接近业务直觉。

#### 2.7.3 结果解读

1. **级别维是主引擎，但标签存疑**：五档齐全、无法解析 0 条，工程质量好；但省级 49.61% 的占比与政策库常识不符，`rank` 数组的「适用范围」语义很可能被当成「发文层级」使用，需抽样核对 50—100 条原始记录。
2. **区域维提供了微弱区分**：国家级事件若省市区三级齐全可得区域满分，与只填省级的同级事件拉开约 0.5 的归一差（约 16.7 分）。这是 Top1 与 47.2 群体之间的主要差距来源之一。
3. **分数刻度极粗**：Top10 只有 2 个值，全库取值点也只有几十个。前端若用连续色阶展示会显得突兀，建议改用分档色（三档或五档）或加抖动说明。
4. **大量并列破坏排序稳定性**：8 条并列 47.2，任何「按影响力排序」的列表都需二级排序键（发布时间、关注度）才能稳定，否则多次查询顺序可能不同。
5. **主题维塌陷是上限瓶颈**：最高分 69.4 < 100 的直接原因是主题维几乎对所有人贡献 0；补齐 theme 采集后，综合性政策将获得第三维加分，分数谱会显著舒展。

## 四、数据缺失情况

主指标可构建（两维可算）；残余缺口按优先级：

1. **`rank` 语义校验**（第一优先）：`rank` 为 JSON 数组串，同一政策带多个层级标签，取 max 后省级占 49.61%，疑将「适用范围」误当「发文层级」。需抽样核对原始记录，必要时改取「首标签」（通常为发文层级）或引入独立的 `pub_org_level` 字段。
2. **`theme` 采集未接通**：20,000 条中仅 2 条非空，主题广度维恒 0，影响力上限被压至 66.7。需接通主题标签采集（政策文本主题模型或人工标引）。
3. **区域维粗刻度**：省市区非空计数混同「层级深度」与「地域广度」，且不表达跨省覆盖；字段若由采集管道自动回填，还会引入「完整度偏差」。建议改为「地域层级 + 辖区类型（全国/跨省/省/市/区县）」的序数变量，并核查占位串（字面 `'NULL'`）。
4. **事件对象为政策代理**：舆情事件与技术突破事件无表，影响力语义仅覆盖政策类。
5. **无时效与失效过滤**：`status` 全库单值「有效」，统计窗未截断，早期高层级文件系统性占优。
6. **无物化结果面**：需落 ADS 并日增量刷新，才能支撑「实时更新等级」。
7. **大量并列**：8/10 条 Top 事件同分，需定义二级排序键，否则列表顺序不稳定。

**甲方侧建议**：影响力维可作为一期分级主判据，但必须披露「层级语义待校验、主题维缺失」；二期优先做 `rank` 语义核对与 theme 采集，两项修复后本指标具备升「完全转换支持」的条件。

### 5.2 新方法概述（备选路径）

备选一（政策力度测量手册）：按彭纪生等的操作手册，对发文层级、政策类型、措施强度分别赋分后加总/平均 (彭纪生 等, 2008)。优点是有明确学术出处、层级赋分更细致；缺点是需要人工判断政策类型与措施强度，20,000 条不可全自动，且「措施强度」主观性大。

备选二（PMC 指数）：10 主变量 50 子变量二值打分，其中含「政策层级」「政策领域」变量 (Ruiz Estrada, 2011)。优点是体系完整、可解释；缺点是逐条人工编码不可行，产出为一致性而非影响力。

备选三（引用网络中心性）：以政策被引次数或网络入度衡量影响力，学术上最接近「影响力」定义 (黄萃 等, 2015)。优点是语义最正；缺点是 `quote_policy` 仅 2 条非空，网络不可构建。

备选四（传播影响力）：以转载量、报道媒体级别衡量。语义直接，但库内无舆情/媒体表。

### 5.4 选用建议与理由

**采用王惠方法**（公式定义人=王惠）。理由三条：其一，**语义方向正确**——用行政层级度量影响力，与政策力度测量传统的核心假设一致 (彭纪生 等, 2008)，比关注度维的文本长度更贴近「分量」语义；其二，**可复现性最优**——另三套备选均需人工编码或无数据，只有王惠口径能在 20,000 条上全自动跑通并复算；其三, **结果可用**——实测 Top1 69.4 与并列群 47.2 拉开了 22 分差距，级别维的排序结果在「国家级 vs 省级」大边界上可信，能支撑一期分级。

须记录的保留意见（供甲方裁决）：

1. **`rank` 取 max 是否改为取首标签**：复合标签取 max 使省级占 49.61%，若数组首元素才是发文层级，应改取首元素。此改动会显著改变级别分布，属口径级变更，需甲方与王惠确认。
2. **三子项权重**：级别维解释力最强，区域维更接近数据完整度，等权未必合理。建议三维齐备后改为「级别 0.6 / 区域 0.3 / 主题 0.1」，需甲方确认。
3. **区域维改用序数变量**：把「非空计数」改为「全国/跨省/省/市/区县」序数，可消除「填得全就分高」的偏差。

结论：王惠方法在可执行性与语义方向上都优于备选，且是唯一能全量自动化的路径，按用户钦定规则优先采用；待 `rank` 语义核对与 theme 采集完成后应重跑本对照。

放弃方案：PMC 全量编码（人力不可行）、传播影响力（无数据）。
