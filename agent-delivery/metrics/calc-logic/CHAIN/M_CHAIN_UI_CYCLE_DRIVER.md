## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 产业链分析 → 产业周期分析 → 分析结果 → 关键驱动因素（选链分析后展示）。

### 1.2 为什么需要本指标

周期判定后用户追问「为什么在这个阶段」：驱动因素面板把周期归因到资本/政策/技术/热度四类信号的变化，支撑节奏决策。

### 1.3 需求文档是否给出定义方法

**需求文档没提及**：驱动因素清单、各信号的归因权重、变化率阈值。

### 1.4 类似指标权威方法可行性分析概要

周期驱动归因通行方法族：①多信号变化率分解（融资/政策/专利/新闻四路同比，本件信号面已探明）；②事件研究法（政策发布前后指标差异）；③Granger 因果（时序先行滞后检验，需长序列）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 产业链分析>产业周期分析>分析结果（20261104 盘点实拍）；缺口清单 seq42。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（产业周期分析模型叶）。
- 探针证据：`metrics/repro/out/M_B3_DEVCHAIN_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**推测定义（非甲方闭合）**：关键驱动因素 = 四类时序信号（资本/政策/技术/热度）中变化率贡献最大的因子排序。**升档触发器**：甲方给出归因规则；专利时序离线聚合补齐。
