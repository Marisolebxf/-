## 摘要

UI 产业周期分析的决策摘要·投资节奏卡。本件实测融资事件年度节奏全序列与轮次结构。判档完全转换支持。

## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 产业链分析 → 产业周期分析 → 分析结果 → 决策摘要「投资节奏」。

### 1.2 为什么需要本指标

决策摘要把周期结论压缩成三张卡（投资节奏/政策窗口/潜在拐点），投资节奏回答「资本正在加速还是撤离」。

### 1.3 需求文档是否给出定义方法

页面语义直读（融资事件时序节奏）；节奏判读=序列趋势可视化直读语义。

### 1.4 类似指标权威方法可行性分析概要

投资节奏通行口径族：①融资事件年度/季度计数序列（本件采用）；②融资金额加权序列（`funding_amount` 列在可叠加）；③轮次结构变迁（early/late 占比漂移）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 产业链分析>产业周期分析>分析结果（20261104 盘点实拍）；缺口清单 seq43。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（产业周期分析模型叶）。
- 探针证据：`metrics/repro/out/M_B3_DEVCHAIN_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**定义（页面语义直读）**：投资节奏 = 融资事件按完成日期的年度计数序列（+轮次结构），支撑加速/放缓/平稳判读。
