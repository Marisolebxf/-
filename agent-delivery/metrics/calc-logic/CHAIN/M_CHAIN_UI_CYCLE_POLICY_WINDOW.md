## 摘要

UI 产业周期分析的决策摘要·政策窗口期卡。本件实测政策发布时序（2015-2021 密集、2020 峰值 2,402 条、2022 起断更）与主表列结构。判档部分支持。

## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 产业链分析 → 产业周期分析 → 分析结果 → 决策摘要「政策窗口期」。

### 1.2 为什么需要本指标

政策窗口卡回答「当前是否处于政策友好窗口」：政策发布强度峰谷 + 与产业周期的对齐，支撑「借窗口落地」节奏决策。

### 1.3 需求文档是否给出定义方法

**需求文档没提及**窗口判定规则（强度阈值/与周期的对齐方式/链级过滤）。

### 1.4 类似指标权威方法可行性分析概要

政策窗口通行口径族：①发布强度时序峰谷（本件时序面已实测）；②政策-产业映射后链级强度（需映射表）；③政策文本力度评分（NLP，需建模，见 seq61 力度评估）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 产业链分析>产业周期分析>分析结果（20261104 盘点实拍）；缺口清单 seq44。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（产业周期分析模型叶）。
- 探针证据：`metrics/repro/out/M_B3_DEVCHAIN_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**推测定义（非甲方闭合）**：政策窗口期 = 政策发布强度时序的峰段区间（峰=窗口开启）。**升档触发器**：链映射给出 + 政策源恢复。
