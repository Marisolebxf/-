## 摘要

「竞争力-企业能力」是区域产业竞争力评价三大维度之一（另两个是学术生态与配套生态），回答「这条链在这个城市的企业，规模、经营质量、创新能力到底行不行」。王惠口径给了三个三级指标：人均产值（营业收入÷从业人数）、研发投入强度（研发经费÷营业收入）、有效专利数量（企业作为第一专利权人的有效发明专利），并明确「权重待甲方确认」。

本报告按三个指标逐一现转，结果差异极大：C 完全可用，2,939,895 件专利按第一申请人归集，发明授权（`kind='B'`）353,020 件，48 个链×城单元全部非零（30—45,857 件，中位 4,264）；B 只能覆盖 875 家上市主体（上市财务 40,239 行），研发强度中位 6.25%、区间 3.62%—9.93%，与上市制造业的常识一致，但 4 个单元无样本；A 最差——90,926 行年报里只有 850 家营收与人数同时有效，最新年度集中在 2014 年前后，且 64.8% 的公司-年「营收÷人数」低于 1,000 元/人，明显是万元与元混用，A 在单位确认前不可用。

按 §〇 判**部分支持**。C 可正式出数并直接进指数；B 可出「上市主体研发强度」但必须标注覆盖率 2.5%；A 只能作为「字段存在但不建议上线」的证据。权重未定稿，本报告给出的等权合成分仅供敏感性演示，不作正式竞争力分值。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标挂在 **科技信息展示系统 → 产业链分析 → 区域产业竞争力评价 → 企业能力**（需规 §1.1.1.2.4.2.2.8）。页面原文把评价体系定为「企业能力、学术生态、配套环境三大维度」，并支持「用户可调整各维度权重，适配不同产业特性」。

本指标是三大维度中的第一个，也是唯一直接依赖企业财务数据的维度。它下面按王惠口径再分三个三级指标，因此本报告的结构是三层的：维度（企业能力）→ 三级指标（A/B/C）→ 链×城单元。

### 1.2 为什么需要本指标

区域产业竞争力若只算专利与论文，会把「技术强但经营差」的链条评成优等。企业能力维的作用是把技术指标拉回经营现实，具体承担三项判断：

1. **规模与效率**：人均产值刻画「每个人创造多少营收」，是区分人力密集与高附加值链条的关键；
2. **投入意愿**：研发投入强度刻画「赚的钱有多少再投回研发」，是判断链条是否可持续的依据；
3. **技术资产存量**：有效发明专利刻画「已经积累了多少可排他的技术」，与产业化程度（申请量）互补。

三项合起来，才能回答「这条链的企业既会赚钱、又肯投入、还有技术积累」这一复合判断。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法；项目内王惠口径给了三个三级指标与计算方式，但权重留空。**

三份说明书只有「企业能力」这一维度词，没有三级指标清单。`calc-logic/CHAIN/M_CHAIN_REG_COMP_ENTERPRISE.md` 给了完整的三级指标表（人均产值、研发投入强度、有效专利数量）与各自源表字段，并明写「采用加权平均……权重待甲方确认」。

因此本报告的定义来自项目内口径，属「已有公式但权重未闭合」的状态。这一状态直接影响支持度判定：即使三个指标都能算，没有权重也无法给出「企业能力」这个单一分值。

### 1.4 类似指标权威机构构建方法可行性分析概要

企业竞争力评价有成熟的国家标准与国际实践。对照如下（完整版见附录 C）。

| 方法族 | 代表来源 | 指标构成 | 与需求贴合度 | 本库可实现性 |
|---|---|---|---|---|
| 企业竞争力评价国家标准 | GB/T 40957—2021《企业竞争力评价规范》（2022-06-01 实施） | 原则、指标、方法、流程、报告 | 高：概念与流程可直接引用 | 部分：标准给框架不给具体权重，需自建 |

## 二、计算过程

### 2.1 方法选择与口径移植

方法族选择见 §1.4：沿用王惠的三级指标，聚合方式按「单元内中位数 + 跨单元 min-max + 等权」实现。三个指标分别对应三张表：

- A 人均产值 ← `dwd_org_annual_financial_info`（年报，90,926 行）
- B 研发投入强度 ← `dwd_org_stock_finance_info`（上市财务，40,239 行）
- C 有效发明专利 ← `dwd_patent`（2,939,895 件）+ 企业链归属

每个三级指标都输出「值 + 样本企业数」两列，避免只看值不看覆盖。形式化：

$$
A(c,r)=\operatorname{median}\left\{\frac{\text{revenue}_i}{\text{employees}_i}\right\}_{i\in E(c,r)},\quad
B(c,r)=\operatorname{median}\left\{100\times\frac{\text{rd}_i}{\text{revenue}_i}\right\}_{i\in E(c,r)}
$$

$$C(c,r)=\sum_{i\in E(c,r)} \text{granted\_invention}_i$$

其中 $E(c,r)$ 为链 $c$、城市 $r$ 的链上企业集合，A/B 对「每家企业取最新有效年度」后再取中位数，C 按企业名聚合后求和。

### 2.2 A 人均产值：样本、年度与量纲

A 的处理分四步：先筛 `operating_revenue` 与 `employees_number` 同时非空且为正的行（90,926 行中仅 1,288 个公司-年满足）；再对每家企业取最新年度（得到 850 家）；再按企业链归属铺到 48 个单元；最后单元内取中位数。

年度分布暴露了第一个问题：有效样本的年份峰值是 2014 年（411 条）、2015 年（194 条），2019 年之后每年只有个位数到十几条。也就是说，**这套年报的主体数据是十年前的**，用它算「当期人均产值」在时效上不成立。

第二个问题更严重：1,288 个公司-年里，834 个（64.8%）的「营收÷人数」低于 1,000 元/人，原始中位数只有 120.76 元/人。一个人一年创造 120 元营收在物理上不可能，唯一解释是营收列存在万元与元混用（部分行以万元记，部分以元记）。这属于**量纲不一致**，不是离群值，无法用缩尾或截断修复——因为不知道哪一行的单位是对的。

因此 A 的产物只作「字段存在性证据」：42 个单元有值（6 个单元无样本），中位 6,697 元/人、p90 358,632 元/人、最大 1,124,836 元/人，这个分布本身就是量纲混乱的表征（跨 5 个数量级）。A 在甲方确认单位并统一换算前，**不得进入任何正式分值**。

### 2.3 B 研发投入强度：上市主体口径

B 从上市财务表取 `operating_revenue` 与 `research_development_amount`，要求期次年份 ≤2025、营收 >0、研发 ≥0，按 `(org_id, period)` 逐期计算研发强度，再对每家企业取最新期，最后单元内取中位数。

结果：879 家企业有可用研发数据，铺到 48 个单元后 44 个单元有值（4 个单元无样本），研发强度中位 6.25%、区间 3.62%—9.93%、44 个单元 44 个不同取值。这个区间与「上市制造业研发强度 3%—10%」的常识吻合，说明 B 的数值本身是可信的。

但 B 的覆盖是根本局限：879 家 ÷ 35,046 家链上企业 = 2.5%。未上市中小企业没有研发披露渠道，本库也没有其他表能补（`dwd_org_annual_financial_info` 的研发列整列为空）。因此 B 只能代表「链上上市主体的研发强度」，不能代表整条链。

### 2.4 C 有效发明专利：口径与代理

C 按王惠口径要求「企业作为第一专利权人的有效发明专利」。本报告分两步实现：

1. **第一专利权人**：用 `dwd_patent.first_applicant_name` 与链上企业名等值匹配，匹配成功即视为该企业为第一专利权人。
2. **有效发明专利**：本库 `dwd_patent.kind` 四类中，`B` 代表授权发明（353,020 件），`A` 代表发明申请（1,153,413 件）。`dwd_patent_legal` 只有 20,000 行，无法做全量有效性判定，故以 `kind='B'` 作为「授权发明」的代理，**不做有效期过滤**。

这一步是明确的**高估**：授权发明中已过期、已放弃、已转让的仍被计入。高估幅度无法用现有数据量化，只能说明方向。相对地，若改用 `kind IN ('A','B')` 会更高估（含未授权申请），故选择较窄的 `B`。

C 的结果是三指标中最好的：48 个单元全部非零，最小 30 件（合成生物×惠州）、中位 4,264 件、最大 45,857 件（智能终端×深圳），48 个单元 48 个不同取值，区分度充分。

### 2.5 链归属与城市归属

三个指标共用同一套归属：城市走 `credit_code → dwd_org_base_info.external_id` 全键（融资表另有 org_id，但本指标三张表都用 credit_code 更一致）；链走 `credit_code → 链上企业链码`（35,046 家）。

需要披露的是归属损耗：年报 850 家中能同时落到「四市 + 12 链」的更少，产物里 A 的单元样本数中位只有 8.5 家、最大 136 家；B 的中位 17.5 家、最大 246 家。这意味着多数单元的中位数只由个位数企业决定，稳定性有限。C 不受此影响，因为专利按企业名匹配，覆盖 3,493 家企业（智能终端×深圳）。

### 2.6 合成与权重缺失的处置

王惠口径明写「权重待甲方确认」，因此本报告不发布单一「企业能力」分值，只发布：

- 三个三级指标各自的单元值与样本数；
- 一个**等权**合成分（`composite_equal_weight_0_100`），仅用于敏感性演示；
- 归一后的分项得分（`_norm` 字段），便于甲方看到「换权重会怎么变」。

等权合成把 A 的量纲问题带进了结果（A 归一后极值单元得 100 分），因此这个合成分在正文中明确标注「不作正式值」。若甲方给出权重且 A 的单位确认，只需替换归一化后的输入即可，计算框架不变。

## 四、数据缺失情况

### 4.1 已识别缺口

第一，**A 的量纲不一致**。1,288 个公司-年里 834 个（64.8%）营收÷人数 <1,000 元/人，原始中位 120.76 元/人。这不是行业差异，是营收列存在万元/元混用。修复需要甲方确认 `operating_revenue` 的计量单位（或提供换算规则），在此之前 A 不可用。

第二，**A 的时效不达标**。有效样本年份峰值 2014 年（411 条），2019 年后每年个位数到十几条。即使单位修好，用 2014 年的年报算「当期人均产值」也不成立。需要甲方补最近年度年报。

第三，**B 只覆盖上市主体 2.5%**。879 / 35,046。未上市中小企业的研发投入在开发库与三方库均无来源（`annual_financial_info` 的研发列整列为空）。这是结构性缺口，不能靠换算或代理解决。

第四，**专利法律状态覆盖 0.68%**。`dwd_patent_legal` 只有 20,000 行，无法全量判有效，故 C 使用「授权发明」代理，方向为高估。需要甲方补全量法律状态表（或至少覆盖 4 市链上企业的子集）。

第五，**权重缺失**。王惠口径明写「权重待甲方确认」，导致维度分无法发布。这是口径缺口而非数据缺口。

### 4.2 甲方需补的四件事

1. **年报金额单位与年度范围**：确认 `operating_revenue` 单位，并补 2022—2025 年年报；
2. **未上市企业研发数据**：研发费用加计扣除申报数据或科技统计年报，用于把 B 从 2.5% 提到可用水平；
3. **专利法律状态全量**：用于把 C 从「授权发明」升级为「有效发明」；
4. **三个三级指标的权重**：用于合成维度分。

### 4.3 可构建结论

本指标**部分可构建**：C 已可正式出数并单独进指数；B 可出「上市主体研发强度」并标注覆盖；A 在单位与年度两项修复前不可用；维度合成需权重。三者的共同问题是「代表性」而非「能否计算」——三个指标都能算出数，但没有一个能代表全部 35,046 家链上企业。

## 五、王惠方法对照与选用建议

### 5.1 王惠原方法还原

- **口径出处**：`calc-logic/CHAIN/M_CHAIN_REG_COMP_ENTERPRISE.md`
- **结构**：「采用加权平均。维度：企业规模/经营质量/创新能力。权重待甲方确认。」
- **三个三级指标**：人均产值（`dwd_org_annual_financial_info` 的营收÷人数）、研发投入强度（`dwd_org_stock_finance_info` 的研发÷营收×100%）、有效专利数量（`dwd_patent` + `dwd_patent_legal`，第一专利权人的有效发明专利）
- **参考文献**：GB/T 40957—2021、工信部《中小企业专精特新发展评价指标体系》

### 5.2 新方法概述

未另立方法：三个三级指标、源表、字段全部照搬；只补两个未定项——单元内取中位数（抗极值）、跨单元 min-max 后等权（演示用）。有效专利一项因法律状态覆盖不足，用 `kind='B'` 代理，方向为高估。

### 5.3 逐维对照

| 维度 | 王惠口径 | 本报告口径 | 数据支撑差异 | 可复现性差异 |
|---|---|---|---|---|
| A 人均产值 | 营收÷人数 | 同，单元内中位数 | 同源；发现量纲不一致 | 等价（同样不可用） |
| B 研发强度 | 研发÷营收×100% | 同，单元内中位数 | 同源（875 家） | 等价 |
| C 有效专利 | 第一专利权人 + 法律状态过滤 | 第一申请人 + `kind='B'` 代理 | 法律状态表覆盖 0.68%，无法过滤 | **新口径为代理**，可复现但高估 |
| 聚合 | 加权平均（权重待定） | 中位数 + min-max + 等权演示 | 无 | 权重仍缺 |
| 区域轴 | credit_code 全键 | 同 | 无 | 等价 |

### 5.4 选用建议与理由

**建议采用王惠口径，但按「分项上线、维度缓发」执行。** 三条基准核对：语义同维（完全一致）；王惠口径在当前库部分可复现（B、C 可，A 因量纲不可，D4 因覆盖不可）；结果合理性（C 优、B 可信、A 不可用）。因此不满足「王惠口径同样可复现」这一条的全部要求，但也不该另立新方法——问题在数据不在方法。

执行建议分三步：第一步，C 单独上线，作为「企业技术资产」指标；第二步，B 加「上市主体」标签上线，并在 UI 上同时显示覆盖企业数；第三步，A 等甲方确认单位与年度后再评估，若届时仍不可用，建议用「营收规模」替代「人均产值」（营收本身不依赖人数，不受量纲混用影响，但会失去效率语义，属替代而非等价）。

## 附录 C 可行性报告完整版

**C.1 文献谱系**

企业竞争力评价的标准化路径在中国已经成型。GB/T 40957—2021《企业竞争力评价规范》由全国标准信息公共服务平台登记、中国标准化研究院归口，2021-11-26 发布、2022-06-01 实施，规定评价原则、指标、方法、流程、报告、结果应用与持续改进，适用于企业自评、同行比较与第三方评价。它的价值在于给出「评什么、按什么流程评」的框架，但**不规定具体权重**——这与本指标「权重待甲方确认」的状态一致，说明权重属场景化决策而非标准缺项。

区域层面，《中国区域科技创新评价报告》以 5 方面、12 个二级、44 个三级指标评价各省，其中「高新技术产业化」与本指标的「有效专利」在语义上相邻。该体系的可借鉴点是分层（投入—产出—环境），不可搬用点是它的指标多为统计年鉴口径。

专利质量侧，国家知识产权局《2024年中国专利调查报告》给出企业发明专利产业化率 53.3%、产业化平均收益 869.5 万元/件等基准，可用于判断本指标 C 项的语义边界：C 量的是「有多少授权发明」，不是「有多少被产业化」。

**C.2 数据矩阵**

| 三级指标 | 需要的量 | 本库对应 | 是否可得 | 覆盖 |
|---|---|---|---|---|
| A 人均产值 | 营收 + 人数 | 年报 90,926 行 | 结构可得、质量不可用 | 850 家（2.4%） |
| B 研发强度 | 研发 + 营收 | 上市财务 40,239 行 | 可得 | 879 家（2.5%） |
| C 有效发明专利 | 专利 + 法律状态 | 专利 2.94M + 法律状态 20k | 专利可得、法律状态不可得 | 全量（代理高估） |
| 权重 | 三项权重 | 无 | 否 | — |

**C.3 方案与备选**

主方案：三分项分项上线 + 维度缓发。备选一：用「营收规模」替代「人均产值」（不依赖人数，避免量纲问题，但失去效率语义）。备选二：用「专利申请量」替代「有效发明专利」（数据更全，但语义从存量变流量）。备选三：把 B 的覆盖面从上市主体扩展到「有年报的企业」（实测年报研发列整列为空，不可行）。

**C.4 风险**

1. A 的单位问题若被忽略，会在指数里产生 5 个数量级的伪差异；
2. B 的 2.5% 覆盖若不加标注，会被误读为全链研发强度；
3. C 未过滤有效性，方向上高估，且高估幅度未知；
4. 权重缺失使维度分无法发布，若强行等权会放大 A 的问题。

**C.5 总判**

方法可行、数据部分可得。判**部分支持**：C 可正式出数，B 可带标注出数，A 待甲方修数。不可因为「三个指标都能算出数字」就判完全转换支持——A 的数字目前不可解释。
