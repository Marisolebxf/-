## 2. 目标骨架（两案，解挂后按已签算法落 seed）

**案 A（专利海外占比单因子，现网最近源）**：
```
国际化指数 = 链上专利中海外申请人专利占比
（海外 = 申请人国别 ≠ CN；前提：dwd_patent 国别字段存在——待核验，未核前案 A 也非现成可算）
```

**案 B（三因子加权，seed 原稿方向）**：
```
指数 = w1×海外企业数占比 + w2×海外专利占比 + w3×进出口强度
（w3 无源，须供方新增或砍因子）
```

## 3. 决策点清单（交唐绍祖 / 甲方）

1. 因子集合：三因子 or 先落专利单因子
2. 「海外」判定基准：申请人国别 / 企业注册地 / 专利同族（无同族字段需供方扩）
3. 权重 w1/w2/w3（若多因子）
4. 指数形态：0-100 分 or 占比直读
5. 是否与 M_CHAIN_SZ_ADVANTAGE_SCORE 城市对标框架统一

## 4. 解挂条件
