## 摘要

「竞争力-学术生态」是区域产业竞争力三维中的第二维，回答「这条链在这个城市，有没有高校与科研机构在支撑、有多少学者、产出多少论文」。王惠口径给了三个三级指标：论文产出（链上高校与科研机构所属学者的论文去重件数）、人才储备（同口径学者去重人数）、科研机构（链上高校与科研机构去重数量），并明确权重待甲方确认。

现转结果呈现一个尖锐的矛盾：底层数据量很大，但「链上」这一层是空的。`dwd_org_industry_tags` 对 4 市高校与科研机构的链标签命中率是 **0**（`heis_city4_tagged = 0`、`inst_city4_tagged = 0`），也就是说开发库从未把大学与院所挂到产业链上。本报告因此改用唯一可溯源的替代路径：从论文 `author_info_list` 里找与链上企业同篇共著的机构，把该机构计入对应链。这条路径命中 8,891 篇论文、473 家机构，但它是「有共著才有」的选择性覆盖，不是全量。

结果呈现明显的两极化：广州因高校密集而占据头部（软件与信息服务×广州 56 家机构、829 位学者、9,168 篇论文），深圳的机构覆盖率只有 1.8%（18/1,024）却覆盖了 96.9% 的学者（190/196），惠州只有 1 家机构、0 位学者。48 个单元里 10 个无机构、20 个无学者、25 个无论文。按 §〇 判**部分支持**：三项都能算出数，但没有一项能代表「全部链上学术资源」，因为「链上」本身只是一个共著子集。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标挂在 **科技信息展示系统 → 产业链分析 → 区域产业竞争力评价 → 学术生态**（需规 §1.1.1.2.4.2.2.8）。页面把学术生态列为三大维度之一，与「企业能力」「配套生态力」并列，并允许用户调权。

本指标下辖三个三级指标（论文产出、人才储备、科研机构），因此报告结构是「维度 → 三级指标 → 链×城单元」三层。与同族企业能力指标的差别在于：企业能力的分子是财务与专利，学术生态的分子是机构、人与论文。

### 1.2 为什么需要本指标

产业链的技术能力不只来自企业，也来自高校与院所的知识供给。学术生态维要回答的是「本地有没有知识生产者、产出多少、是否与产业有连接」。它承担三项判断：

1. **知识供给规模**：本地有多少高校/院所与学者，是长期技术能力的底座；
2. **产学研连接**：这些机构是否真的与本链企业合作（共著是可用证据之一）；
3. **区域差异**：广州的高校密度与深圳的企业密度形成互补，学术生态维是把这种互补显性化的唯一入口。

如果缺这一维，区域产业竞争力就只剩企业侧，无法解释「为什么某些链条在深圳长不出来但广州能长出上游」。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法；项目内王惠口径给了三个三级指标与源表，权重留空。**

三份说明书只有「学术生态」维度词。`calc-logic/CHAIN/M_CHAIN_REG_COMP_ACADEMIC.md` 给了三级指标表：论文产出用 `dwd_scholar` + `dwd_scholar_paper_relation` + `dwd_scholar_papers` + 高校/机构底册；人才储备用 `dwd_scholar` + 底册；科研机构用 `dwd_org_heis_info` + `dwd_research_institute_base_info` + `dwd_org_industry_tags`，并写「采用加权平均……权重待甲方确认」。

关键点在于：王惠口径的「链上」是靠 `dwd_org_industry_tags(credit_code)` 把高校/机构挂到链上。本报告实测该路径命中 0 条（见 §2.2），所以口径虽然给了，但其中最关键的一环没有数据。

学术生态的度量在官方统计里有成熟体系，但都以「机构/人员/经费/成果」四要素展开。对照如下（完整版见附录 C）。

## 二、计算过程

### 2.1 方法选择与口径移植

三个三级指标全部按王惠定义实现，唯一替换是「链上」的判定方式。整体流程：

1. 从高校底册（3,501 家）与科研机构底册（2,074 家）建「机构名 → 城市 + 类型」索引；
2. 从 100,865 篇带机构串的论文里，逐篇提取机构串，若其中出现链上企业（名称前缀最长匹配），则该篇的非企业机构计入对应链；
3. 机构按其城市落到 4 市，得到「链 × 城 → 机构集合」；
4. 学者按 `scholar_org_name_zh` 精确等于机构名匹配，得到「链 × 城 → 学者集合」；
5. 学者 → 论文（`dwd_scholar_paper_relation`，年 ≤2025）去重，得到「链 × 城 → 论文数」。

形式化：设 $I(c,r)$ 为链 $c$、城 $r$ 下经共著反推的机构集合，$S(i)$ 为机构 $i$ 的学者集合，$P(s)$ 为学者 $s$ 的论文集合，则

$$\text{Inst}(c,r)=|I(c,r)|,\quad \text{Scho}(c,r)=\left|\bigcup_{i\in I(c,r)}S(i)\right|,\quad \text{Paper}(c,r)=\left|\bigcup_{s\in\text{Scho}(c,r)}P(s)\right|$$

三个量都按链分别计算，因此同一机构若同时服务多条链，会在各链各计一次。

### 2.2 「链上」判定：为什么必须改路径

王惠口径要求用 `dwd_org_industry_tags.credit_code` 把高校/机构挂链。本报告实测：4 市高校 140 家中被挂链 **0** 家、4 市科研机构 2,074 家中被挂链 **0** 家（产物 `heis_city4_tagged = 0`、`inst_city4_tagged = 0`）。这不是覆盖率低的问题，而是**完全没有**：标签表的对象是企业，高校与院所未被纳入产业链标注体系。

如果坚持王惠路径，48 个单元会全部为 0，指标不可用。因此本报告改用产学研共著反推，并在 §四 明确这是替代路径。替代的合理性在于：一篇论文同时出现「某链上企业」和「某高校」，是产学研合作的可核验证据，比按名称关键词硬挂更可靠。

### 2.3 论文解析与机构匹配

论文侧来自 `ods.dwd_zh_paper.author_info_list`，共 100,865 篇带机构信息（0 坏 JSON）。每条记录是机构串列表，串内可能用 `;`、`，`、`、` 并列多个机构，先拆分再逐段匹配。

机构匹配用「最长前缀匹配」：把底册机构名按前 4 字建索引，对每个机构串检查是否以某个已知机构名开头，取最长命中。例：「上海交通大学材料科学与工程学院上海市高温材料及其精密成形重点实验室」→「上海交通大学」。这样处理的理由是论文机构串通常带院系与实验室后缀，精确相等几乎不可能命中；而前缀匹配能保住主体机构。代价是会把「XX 大学附属医院」归到「XX 大学」，对附属医院独立的机构体系会有偏差。

### 2.4 企业识别与链归属

企业识别同样用前缀匹配，但条件更严：机构串必须含「公司」二字，且长度 ≥6，才进入企业匹配；匹配对象是 35,046 家链上企业名。实测企业提及 37,991 次，名称匹配成功 9,832 次（25.9%），命中链上企业的论文 8,891 篇（占 100,865 篇的 8.8%），涉及 1,504 家企业。

25.9% 的匹配率说明论文里的企业名与工商注册名差异较大（简称、子公司名、英文名），这部分损耗是保守的：漏匹配只会让机构集合偏小，不会虚增。

### 2.5 学者与论文聚合

学者匹配用 `scholar_org_name_zh` 与底册机构名**精确相等**。这是有意选择的保守策略：模糊匹配（如包含关系）会把「中山大学」与「中山大学附属第一医院」的学者混在一起，导致机构口径失真。代价是覆盖率偏低——只有机构名与学者登记名完全一致时才计入。

论文产出按王惠口径取「这些学者的**全部**论文」，而不是仅共著论文。这一选择带来一个必须披露的副作用：同一城市里，一个机构可能同时被多条链共享，于是每条链都继承了该机构学者的全部论文，导致同一城市多个链单元的论文数几乎相同（广州四条链分别为 9,168、9,164、9,097、8,925 篇）。这解释了为什么论文产出的 48 个单元只有 14 个不同取值。为缓解，产物另给 `coauthored_papers_with_chain_enterprise`（该单元实际共著论文数，头部 512 篇），后者区分度更好，建议作为「产学研连接」的补充指标。

## 四、数据缺失情况

### 4.1 已识别缺口

第一，**高校/机构无链标签**。这是最根本的缺口：`dwd_org_industry_tags` 对企业有效，对高校/机构 0 命中。本报告用产学研共著替代，但替代只覆盖「有共著」的机构（473 家），占 4 市机构总量 2,186 家的 21.6%，且集中在大校。

第二，**学者—机构匹配保守**。用精确相等匹配，机构名后缀差异（「XX 大学」vs「XX 大学（本部）」）会导致漏配。方向上低估学者数，尤其影响小型机构。

第三，**论文产出与学者数共线**。按王惠口径取学者全部论文，导致同一城市多链单元数值几乎相同（广州四条链 8,925—9,168），只有 14 个不同取值。信息增量低，建议改用共著论文数作主口径（需甲方确认，属口径变更）。

第四，**惠州、东莞几乎为空**。惠州 1 家机构、0 学者、0 论文；东莞 11 家机构、6 位学者、0 论文。这与两地高校少的现实一致，但也可能是共著记录不足。无法用现有数据区分，故不作结论。

第五，**语料医学偏斜**。按项目实测（`DATA_FACTS_gkx.md` §十），论文语料中医疗类机构占作者-机构实例的 36.6%（35,747 / 97,665）。本指标的链上子集医疗机构实例只有 112 次（因链上企业多为工科），偏斜小于全语料，但机构池仍以高校为主、医院/医学院占比不低，解读时须剔除或分域。

第六，**未使用合著边表**。本报告没有用 `dwd_scholar_coauthor`（1,187,606 行），原因是它只能给「学者—学者」关系，不能给「机构—链」归属。若后续要用它做机构影响力，须先披露三个已知缺陷：30.5% 的边缺对端 ID 已被剔除、对端出现 899,662 个 ID 远多于主表 21,316 位学者（多数为库外学者）、医疗类机构占 36.6%。

### 4.2 甲方需补的三件事

1. **高校/科研机构的产业链标签**：这是把本指标从「共著子集」升级为「全量学术资源」的唯一途径；
2. **论文—机构规范化表**：当前靠前缀匹配，若甲方能提供机构名标准化映射（含附属医院独立编码），覆盖率与准确性都会显著提升；
3. **权重与主口径确认**：三个三级指标的权重，以及「论文产出」是否改用共著论文数。

### 4.3 可构建结论

本指标**部分可构建**：三个三级指标都能算出数，广州与深圳的对比有解释力（高校密集型 vs 企业密集型），但「链上」是共著子集，惠州/东莞几乎为空，论文产出共线。若甲方能补机构链标签，本指标可升为完全转换支持；在此之前，对外只能称「产学研共著视角下的学术生态」。

## 五、王惠方法对照与选用建议

### 5.1 王惠原方法还原

- **口径出处**：`calc-logic/CHAIN/M_CHAIN_REG_COMP_ACADEMIC.md`
- **结构**：「采用加权平均。维度：论文产出/科研机构/人才供给。权重待甲方确认。」
- **论文产出**：链上高校与科研机构所属学者发表论文去重件数（`dwd_scholar` + `dwd_scholar_paper_relation` + `dwd_scholar_papers` + 两张底册）
- **人才储备**：链上高校与科研机构所属学者去重人数（`dwd_scholar` + 底册）
- **科研机构**：链上高校与科研机构去重数量（`dwd_org_heis_info` + `dwd_research_institute_base_info` + `dwd_org_industry_tags`）
- **链上判定**：`dwd_org_industry_tags.credit_code`

### 5.2 新方法概述

三个三级指标的定义不变，唯一改动是「链上」判定从「标签表挂链」改为「与链上企业同篇共著」。另加两个辅助量：共著论文数（区分度更好）、城市覆盖对照（量化链归属损耗）。

| 链上判定 | 标签表 `credit_code` | 产学研共著反推 | 标签表对高校/机构 0 命中 | **新口径可复现，原口径不可** |
| 论文产出 | 学者的全部论文 | 同（另给共著论文数） | 无差异 | 等价 |
| 人才储备 | 学者去重 | 同（精确名匹配） | 匹配更保守 | 略低估 |
| 科研机构 | 高校 + 机构去重 | 同（限共著子集） | 覆盖 21.6% | 低估 |
| 聚合 | 加权平均（权重待定） | 等权演示 | 无 | 权重仍缺 |

### 5.4 选用建议与理由

**建议采用王惠口径的三个三级指标定义，但必须替换「链上」判定，并把支持度定为部分支持。** 三条基准核对：语义同维（三个指标完全一致）；王惠口径在当前库**不可复现**（链上判定 0 命中，这是关键维缺数据，不是小改造）；结果合理性（广州领先符合高校分布，但惠州/东莞为空、论文产出共线，说明替代路径有明显局限）。

因此本报告的做法是「保留王惠的指标定义、替换其不可执行的链上判定、显式降档」。若甲方能补机构链标签，应立即回到王惠原路径，届时可重评为完全转换支持。另建议把「论文产出」的主口径从「学者全部论文」改为「共著论文数」——前者在本库会退化为「城市学术总量」，与链的关系很弱；后者直接对应「与本链企业的合作强度」，语义更贴需求。此项属口径变更，需甲方裁决。

## 附录 C 可行性报告完整版

**C.1 文献谱系**

高校科技活动的官方统计由教育部科学技术与信息化司按年度编制。《2024年高等学校科技统计资料汇编》覆盖 2023 年全国 2,240 所设有理、工、农、医类教学专业的高等学校及其附属医院，内容分科技人力、科技经费、科技机构、项目、成果及技术转让、国际科技交流六部分，并给出分地区表。这一体系的价值在于确立了「机构—人员—经费—成果」四要素骨架，本指标的三级指标正好对应其中的「机构、人员、成果」三项，方法上同构。

区域层面，《中国区域科技创新评价报告》以 5 方面 12 二级 44 三级评价 31 个省区，其中「科技活动产出」与「科技创新环境」与本指标语义相邻；它证明区域学术能力可被指数化，但到省级即止。

产学研连接侧，国家知识产权局《2024年中国专利调查报告》给出「企业专利权人中与高校或科研单位开展合作的比例达 41.0%」这一官方基准，并区分联合研究（47.6%）、委托咨询（42.3%）等方式。该基准可用于判断本报告的共著覆盖率是否偏离：本库 8.8% 的论文命中链上企业，远低于 41.0% 的企业侧合作比例，说明「共著」只是产学研合作的一个子集（企业还可能以委托研发、购买服务等方式合作而不共著），因此本指标的机构覆盖必然偏低。

**C.3 方案与备选**

主方案：共著反推（已实施）。备选一：机构名关键词硬挂链（否决，误判率高且不可回溯）。备选二：只用「双一流」高校名单挂链（覆盖更窄，且名单与链无对应）。备选三：不挂链，只出城市级学术总量（失去链维度，不满足需求）。

**C.4 风险**

1. 共著子集不代表全量，机构覆盖 21.6%，惠州/东莞近乎为空；
2. 学者精确名匹配导致低估；
3. 论文产出与学者数共线，信息增量低；
4. 语料医学偏斜（全语料 36.6%），机构池以高校与医院为主。

**C.5 总判**

方法可行、数据部分可得。判**部分支持**。升档条件明确：补高校/机构的产业链标签；或提供机构名标准化映射 + 共著全量抽取。二者任一到位即可重评为完全转换支持。
