## 摘要

UI 产业周期分析的潜在拐点卡。本件以一阶差分符号翻转法实测融资/政策两路信号的变号点（融资：2016 峰/2019 谷/2021 峰）。判档部分支持。

## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 产业链分析 → 产业周期分析 → 分析结果 → 潜在拐点。

### 1.2 为什么需要本指标

拐点是周期卡的结论位：标出趋势反转的年份（峰=过热回落风险，谷=触底回升机会），支撑「择时」决策。

### 1.3 需求文档是否给出定义方法

**需求文档没提及**拐点判定规则（什么算拐点、基于哪路信号、置信度如何）。

### 1.4 类似指标权威方法可行性分析概要

拐点检测通行方法族：①一阶差分符号翻转（本件采用，简单确定可解释）；②HP 滤波趋势残差（需参数 λ）；③隐马尔可夫状态切换（需拟合算力）；④变点检测（PELT/BSega）。完整版见附录 C。

### 1.6 推测原意与推测定义

**推测定义（方法已披露、非甲方闭合）**：潜在拐点 = 主要信号序列一阶差分符号翻转的年份（峰/谷标注）。**升档触发器**：甲方确认方法或给出规则；专利信号补齐。

## 二、计算过程

### 2.1 检测方法（已披露）

对信号序列 \(x_t\)，计算一阶差分 \(d_t = x_t - x_{t-1}\)；当 \(d_t \cdot d_{t+1} < 0\) 时，\(t\) 为拐点：\(d_t > 0\) 标「峰」、\(d_t < 0\) 标「谷」。

### 2.2 融资序列拐点（实测落产物）

| 年份 | 类型 | 融资事件数 |
|---|---|---:|
| 2016 | 峰 | 3,884 |
| 2019 | 谷 | 1,666 |
| 2021 | 峰 | 2,019 |

### 2.3 政策序列拐点（落产物 `policy_inflections`）

2012-2026 政策发布序列变号点逐年标注（见产物）。

### 2.4 确定性声明

信号序列全 SQL 计数；拐点判定为纯确定性函数（一阶差分），重跑逐位一致（B5）。
