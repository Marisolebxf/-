## 摘要

本件在需求侧对应「技术基础指标模型」指标体系第（8）项**领先专利主体机构**（原句「设定判定领先的指标，比如专利数等，并设定一个指标的阈值，识别领先专利主体机构」），在王惠侧登记为 **M_INNOV_TINN_COMPOSITE-技术创新力综合评估**（三维十一子项：专利数量 2、专利质量 5、技术市场潜力 5，对象为 IPC 前 4 位，0-100 分）。两条语义的交点是：**用一套可复核的多维分数把「谁领先」定量化**；差别在对象粒度——需求问「哪家机构领先」，王惠口径问「哪个技术领域强」。本报告以王惠三维为打分内核、以需求 (8) 的阈值法为主体识别外壳，双粒度同时给出。

实测结论按子项分层。**规模维（全量可算）**：20 万件 PK 分片样本覆盖 620 个 IPC4、49,121 个申请主体；G06F 19,170 件 / 授权 9,760 / 授权率 50.9%，G06N 9,110 / 4,803 / 52.7%，H04L 6,089 / 2,681 / 44.0%，H05K 5,243 / 4,133 / 78.8%。**技术宽度（全量可算）**：件均 IPC4 覆盖 1.628 个（中位 1、最大 12、≥2 占 42.45%），G06N 2.615、G06V 2.526、G06T 2.384 显著高于 G06F 1.971。**质量维（抽样级）**：同族均值 11.591 位成员（最大 293、n=20,593）、被引均值 0.526 次（被引>0 占 17.83%）、法律稳定占比 62.45%（n=2,000）；三者的 pn 与主表可连接率仅 3 个 IPC4，**不可逐域连接**。**市场潜力维（分裂）**：转让全量 22,809 条可算；许可 2 例、质押 10 例、诉讼 0 例、开放许可 1 例——四子维在 2,000 条法律事件抽样中近乎为零。

**主体识别的实测结果具备业务可解释性**：华为 5,388 件居首但整体授权率仅 15.26%，华南理工 1,931 件 / 63.44%、广东工业 1,419 件 / 66.81%、比亚迪 1,853 件 / 55.69%；按申请年批次校正后，华为 2021 批 35.4%、2024 批 5.5%，华南理工 80.9% / 62.1%——**授权率随批次单调下滑是审查滞后伪影，不是质量下滑**，直接把原始授权率当阈值会系统性误判近期高强度申请主体。按 §〇 落 **部分支持**：阈值识别（需求主线）现转可交付，王惠 0-100 综合分因 7 个子项缺数据不可闭合。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标属「技术基础指标模型构建」（l5，基础指标分析模型，章节 DS-07）的主体机构件，挂在技术专题库的技术发展分析。要开发的产品面是：**领先专利主体机构识别服务**——用户按技术领域 / 时间 / 地域，得到一份「谁在这个领域领先」的机构名单，以及每家机构的判定指标值（专利数量、质量、技术覆盖范围）；底层由技术数据库专利表与机构表支撑，通过 API 按领先指标与时间查询。需求给出的实现路线是四步：数据源对接 → 指标设定（选判定指标 + 设阈值）→ 数据清洗 → 数据处理与验证，再加服务化与同步。

族内分工上，DS-07 是 TECH 域的基础指标层：论文/专利数量件回答「有多少」，专利质量件（002）回答「值多少」，本件回答「谁在做」，技术交易额件回答「卖了多少钱」，技术动态资讯件（006）回答「趋势往哪走」。本件与 002 是上下游——002 的五维质量分按主体聚合即本件的质量子项；本件与 005（技术点影响力 / 实体优先级）共享同一套实体—技术点关联，但 005 排的是「展示优先级」，本件排的是「领先与否」并带阈值判定，二者不可互相替代。

### 1.2 为什么需要「领先专利主体机构」这个指标

「领先主体」是技术专题库从「看领域」走到「看主体」的枢纽指标。政策侧，招商与产业培育需要一份可解释的龙头名单：哪些企业在本地的重点技术领域形成专利壁垒、哪些高校院所是可转化的技术源头、哪些主体的申请是「真投入」而非「凑数量」；企业侧，对标与供应链评估需要同领域主体的技术位次；研究侧，创新地理与主体异质性研究需要机构级的专利组合画像。这三种用途共同要求指标**既可排序又可解释**——只有名次没有判定依据（专利数？质量？覆盖范围？）的榜单在政策场景不可用，因为被质疑时无法回溯。

本件的方法论难点不在「怎么排」，而在「排出来能不能站住」。专利数量的排名会被申请策略污染（同一发明拆案、实用新型冲量），授权率的排名会被审查滞后污染（近期申请尚未审结），技术覆盖范围的排名会被分类策略污染（附加分类填得多的主体天然占优）。因此需求原文特意写了「设定判定领先的指标……并设定阈值」——**阈值是把连续分数转成「领先/非领先」二元判断的治理动作**，它要求指标选择与阈值设定都可被业务复核。本报告把这三类污染逐项实测并给出校正口径（§2.5），这也是本件区别于「拉个专利数排行榜」的实质。

### 1.3 需求文档是否给出定义方法

**需求文档给出了判定指标的方向与阈值法的流程，但没有给出任何一个子指标的公式、权重或阈值数值。** 原句只列「例如可以选择专利数量、专利质量、专利技术覆盖范围等指标」，并强调「需要根据指标的特点和实际情况，设定合理的阈值」——即把指标选型与阈值设定留给实现方。王惠注册口径（M_INNOV_TINN_COMPOSITE）补上了公式骨架：规模 2 子项、质量 5 子项、市场潜力 5 子项，维内极值归一后等权，三维持自定义权重合成 0-100；但**仍未闭合**三处：三维之间的权重（「自定义权重」是交互壳，缺省值未给）、阈值（领先/非领先的分界未给）、输出粒度（IPC4 领域分 vs 主体分未区分）。本报告按王惠子项结构重建，并在 §1.6 与 §5.4 显式披露这三处未闭合。

### 1.6 推测原意与推测定义（王惠口径移植）

**推测原意**：需求 (8) 的原始意图是「给一张可解释的龙头名单」——所以它强调「设定判定指标 + 阈值」而不是「算一个分数」。王惠把其登记为技术创新力综合评估，是把「领先」从单指标排名升级为多维综合判断，避免「专利多的就是领先」的粗口径。二者不冲突：综合分是排序器，阈值是切分器，名单是最终产品。

**推测定义（本 TECH-d 批采用，供后续建模；非正式甲方闭合口径）**：

> **领先专利主体机构**：对技术领域 $d$（IPC4）与主体 $e$，构造三维十一子项的技术创新力分：
> $$
> S(e,d)=100\times\Big[w_1\cdot \underbrace{\tfrac12\big[\phi(N^{app}_{e,d})+\phi(N^{grant}_{e,d})\big]}_{\text{规模}}+\;w_2\cdot\underbrace{\tfrac15\sum_{k\in\{fam,clm,cit,wid,leg\}}\phi(x_k)}_{\text{质量}}+\;w_3\cdot\underbrace{\tfrac15\sum_{k\in\{tr,lic,lit,plg,opn\}}\phi(x_k)}_{\text{市场潜力}}\Big]
>
$$
> 其中 $\phi(\cdot)$ 为维内极值归一，$w_1,w_2,w_3$ 为甲方自定义权重（当前缺省未定）。领先判定：
> $$
> \mathrm{Leader}(e,d)=\mathbb{1}\big[N^{app}_{e,d}\ge \theta_N \;\wedge\; \mathrm{GrantRate}^{cohort}_{e,d}\ge \theta_G\big]
>
$$
> 阈值 $(\theta_N,\theta_G)$ 由业务配置（本报告实测 4×3 组阈值网格，见 §2.7.2）。

## 二、计算过程

> **口径说明**：需求只给判定方向，本报告以王惠三维十一子项为打分内核、以阈值法为名单外壳；已由脚本 `code/M_TECH_DS_07_TECH_INNOV_004.py` 实测跑通，结果见同目录 `M_TECH_DS_07_TECH_INNOV_004_out.json`。文内引用为 SCI 叙述式 (Author, year)，完整题录见文末「参考文献」。

### 2.1 方法选择：三维十一子项分治——全量维出分、抽样维出画像、缺维出披露

方法选择由「子项的数据形态」而非「公式的完整性」决定。第一层是**规模维走全量批次口径**：申请量与授权量必须按申请年分批次读，因为授权率的分母是「当年申请」而不是「当年存量」（审查周期 2-4 年，当年授权率会系统低估近期批次）；国家统计局的创新产出指标同样以「每万名 R&D 人员高价值发明专利拥有量」这类存量/强度口径规避审查滞后（国家统计局, 2024）。第二层是**质量维拆成「可逐域」与「仅全局」两段**：技术宽度由主分类+附加分类直接数出，可逐 IPC4 计算；家族规模、被引次数、法律稳定性三子项覆盖率 0.68%-0.70%，且其 pn 与主表可连接的 IPC4 仅 3 个，因此只在全局样本上报告均值与分布，不编造域级值。第三层是**市场潜力维只保留转让**：许可、诉讼、质押、开放许可四子项在 2,000 条法律事件抽样中分别为 2 / 0 / 10 / 1 例，分母不足，任何占比都无统计意义，按「披露而非计算」处理。

第四层是**主体识别外壳用双阈值而非综合分排名**。理由有二：其一，需求 (8) 原文明写「设定一个指标的阈值」，阈值法是需求指定的治理动作，不是本报告的替代方案；其二，综合分在当前数据下不闭合（7 子项缺），而「≥N 件且批次授权率 ≥G」的两个阈值都是可逐家复核的原始量，政策场景可解释性更强。综合分保留为「排序参考」并在输出中显式标注 `composite.closed=false`，避免消费方误读。这一分层策略的实质是：**能用全量说话的用全量，只能用抽样说话的标注抽样，没数据的不假装有**——三者共同构成诚实输出，而不是用插补把矩阵填满（附录 C.6 明列插补风险）。

### 2.2 步骤 1｜规模维：申请量、授权量与批次校正授权率

规模维在主表上按 IPC4 聚合：20 万件 PK 等距分片样本中 164,684 件带 IPC4（82.3%），覆盖 620 个 IPC4 与 49,121 个申请主体。域级实测前五：G06F 19,170 件申请 / 9,760 件授权 / 授权率 50.91%；G06N 9,110 / 4,803 / 52.72%；H04L 6,089 / 2,681 / 44.03%；G01N 6,047 / 3,998 / 66.12%；G06Q 5,928 / 2,688 / 45.34%。授权率跨度 29.4%（H04W）到 78.8%（H05K），说明「域」本身对授权率有强结构效应——通信与电学域的发明专利占比高、审查慢，光学与机械域的实用新型占比高、授权快，跨域直接比授权率无意义。

批次校正的做法是把同一主体的申请按 `apdt_year` 切分，逐年算授权率。实测八个头部主体的批次曲线呈同向单调下滑（2021 批 → 2022 批 → 2023 批 → 2024 批）：维沃 71.4% / 44.1% / 21.6% / 17.4%；OPPO 52.7% / 35.5% / 11.1% / 3.7%；华南理工 80.9% / 82.7% / 67.0% / 62.1%；比亚迪 83.0% / 73.3% / 65.7% / 58.0%；广东工业 81.3% / 84.4% / 66.7% / 71.9%；广东电网 71.2% / 56.8% / 27.2% / 32.1%；中山大学 84.9% / 82.0% / 67.0% / 59.4%；华为四批为 1,386 件 / 35.4%、1,126 / 16.3%、1,143 / 10.2%、1,158 / 5.5%。这不是八家同时「质量崩塌」，而是公开-实审-授权链条的固有滞后：2024 批的申请在取样时点（2026-10）平均只经过 2 年审查窗，发明专利授权率自然低。**结论：领先判定必须用成熟批次（2021 批或更早）的授权率，或对批次做等窗校正；直接用全量授权率会把「近期申请强度大」的主体误判为「质量差」**——华为整体授权率 15.26% 与其 2021 批 35.4% 的差额，正是这一伪影的量化幅度。

域级集中度同样值得披露：G06F 域内 19,168 件专利分摊在 1,784 家主体（≥2 件）上，龙头华为份额 5.10%，前 10 主体合计 19.27%——**这是一个高度分散的领域，不存在「一家独大」**；因此「领先机构」在 G06F 只能是「一档名单」而不是「一个名字」，阈值法比 Top-N 更贴合领域结构。

### 2.3 步骤 2｜质量维：技术宽度可逐域、家族/被引/法律仅全局

技术宽度是质量五子项中唯一可逐域全量计算的：件均 IPC4 去重数 1.628（中位 1、最大 12、≥2 占 42.45%），域级差异显著——G06N 2.615、G06V 2.526、G06T 2.384、G06Q 2.317 属「交叉型」技术，G06F 1.971、H05K 1.961、G05D 1.83 属「纵深型」技术，H04W 1.64、H01M 1.579 最低。这一维度直接对应需求原句的「专利技术覆盖范围」，且不需要任何外部回填，是质量维里唯一可以立刻进阈值的子项。宽度的方法学依据是专利质量文献把「技术范围」列为质量/价值的独立维度（Lanjouw & Schankerman, 2004 的 claims 与 scope 思路），本报告以 IPC4 覆盖数作其可算代理并在输出中标注 `proxy=true`。

家族规模、被引次数、法律稳定性三子项只在全局样本上报告：同族表 20,593 行、均值 11.591 位成员、最大 293 位；被引表 20,515 行、均值 0.526 次、被引>0 占 17.83%、最大 55 次；法律表 2,000 行、授权 1,249（62.45%）、实质审查 514、撤回-视为撤回 93、公开 73、驳回 35。三者的共同问题是**覆盖率 0.68%-0.70% 且 pn 与主表几乎不相交**——本报告实测把三表按 pn 连回主表后，法律维只连上 3 个 IPC4、家族维连上 0 个（`join_coverage.legal_joined_ipc=3`）。因此域级质量分不可算，任何「G06F 家族规模 11.2」式的数字都是编造；本报告只给全局值并明示「不可逐域外推」。这一披露同时解释了对标口径：国家创新指数把「有效发明专利数量」作知识创造维指标（中国科学技术发展战略研究院, 2023），《中国企业创新能力评价报告》把「知识产权能力」列为四维之一（中国科学技术发展战略研究院等, 2023）——官方做法同样依赖登记簿级全量数据，本库当前不具备。

### 2.4 步骤 3｜市场潜力维：转让可算，许可/诉讼/质押/开放许可近零

转让子项由 `dwd_patent_transfer` 22,809 条记录支撑，按生效年分布 2021 年 326 条、2022 年 1,670 条、2023 年 3,770 条、2024 年 7,711 条、2025 年 5,799 条——四年增长 23.6 倍，是 TECH 域增长最快的市场信号。按 pn 连回主表后，转让记录只连上 72 条到 IPC4（`transfer_joined=72`），原因是转让表 pn 与主表抽样 pn 的交集极小（主表样本按 dwd_id 等距抽取，转让表按全量 pn 抽取），因此**域级转让占比当前不可算**，只能给全库年度序列。这一点必须在产品侧披露：弦线图/排行榜上若展示「G06F 转让强度」，须先做全量 pn 对齐（工程可行，需一次全量 join），不可用样本值替代。

许可、诉讼、质押、开放许可四子项的实测近乎为零：2,000 条法律事件抽样中，138 种事件类型里「许可」命中 2 例、「质押」10 例、「诉讼」0 例、「无效」0 例、「开放」1 例；事件类型以「公开」（1,412）、「实质审查的生效」（1,409）、「专利申请权的转移」（1,125）、「授权」（985）、「专利权的转移」（474）为主，另有大量海外事件（Assignments Before Registration、National Phase Entry 等）。这说明**法律事件表记录的是审查流程事件，不是运营事件**；运营类（许可/质押/诉讼/开放许可）在源侧本身稀疏，须依赖 CNIPA 登记簿或运营平台接口回填。按王惠口径这四子项属于市场潜力维的 4/5，缺它们意味着市场潜力维只剩转让一项，权重 $w_3$ 下的实际区分度仅为转让占比。

### 2.5 步骤 4｜主体识别：双阈值网格与「量质分离」现象

主体识别按需求 (8) 的阈值法执行：先按 `first_applicant_name` 聚合（49,121 个主体，其中 220 家 ≥60 件进入评分池），再在「申请量阈值 $\theta_N$ × 批次授权率阈值 $\theta_G$」网格上切分。实测四组关键结果：θ_N=500、θ_G=30% → **12 家**；θ_N=500、θ_G=40% → **10 家**（华南理工、比亚迪、广东工业领衔）；θ_N=300、θ_G=50% → **28 家**；θ_N=1000、θ_G=30% → 仅 3 家。阈值上移时名单收缩的速度揭示了「量质分离」：申请量最大的华为（5,388 件）在任何 θ_G ≥30% 的组合下都落榜，而申请量第 3-6 位的华南理工（1,931）、比亚迪（1,853）、广东工业（1,419）、广东电网（1,342）稳定入选。

「量质分离」不是缺陷而是可解释的结构事实。华为的整体授权率 15.26% 来自其申请结构（大量 2023-2024 年发明申请，审查未完成）与其技术领域（H04W/H04L 发明专利审查周期长），批次校正后 2021 批为 35.4%，仍低于华南理工的 80.9%——后者申请结构中实用新型与已授权发明占比高。因此**名单的正确读法是「同阈值下的可比名单」，不是「跨阈值的好坏排序」**；产品侧应同时展示「判定指标值 + 阈值 + 批次覆盖率」，让用户看到名单是怎么被切出来的。需求原文要求「对计算结果进行有效性验证和调整」，本报告的把关方式是：阈值表全量跑通、名单可逐家回溯原始件数与批次授权率、并在 out.json 中固化 12 组阈值结果，任何一组都可复算。

此外需要披露一处对齐缺口：主体名称未做归一（`有限公司` / `股份有限公司` / 括号地名 / 英文名并存），同一集团的多法人主体被分别计数（例如 APTIV 系、西门子医疗系在转移表中以多个名称出现，详见 007 报告）。本报告的名称对齐只做去空白与 `NULL` 字面串过滤，未做实体消歧，因此「华为技术有限公司」与「华为终端有限公司」是两家主体——这会低估集团级领先度、高估主体数量。消歧是 007 的同一待办，须统一建设。

### 2.6 步骤 5｜综合分的闭合性判定与输出契约

王惠 0-100 综合分的闭合性逐项核对：规模维 2/2 可算、质量维 2/5 可算（宽度全量、法律稳定性仅全局、家族/被引仅全局、权利要求缺列）、市场潜力维 1/5 可算（转让）。合计 5/11 子项具备可用数据，6/11 缺或仅全局。若强行合成，权重 $w_2$ 的 5 个子项里有 3 个是全局常数（对所有主体同值），归一后为 0.5 常数项，实际只有宽度在区分——**这不是「三维综合」，而是「规模 + 宽度 + 转让」的加权**，与王惠口径的语义不符。因此本报告输出 `composite.closed=false` 并附 `missing_subindicators` 清单，产品侧在数据补齐前只展示分维值，不展示 0-100 总分。

输出契约（JSON 结构）：`dim1_scale[{ipc4,n_app,n_grant,grant_rate,width_mean,influence_0_100}]`、`dim2_quality{family_mean_members,cited_avg,cited_pos_share,legal_stable_share,domain_level_join}`、`dim3_market{transfer_rows,transfer_by_year,legal_event_counts_2000}`、`dim4_entities{n_scored,top,thresholds,hhi_by_domain_top16_entities}`、`coverage{}`、`subindicators{computable_full,sample_only,missing}`、`composite{closed,reason}`、`support_judgment{}`。关键设计是把「覆盖」与「缺失」写进契约本身，消费方读到的不是一组漂亮的总分，而是一张带缺口的体检表。

**建议：框架完整采用王惠（11 子项不动、维内归一与维间加权结构不动），但综合分暂不输出；主体名单改用需求 (8) 的双阈值法作为产品面，公式定义人维持「王惠」。** 判定过程：①语义覆盖——王惠三维十一子项与本件需求「专利数量 + 专利质量 + 技术覆盖范围」逐一对应，且比需求更完整（多出市场潜力维），满足「语义同维」；②可复现性——11 子项中 2 项全量、1 项（宽度）全量、1 项（转让）全量、3 项仅全局、4 项近零/缺列，**王惠口径在当前库表不能完整复现**，故不满足「同样可复现」这一条；③结果合理性——本报告已用王惠子项跑出域级分维与主体分维，分维值有区分度且业务可解释（华为量最大但批次授权率最低、华南理工量质均衡），说明子项选择正确。

因此落在规则 5（两种方法各占优势，给混合建议并明确待甲方裁决点）：**打分内核从王惠、名单外壳从需求阈值法**。待甲方裁决三点：其一，三维权重 $w_1,w_2,w_3$ 的缺省值（建议先按等权 1/3 试跑，待运营事件回填后重估）；其二，阈值 $(\theta_N,\theta_G)$ 的业务取值（本报告给 12 组实测，θ=500/40% 出 10 家可作为初始值）；其三，综合分是否允许在「4/11 子项缺失」状态下以「分维展示 + 总分留白」方式上线。王惠口径本身无缺陷，缺的是四类运营/文本数据；数据补齐后应按王惠原式输出 0-100 分，本报告的 `composite.closed=false` 即为该切换点的开关。
