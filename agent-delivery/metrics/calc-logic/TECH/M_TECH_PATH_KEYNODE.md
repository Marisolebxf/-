## 口径定义

本件先做了一次**证伪实验**：如果「关键节点」指「不可替代的割点」，那深圳技术图上 16 个割点里最强的 B62D 移除后也只带走 5 个节点（2.21%），说明网络里**没有不可替代的单点**；于是把定义改成「流量型卡位」，用「介数 40% + 跨部类共现 35% + 强度 25%」三合一打分，分层得到 T1 7 个、T2 21 个、T3 210 个。三合一分在 ±50% 阈值档的 Spearman 为 0.8798—0.9332，稳健；但收紧 100% 时降到 0.6523、T1 只保住 3/7，且 T1 七个点彼此密度 0.9524（几乎是完全图），不是七个独立卡位。判**部分支持**。
