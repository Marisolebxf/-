## 口径定义

专利侧可以给出「堵点候选面」：634 个 IPC4 域中 **238 个**有足够历史量，148 个负增长、115 个跌幅不低于 10%，其中 **18 个**同时满足「2024 年不少于 1,000 件」与「2021→2024 跌幅不低于 10%」，按「跌幅×规模」排序输出，并附申请人集中度、头部结构与头部授权率。但需求要的是「原因识别」——转化流量、市场融资、政策工具、链环停留四类证据全部缺键：转让表名称命中 2.07% 且无 IPC4、融资表无技术域、政策 theme 19,998/20,000 为空、链环无运营表。因此只能交付**候选面 + 归因框架**，不能交付因果结论，按四档口径落**部分支持**。
