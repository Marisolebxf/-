## 口径定义

刻画目标企业集合在各产业链节点上空间分布的均衡水平，基于各产业链节点内企业数量占比构建归一化香农熵。取值0-1,值越接近1表示企业在各节点上分布越均匀（高度多元化），值越接近 0 表示高度集中在少数节点。

## 计算逻辑说明

```
基于各产业链节点企业数量占比计算得到的香农熵，除以存在企业覆盖的去重产业链节点总数的自然对数完成 0~1 归一化；
```

**计算公式文件**：`M_ENT_DIVERSIFICATION_INDEX.md`
