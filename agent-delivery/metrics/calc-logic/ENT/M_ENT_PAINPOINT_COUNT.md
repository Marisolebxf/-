在特定统计周期内，通过企业发展痛难点识别模型，基于经营竞争力、盈利能力、生产效率、人才状况与行业均值阈值的比对分析，识别出存在至少一个维度痛难点问题的企业数量。依照需求文档提供的构建方法。

## L1 计算逻辑说明

```
从经营竞争力、盈利能力、生产效率、人才状况四个维度，将各指标实际值与行业均值阈值比对，低于阈值的企业计为存在痛难点，统计去重数量。
```

**计算公式文件**：`M_ENT_PAINPOINT_COUNT.md`
