## 摘要

UI 企业发展页的产业集群企业数量排名（排序指标）。本件以 L1 行业为集群代理复现排名：制造业 **55,282**、批发和零售业 **48,654**、科学研究和技术服务业 **37,181**、信息传输/软件/信息技术服务业 **19,998**（distinct L1 = **20**）。判档部分支持，映射授权后即切真口径。

## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展 → DevelopmentOverviewPanel（按产业集群企业数量排名排序）。

### 1.2 为什么需要本指标

排名是企业发展页的导航序：用户按集群企业数量从大到小浏览产业集群，快速定位企业集聚度最高的方向。

### 1.3 需求文档是否给出定义方法

**需求文档没提及**「产业集群」的映射口径（哪些行业码归入哪个集群）；Q068 集群映射存在于历史 demo 库，正式口径未在可写库落地。

### 1.4 类似指标权威方法可行性分析概要

产业集群通行口径族：①国标行业大类（L1，本件代理采用，20 类实测）；②战略性新兴产业集群（工信部目录，需码表）；③地方特色集群（如深圳「20+8」，需码表）；④Q068 集群映射（历史口径，等 append 落地）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 企业分析>企业发展>DevelopmentOverviewPanel.vue:L3（20261104 盘点实拍）；缺口清单 seq35。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（产业集群相关叶）。
- 探针证据：`metrics/repro/out/M_ENT_UI_DEVCLUSTER_BATCH_PROBE_out.json`（live DIM 16 表全名单实测无集群面）。

### 1.6 推测原意与推测定义

**推测定义（非甲方闭合）**：产业集群企业数量排名 = COUNT(企业) GROUP BY 集群 ORDER BY COUNT DESC；本件集群=L1 行业（代理）。**升档触发器**：集群映射表在可写库 append 落地（走 `ods_sync.py` 同步路径，绝不 replace 共享库）。
