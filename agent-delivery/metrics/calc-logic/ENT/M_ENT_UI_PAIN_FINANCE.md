## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展痛难点分析 → 诊断范围「融资」。

### 1.2 为什么需要本指标

融资维回答「这家企业是否面临融资堵点」：融资事件时间序列是融资活动最直接的公开记录；「最近一轮距今时长」「轮次断档」是融资难最常用的代理观测。

### 1.3 需求文档是否给出定义方法

**需求文档没提及。** 仅有模型功能叶与维度名，无「何为融资痛难点」的判定规则。

### 1.4 类似指标权威方法可行性分析概要

企业融资状况观测通行方法族：①融资事件序列（轮次/金额/时间，公开披露与工商登记）；②资本结构（股权质押、股东质押比例）；③资本市场通道（上市/挂牌状态）。本件采用 ①（25,654 行确定）+ ③（新三板轮次 3,349 行可代理）；②暂无承载。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 企业分析>企业发展痛难点分析>诊断范围「融资」（20261104 盘点实拍）；缺口清单 seq30。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md` 企业发展痛难点分析模型（无本维逐项口径）。
- 探针证据：`metrics/repro/out/M_ENT_UI_PAIN_FINANCE_out.json`。

### 1.6 推测原意与推测定义

**推测定义（非甲方闭合）**：融资维可观测面 = 企业融资事件序列（轮次/时间）；「是否构成融资痛难点」判定留模型层（典型代理：最近一轮距今时长、轮次断档）。**升档触发器**：甲方给出「融资痛难点」判定规则（如 N 月无新一轮），同一原料直接出模型结果。
