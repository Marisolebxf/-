## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展 → KeyEnterprisesPanel 重点企业领域统计（L448）。

### 1.2 为什么需要本指标

领域分布是重点企业工作台的结构视角：上市资本集聚在哪些产业领域，引导用户按领域下钻重点企业清单。

### 1.3 需求文档是否给出定义方法

页面语义直读（按领域统计）；「领域」实测口径=L1 国标行业门类（与产业树 L1 一致）。

### 1.4 类似指标权威方法可行性分析概要

重点企业领域口径族：①国标 L1 门类（本件采用，与链树层级对齐）；②战略新兴产业目录（需码表）；③产业链节点归属（需 node_company_count 配合，见 `M_ENT_UI_DEV_GRAPH` 披露）。完整版见附录 C。
