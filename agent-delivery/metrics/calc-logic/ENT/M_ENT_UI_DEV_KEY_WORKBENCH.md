## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展 → 产业链重点企业工作台（KeyEnterprisesPanel）。

### 1.2 为什么需要本指标

工作台是「重点企业 × 产业链」的操作面板：按链筛选重点企业清单，支撑评估/跟踪/维护动线，是企业发展页的重操作区。

### 1.3 需求文档是否给出定义方法

**需求文档没提及**「重点企业」的判定规则（哪些标签/阈值入围）。

### 1.4 类似指标权威方法可行性分析概要

重点企业通行口径族：①资本市场面（上市/挂牌，本件实测 1,971 家证券代码）；②资质荣誉面（高企/专精特新/小巨人，live 底册 `is_high_tech` 等布尔列在）；③规模面（营收/注册资本门槛）；④链地位面（链主/关键节点，需链树挂接数配合）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 企业分析>企业发展>KeyEnterprisesPanel.vue:L294（20261104 盘点实拍）；缺口清单 seq34。

### 1.6 推测原意与推测定义

**推测定义（非甲方闭合）**：产业链重点企业工作台 = 按产业链归属组织的重点企业操作清单（重点=多标签并集，具体口径待甲方）。**升档触发器**：甲方给出重点企业判定规则；标签列覆盖核清。
