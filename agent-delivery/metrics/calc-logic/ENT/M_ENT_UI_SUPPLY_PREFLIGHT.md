## 摘要

UI 企业供应链关系分析的预检面板（选企业后交互态）。本件实测供数面与关系边面可用性：企业投资关系 46,967 行、产业基金投资项目 10,891 行；权限判定属系统配置如实披露。判档部分支持。

## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业供应链关系分析 → 数据与权限预检（选企业后触发）。

### 1.2 为什么需要本指标

预检是供应链分析的准入闸门：分析前自检「该企业的供应链数据是否可用、当前用户是否有权限」，避免空转分析与越权访问。

### 1.3 需求文档是否给出定义方法

**需求文档没提及**预检的判定规则（何种数据状态算「可用」、权限矩阵如何配置）。

### 1.4 类似指标权威方法可行性分析概要

数据预检通行口径族：①供数自检（目标企业在关系边面的覆盖：投资/供应商/客户边计数，本件实测承载）；②权限自检（RBAC 角色×数据域矩阵，系统配置面）；③数据新鲜度自检（update_time 距今）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 企业分析>企业供应链关系分析>预检面板（20261104 盘点实拍）；缺口清单 seq26。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（供应链关系相关叶）。
- 探针证据：`metrics/repro/out/M_ENT_UI_DEVCLUSTER_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**推测定义（非甲方闭合）**：预检结果 = {供数：企业在关系边面的记录数>0 → 可用；权限：用户对供应链数据域的授权状态}。供数半边可复现，权限半边等配置口径。**升档触发器**：权限矩阵或接口契约给出。
