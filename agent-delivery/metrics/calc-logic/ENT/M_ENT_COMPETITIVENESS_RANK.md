## 摘要

「企业竞争力排名」输出一张全库排序榜：创新（专利规模）、技术广度（IPC4）、资本活跃（投资 + 股东边）、经营年限、风险扣分，五维加权。它服务的是企业评价与区域实力对比两个场景。

实际参与排名的是四维：经营维（营收/利润）只有 0.734% 的企业有值，用它会让榜单只剩 1,388 家上市公司；风险维没有逐企业扣分数据，按 0 处理等于不扣分。候选集 139,189 家（有专利或有资本边），首位比亚迪 0.644、次位华为 0.627、第三广东电网。

Top100 的城市分布是深圳 57、广州 35、东莞 4、惠州 4。这个分布与四市的企业基数基本同向，说明评分没有明显的城市偏好；但也说明它测的是「大企业密集度」，不是「城市竞争力」。

结论是「部分支持」：榜单可出、可看结构，但缺经营与风险两维，不能当「综合竞争力」的权威排名。脚本 `code/M_ENT_COMPETITIVENESS_RANK.py` 只读快照，重跑 0.4 秒。

## 一、需求定义概述

### 1.1 所属功能模块

该指标挂在**企业服务 → 企业评价 → 竞争力榜单**。页面形态是一张长榜：排名、企业、总分、五维分解、城市。用户从榜上看头部企业，也用它做区域对比（某市有多少家进前 100）。

它与 `M_ENT_TECH_POWER_SCORE` 的区别是：后者只算专利三维，是纯技术分；本件加了资本与年龄，是「综合实力」的近似。两者头部高度重叠（比亚迪、华为都在前列），但中段差异明显。

| 项目 | 内容 |
|---|---|
| 功能路径 | 企业服务 → 企业评价 → 竞争力榜单 |
| 页面载体 | 竞争力榜单、企业画像卡 |
| 输出形态 | 企业 × 总分 + 五维分解 + 排名 |
| 更新频率 | 建议年度 |
| 粒度 | 企业级 |

### 1.2 为什么需要这个指标

竞争力排名回答的是「谁是这个区域里最强的企业」。它是政策资源分配、产业宣传、区域对比的共同基础设施：没有统一排名，每个部门各拿一套榜单，数字对不上。

第二个用途是结构分析。Top100 的城市分布（深圳 57、广州 35）能看出区域企业实力的集中度；五维分解能看出「这家企业强在哪一维」，进而判断它是技术驱动还是资本驱动。

第三个用途是对账。甲方报告里写「我市有 X 家企业进入全国竞争力 500 强」，本件能给出本地口径的前 100，并说明与外部榜单的差异来自哪一维缺失。

### 1.3 需求文档是否给出定义方法

**需求文档给了五维但没给公式与权重。** calc-logic 写的是：

> 企业竞争力排名：综合创新能力、技术广度、资本实力、经营质量与风险水平，输出企业竞争力排序。

五维都点名了，但「经营质量」在库内只有 0.734% 覆盖，「风险水平」没有逐企业分。本件的处理是：经营维剔除、风险维按 0，实际排名用四维。这是一个必须披露的口径降级。

### 1.4 类似指标权威机构构建方法可行性

企业竞争力评价在实践中有三类：官方的高企/百强榜、商业机构的综合评分、学术的多维竞争力模型。它们的共同点是都需要财务数据，而这正是我们最缺的。

| 方法族 | 代表机构/文献 | 核心构架 | 与本指标贴合度 |
|---|---|---|---|
| A 企业百强榜 | 中国企业联合会；地方百强榜 | 按营收排序，辅以利润、资产 | 需营收，库内覆盖不足 | 中（榜单形态可借） |
| B 商业综合评分 | 企查查/天眼查评分 | 工商、司法、知识产权、经营多维合成 | 闭源、权重不公开 | 中（维度可参考） |
| C 竞争力模型 | Porter 五力；资源基础观 | 按资源、能力、市场地位评价 | 定性框架，难量化 | 低 |
| D 四维代理 | 本件做法 | 专利 + 广度 + 资本 + 年龄 | 缺经营与风险 | 高（可落地） |
| E 转发上游排名 | 项目内排名指数 | 直接转发 | 上游未出数 | 低（不可用） |

**A 族（百强榜）**是最贴业务需求的，但它按营收排序，而我们的营收覆盖只有 0.734%。若硬用，榜单会退化成「上市公司榜」，与「竞争力」不是一回事。

**B 族（商业评分）**把司法风险纳入，本件缺这一维。这会导致有大量被执行记录的企业排名偏高——恒大一类的企业如果专利与资本边不弱，会出现在中上位置。

**C 族（五力/资源基础观）**提供的是解释框架，不是可计算的公式。本件借它的「资源 + 能力」二分（专利=资源、资本=能力），但不做完整实现。

### 1.6 推测原意与依赖维度

本报告推测的定义：**score = 0.35×创新 + 0.20×广度 + 0.25×资本 + 0.10×年龄 − 0.10×风险**，风险本期按 0。

年龄分是 `min(age, 30) / 30`，即 30 年以上得满分。这个映射奖励「老企业」，与「竞争力」的关系是弱的——它更像「存续能力」。

边界：① 候选集为有专利或有资本边的企业；② 经营维剔除；③ 风险不扣分；④ 权重为默认值。

| D2 | 技术广度（IPC4） | 计数 | 有 |
| D3 | 资本实力（投资+股东边） | 计数 | 有，46,967 + 70,034 |
| D4 | 经营质量（营收/利润） | 金额 | 不可用（0.734%） |

## 二、计算过程

### 2.1 总体思路与数据流

四维取数 → 归一 → 加权 → 减风险（本期为 0）→ 排序。经营维不参与，但在产物里保留字段位，标注为缺失。

保留字段位是为了让下游知道「这一维本该有」。如果直接删掉，读的人会以为竞争力就只有四维。

| 维度 | 来源 | 权重 | 状态 |
|---|---|---|---|
| 创新 | dwd_patent | 0.35 | 参与 |
| 广度 | IPC4 | 0.20 | 参与 |
| 资本 | invest + shareholder | 0.25 | 参与 |
| 年龄 | base.est_year | 0.10 | 参与 |
| 风险 | 六张风险表 | −0.10 | 按 0，不扣分 |
| 经营 | 营收/利润 | — | 剔除 |

### 2.2 口径定义与公式

`score = 0.35*innov + 0.20*breadth + 0.25*capital + 0.10*age - 0.10*risk`，risk 本期恒为 0。

capital 把投资边与股东边合并计数，权重相同。这意味着「被投」与「投资」被视为同等资本活跃，业务上不完全等价，但库内无法区分方向。

| 参数 | 取值 | 说明 |
|---|---|---|
| 权重 | 0.35/0.20/0.25/0.10/−0.10 | 项目默认 |
| 年龄上限 | 30 年 | 30 年以上满分 |
| 风险 | 0 | 未接入 |
| 候选 | 139,189 | 有专利或资本边 |

### 2.3 候选集与经营维剔除

候选集从 189,116 家主档出发，保留有专利或有资本边的记录，剩 139,189 家。这个规则比招引榜宽（招引要求有专利且非企业排除），因为竞争力榜允许纯资本型企业的存在。

经营维剔除的理由是覆盖 0.734%：1,388 家有营收的企业里大部分是上市公司，若纳入，榜单会变成「上市公司竞争力榜」，且非上市企业全部得 0 分。这不是竞争力差异，是披露差异。

| 项 | 数量 | 说明 |
|---|---|---|
| 主档 | 189,116 | 全量 |
| 候选 | 139,189 | 有专利或资本边 |
| 有营收 | 1,388 | 0.734%，不参与 |
| 非企业 | 已排除 | 高校/机关 |

### 2.4 计算步骤（脚本逐步实现）

1）读主档、专利、资本快照；2）按 org_id 聚合四维；3）筛候选；4）逐维归一；5）加权、减风险（0）、排序取 top100。

第 5 步的减风险虽然本期为 0，代码里保留了这个减法，方便后续接入时不用改结构。

## 四、数据缺失情况

### 4.1 缺口清单

缺口有四类：经营维不可用、风险维未接入、权重未裁定、年龄覆盖不足。第一类无解（需甲方补数），第二类可做（接风险表），第三类待决策，第四类可回填。

| 缺失项 | 影响 | 当前处置 | 补齐路径 |
|---|---|---|---|
| 经营维 | 榜单缺「赚钱能力」 | 剔除并披露 | 甲方提供财报/统计口径 |
| 风险维 | 有风险企业排得偏高 | 按 0 | 接六张风险表做扣分 |
| 权重 | 非甲方认可 | 默认值 | 甲方裁定 |
| 年龄覆盖 | 23.1% 有成立年 | 无成立年不进年龄分 | 回填登记日期 |

### 4.2 逐条影响

风险维按 0 的后果是方向性的：恒大地产有 6,410 条风险记录，但它如果专利与资本边不弱，会排在干净的中小企业前面。这不是随机误差，是系统性偏袒「有记录但没扣分」的企业。

经营维剔除的后果是「上市公司与非上市公司不可比」。1,388 家有营收的企业里大部分是上市公司，若纳入，非上市企业全部得 0，榜单会变成「谁上市了谁靠前」。

年龄分的映射（30 年封顶）也值得商榷。它奖励老企业，而老企业未必更有竞争力。这个选择是为了让「存续」成为一个正面信号，但它把「年轻高成长」压低了。

### 4.3 明确不做什么（禁止的替代）

- 不把四维分当「综合竞争力」——经营与风险两维缺失
- 不把营收纳入排名——覆盖 0.734%，会退化成上市公司榜
- 不把年龄当竞争力——它只是存续年限
- 不对外发布未标注缺失维的榜单
- 不用风险为 0 的分数做尽调

## 五、王惠方法对照

王惠口径要五维。本件实际四维，经营与风险缺失。这是本批里口径降级最明显的一件。

## 附录 M 开发交接说明

**问：榜单名字能不能改？**

答：建议改「企业综合实力（技术资本）榜」。叫竞争力会误导。

**问：怎么补风险？**

答：接六张风险表，按记录数分档扣分（如 0 条 0 分、1—10 条 −0.02、>100 条 −0.1）。规则需甲方确认。

**问：城市分布能说明什么？**

答：只能说明大企业密集度。不能说明城市竞争力，那需要人均产出等指标。

**问：多久更新？**

答：年度。专利与资本关系变化慢。
