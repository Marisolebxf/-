## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展痛难点分析 → 诊断范围「管理」。

管理维回答「这家企业是否面临管理堵点」：高管/股东登记变动反映治理结构稳定性，管理机构登记与财务管理列反映管理规范化程度。

### 1.3 需求文档是否给出定义方法

**需求文档没提及。** 仅有模型功能叶与维度名，无「何为管理痛难点」的判定规则。

### 1.4 类似指标权威方法可行性分析概要

企业治理与管理能力观测通行方法族：①治理结构稳定性（高管/股东变更频率）；②管理规范化（管理机构资质登记、财务审计意见）；③管理费用效率（管理费用率趋势）。本件采用 ①（登记面数据在）+ ③（列在、覆盖待核）；②部分承载（产业基金管理机构登记）。完整版见附录 C。
