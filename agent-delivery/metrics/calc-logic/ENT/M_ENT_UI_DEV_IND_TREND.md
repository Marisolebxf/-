## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展 → DevelopmentOverviewPanel 选中产业历年企业数量趋势。

### 1.2 为什么需要本指标

与深圳锁定版（seq37）互补：用户先选产业、再选区域（不限于深圳），看该产业在所选区域的历年企业数量变化。

### 1.3 需求文档是否给出定义方法

页面语义直读（所选产业 × 所选区域 × 历年 计数趋势）；「历年」实测口径=注册年（1951-2026 可全窗口支撑）。

### 1.4 类似指标权威方法可行性分析概要

同 seq37 口径族：①注册年计数（本件采用）；②存续修正（`reg_status` 可叠加）；③迁入迁出净额（无承载）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 企业分析>企业发展>DevelopmentOverviewPanel.vue:L3（20261104 盘点实拍）；缺口清单 seq39。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（企业画像/趋势叶）。

### 1.6 推测原意与推测定义

**定义（页面语义直读）**：选中产业历年企业数量趋势 = COUNT(企业) WHERE 行业=所选 AND 城市=所选 GROUP BY 注册年。
