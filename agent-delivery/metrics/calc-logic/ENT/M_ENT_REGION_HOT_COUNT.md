## 口径定义

「热点区域」的本质是**分布的头部**，只要区域家数可算，头部就可算；本指标不需要任何外部数据，属纯粹的排序截断转换，故判 **完全转换支持**；唯一未闭合的是 N 的甲方取值，它是参数缺口，不是数据缺口。

## 数据支持度与缺口

- **判档**：完全转换支持
- **判档理由**：区域家数分布可由 gkx.dwd_org_base_info 一次 GROUP BY city 得到，TOP N 求和与集中度均为确定性派生；结构+数据量均够，缺的只是 N 的甲方取值与目标表。
- **基期声明**：本指标为截面计算，产物与参数中均无年度键、无年份窗口，不存在时序分母，故 used/missing 均为空；不是「缺年按 0 摊入」的情形。
