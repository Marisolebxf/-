## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展痛难点分析 → 诊断范围「技术研发」。

### 1.2 为什么需要本指标

技术研发维回答「这家企业是否面临研发堵点」：专利活动强度是技术产出最直接的公开记录，研发人力投入是投入面的直接观测，两者合成技术维可观测面。

### 1.3 需求文档是否给出定义方法

**需求文档没提及。** 仅有模型功能叶与维度名，无「何为技术研发痛难点」的判定规则。

### 1.4 类似指标权威方法可行性分析概要

企业技术创新能力观测通行方法族：①专利产出强度（申请/授权计数、专利族规模）；②研发人力投入（研发人员数/占比）；③研发经费强度（R&D 支出占比）。本件采用 ①（数据在且确定性）+ ②（列结构在、数据缺，如实降档）；③暂无承载。完整版见附录 C。

**推测定义（非甲方闭合）**：技术研发维可观测面 = 企业专利活动（产出）+ 研发人力（投入）；「是否构成痛难点」判定留模型层。**升档触发器**：live 研发人力列灌数（或久新机构映射落地）+ 甲方给出判定规则。
