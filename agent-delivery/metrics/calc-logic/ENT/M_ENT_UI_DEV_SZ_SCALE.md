## 摘要

UI 企业发展页的深圳企业规模分析（ShenzhenEnterprisesPanel）。本件实测深圳企业规模四档分布（小型 42,938 / 微型 41,437 / 中型 9,092 / 大型 1,125，覆盖率 98.63%）。判档完全转换支持。

## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展 → ShenzhenEnterprisesPanel 深圳企业规模分析。

### 1.2 为什么需要本指标

规模结构是深圳企业画像的基本盘：大中小微分布支撑「以小微企业为主体的创新生态」叙事，也是规模筛选器的数据面。

### 1.3 需求文档是否给出定义方法

页面语义直读（按规模类型统计）；规模四档（大型/中型/小型/微型）为工商划型标准值域，列值域实测一致。

### 1.4 类似指标权威方法可行性分析概要

企业规模通行口径族：①工信部大中小微划型（从业+营收双维，本件列值域与其一致）；②注册资本分档（见 `M_ENT_UI_DEV_KEY_SCALE_ENT`）；③用工规模（无承载列）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 企业分析>企业发展>ShenzhenEnterprisesPanel.vue:L3（20261104 盘点实拍）；缺口清单 seq38。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（企业画像字段族）。
- 探针证据：`metrics/repro/out/M_B3_DEVCHAIN_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**定义（页面语义直读）**：深圳企业规模分析 = COUNT(企业) WHERE 城市=深圳 GROUP BY 规模类型（大型/中型/小型/微型）。
