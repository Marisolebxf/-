## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 企业分析 → 企业发展 → ShenzhenEnterprisesPanel 所选产业历年深圳企业数量趋势。

### 1.2 为什么需要本指标

趋势是企业发展页的时间视角：用户选择产业方向后看其在深圳的历年企业数量变化，判断产业冷热与迁入迁出节奏。

### 1.3 需求文档是否给出定义方法

页面语义直读（所选产业 × 历年 × 深圳 计数趋势）；「历年」实测口径=注册年（`incorporation_year` 列在，1951-2026）。

### 1.4 类似指标权威方法可行性分析概要

企业数量趋势通行口径族：①注册年计数（本件采用，列实测 67 桶）；②存续状态修正（当前存续才算，`reg_status` 列在可叠加）；③迁入迁出净额（需变更记录，暂无承载）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：live 30892 企业分析>企业发展>ShenzhenEnterprisesPanel.vue:L3（20261104 盘点实拍）；缺口清单 seq37。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（企业画像/趋势相关叶）。

### 1.6 推测原意与推测定义

**定义（页面语义直读）**：所选产业历年深圳企业数量趋势 = COUNT(企业) WHERE 城市=深圳 AND 行业=所选 GROUP BY 注册年。「历年」起止窗口按页面交互（实测数据面 1951-2026 可全窗口支撑）。
