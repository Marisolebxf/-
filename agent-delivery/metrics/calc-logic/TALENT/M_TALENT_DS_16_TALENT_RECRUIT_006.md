## 摘要

需求要评估国际人才来深后的文化融合风险，输出风险等级供用人单位参考。核查 `gkx` 280 张表后：宗教/族群字段 0 列、国籍/签证/居留字段 0 列、文化/社区/宗教类表 0 张、满意度/离职/冲突类表 0 张。`dwd_forg_base_info` 有 20,000 行，名字看起来像「境外人才」，实际是境外**企业**底册（`company_type`、`incorporation_year`、`stock_code`、`registered_capital`），且 `country` 列全空、去重为 0，连企业国别都给不出。

能算的只有「跨文化暴露度」：海外学历 628 人、海外履历 896 人。bio 里提到「华裔」2 条、「外籍」1 条、「海外」10 条、「留学」4 条，占非空 bio（19,109）的 0.0105%—0.0523%，都是自述且无身份等级。

问题在于方向：文化融合风险与跨文化经历通常负相关。经历越多的人，语言、习俗、团队协作越熟，风险越低。用「海外经历多」推「融合风险高」，会把最该引进的人排到最危险的位置。因此本件**不输出风险分、不输出名单**，只落证据。判定「完全不支持」，不是「数据少」。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

挂在「国际人才引进 → 文化融合风险」。前端设想：每位引进人才一个风险等级（高/中/低），附风险因子（宗教差异、家庭随迁、语言、社区支持），供单位决定是否配文化顾问、是否安排家属安置。后端需要：身份字段（国籍/母语/宗教）、文化距离矩阵、适应结果（留存/满意度/冲突记录）。

### 1.2 为什么需要「文化融合风险评估」

引进人才的流失，常发生在入职 6—18 个月：饮食、宗教节日、子女教育、配偶就业、社交圈缺失。用人方希望在签约前识别高风险个体，提前配置支持资源。业务逻辑成立，但需要「人」的数据，而科技文献库只记「成果」。

深圳的境外背景人才池也不大：海外学历 628、海外履历 896、两者兼有 351。即便全量评估，样本也只有数百人，且没有任何身份/宗教/满意度字段。

### 1.3 需求文档是否给出定义方法

没有。需求只给「文化融合风险」四字，未给维度、权重、等级、数据来源。算法库无实现。按铁律第 6 条，本文不把「bio 提到海外」当成「文化融合风险高」——文本提及不是身份，更不是风险。

### 1.4 类似指标权威机构构建方法可行性分析概要

文化融合评估的成熟做法有三类：一是量表（如 CQ 文化智力、ISS 适应量表），二是组织行为数据（留存率、绩效、冲突事件），三是人口与社区数据（国籍构成、宗教设施密度、族裔社区规模）。三类都需要「人对人」的测量或「组织对人」的记录。

`gkx` 三类都没有：量表 0、组织行为 0、社区 0。唯一接近的是「境外企业底册」，但它是企业不是人。这一点必须在文档里写清楚，否则容易被误认为「有境外数据」。

### 1.6 推测原意与推测定义

推测原意：给引进人才一个「文化适应风险预警」，让人单位知道该配什么支持。推测定义应含三层：

- **I 身份**：国籍、母语、宗教/族群、家庭随迁。决定「文化距离」的起点。
- **D 文化距离**：语言距离、宗教差异、饮食/节日差异、社区支持密度。
- **R 适应结果**：留存、满意度、冲突事件、绩效。

风险可分 `Risk = f(I, D) × (1 - R)`。现有数据：I 的字段 0 个，D 的字段 0 个，R 的表 0 张。唯一有数的是「海外经历」X，而 X 与 D 负相关（经历多则距离小），与 R 正相关（经历多则适应好），因此 X 与 Risk 负相关。用 X 当 Risk，方向全错。

## 二、计算过程

### 2.1 公式出处与「不降级」的必要性

无公式可引。常规公式 `Risk = w1·文化距离 + w2·(1-适应度) + w3·家庭因素`，三项输入全缺。若强行用海外经历做 `(1-适应度)`，等于假设「出过国的人适应差」，与现实相反。

铁律第 6 条要求「先实测后定档」。实测结论：可计算维度 0 个，任何分数都是编的。本文的计算过程是「证据核查」，不是「打分」。

### 4.2 对结论的影响边界

本件只回答「库内能否构建」，不回答「业务是否需要」。业务需要，数据做不到。任何声称「用现有数据能评文化融合风险」的方案，必须先回答：身份从哪来、距离怎么算、结果怎么验。三问答不上，就是造数。

### 4.3 不可外推的三件事

第一，不可把 `dwd_forg_base_info` 当境外人才库：它是企业底册，`country` 还全空。第二，不可把海外学历当文化身份：院校国别 ≠ 国籍 ≠ 文化认同。第三，不可把海外经历当风险：方向相反。

补充三条。第四，不可把 bio 的「外籍」1 条当外籍人才总数：自述、无核验、严重漏记。第五，不可把「留学 4 条」当留学经历总量：绝大多数简历不写。第六，不可把本件的 0 维度理解为「不需要关注」：它只说明当前无法测量。

## 五、王惠方法对照与选用建议

### 5.1 王惠原方法还原

王惠系方法在本指标无实现。可追溯做法是「入境前访谈 + 入职后跟进」：由用人单位或人才服务专员了解家庭情况、宗教习惯、社区需求，定期回访。样本小，但能真实识别风险。

### 5.2 新方法概述

本文无新方法。最小可行方案是「身份登记 + 适应问卷」：引进时登记国籍/母语/宗教/随迁，入职 6 个月发一次适应量表，12 个月再发一次，形成 R。没有这两步，任何模型都是空转。

### 5.3 逐维对照表

| 维度 | 王惠方法 | 本文现状 | 差异与风险 |
|---|---|---|---|
| 身份 | 访谈登记 | 0 字段 | 无法替代 |
| 文化距离 | 专员判断 | 0 表 | 无法替代 |
| 适应结果 | 回访 | 0 表 | 无法替代 |
| 家庭 | 面对面 | 0 字段 | 无法替代 |
| 成本 | 人力 | 0 | 采集成本高 |

### 5.4 选用建议与理由

建议**不上线**自动风险评分。若必须给界面，只放「身份与适应数据未采集」的说明与登记入口，不放分数、不放名单。理由：身份/宗教是敏感信息，误判代价高；且现有代理方向相反，会把海外经历丰富的人误标为高风险。

若未来接入登记与问卷，先做 351 名海外背景人才的小样本，验证量表信度，再谈评分。评分上线前必须过合规审查。
