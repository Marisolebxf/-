## 摘要

本文用三个「境外信号」刻画国际流动经历强度：海外学历（`edu_for>0`）628 人、海外履历（`work_for>0`）896 人、国际合著（`nfor>0`）1,824 人；三者兼有的 351 人。20,420 名有姓名学者中，至少命中一个信号的 2,883 人（14.12%）进入评分，其余 17,537 人不评分——「没查到境外经历」不等于「没有境外经历」，不补 0。

得分均值 29.0312、中位 30、p10 3、p90 70、最大 100；A/B/C/D 为 351 / 822 / 680 / 1,030。榜首 30 人全是 100 分，其中 28 人是「海外学历 + 海外履历 + 无论文锚定」的二维满分，2 人是三维满分（国际合著占比 1.0）。**100 分共 127 人**，榜内 1—30 名的顺序没有区分意义，这是本件最需要向读者说明的地方。

壁垒侧四个维度——签证/居留、国籍、家庭随迁、学历认证——在 `gkx` 280 张表里 0 字段。`dwd_forg_base_info` 有 20,000 行，但那是境外**企业**底册，`country` 去重还是 0。因此本件只能回答「谁有国际流动经历」，不能回答「谁被什么挡住」。这个方向必须在 UI 上成对标注，否则「分数高」会被误读成「壁垒高」。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

挂在「国际人才引进 → 国际流动壁垒」。前端设想：给每位人才一个壁垒画像（签证难度、学历认证、语言、家庭、学术网络），标出「流入深圳的主要障碍」，供引才谈判与政策设计参考。后端需要：签证/居留记录、国籍、学历认证状态、家庭随迁、国际合作网络。

### 1.2 为什么需要「国际流动壁垒分析」

引才不只是「发邀请」，还要解决签证、认证、家属、住房、语言。壁垒高的个体，即使学术强，落地成本也高。政策侧也需要知道「哪一类壁垒最常见」，才能设计针对性服务（如学历认证绿色通道、外籍人才居留便利）。

深圳的现实是：2,883 人有境外信号，但真正「当前在深且与深圳有关联」的只有 60 人（含履历/学历关联）。池子小，壁垒又不可测，所以这项工作的价值主要在「摸清经历结构」，不在「预测谁能来」。

### 1.3 需求文档是否给出定义方法

没有。需求只给「签证/居留、学历认证、语言、家庭、学术网络」五个方向，未给字段、权重、量表、判定规则。算法库无实现。本文把可算的三维做成「经历强度」，把不可算的四维列进 `zero_dims`，不做任何替代打分。

### 1.4 类似指标权威机构构建方法可行性分析概要

国际流动壁垒的成熟测法有三类：一是行政数据（签证签发量、居留许可、入境拒签率），二是调查数据（科学家流动意愿、壁垒感知），三是网络数据（合著、机构迁移）。OECD 的 International Migration Outlook 用行政数据，学术界的「brain circulation」研究多用履历与合著。

`gkx` 只有第三类的碎片：履历、教育、合著。行政与调查数据全无。第三类能测「流动发生过」，不能测「流动被什么阻挡」。这是「部分支持」的边界。

### 1.6 推测原意与推测定义

推测原意：识别「想引来但引不来」的障碍，给政策与服务做靶点。推测定义应含五层：

- **V 签证/居留**：签证类型、办理时长、拒签率、居留许可年限。
- **C 学历认证**：境外学历是否已认证、认证时长。
- **L 语言**：工作语言能力等级。
- **F 家庭**：配偶就业、子女教育、随迁人数。
- **N 学术网络**：国际合作强度、机构迁移次数。

现有数据对 V/C/L/F 全无，只有 N 的碎片（合著、履历、教育）。因此本文把 N 拆成 O1/O2/O3 三项，构造「流动经历强度」：

```
S = 100 × (0.35·O1 + 0.35·O2 + 0.30·share) / Σw
O1 = 海外学历（edu_for > 0）
O2 = 海外履历（work_for > 0）
O3 = 国际合著占比 share = nfor / np
```

S 越高，经历越强，通常壁垒越低。**S 不是壁垒分**。

## 二、计算过程

### 2.1 公式出处与降级的必要性

公式无出处，是本文自建。降级两处：一是「壁垒」降级为「经历」，因为壁垒字段全缺；二是「五维」降级为「三维」，因为 V/C/L/F 全缺。两处降级都在 §4.1 写了修复路径。

为什么不直接把 S 取反当壁垒分：取反会假设「没出过国 = 壁垒高」，但没出过国可能是「不想出」而不是「出不去」。方向不确定，取反同样是编。

### 2.2 口径拆解：对象、信号、归一

对象 20,420 名有姓名学者；入池 2,883 人（至少一个信号）；不评分 17,537 人。信号覆盖：

| 信号 | 人数 | 占 20,420 | 占入池 |
|---|---:|---:|---:|
| O1 海外学历 | 628 | 3.08% | 21.78% |
| O2 海外履历 | 896 | 4.39% | 31.08% |
| O3 国际合著 | 1,824 | 8.93% | 63.27% |
| O1∩O2 | 351 | 1.72% | 12.17% |
| 至少一个 | 2,883 | 14.12% | 100% |

归一：`S = 100 × Σ(w·x) / Σw`，缺失维不参与分母。O3 仅在 `np>0` 时有值（2,552 人有值），331 人只有 O1/O2 两维。

| 维度 | 样本 | 中位 | p90 | 最大 | 权重 |
|---|---:|---:|---:|---:|---:|
| S 总分 | 2,883 | 30.0 | 70.0 | 100.0 | — |
| 国际合著占比 | 2,552 | 0.1667 | 1.0 | 1.0 | 0.30 |

### 2.3 依赖分解（两跳停）

第一跳：`dwd_scholar` → 姓名、机构。第二跳：`dwd_scholar_edu` → 境外院校；`work_experience` → 境外机构；论文面板 → 作者机构含境外机构。第三跳（不存在）：签证/国籍/认证/家庭。链断在第三跳。

### 2.4 算路 / SQL

本件零 SQL，读 `code/_snapshots21/talent22_panel_20261022.json`。算路：

1. 遍历 20,420 名学者，读 `edu_for`、`work_for`、`nfor`、`np`。
2. O1 = `edu_for>0`；O2 = `work_for>0`；O3 = `nfor/np`（np>0 才有）。
3. 三者全 0 → 不评分。
4. 按 0.35/0.35/0.30 加权，缺失维归一。
5. 2,883 人内 p90/p70/p40 切档。
6. top30 按分数排序，附 `ov_edu/ov_work/intl_papers/intl_share/np/dims`。

### 2.5 清洗规则

- 境外信号按「院校/机构是否在境外」判定，港澳台按境外计（口径需在 UI 注明）。
- 短期访学与长期任职都算 O2，不区分时长；履历表 `start_time` 是 `varchar(7)`，本件不按年切分。
- 国际合著按「作者机构含境外机构」判定，不按作者国籍；一篇论文有境外机构即计入 `nfor`。
- `np=0` 者无 O3，按两维归一，不补 0；这会让「双信号无论文」者拿满分（见 §2.6）。
- 无任何信号者不评分，不补 0：履历/教育子表有覆盖上限，没查到 ≠ 没有。
- 同名多 scholar_id 不去重（top30 未见重复），但 UI 需按人合并。

分布：均值 29.0312、中位 30、p10 3、p90 70、p99 100、最大 100、最小 0.7895。A/B/C/D 为 351 / 822 / 680 / 1,030（12.17% / 28.51% / 23.59% / 35.73%）。

榜首 30 人全部 100 分：

| 类型 | 人数 | 构成 |
|---|---:|---|
| 二维满分（无 O3） | 28 | O1=1、O2=1、np=0 |
| 三维满分 | 2 | O1=1、O2=1、share=1.0 |

另一个极端：最小 0.7895 是「只有国际合著、且占比极低」的人。中位 30 对应「只有一项信号」的多数人。

#### 2.7.3 结果解读与评审

评审要接受一个事实：这不是壁垒分，是经历分。三处必须改文案——标题写「国际流动经历强度（壁垒逆向代理）」；分数高标「经历强/壁垒通常低」；100 分标「并列，不代表第一」。

分档也不宜叫 A/B/C/D，建议叫「高/中高/中/低流动经历」，避免与「壁垒等级」混淆。

#### 2.7.4 对照需求文档的结果评审

需求要五维壁垒，本文给三维经历；需求要「被什么挡住」，本文只能给「谁流动过」。差距在签证/认证/家庭数据，不在算法。结论：可用于「国际经历结构盘点」，不可用于「签证政策效果评估」。

### 4.2 对结论的影响边界

S 只覆盖「经历」，不覆盖「壁垒」。S 高的人不一定容易引进（可能更贵），S 低的人不一定难引进（可能不想出国）。分档只表示池内相对位置，不表示政策优先级。与深圳关联的 60 人样本太小，不能据此判断深圳的引才难度。

### 4.3 不可外推的三件事

第一，不可把 S 当壁垒分：方向相反。第二，不可把 100 分当「第一」：127 人并列。第三，不可把「无信号」当「无国际经历」：子表覆盖有限。

补充三条。第四，不可把国际合著当「已流动」：合著可以在原地完成。第五，不可把港澳台经历与欧美经历等同：签证与认证难度不同。第六，不可用本件评估政策效果：没有政策前后对照。

## 五、王惠方法对照与选用建议

### 5.1 王惠原方法还原

王惠系方法在本指标无实现。可追溯做法是「个案跟进」：由引才专员逐人了解签证、认证、家属需求，记录卡点。样本小，但能测真实壁垒。

### 5.2 新方法概述

本文用公开数据做经历强度画像：三维加权、池内分档、并列标注。优点是全覆盖可复现；缺点是不能测壁垒、不能分来源国、不能看时长。

### 5.3 逐维对照表

| 维度 | 王惠方法 | 本文方法 | 差异与风险 |
|---|---|---|---|
| 签证 | 个案记录 | 无 | 无法替代 |
| 认证 | 个案记录 | 无 | 无法替代 |
| 家庭 | 面谈 | 无 | 无法替代 |
| 经历 | 简历 | O1/O2/O3 | 可替代但粗 |
| 方向 | 壁垒 | 经历（逆向） | 必须成对读 |

### 5.4 选用建议与理由

建议把本件定位为**经历结构盘点**，不是**壁垒评估**：标题、图例、tooltip 三处都要写「高分 = 经历强 = 壁垒通常低」。榜单一律显示 `dims` 与 `np`，100 分者标「并列」，不排序。

若业务要真壁垒，需接三样数据：出入境居留许可、留服认证、人才服务问卷。接入前，本件只能用于「谁有国际背景」的筛选，不能用于「谁难引进」的判断。
