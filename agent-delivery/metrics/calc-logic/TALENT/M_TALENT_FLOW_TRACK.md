### 0.3 与旧稿的口径差异

旧稿把"流动"等同于"换单位"，未区分同机构晋升与真流动，也未处理并行任职；分母在"有履历人数"与"全库人数"之间来回切。本件固定三个分母并全程标注：

- `work_rows` = 57,117（履历行，不是人）
- `scholars_with_work` = 14,832（有履历的人）
- `scholars_multi_segment` = 9,281（有 ≥2 段、才可能观测到流动的人）

任何"流动率"只在 9,281 上算；对 14,832 算会系统性低估，对 21,316 算则是错的（56.1% 的人根本没有履历）。

## 摘要

1. **能算的部分**：14,832 人有履历，其中 9,281 人有 ≥2 段，识别出 7,168 名有迁移行为的学者、14,121 次跨机构迁移；另有 5,352 对相邻段是同机构内部晋升，单列不计入流动。
2. **城市级迁移只占 5.99%**：846 次跨市迁移 / 14,121 次跨机构迁移。但真正的约束是属地可判率——只有 1,545 对迁移的两端都能判出城市（10.95%），在这 1,545 对里跨市占 54.76%。其余 12,576 对因一端落在海外校名或无法解析的中文校名而失去城市坐标。
3. **深圳净流入 +39**：流入 83 人次、流出 44 人次（两端可定位口径）。流入来源首位是"海外"23 人次，其次北京 7、武汉 3；"未归属"36 人次说明三分之一的流入无法判清来源城市，这是本件最大的口径漏洞。
4. **流向高度集中于海外→北京/上海**：城市对首位是 海外→北京 98 次、海外→上海 61 次、北京→海外 40 次。国内城际流动的单对量级都在个位数到十几，不足以支撑"某城虹吸某城"的强结论。
5. **年度序列右截断严重**：2022 年 937 次为峰值，2025 年骤降至 313 次、2026 年 6 次，这不是流动骤冷，而是在职者尚未产生下一段履历。2024 年之后的年度数字不可用于趋势判断。
6. **发布建议**：可作为"人才履历迁移"主题的**探索性**看板，必须同时展示分母 9,281 与"重叠丢弃 6,215 对"的提示；不可用于城市人才政策的效果评估，也不可单独引用"深圳净流入 +39"而不带"未归属 36"的脚注。

## 一、需求定义概述

### 1.1 业务问题

某城市/某机构的人才池，在观测窗口内是净吸入还是净失血？流入来自哪里、流出去了哪里、集中在哪些学科？深圳在跨市迁移网络中的位置如何？

### 1.2 指标定义

**人才流动轨迹（Talent Flow Track）**：以学者为单位，把其任职履历按时间排序，相邻两段之间的机构变化记一次迁移；迁移按"起点城市→终点城市"聚合，形成城市间有向流网络，并计算每个城市的流入量、流出量、净流量与来源/去向结构。

形式化：设学者 $i$ 的履历段序列为 $S_i = (s_{i1}, s_{i2}, \dots, s_{ik})$，每段有机构 $o$、城市 $c$、起年 $y^{s}$、止年 $y^{e}$。若 $o_{i,j} \neq o_{i,j+1}$ 且时间不重叠，则记一次迁移 $m = (c_{i,j} \to c_{i,j+1})$。

### 1.3 分子与分母

| 指标 | 分子 | 分母 | 说明 |
|---|---|---|---|
| 迁移人数占比 | `movers` = 7,168 | `scholars_multi_segment` = 9,281 | 只在可观测流动的人上算 |
| 人均迁移次数 | `transitions` = 14,121 | `scholars_multi_segment` = 9,281 | 得 1.5215 次/人 |
| 跨市迁移占比 | `city_transitions` = 846 | `transitions` = 14,121 | 得 5.99% |
| 深圳净流量 | 流入 83 − 流出 44 | 不适用（净额） | 净 +39 人次 |
| 深圳流入结构 | 各来源城市 n | 流入 83 | 未归属 36 单列，不摊派 |

### 1.4 统计单元

- 主单元：`scholar_id`（学者），一次迁移是"学者×相邻段对"，同一人可贡献多次迁移。
- 聚合单元：城市对（有向）、机构对（有向）、学科域（取学者主域）。
- 时间单元：迁移年份取**后一段的起年**（到达年），因为"流动发生"以新岗位生效为准。

### 1.5 时间口径

- 起止年来自 `work_experience.start_year` / `end_year`，精度到年，无月日。
- 在职（`cur=1`）者止年按 2026 计，仅用于重叠判定，不用于"流出年"统计。
- 观测窗口：1990—2026。1990 年前无记录，2024 年后右截断。

### 1.6 与相邻指标的边界

| 相邻指标 | 区别 |
|---|---|
| M_TALENT_ORG_DIST | 那里只看**当前**机构分布，不涉及时间与迁移 |
| M_TALENT_RELATION_NET | 那里是**合作网络**（论文共著），本件是**雇佣网络**（履历迁移），两者不要混用"边"这个词 |
| M_TALENT_SZ_SUPPLY_DEMAND | 那里是"岗位需求 vs 人才供给"的结构错配，本件是"人已经怎么动"的事后轨迹 |
| M_TALENT_REGIONAL_DIST | 那里是存量属地分布，本件是属地的**变化量** |

## 二、计算过程

### 2.1 总览

```
work_experience (57,117 行)
   │  按 scholar_id 分组、按 start_year 升序
   ▼
履历段序列 S_i
   │  相邻段配对，剔除时间重叠（后段起年 < 前段止年）
   ▼
候选相邻对 25,688 → 跨机构 14,121 / 同机构 5,352 / 重叠丢弃 6,215
   │  同机构 → internal_moves（5,352）；异机构 → transitions
   ▼
机构对 / 城市对（loc2 判城市）
   ▼
城市聚合：inflow / outflow / net / 来源结构 / 学科结构
```

### 2.2 数据装载

```python
# code/M_TALENT_FLOW_TRACK.py（节选）
def load_work():
    return C.rows("SELECT scholar_id, org, start_year, end_year, cur "
                  "FROM work_experience", snapshot="work")
```

`C.rows` 优先读 `code/_snapshots21/*.json`，快照缺失时才回落到 `gkx` 只读连接。本次运行全部命中快照，未发起线上查询。

跑通输出：

```
work rows 57117
scholars with work 14832
```

57,117 行 / 14,832 人 = 人均 3.85 段，说明履历表记录粒度较细（含同一单位多岗位）。

### 2.3 履历分段与清洗

按 `scholar_id` 分组后按 `start_year` 升序，`start_year` 为空的行直接丢弃（无法定位时间，也无法判重叠）。清洗后：

```
multi-segment scholars 9281
```

只保留段数 ≥2 的人。9,281 / 14,832 = 62.57%，即 37.43% 的人只有一段履历，天然无法观测流动——这不是"没流动"，是"没记录"。

### 2.4 相邻段配对与重叠剔除

对每对相邻段 $(s_j, s_{j+1})$ 判两件事：

1. **时间重叠**：若 $y^{s}_{j+1} < y^{e}_{j}$，说明两段并行（同一单位多岗位、兼职、临床与教职并存），不构成"先后迁移"，丢弃。
2. **机构是否相同**：`o_j == o_{j+1}` 记为内部晋升（`internal_moves`），不计入流动。

结果：

```
candidate pairs 25,688   (= 14,121 + 5,352 + 6,215)
overlap_dropped 6215   (24.19% of pairs)
internal_moves  5352
transitions     14121   (54.97% of pairs)
```

**这是本件最重要的口径事实**：9,281 人共产生 25,688 对相邻段，其中 6,215 对（24.19%）因时间重叠被丢弃。如果这些并行段里有一部分其实是"先兼职后转全职"，那真实流动次数会比 14,121 更高；反过来，如果重叠判据过松（同年算重叠），也会误杀真实的当年跳槽。本件采用严格判据（$<$ 而非 $\le$），对同一年内离职再入职的情形会漏记，故 14,121 是**保守下限**。

### 2.5 城市判归

机构名 → 城市用 `C.loc2()`：先匹配显式覆盖表（`中山大学`→广州、`北京大学深圳医院`→深圳），再按括号内最右城市名判定，最后按校名关键字。判不出的记"未归属"，不猜。

```python
ciy = C.loc2(r["org"]) or "未归属"
```

这一步直接决定城市级流动的质量，也是本件最弱的一环：14,121 次跨机构迁移里，**12,576 次（89.05%）至少一端判不出城市**，两端都可定位的只有 1,545 次（10.95%）。846 次跨市迁移是在这 1,545 次里算的，占 54.76%。

判不出的主体是海外高校的中文名。迁移段里出现频次最高的未匹配机构依次是 `伦敦大学学院`（120 次）、`剑桥大学`（117）、`斯坦福大学`（116）、`麻省理工学院`（105）、`哈佛大学`（97）、`牛津大学`（96）、`东京大学`（92）、`帝国理工学院`（87）、`南洋理工大学`（86）、`曼彻斯特大学`（83）。现有 `is_foreign` 只认国名（"美国""英国"），不认校名，于是这些机构全部落到"未归属"，既不算海外也不算国内城市。

对深圳切片的具体后果：流入 83 人次里 36 人次（43.37%）来源为"未归属"、23 人次（27.71%）为"海外"；这 36 人次大概率也是海外高校，只是校名未识别。

### 2.6 聚合与净流量

对每个城市 $c$：

$$
\text{inflow}(c) = \sum_{c' \neq c} n(c' \to c), \quad
\text{outflow}(c) = \sum_{c' \neq c} n(c \to c'), \quad
\text{net}(c) = \text{inflow}(c) - \text{outflow}(c)
$$

注意分母：`inflow`/`outflow` 都是**人次**，同一人多次进出会被计多次。本件不做"去重人数"版本，因为履历段数不足以支撑"几次迁移算一个人"的归并规则。

### 3.6 反例与边界检验

- **边界 2**：年度峰值 937 对应的分母是当年有到达记录的人数，不是当年全部在职者，不能算"流动率"。

### 4.4 缺口 1：无流动原因字段

**缺什么**：`work_experience` 只有机构与时间，没有"离职原因""去向类型""是否主动"。

**影响**：无法区分主动跳槽、组织调动、企业裁员、退休、以及"换了个挂靠单位但人没动"。本件把同机构相邻段记为内部晋升（5,352 次），但"换机构但人没动"（兼职转正、附属医院与大学之间挂靠变化）无法识别，会虚增流动。

**从哪补**：需要 HR 侧离职登记表或 LinkedIn 类外部数据；库内无替代路径。短期只能接受"机构变化 ≠ 人变化"的噪声。

### 4.5 缺口 2：流出库外不可观测

**缺什么**：学者一旦离开本库覆盖的机构，履历就断在最后一段，没有"已离职且去向未知"的标记。

**影响**：`outflow` 系统性低估。以深圳为例，流出 44 人次里"海外"9、"未归属"14，真正可归因到国内城市的只有 21 人次。若某学者从深圳高校离职去企业（企业不在库内），本件完全看不到。

**从哪补**：需企业侧雇佣数据或专利发明人地址变更（`patent_inventor` 有地址字段，可作弱信号）；当前 `PATENT_SCAN_LEDGER.md` 未收录发明人地址迁移缓存，故未使用。

### 4.6 缺口 3：重叠丢弃 6,215 对

**缺什么**：并行任职无 `is_primary` 标记，只能按时间重叠全部丢弃。

**影响**：流失 30.56% 的候选迁移对，流动次数偏低。若并行段中"后段起年 = 前段止年"被误判为重叠，还会漏记当年跳槽。

**从哪补**：履历表若有 `job_type`（全职/兼职/临床）即可保留"兼职→全职"的转正；当前无此列。替代方案是用 `position` 的变化（如"博士后→副教授"）作为转正信号，但职称填充率仅 63.3%，会引入新的选择偏差。

### 4.7 缺口 4：年度右截断

**缺什么**：2024 年之后入职的人尚未产生下一段履历。

**影响**：`years` 序列在 2024 年（680）、2025 年（313）、2026 年（6）快速衰减，这是观测窗截断，不是流动降温。任何"近年流动下降"的结论都是伪结论。

**从哪补**：无。只能把年度趋势的可信区间限定在 1990–2023，并在图轴上明确标注截断点。

### 4.8 缺口 5：城市判归的"未归属"

**缺什么**：12,576 对迁移（89.05%）至少一端无法判城市。Top 未匹配机构全是海外高校中文名：`伦敦大学学院` 120、`剑桥大学` 117、`斯坦福大学` 116、`麻省理工学院` 105、`哈佛大学` 97、`牛津大学` 96、`东京大学` 92、`帝国理工学院` 87、`南洋理工大学` 86、`曼彻斯特大学` 83。现有 `is_foreign` 只认国名不认校名。

**影响**：这是本件最大的系统性偏差。海外履历被记成"未归属"而不是"海外"，导致 ①跨市迁移总量被低估（海外→国内本应计入）；②"未归属→深圳"36 人次无法归因。若把这些校名补进海外白名单，深圳流入的来源结构会明显向"海外"集中。

**从哪补**：建海外高校中文名 → 国家的映射表（约 200 条即可覆盖 Top 校），或在 `loc2` 里加"校名在白名单 → 海外"的分支。这是低成本高收益的修复，建议下一版优先做。

### 4.9 缺口 6：学科维度只到"主域"

**缺什么**：一个学者只落一个学科域，取研究方向全文分类。

**影响**：`domain_flows` 里"未标注"占 13,409 / 14,121 = 94.96%，因为流动明细按**迁移段**的机构判域，而多数迁移段的学科无法从机构名推断。这个维度实际上不可用。

**从哪补**：应改用学者级 `domain`（`research_direction` 分类结果，可覆盖 81.47%），而不是迁移段级。本件保留该表仅为暴露问题，不建议上线该切片。

### 4.10 缺口汇总表

| # | 缺口 | 影响方向 | 严重度 | 修复成本 |
|---|---|---|---|---|
| 1 | 无流动原因 | 无法归因 | 高 | 需外部数据 |
| 2 | 流出库外不可见 | 流出低估 | 高 | 需外部数据 |
| 3 | 重叠丢弃 30.56% | 流动低估 | 中 | 需 `job_type` |
| 4 | 年度右截断 | 趋势失真 | 中 | 无解，只能标注 |
| 5 | 未归属城市 | 城市对缺失 | 中 | 低（建映射表） |
| 6 | 学科维不可用 | 切片失效 | 低 | 低（改学者级） |

## 五、结论与发布建议

### 5.1 判档结论

**部分支持。** 机构级与城市级流动可算、可复现、口径清楚；但"原因—价格—库外去向"三维全缺，且 30.56% 的候选对被丢弃，城市级样本量（846 次）偏薄。

### 5.2 可发布 / 不可发布

| 内容 | 建议 | 理由 |
|---|---|---|
| 机构对 Top 榜 | 可发布（探索性） | 频次低，需标注"仅库内可观测" |
| 城市对 Top 榜 | 可发布（探索性） | 海外对占主导，需标注"未归属 50 人次未入表" |
| 深圳净流量 +39 | 谨慎发布 | 必须带"未归属 36 流入 / 14 流出"脚注 |
| 深圳流入学科结构 | **不发布** | 89.16% 未标注，切片无效 |
| 年度流动趋势 | 只发布 1990–2023 | 2024 后右截断 |
| 流动原因分析 | **不发布** | 无字段 |

### 5.3 下一版优先修复

1. 建海外高校中文名 → 国家映射（低成本，可把"未归属"从 36 降到 10 以内）。
2. 流动明细改用学者级 `domain`（`research_direction`），放弃迁移段级判域。
3. 机构别名归并（至少覆盖深圳分支校区的 4 种写法）。
4. 若拿到 `job_type`，重算重叠剔除规则，给出流动次数的上下界。

### 5.4 一句话结论

该库能回答"人从哪个机构/城市换到了哪个机构/城市"，回答不了"为什么换、换得值不值、换到库外之后怎样"；在城市尺度上，可用样本只有 846 次迁移，任何结论都应视为方向性信号而非统计事实。

### C.2 转换规则是否可复核

机构配对规则 3 条、属地规则 6 步，全部写在 `M_TALENT_FLOW_TRACK.py` 的配对循环与 `_talent10_common.loc2()` 里，无隐藏分支。任何人拿两行履历可以手工复算是否构成迁移、属于哪个城市。可复核性满足；不满足的是覆盖率，89.05% 的迁移端判不出城市。

14,121 次迁移足以支撑机构级描述；1,545 对可定位迁移只够支撑「深圳净流入为正」的定性判断。城市对 Top 榜的单对量级在 5—98 次之间，头部稳定、长尾不可用。
