## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 政策分析 → 政策新闻可视化：全国发布密度/全国政策数量及连续性/省级发布密度/省级政策数量及连续性/市级发布密度/市级政策数量及连续性/产业链节点覆盖/深圳产业链节点覆盖。

### 1.2 为什么需要本指标

可视化面板把政策新闻的空间（全国/省/市）与产业（链节点）两个维度的时间分布一屏呈现，是政策分析模块的态势入口。

### 1.3 需求文档是否给出定义方法

页面语义直读（密度=计数序列、连续性=逐年有无）；「产业链节点覆盖」的映射口径未给。

### 1.4 类似指标权威方法可行性分析概要

政策态势可视化通行方法族：①发布量时序（本件采用，三级实测）；②层级结构占比（rank 五档实测可叠加）；③主题-产业映射覆盖（需映射表，本件缺口位）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：views/policy/policyNewsDisplayModel.ts:L12-21（20261104 盘点实拍）；缺口清单 seq58-60/62-63/70-73。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（政策分析相关叶）。
- 探针证据：`metrics/repro/out/M_B4_POLICY_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**定义（密度/连续性直读）**：发布密度=年度政策量序列；连续性=逐年有无断档。**推测部分**：链节点覆盖=政策按链节点归类统计（映射缺，见〇）。**升档触发器**见〇。
