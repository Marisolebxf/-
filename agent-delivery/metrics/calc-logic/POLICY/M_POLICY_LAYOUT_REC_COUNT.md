## 摘要

「政策布局建议条数」是政策布局推荐模型（171）面向三个页面（DS-11-POLICY-EVAL 报告页、DS-12-POLICY-SIM 政策模拟、E7-POLICY 看板）的**结果计数件**：机遇方向集与短板方向集交集的基数即本指标值。既有脚本（2026-10-20 版）用「机会类计数×合规触发=2 条建议」的笛卡尔近似给出占位数；本批 v2 升级为**王惠对冲口径全链复现**：方向键构建（theme 摊平去重，'NULL' 占位清洗）→ 机遇侧复用 170 实测（0 过线 → 机遇方向集空）→ 短板侧三路触发判定（对象覆盖缺口使 5/5 方向触发）→ 对冲计数。实测：方向全集 **5** 个、机遇方向 **0** 个、短板方向 **5** 个、**布局建议条数 = 0**。既有版的「2 条」被判定为笛卡尔近似的虚数（未过机遇线的机会类计数不得入对冲集），已退役为对照区。结论：**部分支持**——计数逻辑完整可复现，断供全部继承自方向键（theme 2 行）与机遇上游（170 三通道空壳）；先验「完全直接支持」与实测不符，以当日实测为准降档。本件与 171 报告构成「模型件+页件」对：方法、文献、王惠对照的完整论证见 171 报告，本件聚焦页件口径、双版本对账与计数交付。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标挂接《科技专题服务算法库》**政策深度分析模型构建 → 政策布局推荐模型**（§1.1.1.1.1.1.1.8.6）在三个页面的建议清单区块：DS-11-POLICY-EVAL（政策分析评价报告页）展示建议条数与清单钻取；DS-12-POLICY-SIM（政策模拟）以建议条数为情景基线（模拟参数变化对建议数的影响）；E7-POLICY（政策要素看板）聚合各区域/产业的建议条数分布。需求原文对该模型输出的定义：布局建议、执行效果预测、优化策略建议——本件是「布局建议」的计数面，服务三页的摘要数字与钻取入口。

### 1.2 为什么需要本指标

布局推荐是政策深度分析链路的终点件，其产出必须以「可数的清单」形态进入产品——建议条数即清单的第一属性。三个消费页面各有诉求：报告页需要「本期提出 N 条布局建议」的摘要句；政策模拟页需要一个可随参数重算的基线数（N 随权重/阈值参数变化的弹性即是模拟的核心输出）；看板需要区域/产业维度的建议数分布以定位「哪里最需要政策加码」。没有本件，171 的对冲结果只是脚本里的集合运算，无法进入任何页面交付。此外，建议条数的时序（本期 vs 上期）是「政策体系布局优化」最直接的量化轨迹，直接服务需求第六步「效果评估与动态优化」。

### 1.3 需求文档是否给出定义方法

**需求文档没提及指标定义方法。** 需求原文（§1.1.1.1.1.1.1.8.6）给出「综合机遇与短板分析结果，采用加权评分法和多维优先级排序生成政策布局建议」的方法提示，但**未给对冲规则、方向键定义或条数口径**。对冲口径（机遇过线 ∧ 短板触发才计数）全部来自王惠 171 原稿。三份需求说明书均未出现「政策布局建议条数」作为独立指标名。

#### 1.4.1 族 A｜政策组合三判据族：缺口方向就是待补清单

**谁在用。** Howlett 与 Rayner 的政策组合研究把设计质量拆成 consistency（目标与工具一致）、coherence（工具之间协调）、congruence（与情境匹配）三条判据，错配之处即「待补方向」 (Howlett & Rayner, 2013)；Howlett 进一步用垂直/水平设计空间刻画组合的边界 (Howlett, 2015)。

**怎么定义与口径边界。** 这一族的产物是**方向清单**，不是分数：判据给出「哪个方向错配」，清单计数是错配方向的数量。它的口径边界是「两侧同时可判」——只有目标面与工具面都能判定，才能说某方向错配；只有一侧有数据时，所谓的「建议」就是猜测。

**在本库能否落地。** 可落地为交集计数：`N = |{t: Opp_t=1 ∧ Short_t=1}|`。**实测可得率**：短板侧 5/5 可判（字段满量）、机遇侧 0（上游 170 零过线）、方向全集 5。**差在哪**：两侧判定本身都在，但机遇侧的分母（theme 分组）只有 2 行，判定结果必然是空集——不是判据说不了，是输入没有区分度。

**为何选。** 它把「布局建议」定义成「两侧都成立的方向」，而不是「某一侧的近似数」。这条交集纪律正是 v2 用来否定旧版「2 条」的理论依据。

#### 1.4.2 族 B｜中国政策试验筛选族：无信号时报告「无可筛选对象」

**谁在用。** Heilmann 对中国的政策试验做了系统描述：「由点到面」的推广依赖候选点具备可信的验证信号，筛选发生在试验之前 (Heilmann, 2008a/2008b)。

**怎么定义与口径边界。** 这一族的纪律是**筛选先于计数**：先判定哪些方向有信号，再数有几个；信号缺失时正确的输出是「本轮无可筛选对象」，而不是「凑几个候选点」。这与统计上的「零样本不估计」同源。

**在本库能否落地。** 可落地为「零建议 + 断点说明」的呈现纪律（§2.3 已执行）。**实测可得率**：纪律 100% 落地；候选方向 0（机遇侧空）。**差在哪**：不是方法缺字段，而是方法要求的「验证信号」在本库尚不存在（theme 未标注）。

**为何选。** 它给「0 条」提供了正当性：0 不是失败，而是「当前没有可信候选」的诚实报告。没有这条背书，0 会被读成模型坏了。

#### 1.4.3 族 C｜门槛判定计数族：计数只能消费同一份判定

**谁在用。** OECD/JRC 的复合指标手册把「判定」与「呈现」分成明确步骤，Saisana 等要求对阈值做敏感性分析并报告结论稳定性 (Saisana et al., 2005)。

**怎么定义与口径边界。** 两条边界：其一，**计数消费的判定必须与模型件逐位一致**——若页件另算一套判定，就会出现「模型 0 条、页面 2 条」的对账事故；其二，**阈值必须参数化**，因为阈值一动，条数就变，而变多少必须可算。

**在本库能否落地。** 完全可落地：v2 与 170/171 共享同一段方向键与判定逻辑，out.json 交叉引用。**实测可得率 100%**（链路可复现）。**差在哪**：判定链路通，但阈值 60 是团队值，且可评分政策只有 2 条——阈值弹性极大（见 §4.1）。

**为何选。** 它是唯一能保证「页件与模型件同源」的方法；也是唯一能解释「0 条是阈值与输入的函数」的语言。

#### 1.4.4 族 D｜商业政策情报族：推荐条数黑箱，不可对账

**谁在用。** 商业政策情报平台提供「政策推荐」「布局建议」类清单，按行业标签与政策文本匹配生成条数。

**怎么定义与口径边界。** 这类产品的推荐逻辑（匹配权重、去重规则、条数上限）通常不公开；同一组输入在不同平台的建议条数可以相差数倍。边界问题是：清单可读、条数不可复现。

**在本库能否落地。** 不可落地：无授权、无接口、无对齐主键（平台以政策标题/行业标签为主，本库以 `id` 与 theme 为主）。**实测可得率 0%**。其推荐规则**未取证，不得假设**。

**为何不选。** 与 C 族冲突：C 族要求计数消费同一份判定，外部推荐条数是第二套不可审计的判定。若甲方需要外部视角，正确用法是参考其**方向命名**，而不是引用其条数。

#### 1.4.5 四族对照与选型结论

| 方法族 | 代表机构/标准 | 产物形态 | 本库可落地性（字段 / 实测） | 选择 |
|---|---|---|---|---|
| A 政策组合三判据 | Howlett & Rayner (2013)；Howlett (2015) | 缺口方向清单 | 两侧判定在库；机遇侧空 | **采用（语义与交集纪律）** |
| B 政策试验筛选 | Heilmann (2008a/2008b) | 候选试验点 | 纪律 100%；候选 0 | **采用（零输出纪律）** |
| C 门槛判定计数 | OECD/JRC 手册；Saisana 等 (2005) | 过线计数 + 敏感性 | 链路 100% | **采用（主轨）** |
| D 商业政策情报 | 各类政策推荐平台 | 推荐清单 | 0%（无授权） | 不采用 |

选型结论：C 给计数、A 给语义、B 给零输出纪律、D 被排除。这也解释了为什么本件敢把「2 条」判成虚数——按 A 的交集纪律，左因子未过线就不是机遇方向；按 C 的同源要求，页件不能自造判定。

### 1.6 推测原意与推测定义

**推测原意**：编写人要求三个页面都能回答「模型本轮推荐了多少个布局方向、分别是什么」——条数是清单概览，也是模拟页参数实验的因变量。条数必须可随调用条件（区域/产业/主题）与权重参数重算。

**推测定义（本报告采用王惠 171 口径）**：布局建议数 = COUNT(DISTINCT t WHERE Opp_t=1 且 Short_t=1)；Opp_t/Short_t 判定完整继承 171（机遇侧复用 170 综合分过线、短板侧 169 三路触发）；任一侧全 0 则输出 0。

## 二、计算过程

> **口径说明**：本件采用王惠 171 对冲口径（v2 升级：既有 20261020 版为笛卡尔近似占位数，本批重写为全链对冲复现），复现脚本 `code/M_POLICY_LAYOUT_REC_COUNT.py`，结果见 `M_POLICY_LAYOUT_REC_COUNT_out.json`。文内 (Author) 与文末参考文献一一对应。

### 2.1 方法选择：对冲交集计数而非笛卡尔积

布局建议计数的正确语义是**交集**而非乘积：只有「机遇已过线」且「短板已触发」同时成立的方向才构成建议——这是 Howlett 政策组合理论中「目标面已强、工具面尚弱」的一致性缺口方向，即最值得投入的补短板靶点 (Howlett & Rayner, 2013; Howlett, 2015)。既有 20261020 版脚本在 theme 通道未探明时用了「机会类计数×合规触发」的笛卡尔近似：把标题含机会动词的政策数（未过机遇线）与合规短板直接相乘得「2 条建议」——该数的问题在于左因子不是机遇判定（未过 60 分线的机会类标题不属于机遇方向集），乘积意义上的「建议」没有任何一侧过判，属虚数。v2 的升级即把左因子换成真正的机遇方向集（复用 170 实测）、右因子换成方向级短板集（复用 169 阈值），按交集计数。升级后实测建议数从「2」修正为 **0**——这不是退步而是纠偏：王惠规则「任一侧全 0 则输出 0」显式禁止用未过线样本凑数，占位期诚实输出零建议优于虚数。中国政策试验研究同样支持这一纪律：试验点筛选的前提是候选方向有可信的验证信号，信号缺失时应报告「无可筛选对象」而非强行出单 (Heilmann, 2008a)。

### 2.2 步骤 1｜方向键与两侧集合构建（继承 171）

本件与 171 脚本共享同一段方向键逻辑（theme JSON 摊平、'NULL' 占位清洗、去重、空不进）：实测方向全集 5 个（创业扶持/财政支持/融资服务/科技创新/乡村振兴，来自 2 条真实 theme 政策）。两侧集合：机遇方向集=∅（170 全库 0 过线的沿链传导）；短板方向集={5 方向全体}（对象覆盖缺口触发：5 方向 vs 301 锚点环节的映射率 1.7%）。这一步的工程含义是：页件与模型件必须消费同一份方向键与两侧集合——任何一侧单独重算都会造成「模型件建议 0 条、页件显示 2 条」的对账事故，v2 通过共享代码段与 out.json 交叉引用杜绝该风险。

### 2.3 步骤 2｜对冲计数与诚实零输出

$$N_{\text{rec}} = |\{t:\ Opp_t=1 \wedge Short_t=1\}| = |\varnothing \cap \{5\}| = 0$$

实测**布局建议条数 = 0**。按王惠规则显式输出零并附断点定位：机遇侧空集的成因是 170 三通道断供（theme 2/keywords 0/quote 2 行真实值），方向键 5 个的成因是同一 theme 断供——两个断点同源，一次补数（theme 标注）同时恢复方向基数与机遇分组。产品侧的呈现纪律：零建议页面必须挂「数据补齐中」状态标并展示断点说明（而非空白页），这与 170 页件的零清单处理一致；DS-12-POLICY-SIM 模拟页在基线为 0 时应提示「待基线恢复后开放参数模拟」，避免用户在空集上做无意义的参数实验。

### 2.4 步骤 3｜条件化调用契约（三页参数映射）

需求要求按区域/产业/主题条件化调用且权重可设。v2 的参数化预留：区域过滤 → `province`/`city`（通道 87.4%/51.5% 可用）；产业过滤 → 产业锚点环节映射（301 环节就绪）；主题过滤 → theme（断供待补）；权重参数 → 对冲单条件为默认，加权模式（需求「加权评分法」）作为可选分支——王惠原稿明确加权模式下「短板是缺口不得当正向分加」，加权只能作用于机遇侧内部维度。当前数据状态下三页可用性：报告页可出零建议+断点说明；模拟页基线 0 待恢复；看板的区域维度可用但建议数恒 0，建议以「方向覆盖差距分布」替代展示（5 方向 vs 301 环节的区域切片）。

### 2.5 步骤 4｜建议清单主体 schema（补数后即插即用）

零建议期的另一项交付是 schema 就绪。v2 定义的建议清单主体字段：方向名、机遇侧证据（过线政策数、最高综合分、代表性政策标题）、短板侧证据（触发维度、子率、阈值线）、优先级位次（补数后按机遇分×短板维数排序，即王惠「机遇综合分×该方向短板维数」的加权式）、建议动作模板（按触发短板维生成）。当前 5 个方向虽未入建议清单，但其短板侧证据已齐（171 out.json 的 short_detail），可预填建议清单的「短板侧」半张表——补数后机遇侧一到位即完成整行。

### 2.6 步骤 5｜效果预测与动态优化的页件预留

需求第六步（效果评估与动态优化）依赖建议落实后的监测回流，页件侧的对应设计是「建议条数的期数序列」：每期快照（方向全集、两侧集合、建议数）留档，形成 N₁, N₂, … 的轨迹——该序列本身即「政策体系布局优化」的量化叙事。v2 的 out.json 结构已含快照语义（probe_date+全链数字），补数后按期累积即可。效果预测（执行效果预测为需求输出物）在无回流数据前不虚算，与 171 报告口径一致。

1. **继承 171 全部缺口**：theme 真实值 2/20,000（方向键+机遇分组双职能）、170 三通道断供——补数动作见 170/171 报告 §四。

3. **零建议呈现设计**：三页统一「数据补齐中」状态标+断点说明+覆盖差距分布的替代展示。
4. **期数序列未启动**：快照机制已就绪（out.json 含 probe_date），首期补数后开始累积。
5. **无 ADS 物化**：建议表需落结果面后服务化。

**甲方侧建议**：本件零独立补数成本——全部投入与 170/171 共享；验收以「对冲口径对账一致+三页字段契约就绪」为通过标准，条数随上游补数自然恢复。

### 4.1 缺口后果归因：0 条由哪一侧决定、能偏到多少

本件的建议数是一个交集：`N = |机遇方向 ∩ 短板方向|`。交集的大小天然由**较小的那一侧**决定。实测机遇侧为 0、短板侧为 5，因此当前 0 条**完全由机遇侧单独决定**——这一判断可以算，不需要猜。

| 缺口 | 偏移方向 | 可算量级 | 交叉验证 |
|---|---|---|---|
| theme 仅 2 行 | 方向全集**偏少** | 5 方向 / 2 条政策（2.5 方向/条） | 能：theme 覆盖率 |
| 机遇侧 0 过线 | 建议数**被压到 0** | 可评分 2 条均 50 分，距阈值 60 差 10 | 能：分数分布 |
| 短板侧 5/5 全触发 | 交集**退化为机遇集** | 5/5 = 100% 触发率 | 能：触发计数 |
| 阈值 60 未校准 | 阈值下调即**有建议** | τ≤50 → 机遇 ≤2 方向 → 建议 ≤2 条 | 能：阈值扫描 |
| 旧版「2 条」虚数 | 若回灌则**高报 2 条** | 0 → 2（相对差 100%） | 能：双版本取数点 |
| 期数序列未启动 | 无偏移，但**无趋势** | 0 期 | 能：快照计数 |

**第一层：0 不是「两侧都没有」，而是「一侧为空」。** 短板侧 5 个方向全部触发（5/5），机遇侧 0 个。交集 = ∅。因此任何「补短板」的工程动作都不会改变 0 条——只有补 theme（进而让 170 能分组评分）才会。这一条对排期至关重要：如果按「短板侧也要补」的思路排工单，会做无用功。

**第二层：短板侧 100% 触发意味着它没有区分度。** 5 个方向全部触发，等价于「所有方向都是短板」。在这种状态下，建议数 = 机遇方向数，短板侧退化成一个恒真条件。它的成因是对象覆盖缺口（5 方向 vs 301 个锚点环节，映射率 1.7%）——方向粒度太粗，任何方向都能找到未覆盖的环节。要让短板侧恢复区分度，须细化方向—环节映射，而不是改阈值。

**第三层：阈值弹性可以直接算出上界。** 两条可评分政策的综合分都是 50.00；若阈值取 60，机遇 0 方向、建议 0 条；若阈值下调到 50，两条政策过线，其所属方向（至多 2 个）进入交集，建议条数至多 2 条。**注意这是上界不是预测**：两条政策可能属于同一方向，实际可能只有 1 条；且下调阈值会同时改变「机遇」的语义，属于口径变更而非参数微调。

**第四层：旧版虚数是「高报」，方向与当前相反。** 20261020 版显示 2 条，v2 为 0 条，相对差 100%。若旧取数点未下线，三页会显示一个比真值高 2 条的数——这不是小的舍入误差，而是把一个未过线的机会类计数当成了建议。退役动作必须落到取数点级别（§2.7.2 已留双版本对照）。

**可交叉验证与不可验证要分开。** 方向全集、触发率、阈值上界、双版本差四项可复算；「theme 补齐后方向全集会变成几个」不可验证，只能标注待取证——因为方向是从 theme 摊平来的，标注体系一换，方向数就变。

## 附录 C　布局建议条数类似指标权威构建方法可行性报告（完整版）

### C.1 报告目的与范围

回答三个问题：权威机构与学界对「建议/推荐清单计数」类指标的构建惯例；本项目库表能否支撑；综合落何档支持度。范围限定为对冲计数的页件交付，组合设计与试验筛选的完整方法论证在 171 报告附录 C，不重复。

### C.2 需求语义锚定

布局建议条数的语义是「两侧判定的交集基数」——必须先有两侧判定再有计数，不得用任何一侧的近似数替代。筛选标准据此定为：计数是否消费真判定、零输出是否可解释、条件化调用是否可重算。

### C.3 权威方法谱系

#### C.3.1 方法族 A：政策组合一致性缺口

**代表**：Howlett & Rayner (2013)；Howlett (2015)。**构架**：组合三判据（consistency/coherence/congruence）识别「目标-工具错配」方向，错配方向即待补清单。**可迁移性**：对冲计数=一致性缺口方向的计数化；交集纪律=「错配须两侧同时可判」的工程化。**结论：主轨背书。**

#### C.3.2 方法族 B：中国政策试验筛选

**代表**：Heilmann (2008a, 2008b)。**构架**：候选方向须有可信验证信号才入试验筛选；无信号时报「无可筛选对象」。**可迁移性**：零建议的诚实输出纪律直接采自该逻辑；期数序列对应「由点到面」的推广轨迹度量。**结论：语境背书采用。**
