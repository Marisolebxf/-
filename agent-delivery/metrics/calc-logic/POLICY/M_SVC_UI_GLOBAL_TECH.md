## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 产业服务链分析 → 服务链专题服务 → 全球服务机构概况面板（环节合计/类型分布合计）+ 服务机构技术能力（综合得分）。

### 1.2 为什么需要本指标

全球面给服务资源「世界坐标系」：国内机构对标全球同类机构的规模位次与技术力位次。

### 1.3 需求文档是否给出定义方法

概况语义直读（总量/类型分布）；「环节合计（可重复计）」= 一机构服务多环节可重复计数——映射口径明确但挂接数据缺；综合得分权重未闭合。

### 1.4 类似指标权威方法可行性分析概要

全球机构画像通行方法族：①OpenAlex 类机构库画像（本件采用，久新同步）；②规模约数（合作面去重估计）；③四维计量评分（本件采用）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：服务链专题服务门户（20261104 盘点实拍）；缺口清单 seq179-180/186。
- 需求叶：`agent-delivery/bid-reference/科技专题服务算法库.md`（服务机构相关叶）。
- 探针证据：`metrics/repro/out/M_B5_SVC_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**定义（直读+计量）**：类型分布合计=按机构类型计数（一机构一类型主分类）；综合得分=四维评分均值（权重闭合前口径）。**推测部分**：环节合计=Σ(机构×所服务环节)（待挂接）。**升档触发器**见〇。
