## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 产业服务链分析 → 引入服务机构推荐分析（招引工作台：候选机构池+招引推荐模型）+ 培育服务机构推荐分析（培育工作台：存量机构+培育推荐模型）。

### 1.2 为什么需要本指标

招引回答「外地哪些机构该引进」，培育回答「本地哪些机构该扶持」——服务链补链强链的双轮驱动件。

### 1.3 需求文档是否给出定义方法

UI 侧有维度权重设计（CULTIVATE_DEMO_DIMS：市场缺口 20%/技术创新 30%/服务成效 25%，余下为演示占位）；正式权重未闭合。

### 1.4 类似指标权威方法可行性分析概要

机构推荐通行方法族：①多维加权评分（本件口径）；②缺口对标法（本地 vs 标杆城市结构差）；③活跃度信号（融资/新闻/招聘流）。完整版见附录 C。

### 1.5 引用来源

- UI 证据：svcRecommendAttractWorkspace.ts:L18/L25、CULTIVATE_DEMO_DIMS 常量（20261104 盘点实拍）；缺口清单 seq81-90。

- 探针证据：`metrics/repro/out/M_B5_SVC_BATCH_PROBE_out.json`。

### 1.6 推测原意与推测定义

**推测定义**：招引分 = f(技术领先性, 对外合作意愿, 行业匹配度, 服务能力)；培育分 = g(市场缺口, 技术创新能力, 服务成效)（权重待甲方闭合）。本件实测各维度原料承载。**升档触发器**见〇。
