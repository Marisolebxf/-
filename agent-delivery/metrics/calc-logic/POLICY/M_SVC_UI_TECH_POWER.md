## 一、需求定义概述

### 1.1 所属功能模块

科技专题服务系统 → 产业服务链分析 → 服务机构技术力评估分析：综合技术力 TOP3 榜单 + 技术力评价模型（成功案例/标准制定/核心专家三维度权重）。

### 1.2 为什么需要本指标

技术力评估给服务机构分级，是「找谁合作」的排序依据；TOP3 是看板首屏的头部结论。

### 1.3 需求文档是否给出定义方法

TOP3 榜单语义直读；模型三维度**有权重表设计**（UI 侧「技术力评价模型权重表」）但权重值未闭合。

### 1.4 类似指标权威方法可行性分析概要

机构技术力通行方法族：①论文计量四维评分（本件实测在，久新 OpenAlex 口径）；②专利计量（发明人/专利族）；③标准制定计数（需标准库）；④专家头衔/人才计划叠加。完整版见附录 C。

### 1.5 引用来源

- UI 证据：SvcOrgCapabilityBoard.vue:L345、技术力评价模型权重表（20261104 盘点实拍）；缺口清单 seq76-79。

### 1.6 推测原意与推测定义

**推测定义**：综合技术力 = Σ(维度得分 × 权重)；维度=成功案例（项目关联）/标准制定（标准&专利）/核心专家（人才密度）。久新四维（论文/引用/人才/主题）为可落地的替代口径。**升档触发器**：权重甲方确认。
