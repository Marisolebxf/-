## 摘要

本指标是 187 的二次合成：对每个结构先算成熟度（结构内叶子归一等权）与均衡度（熵 H/ln(n)×100），
两者等权得结构分，七结构再等权，得到 0—100 的层次指数。在 187 的 gkx 重建产物上重算的结果是：
广州 78.8、深圳 75.0、东莞 15.2、惠州 4.3，排序为广州 > 深圳 > 东莞 > 惠州。

广州反超的全部原因是「没有塌陷的结构」：它的七个结构分是 100.0 / 84.7 / 75.3 / 100.0 / 72.5 /
49.0 / 70.0，最低一项 49.0；深圳是 14.0 / 97.9 / 100.0 / 12.8 / 100.0 / 100.0 / 100.0，
四项满分、两项塌到 15 以下。等权平均后深圳被这两项拖住，广州靠「处处及格」略胜。

必须写进发布口径的限定有三条：其一，两市只差 3.8 分，把均衡度权重从 0.5 调到 0.7 就会翻回
深圳领先（75.6 对 74.9），所以只能发布「两市同处第一梯队」；其二，深圳的服务机构均衡度 0.0
是「占比叶归一为 0」造成的，不是「服务业内部结构崩了」；其三，人才与空间两结构只有一叶，
均衡度不参与，这两个结构分就是成熟度本身。

### 1.2 口径定义（王惠原文要点）

王惠表对该指标的定义是：在 187 的七个结构之上再叠一层「层次」评价——每个结构先看
**成熟度**（结构内叶子是否都做得好），再看**均衡度**（结构内叶子之间是否均衡），
两者等权得到结构分，七结构等权得到 0—100 的层次指数。原文明确「不另取叶子」，
即 188 不允许换一套指标，只能用 187 的叶子。

三处需要讲明：

1. **成熟度 = 187 的结构分**。它是「结构内叶子归一后的等权平均」，衡量的是「这一结构整体多强」。
2. **均衡度是熵**。$H=-\sum p_i\ln p_i$，$p_i$ 是叶子归一值占比，再除以 $\ln n$ 归一化到 0—100。
   它的含义是「这个结构的强度是均匀分布在各叶子上，还是靠一片叶子独撑」。
3. **均衡度对 0 值极度敏感**。任何一片叶子归一为 0，$p_i=0$ 使熵直接掉到 0，
   因此「某城某叶被批内极值压到 0」会被读成「结构不均衡」。这是方法本身的放大效应，
   不是数据错误，但必须在解读时说明。

### 1.3 计算公式与本批实现式

成熟度（与 187 的结构分同式）：

$$M_{c,s}=\frac{1}{|L_s^{ok}|}\sum_{\ell\in L_s^{ok}}\tilde{x}_{c,\ell}$$

均衡度：

$$
B_{c,s}=\frac{H_{c,s}}{\ln n_s}\times 100,\qquad
H_{c,s}=-\sum_{\ell}p_{c,\ell}\ln p_{c,\ell},\qquad
p_{c,\ell}=\frac{\tilde{x}_{c,\ell}}{\sum_{\ell'}\tilde{x}_{c,\ell'}}
$$

结构分与总指数：

$$
S_{c,s}=\tfrac12\left(M_{c,s}+B_{c,s}\right),\qquad
I_c=\frac{1}{7}\sum_{s=1}^{7}S_{c,s}
$$

本批七个结构的叶子数与有效叶子数：

| 结构 | 叶子数 | 有效叶子数 | 均衡度是否可算 |
|---|---:|---:|---|
| 人才结构 | 2 | 1 | 否（n=1 → null） |
| 企业结构 | 3 | 3 | 是 |
| 政策结构 | 2 | 2 | 是 |
| 服务机构结构 | 2 | 2 | 是 |
| 科研机构结构 | 3 | 3 | 是 |
| 资金结构 | 2 | 2 | 是 |
| 空间结构 | 1 | 1 | 否（n=1 → null） |

## 二、计算过程

### 2.1 数据装载与快照清单

188 不连数据库、不读快照，只读一个文件：`metrics/repro/out/M_SYNTH_187_1_out.json`。
装载实测 0.02 秒，瓶颈是 JSON 解析（11.7 KB）。

| 输入 | 内容 | 规模 | 用途 |
|---|---|---|---|
| `metrics/repro/out/M_SYNTH_187_1_out.json` | `leaves`（15 叶）、`leaf_norm`、`dim_scores`、`leaves_degenerate_excluded` | 11.7 KB | 全部输入 |

这种「单文件输入」是刻意的：188 的口径不允许自己取数，否则「不另取叶子」就失守了。
代价是 188 的可复现性完全依赖 187——187 一变，188 必须重跑，脚本里的归一比对就是为此设的。

### 2.2 归城与重名处理

188 不涉及归城与重名：城市维度已经在 187 的 `leaves` 里固定为四个键。
这也是为什么 188 的评价集不能自己改——若 187 只有四市，188 也只能是四市。

### 2.3 维内归一与权重

成熟度用 187 的 `leaf_norm`（批内 min-max，0—100）；均衡度用同一组归一值算占比与熵。
两处细节：

1. **均衡度的输入是归一值，不是原始值**。用原始值算熵会被量纲支配（比如资金结构里
   1,545 亿元与 559 笔，量级差 8 个数量级），归一后都在 0—100，熵才有意义。
2. **n 取「有值的叶子数」**。东莞、惠州在人才结构只有学者密度一片有值（n=1），
   均衡度不可定义记 `null`；深圳、广州有 2 片但高学历叶被剔除，n 也是 1。

结构内权重：成熟度与均衡度各 0.5。这个 0.5 是王惠口径，本批不做数据驱动调权；
但它对结果影响很大（§5.4 的敏感性检查显示 0.7/0.3 就会翻转深穗排序），所以必须写明。

### 2.4 指数合成与缺维处理

七结构等权，`null` 的结构不进分母。本批七结构都有成熟度，没有整结构缺失，
所以七结构全部参与。

均衡度缺失（人才、空间两结构）时，结构分取成熟度本身（`wmean` 自动跳过 `null`）。
这一步要特别说明：它不是「补 60」，是「只用可得的那一项」。两者差别很大——
补 60 相当于给该结构加 30 分基线，而深圳的人才成熟度只有 14.0，补 60 会把它抬到 37.0；
只用成熟度则保持 14.0，如实反映「这一结构只有一片叶子、且这片叶子排末位」。

### 2.5 参数与阈值

| 参数 | 取值 | 依据 |
|---|---|---|
| 成熟度 | 结构内叶子归一等权 | 同 187 |
| 均衡度 | $H/\ln n\times100$；合计 ≤0 记 0；n=1 记 null | 王惠熵均衡度；n=1 无定义 |
| 结构分 | 成熟度 0.5 + 均衡度 0.5（缺均衡度取成熟度） | 王惠口径 |
| 总指数 | 七结构等权 | 王惠口径 |
| 退化叶 | 从上游 `leaves_degenerate_excluded` 读取并剔除 | 与 187 保持一致 |

### 2.6 计算边界与不做事項

本批明确不做五件事：

1. **不另取叶子**。王惠原文要求，188 只用 187 的 15 叶，不引入新指标。
2. **不做新数据源**。不读政策表、不读专利表、不连库。
3. **不做跨年**。187 是 2024 截面，188 继承；政策叶子的存量口径也继承。
4. **不调权重**。成熟度/均衡度 0.5、结构 1/7 都是口径，不做拟合。
5. **不补中值**。均衡度缺失记 null，不填 60。

## 四、数据缺失情况

### 四.1 缺口清单与修复路径

| 缺口 | 影响 | 实测后果 | 修复路径 |
|---|---|---|---|
| 人才结构只剩一叶 | 均衡度 | 该结构均衡度不可算 | 补研发人员数或学位全量，恢复到两叶 |
| 空间结构只有一叶 | 均衡度 | 同上 | 补园区面积/密度 |
| 高学历叶退化 | 人才结构 | 被剔除，人才结构降为单叶 | 补学位全量 |
| 服务机构为行业口径 | 服务机构 | 两叶都是行业口径，均衡度只衡「数」与「占比」 | 补六类服务机构名录 |
| 上游 187 的四处降级 | 全部 | 188 无法比 187 更"支持" | 见 187 §四.1 |
| 均衡度对 0 敏感 | 五结构 | 六个 0.0 来自极值端点 | 方法层问题，扩量不解决 |

### 四.2 结构性缺口（扩量救不了）

1. **均衡度不是「缺数」问题，是「方法对端点敏感」问题**。批内 min-max 必然产生 0 与 100，
   而熵在 0 处不连续（$0\ln0=0$，但接近 0 时斜率无穷）。所以任何一个「批内最差」的叶子
   都会把该结构的均衡度打到 0。这不是把数据补全就能解决的，除非改归一方式（如用绝对刻度），
   但那样又失去批内可比性。
2. **单叶结构的均衡度永远不可定义**。人才结构剔除退化叶后只剩一片，空间结构本来只有一片。
   要让 n≥2，必须补叶子（研发人员、园区面积），补不出来就只能承认「这两个结构只评成熟度」。

### 四.3 本批不采用的数据面

| 数据面 | 为什么不用 |
|---|---|
| 任何新数据源 | 王惠「不另取叶子」，188 只消费 187 |
| 旧版的 60 分中值 | 凭空造数，已废弃 |
| 京沪参考读数 | 不在 187 评价集内，188 无法凭空生成 |

### 四.4 缺口对判档的影响

188 的支持度上限由 187 决定：187 判「部分支持」，188 不可能更高。
在此之上，188 还多了两层方法性缺口（均衡度对 0 敏感、两个单叶结构均衡度不可算），
所以也只能判「部分支持」，且不能声称「层次评价比类型评价更可靠」。

### 五.2 分维画像

**广州**是「均衡型」：七个结构分最低 49.0（资金），最高 100.0（人才、服务机构），
没有塌陷项。它的均衡度在企业 95.2、政策 86.8、科研 93.7、资金 73.6、服务 100.0，
五项都在 73 以上——这意味着它的结构分不是靠单片叶子撑起来的。

**深圳**是「尖峰型」：政策、科研、资金、空间四项满分，但人才 14.0、服务机构 12.8。
服务机构的 12.8 来自均衡度 0.0：科技服务业企业数归一 51.19、占比归一 0.00，
熵直接归零，结构分变成 (25.59 + 0)/2 = 12.8。这不是「深圳服务业结构崩了」，
是「深圳的科技服务业占比在四市里最低」这一事实被熵放大。

**东莞**是「低水平均衡」：服务机构 70.2 是它唯一像样的结构（企业数 7,565、占比 22.52%，
两叶都归一得不错，均衡度 98.9）；科研 0.3（授权 4 件，归一 0，均衡度 0）、
资金 3.0（融资 82 笔归一 12.15、上市研发 59.79 亿元归一 0，均衡度 0）。

**惠州**是「三项归零」：人才、政策、空间三个结构分为 0，企业 21.7 是唯一亮点。
4.3 的指数是「七个结构里只有一个有分」的结果。

### 五.4 敏感性与稳健性

做了四项检查（改权重/改口径重算）：

1. **均衡度权重 0.7 / 0.3**：深圳 75.6、广州 74.9、东莞 14.1、惠州 5.2——**排序翻转**，
   深圳以 0.7 分反超。
2. **只看成熟度**（均衡度权重 0）：即 187 的指数，深圳 76.5、广州 69.1——深圳领先 7.4 分。
3. **旧版口径**（含退化叶 + n=1 记 60）：深圳 78.0、广州 67.3、东莞 23.0、惠州 12.9——
   深圳领先 10.7 分。这两项口径本身就能把排序翻回深圳，说明旧稿的「断层领先」不全是数据差异。
4. **去掉人才结构**（六结构等权）：深圳 86.9、广州 63.9、东莞 14.3、惠州 7.6——深圳领先，
   因为人才结构是广州唯一拿满且深圳接近零的结构。

四项的共同结论：**「广州第一」只在均衡度权重 ≥0.5 时成立，且领先幅度小于权重不确定性**。
发布时只能写「广州与深圳同处第一梯队，广州在结构均衡度上略优」，不能写「广州第一、深圳第二」
这种确定性排序。

### 五.5 反常识点与解释

**反常识一：成熟度深圳更高（76.5 对 69.1），综合却低于广州（75.0 对 78.8）。**
因为 188 把「均衡度」等权加进来，而深圳有两个塌陷结构（人才 14.0、服务机构 12.8）。
等权平均的数学性质是：两个 100 与两个 13 的平均，低于四个 70。

**反常识二：深圳的服务机构均衡度是 0.0，而它的科技服务业企业有 10,002 家（四市第二）。**
均衡度看的是「两片叶子是否同高」：企业数 10,002 归一 51.19、占比 10.46% 归一 0.00，
一高一零 → 熵 0。也就是说，深圳的服务机构分低，主要因为它「企业总数多但占比低」，
不是因为服务业绝对规模小。

**反常识三：东莞的服务机构结构分（70.2）高于深圳（12.8）。**
东莞的科技服务业企业只有 7,565 家（深圳的 76%），但占比 22.52% 归一 46.76，
两叶相对均衡（熵 98.9），结构分因此被抬到 70.2。这是「均衡度奖励小而匀」的典型例子，
也是本指标最容易被误读的地方。

## 六、结论与发布建议

### 六.1 可用结论

1. 在 187 的 gkx 重建产物上，四市层次指数为广州 78.8、深圳 75.0、东莞 15.2、惠州 4.3，
   由成熟度（=187 结构分）与熵均衡度等权、七结构等权合成。
2. 深圳有四个结构满分（政策、科研、资金、空间），广州有两个（人才、服务机构）；
   广州的七个结构分最低 49.0，深圳最低 12.8。
3. 两市差距 3.8 分，同处第一梯队；东莞与惠州（15.2 / 4.3）与前两名是断层。
4. 均衡度可算的五结构里，八个 0.0 全部可追溯到「某叶归一为 0」，可逐项复核。

### 六.2 不可用结论

1. **不能发布「广州第一、深圳第二」的确定性排序**。均衡度权重改到 0.7 就翻转（§5.4）。
2. **不能把均衡度 0.0 读成「结构畸形」**。它是极值端点的数学结果。
3. **不能用 188 反推 187 的结论**。两件问的是不同问题（类型 vs 层次），排序不同是设计使然。
4. **不能与旧稿读数相减**。上游、评价集、n=1 处理全变，83.2 → 75.0 不是「下降」。
5. **不能声称 188 比 187「更支持」**。叶子全继承，188 的支持度上限就是 187 的支持度。

### 六.3 发布口径建议

对外建议用这样一句话：「在深圳都市圈四市范围内，按成熟度与结构均衡度等权评价，2024 年区域
创新要素层次指数为广州 78.8、深圳 75.0、东莞 15.2、惠州 4.3；广州与深圳同处第一梯队，
广州的优势在结构均衡（最弱结构 49.0），深圳的优势在结构强度（四项满分）；
该结论对均衡度权重敏感，权重 0.7 时两市位置互换。」

同时建议在脚注写：均衡度可算结构 5/7、每城有值叶子 15/15/14/14、两市差距 3.8 分。
