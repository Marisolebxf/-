## 摘要

PageRank 的名气比它在本图上的信息量更大。算法本身很干净：稳态方程 $PR=(1-\alpha)/n+\alpha A^{\top}D^{-1}PR$，幂迭代 40 次收敛。麻烦在语义：在**无向图**上，PageRank 退化为「度中心性的阻尼版」，与度高度相关——本件实测 Spearman 0.937701，top-100 重合 92 个。也就是说，009 与 006 讲的是同一件事的两种写法。

| 读数 | 值 |
|---|---|
| 主点集 | P2 巨型连通分量 15,223 节点 / 36,965 边 |
| 参数 | alpha=0.85，tol=1e-12，无向无权 |
| 迭代 / 残差 | 40 次 / 1.3729e-08 |
| 均匀值（1/n） | 0.6569 万分比 |
| 最大 | 17.42688 万分比（26.529 倍均匀） |
| 最大值节点 | 广州中医药大学第一附属医院（度 194、751 篇） |
| 中位 / 均值 | 0.46447 / 0.6569 |
| top-100 占总量 | 6.701% |
| top-1%（152 个）占总量 | 8.818% |
| 与度中心性秩相关 | 0.937701 |
| top-100 与度榜重合 | 92（Jaccard 0.8519） |
| 判档 | 完全转换支持 |

展示单位选「万分比」（×10000）是被量级逼出来的：原始值在 $6.6\times10^{-5}$ 量级，写成小数会变科学计数法，写成百分比则全是零点零零几这样的数。换成万分比后，均匀值恰好是 0.6569，最大值 17.42688，读起来是「均匀值的 26.529 倍」，比「万分之一点七四」直观得多。

三组参数对照是本件的稳健性证据。**alpha 扫描**（0.50/0.70/0.85/0.95/0.99）：最大值从 9.9647 涨到 25.1793（阻尼越大、头部越集中），与基准的秩相关最低 0.973083；top1 在 alpha=0.50 时是华南理工大学，从 0.70 起变成广州中医药大学第一附属医院——**头部第一名对阻尼敏感，第二至十名不敏感**。**加权版**（边权=共著篇数）最大值 36.01595，与无权版 top-20 重合 16 个；**有向版**（署名顺序最前者指向其余）最大值 33.74094，重合也是 16 个。

引用网这条路已经堵死：`dwd_zh_paper_citation` 有 20,031 行，但 `citation_id_list` 里的 id 与本库 `dwd_zh_paper.id` 的闭合率实测 0.0%；换成更宽的 `dwd_zh_paper_reference`（196,619 个 id）也只有 165 个能落回本库，闭合率 0.0857%（详见 §3.2 与产物 `citation_closure`）。在有向图上跑 PageRank 会得到一张「全是悬挂节点」的图，阻尼项把所有权重摊回均匀分布，读数没有意义。这也是为什么本件的主口径只能是无向共著图。

### 1.2 口径定义

PageRank 把图看成一张「随机游走」的地图：一个人从随机节点出发，每一步以 $\alpha$ 的概率沿一条边走到邻居（邻居等概率），以 $1-\alpha$ 的概率跳到全图随机一个节点。长期下来，每个节点被访问的概率就是它的 PageRank。

三个口径选择与前几件一致（点集、去重、归并），本件额外三个：**阻尼 $\alpha$**（取 0.85）、**权重**（主口径无权）、**方向**（主口径无向）。这三个都是「可以选」的，所以必须给对照——单给一组数，读者无法判断结论是不是参数造成的。

### 1.3 计算公式与本批实现式

标准式：

$$PR(v)=\frac{1-\alpha}{n}+\alpha\sum_{u\in N(v)}\frac{PR(u)}{d_u}$$

其中 $N(v)$ 是 $v$ 的邻居集合，$d_u$ 是 $u$ 的度，$\alpha$ 是阻尼系数。无向图上 $N(v)$ 对称，悬空节点（度 0）不存在（P2 内最小度为 1），所以不需要额外的悬挂项。

本批实现式（万分比）：

$$PR^{\prime}(v)=10^4\cdot PR(v)$$

均匀分布时每个节点 $PR=1/n=1/15223$，即 $PR^{\prime}=0.6569$。所以「0.6569 = 平均线」这句话可以直接写进 UI 说明，读者拿任何读数除以 0.6569 就是「相对均匀值的倍数」。

## 二、计算过程

### 2.1 图装载与规模校验

本件读同一份族级快照，取 `c_pr`（无权）、`c_pr_w`（加权）、`c_pr_dir`（有向）三列。校验项：全图 20,436 / 38,208、巨片 15,223 / 36,965、孤立点 3,540。这三项对上之后，还要校验一项本件特有的：**所有 PageRank 之和应为 1**（在 15,223 个节点上），即万分比之和 10,000。产物里 `stats_bp_unweighted.mean` 乘以节点数若偏离 10000，说明归一化被破坏。

### 2.2 幂迭代的实现与收敛

不用 networkx 的 `pagerank`，原因是它不返回迭代次数与残差，而这两项是本件「可复现」的证据。自实现的循环是：初始化 $x=1/n$；每轮先算悬挂项（P2 内为 0）、再对每条边把 $x_i/d_i$ 摊给邻居、最后混入 $(1-\alpha)/n$；用 $L_1$ 范数判断收敛。

实测：无权 40 次、加权 45 次、有向 51 次，残差均在 $1.3\times10^{-8}$ 量级（tol 设为 1e-12，但 $L_1$ 的浮点底噪在 1e-8 附近，继续迭代不再改善）。这个量级足以支撑「读数稳定到小数点后 6 位」的结论。

alpha=0.99 时需要 228 次迭代才收敛，alpha=0.50 时只要 12 次。迭代次数随 $\alpha$ 增大而增大，是因为谱隙变小、收敛变慢——这条规律在 `alpha_scan` 里可以直接看到（12 / 22 / 40 / 83 / 228）。

### 2.3 三组参数对照

**第一组：alpha 扫描。** 阻尼越大，随机游走越依赖图结构、越少跳回随机点，头部越集中。最大值从 9.9647（alpha=0.50）涨到 25.1793（alpha=0.99），涨幅 2.53 倍；与基准（0.85）的秩相关最低 0.973083（alpha=0.50），最高 0.99214（alpha=0.70）。**排序几乎不变，但数值尺度变了**——这解释了为什么报 PageRank 必须同时报 alpha。

**第二组：加权版。** 边权取共同署名篇数，等于把「合作 5 篇」当成 5 条边。最大值从 17.42688 涨到 36.01595（2.07 倍），top-20 与无权版重合 16 个。加权放大了高产合作对（如广州中医药大学第一附属医院 751 篇），但没改变头部结构。

**第三组：有向版。** 方向规则是「每篇论文中署名顺序最前的机构 → 其余每个机构」，即把「一作/通讯」视为指向。有向图 29,768 条边、10,213 个节点有出边（67.09%）、12,012 个节点有入边，最大出度 82、最大入度 94。最大 PageRank 33.74094，top-20 与无权版重合 16 个。**方向只表示署名次序，不表示知识流**，所以有向版只能当对照，不能当主口径。

### 2.4 集中度与分布

| 分位 | 万分比 |
|---|---|
| 最小 | 0.17477 |
| p25 | 0.31473 |
| 中位 | 0.46447 |
| 均值 | 0.6569 |
| p75 | 0.70233 |
| p90 | 1.19658 |
| 最大 | 17.42688 |

均值 0.6569 与均匀值 0.6569 相等（这是归一化的必然），中位 0.46447 低于均值 29.3%，说明分布右偏但不像中介中心性那样极端。最大 17.42688 是均匀值的 26.529 倍，p90 只有 1.19658（1.82 倍均匀值），说明「绝大多数节点接近均匀，少数节点显著抬高」。

集中度：top-100 占总量 6.701%，top-1%（152 个）占 8.818%。这两个数比度中心性（8.87% / 11.6%）还低，原因是 PageRank 的阻尼项不断把权重摊回均匀，天然压缩头部。**这也说明 PageRank 不适合做「找出最重要的 100 家机构」——它的分布太平。**

### 2.5 点集敏感性

本件只做了一组点集对照：P1（有边子图，16,896 节点 / 646 个分量）。P1 上最大 15.70142、均值 0.59186、中位 0.44419。与 P2 相比整体低一档，原因是 P1 含 646 个分量，阻尼项在每个分量内部分配权重，碎片分量的节点拿到的份额被均匀化。

P3/P4 上没有算 PageRank——因为快照的 `sub_nodes` 只带 `c_deg` / `c_close` / `c_betw` 三列（这三列的子图计算由构建器一次完成，避免五件各跑一遍精确 Brandes）。这是有意的取舍：PageRank 在子图上的价值低（它已经与度高度相关），不值得再多算两遍。

### 2.6 与度中心性的关系

| 对照 | Spearman | top-100 交集 | Jaccard |
|---|---|---|---|
| PageRank ~ 度 | 0.937701 | 92 | 0.8519 |
| PageRank ~ 中介 | 0.850506 | — | — |
| 度 ~ 论文数（Pearson） | 0.814667 | — | — |

0.937701 这个数不是巧合。无向图上，PageRank 的稳态方程可以写成 $PR\propto(I-\alpha A D^{-1})^{-1}\mathbf{1}$，它与度的幂级数展开只差高阶项；当 $\alpha$ 不大时，一阶项就是度。**结论：在本图上，PageRank 提供的信息量约等于度中心性加一点二阶修正。**

这不是说 PageRank 没用，而是说**不能把它当独立维度**。若某个界面把「度」和「PageRank」并列成两个榜单，读者会以为看到了两种不同的东西，实际是同一件事的两种算法。

两张表合起来的信息是：**第二张表比第一张宽 36%，但能落回本库的只有 165 个 id**（占 0.0857%）。

在引用网上跑 PageRank 会怎样：几乎所有出边都指向图外，等价于每个节点都是悬挂节点，

## 四、数据缺失情况

### 4.1 无向图上的 PageRank 不是独立维度

这是本件最重要的一条边界。0.937701 的秩相关、92 个 top-100 重合，说明它在讲度中心性已经讲过的事。任何把它包装成「另一个维度的机构影响力」的做法，都是对读者的误导。

正确的用法是：**当用户想「按重要性排序」时，用 PageRank 比度更平滑**（阻尼项压低了超级枢纽的极端值），但不要说这是「另一种重要性」。

### 4.2 引用网不可用

如 §3.2，闭合率 0.0% / 0.0857%（两张表）。这意味着本件不提供「学术影响力」意义上的 PageRank（那种 PageRank 依赖引用方向）。若甲方要求引用口径，需要补「被引论文主数据」，属另一批工作。

### 4.3 有向版的方向语义不可解释

有向版的方向来自「署名顺序最前者 → 其余」，它只表示**署名次序**，不表示知识流、不表示合作主导。max_out 82、max_in 94 这些读数只能说明「有些机构经常排第一」，不能说明「它影响了 94 个机构」。因此有向版只作对照。

### 4.4 加权版放大高产合作

加权版把边权当多条边，等于假设「合作 5 篇 = 5 倍权重」。这在共著网络里是一个强假设：一篇挂 10 个机构的论文会让 45 对机构各加 1，高产的机构被系统性放大。主口径坚持无权，就是这个原因。

### 4.5 机构未归并

与前几件相同：原始机构串、未做上下级归并。PageRank 对归并的敏感度低于中介中心性（后者会产生假桥），但仍会受影响：母体与院系分成两个节点，各自分配权重。

### 4.6 不得外推的三件事

1. **不得读作影响力/实力**：PageRank 是结构份额，与论文质量、营收无关。
2. **不得跨参数比较**：alpha 0.50 的 9.9647 与 alpha 0.99 的 25.1793 不可比，同一份材料里只能出现一个 alpha。
3. **不得跨点集比较**：P2 与 P1 的均值不同（0.6569 对 0.59186），绝对值不可比。

### 4.7 停用与重估条件

出现以下任一情况应重估：① 引用网闭合率修好（id 空间打通），应改为引用口径并重写全部结论；② 机构归并落地，节点数变化；③ 引入业务边，方向语义改写；④ 若甲方要求「个性化 PageRank」（按行业/地域加权），需新增参数并重标口径。

## 五、结果与解读

### 5.1 头部是谁

top20 的类型构成：高校 12 个、院所 6 个、企业 2 个（top-100 口径：高校 72、院所 12、企业 14、其他 2）。前五名：广州中医药大学第一附属医院（17.4269）、华南理工大学（16.0218）、广州地铁设计研究院（12.8791）、中国能源建设集团广东省电力设计研究院（12.4031）、中南大学土木工程学院（11.9814）。

这份名单与度榜高度重合（前 10 名有 8 个相同），差别在排序：度榜第 5 名南方电网科学研究院（度 125）在 PageRank 榜排第 6，度榜第 8 名广州中医药大学（度 112）排第 10。**排序的微调来自二阶结构**，不是新信息。

### 5.2 读数怎么用

第一，做榜单：取 P2 top-100（占总量 6.701%，头部并不集中）。第二，做「平滑的重要性排序」：当度榜被超级枢纽霸屏时，PageRank 会把它们压回来一点。第三，做阈值筛选：不要用绝对值，用 `mult_vs_uniform`（如 ≥5 倍均匀值）。

第四，不要用它做「发现隐藏重要节点」——在本图上它找不出度榜之外的东西。真要找隐藏节点，用中介中心性（008）。

### 5.3 稳定性与互证

| 检验 | 结果 | 结论 |
|---|---|---|
| 幂迭代收敛 | 40 次 / 1.3729e-08 | 数值稳定 |
| alpha 扫描秩相关 | 0.973083—0.99214 | 排序对阻尼不敏感 |
| 加权版 top-20 重合 | 16 | 权重不改头部 |
| 有向版 top-20 重合 | 16 | 方向不改头部 |
| 与度秩相关 | 0.937701 | 同一信息源 |

### 5.4 反常识点与解释

**反常识一：alpha 从 0.50 到 0.99，排序几乎不变（0.973083 以上），数值涨 2.53 倍。** 说明 PageRank 的排序主要由图结构决定，阻尼只是尺度旋钮。

**反常识二：加权版最大值（36.01595）是无权版（17.42688）的 2.07 倍，但 top-20 只换 4 个。** 权重放大的是数值，不是结构。

**反常识三：top-100 只占总量 6.701%，比度榜还低。** 阻尼项不断把权重摊回均匀，头部集中度被系统性压低——**PageRank 天生不适合做「Top N」榜单**。

**反常识四：有向版最大 33.74094，反而比加权版低一点。** 有向图把边数从 36,965 降到 29,768（每篇只保留「最前者 → 其余」），结构更稀疏，头部集中度略降。

### 5.5 与其它指标的联动

与 006：0.937701，top-100 重合 92。两者应视为同一维度的两种算法，不应并列宣传。

与 008：0.850506。中介榜第 2 名「不详」在 PageRank 榜只排第 20（8.3981），说明「桥」与「被重要节点连着」是两件事。

与 007：0.386608，最低。这组低相关是本件最值得记住的联动：**位置居中（closeness 高）与权重高（PageRank 高）几乎无关**。

第一，P2 上 PageRank 40 次迭代收敛（1.3729e-08），最大 17.4269 万分比（26.529 倍均匀值）。第二，与度中心性秩相关 0.937701，**不是独立信息源**。第三，alpha/加权/有向三组对照下 top-20 重合 16 个，说明头部结构稳健、参数只改尺度。
