### 1.2 为什么需要「社群属性」

图谱有 20,436 个机构节点、38,208 条边。平铺展示没有信息量，读者需要的是「分堆」：哪些机构经常一起发论文、这些机构是高校还是企业、在哪个城市、做什么方向、堆与堆之间靠谁连。

需求原文只写了「社群属性与特征分析」七个字，没有定义属性清单，也没有给社群算法。本件按图族既定口径（001/002/011 的建图基线、006—012 的点集写法）落地：用 Louvain 划分、用模块度校验、用拓扑 + 语义两层属性描述。

### 1.3 口径定义

图 $G=(V,E,w)$，节点为机构名，边为共著关系，边权 $w_{uv}$ 为共同署名篇数。社群划分 $\mathcal{C}=\{C_1,\dots,C_k\}$ 由 Louvain 在 P2 巨连通片上求得，模块度：

$$Q=\frac{1}{2m}\sum_{u,v}\left[w_{uv}-\frac{k_uk_v}{2m}\right]\delta(c_u,c_v)$$

社群属性分两层。拓扑层：规模 $|C|$、内部边数、内部密度、内部平均权重、出割边数、出割权重、电导：

$$\phi(C)=\frac{\text{cut}(C,\bar C)}{\min\left(\mathrm{vol}(C),\mathrm{vol}(\bar C)\right)}$$

语义层：机构类型构成（高校/企业/院所/其他）、主题词 Top8、学科分类 Top3、涉及论文数、关键词覆盖率。

## 二、计算过程

### 2.1 点集选择：为什么是 P2

图族 006—012 已把点集定成四套：P0 全图（20,436 节点）、P1 保留碎片分量、P2 巨连通片（15,223 节点）、P3 去孤立点。社群划分只在 P2 上有意义——P0/P3 含 3,540 个孤立点，Louvain 会把每个孤立点单独成社群，社群数会从 60 涨到几千；P1 含 645 个碎片分量，会多出 701 个社群（012 件实测）。

本件选 P2：15,223 节点 / 36,965 边，占全图节点 74.4911%、边 96.7468%。边覆盖率远高于节点覆盖率，说明被剔除的 5,213 个节点只带走 3.2532% 的边——它们是孤立点与碎片，本来就不承载社群结构。

孤立点处置写死：**剔除**。它们没有社群归属，不记 0、不单独成社群。若强行纳入，会出现数千个「单点社群」，模块度虚高且不可解释。

### 2.2 划分来源：读快照，不重跑

Louvain 有随机性（节点顺序敏感），同一张图重跑可能得到不同的社群编号。为了保证本件与 012 件的社群编号逐位一致，本件**直接读快照的 `community` 字段**，不重跑划分。

校验：本件用快照划分重算模块度得 0.755103，与快照记录的 `modularity` 完全相同（`modularity_recomputed == modularity_snapshot`）。这条校验证明「读进来的划分」与「快照声称的划分」是同一个，不是两份。

`membership_missing_nodes = 0`：15,223 个巨片节点全部有社群归属，没有漏标。

### 2.3 规模分布

60 个社群：最小 3、中位 130.5、P90 606、最大 1,637、均值 253.716667。52 个社群 ≥10 节点，8 个 <10（最小 3）。没有单点社群（`n_singleton = 0`）。

最大社群 1,637 节点，占巨片 10.7535%。前 15 大社群合计占 68.3571%——「少数大群 + 长尾中群」的结构。这个形状对展示友好：默认展示前 15 个社群就能覆盖三分之二的节点。

### 2.4 拓扑属性

对每个社群算内部边数、内部密度、内部平均权重、出割边数、出割权重、电导。以最大社群（cid 0）为例：1,637 节点、3,610 条内部边、密度 0.00269591、内部平均权重 1.3834、出割 2,120 条边 / 权重 2,233、电导 0.182718。

密度 0.00269591 看起来很低，但对 1,637 节点的图来说是正常量级——完全图的密度是 1，实际共著图密度普遍在 10⁻³ 量级。

前 15 大社群里电导最低的是 cid 1（0.106387，1,102 节点），最高的是 cid 7（0.294416，580 节点）；全 60 个社群里最低的是 cid 48（0.008，17 节点）。低电导 = 内部连接紧密、对外切割少；cid 1 是广州中医药大学第一附属医院领衔的社群，内部共著极密。

### 2.5 跨社群联系

巨片总边权 48,705，其中跨社群边权 9,303（19.1007%），社群内边权 39,402（80.8993%）。模块度 0.755103 与这个比例一致：八成权重在社群内，两成跨社群。

跨社群权重最高的五对：cid 0—7（358，3.8482%）、cid 1—12（298，3.2033%）、cid 0—3（256，2.7518%）、cid 0—4（238，2.5583%）、cid 1—3（215，2.3111%）。cid 0（土木/建筑）与 cid 7（水利/岩土）联系最紧，cid 1（中医）与 cid 12（中医药大学）联系次之——都是学科邻近的社群。

### 2.6 语义属性：主题词

## 四、数据缺失情况

### 4.1 主题词覆盖率只有 0.7919%

这是本件最硬的缺口。分类表 20,048 行，能 JOIN 上论文的只有 799 行。原因：分类表的 `id` 与论文表的 `id` 不是同一套编码，或是分类只覆盖了少数论文。无论哪种，结果一样——60 个社群里 46 个能挂主题，但每个社群的关键词都只有个位数样本（最高 3 次），词云不可作结论。

旧口径的 19.87% 是错的（20,048/100,900），本件按实测 JOIN 写 0.7919%，并在 `derived.denominator_note` 里把两个分母都列出来（分类表 20,048 / 论文 100,900），防止再混。

### 4.2 机构元数据匹配 11.4038%

1,736 / 15,223。未匹配的 88.5962% 节点类型靠名称关键词推断。推断规则粗糙（含「大学」记高校），会把「XX大学附属医院」判成高校（实际是医院），也会把「XX科技有限公司」判成企业（可能其实是研究院）。

### 4.3 三类业务边结构性无源

| 表 | 检索条件 | 命中 |
|---|---|---:|
| `enterprise_centrality` | `information_schema` 逐字 | 0 |
| `enterprise_cooperation` | 同上 | 0 |
| `enterprise_supply_chain` | 同上 | 0 |
| `enterprise_industry_chain` | 同上 | 0 |
| `graph_node` | 同上 | 0 |

| 模糊 `communit` / `cooperat` / `central` | 表名 LIKE | 0 |

供应链「完全不支持」的逐列正则扇证据已归档在 `_work_gkx21/CHANGELOG_gkx21.md`（2026-10-23 03:17），本件不重推，直接引用。社群不能读作「产业链集群」——共著边是学术合作，与供应链无关。

### 4.4 P2 外的节点被剔除

3,540 个孤立点 + 645 个碎片分量（5,213 节点）不进社群。它们占全图节点的 25.5089%，但不承载社群结构。发布时必须说明「社群覆盖率只对巨片成立」。

### 4.5 社群编号不稳定

cid 是「按规模排序的序号」，不是稳定主键。下一次重跑若规模排序变化，cid 0 可能变成另一个社群。跨版本对比必须用成员集合的 Jaccard，不能用 cid。

### 4.6 不得外推的三件事

1. **不得读作「产业链集群」**：共著边是学术合作。
2. **不得读作「区域创新集群」**：城市分布只是论文库的地域偏置。
3. **不得用小样本词云下结论**：主题覆盖 0.7919%。

### 4.7 停用与重估条件

出现以下任一情况应重估：① 分类表 id 与论文表打通（主题覆盖提升）；② 机构底册补全（元数据匹配提升）；③ 引入企业合作边（社群语义换成产业）；④ 重跑划分（cid 全变，需重写快照）。

## 五、结果与解读

### 5.1 划分的结构

60 个社群、模块度 0.755103，属于强社群结构。规模分布「少数大群 + 长尾中群」：前 15 大占 68.3571%，剩余 45 个分 31.6429%。没有单点社群，说明 P2 的选择是对的——若用 P0，会有 3,540 个单点社群把模块度推到无意义的 0.99。

### 5.2 社群的方向能不能看出来

能看出「大方向」，看不出「细分方向」。cid 0 的关键词是「抗震性能」「城市群」「施工技术」，首位成员是中南大学土木工程学院——土木/建筑方向明确。cid 1 是「冠心病」「治疗」「动物」，首位成员是广州中医药大学第一附属医院——中医临床方向明确。但每个词只出现 2—3 次，无法判断社群内部还有哪些子方向。

### 5.3 跨社群联系

跨社群权重 19.1007%，头部五对都是学科邻近：土木（0）—水利（7）、中医（1）—中医药大学（12）、土木（0）—华南理工（3）、土木（0）—石油勘探（4）、中医（1）—华南理工（3）。这说明社群划分基本沿学科切开，跨群联系主要发生在邻近学科之间。

### 5.4 反常识点

**反常识一：15 个最大社群的主导类型全是「高校」。** 企业节点 2,408 个在巨片里，但没有一个社群以企业为主导。原因是共著网里高校节点度数更高，Louvain 会把企业挂到高校社群的外围。

**反常识二：主题词覆盖率最低的社群（cid 13，0.3523%）有 67 个元数据匹配，比覆盖率高得多的 cid 6（0.7702%，10 个匹配）还多。** 主题覆盖与元数据匹配是两条独立的缺失链，不能互相替代。

**反常识三：cid 1 在前 15 大社群里电导最低（0.106387）但规模只排第二。** 电导低说明内部紧、对外切割少，与规模无关。cid 1 是中医社群，内部共著密度极高。

**反常识四：分类表 20,048 行只连上 799 行论文。** 行数占比会算出 19.87%，实测连接只有 0.7919%——差 25 倍。这条是本件最重要的口径修正。

### 5.5 与其它指标的联动

与 `M_SYNTH_DS_23_GRAPH_ALGO_012`：同一快照、同一划分，012 给划分与模块度，本件给属性。两件必须一起发布，否则读者会把 cid 当成稳定主键。

与 `M_INNOV_DS_26_ECO_012`：012 件给机构分数，本件给社群画像。社群内头部机构的分数可以解释社群强弱。

与 `M_SYNTH_DS_23_GRAPH_ALGO_009`：PageRank 高的节点往往是社群桥接点，可与跨社群权重对照。
