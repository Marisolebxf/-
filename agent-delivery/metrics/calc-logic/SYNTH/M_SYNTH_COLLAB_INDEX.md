## 口径定义

选定区域内、统计年度的区域创新协同指数，由完整度、中心度、密度三项标准化后加权合成，取值 0—100。分数越高表示创新合作越紧密、网络覆盖越好。与 `M_SYNTH_191_1` 同核。

## 计算逻辑说明

**同 `M_SYNTH_191_1` 区域创新协同分析模型。**

建网边：联合专利、合作项目、人才流动。完整度目标类型固定为企业、科研机构、人才机构三类，不含服务机构，不用合作论文另建边。

| 维度 | 指标 | 指标说明 | 计算方法 | 源表字段 | 待建字段 |
| :--------- | :--------------- | :----------------------------------------------- | :----------------------------------------------------------- | -------- | -------- |
| **完整度** | 创新链环节覆盖率 | 企业、科研机构、人才机构三类是否已被合作边覆盖。 | 已进入协同的节点数（至少有一条合作边，即度 ≥ 1）÷ 区域内应纳入节点总数（用户所选主体类型在区域内的节点并集，含孤立节点）。 | 同 M_SYNTH_191_1 | 无 |
| **中心度** | 节点度中心性均值 | 协同网节点平均度数。 | 全部节点度数求和后除以节点数，再极值归一 | 同 M_SYNTH_191_1 | 无 |
| **密度** | 网络密度 | 实际合作边占完全图边数的比重。 | 实际无向边数除以节点两两相连时的边数 | 同 M_SYNTH_191_1 | 无 |
