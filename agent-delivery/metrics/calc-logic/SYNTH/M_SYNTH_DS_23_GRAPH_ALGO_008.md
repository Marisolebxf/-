## 摘要

中介中心性是图算法里「最贵」也「最反直觉」的一个。贵在算法：精确 Brandes 需要 15,223 次单源最短路，实测 566.4 秒。反直觉在语义：它排出来的第一名往往不是度最高的节点，而是**卡在两个群体之间的节点**。

| 读数 | 值 |
|---|---|
| 主点集 | P2 巨型连通分量 15,223 节点 / 36,965 边 |
| 最大中介中心性 | 5.864%（华南理工大学，度 156、334 篇） |
| 第二大 | 5.418%（不详，度 82、75 篇） |
| 中位数 | 0.002% |
| 均值 | 0.032% |
| 零值节点 | 5,629 个（36.98%） |
| 低于 1% 的节点 | 15,178 个（99.7%） |
| 前 1%（152 个）占中介总量 | 32.04% |
| 前 10%（1,522 个）占中介总量 | 75.26% |
| 中介总量 | 4.819943 |
| k=400 抽样 vs 精确 | Spearman 0.986902 |
| 判档 | 完全转换支持 |

这张读数最刺眼的一行是「36.98% 的节点为 0」。在一个连通图里，一个节点的中介中心性为 0，意味着**没有任何一对节点的最短路必须经过它**——它总是挂在某个邻居的「末端」。这类节点在共著网络里非常多，因为大量机构只跟一家单位合作（度 1 或 2），永远是路径的终点而不是中转站。

分布是极端右偏：median 0.002%、mean 0.032%（均值是中位数的 16 倍）、p99 0.437%、max 5.864%。前 1% 的 152 个节点吃掉了 32.04% 的中介量，前 10% 吃掉 75.26%。这意味着：**这张图的「桥」是少数节点承担的**，绝大多数机构在路径结构上可有可无。

第二名的故事比第一名更能说明这个指标的性质：「不详」这个脏值串（度只有 82、75 篇论文）拿到 5.418%，仅次于度 156 的华南理工大学。原因不是它重要，而是它把大量互不相关的论文连成一片，于是「从任意群体到任意群体」的最短路经常要穿过它。**这是一条脏数据污染图算法的直接证据**，也是本件主张「脏值必须在展示层标注」的理由。

计算口径上，本件坚持用精确值而不是抽样。k=400 抽样（约 2.6% 的源点）与精确值的秩相关是 0.986902，看起来很高，但抽样会把「中低段的名次」打乱：0.986902 对应的是 top-100 几乎不变、中段大量换位。正式口径用精确值，抽样值只作「预览/实时筛选」用，并在 UI 上标注。

### 1.2 口径定义

中介中心性衡量节点在**所有最短路径**中的中转份额：对每一对节点 $(s,t)$，看 $s$ 到 $t$ 有多少条最短路，其中有多少条经过 $v$，把比例加起来再归一化。它衡量的是「桥」的位置，不是「重要」的总量。

三个口径选择与前两件一致（点集、去重、归并），本件额外多一个：**归一化方式**。无向图的 Brandes 归一化分母是 $(n-1)(n-2)/2$，本件用 networkx 默认的 $2/((n-1)(n-2))$，使读数落在 0—1 再乘 100 报百分比。

### 1.3 计算公式与本批实现式

标准式：

$$C_B(v)=\sum_{s\neq v\neq t}\frac{\sigma_{st}(v)}{\sigma_{st}}$$

其中 $\sigma_{st}$ 是 $s$ 到 $t$ 的最短路条数，$\sigma_{st}(v)$ 是其中经过 $v$ 的条数。

本批实现式（归一化 + 百分比）：

$$C_B^{\prime}(v)=\frac{2}{(n-1)(n-2)}\cdot\sum_{s\neq v\neq t}\frac{\sigma_{st}(v)}{\sigma_{st}}\times 100$$

在主点集 P2 上 $n=15223$，分母 $(n-1)(n-2)=231{,}695{,}112$，故 $C_B^{\prime}(v)=200\cdot\sum\sigma_{st}(v)/\sigma_{st}/231{,}695{,}112$。最大 5.864% 对应原始值 0.05864。

## 二、计算过程

### 2.1 图装载与规模校验

本件读同一份族级快照 `code/_snapshots21/graph_algo_23_20261023.json`，取 `c_betw` 列。校验项与前两件相同：全图 20,436 / 38,208、巨片 15,223 / 36,965、孤立点 3,540。差异在本件多一项「零值计数」：P2 内 5,629 个节点读数为 0，占 36.98%；这个比例在 P3（9.11%）与 P4（4.13%）上逐步下降，因为截断低度节点会把「末端节点」剔掉。

### 2.2 精确 Brandes 的实现与耗时

Brandes 算法的核心是「一次单源最短路 + 一次反向依赖累加」，无向无权图上用 BFS 即可。对每个源 $s$：第一遍 BFS 求所有节点的距离 $\sigma$ 与前驱列表；第二遍按距离从远到近把依赖 $\delta$ 累加回前驱。总复杂度 $O(VE)$，在 P2 上是 $15{,}223\times52{,}188$ 量级的操作。

实测耗时：P2 566.4 秒（从 329.8 秒到 896.2 秒），P3 45.4 秒（896.2→941.6），P4 约 5 秒。这个耗时占了整个快照构建（约 20 分钟）的近一半。耗时之所以能接受，是因为「一次算完、五件共用」——若 008 自己单独建图重算，批处理时间会翻倍。

实现上有一个容易忽略的细节：无向图的累加必须**只做一次**（用 $s<t$ 的源点集），否则每条最短路会被算两遍。networkx 的 `betweenness_centrality` 内部已处理这一点，本件直接调用，不自己实现，避免这类经典错误。

### 2.3 为什么 P0/P1 不算

这是本件与 006/007 最大的口径差别。P0 有 4,186 个连通分量、P1 有 646 个。中介中心性的定义依赖「最短路存在」：若 $s$ 与 $t$ 不连通，$\sigma_{st}=0$，这一对不贡献任何量。但归一化分母 $(n-1)(n-2)$ 仍然按全图规模取，于是：

1. 分量内算出的原始量被一个「全图规模」的分母除掉，读数被系统性压低；
2. 不同分量的节点之间不可比（一个 14 节点分量内的桥，与巨片内的桥，分母相同但分母的语义不同）。

结论是：**P0/P1 的中介中心性算出来也不能用**。本件因此在产物里显式写 `not_computed: ["P0 全图", "P1 有边子图"]` 与理由，而不是悄悄只报 P2。这一点与已归档的 001/002/011 一致（那三件也不在 P0/P1 上算中介）。

| p99 | 0.437 |
| 最大 | 5.864 |

均值 0.032 是中位数 0.002 的 16 倍，p99 是中位数的 218.5 倍，max 是中位数的 2,932 倍。这是典型的「少数桥 + 大批零」结构。集中度读数把这件事说得更直白：

| 口径 | 节点数 | 占中介总量 |
|---|---|---|
| 前 1% | 152 | 32.04% |
| 前 10% | 1,522 | 75.26% |
| 前 100 名 | 100 | 26.58% |

前 100 名占 26.58%、前 1%（152 个）占 32.04%，两者差 5.46 个百分点，落在第 100—152 名这一段。这说明榜单截断在 100 会丢掉一块可观的中介量——与 006 的度榜不同（006 的前 100 只占 8.87%，因为度的分布更均匀）。

### 2.5 精确值与抽样的对照

`sample_check` 给出 k=400 抽样（约 2.6% 的源点）与精确值的 Spearman 相关：0.986902。这个数看起来很高，但要读懂它需要三个补充事实：

第一，Spearman 是**秩**相关，对「整体顺序」敏感、对「具体数值」不敏感。0.986902 意味着排序大体一致，不意味着数值可以互相替代。

第二，抽样会系统性地低估枢纽：只跑 400 个源点时，那些「只在一小部分最短路中当桥」的节点可能一次都没被抽到，读数直接为 0；而真正的枢纽在每个源点上都出现，读数被相对放大。

第三，抽样值的方差与 $k$ 成反比：$k=400$ 的误差约是 $k=15{,}223$ 的 $\sqrt{38}\approx6.2$ 倍。若前端要用抽样做实时预览，必须标注「近似值」，且不能用于榜单排序的最终结果。

本件的结论是：**正式口径用精确值（566.4 秒，一次性），抽样只用于交互式预览**。

### 2.6 点集敏感性

| 检验 | P3（度≥5） | P4（度≥10） |
|---|---|---|
| 覆盖率（节点） | 21.87% | 7.7% |
| 节点数 | 4,469 | 1,573 |
| 与 P2 的秩相关 | 0.775254 | 0.749574 |
| top-100 交集 | 89 | 81 |
| top-100 Jaccard | 0.8018 | 0.6807 |
| 子图内最大读数 | 5.959% | 5.821% |
| 零值占比 | 9.11% | 4.13% |

三条读数值得注意。第一，秩相关（0.775254 / 0.749574）比 closeness（0.996947 / 0.986691）低得多——**中介中心性对点集截断最敏感**，因为截断会直接删掉「桥两端的路径」，重新定义谁是桥。

第二，top-100 交集 89 / 81 却不算低。这说明头部的一批真枢纽（华工、地铁院、电网院）在任何子图里都是桥，变的是榜尾。

第三，子图内最大读数（5.959%、5.821%）与主口径（5.864%）几乎一样，与度/紧密中心性不同（那两件子图读数会翻倍）。原因是归一化分母按子图节点数缩小的同时，原始最短路计数也同比缩小，两者部分抵消。这一点不能推广成「中介中心性可跨点集比较」——零值占比从 36.98% 掉到 4.13% 就是反例。

## 四、数据缺失情况

### 4.1 P0/P1 不可算

如 §2.3 所述，P0（4,186 个分量）与 P1（646 个分量）上的中介中心性不可用。这不是「暂时算不出」，而是「定义上不可比」：跨分量的最短路不存在，归一化分母却按全图取。本件在产物里显式记录 `not_computed`，并在正文重复一次，避免下游误用。

### 4.2 脏值污染比度中心性更严重

「不详」在中介榜排第 2（5.418%），在度榜只排第 19（5.387‰）。原因是假连接会把「本来要走很长路」的两群节点直接连起来，于是这个假节点成了所有跨群最短路的必经之地。**中介中心性对假边的敏感度高于度中心性**，因为度只加 1，中介却可能加一条主干道。

处理方式：展示层标注为「其他」类型并加 tooltip；不剔除（剔除会改变节点数，与兄弟件对不上）。

### 4.3 分布极偏导致「平均」无意义

均值 0.032% 是 median 的 16 倍，且 36.98% 的节点为 0。任何用「平均中介中心性」描述这张图的说法都是错的；应报中位数（0.002%）与零值占比（36.98%）。

### 4.4 机构未归并

同一所学校的不同院系是不同节点，会产生**假桥**：一所大学的两个学院之间没有被「母体」连起来，反而要通过外部机构中转，于是外部机构的中介被抬高。这是本件读数最需要注意的系统性偏差之一。归并需要机构主数据，本批不做。

### 4.5 边类缺失

| 边类 | 库内承接 | 后果 |
|---|---|---|
| 供应/采购 | 无表 | 无法算供应链上的桥 |
| 企业合作 | 无表 | 无法算业务合作的桥 |
| 技术流向 | 无表 | 无法算技术扩散的中转 |
| 论文共著 | `dwd_zh_paper` | **可用**，本件唯一口径 |

### 4.6 不得外推的三件事

1. **不得读作重要性总量**：中介高只说明「位置关键」，不说明「实力强」；度低的脏值串能排第 2 就是证明。
2. **不得跨点集比较**：P2/P3/P4 的零值占比 36.98% / 9.11% / 4.13% 说明三个点集的结构完全不同。
3. **不得用抽样值做最终榜单**：k=400 的秩相关 0.986902 只保证「大体顺序」，中段换位会改变榜单。

### 4.7 停用与重估条件

出现以下任一情况应重估：① 机构归并落地，假桥消失，排名会显著变化；② 语料扩量到 3 万节点以上，$O(VE)$ 可能从 10 分钟涨到 1 小时，需改抽样；③ 引入有向业务边，需改用有向中介中心性；④ 若前端要「实时算」，只能给抽样值并标误差。

## 五、结果与解读

### 5.1 头部是谁

top20 的类型构成：高校 77%（top-100 口径）、院所 11、企业 10、其他 2。前五名是华南理工大学（5.864%）、不详（5.418%）、广州地铁设计研究院（4.504%）、中国能源建设集团广东省电力设计研究院（3.815%）、广东电网电力科学研究院（3.117%）。

这份名单与度榜的差别在「不详」：它度只有 82，却拿到 5.418% 的中介。第 6 名中国科学院地理科学与资源研究所（3.031%、度 87、83 篇）也是「度不高但中介高」的典型——地理资源类机构横跨多个学科群体，天然是桥。

### 5.2 读数怎么用

第一，做榜单：取 P2 top-100（前 100 名占中介总量 26.58%）。第二，做「桥识别」：门槛不要用绝对值（0.437% 已经是 p99），用排名或「零值以外的前 N%」。第三，做路径高亮：给定一对机构，最短路上的节点按中介值着色，能直观看出「这条路为什么走它」。

第四，不要用中介中心性做节点大小：36.98% 的节点为 0，视觉上会有一大片「消失的点」，读者会以为数据缺失。

### 5.3 稳定性与互证

| 检验 | 结果 | 结论 |
|---|---|---|
| 精确 vs k=400 抽样 | Spearman 0.986902 | 抽样可用于预览，不可用于定榜 |
| P3 秩相关 | 0.775254 | 截断后排序明显变化 |
| P4 秩相关 | 0.749574 | 高门槛下变化更大 |
| 与 006 度相关 | 0.813618 | 两者相关但不重合 |
| 与 007 紧密相关 | 0.496407 | 两个不同问题 |

### 5.4 反常识点与解释

**反常识一：36.98% 的节点中介为 0。** 直觉上「连通图里每个节点都该有点作用」，实际大量节点是「末端」——所有最短路都从它旁边过，不经过它。

**反常识二：脏值「不详」排第 2。** 假边把不相关的论文群连成一片，制造出「必经之地」。这条同时是「图算法对数据质量极敏感」的证据。

**反常识三：子图内的最大读数几乎不变（5.959%、5.821% 对 5.864%）。** 归一化分母缩小与最短路计数缩小部分抵消，但零值占比从 36.98% 掉到 4.13%，说明「头部不变、尾部全变」。

**反常识四：k=400 抽样（2.6% 的源）秩相关就有 0.986902。** 但这不是「抽样够用」的证据，而是「头部枢纽在几乎每个源点上都出现」的必然结果——它恰好说明抽样对头部友好、对中段不友好。

### 5.5 与其它指标的联动

与 006：相关 0.813618，top-100 重合 73。中介榜独有的 27 个位置就是「度不高但卡在中间」的机构。

与 007：相关 0.496407，top-100 重合 62。两榜一起看能区分「位置居中」与「位置关键」。

与 009：相关 0.850506。PageRank 高的节点多为「被枢纽连着」，中介高的节点多为「连接两个枢纽」，两者在头部重合、在腰部不同。
