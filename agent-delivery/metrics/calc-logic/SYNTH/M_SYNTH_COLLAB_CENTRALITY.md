## 摘要

「协同网络中心度」是区域创新协同分析模型（算法库序号 191）三元网络指标中的「核心辐射力」维，用于回答区域内哪些创新主体是合作网络枢纽、整体网络对枢纽的依赖有多强，并与完整度、密度一并合成区域创新协同指数。需求原文只给出「中心度（评估关键节点的辐射影响力）」的语义，**没有给出中心度的具体计算定义**；王惠 calc-logic 在 `M_SYNTH_COLLAB_INDEX` 中把它闭合为「节点度中心性均值 = 全部节点度数求和 ÷ 节点数，再极值归一」，本报告沿用该口径并标注公式定义人为「仿王惠 ai-1020」。复算基于 2026-10-21 已落盘网络事实（联合专利边 + 人才流动边共 179 条城内边、合作项目边 0 条），四城平均度为中心度原始值：上海 0.4145、北京 0.2336、广州 0.00111、深圳 0.000269，极值归一后为上海 100.0、北京 56.34、广州 0.20、深圳 0.00。复算同时暴露一个方法学事实：在无向简单图上，归一化平均点度中心性恒等于图密度（本批四城最大绝对差 3.3×10⁻²⁴，仅为浮点误差），因此王惠的「均值中心度」与「密度」在排序上完全同构，**不能独立承担需求所要求的「识别关键节点」语义**。数据支持度判**部分支持**：三边缺合作项目边、节点分母被采集缺口双向扭曲、节点级度清单未落盘，枢纽识别暂时不可复核。

## 一、需求定义概述

### 1.1 所属功能模块（要开发什么）

本指标属于《科技专题服务算法库》**综合评价模型阶段**「产业综合分析模型构建」下的「区域创新协同分析模型」（§1.1.1.1.1.1.1.10.10，序号 191），在展示系统中挂载于「区域创新协同分析 / 协同度计算模型」（序号 140）。该模型要构建一张「企业—机构—人才」合作关系图谱，以联合专利、合作项目、人才流动三类关系为边，计算完整度、中心度、密度三类网络指标，并加权合成 0—100 的区域创新协同指数；中心度是三元指标中唯一直接指向「节点位置」的维度，产品侧对应「高效协同集群」「关键协同主体」「孤立主体」的识别与可视化。

在 SYNTH 族的指标分解中，本件是 191 模型件的**叶子指标**：191 负责「三边建网 + 三维合成 + 指数」的整体模型，本件只负责其中「中心度」这一维的口径、复现与数据支撑判定。两者共享同一套网络事实，但本件不重复承担指数合成职责；指数落点见 `M_SYNTH_COLLAB_INDEX`。

### 1.2 为什么需要「协同网络中心度」这个指标

区域创新体系不是主体清单，而是关系结构。Borgatti 等指出，社会网络分析的解释力来自「关系位置」而非「个体属性」，节点的度、路径与中心性决定了资源与信息在网络中的可达性 (Borgatti et al., 2009)。Freeman 对中心性概念的系统澄清进一步区分了点度中心性、接近中心性与中介中心性三种直觉：点度中心性刻画「一个节点直接连接了多少他者」，是最贴近「辐射影响力」的度量 (Freeman, 1978)。对区域创新协同分析而言，如果没有中心度，平台只能回答「网络连了多少」，无法回答「谁在连、谁被依赖、哪些主体是孤岛」，也就无法支撑需求原文所要求的「关键协同主体识别」与「协同薄弱环节诊断」。

在政策语境上，广东省委省政府在《广东省科技创新「十四五」规划》中明确提出「打造统一开放、竞争有序的产学研协同创新网络」，并要求促进创新资源自由流动与融合贯通 (广东省人民政府, 2021)。中心度正是把「协同网络」从政策表述转成可观测结构量的最小抓手：度高的主体是产学研网络的实际枢纽，度低或零度的主体是政策需要补链的对象。对深圳而言，这一维度还承担横向比较功能——比较各区、各产业领域、各年度「枢纽集中度」的变化，判断协同政策是造就了少数超级节点，还是扩大了网络参与面。

### 1.3 需求文档是否给出定义方法

**需求文档提及中心度指标及其语义，但没有给出中心度的计算定义。**《科技专题服务算法库》§10.10 只写「定义并计算完整度（衡量网络连接的全面性）、中心度（评估关键节点的辐射影响力）、密度（反映整体合作紧密度）三类指标」，未写节点度如何汇总、是否归一化、用点度还是中介/接近中心性、是否区分节点类型；展示系统 §1.1.1.2.4.2.8.3.1 也只要求「可视化连接密度与中心性指标」，未给公式。

王惠 calc-logic 在 `M_SYNTH_COLLAB_INDEX.md` 的维度表中把中心度落为「节点度中心性均值」：全部节点度数求和后除以节点数，再极值归一。该定义可执行、可与密度、完整度合成，但它是**均值口径**而非**分布口径**——它保留了「网络平均连接水平」，却丢掉了「关键节点是谁」的节点级信息。本报告如实沿用王惠口径以便与 191 对齐，同时在 §2.6 与 §5.4 披露该口径与需求语义之间的落差。

## 二、计算过程

### 2.1 方法选择：为什么用平均点度中心性，而不是中介或接近中心性

把「核心辐射力」操作化为网络指标，第一步是选定中心性族。Freeman 把中心性直觉分为三类：点度中心性看「直接连了多少」，接近中心性看「到其他节点有多近」，中介中心性看「有多少最短路径必须经过它」 (Freeman, 1978)。三者对应不同的网络机制：度中心性适合刻画资源直接触达与辐射面，接近中心性适合刻画信息传播速度，中介中心性适合刻画结构洞与控制力。区域创新协同的产品语义是「关键节点的辐射影响力」与「高效协同集群」，首先需要的是**直接合作规模**，而不是路径长度或桥接控制，因此点度中心性是最贴合的第一选择；这也与王惠「节点度中心性均值」的口径一致。

第二个选择是「均值」还是「分布」。王惠取全部节点度数的算术平均，得到图级平均度，再除以节点数为相对量。这样做的优点是可与完整度、密度共用同一套 $(n,m)$ 观测量，工程上最稳、最少假设；缺点是把「谁是枢纽」压缩成一个标量。Powell 等对生命科学产学研网络的研究表明，合作网络的演化恰恰体现在枢纽的形成与多重连接路径的增加，单看平均度会漏掉「少数超级节点 + 大量孤岛」这一最具政策含义的结构 (Powell et al., 2005)。Borgatti 等也强调，网络分析的许多解释力来自节点位置差异，而非整体均值 (Borgatti et al., 2009)。因此本报告在**保留王惠均值口径作为指数子项**的同时，把分布口径列为 §5.4 的升级建议，而不是擅自替换甲方已登记口径。

第三个选择是节点范围。中心度的分母是「区域内应纳入的主体全集」，不是「有边主体」。这一点在 §2.2 会展开：若只用有边主体作分母，得到的是覆盖子网平均度；若用全量主体作分母，得到的是全网平均度。王惠 INDEX 的完整度明确要求分母含无边主体，中心度作为同一网络的维度，应保持同一节点集，否则三维不可加。本报告据此采用**全量主体集**为主口径，用覆盖子网平均度仅作敏感性对照。广东省「十四五」科技创新规划把「产学研协同创新网络」作为政策目标 (广东省人民政府, 2021)，其政策评估对象是全部创新主体，而非仅已合作主体，这也支持全量分母的选择。

### 2.2 步骤 1｜节点集构建与分母口径

节点集按王惠口径取三类主体的并集（区域内）：存续企业（`dwd_org_base_info`）、科研机构（`dwd_research_institute_base_info`）、学者所属机构（`dwd_scholar.scholar_org_name_zh` 去重）。四城节点数分别为深圳 96,754（企业 95,600 + 科研机构 1,014 + 学者机构 140）、北京 642（163 + 0 + 479）、上海 304（16 + 0 + 288）、广州 50,449（49,605 + 822 + 22）。这组数字第一个要披露的事实是**分母的双向失真**：京沪的企业主档只有 163 与 16 家，真实主体应为万级，分母被严重低估；深广的企业主档是全量口径（95,600 与 49,605），但两类边的采集相对主档只是窄样本，分子被压低。

### 2.4 步骤 3｜节点度与平均点度中心性

对无向简单图 $G=(V,E)$，节点 $i$ 的度 $k_i$ 为与其相连的边数，平均点度中心性定义为全部节点度的算术平均：

$$C_{\mathrm{avg}}=\frac{1}{n}\sum_{i=1}^{n}k_i=\frac{2m}{n}$$

其中 $n=|V|$、$m=|E|$，因子 2 来自无向边对两个端点的贡献。王惠口径进一步把它归一为相对量 $C'_{\mathrm{avg}}=C_{\mathrm{avg}}/(n-1)$，使不同规模网络可比。代入四城 $(n,m)$ 得原始中心度：上海 $2\times63/304=0.41447$、北京 $2\times75/642=0.23364$、广州 $2\times28/50{,}449=0.0011100$、深圳 $2\times13/96{,}754=0.00026872$。这组数就是 §2.7 表格中的 `deg_avg_raw`，与 191 out.json 的 `raw_measures.deg_avg_raw` 逐位一致。

需要当场指出一个数学恒等式：在无向简单图上，$C'_{\mathrm{avg}}=\frac{2m}{n(n-1)}$，而图密度 $\rho=\frac{2m}{n(n-1)}$，两者**完全相同**。本批复算对四城逐城核验，最大绝对差为 $3.3\times10^{-24}$（广州的浮点尾差），其余三城为 0。这意味着：只要中心度取「平均度」口径，它与密度就是同一个量，**不能作为两个独立维度参与指数合成**。191 的指数之所以看起来有三个维度，是因为极值归一前中心度除以 $n$、密度除以 $n(n-1)$，分母相差 $(n-1)$ 倍，归一后分数不同；但排序信息完全同构（四城均为沪 > 京 > 广 > 深）。这是本报告最重要的方法学发现，§2.6 与 §5.4 会给出处理建议。

| 城市 | $n$ | $m$ | 平均度 $2m/n$ | 归一化中心度 $2m/[n(n-1)]$ | 与密度之差 |
|---|---:|---:|---:|---:|---:|
| 深圳 | 96,754 | 13 | 0.00026872 | 2.7774×10⁻⁹ | 0 |
| 北京 | 642 | 75 | 0.23364486 | 3.6450×10⁻⁴ | 0 |
| 上海 | 304 | 63 | 0.41447368 | 1.3679×10⁻³ | 0 |
| 广州 | 50,449 | 28 | 0.00111003 | 2.2003×10⁻⁸ | 3.3×10⁻²⁴ |

### 2.5 步骤 4｜极值归一与嵌入协同指数

中心度进入指数前要与其他两维同尺度。191 采用批内 min-max 归一：对每个维度，取四城最小值与最大值，把原始量线性映射到 0—100，再三维等权平均。中心度的归一结果为上海 100.0、北京 56.34、广州 0.20、深圳 0.00。北京之所以是 56.34 而不是按最大值归一得到的 56.37，是因为 min-max 用深圳的 0.000269 作为下界、上海的 0.41447 作为上界，分子分母都减去了下界；差值虽小，但在小样本四城里会改变第二位小数。归一方式的选择会在 §2.7.3 的敏感性检查中说明。

把中心度放进指数，严格服从王惠 `M_SYNTH_COLLAB_INDEX` 的合成规则：

$$\mathrm{Index}(c)=\frac{1}{3}\Big[\mathrm{mm}(\mathrm{Completeness}_c)+\mathrm{mm}(C_{\mathrm{avg},c})+\mathrm{mm}(\rho_c)\Big]$$

其中 $\mathrm{mm}(\cdot)$ 为批内 min-max 到 0—100。本件只负责 $C_{\mathrm{avg}}$ 这一项及其归一分数；指数整体结果由 `M_SYNTH_COLLAB_INDEX` 落盘，本报告在 §2.7.2 引用其值作一致性校验（上海 100.0、北京 45.05、广州 0.07、深圳 0.02），不重复承担指数解释职责。

中心度在指数中的权重是 1/3，但它的**边际信息量接近于零**，因为密度项已经包含了同一 $(n,m)$ 信息。用四城数据做验证：中心度分数与密度分数的 Spearman 秩相关为 1.0（排序完全相同），Pearson 相关也接近 1（仅因归一标度不同而略小于 1）。这不是数据问题，而是定义问题。若甲方希望三维真正正交，中心度必须换成节点级分布量（如 Top-1% 节点度占比、图级中心化指数），否则指数名义三维、实际二维。本报告不擅自改口径，但把这个结论写进 §5.4 的选用建议与 §四的缺口清单。

### 2.6 步骤 5｜结果校验与口径边界

第一项校验是图论一致性：所有城市满足 $m\le\binom{n}{2}$、$C_{\mathrm{avg}}\le n-1$、密度 $\le 1$，无越界；无向化后度数和等于 $2m$。第二项校验是恒等式：归一化中心度与密度逐城相等，最大差 $3.3\times10^{-24}$，确认二者同构。第三项校验是与兄弟件的一致性：本件 `deg_avg_raw` 与 `M_SYNTH_191_1_out.json` 的 `raw_measures.deg_avg_raw` 四城完全一致（上海 0.4144736842105263、北京 0.2336448598130841、广州 0.0011100319134175107、深圳 0.0002687227401451103），中心度维度分也与 191 的 `dim_scores.中心度` 一致（100.0/56.34/0.2/0.0）。这说明复算没有引入新误差。

第四项校验是覆盖节点缓存值的**图论上界检查**，这是本批必须披露的数据质量问题。上游 `covered_nodes_approx` 记录深圳 128、北京 236、上海 214、广州 46；但无向简单图中 $m$ 条边最多覆盖 $2m$ 个节点，四城上界分别为 26、150、126、56。深圳、北京、上海三城的缓存覆盖数都超过上界，说明该字段的口径不是「城内诱导子图的有边节点数」，可能混入了跨城对端或其他边域节点。中心度不直接用覆盖节点作分母（用全量 $n$），所以该问题不改变本件主值；但它使「覆盖子网平均度」只能作参考，不能作复核证据。§2.7 会同时列出缓存值与上界值。

第五项校验是结果合理性：四城中心度跨 3 个数量级（0.000269 至 0.4145），不是全体同分；高分城市（沪京）确有更多边（63/75 条）和更小分母（304/642 节点），低分城市（深广）确有更少边（13/28 条）和更大分母（96,754/50,449 节点）。分数方向可被 $(n,m)$ 直接解释，符合「小分母 + 足边 → 高中心度」的预期，说明复现逻辑正确，但也再次说明横比不可读作真实辐射力差异。

#### 2.7.3 结果解读

第一，**分数方向可解释，但幅度不可横比**。上海 100 分来自「63 条边 ÷ 304 个节点」，深圳 0 分来自「13 条边 ÷ 96,754 个节点」；分子上海是深圳的 4.8 倍，分母深圳是上海的 318 倍，二者共同造成 1,542 倍的平均度差距。这个差距不是协同辐射力的真实差距，而是企业主档采集口径的差距。正确读法是「城内自比」：在同一城市内看中心度随年度的变化，或看枢纽名单的变化；跨城横比必须等分母统一。

第二，**中心度与密度同构，指数名义三维实际二维**。归一化平均度恒等于密度，这不是近似而是恒等；四城排序完全一致。王惠把三维等权合成，等于给同一个 $(n,m)$ 信息赋了 2/3 权重（中心度 1/3 + 密度 1/3），完整度只占 1/3。191 的指数排序（沪 100、京 45、广 0.07、深 0.02）因此主要由「边/节点比」驱动。若甲方要用指数做政策评估，必须先决定：是接受「结构维只算一个」，还是把中心度换成真正的节点级分布量。

第三，**枢纽识别当前不可交付**。需求原文要求「识别关键协同主体」「发现高效合作集群与孤立主体」，这需要节点级度清单与 Top-N 排名，而本批只落盘了城市级 $(n,m)$ 与一个口径不明的 `covered_nodes_approx`。ORG 基线能列出广州中医药大学第一附属医院（910）、广州中医药大学（433）等枢纽，是因为该件脚本落了 `core_nodes_top15`；本件没有对应字段。工程上这是可补的（同一批边表按节点聚合度即可），但不在本轮「禁重跑探针」的范围内，故列为 §四 第一优先级缺口。

第四，**合作项目边缺失改变中心度的语义**。当前中心度只反映「共同申请专利 + 人才流动」，不反映「共同承担项目」。对产学研协同而言，项目合作是最直接的政策抓手；缺这一边，高校院所的枢纽地位会被系统性低估（它们的合作更多体现在项目而非专利）。因此本件分数只能称「专利—人才双边的中心度」，不能称「三类协同的中心度」。

第五，**与跨域基线的量级关系合理**。ORG 合作链机构子网平均度 3.196、密度 5.5×10⁻⁵；本族上海密度 1.37×10⁻³、北京 3.65×10⁻⁴，高于 ORG 子网，是因为本族分母只含四城主体且京沪分母被压小；深圳 2.78×10⁻⁹、广州 2.20×10⁻⁸ 远低于 ORG，是因为深广分母是全量企业主档。SVC 域代理图密度 3.05×10⁻⁶ 恰好落在本族沪京与深广之间，进一步说明密度量级主要由分母口径决定，而非协同强弱。

## 四、数据缺失情况

主指标可构建、四城已出数；残余缺口按影响排序如下：

1. **节点级度清单未落盘（第一优先级）**：需求要求「识别关键协同主体」，当前只有城市级 $(n,m)$，没有节点级 $k_i$、Top-N、图级中心化。建议在 ETL 落 `ads.synth_collab_node_degree`（region + window + subject_id + degree），本件即可从「均值中心度」升级为「分布中心度」。
2. **合作项目边全 NULL**：`dwd_zh_project.funded_institution` 58,453 行无一非空，三类边退化为两类，中心度不含项目合作语义。建议推动项目承担机构字段补数，或以「项目—机构」关联表重建。
3. **节点分母双向失真**：京沪企业主档 163/16 家（分母压低、中心度抬高），深广全量主档 95,600/49,605 家（分母放大、中心度压零）。建议统一为「有创新活动痕迹的主体入网」口径，或按行政区划/产业领域分层建网。
4. **覆盖节点缓存值与图论上界冲突**：深 128 > 26、京 236 > 150、沪 214 > 126，说明 `covered_nodes_approx` 口径不明。建议回填边清单后重算，或废弃该字段。
5. **中心度与密度同构**：均值口径下归一化中心度恒等于密度，指数三维实际二维。建议中心度改用 Top-1% 节点度占比或 Freeman 图级中心化，需甲方确认口径变更。
6. **无年度窗口**：当前为单窗快照，无法做趋势分析；建议按 `pbdt_year`、任职起止年展开年度网络。
7. **无物化结果面**：live 缺 `ads.synth_collab_centrality` 结果表，需建表承接区域×窗产出。

**甲方侧建议**：本指标属「可算但语义未闭合」；优先补节点级度清单与合作项目边，其次统一分母口径；在缺口修复前，产品层只展示「城内中心度相对变化」与「双边中心度」标注，不做跨城枢纽排名。

## 五、王惠方法对照与选用建议

### 5.1 王惠原方法还原（calc-logic 原文要点）

王惠未为本叶子指标单独出 calc-logic 文件，其口径内嵌在 `gkx-orchestration/agent-delivery/metrics/calc-logic/SYNTH/M_SYNTH_COLLAB_INDEX.md` 的维度表中：

- **维度定义**：中心度 =「节点度中心性均值」，指标说明为「协同网节点平均度数」。
- **计算方法**：全部节点度数求和后除以节点数，再极值归一。
- **源表字段**：同 `M_SYNTH_191_1`（企业主档、科研机构、学者、专利申请人、项目、任职经历）。
- **合成位置**：与完整度、密度等权合成区域创新协同指数（0—100）。

### 5.2 本报告处理概述

本报告未另立新口径，§二 即王惠均值口径的工程复现；仅做三点落地强化：其一，把「平均度 = 2m/n」与「归一化中心度 = 2m/[n(n−1)] = 密度」的恒等式显式化，写入 `identity_check`，避免后续把中心度与密度当独立维度；其二，把四城节点数、边数、原始中心度、维度分逐项落盘，并与 191 的 `raw_measures`/`dim_scores` 逐位比对；其三，增加覆盖节点缓存值的 2E 上界检查，暴露 `covered_nodes_approx` 的口径问题。方法本身未变，公式定义人仍标「仿王惠 ai-1020」。

### 5.3 逐维对照表

| 构件 | 王惠口径 | 本报告处理 | 数据支撑差异 | 可复现性差异 |
|---|---|---|---|---|
| 节点集 | 企业 + 科研机构 + 学者机构 | 完全一致 | 京沪企业缺口、京沪科研机构 0 | 一致 |
| 边集 | 联合专利 + 合作项目 + 人才流动 | 完全一致（合作项目 0 边显式化） | `funded_institution` 全 NULL | 一致（机检增强） |
| 中心度定义 | 节点度中心性均值 | 完全一致 | 节点级度未落盘 | 一致（恒等式核验增强） |
| 归一化 | 极值归一 | 完全一致（min-max） | — | 一致 |
| 合成 | 三维等权 | 仅落中心度维，指数由 INDEX 件承接 | 中心度与密度同构 | 一致 |

### 5.4 选用建议与理由

**建议采用「王惠均值口径 + 分布口径增强」的混合方案，当前交付以王惠为准。**理由分三层。第一，按用户钦定规则，王惠方法没有显著更差时应优先采用；本件王惠口径与权威点度中心性定义同源 (Freeman, 1978)，四城可复现、与 191 一致，工程上最稳，故指数合成继续用王惠均值口径。第二，王惠口径存在一个**语义缺陷**：均值中心度与密度恒等，无法回答需求原文「识别关键协同主体」；这不是「差一点」，而是「缺一类功能」。第三，补分布口径不需要推翻王惠，只需在同一张网络上追加节点级度清单与两个统计量（Top-1% 节点度占比、Freeman 图级中心化），即可保留指数连续性、又满足枢纽识别。建议甲方裁决点：中心度是否允许在指数外用分布口径展示；若允许，本件升级为「均值入指数 + 分布做展示」的双轨口径，公式定义人仍记王惠，增强部分记「仿王惠 ai-1020」。

## 附录 C　类似指标权威构建方法可行性报告（完整版）

### C.1 目的与范围

回答三个问题：权威文献如何定义「网络中心度」；本项目库表能否落地；综合方法可行性与数据可行性后应判何档。范围限定为「区域创新协同网络中的节点中心度」，不含个体网（egocentric）中心性与跨层网络中心性。

### C.2 需求语义锚定

需求原文要求中心度「评估关键节点的辐射影响力」，并用于「识别关键协同主体」「发现高效合作集群与孤立主体」。语义筛选标准：方法是否能区分节点位置、是否能量化直接合作规模、是否可在企业—机构—人才异质节点网络上执行。

### C.3 权威方法谱系

**C.3.1 点度中心性**。Freeman 把点度中心性定义为节点度数，并给出绝对量与相对量（除以 $n-1$）两种形式 (Freeman, 1978)。Wasserman 与 Faust 在 SNA 标准教材中系统整理了度、接近、中介、特征向量中心性的图论定义与性质 (Wasserman & Faust, 1994)。**贴合度：高**——直接对应「辐射影响力」；工程上只需节点—边清单。

**C.3.2 图级中心化**。Freeman 同时提出 graph centralization，用「最中心节点与其余节点的度数落差」度量整个网络对枢纽的依赖 (Freeman, 1978)。**贴合度：高**——可补均值口径丢失的「集中度」语义，回答「网络是少数超级节点还是广泛参与」。

**C.3.3 网络分析的机制视角**。Borgatti 等指出，度中心性对应「直接接触」机制，中介中心性对应「桥接」机制，接近中心性对应「传播」机制，方法选择应由解释机制决定 (Borgatti et al., 2009)。**贴合度：中高**——为「为何选点度而非中介」提供理论依据。

**C.3.4 产学研合作网络实证**。Powell 等以联合研发、共同专利、联盟边重建生命科学产学研网络，发现枢纽形成与多重连接是网络演化的核心 (Powell et al., 2005)；Breschi 与 Lissoni 用发明人流动与共同发明网络刻画知识扩散 (Breschi & Lissoni, 2009)。**贴合度：高**——本指标建边规则的经验锚。

**C.3.5 中国官方政策语境**。《广东省科技创新「十四五」规划》要求「打造统一开放、竞争有序的产学研协同创新网络」，促进创新资源自由流动与融合贯通 (广东省人民政府, 2021)。**贴合度：高**——为「中心度用于识别协同枢纽与补链对象」提供政策语义，非公式标准。

### C.5 推荐方案与风险

主方案：王惠均值口径入指数；增强方案：同一网络追加节点级度清单、Top-1% 度占比与图级中心化，用于枢纽识别与可视化。风险与缓解：合作项目边全 NULL（补数）；节点分母失真（统一入网口径）；覆盖节点口径不明（回填边清单）；中心度与密度同构（甲方裁决是否换分布口径）。总判：**方法可行性高、数据可行性部分（两类边可算、一类边缺失、节点级清单缺失）→ 部分支持**；补节点级清单与合作项目边后可升完全转换支持。
