## 口径定义

选定区域内、统计年度的政策创新成果指数，从创新政策数量、政策类型、政策效果三维评定，取值 0—100。分数越高表示创新政策供给与落地越好。

## 计算逻辑说明

采用加权平均。三维：创新政策数量 / 政策类型 / 政策效果。算法库序号 185 已给这三维，不另起维度。各维极值归一后等权（也可按评估重点改权，ΣW=1）。

### 第一步：入集

统计窗默认自然年。政策城市落到 `dwd_policy_base.city`，与目标区域对齐。有效：`status` 为有效且 `expire_date` 空或 ≥ 统计年末。年键=`publish_year`。类型看 `type` / `theme`。

### 第二步：三个子项

1. **创新政策数量**  
   统计年度该区域有效创新政策去重数。极值归一。

2. **政策类型**  
   实际出现的 `type`（或 `theme`）去重数 / 应覆盖四类（科研扶持、成果转化、产业促进、人才引进，按 `type`/`theme` 文本归并）。归并不上的类型仍计入分子去重，分母固定为 4。

3. **政策效果**  
   需求要执行成效（兑现、市场转化、投资拉动）。无兑现资金字段。正式口径沿用政策分析 `M_POLICY_DS_07_POLICY_GUARD_008` 的「政策实施效果」：实施时效性与政策可见度两子项等权。  
   - 实施时效性 = 当前日在实施日与失效日之间的政策数 / 有效政策总数。  
   - 政策可见度 = `link` 非空的政策数 / 有效政策总数。  
   这是实施周期与公开渠道完备率，不是资金兑付率或专利产出率；不另待建 `policy_fund_disbursed`。

三维等权得指数。输出区域一行，含三维得分与综合分。
