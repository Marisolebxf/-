## 数据支持度与缺口

- **判档**：部分支持
- **判档理由**：数量维在四市都有真实读数（深 879 / 广 325 / 莞 8 / 惠 0 条），类型维可用文件体裁覆盖度代理（深 11 / 广 10 / 莞 4 / 惠 0 类）；但效果维整维不可算：时间戳两列 20,000 行全是 '0000-00-00' 零日期，link 与 status 在四市是常数、零区分度；且王惠的四类政策主题在库内无字段（theme 19,998/20,000 为 0）。三维里一维整缺、一维只能代理，不满足『完全转换支持』的结构+数据双条件，判部分支持
- **基期声明**：政策表是**存量表**：四市 1,212 条公告的 publish_date 全部落在 1992—2022（深圳最早 2000、广州最早 1992、东莞仅 2020—2022 共 8 条、惠州 0 条），base_years_used 列的是库存量实际覆盖的发布年。2023—2026 进 missing 不是「有数据但缺值」：2023/2025/2026 全表零行，2024 只有 1 条北京记录（『平谷区便民咨询服务电话』）属脏数据，四市一条都没有，故这四年不进任何分母。另：publish_date 有 3 条零日期 '0000-00-00'，单独掷出不计年；`implementation_date` / `expire_date` 则是全表 20,000 行全为零日期（范围谓词实测 impl_zero=20000 / exp_zero=20000），不构成任何可用基期，`IS NOT NULL` 会把它们误报成 20,000 行有值，本版按零值处理。
