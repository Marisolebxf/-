## 口径定义

选定区域内、统计年度的区域创新要素综合指数，由类型、层次、领域三维评价结果合成，取值 0—100。分数越高表示创新要素综合禀赋越强。对象=要素综合，不是贡献路径（见 `M_SYNTH_ELEM_CONTRIB`），与 `M_SYNTH_ELEM_INDEX` 同核、本 ID 为算法库序号 190 模型入口。

## 计算逻辑说明

采用加权平均。三维：类型 / 层次 / 领域。算法库序号 190 已写「对区域创新要素类型、层次及领域进行系统化分析」。需求序号 136–138 为要素分析页，二级仍用这三维，不把贡献路径并入本核。各维先取子指数再等权（也可按评估重点改权，ΣW=1）。

本指标不另起叶子、不另选代表指标。三子指数分别调用 187 / 188 / 189 的入集与公式。

### 第一步：入集

入集同 `M_SYNTH_187_1`。

### 第二步：三个子项

1. **类型**  
   直接取 `M_SYNTH_187_1`（同 `M_SYNTH_ELEM_TYPE_INDEX`）综合分。本指标不重算七类要素配置。

2. **层次**  
   直接取 `M_SYNTH_188_1`（同 `M_SYNTH_ELEM_LEVEL_INDEX`）综合分。本指标不重算七结构成熟度与均衡度。

3. **领域**  
   直接取 `M_SYNTH_189_1`（同 `M_SYNTH_ELEM_DOMAIN_INDEX`）综合分。本指标不重算产业/技术覆盖。

三维等权得要素综合指数。输出区域一行，含三子指数与综合分。缺维不补 0、不进平均。
