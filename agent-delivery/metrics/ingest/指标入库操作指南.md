## 3. 最容易犯的计数错误

### 3.1 不要写“王惠定义了 60 个指标”

`指标ID` 的唯一值数量不是“指标总数”的唯一正确说法。每一行代表一个指标层级，可能是一级、二级或三级。正确表述应同时给出：

```text
60 个唯一指标ID
132 个有效指标行（有指标ID）
工作表另有 2 行无指标ID的非正式/空行
物理非空数据行共 134 行
```

本批 `20260817` 的实际值为：

| 口径                                           | 数量 |
| ---------------------------------------------- | ---: |
| 唯一`指标ID`                                 |   60 |
| 有`指标ID` 的有效指标行                      |  132 |
| `指标二级` 非空                              |   77 |
| `指标三级` 非空                              |   67 |
| `是否出现在算法demo UI == 是` 的行数         |   80 |
| `是否出现在算法demo UI == 是` 的唯一指标ID数 |   20 |

### 3.2 每个 XLSX 行都是指标级行

同一个 `指标ID` 可能包含 L1/L2/L3 多行。入主仓时必须把同一个 `metric_id` 的所有行合并为一个 MD 文件，不能一行一个 MD。

### 3.3 “是否出现在算法demo UI”只是工作底稿字段

这个字段用于记录和排查 UI 覆盖，不改主仓 YAML/MD 的正式字段。Excel 工作底稿本身不进 git。

- 全部 `metric_id`；
- 指标名称；
- 子指标行数；
- 对齐状态；
- 是否在数据库；
- MD 文件链接。

## 2. 任务 B：更新 `demo-ui-system-test` UI

### 2.1 范围识别

本批只允许清理“企业分析算法库 / `entan`”相关页面。路径：

```text
repos/demo-ui-system-test/src/views/entan
```

### 2.2 数据库核验方法

数据库地址在仓库根目录：

```text
database_env.yaml
```

核验必须确认：

1. 库是否存在；
2. 表是否存在；
3. 表是否有数据行；
4. 关键字段是否存在；
5. 关键字段是否非空/有多少非空。

只有“表存在且有关键数据”才可写数据库支持。表结构存在但 0 行，必须写“表存在但无数据，不能支撑正式计算”。

### 2.3 UI 指标先分类

页面上的指标分为三类：

1. **王惠正式指标**：在 XLSX 中有 `指标ID` 的指标。
2. **页面辅助/派生字段**：如排名、等级、雷达、维度分拆、图源、展示字段等。它们不是王惠正式指标，应写“王惠 xlsx 未定义此展示字段”。
3. **Mock 虚构指标**：如 `重点度`、`ads.ent_key_enterprise`、`重点资讯统计`、`ads.ent_news_stat` 等。应明确写“王惠 xlsx 未定义此指标；数据源为 mock 阶段虚构”。

### 2.4 更新 `metricReadinessEvidence.ts`

文件：

```text
repos/demo-ui-system-test/src/views/components/metricReadinessEvidence.ts
```

每个展示指标都需要给出：

```ts
{

  d2: string[];    // 库表结构支持，哪些支持、哪些不支持
  d3: string[];    // 源字段映射，哪些映射了、哪些没映射
  d4: string;      // mock / 预计算 / 正式接入状态
  summary: string; // 一句结论，说明堵点位置
}
```

示例：

```ts
M_ENT_TOTAL_COUNT: {

  ],
  d3: [
    '已映射：industry_name -> 未来产业筛选；credit_code -> 去重计数。',
    '未映射：王惠 MD 中 gkx.dwd_org_base_info.external_id 当前 0% 非空。'
  ],
  d4: 'D4=mock/预计算阶段：页面仍读演示汇总，尚未由上述真实表实时聚合。',
  summary: '行业标签可筛选、可去重；企业关联键 external_id 无数据，尚未建立正式口径实时链路。'
}
```

对于 Mock/未定义项：

```ts
d1: '王惠 xlsx 未定义「重点度」；该字段不是企业分析模型指标字段清单中的正式指标。',
d2: ['无王惠正式口径对应的库表结构要求；当前属于页面拆解/演示展示项。'],
d3: ['未建立王惠指标字段映射；页面若出现数值，来自演示/预计算，不应视为正式源字段。'],
d4: 'D4=不适用：无王惠口径下的真实数据接入要求；当前为演示数据。',
summary: '这是 UI 展示/演示指标，不是王惠调查表中的可入库指标。'
```
