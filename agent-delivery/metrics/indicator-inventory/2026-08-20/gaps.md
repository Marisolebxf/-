# 需规能力与指标缺口

本文件记录“需规点了能力，但没有原文点名的独立量化指标”的条目。原则是：没有原文依据不硬造三级或公式。

## 1. 定性输出，未拆独立指标

| 条目 | 位置 | 处理 |
|---|---|---|
| 政策焦点识别模型 | 序号 166 | 原文输出的“堵点、优化建议”属定性结论；inventory 只保留制定背景、目标、适用范围、措施执行情况，不把结论当独立指标 |
| 政策布局推荐模型 | 序号 171 | 原文是流程/组合推荐模型，未给出可独立统计的量化维度，树中标注“本级止” |
| 服务链短板分析模型 | 序号 172 | 短板识别、补链建议为定性输出；inventory 只保留服务质量、经营效益、服务类型结构三个可统计维度 |

## 2. 能力/API 类，不是普通指标

- 服务机构图谱（112/113）、政策图谱（106/107）、综合图谱 API（116）：属于实体识别、关系抽取或 API 能力点。inventory 保留能力清单，但不冒充基础指标或公式。

## 3. 我方公式范围外

- 综合 182（区域科技创新成果）中基础科学、应用科技、科研机构叶子：`owner=第三方`。
- 综合 184（区域产业创新人才）：全模型 `owner=第三方`。
- 综合 186/187/188/189 中“科技、人才、科研机构、技术领域、人才结构”叶子：`owner=第三方`。

## 4. 产业链 / 企业 seed 缺口

具体缺项和补抽条数见 `coverage-check.md`。结论是：基础九维和五类均已登记进 inventory，但增长率、技术交易额、企业重点资讯等仍有补抽项，不能声称 seed 已闭合。
