## 1. 分层与暴露范围（供应方口径）

| 供应方层 | 表名习惯 | 含义 | 对本项目暴露 |
|----------|----------|------|--------------|
| **ODS 贴源层** | 多为 `ods_*` | 贴源数据；供应方侧会继续清洗加工 | **不暴露**（后续也不会对项目侧开放） |
| **DWD 明细层** | **`dwd_` 打头** | 经供应方清洗加工后的可用明细 | **项目侧工作面：专注这些表** |

### 工作约束（强制）

1. **只消费 `dwd_` 打头的表**做字段映射、只读 profile、算法取数与数据工厂输入。
2. **不要依赖 `ods_*`**：即使库内可见，也不得作为正式映射或算法输入真源；供应方明确后续不暴露 ODS。
3. **本项目自建层仍独立**：供应方 `dwd_*` = 本项目的**入站贴源原料**（编排文档里常记为「运行时 ODS 真源」）；本项目自建的 `dwd.*` / ADS **不得**与供应方 `dwd_*` 混名混用。

```text
供应方：  ods_*（不暴露）──清洗加工──► dwd_*（对项目开放）
本项目：  读入站 dwd_* ──数据工厂──► 自建 DWD / DWS / ADS
```

## 2. 统一技术字段（供应方新增）

供应方在相关表上增加以下**技术字段**（做映射 / DDL 对照 / DQ 时必须识别，**不得当业务口径字段**）：

| 字段 | 类型 | 约束 / 默认 | 含义 |
|------|------|-------------|------|
| `created_time` | `DATETIME` | `NOT NULL DEFAULT '1970-01-01 00:00:00'` | 数据在库中的创建时间 |
| `updated_time` | `DATETIME` | 可空 | 该条数据最近一次更新的时间 |
| `creater` | `VARCHAR(100)` | 可空 | 数据新增操作员 |
| `updater` | `VARCHAR(100)` | 可空 | 数据更新操作员 |
| `table_data_source` | `VARCHAR(100)` | 可空 | 技术字段，数据来源 |
| `is_deleted` | `SMALLINT` | `NOT NULL` | 逻辑删除标识：`0` 未删除，`1` 已删除 |

### 使用约定

- 入站取数默认加 **`is_deleted = 0`**（或与供应方确认等价过滤）。
- `created_time` / `updated_time` / `creater` / `updater` / `table_data_source` 仅作血缘、审计、增量窗口；**不**映射为业务展示主字段（除非产品明确要求）。
- 旧基线 `要素库建表语句.sql` 可能缺少上述列；以 **live `gkx` + 本目录 DDL 沙箱** 为准。

参考 DDL 片段：

```sql
created_time      DATETIME NOT NULL DEFAULT '1970-01-01 00:00:00' COMMENT '数据在库中的创建时间',
updated_time      DATETIME COMMENT '该条数据最近一次更新的时间',
creater           VARCHAR(100) COMMENT '数据新增操作员',
updater           VARCHAR(100) COMMENT '数据更新操作员',
table_data_source VARCHAR(100) COMMENT '技术字段，数据来源',
is_deleted        SMALLINT NOT NULL COMMENT '逻辑删除标识，0未删除，1已删除'
```
