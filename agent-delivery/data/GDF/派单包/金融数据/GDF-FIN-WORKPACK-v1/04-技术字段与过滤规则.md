# 技术字段与过滤规则（Wave A）

来源：供应方工作约束。全文：`agent-delivery/data/third-party-source/gkx-mysql-raw/加工/SUPPLIER-WORK-CONSTRAINTS.md`。

## 1. 取数过滤（默认）

```sql
WHERE is_deleted = 0
```

金融 31 张表在行数报告里**都有** `is_deleted` 列。无该列的表登记例外，启动会确认后再灌。

## 2. 技术字段（不得当业务主字段）

live 金融表上的技术字段有 9 个（比供应方约束里的 6 个多 3 个）：

`dwd_id` / `created_time` / `updated_time` / `creater` / `updater` / `table_data_source` / `operator_remarks` / `is_deleted` / `insert_remark`

Wave A 原样镜像。Wave B 只把 `dwd_id` 带进 `src_dwd_id`，其余不进 `fin_*`（09 §3.2）。

`t_id` 是 Excel 多出的列，live 库无，不作源。

## 3. 镜像策略

目标表用源 `SHOW CREATE TABLE` 对齐（库名改为 `gkxlumenx_ods`）。首次全量。Wave A **不做** org 归一、**不做**拆行。

| 档 | 表 | 策略 |
|---|---|---|
| 小表（≤ 10 万行） | P0 全部（除 `dwd_sec_basic_info`）、行业分类、港美估值、期权基本、外汇、美股行情、0 行表 | 全量，每日覆盖或按 `updated_time` 增量，GDF 自定 |
| 大表（> 10 万行） | `dwd_sec_basic_info`（124 万）、主营构成三表（30 / 61 / 46 万）、`dwd_astock_val_indicators`（322 万）、`dwd_ls_stock_daily_quotation`（442 万）、`dwd_hk_sec_daily_quotation`（79 万） | 首次全量；之后按 `updated_time`（无则按 `dt` / `td_date`）增量。**增量与删除、重跑策略回签前不得宣称 CDC 闭环** |

## 4. 禁止

- 写三方 `gkx`。
- 依赖供应方 `ods_*`。
- 贴 / 洗 `*_bak_*`（供应方备份副本，如 `dwd_main_business_composition_*_bak_20260911`）。
- 把技术字段当业务口径。
- 把 `--`、空串、`/` 写成数值 0。

## 5. 缺表

清单有、查不到 → 登记待供应方核验，勿自行认定下线。

## 6. 重叠三表

`dwd_org_financing_info` / `dwd_org_invest_info` / `dwd_org_merger_acquisition_info` 的贴源只在 ENT-v4 配置一次，本包不重复建作业。见 `00` §6。
