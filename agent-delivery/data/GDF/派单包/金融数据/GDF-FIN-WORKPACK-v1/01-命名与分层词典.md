# 命名与分层词典（金融 GDF）— v1.0

> 混名会配错源 / 目标。

## 1. 标准用语

| 说法 | 指什么 | GDF 动作 |
|------|--------|----------|
| 金融要素库 | 三方 Excel「市场研究」工作簿里的 Sheet 名，是逻辑域，**不是物理库** | 表名真源 |
| 供应方表 | `gkx.dwd_*`（live，MySQL） | Wave A **源**（角色=ODS） |
| 供应方 `ods_*` | 供应方内部层 | **不读** |
| `gkxlumenx_ods` | 本项目贴源 | Wave A **目标** |
| `gkxlumenx_dwd.fin_*` | 本项目金融 DWD | Wave B **目标** |
| `gkxlumenx_ads.ads_fin_*` | 本项目金融 ADS | ② **目标**；Java 只读 |
| Demo `demo_gkxlumenx_*` | 联调模拟 | **禁止**当正式目标 |
| 物理表 31 张 | 行数报告「金融要素库」32 行去掉重复的 `dwd_corp_basic_info` | 以 31 计 |

## 2. 易混名

| 用这个 | 错误替代 |
|--------|----------|
| `dwd_*`（供应方）与 `fin_*`（本项目）分开 | 把供应方 `dwd_*` 当项目 DWD；把 `fin_*` 叫 `dwd_fin_*` |
| `fin_industrial_fund_inv_summary`（基金级汇总） | 叫「基金投资项目表」。源表 `dwd_industrial_fund_investment_project_info` 名字带 project，实际每基金一行汇总，不是项目级 |
| `dwd_fund_*`（公募基金，0 行） | `dwd_industrial_fund_*`（产业基金，有数）。两类基金不同表 |
| `org_id` 供应方机构 ID，原样 | `external_id` 信用代码当 `org_id`；自造 ID |
| `sec_id` 证券 ID | `sec_code` 证券代码（不唯一，不同市场可重） |

## 3. 主键

| 对象 | 键 |
|------|-----|
| 非联合 `fin_*` | `src_dwd_id`（供应方 `dwd_id`） |
| 联合 `fin_*` | `(src_table, src_dwd_id)` |
| 业务自然键 | 不作主键，普通索引；唯一性在验收登记（OPEN-FIN-02） |
