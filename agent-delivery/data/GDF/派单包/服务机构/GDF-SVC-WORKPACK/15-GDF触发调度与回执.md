# 触发、调度与回执

## 1. 何时跑

| 条件 | 动作 |
|------|------|
| 四张源表还没核对 | 不配，不跑 |
| 核对通过，人要点这一趟 | 跑一次。不配定时 |
| 当次没有写明重做全量 | `append`，见 `04` |
| 当次写明重做全量 | `replace`，只清 `04` 列出的七张 |
| 圈定没写完 | 不写事件、卡面、指标。本批已写下的行撤回 |

不要去调现网那次抽取。那次只连库名以 `demo_` 开头的库。

同一作业还在跑时，不要再开一份打同一张表。

## 2. 回执

跑完交回这些，并填 `05`。脚本打印的行数本身不是回签。

- 批次号 `svc-fseed-YYYYMMDD`
- 当次是追加还是重做
- 圈定行数、事件行数、卡面行数
- 四张指标表里出现的标识
- 停工时缺的表或少的列

## 3. 不要这样配

1. 不配定时。  
2. 不把这趟放进贴源作业或明细 CDC。  
3. 不写 `gkxlumenx_ods`，不写图库。  
4. 口令只放作业机，不进本包。
