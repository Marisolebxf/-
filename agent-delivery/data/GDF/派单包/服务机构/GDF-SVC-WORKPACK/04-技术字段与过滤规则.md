# 技术字段与过滤规则

这一趟不是贴源镜像。过滤只用于圈定和事件，不把供应方表原样抄进项目库。

## 1. 主表

- `org_id` 非空。
- 有 `is_deleted` 时只留 `0`。没有这列就不按删除标记滤，不停工。
- 别的列缺了就跳过该列。
- `created_time` 不写成投资事件的业务日。

## 2. 年报

每个 `org_id` 取 `year` 最大的一行，只要 `employees_number` 和 `operating_revenue`。没有这一行，卡面这两列空着。不合成，不写回供应方库。

## 3. 事件行才留下

- 融资：同时有 `org_id` 和 `funding_amount`。
- 投资：同时有 `org_id` 和 `investment_amount`。
- 金额解析不成元就空，不写成 0。
- 源表没有 `id` 列就停，不另拼事件键。

## 4. 追加与重做

默认 `append`。圈定池里已经有的 `org_id` 不再插一行。事件、卡面、指标只给本批新插入的机构。已有事件行不删。

只有人在当次写明要重做全量时才 `replace`。先清空这七张，再按当次命中全量写回去：

`svc_org_circle`、`svc_org_finance_event`、`svc_org_card`、`svc_metric_fact`、`svc_metric_series`、`svc_metric_dist`、`svc_region_dist`。

不清别的表。

批次号用运行当天：`svc-fseed-YYYYMMDD`。同一天再跑仍用这一串。

## 5. 缺列

目标表少了 `09` 里的列就停。不在作业里加列。
