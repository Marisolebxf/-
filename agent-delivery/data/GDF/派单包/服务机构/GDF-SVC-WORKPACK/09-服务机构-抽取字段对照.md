# 抽取字段对照

施工只认本文件的列。进池条件和指标算法在 `12`，不在这里改。  
**2026-11-04** round1 答复已落地（`GDF-SVC-WORKPACK-R1A-L01`）。

## 1. 圈定池 `gkxlumenx_dwd.svc_org_circle`

| 列 | 怎么填 |
|----|--------|
| `org_id` | 主表 `org_id`。非空。唯一 |
| `rule_version` | 固定 `svc_rule_demo_kw_v1.1` |
| `hit_fields` | 命中了哪些源列，JSON（可含 `main_activities`） |
| `service_type_candidate` | `12` 的六类之一，或空 |
| `pending_client_confirm` | 固定 `1` |
| `etl_batch_id` | 当天批次号，见 `04` |
| `ext` | 本批不因「不足 10 家整表回退」写入（该规则已取消）。可空 |

## 2. 投融资事件 `gkxlumenx_dwd.svc_org_finance_event`

`event_type` 只取 `FINANCING` 或 `INVEST`。表唯一键：`UNIQUE(event_id)`。

| 列 | 融资 | 投资 |
|----|------|------|
| `org_id` | 源 `org_id`（融资主体） | 源 `org_id`（**投资方**，Q3） |
| `event_id` | `md5` 复合键，见 `08`§3 | 同左 |
| `event_type` | `FINANCING` | `INVEST` |
| `amount` | `funding_amount` 解析成**元**；外币不换汇；解析不了就空 | `investment_amount`（元） |
| `event_date` | `completion_date`，空就空 | 空 |
| `etl_batch_id` | 当天批次号 | 当天批次号 |
| `ext` | `funding_round`、`investors_name`、币种（有则写，不加独立列） | `inv_org_id`、`inv_name`、`created_time` |

禁止源行全字段拼进 `ext`。

## 3. 卡面 `gkxlumenx_ads.svc_org_card`

人口是本批圈定机构。属性从 ODS 主表 / 年报读，不把主体拷进圈定池。

| 列 | 来源 |
|----|------|
| `org_id` | 本批圈定 |
| `name_cn`、`province`、`city` | 主表同名列 |
| `area` | 主表 `area`（所在区县）。项目 ODS **无** `district`，不做回退 |
| `industry` | 主表 `industry`。没有这列就空 |
| `org_size` | 主表 `org_size`。没有就空 |
| `employees_number`、`operating_revenue` | 年报里该机构 `year` 最大的一行。没有这一行就空。**禁止合成** |
| `service_type_candidate` | 圈定池 |
| `pending_client_confirm` | `1` |
| `etl_batch_id` | 当天批次号 |
| `ext` | **本批不映射**（占位列，Q6），留 NULL |

行业分层、行业代码、`main_activities` 只在 `12` 用来圈定，不新增卡面列。
