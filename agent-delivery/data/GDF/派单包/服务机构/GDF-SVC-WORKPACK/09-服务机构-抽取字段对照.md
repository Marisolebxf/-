# 抽取字段对照

施工只认本文件的列。进池条件和指标算法在 `12`，不在这里改。

## 1. 圈定池 `gkxlumenx_dwd.svc_org_circle`

| 列 | 怎么填 |
|----|--------|
| `org_id` | 主表 `org_id`。非空。唯一 |
| `rule_version` | 固定 `svc_rule_demo_kw_v1.1` |
| `hit_fields` | 命中了哪些源列，JSON |
| `service_type_candidate` | `12` 的六类之一，或空 |
| `pending_client_confirm` | 固定 `1` |
| `etl_batch_id` | 当天批次号，见 `04` |
| `ext` | 命中不足 10 家、改走整表时记 `fallback_all_ods=1`。这个键名是旧称，不表示改读别的库 |

## 2. 投融资事件 `gkxlumenx_dwd.svc_org_finance_event`

`event_type` 只取 `FINANCING` 或 `INVEST`。同一 `org_id` + `event_id` + `event_type` 只留一行。

| 列 | 融资 | 投资 |
|----|------|------|
| `org_id` | 源 `org_id` | 源 `org_id` |
| `event_id` | 源 `id` | 源 `id` |
| `event_type` | `FINANCING` | `INVEST` |
| `amount` | `funding_amount` 解析成元。解析不了就空 | `investment_amount` 同样 |
| `event_date` | `completion_date`，空就空 | 空 |
| `etl_batch_id` | 当天批次号 | 当天批次号 |
| `ext` | `funding_round`、`investors_name` | `inv_org_id`、`inv_name`、`created_time` |

## 3. 卡面 `gkxlumenx_ads.svc_org_card`

人口是本批圈定机构。属性从供应方主表读，不把主体拷进圈定池。

| 列 | 来源 |
|----|------|
| `org_id` | 本批圈定 |
| `name_cn`、`province`、`city` | 主表同名列 |
| `area` | 先主表 `area`。没有 `area`、有 `district` 时写入本列 |
| `industry` | 主表 `industry`。没有这列就空 |
| `org_size` | 主表 `org_size`。没有就空 |
| `employees_number`、`operating_revenue` | 年报里该机构 `year` 最大的一行。没有这一行就空 |
| `service_type_candidate` | 圈定池 |
| `pending_client_confirm` | `1` |
| `etl_batch_id` | 当天批次号 |

行业分层、行业代码、经营范围只在 `12` 用来圈定，不新增卡面列。

| 标识 | 表 |
