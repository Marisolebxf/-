# 命名与分层词典（服务机构 GDF）

混名会把供应方机构表配成项目结果表。

## 1. 标准用语

| 说法 | 指什么 | GDF 动作 |
|------|--------|----------|
| 供应方四张表 | `dwd_org_base_info`、`dwd_org_annual_financial_info`、`dwd_org_financing_info`、`dwd_org_invest_info` | 这一趟的**读** |
| `gkxlumenx_dwd.svc_org_circle` | 圈定池 | **写** |
| `gkxlumenx_dwd.svc_org_finance_event` | 投融资事件 | **写** |
| `gkxlumenx_ads.svc_org_card` | 卡面 | **写** |
| `gkxlumenx_ads` 的 `svc_metric_fact` / `svc_metric_series` / `svc_metric_dist` / `svc_region_dist` | 基础指标 | **写** A1–A6 |
| `gkxlumenx_ods` | 本项目贴源 | **不读不写** |
| 库名以 `demo_` 开头 | 中台库 | **不读不写不建表** |
| 供应方 `ods_*` | 供应方内部层 | **不读** |

## 2. 易混名

| 用这个 | 不要当成 |
|--------|----------|
| `svc_org_circle` | 供应方 `dwd_org_base_info` 的整表复制 |
| 卡面上的名称、地区、行业、人数、营收 | 圈定池里的列。圈定池只留机构键和圈定结果 |
| `event_id` = 源表 `id` | `org_id` 加日期再拼一个键 |
| `area` | 从地址文本里拆出来的区县 |
| A1–A6 | `12` 里点名不写的那 9 个标识 |
| 规则号 `svc_rule_demo_kw_v1.1` | 改读另一套库。规则说明文件名仍是 `svc_rule_demo_kw_v1.md` |

## 3. 主键

| 对象 | 键 |
|------|-----|
| 圈定池一行 | `org_id` |
| 事件一行 | `org_id` + `event_id` + `event_type` |
| 卡面一行 | `org_id` |
