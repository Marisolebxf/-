# 技术字段与过滤规则（Wave A）

来源：供应方工作约束（2026-07-17）。全文真源见编排仓  
`agent-delivery/data/third-party-source/gkx-mysql-raw/加工/SUPPLIER-WORK-CONSTRAINTS.md`。

## 1. 取数过滤（默认）

```sql
WHERE is_deleted = 0
```

若某表无 `is_deleted` 列：产线登记例外，启动会与供应方确认等价规则后再灌。

## 2. 六技术字段（不得当业务主字段）

| 字段 | 含义 | Wave A 处理 |
|------|------|-------------|
| `created_time` | 数据创建时间 | 原样镜像 |
| `updated_time` | 最近更新时间 | 原样镜像；可选作增量窗口 |
| `creater` | 新增操作员 | 原样镜像 |
| `updater` | 更新操作员 | 原样镜像 |
| `table_data_source` | 技术来源标记 | 原样镜像 |
| `is_deleted` | 0 未删 / 1 已删 | 过滤后镜像；目标侧建议保留列以便对账 |

## 3. 镜像策略建议

| 项 | 建议（启动会可与 GDF 共定） |
|----|------------------------------|
| DDL | 目标表用源 `SHOW CREATE TABLE` 对齐（库名改为 `gkxlumenx_ods`） |
| 首次 | 全量：TRUNCATE/换表 + 重灌，或空库 CREATE + LOAD |
| 日常 | 可按 `updated_time` 增量；需可证明「源有效行 ≈ 目标有效行」 |
| 主键 | 保持源表主键/唯一键；Wave A 不做 org 归一 |
| 字符集 | `utf8mb4` |

## 4. 禁止

- 写三方 `gkx`  
- 正式产线依赖 `ods_*`  
- 把技术字段映射成业务展示主口径（Wave B 同样遵守，除非产品明确要求）  
- 业务字段未定稿时写死上线契约（供应方声明字段仍可能调整）

## 5. 缺表 / 无权限

- 清单有、查询不到或无权限 → **登记待供应方核验**（表名 + 现象 + 时间），勿自行认定下线。  
- 核验结果回写工作包 CHANGELOG 后再改产线。
