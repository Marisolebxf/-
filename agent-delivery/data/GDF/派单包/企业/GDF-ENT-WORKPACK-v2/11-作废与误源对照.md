## 4. 已建错库时的动作建议

1. 冻结继续按旧 DDL 建新表。  
2. 导出 `information_schema` 与 `10/README` 总览做差集。  
3. 有数据：ALTER 对齐或迁到正确表后 DROP 旧宽表；无数据：DROP 后按 `10/` 重建。  
4. 飞书回写：差集清单 + 迁移说明 + 回签「已停用旧 DDL」。
