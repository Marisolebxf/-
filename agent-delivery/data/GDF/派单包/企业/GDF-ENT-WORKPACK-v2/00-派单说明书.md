## 1. 一句话目标

在 GDF 中台配置产线：

1. **Wave A（贴源）**：只读三方库 `gkx` 中承诺表 → 镜像写入 `gkxlumenx_ods`（同名同结构）  
2. **Wave B（DDL + Mapping）**：按 **`10/`** 对齐 `gkxlumenx_dwd` 表结构 → 按 **`09` v4** 将 `gkxlumenx_ods` 洗入 `enterprise_*` / `risk_*` 等

两阶段同包投递；**执行顺序**仍是 A（至少 P0）验收通过后再跑 B。若库内结构仍是旧 PG/宽表口径，**先按 `10/` 纠偏 DDL，再跑 Mapping**。

## 2. 分层与边界（必须先对齐）

```text
承诺文档：  third-party-source/doc/*.xlsx（企业方向真源）
供应方库：  gkx.<承诺英文表名>（只读）──Wave A──► gkxlumenx_ods.<同名>
本项目：    gkxlumenx_ods ──Wave B Mapping──► gkxlumenx_dwd.enterprise_* / risk_*
DWD DDL：   只认本包 10-DWD-MySQL-DDL/（MySQL 8 · gkxlumenx_dwd）
```

| 做 | 不做 |
|----|------|
| Wave A：按 `02` 清单镜像 40 张表（P0=17 / P1=23） | 读/写供应方 `ods_*` |
| 表名以**承诺英文表名**为准（如 `dwd_org_base_info`） | 用 live 旧名顶替关单（如 `dwd_org_reg_info`） |
| Wave B：按 **`10/` DDL** + **`09` Mapping v4** | 按 v1 / PG 9 表 / Mapping v2/v3 单独施工 |
| 产线调度、失败告警、DDL 对齐重跑 | 改应用代码 / ES / Java API；写三方 `gkx`；用假值填 ❌ 缺口；写 `demo_gkxlumenx_*` |

详见 [01-命名与分层词典.md](01-命名与分层词典.md)。
