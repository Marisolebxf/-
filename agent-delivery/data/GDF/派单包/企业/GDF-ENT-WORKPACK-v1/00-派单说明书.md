## 1. 一句话目标

在 GDF 中台配置产线：

1. **Wave A（贴源）**：只读三方库 `gkx` 中承诺表 → 镜像写入 `gkxlumenx_ods`（同名同结构）  
2. **Wave B（Mapping）**：`gkxlumenx_ods` → 项目自建 `gkxlumenx_dwd.enterprise_*` / `risk_*`（字段级见 **`09`**）

两阶段同包投递；**执行顺序**仍是 A（至少 P0）验收通过后再跑 B。

## 2. 分层与边界（必须先对齐）

```text
承诺文档：  third-party-source/doc/*.xlsx（企业方向真源）
供应方库：  gkx.<承诺英文表名>（只读）──Wave A──► gkxlumenx_ods.<同名>
本项目：    gkxlumenx_ods ──Wave B Mapping──► gkxlumenx_dwd.enterprise_* / risk_*
```

| 做 | 不做 |
|----|------|
| Wave A：按 `02` 清单镜像 40 张表（P0=17 / P1=23） | 读/写供应方 `ods_*` |
| 表名以**承诺英文表名**为准（如 `dwd_org_base_info`） | 用 live 旧名顶替关单（如 `dwd_org_reg_info`） |
| Wave B：按 **`09` Mapping v3** 配置 ETL | 按 Mapping **v2** 或旧 ODS 表名施工 |
| 产线调度、失败告警、DDL 对齐重跑 | 改应用代码 / ES / Java API；写三方 `gkx`；用假值填 ❌ 缺口 |

详见 [01-命名与分层词典.md](01-命名与分层词典.md)。

## 4. GDF 交付物

### Wave A

1. 产线名称、调度周期、失败告警对接人  
2. 已上线表清单（须为承诺表名）+ 每表最近成功批次时间

4. 源表缺名/无权限时的供应方核验登记  
5. 结构变更时的 DDL 对齐与重跑说明  

### Wave B（Mapping）

1. 按 `09` 配置的字段级 Mapping（截图或作业清单）  
2. ETL 作业 + 依赖顺序（`09` §0）+ 失败可重跑  
3. 单位换算 / 枚举 / org 归一说明  
4. 每张 DWD 目标表 ≥20 条抽样对账  
5. 贴源 DDL 与 `09` 列名差异回写本侧
