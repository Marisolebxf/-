# 命名与分层词典（政策 GDF）— v2.0

> 用语继承 v1。供应方 `gkx.dwd_*` 是本项目 ODS，不是项目 DWD。

> 混名会配错源/目标。

## 1. 标准用语

| 说法 | 指什么 | GDF 动作 |
|------|--------|----------|
| 贴源 DDL | `storage/POLICY/sources/ods-ddl.md` | Wave A 列结构真源 |
| 供应方表 | `gkx.dwd_policy_base` / `gkx.dwd_global_policy_base` | Wave A **源**（角色=本项目 ODS） |
| 供应方 `ods_*` | 供应方内部层 | **不读** |
| `gkxlumenx_ods` | 本项目贴源 | Wave A **目标**（同名镜像） |
| `gkxlumenx_dwd.policy_base_info` | 项目政策主表（唯一） | Wave B **目标** |
| Demo `demo_gkxlumenx_*` | 联调模拟 | **禁止**当正式目标 |
| Demo `ods_sync` | `polan/ods_sync.py` | **禁止**当产线 DAG |

## 2. 易混名

| 承诺名（用这个） | 错误替代 |
|------------------|----------|
| `dwd_policy_base` | `dwd_zck_*` / 旧 37 列宽表 |
| `dwd_global_policy_base` | 另建国际 DWD 主表 |
| `policy_id` = ODS `id` | 哈希 / `pol:{id}`（那是图 VID，本包不写图） |
| `source_plane` = `domestic` / `global` | 用 `source` 文案冒充分平面 |
| `rank`（国家级/省级原文） | 旧 smallint `level` / docstatus 20/30 |
| `policy_type`（展示类别原文） | Demo `ext1` 临时代码列当产线正名 |

## 3. 主键

| 对象 | 键 |
|------|-----|
| 项目 DWD 一行 | UK **永远** `(source_plane, policy_id)`（MAP-01 已关） |
| `policy_id` | ODS `id` 原文（≤100） |
| 图 VID `pol:{id}` | **本包不写**；超长截断策略不在本叶 |
