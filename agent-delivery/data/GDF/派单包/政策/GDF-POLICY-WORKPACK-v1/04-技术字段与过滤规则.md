# 技术字段与过滤规则（Wave A）

来源：供应方工作约束。全文：`agent-delivery/data/third-party-source/gkx-mysql-raw/加工/SUPPLIER-WORK-CONSTRAINTS.md`。  
政策另有 `is_history`（`sources/ods-ddl.md`）。

## 1. 取数过滤（默认）

```sql
WHERE is_deleted = 0
  AND IFNULL(is_history, 0) = 0
```

无 `is_deleted` 列：登记例外，启动会确认后再灌。  
`is_history`：`0` 当前 / `1` 历史；`NULL` 按当前纳入（`IFNULL`）。

## 2. 六技术字段（不得当业务主字段）

`created_time` / `updated_time` / `creater` / `updater` / `table_data_source` / `is_deleted`：Wave A 原样镜像。

政策另有 `operator_remarks` / `insert_remark` / `is_history`：贴源原样保留；**不**映射为业务口径。

## 3. 镜像策略

目标表用源 `SHOW CREATE TABLE` 对齐（库名改为 `gkxlumenx_ods`）。首次全量。Wave A **不做**字段改名、**不做**平面切片（`source_plane` 在 Wave B 派生）。

`dwd_policy_base.content` / `dwd_global_policy_base.content` 为 `longtext`，国内合计约百 MB 级：必须流式/分批提交，禁止整表缓冲后一次 commit。禁止截断正文。
