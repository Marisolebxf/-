## 2. 一句话目标

1. **Wave A**：`gkx` 的六张宏观要素库表 → `gkxlumenx_ods` 同名镜像。  
2. **Wave B**：按 **09** 把六表洗进 `gkxlumenx_dwd` 的六张 `macro_*`；事实表带区划反解派生列（`area_resolve` / `city_code` / `city_name` / `province_code`）。  
3. **②a**：事实表 Wave B 成功后，用 `12` 的 SQL 灌 `gkxlumenx_ads.macro_city_section`（城市 × 指标 × 计算维度 × 时间维度 的最新一期截面），供展示 / 专题只读。  
4. **②b（附录）**：落地实效城市卡用的结果面代理口径说明。不进作业，不进字段矩阵。
