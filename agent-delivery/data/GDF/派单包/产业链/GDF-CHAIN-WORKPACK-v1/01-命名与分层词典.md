# 命名与分层词典（产业链 GDF）— v1.0

> 混名会配错源/目标。

## 1. 标准用语

| 说法 | 指什么 | GDF 动作 |
|------|--------|----------|
| 承诺表 | `third-party-source/doc` 产业链要素库 Sheet | Wave A 表名真源 |
| 供应方表 | `gkx.dwd_*` | Wave A **源**（角色=ODS） |
| 供应方 `ods_*` | 供应方内部层 | **不读** |
| `gkxlumenx_ods` | 本项目贴源 | Wave A **目标** |
| `gkxlumenx_dwd.industry_chain_*` | 项目 DWD v5 | Wave B **目标** |
| `industry_analysis_*` | 行业分析六表 | **本期不写** 项目 DWD |
| Demo `demo_gkxlumenx_*` | 联调模拟 | **禁止**当正式目标 |

## 2. 易混名

| 承诺名（用这个） | 错误替代 |
|------------------|----------|
| `dwd_org_industry_tags` | `dwd_org_industry_chain_dtl`（未承诺检出） |
| `industry_chain` 等无 `dwd_` 前缀 | 把 ODS 四表去前缀当 DWD |
| `entity_id` = `org_id` | `credit_code` / Demo `p:{credit}:{id}` |
| INB | 资讯 `IC*` 当 `chain_id` |
| 分析六表只贴 ODS | 同构写入 `industry_analysis_*` / 灌 `news_event` |

## 3. 主键

| 对象 | 键 |
|------|-----|
| 链 / 节点 | INB 原文（Q053） |
| 链上企业 | `org_id`（经 `enterprise_code` 对照） |
