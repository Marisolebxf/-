# 技术字段与过滤规则（Wave A）

来源：供应方工作约束。全文：`agent-delivery/data/third-party-source/gkx-mysql-raw/加工/SUPPLIER-WORK-CONSTRAINTS.md`。

## 1. 取数过滤（默认）

```sql
WHERE is_deleted = 0
```

无 `is_deleted` 列：登记例外，启动会确认后再灌。

## 2. 六技术字段（不得当业务主字段）

`created_time` / `updated_time` / `creater` / `updater` / `table_data_source` / `is_deleted`：Wave A 原样镜像。

## 3. 镜像策略

目标表用源 `SHOW CREATE TABLE` 对齐（库名改为 `gkxlumenx_ods`）。首次全量。Wave A **不做** org 归一、**不做** JSON 拆行（拆行在 Wave B）。

`dwd_org_industry_tags.industry_code` / `industry_link_code` 在供应方可能是 JSON 数组或超长 TEXT：贴源保持原样，禁止截断。

## 4. 禁止

写三方 `gkx`；依赖供应方 `ods_*`；把技术字段当业务口径。

## 5. 缺表

清单有、查不到 → 登记待供应方核验，勿自行认定下线。
