企业域数据 ETL 流程图

自上而下：ODS 入站 → DWD 映射 → DQ 门禁 → 算法指标 → 扇出 ADS / ES / 图谱 → 日更报告 → 线上消费。 执行归属仅两种：混合模式 / 三方模式（已废弃全链路我方落地）。 入库：日可多批，须 幂等 upsert + 时间/ID 水位，支持断点重跑与任意补跑不重复。配套文档 v0.5。 ES：别名 gkx_enterprise → gkx_enterprise_v1 + gkx_enterprise_global_v1；搜索读别名，ETL 写物理索引；国内/国外 DWD→ES 独立调度。

我方应用铁律固定

频率与幂等

  • 日可多批，非限一天一次
  • 业务唯一键 upsert，禁止盲插
  • 水位：update_time(+id) 或单调 ID
  • 断点从上次成功水位续跑
  • 任意时间窗补跑结果一致

日变更量（核心）

  • batch_id / 水位起止
  • ODS 推送行数 / 有效行数
  • DWD 新增 / 更新 / 失效
  • 受影响企业数
  • ADS / ES / 图谱同步量
  • ODS→DWD 转化率异常告警

质量报告补充

  • 主键空值 / 唯一键重复
  • 枚举越界、非法日期
  • org_id 参照完整性
  • 软删一致性
  • 时效 / SLA 延迟
  • 跨层抽样对账
  • 拒绝明细（键+原因）

三方时我方交付

  • Mapping 字段说明
  • 或 可执行 SQL
  • 或 Python 脚本
  • + DQ 规则与报告字典

ES 索引口径

  • 别名 gkx_enterprise 只用于搜索/读
  • 物理索引：gkx_enterprise_v1（国内）
  • 物理索引：gkx_enterprise_global_v1（国外）
  • ETL 写物理索引，不用多索引别名写
  • 国内外 DWD→ES 独立调度

命名防串层

  • 供应 dwd_* = 入站 ODS
  • 项目 gkxlumenx_dwd = DWD
