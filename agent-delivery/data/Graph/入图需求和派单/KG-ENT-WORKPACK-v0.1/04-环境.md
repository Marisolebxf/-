# 环境

下表是本包要用的名字和已经定下的值。图库口令和读接口 `X-API-Key` 不在本包里，也不要写进回执。需要时向白鑫凤索取。MySQL 只读口令写在下面。

| 名字 | 值 | 说明 |
|---|---|---|
| `GRAPH_SPACE` | `gkx_chain` | 燕大加工入图的目标空间。本包新建，之前没有这份数据 |
| `GRAPH_SPACE_DEMO` | `demo_gkx_chain` | 智树展示读图空间。禁止写入，禁止把点或边拷到 `gkx_chain` |
| `GRAPH_ADDRESS` | `10.50.75.136:9669` | Nebula graphd。用户名和口令另给 |
| `VID_TYPE` | `FIXED_STRING(80)` | 点 ID 最长 80 |
| `PARTITION_NUM` | `10` | 建空间参数 |
| `REPLICA_FACTOR` | `1` | 建空间参数 |
| `YANDA_READ_BASE` | `http://10.50.183.56:8093` | 燕大已提供的读接口。路径 `/schema`、`/entity-types/{name}/entities`、`/relation-types/{name}/edges`。这是读接口，不是本包的入库空间 |
| 读接口认证头 | `X-Client-Id`、`X-API-Key` | 只写头的名字。值不进本包 |

不要把 `GRAPH_SPACE` 配成 `demo_gkx_chain`、`gkx_local_1` 或 `gkx_full_1`。
