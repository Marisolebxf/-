## 2. 每次分析久新库前必做

1. 跑 `_local/dw-docs/sync.ps1`：拉最新两份文档，打印「本地记录版本 → 远端最新版本」。
2. 版本有变化 → 先读 `ADS_SCHEMA_RELEASE_NOTES.md` 新增段落，再更新 `DIFF-*.md`，不得按旧口径直接分析。
3. 有密码环境 → 跑 `library-check.sql` 核对表存在与行数；无密码 → 结论中如实标注「库侧未实测」。
4. 结论必须区分：`文档有 + 库有` / `文档有 + 库未验` / `文档有 + 库无`。
