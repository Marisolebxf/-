## 1. 页面 ↔ 接口映射

| 页面/组件 | 需规功能 | 接口 | 说明 |
|---|---|---|---|

| ├ 热力图模式 | 热力图 | `GET /events/heatmap` | weight 直接喂热力图层 |
| ├ 时间筛选条 | 日/周/月/季/年 + 滑动条 + 对比 | `GET /events/stats` | 前端把粒度换算成 startTime/endTime |

| ├ 关联分析面板 | 事件-事件/机构/人员关联 | `GET /events/{id}/relations` | relType 分组展示 |
| └ 导出/分享 | — | `POST /events/{id}/export·share` | — |
| 创新点落图页 | 图谱可视化 + 节点影响分 | `GET /graph/domains`、`/graph/subgraph`、`/graph/nodes/{id}/influence` | 节点大小绑定 influenceScore；点击节点出分项贡献雷达 |
| 影响分排行页 | 排名列表 | `GET /graph/influence/rank` | — |
| 载体排行页 | 总体/领域/地区三 Tab + 筛选 | `GET /carriers/rank`、`/dict/regions` | dimension 切 Tab |

| └ 载体对比 | 2–5 个对比 | `GET /carriers/compare` | — |
| 城市评估页 | 排名 + 详情 + 对标雷达 + 建议 | `GET /cities/*` 系列 | 对标雷达用 subScores 四维；advice 渲染 Markdown |

| 订阅中心 | 订阅/推送历史/监测模型 | `/subscriptions`、`/push/history`、`/monitor-models` | — |

## 2. 关键数据格式约定

### 2.1 地图点位 = 标准 GeoJSON
`/events?mode=geo` 返回 FeatureCollection（结构见 03 文档 §1.1），可直接作为 MapboxGL/高德 Loca/SuperMap 的数据源。**前端必须传 bbox + 当前缩放级**，服务端在低缩放级返回聚合点（properties 带 `cluster:true, count:n`）。

### 2.2 图谱数据
`/graph/subgraph` 的 nodes/edges 结构兼容 AntV G6 / ECharts graph，直接映射：`nodeId→id, name→label, influenceScore→size 比例尺, edgeType→边样式`。

### 2.3 趋势+置信区间（ECharts 示例）
```
series: [
  { name:'历史', type:'line', data: history },
  { name:'预测', type:'line', lineStyle:{type:'dashed'}, data: predict },
  { name:'区间', type:'line', data: ciUpper, stack:'ci', symbol:'none', lineStyle:{opacity:0} },
  { name:'区间', type:'line', data: ciLowerDiff, stack:'ci', areaStyle:{opacity:.15}, symbol:'none' }
]
```

### 2.4 枚举与样式绑定
事件类型颜色、重要性大小、领域树**一律取字典接口**，前端不得写死（事件类型后续可能扩展）。

## 3. 交互注意点

- 时间轴滑动条：拖动中节流 500ms 再请求；
- 重要性"实时更新"：地图页轮询 `/meta/data-status`，事件表更新时间变化才刷新（避免无效轮询）；
- 排行页 period 切换：用 data-status 给出的可用快照期列表渲染下拉；
- 所有金额展示用 `amount + currency` 格式化，不要默认人民币。
