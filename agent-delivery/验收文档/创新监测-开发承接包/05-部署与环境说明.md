## 1. 部署拓扑

```
                 ┌──────────────┐
   用户 ──────→ │  Nginx / 网关  │──→ 前端静态资源
                 └──────┬───────┘
                        ▼
                 ┌──────────────┐     ┌─────────────┐
                 │ Java 服务集群  │──→ │ Redis(缓存)  │
                 │ (innov-api)   │──→ │ ES(事件检索) │
                 └──────┬───────┘     └─────────────┘
                   只读  ▼
                 ┌─────────────────────────────┐
                 │ MySQL: innov_dim/dwd/dwm/    │
                 │        ads/cfg + app_user    │
                 └──────▲──────────────────────┘
                   写入  │
┌────────────────────────┴───────────────────┐
│ Python 批处理集群 (innov-algo)                │
│  调度器(Airflow) + Worker                     │

```

## 2. 模型服务（两档差异点）

| | B 档（默认起步） | A 档（算力到位） |
|---|---|---|
| 硬件 | 1–2 张 T4 / A10 / 4090 | 4–8 卡（A800/H20/H200），9B–32B 级 4 卡性价比最优 |
| 服务化 | BERT/UIE/embedding 模型 → ONNX/TorchServe 或 FastAPI+批推理；CPU 兜底可行 | GLM 私有化 → SGLang/vLLM，OpenAI 兼容 endpoint |
| LLM 用途 | 智谱 API（蒸馏标注/低置信复核/月度润色），月预算数千元级 | 在线全量加工 + RAG 报告 |
| 切换方式 | `conf/settings.yaml: engine: bert` | `engine: llm`（或 hybrid），模型版本登记 `cfg_model_registry` 后灰度 |

> A 档吞吐参考：按 1 万篇资讯/天、单篇 3K 输入+0.5K 输出 ≈ 0.35 亿 token/天；离线批处理走夜间错峰，避免与在线对话业务抢占（参见 Token/ 目录 H200 压测系列报告）。

## 3. 中间件清单与规格建议

| 组件 | 用途 | 起步规格 |
|---|---|---|
| MySQL 8.0 | 契约面主库 | 8C32G，ads 库读写分离可后置 |
| Redis | API 缓存（geo/heatmap/排行） | 4G |
| Elasticsearch 8.x | 事件关键词检索（Python 同步写 `idx_innov_event`，字段=ads 事件表子集） | 3 节点或单节点起步 |
| Neo4j 5.x + GDS | 图谱运行时（PPR/中心性） | 16C64G；S4 前可用 networkx 单机过渡 |
| Milvus / pgvector | 机构别名向量、资讯去重向量 | 单机起步，pgvector 更省运维 |
| Airflow | 调度（日批/小时批/月批） | 单机 LocalExecutor 起步 |
| MinIO（可选） | 模型文件、报告附件 | — |

## 4. 环境与配置管理

- 环境：dev / test / prod 三套；ODS 只读账号由数据组发放，**dev 环境使用脱敏抽样库**；
- 配置：Java 用 Nacos/Apollo（或 Spring profile），Python 用 `conf/settings.yaml` + 环境变量覆盖（DB 密码等不入库）；
- 关键运行时配置均落 `innov_cfg` 表（降级开关、权重、模型版本），改库即生效，发布不重启；
- 版本：三仓独立发版，契约变更（01/03 文档）必须先发文档 PR 评审再动代码。

## 5. 监控与告警（最低集）

| 对象 | 指标 | 告警 |
|---|---|---|
| 流水线 | 各 DAG 任务成功率、延迟、处理量、水位滞后 | 失败/水位滞后 >2h |
| 数据质量 | ads 事件日增量异常（±3σ）、geo 缺失率、置信度分布漂移 | 钉钉/邮件 |
| API | P95 延迟、错误率、5001 数据未就绪次数 | — |
| 模型服务 | QPS、显存、队列深度（A 档）；复核队列积压（B 档） | 积压 >1 天处理量 |
