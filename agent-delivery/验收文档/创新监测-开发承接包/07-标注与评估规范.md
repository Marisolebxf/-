# 07 · 标注与评估规范

> **读者**：算法团队、标注协作人员、验收方
> **适用**：方案 B 的训练数据生产、双轨两方案的统一评测与验收。

## 1. 事件类型标注手册（分类任务）

### 1.1 类型定义与边界（12 类，与 dim_event_type 一致）

| 类型 | 定义 | 边界案例裁决 |
|---|---|---|
| tech_break 技术突破 | 新技术/新工艺/性能纪录/重大研发进展 | 与 achievement 区分：未形成论文/专利载体的进展归此类 |
| achievement 成果发布 | 论文发表、专利授权、软著、新产品发布 | 产品商业发布会归 biz_dynamic |
| financing 融资 | 获得投资（轮次/金额） | 投资方视角的"对外投资"归 invest |
| invest 投资 | 主体对外投资 | — |
| ma 并购 | 收购、合并、控股变更 | 仅股权小比例变动归 biz_dynamic |
| bid 招投标 | 中标、采购公告 | — |
| biz_dynamic 企业动态 | 设立/迁址/更名/合作签约/产线投产 | 兜底类，优先归其他类 |
| policy 政策发布 | 政策、法规、规划、专项申报通知 | — |
| fund_project 基金课题 | 基金立项、课题获批、揭榜挂帅 | 与 policy 区分：面向具体主体的立项归此类 |
| talent_flow 人才流动 | 高管/学者任职变动、团队加盟、人才引进 | 招聘启事不算事件（噪声类） |
| award 奖项荣誉 | 获奖、资质认定、榜单入选 | — |
| industry_event 行业事件 | 会议、展会、竞赛、联盟成立 | — |
| **OTHER/噪声** | 非科创相关、广告、纯行情 | 标注为负样本，参与训练 |

### 1.2 标注规则

- 单标签优先：按"信息主旨"取唯一类型；确实双主旨（如"融资并发布新产品"）允许双标签，主标签在前；
- 标注单位：去重后的事件（同事多稿只标一条代表稿）；
- 每条记录：`{text_id, label_main, label_second?, importance_human(1/2/3), 备注}`——重要性人工分级同步采集，供 P4 验收用。

## 2. 槽位抽取标注（按事件类型 schema）

每类事件的 schema 与 `conf/event_schema/` 一致，示例（financing）：

| 槽位 | 说明 | 必填 |
|---|---|---|
| org_main | 融资主体（原文片段+标准名） | 是 |
| round | 轮次 | 否 |
| amount / currency | 金额数值化（"5亿元"→500000000/CNY；"数千万"→区间中值并记 approx） | 否 |
| investors[] | 投资方列表 | 否 |
| event_date | 事件时间（相对时间"昨日"按发文日换算） | 否 |
| location | 事发地（如有） | 否 |

通用规则：槽位取原文最短完整片段；标准化值另列；无法确定填 `UNK` 不要猜。

## 3. 蒸馏标注流程（LLM 辅助，S3-1）

```
① 分层抽样 2–5 万条历史资讯（按来源/长度/时间分布分层）
② LLM API 批量标注（分类+槽位，JSON Schema 约束输出）
③ 一致性自检：同一条两次温度采样不一致 → 进人工队列
④ 人工抽检 20%（双人背靠背，Kappa≥0.8 方可放量；不足则修订手册重训标注员）
⑤ 产出训练集 v1：train/dev/test = 8/1/1，test 集 100% 人工核验（黄金集，永不参训）
⑥ 上线后低置信复核样本持续回流 → 每月增量重训，黄金集滚动扩充
```

## 4. 评测与验收口径

### 4.1 能力级指标（黄金集上测）

| 能力 | 指标 | 方案 B 验收线 | 方案 A 验收线 |
|---|---|---|---|
| 事件分类 | Macro-F1（12 类+噪声） | ≥0.88 | ≥0.92 |
| 槽位抽取 | Slot-F1（严格匹配） | ≥0.85 | ≥0.90 |
| 去重聚合 | pair 级 P/R | P≥0.95 / R≥0.85 | 同左 |
| 机构 ID 贯通 | 合并对准确率（抽检1000对） | ≥0.98 | 同左 |
| 实体链接/落图 | 链接准确率（链接成功口径）；拒识率另报 | ≥0.88 | ≥0.92 |
| 地理落点 | 城市级准确率 | ≥0.95 | 同左 |
| 重要性分级 | 与人工三级一致率；高级别召回 | ≥0.80；高召回≥0.85 | ≥0.85 |
| 趋势预测 | 年度领域指数 MAPE（留出最后2年回测） | ≤15% | 同左 |
| 突变检测 | 历史已知颠覆性技术案例集命中率（人工构造20例） | ≥0.7 | 同左 |

### 4.2 系统级指标

| 项 | 口径 | 标准 |
|---|---|---|
| 时效 | 资讯入 ODS → ads 事件可见 | ≤1 小时 |
| 吞吐 | 日处理资讯量 | ≥5 万篇/天（B 档 1 卡） |
| API | geo/heatmap P95 | ≤500ms |
| 稳定性 | 日批 DAG 月度成功率 | ≥99% |
| 可解释 | 重要性/指数/赋分必须有分项明细（detail JSON 非空率） | 100% |

### 4.3 双轨回归对比（切换演练用，S5-5）

- 固定回归集（黄金集 + 近一月线上抽样 2000 条），bert/llm 双引擎各跑一遍；
- 对比报告：逐能力指标差异、分歧样本清单、成本（token/GPU 时）对比；
- 切换准入：llm 引擎在全部能力上不劣于 bert 引擎 2pt 以上，且时效达标。

## 5. 数据质量巡检（线上持续）

| 巡检项 | 频率 | 阈值 |
|---|---|---|
| 事件日增量 | 日 | 偏离 30 日均值 ±3σ 告警 |
| 分类置信度分布 | 周 | 均值下漂 >0.05 触发重训评估 |
| geo 缺失率 / UNK 槽位率 | 周 | 环比上升 >5pt 告警 |
| 复核队列积压 | 日 | >1 天处理量告警 |
| 黄金集线上重测 | 月 | 任一能力跌破验收线 → 冻结发版排查 |
