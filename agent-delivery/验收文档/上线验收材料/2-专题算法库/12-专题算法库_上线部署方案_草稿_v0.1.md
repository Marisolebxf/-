## 1. 概述

### 1.1 上线目标

将**专题算法库**（正式仓以 `lumen-algo-py`、`lumen-etl-es-py` 为主；联调台 `lumen-ui-algo-apiview` 按需）部署到**算力云生产环境**，供科技专题服务系统（及共享聚合核心）经 Java → Python `/internal/*` 调用。与现网开发环境隔离；生产 CI/CD **仅灵雀云**。

> 架构铁律：算法只在 Python；Java 禁 NLP/图谱算法/推理。展示与专题共享算法库，不各造一套。

### 1.2 影响范围

| 范围 | 说明 |
|---|---|
| 运行面 | `lumen-platform-algo-py` / worker、entan/innov 等按生产开通子集；ETL-ES |
| 调用方 | `gkxlumen-topic*`、`gkxlumen-metrics`、异步编排等（经网关/Java） |
| 数据 | ADS、ES、Milvus、对象存储分析目录、TRSGraph（只读/约定写路径） |
| 不在本单 | 合规锁定算法闭包篡改（D17）；demo-* 服务（D12 禁 lumen 调用） |

## 2. 上线准备

### 2.1 职责

| 角色 | 建议 | 职责 |

| 总协调 | 淮政玮 | 与专题方案对齐、材料齐套 |

### 2.2 环境（隔离）

| 项 | 生产 |
|---|---|
| 构建 | **灵雀云** Pipeline · 禁 gitlab-runner |
| 镜像 | Harbor `zp-tts` |
| 运行 | 灵雀云工作区 `zhipu-tts` |
| 向量 | Milvus `milvus-proxy.zhipu-infra.svc.cluster.local:19530` |
| 对象存储 | `obs.cc.cs` · `gkx-lumen/gkx-analysis-results` 等；`milvus` 桶业务不写 |
| LLM | 生产 Secret（如统一 Zhipu LLM）· 键名对齐现网规约，**值隔离** |

对照表见环境留档；现网 `cicd-pipeline.md` / `10.50.69.111` **不得**写入生产配置。

### 2.3 上线前检查

- [ ] 生产流水线构建 `lumen-algo-py` api/worker（及开通的 innov/entan）成功
- [ ] Java 侧生产 `python-base-url` / K8s Service DNS 指向生产算法
- [ ] 无 demo-* Feign / 环境变量
- [ ] Milvus / ES / ADS 账号为生产只读或约定权限
- [ ] 合规算法包与「合理」副本边界清晰（D17）

## 3. 实施部署验证

### 3.1 架构

```
Java gkxlumen-*  --/internal/*-->  Python algo Deployment(s)
                                   ├─ ADS / ES
                                   ├─ Milvus
                                   ├─ S3 gkx-analysis-results
                                   └─ TRSGraph（按模块）
```

联调台 UI（若上生产）：仅运维/算法人员；不替代用户专题前端。

### 3.2 部署顺序

1. 中间件（Milvus/ES/S3/Redis 按需）
2. Secret（LLM、库连接）
3. `lumen-algo-py` api → worker
4. 按需 innov/entan/etl-es
5. Java 指向切换与冒烟（选 2～3 个 `/internal` 或经 Java 的专题分析任务）
6. 回滚演练：切回上一 digest

### 3.3 运行服务清单（草稿）

| 工作负载 | 镜像来源仓 | 生产开通 |
|---|---|---|
| algo-py api | lumen-algo-py | 是 |
| algo-py worker | lumen-algo-py | 按异步需要 |
| entan-py / innov-py | lumen-algo-py 制品 | **TBD** 按专题依赖 |
| etl-es-py | lumen-etl-es-py | **TBD** |
| algo-apiview | lumen-ui-algo-apiview | 可选 |

### 3.4 发布策略与回滚

- 灵雀云构建 → Harbor tag → 滚动更新
- 回滚：上一 digest；长任务/worker 注意排空
- 配置变更：环境变量 / Secret 与 Nacos（若有）分单发布

### 3.5 验证

| 项 | 标准 |
|---|---|
| 健康 | `/health` 或探针 Ready |
| 链路 | 经 Java 触发一次分析/指标计算，trace 可查 |
| 隔离 | 日志与数据无现网库地址 |
| 合规 | 锁定路由未被误替换 |
