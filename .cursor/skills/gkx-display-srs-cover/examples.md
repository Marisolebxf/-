# 用法示例

## 例 1 · 二级整表

用户：`需规分句闭合：政策重点比对`

1. 解析 → DS-10 · 213–218 · POL-L2-DS10-CMP  
2. 只读拆分句、对原型/ARCH/ComparisonModal live/用例  
3. 发现 214 图表与优缺点仅 mock → G2；「热力图」若另有歧义 → G5  
4. 有 G5 或双方案 → `SwitchMode` plan + 决策卡  
5. 人选后出一屏计划；「按此计划开始」再进 FDE/bugfix  

## 例 2 · 一级页需人选二级

用户：`形态覆盖：科创政策全景`

1. 列出 QRY / TREND / SENT / CMP  
2. 切 Plan（或一问）请人选先跑哪些  
3. 按所选二级各出一张矩阵（可同会话连续）  

## 例 3 · 单叶

用户：`对照需规：214 详情对比`

1. 只扫 214（可附带 207 优缺点分句是否挂本叶的决策卡）  
2. 矩阵一行集中在表格/图表/优缺点  

## 例 4 · 只归档

用户看完矩阵说：`本次只归档矩阵`

1. 写简报到 `sdd/简报/{日期}-政策重点比对-需规分句闭合.md`  
2. 聊天里用可点链接交付（见 SKILL §9）：`[{文件名}](file:///{GKX_ROOT 正斜杠绝对路径}/...)`  
3. 不建单、不改代码
