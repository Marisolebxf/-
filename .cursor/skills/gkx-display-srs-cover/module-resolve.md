# 展示系统功能模块解析

把用户口头的「功能模块」解析成可审计的 SRS 叶子集合。解析失败就列候选停问，不猜全库。

## 粒度

| 用户粒度 | 审计范围 |
|---|---|
| 二级 level5（推荐） | 该二级全部序号，一张矩阵 |
| 一级页（如科创政策全景） | 下列出全部二级，请人选「先跑哪些」；未选不整页开扫 |
| 单序号 / 序号区间 | 只扫这些叶子 |
| DS 码（DS-10） | 等同一级：列二级请人选 |

## 路径约定

- 需规根：`agent-delivery/bid-reference/srs/02-科技信息展示系统/`
- 合规用例：`agent-delivery/工程过程/04-系统集成/05-展示系统集成/合规演示用例/`
- 政策跟踪二级索引：同维 `WBS.md` §4.1c 表（一级×二级×序号×四单前缀）
- 其它域：先查该域 `WBS.md` / 用例索引；没有二级表则按 SRS 目录文件名 + `### … · 序号 N` 标题拆

## 前端 / 原型落点（政策全景示例）

| 二级 | lumen 大致路径 | demo 大致路径 |

## 歧义处理

1. 「科创政策全景」→ 列出 QRY / TREND / SENT / CMP 四个二级请人选。
2. 「对比」→ 可能是 DS-10 重点比对，也可能是 PC-3 多维政策对比；两个都列。
3. 同名「结果智能输出」出现在 PC-3 与 PC-4 → 用序号或一级名消歧。
