# 演示样本满足循环

先读 `agent-delivery/产品实现规程.md` §6.4 和 §6.5，再动手。同目录 [演示样本满足任务LOOP.md](演示样本满足任务LOOP.md) 只指向这两节。Codex 指针：`.codex/skills/gkx-demo-sample-loop/SKILL.md`。

本循环建单或改状态后，注册表留在本地，不立刻拉取、不立刻推送。

## 何时用

用户要把展示系统某个功能模块的演示样本，反复对到该模块《合规演示用例》里可演行的预期。范围是展示系统。专题系统另点名后才用本技能。SDD、用例、循环都在 `agent-delivery/产品实现规程.md` §4.1、§6.4、§6.5。

## 立刻停

- 用户还在讨论流程，没有说「按 LOOP 跑」或等价的执行口令：只解释，不建单，不改库，不改代码。
- 没有该模块的《合规演示用例》，或覆盖表仍有需规空行：不编预期，不建单。
- 探测 401、424 或 404：通知 human:监管人，验收单 `blocked`，不建子任务，不再开一轮。

## 收尾

一轮结束前，把结果写回该模块 LOOP 计划开头的状态行。通过、阻塞、交给人、子任务签收都要写。只改状态行，不改通过线和派单表。没回写就不算收尾。

样本满足、本轮子任务都已签收或本轮没有子任务、状态行已回写之后，验收单改为 `done`，操作人 `human:淮政玮`。没收尾不改 `done`。已 `done` 的验收单不改回 `ready`，下一轮另建。写法在规程 §6.5。
