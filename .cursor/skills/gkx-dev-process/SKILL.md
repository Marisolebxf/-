# 系统集成过程（gkx-dev-process）

真源：[系统集成整体过程规约.md](../../../agent-delivery/系统集成整体过程规约.md) §7.1、§8、§10、§11。打分表和 Excel 列在 [reference.md](reference.md)。Codex 指针：`.codex/skills/gkx-dev-process/SKILL.md`。

## 何时用

| 用户说 | 模式 |
|---|---|
| 按系统集成整体过程规约建档：{维度} | 建档 |
| 记一笔 / 记约定时点 / 追加流水、纪要、风险 | 记一笔 |
| 今日快照 | 今日快照 |
| 今天到哪了 / 查对接：{维度} | 查询 |
| 导出领导简报 | 领导简报 |

没说上表里的口令，就不写 `当日进展/`、`领导简报/`、各维 `进度.md`，也不改 README 顶部「当前」。

## 始终不做

- 不 `task-create`，不把方案任务改成 `done`，不 `task-update-status`
- 不读 `agent-delivery/task-registry.yaml`，不读指标 seed
- 不改第 2 至第 7 项 `WBS.md` 的行，不改自研 WBS 原文
- 不用口令里的百分数参与打分或汇总
- 不把各行百分比收成一个人的完成率
- 不编截止日期、开始时间、指标条数、风险系数、扣分、扣款、人天
- 不把智树内部出门日写成完成日期要求或对端承诺
- 不改 scope-baseline
- 不回写飞书

任务只用 MCP `task-registry` 的 `task-get`（已知 ID）或 `task-query`（按监管人、epic，不拉全表）。先看工具 schema 再调。

## 建档

仅当 PM 点名的维度目录还不存在。现有 `02`～`07` 不重建、不覆盖。

1. 在 `agent-delivery/工程过程/04-系统集成/{编号}-{维度名}/` 按 [reference.md](reference.md) 的空模板建文件。
2. 在该夹 `INDEX.md` 登记一行：名称、对端、智树角色、方案任务名、阶段「建档」、主文件链接。
3. 不建 registry 任务。

## 记一笔

只追加用户给出的原话，不代写。

| 内容 | 文件 | 谁 |
|---|---|---|
| 流水 | 该维 `沟通流水.md` | PM、参会人、监管人 |
| 纪要 | `纪要/YYYY-MM-DD-题目.md` | PM |
| 风险事实 | `风险.md` | PM；监管人可追加事实 |
| 约定时点、对端文档 | `约定时点.md`、`对接文档/对端/` | 只 PM |

约定时点里，智树内部需要日单独成节。一条流水含日期、谁、何事、指向哪份纪要或文档。

## 今日快照

PM 说「今日快照」才跑。步骤见 [reference.md](reference.md)。

1. 用 MCP 按监管人读第 2 至第 7 项 WBS 里已有任务号。不读注册表全文进回答。
2. 按 §7.1 给每一行打设计分或开发分，再算每个一级工作包、每个维度的设计进度、开发进度、整体百分比。
3. 收集当天已经落在流水或本轮口令里的原话。口令里的百分数只留在「当日进展」单元格，不进三个数。
4. 覆盖写 `agent-delivery/工程过程/当日进展/YYYY-MM-DD.md`。同一天只留这一份。
5. 把同一组数追加到该维 `进度.md`（不覆盖旧日），只刷新该维 `README.md` 顶部「当前」。
6. 另写 `agent-delivery/工程过程/当日进展/WBS汇总-YYYY-MM-DD.xlsx`。表内是本端实现任务，不含定义轨。没有挂上第 2–7 项草案号的，工作项归进「自研模块」，并且只写在第一个 sheet。列、分 sheet 和合并见 [reference.md](reference.md)。不覆盖 `04-系统集成/WBS汇总-2026-10-22.xlsx`。八列表和 §7.1 百分比仍只算第 2 至第 7 项 WBS 行。

阻塞只抄口令里的「阻塞：…」。抄进去的同时在该维 `风险.md` 追加一条。没有这句就不标红。

当天没有口令：当日进展写「今日未报」，状态仍按任务状态，不另造红。

## 查询

只读，不写文件。

- 「今天到哪了」：读 `工程过程/当日进展/` 最新一份，按负责人复述八列。没有文件就说还没跑快照。
- 「查对接：{维度}」：先 `04-系统集成/INDEX.md`，再该维 README、进度顶部、流水最近一条、风险、约定时点；任务号用 `task-get`。回答带出技术方案、我方对接文档、对端对接文档的路径。某一份没有就说还没有。
- 「领导简报」：读 `工程过程/领导简报/` 最新一份。没有就说还没导出。

## 领导简报

PM 说「导出领导简报」才写。与今日快照同一套打分，范围加上第 1 项自研 WBS。

1. 读 `01-自研模块WBS.md` 的实现行（排除对照不进表）和第 2 至第 7 项各 `WBS.md`。
2. 行内任务号用 `task-get`。第 1 项也用 §7.1（设计 30% + 开发 70%）。
3. 写 `agent-delivery/工程过程/领导简报/YYYY-MM-DD.md`，文首标「草稿，未发」。七项各一段：这一项是什么、设计进度、开发进度、整体百分比、阻塞行数、尚未建任务的行数。对不上的写「待 PM 补」。
4. 写 `agent-delivery/工程过程/领导简报/WBS与完成情况-YYYY-MM-DD.xlsx`。列与当日 WBS 汇总相同，自研模块同样在第一个 sheet。只收本端实现任务、不含定义轨。详见 [reference.md](reference.md)。
5. PM 当次没说「本周进度：按计划 / 超前 / 滞后」，文首不勾这三项。不写扣分、扣款、人天，不抄讨论稿附录里的样例原句。

对人只报：两份路径、七项整体百分比、阻塞行数、无截至时间的行数。不把百分比说成已完成交付。
